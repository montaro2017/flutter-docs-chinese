Flutter API 参考文档

Flutter 是 Google 的 SDK，可通过一套代码库为移动端、网页和桌面构建美观、快速的用户体验。Flutter 可以与现有代码协作，供世界各地的开发者和组织使用，并且免费、开源。

本 API 参考文档涵盖 Flutter SDK 导出的所有库。

导入库

框架库

下方“库”部分或左侧导航中的库属于 Flutter 框架核心，可以使用 'package:flutter/<library>.dart' 导入，例如：

import 'package:flutter/material.dart';
import 'package:flutter/services.dart';

Dart 库

“Dart”部分的库位于 dart: 命名空间中，可以使用 'dart:<library>' 导入，例如：

import 'dart:async';
import 'dart:ui';

除了 'dart:core'，使用 Dart 库前都必须先导入它。

配套库

其他部分中的库是随 Flutter 一同提供的配套库。它们按包组织，可以使用 'package:<package>/<library>.dart' 导入，例如：

import 'package:flutter_test/flutter_test.dart';
import 'package:file/local.dart';

pub.dev 上的包

Flutter 拥有丰富的包生态系统，Flutter 团队和广大开源社区将这些包贡献到一个集中仓库中。在数以千计的包中，你可以找到 Firebase、Google Fonts、蓝牙和摄像头等硬件服务的支持，新的 widget 和动画，以及与其他常用网络服务的集成。可以在 pub.dev 浏览这些包。
