Cam16

Cam16 类

CAM16 是一种色彩外观模型。颜色不仅由其十六进制代码定义，还取决于观察条件。

CAM16 实例还具有 CAM16-UCS 色彩空间中的坐标，称为 J*、a*、b*，在代码中分别写作 jstar、astar、bstar。CAM16-UCS 属于 CAM16 规范的一部分，测量颜色之间的距离时应使用它。

在传统色彩空间中，颜色仅由观察者对该颜色的测量结果确定。CAM16 等色彩外观模型还会使用颜色被观察时环境的信息，这些信息称为观察条件。

例如，按照传统假设，正午阳光的白点在 CAM16 的准确测量结果中会呈现为略带色度的蓝色（大约为色相 203、色度 3、亮度 100）。

构造函数

Cam16(double hue, double chroma, double j, double q, double m, double s, double jstar, double astar, double bstar)
CAM16 的所有维度都可以通过以下组合中的 3 个维度计算得出： - {j 或 q}、{c、m 或 s} 以及色相 - jstar、astar、bstar 建议使用根据其中 3 个维度构造对象的静态方法。此构造函数供这些方法调用，以返回所有可能的维度。
