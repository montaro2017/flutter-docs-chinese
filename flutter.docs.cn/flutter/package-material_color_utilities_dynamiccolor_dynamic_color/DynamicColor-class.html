DynamicColor

DynamicColor 类

一种会根据 DynamicScheme 提供的界面状态自动调整的颜色。

此颜色会自动调整，以满足所需的对比度级别；也可根据浅色模式或深色模式、主题类型、生成主题的颜色等情况作相应调整。

没有背景色的颜色不会因对比度变化而改变色调。有背景色的颜色在对比度降低时会更接近背景色，在对比度提高时则会离背景色更远。

建议使用静态构造函数。它们提供了更简单的接口，例如只需指定十六进制颜色代码，或指定十六进制颜色代码和背景色。

计算颜色、根据所需对比度调整颜色，以及确保其与另一种颜色之间具有特定明度或色调差异所需的各个组成部分，最终都由一个接收 DynamicScheme 并返回值的函数提供。这使得颜色行为具有极高的灵活性，可适用于任何设计系统；但通常并不需要如此。详情请参阅默认构造函数。
