ScreenshotCallback typedef

ScreenshotCallback = Future<bool> Function(String name, List<int> image, [Map<String, Object?>? args])

与 integrationDriver 配合使用的回调函数。

回调会收到通过 binding.takeScreenshot(<name>) 传入的截图名称、表示截图的 PNG 字节缓冲区，以及可选的 Map 参数。

测试通过时回调返回 true，否则返回 false。

可以使用此回调将字节保存到本地文件，或上传到某项服务，以便该服务将图像与基准版本进行比较。

可选的 Map 参数可以从集成测试中调用 binding.takeScreenshot(<name>, <args>) 时传入，之后可在 Flutter Driver 定义的 onScreenshot 处理程序中使用。这张 Map 只能包含可序列化为 JSON 的值。

由于此函数在驱动测试的主机上执行，因此可以访问其中的任何环境变量。
