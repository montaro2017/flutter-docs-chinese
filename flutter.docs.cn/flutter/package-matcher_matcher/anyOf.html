anyOf function

Matcher anyOf(
  1. Object? arg0, [
  2. Object? arg1,
  3. Object? arg2,
  4. Object? arg3,
  5. Object? arg4,
  6. Object? arg5,
  7. Object? arg6,
])

给定的任意一个匹配器求值为 true 时即匹配。

参数可以是分别传入的多个匹配器（最多 7 个），也可以是一个匹配器 List。

匹配器按从左到右的顺序求值，并使用短路求值；一旦某个匹配器返回 true，求值便会停止。

任何非匹配器参数都会隐式包装为 Matcher，用于检查相等性。

实现

Matcher anyOf(
  Object? arg0, [
  Object? arg1,
  Object? arg2,
  Object? arg3,
  Object? arg4,
  Object? arg5,
  Object? arg6,
]) {
  return _AnyOf(_wrapArgs(arg0, arg1, arg2, arg3, arg4, arg5, arg6));
}
