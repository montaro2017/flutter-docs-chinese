向此流添加订阅。

返回一个使用提供的 onData、onError 和 onDone 处理程序处理此流事件的 StreamSubscription。订阅的处理程序之后可以更改，但初始值为此处提供的函数。

每当此流发出数据事件时，都会调用订阅者的 onData 处理程序。如果 onData 为 null，则不执行任何操作。

此流发生错误时，会调用 onError 处理程序，并向其传递错误对象以及可能存在的堆栈跟踪。

onError 回调的类型必须是 void Function(Object error) 或 void Function(Object error, StackTrace)。函数类型决定调用 onError 时是否会传入堆栈跟踪参数。如果此流收到的错误不带堆栈跟踪，该参数可以是 StackTrace.empty。

否则，调用时只会传入错误对象。如果省略 onError，此流上的所有错误都会被视为未处理，并传递给当前 Zone 的错误处理程序。默认情况下，未处理的异步错误会按未捕获的顶层错误处理。

如果此流关闭并发出 done 事件，就会调用 onDone 处理程序。如果 onDone 为 null，则不执行任何操作。

如果 cancelOnError 为 true，订阅会在收到第一个错误事件时自动取消。默认值为 false。

订阅暂停期间或取消后，不会收到事件，也不会调用任何事件处理函数。

实现

@override
StreamSubscription<T> listen(
  void Function(T)? onData, {
  Function? onError,
  void Function()? onDone,
  bool? cancelOnError,
}) {
  var subscription = _source;
  if (subscription == null) {
    throw StateError('Stream has already been listened to.');
  }
  cancelOnError = (true == cancelOnError);
  _source = null;

  var result = cancelOnError
      ? _CancelOnErrorSubscriptionWrapper<T>(subscription)
      : subscription;
  result.onData(onData);
  result.onError(onError);
  result.onDone(onDone);
  subscription.resume();
  return result;
}
