  1. Stream<T> callback()

返回之前调用 fetchStream 得到的缓存流，或者运行 callback 计算新流。

如果最近调用过 fetchStream，则返回其先前返回值的副本；否则运行 callback 并返回新结果。

每次调用此函数都会返回一个重放相同事件的流，也就是说，在此缓存失效之前，所有流事件都会被缓存。

只有在流被监听并以 done 事件完成后，才开始计时。

实现

@Deprecated('Feature will be removed')
Stream<T> fetchStream(Stream<T> Function() callback) {
  if (_cachedValueFuture != null) {
    throw StateError('Previously used to cache via `fetch`');
  }
  var splitter = _cachedStreamSplitter ??= StreamSplitter(
    callback().transform(
      StreamTransformer.fromHandlers(
        handleDone: (sink) {
          _startStaleTimer();
          sink.close();
        },
      ),
    ),
  );
  return splitter.split();
}
