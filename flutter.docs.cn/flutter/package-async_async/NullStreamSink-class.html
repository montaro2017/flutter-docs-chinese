NullStreamSink

NullStreamSink<T> 类

会丢弃所有事件的 StreamSink。

调用 close 之前，此接收器会静默丢弃事件；调用之后再添加事件时，则会抛出 StateError。这与远端已关闭的接收器行为相同，例如 WebSocket 连接关闭时的情况。

需要接收器但实际上不会添加任何事件时，可以使用此类。创建接收器时，可以使用 NullStreamSink.error 构造函数表示错误，因为 StreamSink.done 会公开接收器错误。例如：

StreamSink<List<int>> openForWrite(String filename) {
  try {
    return RandomAccessSink(File(filename).openSync());
  } on IOException catch (error, stackTrace) {
    return NullStreamSink.error(error, stackTrace);
  }
}
