IOSinkBase

IOSinkBase 类 抽象

抽象类，按照 onAdd、onError、onClose 和 onFlush 方法实现 dart:io 中 IOSink 的 API。

由于 IOSink 定义在 dart:io 中，此类无法正式实现它。不过，此类的设计与其 API 完全一致，因此子类无需额外修改即可实现 IOSink。

此类会确保调用 close 后或调用 addStream 期间不能再添加事件。
