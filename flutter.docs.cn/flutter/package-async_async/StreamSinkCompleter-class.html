StreamSinkCompleter

StreamSinkCompleter<T> 类

一种稍后才会提供目标接收器的 sink。

此接收器是普通接收器，可以立即向其添加事件；但在调用 setDestinationSink 之前，事件会被缓冲。

也可以使用 StreamController 达到相同效果：目标接收器就绪后，使用 StreamConsumer.addStream 将控制器添加到接收器。此类会在可能时减少一些开销。例如，如果直到设置目标接收器后才向 sink 添加事件，这些事件就会直接添加到目标接收器。
