flush 方法

Future<void> flush()

参见 dart:io 中的 IOSink.flush。

由于此基类本身不缓冲任何内容，flush 会立即完成。

会缓冲事件的子类应重写 flush，使其在所有事件传递完毕后再完成。此外，应在该方法开头调用 super.flush()；如果接收器当前正在添加流，这会抛出 StateError。

实现

Future<void> flush() {
  if (_addingStream) throw StateError('StreamSink is bound to a stream');
  if (_closed) return Future.value();

  _addingStream = true;
  return onFlush().whenComplete(() {
    _addingStream = false;
  });
}
