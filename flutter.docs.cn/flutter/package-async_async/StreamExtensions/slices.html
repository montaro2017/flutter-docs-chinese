slices 方法

Stream<List<T>> slices(
  1. int length
)

创建一个流，其元素是当前流 this 中连续的分片，每片长度为指定值。

此流 this 中的每个分片包含 length 个元素；如果元素不足，最后一个分片可能较短。每个分片都从上一个分片结束后的位置开始。

例如，Stream.fromIterable([1, 2, 3, 4, 5]).slices(2) 会发出 ([1, 2], [3, 4], [5])。

错误发生时会立即转发到结果流，即使此前的数据事件尚未发出（因为下一个分片还不完整）也是如此。

实现

Stream<List<T>> slices(int length) {
  if (length < 1) throw RangeError.range(length, 1, null, 'length');

  var slice = <T>[];
  return transform(
    StreamTransformer.fromHandlers(
      handleData: (data, sink) {
        slice.add(data);
        if (slice.length == length) {
          sink.add(slice);
          slice = [];
        }
      },
      handleDone: (sink) {
        if (slice.isNotEmpty) sink.add(slice);
        sink.close();
      },
    ),
  );
}
