StreamZip

StreamZip<T> 类

合并其他流中各项值的流。

此流会发出列表，每个列表包含从各个输入流收集到的值。第一个列表包含每个流发出的第一个值，第二个列表包含第二个值，依此类推。列表顺序与传给 StreamZip.new 的可迭代对象顺序相同。

任一输入流中的错误都会直接转发到此流。
