创建一个以 value 完成的 CancelableOperation。

取消此操作不会产生任何效果。

调用此构造函数等效于创建一个 CancelableCompleter 并使用 value 完成它。

实现

factory CancelableOperation.fromValue(T value) =>
    (CancelableCompleter<T>()..complete(value)).operation;
