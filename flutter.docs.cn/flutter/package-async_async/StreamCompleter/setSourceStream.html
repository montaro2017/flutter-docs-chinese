将一个流设为 StreamCompleter 的 stream 的事件源。

完成器的 stream 将与 sourceStream 完全一致。

如果在监听 stream 之前设置了源流，那么对 stream 的监听调用会直接转发给 sourceStream。

如果在设置源流之前就开始监听 stream，则会创建一个中间订阅。它看起来与普通订阅完全相同，可以暂停或取消，但在提供源流之前不会发出任何事件。

如果在设置源流之前取消了 stream 订阅，之后会监听源流并立即再次取消。

否则，设置源流后会立即开始监听，并将其事件转发给现有订阅。

setSourceStream、setEmpty 和 setError 中的任意一个方法最多只能调用一次。再次调用其中任何方法都会失败。

实现

void setSourceStream(Stream<T> sourceStream) {
  if (_stream._isSourceStreamSet) {
    throw StateError('Source stream already set');
  }
  _stream._setSourceStream(sourceStream);
}
