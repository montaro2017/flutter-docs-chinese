StreamQueueTransaction<T> startTransaction()

请求一个可以有条件地消费事件的事务。

事务可以使用 StreamQueueTransaction.newQueue 在当前位置创建此队列的副本。每个副本彼此独立，也独立于父队列。调用以下两个方法之一后，事务即结束：

  • StreamQueueTransaction.commit 会更新父队列的位置，使其与其中一个副本的位置一致。

  • StreamQueueTransaction.reject 会让父队列继续运行，就像从未调用过 startTransaction 一样。

事务结束之前，此队列不会发出任何事件。

另请参阅 withTransaction 和 cancelable。

/// Consumes all empty lines from the beginning of [lines].
Future<void> consumeEmptyLines(StreamQueue<String> lines) async {
  while (await lines.hasNext) {
    var transaction = lines.startTransaction();
    var queue = transaction.newQueue();
    if ((await queue.next).isNotEmpty) {
      transaction.reject();
      return;
    } else {
      transaction.commit(queue);
    }
  }
}
