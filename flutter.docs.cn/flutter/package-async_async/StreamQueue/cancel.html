Future? cancel({
  1. bool immediate = false,
})

取消底层事件源。

如果 immediate 为 false（默认值），取消操作会等待所有先前请求的事件处理完毕，然后取消负责提供这些事件的订阅。

如果 immediate 为 true，则会立即取消事件源。所有待处理事件都会像底层流已关闭一样完成。

返回的 Future 会以对源流订阅调用 cancel 的结果完成。

调用 cancel 后，不能再请求任何事件。之后不得再次调用 lookAhead、next、peek、rest、skip、take 或 cancel。

实现

Future? cancel({bool immediate = false}) {
  _checkNotClosed();
  _isClosed = true;

  if (!immediate) {
    var request = _CancelRequest<T>(this);
    _addRequest(request);
    return request.future;
  }

  if (_isDone && _eventQueue.isEmpty) return Future.value();
  return _cancel();
}
