StreamQueue

StreamQueue<T> 类

用于以异步拉取方式访问流事件的接口。

包装一个流，并按请求逐个提供事件。

可以从流中请求（并预留）一个或多个事件；在所有先前请求都得到满足后，流事件才会用于满足当前请求。

例如，连续调用两次 next 时，返回的 Future 会分别由流中接下来两个尚未被请求的事件完成。

没有待处理的请求时，流订阅会暂停。

某些流（包括广播流）会在暂停期间缓存事件，因此两次请求之间等待过久，可能会导致其他地方的内存占用增长。

它与 StreamIterator 类似，但使用起来更方便。使用 StreamIterator 时，需要手动检查新事件是否可用，而且在检查下一个事件之前只能访问当前事件的值。StreamQueue 则允许一次请求多个事件，例如一次请求三个；可以逐个请求、使用 take 或 skip 成组请求，也可以组合使用。

你还可以通过 rest 将流中剩余的事件作为一个新流获取。例如，可以先从流中取出第一个事件，再将剩余部分继续作为流使用。

示例：

var events = StreamQueue<String>(someStreamOfLines);
var first = await events.next;
while (first.startsWith('#')) {
  // Skip comments.
  first = await events.next;
}

if (first.startsWith(MAGIC_MARKER)) {
  var headerCount =
      first.parseInt(first.substring(MAGIC_MARKER.length + 1));
  handleMessage(headers: await events.take(headerCount),
                body: events.rest);
  return;
}
// Error handling.

不再需要其他事件时，应调用 cancel 关闭 StreamQueue。这样会释放底层流订阅。
