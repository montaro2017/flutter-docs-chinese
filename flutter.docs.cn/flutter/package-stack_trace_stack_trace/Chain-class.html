Chain

Chain 类

由多个堆栈跟踪组成的调用链。

堆栈链由一个或多个堆栈跟踪组成，共同表示从 main 经过嵌套函数调用到某个代码位置（通常是错误抛出位置）的路径。使用异步函数时需要多个堆栈跟踪，因为每次运行异步回调前，程序的堆栈都会重置。

可以使用 Chain.capture 自动跟踪堆栈链。它会创建一个新的 Zone，在其中跟踪当前堆栈链，并可通过 Chain.current 访问。在该 Zone 中成为顶层的错误可由 onError 回调及其关联的堆栈链共同处理。例如：

Chain.capture(() {
  // ...
}, onError: (error, stackChain) {
  print("Caught error $error\n"
        "$stackChain");
});
