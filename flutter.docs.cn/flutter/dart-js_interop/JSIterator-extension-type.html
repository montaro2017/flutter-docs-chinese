JSIterator

JSIterator<T extends JSAny?> extension type

符合规范的 JS 迭代器。

在 JS 中，“符合规范的迭代器”会实现 JS iterator protocol，并且是 JS Iterator 类的实例。

此库不为缺少 JS iterator protocol 成员的 JS Iterator 类型提供类型定义，因为这类对象没有实用价值。

on
  • JSObject
实现的类型
  • JSIteratorProtocol<T>
  • JSIterable<T>
Available extensions
  • JSAnyOperatorExtension
  • JSAnyUtilityExtension
  • JSIterableToIterable
  • JSIteratorToIterator
  • NullableUndefineableJSAnyExtension
注解

  • @Since.new('3.12')
