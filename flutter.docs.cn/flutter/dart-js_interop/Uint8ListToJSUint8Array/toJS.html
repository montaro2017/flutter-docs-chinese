JSUint8Array get toJS

通过类型转换、解包或克隆，将此 Uint8List 转换为 JSUint8Array，克隆时会复制源 Uint8List。

注意

根据代码编译为 JavaScript 还是 Wasm，此转换的语义会有所不同。

编译为 JavaScript 时，所有类型化列表都是对应的 JavaScript 类型化数组，因此此 getter 只需进行类型转换。

编译为 Wasm 时，如果此 Uint8List 是通过 JSUint8ArrayToUint8List.toDart 转换而来的 Uint8Array 包装对象，此 getter 会将其解包并返回 Uint8Array。如果它是在 Dart 中实例化的，此 getter 会将该 Uint8List 中的值克隆到新的 JSUint8Array 中。

除非它先通过 JSUint8ArrayToUint8List.toDart 转换，否则不要假定在所有编译器中，对此 Uint8List 的修改都会影响返回的 JSUint8Array，反之亦然。
