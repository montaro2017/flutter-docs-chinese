JSObject

JSObject extension type

JavaScript Object。

JSObject 是所有 JavaScript 对象的超类型，但不包括原始值等其他 JS 类型。有关如何使用 JavaScript 互操作的详情，请参阅 https://dart.dev/interop/js-interop。

声明互操作扩展类型时，通常会使用 JSObject 作为表示类型。
