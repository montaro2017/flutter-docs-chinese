toExternalReference 属性

ExternalDartReference<T> get toExternalReference

对此类型为 T 的值的一个不透明引用，可将其传递给 JavaScript。

编译为 JavaScript 时，Dart 对象就是 JavaScript 对象，因此会直接返回该 Dart 对象。编译为 Wasm 时，会使用内部 Wasm 函数将 Dart 对象转换为不透明的 JavaScript 值。如果该值为 null，则返回 null。

ExternalDartReference 类型的值应被视为完全不透明。只能原样传递，或使用 ExternalDartReferenceToObject.toDartObject 将其转换回来。

对同一个 Dart 对象多次调用此 getter 时，生成的 ExternalDartReference 中的底层引用保证相等。因此，这类 ExternalDartReference 之间的 == 始终返回 true。不过，与 JS 类型一样，这些值之间的 identical 结果可能因编译器而异。
