anonymous top-level constant

_Anonymous const anonymous

此注解表示带有 JS 注解的类采用结构化互操作，并且没有已知的 JavaScript 原型。

标记为 anonymous 的类允许使用带命名参数的外部工厂构造函数。调用这些工厂函数会创建 JavaScript 对象字面量，其中的名称和值分别对应命名参数及其值。如果没有命名参数，则会创建一个空的 JavaScript 对象。

anonymous 类有以下限制：

  • They must contain a JS annotation, either from this library or from dart:js_interop. If the latter, the class must also contain staticInterop.
  • They cannot contain any non-external members unless it's a staticInterop class, in which case it can also contain non-external factories and static methods.
  • They cannot contain any external generative constructors.
  • Any external factory must not contain any positional parameters.
  • They cannot extend or be extended by a non-JS annotated class.
  • The annotation should only be applied to non-mixin classes and no other declarations.

实现

const _Anonymous anonymous = _Anonymous();
