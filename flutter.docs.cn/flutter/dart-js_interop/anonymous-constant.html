anonymous

anonymous top-level constant

_Anonymous const anonymous

此注解表示带有 JS 注解的类采用结构化互操作，并且没有已知的 JavaScript 原型。

标记为 anonymous 的类允许使用带命名参数的外部工厂构造函数。调用这些工厂函数会创建 JavaScript 对象字面量，其中的名称和值分别对应命名参数及其值。如果没有命名参数，则会创建一个空的 JavaScript 对象。

anonymous 类有以下限制：

  • 它们必须包含 JS 注解；该注解可以来自此库，也可以来自 dart:js_interop。如果来自后者，该类还必须包含 staticInterop。
  • 它们不能包含任何非 external 成员；但如果是 staticInterop 类，还可以包含非 external 工厂构造函数和静态方法。
  • 它们不能包含任何 external 生成式构造函数。
  • 任何 external 工厂构造函数都不能包含位置参数。
  • 它们不能继承未标记 JS 注解的类，也不能被此类继承。
  • 此注解仅应应用于非 mixin 类，不应应用于其他声明。

实现

const _Anonymous anonymous = _Anonymous();
