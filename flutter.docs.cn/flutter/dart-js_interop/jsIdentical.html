jsIdentical function

  1. @Since.new('3.12')
bool jsIdentical(
  1. Object? a,
  2. Object? b
)

如果 a 和 b 的底层 JavaScript 值相同，则返回 true。

其语义等同于 JavaScript 的 === 运算符。对于不直接使用 JS 值的后端，会使用 JS === 比较原生对象所对应的底层 JS 值。这样一来，与只比较原生引用的 identical 不同，此函数在不同后端上的结果应保持一致。

jsIdentical(a,b) 并不意味着 a.runtimeType == b.runtimeType 或 a.hashCode == b.hashCode，因为被比较的 JS 值可能由不同的原生类型包装。因此，不能互换使用变量 a 和 b。
