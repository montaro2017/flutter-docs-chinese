toJSProxyOrRef 属性

JSArray<T> get toJSProxyOrRef

通过类型转换、解包或代理，将此 List 转换为 JSArray，其输入为 List。

注意

根据代码编译为 JavaScript 还是 Wasm，此转换的语义会有所不同。

编译为 JavaScript 时，核心 List 就是 JavaScript Array，因此此 getter 只需进行类型转换。如果此 List 不是核心 List（例如用户自定义的列表），此 getter 会因类型转换错误而抛出异常。

编译为 Wasm 时，如果此 List 是通过 JSArrayToList.toDart 转换而来的 Array 包装对象，此 getter 会将其解包并返回 Array。如果它是在 Dart 中实例化的，此 getter 会使用占用较多资源的 Array 包装器代理该 List。访问原始 List 的元素时，性能可能会很差。

对此 List 的修改会影响返回的 JSArray，反之亦然。

实现
