globalContext

globalContext top-level property

JSObject get globalContext

用于查找用户声明的互操作成员的全局作用域。

例如：

library;

@JS()
external String get name;

读取顶层成员 name 时，会执行类似 <globalContext>.name 的 JavaScript 代码。

不同编译器之间存在一些细微差异，但通常可以将 globalContext 视为 JavaScript 的 globalThis。

实现

external JSObject get globalContext;
