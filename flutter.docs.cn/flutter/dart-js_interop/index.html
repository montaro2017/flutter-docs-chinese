dart:js_interop

dart:js_interop 库

与 JavaScript 和浏览器 API 互操作（简称“interop”）。

JavaScript 互操作让 Dart 程序能够与 JavaScript 运行时交互。例如，可以访问 JavaScript 声明并与 JavaScript 值交互，也可以转换 Dart 值，以便将它们传递给 JavaScript 代码并供其使用。

此 JavaScript 互操作库通过以下方式实现：为 JavaScript 值提供抽象；定义一套映射已知 JavaScript 类型的 Dart 类型层次结构（“JS 类型”）；并提供框架，用于声明将 Dart 类型绑定到 JavaScript 值的新 Dart 类型，以及将外部成员声明绑定到 JavaScript API。

有了此抽象，同一套互操作 API 既可用于编译为 JavaScript 的 Dart 代码，也可用于编译为 Wasm 的 Dart 代码。

有关用法、类型和早期 JavaScript 互操作方式的详情，请参阅 https://dart.dev/interop/js-interop。

注意

此库定义的类型只提供静态保证。运行时类型会因后端而异，因此应依赖转换函数等静态功能。同样，不要依赖涉及 JS 类型或 JS 类型化值的 is 检查。此外，同一个 JS 值的 identical 结果也可能因编译器而异。检查两个 JS 类型化值是否相等时请使用 ==，但不要比较 Dart 值与 JS 类型化值是否相等。
