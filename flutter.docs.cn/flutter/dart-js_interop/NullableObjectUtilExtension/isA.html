isA<T extends JSAny?> 方法

  1. @Since.new('3.4')
bool isA<T extends JSAny?>()

此 Object? 是否为由 T 声明的 JavaScript 类型的实例。

此函数的结果可用于判断是否能安全地转换为 T。由于各平台的运行时类型存在差异，不要期待此函数对同一类型在每个平台上都返回相同结果，例如 0.isA()。

由于此函数生成的类型检查由编译时决定，T 必须是编译时可确定的互操作扩展类型。具体来说，不能将泛型类型变量作为类型参数传给 isA。

此方法结合使用 null、typeof 和 instanceof 检查以及内建函数来执行检查。进行跨平台类型检查时，应使用此方法代替 is 检查。

如果 T 是 JSString 这类原始 JS 类型，此方法会使用与该原始类型对应的 typeof 检查，例如 typeofEquals('string')。

如果 T 是 JSArray 这类非原始 JS 类型，或是基于此类类型的互操作扩展类型，此方法会使用 instanceof 检查，并采用该类型的名称或 @JS 重命名，例如 instanceOfString('Array')。注意，如果你使用 @JS 注解重命名了库，则 instanceof 检查会使用该重命名，例如 instanceOfString('library1.JSClass')。

为确定 instanceof 检查中用作右操作数的 JavaScript 构造函数，此函数会使用与扩展类型关联的 JavaScript 名称，该名称要么来自 @JS 注解所提供的参数，要么就是 Dart 声明名称。因此，如果互操作扩展类型 JSClass 包装了未重命名的 JSArray，此方法会检查 instanceOfString('JSClass')，而不是 instanceOfString('Array')。

T 有少数几种情况不遵循此规则：

  • JSTypedArray: As TypedArray does not exist as a class in JavaScript, this does some prototype checking to make isA<JSTypedArray> do the right thing.
  • JSBoxedDartObject: isA<JSBoxedDartObject> will check if the value is a result of a previous ObjectToJSBoxedDartObject.toJSBox call.
  • JSAny: isA<JSAny> will call an intrinsic function to check that the value is a JS value.
  • JSObject: isA<JSObject> will call an intrinsic function to check that the value is a JS object (instanceof Object is insufficient for some objects).
  • JSExportedDartFunction: isA<JSExportedDartFunction<U>> will check if the value is a result of a previous FunctionToJSExportedDartFunction.toJS or FunctionToJSExportedDartFunction.toJSCaptureThis call and that the Dart function the value forwards to is a function of type U.
  • 表示类型为 JS 基本类型的用户互操作类型：为避免无法判断类型检查中是否使用了该用户互操作类型，这会导致错误。此时应改用 JS 基本类型作为 T 的值。
  • User interop types that have an object literal constructor: This will result in an error as you likely want to use JSObject instead.
