EdgeInsetsDirectional 类

表示四个基本方向偏移量的不可变集合，其水平分量会根据书写方向变化。

此类可用于表示从左侧开始的内边距（适用于 TextDirection.ltr 文本）或从右侧开始的内边距（适用于 TextDirection.rtl 文本），而无需关心当前文本方向。

另请参阅：

  • EdgeInsets, a variant that uses physical labels (left and right instead of start and end).
