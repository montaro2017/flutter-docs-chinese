StrutStyle 类

定义文本支架，用于设置文本行相对于基线的最小高度。

文本支架会应用于段落中的所有行，用来设定最小行高。其效果相当于在段落每一行的开头插入一个零宽空格。此虚拟空格会根据本类定义的属性进行“整形”。Flutter 的文本支架基于排版中的支架以及 CSS 的 line-height。

任何一行都不会比文本支架更矮。系统会计算文本支架的上升高度和下降高度；如果已布局文本的上升高度或下降高度小于文本支架对应的值，就会采用文本支架的度量值。若文本的上升高度或下降高度大于文本支架的对应值，则按正常方式布局，并超出文本支架范围。

文本支架独立于任何文本内容或 TextStyle 定义。

文本支架包含以下垂直分量：

  • 字体定义行距的一半
  • ascent * height
  • descent * height
  • 字体定义行距的一半

以上四个值的总和就是文本行的总高度。

上升高度是基线上方、不含行距的字体间距；下降高度是基线下方、不含行距的字体间距。行距平均分布在顶部和底部。ascent 和 descent 的值由 fontFamily 指定的字体提供。如果没有指定 fontFamily 或 fontFamilyFallback，则使用平台默认字体系列。许多字体的行距为零，因此实际使用中，行距分量通常没有影响。

省略 height 或将其设为 null 时，使用字体定义的上升高度和下降高度。两者之和可能大于或小于 fontSize。如果指定了 height，则会按 height 缩放行的 EM 方框上升高度和下降高度（两者之和等于 fontSize），使最终行高为 fontSize * height + fontSize * leading 个逻辑像素。指定 height 后，上升高度与下降高度的比例仍与字体度量定义的比例相同。

每行基线上方的间距至少等于半个行距加上上升高度；基线下方的间距至少等于半个行距加上下降高度。

字段及其默认值

省略或设为 null 的属性将使用以下默认值：

  • fontFamily：计算文本支架时使用的字体名称（例如 Roboto）。不会绘制该字体的字形；该字体仅用于提供度量值。

  • fontFamilyFallback：当 fontFamily 中指定的字体不可用时，按顺序搜索的字体系列名称列表。所有指定字体系列都尝试完仍未找到匹配项时，将使用平台默认字体。

  • fontSize：上升高度与下降高度之和，以逻辑像素表示。它也用于计算自定义行距。此值不能为负数。
    默认值为 14 个逻辑像素。

  • height：行高相对于 fontSize 的倍数。如果省略 height 或将其设为 null，行高将采用字体的上升高度和下降高度；如果指定了该值，则按 height 缩放 EM 方框的上升高度和下降高度（两者之和等于 fontSize）。height 对基线上下间距的影响取决于字体上升高度和下降高度的比例。此属性独立于通过 leading 控制的行距倍数。
    默认值为 null。

  • leading：要应用于文本支架的自定义行距，以 fontSize 的倍数表示。行距是行与行之间的额外间隔，其中一半加在行高顶部，另一半加在底部。这不同于 height：行距会平均分布在基线上下。
    默认值为 null，此时使用字体指定的行距。

  • fontWeight：计算文本支架时使用的字体粗细（例如粗体）。
    默认值为 FontWeight.w400。

  • fontStyle：计算文本支架时使用的字体样式变体（例如斜体）。
    默认值为 FontStyle.normal。

  • forceStrutHeight：为 true 时，所有文本行都会按照文本支架的高度进行布局。所有行级和文本片段级的度量值都会被忽略或覆盖，改用文本支架的度量值。此属性可确保行距一致，但相邻行中的文本可能会相互重叠。启用时应谨慎，因为它会绕过垂直布局系统中的大部分处理。默认值为 false。

示例

在这个简单示例中，文本将以 10 号字体渲染；不过，由于文本本身比支架矮，每行的垂直高度将采用文本支架的高度（Roboto 字体大小 30 × 1.5）。
link 
const Text(
  'Hello, world!\nSecond line!',
  style: TextStyle(
    fontSize: 10,
    fontFamily: 'Raleway',
  ),
  strutStyle: StrutStyle(
    fontFamily: 'Roboto',
    fontSize: 30,
    height: 1.5,
  ),
)

这里使用文本支架吸收第二行增加的行高。文本支架的 height 设为 1.5（默认字号为 14），因此所有行的布局高度都比不使用文本支架时更高。额外空间容纳了字号较大的 Second line!，避免只有第二行的行高发生变化。因此，此示例中的所有行高度相同（14 * 1.5）。

这里使用文本支架让文本产生奇特的重叠效果，从而实现独特的视觉表现。第 2 行和第 3 行中的 M 可以延伸到各自行的上方，填充上方行中的空白。forceStrutHeight 已启用，并作为字形绘制所依循的“网格”。

    fontFamily: 'Roboto',
    fontSize: 14,
    height: 1,
    forceStrutHeight: true,
  ),
)

此示例使用 forceStrutHeight 为“The”中的字母“T”创建首字下沉效果。将行高锁定为 14 磅衬线字体的度量值后，就可以在第二行布局一个较大的 37 磅“T”，让它同时占据第一行和第二行的空间。
