SweepGradient 类

二维扫描渐变。

BoxDecoration 使用此类表示扫描渐变。此类将 dart:ui 库中 ui.Gradient.sweep 构造函数的参数封装起来。

渐变具有一个中心点、一个 startAngle 和一个 endAngle。startAngle 对应 0.0，endAngle 对应 1.0。这些角度以弧度表示。

颜色由 Color 对象列表描述，至少需要两种颜色。如果指定了 stops 列表，其长度必须与颜色列表相同。该列表为每种颜色指定从起点到终点向量上的比例，范围为 0.0 到 1.0。如果该列表为 null，则使用均匀分布。

画布中位于 startAngle 之前和 endAngle 之后的区域，将根据 tileMode 着色。

此类通常与负责绘制的 BoxDecoration 一起使用。若要直接在画布上使用 SweepGradient 绘制，请参阅 createShader。

此示例在每个象限中绘制不同的颜色。
link 
Container(
  decoration: const BoxDecoration(
    gradient: SweepGradient(
      center: FractionalOffset.center,
      colors: <Color>[
        Color(0xFF4285F4), // blue
        Color(0xFF34A853), // green
        Color(0xFFFBBC05), // yellow
        Color(0xFFEA4335), // red
        Color(0xFF4285F4), // blue again to seamlessly transition to the start
      ],
      stops: <double>[0.0, 0.25, 0.5, 0.75, 1.0],
    ),
  )
)

此示例将上面的渐变旋转 math.pi/4 弧度，即 45 度。
