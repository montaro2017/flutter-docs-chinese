painting 库

Flutter 绘制库。

使用前，请导入 package:flutter/painting.dart。

此库包含多种类，用于封装 Flutter 引擎的绘制 API，以实现更专门的用途，例如绘制缩放后的图像、插值阴影，以及绘制方框边框等。

具体来说：

  • 使用 TextPainter 类绘制文本。
  • 使用 Decoration（更具体地说，使用 BoxDecoration）绘制方框。
