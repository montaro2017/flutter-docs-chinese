lerp static 方法

Gradient? lerp(
  1. Gradient? a,
  2. Gradient? b,
  3. double t
)

在两个 Gradient 之间进行线性插值。

如果 b 非 null，此方法会委托给 b 的 lerpTo 函数。如果 b 为 null，或其 lerpTo 返回 null，则改用 a 的 lerpFrom 函数。如果两者都返回 null，则在 t == 0.5 之前返回 a，在 t == 0.5 之后返回 b。

t 参数表示时间线上的位置：0.0 表示插值尚未开始，返回 a（或与 a 等价的值）；1.0 表示插值完成，返回 b（或与 b 等价的值）；中间值表示处于 a 与 b 之间时间线的相应位置。插值可以外推到 0.0 和 1.0 之外，因此负值及大于 1.0 的值都有效（Curves.elasticInOut 等曲线很容易产生这些值）。

t 的值通常来自 Animation<double>，例如 AnimationController。

实现

static Gradient? lerp(Gradient? a, Gradient? b, double t) {
  if (identical(a, b)) {
    return a;
  }
  Gradient? result;
  if (b != null) {
    result = b.lerpFrom(a, t); // if a is null, this must return non-null
  }
  if (result == null && a != null) {
    result = a.lerpTo(b, t); // if b is null, this must return non-null
  }
  if (result != null) {
    return result;
  }
  assert(a != null && b != null);
  return t < 0.5 ? a!.scale(1.0 - (t * 2.0)) : b!.scale((t - 0.5) * 2.0);
}
