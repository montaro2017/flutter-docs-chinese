HSVColor 类

使用 alpha、hue、saturation 和 value 表示的颜色。

HSVColor 使用基于人类对颜料颜色感知的参数空间来表示颜色（例如油漆和打印机墨水）。这种表示法适用于某些颜色计算（例如沿色相环旋转），因为分别对红、绿、蓝通道进行插值或选取颜色，并不总能得到直观的结果。

HSV 颜色空间描述了人们混合不同颜料时的感知方式。色相描述使用哪种颜料，饱和度描述颜料的色调，而 value 则类似于将颜料与不同用量的黑色或白色颜料混合。

另请参阅：

  • HSLColor, a color that uses a color space based on human perception of colored light.
  • HSV and HSL Wikipedia article, which this implementation is based upon.

属性

透明度范围为 0.0 到 1.0，用于表示颜色的不透明度。值为 0.0 时完全透明，值为 1.0 时完全不透明。
final

此对象的哈希码。
无 setter重写
hue → double
色相范围为 0.0 到 360.0，用于表示光谱中的颜色。值为 0.0 和 360.0 时均表示红色；中间值涵盖 RGB 可表示的所有色相。可以将它理解为要添加到颜色中的颜料。
final
runtimeType → Type
此对象运行时类型的表示。
无 setter继承
saturation → double
饱和度范围为 0.0 到 1.0，用于描述颜色的鲜艳程度。0.0 表示灰色（即没有颜料），1.0 表示该色相所能达到的最鲜艳颜色。可以将其理解为添加的颜料量。
final
value → double
明度值范围为 0.0 到 1.0，表示 HSV 颜色模型中的亮度分量。
final
