paint abstract 方法

void paint(
  1. Canvas canvas,
  2. Offset offset,
  3. ImageConfiguration configuration
)

使用给定配置，在给定画布上绘制创建此对象时对应的 Decoration。

作为第三个参数传入的 ImageConfiguration 对象至少必须包含非 null 的 Size。

如果此对象会缓存绘制资源（例如 Paint 对象），当使用新配置调用 paint 时，缓存可能会被清除。因此，在同一帧中绘制不同矩形时，为每个矩形分别调用 Decoration.createBoxPainter 可能更高效。

例如，装饰的拥有者可能希望先按完整尺寸绘制一次，再只绘制右下角区域。此时可以获取两个 BoxPainter 实例，每个区域使用一个。不过，尺寸发生变化时，仍可继续使用这些实例，因为先前的资源已不再相关，丢弃它们也没有影响。

实现应在画布上一个矩形区域内绘制装饰：矩形左上角位于给定的 offset，尺寸由 configuration.size 指定。

在 Container 或 DecoratedBox（Container 内部使用该组件）中绘制 Decoration 时，ImageConfiguration.textDirection 属性会根据环境中的 Directionality 填充。
