StadiumBorder 类

一种可在组件矩形范围内绘制体育场形边框的边框（即两端为半圆的方框）。

通常与 ShapeDecoration 一起用于绘制体育场形边框。

如果矩形高度大于宽度，半圆会位于顶部和底部；否则会位于左侧和右侧。

另请参阅：

  • BorderSide, which is used to describe the border of the stadium.
