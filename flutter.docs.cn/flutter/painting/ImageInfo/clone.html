clone 方法

ImageInfo clone()

创建一个包含克隆后 image 的 ImageInfo。

当持有 ImageInfo 的客户端需要与另一客户端共享此图像信息对象，同时之后仍需访问底层图像数据时（例如还要将其共享给其他客户端），必须使用此方法。

释放约定的详情请参阅类说明。

另请参阅：

  • ui.Image.clone，说明图像克隆的方式和原因。

实现

ImageInfo clone() {
  return ImageInfo(image: image.clone(), scale: scale, debugLabel: debugLabel);
}
