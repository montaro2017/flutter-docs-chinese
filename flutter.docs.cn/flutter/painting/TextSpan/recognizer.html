recognizer 属性

GestureRecognizer? recognizer
final

用于接收命中此区段的事件的手势识别器。

InlineSpan 本身不实现命中测试或事件分发。管理 InlineSpan 绘制的对象也负责分发事件。在渲染库中，该对象是 RenderParagraph，它对应于组件层的 RichText。这些对象不会在 InlineSpan 之间冒泡传递事件，因此 recognizer 只对直接命中该 InlineSpan 的 text 的事件生效，不适用于其 children。

InlineSpan 也不负责管理手势识别器的生命周期。拥有 GestureRecognizer 对象的代码必须在不再使用 InlineSpan 对象时调用 GestureRecognizer.dispose。

此示例展示如何管理传递给 InlineSpan 对象的手势识别器的生命周期。示例定义了一个 BuzzingText 组件：用户长按带有波浪绿色下划线的“find the”文本区段时，该组件会使用 HapticFeedback 类让设备振动。命中测试由 RichText 组件处理，同时会将悬停时的鼠标光标改为 precise。

class BuzzingText extends StatefulWidget {
  const BuzzingText({super.key});

  @override
  State<BuzzingText> createState() => _BuzzingTextState();
}

class _BuzzingTextState extends State<BuzzingText> {
  late LongPressGestureRecognizer _longPressRecognizer;

  @override
  void initState() {
    super.initState();
    _longPressRecognizer = LongPressGestureRecognizer()
      ..onLongPress = _handlePress;
  }

  @override
  void dispose() {
    _longPressRecognizer.dispose();
    super.dispose();
  }

  void _handlePress() {
    HapticFeedback.vibrate();
  }

  @override
  Widget build(BuildContext context) {
    return Text.rich(
      TextSpan(
        text: 'Can you ',
        style: const TextStyle(color: Colors.black),
        children: <InlineSpan>[
          TextSpan(
            text: 'find the',
            style: const TextStyle(
              color: Colors.green,
              decoration: TextDecoration.underline,
              decorationStyle: TextDecorationStyle.wavy,
            ),
            recognizer: _longPressRecognizer,
            mouseCursor: SystemMouseCursors.precise,
          ),
          const TextSpan(
            text: ' secret?',
          ),
        ],
      ),
    );
  }
}
