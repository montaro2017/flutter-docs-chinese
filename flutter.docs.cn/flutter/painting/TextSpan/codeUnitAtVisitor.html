重写

在每个 InlineSpan 中检查 index 是否位于其范围内；若在范围内，则返回对应的代码单元，否则返回 null。

offset 参数用于跟踪当前文本缓冲区中的索引偏移量。该缓冲区相当于从根 InlineSpan 开始，将 InlineSpan 树的内容连接起来后形成的文本。

不应直接调用此方法，请改用 codeUnitAt。

实现

@override
int? codeUnitAtVisitor(int index, Accumulator offset) {
  final String? text = this.text;
  if (text == null) {
    return null;
  }
  final int localOffset = index - offset.value;
  assert(localOffset >= 0);
  offset.increment(text.length);
  return localOffset < text.length ? text.codeUnitAt(localOffset) : null;
}
