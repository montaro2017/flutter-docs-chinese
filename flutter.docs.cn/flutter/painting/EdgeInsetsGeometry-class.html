EdgeInsetsGeometry
description

EdgeInsetsGeometry 类 抽象

EdgeInsets 的基类，支持根据文本方向进行解析。

此类型的属性或参数接受通过 EdgeInsets.fromLTRB 及其变体，或通过 EdgeInsetsDirectional.fromSTEB 及其变体创建的类。

若要将类型不确定的 EdgeInsetsGeometry 对象转换为 EdgeInsets 对象，请调用 resolve 方法。

另请参阅：

  • Padding, a widget that describes margins using EdgeInsetsGeometry.
