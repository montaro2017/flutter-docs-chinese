EdgeInsets 类

表示四个基本方向偏移量的不可变集合。

通常用于表示方框四条边各自的偏移量。例如，可以用此类表示方框内部的内边距。

EdgeInsets 类使用视觉边缘指定偏移量，即左、上、右、下。这些值不受 TextDirection 影响。若要同时支持从左到右和从右到左的布局，可以使用 EdgeInsetsDirectional，它使用 start、上、end 和下指定偏移量；其中 start 和 end 会根据 TextDirection（通常从环境中的 Directionality 获取）解析。

下面是创建 EdgeInsets 实例的示例：

四周均为 8 像素的常用外边距：

link 
const EdgeInsets.all(8.0)

上下为 8 像素、左右无外边距：
link 
const EdgeInsets.symmetric(vertical: 8.0)

左侧缩进 40 像素：
link 
const EdgeInsets.only(left: 40.0)

另请参阅：

  • Padding, a widget that accepts EdgeInsets to describe its margins.
  • EdgeInsetsDirectional, which (for properties and arguments that accept the type EdgeInsetsGeometry) allows the horizontal insets to be specified in a TextDirection-aware manner.
