AlignmentGeometry 类 抽象

Alignment 的基类，支持根据文本方向进行解析。

此类型的属性或参数接受通过 Alignment 及其变体创建的对象，也接受通过 AlignmentDirectional.new 创建的对象。

若要将类型尚未确定的 AlignmentGeometry 对象转换为 Alignment 对象，请调用 resolve 方法。
