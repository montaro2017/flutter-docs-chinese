lerp static 方法

FractionalOffset? lerp(
  1. FractionalOffset? a,

重写

在两个 FractionalOffset 之间进行线性插值。

如果任一参数为 null，此函数会从 FractionalOffset.center 开始插值。

t 参数表示时间线上的位置：0.0 表示插值尚未开始，返回 a（或与 a 等效的对象）；1.0 表示插值已结束，返回 b（或与 b 等效的对象）；中间值表示时间线到达 a 与 b 之间的相应位置。插值可以超出 0.0 到 1.0 的范围，因此负值和大于 1.0 的值也有效（例如 Curves.elasticInOut 等曲线可以轻松产生这些值）。

t 的值通常来自 Animation<double>，例如 AnimationController。

实现

static FractionalOffset? lerp(FractionalOffset? a, FractionalOffset? b, double t) {
  if (identical(a, b)) {
    return a;
  }
  if (a == null) {
    return FractionalOffset(ui.lerpDouble(0.5, b!.dx, t)!, ui.lerpDouble(0.5, b.dy, t)!);
  }
  if (b == null) {
    return FractionalOffset(ui.lerpDouble(a.dx, 0.5, t)!, ui.lerpDouble(a.dy, 0.5, t)!);
  }
  return FractionalOffset(ui.lerpDouble(a.dx, b.dx, t)!, ui.lerpDouble(a.dy, b.dy, t)!);
}
