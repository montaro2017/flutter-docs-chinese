ExactAssetImage 类

从 AssetBundle 获取图像，并将其与指定缩放比例关联。

创建时必须显式提供最终的 assetName 和 scale；此实现会忽略传递给 resolve 的配置中的设备像素比和尺寸。若要根据这些配置选择合适图像的分辨率感知变体，请参阅 AssetImage。

获取资源

获取应用自身提供的图像时，使用 assetName 参数指定要选择的资源。例如，假设目录 icons 中有一张名为 heart.png 的图像。首先，项目的 pubspec.yaml 应在 flutter 部分声明这些资源：

flutter:
  assets:
    - icons/heart.png

然后，若要获取图像并将其与 1.5 的缩放比例关联，请使用：

link 
const ExactAssetImage('icons/heart.png', scale: 1.5)

程序包中的资源

要从程序包获取资源，必须提供 包 参数。例如，假设上面的目录结构位于名为 my_icons 的程序包中。要获取图像，请使用：

link 
const ExactAssetImage('icons/heart.png', scale: 1.5, package: 'my_icons')

程序包自身使用的资源也应像上面那样通过 包 参数获取。

如果所需资源已在程序包的 pubspec.yaml 中声明，它会自动随应用打包。特别是，程序包自身使用的资源必须在该程序包的 pubspec.yaml 中声明。

程序包也可以选择在自身的 lib/ 文件夹中存放资源，而不必在 pubspec.yaml 中声明这些资源。若要将这些图像打包，应用必须指定要包含哪些图像。例如，名为 fancy_backgrounds 的程序包可以包含：

lib/backgrounds/background1.png
lib/backgrounds/background2.png
lib/backgrounds/background3.png

例如，若要包含第一张图像，应用的 pubspec.yaml 应在 assets 部分声明该图像：

  assets:
    - packages/fancy_backgrounds/backgrounds/background1.png

路径中默认包含 lib/，因此资源路径中不应再写入它。

  • Image.asset 是基于 ExactAssetImage 创建的 Image widget 的便捷写法（使用 scale 时）。
