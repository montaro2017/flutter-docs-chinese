BoxDecoration? lerp(
  1. BoxDecoration? a,

重写

在两个盒子装饰之间进行线性插值。

分别对盒子装饰的每个参数进行插值。

shape 不参与插值。若要对形状进行插值，可考虑使用边框形状不同的 ShapeDecoration。

如果两个值都为 null，则返回 null；否则返回非 null 值。如果其中一个值为 null，则对另一个值应用 scale 得到结果。如果两个值都不为 null 且 t == 0.0，则原样返回 a；如果 t == 1.0，则原样返回 b。其他情况下，会对相应属性进行插值以计算结果。

t 参数表示时间轴上的位置：0.0 表示插值尚未开始，返回 a（或与 a 等效的值）；1.0 表示插值已完成，返回 b（或与 b 等效的值）；两者之间的值表示时间轴上从 a 到 b 的相应位置。插值可以超出 0.0 到 1.0 的范围，因此负值和大于 1.0 的值都有效（例如 Curves.elasticInOut 等曲线很容易产生这些值）。

t 的值通常来自 Animation<double>，例如 AnimationController。

另请参阅：

  • Decoration.lerp 可以在任意两种 Decoration 类型之间插值，而不仅限于 BoxDecoration。
  • lerpFrom 和 lerpTo 用于实现 Decoration.lerp 并在插值时使用 BoxDecoration.lerp 对两个 BoxDecoration 之间进行插值，或者对一个 BoxDecoration 与 null 之间进行插值。

实现

static BoxDecoration? lerp(BoxDecoration? a, BoxDecoration? b, double t) {
  if (identical(a, b)) {
    return a;
  }
  if (a == null) {
    return b!.scale(t);
  }
  if (b == null) {
    return a.scale(1.0 - t);
  }
  if (t == 0.0) {
    return a;
  }
  if (t == 1.0) {
    return b;
  }
  return BoxDecoration(
    color: Color.lerp(a.color, b.color, t),
    image: DecorationImage.lerp(a.image, b.image, t),
    border: BoxBorder.lerp(a.border, b.border, t),
    borderRadius: BorderRadiusGeometry.lerp(a.borderRadius, b.borderRadius, t),
    boxShadow: BoxShadow.lerpList(a.boxShadow, b.boxShadow, t),
    gradient: Gradient.lerp(a.gradient, b.gradient, t),
    shape: t < 0.5 ? a.shape : b.shape,
  );
}
