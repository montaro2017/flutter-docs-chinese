ImageStreamListener 类

用于接收图像加载通知的接口。

此类重写 operator == 和 hashCode，以比较监听器中的各个回调。因此，添加此类实例作为监听器（例如通过 ImageStream.addListener）后，移除监听器时可以创建此类的另一个实例；只要关联的回调都相等，监听器就能正确移除。

供 ImageStream 和 ImageStreamCompleter 使用。
