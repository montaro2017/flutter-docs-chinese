decodeImageFromList function

Future<Image> decodeImageFromList(
  1. Uint8List bytes
)

根据字节列表创建图像。

此函数会尝试将给定字节解析为图像。解析成功时，返回的 Future 会解析为解码后的图像；否则该 Future 会解析为 null。

如果图像是动画图像，此函数会返回第一帧。如果需要支持动画图像，请考虑使用 instantiateImageCodec。

此函数与 decodeImageFromList 的区别在于，它会委托给 PaintingBinding.instantiateImageCodecWithSize，因此可以在测试中模拟。

实现

Future<ui.Image> decodeImageFromList(Uint8List bytes) async {
  final ui.ImmutableBuffer buffer = await ui.ImmutableBuffer.fromUint8List(bytes);
  final ui.Codec codec = await PaintingBinding.instance.instantiateImageCodecWithSize(buffer);
  final ui.FrameInfo frameInfo;
  try {
    frameInfo = await codec.getNextFrame();
  } finally {
    codec.dispose();
  }
  return frameInfo.image;
}
