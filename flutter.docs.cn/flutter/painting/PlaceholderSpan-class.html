PlaceholderSpan 类 抽象

以内联形式嵌入文本的不可变占位符。

PlaceholderSpan 表示一个占位符，用作其他内容的替代标记。PlaceholderSpan 本身不包含可用于更改 TextSpan 的有效信息。widgets 库中的 WidgetSpan 继承自 PlaceholderSpan，可用于指定占位符所承载的组件。

诸如 TextField、Text 和 RichText 之类的 Flutter 组件，只识别 WidgetSpan，不识别其他 PlaceholderSpan 子类。建议实现 WidgetSpan 接口，而不是 Placeholder 接口。

另请参阅：

  • WidgetSpan, a leaf node that represents an embedded inline widget.
  • TextSpan, a node that represents text in a TextSpan tree.
  • Text, a widget for showing uniformly-styled text.
  • RichText, a widget for finer control of text rendering.
  • TextPainter, a class for painting TextSpan objects on a Canvas.
