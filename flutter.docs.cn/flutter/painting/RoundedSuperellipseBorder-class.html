RoundedSuperellipseBorder
description

RoundedSuperellipseBorder 类

一种矩形边框，其圆角沿用 RSuperellipse 的形状。

通常与 ShapeDecoration 一起使用，绘制类似 iOS 设计中常见圆角矩形风格的方框。

此交互示例演示了 RoundedSuperellipseBorder 的用法。

切换顶部的开关，对比 RoundedSuperellipseBorder 与传统 RoundedRectangleBorder，观察两者细微的视觉差异。

使用下方滑块调整边框的粗细和半径，实时观察其效果。

link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=painting.RoundedSuperellipseBorder.1 mysample

另请参阅：

  • RSuperellipse, which defines the shape.
  • RoundedRectangleBorder, which uses the traditional RRect shape.
