TextPainter 类

将 TextSpan 树绘制到 Canvas 上的对象。

使用 TextPainter 的步骤如下：

  1. 创建 TextSpan 树，并将其传给 TextPainter 构造函数。

  2. 调用 layout 来准备段落。

  3. 根据需要多次调用 paint 来绘制段落。

  4. 对象不再使用时，调用 dispose 以释放原生资源。对于会重复使用并保存在 State 或 RenderObject 中的 TextPainter 对象，应在 State.dispose、RenderObject.dispose 或类似生命周期方法中调用 dispose。对于仅临时使用的 TextPainter 对象，在最后一次调用其方法或属性后立即释放是安全的。

如果绘制文本的区域宽度发生变化，请返回第 2 步。如果要绘制的文本发生变化，请返回第 1 步。

在非 Web 平台上，默认文本样式颜色为白色；在 Web 上则为黑色。如果要同时支持这两类平台，请务必显式设置文本颜色。
