height 属性

double? height
final

文本支架的最小高度，以 fontSize 的倍数表示。

省略 height 或将其设为 null 时，文本支架的高度等于字体定义的上升高度、下降高度与 leading 之和。字体定义的上升高度与下降高度之和可能大于或小于 fontSize。

如果指定了 height，则会按 height 缩放行的 EM 方框上升高度和下降高度（两者之和等于 fontSize），使最终文本支架高度为 fontSize * height + fontSize * leading 个逻辑像素。下图展示了字体度量定义的高度与 EM 方框高度之间的差异：

指定 height 时，上升高度与下降高度的比例，与省略或将 height 设为 null 时按字体度量计算出的比例相同。

请参阅 TextStyle.height，其工作方式类似。

默认高度为 null。
