ResizeImage 类

指示 Flutter 按照指定尺寸解码图像，而不是使用图像的原始尺寸。

这可以更精细地控制图像在 ImageCache 中的尺寸，通常用于降低 ImageCache 的内存占用。

解码后的图像仍可按不同于此处缓存尺寸的大小显示。

width 和 height 参数决定图像分辨率。如果图像未受约束，这些值也会设置其逻辑像素宽度和高度。

此示例展示如何将图像宽度设为屏幕宽度的一半。
link 
   Image(
     image: ResizeImage(
       FileImage(File('path/to/image')),
       width: MediaQuery.widthOf(context) ~/ 2, // Half of the screen's width.
     ),
   );

另请参阅：

  • ui.FlutterView.devicePixelRatio, used to convert between physical and logical pixels.
