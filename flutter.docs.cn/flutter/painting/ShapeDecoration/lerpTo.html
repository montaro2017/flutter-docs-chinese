  1. @重写

  1. Decoration? b,
  2. double t

重写

从 this 线性插值到另一个 Decoration（可能属于不同类）。

如果 b 的 lerpFrom 不知道如何处理当前类，就会调用此方法。

在子类中实现此方法时，如果当前类无法插值到 b，则返回 null。在这种情况下，lerp 会改用默认行为。类应同时实现 lerpFrom 和 lerpTo。

建议支持插值到 null，因为当两个类无法彼此插值时，Decoration.lerp 会将此方法用作回退方案。

t 参数表示时间轴上的位置：0.0 表示插值尚未开始，返回 this（或与 this 等效的值）；1.0 表示插值已完成，返回 b（或与 b 等效的值）；两者之间的值表示时间轴上从 this 到 b 的相应位置。插值可以超出 0.0 到 1.0 的范围，因此负值和大于 1.0 的值都有效（例如 Curves.elasticInOut 等曲线很容易产生这些值）。

t 的值通常来自 Animation<double>，例如 AnimationController。

请使用 Decoration.lerp，而不要直接调用此方法。

实现

@override
ShapeDecoration? lerpTo(Decoration? b, double t) {
  return switch (b) {
    BoxDecoration() => ShapeDecoration.lerp(this, ShapeDecoration.fromBoxDecoration(b), t),
    ShapeDecoration? _ => ShapeDecoration.lerp(this, b, t),
    _ => super.lerpTo(b, t) as ShapeDecoration?,
  };
}
