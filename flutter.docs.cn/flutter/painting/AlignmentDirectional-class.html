AlignmentDirectional 类

一种偏移量，以 Size 的比例表示，但其水平分量取决于书写方向。

无需了解当前文本方向，即可在 TextDirection.ltr 文本中表示从左侧开始的偏移量，或在 TextDirection.rtl 文本中表示从右侧开始的偏移量。

另请参阅：

  • Alignment, a variant that is defined in physical terms (i.e. whose horizontal component does not depend on the text direction).
