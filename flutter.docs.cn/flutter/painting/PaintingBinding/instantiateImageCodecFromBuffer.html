从 ImageCache 转调 dart:ui.instantiateImageCodecFromBuffer。

buffer 参数应为 ui.ImmutableBuffer 实例，可通过 ui.ImmutableBuffer.fromUint8List 或 ui.ImmutableBuffer.fromAsset 获取。

指定 cacheWidth 和 cacheHeight 参数时，它们表示图像解码后的目标尺寸。

cacheWidth 和 cacheHeight 必须为大于或等于 1 的正值，或为 null。可以只指定 cacheWidth 或 cacheHeight，并将另一个参数设为 null；此时未指定的尺寸会按原始宽高比缩放。如果两个参数均为 null 或省略，则图像将按原始分辨率解码。

allowUpscaling 参数决定是否将 cacheWidth 或 cacheHeight 限制在原始图像的固有宽高范围内。默认会限制尺寸，以避免不必要的内存使用。若要以高于原始分辨率的尺寸显示图像，调用方应优先缩放绘制图像的画布。

实现

@Deprecated(
  'Use instantiateImageCodecWithSize instead. '
  'This feature was deprecated after v3.7.0-1.4.pre.',
)
Future<ui.Codec> instantiateImageCodecFromBuffer(
  ui.ImmutableBuffer buffer, {
  int? cacheWidth,
  int? cacheHeight,
  bool allowUpscaling = false,
}) {
  assert(cacheWidth == null || cacheWidth > 0);
  assert(cacheHeight == null || cacheHeight > 0);
  return ui.instantiateImageCodecFromBuffer(
    buffer,
    targetWidth: cacheWidth,
    targetHeight: cacheHeight,
    allowUpscaling: allowUpscaling,
  );
}
