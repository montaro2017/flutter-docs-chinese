  1. @Deprecated('Look up the current FlutterView from the context via View.of(context) or consult the PlatformDispatcher directly instead. ' 'Deprecated to prepare for the upcoming multi-window support. ' 'This feature was deprecated after v3.7.0-32.0.pre.')
SingletonFlutterWindow get window
继承

已弃用；将在 Flutter 的未来版本中移除。

弃用此属性是为了适配 Flutter 即将推出的多视图和多窗口支持。

对于只有一个视图的应用（例如面向单屏移动设备的应用），此属性表示主视图。如果嵌入器支持多个视图，它会指向最先创建、并被视为主视图的那个视图。如果尚未创建任何视图，或最初创建的视图已被移除，则会抛出异常。

迁移依赖此弃用属性的代码时，可以采用以下方式：

如果可以获取 BuildContext，可通过 View.of 查找与该上下文关联的当前 FlutterView。它提供与此弃用属性相同的功能。不过，特定于平台的功能已移至 PlatformDispatcher；可以通过 View.of 返回的视图访问其 FlutterView.platformDispatcher。使用 View.of 和 BuildContext 是迁移离开此弃用的 window 属性的推荐方式。

如果没有上下文来查找 FlutterView，可以直接使用此绑定提供的 platformDispatcher 来访问特定于平台的功能。它还会在 PlatformDispatcher.views 中维护所有可用 FlutterView 的列表，以便在没有上下文时访问各视图的功能。

另请参阅：

  • View.of to access view-specific functionality on the FlutterView associated with the provided BuildContext.
  • FlutterView.platformDispatcher to access platform-specific functionality from a given FlutterView.
  • platformDispatcher on this binding to access the PlatformDispatcher, which provides platform-specific functionality.
