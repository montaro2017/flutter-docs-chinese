安排给定的临时帧回调。

将给定回调添加到帧回调列表中；如果 scheduleNewFrame 参数为 true，则确保安排一帧。

scheduleNewFrame 参数决定是否应调用 scheduleFrame 来确保安排新帧。默认值为 true。

如果在帧的动画阶段（仍在调用临时帧回调时）调用此方法，callback 将在下一帧调用，而不是当前帧。

如果这是一次性注册，请忽略 rescheduling 参数。

如果此回调每次触发后都会重新注册，则重新注册时应将 rescheduling 参数设为 true。此设置在 release 构建中无效；在 debug 构建中，它会确保为此回调保存的是首次注册时的原始堆栈跟踪，而非重新注册时的跟踪。这有助于查明调用特定回调的最初原因。如果 rescheduling 为 true，则必须在帧回调上下文中调用此方法。

通过此方法注册的回调可以使用 cancelFrameCallbackWithId 取消。

另请参阅：

  • WidgetsBinding.drawFrame, which explains the phases of each frame for those apps that use Flutter widgets (and where transient frame callbacks fit into those phases).

实现

int scheduleFrameCallback(
  FrameCallback callback, {
  bool rescheduling = false,
  bool scheduleNewFrame = true,
}) {
  if (scheduleNewFrame) {
    scheduleFrame();
  }
  _nextFrameCallbackId += 1;
  _transientCallbacks[_nextFrameCallbackId] = _FrameCallbackEntry(
    callback,
    rescheduling: rescheduling,
  );
  return _nextFrameCallbackId;
}
