继承

在 debug 模式下断言不存在待处理的性能模式请求。

如果仍有待处理的性能模式请求，则抛出 FlutterError，因为这可能表示发生了内存泄漏。

实现

bool debugAssertNoPendingPerformanceModeRequests(String reason) {
  assert(() {
    if (_performanceMode != null) {
      throw FlutterError(reason);
    }
    return true;
  }());
  return true;
}
