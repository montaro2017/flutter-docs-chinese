AxisDirection enum

沿水平或垂直 Axis 的方向，用于确定原点（即零位置）。

此值表示滚动偏移量从原点开始增大的方向。它不表示可能改变滚动偏移量的用户输入方向，例如拖动方向。当前实际滚动方向请参阅 ScrollDirection。

此示例展示一个 CustomScrollView，其 AppBar.bottom 中的 Radio 按钮可更改 AxisDirection，以演示不同的配置。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=painting.AxisDirection.1 mysample

另请参阅：

  • ScrollDirection, the direction of active scrolling, relative to the positive scroll offset axis given by an AxisDirection and a GrowthDirection.
  • GrowthDirection, the direction in which slivers and their content are ordered, relative to the scroll offset axis as specified by AxisDirection.
  • CustomScrollView.anchor, the relative position of the zero scroll offset in a viewport and inflection point for AxisDirections of the same cardinal Axis.
  • axisDirectionIsReversed：返回沿给定轴方向移动时，是否会按数值递减的顺序经过该轴上的坐标。

Values

up → const AxisDirection

Axis.vertical 轴上的一种方向：零点位于底部，正方向朝上，示意符号为 ⇈。

采用 GrowthDirection.forward 方向排列的字母内容中，A 会位于底部，Z 会位于顶部。

例如，将 ListView 的 ListView.reverse 设为 true 时，其行为就会采用此轴方向。

另请参阅：

  • axisDirectionIsReversed：返回沿给定轴方向移动时，是否会按数值递减的顺序经过该轴上的坐标。
right → const AxisDirection

Axis.horizontal 轴上的一种方向：零点位于左侧，正方向朝右，示意符号为 ⇉。

采用 GrowthDirection.forward 方向排列的字母内容中，A 会位于左侧，Z 会位于右侧。例如，这是英语应用中水平标签组的常规阅读顺序。

例如，将 ListView 的 ListView.scrollDirection 设为 Axis.horizontal 时，其行为就会采用此轴方向。

另请参阅：

  • axisDirectionIsReversed：返回沿给定轴方向移动时，是否会按数值递减的顺序经过该轴上的坐标。
down → const AxisDirection

Axis.vertical 轴上的一种方向：零点位于顶部，正方向朝下，示意符号为 ⇊。

采用 GrowthDirection.forward 方向排列的字母内容中，A 会位于顶部，Z 会位于底部。这是垂直列表的常规阅读顺序。

例如，ListView 的默认行为就会采用此轴方向。

另请参阅：

  • axisDirectionIsReversed：返回沿给定轴方向移动时，是否会按数值递减的顺序经过该轴上的坐标。
left → const AxisDirection

Axis.horizontal 轴上的一种方向：零点位于右侧，正方向朝左，示意符号为 ⇇。

采用 GrowthDirection.forward 方向排列的字母内容中，A 会位于右侧，Z 会位于左侧。例如，这是希伯来语应用中水平标签组的常规阅读顺序。

例如，将 ListView 的 ListView.scrollDirection 设为 Axis.horizontal，并将 ListView.reverse 设为 true 时，其行为就会采用此轴方向。

另请参阅：

  • axisDirectionIsReversed：返回沿给定轴方向移动时，是否会按数值递减的顺序经过该轴上的坐标。
