InlineSpan 类 抽象

构成段落一部分的不可变行内内容片段。

  • The subclass TextSpan specifies text and may contain child InlineSpan。
  • PlaceholderSpan 子类表示可填入非文本内容的占位符。PlaceholderSpan 本身定义了 PlaceholderAlignment 和 TextBaseline。若要实际使用，必须扩展 PlaceholderSpan 来定义内容。WidgetSpan 就是 widgets 库中的一个实例。
  • The subclass WidgetSpan specifies embedded inline widgets.

此示例展示一个由 InlineSpan 构成的树，其中内嵌了一个 TextField，用于询问姓名。
link 
Text.rich(
  TextSpan(
    text: 'My name is ',
    style: const TextStyle(color: Colors.black),
    children: <InlineSpan>[
      WidgetSpan(
        alignment: PlaceholderAlignment.baseline,
        baseline: TextBaseline.alphabetic,
        child: ConstrainedBox(
          constraints: const BoxConstraints(maxWidth: 100),
          child: const TextField(),
        )
      ),
      const TextSpan(
        text: '.',
      ),
    ],
  ),
)

另请参阅：

  • Text，一种用于显示样式统一文本的 widget。
  • RichText，一种可更精细控制文本渲染的 widget。
  • TextPainter，用于将 InlineSpan 对象绘制到 Canvas 上。
