PlaceholderDimensions 类

保存用于表示文本中占位符尺寸所需的 Size 和基线信息。

占位符会在文本布局中留出空白，供之后在由 WidgetSpan 定义的位置渲染任意行内组件。

另请参阅：

  • WidgetSpan, a subclass of InlineSpan 和 PlaceholderSpan that represents an inline widget embedded within text. The space this widget takes is indicated by a placeholder.
  • RichText，一种支持行内 widget 的文本 widget。
