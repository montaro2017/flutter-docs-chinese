FractionalOffset 类

以 Size 的分数表示的偏移量。

FractionalOffset(1.0, 0.0) 表示 Size 的右上角。

FractionalOffset(0.0, 1.0) 表示 Size 的左下角。

FractionalOffset(0.5, 2.0) 表示 Size 水平中点处的一个点；该点位于矩形底部之外，距离底部一个 Size 的高度。

FractionalOffset 类以距左上角的距离指定偏移量，与 TextDirection 无关。

设计讨论

FractionalOffset 和 Alignment 是表示同一信息的两种不同方式：相对于矩形尺寸的矩形内位置。两个类的区别在于它们表示位置时所用的坐标系。

FractionalOffset 使用以矩形左上角为原点的坐标系，而 Alignment 使用以矩形中心为原点的坐标系。

FractionalOffset 的历史早于 Alignment。尝试创建一个能适配 TextDirection 的 FractionalOffset 版本时，我们遇到了困难：将原点放在左上角会引入难以消除的从左到右偏向。

由于原点位于中心，Alignment 和 AlignmentDirectional 可以使用同一个原点，因此我们能够通过线性函数，在 TextDirection.rtl 和 TextDirection.ltr 两种方向下，将 AlignmentDirectional 转换为 Alignment。

Alignment 大多数情况下比 FractionalOffset 更合适，应优先使用 FractionalOffset 的替代方案。我们仍继续实现 FractionalOffset，以支持早于 Alignment 的代码。
