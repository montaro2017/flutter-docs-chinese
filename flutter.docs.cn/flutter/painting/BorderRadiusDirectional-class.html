BorderRadiusDirectional 类

一种用于矩形各角的不可变半径集合，但角的位置根据书写方向指定。

此类可为框的前导侧或尾随侧指定角半径；文本对齐方向翻转时，半径也会移到另一侧（例如，英文文本中的右上角在阿拉伯文文本中会变为左上角）。

另请参阅：

  • BorderRadius, a variant that uses physical labels (topLeft 和 topRight instead of topStart 和 topEnd).
