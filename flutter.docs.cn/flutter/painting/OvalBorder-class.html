OvalBorder 类

适配椭圆形状的边框。

通常与 ShapeDecoration 配合绘制椭圆。与 CircleBorder 将 Border 置于正方形中央不同，它会填满可用空间并接触方框边缘。CircleBorder(eccentricity = 1.0) 与 OvalBorder() 没有区别。OvalBorder 是此功能的别名，便于用户发现和使用。

另请参阅：

  • CircleBorder, which draws a circle, centering when the box is rectangular.
  • Border, which, when used with BoxDecoration, can also describe an oval.
