MemoryImage 类

将给定的 Uint8List 缓冲区解码为图像，并为其关联指定的比例。

将缓冲区通过 bytes 提供给 MemoryImage 后，不应再修改它。若要提供一个可随时间表示不同图像的 ImageStream，可以创建新的 ImageProvider 子类，并让其 loadImage 方法返回能够提供多个图像的 ImageStreamCompleter 子类。

另请参阅：

  • Image.memory for a shorthand of an Image widget backed by MemoryImage.
