lerpFrom 方法

  1. @protected
ShapeBorder? lerpFrom(
  1. ShapeBorder? a,
  2. double t

从另一个 ShapeBorder（可能属于其他类）线性插值到 this。

在子类中实现此方法时，如果当前类无法从 a 插值，则返回 null。在这种情况下，lerp 会尝试其他方式在两个边框之间插值，然后再采用默认行为。如果 a 为 null，此方法不得返回 null。

基类实现通过调用 scale 来处理 a 为 null 的情况。

t 参数表示时间轴上的位置：0.0 表示插值尚未开始，返回 a（或与 a 等效的值）；1.0 表示插值已完成，返回 this（或与 this 等效的值）；两者之间的值表示时间轴上从 a 到 this 的相应位置。插值可以超出 0.0 到 1.0 的范围，因此负值和大于 1.0 的值都有效（例如 Curves.elasticInOut 等曲线很容易产生这些值）。

t 的值通常来自 Animation<double>，例如 AnimationController。

请使用 ShapeBorder.lerp，而不要直接调用此方法。

实现

@protected
ShapeBorder? lerpFrom(ShapeBorder? a, double t) {
  if (a == null) {
    return scale(t);
  }
  return null;
}
