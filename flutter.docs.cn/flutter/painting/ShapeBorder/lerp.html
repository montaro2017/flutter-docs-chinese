lerp static 方法

ShapeBorder? lerp(
  1. ShapeBorder? a,
  2. ShapeBorder? b,
  3. double t
)

在两个 ShapeBorder 之间进行线性插值。

首先尝试正向插值：先调用 b.lerpFrom(a, t)，再调用 a.lerpTo(b, t)。如果两者都返回 null，则尝试沿反向时间轴插值：先调用 b.lerpTo(a, 1.0 - t)，再调用 a.lerpFrom(b, 1.0 - t)。如果这些方法仍全部返回 null，则在 t=0.5 处分界：前半段返回 a，后半段返回 b；切换点为 t=0.5。

t 参数表示时间线上的位置：0.0 表示插值尚未开始，返回 a（或与 a 等价的值）；1.0 表示插值完成，返回 b（或与 b 等价的值）；中间值表示处于 a 与 b 之间时间线的相应位置。插值可以外推到 0.0 和 1.0 之外，因此负值及大于 1.0 的值都有效（Curves.elasticInOut 等曲线很容易产生这些值）。

t 的值通常来自 Animation<double>，例如 AnimationController。

实现

static ShapeBorder? lerp(ShapeBorder? a, ShapeBorder? b, double t) {
  if (identical(a, b)) {
    return a;
  }
  final ShapeBorder? result =
      b?.lerpFrom(a, t) ?? a?.lerpTo(b, t) ?? b?.lerpTo(a, 1.0 - t) ?? a?.lerpFrom(b, 1.0 - t);
  return result ?? (t < 0.5 ? a : b);
}
