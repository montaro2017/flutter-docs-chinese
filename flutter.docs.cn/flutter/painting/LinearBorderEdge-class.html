LinearBorderEdge 类

定义 LinearBorder 一条边的相对尺寸和对齐方式。

LinearBorder 将方框轮廓定义为零到四条边，每条边都绘制为一条直线。直线的宽度和颜色由 LinearBorder.side 定义。

每条线的长度由 size 定义。该值介于 0.0 和 1.0 之间（默认值为 1.0），表示线长占对应方框边长的比例。

当 size 小于 1.0 时，线条会根据 alignment 在可用空间内对齐；该值介于 -1.0 和 1.0 之间。默认值为 0.0，表示居中；-1.0 表示对齐到 start 侧，1.0 表示对齐到 end 侧。start 和 end 的含义取决于当前 TextDirection，参见 Directionality。
