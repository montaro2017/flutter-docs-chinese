TextSpan 类

不可变的文本区段。

TextSpan 对象可以通过 style 属性设置样式。该样式会应用于 text 和 children。

TextSpan 对象可以只包含纯文本，也可以包含具有自身样式的子 TextSpan 对象；这些样式可以全部或部分覆盖此对象的 style。如果一个 TextSpan 同时具有 text 和 children，则该 text 会被视为未设置样式的 TextSpan，放在 children 列表的开头。如果 TextSpan 的 text 字段为 null，该对象会作为 InlineSpan 树中的空节点，仅包含子项列表。

若要在 Canvas 上绘制 TextSpan，请使用 TextPainter。若要在组件中显示文本区段，请使用 RichText。对于只有一种样式的文本，可以考虑使用 Text 组件。

文本“Hello world!”，颜色为黑色：
link 
const TextSpan(
  text: 'Hello world!',
  style: TextStyle(color: Colors.black),
)

recognizer 属性的文档中提供了更详细的示例代码。

除非通过 TextSpan.semanticsLabel 属性覆盖，否则 TextSpan.text 会用作语义标签。TextSpan.children 列表中的任何 PlaceholderSpan 都会将其前后的文本分隔为两个语义节点。

  • Text, a widget for showing uniformly-styled text.
  • RichText, a widget for finer control of text rendering.
  • TextPainter, a class for painting TextSpan objects on a Canvas.
