lerp static 方法

HSLColor? lerp(
  1. HSLColor? a,
  2. HSLColor? b,
  3. double t
)

在两个 HSLColor 之间进行线性插值。

插值时会分别对 alpha、hue、saturation 和 lightness 通道进行插值；与分别插值红、绿、蓝通道的 Color.lerp 相比，这通常能产生更悦目的效果。

如果任一颜色为 null，此函数会从另一颜色的透明实例开始进行线性插值。通常这比从 Colors.transparent（const Color(0x00000000)）开始更合适，因为后者会从透明红色开始，并无论目标颜色的色相为何，都沿色相变化以匹配目标颜色。

t 参数表示时间线上的位置：0.0 表示插值尚未开始，返回 a（或与 a 等效的值）；1.0 表示插值已完成，返回 b（或与 b 等效的值）；介于两者之间的值表示时间线从 a 到 b 的相应位置。插值可以超出 0.0 和 1.0 的范围，因此负值和大于 1.0 的值也有效（例如 Curves.elasticInOut 等曲线很容易产生这些值）。

超出各通道有效范围的值会被限制在有效范围内。

t 的值通常来自 Animation<double>，例如 AnimationController。

实现

static HSLColor? lerp(HSLColor? a, HSLColor? b, double t) {
  if (identical(a, b)) {
    return a;
  }
  if (a == null) {
    return b!._scaleAlpha(t);
  }
  if (b == null) {
    return a._scaleAlpha(1.0 - t);
  }
  return HSLColor.fromAHSL(
    clampDouble(lerpDouble(a.alpha, b.alpha, t)!, 0.0, 1.0),
    lerpDouble(a.hue, b.hue, t)! % 360.0,
    clampDouble(lerpDouble(a.saturation, b.saturation, t)!, 0.0, 1.0),
    clampDouble(lerpDouble(a.lightness, b.lightness, t)!, 0.0, 1.0),
  );
}
