ImageConfiguration 类

传递给 ImageProvider.resolve 方法、用于选择特定图像的配置信息。

另请参阅：

  • createLocalImageConfiguration，可创建一个 ImageConfiguration based on ambient configuration in a Widget environment.
  • ImageProvider，使用 ImageConfiguration 对象确定要获取的图像。
