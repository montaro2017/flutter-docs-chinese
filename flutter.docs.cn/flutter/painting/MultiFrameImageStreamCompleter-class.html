MultiFrameImageStreamCompleter 类

负责解码并调度图像帧。

只有在此流注册了监听器（通过 addListener 注册）时，才会发出新帧。

此类处理两种帧：

  • image frames（图像帧）——动画图像中的图像帧。
  • app frames（应用帧）——Flutter 引擎绘制到屏幕上以显示应用界面的帧。

对于单帧图像，流只会完成一次。

对于动画图像，此类会预先解码下一帧，并在图像帧持续时间结束后安排的首个应用帧中，通知监听器新帧已就绪。

只在已安排的应用帧中安排新计时器，可确保应用不可见时暂停动画（因为此时不会安排新的应用帧）。

请参见以下时间线示例：

| Time | Event                                      | Comment                   |
|------|--------------------------------------------|---------------------------|
| t1   | App frame scheduled (image frame A posted) |                           |
| t2   | App frame scheduled                        |                           |
| t3   | App frame scheduled                        |                           |
| t4   | Image frame B decoded                      |                           |
| t5   | App frame scheduled                        | t5 - t1 < frameB_duration |
| t6   | App frame scheduled (image frame B posted) | t6 - t1 > frameB_duration |
