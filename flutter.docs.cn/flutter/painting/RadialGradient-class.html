RadialGradient 类

二维径向渐变。

BoxDecoration 使用此类表示径向渐变。此类将 dart:ui 库中 ui.Gradient.radial 构造函数的参数封装起来。

普通径向渐变具有一个中心点和一个半径。中心点对应 0.0，距中心半径处的圆环对应 1.0。这些长度以比例表示，因此同一个渐变可以用于不同尺寸的方框，而无需更改参数。（与此不同，ui.Gradient.radial 的参数以逻辑像素表示。）

也可以创建双点（或焦点）径向渐变（有时称为双点圆锥渐变，但它不同于 CSS 圆锥渐变；后者对应 SweepGradient）。可以像指定中心点和半径一样，指定焦点和 focalRadius，使渲染出的渐变看起来朝焦点方向聚拢或延伸。只有当焦点与中心点不相等，或 focalRadius > 0.0 时，这才会产生影响（否则视觉效果与普通径向渐变相同）。需要避免的一种情况是：当 focalRadius > 0.0 时，焦点和中心点都解析为 Offset.zero。在这种情况下，框架无法创建有效的着色器。

颜色由 Color 对象列表描述，至少需要两种颜色。如果指定了 stops 列表，其长度必须与颜色列表相同。该列表指定半径上从 0.0 到 1.0 的比例，为每个颜色停靠点定义同心圆环。如果该列表为 null，则使用均匀分布。

画布中距离中心点超过半径的区域，将根据 tileMode 着色。

此类通常与负责绘制的 BoxDecoration 一起使用。若要直接在画布上使用 RadialGradient 绘制，请参阅 createShader。

此函数绘制的渐变效果类似蓝天中的太阳。
link 
void paintSky(Canvas canvas, Rect rect) {
  const RadialGradient gradient = RadialGradient(
    center: Alignment(0.7, -0.6), // near the top right
    radius: 0.2,
    colors: <Color>[
      Color(0xFFFFFF00), // yellow sun
      Color(0xFF0099FF), // blue sky
    ],
    stops: <double>[0.4, 1.0],
  );
  // rect is the area we are painting over
  final Paint paint = Paint()
    ..shader = gradient.createShader(rect);
  canvas.drawRect(rect, paint);
}
