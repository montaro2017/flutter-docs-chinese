  2. required Object exception,

调用所有已注册的错误监听器，通知它们图像解析期间发生的错误。

如果没有附加错误监听器（即指定了 ImageStreamListener.onError 的监听器），或所有处理器都原样重新抛出异常（使用 throw exception），则会通过 FlutterError.reportError 报告 FlutterError。如果曾在此 completer 上注册过 ImageStreamListener，且其 ImageStreamListener.reportErrors 为 false，则会抑制此报告。

context 应是描述错误捕获位置的字符串；与“抛出”连用时应表达通顺，例如“从网络获取图像时抛出”（上下文为“从网络获取图像时”）。

exception 是要报告的错误；stack 是与该异常关联的 StackTrace。

informationCollector 是一个回调（类型为 InformationCollector），在 FlutterError.reportError 使用该异常时调用。它用于收集要写入日志的更多信息；由于收集这些信息可能开销较大，因此只有确实要记录错误时才应收集。

将 silent 参数传给 FlutterError.reportError 后，在发布版本中不会将异常写入日志（但仍会发送给错误处理器）。对于预期在发布版本中出现的错误（例如网络错误），应将此参数设为 true。这样终端用户设备的日志不会出现无关信息，同时开发期间的错误仍会报告。

这些值的更多详情请参阅 FlutterErrorDetails。

实现

@pragma('vm:notify-debugger-on-exception')
void reportError({
  DiagnosticsNode? context,
  required Object exception,
  StackTrace? stack,
  InformationCollector? informationCollector,
  bool silent = false,
}) {
  _currentError = FlutterErrorDetails(
    exception: exception,
    stack: stack,
    library: 'image resource service',
    context: context,
    informationCollector: informationCollector,
    silent: silent,
  );

  // Make a copy to allow for concurrent modification.
  final localErrorListeners = <ImageErrorListener>[
    ..._listeners
        .map<ImageErrorListener?>((ImageStreamListener listener) => listener.onError)
        .whereType<ImageErrorListener>(),
    ..._ephemeralErrorListeners,
  ];

  _ephemeralErrorListeners.clear();

  var handled = false;
  for (final errorListener in localErrorListeners) {
    try {
      errorListener(exception, stack);
      handled = true;
    } catch (newException, newStack) {
      if (newException != exception) {
        FlutterError.reportError(
          FlutterErrorDetails(
            context: ErrorDescription('when reporting an error to an image listener'),
            library: 'image resource service',
            exception: newException,
            stack: newStack,
          ),
        );
      }
    }
  }
  if (!handled) {
    // If a listener with reportErrors=false was previously registered,
    // the error was intended to be handled. Skip reporting to
    // FlutterError.onError after the widget is disposed.
    if (_hadErrorListener) {
      return;
    }
    FlutterError.reportError(_currentError!);
  }
}
