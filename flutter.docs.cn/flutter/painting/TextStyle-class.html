TextStyle 类

用于描述文本格式和绘制方式的不可变样式。

粗体

此处为 Text 组件中的单行文本指定了样式覆盖。Text 组件会将该样式与环境中的 DefaultTextStyle 混合。

link 
const Text(
  'No, we need bold strokes. We need this plan.',
  style: TextStyle(fontWeight: FontWeight.bold),
)

斜体

与上例一样，此处为 Text 组件指定了样式覆盖，该样式会与环境中的 DefaultTextStyle 隐式混合。

link 
const Text(
  "Welcome to the present, we're running a real nation.",
  style: TextStyle(fontStyle: FontStyle.italic),
)

不透明度和颜色

这里的每一行都逐渐变得更加不透明。基础颜色为 Colors.black，并使用 Color.withOpacity 创建所需不透明度的派生颜色。此 RichText 组件的根 TextSpan 显式设置为环境中的 DefaultTextStyle，因为 RichText 不会自动这样做。内部的 TextStyle 对象会与父级 TextSpan 的 TextSpan.style 隐式混合。

如果指定了 color，则 foreground 必须为 null，反之亦然。color 是 Paint()..color = color 的简写形式。

如果指定了 backgroundColor，则 background 必须为 null，反之亦然。backgroundColor 是 background: Paint()..color = backgroundColor 的简写形式。

RichText(
  text: TextSpan(
    style: DefaultTextStyle.of(context).style,
    children: <TextSpan>[
      TextSpan(
        text: "You don't have the votes.\n",
        style: TextStyle(color: Colors.black.withValues(alpha: 0.6)),
      ),
      TextSpan(
        text: "You don't have the votes!\n",
        style: TextStyle(color: Colors.black.withValues(alpha: 0.8)),
      ),
      TextSpan(
        text: "You're gonna need congressional approval and you don't have the votes!\n",
        style: TextStyle(color: Colors.black.withValues(alpha: 1.0)),
      ),
    ],
  ),
)

字号

此示例显式调整了环境中的 DefaultTextStyle，以获取字号为默认值两倍的 TextStyle。

link 
Text(
  "These are wise words, enterprising men quote 'em.",
  style: DefaultTextStyle.of(context).style.apply(fontSizeFactor: 2.0),
)

行高

默认情况下，文本会按照字体定义的行高进行布局。由字体度量定义的行高可能高于或低于字号。height 属性允许手动调整行高，使其成为 fontSize 的倍数。对于大多数字体，将 height 设为 1.0 与省略该属性或将其设为 null 并不相同。下图展示了字体度量定义的行高与使用 height: 1.0（也称 EM 方框）得到的行高之间的差异：

height 属性可用于调整行高。此处将行高设为字号的 5 倍，使文本间距非常大。由于 fontSize 设为 10，最终行高为 50 像素。
link 
const Text(
  'Ladies and gentlemen, you coulda been anywhere in the world tonight, but you’re here with us in New York City.',
  style: TextStyle(height: 5, fontSize: 10),
)

如需在段落级别进一步控制行高，请参阅 StrutStyle。

行间距分布与裁剪

行间距是相邻行中字形之间的垂直空间。数值上，它等于行高（见上一节）减去字体的上升部和下降部。如果 height 足够小，Leading 可能为负值。

当 height 倍数为 null 时，leading 及其分布方式由字体的 度量数据决定。指定 height 倍数后，可以通过 leadingDistribution 和 TextPainter.textHeightBehavior 配置具体行为。

上图并排比较了不同 leadingDistribution 与 TextPainter.textHeightBehavior 的组合效果。

  • 配置 1：默认设置。leadingDistribution 设为 TextLeadingDistribution.proportional.
  • 配置 2：与配置 1 相同，但 TextHeightBehavior.applyHeightToFirstAscent 设为 false.
  • 配置 3：leadingDistribution 设为 TextLeadingDistribution.even.
  • 配置 4：与配置 3 相同，但 TextHeightBehavior.applyHeightToLastDescent 设为 false.

leadingDistribution 属性控制文本上方和下方的行间距如何分布。使用 TextLeadingDistribution.proportional（配置 1）时，Top Leading : Bottom Leading = Font Ascent : Font Descent，这也意味着字母基线按字体上升部和下降部的比例将行高分为两部分。使用 TextLeadingDistribution.even（配置 3）时，Top Leading 等于 Bottom Leading，字形大致居中于分配的行高内。

TextPainter.textHeightBehavior 属性用于控制段落级别的行间距。applyHeightToFirstAscent 属性在 height 和 leadingDistribution 之后应用。将其设为 false 时，如果文本框位于首行，会裁去顶部行间距，使其与字体上升部对齐（参见配置 2）。类似地，将 applyHeightToLastDescent 设为 false 会把末行文本的底部行间距缩减为 0（配置 4）。

黑色文本与红色波浪下划线

样式可以组合使用。此示例将拼写错误的单词显示为黑色，并用红色波浪线加下划线标出。（其余文本采用 Flutter 默认文本样式，而不是环境中的 DefaultTextStyle，因为此处未显式指定样式，且 RichText 不会自动使用环境中的 DefaultTextStyle。）

link 
RichText(
  text: const TextSpan(
    text: "Don't tax the South ",
    children: <TextSpan>[
      TextSpan(
        text: 'cuz',
        style: TextStyle(
          color: Colors.black,
          decoration: TextDecoration.underline,
          decorationColor: Colors.red,
          decorationStyle: TextDecorationStyle.wavy,
        ),
      ),
      TextSpan(
        text: ' we got it made in the shade',
      ),
    ],
  ),
)

边框和描边（前景）

若要创建带边框的文本，应提供一个将 Paint.style 设为 PaintingStyle.stroke 的 Paint，并将其作为 foreground 画笔。以下示例使用 Stack 实现描边和填充效果。

link 
Stack(
  children: <Widget>[
    // Stroked text as border.
    Text(
      'Greetings, planet!',
      style: TextStyle(
        fontSize: 40,
        foreground: Paint()
          ..style = PaintingStyle.stroke
          ..strokeWidth = 6
          ..color = Colors.blue[700]!,
      ),
    ),
    // Solid text as fill.
    Text(
      'Greetings, planet!',
      style: TextStyle(
        fontSize: 40,
        color: Colors.grey[300],
      ),
    ),
  ],
)

渐变（前景）

foreground 属性还可以将渐变等效果应用于文本。此处提供了一个带有 Gradient 着色器的 Paint。

link 
Text(
  'Greetings, planet!',
  style: TextStyle(
    fontSize: 40,
    foreground: Paint()
      ..shader = ui.Gradient.linear(
        const Offset(0, 20),
        const Offset(150, 20),
        <Color>[
          Colors.red,
          Colors.yellow,
        ],
      )
  ),
)

自定义字体

可以按如下方式在 pubspec.yaml 文件中声明自定义字体：

flutter:
  fonts:
    - family: Raleway
      fonts:
        - asset: fonts/Raleway-Regular.ttf
        - asset: fonts/Raleway-Medium.ttf
          weight: 500
        - asset: assets/fonts/Raleway-SemiBold.ttf
          weight: 600
     - family: Schyler
       fonts:
         - asset: fonts/Schyler-Regular.ttf
         - asset: fonts/Schyler-Italic.ttf
           style: italic

family 属性用于指定字体名称，可在 fontFamily 参数中使用。asset 属性是相对于 pubspec.yaml 文件的字体文件路径。weight 属性以 100 到 900 之间的 100 的整数倍指定文件中字形轮廓的粗细；它对应于 FontWeight 类，可用于 fontWeight 参数。style 属性指定文件中的轮廓为 italic 还是 normal；这些值对应于 FontStyle 类，可用于 fontStyle 参数。

若要选择自定义字体，请按下例使用 fontFamily 参数创建 TextStyle：

link 
const TextStyle(fontFamily: 'Raleway')

若要使用软件包中定义的字体系列，必须提供 package 参数。例如，假设上述字体声明位于应用所依赖的 my_package 软件包的 pubspec.yaml 文件中，那么可以如下创建 TextStyle：

const TextStyle(fontFamily: 'Raleway', package: 'my_package')

如果软件包内部也使用其定义的字体，创建文本样式时仍应像上例一样指定 package 参数。

软件包也可以提供未在其 pubspec.yaml 中声明的字体文件。这些文件应放在软件包的 lib/ 文件夹中。字体文件不会自动打包到应用中；应用可以在声明字体时选择性地使用它们。例如，名为 my_package 的软件包可能包含：

lib/fonts/Raleway-Medium.ttf

然后，应用可以像下面这样声明字体：

flutter:
  fonts:
    - family: Raleway
      fonts:
        - asset: assets/fonts/Raleway-Regular.ttf
        - asset: packages/my_package/fonts/Raleway-Medium.ttf
          weight: 500

lib/ 是隐含的，因此不应包含在资源路径中。

在这种情况下，由于字体是在应用本地定义的，创建 TextStyle 时无需提供 package 参数：

link 
const TextStyle(fontFamily: 'Raleway')

支持的字体格式

Flutter 目前支持以下字体格式：

  • .ttc
  • .ttf
  • .otf

Flutter 并非在所有平台上都支持 .woff 和 .woff2 字体。

自定义字体回退

可以提供自定义的 fontFamilyFallback 列表。列表应按尝试顺序排列字体系列名称字符串。

只有当请求的字形不存在于 fontFamily 中时，才会使用 fontFamilyFallback 中的字体。

字体回退顺序如下：

  • fontFamily
  • fontFamilyFallback，按优先级从前到后排列。
  • 系统回退字体会因平台而异。

始终会使用回退顺序中第一个匹配的字形。

fontFamilyFallback 属性常用于为多语言文本区段指定不同字体系列，也可为 emoji 等字形指定单独的字体。

在以下示例中，字体 Raleway 中找不到的字形会依次尝试使用 Noto Sans CJK SC 和 Noto Color Emoji 解析：
link 
const TextStyle(
  fontFamily: 'Raleway',
  fontFamilyFallback: <String>[
    'Noto Sans CJK SC',
    'Noto Color Emoji',
  ],
)

如果所有自定义回退字体系列都已尝试且仍未找到匹配项，或者没有提供自定义回退字体，则会使用平台字体回退。

平台字体差异

默认情况下，不同平台使用的字体有所不同。

  • 平台 Android,Fuchsia、Linux 的默认字体系列为 Roboto。
  • 平台 iOS 的默认字体系列为 SF Pro Display/SF Pro Text。
  • 平台 MacOS 的默认字体系列为 .AppleSystemUIFont。
  • 平台 Windows 的默认字体系列为 Segoe UI。

Flutter 默认字体的发现过程取决于设备上安装的字体，因此不能假设所有默认字体在各设备上都可用或保持一致。

一个已知例子是，Samsung 设备附带的 CJK 字体行间距小于 Android 默认字体。因此，在未指定自定义字体时，Samsung 设备上的文本间距会比其他 Android 设备更紧凑。

如果应用要求字体完全一致，应指定自定义字体以避免这种差异。
