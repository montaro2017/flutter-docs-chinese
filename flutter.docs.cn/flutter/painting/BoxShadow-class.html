BoxShadow 类

盒子投射的阴影。

如果盒子不是矩形（例如带有圆角或呈圆形），BoxShadow 可以投射非矩形阴影。

此类与 CSS 的 box-shadow 类似。

另请参阅：

  • Canvas.drawShadow, which is a more efficient way to draw shadows.
  • PhysicalModel，一种用于显示阴影的 widget。
  • kElevationToShadow，包含 Material Design 中预定义阴影的映射。
  • Shadow, which is the parent class that lacks spreadRadius.
