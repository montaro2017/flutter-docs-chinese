InlineSpanVisitor typedef

InlineSpanVisitor = bool Function(InlineSpan span)

InlineSpan.visitChildren 遍历 InlineSpan 树时，会对每个片段调用此回调。

返回 true 表示应继续遍历；返回 false 则停止访问后续 InlineSpan。
