BorderSide 类

框边框的一侧。

一个 Border 由四个 BorderSide 对象组成：Border.top、Border.left、Border.right 和 Border.bottom。

将 BorderSide.width 设为 0.0 会产生发丝线渲染；更详细的说明请参阅 BorderSide.width。

此示例展示如何通过 BoxDecoration 和 Border 在 Container 中使用 BorderSide 对象来装饰 Text。示例中，文本上方绘有浅蓝色粗边框，下方绘有深蓝色粗边框。
link 
Container(
  padding: const EdgeInsets.all(8.0),
  decoration: BoxDecoration(
    border: Border(
      top: BorderSide(width: 16.0, color: Colors.lightBlue.shade50),
      bottom: BorderSide(width: 16.0, color: Colors.lightBlue.shade900),
    ),
  ),
  child: const Text('Flutter in the sky', textAlign: TextAlign.center),
)

另请参阅：

  • Border, which uses BorderSide objects to represent its sides.
  • BoxDecoration, which optionally takes a Border object.
  • TableBorder, which is similar to Border but has two more sides (TableBorder.horizontalInside 和 TableBorder.verticalInside), both of which are also BorderSide objects.
