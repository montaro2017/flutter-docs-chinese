preferPaintInterior 属性

  1. @重写
bool get preferPaintInterior
重写

指示是否已实现 paintInterior。

如果此 getter 返回 true，ShapeDecoration 等类会优先使用 paintInterior。这样可以更快绘制：无需先通过 getOuterPath 计算形状再调用 Canvas.drawPath 绘制路径，而是可以使用 Canvas.drawRect 或 Canvas.drawCircle 等专用方法直接在 Canvas 上绘制。

默认情况下，此 getter 返回 false。

实现了 paintInterior 的子类应重写此方法并返回 true。只有在能够比 Canvas.drawPath 更快地渲染时，子类才应重写 paintInterior（因此，子类不应在 paintInterior 中调用 Canvas.drawPath）。

另请参阅：

  • paintInterior，其 API 文档包含一个示例实现。

实现

@override
bool get preferPaintInterior => true;
