在画布上绘制相应形状。

对于 ShapeBorder 子类，如果其 preferPaintInterior 方法返回 true，此方法应比使用 Canvas.drawPath 绘制 getOuterPath 提供的路径更快。（如果 preferPaintInterior 返回 false，此方法会在调试模式下断言，在发布模式下不执行任何操作。）

如果 Canvas API 提供了专用方法来绘制相应形状，子类应实现此方法。例如，CircleBorder 会调用 Canvas.drawCircle，而 RoundedRectangleBorder 会调用 Canvas.drawRRect。

实现此方法的子类必须确保调用 paintInterior 与使用相同的 Paint 和 getOuterPath 返回的 Path 调用 Canvas.drawPath 在语义上等效（即渲染出相同像素），并且必须重写 preferPaintInterior 使其返回 true。

例如，绘制矩形的形状可以按如下方式实现 getOuterPath、paintInterior 和 preferPaintInterior：

class RectangleBorder extends OutlinedBorder {
  // ...

  @override
  Path getOuterPath(Rect rect, { TextDirection? textDirection }) {
   return Path()
     ..addRect(rect);
  }

  @override
  void paintInterior(Canvas canvas, Rect rect, Paint paint, {TextDirection? textDirection}) {
   canvas.drawRect(rect, paint);
  }

  @override
  bool get preferPaintInterior => true;

  // ...
}

如果形状只能通过路径绘制，preferPaintInterior 必须返回 false。此时，ShapeDecoration 等类会缓存 getOuterPath 返回的路径，并直接调用 Canvas.drawPath。

实现

@override
void paintInterior(Canvas canvas, Rect rect, Paint paint, {TextDirection? textDirection}) {
  if (eccentricity == 0.0) {
    canvas.drawCircle(rect.center, rect.shortestSide / 2.0, paint);
  } else {
    canvas.drawOval(_adjustRect(rect), paint);
  }
}
