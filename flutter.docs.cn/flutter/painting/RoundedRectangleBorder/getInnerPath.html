创建一个 Path，用于描述边框的内缘。

此路径不得与同一 Rect 对应的 getOuterPath 路径相交。

若要获取描述边框区域本身的 Path，请将返回对象的 Path.fillType 设为 PathFillType.evenOdd，并使用 Path.addPath 将 getOuterPath 返回的路径添加到该对象中。

如果边框依赖文本方向（例如使用“start”和“end”而非“left”和“right”表示），则必须提供非 null 的 textDirection 参数。如果绘制边框时不需要文本方向，该参数可以为 null。

另请参阅：

  • getOuterPath, which creates the path for the outer edge.
  • Path.contains，可用于判断 Offset 是否位于 Path 内。

实现

@override
Path getInnerPath(Rect rect, {TextDirection? textDirection}) {
  final RRect borderRect = borderRadius.resolve(textDirection).toRRect(rect);
  final RRect adjustedRect = borderRect.deflate(side.strokeInset);
  return Path()..addRRect(adjustedRect);
}
