LinearBorder 类

一种类似于 BoxBorder 的 OutlinedBorder，可通过零到四条 LinearBorderEdge 定义矩形（方框）边框；每条边均绘制为一条直线。

每条线的颜色和宽度由 side 定义。将 LinearBorder 与边框边线和形状由 ButtonStyle 定义的类配合使用时，非 null 的 ButtonStyle.side 会覆盖此处指定的值。例如，下面 TextButton 示例中的 LinearBorder 为按钮添加了红色下划线。这是因为 TextButton 的 side 参数会覆盖其 ButtonStyle.shape 的 side 属性。

 TextButton(
   style: TextButton.styleFrom(
     side: const BorderSide(color: Colors.red),
     shape: const LinearBorder(
       side: BorderSide(color: Colors.blue),
       bottom: LinearBorderEdge(),
     ),
   ),
   onPressed: () { },
   child: const Text('Red LinearBorder'),
 )

此类会根据当前 TextDirection 解析自身（参见 Directionality）。在 TextDirection.ltr 下，start 和 end 分别解析为左侧和右侧；在 TextDirection.rtl 下则分别解析为右侧和左侧。

针对仅指定一条边的常见情况，提供了便捷构造函数：LinearBorder.start、LinearBorder.end、LinearBorder.top 和 LinearBorder.bottom。
