applyBoxFit function

FittedSizes applyBoxFit(
  1. BoxFit fit,
  2. Size inputSize,
  3. Size outputSize
)

应用一个 BoxFit 值。

除要应用的 BoxFit 值外，此方法还接收两个尺寸，通常分别表示输入框和输出框的尺寸。具体来说，inputSize 参数表示要适配的完整源内容尺寸，outputSize 表示绘制源内容的矩形尺寸。

此函数会将两个尺寸合并到一个 FittedSizes 对象中并返回。

FittedSizes.source 表示要显示的 inputSize 子区域。如果显示整个输入源，它就等于 inputSize；如果输入源需要裁剪，该尺寸可能会更小。

FittedSizes.destination 表示用于绘制（可能已裁剪的）源内容的 outputSize 子区域。如果 FittedSizes.destination 小于 outputSize，则源内容会留出上下或左右空白。

此方法不规定源尺寸和目标尺寸在输入、输出矩形中的对齐方式。通常它们会居中（例如 BoxDecoration 就是如此，BoxFit 也是按此方式定义的）。Alignment 类提供了便捷方法 Alignment.inscribe，可按下方示例将尺寸解析为矩形。

此函数使用 Paint paint，在 Canvas canvas 上将 dart:ui.Image image 绘制到 Rect outputRect，并应用 BoxFit 算法 fit：
link 
void paintImage(ui.Image image, Rect outputRect, Canvas canvas, Paint paint, BoxFit fit) {
  final Size imageSize = Size(image.width.toDouble(), image.height.toDouble());
  final FittedSizes sizes = applyBoxFit(fit, imageSize, outputRect.size);
  final Rect inputSubrect = Alignment.center.inscribe(sizes.source, Offset.zero & imageSize);
  final Rect outputSubrect = Alignment.center.inscribe(sizes.destination, outputRect);
  canvas.drawImageRect(image, inputSubrect, outputSubrect, paint);
}

另请参阅：

  • FittedBox，一种将此算法应用于另一个 widget 的 widget。
  • paintImage，一个将此算法应用于图像绘制的函数。
  • DecoratedBox、BoxDecoration 和 DecorationImage 三者共同使 widget 层能够访问 paintImage。

实现

FittedSizes applyBoxFit(BoxFit fit, Size inputSize, Size outputSize) {
  if (inputSize.height <= 0.0 ||
      inputSize.width <= 0.0 ||
      outputSize.height <= 0.0 ||
      outputSize.width <= 0.0) {
    return const FittedSizes(Size.zero, Size.zero);
  }

  Size sourceSize, destinationSize;
  switch (fit) {
    case BoxFit.fill:
      sourceSize = inputSize;
      destinationSize = outputSize;
    case BoxFit.contain:
      sourceSize = inputSize;
      if (outputSize.width / outputSize.height > sourceSize.width / sourceSize.height) {
        destinationSize = Size(
          sourceSize.width * outputSize.height / sourceSize.height,
          outputSize.height,
        );
      } else {
        destinationSize = Size(
          outputSize.width,
          sourceSize.height * outputSize.width / sourceSize.width,
        );
      }
    case BoxFit.cover:
      if (outputSize.width / outputSize.height > inputSize.width / inputSize.height) {
        sourceSize = Size(inputSize.width, inputSize.width * outputSize.height / outputSize.width);
      } else {
        sourceSize = Size(
          inputSize.height * outputSize.width / outputSize.height,
          inputSize.height,
        );
      }
      destinationSize = outputSize;
    case BoxFit.fitWidth:
      if (outputSize.width / outputSize.height > inputSize.width / inputSize.height) {
        // Like "cover"
        sourceSize = Size(inputSize.width, inputSize.width * outputSize.height / outputSize.width);
        destinationSize = outputSize;
      } else {
        // Like "contain"
        sourceSize = inputSize;
        destinationSize = Size(
          outputSize.width,
          sourceSize.height * outputSize.width / sourceSize.width,
        );
      }
    case BoxFit.fitHeight:
      if (outputSize.width / outputSize.height > inputSize.width / inputSize.height) {
        // Like "contain"
        sourceSize = inputSize;
        destinationSize = Size(
          sourceSize.width * outputSize.height / sourceSize.height,
          outputSize.height,
        );
      } else {
        // Like "cover"
        sourceSize = Size(
          inputSize.height * outputSize.width / outputSize.height,
          inputSize.height,
        );
        destinationSize = outputSize;
      }
    case BoxFit.none:
      sourceSize = Size(
        math.min(inputSize.width, outputSize.width),
        math.min(inputSize.height, outputSize.height),
      );
      destinationSize = sourceSize;
    case BoxFit.scaleDown:
      sourceSize = inputSize;
      destinationSize = inputSize;
      final double aspectRatio = inputSize.width / inputSize.height;
      if (destinationSize.height > outputSize.height) {
        destinationSize = Size(outputSize.height * aspectRatio, outputSize.height);
      }
      if (destinationSize.width > outputSize.width) {
        destinationSize = Size(outputSize.width, outputSize.width / aspectRatio);
      }
  }
  return FittedSizes(sourceSize, destinationSize);
}
