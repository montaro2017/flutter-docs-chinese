ImageStream 类

指向图像资源的句柄。

ImageStream 表示指向 dart:ui.Image 对象及其比例的句柄（两者由 ImageInfo 对象共同表示）。底层图像对象可能会随时间变化，例如图像正在播放动画，或底层图像资源被修改。

ImageStream 也可以表示尚未加载完成的图像。

ImageStream 对象由 ImageStreamCompleter 对象提供支持。

ImageCache 会在至少添加过一个监听器后，持续将图像视为活动状态，直到监听器数量降为零。ImageStreamCompleter.addOnLastListenerRemovedCallback 方法用于跟踪此信息。

另请参阅：

  • ImageProvider, which has an example that includes the use of an ImageStream in a Widget.
