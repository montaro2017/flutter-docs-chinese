Alignment 类

矩形内的一个点。

Alignment(0.0, 0.0) 表示矩形的中心。从 -1.0 到 +1.0 的距离，等于矩形一侧到另一侧的距离。因此，水平方向（或垂直方向）的 2.0 个单位相当于矩形的宽度（或高度）。

Alignment(-1.0, -1.0) 表示矩形的左上角。

Alignment(1.0, 1.0) 表示矩形的右下角。

Alignment(0.0, 3.0) 表示一个点：它相对于矩形水平居中，并且位于矩形底边下方一个矩形高度处。

Alignment(0.0, -0.5) 表示一个点：它相对于矩形水平居中，垂直位置在顶边与中心之间的中点。

对于高度为 h、宽度为 w 的矩形，Alignment(x, y) 描述该矩形坐标系中的点 (x * w/2 + w/2, y * h/2 + h/2)。

Alignment 使用视觉坐标，即增大 x 会使点从左向右移动。若要支持从右向左的布局，可考虑使用 TextDirection；也可使用 AlignmentDirectional，其点随水平值增大而移动的方向取决于 TextDirection。

许多 widget 会在配置中使用 Alignment，其中最常见的有：

  • Align positions a child according to an Alignment.

另请参阅：

  • AlignmentDirectional, which has a horizontal coordinate orientation that depends on the TextDirection.
  • AlignmentGeometry, which is an abstract type that is agnostic as to whether the horizontal direction depends on the TextDirection.
