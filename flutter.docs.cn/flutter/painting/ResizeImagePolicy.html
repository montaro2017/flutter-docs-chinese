ResizeImagePolicy enum

配置 ResizeImage 的行为。

此策略用于 ResizeImage.policy，以决定如何解释 ResizeImage.width 和 ResizeImage.height 属性。

Values

exact → const ResizeImagePolicy

将图像调整到 ResizeImage.width 和 ResizeImage.height 指定的精确宽高。

如果 ResizeImage.width 和 ResizeImage.height 均不为 null，输出图像就会采用指定的宽高及对应的宽高比，无论该宽高比是否与源图像的固有宽高比一致。这种情况类似于 BoxFit.fill。

如果 width 和 height 中只有一个不为 null，输出图像会按该宽度或高度缩放，另一个维度则取保持图像原始宽高比所需的值。这两种情况分别类似于 BoxFit.fitWidth 和 BoxFit.fitHeight。

如果 ResizeImage.allowUpscaling 为 false（默认值），输出图像的宽度和高度会分别限制在图像的固有宽度和高度以内。这可能导致输出宽高比不同于目标宽高指定的比例，例如高度被向下限制而宽度未受限制时。

fit → const ResizeImagePolicy

按需缩放图像，使其在保持宽高比的同时适配 ResizeImage.width 和 ResizeImage.height 指定的边界框。

如果 ResizeImage.allowUpscaling 为 true，图像会放大或缩小，以尽可能适配边界框；否则只会缩小。

其概念与 BoxFit.contain 类似。
