ImageInfo 类

包含对应缩放比例的 dart:ui.Image 对象。

ImageStream 对象使用 ImageInfo 表示获取到的图像实际数据。

ImageInfo（以及 ui.Image）的释放约定不同于传统约定。传统约定通常要求对象释放由自身创建的成员；而此处的释放约定如下：

  • ImageInfo disposes image, even if it is received as a constructor argument.
  • ImageInfo 应由持有它的对象释放，而不是由创建它的对象释放。
  • It is expected that only one object owns reference to ImageInfo object.

安全提示：

  • 要在对象间共享 ImageInfo 或 ui.Image，请使用 clone 方法。此方法不会复制整个底层图像，只会引用图像及其信息。
  • After passing a ui.Image or ImageInfo reference to another object, release the reference.
