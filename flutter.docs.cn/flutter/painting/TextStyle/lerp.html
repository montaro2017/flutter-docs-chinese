lerp static 方法

TextStyle? lerp(
  1. TextStyle? a,
  2. TextStyle? b,
  3. double t
)

在两个文本样式之间进行插值，以实现动画过渡。

如果两个样式指定的字段不同，插值效果可能不理想。为使过渡保持平滑，对于颜色等可插值字段，实现在整个过渡期间都会采用非 null 值。例如，一个 TextStyle 指定了 fontSize 而另一个没有时，无论 t 的值是多少，返回的 TextStyle 都会使用已指定 fontSize 的那个 TextStyle 中的值。

如果给定的 TextStyle 具有不同的 inherit 值，且两个 TextStyle 都缺少某个可插值字段，此方法会抛出异常，因为这可能导致过渡出现跳变。

t 参数表示时间线上的位置：0.0 表示插值尚未开始，返回 a（或与 a 等价的值）；1.0 表示插值完成，返回 b（或与 b 等价的值）；中间值表示处于 a 与 b 之间时间线的相应位置。插值可以外推到 0.0 和 1.0 之外，因此负值及大于 1.0 的值都有效（Curves.elasticInOut 等曲线很容易产生这些值）。

t 的值通常来自 Animation<double>，例如 AnimationController。

如果 a 或 b 中指定了 foreground，则两者都会被视为具有 foreground 画笔（必要时根据 color 属性创建新的 Paint）。

如果 a 或 b 中指定了 background，则两者都会被视为具有 background 画笔（必要时根据 backgroundColor 属性创建新的 Paint）。

    return a;

  String? lerpDebugLabel;

  if (a == null) {

  if (b == null) {

      inherit: a.inherit,

      backgroundColor: Color.lerp(null, a.backgroundColor, t),
      fontSize: t < 0.5 ? a.fontSize : null,

      if (a.foreground == null && b.foreground == null && a.color == null && b.color == null)
