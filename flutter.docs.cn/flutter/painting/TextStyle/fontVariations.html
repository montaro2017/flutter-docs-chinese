fontVariations 属性

List<FontVariation>? fontVariations
final

影响可变字体呈现方式的 FontVariation 列表。

有些字体是可变字体，可根据可自定义属性的值生成多种字体样式。例如，可变字体可能具有一个字重轴，其取值范围为 1 到 1000。可以使用 FontVariation 设置这些设计轴的值。

例如，若要控制 Roboto Slab 可变字体的字重轴（https://fonts.google.com/specimen/Roboto+Slab）：

const TextStyle(
  fontFamily: 'RobotoSlab',
  fontVariations: <FontVariation>[FontVariation('wght', 900.0)]
)

可以通过 lerp 对字体变体进行插值。如果两个 TextStyle 对象指定了相同的字体变体轴，并且顺序相同，插值速度会最快。另请参阅 lerpFontVariations。

另请参阅：

  • fontFeatures, for font variations that have discrete values.
