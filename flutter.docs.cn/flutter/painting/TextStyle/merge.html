merge 方法

TextStyle merge(
  1. TextStyle? other
)

返回一个新的文本样式，由此样式与给定的 other 样式组合而成。

如果给定的 other 文本样式将 TextStyle.inherit 设为 true，则会用此文本样式中非 null 的属性替换它的 null 属性。也就是说，other 样式会继承此样式的属性。也可以理解为：此样式会用自身属性填补 other 样式中“缺失”的属性。

如果给定的 other 文本样式将 TextStyle.inherit 设为 false，则原样返回给定的 other 样式；other 样式不会继承此样式的属性。

如果给定的文本样式为 null，则返回此文本样式。

color 和 foreground 中必须有一个为 null。如果此样式或 other 指定了 foreground，则它优先于任何 color 参数。

同样，backgroundColor 和 background 中必须有一个为 null。如果此样式或 other 指定了 background，则它优先于任何 backgroundColor 参数。

实现

TextStyle merge(TextStyle? other) {
  if (other == null) {
    return this;
  }
  if (!other.inherit) {
    return other;
  }

  String? mergedDebugLabel;
  assert(() {
    if (other.debugLabel != null || debugLabel != null) {
      mergedDebugLabel =
          '(${debugLabel ?? _kDefaultDebugLabel}).merge(${other.debugLabel ?? _kDefaultDebugLabel})';
    }
    return true;
  }());

  return copyWith(
    color: other.color,
    backgroundColor: other.backgroundColor,
    fontSize: other.fontSize,
    fontWeight: other.fontWeight,
    fontStyle: other.fontStyle,
    letterSpacing: other.letterSpacing,
    wordSpacing: other.wordSpacing,
    textBaseline: other.textBaseline,
    height: other.height,
    leadingDistribution: other.leadingDistribution,
    locale: other.locale,
    foreground: other.foreground,
    background: other.background,
    shadows: other.shadows,
    fontFeatures: other.fontFeatures,
    fontVariations: other.fontVariations,
    decoration: other.decoration,
    decorationColor: other.decorationColor,
    decorationStyle: other.decorationStyle,
    decorationThickness: other.decorationThickness,
    debugLabel: mergedDebugLabel,
    fontFamily: other._fontFamily,
    fontFamilyFallback: other._fontFamilyFallback,
    package: other._package,
    overflow: other.overflow,
  );
}
