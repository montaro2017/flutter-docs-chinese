BoxDecoration 类

不可变对象，用于描述如何绘制一个盒子。

BoxDecoration 类提供多种绘制盒子的方式。

盒子包含 边框 和主体，还可以投射 阴影。

盒子的 形状可以是 BoxShape.circle 或 BoxShape.rectangle。若为 BoxShape.rectangle，可通过 borderRadius 属性将其绘制为圆角矩形（RRect）。

盒子的主体分层绘制。最底层是填充盒子的 颜色；其上是同样填充盒子的 渐变；最上层是 图像，其具体对齐方式由 DecorationImage 类控制。

边框绘制在主体上方；顾名思义，阴影绘制在主体下方。

以下示例将 BoxDecoration 应用于 Container 组件，绘制一张猫头鹰图像，并为其添加粗黑色边框和圆角。

link 
Container(
  decoration: BoxDecoration(
    color: const Color(0xff7c94b6),
    image: const DecorationImage(
      image: NetworkImage('https://flutter.github.io/assets-for-api-docs/assets/widgets/owl-2.jpg'),
      fit: BoxFit.cover,
    ),
    border: Border.all(
      width: 8,
    ),
    borderRadius: BorderRadius.circular(12),
  ),
)

形状或 borderRadius 不会裁剪装饰 Container 的子项。如果需要裁剪，请将裁剪组件（例如 ClipRect、ClipRRect 或 ClipPath）作为 Container 的子项。请注意，裁剪可能会带来较高的性能开销。

另请参阅：

  • DecoratedBox 和 Container 都是可配置 BoxDecoration 对象的 widget。
  • DecoratedSliver，一种可配置 BoxDecoration 的 widget；该装饰会转换为适用于 sliver 的渲染对象。
  • CustomPaint，一种可用于绘制任意图形的 widget。
  • Decoration，用于定义其他装饰的基类。
