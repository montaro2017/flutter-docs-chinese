ImageCache 类

用于缓存图像的类。

实现最多缓存 1000 张图像、总量最多 100 MB 的最近最少使用（LRU）缓存。可通过 maximumSize 和 maximumSizeBytes 调整最大容量。

缓存还会维护一组“活动”引用。如果某个 ImageStreamCompleter 至少添加过一个监听器，且监听器数量之后从未降至零，则对应图像会被视为活动图像。缓存通过 ImageStreamCompleter.addOnLastListenerRemovedCallback 判断监听器是否发生过这种变化。

putIfAbsent 是缓存 API 的主要入口。如果给定键对应的 ImageStreamCompleter 已缓存，则返回该对象；否则先调用给定回调获取对象。无论哪种情况，都会将该键移至“最近使用”位置。

调用方可以使用 containsKey 判断图像是否已在缓存中：如果缓存正在跟踪该图像，且图像处于等待中或已完成状态，则返回 true。若要获取更详细的信息，请使用 statusForKey 方法。

通常不直接使用此类。ImageProvider 类及其子类会自动处理图像缓存。

PaintingBinding 持有此缓存的共享实例，可通过 imageCache 库顶层属性（位于 painting 库）获取。

此示例展示如何提供自定义缓存逻辑并替换全局 imageCache 变量。
link 
/// This is the custom implementation of [ImageCache] where we can override
/// the logic.
class MyImageCache extends ImageCache {
  @override
  void clear() {
    print('Clearing cache!');
    super.clear();
  }
}

class MyWidgetsBinding extends WidgetsFlutterBinding {
  @override
  ImageCache createImageCache() => MyImageCache();
}

void main() {
  // The constructor sets global variables.
  MyWidgetsBinding();
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return Container();
  }
}
