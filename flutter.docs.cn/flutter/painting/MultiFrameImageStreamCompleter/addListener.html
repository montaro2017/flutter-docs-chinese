重写

添加一个监听回调；每当有新的具体 ImageInfo 对象可用或报告错误时，就会调用该回调。如果具体图像已可用或此前已报告错误，此对象会同步通知监听器。

如果 ImageStreamCompleter 在其生命周期内完成并提供多个图像，此监听器的 ImageStreamListener.onImage 会被多次调用。

监听器会收到一个标志，用于指示调用是否同步。如果在渲染对象的绘制函数中添加监听器，应使用此标志避免在绘制期间调用 RenderObject.markNeedsPaint。

如果同一个 listener 被重复注册 N 次，那么图像流完成时（无论是新图像可用还是发生错误），它就会被调用 N 次。同样，若要移除该监听器的所有实例，也需要调用 N 次 removeListener。

listener 收到 ImageInfo 对象时，该 listener 负责释放 ImageInfo.image。

另请参阅：

  • addEphemeralErrorListener，用于添加错误监听器，并在图像首次加载完成或发生错误后自动移除。

实现

@override
void addListener(ImageStreamListener listener) {
  if (!hasListeners && _codec != null && (_currentImage == null || _codec!.frameCount > 1)) {
    _decodeNextFrameAndSchedule();
  }
  super.addListener(listener);
}
