返回用于界定给定选区的一组矩形。

selection 必须是有效范围（即 TextSelection.isValid 为 true）。

boxHeightStyle 和 boxWidthStyle 参数可用于选择 TextBox 的形状。这两个属性分别默认为 ui.BoxHeightStyle.tight 和 ui.BoxWidthStyle.tight。

如果此文本绘制器包含双向文本，一个选区可能对应多个矩形，因为逻辑上连续的文本在视觉上未必连续。

开头或结尾的换行符将表示为宽度为零的 TextBox。

此方法只返回完全落在给定 selection 范围内的字形对应的 TextBox：如果某个字形由多个代码单元组成，而其中只有一部分代码单元位于 selection 中，该字形就会被排除。

实现

List<TextBox> getBoxesForSelection(
  TextSelection selection, {
  ui.BoxHeightStyle boxHeightStyle = ui.BoxHeightStyle.tight,
  ui.BoxWidthStyle boxWidthStyle = ui.BoxWidthStyle.tight,
}) {
  assert(_debugAssertTextLayoutIsValid);
  assert(selection.isValid);
  assert(!_debugNeedsRelayout);
  final _TextPainterLayoutCacheWithOffset cachedLayout = _layoutCache!;
  final Offset offset = cachedLayout.paintOffset;
  if (!offset.dx.isFinite || !offset.dy.isFinite) {
    return <TextBox>[];
  }
  final List<TextBox> boxes = cachedLayout.paragraph.getBoxesForRange(
    selection.start,
    selection.end,
    boxHeightStyle: boxHeightStyle,
    boxWidthStyle: boxWidthStyle,
  );
  return offset == Offset.zero
      ? boxes
      : boxes.map((TextBox box) => _shiftTextBox(box, offset)).toList(growable: false);
}
