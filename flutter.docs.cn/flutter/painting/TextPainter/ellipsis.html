ellipsis 属性

String? get ellipsis

用于省略溢出文本的字符串。如果将此属性设为非空字符串，当文本无法放入指定的最大宽度时，该字符串会替代剩余文本。

具体来说，如果 maxLines 不为 null，且被 maxLines 截断行之前的最后一行超出宽度限制，则省略号会应用于该行；如果 maxLines 为 null，则会应用于第一条宽度超出限制的行。宽度限制是传给 layout 的 maxWidth。

设置此值后，必须在下次调用 paint 之前调用 layout。

系统的上层（例如 Text 组件）使用 TextOverflow 枚举表示溢出效果。TextOverflow.ellipsis 对应于将此属性设为 U+2026 水平省略号（…）。

实现

String? get ellipsis => _ellipsis;
set ellipsis (String? value)

实现

set ellipsis(String? value) {
  assert(value == null || value.isNotEmpty);
  if (_ellipsis == value) {
    return;
  }
  _ellipsis = value;
  markNeedsLayout();
}
