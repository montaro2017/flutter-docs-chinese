BorderDirectional 类

一种由四条边组成的矩形边框，其两侧边会根据阅读方向翻转。

两侧边称为 start 和 end。在从左向右的环境中，start 边绘制在左侧，end 边绘制在右侧；在从右向左的环境中则相反。其余两边是 top 和 bottom。

每条边均由 BorderSide 对象表示。

如果 start 边和 end 边相同，使用 Border 对象比使用 BorderDirectional 对象稍高效。

另请参阅：

  • BoxDecoration 使用此类描述其边缘装饰。
  • BorderSide，用于描述盒子的每一条边。
  • Theme 位于 Material 层，可用于查询适合 MaterialApp 中边框的颜色，如上方“divider”示例所示。
  • pub.dev/packages/non_uniform_border，这是一个用于 ShapeBorder 的非统一边框实现，可通过 "shape" 字段应用于 Material Design 按钮和其他组件。
