Script

Script 类

Script 提供 Dart 语言脚本的相关信息。

tokenPosTable 是一个由 int 数组组成的数组。每个子数组先给出行号，后跟若干 (tokenPos, columnNumber) 对：

[lineNumber, (tokenPos, columnNumber)*]

tokenPos 是用于表示源代码位置的任意整数值。tokenPos 本身没有意义，代码不应依赖返回的具体值。

例如，值如下的 tokenPosTable……

[[1, 100, 5, 101, 8],[2, 102, 7]]

……编码了以下映射：

tokenPos 行 列
100 1 5
101 1 8
102 2 7
