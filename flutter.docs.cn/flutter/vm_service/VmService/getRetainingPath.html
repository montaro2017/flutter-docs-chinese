getRetainingPath RPC 用于查找一条从 targetId 指定的对象到 GC 根的路径（即阻止该对象被垃圾回收的对象）。

如果 isolateId 指向的 isolate 已退出，则返回 Collected Sentinel。

如果 targetId 指向的堆对象已被 VM 的垃圾回收器回收，则返回 Collected Sentinel。

如果 targetId 指向的非堆对象已被删除，则返回 Collected Sentinel。

如果对象句柄尚未过期且对象尚未被回收，则返回一个 RetainingPath。

limit 参数指定保留路径中要报告的最大路径长度。如果路径超过 limit，则会从根端截断。

如果提供了 idZoneId，RPC 响应中 InstancesRef 和 Instances 的临时 ID 将分配到指定的 ID 区域。如果省略 idZoneId，则会为该 isolate 使用默认 ID 区域。有关 ID 区域的更多信息，请参阅 IDs and Names。

另请参阅 RetainingPath。

如果返回了 Sentinel，此方法将抛出 SentinelException。

实现

Future<RetainingPath> getRetainingPath(
  String isolateId,
  String targetId,
  int limit, {
  String? idZoneId,
}) =>
    _call('getRetainingPath', {
      'isolateId': isolateId,
      'targetId': targetId,
      'limit': limit,
      if (idZoneId != null) 'idZoneId': idZoneId,
    });
