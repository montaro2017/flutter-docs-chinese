getSourceReport RPC 用于生成一组与某个 isolate 中源代码位置相关的报告。

reports 参数用于指定要生成哪些报告。reports 参数是一个列表，因此可以基于一致的 isolate 状态同时生成多份报告。reports 参数允许为空（例如，可用于强制编译脚本中的某个子范围）。

可用的报告类型包括：

报告类型 含义
覆盖率 提供代码覆盖率信息
PossibleBreakpoints 提供与以下内容对应的标记位置列表
可作为可能断点的位置。

scriptId 参数用于将报告限制到特定脚本。分析特定脚本时，可以提供 tokenPos 和 endTokenPos 参数中的一个或两个，以将分析限制在脚本的某个子范围内（例如，可用于限制到特定类或函数的范围）。

如果未提供 scriptId 参数，则会为所有已加载的脚本生成报告，并且不允许使用 tokenPos 和 endTokenPos 参数。

forceCompilation 参数可用于强制编译报告范围内的所有函数。强制编译可能导致编译错误，进而终止正在运行的 Dart 程序。如果未提供此参数，则视为其值为 false。

reportLines 参数会将 SourceReportRange.possibleBreakpoints 和 SourceReportCoverage 中的标记位置转换为行号。如果客户端只关心行号，这可以减少所需执行的 RPC 数量。未提供此参数时，视为其值为 false。

libraryFilters 参数适用于收集整个 isolate 的覆盖率。提供该参数后，SourceReport 只会包含 URI 以某个过滤字符串开头的脚本的结果。例如，传入 ["package:foo/"] 可只包含 foo 包中的脚本。

librariesAlreadyCompiled 参数会按库覆盖 forceCompilation 参数，将列表中的库对应值设为 false。当启用了 forceCompilation 并发送多个 getSourceReport RPC 时，此参数可避免重复编译同一个库。使用时，先启用 forceCompilation，缓存每次 getSourceReport RPC 的结果，然后在后续 RPC 的 librariesAlreadyCompiled 中传入此前 SourceReport 提到的所有库。

如果 isolateId 指向的 isolate 已退出，则返回 Collected Sentinel。

另请参阅 SourceReport。

如果返回了 Sentinel，此方法将抛出 SentinelException。

Future<SourceReport> getSourceReport(
  String isolateId,
  /*List<SourceReportKind>*/ List<String> reports, {
  String? scriptId,
  int? tokenPos,
  int? endTokenPos,
  bool? forceCompile,
  bool? reportLines,
  List<String>? libraryFilters,
  List<String>? librariesAlreadyCompiled,
}) =>
    _call('getSourceReport', {
      'isolateId': isolateId,
      'reports': reports,
      if (scriptId != null) 'scriptId': scriptId,
      if (tokenPos != null) 'tokenPos': tokenPos,
      if (endTokenPos != null) 'endTokenPos': endTokenPos,
      if (forceCompile != null) 'forceCompile': forceCompile,
      if (reportLines != null) 'reportLines': reportLines,
      if (libraryFilters != null) 'libraryFilters': libraryFilters,
      if (librariesAlreadyCompiled != null)
        'librariesAlreadyCompiled': librariesAlreadyCompiled,
    });
