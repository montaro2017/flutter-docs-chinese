streamListen 方法

Future<Success> streamListen(
  1. String streamId
)

streamListen RPC 用于订阅 VM 中的流。订阅后，客户端会开始接收该流的事件。

如果客户端已经订阅该流，则返回 RPC 错误代码 103（Stream already subscribed）。

streamId 参数可以是以下已发布的值：

streamId 提供的事件类型
VM VMUpdate, VMFlagUpdate
Isolate IsolateStart, IsolateRunnable, IsolateExit, IsolateUpdate,
IsolateReload, ServiceExtensionAdded
Debug PauseStart, PauseExit, PauseBreakpoint, PauseInterrupted,
PauseException, PausePostRequest, Resume, BreakpointAdded,
BreakpointResolved, BreakpointRemoved, BreakpointUpdated, Inspect, None
Profiler CpuSamples, UserTagChanged
GC GC
Extension Extension
Timeline TimelineEvents, TimelineStreamsSubscriptionUpdate
Logging Logging
Service ServiceRegistered, ServiceUnregistered
HeapSnapshot HeapSnapshot
Timer TimerSignificantlyOverdue

此外，某些嵌入器会提供 Stdout 和 Stderr 流。客户端可通过这些流订阅标准输出和标准错误的写入事件。

streamId 提供的事件类型
Stdout WriteEvent
Stderr WriteEvent

向现有流添加新的事件类型属于 backwards compatible 更改。客户端应妥善处理这种情况，例如发出警告并忽略该事件。

另请参阅 Success。

实现

Future<Success> streamListen(String streamId) =>
    _call('streamListen', {'streamId': streamId});
