invoke RPC 用于对某个接收对象执行常规方法调用，效果类似于 dart:mirror 的 ObjectMirror.invoke。注意，此 RPC 不支持调用 getter、setter 或构造函数。

targetId 可以指向 Library、Class 或 Instance。

argumentId 中的每个元素都可以指向一个 Instance。

如果提供了 disableBreakpoints 并将其设为 true，则忽略此次调用触发的任何断点，包括通过 dart:developer 调用 debugger() 导致的暂停。未提供时默认为 false。

如果提供了 idZoneId，RPC 响应中 InstancesRef 和 Instances 的临时 ID 将分配到指定的 ID 区域。如果省略 idZoneId，则会为该 isolate 使用默认 ID 区域。有关 ID 区域的更多信息，请参阅 IDs and Names。

如果 targetId 或 argumentIds 中的任一元素是已过期的临时 ID，则返回 Expired Sentinel。

如果 targetId 或 argumentIds 中的任一元素指向的对象已被 VM 的垃圾回收器回收，则返回 Collected Sentinel。

如果 isolateId 指向的 isolate 已退出，则返回 Collected Sentinel。

如果调用触发了编译失败，将返回 RPCError 113“表达式编译错误”（Expression compilation error）。

如果执行调用时发生运行时错误，将返回一个 ErrorRef 引用。

如果调用成功求值，将返回一个 InstanceRef 引用。

返回值可以是 InstanceRef 或 ErrorRef。

如果返回了 Sentinel，此方法将抛出 SentinelException。

实现

Future<Response> invoke(
  String isolateId,
  String targetId,
  String selector,
  List<String> argumentIds, {
  bool? disableBreakpoints,
  String? idZoneId,
}) =>
    _call('invoke', {
      'isolateId': isolateId,
      'targetId': targetId,
      'selector': selector,
      'argumentIds': argumentIds,
      if (disableBreakpoints != null)
        'disableBreakpoints': disableBreakpoints,
      if (idZoneId != null) 'idZoneId': idZoneId,
    });
