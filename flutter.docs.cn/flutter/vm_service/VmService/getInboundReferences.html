Future<InboundReferences> getInboundReferences(
  1. String isolateId,
  2. String targetId,
  3. int limit, {
  4. String? idZoneId,
})

返回一组指向由 targetId 指定对象的入向引用。最多返回 limit 个引用。

如果提供了 idZoneId，RPC 响应中 InstancesRef 和 Instances 的临时 ID 将分配到指定的 ID 区域。如果省略 idZoneId，则会为该 isolate 使用默认 ID 区域。有关 ID 区域的更多信息，请参阅 IDs and Names。

引用的顺序未定义（即与分配顺序无关）且不稳定（即使两次调用之间没有执行任何 Dart 代码，对同一对象多次调用此方法也可能得到不同结果）。

这些引用中可能有多个 objectId 指向同一个对象。

这些引用可能包含尚未被垃圾回收、但已经不可达的对象。

如果 targetId 是已过期的临时 ID，则返回 Expired Sentinel。

如果 targetId 指向的对象已被 VM 的垃圾回收器回收，则返回 Collected Sentinel。

如果 isolateId 指向的 isolate 已退出，则返回 Collected Sentinel。

另请参阅 InboundReferences。

如果返回了 Sentinel，此方法将抛出 SentinelException。

实现

Future<InboundReferences> getInboundReferences(
  String isolateId,
  String targetId,
  int limit, {
  String? idZoneId,
}) =>
    _call('getInboundReferences', {
      'isolateId': isolateId,
      'targetId': targetId,
      'limit': limit,
      if (idZoneId != null) 'idZoneId': idZoneId,
    });
