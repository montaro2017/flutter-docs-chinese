createIdZone RPC 用于创建新的 ID zone，以便为指定 isolate 中的实例分配临时 ID。有关 ID zone 的更多信息，请参阅 IDs and Names。

backingBufferKind 含义
ring 使用环形缓冲区作为该 zone 的底层存储。
idAssignmentPolicy 含义
alwaysAllocate 当 RPC 调用指定此 ID zone 时，
该 RPC 响应中的 InstancesRef 和 Instances 将始终
其 id 字段会填入新分配的临时 ID，
即使已有 ID 指向同一实例。
reuseExisting 当 RPC 调用指定此 ID zone 时，
该 RPC 响应中的 InstancesRef 和 Instances 会
尽可能使用已有 ID 填充其 id 字段。
这会额外对 zone 执行一次线性搜索，以检查是否存在已有 ID
— 对响应中返回的每个 InstanceRef 或 Instance 都如此。

capacity 参数可用于指定该 zone 同时可容纳的最大 ID 数量。如果未提供 capacity 参数，则新 zone 的默认容量为 512 个 ID。

VM Service 客户端断开连接时，该客户端创建的所有 Service ID zone 都会被删除。因此，不同客户端之间不应共享 Service ID zone ID。

实现

Future<IdZone> createIdZone(
  String isolateId,
  /*IdZoneBackingBufferKind*/ String backingBufferKind,
  /*IdAssignmentPolicy*/ String idAssignmentPolicy, {
  int? capacity,
}) =>
    _call('createIdZone', {
      'isolateId': isolateId,
      'backingBufferKind': backingBufferKind,
      'idAssignmentPolicy': idAssignmentPolicy,
      if (capacity != null) 'capacity': capacity,
    });
