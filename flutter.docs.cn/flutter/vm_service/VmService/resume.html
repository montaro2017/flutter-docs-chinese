resume RPC 用于恢复已暂停 isolate 的执行。

如果未提供 step 参数，程序将恢复常规执行。

如果提供了 step 参数，则表示要使用哪种单步执行方式。

单步方式 含义
Into 单步执行，并进入函数调用
Over 单步执行，跳过函数调用
Out 单步执行，直到当前函数退出
Rewind 立即退出顶部帧（可多个），而不执行任何代码。
isolate 将在最后退出的函数调用处暂停。

frameIndex 参数仅在 step 参数为 Rewind 时使用。它指定要回退到的堆栈帧。堆栈帧 0 是当前正在执行的函数，因此 frameIndex 必须至少为 1。

如果未提供 frameIndex 参数，则默认为 1。

如果 isolateId 指向的 isolate 已退出，则返回 Collected Sentinel。

另请参阅 Success、StepOption。

如果返回了 Sentinel，此方法将抛出 SentinelException。

实现

Future<Success> resume(String isolateId,
        {/*StepOption*/ String? step, int? frameIndex}) =>
    _call('resume', {
      'isolateId': isolateId,
      if (step != null) 'step': step,
      if (frameIndex != null) 'frameIndex': frameIndex,
    });
