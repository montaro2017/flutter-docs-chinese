evaluate RPC 用于在某个目标的上下文中计算表达式。

targetId 可以指向 Library、Class 或 Instance。

如果 targetId 是已过期的临时 ID，则返回 Expired Sentinel。

如果 targetId 指向的对象已被 VM 垃圾回收器回收，则返回 Collected Sentinel。

如果 isolateId 指向的 isolate 已退出，则返回 Collected Sentinel。

如果提供了 scope，它应是一个从标识符映射到对象 ID 的映射。这些绑定会加入表达式求值所在的作用域；该作用域是类目标或库目标对应类或库的子作用域。这意味着 scope 中提供的绑定可能会遮蔽实例成员、类成员和顶层成员。

如果提供 disableBreakpoints 并将其设为 true，则忽略此次求值导致命中的任何断点。如果未提供，默认值为 false。

如果提供了 idZoneId，RPC 响应中 InstancesRef 和 Instances 的临时 ID 将在指定的 ID zone 中分配。如果省略 idZoneId，则在此 isolate 的默认 ID zone 中分配 ID。有关 ID zone 的更多信息，请参阅 IDs and Names。

如果表达式解析或编译失败，则返回 RPCError 113“表达式编译错误”。

如果表达式求值时发生错误，则返回 ErrorRef 引用。

如果表达式成功求值，则返回 InstanceRef 引用。

返回值可以是 InstanceRef 或 ErrorRef。

如果返回 Sentinel，此方法会抛出 SentinelException。

实现

Future<Response> evaluate(
  String isolateId,
  String targetId,
  String expression, {
  Map<String, String>? scope,
  bool? disableBreakpoints,
  String? idZoneId,
}) =>
    _call('evaluate', {
      'isolateId': isolateId,
      'targetId': targetId,
      'expression': expression,
      if (scope != null) 'scope': scope,
      if (disableBreakpoints != null)
        'disableBreakpoints': disableBreakpoints,
      if (idZoneId != null) 'idZoneId': idZoneId,
    });
