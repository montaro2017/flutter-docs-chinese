getInstances RPC 用于获取属于某个特定类的一组实例。

实例的顺序未定义（即与分配顺序无关）且不稳定（即使两次调用之间没有执行任何 Dart 代码，对同一个类多次调用此方法也可能得到不同结果）。

实例集合可能包含尚未被垃圾回收、但已经不可达的对象。

objectId 是要获取其实例的 Class 的 ID。objectId 必须是某个 Class 的 ID，否则会返回 RPCError。

limit 是要返回的最大实例数。

如果 includeSubclasses 为 true，则集合中会包含指定类的子类实例。

如果 includeImplementers 为 true，则集合中会包含实现指定类的类型的实例。请注意，类的子类也被视为该类的实现者。

如果提供了 idZoneId，RPC 响应中 InstancesRef 和 Instances 的临时 ID 将分配到指定的 ID 区域。如果省略 idZoneId，则会为该 isolate 使用默认 ID 区域。有关 ID 区域的更多信息，请参阅 IDs and Names。

如果 isolateId 指向的 isolate 已退出，则返回 Collected Sentinel。

另请参阅 InstanceSet。

如果返回了 Sentinel，此方法将抛出 SentinelException。

实现

Future<InstanceSet> getInstances(
  String isolateId,
  String objectId,
  int limit, {
  bool? includeSubclasses,
  bool? includeImplementers,
  String? idZoneId,
}) =>
    _call('getInstances', {
      'isolateId': isolateId,
      'objectId': objectId,
      'limit': limit,
      if (includeSubclasses != null) 'includeSubclasses': includeSubclasses,
      if (includeImplementers != null)
        'includeImplementers': includeImplementers,
      if (idZoneId != null) 'idZoneId': idZoneId,
    });
