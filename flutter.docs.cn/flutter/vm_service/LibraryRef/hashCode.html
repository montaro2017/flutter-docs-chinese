重写

此对象的哈希码。

哈希码是一个整数，用于表示会影响 operator == 比较结果的对象状态。

所有对象都有哈希码。Object 实现的默认哈希码仅表示对象的标识；同样，默认的 operator == 实现也只会在对象完全相同时判定它们相等（参见 identityHashCode）。

如果重写 operator ==，使其改为使用对象状态进行比较，也必须更改哈希码以反映该状态；否则，此对象将无法用于基于哈希的数据结构，例如默认的 Set 和 Map 实现。

根据 operator == 判定为相等的对象必须具有相同的哈希码。仅当对象发生会影响相等性判断的变化时，其哈希码才应改变。除此之外，哈希码没有其他要求：同一程序的不同运行之间不必保持一致，也不保证哈希码的分布情况。

不相等的对象可以具有相同的哈希码。严格来说，甚至允许所有实例都具有相同的哈希码；但如果冲突过于频繁，可能会降低基于哈希的数据结构（例如 HashSet 或 HashMap）的效率。

如果子类重写了 hashCode，也应重写 operator == 运算符，以保持一致性。

实现

@override
int get hashCode => id.hashCode;
