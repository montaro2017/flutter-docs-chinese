在给定的 StreamChannel 上创建一个通过 stream 和 sink 通信的新实例。

与 StreamChannel.new 不同，此构造器会强制满足 StreamChannel 文档中列出的保证。它的效率略低于直接包装 stream 和 sink，因此如果它们本身已满足这些保证，应使用 StreamChannel.new。

如果 allowSinkErrors 为 false，则不允许向 sink 传递错误。如果传入错误，连接将关闭，并且该错误会转发到 sink.done。

实现

factory StreamChannel.withGuarantees(Stream<T> stream, StreamSink<T> sink,
        {bool allowSinkErrors = true}) =>
    GuaranteeChannel(stream, sink, allowSinkErrors: allowSinkErrors);
