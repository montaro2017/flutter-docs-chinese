StreamChannelTransformer

StreamChannelTransformer<S, T> 类

StreamChannelTransformer 用于转换传入 StreamChannel 并由其发出的事件。

其原理与 StreamTransformer 和 StreamSinkTransformer 相同。每个转换器都定义一个 bind 方法，该方法接收原始 StreamChannel 并返回转换后的通道。

转换器必须支持多次调用 bind。如果子类显式实现 bind，应确保返回的 stream 满足通道的第二项保证：关闭 sink 后，stream 必须在发出更多事件之前关闭。如果在原始 stream 分发事件与返回的 stream 分发事件之间加入异步间隔（例如通过 StreamTransformer 转换），这项保证就会失效。可以使用 StreamChannel.withCloseGuarantee 轻松保留此保证。
