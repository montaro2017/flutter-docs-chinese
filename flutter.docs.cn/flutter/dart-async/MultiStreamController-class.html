MultiStreamController

MultiStreamController<T> 类 抽象 interface

由 Stream.multi 提供的增强型流控制器。

它的行为类似普通的异步控制器，但也允许同步添加事件。与任何同步事件传递一样，发送方必须谨慎，避免在新侦听器可能尚未准备好接收事件时发送事件。通常只应在响应其他异步事件时同步发送，因为这正是异步事件可能发生的时机。

实现的类型

Available extensions
