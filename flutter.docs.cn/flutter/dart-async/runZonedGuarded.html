在独立的错误 zone 中运行 body。

根据 zoneSpecification 和 zoneValues，使用 Zone.fork 创建新 zone，然后在该 zone 中运行 body 并返回结果。

onError 函数同时用于处理异步错误（如果提供了 zoneSpecification，则通过覆盖其中的 ZoneSpecification.handleUncaughtError 实现），以及处理调用 body 时同步抛出的错误。

如果 body 中同步发生错误，且 onError 处理器抛出异常，则调用 runZonedGuarded 时会抛出该错误；否则调用 runZonedGuarded 会返回 null。

创建的 zone 始终是一个错误 zone。不同 Zone.errorZone 所属 zone 之间，future 中的异步错误不会跨越 zone 边界传播。因此，在属于不同错误 zone 的 zone 中使用时，若某个 Future 在新建 zone 中以错误完成，它看起来可能永远不会完成。在无法访问该错误的 zone 中多次尝试使用此 future，会导致该错误在其原始错误 zone 中再次报告。

实现

R? runZonedGuarded<R>(
  R body(),
  void onError(Object error, StackTrace stack), {
  Map<Object?, Object?>? zoneValues,
  ZoneSpecification? zoneSpecification,
}) {
  _Zone parentZone = Zone._current;
  HandleUncaughtErrorHandler errorHandler =
      (
        Zone self,
        ZoneDelegate parent,
        Zone zone,
        Object error,
        StackTrace stackTrace,
      ) {
        try {
          parentZone.runBinary(onError, error, stackTrace);
        } catch (e, s) {
          if (identical(e, error)) {
            parent.handleUncaughtError(zone, error, stackTrace);
          } else {
            parent.handleUncaughtError(zone, e, s);
          }
        }
      };
  if (zoneSpecification == null) {
    zoneSpecification = ZoneSpecification(handleUncaughtError: errorHandler);
  } else {
    zoneSpecification = ZoneSpecification.from(
      zoneSpecification,
      handleUncaughtError: errorHandler,
    );
  }
  try {
    return _runZoned<R>(body, zoneValues, zoneSpecification);
  } catch (error, stackTrace) {
    onError(error, stackTrace);
  }
  return null;
}
