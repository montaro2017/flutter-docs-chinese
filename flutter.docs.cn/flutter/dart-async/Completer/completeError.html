使用错误完成 future。

complete 或 completeError 最多只能调用一次。

以错误完成 future 表示在尝试生成值时发生了异常。

如果 error 是一个 Future，则 future 本身会作为错误值使用。如果你想以该 future 的结果完成，可以这样写：

thisCompleter.complete(theFuture)

如果只想处理该 future 中的错误，则可以这样写：

theFuture.catchError(thisCompleter.completeError);

必须先为 future 安装错误处理器，再调用 completeError；否则 error 会被视为未捕获错误。

void doStuff() {
  // Outputs a message like:
  // Uncaught Error: Assertion failed: "future not consumed"
  Completer().completeError(AssertionError('future not consumed'));
}

可以通过 Future.catchError、Future.then 或 await 操作安装错误处理器。

void doStuff() {
  final c = Completer();
  c.future.catchError((e) {
    // Handle the error.
  });
  c.completeError(AssertionError('future not consumed'));
}

有关未捕获错误的详情，请参阅 Zones 文章。
