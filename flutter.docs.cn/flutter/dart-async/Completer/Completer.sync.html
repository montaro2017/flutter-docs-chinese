Completer<T>.sync 构造函数

Completer<T>.sync()

同步完成 future。

除非已知 future 的完成就是另一项异步操作的最终结果，否则应避免使用此构造函数。如有疑问，请使用默认的 Completer 构造函数。

使用普通的异步 completer 永远不会导致错误行为，但错误使用同步 completer 可能会使原本正确的程序出错。

同步 completer 仅用于优化事件传播，例如一个异步事件立即触发另一个异步事件。只有在能够保证对 complete 和 completeError 的调用不会破坏 Future 不变量时，才可以使用它。

同步完成意味着：在同步 completer 上调用 complete 或 completeError 时，其 future 会立即完成，并调用所有已注册到该 future 的回调。

同步完成不得违反以下规则：向 future 添加回调后，在添加该回调的代码执行完毕之前，不得调用该回调。因此，同步完成只能发生在另一个同步事件的最末尾（即“尾部位置”）；此时立即完成 future，效果等同于返回事件循环并在下一个微任务中完成 future。

示例：

var completer = Completer.sync();
// The completion is the result of the asynchronous onDone event.
// No other operation is performed after the completion. It is safe
// to use the Completer.sync constructor.
stream.listen(print, onDone: () { completer.complete("done"); });

错误示例。请勿使用此代码；这里只用于说明：

var completer = Completer.sync();
completer.future.then((_) { bar(); });
// The completion is the result of the asynchronous onDone event.
// However, there is still code executed after the completion. This
// operation is *not* safe.
stream.listen(print, onDone: () {
  completer.complete("done");
  foo();  // In this case, foo() runs after bar().
});

实现
