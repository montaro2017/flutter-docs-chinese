doWhile static 方法

Future<void> doWhile(
  1. FutureOr<bool> action()
)

重复执行某项操作，直到它返回 false。

该操作 action 可以是同步的，也可以是异步的。

只要操作返回 bool 值 true，或返回 Future<bool> 并以 true 完成，就会重复调用该操作。

如果调用 action 后返回 false，或返回一个以 false 完成的 Future，迭代就会结束，并且 doWhile 返回的 future 会以 null 值完成。

如果调用 action 时抛出异常，或 action 返回的 future 以错误完成，迭代就会结束，且 doWhile 返回的 future 会以相同错误完成。

调用 action 的时间不受限制，也可能紧接在调用 doWhile 后发生。唯一的限制是：上一次调用返回前不会再次调用 action；如果上一次调用返回了 Future<bool>，则必须等该 future 完成后才会再次调用。

示例：

void main() async {
  var value = 0;
  await Future.doWhile(() async {
    value++;
    await Future.delayed(const Duration(seconds: 1));
    if (value == 3) {
      print('Finished with $value');
      return false;
    }
    return true;
  });
}
// Outputs: 'Finished with 3'

实现

static Future<void> doWhile(FutureOr<bool> action()) {
  @pragma('vm:awaiter-link')
  _Future<void> doneSignal = _Future<void>();
  late void Function(bool) nextIteration;
  // Bind this callback explicitly so that each iteration isn't bound in the
  // context of all the previous iterations' callbacks.
  // This avoids, e.g., deeply nested stack traces from the stack trace
  // package.
  nextIteration = Zone.current.bindUnaryCallbackGuarded((bool keepGoing) {
    while (keepGoing) {
      FutureOr<bool> result;
      try {
        result = action();
      } catch (error, stackTrace) {
        // Cannot use `_completeWithErrorCallback` because it completes
        // the future synchronously.
        doneSignal._asyncCompleteErrorObject(
          _interceptCaughtError(error, stackTrace),
        );
        return;
      }
      if (result is Future<bool>) {
        result.then(nextIteration, onError: doneSignal._completeError);
        return;
      }
      keepGoing = result;
    }
    doneSignal._complete(null);
  });
  nextIteration(true);
  return doneSignal;
}
