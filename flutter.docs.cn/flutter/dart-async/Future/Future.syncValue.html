Future<T>.syncValue 构造函数

  1. @Since.new("3.10")
Future<T>.syncValue(
  1. T value

创建一个以 value 完成的 future。

此 future 保证不会以错误完成。

如果同步计算可能抛出异常，与其调用 Future.syncValue(computation()) 并用 try/catch 包裹，不如使用 Future.sync，它会将异常捕获到返回的 future 中，例如 Future.sync(() => computation())。

实现

@Since("3.10")
factory Future.syncValue(T value) => _Future<T>().._setValue(value);
