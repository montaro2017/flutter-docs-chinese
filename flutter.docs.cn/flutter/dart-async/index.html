dart:async

dart:async 库

提供异步编程支持，包含 Future 和 Stream 等类。

Future 和 Stream 是 Dart 异步编程的基本构件。语言通过 async 和 async* 函数直接支持它们，所有库也都可以通过 dart:core 库使用它们。

此库还提供更多工具，用于创建、消费和转换 Future 与 Stream，也可以直接访问其他异步原语，例如 Timer、scheduleMicrotask 和 Zone。

在代码中使用此库：

import 'dart:async';

Future

Future 对象表示一项计算，其返回值可能暂时尚不可用。计算在未来某个时刻完成后，Future 会返回该计算的值。Future 常用于通过其他线程或 isolate 实现的 API，例如 dart:io 的异步 I/O 操作或 dart:html 的 HTTP 请求。

Dart 库中的许多方法在执行任务时会返回 Future。例如，将 HttpServer 绑定到主机和端口时，bind() 方法会返回 Future。

 HttpServer.bind('127.0.0.1', 4444)
     .then((server) => print('${server.isBroadcast}'))
     .catchError(print);

Future.then 会注册一个回调函数；当 Future 的操作（此处为 bind() 方法）成功完成时，该函数就会运行。操作返回的值会传递给回调函数。在此示例中，bind() 方法返回 HttpServer 对象，回调函数会打印它的一个属性。Future.catchError 会注册一个回调函数，在 Future 内发生错误时运行。

Stream

Stream 提供异步数据序列。数据序列可以是单个事件（例如鼠标点击），也可以是较大数据的连续分块（例如文件内容中的多个字节列表）。下面的示例会打开一个文件进行读取。Stream.listen 会注册回调函数；每当有更多数据可用、发生错误或流结束时，就会运行相应回调。Stream 还提供了其他功能，这些功能通过调用 Stream.listen 获取实际数据来实现。

Stream<List<int>> stream = File('quotes.txt').openRead();
stream.transform(utf8.decoder).forEach(print);

此流会发出一系列字节列表。程序接下来必须以某种方式处理这些列表。这里使用 UTF-8 解码器（由 dart:convert 库提供），将字节序列转换为 Dart 字符串序列。

Stream 的另一个常见用途是在 Web 应用中处理用户生成的事件：以下代码会监听按钮上的鼠标点击。

querySelector('#myButton')!.onClick.forEach((_) => print('Click.'));
