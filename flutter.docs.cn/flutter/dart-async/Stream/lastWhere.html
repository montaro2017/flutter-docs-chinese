Future<T> lastWhere(
  1. bool test(
    1. T element
    ), {
  2. T orElse()?,
})

查找此数据流中最后一个满足 test 条件的元素。

返回一个 future，该 future 会以此数据流中最后一个使 test 返回 true 的元素完成。

如果此数据流结束前未找到这样的元素，且提供了 orElse 函数，则调用 orElse 的结果会成为 future 的值。如果 orElse 抛出异常，返回的 future 会以该错误完成。

如果此数据流在任何时候发出错误，返回的 future 都会以该错误完成，并取消订阅。

此数据流结束前无法提供非错误结果。

此方法类似 firstWhere，但它查找的是最后一个匹配元素，而不是第一个。

示例：

var result = await Stream.fromIterable([1, 3, 4, 7, 12, 24, 32])
    .lastWhere((element) => element % 6 == 0, orElse: () => -1);
print(result); // 24

result = await Stream.fromIterable([1, 3, 4, 7, 12, 24, 32])
    .lastWhere((element) => element % 10 == 0, orElse: () => -1);
print(result); // -1

实现

Future<T> lastWhere(bool test(T element), {T orElse()?}) {
  @pragma('vm:awaiter-link')
  _Future<T> future = _Future();
  late T result;
  bool foundResult = false;
  StreamSubscription<T> subscription = this.listen(
    null,
    onError: future._completeError,
    onDone: () {
      if (foundResult) {
        future._complete(result);
        return;
      }
      if (orElse != null) {
        _runUserCode(orElse, future._complete, future._completeError);
        return;
      }
      var stack = StackTrace.current;
      var error = IterableElementError.noElement();
      _trySetStackTrace(error, stack);
      _completeWithErrorCallback(future, error, stack);
    },
    cancelOnError: true,
  );

  subscription.onData((T value) {
    _runUserCode(() => test(value), (bool isMatch) {
      if (isMatch) {
        foundResult = true;
        result = value;
      }
    }, _cancelAndErrorClosure(subscription, future));
  });
  return future;
}
