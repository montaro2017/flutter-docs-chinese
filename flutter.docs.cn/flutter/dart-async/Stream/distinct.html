distinct 方法

如果数据事件与前一个数据事件相等，则跳过该事件。

返回的数据流与此数据流包含相同事件，但不会连续发出两个相等的数据事件。也就是说，错误会直接传递到返回的数据流；只有与最近一次发出的数据事件不同的数据事件才会传递。

通过提供的 equals 方法判断是否相等。如果未提供该方法，则使用上一个数据元素的 == 运算符。

如果 equals 抛出异常，该数据事件会被替换为包含所抛异常的错误事件。其行为等同于原始数据流发出该错误事件，并且不会改变最近一次发出的数据事件。

如果此数据流是广播流，返回的数据流也会是广播流。如果多次侦听广播流，每个订阅都会各自执行 equals 测试。

示例：

final stream = Stream.fromIterable([2, 6, 6, 8, 12, 8, 8, 2]).distinct();
stream.forEach(print); // Outputs events: 2,6,8,12,8,2.

实现

Stream<T> distinct([bool equals(T previous, T next)?]) {
  return _DistinctStream<T>(this, equals);
}
