drain<E> 方法

Future<E> drain<E>([
  1. E? futureValue
])

丢弃此数据流中的所有数据，但会通知调用方数据流已结束或发生错误。

使用 drain 订阅时，cancelOnError 会设为 true。这意味着此数据流首次发生错误时，future 就会完成，随后订阅会被取消。

如果此数据流发出错误，返回的 future 会以该错误完成，并停止处理。

发生 done 事件时，future 会以指定的 futureValue 完成。

如果 null 不能赋给 E，就必须提供 futureValue。

示例：

final result = await Stream.fromIterable([1, 2, 3]).drain(100);
print(result); // Outputs: 100.

实现

Future<E> drain<E>([E? futureValue]) {
  if (futureValue == null) {
    futureValue = futureValue as E;
  }
  return listen(null, cancelOnError: true).asFuture<E>(futureValue);
}
