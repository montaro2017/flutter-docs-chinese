take 方法

Stream<T> take(
  1. int count
)

最多提供此数据流最前面的 count 个数据事件。

返回一个数据流；如果同时开始侦听，它会发出与此数据流相同的事件，直到此数据流结束或已发出 count 个数据事件为止，此时返回的数据流就会结束。

如果此数据流结束前产生的数据事件少于 count 个，返回的数据流也会发出相同数量的数据事件后结束。

开始侦听返回的数据流时，就会开始侦听此数据流；收到最前面的 count 个数据事件后，就会停止侦听。

因此，如果这是单订阅（非广播）流，在返回的数据流被侦听后，此流就无法再次使用。

如果此数据流是广播流，返回的数据流也会是广播流。在这种情况下，只会统计开始侦听返回的数据流之后产生的事件。

示例：

final stream =
    Stream<int>.periodic(const Duration(seconds: 1), (i) => i)
        .take(60);
stream.forEach(print); // Outputs events: 0, ... 59.

实现

Stream<T> take(int count) {
  return _TakeStream<T>(this, count);
}
