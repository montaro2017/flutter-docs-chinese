Stream<S> map<S>(
  1. S convert(
    1. T event

将此数据流中的每个元素转换为新的流事件。

使用 convert 函数将此数据流中的每个元素转换为新值，并创建一个发出转换结果的新数据流。

对于此数据流中的每个数据事件 o，返回的数据流都会发出一个值为 convert(o) 的数据事件。如果 convert 抛出异常，返回的数据流会改为将其作为错误事件报告。

错误事件和完成事件会原样传递到返回的数据流。

如果此数据流是广播流，返回的数据流也会是广播流。每个侦听器处理每个数据事件时，都会调用一次 convert 函数。如果多次侦听广播流，每个订阅都会针对每个数据事件分别调用 convert。

与 transform 不同，此方法不会将数据流视为单个值拆分出的多个数据块。相反，每个事件都会独立转换，不受前后事件影响；这种做法不一定总是正确。例如，如果一个代理对或多字节 UTF-8 编码被拆分到不同事件中，并分别进行编码或解码，就会产生错误结果。

示例：

final stream =
    Stream<int>.periodic(const Duration(seconds: 1), (count) => count)
        .take(5);

final calculationStream =
    stream.map<String>((event) => 'Square: ${event * event}');
calculationStream.forEach(print);
// Square: 0
// Square: 1
// Square: 4
// Square: 9
// Square: 16

实现

Stream<S> map<S>(S convert(T event)) {
  return _MapStream<T, S>(this, convert);
}
