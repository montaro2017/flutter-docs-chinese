wait 属性

Future<(T1, T2, T3, T4)> get wait

并行等待多个 future。

等待此记录中的所有 future。如果全部成功，则返回包含这些值的记录。

所有 future 都完成后，返回的 future 才会完成。如果其中任何 future 未完成，返回的 future 也不会完成。

如果部分 future 以错误完成，返回的 future 会以 ParallelWaitError 完成。ParallelWaitError.values 是一个记录，包含成功 future 的值；出错的 future 对应 null。ParallelWaitError.errors 是形状相同的记录，成功 future 对应 null，出错的 future 则对应包含该错误的 AsyncError。

实现

Future<(T1, T2, T3, T4)> get wait {
  @pragma('vm:awaiter-link')
  final c = Completer<(T1, T2, T3, T4)>.sync();
  final v1 = _FutureResult<T1>($1);
  final v2 = _FutureResult<T2>($2);
  final v3 = _FutureResult<T3>($3);
  final v4 = _FutureResult<T4>($4);

  _FutureResult._waitAll([v1, v2, v3, v4], (int errors) {
    if (errors == 0) {
      c.complete((v1.value, v2.value, v3.value, v4.value));
    } else {
      c.completeError(
        ParallelWaitError(
          (v1.valueOrNull, v2.valueOrNull, v3.valueOrNull, v4.valueOrNull),
          (v1.errorOrNull, v2.errorOrNull, v3.errorOrNull, v4.errorOrNull),
          errorCount: errors,
          defaultError:
              v1.errorOrNull ??
              v2.errorOrNull ??
              v3.errorOrNull ??
              v4.errorOrNull,
        ),
      );
    }
  });
  return c.future;
}
