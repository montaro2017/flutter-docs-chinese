StreamTransformer

StreamTransformer<S, T> 类 抽象 interface

转换数据流。

调用数据流的 Stream.transform 方法并传入 StreamTransformer 时，数据流会调用该转换器的 bind 方法。随后，Stream.transform 方法会返回生成的数据流。

从概念上说，转换器就是一个封装在类中的 Stream 到 Stream 的函数。

建议编写可重复使用的转换器。

Stream 上的其他转换方法，例如 Stream.map、Stream.where 或 Stream.expand，都可以使用 Stream.transform 实现。因此，StreamTransformer 功能强大，但通常也稍微复杂一些。

StreamTransformer.fromHandlers 构造函数允许分别传入回调，以处理事件、错误和数据流结束。StreamTransformer.fromBind 构造函数会创建一个 StreamTransformer，其 bind 方法通过调用传给构造函数的函数实现。
