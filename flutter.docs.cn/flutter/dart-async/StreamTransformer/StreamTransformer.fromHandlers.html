创建一个将事件委托给指定函数的 StreamTransformer。

复制事件的转换器示例：

stringStream.transform(StreamTransformer<String, String>.fromHandlers(
    handleData: (String value, EventSink<String> sink) {
      sink.add(value);
      sink.add(value);  // Duplicate the incoming events.
    }));

侦听通过调用 bind 返回的转换后数据流时，也会侦听源数据流，并为源数据流中的每个事件调用相应的处理函数。

调用处理函数时会传入事件数据和一个接收端，处理函数可以使用该接收端向转换后的数据流发出事件。

源数据流发生数据事件时，会调用 handleData 处理器。如果省略 handleData，数据事件会直接添加到创建的数据流中，效果等同于使用事件值调用接收端上的 EventSink.add。如果省略 handleData，源数据流的事件类型 S 必须是转换后数据流事件类型 T 的子类型。

源数据流发生错误时，会为每个错误调用 handleError 处理器。如果省略 handleError，错误会直接转发到转换后的数据流中，效果等同于使用错误和堆栈跟踪调用 EventSink.addError。

源数据流关闭并发出完成事件时，会调用 handleDone 处理器。完成处理器不会接收事件值，但仍可在调用 EventSink.close 前发出其他事件。如果省略 handleDone，源数据流发出的完成事件会关闭转换后的数据流。

如果任何处理器对提供的接收端调用 EventSink.close，转换后的接收端就会关闭，且源数据流的订阅会被取消。该处理器之后不能再向接收端添加事件，源数据流也不会再产生事件。

传给事件处理器的接收端只能在调用该处理器期间使用，不得保存起来供之后使用。

以这种方式创建的转换器应当是无状态的。处理器调用之间不应保留状态，因为同一个转换器及其处理器可能用于多个数据流，也可能用于可多次侦听的数据流。如需创建针对每个数据流的处理器，可以使用 StreamTransformer.fromBind，为每个待转换的数据流创建新的 StreamTransformer.fromHandlers。

var controller = StreamController<String>.broadcast();
controller.onListen = () {
  scheduleMicrotask(() {
    controller.addError("Bad");
    controller.addError("Worse");
    controller.addError("Worst");
  });
};
var sharedState = 0;
var transformedStream = controller.stream.transform(
    StreamTransformer<String>.fromHandlers(
        handleError: (error, stackTrace, sink) {
  sharedState++; // Increment shared error-counter.
  sink.add("Error $sharedState: $error");
}));

transformedStream.listen(print);
transformedStream.listen(print); // Listen twice.
// Listening twice to the same stream makes the transformer share the same
// state. Instead of having "Error 1: Bad", "Error 2: Worse",
// "Error 3: Worst" as output (each twice for the separate subscriptions),
// this program emits:
// Error 1: Bad
// Error 2: Bad
// Error 3: Worse
// Error 4: Worse
// Error 5: Worst
// Error 6: Worst
