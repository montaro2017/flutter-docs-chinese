Completer

Completer<T> 类 抽象 interface

用于创建 Future 对象，并在之后为其设置值或错误的方式。

大多数情况下，创建 future 最简单的方法是使用 Future 构造函数来获取一次异步计算的结果：

Future(() { doSomething(); return result; });

如果 future 表示一系列异步计算的结果，也可以使用 Future.then 或 Future 上的类似函数将这些计算串联起来：

Future doStuff(){
  return someAsyncOperation().then((result) {
    return someOtherAsyncOperation(result);
  });
}

如果确实需要从头创建 Future（例如将基于回调的 API 转换为基于 Future 的 API），可以按如下方式使用 Completer：

class AsyncOperation {
  final Completer _completer = new Completer();

  Future<T> doOperation() {
    _startOperation();
    return _completer.future; // Send future object back to client.
  }

  // Something calls this when the value is ready.
  void _finishOperation(T result) {
    _completer.complete(result);
  }

  // If something goes wrong, call this.
  void _errorHappened(error) {
    _completer.completeError(error);
  }
}
