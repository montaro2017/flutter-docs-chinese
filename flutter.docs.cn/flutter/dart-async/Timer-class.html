Timer

Timer 类 抽象 interface

可配置为触发一次或重复触发的倒计时器。

计时器从指定时长开始倒计时至 0。当计时器到达 0 时，会调用指定的回调函数。如需按相同间隔重复倒计时，请使用周期性计时器。

负时长会按 Duration.zero 处理。如果时长在编译时已知为 0，可考虑使用 run。

void main() {
  Timer(const Duration(seconds: 5), handleTimeout);
}

void handleTimeout() {  // callback function
  // Do some work.
}

注意：如果使用 Timer 的 Dart 代码被编译为 JavaScript，浏览器可用的最小时间粒度为 4 毫秒。
