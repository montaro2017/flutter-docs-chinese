StreamSink

StreamSink<S> 类 抽象 interface

用于同步和异步接收流事件的对象。

StreamSink 汇集了 StreamConsumer 和 EventSink 的方法。

EventSink 的方法不能在调用 addStream 时使用。addStream 返回的 Future 一旦以值完成，就可以再次使用 EventSink 的方法。

调用 addStream 时，如果此前已经调用过任何 EventSink 方法，该调用会延迟到 EventSink 方法添加的数据被底层系统消费之后。

使用 EventSink 方法时，可以通过 done Future 捕获错误。

调用 close 时，会返回 done Future。
