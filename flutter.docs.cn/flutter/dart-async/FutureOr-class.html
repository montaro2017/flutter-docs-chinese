FutureOr

FutureOr<T> 类 抽象

表示值可以是 Future<T> 或 T 的类型。

此类声明是内部 future-or-value 泛型类型的公开替代名称；该泛型类型本身并非类。对这个类的引用会解析为内部类型。

任何类都不得扩展、混入或实现 FutureOr，否则会产生编译时错误。

示例

// The `Future<T>.then` function takes a callback [f] that returns either
// an `S` or a `Future<S>`.
Future<S> then<S>(FutureOr<S> f(T x), ...);

// `Completer<T>.complete` takes either a `T` or `Future<T>`.
void complete(FutureOr<T> value);

进阶

FutureOr<int> 类型实际上是 int 和 Future<int> 两种类型的“类型并集”。这种类型并集的定义方式使 FutureOr<Object> 既是 Object 的超类型，也是它的子类型（它是子类型，因为 Object 是并集中的一种类型；它是超类型，因为 Object 是并集中两种类型的超类型）。因此，FutureOr<Object> 等同于 Object。

由此可推得，FutureOr<Object> 等同于 FutureOr<FutureOr<Object>>；而 FutureOr<Future<Object>> 等同于 Future<Object>。
