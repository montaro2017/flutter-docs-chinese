formattedRetainingPath function

Future<String?> formattedRetainingPath(
  1. WeakReference<Object> ref
)

返回指向 WeakReference.target 的格式化保留路径。

如果对象已被垃圾回收或未被保留，则返回 null。

此方法在 Web 和发布模式下不起作用。

若要在 flutter test 中运行此方法，请传入 --enable-vmservice。

此方法也不适用于未由 getInstances 返回的对象。详情请参阅 https://github.com/dart-lang/sdk/blob/3e80d29fd6fec56187d651ce22ea81f1e8732214/runtime/vm/object_graph.cc#L1803。

实现

Future<String?> formattedRetainingPath(WeakReference ref) async {
  if (ref.target == null) return null;
  final connection = await connect();
  final path = await retainingPath(
    connection,
    ref.target,
  );

  if (path == null) return null;
  return retainingPathToString(path);
}
