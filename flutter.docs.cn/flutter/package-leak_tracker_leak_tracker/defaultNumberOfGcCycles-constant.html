defaultNumberOfGcCycles top-level constant

int const defaultNumberOfGcCycles

足以让不可达对象被垃圾回收的完整 GC 周期数的默认值。

此值采用较保守的假设，认为用户希望检测泄漏的频率不高于每秒一次。

理论上，2 个周期应该足够；但如果应用大约 5 分钟没有活动，就会产生误报。

实现

const defaultNumberOfGcCycles = 3;
