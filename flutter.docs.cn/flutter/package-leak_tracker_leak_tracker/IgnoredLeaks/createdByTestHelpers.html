createdByTestHelpers 属性

bool createdByTestHelpers
final

如果为 true，则忽略由测试辅助工具创建的泄漏对象。

如果泄漏跟踪开始时的堆栈跟踪中，在测试主体帧之后包含指向 test 文件夹或 flutter_test package 的帧，则该对象视为由测试辅助工具创建。但以下情况除外：

  • 用于从测试主体调用的方法，例如 runAsync 或 pump
  • 与 testHelperExceptions 匹配的堆栈帧

实现
