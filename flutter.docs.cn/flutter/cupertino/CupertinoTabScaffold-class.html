CupertinoTabScaffold 类

实现 iOS 标签式应用的根布局和行为结构。

脚手架会将标签栏布局在底部，并在标签栏上方布局内容，或使内容延伸到标签栏后方。

必须提供 tabBar 和 tabBuilder。CupertinoTabScaffold 会自动监听所提供的 CupertinoTabBar 点击回调，以切换当前活动标签。

可以使用 controller 指定初始选中标签的索引，并管理后续的标签切换。如果未指定控制器，脚手架会自行创建 CupertinoTabController 并在内部管理。否则，使用完毕后应由 controller 的所有者调用其 dispose。

标签内容会由 tabBuilder 根据当前活动标签的索引构建。tabBuilder 必须能够构建与 tabBar 项目数量相同的页面。非活动标签会移至 Offstage，并停用其动画。

虽然支持添加、移除标签或更改标签顺序，但不建议这样做。这不符合 iOS 人机界面指南，而且 CupertinoTabScaffold 可能会在此过程中丢失部分标签的状态。

将 CupertinoTabView 用作每个标签的根组件，可以支持各标签拥有独立的导航状态和历史记录。每个 CupertinoTabView 都包含一个 Navigator，因此，即使在 CupertinoTabView.builder 中使用不同的 WidgetBuilder 实例重新构建 CupertinoTabView，也不会重建 CupertinoTabView 的导航堆栈或更新界面。构建完成后若要更新 CupertinoTabView 的内容，应从其后代组件触发重建（例如调用 State.setState），而不是从祖先组件触发。

flutter create --sample=cupertino.CupertinoTabScaffold.1 mysample
