CupertinoPage<T> 类

用于创建 Cupertino 风格 PageRoute 的页面。

页面从右侧滑入，退出时沿相反方向滑出。另一页面进入并覆盖它时，页面还会以视差效果向左移动。

对于全屏对话框，页面会从底部滑入，并沿相反方向退出，且不产生视差效果。

默认情况下，创建的模态路由被另一条路由替换后，先前的路由仍会保留在内存中。如果不需要保留它并希望释放所有资源，请将 maintainState 设为 false。

类型 T 指定路由的返回值类型。弹出路由时，可以通过 Navigator.transitionDelegate 提供该值：将可选的 result 参数传给 RouteTransitionRecord.markForPop，该方法由 TransitionDelegate.resolve 调用。

另请参阅：

  • CupertinoPageRoute, for a PageRoute version of this class.
