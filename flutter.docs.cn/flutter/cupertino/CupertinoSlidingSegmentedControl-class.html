CupertinoSlidingSegmentedControl<T extends Object> 类

iOS 13 风格的分段控件。

以水平列表形式显示 Map 中提供的 children widget。用户可以通过点按或在分段控件内拖动，在多个互斥选项之间选择。

分段控件的 children Map 中，每个值都可以是任意 Widget。T 是用于标识各个 widget 并确定选中项的 Map 键的类型。按照 Map 类的要求，所有键必须类型一致且可比较。children 参数必须是有序的 Map，例如 LinkedHashMap；键的顺序决定控件中 widget 的显示顺序。

当用户在未选中的分段上完成有效手势时，控件会调用 onValueChanged 回调。onValueChanged 回调会返回与新选中 widget 关联的 Map 键。通常，使用分段控件的 widget 会监听 onValueChanged 回调，并使用新的 groupValue 重建分段控件，以更新当前选项。

children 会按照 Map 键的顺序，并沿当前 TextDirection 排列。所有子 widget 的尺寸相同。分段控件的高度由最高的子 widget 决定。每个子项的宽度取最宽子项的固有宽度与可用水平空间除以 children 数量两者中的较小值。

也可以为分段控件自定义颜色。使用 thumbColor 和 backgroundColor 参数可以覆盖默认颜色。
