CupertinoNavigationBar 类

iOS 风格的导航栏。

导航栏是一种工具栏，最简形式只需包含一个组件，通常是页面标题。

工具栏两端还可以放置 leading 和 trailing 组件，通常用于操作和导航。

如果未提供 leading 组件，且 automaticallyImplyLeading 为 true（默认值），系统会自动将其设为返回箭头按钮；在全屏对话框中则会设为取消按钮，用于弹出当前路由。

此工具栏应放置在屏幕顶部，系统会自动为操作系统状态栏留出空间。

如果 backgroundColor 的不透明度不为 1.0（默认即如此），导航栏会模糊其后方的内容。

布局选项

CupertinoSliverNavigationBar 会根据滚动动态改变尺寸和布局；这个静态版本则可显示相同的大（展开）或小（折叠）布局。

默认构造函数会显示折叠状态的 CupertinoSliverNavigationBar。如果未提供 middle 组件，且 automaticallyImplyMiddle 为 true（默认值），则会自动使用当前 CupertinoPageRoute 的标题文本。

使用 CupertinoNavigationBar.large 构造函数会显示展开状态的 CupertinoSliverNavigationBar。如果未提供 largeTitle 组件，且 automaticallyImplyTitle 为 true（默认值），则会自动使用当前 CupertinoPageRoute 的标题文本。

转场

当 transitionBetweenRoutes 为 true 时，如果目标路由也包含 CupertinoNavigationBar 或 CupertinoSliverNavigationBar，且其 transitionBetweenRoutes 也设为 true，此导航栏会在路由上方转场，而不是在路由内部转场。如果 transitionBetweenRoutes 为 true，任何 Widget 参数的子树都不能包含 key，因为转场期间该组件会同时出现在树中的多个位置。

默认转场要求每个 PageRoute 中最多只放置一个 CupertinoNavigationBar 或 CupertinoSliverNavigationBar。若要自定义同一路由中多个导航栏的转场行为，请使用 transitionBetweenRoutes 或 heroTag。

在 CupertinoPageScaffold 中使用时，CupertinoPageScaffold.navigationBar 会关闭文本缩放，以匹配原生 iOS 行为。若要覆盖此设置，请将 navigationBar 的每个组件包在 MediaQuery 中，并指定所需的 TextScaler。
