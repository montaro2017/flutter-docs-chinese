CupertinoPageRoute<T> 类

一种模态路由，可通过 iOS 转场动画替换整个屏幕。

页面从右侧滑入，退出时沿相反方向滑出。另一页面进入并覆盖它时，页面还会以视差效果向左移动。

对于全屏对话框，页面会从底部滑入，并沿相反方向退出，且不产生视差效果。

默认情况下，模态路由被另一条路由替换后，先前的路由仍会保留在内存中。如果不需要保留它并希望释放所有资源，请将 maintainState 设为 false。

类型 T 指定路由的返回值类型。弹出路由时，可以通过 Navigator.pop 提供该值，并传入可选的 result 参数。

如果 barrierDismissible 为 true，按下键盘上的 Escape 键会弹出当前路由，并将 null 作为返回值。

另请参阅：

  • CupertinoRouteTransitionMixin, 为此模态路由提供 iOS 转场效果的 mixin。
  • MaterialPageRoute, 一种自适应的 PageRoute，使用适合当前平台的转场效果。
  • CupertinoPageScaffold, 适用于顶部带固定导航栏的单页面应用。
  • CupertinoTabScaffold, 适用于底部带标签栏且包含多个页面的应用。
  • CupertinoPage，此类对应的 Page 版本。
