CupertinoSwitch 类

iOS 风格的开关。

用于切换单个设置的开关状态。

开关本身不维护切换状态。开关状态发生变化时，widget 会调用 onChanged 回调。大多数使用开关的 widget 会监听 onChanged 回调，并使用新的 value 重建开关，以更新其视觉外观。

此示例展示可切换的 CupertinoSwitch。滑块移到轨道另一侧时，开关会在开启和关闭状态之间切换。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=cupertino.CupertinoSwitch.1 mysample

此示例展示如何使用 CupertinoSwitch，并将其放在 CupertinoListTile 中。通过 MergeSemantics，辅助功能工具会将整个 CupertinoListTile 视为一个项目。
link 
MergeSemantics(
  child: CupertinoListTile(
    title: const Text('Lights'),
    trailing: CupertinoSwitch(
      value: _lights,
      onChanged: (bool value) { setState(() { _lights = value; }); },
    ),
    onTap: () { setState(() { _lights = !_lights; }); },
  ),
)
