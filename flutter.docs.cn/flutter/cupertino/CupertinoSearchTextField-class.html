CupertinoSearchTextField 类

外观和行为与 UIKit 的 UISearchTextField 相似的 CupertinoTextField。

此控件默认显示 UISearchTextField 的基本元素，例如“搜索”占位提示、前置搜索图标和后置 X 形清除图标。

若要控制文本框中显示的文本，请使用 controller。例如，若要设置文本框的初始值，可以使用已包含文本的 controller，如下所示：

此示例展示如何为 CupertinoSearchTextField 使用 controller 属性设置初始文本。

要使用此代码示例创建本地项目，请运行：
flutter create --sample=cupertino.CupertinoSearchTextField.1 mysample

建议同时为 onChanged 和 onSubmitted 参数传入 ValueChanged<String>，以便在文本框内容发生变化或通过键盘提交时收到通知：
