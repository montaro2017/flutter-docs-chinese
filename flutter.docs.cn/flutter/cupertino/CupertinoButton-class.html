CupertinoButton 类

iOS 风格的按钮。

接收文本或图标，并在触摸时淡入淡出。也可以选择为按钮设置背景。

padding 默认值为 16.0 像素。在固定高度的父组件（例如 CupertinoNavigationBar）中使用 CupertinoButton 时，应使用较小的内边距，必要时可设为 EdgeInsets.zero，以免较大的 child widget 被裁剪。

保留父级的 IconThemeData，但会将其 IconThemeData.color 覆盖为 CupertinoThemeData.primaryColor；按钮禁用时则使用 CupertinoThemeData.primaryContrastingColor。

此示例展示已启用和已禁用状态的 CupertinoButton，以及 CupertinoButton.filled。
