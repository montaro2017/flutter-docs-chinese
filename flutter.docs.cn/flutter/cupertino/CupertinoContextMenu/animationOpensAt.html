animationOpensAt 属性

double animationOpensAt
final

CupertinoContextMenu 开始动画并进入打开状态的位置。

此值介于 0.0 和 1.0 之间，对应于 builder 动画中的某个位置。向 builder 传入动画时，animationOpensAt 之前的范围对应按下并按住组件时的动画，之后的范围则对应菜单完全打开时的动画。示例请参阅 builder 文档。

实现

static final double animationOpensAt =
    _previewLongPressTimeout.inMilliseconds / _animationDuration;
