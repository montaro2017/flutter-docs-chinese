创建 iOS 风格的文本框。

若要预先填入文本，请将带有初始值的 TextEditingController 传给 controller 参数。

若要在文本为空时显示占位提示，请将 String 传给 placeholder 参数。

将 maxLines 设为 null 可取消行数限制。此模式下，组件的固有高度会随文本行数增加而增长。默认值为 1，即单行文本框；内容超出时会水平滚动。maxLines 不能为零。

当 showCursor 为 false，或 showCursor 为 null（默认值）且 readOnly 为 true 时，不显示文本光标。

如果指定了 maxLength，其值必须大于零。

selectionHeightStyle 和 selectionWidthStyle 属性可用于更改选中高亮区域的形状。它们分别默认为 EditableText.defaultSelectionHeightStyle 和 EditableText.defaultSelectionWidthStyle。

autocorrect、autofocus、clearButtonMode、dragStartBehavior、expands、obscureText、prefixMode、readOnly、scrollPadding、suffixMode、textAlign、selectionHeightStyle、selectionWidthStyle、enableSuggestions 和 enableIMEPersonalizedLearning 属性都不能为 null。

排查常见无障碍问题

自定义用户输入的无障碍播报

若要自定义文字变化触发的用户输入无障碍播报，请使用 SemanticsService.sendAnnouncement 发出所需的播报。

在 iOS 上，当 TextInputFormatter 为货币输入框插入千位分隔符时，屏幕键盘可能会错误播报最近输入的内容。以下示例通过始终将输入框内容播报为美元金额，来抑制默认无障碍播报（\$ 会插入美元符号，$newText 会插入 newText 变量的值）：

onChanged: (String newText) {
  if (newText.isNotEmpty) {
    SemanticsService.sendAnnouncement(
      View.of(context),
      '\$$newText',
       Directionality.of(context),
    );
  }
}

另请参阅：

  • minLines, which is the minimum number of lines to occupy when the content spans fewer lines.
  • expands, to allow the widget to size itself to its parent's height.
  • maxLength, which discusses the precise meaning of "number of characters" and how it may differ from the intuitive meaning.
