minLines 属性

int? minLines
final

当内容行数较少时，输入框仍占用的最小行数。

此值会影响输入框自身的高度，但不会限制用户可输入的总行数。

如果为 null（默认值），文字容器会预留一行的垂直空间，并随着输入内容增加而增高。

可以与 maxLines 配合使用，以实现不同的行为。

如果设置了此值，则必须大于零。如果此值大于 1，maxLines 也必须设为 null 或大于此值。

同时设置 maxLines 时，输入框高度会在指定行数范围内增长。如果 maxLines 为 null，高度会从 minLines 开始按需增长。

以下列出 minLines 和 maxLines 可实现的一些行为示例。这些示例同样适用于 TextField、TextFormField、CupertinoTextField 和 EditableText。

输入框始终至少占用两行，最大行数不受限，并会根据内容按需增高。

TextField(minLines: 2)

输入框高度从两行开始，最多增至四行；达到高度限制后，继续输入的内容会垂直滚动。

const TextField(minLines:2, maxLines: 4)

默认为 null。
