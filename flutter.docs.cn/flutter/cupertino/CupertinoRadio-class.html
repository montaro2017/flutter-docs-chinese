CupertinoRadio<T> 类

使用 macOS 风格界面构建 RawRadio 的 widget。

用于在多个互斥值之间进行选择。选中组中的一个单选按钮时，组内其他按钮会取消选中。值的类型为 T，也就是 CupertinoRadio 类的类型参数。此场景中常使用枚举。

此 widget 通常位于 RadioGroup 后代中。RadioGroup.groupValue 提供当前分组值，其下 CupertinoRadio 的 value 与之匹配时便会被选中。

以下示例展示了放在 CupertinoListTile 中的 CupertinoRadio widget。

当前选中的字符会传入 RadioGroup.groupValue，并由示例的 State 保存。本例中，第一个 CupertinoRadio 初始处于选中状态，因为 _character 初始化为 SingingCharacter.lafayette。

点按第二个单选按钮后，示例会通过 setState 更新状态，将 _character 改为 SingingCharacter.jefferson。这会使按钮使用更新后的 RadioGroup.groupValue 重新构建，因此第二个按钮会被选中。
