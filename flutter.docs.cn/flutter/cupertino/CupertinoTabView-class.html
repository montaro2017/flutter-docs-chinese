CupertinoTabView 类

一个独立的标签视图，拥有自己的 Navigator 状态和导航历史。

典型用法是将标签视图作为 CupertinoTabScaffold 中每个标签的内容，使多个具有独立导航状态和历史记录的标签能够并存。

CupertinoTabView 会按以下顺序配置顶层 Navigator 来查找路由：

  1. 对于 / 路由，如果 builder 属性不为 null，则使用该属性。

  2. 否则，如果 routes 表中包含该路由的条目，则使用该表；当未指定 builder 时，表中也可以包含 / 路由。

  3. 否则，如果提供了 onGenerateRoute，则调用它。对于 builder 和 routes 未处理的任何有效路由，它都应返回非 null 值。

  4. 如果以上方式都无法处理，则最后调用 onUnknownRoute。

这些导航属性不会与同级的其他 CupertinoTabView，也不会与任何祖先或后代 Navigator 实例共享。

如果要将路由推送到此 CupertinoTabView 上方，而不是推送到它内部（例如，要在所有标签上方显示对话框），请使用 Navigator.of(rootNavigator: true)。

另请参阅：

  • CupertinoTabScaffold, a typical host that supports switching between tabs.
  • CupertinoPageRoute, a typical modal page route pushed onto the CupertinoTabView's Navigator.
