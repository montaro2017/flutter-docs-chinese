CupertinoContextMenu 类

长按 child 时打开的全屏模态路由。

打开后，CupertinoContextMenu 会在大型全屏 Overlay 中显示 child，并展示由 actions 指定的按钮列表。child 预览内容放在 Expanded widget 中；如果其尺寸不受约束，就会扩展并填满 Overlay。

关闭时，CupertinoContextMenu 会像不存在一样显示 child；也就是说，CupertinoContextMenu 不会影响 child 的尺寸和位置。与其他 PopupRoute 一样，可以通过点按背景或调用 Navigator.pop(context) 关闭菜单。不同于普通的 PopupRoute，它还支持向下滑动关闭。

此示例展示一个简单的 CupertinoContextMenu，用于呈现 Flutter 标志。长按标志即可打开菜单。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=cupertino.CupertinoContextMenu.1 mysample
