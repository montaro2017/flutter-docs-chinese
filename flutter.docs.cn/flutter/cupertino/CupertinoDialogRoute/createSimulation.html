创建驱动此路由转场动画的模拟器。

默认情况下，此方法返回 null，表示路由不使用模拟器，而是通过调用 AnimationController.forward 或 AnimationController.reverse，并使用 transitionDuration 和控制器的曲线来启动转场。

子类可以重写此方法并返回非 null 的 Simulation。此时，controller 会改用提供的模拟，通过 AnimationController.animateWith 或 AnimationController.animateBackWith 为转场添加动画，并将 Simulation.x 转发为 animation 的值。controller 的曲线和 transitionDuration 将被忽略。

每次 Navigator 推入或弹出此路由时都会调用此方法。forward 参数表示转场方向：推入路由时为 true，弹出时为 false。

实现

@override
Simulation createSimulation({required bool forward}) {
  assert(!debugTransitionCompleted(), 'Cannot reuse a $runtimeType after disposing it.');
  final end = forward ? 1.0 : 0.0;
  return SpringSimulation(
    _kStandardSpring,
    controller!.value,
    end,
    0,
    tolerance: _kStandardTolerance,
    snapToEnd: true,
  );
}
