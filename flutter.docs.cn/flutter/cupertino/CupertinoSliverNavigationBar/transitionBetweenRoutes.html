transitionBetweenRoutes 属性

bool transitionBetweenRoutes
final

是否在导航栏之间执行过渡动画。

当 transitionBetweenRoutes 为 true 时，如果目标路由也包含 CupertinoNavigationBar，或包含 transitionBetweenRoutes 为 true 的 CupertinoSliverNavigationBar，此导航栏会在路由上方过渡，而不是在路由内部过渡。

与 iOS 一样，边缘返回滑动手势也会触发此过渡，但只有当下方的前一页面所属 PageRoute 将 maintainState 设为 true 时才会触发。

设为 true 时，每个路由只能有一个导航栏，除非同时设置了 heroTag。

此值默认为 true。
