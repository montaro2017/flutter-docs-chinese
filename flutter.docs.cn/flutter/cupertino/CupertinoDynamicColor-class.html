CupertinoDynamicColor
description

CupertinoDynamicColor 类

表示一组颜色及该颜色组中当前生效颜色的 Color 子类。

作为普通颜色使用时，CupertinoDynamicColor 等同于当前生效颜色（即已弃用的 CupertinoDynamicColor.value 会取自生效颜色）。生效颜色由最后一次解析它时所用的 BuildContext 决定。如果从未解析过，则使用浅色、普通对比度、基础层级的 CupertinoDynamicColor.color 作为默认生效颜色。

有时无需手动解析 CupertinoDynamicColor，因为 Cupertino 库内置了对它的支持。

在 Cupertino widget 中使用 CupertinoDynamicColor

如果将 CupertinoDynamicColor 直接传给 Cupertino widget 的构造函数，或通过该 widget 所依赖的 InheritedWidget（例如 DefaultTextStyle）提供，widget 通常会尽力使用自身的 BuildContext 调用 CupertinoDynamicColor.resolve 自动解析颜色。

默认情况下，CupertinoButton 没有背景色。下面的示例代码会创建一个 CupertinoButton，使其在浅色模式下显示为白色，并在深色模式下自动变为黑色。
link 
CupertinoButton(
  // CupertinoDynamicColor works out of box in a CupertinoButton.
  color: const CupertinoDynamicColor.withBrightness(
    color: CupertinoColors.white,
    darkColor: CupertinoColors.black,
  ),
  onPressed: () { },
  child: child,
)

从 CupertinoTheme 中使用 CupertinoDynamicColor

引用 CupertinoTheme 的颜色时，通常颜色已经适配当前的 BuildContext，因为 CupertinoTheme.of 会在返回获取到的 CupertinoThemeData 前，隐式解析其中使用的所有颜色。

下面的代码示例使用当前主题的 primaryColor 创建一个 Container。如果 primaryColor 是 CupertinoDynamicColor，多亏了 CupertinoTheme.of，容器会自动适配：开启深色模式后切换为 primaryColor 的深色变体；当环境中的 MediaQueryData.highContrast 请求 MediaQuery 时，则切换为 primaryColor 的高对比度变体，等等。
link 
Container(
  // Container is not a Cupertino widget, but CupertinoTheme.of implicitly
  // resolves colors used in the retrieved CupertinoThemeData.
  color: CupertinoTheme.of(context).primaryColor,
)

手动解析 CupertinoDynamicColor

将 CupertinoDynamicColor 用于配置非 Cupertino widget，或将它包装在接收方 Cupertino 组件无法识别的对象中时，绘制前可能需要先手动调用 CupertinoDynamicColor.resolve 解析颜色。例如，要在 CupertinoNavigationBar 中使用自定义 Border，必须先手动解析 Border 中使用的颜色，再将其传给 CupertinoNavigationBar 的构造函数。

以下代码示例展示了必须手动解析 CupertinoDynamicColor 的两种情况。
link 
CupertinoNavigationBar(
  // CupertinoNavigationBar does not know how to resolve colors used in
  // a Border class.
  border: Border(
    bottom: BorderSide(
      color: CupertinoDynamicColor.resolve(CupertinoColors.systemBlue, context),
    ),
  ),
)

// ...

Container(
  // Container is not a Cupertino widget.
  color: CupertinoDynamicColor.resolve(CupertinoColors.systemBlue, context),
)

另请参阅：

  • CupertinoUserInterfaceLevel：一种可能影响 CupertinoDynamicColor 颜色解析的 InheritedWidget。
  • CupertinoTheme.of：一个静态方法，用于获取当前环境中的 CupertinoThemeData，并解析其中使用的 CupertinoDynamicColor。
