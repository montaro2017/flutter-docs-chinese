CupertinoCheckbox 类

macOS 风格的复选框。

复选框本身不维护状态。状态发生变化时，widget 会调用 onChanged 回调。大多数使用复选框的 widget 会监听 onChanged 回调，并使用新的 value 重建复选框，以更新其视觉外观。

如果 tristate 为 true，复选框可以显示 true、false 和 null 三种值。value 为 null 时会显示短横线。默认情况下，tristate 为 false，此时复选框的 value 必须为 true 或 false。

Apple《人机界面指南》（HIG）建议在 macOS 上使用复选框，但没有明确说明是否应在 iOS 上使用。若 iOS 应用需要多选组件，HIG 建议改用开关（Flutter 中对应 CupertinoSwitch），或设计合适的自定义方案。

从视觉上看，复选框是一个边长为 CupertinoCheckbox.width 像素的正方形。不过，widget 的点击区域和布局尺寸取决于平台：

  • 在桌面设备上，点击区域与视觉尺寸相同。
  • 在移动设备上，点击区域会扩展为边长为 kMinInteractiveDimensionCupertino 像素的正方形，以符合无障碍指南。
