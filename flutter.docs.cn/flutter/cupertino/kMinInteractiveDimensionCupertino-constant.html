kMinInteractiveDimensionCupertino top-level constant

double const kMinInteractiveDimensionCupertino

根据 iOS 人机界面指南，任意可交互区域的最小尺寸。

此尺寸用于避免区域过小而难以操作。它同时适用于区域的宽和高，因此，尺寸为 kMinInteractiveDimension × kMinInteractiveDimension 的正方形是能够响应手势的最小合格区域。

另请参阅：

  • kMinInteractiveDimension
  • developer.apple.com/ios/human-interface-guidelines/visual-design/adaptivity-and-layout/

实现

const double kMinInteractiveDimensionCupertino = 44.0;
