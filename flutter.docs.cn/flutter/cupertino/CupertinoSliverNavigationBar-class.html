CupertinoSliverNavigationBar 类

这是一个采用 iOS 风格的导航栏，通过 sliver 实现 iOS 11 风格的大标题。

CupertinoSliverNavigationBar 必须放在 sliver 组中，例如 CustomScrollView。

此导航栏由两部分组成：顶部固定的静态区域，以及下方包含 iOS 11 风格大标题的滑动区域。

应将它放在屏幕顶部；它会自动为 iOS 状态栏留出空间。

此导航栏仅在纵向模式下展开。在横向模式下，导航栏会一直保持收起状态；在纵向模式下滚动时，导航栏也会收起。

至少需要提供一个 largeTitle widget：sliver 收起时，它会显示在应用栏中央；sliver 展开时，它会移到下方并以更大的字号显示。此展开视图仅会在纵向模式下出现；横向模式下，导航栏会保持收起状态。

如需更灵活的布局，可以提供可选的 middle widget，在 sliver 收起时于导航栏中央显示另一个 widget。

与 CupertinoNavigationBar 一样，它也支持在顶部静态区域放置 leading 和 trailing widget；滚动时该区域会保持不动。

如果未提供 leading widget，且 automaticallyImplyLeading 为 true（默认值），它会自动显示返回箭头按钮；如果当前是全屏对话框，则显示取消按钮。点击按钮会弹出当前路由。

如果未提供 largeTitle widget，且 automaticallyImplyTitle 为 true（默认值），它会自动使用当前 CupertinoPageRoute 的标题文本。

当 transitionBetweenRoutes 为 true 时，如果目标路由也包含 CupertinoNavigationBar 或 CupertinoSliverNavigationBar，并且目标导航栏的 transitionBetweenRoutes 也设为 true，此导航栏会在路由上方过渡，而不是在路由内部过渡。只有启用 transitionBetweenRoutes 时，各个 Widget 参数的子树都不能包含 GlobalKey，因为过渡期间这些 widget 会同时出现在树中的多个位置。

默认情况下，每个 PageRoute 中应只放置一个 CupertinoNavigationBar 或 CupertinoSliverNavigationBar，以支持默认过渡效果。若要在同一路由中使用多个导航栏，可通过 transitionBetweenRoutes 或 heroTag 自定义过渡行为。

stretch 参数用于控制导航栏是否拉伸以填充过度滚动区域。用户滚动时，导航栏仍可展开和收起；如果 stretch 的值为 true，用户过度滚动时导航栏还会拉伸。默认值为 false。
