CupertinoIcons 类 抽象 final

Cupertino 图标集中受支持图标的标识符。

与 Icon 类配合使用，以显示指定图标。

每个图标都使用下方列出的名称进行标识。

使用此类之前，请确保在项目的 pubspec.yaml 文件中添加对 cupertino_icons 的依赖。这样可确保应用中包含 CupertinoIcons 字体，该字体用于显示图标。例如：

name: my_awesome_application

dependencies:
  cupertino_icons: ^1.0.0

此示例展示如何创建一行不同颜色和大小的 Cupertino Row 布局中的 Cupertino Icon。第一个 Icon 使用 Icon.semanticLabel，以便 VoiceOver 等辅助功能模式朗读图标信息。

link 
const Row(
  mainAxisAlignment: MainAxisAlignment.spaceAround,
  children: <Widget>[
    Icon(
      CupertinoIcons.heart_fill,
      color: Colors.pink,
      size: 24.0,
      semanticLabel: 'Text to announce in accessibility modes',
    ),
    Icon(
      CupertinoIcons.bell_fill,
      color: Colors.green,
      size: 30.0,
    ),
    Icon(
      CupertinoIcons.umbrella_fill,
      color: Colors.blue,
      size: 36.0,
    ),
  ],
)
