CupertinoTextField 类

iOS 风格的文本框。

文本框允许用户通过硬件键盘或屏幕键盘输入文本。

在 iOS 上，此 widget 对应 UITextField 和可编辑的 UITextView。

用户更改文本框中的文本时，文本框会调用 onChanged 回调。如果用户表示已完成输入（例如按下软键盘上的按钮），文本框会调用 onSubmitted 回调。

处理可能包含复杂字符的用户输入时，务必使用 characters。这样可以确保扩展字素簇和代理项对按用户所见被视为单个字符。

例如，获取用户输入长度时，请使用 string.characters.length。不要使用 string.length，也不要使用 string.runes.length。复杂字符“👨‍👩‍👦”在用户看来是一个字符，因此 string.characters.length 会直观地返回 1；而 string.length 会返回 8，string.runes.length 会返回 5！

controller 也可以控制选区和组合输入区域，并监听文本、选区及组合输入区域的变化。

文本框提供可覆盖的 decoration，默认会在文本框周围绘制圆角矩形边框。将 decoration 属性设为 null，即可完全移除装饰。

组件获得焦点时，会通过底层 EditableText 的 AutomaticKeepAliveClientMixin.wantKeepAlive 暂缓销毁，以避免丢失选区。移除焦点后即可销毁。

不再需要时，记得调用 TextEditingController.dispose。这样可以释放该对象使用的资源。

聚焦时保持插入光标可见

获得焦点时，此 widget 会尝试在以下情况下保持文本区域及其插入光标可见（即使 showCursor 为 false）：

  • 用户将焦点放到文本框上，且 readOnly 不为 true 时。
  • 用户更改文本框选区，或在 readOnly 不为 true 时更改文本。
  • 虚拟键盘弹出时。

滚动注意事项

如果此 CupertinoTextField 不在 Scaffold 后代中，且位于 Scrollable 或嵌套的 Scrollable 中，请考虑在包含此 CupertinoTextField 的根 Scrollable 上方放置 ScrollNotificationObserver，以确保 CupertinoTextField 及其组件（例如 TextSelectionOverlay）能够正确协调滚动。
