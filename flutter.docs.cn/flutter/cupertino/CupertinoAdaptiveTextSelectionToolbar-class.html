description

CupertinoAdaptiveTextSelectionToolbar 类

在当前平台上，使用给定子组件显示的默认 Cupertino 文本选择上下文菜单。

它会在所有移动平台（不只 iOS）上构建移动版 Cupertino 上下文菜单，并在所有桌面平台（不只 macOS）上构建桌面版菜单。若要构建在所有平台上都呈现原生外观的上下文菜单，请参阅 AdaptiveTextSelectionToolbar。

另请参阅：

  • AdaptiveTextSelectionToolbar：功能与此 widget 相同， 但支持所有平台，而不局限于 Cupertino 风格的平台。
  • CupertinoAdaptiveTextSelectionToolbar.getAdaptiveButtons, which builds 会根据当前平台和给定的 ContextMenuButtonItem 构建 Cupertino 按钮 widget。
