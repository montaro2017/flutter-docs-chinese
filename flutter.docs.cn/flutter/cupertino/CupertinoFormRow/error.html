error 属性

Widget? error
final

显示在 prefix 和 child 组件下方的组件。

error 组件主要用于告知用户输入错误。如果将 Text 传给 error，文本会以 CupertinoColors.destructiveRed 颜色和中等字重显示。行高会增加，以便在 prefix 和 child 下方显示 helper 组件。为 null 时，行高较短。
