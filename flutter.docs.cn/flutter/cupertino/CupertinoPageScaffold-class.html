CupertinoPageScaffold 类

用于实现单个 iOS 应用页面的布局。

此脚手架会将导航栏放在顶部，并将页面内容布局在导航栏下方或其后方。

点按页面顶部的状态栏时，当前主 ScrollView 会播放动画并滚动到起始位置。此功能通过包裹 ScrollView 的 PrimaryScrollController 实现。ScrollView.primary 标志用于将 ScrollView 连接到外层的 PrimaryScrollController。

此示例展示 CupertinoPageScaffold，其中 Center 是 child。 CupertinoButton 连接到一个会递增计数器的回调。 可以更改 backgroundColor。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=cupertino.CupertinoPageScaffold.1 mysample

另请参阅：

  • CupertinoTabScaffold，用于标签式应用的类似 widget。
  • CupertinoPageRoute，一种通常承载 CupertinoPageScaffold并支持 iOS 风格页面转场的模态页面路由。
