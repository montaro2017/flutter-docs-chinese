根据具体的子组件列表创建选择器。

itemExtent 必须大于零。

backgroundColor 默认为 null，即完全禁用背景绘制（选择器背景完全透明），以匹配原生 UIPicker 和 UIDatePicker。此外，如果背景色包含透明度，则不会绘制渐变效果。

scrollController 参数可用于指定自定义的 FixedExtentScrollController，以便通过代码读取或更改当前选择器索引，或设置初始索引。

looping 参数决定子组件列表是否循环并可无限滚动。如果设为 true，滚动超过列表末尾时会从头开始。如果设为 false，滚动到列表开头或末尾时就会停止。

CupertinoPicker({
  super.key,
  this.diameterRatio = _kDefaultDiameterRatio,
  this.backgroundColor,
  this.offAxisFraction = 0.0,
  this.useMagnifier = false,
  this.magnification = 1.0,
  this.scrollController,
  this.squeeze = _kSqueeze,
  this.changeReportingBehavior = ChangeReportingBehavior.onScrollUpdate,
  required this.itemExtent,
  required this.onSelectedItemChanged,
  required List<Widget> children,
  this.selectionOverlay = const CupertinoPickerDefaultSelectionOverlay(),
  bool looping = false,
}) : assert(diameterRatio > 0.0, RenderListWheelViewport.diameterRatioZeroMessage),
     assert(magnification > 0),
     assert(itemExtent > 0),
     assert(squeeze > 0),
     childDelegate = looping
         ? ListWheelChildLoopingListDelegate(children: children)
         : ListWheelChildListDelegate(children: children);
