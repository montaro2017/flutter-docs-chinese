CupertinoScrollbar 类

iOS 风格的滚动条。

若要为 ScrollView 添加滚动条，请使用 CupertinoScrollbar widget 包裹滚动视图 widget。

滚动条滑块指示 ScrollView 当前实际可见的部分。

默认情况下，子滚动视图滚动时，滑块会淡入淡出。将 thumbVisibility 设为 true 后，滑块会一直显示，不再播放淡入淡出动画。此时必须将与 Scrollable widget 关联的 ScrollController 传给 controller，或者让该 Scrollable widget 使用 PrimaryScrollController。

如果滚动条包裹多个 ScrollView，默认只响应最近的 ScrollView，并显示对应的滑块。通过 notificationPredicate 可以自定义滚动条监听哪些 ScrollNotification。

如果子 ScrollView 无限长，RawScrollbar 将不会绘制。在这种情况下，滚动条无法准确表示可视区域的相对位置，也无法准确计算拖动滑块或点按轨道时应应用的滚动距离。

交互

滚动条支持交互；未设置 controller 时，可以使用 PrimaryScrollController。可拖动交互式滚动条滑块，使其沿 ScrollView 主轴移动，从而改变 ScrollPosition。点按滑块以外的轨道区域时，会根据该位置与滑块的相对位置触发基于 ScrollIncrementType.page 的滚动。

使用 PrimaryScrollController 时，它不能同时附加到多个 ScrollPosition。未指定 ScrollController 且 ScrollView.scrollDirection 为 Axis.vertical 的 ScrollView 会自动将其 ScrollPosition 附加到 PrimaryScrollController。此时应为每个 Scrollable 提供唯一的 ScrollController，以避免多个 ScrollPosition 同时附加到 PrimaryScrollController。

此示例展示同一路由中包含两个可滚动组件的应用。默认情况下，每个路由都有一个 PrimaryScrollController，而且两个组件的滚动方向都是 Axis.vertical，因此在移动平台上它们都会尝试连接到该控制器。Scrollbar 不支持同一控制器连接多个滚动位置，因此其中一个 ListView 及其 Scrollbar 使用了独立的 ScrollController。桌面平台不会自动连接到 PrimaryScrollController；若要使用它，需将 ScrollView.primary 设为 true。

或者，也可以在其中一个 ListView 上方创建新的 PrimaryScrollController。

桌面平台上的自动滚动条

在 TargetPlatformVariant.desktop 平台上，大多数 Scrollable widget 默认会添加滚动条。这由应用 ScrollConfiguration 中的 ScrollBehavior.buildScrollbar 实现。未使用 PrimaryScrollController，或已传入 ScrollController 的 Scrollable 会获得一个专用于滚动条的 ScrollController。此时，除非将 interactive 设为 false，否则只能有一个 Scrollable 使用 PrimaryScrollController。若要阻止纵向 Axis.vertical Scrollable 使用 PrimaryScrollController，请将 ScrollView.primary 设为 false。以下 Scrollable widget 不会自动应用滚动条：

  • EditableText
  • ListWheelScrollView
  • PageView
  • NestedScrollView
  • DropdownButton

将 ScrollBehavior 的 scrollbars 设为 false，即可在整个应用中禁用默认滚动条。

link 
MaterialApp(
  scrollBehavior: const MaterialScrollBehavior()
    .copyWith(scrollbars: false),
  home: Scaffold(
    appBar: AppBar(title: const Text('Home')),
  ),
)

此示例展示如何为 Scrollable 组件禁用默认滚动条，以避免在桌面平台上出现重复滚动条。

拖动 CupertinoScrollbar 滑块时，粗细和圆角会分别从 thickness 和 radius 动画过渡到 thicknessWhileDragging 和 radiusWhileDragging。

此示例展示一个 CupertinoScrollbar，它会在滚动时淡入淡出。用户滚动时滚动条会淡入显示，停止滚动后会淡出。用户拖动滚动条时，其 thickness 会从 6 像素动画变为 thicknessWhileDragging 的 10 像素；滚动条滑块边角的 radius 会从 34 动画变为 radiusWhileDragging 的 0。
