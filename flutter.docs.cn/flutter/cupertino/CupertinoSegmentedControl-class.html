CupertinoSegmentedControl<T extends Object> 类

iOS 风格的分段控件。

以水平列表形式显示 Map 中提供的 children widget。用户可在多个互斥选项之间选择；选中某个选项后，控件中的其他选项会取消选中。

分段控件的 Map 中可以将任意 Widget 作为 children 的值。T 是用于标识每个 widget 并确定选中项的键类型。按照 Map 类的要求，所有键必须类型一致且可比较。键的顺序决定分段控件中 widget 的显示顺序。

分段控件状态变化时，widget 会调用 onValueChanged 回调。onValueChanged 回调会返回与新选中 widget 关联的 Map 键。通常，使用分段控件的 widget 会监听 onValueChanged 回调，并用新的 groupValue 重建控件，以更新当前选项。

children 会按照 Map 中键的顺序显示。分段控件的高度由 Map 的 children 值中最高的 widget 决定。每个子项的宽度通常与最宽子项相同；如果所有子项的总宽度超出可用水平空间，则将可用空间平均分配给提供的 children，以确定每个 widget 的宽度。随后，各个 Map 中 children 的选择区域会扩展以填满分配的空间，因此每个 widget 看起来尺寸相同。

也可以为分段控件自定义颜色。unselectedColor、selectedColor、borderColor 和 pressedColor 参数可覆盖 CupertinoTheme 中的默认颜色。分段禁用时，disabledColor 和 disabledTextColor 分别设置背景色和文字颜色。

将子项添加到 Set disabledChildren 中即可禁用对应分段。如果子项不在 Set 中，则默认处于启用状态。

此示例展示带有枚举类型的 CupertinoSegmentedControl。

传给 onValueChanged 的回调应使用父级 StatefulWidget 的 State.setState 方法更新状态，以便重建父级。

此示例还展示如何通过切换各个 CupertinoSwitch，使用 disabledChildren 属性启用或禁用分段。
