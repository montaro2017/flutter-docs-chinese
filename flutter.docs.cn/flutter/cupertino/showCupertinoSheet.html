显示一个 Cupertino 风格的表单组件。它会从屏幕底部滑入，并将之前的路由堆叠在新表单后方。

此便捷方法适用于大多数情况，用于显示 CupertinoSheetRoute。scrollableBuilder 返回的组件将用于显示 CupertinoSheetRoute 表单内容。如果表单内容包含可滚动视图，可以使用 scrollableBuilder 提供的 ScrollController，使下拉关闭手势能够与内容滚动协同工作。示例请参阅 CupertinoSheetRoute.scrollableBuilder。

启用 useNestedNavigation 后，会在 CupertinoSheetRoute 中添加新的 Navigator，从而允许在 CupertinoSheetRoute 内推送新路由。

将 useNestedNavigation 设为 true 时，从 CupertinoSheetRoute 上下文推送的路由都会显示在该表单内。系统返回手势以及在表单初始路由上执行的程序化 pop 也会被拦截，用于关闭整个 CupertinoSheetRoute。如果需要自定义 Navigator 配置（例如启用命名路由或 pages API），建议直接将所需配置的 CupertinoSheetRoute 推入路由栈。示例请参阅 CupertinoSheetRoute，其中演示了如何手动设置嵌套导航。

可以通过向下拖动表单，或调用 CupertinoSheetRoute.popSheet 一次性关闭整个表单。

enableDrag 设为 true（默认值）时，用户可以向下拖动表单，或调用 CupertinoSheetRoute.popSheet 将其关闭。将 enableDrag 设为 false 时，用户不能通过拖动关闭表单，只能调用 CupertinoSheetRoute.popSheet。

topGap 参数用于按屏幕高度的比例自定义屏幕顶部与表单顶部之间的间距。其值应介于 0.0 至 0.9 之间：0.0 表示没有间距，0.9 表示表单只占据屏幕底部 10% 的区域。未指定时默认为 0.08（屏幕高度的 8%）。

showDragHandle 设为 true 时，会在表单顶部显示拖动手柄。此标志默认为 false。

iOS 表单组件通常与打开它的组件上下文紧密关联。因此，不建议在未先关闭表单的情况下推送会覆盖表单的非表单路由。如有需要，可以将路由推送到根 Navigator。

如果 useNestedNavigation 为 false（默认值），显示的 CupertinoSheetRoute 中不会包含 Navigator 组件。如有需要，仍可多次调用 showCupertinoSheet，以显示多个堆叠的表单。

showCupertinoSheet 始终会将 CupertinoSheetRoute 推送到根 Navigator，以确保之前的路由正确播放动画。

返回一个 Future，在表单关闭时解析为传递给 Navigator.pop 的值（如果有）。

Future<T?> showCupertinoSheet<T>({
  required BuildContext context,
  @Deprecated(
    'Use scrollableBuilder instead. '
    'This feature was deprecated after v3.33.0-0.2.pre.',
  )
  WidgetBuilder? pageBuilder,
  @Deprecated(
    'Use scrollableBuilder instead. '
    'This feature was deprecated after v3.40.0-0.2.pre.',
  )
  WidgetBuilder? builder,
  ScrollableWidgetBuilder? scrollableBuilder,
  bool useNestedNavigation = false,
  bool enableDrag = true,
  RouteSettings? settings,
  double? topGap,
  bool showDragHandle = false,
}) {
  assert(topGap == null || (topGap >= 0.0 && topGap <= 0.9), 'topGap must be between 0.0 and 0.9');
  assert(pageBuilder != null || builder != null || scrollableBuilder != null);
  assert(
    (pageBuilder == null && builder == null && scrollableBuilder != null) ||
        scrollableBuilder == null,
  );

  final WidgetBuilder? effectiveBuilder = builder ?? pageBuilder;
  final nestedNavigatorKey = GlobalKey<NavigatorState>();
  if (!useNestedNavigation) {
    final PageRoute<T> route = CupertinoSheetRoute<T>(
      builder: effectiveBuilder,
      scrollableBuilder: scrollableBuilder,
      settings: settings,
      enableDrag: enableDrag,
      topGap: topGap,
    );

    return Navigator.of(context, rootNavigator: true).push<T>(route);
  } else {
    Widget nestedNavigationContent(WidgetBuilder builder) {
      return NavigatorPopHandler(
        onPopWithResult: (T? result) {
          nestedNavigatorKey.currentState!.maybePop();
        },
        child: Navigator(
          key: nestedNavigatorKey,
          initialRoute: '/',
          onGenerateInitialRoutes: (NavigatorState navigator, String initialRouteName) {
            return <Route<void>>[
              CupertinoPageRoute<void>(
                builder: (BuildContext context) {
                  return PopScope(
                    canPop: false,
                    onPopInvokedWithResult: (bool didPop, Object? result) {
                      if (didPop) {
                        return;
                      }
                      Navigator.of(context, rootNavigator: true).pop(result);
                    },
                    child: builder(context),
                  );
                },
              ),
            ];
          },
        ),
      );
    }

    final route = CupertinoSheetRoute<T>(
      scrollableBuilder: (BuildContext context, ScrollController controller) =>
          nestedNavigationContent(
            scrollableBuilder != null
                ? (BuildContext context) => scrollableBuilder(context, controller)
                : effectiveBuilder!,
          ),
      settings: settings,
      enableDrag: enableDrag,
      topGap: topGap,
    );
    return Navigator.of(context, rootNavigator: true).push<T>(route);
  }
}
