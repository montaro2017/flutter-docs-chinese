CupertinoScrollBehavior 类

描述 Scrollable 组件在 CupertinoApp 中的行为。

ScrollConfiguration 使用此类来配置子树中的 Scrollable 组件。

可以继承此类，进一步自定义子树的 ScrollBehavior。例如，重写 ScrollBehavior.getScrollPhysics，可以为继承该 ScrollConfiguration 的 Scrollable 设置默认的 ScrollPhysics。重写 ScrollBehavior.buildOverscrollIndicator 可以添加或更改默认的 GlowingOverscrollIndicator 装饰；重写 ScrollBehavior.buildScrollbar 则可以更改默认的 Scrollbar。

如果只想便捷地切换默认装饰，可以使用 ScrollBehavior.copyWith，无需创建自己的 ScrollBehavior 类。scrollbar 和 overscrollIndicator 标志可用于关闭这些装饰。

设置 CupertinoScrollBehavior 后，后代 Scrollable 组件默认会使用 BouncingScrollPhysics。使用 CupertinoScrollBehavior 时，无论运行在哪个平台，都不会应用 GlowingOverscrollIndicator。在桌面平台上，子组件还会应用 CupertinoScrollbar。

另请参阅：

  • ScrollBehavior, the default scrolling behavior extended by this class.
