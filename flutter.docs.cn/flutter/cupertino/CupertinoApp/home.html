home 属性

Widget? home
final

应用默认路由的组件（Navigator.defaultRouteName，即 /）。

通常启动应用时首先显示此路由，除非指定了 initialRoute。如果无法显示 initialRoute，也会显示此路由。

如果要在构造函数中设置 home 参数的代码里直接调用 Theme.of、MediaQuery.of 等方法，可以使用 Builder widget 来获取 BuildContext。

如果指定了 home，则 routes 中不得包含 / 对应的条目，因为它会由 home 取代。

只有在提供了路由（通过 home、routes、onGenerateRoute 或 onUnknownRoute）时，才会构建 Navigator；如果未提供这些路由，builder 必须不为 null。

home 与 builder 的区别在于：home 子树会插入应用中，位于 Navigator 下方（因此也位于 Navigator 使用的 Overlay 下方）。因此，使用 home 时，对话框会自动正常工作，routes 表会生效，Navigator.push 和 Navigator.pop 等 API 也会按预期工作。相反，builder 返回的 widget 会插入应用的 Navigator（如果有）之上。
