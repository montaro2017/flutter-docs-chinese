显示一个 iOS 风格的模态弹出窗口，并使其从屏幕底部滑入。

这种弹出窗口可替代菜单或对话框，并会阻止用户与应用的其他部分交互。

context 参数用于查找显示弹出窗口的 Navigator，仅在调用此方法时使用。弹出窗口关闭前，可以安全地将与此上下文对应的组件从组件树中移除。

barrierColor 参数用于确定弹出窗口下方屏障的 Color。未指定时，默认使用浅色半透明黑色遮罩，样式参考 iOS 对话框界面。

barrierDismissible 参数用于决定点按弹出窗口外部区域是否会将其关闭。默认值为 true。

useRootNavigator 参数用于决定将弹出窗口推送到距离给定 context 最远还是最近的 Navigator。默认值为 true。

semanticsDismissible 参数用于决定是否将模态屏障的语义信息包含在语义树中。

routeSettings 参数用于为创建的路由提供 RouteSettings。

builder 参数通常用于构建 CupertinoActionSheet。组件下方的内容会由 ModalBarrier 遮暗。builder 构建的组件与最初调用 showCupertinoModalPopup 的位置不共享上下文。如果组件需要动态更新，请使用 StatefulBuilder 或自定义 StatefulWidget。

requestFocus 参数用于指定显示弹出窗口时是否请求焦点。如果未提供 requestFocus，则使用 Navigator.requestFocus 的值。

DisplayFeature 可能会将屏幕分割成多个子屏幕。系统会在距离 anchorPoint 最近的子屏幕中呈现内容。

如果未提供 anchorPoint，则使用 Directionality：

  • for TextDirection.ltr, anchorPoint is Offset.zero, which will cause the content to appear in the top-left sub-screen.
  • for TextDirection.rtl, anchorPoint is Offset(double.maxFinite, 0), which will cause the content to appear in the top-right sub-screen.

如果未提供 anchorPoint，且组件树中没有 Directionality 祖先组件，则调试模式下会在构建时触发断言。

返回一个 Future，在弹出窗口关闭时解析为传递给 Navigator.pop 的值。

State Restoration in Modals

使用此方法不会为模态窗口启用状态恢复。若要启用状态恢复，请将 Navigator.restorablePush 或 Navigator.restorablePushNamed 与 CupertinoModalPopupRoute 配合使用。

有关状态恢复的更多信息，请参阅 RestorationManager。

此示例展示如何创建可恢复的 Cupertino 模态路由。通过指定 CupertinoApp.restorationScopeId 启用状态恢复，并在点击 Navigator.restorablePush 时使用 CupertinoModalPopupRoute 推入 CupertinoButton。

在 Android 上测试状态恢复：

  1. 启用“不保留活动”选项。用户离开应用后，该选项会立即销毁 Android Activity。设备开启开发者选项后即可使用此选项。
  2. 在 Android 设备上运行此代码示例。
  3. 在手机上的应用中创建一些仅保存在内存中的状态，例如导航到其他屏幕。
  4. 将 Flutter 应用切换到后台，然后重新打开。应用会重启并恢复状态。

在 iOS 上测试状态恢复：

  1. Open ios/Runner.xcworkspace/ in Xcode.
  2. 仅限 iOS 14 及更高版本：请切换到 profile 或 release 构建模式，因为不支持从主屏幕以 debug 模式启动应用。
  3. 在 Xcode 中按下运行按钮以构建并运行应用。
  4. 在手机上的应用中创建一些仅保存在内存中的状态，例如导航到其他屏幕。
  5. 将应用切换到后台，例如返回主屏幕。
  6. 应用在后台运行时，在 Xcode 中按下停止按钮以终止应用。
  7. 再次从手机打开应用（不要通过 Xcode 打开）。应用会重启并恢复状态。

实现

Future<T?> showCupertinoModalPopup<T>({
  required BuildContext context,
  required WidgetBuilder builder,
  ImageFilter? filter,
  Color barrierColor = kCupertinoModalBarrierColor,
  bool barrierDismissible = true,
  bool useRootNavigator = true,
  bool semanticsDismissible = false,
  RouteSettings? routeSettings,
  Offset? anchorPoint,
  bool? requestFocus,
}) {
  return Navigator.of(context, rootNavigator: useRootNavigator).push(
    CupertinoModalPopupRoute<T>(
      builder: builder,
      filter: filter,
      barrierColor: CupertinoDynamicColor.resolve(barrierColor, context),
      barrierDismissible: barrierDismissible,
      semanticsDismissible: semanticsDismissible,
      settings: routeSettings,
      anchorPoint: anchorPoint,
      requestFocus: requestFocus,
    ),
  );
}
