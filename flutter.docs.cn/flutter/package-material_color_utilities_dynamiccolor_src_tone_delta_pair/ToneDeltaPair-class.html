ToneDeltaPair

ToneDeltaPair 类

用于描述两个 DynamicColor 之间的约束：它们的色调必须相隔指定距离。 优先使用带背景的 DynamicColor。此约束适用于特殊情况：设计师希望两种颜色之间具有色调距离（也就是对比度），但两者没有背景与前景关系，也没有对比度保证。
