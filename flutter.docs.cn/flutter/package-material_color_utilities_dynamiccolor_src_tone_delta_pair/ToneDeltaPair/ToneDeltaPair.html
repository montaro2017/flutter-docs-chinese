ToneDeltaPair 构造函数

ToneDeltaPair(
  1. DynamicColor roleA,
  2. DynamicColor roleB,
  3. double delta,
  4. TonePolarity polarity,
  5. bool stayTogether,
)
用于描述两个 DynamicColor 之间的色调距离约束。 polarity 是一个形容词，用于描述“A”相对于“B”的关系。 例如，ToneDeltaPair(A, B, 15, 'darker', stayTogether) 表示 A 的色调应至少比 B 暗 15。 “nearer”和“farther”表示与表面角色的接近程度。例如，ToneDeltaPair(A, B, 10, 'nearer', stayTogether) 表示浅色模式下 A 应比 B 亮 10，深色模式下则应比 B 暗 10。 roleA 配对中的第一个角色。
roleB 配对中的第二个角色。
delta 色调之间要求的差值，取绝对值；负值的行为未定义。
polarity roleA 与 roleB 色调之间的相对关系，如上所述。
stayTogether 这两个角色是否应保持在“尴尬区间”（T50-59）的同一侧。若某个角色有两个背景色，则必须启用此项。
