DateSymbols

DateSymbols 类

此类保存特定区域设置的日期格式信息。内容主要是字符串，例如月份名和星期名，也包括一周的第一天等信息。此类实例的数据预计由 ICU 或类似的参考来源生成。它与 date_time_patterns 配合使用；后者定义特定区域设置中会使用这些数据的各种命名格式。
