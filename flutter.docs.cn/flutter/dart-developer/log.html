发出日志事件，可在 DevTools 的 Logging 视图中查看。

此函数的设计目标是尽可能贴近 package:logging 收集的日志信息。

  • message 是日志消息
  • time（可选）是时间戳
  • sequenceNumber（可选）是单调递增的序号
  • level（可选）是严重程度（取值为 0 至 2000）；可参阅 package:logging Level 类中关于可能值的概述
  • name（可选）是日志消息的来源名称
  • zone（可选）是日志发出时所处的 zone
  • error（可选）是与此日志事件关联的错误对象
  • stackTrace（可选）是与此日志事件关联的堆栈跟踪
