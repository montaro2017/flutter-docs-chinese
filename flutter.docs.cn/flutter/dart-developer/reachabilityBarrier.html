int get reachabilityBarrier

当前的可达性屏障状态。

可达性屏障状态提供了一种基于可达性进行同步的方式。当屏障值为 “x” 时，在 “value” < “x” 期间变为不可达的对象都已被回收，相关终结器也已安排执行。因此，如果终结器尚未执行，就可以可靠地判断该对象在先前的屏障状态下仍然可达。

在当前屏障状态中变为不可达的对象可能尚未被回收或终结。

注意：不保证该值会持续向前推进。此屏障状态的实现可能永远返回同一个值。
