CreationLocation

CreationLocation 类 final

当类带有 @pragma('track-creation-locations') 注解时，此类会保存创建对象的源代码位置。

当类定义带有 @pragma('track-creation-locations') 注解时，Dart 编译器会将调用位置注入该类及其子类构造函数的每次调用，并将其存储在创建的对象中。

调用 CreationLocation.of 并传入该对象，即可读取对象的创建位置。

示例

import 'dart:developer';

// Marks this and any subclass to have their constructor call-sites tracked.
@pragma('track-creation-locations')
class TargetClass {
  TargetClass();
}

void main() {
  // The source-code location of this constructor call is injected into the object.
  final instance = TargetClass();

  final location = CreationLocation.of(instance);
  print(location); // Will print the current file path, line 11, column 20
}

限制

编译器转换依赖于向目标类的构造函数注入一个命名参数。由于 Dart 语义不允许函数同时具有可选位置参数和命名参数，该转换会静默跳过声明了可选位置参数的构造函数。对被跳过构造函数创建的对象调用 CreationLocation.of 时，会返回 null。
