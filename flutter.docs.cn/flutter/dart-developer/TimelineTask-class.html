TimelineTask

TimelineTask 类 final

时间线上的异步任务。一个异步任务可以包含多个（嵌套的）同步操作。同步操作的生命周期可以超过当前 isolate 事件。若要将 TimelineTask 传递给另一个 isolate，必须先调用 pass 获取任务 ID，然后在另一个 isolate 中创建新的 TimelineTask。

构造函数

TimelineTask({TimelineTask? parent, String? filterKey})
创建一个任务，任务 ID 由系统设置。
TimelineTask.withTaskId(int taskId, {String? filterKey})
使用显式指定的 taskId 创建任务。在不同 isolate 之间传递任务时这很有用。
