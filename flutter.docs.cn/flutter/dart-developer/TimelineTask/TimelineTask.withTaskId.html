TimelineTask.withTaskId 构造函数

TimelineTask.withTaskId(
  1. int taskId, {
  2. String? filterKey,
})

使用显式指定的 taskId 创建任务。在将任务从一个 isolate 传递到另一个 isolate 时，此构造函数很有用。

重要提示：只应提供通过调用 TimelineTask.pass 获得的任务 ID。指定自定义 ID 可能导致 ID 冲突，从而使时间线事件显示错误。

如果提供了 filterKey，则会在与此任务关联的每个事件参数中插入一个名为 filterKey 的属性。filterKey 的值会设置为 filterKey。

实现

TimelineTask.withTaskId(int taskId, {String? filterKey})
  : _parent = null,
    _filterKey = filterKey,
    _taskId = taskId {}
