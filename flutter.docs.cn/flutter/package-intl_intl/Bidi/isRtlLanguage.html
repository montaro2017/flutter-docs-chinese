检查 BCP 47 / III languageString 是否表示从右至左（RTL）语言。

也就是说，满足以下任一条件：

  • a language code explicitly specifying one of the right-to-left scripts, e.g. "az-Arab", or
  • 指定一种通常使用从右向左书写文字的语言代码，例如 "fa"（波斯语）；明确指定拉丁或西里尔文字（通常对应从左向右书写）的语言除外。

从右至左书写系统列表位于 http://www.unicode.org/iso15924/iso15924-num.html 中的 100–199 范围内，其中阿拉伯文和希伯来文是使用最广泛的两种文字。此处还识别现代使用较广的塔安那文、恩科文和提非纳文。其余文字（叙利亚文、撒马利亚文、曼达安文等）现代使用极少或已不再使用，因此不予识别。通常使用从右至左文字书写的语言包括在 http://www.iana.org/assignments/language-subtag-registry 中具有 Suppress-Script 标记 Hebr|Arab|Thaa|Nkoo|Tfng 的语言，以及信德语（sd）和维吾尔语（ug）。语言代码中的其他子标签（例如 EG（埃及）等地区代码）会被忽略。

实现

static bool isRtlLanguage([String? languageString]) {
  var language = languageString ?? global_state.getCurrentLocale();
  if (_lastLocaleCheckedForRtl != language) {
    _lastLocaleCheckedForRtl = language;
    _lastRtlCheck = _rtlLocaleRegex.hasMatch(language);
  }
  return _lastRtlCheck!;
}
