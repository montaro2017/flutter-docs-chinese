NumberFormat

NumberFormat 类

提供按特定区域设置格式化数字的功能。

格式由 ICU 格式模式的一个子集指定。

  • 0 一位数字
  • # 一位数字；值为零时省略
  • . 小数分隔符
  • - 负号
  • , 分组分隔符
  • E 分隔尾数和指数
  • + 指数前的正号标记，表示需要添加正号。
  • % 作为前缀或后缀时，乘以 100 并显示为百分比
  • ‰ (\u2030) 作为前缀或后缀时，乘以 1000 并显示为千分比
  • ¤ (\u00A4) 货币符号，将由货币名称替代
  • ' 用于引用特殊字符
  • ; 用于分隔正数和负数模式（如果两者都存在）

例如：

  var f = NumberFormat("###.0#", "en_US");
  print(f.format(12.345));
      ==> 12.34

如果未指定区域设置，则默认使用当前区域设置。如果未指定格式，则使用基本格式打印数字，至少包含一位整数和三位小数。

也可以通过特殊构造函数使用标准格式。例如：

  var percent = NumberFormat.percentPattern("ar");
  var eurosInUSFormat = NumberFormat.currency(locale: "en_US",
      symbol: "€");

此类还提供多个类似构造函数，但其中一些功能有限。例如，目前 scientificPattern 只按等效于“#E0”的格式打印，不会考虑有效数字位数。
