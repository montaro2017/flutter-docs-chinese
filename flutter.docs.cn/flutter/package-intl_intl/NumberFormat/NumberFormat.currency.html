NumberFormat.currency({

创建一个 NumberFormat，使用区域设置中的 CURRENCY_PATTERN 格式。

如果未指定 locale，则使用当前默认区域设置。

如果指定了 name，则使用该 ISO 4217 货币代码对应的货币；否则使用当前区域设置的默认货币名称。如果未指定 symbol，格式化结果中会使用货币名称。例如：
var f = NumberFormat.currency(locale: 'en_US', name: 'EUR')
会将货币格式化为“EUR1.23”。如果未指定名称，则会格式化为“USD1.23”。

如果指定了 symbol，格式化时将使用该符号代替货币名称。例如：
var eurosInCurrentLocale = NumberFormat.currency(symbol: "€");
会将货币格式化为“€1.23”。否则会使用货币名称。如果未在构造函数中显式指定，给定货币名称时会使用该货币的默认符号；否则会使用区域设置格式模式中的符号。

如果指定了 decimalDigits，数字的小数点后将格式化为指定的位数。否则会使用 name 所指定货币的默认小数位数；如果未指定货币名称，则使用 locale 的默认货币的小数位数。例如：
NumberFormat.currency(name: 'USD', decimalDigits: 7)
会按要求格式化为 7 位小数。但
NumberFormat.currency(locale: 'en_US', name: 'JPY')
会格式化为 0 位小数，因为这是 JPY 的默认值，且货币默认值优先于区域设置默认值。
NumberFormat.currency(locale: 'en_US')
会格式化为 2 位小数，这是该区域设置的默认值。

customPattern 参数可用于指定特定格式。当你拥有包含尚不支持格式（例如货币会计格式）的自定义区域设置数据时，此参数很有用。

实现

// TODO(alanknight): Should we allow decimalDigits on other numbers.
factory NumberFormat.currency({
  String? locale,
  String? name,
  String? symbol,
  int? decimalDigits,
  String? customPattern,
}) => NumberFormat._forPattern(
  locale,
  (x) => customPattern ?? x.CURRENCY_PATTERN,
  name: name,
  currencySymbol: symbol,
  decimalDigits: decimalDigits,
  isForCurrency: true,
);
