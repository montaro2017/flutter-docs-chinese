NumberFormat.simpleCurrency 构造函数

NumberFormat.simpleCurrency({
  1. String? locale,
  2. String? name,
  3. int? decimalDigits,
})

为货币创建一个 NumberFormat。如果有简单货币符号（例如 $、€），则会使用该符号，因此仅应在短货币符号不会产生歧义时使用。

如果未指定 locale，则使用当前默认区域设置。

如果指定了 name，则使用该 ISO 4217 货币代码对应的货币；否则使用当前区域设置的默认货币名称。此处假定该货币符号在此区域设置中广为人知且不会产生歧义。例如，在 en_US 区域设置中使用此格式格式化 CAD 会显示为“$”，这可能会让用户感到困惑。

如果指定了 decimalDigits，数字的小数点后将格式化为指定的位数。否则会使用 name 所指定货币的默认小数位数；如果未指定货币名称，则使用 locale 的默认货币的小数位数。例如：
NumberFormat.simpleCurrency(name: 'USD', decimalDigits: 7)
会按要求格式化为 7 位小数。但
NumberFormat.simpleCurrency(locale: 'en_US', name: 'JPY')
会格式化为 0 位小数，因为这是 JPY 的默认值，且货币默认值优先于区域设置默认值。
NumberFormat.simpleCurrency(locale: 'en_US')
会格式化为 2 位小数，这是该区域设置的默认值。

实现

factory NumberFormat.simpleCurrency({
  String? locale,
  String? name,
  int? decimalDigits,
}) {
  return NumberFormat._forPattern(
    locale,
    (x) => x.CURRENCY_PATTERN,
    name: name,
    decimalDigits: decimalDigits,
    lookupSimpleCurrencySymbol: true,
    isForCurrency: true,
  );
}
