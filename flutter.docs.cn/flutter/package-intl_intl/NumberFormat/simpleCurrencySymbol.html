返回指定货币代码的简单货币符号；如果未列出简单符号，则返回 currencyCode。

简单货币符号通常较短，并且通常与该货币官方使用国家或地区中的符号相同或相关。它可以是单个符号字符，也可以包含字母，或两者兼有。符号可能因区域设置而异：例如，阿拉伯语区域设置中可能使用阿拉伯字母，而法语区域设置中可能使用拉丁字母。它不一定唯一，例如 USD 和 CAD 都可能显示为“$”。

（当前实现对所有区域设置都相同，但这是暂时情况，调用方不应依赖此行为。）

实现

String simpleCurrencySymbol(String currencyCode) =>
    constants.simpleCurrencySymbols[currencyCode] ?? currencyCode;
