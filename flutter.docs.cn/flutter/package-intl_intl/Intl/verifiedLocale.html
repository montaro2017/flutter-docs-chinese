根据 newLocale 返回与其相近且具有可用数据的区域设置（如果存在）。

如果能直接找到 newLocale，则返回它。否则尝试仅根据语言查找（例如 "en_CA" → "en"）。查找时也接受连字符作为分隔符并将其替换为下划线，同时会将国家/地区代码转换为大写。

特殊情况下，如果存在名为“fallback”且已初始化的区域设置，则返回该名称。对于不希望直接使用原始源代码文本、而希望使用通用回退译文的消息，这很有用。

null 表示默认区域设置，因此如果 newLocale 为 null，则返回默认区域设置。

只有验证失败且 onFailure 返回 null 时才会返回 null；否则会抛出异常。
