用于创建需要根据不同区域设置进行翻译的消息。通常应在外层函数中调用此方法，该函数只返回本次调用的结果，并为消息中要替换的变量提供作用域。

messageText 是待翻译的字符串，可以根据一个或多个变量进行插值。

args 是外层函数参数组成的列表。如果函数没有参数，可以省略 args。

仅当消息包含 args 时才必须提供 name；不含 args 时则为可选。运行时会使用它查找消息并传入相应参数。如果提供了 name，它必须在程序中全局唯一，并且应与外层函数名称一致。如果函数是类的方法，name 也可以采用 <className>_<methodName> 形式，以区分不同类中同名的消息。

desc 用于描述消息的用途。

examples 是一个 const Map，用于为每个插值变量提供示例。例如：

String hello(String yourName) => Intl.message(
      'Hello, $yourName',
      name: 'hello',
      args: [yourName],
      desc: 'Say hello',
      examples: const {'yourName': 'Sparky'},
    );

源代码会由分析器处理以提取消息数据，因此只接受一部分有效 Dart 代码。具体而言，所有内容都必须是字面量，不能引用外层函数作用域之外的变量。examples 必须是有效的 const 字面量映射；desc 参数必须是简单的单个字符串；skip 必须是布尔字面量。这三个参数不会在运行时使用，而是从源代码中提取，作为提供给译者的补充信息。详情请参阅主 package documentation中的“Messages”部分（https://pub.dev/packages/intl）。

skip 参数仍会验证消息，但提取消息时会将其过滤掉。开发过程中可用它设置尚未定稿、暂不希望自动翻译的占位消息。
