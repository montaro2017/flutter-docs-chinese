debugName 属性

String? get debugName

用于调试时显示的 Isolate 名称。

可以通过 spawn 和 spawnUri 中的 debugName 参数设置此名称。

此名称不能唯一标识 isolate。同一进程中的多个 isolate 可以具有相同的 debugName。

对于给定的 isolate，此值与 C 嵌入 API 中 Dart_DebugName 返回的值以及 IsolateMirror 的 debugName 属性相同。
