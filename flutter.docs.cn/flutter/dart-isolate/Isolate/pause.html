pause

pause 方法

Capability pause([
  1. Capability? resumeCapability
])

请求暂停该 isolate。

isolate 收到暂停命令后，会停止处理事件循环队列中的事件。它仍可能因计时器或接收端口消息等原因向队列添加新事件。isolate 恢复后，会开始处理已入队的事件。

暂停请求通过 isolate 的命令端口发送，该端口会绕过接收方 isolate 的事件循环。请求收到时立即生效，并暂停当时正在运行的事件循环。

resumeCapability 用于标识此次暂停，之后必须再次使用它并调用 resume 才能结束暂停。如果省略 resumeCapability，系统会创建并使用新的 capability 对象。

如果使用同一 capability 多次暂停某个 isolate，只需使用该 capability 恢复一次即可结束暂停。

如果使用多个 capability 暂停某个 isolate，则必须分别结束每项暂停，该 isolate 才会恢复运行。

返回用于结束暂停的 capability。它是 resumeCapability；如果省略 resumeCapability，则返回新创建的 capability。

如果 pauseCapability 为 null，或不是由 controlPort 标识的 isolate 的暂停 capability，接收方 isolate 会忽略此暂停请求。

实现

Capability pause([Capability? resumeCapability]) {
  resumeCapability ??= Capability();
  _pause(resumeCapability);
  return resumeCapability;
}
