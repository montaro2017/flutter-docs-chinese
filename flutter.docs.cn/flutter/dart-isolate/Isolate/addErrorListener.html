  1. SendPort port
)

请求将该 isolate 中未捕获的错误发送回 port。

错误会以包含两个元素的列表发回。第一个元素是错误的 String 表示形式，通常通过调用错误对象的 toString 创建。第二个元素是相关堆栈跟踪的 String 表示形式；如果没有提供堆栈跟踪，则为 null。若要将其转换回 StackTrace 对象，请使用 StackTrace.fromString。

多次使用同一端口监听不会产生额外效果。每个错误只会发送到该端口一次；只需使用 removeErrorListener 移除一次即可。

关闭与该端口关联的接收端口，不会阻止 isolate 发送未捕获的错误，只会导致错误丢失。应改用 removeErrorListener，停止通过 port 接收错误。

由于各 isolate 并发运行，可能出现错误监听器尚未建立，isolate 就已退出的情况。为避免此问题，请以暂停状态启动 isolate，添加监听器，然后恢复 isolate。
