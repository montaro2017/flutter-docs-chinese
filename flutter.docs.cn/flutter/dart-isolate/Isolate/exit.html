Never exit([
  1. SendPort? finalMessagePort,

])

同步终止当前 isolate。

此操作可能有危险，应谨慎使用。isolate 会立即停止运行。如果可选的 message 不符合 isolate 间消息传递限制（详情请参阅 SendPort.send），此操作会抛出异常。如果 finalMessagePort 关联的 isolate 是通过 spawnUri 在当前 isolate 组之外创建的，也会抛出异常。有关 isolate 组的详情，请参阅 isolate group。

如果操作成功，此方法调用不会返回。待执行的 finally 代码块不会运行，控制流不会返回事件循环，已调度的异步请求也不会运行，甚至待处理的 isolate 控制命令也可能被忽略。（isolate 仍会向已通过 Isolate.addOnExitListener 注册的端口发送消息，但不会再运行任何 Dart 代码。）

如果提供了 finalMessagePort，且 message 可以通过该端口发送（详情请参阅 SendPort.send），则当前 isolate 会将消息通过该端口发送，作为最后一项操作。SendPort.send 调用返回后，isolate 会立即终止。

如果该端口是原生端口（由 ReceivePort.sendPort 或 RawReceivePort.sendPort 提供），系统发送此最终消息的效率可能高于活动 isolate 之间的常规端口通信。在这种情况下，最终消息的对象图会直接重新分配给接收 isolate，而无需复制。此外，接收 isolate 在大多数情况下可以在固定时间内收到消息。
