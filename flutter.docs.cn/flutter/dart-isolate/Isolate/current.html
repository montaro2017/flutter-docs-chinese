current 属性

Isolate get current

表示当前 isolate 的 Isolate 对象。

对于使用 current 的代码，当前 isolate 就是正在运行该代码的 isolate。

该 isolate 对象提供检查、暂停或终止此 isolate 所需的 capability，也允许将这些 capability 授予其他对象。

可以暂停当前 isolate，但如果没有先将恢复它的能力交给另一个 isolate，程序必然会挂起。

实现

external static Isolate get current;
