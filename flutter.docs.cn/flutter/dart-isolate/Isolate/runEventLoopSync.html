runEventLoopSync 方法

  1. @Since.new("3.13")
void runEventLoopSync()

在当前线程上同步运行目标 isolate 的事件循环。

此函数会阻塞，直到获得目标 isolate 的独占访问权。只有在事件循环的两个轮次之间、没有其他线程正在目标 isolate 中执行代码时，才能进入 isolate 执行同步操作。

当该 isolate 不再有开放的保持活动状态接收端口时，此函数会返回。

该 isolate 会被标记为固定到当前线程。

类似于 Dart VM C API 中的 Dart_RunLoop，但与 Dart_RunLoop 不同，此函数会在当前线程上执行 isolate 的事件循环，而不是将其委派给线程池。

如果目标 isolate 固定在另一个线程上，或其事件循环已经在运行，则会抛出错误。
