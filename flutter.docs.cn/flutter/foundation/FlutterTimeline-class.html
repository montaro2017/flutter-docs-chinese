description

FlutterTimeline 类 抽象 final

测量代码区块的运行耗时。

此类可直接替代 Timeline，因为它提供的方法在签名上与 Timeline 兼容，并且开销很小。

提供 debugReset 和 debugCollect 方法，便于在以帧为单位的环境中使用。在这种环境中，可以将收集的指标归属于某一帧，再汇总为帧统计数据，例如每帧平均值。

将测量结果转发给 Timeline，使其显示在 Flutter DevTools 中。
