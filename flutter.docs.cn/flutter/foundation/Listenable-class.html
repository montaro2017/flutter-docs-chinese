Listenable 类 抽象

维护监听器列表的对象。

监听器通常用于通知使用方：此对象已更新。

此接口有两种扩展形式：

  • ValueListenable 接口在 Listenable 接口的基础上增加了当前值的概念。

  • Animation 接口在 ValueListenable 接口的基础上增加了方向（正向或反向）的概念。

Flutter API 中的许多类使用或实现这些接口。以下子类尤其值得关注：

  • 可以继承 ChangeNotifier，或将其作为 mixin 使用，来创建实现 Listenable 接口的对象。

  • ValueNotifier 实现了 ValueListenable 接口，提供一个可变的值，并在该值被修改时触发通知。

文档中的“通知使用方”“发送通知”和“触发通知”等表述含义相同。

另请参阅：

  • AnimatedBuilder 是一个 widget，每当给定的 Listenable 触发通知时，它都会通过构建回调重新构建。它通常与 Animation 子类一起使用，因此得名，但它可以用于任何 Listenable。它继承自 AnimatedWidget，后者可用于创建由 Listenable 驱动的 widget。
  • ValueListenableBuilder 是一个 widget，每当 ValueListenable 对象触发通知时，它都会通过构建回调重新构建，并向该回调提供对象的值。
  • InheritedNotifier 是 widget 的抽象父类，这些 widget 使用 Listenable 的通知，并借助 InheritedWidget 机制，触发声明依赖于它们的后代 widget 重新构建。
  • Listenable.merge 创建一个 Listenable，当列表中任意其他 Listenable 触发通知时，它也会触发通知。
