context 属性

DiagnosticsNode? context
final

提供人类可读说明的 DiagnosticsNode，用于指出错误被捕获的位置（而不是抛出的位置）。

此节点（例如 ErrorDescription）的措辞应能自然接在“thrown”（抛出）之后，例如“thrown while obtaining the image from the network”（在从网络获取图像时抛出）；上下文可以写成“while obtaining the image from the network”（在从网络获取图像时）。

此示例展示了在调用 FlutterError.reportError 时，如何将 ErrorDescription 用作 FlutterErrorDetails.context。
link 
void maybeDoSomething() {
  try {
    // Try to do something!
  } catch (error) {
    // Catch & report error.
    FlutterError.reportError(FlutterErrorDetails(
      exception: error,
      library: 'Flutter test framework',
      context: ErrorDescription('while dispatching notifications for $runtimeType'),
    ));
  }
}

另请参阅：

  • ErrorDescription：提供对问题及其原因的说明，以及有助于排查问题的其他信息、背景资料等。
  • ErrorSummary, 提供对检测到的问题的简短（单行）描述。
  • ErrorHint，提供可能适用的、具体且不显而易见的建议。
  • FlutterError，最常使用 FlutterErrorDetails 的地方。
