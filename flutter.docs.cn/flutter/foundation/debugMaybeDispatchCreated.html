如果已启用内存分配跟踪，则派发 Flutter 对象创建事件。

此方法不属于 FlutterMemoryAllocations，因为禁用内存分配跟踪时，FlutterMemoryAllocations 不应增加 Flutter 应用的体积。

flutterLibrary 参数是声明该对象的 Flutter 库名称。例如，widgets.dart 对应“widgets”。

只能在 assert 内部调用，且只能在 Flutter 框架内部使用。

返回 true，以便将调用包裹在 assert 中。

实现

bool debugMaybeDispatchCreated(String flutterLibrary, String className, Object object) {
  if (kFlutterMemoryAllocationsEnabled) {
    FlutterMemoryAllocations.instance.dispatchObjectCreated(
      library: 'package:flutter/$flutterLibrary.dart',
      className: className,
      object: object,
    );
  }
  return true;
}
