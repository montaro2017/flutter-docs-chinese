DiagnosticsNode 类 抽象

定义 value 的诊断数据。

在调试和性能分析模式下，DiagnosticsNode 通过 toStringDeep 提供易读的多行字符串输出。核心成员包括 name、toDescription、getProperties、value 和 getChildren。其他成员通常用于提示 toStringDeep 和调试工具如何格式化输出。

在发布模式下，保留的信息会少得多，某些信息可能完全不会输出。
