Category 类

用于为类添加文档分类的注解。

分类通常由一个一级分类和一个二级分类表示，两者都是字符串。类所属库的工程团队负责定义该库中各类使用的分类。例如，Flutter 工程团队为 Flutter 组件定义了“Basic/Buttons”和“Material Design/Buttons”等分类。

一个类可以属于多个分类。

link 
/// A copper coffee pot, as desired by Ben Turpin.
/// ...documentation...
@Category(<String>['Pots', 'Coffee'])
@Category(<String>['Copper', 'Cookware'])
@DocumentationIcon('https://example.com/images/coffee.png')
@Summary('A proper cup of coffee is made in a proper copper coffee pot.')
class CopperCoffeePot {
  // ...code...
}

另请参阅：

  • DocumentationIcon，用于提供代表该类的图片 URL。
  • Summary，用于提供类的单行描述，以替代内联文档本身的描述。
