TextTreeRenderer 构造函数

TextTreeRenderer({
  1. DiagnosticLevel minLevel = DiagnosticLevel.debug,
  2. int wrapWidth = 100,
  3. int wrapWidthProperties = 65,
  4. int maxDescendentsTruncatableNode = -1,
})

创建一个 TextTreeRenderer 对象，通过给定参数指定树的渲染方式。

行的换行宽度取 wrapWidth 与当前缩进宽度加上 wrapWidthProperties 个字符这两者中的较大值。这样可以避免在显示很深的树时过度换行，并且只有在树的缩进较小时，才按整体的 wrapWidth 换行。如果指定了 maxDescendentsTruncatableNode，则对于 allowTruncate 设置为 true 的 DiagnosticsNode 对象，在包含待截断节点的 maxDescendentsTruncatableNode 个后代节点后截断。

实现

TextTreeRenderer({
  DiagnosticLevel minLevel = DiagnosticLevel.debug,
  int wrapWidth = 100,
  int wrapWidthProperties = 65,
  int maxDescendentsTruncatableNode = -1,
}) : _minLevel = minLevel,
     _wrapWidth = wrapWidth,
     _wrapWidthProperties = wrapWidthProperties,
     _maxDescendentsTruncatableNode = maxDescendentsTruncatableNode;
