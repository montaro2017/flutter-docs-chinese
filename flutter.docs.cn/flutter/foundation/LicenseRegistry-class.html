LicenseRegistry 类 抽象 final

供软件包添加许可证的注册表，以便在 LicensePage 等界面中集中显示。

软件包可以通过 addLicense 注册许可证。需要显示全部许可证的用户界面可以通过访问 licenses 获取它们。

flutter 工具会自动收集每个软件包根目录中 LICENSE 文件的内容，将其合并为默认资源包中的一个 NOTICES 文件（或其压缩版本 NOTICES.Z）。文件中各许可证之间用一行八十个连字符（-）分隔。每项许可证以其适用的软件包名称列表开头，每行一个名称，名称列表与许可证正文之间以空行分隔。services 包会注册一个许可证收集器，拆分此文件并将每个条目添加到注册表中。

每个软件包的 LICENSE 文件可以只包含一个许可证，也可以采用上述格式。采用后一种格式时，每项组成许可证及其软件包名称列表都会独立合并。

另请参阅：

  • showAboutDialog 显示包含应用信息的 Material 风格对话框，其中包含打开 LicensePage 的按钮；该页面使用此 API 选择要显示的许可证。
  • AboutListTile 是可添加到 Drawer 的 widget，点击时会调用 showAboutDialog。
