ValueNotifier<T> 类

保存单个值的 ChangeNotifier。

当 value 被替换为新值，且相等运算符（==）判定新旧值不相等时，此类会通知其监听器。

限制

通知的触发依据是相等性（==），而非值内部的变化。因此，对可变对象进行不会影响其相等性的修改，不会通知监听器。

例如，原地修改现有列表的内容时，ValueNotifier<List<int>> 不会通知监听器；只有为 value 属性赋予新值（即 value = newValue），且通过 == 判断新旧值不相等时，才会发送通知。

由于这种行为，ValueNotifier 最适合与不可变数据类型一起使用。

对于可变数据类型，可以考虑直接继承 ChangeNotifier，并在发生变化时手动调用 notifyListeners。
