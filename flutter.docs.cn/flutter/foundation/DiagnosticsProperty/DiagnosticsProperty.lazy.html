仅在需要时才计算 value 的属性。

如果计算属性的 value 可能抛出异常或开销较大，请使用此构造函数。

level 参数仅是建议值。如果属性的其他情况使其级别更低或更高，此值可能被覆盖。例如，如果调用 computeValue 抛出异常，level 将始终返回 DiagnosticLevel.error。
