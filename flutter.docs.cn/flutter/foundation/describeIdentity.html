返回 object 的运行时类型和哈希码摘要。

另请参阅：

  • Object.hashCode，将对象放入 Map 或其他类似数据结构时使用的值，也用于在调试输出中区分同一类的实例（哈希冲突可能发生，但足够少见，因此在调试输出中使用它仍有价值）。
  • Object.runtimeType，对象的 Type。

实现

String describeIdentity(Object? object) =>
    '${objectRuntimeType(object, '<optimized out>')}#${shortHash(object)}';
