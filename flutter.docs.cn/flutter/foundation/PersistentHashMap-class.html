PersistentHashMap<K extends Object, V> 类

键值对集合，支持通过键高效检索值。

此类实现了持久化映射：向映射添加新的键值对不会修改现有实例，而是创建一个新实例。

与 Map 不同，此类不支持将 null 用作键，并且仅实现框架核心中特定使用场景所需的功能。

底层实现采用哈希数组映射字典树（hash array mapped trie）数据结构的一种变体，其节点经过压缩并使用位图索引。

另请参阅：

  • Steindorfer, Michael J., and Jurgen J. Vinju. "Optimizing hash-array mapped tries for fast and lean immutable JVM collections.";
