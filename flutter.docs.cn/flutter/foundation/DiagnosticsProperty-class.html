DiagnosticsProperty<T> 类

具有 T 类型的 value 的属性。

如果默认的 value.toString() 无法充分描述该值，请指定 description 以定义自定义描述。

showSeparator 属性指示是否应在属性的 name 与其 value 之间放置分隔符。
