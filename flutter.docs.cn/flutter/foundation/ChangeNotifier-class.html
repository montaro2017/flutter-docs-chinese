ChangeNotifier 类 mixin

可被继承或作为 mixin 使用的类，提供通过 VoidCallback 发送通知的变化通知 API。

添加监听器的时间复杂度为 O(1)，移除监听器和派发通知的时间复杂度为 O(N)，其中 N 为监听器数量。

使用 ChangeNotifier 子类作为数据模型

数据结构可以继承 ChangeNotifier 或将其作为 mixin 使用，以实现 Listenable 接口。这样就能与监听 Listenable 变化的 widget（例如 ListenableBuilder）一起使用。

下面的示例实现了一个简单计数器，使用 ListenableBuilder，使重新构建仅发生在显示计数的 Text widget 上。当前计数保存在 ChangeNotifier 子类中；值发生变化时，会重新构建 ListenableBuilder 的内容。

要使用此代码示例创建本地项目，请运行：
flutter create --sample=foundation.ChangeNotifier.1 mysample

在此示例中，ChangeNotifier 子类封装了一个列表，每次向列表添加元素时都会通知使用方。此示例仅支持添加元素；作为练习，可以考虑再添加按钮，用于移除列表中的元素。
