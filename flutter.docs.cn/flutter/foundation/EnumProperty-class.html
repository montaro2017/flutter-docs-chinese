EnumProperty<T extends Enum?> 类

以 Enum 为值的 DiagnosticsProperty。

显示枚举值时会去掉枚举类型名。例如，HitTestBehavior.deferToChild 显示为 deferToChild。

此类可用于枚举，并返回枚举的 name getter。也可用于可空属性；空值表示为 null。

另请参阅：

  • DiagnosticsProperty，其文档介绍了所有 DiagnosticsProperty 共用的命名参数。
