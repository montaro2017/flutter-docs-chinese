demangleStackTrace 属性

StackTraceDemangler demangleStackTrace
getter/setter 对

Flutter 框架在尝试解析 StackTrace 之前会调用此函数。

某些 StackTrace 实现的 toString 格式与框架预期不同，例如来自 package:stack_trace 的实现。为确保仍能解析和过滤经过改写的 StackTrace，框架会先调用此函数还原堆栈格式。

任何可能将特殊格式堆栈跟踪传递给框架的环境都应设置此函数。否则，默认行为会假定所有堆栈跟踪均采用 Dart 通常生成的格式。

以下示例通过将 package:stack_trace 跟踪转换为 VM 跟踪来还原其格式，使框架能够解析：

FlutterError.demangleStackTrace = (StackTrace stack) {
  // Trace and Chain are classes in package:stack_trace
  if (stack is Trace) {
    return stack.vmTrace;
  }
  if (stack is Chain) {
    return stack.toTrace().vmTrace;
  }
  return stack;
};

实现

static StackTraceDemangler demangleStackTrace = _defaultStackTraceDemangler;
