FlutterError 构造函数

FlutterError(
  1. String message
)

从字符串创建错误消息。

消息可以包含换行。第一行应简要描述错误，例如“GlobalKey 使用不正确”或“在构建过程中调用了 setState() 或 markNeedsBuild()”。后续各行应包含充分的补充信息，最好足以帮助制定正确的解决方案。

某些情况下，向用户报告 FlutterError 时只包含第一行。例如，Flutter 通常只在运行时完整报告第一个异常，后续错误仅显示第一行。

错误中的所有句子都应使用正确的标点（也就是说，错误消息应以句号结尾）。

此构造函数委托给 FlutterError.fromParts 构造函数。第一行会隐式包装为 ErrorSummary，后续各行会隐式包装为 ErrorDescription。可考虑使用 FlutterError.fromParts 构造函数提供更多详情，例如使用 ErrorHint 或其他 DiagnosticsNode。

实现

factory FlutterError(String message) {
  final List<String> lines = message.split('\n');
  return FlutterError.fromParts(<DiagnosticsNode>[
    ErrorSummary(lines.first),
    ...lines.skip(1).map<DiagnosticsNode>((String line) => ErrorDescription(line)),
  ]);
}
