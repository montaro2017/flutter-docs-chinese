debugDefaultTargetPlatformOverride top-level property

TargetPlatform? get debugDefaultTargetPlatformOverride

在调试构建中覆盖 defaultTargetPlatform。

将此值设为 null，会使 defaultTargetPlatform 恢复原始值，即根据实际当前平台确定的值。

通常，此覆盖设置仅对测试有用。要改变 widget 模拟的平台外观与行为，可以考虑使用平台覆盖 API，例如 material 库中的 ThemeData.platform。

设置 debugDefaultTargetPlatformOverride 而非 ThemeData.platform 等属性，会产生意外且不理想的影响。例如，当应用在 Android 上运行时，将其设为 TargetPlatform.iOS 会使 Android 的 TalkBack 无障碍工具接收到原本供 iOS VoiceOver 使用的数据，从而产生混乱。同样，在 iOS 上将其设为 TargetPlatform.android，会使某些 widget 假定系统具有全局返回按钮；由于 iOS 没有该按钮，这些 widget 将无法使用。

在非调试构建中尝试覆盖此属性会导致错误。

set debugDefaultTargetPlatformOverride(TargetPlatform? value) {
  if (!kDebugMode) {
    throw FlutterError('Cannot modify debugDefaultTargetPlatformOverride in non-debug builds.');
  }
  _debugDefaultTargetPlatformOverride = value;
}
