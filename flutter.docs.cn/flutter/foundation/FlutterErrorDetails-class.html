FlutterErrorDetails 类

为 FlutterExceptionHandler 回调提供信息的类。

此示例展示了调用 FlutterError.reportError 时如何使用 FlutterErrorDetails。
link 
void main() {
  try {
    // Try to do something!
  } catch (error) {
    // Catch & report error.
    FlutterError.reportError(FlutterErrorDetails(
      exception: error,
      library: 'Flutter test framework',
      context: ErrorSummary('while running async test code'),
    ));
  }
}

另请参阅：

  • FlutterError.onError，Flutter 框架捕获错误时会调用它。
