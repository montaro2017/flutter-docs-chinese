StackFrame 类

堆栈跟踪中一个帧的对象表示。

此示例从当前 StackTrace 创建一个可遍历的列表，其中包含解析后的 StackFrame 对象。
link 
final List<StackFrame> currentFrames = StackFrame.fromStackTrace(StackTrace.current);
