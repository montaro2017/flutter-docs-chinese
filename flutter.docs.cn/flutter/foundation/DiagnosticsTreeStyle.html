DiagnosticsTreeStyle enum

用于显示 DiagnosticsNode 树中节点的样式。

在发布模式下，这些样式可能被忽略，因为诊断信息会被压缩或截断，以减小二进制文件大小。

另请参阅：

  • DiagnosticsNode.toStringDeep，按这些样式输出字符图形式的树。
继承关系
  • Object
  • Enum
  • DiagnosticsTreeStyle
Available extensions
  • EnumName

Values

none → const DiagnosticsTreeStyle

不显示树的样式，用于发布模式。

sparse → const DiagnosticsTreeStyle

用于显示树的稀疏样式。

另请参阅：

  • RenderObject，使用此样式。
offstage → const DiagnosticsTreeStyle

用虚线将节点连接到其父节点。

另请参阅：

  • RenderSliverMultiBoxAdaptor，使用此样式区分不在显示区域中的子节点与正在显示的子节点。
dense → const DiagnosticsTreeStyle

比 sparse 样式稍紧凑的版本。

另请参阅：

  • Element，使用此样式。
transition → const DiagnosticsTreeStyle

支持从一种样式的节点过渡到另一种样式的子节点的样式。

另请参阅：

  • RenderParagraph，使用此样式显示 TextSpan 子节点，使其与 DiagnosticsTreeStyle.sparse 样式的 RenderObject 树兼容。
error → const DiagnosticsTreeStyle

用于显示错误描述内容的样式。

另请参阅：

  • FlutterError，在描述错误的树中，将此样式用于根节点。
whitespace → const DiagnosticsTreeStyle

仅使用空白字符渲染树，不使用线条连接父子节点。

另请参阅：

  • SliverGeometry，使用此样式。
flat → const DiagnosticsTreeStyle

渲染树时完全不缩进子节点。

另请参阅：

  • DiagnosticsStackTrace，使用此样式。
singleLine → const DiagnosticsTreeStyle

将树渲染为单行，不显示子节点。

errorProperty → const DiagnosticsTreeStyle

使用适合错误消息中属性的样式渲染树。

名称单独占一行，值和属性放在下一行。

另请参阅：

  • singleLine，显示相同的信息，但将属性和值保留在同一行。
shallow → const DiagnosticsTreeStyle

仅渲染节点的直接属性，而不是整棵树。

另请参阅：

  • DebugOverflowIndicatorMixin，使用此样式仅显示节点的直接子节点。
truncateChildren → const DiagnosticsTreeStyle

仅渲染节点的子节点，在树变得过大之前截断。
