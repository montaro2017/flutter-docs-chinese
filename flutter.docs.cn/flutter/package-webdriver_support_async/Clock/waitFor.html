等待 condition 的计算结果与 matcher 匹配，或直到经过 timeout 指定的时间。如果 condition 返回 Future，则使用该 Future 的值，而不是 condition 的返回值。

如果等待成功，则返回 condition 中匹配的返回值。否则，如果 condition 抛出异常，则重新抛出该异常。如果 condition 未抛出异常，则抛出 expect 异常。

reason 为可选参数，通常无需提供，因为系统会根据 matcher 生成原因；如果提供了 reason，则会将其附加到 matcher 生成的原因之后。

实现

Future<T> waitFor<T>(FutureOr<T> Function() condition,
    {Object? matcher,
    Duration timeout = defaultTimeout,
    Duration interval = defaultInterval,
    String? reason}) async {
  final mMatcher = matcher == null ? null : m.wrapMatcher(matcher);
  final endTime = now.add(timeout);
  while (true) {
    try {
      final value = await condition();
      if (mMatcher != null) {
        _matcherExpect(value, mMatcher, reason);
      }
      return value;
    } catch (e) {
      if (now.isAfter(endTime)) {
        rethrow;
      } else {
        await sleep(interval);
      }
    }
  }
}
