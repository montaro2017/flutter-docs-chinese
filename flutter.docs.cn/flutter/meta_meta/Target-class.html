Target

Target 类

用于注解类的注解，用来指明该注解适用的声明种类和指令种类。

这些种类由 TargetKind 中定义的常量表示。

analyzer 等工具可以在以下情况下提供反馈：

  • the annotation is associated with anything other than a class, where the class must be usable as an annotation (that is, contain at least one const constructor).
  • the annotated annotation is associated with anything other than the kinds of declarations listed as valid targets.

此类型不适合被扩展，并将在 package:meta 的未来版本中标记为 final。

注解
  • @Target({TargetKind.classType})
