将 L* 值转换为 Y 值。

Lab* 中的 L* 与 XYZ 中的 Y 衡量的是同一属性：亮度。

L* 衡量感知亮度，采用线性刻度；XYZ 中的 Y 衡量相对亮度，采用对数刻度。

lstar L*（Lab* 色彩空间） 返回 XYZ 色彩空间中的 Y

实现

static double yFromLstar(double lstar) {
  return 100.0 * _labInvf((lstar + 16.0) / 116.0);
}
