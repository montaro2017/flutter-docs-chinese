CustomSemanticsAction 类

自定义语义操作的标识符。

提供自定义语义操作可以改善复杂用户交互的无障碍体验。例如，应用有一个拖放列表，用户需要按住某个项目才能移动它；使用硬件开关操作应用的用户可能难以完成此操作。可以创建自定义操作，并为其配置处理程序，以便将列表项向上或向下移动，从而让此交互更易于访问。

在 Android 上，这些操作会显示在本地上下文菜单中；在 iOS 上，则显示在环形上下文菜单中。

提供的标签或提示不会自动应用本地化和文本方向。

此类实例应使用 const 创建，或者将新实例缓存在静态字段中。

另请参阅：

  • SemanticsProperties, where the handler for a custom action is provided.
