SemanticsService 类 抽象 final

允许访问平台的无障碍服务。

此服务发送的事件由 Flutter 引擎中的平台专属无障碍桥接层处理。

在可行的情况下，优先使用 Semantics 等机制隐式触发播报，而不是使用此事件。
