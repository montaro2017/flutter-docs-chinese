SemanticsNode 类

表示某些语义数据的节点。

语义树会在流水线的语义阶段维护（即调用 PipelineOwner.flushSemantics 期间），该阶段发生在合成之后。随后，语义树会上传到引擎，供辅助技术使用。

混入的类型
  • DiagnosticableTreeMixin

构造函数

SemanticsNode({Key? key, VoidCallback? showOnScreen})
创建语义节点。
SemanticsNode.root({Key? key, VoidCallback? showOnScreen, required SemanticsOwner owner})
创建用于表示语义树根节点的语义节点。
