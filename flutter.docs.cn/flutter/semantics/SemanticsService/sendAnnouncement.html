为特定视图发送语义播报。

可以使用 View.of 获取当前的 FlutterView。

当系统不会因界面状态变化而自然播报时，应使用此方法进行播报。

例如，相机应用可以使用此方法播报取景器中物体的无障碍信息。

播报的强制级别由 assertiveness 决定。目前只有 Web 引擎支持此设置，在其他平台上不起作用。默认模式为 Assertiveness.polite。

并非所有平台都支持播报。调用此方法前，请使用 MediaQuery.supportsAnnounceOf 检查是否受支持。

Android

由于 Android 的播报事件会打断 TalkBack，迫使其清空语音队列并朗读所提供的文本，因此这些事件已被弃用。请改用 Semantics 等机制隐式触发播报。

实现

static Future<void> sendAnnouncement(
  FlutterView view,
  String message,
  TextDirection textDirection, {
  Assertiveness assertiveness = Assertiveness.polite,
}) async {
  final event = AnnounceSemanticsEvent(
    message,
    textDirection,
    view.viewId,
    assertiveness: assertiveness,
  );
  await SystemChannels.accessibility.send(event.toMap());
}
