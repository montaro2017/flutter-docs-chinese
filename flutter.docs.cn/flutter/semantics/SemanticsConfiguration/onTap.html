onTap 属性

VoidCallback? get onTap

SemanticsAction.tap 的处理程序。

此操作在语义上等同于用户用手指短暂轻点屏幕且不移动。例如，按钮应实现此操作。

iOS 上的 VoiceOver 用户和 Android 上的 TalkBack 用户可以在元素获得焦点时双击屏幕来触发此操作。

在 Android Oreo 之前的版本中，如果带有 onTap 处理程序的元素获得焦点，用户双击屏幕时不会调用已注册的处理程序。Android 会改为在焦点元素的中心模拟一次指针按下和抬起事件。其分发方式与禁用 TalkBack 后的常规轻点相同：中心位置上监听手势的 GestureDetector 会处理这些事件。因此，为确保 Android Oreo 之前版本上的 onTap 处理程序正常工作，定义了语义 onTap 处理程序的元素应始终由带有 onTap 处理程序的 GestureDetector 包裹。默认情况下，GestureDetector 会按照此原则注册自己的语义 onTap 处理程序。

实现

VoidCallback? get onTap => _onTap;
set onTap (VoidCallback? value)

实现

set onTap(VoidCallback? value) {
  _addArgumentlessAction(SemanticsAction.tap, value!);
  _onTap = value;
}
