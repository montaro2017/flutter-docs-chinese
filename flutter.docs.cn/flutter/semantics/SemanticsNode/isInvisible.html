isInvisible 属性

bool get isInvisible

此节点是否不可见。

如果节点的 rect 位于屏幕边界之外，因而用户无法访问，并且其语义信息未合并到部分或全部可见的父节点中（由 isMergedIntoParent 指示），则该节点会被视为不可见。

从语义树中安全移除不可见节点，不会丢失描述屏幕当前内容所需的语义信息。

实现

bool get isInvisible => !isMergedIntoParent && (rect.isEmpty || (transform?.isZero() ?? false));
