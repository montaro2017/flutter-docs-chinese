SemanticsSortKey 类 抽象

所有用于 SemanticsProperties.sortKey 无障碍遍历顺序排序的排序键基类。

排序键先按 name 排序，然后按子类实现的比较规则排序。如果指定了 SemanticsProperties.sortKey，同一语义组中的排序键必须全部属于相同类型。

没有 name 的键彼此比较，并且会先于具有 name 的键进行遍历（此处所指的是具有 name 的键）。

如果语义节点没有应用排序键，则会使用依赖平台的默认算法进行排序。
