semantics 库

Flutter 语义（semantics）库。

使用时，请导入 package:flutter/semantics.dart。

SemanticsEvent 类定义了向平台发送语义事件的协议。

SemanticsNode 层级表示 UI 的语义结构，并由特定平台的无障碍服务使用。
