kCupertinoSupportedLanguages top-level property

Set<String> kCupertinoSupportedLanguages
final

支持的语言集合，以语言代码字符串表示。

GlobalCupertinoLocalizations.delegate 可以为此集合中的任何 Locale 生成本地化资源，无论其区域代码为何。部分区域提供专门支持（例如，de 覆盖所有德语形式，而另有针对瑞士的 de-CH 支持，用于覆盖瑞士专用译文）。

另请参阅：

  • getCupertinoTranslation, whose documentation describes these values.
