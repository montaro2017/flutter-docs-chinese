GlobalMaterialLocalizations
description

GlobalMaterialLocalizations 类 抽象

使用 intl 包为 Material 组件实现本地化字符串，并提供日期和时间格式。

示例代码

要在 MaterialApp 中包含此类提供的本地化内容，请将 GlobalMaterialLocalizations.delegates 添加到 MaterialApp.localizationsDelegates，并通过 MaterialApp.supportedLocales 指定应用支持的区域设置：

const MaterialApp(
  localizationsDelegates: GlobalMaterialLocalizations.delegates,
  supportedLocales: <Locale>[
    Locale('en', 'US'), // American English
    Locale('he', 'IL'), // Israeli Hebrew
    // ...
  ],
  // ...
)

覆盖翻译

如果要创建与现有语言翻译相似、但字符串略有不同的翻译，可以直接继承相应的翻译类，然后创建 LocalizationsDelegate<MaterialLocalizations> 子类来定义如何加载它。

不要继承无关语言的翻译类（例如，继承 MaterialLocalizationEn，却向构造函数传入非英语的 localeName）。这样会使区域设置相关行为产生歧义；尤其是依赖 localeName 决定复数形式的翻译会出现错误。只有在小幅修改现有字符串时，才适合继承现有语言的翻译。若要完整提供一种新语言，应直接实现 MaterialLocalizations。

另请参阅：

  • The Flutter Internationalization Tutorial, flutter.dev/to/internationalization/.
  • DefaultMaterialLocalizations, which only provides US English translations.
