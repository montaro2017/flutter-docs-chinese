GlobalCupertinoLocalizations
description

GlobalCupertinoLocalizations 类 抽象

使用 intl 包为 Cupertino 组件实现本地化字符串，并提供日期和时间格式。

日期和时间格式之外的字符串本地化，由 GlobalCupertinoLocalizations 的特定语言子类提供。

示例代码

要在 CupertinoApp 中包含此类提供的本地化内容，请将 GlobalCupertinoLocalizations.delegates 添加到 CupertinoApp.localizationsDelegates，并通过 CupertinoApp.supportedLocales 指定应用支持的区域设置：

const CupertinoApp(
  localizationsDelegates: GlobalCupertinoLocalizations.delegates,
  supportedLocales: <Locale>[
    Locale('en', 'US'), // American English
    Locale('he', 'IL'), // Israeli Hebrew
    // ...
  ],
  // ...
)

另请参阅：

  • DefaultCupertinoLocalizations, which provides US English localizations for Cupertino widgets.
