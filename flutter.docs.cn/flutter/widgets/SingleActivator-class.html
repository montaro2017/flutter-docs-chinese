SingleActivator 类

由单个按键和修饰键组成的快捷键组合。

SingleActivator 可实现常见快捷键，例如：

  • ArrowLeft
  • Shift + Delete
  • Control + Alt + Meta + Shift + A

更具体地说，它会创建由一个 trigger 键以及四个修饰键（control、shift、alt、meta）中的任意零个、部分或全部组成的快捷键组合。满足以下条件时会触发快捷键：

  • 收到的事件是某个 trigger 键的按下事件。
  • 如果 control 为 true，则必须按住至少一个 Control 键；否则不得按住任何 Control 键。
  • alt、shift 和 meta 键也适用类似条件。

这与大多数操作系统的常见行为相似，但与 LogicalKeySet 相比，它以如下方式处理修饰键：

  • SingleActivator 允许同时按下其他非修饰键来触发快捷键。例如，按住 ControlLeft 的同时按下 X 和 A 键，也会被 SingleActivator(LogicalKeyboardKey.keyX, control: true) 接受。
  • SingleActivator 不会将修饰键视为触发键。例如，按住 X 键时按下 ControlLeft 不会触发 SingleActivator(LogicalKeyboardKey.keyX, control: true)。

另请参阅：

  • CharacterActivator：一种表示可产生指定字符（例如问号）的按键组合的激活器。
