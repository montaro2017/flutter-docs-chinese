WidgetStatesController 类

管理一组 WidgetState，并在状态变化时通知监听器。

供需要公开内部状态、以便扩展支持其他状态的组件使用。示例请参阅 TextButton。

控制器的 value 是当前状态集合。每当 value 发生变化时，都会通知监听器。应仅通过 update 修改 value，不要直接改动。

控制器的 value 表示用于解析组件视觉属性（通常是 WidgetStateProperty 值）的一组状态，并不代表组件的内在状态。组件负责确保控制器的 value 与其内在状态保持同步。例如，不能通过向控制器添加 WidgetState.focused 来请求组件获得键盘焦点。组件获得或失去焦点时，会调用 update 更新控制器的 value，并通知监听器状态已变化。

在 WidgetStatesController 监听器中调用 setState 时，应使用 SchedulerBinding.addPostFrameCallback，将 setState 调用延迟到帧渲染完成之后。通常也建议使用 SchedulerBinding.addPostFrameCallback，因为依赖 WidgetStatesController 的某些组件可能会在构建方法中调用 update。若监听器在构建阶段调用 setState，就会导致错误。

另请参阅：

  • MaterialStatesController, the Material specific version of WidgetStatesController.
