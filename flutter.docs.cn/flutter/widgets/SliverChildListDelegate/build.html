重写

返回具有给定索引的子项。

如果请求构建索引超出实际范围的 widget，应返回 null。如果此处返回 null，之后 estimatedChildCount 必须返回精确的非 null 值（该值随后用于实现 RenderSliverBoxChildManager.childCount）。

子类通常会重写此函数，并使用 AutomaticKeepAlive、IndexedSemantics 和 RepaintBoundary widget 包装子项。

此方法返回的值会被缓存。若要表明 widget 已更改，必须提供新的委托对象，并确保新委托对象的 shouldRebuild 方法返回 true。

实现

@override
Widget? build(BuildContext context, int index) {
  if (index < 0 || index >= children.length) {
    return null;
  }
  Widget child = children[index];
  final Key? key = child.key != null ? _SaltedValueKey(child.key!) : null;
  if (addRepaintBoundaries) {
    child = RepaintBoundary(child: child);
  }
  if (addSemanticIndexes) {
    final int? semanticIndex = semanticIndexCallback(child, index);
    if (semanticIndex != null) {
      child = IndexedSemantics(index: semanticIndex + semanticIndexOffset, child: child);
    }
  }
  if (addAutomaticKeepAlives) {
    child = AutomaticKeepAlive(child: _SelectionKeepAlive(child: child));
  }

  return KeyedSubtree(key: key, child: child);
}
