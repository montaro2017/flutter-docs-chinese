addAutomaticKeepAlives 属性

bool addAutomaticKeepAlives
final

是否将每个子组件都包在 AutomaticKeepAlive 中。

通常，延迟布局的子组件会包在 AutomaticKeepAlive 中，以便在它们滚出屏幕并可能被垃圾回收时，使用 KeepAliveNotification 保留自身状态。

如果子组件将自行维护其 KeepAlive 状态，则必须禁用此功能以及 addRepaintBoundaries。如果事先确定所有子组件都不会尝试保持存活，禁用此功能也可能更高效。

默认为 true。

此示例展示如何结合使用 AutomaticKeepAlive 组件与 AutomaticKeepAliveClientMixin，有选择地保留可滚动列表中各个条目的状态。

通常，为提升性能，像 ListView.builder 这样延迟构建的列表会在子组件离开可见区域时将其释放。这意味着 StatefulWidget 中的状态会丢失，除非显式保留。

此示例中，每个列表条目都是包含计数器和递增按钮的 StatefulWidget。为保留选定条目的状态（根据其索引选择），示例使用 AutomaticKeepAlive 和 AutomaticKeepAliveClientMixin：

  • 项目的 state 类中的 wantKeepAlive getter 对偶数索引项返回 true，表示应保留这些项目的状态。
  • 对于奇数索引项，wantKeepAlive 返回 false，因此滚出视野后不会保留其状态。

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.SliverChildBuilderDelegate.addAutomaticKeepAlives.1 mysample

此示例展示如何使用 KeepAlive 组件，在 ListView 列表条目滚出视野后仍保留其各自的状态。

默认情况下，ListView.builder 只会让当前位于视口中的组件保持存活。条目滚出视野后，可能会被释放以节省资源。如果没有显式保留状态，StatefulWidget 的状态可能会丢失。

此示例中的每个列表条目都是一个维护计数器的 StatefulWidget。点击“+”按钮会增加计数器。为了有选择地保留状态，每个条目都会包在 KeepAlive 组件中，并根据条目的索引设置 keepAlive 参数：

  • 对于偶数索引项，使用 keepAlive: true，因此即使滚出屏幕也会保留其状态。
  • 对于奇数索引项，keepAlive: false，因此它们不再可见时，其状态会被丢弃。

  • AutomaticKeepAlive，使子树可以请求在惰性列表中保持存活。
