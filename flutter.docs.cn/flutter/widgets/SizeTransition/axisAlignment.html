axisAlignment 属性

  1. @Deprecated('Use alignment instead. ' 'This property provides full control over both axes, which is an improvement over the old axisAlignment. ' 'This feature was deprecated after v3.41.0-1.0.pre.')
double? axisAlignment
final

描述如何沿着 sizeFactor 所调整的轴对齐子项。

值为 -1.0 时表示顶部（当 axis 为 Axis.vertical 时），或起始位置（当 axis 为 Axis.horizontal 时）。文本方向为 TextDirection.ltr 时起始位置在左侧，为 TextDirection.rtl 时则在右侧。

值为 1.0 时表示底部或末尾，具体取决于 axis。

值为 0.0（默认值）时，无论 axis 为何值，都表示居中。

此属性已弃用，现由 alignment 取代。现有用法可按以下方式迁移到 alignment：

  • 当 axis 为 Axis.horizontal 时，替换为 Alignment(axisAlignment ?? 0.0, -1.0)。
  • 当 axis 为 Axis.vertical 时，替换为 Alignment(-1.0, axisAlignment ?? 0.0)。
