restoreScrollOffset 方法

  1. @protected
void restoreScrollOffset()

每当创建 ScrollPosition 时调用；如果可能，则恢复滚动偏移量。

滚动位置变化时，saveScrollOffset 会保存该值，以便在同一会话中销毁并重新创建 Scrollable 时恢复。例如，某个 ListView 位于 TabBarView 的一个页面中，该页面先显示、随后隐藏、之后再次显示。

默认实现会从 context 的 ScrollContext.storageContext 属性所能找到的最近 PageStorage 中读取该值，并在 pixels 仍为 null 时通过 correctPixels 设置该值。

此方法在构造函数中调用，因此调用时尚未进行布局，也尚不知道视口尺寸。

实现

// TODO(goderbauer): Deprecate this when state restoration supports all features of PageStorage.
@protected
void restoreScrollOffset() {
  if (!hasPixels) {
    final value =
        PageStorage.maybeOf(context.storageContext)?.readState(context.storageContext) as double?;
    if (value != null) {
      correctPixels(value);
    }
  }
}
