提供一种启发式方法，用于判断是否应延迟执行耗费较大的帧内任务。

实际判断会委托给 physics，通过当前 activity 的 ScrollActivity.velocity 调用 ScrollPhysics.recommendDeferredLoading。

此方法返回 true 表示 ScrollPhysics 判断当前滚动速度足够快，因此应延迟可能影响界面的高开销操作。

实现

bool recommendDeferredLoading(BuildContext context) {
  assert(activity != null);
  return physics.recommendDeferredLoading(
    activity!.velocity + _impliedVelocity,
    copyWith(),
    context,
  );
}
