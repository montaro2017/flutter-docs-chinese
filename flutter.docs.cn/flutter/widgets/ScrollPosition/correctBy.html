重写

在布局期间修正滚动偏移量。

此方法应将 pixels 值按 correction 指定的量进行更改，但不调用 notifyListeners。RenderViewport 会在布局期间、调用 applyContentDimensions 之前调用此方法。调用后会重新计算布局，极少数情况下可能再次调用此方法。

另请参阅：

  • 若要在布局之外更改滚动位置，也可使用 jumpTo。jumpTo 会立即应用更改并通知监听器。
  • correctPixels 由 ScrollPosition 自身使用，用于在构造期间或调用 applyViewportDimension 或 applyContentDimensions 后初始化偏移量。

实现

@override
void correctBy(double correction) {
  assert(
    hasPixels,
    'An initial pixels value must exist by calling correctPixels on the ScrollPosition',
  );
  _pixels = _pixels! + correction;
  _didChangeViewportDimensionOrReceiveCorrection = true;
}
