RawScrollbar 类

用于构建可淡入和淡出的滚动条的可扩展基类。

若要为 ScrollView（例如 ListView 或 CustomScrollView）添加滚动条，请用 RawScrollbar 组件包裹滚动视图组件。

滚动条滑块用于指示 ScrollView 中当前可见的部分。

默认情况下，子滚动视图滚动时，滑块会淡入和淡出。将 thumbVisibility 设为 true 后，滚动条滑块会保持可见，不执行淡出动画。这要求将与 Scrollable 组件关联的 ScrollController 传给 controller，或者由该 Scrollable 组件使用 PrimaryScrollController。

如果滚动条包裹了多个 ScrollView，默认情况下它只响应最近的 ScrollView，并显示对应的滑块。通过 notificationPredicate，可以自定义滚动条要监听哪些 ScrollNotification。

如果子 ScrollView 的长度无限，RawScrollbar 将不会绘制。在这种情况下，滚动条无法准确表示可视区域的相对位置，也无法计算拖动滑块或点击轨道时应应用的准确增量。

交互

滚动条支持交互；如果未设置 controller，则可以使用 PrimaryScrollController。用户可以沿 ScrollView 的主轴拖动交互式滚动条滑块，以更改 ScrollPosition。点击滑块以外的轨道时，会根据点击位置相对于滑块的位置触发 ScrollIncrementType.page。

使用 PrimaryScrollController 时，它不能同时附加到多个 ScrollPosition。未提供 ScrollController，且 ScrollView.scrollDirection 为 Axis.vertical 的 ScrollView 会自动将其 ScrollPosition 附加到 PrimaryScrollController。此时应为每个 Scrollable 提供唯一的 ScrollController，避免多个 ScrollPosition 附加到同一个 PrimaryScrollController。

此示例展示了同一路由中包含两个可滚动组件的应用。由于每个路由默认只有一个 PrimaryScrollController，且这两个组件的滚动方向都是 Axis.vertical，在移动平台上它们都会尝试附加到该控制器。Scrollbar 不支持多个位置同时附加到同一控制器，因此其中一个 ListView 及其 Scrollbar 使用了单独的 ScrollController。桌面平台不会自动附加到 PrimaryScrollController；若要使用它，需要改为将 ScrollView.primary 设为 true。

Alternatively, a new PrimaryScrollController could be created above one of the ListView。

桌面平台上的自动滚动条

在 TargetPlatformVariant.desktop 平台上，大多数 Scrollable 组件默认会添加滚动条。这通过应用的 ScrollConfiguration 中的 ScrollBehavior.buildScrollbar 实现。未使用 PrimaryScrollController，或自身提供了 ScrollController 的 Scrollable 会获得一个供滚动条使用的唯一 ScrollController。此时，除非将 interactive 设为 false，否则只能有一个 Scrollable 使用 PrimaryScrollController。若要阻止 Axis.vertical 方向的 Scrollable 使用 PrimaryScrollController，请将 ScrollView.primary 设为 false。以下 Scrollable 组件不会自动应用滚动条：

  • EditableText
  • ListWheelScrollView
  • PageView
  • NestedScrollView
  • DropdownButton

若要为整个应用停用默认滚动条，可设置一个 ScrollBehavior，并将 scrollbars 设为 false。

link 
MaterialApp(
  scrollBehavior: const MaterialScrollBehavior()
    .copyWith(scrollbars: false),
  home: Scaffold(
    appBar: AppBar(title: const Text('Home')),
  ),
)
