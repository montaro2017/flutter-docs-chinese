Flex 类

沿一维方向排列其子项的 widget。

Flex widget 允许你控制子项排列的轴向（水平或垂直），称为主轴。如果主轴方向已知，可考虑改用 Row（水平）或 Column（垂直），因为写法更简洁。

若要让子项沿此 widget 主轴的 direction 扩展并填满可用空间，可使用 Expanded widget 包装子项。

Flex widget 不会滚动（通常，子项数量超过 Flex 可用空间会被视为错误）。如果有一组 widget 在空间不足时需要支持滚动，请考虑使用 ListView。

Flex widget 不允许其子项换行到多个水平或垂直排列行中。若需要子项能够换行，请改用 Wrap，而不是 Flex。

如果只有一个子项，与其使用 Flex、Row 或 Column，不如使用 Align 或 Center 来定位子项。

布局算法

本节介绍框架如何渲染 Flex。盒式布局模型简介请参阅 BoxConstraints。

Flex 的布局分为六个步骤：

  1. 使用主轴无界约束和传入的交叉轴约束，对每个 flex 因子为 null 或零的子项进行布局（例如未使用 Expanded 的子项）。如果 crossAxisAlignment 为 CrossAxisAlignment.stretch，则改用紧约束，使交叉轴约束与传入的交叉轴最大范围一致。
  2. 根据 flex 因子，将主轴剩余空间分配给 flex 因子非零的子项（例如使用 Expanded 的子项）。例如，flex 因子为 2.0 的子项获得的主轴空间是因子为 1.0 子项的两倍。
  3. 使用与步骤 1 相同的交叉轴约束布局其余子项，但不再使用无界主轴约束，而是根据步骤 2 分配的空间设置主轴最大约束。Flexible.fit 为 FlexFit.tight 的子项会受到紧约束（即必须填满所分配空间）；为 Flexible.fit 属性为 FlexFit.loose 的子项则受到松约束（即不必填满所分配空间）。
  4. Flex 的交叉轴范围取子项交叉轴范围的最大值（这始终满足传入的约束）。
  5. Flex 的主轴范围由 mainAxisSize 属性决定。如果 mainAxisSize 属性为 MainAxisSize.max，则 Flex 的主轴范围为传入主轴约束的最大范围。如果 mainAxisSize 属性为 MainAxisSize.min，则 Flex 的主轴范围为子项主轴范围之和（但仍受传入约束限制）。
  6. 根据 mainAxisAlignment 和 crossAxisAlignment 确定每个子项的位置。例如，当 mainAxisAlignment 为 MainAxisAlignment.spaceBetween 时，未分配给子项的主轴空间会均匀分配并放置在子项之间。

另请参阅：

  • Row：此 widget 的水平排列版本。
  • Column：此 widget 的垂直排列版本。
  • Expanded：指示子项应占用所有剩余空间。
  • Flexible：指示子项应共享剩余空间。
  • Spacer：按 flex 值比例占用空间的 widget；也可以缩小尺寸，从而留下一部分未使用的空间。
  • Wrap：允许子项换行到多个行中的 widget。
  • 布局 widget 目录。
