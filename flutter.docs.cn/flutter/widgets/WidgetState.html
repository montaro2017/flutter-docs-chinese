WidgetState enum

部分组件在接收用户输入时可能处于的交互状态。

这些状态由 https://m3.material.io/foundations/interaction/states 定义，但不限于 Material 设计系统或 Material 库。

一些组件会使用 Set<WidgetState> 跟踪当前状态。

另请参阅：

  • MaterialState, the Material specific version of WidgetState.
  • WidgetStateProperty, an interface for objects that "resolve" to different values depending on a widget's state.
  • WidgetStateColor, a Color that implements WidgetStateProperty which is used in APIs that need to accept either a Color or a WidgetStateProperty<Color>.
  • WidgetStateMouseCursor, a MouseCursor that implements WidgetStateProperty，用于需要接受 MouseCursor 或 WidgetStateProperty<MouseCursor> 中任一类型的 API。
  • WidgetStateOutlinedBorder, an OutlinedBorder that implements WidgetStateProperty，用于需要接受 OutlinedBorder 或 WidgetStateProperty<OutlinedBorder> 中任一类型的 API。
  • WidgetStateBorderSide, a BorderSide that implements WidgetStateProperty，用于需要接受 BorderSide 或 WidgetStateProperty<BorderSide> 中任一类型的 API。
  • WidgetStateTextStyle, a TextStyle that implements WidgetStateProperty，用于需要接受 TextStyle 或 WidgetStateProperty<TextStyle> 中任一类型的 API。

Values

hovered → const WidgetState

用户将鼠标光标悬停在该组件上时所处的状态。

参见：https://material.io/design/interaction/states.html#hover。

focused → const WidgetState

用户使用键盘将焦点移至给定组件时所处的状态。

有时，点击组件也会触发此状态。例如，点击 TextField 后，该组件会进入 focused。

参见：https://material.io/design/interaction/states.html#focus。

pressed → const WidgetState

用户正在按下给定组件时所处的状态。

参见：https://material.io/design/interaction/states.html#pressed。

dragged → const WidgetState

用户将该组件从一处拖动到另一处时所处的状态。

https://material.io/design/interaction/states.html#dragged。

selected → const WidgetState

该项已被选中时所处的状态。

这适用于可切换的控件（例如 标签式组件和复选框），也适用于从一组选项中选择的控件（例如标签页和单选按钮）。

参见：https://material.io/design/interaction/states.html#selected。

scrolledUnder → const WidgetState

该组件覆盖其下方可滚动内容时所处的状态。

此状态供 AppBar 使用，以表示主可滚动内容已向上滚动到应用栏后方。

disabled → const WidgetState

该组件被禁用且无法交互时所处的状态。

已禁用的组件不应响应悬停、焦点、按压或拖动交互。

参见：https://material.io/design/interaction/states.html#disabled。

error → const WidgetState

组件进入某种无效状态时所处的状态。

参见 https://material.io/design/interaction/states.html#usage。
