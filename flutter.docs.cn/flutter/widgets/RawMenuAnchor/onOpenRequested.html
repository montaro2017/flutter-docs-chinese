onOpenRequested 属性

RawMenuAnchorOpenRequestedCallback onOpenRequested
final

收到打开菜单的请求时调用。

每次调用 MenuController.open 时都会触发此回调，即使菜单浮层已经显示也是如此。因此，可以在此处启动菜单打开动画，或监听菜单重新定位。

拦截打开请求后，应在菜单浮层（由 overlayBuilder 构建的组件）准备好显示时调用 showOverlay 回调。可以立即调用（默认行为），也可以延迟调用。调用 showOverlay 会将 MenuController.isOpen 设为 true，构建或重新构建浮层组件，并将菜单显示在浮层栈的最前方。

如果不调用 showOverlay，菜单会保持隐藏。组件释放后调用 showOverlay 不会执行任何操作，也不会触发 onOpen 或显示菜单浮层。

如果 RawMenuAnchor 用于带打开动画的主题菜单，则主题菜单应先显示浮层，再启动打开动画，因为动画是在浮层本身上播放的。

position 参数就是调用 MenuController.open 时传入的 position。

典型的 onOpenRequested 包含以下步骤：

  1. Optional delay.
  2. Call showOverlay (whose call chain eventually invokes onOpen).
  3. Optionally start the opening animation.

默认回调会立即显示菜单。
