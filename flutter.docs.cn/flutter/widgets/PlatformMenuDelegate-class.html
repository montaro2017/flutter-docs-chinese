PlatformMenuDelegate 类 抽象

可用于设置 WidgetsBinding.platformMenuDelegate 以管理平台菜单的抽象委托类。

可以通过子类实现不同于默认系统插件的菜单插件，用于管理 PlatformMenuBar 菜单。

当 PlatformMenuBar 的菜单层级发生变化时，可以调用 setMenus 方法设置菜单层级。

此委托不处理点击菜单项后的结果；其子类 PlatformMenuDelegate 的实现者需要自行处理。

此委托通常负责序列化 PlatformMenu 层级、通过通道发送数据，并注册通道调用，以处理菜单项被调用或子菜单打开、关闭的情况。

实现示例请参阅 DefaultPlatformMenuDelegate。

另请参阅：

  • PlatformMenuBar 是一种为应用添加平台菜单栏的 widget，并通过 setMenus 将菜单发送到平台。
  • PlatformMenu, the class that describes a menu item with children that appear in a cascading menu.
  • PlatformMenuItem, the class that describes the leaves of a menu hierarchy.
