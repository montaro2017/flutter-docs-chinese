TextSelectionGestureDetectorBuilder 类

构建一个用于包裹 EditableText 的 TextSelectionGestureDetector。

此类为与 EditableText 进行的多种用户交互实现了合理的默认行为（请参阅各个手势处理方法的文档，例如 onTapDown、onForcePressStart 等）。TextSelectionGestureDetectorBuilder 的子类可以重写此类中对应的处理方法，以更改对这些手势事件的响应行为。

要获取用于包裹 EditableText 的 TextSelectionGestureDetector，请调用 buildGestureDetector。

TextSelectionGestureDetectorBuilder 必须接收一个 TextSelectionGestureDetectorBuilderDelegate，以便从中获取有关 EditableText 的信息。通常，构建 EditableText 的 widget 的 State 会实现此接口，然后将自身作为 delegate 传入。

另请参阅：

  • TextField, which uses a subclass to implement the Material-specific gesture logic of an EditableText.
  • CupertinoTextField, which uses a subclass to implement the Cupertino-specific gesture logic of an EditableText.
