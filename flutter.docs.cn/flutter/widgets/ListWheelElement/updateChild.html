重写

使用给定的新配置更新指定子项。

此方法是 widget 系统的核心。每当需要根据更新后的配置添加、更新或移除子项时，都会调用它。

newSlot 参数指定此 Element 的 slot 新值。

如果 child 为 null 而 newWidget 不为 null，就需要创建一个新的 Element，并以 newWidget 为其配置。

如果 newWidget 为 null 而 child 不为 null，就需要移除该子项，因为它已不再有配置。

如果二者都不为 null，就需要将 child 的配置更新为 newWidget 指定的新配置。如果现有子项可以接收 newWidget（由 Widget.canUpdate 判断），就直接更新；否则需要释放旧子项，并为新配置创建一个新子项。

如果二者都为 null，说明当前没有子项，也不会有子项，因此无需执行任何操作。

updateChild 方法会返回新创建的子项、仅更新配置时传入的原子项，或者在移除子项且未替换它时返回 null。

下表总结了上述内容：

newWidget == null newWidget != null
child == null Returns null. Returns new Element.
child != null Old child is removed, returns null. Old child updated if possible, returns child or new Element.

newSlot 参数仅在 newWidget 不为 null 时使用。如果 child 为 null（或旧子项无法更新），就会将 newSlot 传给为该子项创建的新 Element，并通过 inflateWidget 创建它。如果 child 不为 null（且旧子项可以更新），则会将 newSlot 传给 updateSlotForChild 来更新其 slot，以应对它自上次构建后发生的位置变化。

有关 slot 的更多信息，请参阅 RenderObjectElement 文档。

实现

@override
Element? updateChild(Element? child, Widget? newWidget, Object? newSlot) {
  final oldParentData = child?.renderObject?.parentData as ListWheelParentData?;
  final Element? newChild = super.updateChild(child, newWidget, newSlot);
  final newParentData = newChild?.renderObject?.parentData as ListWheelParentData?;
  if (newParentData != null) {
    newParentData.index = newSlot! as int;
    if (oldParentData != null) {
      newParentData.offset = oldParentData.offset;
    }
  }

  return newChild;
}
