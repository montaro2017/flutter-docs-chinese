WidgetsFlutterBinding 类

面向 Widgets 框架应用的具体绑定实现。

它负责将框架与 Flutter 引擎连接起来。

使用 Widgets 框架时，必须使用此绑定，或使用实现相同接口的绑定。以下混入共同实现此绑定：

  • GestureBinding，实现命中测试的基本功能。
  • SchedulerBinding，引入帧的概念。
  • ServicesBinding，提供对插件子系统的访问。
  • PaintingBinding，支持图像解码。
  • SemanticsBinding，支持无障碍功能。
  • RendererBinding，负责处理渲染树。
  • WidgetsBinding，负责处理组件树。
