提供一种启发式方法，用于判断在特定时刻是否应为给定 context 延迟执行耗费较大的帧内任务。

调用此方法不会建立对其他组件的依赖。这也意味着返回值只对调用时刻有效；如果该值发生变化，调用方不会收到更新。

此 Scrollable 使用的启发式规则由 physics 决定，具体通过 ScrollPhysics.recommendDeferredLoading 实现。调用时会传入当前 ScrollPosition.activity 的 ScrollActivity.velocity。

可选的 Axis 可用于指定某个方向上的 Scrollable，在多个 Scrollable 嵌套时尤其有用。提供 axis 后，会对该 Axis 方向上最近的 Scrollable 调用 ScrollPosition.recommendDeferredLoading。

如果 context 上方的组件树中没有 Scrollable，此方法返回 false。

实现

static bool recommendDeferredLoadingForContext(BuildContext context, {Axis? axis}) {
  _ScrollableScope? widget = context.getInheritedWidgetOfExactType<_ScrollableScope>();
  while (widget != null) {
    if (axis == null || axisDirectionToAxis(widget.scrollable.axisDirection) == axis) {
      return widget.position.recommendDeferredLoading(context);
    }
    context = widget.scrollable.context;
    widget = context.getInheritedWidgetOfExactType<_ScrollableScope>();
  }
  return false;
}
