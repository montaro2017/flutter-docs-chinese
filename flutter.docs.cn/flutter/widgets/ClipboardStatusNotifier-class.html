ClipboardStatusNotifier
description

ClipboardStatusNotifier 类

一种 ValueNotifier，其 value 表示剪贴板当前内容是否可以粘贴。

只能通过异步调用 Clipboard.getData 读取剪贴板内容，因此此类会维护一个可同步读取的值。若需要更新该值，请调用 update 以异步获取最新状态。
