Expansible 类

可展开和折叠的 StatefulWidget。

Expansible 由一个始终显示的标题和一个主体组成；主体在折叠状态下隐藏，在展开状态下显示。

Expansible 通过 AnimationController 驱动的动画展开或折叠。widget 展开时，主体高度会从 0 动画变化到完全展开后的高度。

此 widget 通常与 ListView 配合使用，以创建可展开和折叠的列表项。在与 ListView 等滚动 widget 配合使用时，必须将唯一的 PageStorageKey 指定为 key，这样 Expansible 才能在滚出和滚回视野时保存并恢复展开状态。

提供 headerBuilder 和 bodyBuilder 回调来构建标题和主体 widget。还可以提供额外的 expansibleBuilder 回调，以进一步自定义 widget 布局。

Expansible 本身不会切换展开状态。要切换展开状态，请按需调用 ExpansibleController.expand 和 ExpansibleController.collapse，通常是在轻触由 headerBuilder 返回的标题时调用。

此示例演示如何使用 Expansible widget，以及如何通过 ExpansibleController 以编程方式展开或折叠它。
