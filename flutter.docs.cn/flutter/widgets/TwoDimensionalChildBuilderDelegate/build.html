返回给定 ChildVicinity 对应的子项；其位置由 x 和 y 索引描述。

子类必须实现此函数，并且通常会将子项包装在 RepaintBoundary widget 中。

此方法返回的值会被缓存。若要表明 widget 已更改，必须提供新的 delegate，并确保新 delegate 的 shouldRebuild 方法返回 true。也可以调用 notifyListeners，以便继续使用同一个 delegate。

实现

@override
Widget? build(BuildContext context, ChildVicinity vicinity) {
  // If we have exceeded explicit upper bounds, return null.
  if (vicinity.xIndex < 0 || (maxXIndex != null && vicinity.xIndex > maxXIndex!)) {
    return null;
  }
  if (vicinity.yIndex < 0 || (maxYIndex != null && vicinity.yIndex > maxYIndex!)) {
    return null;
  }

  Widget? child;
  try {
    child = builder(context, vicinity);
  } catch (exception, stackTrace) {
    child = _createErrorWidget(exception, stackTrace);
  }
  if (child == null) {
    return null;
  }
  if (addRepaintBoundaries) {
    child = RepaintBoundary(child: child);
  }
  if (addAutomaticKeepAlives) {
    child = AutomaticKeepAlive(child: _SelectionKeepAlive(child: child));
  }
  return child;
}
