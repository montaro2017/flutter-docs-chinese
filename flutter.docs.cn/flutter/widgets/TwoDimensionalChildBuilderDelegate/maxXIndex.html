maxXIndex 属性

int? get maxXIndex

子项在 x 轴上的最大 ChildVicinity.xIndex。

对于每个 ChildVicinity，子项的相对位置由 x 和 y 索引描述，从而让视口中的所有子项都遵循一致的遍历模式。

在表格实现中，这通常很直观：每一行的列数通常相同（反过来也一样），并且各列依次对齐。

以更抽象的方式在二维空间中布置子项时，不同行对应的 x 索引数量可能不同。例如，散点图顶部的子项可能比底部更多。

如果该值为 null，RenderTwoDimensionalViewport 的子类可以继续调用 builder，直到所有已知 x 和 y 索引都返回 null。有时 null 并不表示遍历结束，例如表格中的合并单元格可能跨越多个索引。请参阅相应的 TwoDimensionalViewport 子类，了解此值在具体场景中的用法。

如果此值不为 null，则必须大于或等于 -1；-1 表示不会向 TwoDimensionalViewport 提供任何子项。

此值发生变化时，delegate 会调用 notifyListeners，通知 RenderTwoDimensionalViewport delegate 中缓存的信息已失效。

此值表示二维滚动视图中所有 ChildVicinity 的最大 x 索引。

另请参阅：

  • RenderTwoDimensionalViewport.buildOrObtainChildFor, the method that leads to calling on the delegate to build a child of the given ChildVicinity.

实现

int? get maxXIndex => _maxXIndex;

实现

set maxXIndex(int? value) {
  if (value == maxXIndex) {
    return;
  }
  assert(value == null || value >= -1);
  _maxXIndex = value;
  notifyListeners();
}
