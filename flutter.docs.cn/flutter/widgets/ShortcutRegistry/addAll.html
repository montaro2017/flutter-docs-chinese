addAll 方法

ShortcutRegistryEntry addAll(
  1. Map<ShortcutActivator, Intent> value
)

将给定的所有快捷键绑定添加到此 ShortcutRegistry，并返回一个用于管理这些绑定的条目。

不再需要这些快捷键时，应对该条目调用 ShortcutRegistryEntry.dispose。这会从注册器中移除快捷键，并使条目失效。

如果另一个条目（即尚未处置的条目）已添加了给定快捷键，此方法会在调试模式下触发断言。

如果添加了两个等效但不同的 ShortcutActivator，触发时会执行它们全部。例如，同时添加 SingleActivator(LogicalKeyboardKey.keyA) 和 CharacterActivator('a') 后，按下 “a” 键时两者都会执行。

另请参阅：

  • ShortcutRegistryEntry.replaceAll, a function used to replace the set of shortcuts associated with a particular entry.
  • ShortcutRegistryEntry.dispose, a function used to remove the set of shortcuts associated with a particular entry.

实现

ShortcutRegistryEntry addAll(Map<ShortcutActivator, Intent> value) {
  assert(ChangeNotifier.debugAssertNotDisposed(this));
  assert(value.isNotEmpty, 'Cannot register an empty map of shortcuts');
  final entry = ShortcutRegistryEntry._(this);
  _registeredShortcuts[entry] = value;
  assert(_debugCheckForDuplicates());
  _notifyListenersNextFrame();
  return entry;
}
