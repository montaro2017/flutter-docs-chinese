applyBoundaryConditions 方法

double applyBoundaryConditions(
  1. ScrollMetrics position,
  2. double value
)

通过应用边界条件确定过度滚动量。

ScrollPosition.setPixels 会在更新 ScrollPosition.pixels 值之前调用 ScrollPosition.applyBoundaryConditions，后者再调用此方法，以确定需要截去多少偏移量并传给 ScrollPosition.didOverscrollBy。

调用此方法时，value 参数保证不等于 position 参数的 ScrollMetrics.pixels。

调用此方法时，position 可能已处于越界状态。此时，边界条件通常只应阻止越界程度进一步增大，同时允许其减小并成功应用，这样动画便能平滑地将越界位置弹回边界。参见 BallisticScrollActivity。

此方法不得截断给定 position 所描述边界范围内的偏移量部分。

给定的 position 仅在此方法调用期间有效。不要保留它以供之后使用，因为其值可能更新、保持不变，或变为与完全无关的另一个可滚动组件的值。

示例

BouncingScrollPhysics 返回零。也就是说，它允许滚动不受阻碍地越过边界。

ClampingScrollPhysics 返回该值超出当前位置或边界的距离，取离内容更远者。也就是说，它不允许滚动越过边界；但如果位置因某种原因已经过度滚动，则允许滚动回到边界范围内。

实现

double applyBoundaryConditions(ScrollMetrics position, double value) {
  return parent?.applyBoundaryConditions(position, value) ?? 0.0;
}
