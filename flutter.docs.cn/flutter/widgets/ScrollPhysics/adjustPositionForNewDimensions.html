说明视口尺寸发生变化后，滚动位置应如何调整。

此方法由 ScrollPosition.correctForNewDimensions 调用。

参数包括上一帧中的滚动度量值，以及最近一次布局后当前的滚动度量值，其中包含滚动位置、最小和最大滚动范围；还包括一个标志，用于指示当前 ScrollActivity 是否认为用户正在主动滚动（参阅 ScrollActivity.isScrolling）；以及滚动活动驱动滚动位置时的当前速度（用户手势期间该值为 0.0，参阅 ScrollActivity.velocity）。

除 ScrollMetrics.minScrollExtent 和 ScrollMetrics.maxScrollExtent 外，滚动度量值都相同。这两个参数分别称为 oldPosition 和 newPosition。虽然它们在技术上具有相同的“位置”（即 ScrollMetrics.pixels），但它们分别是在更新滚动范围前后，根据 ScrollPosition 生成的。

如果返回值与 newPosition 参数给出的滚动偏移量（参阅 ScrollMetrics.pixels）不完全相同，ScrollPosition 就会调用 ScrollPosition.correctPixels，将新的滚动位置更新为该返回值，并重新执行布局。这项操作开销较大。新值还会继续受到 applyBoundaryConditions 的处理。

如果返回值与 newPosition.pixels 滚动偏移量完全相同，接下来会调用 ScrollPosition.applyNewDimensions。在这种情况下，返回值不会再经过 applyBoundaryConditions 处理。

给定的 ScrollMetrics 仅在此方法调用期间有效。不要保留这些对象的引用供之后使用，因为其中的值可能会更新、保持不变，或更新为完全无关的另一个可滚动组件的数据。

默认实现会返回 newPosition 的 ScrollMetrics.pixels，表示当前滚动偏移量可以接受。

另请参阅：

  • RangeMaintainingScrollPhysics 默认启用，可防止内容尺寸意外变化导致滚动位置进一步超出边界。

实现

double adjustPositionForNewDimensions({
  required ScrollMetrics oldPosition,
  required ScrollMetrics newPosition,
  required bool isScrolling,
  required double velocity,
}) {
  if (parent == null) {
    return newPosition.pixels;
  }
  return parent!.adjustPositionForNewDimensions(
    oldPosition: oldPosition,
    newPosition: newPosition,
    isScrolling: isScrolling,
    velocity: velocity,
  );
}
