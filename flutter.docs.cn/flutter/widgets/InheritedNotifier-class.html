description

InheritedNotifier<T extends Listenable> 类 抽象

供 Listenable notifier 使用的继承组件；当 notifier 触发时，会更新依赖于它的组件。

这是 InheritedWidget 的一个变体，专为 Listenable 的子类设计，例如 ChangeNotifier 或 ValueNotifier。

每当 notifier 发出通知，或 notifier 对象身份发生变化时，都会通知依赖组件。

多个通知会合并处理，因此即使 notifier 在两帧之间多次触发，依赖组件也只会重建一次。

此类通常会被子类化；子类提供一个名为 of 的静态方法，并通过该类调用 BuildContext.dependOnInheritedWidgetOfExactType。

也可以重写 updateShouldNotify，以改变 notifier 本身发生变化时的处理逻辑。当 notifier 发生变化时，该 updateShouldNotify 方法接收旧的 notifier。如果返回 true，依赖组件会被标记为需要在当前帧重建。

此示例展示三个旋转方块如何使用祖先 InheritedNotifier（SpinModel）中 notifier 的值来确定旋转角度。InheritedNotifier 无需了解其子组件；notifier 参数也不必是动画控制器，任何实现了 Listenable 的对象（例如 ChangeNotifier）都可以。

The SpinModel class could just as easily listen to another object (say, a separate object that keeps the value of an input or data model value) that is a Listenable, and get the value from that. The descendants also don't need to have an instance of the InheritedNotifier in order to use it, they just need to know that there is one in their ancestry. This can help with decoupling widgets from their models.
