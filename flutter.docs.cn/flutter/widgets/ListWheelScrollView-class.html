ListWheelScrollView
description

ListWheelScrollView 类

一种可在滚轮上滚动子项的盒子。

此 widget 类似于 ListView，但有一个限制：所有子项沿滚动轴的尺寸必须相同。

列表滚动偏移为零时，第一个子项会与视口中心对齐；滚动到最终偏移时，最后一个子项会与视口中心对齐。

子项看起来像是在滚轮上旋转，而不是在平面上滚动。
