Builder 类

一种无状态工具 Widget，其 build 方法会使用 builder 回调创建子项。

此 Widget 是定义 StatelessWidget 子类的一种内联替代方式。例如，可以按以下方式定义 Widget：

class Foo extends StatelessWidget {
  const Foo({super.key});
  @override
  Widget build(BuildContext context) => const Text('foo');
}

并像平常一样使用它：

// continuing from previous example...
const Center(child: Foo())

也可以不定义新的 Widget 类，而是在一个步骤中完成定义和使用：

Center(
  child: Builder(
    builder: (BuildContext context) => const Text('foo'),
  ),
)

与前两个示例相比，直接创建子项而不插入中间 Widget 的区别在于：额外的 Widget 会添加一个 BuildContext Element。当树中包含通过 Scaffold.of 等方法引用的继承 Widget 时，这一点尤其明显，因为该方法会遍历子 Widget 的 BuildContext 祖先。

在下面的示例中，按钮的 onPressed 回调无法通过 Scaffold.of 找到外围的 ScaffoldState：

Widget build(BuildContext context) {
  return Scaffold(
    body: Center(
      child: TextButton(
        onPressed: () {
          // Fails because Scaffold.of() doesn't find anything
          // above this widget's context.
          print(Scaffold.of(context).hasAppBar);
        },
        child: const Text('hasAppBar'),
      )
    ),
  );
}

Builder Widget 会引入额外的 BuildContext Element，因此 Scaffold.of 方法可以成功找到 Scaffold。

Widget build(BuildContext context) {
  return Scaffold(
    body: Builder(
      builder: (BuildContext context) {
        return Center(
          child: TextButton(
            onPressed: () {
              print(Scaffold.of(context).hasAppBar);
            },
            child: const Text('hasAppBar'),
          ),
        );
      },
    ),
  );
}
