从包围 context 的 TickerMode 获取 ValueListenable，用于指示给定子树中的 ticker 是否已启用。

该 TickerMode 启用或禁用 ticker 时，此 listenable 会通知其监听器。

只要包围它的 TickerMode 生命周期内保持稳定，ValueListenable 就不会改变。但调用此方法不会在 context 与 TickerMode 之间建立依赖，因此拥有该 context 的 widget 不会在 ticker 模式从 true 变为 false（或反向变化）时重建。当 ticker 模式不会影响当前屏幕上的渲染内容时，这种方式更合适，例如只用于静音或取消静音 Ticker 时。由于没有建立依赖，当拥有该 context 的 widget 被移动到树中的新位置、并遇到不同的 TickerMode 祖先时，它也不会收到通知。此时 widget 必须手动取消订阅旧 listenable，从新的祖先 TickerMode 再次调用此方法获取新的 listenable，并重新订阅。例如，StatefulWidget 可以在 widget 移动到新位置后调用的 State.activate 中完成这些操作。

也可以使用 of 代替此方法，从而在给定的 context 与祖先 TickerMode 之间建立依赖。这样，当 ticker 模式改变或 widget 移动到新的 TickerMode 祖先下时，widget 会自动重建，简化了 widget 内的管理，但可能导致一些不必要的重建。

如果不存在 TickerMode widget，此函数会返回一个 ValueListenable，其 ValueListenable.value 始终为 true。

实现

@Deprecated(
  'Use TickerMode.getValuesNotifier to get both enabled and forceFrames. '
  'This feature was deprecated after v3.35.0-0.0.pre.',
)
static ValueListenable<bool> getNotifier(BuildContext context) {
  final _EffectiveTickerMode? widget = context
      .getInheritedWidgetOfExactType<_EffectiveTickerMode>();
  return widget?.notifier ?? const _ConstantValueListenable<bool>(true);
}
