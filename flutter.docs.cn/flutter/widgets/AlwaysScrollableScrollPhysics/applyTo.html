applyTo 方法

  1. @重写
AlwaysScrollableScrollPhysics applyTo(
  1. ScrollPhysics? ancestor
)
重写

将此 ScrollPhysics 实例与给定的物理效果组合。

当此实例能够决定物理效果时，返回的对象会使用此实例；否则会采用给定 ancestor 对象的物理效果。

如果 parent 为 null，此方法会返回一个 ScrollPhysics，其 runtimeType 与当前实例相同，但 parent 已替换为 ancestor。

如果此滚动物理对象已有父级，此方法会递归应用，并将 ancestor 放在现有父级链的末尾。

使用 null 参数调用此方法会复制当前对象。这种做法效率较低。

在下面的示例中，使用 applyTo 方法组合两个 ScrollPhysics 对象的滚动物理效果。生成的 ScrollPhysics x 与 y 的行为相同。
link 
final FooScrollPhysics x = const FooScrollPhysics().applyTo(const BarScrollPhysics());
const FooScrollPhysics y = FooScrollPhysics(parent: BarScrollPhysics());

实现 applyTo

创建自定义 ScrollPhysics 子类时，必须实现此方法。如果物理效果类没有构造函数参数，只需调用构造函数，并使用 buildParent 构建 parent，如下所示：

class MyScrollPhysics extends ScrollPhysics {
  const MyScrollPhysics({ super.parent });

  @override
  MyScrollPhysics applyTo(ScrollPhysics? ancestor) {
    return MyScrollPhysics(parent: buildParent(ancestor));
  }

  // ...
}

如果物理效果类有构造函数参数，也必须在此处将这些参数传递给构造函数，以便创建副本。

另请参阅：

  • buildParent, a utility method that's often used to define applyTo methods for ScrollPhysics 的子类配合使用。
