MultiSelectableSelectionContainerDelegate
description

MultiSelectableSelectionContainerDelegate 类 抽象

用于处理多个 Selectable 子元素的事件和更新的委托。

通过跟踪位于选区边缘的 Selectable 来优化更新。子类应实现 ensureChildUpdated，以说明将 Selectable 添加到选区时应如何处理。
