getInheritedWidgetOfExactType<T extends InheritedWidget> 方法

  1. @重写
T? getInheritedWidgetOfExactType<T extends InheritedWidget>()
继承

返回给定 InheritedWidget 子类 T 的最近祖先 widget；如果找不到合适的祖先，则返回 null。

与更常用的 dependOnInheritedWidgetOfExactType 不同，此方法不会建立依赖，因此 InheritedWidget 发生变化时，此 context 不会重建。此方法适用于不希望建立依赖的少数情况。

当时元素树已不再稳定，因此不能在 State.dispose 中调用此方法。若要在该方法中引用祖先，应在 State.didChangeDependencies 中保存对祖先的引用。可以在 State.deactivate 中安全地调用此方法；每当组件从树中移除时都会调用该方法。

也可以在交互事件处理器（例如手势回调）或定时器中调用此方法来获取一次性值，前提是之后不缓存或重复使用该值。

调用此方法的时间复杂度为 O(1)，常数开销较小。

实现

@override
T? getInheritedWidgetOfExactType<T extends InheritedWidget>() {
  return getElementForInheritedWidgetOfExactType<T>()?.widget as T?;
}
