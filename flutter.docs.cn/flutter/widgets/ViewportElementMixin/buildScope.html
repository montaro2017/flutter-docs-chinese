buildScope 属性

BuildScope get buildScope
继承

一个 BuildScope，其中标记为 dirty 的 Element 只能通过 BuildOwner.buildScope 调用重建，且该调用的 context 参数必须是此 BuildScope 中的 Element。

通常只有当此 Element 已 mounted 时，访问此 getter 才是安全的。

默认实现会返回父级 Element 的 buildScope。大多数情况下，当祖先不再是 dirty 时，Element 就可以重建。一个显著例外是 LayoutBuilder 的后代：在收到布局约束之前，它们不能重建。LayoutBuilder 的 Element 会重写 buildScope，确保在收到约束前其后代均不能重建。

若重写此 getter 以建立自己的 BuildScope，则需在适当时机手动调用 BuildOwner.buildScope，并传入 Element（即该 BuildScope 的根），以刷新 BuildScope 中状态已变脏的 Element。Flutter 框架不会尝试注册或管理自定义 BuildScope。

如果重写此 getter，始终返回同一个 BuildScope 实例。运行时更改此 getter 返回的值不受支持。

updateChild 方法不会考虑 buildScope：如果父级 Element 对拥有不同 BuildScope 的子级调用 updateChild，该子级仍可能重建。

另请参阅：

  • LayoutBuilder, a widget that establishes a custom BuildScope.

实现

BuildScope get buildScope => _parentBuildScope!;
