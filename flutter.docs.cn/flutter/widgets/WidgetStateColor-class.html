WidgetStateColor 类 抽象

定义一个同时也是 WidgetStateProperty 的 Color。

此类使具有 Color 类型属性的组件也能接受 WidgetStateProperty<Color> 值。状态颜色属性表示一种取决于组件“交互状态”的颜色。该状态由一组 Set 的 WidgetState 组成，例如 WidgetState.pressed、WidgetState.focused 和 WidgetState.hovered。

WidgetStateColor 仅应与文档明确说明支持它的组件搭配使用，例如 TimePickerThemeData.dayPeriodColor。

可以通过以下方式之一创建 WidgetStateColor：

  1. Create a subclass of WidgetStateColor and implement the abstract resolve method.
  2. Use WidgetStateColor.resolveWith and pass in a callback that will be used to resolve the color in the given states.
  3. Use WidgetStateColor.fromMap to assign a value using a WidgetStateMap.

此示例使用 const 构造函数定义一个 WidgetStateColor。
link 
class MyColor extends WidgetStateColor {
  const MyColor() : super(_defaultColor);

  static const int _defaultColor = 0xcafefeed;
  static const int _pressedColor = 0xdeadbeef;

  @override
  Color resolve(Set<WidgetState> states) {
    if (states.contains(WidgetState.pressed)) {
      return const Color(_pressedColor);
    }
    return const Color(_defaultColor);
  }
}
