confirmDismiss 属性

ConfirmDismissCallback? confirmDismiss
final

为应用提供确认或否决待处理关闭操作的机会。

返回的 future 完成之前，不能再次拖动此 widget。

如果返回的 Future<bool> 以 true 完成，此 widget 将被关闭；否则会移回原来的位置。

如果返回的 Future<bool?> 以 false 或 null 完成，则不会调用 onResize 和 onDismissed 回调。
