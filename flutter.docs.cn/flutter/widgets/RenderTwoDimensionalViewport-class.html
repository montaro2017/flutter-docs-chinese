RenderTwoDimensionalViewport
description

RenderTwoDimensionalViewport 类 抽象

用于呈现二维滚动渲染对象的基类。

视口会监听两个 ViewportOffset，由此确定可见内容。

子类必须实现 layoutChildSequence，并在其中调用 buildOrObtainChildFor 来管理视口的子项。

子类不应重写 performLayout，因为它会在调用 layoutChildSequence 前后执行必要的清理工作。
