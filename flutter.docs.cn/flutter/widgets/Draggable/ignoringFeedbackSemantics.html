ignoringFeedbackSemantics 属性

bool ignoringFeedbackSemantics
final

构建语义树时是否忽略 feedback widget 的语义信息。

如果 feedback widget 与 child 表示同一个对象，应将此值设为 false。在此 widget 上设置 GlobalKey，可确保元素移入和移出 feedback 位置时保留语义焦点。

默认为 true。
