AnimatedDefaultTextStyle 类

DefaultTextStyle 的动画版本。每当给定样式发生变化时，它都会在指定时长内自动过渡到新的默认文本样式（应用于未显式指定样式的后代 Text widget 的文本样式）。

textAlign、softWrap、overflow、maxLines、textWidthBasis 和 textHeightBehavior 属性不会添加动画，变化后会立即生效。

下面展示此组件使用 Curves.elasticInOut 作为 curve 时的效果。

可以为动画选择 curve 和 duration，此 widget 会自动过渡到新的默认文本样式。如果需要更精细地控制动画（例如在动画进行到一半时停止），可以改用 DefaultTextStyleTransition，并向其传入 Animation。这样虽然可以精细调整动画，但需要手动管理底层 AnimationController 的生命周期，开发工作也更多。
