TextSelectionControls 类 抽象

用于构建选区 UI 的接口，由工具栏 widget 的实现者提供。

此类的部分功能（包括 buildToolbar）已弃用，建议改用 EditableText.contextMenuBuilder 来自定义上下文菜单。

与 EditableText.contextMenuBuilder 配合使用

在弃用期间，为保持向后兼容，如果将 EditableText.selectionControls 设为未混入 TextSelectionHandleControls 的对象，则会忽略 EditableText.contextMenuBuilder，转而使用已弃用的 buildToolbar。

若要将代码从 buildToolbar 迁移到推荐的 EditableText.contextMenuBuilder，同时继续使用 buildHandle，请在 TextSelectionControls 子类中混入 TextSelectionHandleControls，并将工具栏代码迁移到传给 EditableText.contextMenuBuilder 的回调中。

之后会移除 buildToolbar，此时该 mixin 也不再需要用于告知框架代码已完成迁移、不期望调用 buildToolbar。

更多信息请参阅 docs.flutter.dev/release/breaking-changes/context-menus。

另请参阅：

  • SelectionArea, which selects appropriate text selection controls based on the current platform.
