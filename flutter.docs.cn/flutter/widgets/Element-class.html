Element 类 抽象

树中某个特定位置上的 Widget 实例。

Widget 描述如何配置子树，但由于 widget 是不可变的，同一个 widget 可以同时用于配置多个子树。Element 表示在树中的特定位置使用一个 widget 进行配置。随着时间推移，与某个 element 关联的 widget 可能会改变，例如父 widget 重新构建并为该位置创建了新的 widget。

Element 构成一棵树。大多数 element 只有一个子项，但某些 widget（例如 RenderObjectElement 的子类）可以有多个子项。

Element 的生命周期如下：

  • 框架会对用作 element 初始配置的 widget 调用 Widget.createElement，以创建 element。
  • 框架会调用 mount，在指定父级的指定插槽中将新创建的 element 添加到树中。mount 方法负责扩充所有子 widget，并在必要时调用 attachRenderObject，将相关渲染对象附加到渲染树。
  • 此时，该 element 被视为“活动”状态，并可能显示在屏幕上。
  • 之后，父级可能决定更改用于配置此 element 的 widget，例如父级以新状态重新构建时。此时，框架会使用新的 widget 调用 update。新旧 widget 的 runtimeType 和 key 始终相同。如果父级希望更改树中此位置上 widget 的 runtimeType 或 key，可以先卸载此 element，再在此位置扩充新的 widget。
  • 之后，某个祖先可能决定从树中移除此 element（或其中间祖先），祖先会通过对自身调用 deactivateChild 来完成此操作。停用中间祖先会从渲染树中移除该 element 的渲染对象，并将此 element 添加到 owner 的非活动 element 列表中，从而使框架对该 element 调用 deactivate。
  • 此时，该 element 被视为“非活动”状态，不会显示在屏幕上。element 只能保持非活动状态直到当前动画帧结束。动画帧结束时，所有仍处于非活动状态的 element 都会被卸载。
  • 如果该 element 重新并入树中（例如它本身或某个祖先拥有被重新使用的全局 key），框架会将该 element 从 owner 的非活动 element 列表中移除，对其调用 activate，并将它的渲染对象重新附加到渲染树。（此时，该 element 会再次被视为“活动”状态，并可能显示在屏幕上。）
  • 如果该 element 在当前动画帧结束前没有重新并入树中，框架就会对其调用 unmount。
  • 此时，该 element 被视为“失效”状态，今后不会再并入树中。
