SliverOverlapAbsorberHandle 类

提供给 SliverOverlapAbsorber、SliverOverlapInjector 和 NestedScrollViewViewport 的句柄，用于在 NestedScrollView 中调整重叠部分。

同一时间，一个 SliverOverlapAbsorberHandle 只能分配给一个 SliverOverlapAbsorber。它也可以（通常确实如此）分配给一个或多个 SliverOverlapInjector；这些 injector 必须是同一个 NestedScrollViewViewport 中、位于 SliverOverlapAbsorber 之后的后代。SliverOverlapAbsorber 必须是 NestedScrollViewViewport 的直接后代，并参与同一 sliver 布局。（SliverOverlapInjector 可以是参与嵌套滚动视图 sliver 布局的后代。）

每当 NestedScrollViewViewport 因布局而标记为脏时，它都会通知已分配的 SliverOverlapAbsorberHandle。如果布局过程中几何信息随后发生变化，SliverOverlapInjector（及其他客户端）有责任在收到通知时将自身标记为脏。

另请参阅：

  • NestedScrollView, which uses a NestedScrollViewViewport and a SliverOverlapAbsorber to align its children, and which shows sample usage for this class.
