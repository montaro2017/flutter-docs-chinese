void performResize()
重写

仅根据约束更新 render object 的尺寸。

不要直接调用此函数，请改为调用 layout。当布局过程中此 render object 确实需要执行工作时，layout 会调用此函数。可通过 constraints getter 获取父级提供的布局约束。

仅当 sizedByParent 为 true 时才会调用此函数。

默认情况下，此方法会将 size 设为使用当前 constraints 调用 computeDryLayout 所得到的结果。建议考虑重写 computeDryLayout，而不是重写此方法。

实现

@override
void performResize() {
  final Size? oldSize = hasSize ? size : null;
  super.performResize();
  // Ignoring return value since we are doing a layout either way
  // (performLayout will be invoked next).
  horizontalOffset.applyViewportDimension(size.width);
  verticalOffset.applyViewportDimension(size.height);
  if (oldSize != size) {
    // Specs can depend on viewport size.
    _didResize = true;
  }
}
