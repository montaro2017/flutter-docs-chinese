ChildVicinity 类

子项在 TwoDimensionalViewport 中相对于其他子项的位置。

子项可以在二维空间中任意排列；ChildVicinity 用于区分它们的位置，并确定空间中子项的遍历顺序。

结合 RenderTwoDimensionalViewport.mainAxis 后，每个子项的位置会决定其在所有子项中的绘制顺序。
