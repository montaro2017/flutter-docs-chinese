currentConfiguration 属性

T? get currentConfiguration
继承

Router 检测到重建可能导致路由信息发生变化时，会调用此 getter。

如果此 getter 返回非 null，Router 就会开始向引擎报告新的路由信息。在 Web 应用中，新路由信息会用于填充浏览器历史记录，以支持前进和后退按钮。

重写此方法时，此 getter 返回的配置必须能够构建当前应用状态；如果将相同配置传回 setNewRoutePath，也必须能通过 build 方法构建相同的组件树。否则，浏览器的前进和后退按钮将无法正常工作。

默认情况下，此 getter 返回 null，阻止 Router 报告路由信息。子类可以重写此 getter 并返回当前配置，以启用此功能。

最多只能有一个 Router 启用路由信息报告。通常，只有由 WidgetsApp.router 创建的最顶层 Router 才应启用此功能。

状态恢复

Router 也会使用此 getter 实现状态恢复。序列化状态时，Router 会保存当前配置；恢复状态时，则通过调用 setRestoredRoutePath 将其传回委托。
