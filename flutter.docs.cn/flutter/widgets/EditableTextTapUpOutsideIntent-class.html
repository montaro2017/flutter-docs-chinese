EditableTextTapUpOutsideIntent 类

表示“在字段外部轻触”的 Intent。

当 EditableText.onTapUpOutside 为 null 时，如果用户在当前获得焦点的 EditableText 外部抬起手指，就会触发此操作。

重写此 Intent 可修改默认行为：在 Web 上，触摸事件会取消焦点；在其他平台上则不执行任何操作。

一种常见需求是：用户轻触文本字段外部时取消文本字段焦点。出于用户体验考虑，通常只希望在用户轻触字段外部时取消焦点，而在滚动时不取消。

为此，可以重写 EditableTextTapOutsideIntent 和 EditableTextTapUpOutsideIntent 的默认行为，在决定是否取消焦点前，检查指针按下与抬起事件之间的距离差。
