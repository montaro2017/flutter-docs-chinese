callingAction 属性

  1. @protected
Action<T>? get callingAction

被此 Action 覆盖的 Action。

Action.overridable 构造函数会创建一个可覆盖的 Action：它允许最近的祖先 Action 覆盖自身；如果没有找到覆盖项，则回退到自身的 defaultAction。存在覆盖项时，可覆盖的 Action 会将所有传入的方法调用转发给该覆盖项，并允许覆盖项通过 callingAction 属性访问 defaultAction。

在将调用转发给覆盖项之前，可覆盖的 Action 负责将 callingAction 设为自身的 defaultAction。通过 Action.overridable 创建的可覆盖 Action 已自动处理此事。

仅当此 Action 覆盖了 callingAction，且当前正由 callingAction 调用时，此属性才非 null。

可以调用 callingAction 的方法或访问其属性，不会造成无限循环或无限递归。

一个处理 PasteTextIntent、但大体行为与可覆盖操作相同的示例 Action。在此 Action 的实现中调用 callingAction?.isActionEnabled 是允许的。
link 
class MyPasteAction extends Action<PasteTextIntent> {
  @override
  Object? invoke(PasteTextIntent intent) {
    print(intent);
    return callingAction?.invoke(intent);
  }

  @override
  bool get isActionEnabled => callingAction?.isActionEnabled ?? false;

  @override
  bool consumesKey(PasteTextIntent intent) => callingAction?.consumesKey(intent) ?? false;
}
