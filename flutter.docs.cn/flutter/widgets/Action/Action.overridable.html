Action<T extends Intent>.overridable 构造函数

Action<T extends Intent>.overridable({
  1. required Action<T> defaultAction,
  2. required BuildContext context,
})

创建一个 Action，使其能够被给定 context 中最近的、处理相同 Intent 的祖先 Action 覆盖（如果存在）。

调用时，生成的 Action 会在给定 context 中查找最近的、处理与 defaultAction 相同类型 Intent 的 Action，然后调用其 Action.invoke 方法。如果找不到可覆盖它的 Action，则调用 defaultAction。

如果存在可覆盖它的 Action，可覆盖操作会将所有行为委托给该操作；否则，其行为与 defaultAction 相同。因此，覆盖操作可以完全决定如何处理 Intent，以及是否消耗按键事件。覆盖 Action 的 callingAction 属性会设为它当前覆盖的 Action，从而可以访问默认行为。示例请参阅 callingAction 属性。

context 参数是用于查找覆盖操作的 BuildContext。它通常位于 BuildContext 之上，包含此可覆盖 Action 的 Actions widget 之上。

defaultAction 参数是在 context 中找不到处理相同类型 Intent 的祖先 Action 时要调用的 Action。

这适用于在叶子 widget 中提供一组默认 Action，以便后续覆盖；也可以让 Intent 继续传递给同样支持该 Intent 的父级 widget。

此示例展示如何实现一个简易的 CopyableText widget：按下 Ctrl-C 时，它会将自身内容复制到剪贴板。

如果要在 package 中提供 CopyableText，使用该 widget 的开发者可能希望更改复制内容的处理方式。作为 package 作者，可以将相应的 Action 设为可覆盖，从而支持这种定制。在代码示例的第二部分，三个 CopyableText widget 被组合成一个验证码 widget，它会覆盖“复制”操作，将三个 CopyableText widget 的数字合并后复制。

实现

factory Action.overridable({required Action<T> defaultAction, required BuildContext context}) {
  return defaultAction._makeOverridableAction(context);
}
