为 child 覆盖继承得到的 Locale 或 LocalizationsDelegate。

此工厂构造函数用于一种通常较少见的情况：应用的某个部分需要使用不同于设备默认值的区域设置，或者需要使用不同于 WidgetsApp.localizationsDelegates 所定义列表的 LocalizationsDelegate 列表来提供本地化资源。

例如，可以指定仅对美式英语区域设置进行本地化的 myWidget：

Widget build(BuildContext context) {
  return Localizations.override(
    context: context,
    locale: const Locale('en', 'US'),
    child: myWidget,
  );
}

locale 和 delegates 参数默认采用最近的 Localizations 祖先中的 Localizations.locale 和 Localizations.delegates 值。

要为整个应用覆盖 Localizations.locale 或 Localizations.delegates，请指定 WidgetsApp.locale 或 WidgetsApp.localizationsDelegates（也可以为 MaterialApp 指定相同参数）。

实现

factory Localizations.override({
  Key? key,
  required BuildContext context,
  Locale? locale,
  List<LocalizationsDelegate<dynamic>>? delegates,
  Widget? child,
}) {
  final List<LocalizationsDelegate<dynamic>> mergedDelegates = Localizations._delegatesOf(
    context,
  );
  if (delegates != null) {
    mergedDelegates.insertAll(0, delegates);
  }
  return Localizations(
    key: key,
    locale: locale ?? Localizations.localeOf(context),
    delegates: mergedDelegates,
    child: child,
  );
}
