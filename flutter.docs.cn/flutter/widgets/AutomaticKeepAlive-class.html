AutomaticKeepAlive 类

允许延迟列表中的子树请求保持存活。

此 widget 类似于 KeepAlive，但无需显式配置；它会监听来自 child 及其他后代的 KeepAliveNotification 消息。

只要有一个或多个后代发送了 KeepAliveNotification 且尚未调用其 KeepAliveNotification.handle，该子树就会保持存活。

可考虑使用 AutomaticKeepAliveClientMixin 发送这些通知。

与 SliverList 和 SliverGrid 搭配使用的 SliverChildBuilderDelegate 与 SliverChildListDelegate，以及对应的滚动视图 ListView 和 GridView，都提供默认启用的 addAutomaticKeepAlives 功能。此功能会在每个子项周围插入 AutomaticKeepAlive widget，并由它们响应 KeepAliveNotification 配置 KeepAlive widget。

TwoDimensionalChildBuilderDelegate 和 TwoDimensionalChildListDelegate 也支持相同的 addAutomaticKeepAlives 功能。

此示例演示了如何使用 AutomaticKeepAlive widget，并将其与 AutomaticKeepAliveClientMixin 配合使用，从而选择性地保留可滚动列表中各个项目的状态。

通常，像 ListView.builder 这样延迟构建列表中的 widget 离开可见区域后会被释放，以维持性能。因此，StatefulWidget 中的状态会丢失，除非显式保留。

此示例中的每个列表项都是一个包含计数器和递增按钮的 StatefulWidget。为了根据索引保留选定项目的状态，示例使用 AutomaticKeepAlive widget 和 AutomaticKeepAliveClientMixin：

  • The wantKeepAlive getter in the item’s state class returns true for even-indexed items, indicating that their state should be preserved.
  • For odd-indexed items, wantKeepAlive returns false, so their state is not preserved when scrolled out of view.

  • AutomaticKeepAliveClientMixin, which is a mixin with convenience methods for clients of AutomaticKeepAlive. Used with State 的子类配合使用。
  • KeepAlive，将子项标记为需要保持存活，即使它处于惰性列表中且列表本会将其移除。
