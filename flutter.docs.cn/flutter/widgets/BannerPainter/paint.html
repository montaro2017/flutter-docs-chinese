重写

每当对象需要绘制时调用。给定的 Canvas 已配置坐标空间，使原点位于矩形左上角。矩形区域的大小由 size 参数决定。

绘制操作应限制在给定区域内。边界之外的图形操作可能会被静默忽略、裁剪，也可能不被裁剪。有时很难保证某个操作位于边界内（例如，绘制矩形的大小由用户输入决定）。这种情况下，可以考虑在 paint 开始时调用 Canvas.clipRect，以确保后续所有绘制都限制在裁剪区域内。

实现时应确保正确配对对 Canvas.save/Canvas.saveLayer 和 Canvas.restore 的调用；否则可能影响此画布上的后续绘制，导致看似滑稽却令人困惑的结果。

要在 Canvas 上绘制文本，请使用 TextPainter。

要在 Canvas 上绘制图像：

  1. 获取一个 ImageStream，例如在 AssetImage 或 NetworkImage 对象上调用 ImageProvider.resolve。

  2. 每当 ImageStream 底层的 ImageInfo 对象发生变化时（参阅 ImageStream.addListener），都应创建一个新的自定义绘制委托实例，并将新的 ImageInfo 对象传给它。

  3. 在委托的 paint 方法中，调用 Canvas.drawImage、Canvas.drawImageRect 或 Canvas.drawImageNine 方法来绘制 ImageInfo.image 对象，并应用 ImageInfo.scale 值以获得正确的渲染尺寸。

实现

@override
void paint(Canvas canvas, Size size) {
  if (!_prepared) {
    _prepare();
  }
  canvas
    ..translate(_translationX(size.width), _translationY(size.height))
    ..rotate(_rotation)
    ..drawRect(_kRect, _paintShadow)
    ..drawRect(_kRect, _paintBanner);
  const double width = _kOffset * 2.0;
  _textPainter!.layout(minWidth: width, maxWidth: width);
  _textPainter!.paint(
    canvas,
    _kRect.topLeft + Offset(0.0, (_kRect.height - _textPainter!.height) / 2.0),
  );
}
