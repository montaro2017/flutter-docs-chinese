ScrollableState 类

Scrollable widget 的 State 对象。

若要操作 Scrollable widget 的滚动位置，请使用从 position 属性获取的对象。

若要获知 Scrollable widget 何时正在滚动，请使用 NotificationListener 监听 ScrollNotification 通知。

此类不适合被继承。若要自定义 Scrollable 的行为，请为其提供 ScrollPhysics。
