description

ReorderableList 类

允许用户通过交互重新排列列表项的滚动容器。

此组件类似于通过 ListView.builder 创建的组件，并使用 IndexedWidgetBuilder 创建每个列表项。

应用需要为每个子项（或子项中的某个部分，例如拖动手柄）包装一个拖动监听器。该监听器负责识别列表项拖动的开始，并调用 ReorderableListState.startItemDragReorder 开始重新排序。最简单的做法是用 ReorderableDragStartListener 或 ReorderableDelayedDragStartListener 包装每个子项。它们会识别拖动手势的开始，并调用列表状态对象的 ReorderableListState.startItemDragReorder 方法。

此组件的 ReorderableListState 可用于手动开始重新排列列表项，或取消当前拖动。可以为 ReorderableListState 提供 GlobalKey 来引用它，也可以在列表项的 build 方法中使用静态方法 ReorderableList.of。

另请参阅：

  • SliverReorderableList, a sliver list that allows the user to reorder its items.
  • ReorderableListView，一种允许用户重新排列项目的 Material Design 列表。
