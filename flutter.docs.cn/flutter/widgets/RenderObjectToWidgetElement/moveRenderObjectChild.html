将指定子节点从旧 slot 移动到新 slot。

保证指定子节点的父节点为 renderObject。

slot 的语义由此元素决定。例如，如果此元素只有一个子节点，slot 应始终为 null；如果此元素有多个子节点，将前一个兄弟元素包装在 IndexedSlot 中，便可作为 slot 的合适值。

只有当 updateChild 可能使用现有的子 Element 调用，并且传入的 slot 与此前分配给该元素的 slot 不同时，才会调用此方法。例如，MultiChildRenderObjectElement 会这样做，而 SingleChildRenderObjectElement 不会（因为 slot 始终为 null）。如果某个 Element 的子项具有固定的一组 slot，每个子项的 slot 始终不变，且更新一个 slot 时不会与其他 slot 中的子项相互比较，那么就永远不会调用此方法。
