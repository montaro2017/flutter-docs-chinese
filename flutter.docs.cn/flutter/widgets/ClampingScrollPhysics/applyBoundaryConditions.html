通过应用边界条件确定过度滚动量。

ScrollPosition.applyBoundaryConditions 会在更新 ScrollPosition.pixels 值之前调用此方法；而它由 ScrollPosition.setPixels 调用，用于确定偏移量中有多少需要被限制，并传递给 ScrollPosition.didOverscrollBy。

调用此方法时，value 参数保证不等于 position 参数的 ScrollMetrics.pixels。

此方法可能会在 position 描述的位置已经超出边界时调用。此时，边界条件通常只应阻止越界程度进一步增加，同时允许越界程度减小，以便动画可以平滑地将越界位置吸附回边界。参阅 BallisticScrollActivity。

此方法不得限制给定 position 所描述边界范围内的偏移量部分。

给定的 position 仅在此方法调用期间有效。不要保留其引用供之后使用，因为相关值可能会更新、保持不变，或变为完全无关的另一个可滚动对象的值。

示例

BouncingScrollPhysics 返回零。也就是说，它允许滚动不受阻碍地越过边界。

ClampingScrollPhysics 返回当前位置超出边界的距离，具体取位置或边界中距离内容更远的一方。也就是说，它不允许滚动越过边界；但如果位置因某种原因已经发生过度滚动，则允许滚动回到边界内。

实现

@override
double applyBoundaryConditions(ScrollMetrics position, double value) {
  assert(() {
    if (value == position.pixels) {
      throw FlutterError.fromParts(<DiagnosticsNode>[
        ErrorSummary('$runtimeType.applyBoundaryConditions() was called redundantly.'),
        ErrorDescription(
          'The proposed new position, $value, is exactly equal to the current position of the '
          'given ${position.runtimeType}, ${position.pixels}.\n'
          'The applyBoundaryConditions method should only be called when the value is '
          'going to actually change the pixels, otherwise it is redundant.',
        ),
        DiagnosticsProperty<ScrollPhysics>(
          'The physics object in question was',
          this,
          style: DiagnosticsTreeStyle.errorProperty,
        ),
        DiagnosticsProperty<ScrollMetrics>(
          'The position object in question was',
          position,
          style: DiagnosticsTreeStyle.errorProperty,
        ),
      ]);
    }
    return true;
  }());
  if (value < position.pixels && position.pixels <= position.minScrollExtent) {
    // Underscroll.
    return value - position.pixels;
  }
  if (position.maxScrollExtent <= position.pixels && position.pixels < value) {
    // Overscroll.
    return value - position.pixels;
  }
  if (value < position.minScrollExtent && position.minScrollExtent < position.pixels) {
    // Hit top edge.
    return value - position.minScrollExtent;
  }
  if (position.pixels < position.maxScrollExtent && position.maxScrollExtent < value) {
    // Hit bottom edge.
    return value - position.maxScrollExtent;
  }
  return 0.0;
}
