重写

返回一个模拟，使滚动从给定位置以给定速度开始进行弹道滚动。

ScrollPositionWithSingleContext 会在 ScrollPositionWithSingleContext.goBallistic 方法中使用此方法。如果返回值非 null，ScrollPositionWithSingleContext 将使用该值启动 BallisticScrollActivity；否则会启动空闲活动。

给定的 position 仅在此方法调用期间有效。不要保留其引用供之后使用，因为相关值可能会更新、保持不变，或变为完全无关的另一个可滚动对象的值。

此方法可能每一帧都会调用，即使用户感知到的同一次弹道滚动仍在进行也是如此。例如，在 ListView 中，先前位于屏幕外的条目进入视野并完成布局时，此方法可能会收到新的 ScrollMetrics.maxScrollExtent。如果仍要执行相同的弹道滚动，实现应确保这些调用不会改变滚动物理效果，只会让该运动继续进行。

通常可通过让 Simulation 符合弹道飞行粒子的物理模型来确保这一点：粒子所受的力只取决于其位置、速度和环境，而不取决于当前时间或任何内部状态。这意味着 Simulation.dx 对时间的导数在数学上应能仅表示为 Simulation.x、Simulation.dx 以及构造 Simulation 时使用的参数的函数，而与时间无关。

实现

@override
Simulation? createBallisticSimulation(ScrollMetrics position, double velocity) {
  final Tolerance tolerance = toleranceFor(position);
  if (position.outOfRange) {
    double? end;
    if (position.pixels > position.maxScrollExtent) {
      end = position.maxScrollExtent;
    }
    if (position.pixels < position.minScrollExtent) {
      end = position.minScrollExtent;
    }
    assert(end != null);
    return ScrollSpringSimulation(
      spring,
      position.pixels,
      end!,
      math.min(0.0, velocity),
      tolerance: tolerance,
    );
  }
  if (velocity.abs() < tolerance.velocity) {
    return null;
  }
  if (velocity > 0.0 && position.pixels >= position.maxScrollExtent) {
    return null;
  }
  if (velocity < 0.0 && position.pixels <= position.minScrollExtent) {
    return null;
  }
  return ClampingScrollSimulation(
    position: position.pixels,
    velocity: velocity,
    tolerance: tolerance,
  );
}
