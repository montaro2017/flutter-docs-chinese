AnimatedListState 类

AnimatedListState 是 AnimatedList 的状态对象；AnimatedList 是一个可滚动列表容器，在项目插入或移除时播放动画。

插入项目时会调用 insertItem 并开始播放动画。每当需要构建项目的 widget，动画都会传递给 AnimatedList.itemBuilder。

插入多个项目时调用 insertAllItems 并开始播放动画。每当需要构建项目的 widget，动画都会传递给 AnimatedList.itemBuilder。

如果使用 AnimatedList.separated，每当需要构建分隔符 widget 时，动画也会传递给 AnimatedList.separatorBuilder。

使用 removeItem 移除项目时，其动画会反向播放。被移除项目的动画会传递给 removeItem 构建器参数。如果使用 AnimatedList.separated，对应分隔符的动画也会传递给 AnimatedList.removedSeparatorBuilder 参数。

需要响应事件插入或移除项目的应用，可以使用全局 key 引用 AnimatedList 的状态：

// (e.g. in a stateful widget)
GlobalKey<AnimatedListState> listKey = GlobalKey<AnimatedListState>();

// ...

@override
Widget build(BuildContext context) {
  return AnimatedList(
    key: listKey,
    itemBuilder: (BuildContext context, int index, Animation<double> animation) {
      return const Placeholder();
    },
  );
}

// ...

void _updateList() {
  // adds "123" to the AnimatedList
  listKey.currentState!.insertItem(123);
}

AnimatedList 项目的输入处理函数也可以通过静态 AnimatedList.of 方法引用其 AnimatedListState。
