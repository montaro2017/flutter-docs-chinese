RawRadio<T> 类

提供基本单选功能的单选按钮。

提供 builder 以绘制单选按钮的界面。

如果需要绘制径向墨水反馈效果（例如 Material Design 中的效果），可以提供 CustomPaint，并将 ToggleablePainter 子类作为 CustomPaint.painter。该子类负责实现此控件的径向墨水反馈绘制逻辑。绘制器通常使用此 mixin 提供的 ToggleableStateMixin.reaction、ToggleableStateMixin.position、ToggleableStateMixin.reactionHoverFade 和 ToggleableStateMixin.reactionFocusFade 动画配置。它应根据这些动画的当前值绘制 Toggleable 的视觉效果。mixin 会触发这些动画，使 Toggleable 在不同状态之间过渡。

此组件允许从多个互斥值中进行选择。选中某个组内的单选按钮后，组中的其他按钮会取消选中。值的类型为 T，即单选组件的类型参数。此用途通常会使用枚举。

单选按钮依靠 groupRegistry 管理选中状态。如果与 RadioGroup 组件配合使用，请通过 RadioGroup.maybeOf 从上下文中获取组注册表。

如果 enabled 为 false，单选按钮将不可交互。

另请参阅：

  • Radio, which uses this widget to build a Material styled radio button.
  • CupertinoRadio, which uses this widget to build a Cupertino styled radio button.
