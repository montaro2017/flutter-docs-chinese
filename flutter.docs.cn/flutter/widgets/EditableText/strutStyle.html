strutStyle 属性

StrutStyle get strutStyle

用于垂直布局的 strut 样式。

StrutStyle 用于建立可预测的垂直布局。由于字体可能因用户输入和字体回退而变化，默认会启用 StrutStyle.forceStrutHeight，将所有行的高度锁定为由 style 提供的基础 TextStyle 高度。这样可以确保输入文本适合分配的空间。

如果为 null，strut 将从 style 继承值，并将 StrutStyle.forceStrutHeight 设为 true。如果未传入 style，则改用主题的 TextStyle 生成 strutStyle。

若要禁用基于 strut 的垂直对齐，并允许根据输入字形动态调整垂直布局，请使用 StrutStyle.disabled。

Flutter 的 strut 基于排版支架，也与 CSS 的 line-height 对应。

在可编辑文本和文本字段中，StrutStyle 不会使用其独立默认值，而是从 TextStyle 继承未指定或为 null 的属性。另请参阅 StrutStyle.inheritFromTextStyle。

用户或平台可以通过祖先 MediaQuery 的 MediaQueryData.lineHeightScaleFactorOverride 覆盖此 strutStyle 的 StrutStyle.height。

实现

StrutStyle get strutStyle {
  if (_strutStyle == null) {
    return StrutStyle.fromTextStyle(style, forceStrutHeight: true);
  }
  return _strutStyle.inheritFromTextStyle(style);
}
