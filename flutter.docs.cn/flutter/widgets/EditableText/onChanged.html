onChanged 属性

ValueChanged<String>? onChanged
final

用户插入或删除文字、主动更改 TextField 的值时调用。

通过 TextField 的 controller 以编程方式更改文本时，不会运行此回调。通常无需监听这类更改，因为它们由应用自身发起。

若要监听 TextField 的文本、光标和选区的所有变化，可以使用 TextEditingController.addListener 为其 controller 添加监听器。

用户表示编辑完成时（例如按下键盘上的“完成”按钮），会先调用 onChanged，再调用 onSubmitted。此默认行为可以覆盖，详情请参阅 onEditingComplete。

处理表情符号和其他复杂字符

处理可能包含复杂字符的用户输入时，务必使用 characters。这样可以确保扩展字素簇和代理项对按用户所见被视为单个字符。

例如，获取用户输入长度时，请使用 string.characters.length。不要使用 string.length，也不要使用 string.runes.length。复杂字符“👨‍👩‍👦”在用户看来是一个字符，因此 string.characters.length 会直观地返回 1；而 string.length 会返回 8，string.runes.length 会返回 5！

另请参阅：

  • inputFormatters, which are called before onChanged runs and can validate and change ("format") the input value.
  • onEditingComplete, onSubmitted, onSelectionChanged: which are more specialized input change notifications.
  • TextEditingController 实现了 Listenable 接口，并会在 TextEditingValue 发生变化时通知其侦听器。
