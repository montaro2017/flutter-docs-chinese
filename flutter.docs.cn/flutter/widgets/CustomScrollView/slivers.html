什么是 sliver？

sliver（名词）：细小、薄片状的东西。

sliver 是由 RenderSliver 子类支持的组件，也就是说，它实现了使用 SliverConstraints 和 SliverGeometry 的约束/几何协议。

与之相对的是由 RenderBox 子类支持的组件，它们分别使用 BoxConstraints 和 Size，称为 box 组件。（Container、Row 和 SizedBox 等组件都属于 box 组件。）

box 布局较为直接（实现简单的二维笛卡尔布局系统）；sliver 功能更强大，并针对单轴滚动场景进行了优化。

Sliver 由视口托管，视口也称为滚动视图，其中最常见的是 CustomScrollView。

Sliver 示例

Flutter 框架内置了许多 sliver 组件，也可以用相同方式创建自定义组件。按照惯例，sliver 组件的名称总以 Sliver 为前缀，并且总是在名为 sliver 或 slivers 的属性中使用（box 组件则使用 child 和 children）。

sliver 特有组件的示例包括：

  • SliverList, a lazily-loading list of variably-sized box widgets.
  • SliverFixedExtentList, a lazily-loading list of box widgets that are all forced to the same height.
  • SliverPrototypeExtentList, a lazily-loading list of box widgets that are all forced to the same height as a given prototype widget.
  • SliverGrid, a lazily-loading grid of box widgets.
  • SliverAnimatedList 和 SliverAnimatedGrid, animated variants of SliverList 和 SliverGrid.
  • SliverFillRemaining 会填满滚动视图中的所有剩余空间，并在其中布局一个 box widget。
  • SliverFillViewport, a widget that lays a list of boxes out, each being sized to fit the whole viewport.
  • SliverPersistentHeader, a sliver that implements pinned and floating headers, e.g. used to implement SliverAppBar.
  • SliverToBoxAdapter, a sliver that wraps a box widget.

常见 box 组件对应的 sliver 变体示例包括：

  • SliverOpacity, SliverAnimatedOpacity, and SliverFadeTransition, sliver versions of Opacity, AnimatedOpacity, and FadeTransition.
  • SliverIgnorePointer, 对应的 Sliver 版本。IgnorePointer.
  • SliverLayoutBuilder, 对应的 Sliver 版本。LayoutBuilder.
  • SliverOffstage, 对应的 Sliver 版本。Offstage.
  • SliverPadding, 对应的 Sliver 版本。Padding.
  • SliverReorderableList, 对应的 Sliver 版本。ReorderableList
  • SliverSafeArea, 对应的 Sliver 版本。SafeArea.
  • SliverVisibility, 对应的 Sliver 版本。Visibility.

Sliver 相比 box 的优势

Sliver 协议（SliverConstraints 和 SliverGeometry）支持各种滚动效果，例如浮动应用栏、滚动时展开和收起的组件、仅在其子项可见期间固定的分区标题等。

混合使用 sliver 与 box

通常，sliver 会包装 box 组件来实际呈现内容（例如，没有与 Text 或 Container 对应的 sliver）；sliver 主要负责在视口中（即滚动时）布局这些 box。

在 sliver 环境中组合 box，最简单的方式通常是使用 SliverList（也可以使用 ListView，它方便地组合了 CustomScrollView 和 SliverList）。少数情况下，例如需要在两个 SliverGrid 之间放置一个 Divider，可以使用 SliverToBoxAdapter 包装 box 组件。

性能注意事项

滚动视图的用途就是滚动，因此通常包含的内容会多于任一时刻屏幕上实际呈现的内容。

为了提升滚动视图的性能，可以使用延迟构建组件来呈现内容，尤其是 SliverList 和 SliverGrid（以及 SliverFixedExtentList 和 SliverAnimatedGrid 等变体）。这些组件只会构建、布局和绘制子项列表中当前可见的部分。

ListView 和 GridView 组件分别提供了组合 CustomScrollView 与 SliverList 或 SliverGrid 的便捷方式。
