RouterDelegate<T> 类 抽象

供 Router widget 使用的委托，用于构建和配置导航 widget。

此委托是 Router widget 的核心。它会响应引擎发出的推入路由和弹出路由意图，并通知 Router 重新构建。它还充当 Router widget 的构建器：当 Router widget 构建时，会构建导航 widget，通常是 Navigator。

引擎推入新路由时，路由信息会由 RouteInformationParser 解析，以生成 T 类型的配置。路由委托通过 setInitialRoutePath 或 setNewRoutePath 接收该配置，以完成自身配置；在被请求时（build）构建最新的导航 widget。

实现子类时，可以考虑定义一个 Listenable 应用状态对象，用于构建导航 widget。路由委托应相应更新应用状态，并在应用状态变化或收到引擎发出的路由意图（例如 setNewRoutePath、setInitialRoutePath 或 popRoute）时通知自己的监听器。

所有子类都必须实现 setNewRoutePath、popRoute 和 build。

状态恢复

如果拥有此委托的 Router 已配置状态恢复，就会通过以下机制持久化和恢复此 RouterDelegate 的配置：操作系统终止应用前，currentConfiguration 的值会被序列化并持久化。应用重启后，该值会被反序列化，并通过调用 setRestoredRoutePath 传回 RouterDelegate（默认实现只调用 setNewRoutePath）。RouterDelegate 负责使用提供的配置信息恢复其内部状态。

另请参阅：

  • RouteInformationParser 负责先将路由信息解析为配置，再传递给路由委托。
  • Router 是将所有委托连接起来、提供完整路由解决方案的 widget。
