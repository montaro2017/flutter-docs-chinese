groupId 属性

Object? get groupId

可选的组 ID，用于将多个 RenderTapRegion 归为一组，使其作为一个区域运行。如果某次轻点命中了组中任一成员，则不会为任何成员调用 onTapOutside 或 onTapUpOutside。如果命中了组中任一成员，则会为所有成员调用 onTapInside 或 onTapUpInside。

如果 group ID 为 null，则命中测试只会针对当前区域进行。

实现

Object? get groupId => _groupId;
set groupId (Object? value)

实现

set groupId(Object? value) {
  if (_groupId != value) {
    // If the group changes, we need to unregister and re-register under the
    // new group. The re-registration happens automatically in layout().
    if (_isRegistered) {
      _registry!.unregisterTapRegion(this);
      _isRegistered = false;
    }
    _groupId = value;
    markNeedsLayout();
  }
}
