计算此渲染对象的布局。

父对象主要通过此方法要求子项更新其布局信息。父对象会传入一个约束对象，告知子项允许采用哪些布局；子项必须遵守给定约束。

如果父对象会读取子项布局期间计算的信息，就必须将 parentUsesSize 设为 true。在这种情况下，当子项被标记为需要布局时，父对象也会被标记为需要布局，因为父对象的布局信息依赖于子项的布局信息。如果父对象对 parentUsesSize 使用默认值 false，子项可以在给定约束范围内更改布局信息，而无需通知父对象。

子类不应直接重写 layout。应改为重写 performResize 和/或 performLayout。layout 方法会将实际工作委托给 performResize 和 performLayout。

父对象的 performLayout 方法应无条件地对所有子项调用 layout。如果子项无需执行任何工作来更新布局信息，layout 方法（如本实现所示）负责提前返回。

实现

@override
void layout(Constraints constraints, {bool parentUsesSize = false}) {
  super.layout(constraints, parentUsesSize: parentUsesSize);
  if (_registry == null) {
    return;
  }
  if (_isRegistered) {
    _registry!.unregisterTapRegion(this);
  }
  final bool shouldBeRegistered = _enabled && _registry != null;
  if (shouldBeRegistered) {
    _registry!.registerTapRegion(this);
  }
  _isRegistered = shouldBeRegistered;
}
