AnimatedSwitcher 类

默认会在新 widget 与之前设置为 AnimatedSwitcher 子级的 widget 之间进行交叉淡变。

如果切换速度足够快（也就是在 duration 结束前再次切换），多个先前的子级可以同时存在并正在淡出，而最新子级则正在淡入。

如果“新”子级与“旧”子级的 widget 类型和 key 相同，但参数不同，那么 AnimatedSwitcher 不会在两者之间执行过渡，因为从框架的角度看它们是同一个 widget，可以直接用新参数更新现有 widget。若要强制执行过渡，请为每个需要视为不同对象的子级设置 Key（通常可使用能够区分此子级数据的 ValueKey）。

新子级可以使用与某个已淡出的子级相同的 key；两者不会被视为相关对象。（例如，先显示 key 为 A 的进度指示器，再显示 key 为 B 的图片，随后又快速显示 key 为 A 的进度指示器时，旧进度指示器和图片会淡出，同时新的进度指示器会淡入。）

通过设置 transitionBuilder，可以将交叉淡变改为自定义过渡效果。

此示例展示一个计数器：每当数值变化时，文本 widget 都会缩放并播放动画。
