TweenAnimationBuilder
description

TweenAnimationBuilder<T extends Object?> 类

当目标值变化时，将 Widget 的某个属性动画过渡到目标值的 Widget 构建器。

动画属性的类型（例如 Color、Rect、double 等）由所提供的 tween 类型决定（例如 ColorTween、RectTween、Tween<double> 等）。

tween 也定义动画的目标值：widget 首次构建时，会从 Tween.begin 动画过渡到 Tween.end。随时都可以通过提供具有新 Tween.end 值的新 tween 来触发新动画。新动画会从当前动画值开始（如果旧动画已完成，该值可能是旧 tween 的 Tween.end），并过渡到新 tween 的 Tween.end。

The animation is further customized by providing a curve 和 duration.

The current value of the animation along with the child is passed to the builder callback, which is expected to build a Widget based on the current animation value. The builder is called throughout the animation for every animation value until Tween.end 。

每当动画完成时，都会调用所提供的 onEnd 回调。注册 此回调可在当前动画结束时触发操作，例如启动另一段动画。

性能优化

如果 builder 函数包含不依赖动画的子树，那么只构建一次该子树，比每次动画帧都重新构建更高效。

如果将预先构建的子树作为 child 参数传入，AnimatedBuilder 会将它传回 builder 函数，以便纳入构建结果。

使用此预构建子级完全可选，但在某些情况下可以显著提升性能，因此这是一个良好实践。

对 Tween 的所有权

TweenAnimationBuilder 会完全接管所提供的 tween 实例，并修改它。将 Tween 传给 TweenAnimationBuilder 后，不应再访问或更改其属性，以免干扰 TweenAnimationBuilder。

建议不要将传给 TweenAnimationBuilder 的 Tween 保存在实例变量中，以免意外修改 它。

与 ImplicitlyAnimatedWidget 和 AnimatedWidget 的关系

ImplicitlyAnimatedWidget 有许多子类，为常规 widget 提供带动画的版本。这些子类（例如 AnimatedOpacity、AnimatedContainer、AnimatedSize 等）会平滑地动画过渡其属性变化，比这种通用构建器更容易使用。不过，TweenAnimationBuilder 本身也是 ImplicitlyAnimatedWidget 的子类，适合将任意 widget 属性动画过渡到指定目标值，即使 Flutter 框架或第三方 widget 库没有提供该 widget 的动画版本也可以使用。

这些 ImplicitlyAnimatedWidget（包括 TweenAnimationBuilder）都会管理内部的 AnimationController 来驱动动画。如果除了设置目标值、duration 和 curve 以外，还需要更多动画控制，可以查看 AnimatedWidget 的子类。使用这些类时，必须手动管理 AnimationController，从而完全控制动画。AnimatedBuilder 就是一个 AnimatedWidget 示例，它的用法与 TweenAnimationBuilder 类似，但动画由开发者管理的 AnimationController 驱动。
