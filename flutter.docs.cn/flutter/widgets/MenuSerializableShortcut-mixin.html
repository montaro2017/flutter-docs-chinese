MenuSerializableShortcut mixin

一个 mixin，使 ShortcutActivator 能在向平台发送快捷键时提供可序列化的数据。

此功能面向自行编写了 ShortcutActivator 子类，并希望该子类也能用于 PlatformMenuBar 菜单的开发者。

请注意，平台 API 的能力有限，并非所有类型的 ShortcutActivator 都能与之配合使用。

另请参阅：

  • SingleActivator, a ShortcutActivator which implements this mixin.
  • CharacterActivator, another ShortcutActivator which implements this mixin.
