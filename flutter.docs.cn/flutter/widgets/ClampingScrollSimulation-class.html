ClampingScrollSimulation 类

一种与 Android 滚动效果相符的滚动物理模拟。

无论 velocity 为何值，此模拟的总行程都与 Android 滚动物理效果相同。

此滚动物理效果经过相对于 Android 的调整，以实现弹道特性，即任一时刻的减速度只取决于当前速度 dx，而不取决于模拟开始了多久。（这是 Flutter 滚动协议所要求的；协议允许 ScrollActivityDelegate.goBallistic 仅依据当前速度和滚动位置自身的状态重新启动滚动活动。）相比之下，Android 的滚动一开始更快，随后更慢，最终到达相同位置，但耗时略长。

时间以秒为单位，位置以逻辑像素为单位。

另请参阅：

  • BouncingScrollSimulation, which implements iOS scroll physics.
