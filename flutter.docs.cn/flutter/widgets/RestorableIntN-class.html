RestorableIntN 类

A RestorableProperty that knows how to store and restore a int that is nullable.

此属性当前的 value 存储在状态恢复数据中。恢复状态时，属性会还原为收集到这些恢复数据时的值。

如果没有状态恢复数据，构造函数提供的 defaultValue 会用于初始化 value。

另请参阅：

  • RestorableInt，对应此类的非空版本。
