positionDelegate 属性

TooltipPositionDelegate? positionDelegate
final

用于计算提示工具位置的自定义位置委托函数。

提供此函数时，会传入包含定位所需全部信息的 TooltipPositionContext。函数应返回一个 Offset，用于指示提示工具在最近的 Overlay 中的放置位置。

这允许使用自定义定位方式，例如放在左侧或右侧，也可以实现任意其他定位逻辑。

例如，如果 Overlay 占据整个屏幕，返回 Offset.zero 会将提示工具放在屏幕左上角。

TooltipPositionContext 提供的信息可用于将提示工具相对于目标组件或子组件定位。

例如：

positionDelegate: (TooltipPositionContext context) {
  // Use the context information to position the tooltip to the right of
  // the target.
  return Offset(
    context.target.dx + context.targetSize.width / 2,
    context.target.dy - context.tooltipSize.height / 2,
  );
}

为 null 时，默认使用 positionDependentBox，将提示工具置于目标下方并水平居中。

另请参阅：

  • TooltipPositionContext, which contains the positioning parameters.
  • TooltipPositionDelegate, the function signature for custom positioning.
