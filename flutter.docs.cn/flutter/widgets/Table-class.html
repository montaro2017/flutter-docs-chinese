Table 类

使用表格布局算法排列其子级的 widget。

此示例展示了一个带边框的 Table，其中使用了多种列宽类型和不同的单元格垂直对齐方式。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.Table.1 mysample

如果只有一行，使用 Row widget 更合适。如果只有一列，使用 SliverList 或 Column widget 更合适。

行的垂直尺寸由其内容决定。若要控制各列的宽度，可通过 columnWidths 属性为每一列指定一个 TableColumnWidth。如果 columnWidths 为 null，或 columnWidths 中某一列对应的条目为 null，则表格会改用 defaultColumnWidth。

默认情况下，defaultColumnWidth 是 FlexColumnWidth。此 TableColumnWidth 会分配水平方向的剩余空间，以确定列宽。如果将 Table 放入水平 ScrollView 中，请选择其他 TableColumnWidth，例如 FixedColumnWidth。

有关表格布局算法的详细信息，请参阅 RenderTable。若要控制子级的对齐方式，请参阅 TableCell。
