创建一个固定长度、可滚动的线性列表，其中列表“条目”由列表项“分隔符”隔开。

此构造函数适用于条目和分隔符子组件数量较多的列表视图，因为 builder 只会为当前可见的子组件调用。

只有当索引大于等于零且小于 itemCount 时，才会调用 itemBuilder 回调。

分隔符只会出现在列表项之间：分隔符 0 位于条目 0 之后，最后一个分隔符位于最后一个条目之前。

只有当索引大于等于零且小于 itemCount - 1 时，才会调用 separatorBuilder 回调。

每次调用 itemBuilder 和 separatorBuilder 时都应实际创建新的组件实例。避免使用返回先前已构建组件的 builder；如果列表视图的子组件预先创建，或在创建 ListView 时一次性创建，使用 ListView 构造函数会更高效。

itemBuilder 返回 null 是合法的。如果发生这种情况，即使尚未到达 itemCount，滚动视图也会停止调用 itemBuilder。由于返回了 null，除非用户已滚动到 ScrollPosition.maxScrollExtent 的末尾，否则 ScrollView 将不准确；这也可能导致 Scrollbar 随着用户滚动而增长。

若要获得更准确的 ScrollMetrics，请考虑指定 itemCount。

findChildIndexCallback 对应 SliverChildBuilderDelegate.findChildIndexCallback 属性。如果该回调为 null，当子节点构建器返回的子 Widget 顺序变化时，子 Widget 可能无法映射到现有的 RenderObject，从而导致状态丢失。如果子节点顺序之后可能发生变化，就必须实现此回调。

findItemIndexCallback 返回条目索引（不包括分隔符）；已弃用的 findChildIndexCallback 则返回子组件索引（同时包括条目和分隔符）。

例如，一个包含 3 个条目和 2 个分隔符的列表：

  • Item indices: 0, 1, 2
  • Child indices: 0 (item), 1 (separator), 2 (item), 3 (separator), 4 (item)

如果条目顺序之后可能发生变化，应实现此回调。若为 null，重新排列条目可能导致状态丢失，因为组件可能无法映射到其原有的 RenderObject。

此示例展示如何创建一个 ListView，其中的 ListTile 列表项由 Divider 分隔。

ListView.separated(
  itemCount: 25,
  separatorBuilder: (BuildContext context, int index) {
    return const SizedBox(
      height: 1.0,
      width: double.infinity,
      child: ColoredBox(color: Color(0xFF000000)),
    );
  },
  itemBuilder: (BuildContext context, int index) {
    return ListTile(
      title: Text('item $index'),
    );
  },
)

addAutomaticKeepAlives 参数对应 SliverChildBuilderDelegate.addAutomaticKeepAlives 属性。addRepaintBoundaries 参数对应 SliverChildBuilderDelegate.addRepaintBoundaries 属性。addSemanticIndexes 参数对应 SliverChildBuilderDelegate.addSemanticIndexes 属性。这些参数都不能为 null。

ListView.separated({
  super.key,
  super.scrollDirection,
  super.reverse,
  super.controller,
  super.primary,
  super.physics,
  super.shrinkWrap,
  super.padding,
  required NullableIndexedWidgetBuilder itemBuilder,
  @Deprecated(
    'Use findItemIndexCallback instead. '
    'findChildIndexCallback returns child indices (which include separators), '
    'while findItemIndexCallback returns item indices (which do not). '
    'If you were multiplying results by 2 to account for separators, '
    'you can remove that workaround when migrating to findItemIndexCallback. '
    'This feature was deprecated after v3.37.0-1.0.pre.',
  )
  ChildIndexGetter? findChildIndexCallback,
  ChildIndexGetter? findItemIndexCallback,
  required IndexedWidgetBuilder separatorBuilder,
  required int itemCount,
  bool addAutomaticKeepAlives = true,
  bool addRepaintBoundaries = true,
  bool addSemanticIndexes = true,
  @Deprecated(
    'Use scrollCacheExtent instead. '
    'This feature was deprecated after v3.41.0-0.0.pre.',
  )
  super.cacheExtent,
  super.scrollCacheExtent,
  super.dragStartBehavior,
  super.keyboardDismissBehavior,
  super.restorationId,
  super.clipBehavior,
  super.hitTestBehavior,
}) : assert(itemCount >= 0),
     assert(
       findItemIndexCallback == null || findChildIndexCallback == null,
       'Cannot provide both findItemIndexCallback and findChildIndexCallback. '
       'Use findItemIndexCallback as findChildIndexCallback is deprecated.',
     ),
     itemExtent = null,
     itemExtentBuilder = null,
     prototypeItem = null,
     childrenDelegate = SliverChildBuilderDelegate(
       (BuildContext context, int index) {
         final int itemIndex = index ~/ 2;
         if (index.isEven) {
           return itemBuilder(context, itemIndex);
         }
         return separatorBuilder(context, itemIndex);
       },
       findChildIndexCallback: findItemIndexCallback != null
           ? (Key key) {
               final int? itemIndex = findItemIndexCallback(key);
               return itemIndex == null ? null : itemIndex * 2;
             }
           : findChildIndexCallback,
       childCount: _computeActualChildCount(itemCount),
       addAutomaticKeepAlives: addAutomaticKeepAlives,
       addRepaintBoundaries: addRepaintBoundaries,
       addSemanticIndexes: addSemanticIndexes,
       semanticIndexCallback: (Widget widget, int index) {
         return index.isEven ? index ~/ 2 : null;
       },
     ),
     super(semanticChildCount: itemCount);
