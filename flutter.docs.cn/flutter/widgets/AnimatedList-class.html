AnimatedList 类

一个可滚动容器，在项目插入或移除时播放动画。

此 widget 的 AnimatedListState 可用于动态插入或移除项目。要引用 AnimatedListState，可以提供一个 GlobalKey，也可以在项目的输入回调中使用静态 of 方法。

此 widget 类似于使用 ListView.builder 创建的 widget。

此示例应用使用 AnimatedList，在项目从列表中移除或添加时创建动画效果。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.AnimatedList.1 mysample

默认情况下，AnimatedList 会自动为可滚动列表的边界添加内边距，以避免被以下对象指示的部分遮挡： MediaQuery 的 padding。若要避免此行为，请将 padding 属性设为零。

以下示例演示如何使用 MediaQuery.removePadding 覆盖默认的顶部和底部内边距。
link 
Widget myWidget(BuildContext context) {
  return MediaQuery.removePadding(
    context: context,
    removeTop: true,
    removeBottom: true,
    child: AnimatedList(
      initialItemCount: 50,
      itemBuilder: (BuildContext context, int index, Animation<double> animation) {
        return Card(
          color: Colors.amber,
          child: Center(child: Text('$index')),
        );
      }
    ),
  );
}
