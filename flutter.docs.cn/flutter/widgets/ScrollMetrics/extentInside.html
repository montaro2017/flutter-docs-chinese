extentInside 属性

double get extentInside

可滚动内容中概念上位于视口内部的内容量（如果总内容量小于 viewportDimension，也包括空白区域）。

当 outOfRange 为 false 时，此值通常等于视口尺寸（viewportDimension）；发生过度滚动时可能更小。

此值始终非负，且小于或等于 viewportDimension。

实现

double get extentInside {
  assert(minScrollExtent <= maxScrollExtent);
  return viewportDimension
      // "above" overscroll value
      -
      clampDouble(minScrollExtent - pixels, 0, viewportDimension)
      // "below" overscroll value
      -
      clampDouble(pixels - maxScrollExtent, 0, viewportDimension);
}
