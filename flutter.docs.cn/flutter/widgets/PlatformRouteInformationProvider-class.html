PlatformRouteInformationProvider 类

用于传播平台路由信息变更的路由信息提供方。

此提供方还会通过消息通道方法 SystemNavigator.routeInformationUpdated，将 Router 组件生成的新路由信息回报给引擎。

每次调用 SystemNavigator.routeInformationUpdated 时，也会调用 SystemNavigator.selectMultiEntryHistory 方法。这会覆盖 Navigator.reportsRouteUpdateToEngine 的初始化行为。
