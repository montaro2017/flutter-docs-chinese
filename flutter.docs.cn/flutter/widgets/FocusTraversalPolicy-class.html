FocusTraversalPolicy 类 抽象

确定在 FocusTraversalGroup 中如何遍历可聚焦 widget。

焦点遍历策略用于确定相对于当前拥有焦点的 FocusNode（通常是 Focus widget），哪个 widget 是“下一个”“上一个”或某个方向上的目标。

可以使用预定义子类，也可以定义自定义策略来创建独特的焦点顺序。

定义自定义策略时，子类应实现 sortDescendants，以指定后代的遍历顺序。

另请参阅：

  • FocusNode，用于了解焦点系统。
  • FocusTraversalGroup, 一种将其分组，并为其应用遍历策略的组件：Focus 节点（位于该组件下方的 widget 树中）。
  • FocusNode，会受到焦点遍历策略的影响。
  • WidgetOrderTraversalPolicy，一种依据 widget 创建顺序确定遍历顺序的策略。
  • ReadingOrderTraversalPolicy，一种按照当前 Directionality 的自然“阅读顺序”确定遍历顺序的策略。
  • OrderedTraversalPolicy，一种通过 FocusTraversalOrder widget 显式指定遍历顺序的策略。
  • DirectionalFocusTraversalPolicyMixin，一种实现定向焦点遍历的 mixin。
