SliverReorderableList 类

允许用户以交互方式重新排列列表项的 sliver 列表。

应用需要为每个子项（或子项内部的一部分）添加拖动监听器，以识别拖动项目的开始，并调用 SliverReorderableListState.startItemDragReorder 开始重新排序。最简单的方法是将每个子项包装在 ReorderableDragStartListener 或 ReorderableDelayedDragStartListener 中。它们会负责识别拖动手势的开始，并调用列表状态对象的项目拖动方法。

此 widget 的 SliverReorderableListState 可用于手动开始项目重排，或取消正在进行的拖动。要引用 SliverReorderableListState，可以提供 GlobalKey，也可以在某个项目的 build 方法中使用静态 SliverReorderableList.of 方法。

另请参阅：

  • ReorderableList, a regular widget list that allows the user to reorder its items.
  • ReorderableListView，一种允许用户重新排列项目的 Material Design 列表。
