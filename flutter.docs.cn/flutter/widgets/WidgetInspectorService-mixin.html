description

WidgetInspectorService mixin

供 GUI 工具与 WidgetInspector 交互时使用的服务。

GUI 工具通常会调用此对象，例如通过 Flutter IntelliJ Plugin。此类使用自己的对象 ID，并自行管理对象生命周期，而不依赖 Dart VM Service 协议指定的 对象 ID，因为 VM Service 协议中的 ID 可能会不可预测地过期。对象引用按组跟踪，因此客户端工具可以通过一次操作解除对某组中所有对象的引用，从而更容易避免内存泄漏。

此类的所有方法都适合调试工具通过 VM service protocol 调用，用于计算如下形式的 Dart 表达式：WidgetInspectorService.instance.methodName(arg1, arg2, ...)。如果修改此类的任何实例方法，都需要确认修改后 Flutter IntelliJ Plugin 的 widget inspector 功能仍然正常。

所有返回 String 值的方法都会返回 JSON。
