GlobalKey<T extends State<StatefulWidget>> 类 抽象

在整个应用中唯一的键。

全局键可唯一标识元素，并提供对与这些元素关联对象的访问权限，例如 BuildContext。 对于 StatefulWidget，全局键还可用于访问 State。

具有全局键的组件在树中移动时，会将其子树重新挂接到新位置。要重新挂接子树，组件必须在被移出旧位置的同一动画帧内到达树中的新位置。

使用全局键重新挂接 Element 的开销相对较高，因为此操作会触发关联 State.deactivate 及其所有后代的 State 调用；随后还会强制依赖 InheritedWidget 的所有组件重建。

如果不需要上述功能，可以考虑改用 Key、 ValueKey、ObjectKey 或 UniqueKey。

不能在树中同时放入两个具有相同全局键的组件。尝试这样做会在运行时触发断言。

注意事项

不应在每次 build 时重新创建 GlobalKey。通常应将其作为长生命周期对象由 State 持有。

每次 build 都创建新的 GlobalKey，会丢弃与旧键关联子树的状态，并为新键创建全新子树。这不仅会损害性能，还可能导致子树中的组件出现意外行为。例如，子树中的 GestureDetector 会在每次 build 时重新创建，因此无法继续跟踪正在进行的手势。

建议让 State 对象持有 GlobalKey，并在 build 方法之外（例如在 State.initState 中）实例化它。
