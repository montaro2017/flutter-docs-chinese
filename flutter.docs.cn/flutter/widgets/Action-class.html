Action<T extends Intent> 类 抽象

用于表示要执行的操作或命令的基类。

Actions 通常由用户行为触发。例如，Shortcuts 组件会将键盘快捷键映射为 Intent，然后交给 ActionDispatcher，由其将 Intent 映射到 Action 并调用该操作。

ActionDispatcher 可以在主焦点上调用 Action，也可以不考虑焦点来调用。

Action Overriding

使用叶组件构建更专用的组件时，有时需要更改该叶组件中定义的 Intent 的默认处理方式。例如，TextField 默认会通过 SelectAllTextIntent 选中当前包含的文本；但由 3 个不同 TextField（区号、前缀和号码）组成的美国电话号码组件中，SelectAllTextIntent 应改为选中这 3 个 TextField 中的所有文本。

可覆盖操作是一种特殊的 Action，通过 Action.overridable 构造函数创建。它可以访问一个默认 Action 和一个可空的覆盖 Action。如果存在覆盖操作，它的行为与覆盖的 Action 相同；否则，它会反映 defaultAction 的行为。

Action.overridable 构造函数会创建可覆盖的 Action，该操作会通过 BuildContext 在祖先 Actions 组件中查找合适的覆盖项。使用通用叶组件时，可以用此方式提供默认实现；之后用该叶组件构建更专用的组件时，再覆盖默认实现。以上述 TextField 组件为例 TextField，它使用可覆盖的 Action 为 SelectAllTextIntent 提供合理的默认行为，同时允许应用开发者添加祖先 Actions 组件，将 SelectAllTextIntent 映射到其他 Action，从而更改默认行为。

有关详细说明，请参阅《使用 Actions 和 Shortcuts》一文：flutter.dev/to/actions-shortcuts。

另请参阅：

  • Shortcuts, which is a widget that contains a key map, in which it looks up key combinations in order to invoke actions.
  • Actions, which is a widget that defines a map of Intent to Action and allows redefining of actions for its descendants.
