请求输入法客户端执行给定的私有命令。

可用于提供特定输入法及其客户端之间约定的领域专属功能。

另请参阅：

  • performPrivateCommand，这是 Android 关于 performPrivateCommand 的文档，用于从输入法发送命令。
  • sendAppPrivateCommand，这是 Android 关于 sendAppPrivateCommand 的文档，用于向输入法发送命令。

实现

@override
void performPrivateCommand(String action, Map<String, dynamic> data) {
  widget.onAppPrivateCommand?.call(action, data);
}
