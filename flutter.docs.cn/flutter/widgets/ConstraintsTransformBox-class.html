ConstraintsTransformBox 类

一种容器组件，可对约束应用任意变换，并使用变换后得到的 BoxConstraints 布局子项；还可选择裁剪溢出内容，或将溢出视为错误。

此容器会先将 constraintsTransform 应用于自身约束，再使用生成的 BoxConstraints 布局子项。随后，容器会尝试在自身约束允许的范围内采用与子项相同的尺寸。如果最终尺寸不同，则根据 alignment 对齐子项。如果容器无法扩展到足以容纳整个子项，并且 clipBehavior 不是 Clip.none，就会裁剪子项。

在调试模式下，如果 clipBehavior 为 Clip.none 且子项溢出容器，控制台会打印警告，并在溢出位置显示黑黄相间的条纹区域。

当 child 为 null 时，此组件会缩至最小尺寸，且不会发生溢出。

此组件可用于确保 child 的部分自然尺寸得到保留，并在开发期间提前发出警告。例如，如果 child 需要最小高度才能完整显示内容，可以将 constraintsTransform 设为 maxHeightUnconstrained。这样，即使父级 RenderObject 未能提供足够的垂直空间，调试模式下仍会显示警告，同时允许 child 在垂直方向继续增长：

在以下代码片段中，Card 的高度至少会达到其“自然”高度。与 UnconstrainedBox 不同，如果其“自然”高度小于 40 px，它仍会扩展到更高。如果 Container 不够高，无法显示 Card 的全部内容，调试模式下会发出警告。
link 
Container(
  constraints: const BoxConstraints(minHeight: 40, maxHeight: 100),
  alignment: Alignment.center,
  child: const ConstraintsTransformBox(
    constraintsTransform: ConstraintsTransformBox.maxHeightUnconstrained,
    child: Card(child: Text('Hello World!')),
  )
)
