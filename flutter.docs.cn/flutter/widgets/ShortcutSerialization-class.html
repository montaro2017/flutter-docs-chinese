ShortcutSerialization 类

MenuSerializableShortcut 使用此类描述快捷键，以便序列化并发送到平台，从而渲染 PlatformMenuBar。

另请参阅：

  • PlatformMenuBar，一种为平台定义原生菜单栏的 widget。
  • MenuSerializableShortcut 是一个 mixin，允许 ShortcutActivator 提供快捷键序列化数据，以便发送到平台。
