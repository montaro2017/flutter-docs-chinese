创建一个用于包装应用常用组件的 Widget。

大多数调用方会使用 home 或 routes 参数，也可以同时使用两者。home 参数相当于以下 routes 映射：

<String, WidgetBuilder>{ '/': (BuildContext context) => myWidget }

可以同时指定 home 和 routes，但前提是 routes 中不包含 '/' 条目。反过来，如果省略 home，则 routes 必须包含 '/' 条目。

如果 home 或 routes 不为 null，路由实现就需要知道如何创建 PageRoute。可通过提供 pageRouteBuilder 参数实现。MaterialApp 和 CupertinoApp 分别使用 pageRouteBuilder 创建 MaterialPageRoute 和 CupertinoPageRoute。

builder 参数用于将应用的可见内容包装在其他 Widget 中。如果应用只显示单个路由，建议使用 home，而不是 builder。

WidgetsApp 还可以通过 onGenerateRoute 和 onUnknownRoute 参数提供自定义路由实现。这两个参数分别对应 Navigator.onGenerateRoute 和 Navigator.onUnknownRoute。如果 home、routes 和 builder 均为 null，或者它们无法创建请求的路由，就会调用 onGenerateRoute。若该方法也未能处理，则会调用 onUnknownRoute。

pageRouteBuilder 用于创建包装新建路由的 PageRoute。如果 builder 不为 null 且 onGenerateRoute 参数为 null，那么 builder 只会收到 context 和 child Widget，而 pageRouteBuilder 会收到 RouteSettings。在此配置下，navigatorKey、onUnknownRoute、navigatorObservers 和 initialRoute 属性必须使用默认值，因为它们不会生效。

supportedLocales 参数必须至少包含一个元素。默认值为 [const Locale('en', 'US')]。
