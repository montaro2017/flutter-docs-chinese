home 属性

Widget? home
final

应用默认路由的组件（Navigator.defaultRouteName，即 /）。

应用正常启动时首先显示此路由，除非指定了 initialRoute。如果无法显示 initialRoute，也会显示此路由。

如果要在构造函数中设置 home 参数的代码里直接调用 Theme.of、MediaQuery.of 等方法，可以使用 Builder Widget 获取 BuildContext。

如果指定了 home，则 routes 不能包含 / 条目，因为该条目会由 home 取代。

只有在提供了路由（通过 home、routes、onGenerateRoute 或 onUnknownRoute）时，才会构建 Navigator；否则，builder 不能为 null。

home 与 builder 的区别在于，home 子树会插入到应用中 Navigator 的下方（因此也在 Overlay（由 Navigator 使用）的下方）。因此，使用 home 时，对话框会自动正常工作，会使用 routes 表，并且 Navigator.push 和 Navigator.pop 等 API 会按预期工作。相反，builder 返回的 widget 会插入到应用中的Navigator 上方（如果有）。

如果设置了此属性，也必须设置 pageRouteBuilder，这样默认路由处理器才知道应创建哪种 PageRoute。
