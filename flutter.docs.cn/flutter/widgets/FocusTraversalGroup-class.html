FocusTraversalGroup 类

用于描述后代 widget 所继承的焦点遍历策略，并将后代划分到单独遍历组中的 widget。

排序算法会将一个遍历组视为单个实体。因此，使用 OrderedTraversalPolicy 时，可用它将 widget 树中需要采用不同算法和/或排序规则的部分隔离开来。

组内元素会按照指定的 policy 排序；遍历组本身则按照父组的策略排序。

默认使用 ReadingOrderTraversalPolicy 按阅读顺序遍历。

若要阻止组内成员获得焦点，请将 descendantsAreFocusable 属性设为 false。

此示例展示三排按钮，每排都由一个 FocusTraversalGroup 分组，并使用不同的遍历顺序策略。使用 Tab 遍历可查看各项的遍历顺序：第一排按数字顺序排列；第二排按词典顺序排列（从右向左遍历）；第三排则忽略分配给它的数字顺序，改按 widget 顺序遍历。

若要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.FocusTraversalGroup.1 mysample

另请参阅：

  • FocusNode，用于了解焦点系统。
  • WidgetOrderTraversalPolicy，一种依据 widget 创建顺序确定遍历顺序的策略。
  • ReadingOrderTraversalPolicy，一种按照当前 Directionality 的自然“阅读顺序”确定遍历顺序的策略。
  • DirectionalFocusTraversalPolicyMixin，一种实现定向焦点遍历的 mixin。
