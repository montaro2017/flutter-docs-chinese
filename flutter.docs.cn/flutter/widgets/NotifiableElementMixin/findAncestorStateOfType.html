findAncestorStateOfType<T extends State<StatefulWidget>> 方法

  1. @重写
T? findAncestorStateOfType<T extends State<StatefulWidget>>()
继承

返回最近祖先中类型为给定 T 的 StatefulWidget widget 所对应的 State 对象。

不应在 build 方法中使用此方法，因为如果它返回的值发生变化，构建上下文不会重建。通常，此类情况更适合使用 dependOnInheritedWidgetOfExactType。此方法适用于一次性更改祖先 widget 的状态，例如使祖先滚动列表将当前构建上下文中的 widget 滚动到视野内，或响应用户交互移动焦点。

不过，通常应考虑使用回调来触发祖先的状态变化，而不是采用此方法隐含的命令式方式。这样通常可以解耦 widget，使代码更易维护和复用。

调用此方法的开销相对较大（与树的深度成正比）。只有在确定此组件与目标祖先之间的距离较小且有上限时，才应调用此方法。

在 State.deactivate 或 State.dispose 中不应调用此方法，因为此时 widget 树已不稳定。若需在这些方法中引用祖先，应在 State.didChangeDependencies 中调用 findAncestorStateOfType 并保存祖先引用。

实现

@override
T? findAncestorStateOfType<T extends State<StatefulWidget>>() {
  assert(_debugCheckStateIsActiveForAncestorLookup());
  Element? ancestor = _parent;
  while (ancestor != null) {
    if (ancestor is StatefulElement && ancestor.state is T) {
      break;
    }
    ancestor = ancestor._parent;
  }
  final statefulAncestor = ancestor as StatefulElement?;
  return statefulAncestor?.state as T?;
}
