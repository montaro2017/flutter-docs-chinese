unmount 方法

  1. @mustCallSuper
void unmount()
继承

从“inactive”（非活动）生命周期状态转换为“defunct”（已失效）状态。

当框架确定某个非活动 element 永远不会重新激活时调用。每个动画帧结束时，框架都会对仍处于非活动状态的元素调用 unmount，确保非活动元素不会连续超过一个动画帧。

调用此函数后，该 element 将不再被纳入组件树。

此时应释放该 element 持有的所有资源。例如，RenderObjectElement.unmount 会调用 RenderObject.dispose，并清空其对渲染对象的引用。

有关详细信息，请参阅 Element 的生命周期文档。

此方法的实现应以调用继承的方法结束，例如 super.unmount()。

实现

@mustCallSuper
void unmount() {
  assert(_lifecycleState == _ElementLifecycle.inactive);
  assert(_widget != null); // Use the private property to avoid a CastError during hot reload.
  assert(owner != null);
  assert(debugMaybeDispatchDisposed(this));
  // Use the private property to avoid a CastError during hot reload.
  final Key? key = _widget?.key;
  if (key is GlobalKey) {
    owner!._unregisterGlobalKey(key, this);
  }
  // Release resources to reduce the severity of memory leaks caused by
  // defunct, but accidentally retained Elements.
  _widget = null;
  _dependencies = null;
  _lifecycleState = _ElementLifecycle.defunct;
}
