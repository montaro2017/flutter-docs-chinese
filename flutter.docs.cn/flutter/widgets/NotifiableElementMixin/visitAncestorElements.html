继承

从此构建上下文 widget 的父级开始遍历祖先链，并对每个祖先调用传入的回调。

回调会收到祖先 widget 对应的 Element 对象引用。遍历到根 widget 或回调返回 false 时停止。回调不得返回 null。

此方法可用于检查 widget 树。

调用此方法的开销相对较大（复杂度为 O(N)，其中 N 是树的深度）。

由于此时元素树不再稳定，不应从 State.deactivate 或 State.dispose 中调用此方法。若要在这些方法中引用祖先，应在 State.didChangeDependencies 中调用 visitAncestorElements 并保存祖先引用。

实现

@override
void visitAncestorElements(ConditionalElementVisitor visitor) {
  assert(_debugCheckStateIsActiveForAncestorLookup());
  Element? ancestor = _parent;
  while (ancestor != null && visitor(ancestor)) {
    ancestor = ancestor._parent;
  }
}
