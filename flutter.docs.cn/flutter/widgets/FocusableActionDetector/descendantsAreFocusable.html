descendantsAreFocusable 属性

bool descendantsAreFocusable
final

若为 false，此组件的后代将无法获得焦点。

默认为 true。此设置不会影响此节点本身能否获得焦点（只影响其后代）；若要控制此节点，请使用 FocusNode.canRequestFocus。

如果将此值设为 false 时有后代节点正处于焦点状态，这些节点会失去焦点。再次将 descendantsAreFocusable 设为 true 时，它们不会自动重新获得焦点，但之后可以再次接受焦点。

此设置不会影响后代节点上 FocusNode.canRequestFocus 的值。

更改此值导致某个后代节点失去焦点时，焦点会移至包含此节点的作用域。

另请参阅：

  • ExcludeFocus，一种可按条件排除子树焦点的 widget。
  • descendantsAreTraversable, which makes this widget's descendants untraversable.
  • ExcludeFocusTraversal，一个会按条件排除子树焦点遍历的 widget。
  • FocusTraversalGroup，是一种用于为 widget 子树分组并配置焦点遍历策略的组件；它还提供 descendantsAreFocusable 参数，可按条件阻止整个子树获取焦点。
