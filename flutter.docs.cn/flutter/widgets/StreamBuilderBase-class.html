StreamBuilderBase<T, S> 类 抽象

根据与指定 Stream 的交互构建自身的 widget 基类。

StreamBuilderBase 是有状态的，会维护截至当前的交互摘要。摘要的类型以及每次交互后如何更新，由子类定义。

摘要示例包括：

  • 整数流的运行平均值；
  • 根据地理位置数据流计算出的当前方向和速度；
  • 显示数据流中数据点的图表。

一般而言，摘要是对从流中接收的数据项和错误进行折叠计算的结果，其中还包括表示流终止或变更的伪事件。子类通过重写 initial 指定初始摘要。收到流数据或错误后，分别通过重写 afterData 和 afterError 更新摘要。如有需要，可通过重写 afterDone 在流终止时更新摘要。最后，流发生变化时，可通过重写 afterDisconnected 和 afterConnected 更新摘要。

T 是 Stream 事件的类型。

S 是交互摘要的类型。

另请参阅：

  • StreamBuilder 专用于构建 widget 时只需使用最近一次交互结果的情况。
