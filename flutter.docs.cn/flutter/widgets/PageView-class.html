PageView 类

一种可按页面滚动的列表。

PageView 的每个子项都会被强制设为与视口相同的尺寸。

可以使用 PageController 控制视图中显示的页面。除了控制 PageView 内容的像素偏移量，PageController 还可以按页面控制偏移量；每页对应一个视口尺寸的增量。

PageController 还可以用来设置 PageController.initialPage，以决定首次创建 PageView 时显示哪个页面；也可以设置 PageController.viewportFraction，以视口尺寸的一定比例确定每页的大小。

在会话期间保留滚动位置

滚动视图会尝试使用 PageStorage 保留滚动位置。对于 PageView，可以将 PageController.keepPage 设为 false 来禁用此功能。如果启用了此功能，建议将 PageStorageKey 用作此 widget 的 key，以便区分不同的滚动视图；也可以通过 controller 访问相应的控制器。

另请参阅：

  • PageController, which controls which page is visible in the view.
  • SingleChildScrollView, when you need to make a single child scrollable.
  • ListView, for a scrollable list of boxes.
  • GridView, for a scrollable grid of boxes.
  • ScrollNotification 和 NotificationListener, which can be used to watch the scroll position without using a ScrollController.
