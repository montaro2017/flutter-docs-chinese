ImageLoadingBuilder typedef

ImageLoadingBuilder = Widget Function(BuildContext context, Widget child, ImageChunkEvent? loadingProgress)

Image.loadingBuilder 使用的函数签名，用于构建表示图像加载进度的组件。

对于逐步加载的图像（例如从本地文件系统或网络加载），如果应用希望向用户提示图像何时可显示，此构建器就很有用。

child 参数包含默认图像组件，且保证非 null。通常，此构建器会以某种方式包装 child 并返回包装后的组件。如果直接返回 child，结果与将 Image.loadingBuilder 设为 null 相同。

loadingProgress 参数包含当前图像加载进度。图像加载期间此参数非 null，但在以下情况下会为 null：

  • 组件首次渲染、尚未加载任何字节时。
  • 图像已完全加载并可供绘制时。

调用方自定义实现 ImageProvider 和 ImageStream 实例的情况非常少见，但此类实现可能会在图像帧加载完成后继续触发图像分块事件。在这种情况下，child 参数表示当前已完全加载的图像帧。

另请参阅：

  • Image.loadingBuilder, which makes use of this signature in the Image widget.
  • ImageChunkListener, a lower-level signature for listening to raw ImageChunkEvent。
