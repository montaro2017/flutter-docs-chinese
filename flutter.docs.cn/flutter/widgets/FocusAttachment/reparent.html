确保附加在此附着点上的 FocusNode 具有正确的父节点；必要时会进行更改。

如果提供了 parent 节点，则确保它是附加在此附着点上的节点之父节点；必要时会进行更改。不过，通常无需显式提供父节点，因为 reparent 会使用 Focus.of，根据 FocusNode.attach 中给定的 context 确定正确的父节点。

如果 isAttached 为 false，调用此方法不会执行任何操作。

每当关联 widget 重建时，都应调用此方法以维护焦点层级。

托管 FocusNode 的 StatefulWidget 应在 State.build 或 State.didChangeDependencies 中对所托管的节点调用此方法，以应对 widget 被移动到树中其他位置、且新位置具有不同 FocusScope 或 context 的情况。

如果不使用 Focus 和 FocusScope widget 构建焦点树，或需要显式指定父节点（这两种情况都不常见），则必须提供可选的 parent 参数。

实现

void reparent({FocusNode? parent}) {
  if (isAttached) {
    assert(_node.context != null);
    parent ??= Focus.maybeOf(_node.context!, scopeOk: true);
    parent ??= _node.context!.owner!.focusManager.rootScope;
    parent._reparent(_node);
  }
}
