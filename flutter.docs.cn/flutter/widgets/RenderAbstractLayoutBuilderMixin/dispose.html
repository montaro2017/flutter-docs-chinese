dispose 方法

  1. @mustCallSuper
void dispose()
继承

释放此渲染对象持有的所有资源。

创建 RenderObject 的对象负责释放它。如果此渲染对象直接创建了子项，也必须在此方法中释放这些子项。不得释放由其他对象（例如 RenderObjectElement）创建的子项。这些子项会在对应元素卸载时释放；如果元素被移动到树的其他部分，释放可能会延迟进行。

此方法的实现必须以调用继承的方法结束，例如 super.dispose()。

调用 dispose 后，此对象将无法继续使用。

实现

@mustCallSuper
void dispose() {
  assert(!_debugDisposed);
  assert(debugMaybeDispatchDisposed(this));
  _layerHandle.layer = null;
  assert(() {
    // TODO(dnfield): Enable this assert once clients have had a chance to
    // migrate.
    // visitChildren((RenderObject child) {
    //   assert(
    //     child.debugDisposed!,
    //     '${child.runtimeType} (child of $runtimeType) must be disposed before calling super.dispose().',
    //   );
    // });
    _debugDisposed = true;
    return true;
  }());
}
