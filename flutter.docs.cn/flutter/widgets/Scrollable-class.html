Scrollable 类

管理单轴滚动，并通知用于显示内容的 Viewport 的组件。

Scrollable 实现可滚动组件的交互模型（包括手势识别），但不规定实际用于显示子项的视口应如何构建。

直接构造 Scrollable 的情况很少。通常应考虑使用 ListView 或 GridView，它们组合了滚动、视口和布局模型。若要组合不同布局模型（或使用自定义布局模式），可以使用 CustomScrollView。

通常会使用静态函数 Scrollable.of 和 Scrollable.ensureVisible，与 ListView 或 GridView 内部的 Scrollable 组件交互。

若要进一步自定义 Scrollable 的滚动行为，可以：

  1. 提供 viewportBuilder 来自定义子项模型。例如，SingleChildScrollView 使用只显示一个 box 子项的视口，而 CustomScrollView 使用 Viewport 或 ShrinkWrappingViewport，两者都会显示 sliver 列表。

  2. 也可以提供自定义 ScrollController，以创建自定义 ScrollPosition 子类。例如，PageView 使用 PageController 创建面向页面的滚动位置子类；当 Scrollable 调整尺寸时，该子类会保持当前页面可见。

在会话期间保留滚动位置

可滚动组件会尝试使用 PageStorage 保留滚动位置。若要禁用此功能，可将 controller 上的 ScrollController.keepScrollOffset 设为 false。启用此功能时，建议将 PageStorageKey 用作此组件（或其某个祖先，例如 ScrollView）的 key，以便区分不同的 Scrollable。

另请参阅：

  • ListView, which is a commonly used ScrollView that displays a scrolling, linear list of child widgets.
  • PageView, which is a scrolling list of child widgets that are each the size of the viewport.
  • GridView, which is a ScrollView that displays a scrolling, 2D array of child widgets.
  • CustomScrollView, which is a ScrollView that creates custom scroll effects using slivers.
  • SingleChildScrollView, which is a scrollable widget that has a single child.
  • ScrollNotification 和 NotificationListener, which can be used to watch the scroll position without using a ScrollController.
