opaque 属性

bool opaque
final

此 widget 是否应阻止其视觉上后方的其他 MouseRegion 检测指针。

此设置会改变指针悬停区域的列表，从而影响这些区域的 onHover、onEnter、onExit 和 cursor 行为。

如果 opaque 为 true，此 widget 会吸收鼠标指针，并阻止其同级 widget（以及任何非此 widget 祖先或后代的其他 widget）检测鼠标指针，即使指针位于它们的区域内也是如此。

如果 opaque 为 false，此对象不会影响其后方 MouseRegion 的行为；只要指针位于这些区域内，它们仍能检测到指针。

默认值为 true。
