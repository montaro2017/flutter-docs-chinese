description

RawMenuAnchor 类

用于包裹子组件并锚定浮动菜单的组件。

子组件可以是任意组件，通常是按钮或文本字段；对于上下文菜单，也可以是整个屏幕。

调用已附加的 MenuController 上的 MenuController.open，即可显示 RawMenuAnchor 的菜单浮层。

打开 RawMenuAnchor 后，会调用 overlayBuilder，在 Overlay 中构建菜单内容。Overlay 使菜单能够浮在其他组件上方。传给 overlayBuilder 的 info 参数包含锚点的 Rect、浮层的 Size、菜单系统各成员使用的 TapRegion.groupId，以及传给 MenuController.open 的 position 参数。

如果调用 MenuController.open 时传入 position 参数，该值会传递给 overlayBuilder 函数的 info 参数。

RawMenuAnchor 不负责管理菜单的语义信息和焦点。

为菜单添加动画

从它的 API（完全不涉及 AnimationController）可以看出，RawMenuAnchor 并不了解动画；它只知道浮层当前是显示还是隐藏。

如果其他组件要实现带有打开和关闭转场的菜单，则在整个打开和关闭动画期间，RawMenuAnchor 的浮层都应保持可见。

因此，应在打开动画的第一帧之前调用传给 onOpenRequested 的 showOverlay 回调。相应地，只有在关闭动画结束后，才能在 onCloseRequested 中调用 hideOverlay。

这也意味着，如果浮层已经可见时调用 MenuController.open，RawMenuAnchor 无法判断菜单正在打开、正在关闭还是稳定显示。在这种情况下，父组件需要管理额外信息（例如 AnimationController 的状态），以决定如何响应。

要以编程方式控制 RawMenuAnchor（例如打开、关闭菜单或查询其状态），可以获取关联的 MenuController。使用 MenuController.maybeOf(BuildContext context) 可取得给定 BuildContext 最近的 RawMenuAnchor 祖先所关联的控制器。关于 MenuController 的更多用法，请参阅其类文档。
