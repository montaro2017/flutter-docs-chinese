UndoHistoryController 类

用于撤销历史记录的控制器，例如可编辑文本框的撤销控制器。

每当 UndoHistory widget 跟踪的底层值发生变化时，该 widget 都会更新 value，控制器也会通知其监听器。监听器随后可以读取 value 的 canUndo 和 canRedo 属性，以确定是否可以执行 undo 或 redo。

The controller also has undo 和 redo methods to modify the undo history.

This example creates a TextField with an UndoHistoryController which provides undo and redo buttons.
