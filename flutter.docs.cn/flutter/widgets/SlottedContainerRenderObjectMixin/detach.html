detach 方法

  1. @重写
void detach()
重写

将此渲染对象标记为已从其 PipelineOwner 分离。

通常仅由 parent 的 detach 方法调用；owner 也会调用此方法，将树的根节点标记为已分离。

带有子项的子类应重写此方法，在调用继承的方法后，将所有子项 detach，例如调用 super.detach()。

实现

@override
void detach() {
  super.detach();
  for (final ChildType child in children) {
    child.detach();
  }
}
