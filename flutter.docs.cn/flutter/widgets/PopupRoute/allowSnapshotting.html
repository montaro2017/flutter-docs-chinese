allowSnapshotting 属性

  1. @重写
bool get allowSnapshotting
重写

路由转场是否优先为进入和退出的路由制作快照并对其进行动画处理。

此值为 true 时，某些路由转场（例如 Android 缩放页面转场）会为进入和退出的路由制作快照。随后会对这些快照进行动画处理，以替代底层组件，从而提升转场性能。

通常，这意味着路由动画播放期间，进入或退出路由上的动画可能会冻结；Hero 动画或绘制在独立叠加层中的内容除外。

实现

@override
bool get allowSnapshotting => false;
