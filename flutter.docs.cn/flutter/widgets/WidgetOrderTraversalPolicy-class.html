WidgetOrderTraversalPolicy 类

一种 FocusTraversalPolicy，按照 widget 在 widget 层级中的顺序遍历焦点。

当所需顺序就是 widget 在 widget 层级中的创建顺序时，可使用此策略。

另请参阅：

  • FocusNode，用于了解焦点系统。
  • FocusTraversalGroup, 一种将其分组，并为其应用遍历策略的组件：Focus 节点（位于该组件下方的 widget 树中）。
  • ReadingOrderTraversalPolicy，一种按照当前 Directionality 的自然“阅读顺序”确定遍历顺序的策略。
  • DirectionalFocusTraversalPolicyMixin，一种实现定向焦点遍历的 mixin。
  • OrderedTraversalPolicy，一种通过 FocusTraversalOrder widget 显式指定遍历顺序的策略。
