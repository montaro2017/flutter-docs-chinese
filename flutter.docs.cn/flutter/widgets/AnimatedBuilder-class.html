AnimatedBuilder 类

用于构建动画的通用 widget。

对于希望在较大的构建函数中加入动画的复杂 widget，AnimatedBuilder 很有用。使用时，创建 AnimatedBuilder 并向其传入 builder 函数。

对于不需要额外状态的简单情况，可以考虑使用 AnimatedWidget。

尽管名称如此，AnimatedBuilder 并不局限于 Animation。任何 Listenable 子类型（例如 ChangeNotifier 或 ValueNotifier）都可用于触发重建。虽然它们的实现完全相同，但如果监听的不是 Animation，可以考虑使用 ListenableBuilder，这样代码更易读。

性能优化

如果 builder 函数包含不依赖构造函数所传入动画的子树，那么只构建该子树一次会更高效，避免每次动画更新时都重新构建。

如果通过 child 参数传入预先构建的子树，AnimatedBuilder 会将它传回 builder 函数，以便纳入构建结果。

预先构建 child 完全是可选的，但在某些情况下能显著提升性能，因此这是值得采用的做法。
