ListWheelChildLoopingListDelegate 类

通过循环使用显式列表，为 ListWheelScrollView 无限提供子项的 delegate。

ListWheelScrollView 会按需构建子项，避免创建 Viewport 中不可见的子项。此 delegate 使用显式列表提供子项，虽然方便，但会降低按需构建的优势。

通常，预先构建所有 widget 并不高效。更好的做法是创建一个按需构建子项的 delegate，例如使用 ListWheelChildBuilderDelegate，或直接继承 ListWheelChildDelegate。

当子项列表早已确定（最好子项本身是编译期常量，因此创建 delegate 时无需重新构建），或列表很短、很可能始终可见（按需构建没有收益）时，适合使用此类。例如，对话框的主体内容可能同时满足这两个条件。
