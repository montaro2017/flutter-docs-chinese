DraggableScrollableSheet 类

为 Scrollable 提供容器：响应拖动手势调整可滚动区域的大小，达到边界后再滚动内容。

此 widget 可沿垂直方向在 minChildSize 与 maxChildSize 之间拖动。两者默认值分别为 0.25 和 1.0，表示相对于父容器高度的比例。

用户沿水平方向拖动时，此 widget 会协调调整 builder 返回的 widget 的尺寸并滚动其内容。

此 widget 初始显示尺寸由 initialChildSize 指定，默认值为 0.5，即父容器高度的一半。只要 builder 创建的 widget 使用所提供的 ScrollController，面板就可以在 minChildSize 和 maxChildSize 之间（即父容器高度的相应比例）拖动。如果 ScrollableWidgetBuilder 创建的 widget 未使用所提供的 ScrollController，面板会保持在 initialChildSize。

默认情况下，widget 会停留在用户拖动到的尺寸。若要在拖动时用户抬起手指后吸附到特定尺寸，请将 snap 设为 true。面板会在 minChildSize 和 maxChildSize 之间吸附。使用 snapSizes 可添加更多吸附尺寸。

吸附效果仅适用于用户拖动。通过 DraggableScrollableController.animateTo 或 DraggableScrollableController.jumpTo 以编程方式调整面板尺寸时，会忽略 snap 和 snapSizes。

默认情况下，widget 会扩展未占用的区域以填满父级可用空间。如果不需要这样做（例如父级希望根据面板所占空间来定位它），可将 expand 属性设为 false。

这是一个示例 widget，展示了一个 ListView，其中包含 25 个 ListTile 项。初始时它占据 Scaffold 主体高度的一半，并可向上拖至 Scaffold 全高，或向下拖至其高度的 25%。到达全高后，可以滚动列表内容；当内容再次到达列表顶部时，用户可将面板向下拖回。

在桌面平台上的桌面端和 Web 环境中，默认禁用使用鼠标拖动来滚动，以符合其他桌面应用程序中的自然交互方式。

此行为由 ScrollBehavior 决定。将 PointerDeviceKind.mouse 添加到 ScrollBehavior.dragDevices. For more info on this, please refer 添加到 https://docs.flutter.dev/release/breaking-changes/default-scroll-behavior-drag

或者，此示例展示如何为桌面应用程序添加拖动手柄。
