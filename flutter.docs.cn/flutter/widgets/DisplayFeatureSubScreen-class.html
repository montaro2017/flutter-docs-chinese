DisplayFeatureSubScreen 类

将 child 放置在适当位置，避免其与会将屏幕分割为多个子屏幕的 DisplayFeature 重叠。

满足以下两个条件时，DisplayFeature 会将屏幕分割为多个子屏幕：

  • 如果它遮挡屏幕，也就是说它占据的区域不为 0，或其 state 为 DisplayFeatureState.postureHalfOpened。
  • 它至少与屏幕等高（形成左右两个子屏幕），或至少与屏幕等宽（形成上下两个子屏幕）。

确定各子屏幕后，会选择距离 anchorPoint 最近的子屏幕来渲染内容。

如果未提供 anchorPoint，则使用 Directionality：

  • 对于 TextDirection.ltr，anchorPoint 为 Offset.zero，因此内容会显示在左上方的子屏幕中。
  • 对于 TextDirection.rtl，anchorPoint 为 Offset(double.maxFinite, 0)，因此内容会显示在右上方的子屏幕中。

如果未提供 anchorPoint，且 widget 树中也没有 Directionality 祖先 widget，则在调试模式下构建此 widget 时会触发断言。

与 SafeArea 类似，此 widget 假定它与第一个 MediaQuery 祖先之间没有额外填充。它会将 child 包装在一个新的 MediaQuery 实例中，其中仅包含所选子屏幕内的 DisplayFeature，且坐标相对于该子屏幕。此 widget 还会调整填充，将其避开的边缘填充设为零。

另请参阅：

  • showDialog 可用于显示 DialogRoute。
  • showCupertinoDialog 用于显示 iOS 风格的对话框。
