didPopRoute 方法

Future<bool> didPopRoute()

系统通知应用弹出当前路由时调用，例如按下系统返回按钮或执行返回手势后。

观察者会按注册顺序收到通知，直到其中一个返回 true。如果没有观察者返回 true，应用就会退出。

如果观察者能够处理此通知（例如关闭当前对话框），应返回 true；否则返回 false。WidgetsApp widget 会使用此机制通知 Navigator widget：如果可能，应弹出当前路由。

此方法会转发 SystemChannels.navigation 发出的 popRoute 通知。

提前处理返回操作

并非所有系统返回操作都会调用此方法。有些操作完全由系统处理，不会通知 Flutter 框架。

Android API 33 及更高版本引入了预测性返回功能，用户可以在返回手势过程中预览当前应用或路由下方的界面，然后选择取消或确认返回。Flutter 会在返回手势发生前启用或禁用此功能；触发预测性返回的手势完全由系统处理，不会在框架中调用此方法。

默认情况下，框架通过 WidgetsApp 中的 SystemNavigator.setFrameworkHandlesBack 通知系统是否希望处理返回手势。系统会根据 Navigator 堆栈以及任何 PopScope widget 的状态自动设置此值。开发者也可以直接调用该方法，或使用 NavigationNotification 手动设置。

实现

Future<bool> didPopRoute() => Future<bool>.value(false);
