SliverMainAxisGroup
description

SliverMainAxisGroup 类

沿主轴依次以线性数组方式放置多个 sliver 子项的 sliver。

布局算法

本节介绍框架如何使 RenderSliverMainAxisGroup 布置其子项。

RenderSliverMainAxisGroup 的布局分为四个步骤：

  1. Keep track of an offset variable which is the total SliverGeometry.scrollExtent of the slivers laid out so far.
  2. 要确定下一个 sliver 子项的布局约束，先计算 offset 变量从 0.0 到当前位置所占用的绘制范围，并从 SliverConstraints.remainingPaintExtent 中减去该值，得到子项可用的 SliverConstraints.remainingPaintExtent。对于 SliverConstraints.scrollOffset，从传入约束的值中减去 offset 变量；如果结果为负数，则使用 0.0。
  3. 完成所有 sliver 布局后，这个 offset 变量就表示 sliver 组的 SliverGeometry.scrollExtent。由于特定 sliver 可能尝试在 sliver 组的滚动范围之外绘制（参见 SliverPersistentHeader），我们必须再进行一轮，将 SliverPhysicalParentData.paintOffset 设置为合适的值，确保它位于 sliver 组的范围内。
  4. Finally, set the RenderSliverMainAxisGroup.geometry with the total SliverGeometry.scrollExtent, SliverGeometry.paintExtent calculated from the constraints and SliverGeometry.scrollExtent, and SliverGeometry.maxPaintExtent.

In this sample the CustomScrollView renders a SliverMainAxisGroup and a SliverToBoxAdapter with some content. The SliverMainAxisGroup renders a SliverAppBar, SliverList, and SliverToBoxAdapter. Notice that when the SliverMainAxisGroup goes out of view, so does the pinned SliverAppBar.
