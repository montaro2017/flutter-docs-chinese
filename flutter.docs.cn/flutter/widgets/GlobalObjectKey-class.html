GlobalObjectKey<T extends State<StatefulWidget>> 类

其标识由作为值的对象决定的全局键。

用于将组件的标识与生成该组件所用对象的标识绑定。

为同一对象创建的任何 GlobalObjectKey 都会匹配。

如果该对象不是私有对象，不同组件可能会在树的不同部分复用同一对象作为其 GlobalObjectKey 值，从而发生冲突并导致全局键冲突。要避免此问题，请创建一个私有的 GlobalObjectKey 子类，例如：

class _MyKey extends GlobalObjectKey {
  const _MyKey(super.value);
}

键的 runtimeType 是其标识的一部分，因此即使其他 GlobalObjectKey 具有相同的值，也不会发生冲突。
