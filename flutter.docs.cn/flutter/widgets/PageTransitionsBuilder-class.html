PageTransitionsBuilder 类 抽象

为 PageRoute 定义页面转场动画。

PageTransitionsBuilder 可直接与任何设计系统中的 widget 层基础组件搭配使用。自定义 PageRoute 子类可以接收 PageTransitionsBuilder，并在重写 ModalRoute.buildTransitions 时委托给它的 buildTransitions 方法。这样便可复用转场动画，并与 Navigator 及其他导航基础组件协同工作。

用法示例

此示例展示如何创建自定义 PageTransitionsBuilder，让新页面从右侧滑入并同时淡入，以及如何将其与自定义 PageRoute 配合使用。

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.PageTransitionsBuilder.1 mysample

例如，在 Material 库中，此类由 PageTransitionsTheme 用于定义 MaterialPageRoute 的页面转场动画。应用可以配置 ThemeData.pageTransitionsTheme 的 builder 映射，以自定义不同平台上 MaterialPageRoute 的默认页面转场动画。

另请参阅：

  • PageTransitionsTheme, which uses this class to configure page transitions.
  • MaterialPageRoute, which uses this class to build its transition.
  • FadeUpwardsPageTransitionsBuilder，定义了与 Android O 所提供转场相似的页面转场。
  • OpenUpwardsPageTransitionsBuilder，定义了与 Android P 所提供转场相似的页面转场。
  • ZoomPageTransitionsBuilder，定义了与 Android Q 提供的页面转场相似的转场。
  • CupertinoPageTransitionsBuilder，定义与原生 iOS 页面转场相匹配的水平页面转场。
  • FadeForwardsPageTransitionsBuilder，定义了与 Android U 所提供转场相似的页面转场。
