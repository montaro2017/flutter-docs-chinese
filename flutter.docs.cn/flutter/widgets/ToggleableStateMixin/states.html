states 属性

Set<WidgetState> get states

描述 Toggleable 当前的 WidgetState。

返回的集合包含：

  • WidgetState.disabled 状态表示 isInteractive 为 false。
  • 指针悬停在 Toggleable 上时，状态集包含 WidgetState.hovered。
  • Toggleable 获得输入焦点时，状态集包含 WidgetState.focused。
  • WidgetState.selected 表示 value 为 true 或 null。

实现

Set<WidgetState> get states => <WidgetState>{
  if (!isInteractive) WidgetState.disabled,
  if (_hovering) WidgetState.hovered,
  if (_focused) WidgetState.focused,
  if (value ?? true) WidgetState.selected,
};
