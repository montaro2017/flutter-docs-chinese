继承

此方法会在 Widget 配置发生变化时调用。

如果父组件重建并要求此树位置更新为新的 Widget，且其 runtimeType 与 Widget.key 和原组件相同，框架会更新此 State 对象的 widget 属性，使其指向新 Widget，然后以旧 Widget 为参数调用此方法。

重写此方法以响应 widget 的变化（例如启动隐式动画）。

框架在调用 didUpdateWidget 后总会调用 build，因此在 didUpdateWidget 中调用 setState 是多余的。

如果 State 的 build 方法依赖可能自行改变状态的对象（例如 ChangeNotifier、Stream，或其他可订阅以接收通知的对象），请务必在 initState、didUpdateWidget 和 dispose 中正确订阅和取消订阅：

  • In initState, subscribe to the object.
  • In didUpdateWidget unsubscribe from the old object and subscribe to the new one if the updated widget configuration requires replacing the object.
  • In dispose, unsubscribe from the object.

实现应以调用继承的方法开始，例如 super.didUpdateWidget(oldWidget)。

有关此方法调用时机的更多信息，请参阅 Element.rebuild 的讨论。
