Container 类

一个便捷组件，可组合常见的绘制、定位和尺寸控制组件。

Container 首先在子组件周围添加 padding（并将 decoration 中已有的边框计入内边距），然后对内边距区域施加额外的 constraints（如果指定了非 null 的 width 或 height，也会将其作为约束）。最后，Container 外围会增加由 margin 描述的空白区域。

绘制时，Container 会先应用指定的 transform，然后在内边距区域绘制 decoration，接着绘制子组件，最后也在内边距区域绘制 foregroundDecoration。

没有子组件的 Container 会尽量扩展到最大尺寸；如果收到的约束没有边界，则会尽量缩小。有子组件时，Container 会根据子组件确定自身尺寸。构造函数中的 width、height 和 constraints 参数会覆盖此行为。

默认情况下，Container 的所有命中测试都会返回 false。指定 color 后，命中测试由始终返回 true 的 ColoredBox 处理。指定 decoration 或 foregroundDecoration 后，则由 Decoration.hitTest 处理。

布局行为

盒子布局模型简介请参阅 BoxConstraints。

Container 组合了多个各自具有布局行为的组件，因此 Container 的布局行为比较复杂。

摘要：Container 会依次尝试遵循 alignment、根据 child 确定自身尺寸、遵循 width、height 和 constraints、扩展以填满父组件，最后尽可能缩小。

具体来说：

如果组件没有子组件、height、width、constraints，且父组件提供无边界约束，Container 会尽量缩小。

如果组件没有子组件和 alignment，但指定了 height、width 或 constraints，Container 会根据这些约束与父组件约束的组合尽可能缩小。

如果组件没有子组件、height、width、constraints 和 alignment，但父组件提供了有边界的约束，Container 会扩展以填满父组件提供的约束范围。

如果组件设置了 alignment，而父组件提供无边界约束，则 Container 会围绕子组件确定自身尺寸。

如果组件设置了 alignment，而父组件提供有边界的约束，则 Container 会扩展以填满父组件，再按 alignment 在内部放置子组件。

其他情况下，组件有 child，但没有 height、width、constraints 或 alignment；此时 Container 会将父组件的约束传给子组件，并根据子组件确定自身尺寸。

margin 和 padding 属性也会影响布局，详情请参阅各自的说明（它们只会在上述规则基础上增加影响）。decoration 也可能隐式增加 padding（例如，BoxDecoration 中的边框会计入 padding）；参阅 Decoration.padding。

示例

此示例展示一个 48×48 的琥珀色正方形（放在 Center widget 中，以适应父 widget 对 Container 尺寸的限制），并设置外边距使其与相邻 widget 保持距离：

link 
Center(
  child: Container(
    margin: const EdgeInsets.all(10.0),
    color: Colors.amber[600],
    width: 48.0,
    height: 48.0,
  ),
)

此示例展示如何同时使用 Container 的多项功能。constraints 适应字体大小并留出垂直空间，同时水平扩展以适应父项；padding 在内容与文本之间留出间距；color 将容器设为蓝色；alignment 使 child 居中；最后，transform 让整体轻微旋转。

link 
Container(
  constraints: BoxConstraints.expand(
    height: Theme.of(context).textTheme.headlineMedium!.fontSize! * 1.1 + 200.0,
  ),
  padding: const EdgeInsets.all(8.0),
  color: Colors.blue[600],
  alignment: Alignment.center,
  transform: Matrix4.rotationZ(0.1),
  child: Text('Hello World',
    style: Theme.of(context)
        .textTheme
        .headlineMedium!
        .copyWith(color: Colors.white)),
)
