OverlayPortalController 类

用于在目标 Overlay 中显示、隐藏或将 OverlayPortal 的 overlay 子项置顶的类。

一个 OverlayPortalController 同一时间最多只能关联一个 OverlayPortal。将 OverlayPortalController 从一个 OverlayPortal 移到另一个时，其 isShowing 状态不会保留。

即使控制器尚未分配给任何 OverlayPortal，也可以调用 OverlayPortalController.show 和 OverlayPortalController.hide；但通常不应在 widget 树重建期间调用它们。
