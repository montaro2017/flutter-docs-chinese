创建一个组件，用于显示从网络获取的 ImageStream。

应指定 width 和 height 参数，或者将组件放在具有紧约束的布局环境中。否则，图像加载时尺寸会发生变化，造成不自然的布局跳动。

scale 参数指定以预期尺寸绘制此图像时使用的线性缩放因子，并同时适用于宽度和高度。例如，值为 2.0 表示每个逻辑像素对应四个图像像素；图像的实际宽高（由 dart:ui.Image.width 和 dart:ui.Image.height 属性给出）是绘制时应使用的宽高的两倍（例如传递给 Canvas.drawImage 的参数）。

所有网络图像都会被缓存，不受 HTTP 标头影响。

可以使用可选的 headers 参数，在图像请求中发送自定义 HTTP 标头。

使用 filterQuality 指定图像的渲染质量。

如果 excludeFromSemantics 为 true，则会忽略 semanticLabel。

如果提供了 cacheWidth 或 cacheHeight，引擎会据此按指定尺寸解码图像。无论这些参数为何值，图像仍会按照布局约束或 width、height 参数进行渲染。这些参数主要用于减少 ImageCache 的内存占用。

如果网络图像运行在 Web 平台上，cacheWidth 和 cacheHeight 参数会被忽略，因为 Web 引擎会将图像解码交给浏览器，而浏览器不支持自定义解码尺寸。

Web 上的同源策略

由于浏览器的跨源资源共享（CORS）限制，除非图像所在源明确允许，否则 Flutter Web 无法从托管应用的源之外获取图像。源由域名、协议或端口决定。可以通过配置图像托管服务器解决 CORS 错误。更多信息请参阅 Mozilla 对同源策略和 CORS 错误的介绍。

如果无法配置主机（例如图像托管在 CDN 上或来自任意 URL），应用可以将 Image.network 的 webHtmlElementStrategy 参数设为通过 HTML 元素显示图像，从而绕过同源策略。

HTML 元素会放置在平台视图中，因此存在以下缺点：

  • Suboptimal performance.
  • Can't be captured by screenshot widgets.
  • The headers argument must be null or empty.
  • Some image options are ignored, including opacity, colorBlendMode, repeat, filtering, and blurring.

默认情况下，此功能处于关闭状态（WebHtmlElementStrategy.never）。

Android 权限

从网络获取图像需要互联网权限。请确保所有 AndroidManifest.xml 变体（尤其是 release 版本）都声明了互联网权限。更多信息请参阅 Flutter 网络文档。

Image.network(
  String src, {
  super.key,
  double scale = 1.0,
  this.frameBuilder,
  this.loadingBuilder,
  this.errorBuilder,
  this.semanticLabel,
  this.excludeFromSemantics = false,
  this.width,
  this.height,
  this.color,
  this.opacity,
  this.colorBlendMode,
  this.fit,
  this.alignment = Alignment.center,
  this.repeat = ImageRepeat.noRepeat,
  this.centerSlice,
  this.matchTextDirection = false,
  this.gaplessPlayback = false,
  this.filterQuality = FilterQuality.medium,
  this.isAntiAlias = false,
  Map<String, String>? headers,
  int? cacheWidth,
  int? cacheHeight,
  WebHtmlElementStrategy webHtmlElementStrategy = WebHtmlElementStrategy.never,
}) : image = ResizeImage.resizeIfNeeded(
       cacheWidth,
       cacheHeight,
       NetworkImage(
         src,
         scale: scale,
         headers: headers,
         webHtmlElementStrategy: webHtmlElementStrategy,
       ),
     ),
     assert(cacheWidth == null || cacheWidth > 0),
     assert(cacheHeight == null || cacheHeight > 0);
