创建一个组件，用于显示从资源包中获取的 ImageStream。图像的键由 name 参数指定。

从 package 中显示图像时，package 参数必须非 null；否则必须为 null。详情请参阅 Assets in packages 部分。

如果省略 bundle 参数或将其设为 null，则会使用 DefaultAssetBundle。

scale 参数指定以图像预期尺寸绘制时使用的线性缩放因子，同时作用于宽度和高度。例如，若该值为 2.0，则每个逻辑像素对应四个图像像素；图像的实际宽度和高度（由 dart:ui.Image.width 和 dart:ui.Image.height 属性给出）是绘制图像时所用宽度和高度的两倍（例如传给 Canvas.drawImage 的参数）。

默认情况下，会尝试根据像素密度解析资源。此外：

  • 如果提供了 scale 参数且其值不为 null，就会使用指定的资源。若要显示特定像素密度的图片变体，必须提供准确路径（例如 images/2x/cat.png）。

如果 excludeFromSemantics 为 true，则会忽略 semanticLabel。

如果提供了 cacheWidth 或 cacheHeight，就表示应按指定尺寸解码图像。无论这些参数为何值，图像最终都会适配布局约束或 width 和 height。这些参数主要用于减少 ImageCache 的内存占用。

应同时指定 width 和 height 参数，或者将此 widget 放在具有紧约束的布局环境中。否则，图像加载时尺寸会发生变化，导致布局产生不理想的跳动。

使用 filterQuality 指定图像的渲染质量。

假设项目的 pubspec.yaml 文件包含以下内容：
link 
flutter:
  assets:
    - images/cat.png
    - images/2x/cat.png
    - images/3.5x/cat.png

在设备像素比为 2.0 的屏幕上，以下组件会渲染 images/2x/cat.png 文件：

Image.asset('images/cat.png')

这对应于项目 images/2x/ 目录中名为 cat.png 的文件（路径相对于 pubspec.yaml 文件）。

在设备像素比为 4.0 的设备上，会使用 images/3.5x/cat.png 资源；在设备像素比为 1.0 的设备上，则会使用 images/cat.png。

可以不在磁盘上提供 images/cat.png 图像（但仍须在清单中声明）。如果缺少该文件，在设备像素比为 1.0 的设备上会改用 images/2x/cat.png 图像。

package 中的资源

要使用 package 中的资源创建组件，必须提供 package 参数。例如，假设名为 my_icons 的 package 中包含 icons/heart.png。

然后可以使用以下代码显示图像：
link 
Image.asset('icons/heart.png', package: 'my_icons')

显示 package 自身使用的资源时，也应像上面一样提供 package 参数。

如果所需资源已在 package 的 pubspec.yaml 中声明，它会自动随应用打包。特别是，package 自身使用的资源必须在其 pubspec.yaml 中声明。

package 也可以选择将未在其 pubspec.yaml 中声明的资源放在 lib/ 文件夹中。若要将这些图像打包进应用，应用必须指定要包含哪些资源。例如，名为 fancy_backgrounds 的 package 可能包含：

lib/backgrounds/background1.png
lib/backgrounds/background2.png
lib/backgrounds/background3.png

例如，要包含第一张图像，应用的 pubspec.yaml 应在 assets 部分声明该资源：

  assets:
    - packages/fancy_backgrounds/backgrounds/background1.png

路径中已隐含 lib/，因此无需将其写入资源路径。

另请参阅：

  • AssetImage：用于实现未指定 scale 时的行为。
  • ExactAssetImage：用于实现指定 scale 时的行为。
  • docs.flutter.dev/ui/assets/assets-and-images：Flutter 资源使用简介。

Image.asset(
  String name, {
  super.key,
  AssetBundle? bundle,
  this.frameBuilder,
  this.errorBuilder,
  this.semanticLabel,
  this.excludeFromSemantics = false,
  double? scale,
  this.width,
  this.height,
  this.color,
  this.opacity,
  this.colorBlendMode,
  this.fit,
  this.alignment = Alignment.center,
  this.repeat = ImageRepeat.noRepeat,
  this.centerSlice,
  this.matchTextDirection = false,
  this.gaplessPlayback = false,
  this.isAntiAlias = false,
  String? package,
  this.filterQuality = FilterQuality.medium,
  int? cacheWidth,
  int? cacheHeight,
}) : image = ResizeImage.resizeIfNeeded(
       cacheWidth,
       cacheHeight,
       scale != null
           ? ExactAssetImage(name, bundle: bundle, scale: scale, package: package)
           : AssetImage(name, bundle: bundle, package: package),
     ),
     loadingBuilder = null,
     assert(cacheWidth == null || cacheWidth > 0),
     assert(cacheHeight == null || cacheHeight > 0);
