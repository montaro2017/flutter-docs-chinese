创建一个组件，用于显示从 Uint8List 获取的 ImageStream。

bytes 参数指定已编码的图像字节，可使用以下任一受支持格式编码：JPEG、PNG、GIF、动画 GIF、WebP、动画 WebP、BMP 和 WBMP。底层平台可能还支持其他格式。对于无法识别的格式，Flutter 会尝试调用平台 API 解码；如果平台 API 支持该格式，Flutter 就能渲染该图像。

scale 参数指定以预期尺寸绘制此图像时使用的线性缩放因子，并同时适用于宽度和高度。例如，值为 2.0 表示每个逻辑像素对应四个图像像素；图像的实际宽高（由 dart:ui.Image.width 和 dart:ui.Image.height 属性给出）是绘制时应使用的宽高的两倍（例如传递给 Canvas.drawImage 的参数）。

此构造函数只接受压缩图像格式（例如 PNG）。未压缩格式（如 rawRgba，即 dart:ui.Image.toByteData 的默认格式）会导致异常。

应指定 width 和 height 参数，或者将组件放在具有紧约束的布局环境中。否则，图像加载时尺寸会发生变化，造成不自然的布局跳动。

使用 filterQuality 指定图像的渲染质量。

如果 excludeFromSemantics 为 true，则会忽略 semanticLabel。

如果提供了 cacheWidth 或 cacheHeight，引擎会据此按指定尺寸解码图像。无论这些参数为何值，图像仍会按照布局约束或 width、height 参数进行渲染。这些参数主要用于减少 ImageCache 的内存占用。
