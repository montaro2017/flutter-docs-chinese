RestorableRouteFuture<T> 类

提供对 Route 对象及其返回值的访问；该路由通过 Navigator 的某个可恢复 API 方法添加。

当 State 对象需要访问自己推入 Navigator 的 Route 返回值时，RestorableRouteFuture 可确保状态恢复后仍能访问该值。

要在由 navigatorFinder 定位的 Navigator 上显示新路由，请调用 present，该方法会调用 onPresent 回调。onPresent 回调必须使用某个可恢复 API 方法，将新路由添加到传入的 Navigator 中。新路由完成后，会执行 onComplete 回调，并向其传入路由的返回值（可能为 null）。

通过 present 添加的路由显示在 Navigator 上时，可以通过 route getter 访问它。

如果属性恢复到曾调用过 present、但路由尚未完成的状态，RestorableRouteFuture 会再次从 Navigator 获取恢复后的路由对象，并在路由完成时调用 onComplete。

RestorableRouteFuture 一次只能跟踪一个活动的 route。调用 present 添加路由后，必须等该路由完成，才能再次调用 present。
