WidgetStateTextStyle
description

WidgetStateTextStyle 类 抽象

定义一个同时也是 WidgetStateProperty 的 TextStyle。

此类使具有 TextStyle 类型属性的组件也能接受 WidgetStateProperty<TextStyle> 值。状态文本样式属性表示一种取决于组件“交互状态”的文本样式。该状态由一组 Set 的 WidgetState 组成，例如 WidgetState.pressed、WidgetState.focused 和 WidgetState.hovered。

WidgetStateTextStyle 仅应与文档明确说明支持它的组件搭配使用，例如 InputDecoration.labelStyle。

可以通过以下方式之一创建 WidgetStateTextStyle：

  1. Create a subclass of WidgetStateTextStyle and implement the abstract resolve method.
  2. Use WidgetStateTextStyle.resolveWith and pass in a callback that will be used to resolve the text style in the given states.
  3. Use WidgetStateTextStyle.fromMap to assign a style using a WidgetStateMap.
