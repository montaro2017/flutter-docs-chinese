SizedBox 类

具有指定尺寸的盒子。

If given a child, this widget will try to size its child as close to the specified height 和 width as possible given the parent's constraints. If either the width or height is null, this widget will try to size itself to match the child's size in that dimension. If the child's size depends on the size of its parent, the height and width must be provided.

如果没有子项，SizedBox 会在父项约束允许的范围内，尽量采用指定的宽度和高度。如果 height 或 width 为 null 或未指定，则会按零处理。

The SizedBox.expand constructor can be used to make a SizedBox that sizes itself to fit the parent. It is equivalent to setting width 和 height to double.infinity.

此代码片段让子 widget（一个包含若干 Text 的 Card）精确采用 200×300 的尺寸，前提是父级约束允许：
link 
const SizedBox(
  width: 200.0,
  height: 300.0,
  child: Card(child: Text('Hello World!')),
)

问题排查

为什么我的 SizedBox 会被忽略？

在 Flutter 的布局协议中，约束向下传递，尺寸向上传递。widget 必须遵守父项传入的约束，因此 SizedBox 的尺寸值可能会被忽略：

此代码片段将 ColoredBox 的尺寸设为 200×200。内部 100×100 的尺寸会被忽略，因为它与父级要求精确为 200×200 的约束不兼容：
link 
const SizedBox(
  width: 200.0,
  height: 200.0,
  child: SizedBox( // Ignored!
    width: 100.0,
    height: 100.0,
    child: ColoredBox(color: Colors.green),
  ),
)

可以将子项 SizedBox 包裹在允许其尺寸不超过父项尺寸的 widget 中来解决此问题，例如 Center 或 Align。

另请参阅：

  • ConstrainedBox, 此类更通用的版本，可接受任意BoxConstraints，无需明确指定宽度和高度。
  • UnconstrainedBox，一种会尝试让子组件不受约束地绘制的容器。
  • FractionallySizedBox, a widget that sizes its child to a fraction of the total available space.
  • AspectRatio, a widget that attempts to fit within the parent's constraints while also sizing its child to match a given aspect ratio.
  • FittedBox, which sizes and positions its child widget to fit the parent according to a given BoxFit discipline.
  • The catalog of layout widgets.
  • Understanding constraints, an in-depth article about layout in Flutter.
