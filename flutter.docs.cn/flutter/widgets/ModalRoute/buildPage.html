Widget buildPage(
  1. BuildContext context,
  2. Animation<double> animation,
  3. Animation<double> secondaryAnimation
)

重写此方法以构建此路由的主要内容。

这些参数含义如下：

  • context：构建此路由时所处的上下文。
  • animation：此路由过渡动画。进入路由时，动画从 0.0 正向运行至 1.0；退出路由时，则从 1.0 反向运行至 0.0。
  • secondaryAnimation：压入此路由上方的路由所使用的动画。此动画使当前路由能够与压入其上方的路由的进入和退出过渡协调配合。

仅在首次构建路由时调用此方法，此后很少再调用。特别是，除非使用了 ModalRoute.of，否则路由状态变化时不会自动再次调用此方法。如果需要在路由状态每次变化时都调用构建器，请考虑使用 buildTransitions。如果 widget 需要在路由状态变化时改变行为，请考虑使用 ModalRoute.of 获取路由引用；这样每次路由状态变化时都会重建该 widget。

通常应使用 buildPage 构建页面内容，并使用 buildTransitions 构建页面进入或退出视图时会变化的 widget。对于不会变化的内容，不要使用 buildTransitions；在 buildPage 中一次性构建会更高效。
