Future<RoutePopDisposition> willPop()
重写

如果通过 addScopedWillPopCallback 添加的任一回调返回 false 或 null，则返回 RoutePopDisposition.doNotPop。如果它们全部返回 true，则返回基础 Route.willPop 的结果。回调按添加顺序调用，并且只有先前所有回调都返回 true 时才会调用后续回调。

通常不会重写此方法，因为应用一般不会直接创建模态路由，而是使用 showDialog 等更高级别的原语。作用域内的 WillPopCallback 列表使 ModalRoute 的后代能够共同定义 willPop 的值。

另请参阅：

  • Form, which provides an onWillPop callback that uses this mechanism.
  • addScopedWillPopCallback, which adds a callback to the list this method checks.
  • removeScopedWillPopCallback, which removes a callback from the list this method checks.

实现

@override
Future<RoutePopDisposition> willPop() async {
  final _ModalScopeState<T>? scope = _scopeKey.currentState;
  assert(scope != null);
  for (final callback in List<WillPopCallback>.of(_willPopCallbacks)) {
    if (!await callback()) {
      return RoutePopDisposition.doNotPop;
    }
  }
  return super.willPop();
}
