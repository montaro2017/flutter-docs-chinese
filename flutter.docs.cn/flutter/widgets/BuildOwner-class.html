BuildOwner 类

Widget 框架的管理类。

此类会跟踪需要重新构建的 Widget，并处理适用于整个 Widget 树的其他任务，例如管理树中的非活动 Element 列表，以及在调试模式下热重载期间按需触发“重新组装”命令。

主 BuildOwner 通常由 WidgetsBinding 持有，并与构建、布局和绘制流水线的其余部分一起由操作系统驱动。

也可以创建其他 BuildOwner 来管理屏幕外的 Widget 树。

若要为一棵树指定 BuildOwner，请在该 Widget 树的根 Element 上使用 RootElementMixin.assignOwner 方法。

此示例展示如何构建屏幕外的 Widget 树，以测量渲染后树的布局尺寸。在某些场景中，使用更简单的 Offstage Widget 可能是更好的替代方案。
