Padding 类

按照给定的内边距将子组件向内缩进的组件。

向子组件传递布局约束时，Padding 会根据给定的内边距缩小约束，使子组件以更小的尺寸布局。随后 Padding 会根据子组件尺寸加上内边距确定自身尺寸，从而在子组件周围形成空白区域。

此示例会在 Card 内创建一个四周各缩进十六像素的“Hello World!” Text。

link 
const Card(
  child: Padding(
    padding: EdgeInsets.all(16.0),
    child: Text('Hello World!'),
  ),
)

设计讨论

为什么使用 Padding，而不是使用带 Container.padding 属性的 Container？

两者基本没有区别。提供 Container.padding 参数时，Container 会为你构建一个 Padding 组件。

Container 不会直接实现自身属性，而是将多个简单组件组合成便捷的整体。例如，Container 的 Container.padding 属性会使 Container 构建 Padding 组件，Container.decoration 属性则会使它构建 DecoratedBox 组件。如果觉得 Container 使用方便，就可以继续使用；否则也可以按需求任意组合这些更简单的组件。

事实上，Flutter 中大多数组件都是由其他简单组件组合而成的。构建组件主要依靠组合，而不是继承。

  • AnimatedPadding, which animates changes in padding over a given duration.
  • SliverPadding, the sliver equivalent of this widget.
