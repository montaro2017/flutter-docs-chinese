precacheImage function

Future<void> precacheImage(
  1. ImageProvider<Object> provider,
  2. BuildContext context, {
  3. Size? size,

将图像预加载到图像缓存中。

返回一个 Future；当 ImageProvider 提供的第一张图像可用或加载失败时，该 Future 会完成。

之后如果 Image、BoxDecoration 或 FadeInImage 使用该图像，加载速度可能会更快。使用图像的组件不必使用同一个 ImageProvider 实例。只要两个图像的键相同且图像仍保留在缓存中，ImageCache 就能找到该图像。

如果缓存已禁用、图像过大，或自定义 ImageCache 实现的其他条件不满足，缓存可能会拒绝保留该图像。

只要图像对应的 ImageStreamCompleter 至少有一个监听器，ImageCache 就会保留传递给 ImageCache.putIfAbsent 的所有图像。此方法返回的 future 完成后，还会等到当前帧结束才移除自身的监听器，以便调用方在需要时监听该流。调用方可以使用 ImageProvider.obtainCacheStatus 确认图像是否进入缓存。如果图像只以 ImageCacheStatus.live 状态保留，而调用方希望让已解析的图像继续驻留在内存中，应立即调用 provider.resolve，并为返回的 ImageStream 添加监听器。即使图像原本无法放入缓存，在调用方移除该流的监听器之前，图像也至少会一直固定在内存中。

调用方应谨慎将大型图像或大量图像固定在内存中，否则可能耗尽内存并被操作系统终止。可用物理内存越少，出现内存不足问题的风险越高。这类问题会导致进程立即退出，有时不会显示其他错误消息。

The BuildContext 和 Size are used to select an image configuration (see createLocalImageConfiguration).

即使预加载失败，返回的 future 也不会以错误状态完成。可以使用 onError 参数手动处理预加载过程中的错误。

另请参阅：

  • ImageCache, which holds images that may be reused.

实现

Future<void> precacheImage(
  ImageProvider provider,
  BuildContext context, {
  Size? size,
  ImageErrorListener? onError,
}) {
  final ImageConfiguration config = createLocalImageConfiguration(context, size: size);
  final completer = Completer<void>();
  final ImageStream stream = provider.resolve(config);
  ImageStreamListener? listener;
  listener = ImageStreamListener(
    (ImageInfo? image, bool sync) {
      if (!completer.isCompleted) {
        completer.complete();
      }
      // Give callers until at least the end of the frame to subscribe to the
      // image stream.
      // See ImageCache._liveImages
      SchedulerBinding.instance.addPostFrameCallback((Duration timeStamp) {
        image?.dispose();
        stream.removeListener(listener!);
      }, debugLabel: 'precacheImage.removeListener');
    },
    onError: (Object exception, StackTrace? stackTrace) {
      if (!completer.isCompleted) {
        completer.complete();
      }
      stream.removeListener(listener!);
      if (onError != null) {
        onError(exception, stackTrace);
      } else {
        FlutterError.reportError(
          FlutterErrorDetails(
            context: ErrorDescription('image failed to precache'),
            library: 'image resource service',
            exception: exception,
            stack: stackTrace,
            silent: true,
          ),
        );
      }
    },
  );
  stream.addListener(listener);
  return completer.future;
}
