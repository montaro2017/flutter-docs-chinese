WidgetStateMouseCursor 类 抽象

定义一个 MouseCursor，其值取决于一组 WidgetState；这些状态表示组件的交互状态。

当组件支持的交互操作会随状态变化时，这类 MouseCursor 很有用。例如，鼠标悬停在已禁用的 ListTile 上时，不应显示 SystemMouseCursors.click，因为禁用的列表项不会响应鼠标点击。ListTile 默认使用 WidgetStateMouseCursor.clickable；按钮禁用时，它会解析为 SystemMouseCursors.basic。

此类仅应用于文档明确说明支持 WidgetStateMouseCursor 的参数。

可以通过以下方式之一创建 WidgetStateMouseCursor：

  1. Create a subclass of WidgetStateMouseCursor and implement the abstract resolve method.
  2. 使用 WidgetStateMouseCursor.resolveWith 并传入回调，以便根据给定状态解析相应值。
  3. Use WidgetStateMouseCursor.fromMap to assign a value using a WidgetStateMap.

This example defines a mouse cursor that resolves to SystemMouseCursors.forbidden when its widget is disabled.
