RenderSliverOverlapAbsorber
description

RenderSliverOverlapAbsorber 类

包裹另一个 sliver，并强制将其布局范围视为重叠部分的 sliver。

子级 sliver 请求的重叠量与此 widget 报告的重叠量之间的差值称为已吸收重叠量，并会报告给 SliverOverlapAbsorberHandle。该句柄通常会传递给 RenderSliverOverlapInjector。

构造函数

RenderSliverOverlapAbsorber({required SliverOverlapAbsorberHandle handle, RenderSliver? sliver})
创建一个会吸收重叠区域并将其报告给 SliverOverlapAbsorberHandle 的 sliver。
