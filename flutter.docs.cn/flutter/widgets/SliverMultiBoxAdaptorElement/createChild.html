重写

布局期间需要新子项时调用。子项应插入到子项列表中的适当位置，即位于 after 子项之后（若 after 为 null，则插入列表开头）。其索引和滚动偏移量会自动设置为适当值。

index 参数表示要显示的子项索引。请求负数索引也是可能的。例如，用户从子项 0 滚动到子项 10 后，如果这些子项变得小得多，用户再向上滚动，此方法最终可能会收到请求，需要为索引 -1 创建子项。

如果索引 index 没有对应的子项，则不执行任何操作。

索引 0 对应哪个子项，取决于 RenderSliverMultiBoxAdaptor 的 constraints 中指定的 GrowthDirection。例如，若子项是字母表，且 SliverConstraints.growthDirection 为 GrowthDirection.forward，则索引 0 对应 A，索引 25 对应 Z。反之，若 SliverConstraints.growthDirection 为 GrowthDirection.reverse，则索引 0 对应 Z，索引 25 对应 A。

调用 createChild 期间，如果其他子项并非在本帧创建，且尚未在本帧更新，则可以将它们从 RenderSliverMultiBoxAdaptor 对象中移除。此时不能向该渲染对象添加其他子项。

实现

@override
void createChild(int index, {required RenderBox? after}) {
  assert(_currentlyUpdatingChildIndex == null);
  owner!.buildScope(this, () {
    final insertFirst = after == null;
    assert(insertFirst || _childElements[index - 1] != null);
    _currentBeforeChild = insertFirst
        ? null
        : (_childElements[index - 1]!.renderObject as RenderBox?);
    Element? newChild;
    try {
      final adaptorWidget = widget as SliverMultiBoxAdaptorWidget;
      _currentlyUpdatingChildIndex = index;
      newChild = updateChild(_childElements[index], _build(index, adaptorWidget), index);
    } finally {
      _currentlyUpdatingChildIndex = null;
    }
    if (newChild != null) {
      _childElements[index] = newChild;
    } else {
      _childElements.remove(index);
    }
  });
}
