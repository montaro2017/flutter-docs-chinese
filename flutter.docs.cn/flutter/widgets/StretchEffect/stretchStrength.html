stretchStrength 属性

double stretchStrength
final

拉伸效果使用的过度滚动强度。

取值应在 -1.0 到 1.0 之间，且包含这两个边界值。

对于水平方向：

  • 正值会产生从左向右的拉动，1.0 表示向右的最大拉伸幅度。
  • 负值会产生从右向左的拉动，-1.0 表示向左的最大拉伸幅度。

对于垂直方向：

  • 正值会产生从上向下的拉动，1.0 表示向下的最大拉伸幅度。
  • 负值会产生从下向上的拉动，-1.0 表示向上的最大拉伸幅度。

此示例展示如何将水平拉伸强度设为向右拉动。
link 
const StretchEffect(
  stretchStrength: 0.5,
  axis: Axis.horizontal,
  child: Text('Hello, World!'),
);
