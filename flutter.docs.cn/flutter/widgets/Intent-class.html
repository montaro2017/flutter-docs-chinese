Intent

Intent 类 抽象

表示 Action 特定配置的抽象类。

Shortcuts.shortcuts 映射表以此类对象作为值。ActionDispatcher 会使用它查找并调用操作，并将此对象传入，以提取配置信息。

另请参阅：

  • Shortcuts, a widget used to bind key combinations to Intent。
  • Actions, a widget used to map Intents to Action。
  • Actions.invoke, which invokes the action associated with a specified Intent using the Actions widget that most tightly encloses the given BuildContext.
