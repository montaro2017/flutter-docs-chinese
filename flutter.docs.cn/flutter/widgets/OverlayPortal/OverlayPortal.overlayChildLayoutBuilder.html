创建一个 OverlayPortal：调用 OverlayPortalController.show 时，它会将 overlayChildBuilder 构建的 widget 绘制到最近的 Overlay 上。

开发者可以根据目标 Overlay 中 OverlayPortal.child 的尺寸和位置，以及 Overlay 本身的尺寸，通过 overlayChildBuilder 配置 overlay 子项。例如，可以让 overlay 子项始终跟随 OverlayPortal.child，同时根据它与 Overlay 边缘的距离调整自身大小。

overlayChildBuilder 回调会在布局期间调用。为确保届时 OverlayPortal.child 相对于目标 Overlay 的绘制变换是最新的，从 OverlayPortal 到目标 Overlay 之间的所有 RenderObject 都必须在布局阶段建立其绘制变换；大多数 RenderObject 都会这样做。一个例外是 CompositedTransformFollower widget，它的 RenderObject 只有在合成阶段才会建立绘制变换。如果在 OverlayPortal 与 Overlay 之间放置 CompositedTransformFollower，传给 overlayChildBuilder 的子项绘制变换可能不正确，并会在调试模式下触发断言。

overlayLocation 用于指定此 widget 将 overlayChildBuilder 返回的 widget 附加到哪个 Overlay。默认值为 OverlayChildLocation.nearestOverlay。
