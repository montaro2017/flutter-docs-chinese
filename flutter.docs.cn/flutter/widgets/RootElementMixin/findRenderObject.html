findRenderObject 方法

  1. @重写
RenderObject? findRenderObject()
继承

此组件当前的 RenderObject。如果组件是 RenderObjectWidget，则返回它为自身创建的渲染对象；否则返回第一个后代 RenderObjectWidget 的渲染对象。

只有构建阶段完成后，此方法才会返回有效结果，因此不能在 build 方法中调用。只能在交互事件处理程序（例如手势回调）、布局回调或绘制回调中调用。如果 State.mounted 返回 false，也不能调用此方法。

如果渲染对象是常见的 RenderBox，可以通过 size getter 获取其尺寸。此操作只有布局阶段完成后才有效，因此应仅在绘制回调或交互事件处理程序（例如手势回调）中执行。

有关一帧中各个阶段的详情，请参见 WidgetsBinding.drawFrame 中的说明。

从理论上说，此方法的开销相对较高（与树的深度 N 成正比）；但实际上通常开销很小，因为树中一般有许多渲染对象，因此到最近渲染对象的距离通常很短。

实现

@override
RenderObject? findRenderObject() {
  assert(() {
    if (_lifecycleState != _ElementLifecycle.active) {
      throw FlutterError.fromParts(<DiagnosticsNode>[
        ErrorSummary('Cannot get renderObject of inactive element.'),
        ErrorDescription(
          'In order for an element to have a valid renderObject, it must be '
          'active, which means it is part of the tree.\n'
          'Instead, this element is in the $_lifecycleState state.\n'
          'If you called this method from a State object, consider guarding '
          'it with State.mounted.',
        ),
        describeElement('The findRenderObject() method was called for the following element'),
      ]);
    }
    return true;
  }());
  return renderObject;
}
