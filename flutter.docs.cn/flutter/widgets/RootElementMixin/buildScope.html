buildScope 属性

BuildScope get buildScope
继承

一个 BuildScope。其中的脏 Element 只能通过调用 BuildOwner.buildScope 重建，并且该调用的 context 参数必须是此 Element 内的 BuildScope。

通常只有在此 Element 已 mounted 时，才能安全地访问此 getter。

默认实现返回父级 Element 的 buildScope。大多数情况下，只要某个 Element 的祖先不再处于脏状态，该元素就可以重建。一个明显例外是 LayoutBuilder 的后代：在传入约束可用之前，它们不能重建。LayoutBuilder 的 Element 会重写 buildScope，确保在获知传入约束之前，不重建其任何后代。

If you choose to override this getter to establish your own BuildScope, to flush the dirty Elements in the BuildScope you need to manually call BuildOwner.buildScope with the root Element of your BuildScope when appropriate, as the Flutter framework does not try to register or manage custom BuildScope。

如果重写此 getter，始终应返回同一个 BuildScope 实例。运行时更改 getter 的返回值是不受支持的。

updateChild 方法会忽略 buildScope：如果父级 Element 使用不同的 BuildScope 调用 updateChild 更新子节点，该子节点仍可能重建。

另请参阅：

  • LayoutBuilder, a widget that establishes a custom BuildScope.

实现

BuildScope get buildScope => _parentBuildScope!;
