继承

从组件树中移除此对象时调用。

每当框架从树中移除此 State 对象时，都会调用此方法。在某些情况下，框架会将 State 对象重新插入树中的其他位置（例如，包含此 State 的子树因使用 GlobalKey 而从树中的一个位置移动到另一个位置）。发生这种情况时，框架会调用 activate，让 State 对象有机会重新获取它在 deactivate 中释放的资源。随后还会调用 build，使 State 对象能适应树中的新位置。如果框架确实重新插入该子树，会在移除该子树的动画帧结束前完成。因此，State 对象可以等到框架调用其 dispose 方法时，再释放大多数资源。

子类应重写此方法，清理此对象与树中其他元素之间的所有引用（例如，当祖先持有指向后代 RenderObject 的指针时）。

实现应以调用继承的方法结束，例如 super.deactivate()。

另请参阅：

  • dispose，如果 widget 被永久移出树，则会在 deactivate 后调用。
