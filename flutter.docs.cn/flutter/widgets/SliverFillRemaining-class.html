description

SliverFillRemaining 类

一种包含单个盒子子项的 sliver，该子项会填满视口中的剩余空间。

关于 sliver 的更多信息，请参阅 CustomScrollView.slivers。

SliverFillRemaining 会将其 child 调整为填满视口的交叉轴空间。sliver 在主轴上的范围以及其子项在主轴上的尺寸会根据条件计算，详情见下文。

通常它会是视口中的最后一个 sliver，因为按定义，此 sliver 后面不会再有空间容纳其他内容。

主轴范围

当 SliverFillRemaining 包含可滚动子项时

hasScrollBody 标志表示 sliver 的子项是否包含可滚动主体。此值永远不会为 null，默认值为 true。常见示例是 NestedScrollView。在这种情况下，sliver 会将子项调整为填满最大可用范围。SliverFillRemaining 不会限制可滚动区域，因为该区域可能无限延伸。ScrollView 的 ScrollView.shrinkWrap 为 true 时也同样如此。

当 SliverFillRemaining 不包含可滚动子项时

当 hasScrollBody 设为 false 时，计算填充空间的范围会考虑子项的尺寸。决定如何布局此 sliver 时，也会考虑前面的 sliver 已滚动的距离。

如果剩余空间大于子项的范围，且此前的滚动距离未超过视口主轴范围，SliverFillRemaining 会将其 child 调整为填满视口的主轴空间。

此示例中，SliverFillRemaining 会将其 child 调整为填满视口两个轴向上的剩余范围。图标在 sliver 中居中显示，无论 sliver 的范围如何计算，图标都会保持居中。

如果 SliverFillRemaining 的 child 尺寸超过视口中的剩余空间，它会采用子项本身的尺寸。

此示例中，SliverFillRemaining 采用其 child 的尺寸，因为子项范围超过视口主轴的剩余范围。

此示例中，SliverFillRemaining 采用其 child 的尺寸，因为 SliverConstraints.precedingScrollExtent 已超过视口主轴的范围。

对于允许过度滚动的 ScrollPhysics（例如 BouncingScrollPhysics），将 fillOverscroll 标志设为 true，可让 child 尺寸拉伸以填充过度滚动区域。无论采用哪种方式确定子项尺寸，此行为都会生效。

此示例中，当 fillOverscroll 为 true 时，SliverFillRemaining 的子项会拉伸以填满过度滚动区域。示例还包含一个固定在 sliver 底部的按钮，不受尺寸或过度滚动行为影响。切换 fillOverscroll 即可查看差异。

此示例仅展示支持过度滚动的设备上的过度滚动行为。
