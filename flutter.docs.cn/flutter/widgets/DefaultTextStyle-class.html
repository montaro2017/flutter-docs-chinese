DefaultTextStyle 类

应用于后代 Text widget 的文本样式；当它们没有显式指定样式时使用。

Text widget 的 MediaQuery 祖先仍可能通过 MediaQueryData.lineHeightScaleFactorOverride、MediaQueryData.letterSpacingOverride 和 MediaQueryData.wordSpacingOverride 成员，覆盖此 DefaultTextStyle widget 所设置 TextStyle 的 TextStyle.height、TextStyle.letterSpacing 和 TextStyle.wordSpacing。

此示例展示如何使用 DefaultTextStyle.merge，继承当前默认文本样式的信息并覆盖其中部分属性，从而创建新的默认文本样式。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.DefaultTextStyle.1 mysample

另请参阅：

  • AnimatedDefaultTextStyle, which animates changes in the text style smoothly over a given duration.
  • DefaultTextStyleTransition, which takes a provided Animation to animate changes in text style smoothly over time.
