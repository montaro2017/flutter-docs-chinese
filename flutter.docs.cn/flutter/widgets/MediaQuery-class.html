MediaQuery 类

建立一个子树，使其中的媒体查询返回给定数据。

例如，若要获取当前视图（如包含应用的 FlutterView）的大小，可以使用 MediaQuery.sizeOf：MediaQuery.sizeOf(context)。

使用特定方法查询当前媒体信息（例如 MediaQuery.sizeOf 或 MediaQuery.paddingOf）时，只要对应属性发生变化，组件就会自动重建。

使用 MediaQuery.of 查询时，只要 MediaQueryData 的任意字段发生变化（例如用户旋转设备），组件就会自动重建。因此，除非需要关注整个 MediaQueryData 对象的变化，否则应优先使用特定方法（例如 MediaQuery.sizeOf 和 MediaQuery.paddingOf），这样重建效率更高。

如果作用域内没有 MediaQuery，调用 MediaQuery.of 和类似 MediaQuery.sizeOf 的“...Of”方法会抛出异常。也可以使用“maybe-”变体方法（例如 MediaQuery.maybeOf 和 MediaQuery.maybeSizeOf）；当作用域内没有 MediaQuery 时，这些方法会返回 null，而不是抛出异常。

另请参阅：

  • WidgetsApp 和 MaterialApp, which introduce a MediaQuery and keep it up to date with the current screen metrics as they change.
  • MediaQueryData, the data structure that represents the metrics.
