TreeSliverController 类

用于控制 TreeSliver 中的 TreeSliverNode。

例如，系统事件发生时，可以通过编程方式展开或折叠树节点，从而重新配置现有节点。为此，可以创建一个带有 TreeSliverController 的 TreeSliver，并让有状态 widget 持有该控制器；也可以通过 TreeSliverController.of 查找树自动创建的 TreeSliverController。

控制器的展开或折叠方法会导致 TreeSliver 重建，因此不能在 build 方法中调用。
