DeviceOrientationBuilder 类

构建一个可根据设备方向确定布局的 widget 树。

设备方向通过 MediaQuery.orientationOf 获取，该值反映平台报告的实际设备方向。这可确保其与 MediaQueryData.orientation 保持一致，并在可折叠设备以及设备方向可能与布局尺寸不同的其他场景中正确工作。

这与 OrientationBuilder 不同：后者根据父级 widget 的布局约束（宽度与高度）确定方向，而不是根据设备的物理方向。

此示例展示如何使用 DeviceOrientationBuilder 根据设备方向显示不同的 widget。
link 
DeviceOrientationBuilder(
  builder: (BuildContext context, Orientation orientation) {
    return Text(orientation == Orientation.portrait
        ? 'Device is in Portrait'
        : 'Device is in Landscape');
  },
)

此 widget 需要 MediaQuery 祖先节点来获取设备方向。通常由 MaterialApp 或 WidgetsApp 提供。

另请参阅：

  • OrientationBuilder, which builds based on parent widget's layout constraints rather than device orientation.
  • MediaQueryData.orientation, which provides the device orientation directly from MediaQuery.
  • LayoutBuilder, which exposes the complete layout constraints.
