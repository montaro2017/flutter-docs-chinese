SnapshotController 类

用于控制 SnapshotWidget 的控制器，可决定何时显示子级图像以及何时重新生成子级图像。

当 allowSnapshotting 为 true 时，SnapshotWidget 会根据自身的 SnapshotMode 绘制子 widget。

allowSnapshotting 的值发生变化或调用 clear 时，控制器会通知其监听器。

要强制 SnapshotWidget 重新创建子级图像，请调用 clear。
