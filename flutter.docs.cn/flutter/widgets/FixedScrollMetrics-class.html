FixedScrollMetrics 类

与 Scrollable 视口相关的一组不可变值的快照。

详情请参阅定义此对象接口的 ScrollMetrics。

此示例展示了调整 Viewport 大小导致 ScrollMetrics 变化时，如何派发 ScrollMetricsNotification。按下悬浮操作按钮可增大可滚动窗口。
link

若要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.FixedScrollMetrics.1 mysample
