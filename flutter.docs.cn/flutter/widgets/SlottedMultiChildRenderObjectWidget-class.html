SlottedMultiChildRenderObjectWidget<SlotType, ChildType extends RenderObject> 类 抽象

为按不同插槽组织子级的 RenderObjectWidget 子类提供配置的基类，这些子类会配置 RenderObject 子类。

此 mixin 的实现者必须通过重写 slots 提供可用插槽列表。对于实现此 mixin 的给定类，插槽列表必须始终保持不变。常见做法是使用 Enum 值作为插槽，并让 slots 返回该枚举的 values getter 所返回的值。

此外，必须实现 childForSlot，以返回给定插槽当前对应的 widget 配置。

由 createRenderObject 返回并由 updateRenderObject 更新的 RenderObject 必须实现 SlottedContainerRenderObjectMixin。

类型参数 SlotType 是此 RenderObjectWidget 及其所配置的 RenderObject 所使用的插槽类型。通常，SlotType 是 Enum 类型。

类型参数 ChildType 是 RenderObject 子级的类型（例如 RenderBox 或 RenderSliver）。通常，ChildType 为 RenderBox。此类不支持不同插槽使用不同类型的子级。

This example uses the SlottedMultiChildRenderObjectWidget in combination with the SlottedContainerRenderObjectMixin to implement a widget that provides two slots: topLeft and bottomRight. The widget arranges the children in those slots diagonally.
