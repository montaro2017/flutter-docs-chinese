根据显式提供的 widget List，创建一个逐页滚动的可滚动列表。

此构造函数适用于子项数量较少的页面视图，因为创建该 List 时，需要处理页面视图中所有可能显示的子项，而不仅是当前可见的子项。

与框架中的其他 widget 一样，此 widget 要求传入后不再修改 children 列表。更多信息请参阅 SliverChildListDelegate.children 文档。

如果 allowImplicitScrolling 为 true，PageView 参与辅助功能滚动的方式会更像 ListView：隐式滚动操作会移至下一页，而不是滚入 PageView 的内容区域。

  super.key,
  this.scrollDirection = Axis.horizontal,
  this.reverse = false,
  this.controller,
  this.physics,
  this.pageSnapping = true,

  this.clipBehavior = Clip.hardEdge,
  this.hitTestBehavior = HitTestBehavior.opaque,
  this.scrollBehavior,
  this.padEnds = true,
}) : assert(
       scrollCacheExtent == null || (scrollCacheExtent.value > 0.0) == allowImplicitScrolling,

       'scrollCacheExtent must be greater than 0.0 when allowImplicitScrolling is true, '
       'and must be 0.0 when allowImplicitScrolling is false.',
     ),
     scrollCacheExtent =
         scrollCacheExtent ?? ScrollCacheExtent.viewport(allowImplicitScrolling ? 1.0 : 0.0),
