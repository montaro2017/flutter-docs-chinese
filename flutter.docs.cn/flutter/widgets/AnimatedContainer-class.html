AnimatedContainer 类

Container 的动画版本，会在一段时间内逐渐改变自身属性值。

属性值发生变化时，AnimatedContainer 会使用给定的曲线和时长，在旧值与新值之间自动添加动画。值为 null 的属性不会产生动画。其子级及后代不会添加动画。

此类适合通过其内部的 AnimationController，在 Container 的不同参数之间创建简单的隐式过渡。对于更复杂的动画，通常应使用 DecoratedBoxTransition 等 AnimatedWidget 子类，或自行使用 AnimationController。

下方示例展示了图中效果：点击时，AnimatedContainer 会在两种状态之间过渡，并调整 height、width、color 和 alignment 属性。
