RawAutocomplete<T extends Object> 类

帮助用户通过输入文本并从选项列表中选择内容来完成选择的组件。

用户输入的文本由 fieldViewBuilder 参数构建的字段接收。要显示的选项由 optionsBuilder 确定，并由 optionsViewBuilder 构建。

字段获得焦点或文本发生变化时，只要 optionsBuilder 至少返回一个选项，就会打开选项视图。用户选中选项、没有匹配选项或字段失去焦点时，选项视图会关闭。

这是框架提供的基础组件，界面非常简单。

此示例展示如何使用 fieldViewBuilder 和 optionsViewBuilder 参数创建一个非常基础的自动补全组件。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.RawAutocomplete.1 mysample

The type parameter T represents the type of the options. Most commonly this is a String, as in the example above. However, it's also possible to use another type with a toString method, or a custom displayStringForOption. Options will be compared using ==, so it may be beneficial to override Object.== 和 Object.hashCode for custom types.

此示例与前一个示例类似，但使用自定义 T 数据类型，而不是直接使用 String。
