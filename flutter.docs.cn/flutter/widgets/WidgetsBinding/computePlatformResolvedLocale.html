computePlatformResolvedLocale 方法

Locale? computePlatformResolvedLocale(
  1. List<Locale> supportedLocales
)

计算当前平台会解析出的语言区域。

此方法旨在作为 WidgetsApp.localeListResolutionCallback 的一部分使用。由于此方法可能返回 null，因此仍应提供 Flutter/Dart 算法作为后备，以应对无法确定原生解析语言区域或原生解析结果不符合预期的情况。

如果平台不支持原生语言区域解析，或解析失败，此方法可能返回 null Locale。

第一个 supportedLocale 会被视为默认语言区域；如果找不到更合适的匹配项，就会返回它。

目前支持 Android 和 iOS。

在 Android 上，使用 https://developer.android.com/guide/topics/resources/multilingual-support 中所述的算法确定解析后的语言区域。具体使用现代算法（API 24 及以上）还是旧版算法（低于 API 24），取决于设备的 Android 版本。

在 iOS 上，此方法返回 NSBundle 的 preferredLocalizationsFromArray 方法的结果。关于所用方法的详细信息，请参阅：https://developer.apple.com/documentation/foundation/nsbundle/1417249-preferredlocalizationsfromarray?language=objc。

iOS 将脚本代码视为匹配所必需的条件，因此用户首选语言区域为 zh_Hans_CN 时，不会匹配到受支持的 zh_CN。

由于此方法的实现可能因平台而异，而且开销可能较大，如果需要多次使用其结果，建议缓存结果。

如需获得次优及其他候选匹配语言区域，可以再次调用此方法，并从 supportedLocales 中排除第一次调用所匹配的语言区域。

实现

Locale? computePlatformResolvedLocale(List<Locale> supportedLocales) {
  return platformDispatcher.computePlatformResolvedLocale(supportedLocales);
}
