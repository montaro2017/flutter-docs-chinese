根据当前环境，为给定的 RenderView 返回相应的 ViewConfiguration。

添加 addRenderView 时会调用此方法；系统尺寸变化时也会调用它，以更新已添加到 binding 的所有 renderViews。

Binding 可以覆盖此方法，以更改 RenderView 使用的尺寸或设备像素比。例如，测试框架会在设备上通过 flutter run 运行测试时，使用此方法将显示尺寸强制设为 800x600。

实现

@protected
ViewConfiguration createViewConfigurationFor(RenderView renderView) {
  return ViewConfiguration.fromView(renderView.flutterView);
}
