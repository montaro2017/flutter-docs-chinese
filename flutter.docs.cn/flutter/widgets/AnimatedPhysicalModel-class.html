AnimatedPhysicalModel 类

PhysicalModel 的动画版本。

borderRadius 和 elevation 会添加动画。

如果设置了 animateColor 属性，color 会添加动画；否则，color 会在另外两个属性的动画开始时立即改变。这样可以单独为 color 添加动画（例如由 AnimatedTheme 驱动颜色变化）。

shape 不会添加动画。

下图展示了此 widget 的效果，使用的 curve 为 Curves.fastOutSlowIn。
