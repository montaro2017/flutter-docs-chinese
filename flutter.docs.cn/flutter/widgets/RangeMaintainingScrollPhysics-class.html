RangeMaintainingScrollPhysics 类

当内容尺寸突然变化时，尝试使滚动位置保持在有效范围内的滚动物理效果。

如果滚动位置已经超出范围，且滚动边界缩小（意味着部分内容被移除），此效果会尝试保留已有的过度滚动或滚动不足量。设置这一条件的原因是：添加新内容时，若仍保留相同的过度滚动量，新增内容就会被直接跳过，滚动位置会一下跳到最大边界，用户无法看到它们。

如果滚动活动正在为滚动位置播放动画，则允许滚动尺寸突然变化，以避免动画在范围内和范围外的数值之间来回跳动。

此物理效果应与其他滚动物理效果组合使用，例如 BouncingScrollPhysics 或 ClampingScrollPhysics，以完整描述常见的滚动行为。请参阅 applyTo。

实现细节

具体来说，此物理效果会进行两项调整。

第一项是在位置超出范围时保留过度滚动量。

第二项是在位置处于范围内时强制执行边界约束。

如果当前速度不为零，则不会进行这两项调整。这里假定动画仍在进行，因此进一步更改滚动位置会破坏交互体验。

如果滚动边界没有变化，则不会调整过度滚动量。这里假定：如果位置处于过度滚动状态，那就是有意如此，否则它不可能到达该位置。（例如，可以对比 ClampingScrollPhysics 与 BouncingScrollPhysics。）

如果滚动位置自上一动画帧以来发生了变化，则不会保留过度滚动量。其假设与上一种情况类似：除非有意为之，否则滚动位置不会被置于有效范围之外。

此外，如果滚动位置发生变化，且边界在变化前后均为有限值，也不会强制执行边界约束，原因相同。不过，只要任一边界在变化前或变化后为无限值，就会强制执行边界约束。这里假定无限边界表示这是一个延迟加载的滚动视图；在完整列表尚未加载时，它无法执行边界约束。

如果滚动位置原本超出范围，即使没有保留超出量，也不会强制执行边界约束。如果保留了超出量，则会将旧位置与旧边界之间的距离应用到新边界上，以得到新位置。

如果滚动位置原本处于范围内，且需要强制执行边界约束，则先将新位置交由其他物理效果（如果有）处理，再将其限制在新的有效范围内。
