AutomaticKeepAliveClientMixin<T extends StatefulWidget> mixin

为 AutomaticKeepAlive 客户端提供便捷方法的 mixin。它与 State 子类配合使用，以管理延迟构建列表中的保持存活行为。

此 mixin 会在需要时自动发送 KeepAliveNotification，从而简化与 AutomaticKeepAlive 的交互。子类必须实现 wantKeepAlive，指明是否应保持 widget 存活，并在其值变化时调用 updateKeepAlive。

此 mixin 在内部管理一个 KeepAliveHandle，用于向最近的 AutomaticKeepAlive 祖先通知保持存活要求的变化。AutomaticKeepAlive 会监听此 mixin 发送的 KeepAliveNotification，并动态地用 KeepAlive widget 包裹子树，使其在离开视口后仍保留状态。

子类必须实现 wantKeepAlive，并且其 build 方法必须调用 super.build（但应忽略返回值）。

每当 wantKeepAlive 的值变化（或可能变化）时，子类都应调用 updateKeepAlive。

类型参数 T 是混入此类的 State 所属的 StatefulWidget 子类类型。

与 SliverList 和 SliverGrid 搭配使用的 SliverChildBuilderDelegate 与 SliverChildListDelegate，以及对应的滚动视图 ListView 和 GridView，都提供默认启用的 addAutomaticKeepAlives 功能。此功能会在每个子项周围插入 AutomaticKeepAlive widget，并由它们响应 KeepAliveNotification 配置 KeepAlive widget。

TwoDimensionalChildBuilderDelegate 和 TwoDimensionalChildListDelegate 也支持相同的 addAutomaticKeepAlives 功能。
