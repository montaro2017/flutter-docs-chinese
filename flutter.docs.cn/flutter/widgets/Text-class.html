Text 类

使用单一样式显示一段文本的 widget。

Text widget 使用单一样式显示字符串。具体是换成多行，还是始终显示在同一行，取决于布局约束。

style 参数为可选项。省略时，文本会使用最近祖先 DefaultTextStyle 的样式。如果给定样式的 TextStyle.inherit 属性为 true（默认值），给定样式会与最近祖先 DefaultTextStyle 合并。例如，可以在沿用默认字体系列和字号的同时，让文本加粗。

此示例展示如何使用 Text widget 显示文本，并将 overflow 设为 TextOverflow.ellipsis。

link 
Container(
  width: 100,
  decoration: BoxDecoration(border: Border.all()),
  child: const Text(
    'Hello, how are you?',
    overflow: TextOverflow.ellipsis,
  ),
)

将 maxLines 设为 1 并不等同于通过 softWrap 禁用软换行。使用 TextOverflow.fade 时，以下示例可以说明这一点。

此处启用了软换行，Text widget 会尝试将“how are you?”换到第二行。maxLines 的值为 1，因此无法换行。结果是第二行发生溢出，底部出现水平渐隐效果。

此处通过 softWrap: false 禁用了软换行，Text widget 会尝试将文本显示在一条不断开的行中。结果是该行发生溢出，并在右侧出现垂直渐隐效果。

link 
const Text(
  'Hello, how are you?',
  overflow: TextOverflow.fade,
  maxLines: 1,
)

// ...

const Text(
  'Hello, how are you?',
  overflow: TextOverflow.fade,
  softWrap: false,
)

使用 Text.rich 构造函数时，Text widget 可以显示由不同样式 TextSpan 组成的段落。下方示例使用不同样式显示“Hello beautiful world”中的每个单词。

link 
const Text.rich(
  TextSpan(
    text: 'Hello', // default text style
    children: <TextSpan>[
      TextSpan(text: ' beautiful ', style: TextStyle(fontStyle: FontStyle.italic)),
      TextSpan(text: 'world', style: TextStyle(fontWeight: FontWeight.bold)),
    ],
  ),
)

交互

若要让 Text 响应触摸事件，请将其包装在带有 GestureDetector.onTap 处理器的 GestureDetector widget 中。

在 Material Design 应用中，可以考虑改用 TextButton；如果不合适，至少考虑使用 InkWell，而不是 GestureDetector。

若要让文本中的部分内容可交互，请使用 RichText，并将 TapGestureRecognizer 指定为相关文本部分的 TextSpan.recognizer。

选择

Text 默认不可选择。若要使 Text 可选择，可以用 SelectionArea widget 包装一段子树。若要排除 SelectionArea 下子树中的某一部分，可以用 SelectionContainer.disabled 包装该部分。
