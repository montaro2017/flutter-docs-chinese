一种 sliver，会沿主轴方向以线性数组排列多个盒子子节点。

此构造函数使用 Widget 列表来构建 sliver。

addAutomaticKeepAlives 参数对应 SliverChildBuilderDelegate.addAutomaticKeepAlives 属性。addRepaintBoundaries 参数对应 SliverChildBuilderDelegate.addRepaintBoundaries 属性。addSemanticIndexes 参数对应 SliverChildBuilderDelegate.addSemanticIndexes 属性。

此示例可插入到 a CustomScrollView.slivers 列表中，用于显示无限多个深浅不一的蓝色项目：
link 
SliverPrototypeExtentList.list(
  prototypeItem: const Text('Hello'),
  children: const <Widget>[
    Text('Hello'),
    Text('World!'),
  ],
);
