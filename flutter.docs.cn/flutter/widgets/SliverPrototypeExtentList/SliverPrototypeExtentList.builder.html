沿主轴以线性数组方式放置盒子子项，并将它们限制为与原型子项具有相同范围的 sliver。

此构造函数适用于子项数量较多（或无限）且范围已确定的 sliver 列表。

提供非 null 的 itemCount 有助于 SliverGrid 估算最大滚动范围。

itemBuilder 仅会收到大于或等于零且小于 itemCount 的索引。

itemBuilder 返回 null 是合法的。如果发生这种情况，即使尚未到达 itemCount，滚动视图也会停止调用 itemBuilder。由于返回了 null，除非用户已滚动到 ScrollPosition.maxScrollExtent 的末尾，否则 ScrollView 将不准确；这也可能导致 Scrollbar 随着用户滚动而增长。

若要获得更准确的 ScrollMetrics，请考虑指定 itemCount。

prototypeItem 参数用于确定每个项目的范围。

findChildIndexCallback 对应 SliverChildBuilderDelegate.findChildIndexCallback 属性。如果该回调为 null，当子节点构建器返回的子 Widget 顺序变化时，子 Widget 可能无法映射到现有的 RenderObject，从而导致状态丢失。如果子节点顺序之后可能发生变化，就必须实现此回调。

addAutomaticKeepAlives 参数对应 SliverChildBuilderDelegate.addAutomaticKeepAlives 属性。addRepaintBoundaries 参数对应 SliverChildBuilderDelegate.addRepaintBoundaries 属性。addSemanticIndexes 参数对应 SliverChildBuilderDelegate.addSemanticIndexes 属性。

此示例可插入到 a CustomScrollView.slivers 列表中，用于显示无限多个深浅不一的蓝色项目：
link 
SliverPrototypeExtentList.builder(
  prototypeItem: Container(
    alignment: Alignment.center,
    child: const Text('list item prototype'),
  ),
  itemBuilder: (BuildContext context, int index) {
    return Container(
      alignment: Alignment.center,
      color: Colors.lightBlue[100 * (index % 9)],
      child: Text('list item $index'),
    );
  },
)
