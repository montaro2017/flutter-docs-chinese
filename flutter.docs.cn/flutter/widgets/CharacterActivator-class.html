CharacterActivator 类

一种由产生特定字符的按键事件触发的快捷键组合。

按键与修饰键组合后通常会产生不同字符。例如，用户按下问号（“?”）时弹出帮助菜单可能很有用。但并没有直接表示问号的逻辑按键。虽然在美式键盘上按 Shift+斜杠会产生“?”，其逻辑按键仍被视为斜杠；在这种情况下硬编码“Shift+斜杠”会让使用其他键盘布局的用户感到不便。

例如，在美式键盘上，按键组合产生问号时会触发 CharacterActivator('?')，该组合是 Shift+斜杠；而在法语键盘上则是 Shift+逗号。

alt、control 和 meta 标志分别表示对应修饰键应按下（true）还是松开（false）；默认均为 false。CharacterActivator 无法检查 Shift 键，因为 Shift 会影响产生的字符。只要按键事件产生了正确字符，无论任一 Shift 键是否按下都会接受该事件。

默认情况下，activator 会检查所有 KeyDownEvent 或 KeyRepeatEvent，判断它们与请求的修饰键组合后是否产生指定的 character。如果 includeRepeats 为 false，则只会考虑属于 KeyDownEvent 的 character 事件。

在 macOS 和 iOS 上，alt 标志表示 Option 键（⌥）已按下。由于 Option 键会影响这些平台上生成的字符，为它们定义 CharacterActivator 可能不太直观。

例如，如果希望按下 Option+s（⌥-s）时触发快捷键，且意图是在生成字符“ß”时触发，则应使用 CharacterActivator('ß') 或 CharacterActivator('ß', alt: true)，而不是 CharacterActivator('s', alt: true)。这是因为按住 Option 键时无法生成“s”，所以 CharacterActivator('s', alt: true) 永远不会触发。

如果希望无论生成何种字符，只要按下 Option+s（⌥-s）就触发快捷键，则更适合使用 SingleActivator，例如 SingleActivator(LogicalKeyboardKey.keyS, alt: true)。

另请参阅：

  • SingleActivator, an activator that represents a single key combined with modifiers, such as Ctrl+C or Ctrl-Right Arrow.
