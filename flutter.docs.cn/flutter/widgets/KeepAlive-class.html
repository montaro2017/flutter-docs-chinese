KeepAlive 类

将子组件标记为需要保持存活，即使它位于通常会被移除子组件的延迟列表中也不会被移除。

此组件用于 RenderAbstractViewport，例如 Viewport 或 TwoDimensionalViewport，以管理需要在滚动出视野后仍保持存活的组件的生命周期。

The SliverChildBuilderDelegate 和 SliverChildListDelegate delegates, used with SliverList 和 SliverGrid, as well as the scroll view counterparts ListView 和 GridView, have an addAutomaticKeepAlives feature, which is enabled by default. This feature inserts AutomaticKeepAlive widgets around each child, which in turn configure KeepAlive widgets in response to KeepAliveNotification。

The same addAutomaticKeepAlives feature is supported by TwoDimensionalChildBuilderDelegate 和 TwoDimensionalChildListDelegate.

可以直接使用 KeepAlive 管理保持存活的行为，也可以依赖通知。为方便起见，可在 State 子类中混入 AutomaticKeepAliveClientMixin。详情请参阅 AutomaticKeepAliveClientMixin 文档。

此示例展示如何使用 KeepAlive 组件，在 ListView 中的列表条目滚出视野后仍保留其各自的状态。

默认情况下，ListView.builder 只会让当前位于视口中的组件保持存活。条目滚出视野后，可能会被释放以节省资源。如果没有显式保留状态，StatefulWidget 的状态可能会丢失。

此示例中的每个列表条目都是一个维护计数器的 StatefulWidget。点击“+”按钮会增加计数器。为了有选择地保留状态，每个条目都会包在 KeepAlive 组件中，并根据条目的索引设置 keepAlive 参数：

  • 对于偶数索引项，使用 keepAlive: true，因此即使滚出屏幕也会保留其状态。
  • For odd-indexed items, keepAlive: false, so their state is discarded when they are no longer visible.
