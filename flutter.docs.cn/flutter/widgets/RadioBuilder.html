RadioBuilder typedef

RadioBuilder = Widget Function(BuildContext context, ToggleableStateMixin<StatefulWidget> state)

RawRadio.builder 的签名。

构建器可以使用 state 确定单选按钮的状态，并据此构建其外观。

例如，在 Material Design 中，如果需要绘制径向墨水波纹效果，可以将 CustomPaint 与 ToggleablePainter 子类一起用作 CustomPaint.painter，并在其中实现此控件的径向墨水波纹绘制逻辑。通常会使用此混入提供的 ToggleableStateMixin.reaction、ToggleableStateMixin.position、ToggleableStateMixin.reactionHoverFade 和 ToggleableStateMixin.reactionFocusFade 动画配置绘制器。绘制器应根据这些动画的当前值绘制 Toggleable 的视觉效果。此混入会触发动画，使 Toggleable 在不同状态间过渡。
