ToggleableStateMixin<S extends StatefulWidget> mixin

供实现可切换控件及其切换动画的 StatefulWidget 使用的 mixin，例如 Switch、CupertinoSwitch、Checkbox、CupertinoCheckbox、Radio 和 CupertinoRadio。

此 mixin 实现控件切换逻辑（例如点击时切换），并提供一组动画控制器，使控件从一种状态过渡到另一种状态。它不规定可切换 widget 的视觉表现；视觉效果由传给 buildToggleable 的 CustomPainter 定义。使用此 mixin 的 State 对象应在其 build 方法中调用该方法。
