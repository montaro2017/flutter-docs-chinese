LocalizationsDelegate<T> 类 抽象

用于创建一组类型为 T 的本地化资源，并供 Localizations 组件加载的工厂。

典型应用只有一个 Localizations 组件，由 WidgetsApp 创建，并通过应用的 localizationsDelegates 参数（委托列表）进行配置。委托的 type 用于识别各委托的 load 方法所创建的对象。

这里的 T 可以是 MaterialLocalizations 这样的类。
