PopScope<T> 类

用于管理返回导航手势。

泛型类型应与外围 Route 的泛型类型相同或为其超类型。例如，如果外围 Route 是 MaterialPageRoute<int>，则可以将 PopScope 的泛型指定为 int 或其任意超类型（int 的超类型）。

将 canPop 设为 false 时，会禁用返回手势。

onPopInvokedWithResult 参数会报告是否尝试了弹出导航；didPop 用于指示导航是否成功。result 包含弹出操作的结果。

Android 提供系统返回手势，即从屏幕边缘附近向内滑动。Android 会先识别该手势，再将其传递给 Flutter。iOS 也有类似手势，但由 Flutter 中的 CupertinoRouteTransitionMixin 识别，而不是由 iOS 识别，因此它不属于系统返回手势。

如果 canPop 为 false，系统返回手势不会使外围 Navigator 弹出当前路由。此时仍会调用 onPopInvokedWithResult，且 didPop 为 false。在 iOS 上，如果使用 CupertinoRouteTransitionMixin，并将 canPop 设为 false，则系统完全不会识别该手势，因此不会调用 onPopInvokedWithResult。以编程方式尝试弹出路由也会调用 onPopInvokedWithResult，并通过 didPop 指示操作成功或失败。

如果 canPop 为 true，系统返回手势会像往常一样使外围 Navigator 收到弹出请求。除非弹出因与 PopScope 无关的原因失败，否则调用 onPopInvokedWithResult 时，didPop 为 true；如果弹出失败，该值则为 false。
