DraggableScrollableController 类

控制 DraggableScrollableSheet。

DraggableScrollableController 通常作为成员变量存储在 State 对象中，并在每次 State.build 调用中重复使用。一个 controller 一次只能控制一个面板。只有在之前的面板已释放后，controller 才能用于新的面板。

在将 controller 传给 DraggableScrollableSheet，且该面板已运行 initState 之前，不能调用 controller 的方法。

DraggableScrollableController 是一个 Listenable。附加的面板尺寸发生变化时，它会通知监听器。首次附加面板时，或附加面板的参数发生变化但当前尺寸未受影响时，它不会通知监听器。如果 size 未变化而 pixels 发生变化，也不会触发通知；例如，附加面板收到的约束发生变化时就是如此。
