ScrollbarPainter 类

绘制滚动条的轨道和滑块。

通常，滚动条沿滚动方向的尺寸与屏幕上完全可见的内容比例成正比；但其尺寸不会小于 minLength，且越界滚动时不适用此比例。

如果 padding 是 EdgeInsetsDirectional，则必须提供非 null 的 textDirection，才能正确解析 padding 值。

与 CustomPainter 子类不同，继承 CustomPainter 的绘制器只有在 shouldRepaint 返回 true 时才会重绘（这要求重新构建此 CustomPainter），而此绘制器还进行了优化：在以下情况下会重绘而无需重新构建：

  • 滚动位置发生变化；
  • 滚动条淡出时。

使用新的 ScrollMetrics 调用 update，会根据新的滚动条位置重新绘制。

所提供的 fadeoutOpacityAnimation 的值更新时，会以新的不透明度重新绘制。

不再使用此 ScrollbarPainter 时，必须调用其 dispose。

另请参阅：

  • Scrollbar 是一个 widget，用于以 Material Design 风格在 Scrollable 周围显示滚动条。
  • CupertinoScrollbar 是一个用于在 Scrollable 周围显示 iOS 风格滚动条的 widget。
