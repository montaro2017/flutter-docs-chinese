WidgetStateProperty<T> 类 抽象

Interface for classes that resolve to a value of type T based on a widget's interactive "state", which is defined as a set of WidgetState。

状态属性表示取决于组件“状态”的值。状态编码为一组 WidgetState，例如 WidgetState.focused、WidgetState.hovered 和 WidgetState.pressed。例如，InkWell.overlayColor 定义了墨水效果在按下（即“溅起颜色”）、获得焦点或悬停时所填充的颜色。InkWell 会使用叠加颜色的 resolve 方法，根据当前状态计算墨水效果的颜色。

ButtonStyle 用于配置 TextButton、ElevatedButton 和 OutlinedButton 等按钮的外观，其中包含许多 Material 状态属性。按钮组件会跟踪当前 Material 状态，并在需要值时解析样式中的状态属性。

This example shows how the default text and icon color (the "foreground color") of a TextButton can be overridden with a WidgetStateProperty. In this example, the button's text color will be colored differently depending on whether the button is pressed, hovered, or focused.

性能注意事项

In order for constructed WidgetStateProperty objects to be recognized as equivalent, they need to either be const objects, or have overrides for operator== 和 hashCode.

例如，比较两个 ThemeData 对象是否相等时，就会涉及这一点。

如需支持稳定相等性检查的具体 WidgetStateProperty 对象，可以考虑使用 WidgetStateMapper。

另请参阅：

  • MaterialStateProperty, the Material specific version of WidgetStateProperty.
  • WidgetStateColor, a Color that implements WidgetStateProperty which is used in APIs that need to accept either a Color or a WidgetStateProperty<Color>.
  • WidgetStateMouseCursor, a MouseCursor that implements WidgetStateProperty which is used in APIs that need to accept either a MouseCursor or a WidgetStateProperty<MouseCursor>.
  • WidgetStateOutlinedBorder, an OutlinedBorder that implements WidgetStateProperty which is used in APIs that need to accept either an OutlinedBorder or a WidgetStateProperty<OutlinedBorder>.
  • WidgetStateBorderSide, a BorderSide that implements WidgetStateProperty which is used in APIs that need to accept either a BorderSide or a WidgetStateProperty<BorderSide>.
  • WidgetStateTextStyle, a TextStyle that implements WidgetStateProperty which is used in APIs that need to accept either a TextStyle or a WidgetStateProperty<TextStyle>.
