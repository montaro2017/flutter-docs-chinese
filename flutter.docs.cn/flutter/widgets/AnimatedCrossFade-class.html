description

AnimatedCrossFade 类

在两个给定子级之间交叉淡入淡出，并为自身尺寸变化添加动画的 widget。

动画由 crossFadeState 参数控制。firstCurve 和 secondCurve 分别表示两个子级的透明度曲线。firstCurve 会反转；也就是说，传入 Curves.linear 这类递增曲线时，它会淡出。sizeCurve 是用于在淡出子级和淡入子级的尺寸之间过渡的曲线。

此 widget 适用于两个宽度相同的 widget。如果两个子级高度不同，动画期间会对溢出的子级进行裁剪，并将它们的顶部边缘对齐，因此底部可能被裁掉。

当已有的 AnimatedCrossFade 因 crossFadeState 属性值改变而重建时，动画会自动触发。

此代码会在 Flutter 标志的两种呈现方式之间淡入淡出。它由布尔字段 _first 控制：当 _first 为 true 时显示第一个标志，否则显示第二个标志。字段状态变化时，AnimatedCrossFade widget 会在三秒内让标志在两种形式之间交叉淡入淡出。

AnimatedCrossFade(
  duration: const Duration(seconds: 3),
  firstChild: const FlutterLogo(style: FlutterLogoStyle.horizontal, size: 100.0),
  secondChild: const FlutterLogo(style: FlutterLogoStyle.stacked, size: 100.0),
  crossFadeState: _first ? CrossFadeState.showFirst : CrossFadeState.showSecond,
