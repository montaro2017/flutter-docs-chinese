consumeKeyboardToken 方法

bool consumeKeyboardToken()

如果此焦点节点持有键盘令牌，则将其移除。

此机制有助于区分输入控件是默认获得焦点，还是因用户明确操作而获得焦点。

焦点节点请求焦点时（通过 FocusScopeNode.requestFocus 或 FocusScopeNode.autofocus），如果它尚未持有键盘令牌，就会获得一个。之后节点获得焦点时，管理 TextInputConnection 的 widget 只有在成功从焦点节点消费该键盘令牌后，才应显示键盘（即调用 TextInputConnection.show）。

如果此方法成功消费键盘令牌，则返回 true。

实现

bool consumeKeyboardToken() {
  if (!_hasKeyboardToken) {
    return false;
  }
  _hasKeyboardToken = false;
  return true;
}
