hasFocus 属性

bool get hasFocus

此节点是否拥有输入焦点。

当 FocusNode 是某个 hasPrimaryFocus 返回 true 的节点的祖先，或节点本身拥有主要焦点时，它就拥有焦点。

hasFocus 与 hasPrimaryFocus 不同：只要节点位于焦点链的任意位置，hasFocus 就为 true；而 hasPrimaryFocus 只有在节点位于焦点链末端时才返回 true。

如果某节点的 hasFocus 返回 true，且其拥有焦点的后代节点都没有通过已弃用的 onKey 处理器处理事件，该节点就会接收按键事件。

此对象是 ChangeNotifier；每当此值变化时，都会通知其 Listenable 监听器（通过 addListener 注册）。

另请参阅：

  • Focus.isAt 是静态方法，可返回最近祖先 Focus widget 的焦点节点当前是否获得焦点。

实现

bool get hasFocus =>
    hasPrimaryFocus || (_manager?.primaryFocus?.ancestors.contains(this) ?? false);
