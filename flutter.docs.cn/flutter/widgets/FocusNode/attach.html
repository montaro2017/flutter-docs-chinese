由宿主 StatefulWidget 调用，以将 FocusNode 附加到 widget 树。

若要将 FocusNode 附加到 widget 树，请调用 attach，通常在 StatefulWidget 的 State.initState 方法中调用。

如果宿主 widget 更换了焦点节点，则需要附加新节点。应先对旧节点调用 FocusAttachment.detach，再对新节点调用 attach。这通常发生在 State.didUpdateWidget 方法中。

若要接收发往此节点的按键事件，请向 onKeyEvent 传入监听器。

实现

@mustCallSuper
FocusAttachment attach(
  BuildContext? context, {
  FocusOnKeyEventCallback? onKeyEvent,
  @Deprecated(
    'Use onKeyEvent instead. '
    'This feature was deprecated after v3.18.0-2.0.pre.',
  )
  FocusOnKeyCallback? onKey,
}) {
  _context = context;
  this.onKey = onKey ?? this.onKey;
  this.onKeyEvent = onKeyEvent ?? this.onKeyEvent;
  _attachment = FocusAttachment._(this);
  return _attachment!;
}
