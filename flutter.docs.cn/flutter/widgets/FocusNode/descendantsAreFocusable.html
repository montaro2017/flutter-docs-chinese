descendantsAreFocusable 属性

bool get descendantsAreFocusable

为 false 时，会禁用此节点所有后代的焦点。

默认值为 true。此项不影响此节点本身是否可获得焦点；要控制此节点，请使用 canRequestFocus。

如果将此项设为 false 时有后代正处于焦点状态，这些后代会失去焦点。再次将 descendantsAreFocusable 设为 true 时，它们不会自动重新获得焦点，但可以再次接受焦点。

此项不影响后代的 canRequestFocus 值。

更改此值导致后代节点失去焦点时，焦点会移动到包含此节点的范围。

另请参阅：

  • ExcludeFocus，一种可按条件排除子树焦点的 widget。
  • descendantsAreTraversable，会使此 widget 的后代节点无法遍历。
  • ExcludeFocusTraversal，一个会按条件排除子树焦点遍历的 widget。
  • Focus, 这是一个将此设置作为参数公开的 widget。
  • FocusTraversalGroup 是一个 widget，用于将 widget 子树组合在一起并配置其焦点遍历策略；它还提供 descendantsAreFocusable 参数，用于阻止子项获得焦点。

实现

@mustCallSuper
set descendantsAreFocusable(bool value) {
  if (value == _descendantsAreFocusable) {
    return;
  }
  // Set _descendantsAreFocusable before unfocusing, so the scope won't try
  // and focus any of the children here again if it is false.
  _descendantsAreFocusable = value;
  if (!value && hasFocus) {
    unfocus(disposition: UnfocusDisposition.previouslyFocusedChild);
  }
  _manager?._markPropertiesChanged(this);
}
