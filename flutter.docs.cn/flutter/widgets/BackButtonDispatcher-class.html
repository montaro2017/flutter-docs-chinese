BackButtonDispatcher 类 抽象

当用户在支持返回按钮的平台（例如 Android）上点击返回键时，向 Router 报告。

当 Router widget 嵌套时，可以使用 ChildBackButtonDispatcher，并将父级 BackButtonDispatcher 传给它，以便将返回键请求分派给适当的 Router。为确保正常工作，每当 Router 认为自己应接收返回键消息时（例如用户在其中点击后），都必须在自己的 BackButtonDispatcher（或 ChildBackButtonDispatcher）实例上调用 takePriority。

此类接收一个回调，该回调必须返回 Future<bool>。回调语义与 WidgetsBindingObserver.didPopRoute 相同：若能处理弹出请求，应返回最终结果为 true 的 future；否则返回最终结果为 false 的 future。
