WidgetSpan 类

一种不可变 widget，可嵌入文本行内。

child 属性指定要嵌入的 widget。子级的宽度受段落宽度约束。

child 属性也可以包含自己的 Widget 子级（如适用）， 包括 Text 和 RichText widget，这些 widget 还可以包含其他 WidgetSpan。子级 Text 和 RichText widget 会独立布局， 并在父级文本布局中占据矩形空间。

直接传给 TextPainter 时会忽略 WidgetSpan。若要正确布局和绘制 child widget，应将 WidgetSpan 传给 Text.rich widget。

一个在 TextSpan 树中行内嵌入 Hello World! 的卡片示例。
link 
const Text.rich(
  TextSpan(
    children: <InlineSpan>[
      TextSpan(text: 'Flutter is'),
      WidgetSpan(
        child: SizedBox(
          width: 120,
          height: 50,
          child: Card(
            child: Center(
              child: Text('Hello World!')
            )
          ),
        )
      ),
      TextSpan(text: 'the best!'),
    ],
  )
)

WidgetSpan 会将 WidgetSpan.child 的语义信息添加到语义树中。

另请参阅：

  • TextSpan，表示 InlineSpan 树中文本的节点。
  • Text，用于显示统一样式文本的 widget。
  • RichText，可更精细地控制文本渲染的 widget。
  • TextPainter，用于将 InlineSpan 对象绘制到 Canvas 上的类。
