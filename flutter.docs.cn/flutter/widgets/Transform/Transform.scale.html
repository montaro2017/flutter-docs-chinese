Transform.scale 构造函数

创建一个在二维平面上缩放其子级的 widget。

scaleX 参数提供 x 轴的缩放系数，x 轴上的缩放结果由此系数计算；scaleY 参数提供 y 轴的缩放系数，y 轴同理。任一参数都可以省略，省略时对应轴的缩放系数默认为 1.0。

为了方便地统一缩放子级，可以使用 scale 参数，而无需分别提供 scaleX 和 scaleY。

scale、scaleX 和 scaleY 中至少有一个不能为 null。如果提供了 scale，另外两个必须为 null；如果未提供 scale，则必须提供另外两个中的一个。

alignment 用于控制缩放原点；默认原点是矩形中心。

此示例将包含文本的橙色方块缩小，使其宽度和高度都变为原来的一半。
link 
Transform.scale(
  scale: 0.5,
  child: Container(
    padding: const EdgeInsets.all(8.0),
    color: const Color(0xFFE8581C),
    child: const Text('Bad Idea Bears'),
  ),
)

另请参阅：

  • ScaleTransition, which animates changes in scale smoothly over a given duration.

实现

Transform.scale({
  super.key,
  double? scale,
  double? scaleX,
  double? scaleY,
  this.origin,
  this.alignment = Alignment.center,
  this.transformHitTests = true,
  this.filterQuality,
  super.child,
}) : assert(
       !(scale == null && scaleX == null && scaleY == null),
       "At least one of 'scale', 'scaleX' and 'scaleY' is required to be non-null",
     ),
     assert(
       scale == null || (scaleX == null && scaleY == null),
       "If 'scale' is non-null then 'scaleX' and 'scaleY' must be left null",
     ),
     transform = Matrix4.diagonal3Values(scale ?? scaleX ?? 1.0, scale ?? scaleY ?? 1.0, 1.0);
