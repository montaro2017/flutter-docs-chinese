Transform.flip 构造函数

Transform.flip({
  1. Key? key,
  2. bool flipX = false,

创建一个绕 widget 中心点镜像其子级的 widget。

如果 flipX 为 true，子级会水平翻转。默认值为 false。

如果 flipY 为 true，子级会垂直翻转。默认值为 false。

如果两者都为 true，子级会同时水平和垂直翻转，效果等同于旋转 180 度。

此示例将文本水平翻转。
link 
Transform.flip(
  flipX: true,
  child: const Text('Horizontal Flip'),
)

实现

Transform.flip({
  super.key,
  bool flipX = false,
  bool flipY = false,
  this.origin,
  this.transformHitTests = true,
  this.filterQuality,
  super.child,
}) : alignment = Alignment.center,
     transform = Matrix4.diagonal3Values(flipX ? -1.0 : 1.0, flipY ? -1.0 : 1.0, 1.0);
