TwoDimensionalScrollable 类

用于管理垂直和水平方向滚动，并向 TwoDimensionalViewport 提供内容视口信息的 widget。

TwoDimensionalScrollable 实现了二维可滚动 widget 的交互模型，包括手势识别，但不决定实际用于显示子项的 TwoDimensionalViewport 应如何构建。

很少需要直接构造 TwoDimensionalScrollable。通常应考虑继承 TwoDimensionalScrollView，它将两个维度上的滚动、视口和布局模型组合在一起。

另请参阅：

  • TwoDimensionalScrollView, an abstract base class for displaying a scrolling array of children in both directions.
  • TwoDimensionalViewport, which can be used to customize the child layout model.
