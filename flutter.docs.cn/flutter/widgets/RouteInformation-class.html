RouteInformation 类

一段路由信息。

路由信息由应用的位置字符串以及用于配置应用在该位置状态的 state 对象组成。

此信息会双向流动：从 RouteInformationProvider 流向 Router，或从 Router 流向 RouteInformationProvider。

在前一种情况下，RouteInformationProvider 会在有新的 RouteInformation 时通知 Router widget。Router widget 会使用这些信息进行导航。

后一种情况发生在 Web 应用中，此时 Router 会将路由变化报告回 Web 引擎。

应用当前的 RouteInformation 也用于状态恢复。应用被终止前，Router 会借助 RouteInformationProvider 将当前配置转换为 RouteInformation 对象。随后该 RouteInformation 对象会被序列化并持久化。状态恢复时，对象会被反序列化并传回 RouteInformationProvider，再由它转换为 Router 的配置，以恢复其状态。
