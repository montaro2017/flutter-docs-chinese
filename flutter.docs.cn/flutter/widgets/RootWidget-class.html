RootWidget 类

widget 树的根 widget。

提供 attach 方法，用于将 widget 树附加到 BuildOwner。该方法还会引导启动元素树。

WidgetsBinding.attachRootWidget 使用此类引导应用；该方法会由 runApp 间接调用。
