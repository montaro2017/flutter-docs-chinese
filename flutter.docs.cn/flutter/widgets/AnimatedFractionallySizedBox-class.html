AnimatedFractionallySizedBox 类

FractionallySizedBox 的动画版本。每当 widthFactor 或 heightFactor 改变时，它会在指定时长内自动为子级尺寸添加过渡动画；每当 alignment 改变时，也会为子级位置添加动画。

可以为动画选择 curve 和 duration，此 widget 会自动过渡到新的 widthFactor 或 heightFactor 目标值。

下面的示例展示 AnimatedFractionallySizedBox 在两种状态之间过渡的效果。点击时，它会调整 heightFactor、widthFactor 和 alignment 属性，并使用 curve Curves.fastOutSlowIn。
