Icon 类

使用字体中的字形绘制图标的图形组件。该字体由 IconData 描述，例如 Icons 中预定义的 Material IconData。

图标不可交互。若需要可交互的图标，请考虑使用 Material 的 IconButton。

使用 Icon 时，环境中必须存在 Directionality 组件。通常 WidgetsApp 或 MaterialApp 会自动提供它。

此组件假定渲染的图标为正方形。非正方形图标可能无法正确显示。

此示例展示如何创建一行颜色和大小各异的图标：使用 Row 排列多个 Icon。第一个 Icon 使用 semanticLabel，以便在 TalkBack 和 VoiceOver 等无障碍模式下进行播报。

link 
const Row(
  mainAxisAlignment: MainAxisAlignment.spaceAround,
  children: <Widget>[
    Icon(
      Icons.favorite,
      color: Colors.pink,
      size: 24.0,
      semanticLabel: 'Text to announce in accessibility modes',
    ),
    Icon(
      Icons.audiotrack,
      color: Colors.green,
      size: 30.0,
    ),
    Icon(
      Icons.beach_access,
      color: Colors.blue,
      size: 36.0,
    ),
  ],
)

另请参阅：

  • IconButton，用于创建可交互的图标。
  • Icons，列出了可与此类配合使用的 Material 图标。
  • IconTheme，为图标提供环境配置。
  • ImageIcon，用于显示来自 AssetImage 或其他 ImageProvider 的图标。
