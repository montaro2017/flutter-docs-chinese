description

RepeatingAnimationBuilder<T extends Object> 类

为 Animatable 值创建无限循环重复播放的动画。

动画会不断地从 Animatable 在 0.0 时产生的值变化到 1.0 时产生的值。builder 会接收此 Animatable 当前产生的值，并据此构建子组件。动画到达 1.0 时，会根据配置的 repeatMode 从 0.0 重新开始，或反向播放。paused 为 true 时，动画会停留在当前值。

This example shows a continuously rotating square that can be paused and resumed.
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.RepeatingAnimationBuilder.1 mysample

对于更复杂、有状态或需要协调的动画，可以考虑直接管理 AnimationController，并将其与 AnimatedBuilder 或 AnimatedWidget 组合使用。

另请参阅：

  • TweenAnimationBuilder, which animates a tween value once.
  • AnimationController.repeat, the underlying mechanism.
