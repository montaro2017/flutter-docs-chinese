ChildBackButtonDispatcher 类

BackButtonDispatcher 的一种变体，会监听父级返回按钮分发器发出的通知，并可向父级取得优先级，以处理这些通知。

适用于嵌套使用多个 Router 的情况。

使用 Router.of 获取最近祖先 Router 的引用，再找到 Router.backButtonDispatcher，并将其用作 ChildBackButtonDispatcher 的 parent。
