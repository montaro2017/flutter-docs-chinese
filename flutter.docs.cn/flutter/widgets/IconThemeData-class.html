IconThemeData 类

定义图标的尺寸、字体变体、颜色、不透明度和阴影。

IconTheme 使用此类控制组件子树中的这些属性。

要获取当前图标主题，请使用 IconTheme.of。要将图标主题转换为所有字段均已填充的版本，请使用 IconThemeData.fallback。
