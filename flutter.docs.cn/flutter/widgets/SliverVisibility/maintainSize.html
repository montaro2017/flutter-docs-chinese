maintainSize 属性

bool maintainSize
final

是否保留 sliver 原本占据的空间。

若要启用此项，还必须启用 maintainAnimation。

sliver 不可见时仍保留尺寸，其开销并不明显高于仅让动画继续运行。在某些情况下，如果子树很简单且 visible 属性频繁切换，保留尺寸甚至会略省开销，因为这样可以避免在切换 visible 时触发布局变化。如果 sliver 子树并不简单，且 visible 状态需要考虑，那么连状态也不保留会节省很多开销（参见 maintainState）。

此属性为 false 时，会使用 SliverOffstage。

此属性为 false 时，maintainSemantics 和 maintainInteractivity 也必须为 false。

动态更改此值可能导致子树当前状态丢失（会立即创建包含新的 State 对象的子树实例，但前提是 visible 为 true）。
