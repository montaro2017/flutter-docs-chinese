StandardComponentType enum

用于标识标准 UI 组件的枚举。

此枚举用于为 widget 附加一个 key，以标识其为标准 UI 组件，供测试和发现功能使用。

测试基础设施（例如 Flutter 测试框架中的 find 对象）会使用它来确认和/或激活特定 widget，并将其识别为标准 UI 组件。由于许多此类组件使用的图标或工具提示略有不同，为它们创建有效的测试匹配器会很脆弱，也容易出错。

这些 key 不会影响 UI 元素的功能，只用于识别元素。除测试基础设施可以通过此 key 找到 widget 外，带有此 key 的 widget 不会受到特殊处理。如果测试不会查找这些组件，那么给 widget 添加此 key 就没有意义。

任何应用了此处某个值对应 key 的 widget，在测试中都会被视为该类型的标准 UI 组件。

此处通常只包含那些难以或脆弱地创建可靠测试匹配器的组件类型。这并非标准 UI 组件的完整列表，也不应发展为完整列表。

另请参阅：

  • CommonFinders.backButton, which in tests is used as find.backButton().
  • CommonFinders.closeButton, which in tests is used as find.closeButton().
