OrderedTraversalPolicy 类

一种 FocusTraversalPolicy，根据最近祖先 FocusTraversalOrder widget 中指定的顺序排列节点。

只有类型相同的顺序值才能互相比较。如果同一 FocusTraversalGroup 中包含无法互相比较的顺序值，系统会触发断言，因为这些键之间的顺序未定义。为避免冲突，请使用 FocusTraversalGroup 将顺序相近的 widget 分组。

重写此类时，必须重写 FocusOrder.doCompare，而不是 FocusOrder.compareTo；后者会调用 FocusOrder.doCompare 执行实际比较。

此示例演示如何为 widget 指定遍历顺序。示例中的焦点顺序从右下角的“One”按钮开始，依次到达左上角的“Six”按钮。

另请参阅：

  • FocusTraversalGroup, 一种将其分组，并为其应用遍历策略的组件：Focus 节点（位于该组件下方的 widget 树中）。
  • WidgetOrderTraversalPolicy，一种依据 widget 创建顺序确定遍历顺序的策略。
  • ReadingOrderTraversalPolicy，一种按照当前 Directionality 的自然“阅读顺序”确定遍历顺序的策略。
  • NumericFocusOrder, a focus order that assigns a numeric traversal order to a FocusTraversalOrder widget.
  • LexicalFocusOrder, a focus order that assigns a string-based lexical traversal order to a FocusTraversalOrder widget.
  • FocusOrder, an abstract base class for all types of focus traversal orderings.
