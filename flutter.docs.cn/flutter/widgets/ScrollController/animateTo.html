animateTo 方法

  1. @awaitNotRequired
Future<void> animateTo(
  1. double offset, {
  2. required Duration duration,
  3. required Curve curve,
})

将滚动位置从当前值动画移动到指定值。

任何正在进行的动画都会取消。如果用户当前正在滚动，该操作也会取消。

返回的 Future 会在动画结束时完成，无论动画是正常完成还是提前中断。

用户尝试手动滚动、启动其他活动，或动画到达视口边缘并尝试过度滚动时，动画都会中断。（如果 ScrollPosition 不会过度滚动，而是允许滚动超出范围，则超出范围不会中断动画。）

视口或内容尺寸发生变化不会影响此动画。

对于 ListView.builder 等延迟构建内容的可滚动组件，根据 ScrollPosition.maxScrollExtent 计算的值可能只是估算值。由于动画目标根据当前 ScrollMetrics.maxScrollExtent 估算值计算，动画可能无法到达当前缓存范围之外新添加的内容。动画过程中，随着更多子项完成布局，目标值不会更新。若要显示已构建的子项，请将该子项的 BuildContext 传给 Scrollable.ensureVisible。

动画完成后，如果滚动位置不稳定（例如超出滚动范围，而通常应在此情况下弹回），就会尝试开始弹道活动。

duration 不能为零。若要不使用动画直接跳到指定值，请使用 jumpTo。

在 Widget 测试中调用 animateTo 时，对返回的 Future 使用 await 可能导致测试挂起并超时。请改用 WidgetTester.pumpAndSettle。

实现

@awaitNotRequired
Future<void> animateTo(double offset, {required Duration duration, required Curve curve}) async {
  assert(_positions.isNotEmpty, 'ScrollController not attached to any scroll views.');
  await Future.wait<void>(<Future<void>>[
    for (int i = 0; i < _positions.length; i += 1)
      _positions[i].animateTo(offset, duration: duration, curve: curve),
  ]);
}
