description

FlutterLogo 类

以 widget 形式呈现的 Flutter 标志。此 widget 会遵循 IconTheme。有关 Flutter 标志的使用指南，请访问 https://flutter.dev/brand。

另请参阅：

  • IconTheme, which provides ambient configuration for icons.
  • Icon, for showing icons the Material design icon library.
  • ImageIcon, for showing icons from AssetImages or other ImageProvider。
