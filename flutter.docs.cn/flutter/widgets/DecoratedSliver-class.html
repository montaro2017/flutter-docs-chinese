DecoratedSliver 类

一种 Sliver 组件，可在子项绘制之前或之后绘制 Decoration。

与 DecoratedBox 不同，此组件要求其子项为 Sliver，且必须放置在接收 Sliver 的组件中。

如果子 Sliver 的 SliverGeometry.scrollExtent 为无限值，那么装饰只会绘制到 SliverGeometry.cacheExtent 的底部；必须确保底部边框不会越过底部缓存区域的顶部。如果底部圆角半径大于缓存区域的范围，就可能发生这种情况。

通常与 BoxDecoration 配合使用。

是否启用裁剪由 Switch 决定，Slider 用于调整窗口高度。

link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.DecoratedSliver.2 mysample

此组件不会对其 child 进行额外裁剪。若要根据 Decoration 的形状裁剪子项，可以考虑使用 ClipPath 组件。

另请参阅：

  • DecoratedBox 是此类适用于 RenderBox widget 的版本。
  • Decoration 可通过扩展来配合 DecoratedSliver 提供其他效果。
  • CustomPaint 是从 widget 层绘制自定义效果的另一种方式。
