ToggleablePainter
description

ToggleablePainter 类 抽象

CustomPainter 的基类，可传给 ToggleableStateMixin.buildToggleable，用于绘制 Toggleable 的视觉表示。

子类必须实现 paint 方法来绘制实际内容。

如果需要绘制径向墨水波纹（例如 Material Design 中的效果），子类可以在 paint 方法中调用 paintRadialReaction。
