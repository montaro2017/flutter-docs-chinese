Visibility 类

控制是否显示子级。

默认情况下，visible 属性决定是否将 child 纳入子树；如果 visible 为 false，则改为纳入 replacement 子级（通常是零尺寸盒子）。

可以使用多种标志调整隐藏子级的具体方式。（不建议动态更改这些标志，因为这可能导致 child 子树重建，并丢弃子树中的状态。通常只动态更改 visible 标志。）

以下 widget 提供了此 widget 的部分功能：

  • Opacity 可以阻止绘制其子级。
  • Offstage 可以阻止对子级进行布局或绘制。
  • TickerMode 可以阻止对子级执行动画。
  • ExcludeSemantics 可以让无障碍工具忽略子级。
  • IgnorePointer 可以禁用与子级之间的触摸交互。

隐藏子级并不一定要使用此 widget。最简单的方法是直接不包含该子级；如果必须提供子级（例如父级是 StatelessWidget），则可以使用 SizedBox.shrink 代替原本要包含的子级。

另请参阅：

  • AnimatedSwitcher 可以在子树变化时淡入淡出地切换子级。
  • AnimatedCrossFade 可以在两个指定的子级之间淡入淡出切换。
  • SliverVisibility 是此 widget 对应的 sliver 版本。
