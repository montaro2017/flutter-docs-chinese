FocusNode findLastFocus(
  1. FocusNode currentNode, {
  2. bool ignoreCurrentFocus = false,

当前没有焦点且焦点反向遍历时，返回应获得焦点的节点。

如果 currentNode 所属的最近 FocusScopeNode 当前没有焦点，此方法返回的节点应在焦点反向遍历（即调用 previous）时获得焦点。

如果 ignoreCurrentFocus 为 false 或未指定，此函数会优先返回 currentNode 最近范围中已设置的 FocusScopeNode.focusedChild；否则返回 sortDescendants 的最后一个节点。如果没有后代，则返回给定的 currentNode。

如果 ignoreCurrentFocus 为 true，算法会返回 sortDescendants 的最后一个节点；如果没有后代，则返回给定的 currentNode。

另请参阅：

  • previous，用于将焦点移至前一个节点的函数。
  • DirectionalFocusTraversalPolicyMixin.findFirstFocusInDirection，用于查找特定方向上第一个可获得焦点的组件。

实现

FocusNode findLastFocus(FocusNode currentNode, {bool ignoreCurrentFocus = false}) {
  return _findInitialFocus(currentNode, fromEnd: true, ignoreCurrentFocus: ignoreCurrentFocus);
}
