SelectableRegionSelectionStatusScope
description

SelectableRegionSelectionStatusScope 类 final

当 SelectableRegion 或 SelectionArea 下方的选区正在更改或已确定时，通知其监听器。

使用 SelectableRegionSelectionStatusScope.maybeOf 可访问 SelectableRegion 下方类型为 SelectableRegionSelectionStatus 的 ValueListenable。即使 SelectableRegionSelectionStatus 的值没有变化，也会调用其监听器。
