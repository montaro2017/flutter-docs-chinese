HtmlElementView 类

在 Flutter Web 的组件树中嵌入 HTML 元素。

嵌入的 HTML 会像其他 Flutter 组件一样参与布局，透明度、裁剪等变换也同样适用。

此组件会填满所有可用空间，因此其父组件必须提供有界的布局约束。

嵌入 HTML 是一项可能开销较大的操作；如果有 Flutter 等效实现，应避免使用。（请参阅下方的 isVisible 参数。）此组件适用于将原生 HTML 元素集成到 Flutter Web 应用中，例如 <video> 标签，或用于渲染 Google Map 的 <div>。

此组件仅适用于 Flutter Web。若要在其他平台嵌入 Web 内容，请考虑使用 webview_flutter 插件。

用法

使用 HtmlElementView 组件有两种方式：

HtmlElementView.fromTagName

HtmlElementView.fromTagName 构造函数会创建由 tagName 指定的 HTML 元素，并将其传递给 onElementCreated 回调，以便进行自定义：

// In a `build` method...
HtmlElementView.fromTagName(
  tagName: 'div',
  onElementCreated: myOnElementCreated,
);

此示例创建一个 <div> 元素，然后将新创建的 <div> 传递给 onElementCreated 回调，使其可以在附加到 DOM 之前进行自定义。

（有关 onElementCreated 的更多详情，请参阅下方的生命周期部分。）

使用 PlatformViewRegistry

用于实现 HtmlElementView.fromTagName 的基础 API 可通过 dart:ui_web 的 platformViewRegistry 通用使用。

通过这些基础 API 创建 HtmlElementView 分为两个步骤：

1. registerViewFactory

首先，需要为指定的 viewType 注册一个 viewFactory 函数。Flutter Web 会调用该工厂函数创建稍后要附加的 element：

import 'dart:ui_web' as ui_web;
import 'package:web/web.dart' as web;

void registerRedDivFactory() {
  ui_web.platformViewRegistry.registerViewFactory(
    'my-view-type',
    (int viewId, {Object? params}) {
      // Create and return an HTML Element from here
      final web.HTMLDivElement myDiv = web.HTMLDivElement()
        ..id = 'some_id_$viewId'
        ..style.backgroundColor = 'red'
        ..style.width = '100%'
        ..style.height = '100%';
      return myDiv;
    },
  );
}

必须在 build 方法之外调用 registerViewFactory，以确保执行 build 时注册的函数已可用。

以下是可用作 viewFactory 的不同函数类型：

  • typedef ui_web.PlatformViewFactory
  • typedef ui_web.ParameterizedPlatformViewFactory

2. HtmlElementView 组件

注册工厂后，可以将指定 viewType 的 HtmlElementView 组件添加到组件树中，例如：

// In a `build` method...
const HtmlElementView(
  viewType: 'my-view-type',
  onPlatformViewCreated: myOnPlatformViewCreated,
  creationParams: <String, Object?>{
    'key': 'someValue',
  },
);

viewType 必须与之前传递给 registerViewFactory 的值一致。

如果 viewFactory 函数接受 creationParams，则会将其传入（此参数可选）。

onPlatformViewCreated 会在由 viewFactory 创建的平台视图（element）附加到 DOM 之前，接收其 viewId。

The viewId can be used to retrieve the created element (The same one passed to onElementCreated in HtmlElementView.fromTagName) with the ui_web.platformViewRegistry.getViewById 方法.

（有关 onPlatformViewCreated 的更多详情，请参阅下方的生命周期部分。）

生命周期

HtmlElementView 组件与其他 Flutter 无状态组件类似，但额外提供一个生命周期回调：onPlatformViewCreated 或 onElementCreated（取决于使用的构造函数，参见上方的用法部分）。

这两个回调的区别在于它们接收的参数不同：

  • onPlatformViewCreated will be called with the created viewId as a parameter, and needs ui_web.platformViewRegistry.getViewById to retrieve the created element (See PlatformViewCreatedCallback).
  • onElementCreated will be called with the created element directly, skipping its viewId (See ElementCreatedCallback).

两个回调都会在 HTML element 创建之后、附加到 DOM 之前调用。

HTML 生命周期

浏览器 DOM API 为 HtmlElementView 的根 element 提供了额外的 HTML 生命周期回调。

元素附加到 DOM

JavaScript 代码通常通过选择器查找所需 DOM 元素，而不是直接接收这些元素。在这种情况下，element 必须先附加到 DOM，选择器才能正常工作。

下面的示例演示如何创建 onElementAttached 函数：使用 onElementCreated 生命周期方法，通过 package:web 中的 ResizeObserver，在根 element 附加到 DOM 时调用该函数：

import 'dart:js_interop';
import 'package:web/web.dart' as web;

// Called after `element` is attached to the DOM.
void onElementAttached(web.HTMLDivElement element) {
  final web.Element? located = web.document.querySelector('#someIdThatICanFindLater');
  assert(located == element, 'Wrong `element` located!');
  // Do things with `element` or `located`, or call your code now...
  element.style.backgroundColor = 'green';
}

void onElementCreated(Object element) {
  element as web.HTMLDivElement;
  element.style.backgroundColor = 'red';
  element.id = 'someIdThatICanFindLater';

  // Create the observer
  final web.ResizeObserver observer = web.ResizeObserver((
    JSArray<web.ResizeObserverEntry> entries,
    web.ResizeObserver observer,
  ) {
    if (element.isConnected) {
      // The observer is done, disconnect it.
      observer.disconnect();
      // Call our callback.
      onElementAttached(element);
    }
  }.toJS);

  // Connect the observer.
  observer.observe(element);
}
  • Read more about ResizeObserver in the MDN.

其他观察器

上面的示例使用 ResizeObserver，因为它可以直接应用于即将附加的 element。稍加编写更多代码后，也可以使用其他观察器，例如 MutationObserver。

MutationObserver 需要知道将要插入 HtmlElementView 的父元素。安全地获取平台视图父元素的方法，是读取渲染该 HtmlElementView 的 FlutterView 的 hostElement。

可以通过以下方式获取当前 FlutterView 的 hostElement：

import 'dart:js_interop';
import 'dart:ui_web' as ui_web;
import 'package:flutter/widgets.dart';

void useHostElement(BuildContext context) {
  final int flutterViewId = View.of(context).viewId;
  final JSAny? hostElement = ui_web.views.getHostElement(flutterViewId);
  // Use `package:web` with `hostElement`...
}

重要提示：FlutterView.viewId 与传递给 viewFactory 的 viewId 参数标识的是不同的对象：

  • flutterViewId (from View.of(context)) represents the FlutterView where the web app is currently rendering.
  • viewId (passed to the viewFactory function) represents a unique ID for the HtmlElementView instance that is being attached to the app.

请参阅 Flutter API 文档中有关 FlutterView 的更多信息：

  • View.of
  • getHostElement

指针事件

为了使 HtmlElementView 的内容可交互，它允许处理 pointer-events。这可能导致 Flutter 收不到部分事件，因为这些事件已由 HtmlElementView 处理，Flutter 因而无法观察到。

当需要在 HtmlElementView 上方叠加 Flutter 内容时，package:pointer_interceptor 在某些情况下会有所帮助。也可以在 onElementCreated 中将 pointer-events: none 属性设为生效；但这会阻止对底层 HTML 内容进行所有交互。

如果 HtmlElementView 是 <iframe> 元素，Flutter 将收不到落在该 <iframe> 中的指针事件（点击、轻点、拖动、放置等）。此时，HtmlElementView 看起来会像是吞掉了这些事件，Flutter 的手势检测也不会收到它们。

isVisible 参数

在 canvas 像素之间渲染自定义 HTML 内容（来自 HtmlElementView）时，Flutter Web 引擎需要将画布绘制内容拆分为位于 HTML 内容后方和前方的元素。

在 Flutter Web 引擎中，每次将画布拆分以便在中间嵌入 HTML 内容都称为一个覆盖层。

场景中的每个覆盖层都会影响内存占用和执行性能，因此最好尽量减少覆盖层数量；浏览器在同一场景中同时支持的覆盖层数量有限。

HtmlElementView 对象具有 isVisible 属性，可通过 registerViewFactory 或 fromTagName 传入。isVisible 表示 HtmlElementView 是否会在屏幕上绘制像素。

正确设置此值有助于 Flutter Web 渲染引擎优化绘制特定场景所需的覆盖层数量。

通常应将 isVisible 保持为默认值 true；但对于某些 HtmlElementView（例如 pointer_interceptor 或 Link 组件），可以将其设为 false，这样引擎就不会为了在不绘制任何像素的视图上方渲染 Flutter 内容而浪费覆盖层。
