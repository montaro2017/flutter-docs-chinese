ScrollController 类

控制可滚动 widget。

ScrollController 通常作为成员变量存储在 State 对象中，并在每次 State.build 调用中重复使用。一个 ScrollController 可以控制多个可滚动 widget，但某些操作（例如读取滚动 offset）要求 controller 只用于一个可滚动 widget。

ScrollController 会创建一个 ScrollPosition，用于管理单个 Scrollable widget 的专属状态。若要使用自定义的 ScrollPosition，请继承 ScrollController 并重写 createScrollPosition。

获取滚动信息

获取滚动和可滚动 widget 信息的方式有多种，但每种方式提供的信息各不相同，包括滚动活动、滚动位置以及 Viewport 尺寸等。

ScrollController 是一个 Listenable。每当其附加的 ScrollPosition 通知自身监听器时（例如发生滚动时），它也会通知自己的监听器。这与使用 NotificationListener 监听 ScrollNotification 类型的通知非常相似。区别在于，通知监听器会提供滚动活动的信息，还可以进一步监听 ScrollNotification 的特定子类，例如 UserScrollNotification。

此示例展示使用 ScrollController 或使用 NotificationListener 监听 ScrollNotification 类型通知来监听滚动活动的区别。切换 Radio 按钮即可在两者之间切换。使用 ScrollNotification 可以获取滚动活动详情及 ScrollPosition 的度量信息，但不能直接获取滚动位置对象本身。使用 ScrollController 监听时，则可以直接访问该位置对象。这两类通知都只会在发生滚动时触发。

ScrollController 在附加的 ScrollPosition 列表发生变化时不会通知其监听器。若要监听滚动位置附加到 controller 或从中分离，请使用 ScrollController.onAttach 和 ScrollController.onDetach。这也适用于在 Scrollable 的 build 方法中创建滚动位置时，为 ScrollPosition.isScrollingNotifier 添加监听器。

滚动位置刚附加时，ScrollMetrics（例如 ScrollMetrics.maxScrollExtent）尚不可用。只有 Scrollable 完成内容布局并计算内容总范围等信息后，这些度量值才会确定。可通过 ScrollPosition.hasContentDimensions 判断度量值何时可用，也可以使用下文进一步介绍的 ScrollMetricsNotification。

此示例展示如何使用 ScrollController.onAttach 为 ScrollPosition.isScrollingNotifier 添加监听器。滚动发生时，此监听器会更改 AppBar 的颜色。

来自不同的 context

如果需要从滚动 widget 内部的 context 获取滚动信息，请使用 Scrollable.of 访问 ScrollableState 及其 ScrollableState.position。这与附加到 ScrollController 的 ScrollPosition 相同。

如果需要从并非滚动 widget 祖先的 context 获取滚动信息，请使用 ScrollNotificationObserver。AppBar 就使用它来实现内容滚动到其下方时的效果。由于 Scaffold.appBar 和 Scaffold.body 位于不同子树中，滚动通知不会冒泡到 app bar。请使用 ScrollNotificationObserverState.addListener 监听当前 context 之外发生的滚动通知。

尺寸变化

最后，监听 ScrollController 或 ScrollPosition 时，若某个滚动位置的 ScrollMetrics 发生变化（例如窗口大小改变，导致 Viewport 尺寸及前文提到的可滚动范围发生变化），不会收到通知。若要监听滚动度量值的变化，请使用 NotificationListener 监听 ScrollMetricsNotification。这类通知与 ScrollNotification 不同：它不关联滚动活动，而是关联可滚动区域的尺寸，例如窗口大小。

通常与 ListView、GridView 和 CustomScrollView 搭配使用。

另请参阅：

  • ListView, GridView, CustomScrollView, which can be controlled by a ScrollController.
  • Scrollable, which is the lower-level widget that creates and associates ScrollPosition objects with ScrollController objects.
  • PageController, which is an analogous object for controlling a PageView.
  • ScrollPosition, which manages the scroll offset for an individual scrolling widget.
  • ScrollNotification 和 NotificationListener, which can be used to listen to scrolling occur without using a ScrollController.
