Actions 类

一种组件，可将 Intent 映射为其后代在调用 Action 时使用的 Action。

通常使用 Shortcuts 调用 Actions。也可以在包含环境中 Actions 组件的上下文中，通过 Actions.invoke 调用。

此示例创建了一个自定义的 Action 子类 ModifyAction，用于修改模型；另一个，SaveAction 则用于保存模型。

此示例演示如何向 Intent 传递参数，以便传给 Action。Action 可以从自身构造参数中获取数据（例如本示例中的 model），也可以从调用时传入的 intent 中获取（例如本示例中的递增 amount）。

此示例还演示了如何使用 Intent 限制 widget 对其周围环境的依赖。SaveButton widget（在此示例中定义）可以调用其祖先 widget 中定义的操作，并可根据它所在的 widget 树部分进行自定义。它无需了解 SaveAction 类，只需了解 SaveIntent，并且只需依赖一个值通知器，而不必了解整个模型。
