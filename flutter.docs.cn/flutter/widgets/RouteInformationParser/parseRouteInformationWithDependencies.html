parseRouteInformationWithDependencies 方法

Future<T> parseRouteInformationWithDependencies(
  1. RouteInformation routeInformation,
  2. BuildContext context
)

将给定的路由信息转换为已解析的数据，并传递给 RouterDelegate。

此方法应返回一个 future，并在解析完成时完成。如果解析器需要与 OEM 线程通信以获取有关路由的其他数据，解析过程可能是异步的。

如果结果可同步计算，可以考虑使用 SynchronousFuture，这样 Router 就不必等到下一个微任务才将数据传给 RouterDelegate。

输入的 BuildContext 可用于查找 InheritedWidget。如果使用 BuildContext.dependOnInheritedWidgetOfExactType，就会建立依赖关系。如果该依赖项通知其监听器，Router 会从 RouteInformationProvider 重新解析 RouteInformation。

也可以使用 BuildContext.getElementForInheritedWidgetOfExactType 查找 InheritedWidget，而不建立依赖关系。

实现

Future<T> parseRouteInformationWithDependencies(
  RouteInformation routeInformation,
  BuildContext context,
) {
  return parseRouteInformation(routeInformation);
}
