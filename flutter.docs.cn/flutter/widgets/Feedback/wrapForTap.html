包装 GestureTapCallback，使其在执行所提供的回调之前，为轻触操作提供与平台相关的反馈。

在 Android 上会播放平台常见的系统点击声。在 iOS 上则不执行任何操作，因为该平台通常不会为轻触提供反馈。

另请参阅：

  • forTap 仅用于触发平台特定的反馈，不封装 GestureTapCallback。

实现

static GestureTapCallback? wrapForTap(GestureTapCallback? callback, BuildContext context) {
  if (callback == null) {
    return null;
  }
  return () {
    forTap(context);
    callback();
  };
}
