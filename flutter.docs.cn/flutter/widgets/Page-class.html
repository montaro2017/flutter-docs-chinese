Page<T> 类 抽象

描述 Route 的配置。

类型参数 T 是对应 Route 的返回类型，用于 Route.currentResult、Route.popped 和 Route.didPop。

canPop 和 onPopInvoked 用于拦截弹出操作。

此示例演示如何使用 canPop 和 onPopInvoked 拦截弹出操作。
link

若要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.Page.1 mysample

另请参阅：

  • Navigator.pages, which accepts a list of Pages and updates its routes history.
