snapSizes 属性

List<double>? snapSizes
final

此 widget 应吸附到的目标尺寸列表。

吸附尺寸是相对于父容器高度的比例。列表必须按递增顺序排列，且各值必须介于 minChildSize 和 maxChildSize 之间。

minChildSize 和 maxChildSize 会隐式包含在吸附尺寸中，无需在此指定。例如，snapSizes = [.5] 会使面板在 minChildSize、.5 和 maxChildSize 之间吸附。

对 snapSizes 列表的任何修改，都要等到再次运行包含此 widget 的 build 函数后才会生效。

使用修改后的列表或新列表重新构建会触发吸附；但如果面板自首次构建或上次调用 DraggableScrollableActuator.reset 后尚未离开 initialChildSize，则不会触发。
