显示放大镜；如果调用 showMagnifier 时工具栏正在显示，也会将其隐藏。在非移动平台上调用此方法是安全的，因为这些平台不会提供 magnifierBuilder，或者 magnifierBuilder 会返回 null。

此属性不是判断放大镜是否显示的权威依据，因为放大镜可能会自行隐藏。如果需要此信息，请检查 MagnifierController.shown。

实现

void showMagnifier(MagnifierInfo initialMagnifierInfo) {
  // Do not show the magnifier if one already exists.
  if (_magnifierController.overlayEntry != null) {
    return;
  }
  if (toolbarIsVisible) {
    hideToolbar();
  }

  // Start from empty, so we don't utilize any remnant values.
  _magnifierInfo.value = initialMagnifierInfo;

  // Pre-build the magnifiers so we can tell if we've built something
  // or not. If we don't build a magnifiers, then we should not
  // insert anything in the overlay.
  final Widget? builtMagnifier = magnifierConfiguration.magnifierBuilder(
    context,
    _magnifierController,
    _magnifierInfo,
  );

  if (builtMagnifier == null) {
    return;
  }

  _magnifierController.show(
    context: context,
    below: magnifierConfiguration.shouldDisplayHandlesInMagnifier ? null : _handles?.start,
    builder: (_) => builtMagnifier,
  );
}
