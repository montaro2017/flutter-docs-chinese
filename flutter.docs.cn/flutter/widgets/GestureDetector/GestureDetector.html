创建一个用于检测手势的 widget。

不能同时使用 pan 和 scale 回调，因为 scale 是 pan 的超集。请改用 scale 回调。

不能同时使用水平和垂直拖动回调，因为水平拖动与垂直拖动的组合就是 pan。请改用 pan 回调。

默认情况下，手势检测器会向供辅助技术使用的语义树提供语义信息。

       final bool haveVerticalDrag =
           onVerticalDragStart != null ||
           onVerticalDragUpdate != null ||
           onVerticalDragEnd != null;
       final bool haveHorizontalDrag =
