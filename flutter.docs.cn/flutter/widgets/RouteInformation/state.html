state 属性

Object? state
final

应用在 uri 位置的状态。

即使位于同一位置，应用也可能有不同状态。例如 TextField 中的文本或 ScrollView 的滚动位置。这些 widget 状态可以存储在 state 中。

在 Web 平台上，Router 通过 PlatformRouteInformationProvider 将此路由信息报告回 Web 引擎时，信息会存入浏览器历史记录。用户点击后退或前进按钮时，浏览器会连同 uri 一起传回这些信息。

出于状态恢复的需要，此信息也会与 uri 一同序列化并持久化。状态恢复期间，这些信息会再次提供给 Router，使其能够恢复到先前的配置。

此状态必须可序列化。
