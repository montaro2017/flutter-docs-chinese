TrackingScrollController 类

一种 ScrollController，其 initialScrollOffset 会跟踪最近更新的 ScrollPosition。

此类可用于同步两个或多个延迟创建的滚动视图的滚动偏移量，这些视图共用一个 TrackingScrollController。它会跟踪最近更新的滚动位置，并将该位置报告为 initialScrollOffset。

在此示例中，每个 PageView 页面都包含一个 ListView，三个 ListView 共用同一个 TrackingScrollController。在列表长度允许的范围内，三个列表视图的滚动偏移量会彼此同步。
link 
PageView(
  children: <Widget>[
    ListView(
      controller: _trackingScrollController,
      children: List<Widget>.generate(100, (int i) => Text('page 0 item $i')).toList(),
    ),
    ListView(
      controller: _trackingScrollController,
      children: List<Widget>.generate(200, (int i) => Text('page 1 item $i')).toList(),
    ),
    ListView(
     controller: _trackingScrollController,
     children: List<Widget>.generate(300, (int i) => Text('page 2 item $i')).toList(),
    ),
  ],
)

在此示例中，_trackingController 由构建该 widget 树的有状态 widget 创建。

Creates a scroll controller that continually updates its initialScrollOffset to match the last scroll notification it received.
