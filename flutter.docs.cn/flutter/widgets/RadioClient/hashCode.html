hashCode 属性

int get hashCode
继承

此对象的哈希码。

哈希码是一个整数，表示对象中影响 operator == 比较的状态。

所有对象都有哈希码。Object 实现的默认哈希码只表示对象的身份，这与默认的 operator == 实现只在对象相同时才认为它们相等的方式一致（参见 identityHashCode）。

如果重写 operator == 以改为使用对象状态，那么哈希码也必须随之更改以表示该状态，否则该对象就无法用于基于哈希的数据结构，例如默认的 Set 和 Map 实现。

彼此相等（依据 operator ==）的对象必须具有相同的哈希码。对象的哈希码只应在对象以影响相等性的方式发生变化时才改变。哈希码没有其他要求。它们不需要在程序的多次执行之间保持一致，也没有分布方面的保证。

不相等的对象可以具有相同的哈希码。理论上甚至允许所有实例都使用同一哈希码；但如果冲突过于频繁，可能降低 HashSet 或 HashMap 等基于哈希的数据结构的效率。

如果子类重写了 hashCode，那么它也应该重写 operator == 运算符以保持一致性。
