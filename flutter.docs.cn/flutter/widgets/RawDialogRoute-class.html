RawDialogRoute<T> 类

用于显示对话框弹出窗口、并允许自定义的通用路由。

它由 showGeneralDialog 在内部使用，也可以直接推入 Navigator 栈以启用状态恢复。有关状态恢复应用示例，请参阅 showGeneralDialog。

此函数接收一个 pageBuilder，通常用于构建对话框。对话框下方的内容会由 ModalBarrier 遮暗。builder 返回的组件与最初调用 showDialog 的位置不共享上下文。如果对话框需要动态更新，请使用 StatefulBuilder 或自定义 StatefulWidget。

barrierDismissible 参数用于指定点击屏障是否会关闭对话框。该参数默认为 true，且不能为 null。

barrierColor 参数用于指定模态屏障的颜色；屏障会使对话框下方的所有内容变暗。如果该参数为 null，则使用默认颜色 Colors.black54。

settings 参数定义此路由的设置。详情请参阅 RouteSettings。

DisplayFeature 可能会将屏幕分割为多个子屏幕。渲染内容时，会使用距离 anchorPoint 最近的子屏幕。

如果未提供 anchorPoint，则会使用 Directionality：

  • 当TextDirection.ltr时，anchorPoint 为 Offset.zero，内容会显示在左上角子屏幕中。
  • 当TextDirection.rtl时，anchorPoint 为 Offset(double.maxFinite, 0)，内容会显示在右上角子屏幕中。

如果未提供 anchorPoint，且组件树中也没有 Directionality 祖先组件，则组件会在调试模式下于构建期间触发断言。

另请参阅：

  • DisplayFeatureSubScreen，详细说明 DisplayFeature 如何将屏幕划分为多个子屏幕。
  • showGeneralDialog, which is a way to display a RawDialogRoute.
  • showDialog, which is a way to display a DialogRoute.
  • showCupertinoDialog, which displays an iOS-style dialog.
