ScrollActivity 类 抽象

拖动和甩动等滚动活动的基类。

另请参阅：

  • ScrollPosition, which uses ScrollActivity objects to manage the ScrollPosition ，其对应的原对象为 Scrollable.
实现类
  • BallisticScrollActivity
  • DragScrollActivity
  • DrivenScrollActivity
  • HoldScrollActivity
  • IdleScrollActivity

构造函数

ScrollActivity(ScrollActivityDelegate _delegate)
Initializes delegate for subclasses.

属性

delegate → ScrollActivityDelegate
此 activity 用于驱动滚动视图的 delegate。
无 setter
hashCode → int
此对象的哈希码。
无 setter继承
isScrolling → bool
执行此 activity 是否构成滚动行为。
无 setter
runtimeType → Type
此对象运行时类型的表示。
无 setter继承
shouldIgnorePointer → bool
此滚动活动进行期间，滚动视图是否应忽略指针事件。
无 setter
velocity → double
如果适用，表示此活动下滚动偏移当前自主变化的速度（即不受拖动手势等外部刺激影响时的速度），单位为逻辑像素/秒。
无 setter
