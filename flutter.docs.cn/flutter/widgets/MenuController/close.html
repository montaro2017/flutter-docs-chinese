close 方法

void close()

关闭与此 MenuController 关联的菜单。

将 MenuController 传递给 MenuAnchor、RawMenuAnchor 或 RawMenuAnchorGroup，即可将控制器与菜单关联。

如果祖先滚动了菜单锚点，或者视图尺寸发生变化，任何已打开的菜单都会自动关闭。

实现

void close() {
  _anchor?.handleCloseRequest();
}
