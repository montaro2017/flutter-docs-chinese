description

RestorableTextEditingController 类

一种 RestorableProperty，用于保存和恢复 TextEditingController。

可以通过 value getter 访问 TextEditingController。进行状态恢复时，此属性会将 TextEditingController.text 恢复为收集状态恢复数据时的值。
