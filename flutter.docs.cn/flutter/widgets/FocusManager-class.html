FocusManager 类

管理焦点树。

焦点树与 widget 树分离，且更加稀疏；它维护 widget 树中可聚焦 widget 之间的层级关系。

焦点管理器负责跟踪哪个 FocusNode 拥有主要输入焦点（primaryFocus），持有作为焦点树根节点的 FocusScopeNode（rootScope），并记录当前的 highlightMode。它还会将 KeyEvent 分发给焦点树中的节点。

单例 FocusManager 实例由 WidgetsBinding 通过 WidgetsBinding.focusManager 持有，也可以使用静态访问器 FocusManager.instance 方便地访问。

要根据 FocusNode 查找给定的 BuildContext，请使用 Focus.of。要根据 FocusScopeNode 查找给定的 BuildContext，请使用 FocusScope.of。

如果需要在 primaryFocus 每次变化时收到通知，请使用 addListener 注册监听器。不再需要接收这些事件时（例如对象即将释放），必须使用 removeListener 注销监听器，以避免内存泄漏。有状态 widget 通常会在 State.dispose 中移除监听器。

highlightMode 用于描述 UI 组件如何显示焦点高亮。highlightMode 的变化会通过 addHighlightModeListener 单独通知，并通过 removeHighlightModeListener 取消监听。用户在鼠标和触摸操作之间切换时，高亮模式也会随之变化。

用于管理 widget 树中焦点的 widget 包括：

  • Focus：在焦点树中管理 FocusNode，使焦点树反映 widget 层级的变化。
  • FocusScope：在焦点树中管理 FocusScopeNode，并创建新的 scope，以将焦点限制在一组焦点节点内。
  • FocusTraversalGroup：将应按指定 FocusTraversalPolicy 顺序遍历的节点分组。

另请参阅：

  • FocusNode：焦点树中可以接收焦点的节点。
  • FocusScopeNode：焦点树中的节点，用于将子树归为一组并限制焦点范围。
  • primaryFocus 全局访问器：方便从任意位置访问当前焦点管理器状态。
