UiKitView 类

在 Widget 层级结构中嵌入 iOS 视图。

嵌入 iOS 视图的开销较高；如果可以使用 Flutter 等效组件，应避免这样做。

此 widget 会占满所有可用空间，因此其父级必须提供有界的布局约束。

此 widget 会参与 Flutter 的手势竞技场，并且仅在赢得竞技场后才向平台视图分发触摸事件。可在构造函数的 gestureRecognizers 参数中指定应分发给平台视图的手势。如果手势识别器集合为空，只有在没有其他手势识别器认领手势时，才会将手势分发给平台视图。

平台视图的生命周期与此 widget 的 State 对象相同。当 State 被释放时，平台视图及其辅助资源会延迟释放（部分资源立即释放，部分由平台垃圾回收器释放）。当有状态 widget 从树中移除或在树中移动时，其状态会被释放。如果该 widget 有 key，且只是在同级节点之间移动；或者它有 GlobalKey 并在树中移动，则不会被释放。

UIView 会异步创建。在 UIView 准备就绪之前，此 widget 不会绘制任何内容，但会保持相同的布局约束。

对 UiKitView 执行裁剪操作可能导致性能下降。由于 Quartz 的限制，如果对 UIKitView 使用圆锥路径裁剪，会改用四边形路径近似裁剪效果。
