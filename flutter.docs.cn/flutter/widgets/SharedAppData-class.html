SharedAppData 类

允许与 child 及其所有后代共享键值数据。

  • SharedAppData.getValue(context, key, initCallback) 会创建对该键的依赖，并从共享数据表中返回该键的值。如果该键没有对应的值，则使用 initCallback 创建初始值。

  • SharedAppData.setValue(context, key, value) 会更改共享数据表中某个条目的值，并强制依赖该条目的 widget 重新构建。

如果某个 widget 的 build 方法使用 SharedAppData.getValue(context, keyword, initCallback)，它就会依赖 SharedAppData。keyword 的值通过 SharedAppData.setValue() 更改时，该 widget 会重新构建。SharedAppData 管理的值应为不可变对象：值的内部状态发生变化不会触发依赖它的 widget 重新构建。

此 widget 的实例会由 WidgetsApp 自动创建。

有很多方法可以与 widget 子树共享数据。此类基于 InheritedModel，而它是 InheritedWidget 的一种。此类旨在供需要在自己的组件之间共享少量值的软件包使用。

SharedAppData 并非 Provider 或其他通用应用状态管理系统的替代品。它适用于软件包的自定义 widget 需要共享一个或少量可延迟初始化的不可变数据对象的场景。借助它，这些软件包可以提供自定义 widget，而无需开发者在应用中额外添加该软件包专属的外层 widget。

为 SharedAppData 创建键时，可使用静态的 Object() 值来避免与其他软件包潜在的键冲突。下方的 SharedObject 示例采用了这种做法。
