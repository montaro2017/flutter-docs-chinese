Stack 类

一种根据自身边缘来放置子级的 widget。

如果要以简单方式重叠多个子级，此类很有用。例如，可以将文本和图像叠放，并添加渐变背景以及位于底部的按钮。

Stack widget 的每个子级都是定位子级或非定位子级。定位子级是指由至少一个属性非 null 的 Positioned widget 包裹的子级。Stack 会调整自身大小以容纳所有非定位子级，并根据 alignment 放置这些子级（从左到右的环境中默认为左上角，从右到左的环境中默认为右上角）。随后，Stack 会根据定位子级的 top、right、bottom 和 left 属性放置它们。

Stack 按顺序绘制子级，第一个子级位于最底层。若要更改子级的绘制顺序，可以按新的顺序重新构建 Stack。以这种方式调整顺序时，可以为子级设置非 null 的 key。这样框架会将子级底层对象移动到新位置，而不是重新创建它们。

有关 Stack 布局算法的详细信息，请参阅 RenderStack。

如果要按特定模式排列多个子级，或创建自定义布局管理器，可能应改用 CustomMultiChildLayout。特别是，使用 Stack 时，无法根据子级自身大小或 Stack 的大小来定位子级。

使用 Stack 可以将 widget 彼此叠放。

link 
Stack(
  children: <Widget>[
    Container(
      width: 100,
      height: 100,
      color: Colors.red,
    ),
    Container(
      width: 90,
      height: 90,
      color: Colors.green,
    ),
    Container(
      width: 80,
      height: 80,
      color: Colors.blue,
    ),
  ],
)

此示例展示如何使用 Stack 添加渐变背景，从而提高文本的可读性。

link 
SizedBox(
  width: 250,
  height: 250,
  child: Stack(
    children: <Widget>[
      Container(
        width: 250,
        height: 250,
        color: Colors.white,
      ),
      Container(
        padding: const EdgeInsets.all(5.0),
        alignment: Alignment.bottomCenter,
        decoration: BoxDecoration(
          gradient: LinearGradient(
            begin: Alignment.topCenter,
            end: Alignment.bottomCenter,
            colors: <Color>[
              Colors.black.withAlpha(0),
              Colors.black12,
              Colors.black45
            ],
          ),
        ),
        child: const Text(
          'Foreground Text',
          style: TextStyle(color: Colors.white, fontSize: 20.0),
        ),
      ),
    ],
  ),
)
