RawImage 类

直接显示 dart:ui.Image 的组件。

图像通过 paintImage 绘制；该函数会更详细地说明此类各字段的含义。

此组件不会释放 image。创建该组件的调用方应在 RawImage 不再需要构建后，对 image 调用 dart:ui.Image.dispose。

scale 参数指定以预期尺寸绘制图像时使用的线性缩放因子，并同时适用于宽度和高度。例如，值为 2.0 表示每个逻辑像素对应四个图像像素；图像的实际宽高（由 dart:ui.Image.width 和 dart:ui.Image.height 属性给出）是绘制时应使用的宽高的两倍（例如传递给 Canvas.drawImage 的参数）。

此组件很少直接使用。建议改用 Image。
