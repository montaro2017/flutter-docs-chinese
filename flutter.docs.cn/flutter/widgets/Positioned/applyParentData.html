重写

将此组件中的数据写入给定渲染对象的父级数据。

每当框架检测到与 RenderObject 关联的 child 的 RenderObject.parentData 已过时时，就会调用此函数。例如，渲染对象刚被插入渲染树时，其 parent data 可能与此组件中的数据不一致。

子类应重写此函数，将自身字段中的数据复制到给定渲染对象的 RenderObject.parentData 字段中。该渲染对象的父级保证由类型为 T 的组件创建，因此此函数通常可以假定：父级的 parent data 对象继承自某个特定类。

如果此函数修改的数据可能影响父级的布局或绘制，就必须根据情况在父级上调用 RenderObject.markNeedsLayout 或 RenderObject.markNeedsPaint。

实现

@override
void applyParentData(RenderObject renderObject) {
  assert(renderObject.parentData is StackParentData);
  final parentData = renderObject.parentData! as StackParentData;
  var needsLayout = false;

  if (parentData.left != left) {
    parentData.left = left;
    needsLayout = true;
  }

  if (parentData.top != top) {
    parentData.top = top;
    needsLayout = true;
  }

  if (parentData.right != right) {
    parentData.right = right;
    needsLayout = true;
  }

  if (parentData.bottom != bottom) {
    parentData.bottom = bottom;
    needsLayout = true;
  }

  if (parentData.width != width) {
    parentData.width = width;
    needsLayout = true;
  }

  if (parentData.height != height) {
    parentData.height = height;
    needsLayout = true;
  }

  if (needsLayout) {
    renderObject.parent?.markNeedsLayout();
  }
}
