FocusScope 类

FocusScope 类似于 Focus，但还为其后代提供一个范围，将焦点遍历限制在该范围内的控件。

例如，推入新 route 时会自动创建新的 FocusScope，防止焦点遍历移动到上一条 route 中的控件。

如果只想将 widget 编组，使其按特定顺序遍历，但焦点仍可离开该组，请使用 FocusTraversalGroup。

与 Focus 一样，FocusScope 提供 onFocusChange，用于在此 widget 获得或失去焦点时接收通知。

onKey 参数允许指定按键事件处理器；当此节点或其任一子项拥有焦点时会调用该处理器。按键首先发送给拥有主要焦点的 widget，然后沿该节点的祖先节点传播；如果某个节点的 onKey 返回 KeyEventResult.handled，表示已处理事件，传播就会停止。

管理 FocusScopeNode 包括管理其生命周期、监听焦点变化，并在需要时重新指定父节点，以使焦点层级与 widget 层级保持同步。此 widget 会为你处理这些工作。如果不使用 FocusScope widget 而需要自行管理节点，请参阅 FocusScopeNode 了解详情。

FocusScopeNode 会记住其后代中最近获得焦点的 FocusNode。对 FocusNode 或 FocusScopeNode 调用 FocusNode.nextFocus、FocusNode.previousFocus 或 FocusNode.focusInDirection 时，可将焦点移动到下一个／上一个节点或特定方向上的节点。

To move the focus, use methods on FocusNode by getting the FocusNode through the of method. For instance, to move the focus to the next node in the focus traversal order, call Focus.of(context).nextFocus(). To unfocus a widget, call Focus.of(context).unfocus().
