创建一个默认文本样式，用于覆盖 widget 树中当前位置作用域内的文本样式。

给定的 style 会与插入此 widget 的 BuildContext 对应默认文本样式中的 style 合并；其他非 null 参数则会替换该默认文本样式中的相应属性。

此构造函数无法将祖先 DefaultTextStyle 的 maxLines 属性覆盖为 null，因为这里的 null 表示“沿用祖先设置”。如果要将祖先的非 null maxLines 改为 null（取消行数限制），请手动使用 DefaultTextStyle.of 获取当前默认文本样式，然后直接用 DefaultTextStyle.new 构造函数创建新的 DefaultTextStyle。下面的源代码提供了示例，因为这基本上就是此构造函数内部所做的事情。

如果提供了 textHeightBehavior，现有配置会被完全替换。若要保留原 textHeightBehavior 的部分设置，请使用 DefaultTextStyle.of 手动获取当前的 DefaultTextStyle。

实现

static Widget merge({
  Key? key,
  TextStyle? style,
  TextAlign? textAlign,
  bool? softWrap,
  TextOverflow? overflow,
  int? maxLines,
  TextWidthBasis? textWidthBasis,
  TextHeightBehavior? textHeightBehavior,
  required Widget child,
}) {
  return Builder(
    builder: (BuildContext context) {
      final DefaultTextStyle parent = DefaultTextStyle.of(context);
      return DefaultTextStyle(
        key: key,
        style: parent.style.merge(style),
        textAlign: textAlign ?? parent.textAlign,
        softWrap: softWrap ?? parent.softWrap,
        overflow: overflow ?? parent.overflow,
        maxLines: maxLines ?? parent.maxLines,
        textWidthBasis: textWidthBasis ?? parent.textWidthBasis,
        textHeightBehavior: textHeightBehavior ?? parent.textHeightBehavior,
        child: child,
      );
    },
  );
}
