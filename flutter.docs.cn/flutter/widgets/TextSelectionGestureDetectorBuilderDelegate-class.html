TextSelectionGestureDetectorBuilderDelegate 类 抽象

TextSelectionGestureDetectorBuilder 的 delegate 接口。

此接口通常由封装 EditableText 的文本字段实现类中的 State 实现，以便使用 TextSelectionGestureDetectorBuilder 为其 EditableText 构建 TextSelectionGestureDetector。delegate 会向 builder 提供文本字段的当前状态信息，builder 再据此为手势检测器添加合适的手势处理器。

另请参阅：

  • TextField, which implements this delegate for the Material text field.
  • CupertinoTextField, which implements this delegate for the Cupertino text field.
