重写

返回一个从给定位置以给定速度开始的弹道滚动模拟。

ScrollPositionWithSingleContext 会在 ScrollPositionWithSingleContext.goBallistic 方法中使用此结果。如果结果不为 null，ScrollPositionWithSingleContext 会根据返回值启动 BallisticScrollActivity；否则会改为启动空闲活动。

给定的 position 仅在此方法调用期间有效。不要保留该对象的引用供之后使用，因为其中的值可能会更新、保持不变，或更新为完全无关的另一个可滚动组件的数据。

此方法可能每一帧都会被调用，甚至可能发生在用户感知为一次连续弹道滚动的过程中。例如，在 ListView 中，先前位于屏幕外的条目进入视野并完成布局时，可能会以新的 ScrollMetrics.maxScrollExtent 调用此方法。实现时应确保：如果仍然需要相同的弹道滚动运动，这些调用除了继续该运动外，不会对滚动物理效果产生副作用。

通常，可让 Simulation 符合弹道飞行粒子的物理模型来保证这一点：作用于粒子的力只取决于其位置、速度和环境，而不取决于当前时间或任何内部状态。这意味着，Simulation.dx 对时间的导数应能仅用 Simulation.x、Simulation.dx 的值以及构造 Simulation 时使用的参数表示，并且与时间无关。

实现

@override
Simulation? createBallisticSimulation(ScrollMetrics position, double velocity) {
  // If we're out of range and not headed back in range, defer to the parent
  // ballistics, which should put us back in range at a page boundary.
  if ((velocity <= 0.0 && position.pixels <= position.minScrollExtent) ||
      (velocity >= 0.0 && position.pixels >= position.maxScrollExtent)) {
    return super.createBallisticSimulation(position, velocity);
  }
  final Tolerance tolerance = toleranceFor(position);
  final double target = _getTargetPixels(position, tolerance, velocity);
  if (target != position.pixels) {
    return ScrollSpringSimulation(
      spring,
      position.pixels,
      target,
      velocity,
      tolerance: tolerance,
    );
  }
  return null;
}
