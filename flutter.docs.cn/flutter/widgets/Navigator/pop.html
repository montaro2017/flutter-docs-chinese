pop<T extends Object?> static 方法

  1. @optionalTypeArgs
void pop<T extends Object?>(
  1. BuildContext context, [
  2. T? result

从距离给定 context 最近的 Navigator 中弹出栈顶路由。

首先调用当前路由的 Route.didPop 方法。如果该方法返回 false，则路由仍保留在 Navigator 的历史记录中（这表示该路由预期已弹出某些内部状态；例如 LocalHistoryRoute）。否则，以下说明适用。

如果 result 非 null，它将作为被弹出路由的返回结果；先前推入该路由时返回的 future 会以 result 完成。对话框或弹出菜单等路由通常使用此机制，将用户选择的值返回给创建该路由的 widget。如果提供了 result，其类型必须与被弹出路由所属类的类型参数 T 相符。

被弹出的路由及其下方的路由都会收到通知（参见 Route.didPop、Route.didComplete 和 Route.didPopNext）。如果 Navigator 配置了 Navigator.observers，这些观察者也会收到通知（参见 NavigatorObserver.didPop）。

T 类型参数表示被弹出路由的返回值类型。

如果提供了 result，其类型必须与被弹出路由所属类的类型参数 T 相符。

关闭路由的典型用法如下：
link 
void _close() {
  Navigator.pop(context);
}

也可以通过返回结果来关闭对话框：

void _accept() {
  Navigator.pop(context, true); // dialog returns true
}

实现

@optionalTypeArgs
static void pop<T extends Object?>(BuildContext context, [T? result]) {
  Navigator.of(context).pop<T>(result);
}
