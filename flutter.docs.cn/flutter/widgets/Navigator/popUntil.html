popUntil static 方法

void popUntil(
  1. BuildContext context,
  2. RoutePredicate predicate
)

在距离给定 context 最近的 Navigator 上重复调用 pop，直到谓词返回 true。

如果 Route.willHandlePopInternally 为 true，同一路由可能会多次应用该谓词。

要一直弹出路由，直到遇到具有特定名称的路由，请使用由 ModalRoute.withName 返回的 RoutePredicate。

这些路由会以 null 作为 return 值关闭。

有关弹出路由语义的更多详情，请参阅 pop。

典型用法如下：
link 
void _logout() {
  Navigator.popUntil(context, ModalRoute.withName('/login'));
}

实现

static void popUntil(BuildContext context, RoutePredicate predicate) {
  Navigator.of(context).popUntil(predicate);
}
