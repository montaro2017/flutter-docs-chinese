canPop static 方法

bool canPop(
  1. BuildContext context
)

给定 context 最近的祖先 Navigator 是否可以弹出路由。

初始路由不能从 Navigator 中弹出；也就是说，只有当弹出 Navigator 不会移除初始路由时，此函数才返回 true。

如果当前作用域内没有 Navigator，则返回 false。

此方法不会考虑可能从外部阻止弹出的因素，例如 PopEntry。

另请参阅：

  • Route.isFirst 对 canPop 返回 false 的路由返回 true。

实现

static bool canPop(BuildContext context) {
  final NavigatorState? navigator = Navigator.maybeOf(context);
  return navigator != null && navigator.canPop();
}
