将给定路由推入距离给定 context 最近的 Navigator，然后移除所有先前路由，直到 predicate 返回 true。

如果 Route.willHandlePopInternally 为 true，同一路由可能会多次应用该谓词。

若要移除路由，直到遇到具有指定名称的路由，请使用 RoutePredicate 返回的 ModalRoute.withName。

若要移除推入路由下方的所有路由，请使用始终返回 false 的 RoutePredicate（例如，(Route<dynamic> route) => false）。

被移除的路由不会完成，因此此方法不接收返回值参数。

The newly pushed route and its preceding route are notified for Route.didPush. After removal, the new route and its new preceding route, (the route below the bottommost removed route) are notified through Route.didChangeNext). If the Navigator has any Navigator.observers, they will be notified as well (see NavigatorObserver.didPush 和 NavigatorObserver.didRemove). The removed routes are disposed of and notified, once the new route has finished animating. The futures that had been returned from pushing those routes will complete.

向当前路由推入新路由时，当前路由中正在进行的手势会被取消。

类型参数 T 表示新路由返回值的类型。

返回一个 Future；当推入的路由从 Navigator 弹出时，该 Future 会完成，并携带传递给 pop 的 result 值。

Typical usage is as follows:
link 
void _finishAccountCreation() {
  Navigator.pushAndRemoveUntil<void>(
    context,
    MaterialPageRoute<void>(builder: (BuildContext context) => const MyHomePage()),
    ModalRoute.withName('/'),
  );
}

另请参阅：

  • restorablePushAndRemoveUntil, which pushes a route that can be restored during state restoration.

实现

@optionalTypeArgs
@awaitNotRequired
static Future<T?> pushAndRemoveUntil<T extends Object?>(
  BuildContext context,
  Route<T> newRoute,
  RoutePredicate predicate,
) {
  return Navigator.of(context).pushAndRemoveUntil<T>(newRoute, predicate);
}
