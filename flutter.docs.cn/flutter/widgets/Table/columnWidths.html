columnWidths 属性

Map<int, TableColumnWidth>? columnWidths
final

用于确定此表格各列水平范围的方式。

如果 Map 中某一列对应的条目为 null，表格会改用 defaultColumnWidth。默认情况下，该属性使用弹性布局，在各列之间平均分配剩余空间。

可以使用 FixedColumnWidth 类指定以像素为单位的固定宽度。这是确定表格列宽开销最低的方式。

表格的布局性能在很大程度上取决于此处使用的列宽算法。尤其是 IntrinsicColumnWidth 开销很高，因为它需要测量列中的每个单元格，才能确定该列的固有尺寸。

此 Map 的键（列索引）从 0 开始。

如果设为 null，则会按空 Map 处理。
