defaultColumnWidth 属性

TableColumnWidth defaultColumnWidth
final

用于确定未显式指定尺寸算法的列的宽度。

如果 columnWidths[i] 为 null，则第 i 列使用 defaultColumnWidth。默认值为 FlexColumnWidth，它会在具有相同 TableColumnWidth 类型的列之间平均分配剩余水平空间。

由于水平空间是无限的，位于水平 ScrollView 中的 Table 必须使用 FixedColumnWidth 或 IntrinsicColumnWidth。
