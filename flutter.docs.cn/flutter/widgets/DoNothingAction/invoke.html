invoke 方法

重写

执行此操作时调用。

通过 Actions.invoke 调用某个操作时，或直接使用 ActionDispatcher.invokeAction 调用时，ActionDispatcher 会调用此方法。

此方法仅供 ActionDispatcher 或其子类调用，并且只有在 isEnabled 为 true 时才能调用。

重写此方法时，返回值可以是任意 Object；但如果将重写方法的返回类型改为与实际返回值一致，就能获得更好的类型安全性。

例如，如果重写的 invoke 方法返回 int，可以这样定义：

class IncrementIntent extends Intent {
  const IncrementIntent({required this.index});

  final int index;
}

class MyIncrementAction extends Action<IncrementIntent> {
  @override
  int invoke(IncrementIntent intent) {
    return intent.index + 1;
  }
}

若要接收操作调用的结果，必须使用 Actions.invoke 或 ActionDispatcher 来调用该操作。通过 Shortcuts 组件触发的操作会忽略其返回值。

如果操作的行为依赖于 BuildContext，请继承 ContextAction，而不是 Action。
