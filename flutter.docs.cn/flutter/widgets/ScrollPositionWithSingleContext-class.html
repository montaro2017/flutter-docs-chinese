ScrollPositionWithSingleContext 类

管理单个 ScrollContext 滚动活动的滚动位置。

此类是 ScrollPosition 逻辑的具体子类，用于处理单个 ScrollContext，例如 Scrollable。此类的实例负责管理 ScrollActivity 实例，这些活动会改变 Scrollable 的 Viewport 中可见的内容。

获取滚动信息

获取滚动和可滚动 widget 信息的方式有多种，但每种方式提供的信息各不相同，包括滚动活动、滚动位置以及 Viewport 尺寸等。

ScrollController 是一个 Listenable。每当其附加的 ScrollPosition 通知自身监听器时（例如发生滚动时），它也会通知自己的监听器。这与使用 NotificationListener 监听 ScrollNotification 类型的通知非常相似。区别在于，通知监听器会提供滚动活动的信息，还可以进一步监听 ScrollNotification 的特定子类，例如 UserScrollNotification。

此示例展示使用 ScrollController 或使用 NotificationListener 监听 ScrollNotification 类型通知来监听滚动活动的区别。切换 Radio 按钮即可在两种方式间切换。使用 ScrollNotification 可以获取滚动活动及 ScrollPosition 度量值的详细信息，但无法直接获取滚动位置对象本身。使用 ScrollController 监听时，则可以直接访问该位置对象。这两类通知都只会在发生滚动时触发。

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.ScrollPosition.1 mysample

ScrollController 不会在附加到它的 ScrollPosition 列表发生变化时通知监听器。若要监听滚动位置附加到控制器或从控制器分离，请使用 ScrollController.onAttach 和 ScrollController.onDetach 方法。这也适用于在 Scrollable 的构建过程中创建滚动位置时，为 ScrollPosition.isScrollingNotifier 添加监听器。

滚动位置刚附加时，ScrollMetrics（例如 ScrollMetrics.maxScrollExtent）尚不可用。只有等到 Scrollable 完成内容布局并计算内容总范围等信息后，才能确定这些度量值。可使用 ScrollPosition.hasContentDimensions 判断度量值何时可用，也可以使用下文介绍的 ScrollMetricsNotification。

从其他上下文访问

如果要从滚动 widget 内部的某个上下文获取滚动信息，请使用 Scrollable.of 访问 ScrollableState 及其 ScrollableState.position。这就是附加到 ScrollController 的同一个 ScrollPosition。

如果要从并非滚动 widget 祖先的上下文获取滚动信息，请使用 ScrollNotificationObserver。AppBar 就使用它来创建内容滚动到其下方时的视觉效果。由于 Scaffold.appBar 和 Scaffold.body 位于不同的子树中，滚动通知不会向上冒泡到应用栏。请使用 ScrollNotificationObserverState.addListener 监听当前上下文之外发生的滚动通知。

尺寸变化

最后，监听 ScrollController 或 ScrollPosition 不会在给定滚动位置的 ScrollMetrics 发生变化时通知监听器，例如窗口调整大小导致 Viewport 尺寸和前述可滚动范围发生变化。若要监听滚动度量值的变化，请使用 NotificationListener 监听 ScrollMetricsNotification。这类通知不同于 ScrollNotification：它与滚动活动无关，而是针对可滚动区域的尺寸变化，例如窗口大小变化。
