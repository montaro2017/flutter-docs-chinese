TwoDimensionalScrollView
description

TwoDimensionalScrollView 类 抽象

一种 widget，将 TwoDimensionalScrollable 与 TwoDimensionalViewport 组合起来，在垂直和水平方向上创建可交互的内容滚动区域。

双向滚动 widget 由三个部分组成：

  1. A TwoDimensionalScrollable widget, which listens for various user gestures and implements the interaction design for scrolling.
  2. A TwoDimensionalViewport widget, which implements the visual design for scrolling by displaying only a portion of the widgets inside the scroll view.
  3. A TwoDimensionalChildDelegate, which provides the children visible in the scroll view.

TwoDimensionalScrollView 负责协调这些部分：它会创建 TwoDimensionalScrollable，并交由子类实现 buildViewport，以构建 TwoDimensionalViewport 的子类。TwoDimensionalChildDelegate 通过 delegate 参数提供。

TwoDimensionalScrollView 有两个不同的 ScrollPosition，每个 Axis 各一个。因此，这些位置也分别使用不同的 ScrollController。若要通过 ScrollController 访问 ScrollPosition，请使用传给此滚动视图的对应轴的 ScrollableDetails.controller 属性。
