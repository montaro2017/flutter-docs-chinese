ScrollableDetails 类

描述 Scrollable widget 的相关属性，以便供 ScrollBehavior 等继承型 widget 用于装饰，或供 TwoDimensionalScrollable 等组合滚动组件枚举这些属性。

GlowingOverscrollIndicator 和 Scrollbar 等装饰组件需要了解 Scrollable 的信息才能完成初始化。
