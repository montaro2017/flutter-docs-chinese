Dismissible 类

可沿指定方向拖动以关闭的 widget。

沿 DismissDirection 指定的方向拖动或快速滑动此 widget，会使其子项滑出视野。滑动动画结束后，如果 resizeDuration 不为 null，Dismissible widget 会在 resizeDuration 指定的时长内，将自身高度（或宽度，取决于哪个方向与关闭方向垂直）动画调整为零。

此示例展示如何使用 Dismissible widget，通过滑动手势移除列表项。向左或向右滑动任意列表项，即可将其从 ListView 中关闭。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.Dismissible.1 mysample

可以使用背景实现“滑走后露出内容”的交互模式。如果指定了背景，它会叠放在 Dismissible 子项后面，并在子项移动时显露出来。

当尺寸缩小到零后（如果 resizeDuration 不为 null），或在滑动动画结束后立即（如果 resizeDuration 为 null），此 widget 会调用 onDismissed 回调。如果 Dismissible 是列表项，就必须为其设置一个能与其他项区分开的 key，并在 onDismissed 回调中从列表移除此项。
