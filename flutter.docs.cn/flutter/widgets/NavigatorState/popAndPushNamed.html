从 Navigator 中弹出当前路由，并在其位置推入一个命名路由。

先前路由的弹出操作按照 pop 的规则处理。

新路由的名称会传递给 Navigator.onGenerateRoute 回调。回调返回的路由将被推入 Navigator。

The new route, the old route, and the route below the old route (if any) are all notified (see Route.didPop, Route.didComplete, Route.didPopNext, Route.didPush, and Route.didChangeNext). If the Navigator has any Navigator.observers, they will be notified as well (see NavigatorObserver.didPop 和 NavigatorObserver.didPush). The animations for the pop and the push are performed simultaneously, so the route below may be briefly visible even if both the old route and the new route are opaque (see TransitionRoute.opaque).

向当前路由推入新路由时，当前路由中正在进行的手势会被取消。

类型参数 T 是新路由返回值的类型，TO 是旧路由返回值的类型。

使用 popAndPushNamed 时，必须提供 Navigator.onGenerateRoute 回调。

返回一个 Future；当推入的路由从 Navigator 弹出时，该 Future 会完成，并携带传递给 pop 的 result 值。

提供的 arguments 会通过 RouteSettings.arguments 传递给被推入的路由。arguments 可以是任意对象（例如 String、int，或自定义的 MyRouteArguments 类实例）。通常使用 Map 传递键值对。

arguments 可用于 Navigator.onGenerateRoute 或 Navigator.onUnknownRoute，以构造路由。

典型用法如下：
link 
void _begin() {
  navigator.popAndPushNamed('/nyc/1776');
}

另请参阅：

  • restorablePopAndPushNamed, which pushes a new route that can be restored during state restoration.

实现

@awaitNotRequired
@optionalTypeArgs
Future<T?> popAndPushNamed<T extends Object?, TO extends Object?>(
  String routeName, {
  TO? result,
  Object? arguments,
}) {
  pop<TO>(result);
  return pushNamed<T>(routeName, arguments: arguments);
}
