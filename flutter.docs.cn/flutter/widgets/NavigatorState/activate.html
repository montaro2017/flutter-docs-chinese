activate 方法

  1. @protected

void activate()
重写

通过 deactivate 从组件树中移除后，将此对象重新插入树中时调用。

大多数情况下，State 对象停用后不会重新插入树中；框架会调用其 dispose 方法，表示它已准备好进行垃圾回收。

但在某些情况下，框架会将已停用的 State 对象重新插入树中的其他位置（例如，包含该 State 对象的子树因使用 GlobalKey 而从树中的一个位置移动到另一个位置）。发生这种情况时，框架会调用 activate，让 State 对象有机会重新获取它在 deactivate 中释放的资源。随后还会调用 build，使该对象能适应树中的新位置。如果框架确实重新插入该子树，会在移除该子树的动画帧结束前完成。因此，State 对象可以等到框架调用其 dispose 方法时，再释放大多数资源。

首次将 State 对象插入组件树时，框架不会调用此方法；这种情况下，框架会调用 initState。

实现应以调用继承的方法开始，例如 super.activate()。

另请参阅：

  • Element.activate，是 element 从“非活动”生命周期状态切换到“活动”状态时对应的方法。

实现

@protected
@override
void activate() {
  super.activate();
  _updateEffectiveObservers();
  for (final NavigatorObserver observer in _effectiveObservers) {
    assert(observer.navigator == null);
    NavigatorObserver._navigators[observer] = this;
  }
}
