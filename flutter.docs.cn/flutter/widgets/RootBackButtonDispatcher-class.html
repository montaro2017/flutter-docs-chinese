RootBackButtonDispatcher
description

RootBackButtonDispatcher 类

根路由器的默认返回按钮分发器实现。

此分发器会监听平台发出的弹出路由通知。平台希望弹出当前路由时，分发器会调用 BackButtonDispatcher.invokeCallback 方法处理请求。
