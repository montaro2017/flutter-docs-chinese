Overlay 类

一种可独立管理的条目堆栈。

Overlay 允许彼此独立的子 widget 将视觉元素插入其堆栈，使这些元素“悬浮”在其他 widget 上方。每个 widget 都可以通过 OverlayEntry 对象管理自己在 Overlay 中的显示。

虽然可以直接创建 Overlay，但最常见的做法是使用 WidgetsApp、CupertinoApp 或 MaterialApp 中 Navigator 创建的 Overlay。Navigator 使用它的 Overlay 管理各个路由的视觉呈现。

Overlay widget 使用自定义的堆栈实现，与 Stack widget 非常相似。Overlay 的主要用途与导航有关，可将 widget 插入应用页面上方。对于与导航无关的布局，请考虑改用 Stack。

Overlay widget 所在范围内必须存在 Directionality widget，以便解析其 Positioned.directional 子项中依赖方向的坐标。

对于在 OverlayEntry 中绘制的 widget，不要假定 Overlay 的尺寸等于 MediaQuery.sizeOf 返回的尺寸。嵌套 Overlay 的尺寸可能不同。
