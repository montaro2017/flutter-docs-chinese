AnimatedModalBarrier 类

一种可阻止用户与其后方 widget 交互的 widget，并可为其配置动画颜色值。

模态屏障是绘制在每个路由后方的遮罩，通常用于阻止用户与当前路由下方的路由交互，并会部分遮挡这些路由。

例如，屏幕上显示对话框时，模态屏障通常会使对话框下方的页面变暗。

此 widget 类似于 ModalBarrier，但它接收动画 color，而不是单一颜色。

另请参阅：

  • ModalRoute, which uses this widget.
