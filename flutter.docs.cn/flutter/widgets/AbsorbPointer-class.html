AbsorbPointer 类

一种在命中测试期间吸收指针事件的组件。

absorbing 为 true 时，此组件会在自身处终止命中测试，从而阻止其子树接收指针事件。它在布局期间仍会占据空间，并照常绘制子组件；它只是不让子组件成为定位事件的目标，因为它会从 RenderBox.hitTest 返回 true。

ignoringSemantics 为 true 时，此子树对语义层不可见（因此辅助功能工具等也无法访问）。

以下示例中，堆栈顶部的按钮外层包裹着 AbsorbPointer 组件。它会吸收指针事件，阻止其子按钮以及堆栈中下方的按钮接收这些事件。

Semantics

使用此类也可能影响其下方语义子树的收集方式。

absorbing 为 true 时，语义子树中与指针相关的 SemanticsAction 会被移除；否则，子树保持不变。

不建议使用 ignoringSemantics，该用法已弃用。此属性是在 v3.8.0-12.0.pre 之前引入的，用于应对 IgnorePointer 及其相关组件的语义行为问题。

在该版本之前，如果 absorbing 为 true，整个语义子树都会被移除。开发者只能通过 absorbing 和 ignoringSemantics 属性保留语义子树。

在该版本之后，absorbing 为 true 时，只会阻止语义子树中的用户操作，同时保留其他 SemanticsProperties。因此不再需要 ignoringSemantics。

ignoringSemantics 为 true 时，语义子树会被移除，因此辅助技术无法访问该子树。

ignoringSemantics 为 false 时，会照常收集语义子树。

另请参阅：

  • IgnorePointer, which also prevents its children from receiving pointer events but is itself invisible to hit testing.
