在 context 当前的 LookupBoundary 内，获取最近的指定类型 T 的组件。T 必须是具体 InheritedWidget 子类的类型。

除仅考虑给定 BuildContext 与其最近的 LookupBoundary 祖先之间指定类型 T 的 InheritedWidget 外，此方法的行为与 BuildContext.getInheritedWidgetOfExactType 完全相同。该 LookupBoundary 之外的 InheritedWidget 对此方法不可见。树的根节点被视为隐式查询边界。

与通常使用的 dependOnInheritedWidgetOfExactType 不同，此方法不会建立依赖关系，因此如果 InheritedWidget 发生变化，此上下文也不会重建。此函数适用于不希望建立依赖关系的少数情况。

当时元素树已不再稳定，因此不能在 State.dispose 中调用此方法。若要在该方法中引用祖先，应在 State.didChangeDependencies 中保存对祖先的引用。可以在 State.deactivate 中安全地调用此方法；每当组件从树中移除时都会调用该方法。

也可以在交互事件处理器（例如手势回调）或定时器中调用此方法来获取一次性值，前提是之后不缓存或重复使用该值。

调用此方法的时间复杂度为 O(1)，常数开销较小。

实现

static T? getInheritedWidgetOfExactType<T extends InheritedWidget>(
  BuildContext context, {
  Object? aspect,
}) {
  final InheritedElement? candidate = getElementForInheritedWidgetOfExactType<T>(context);
  if (candidate == null) {
    return null;
  }
  return candidate.widget as T;
}
