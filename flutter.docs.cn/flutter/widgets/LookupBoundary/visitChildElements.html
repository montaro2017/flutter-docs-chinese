遍历给定 context 的子 Element，但不跨越 LookupBoundary。

除只访问不是 LookupBoundary 的子组件外，此方法与 BuildContext.visitChildElements 的行为完全相同。

此方法适用于子组件构建完成后、无需等待下一帧就对其进行更改的情况，尤其是已知子组件内容时；如果恰好只有一个子组件（StatefulWidget 和 StatelessWidget 始终如此），则更为适用。

对于对应 StatefulWidget 或 StatelessWidget 的构建上下文，调用此方法的开销很低（O(1)，因为只有一个子组件）。

对于对应 RenderObjectWidget 的构建上下文，调用此方法的开销可能较大（与子组件数量成正比）。

递归调用此方法的开销极大（与后代数量成正比），应尽可能避免。通常使用 InheritedWidget 并让后代向下获取数据，明显比递归使用 visitChildElements 向下推送数据更高效。

实现

static void visitChildElements(BuildContext context, ElementVisitor visitor) {
  context.visitChildElements((Element child) {
    if (child.widget.runtimeType != LookupBoundary) {
      visitor(child);
    }
  });
}
