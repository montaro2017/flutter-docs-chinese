MagnifierBuilder typedef

MagnifierBuilder = Widget? Function(BuildContext context, MagnifierController controller, ValueNotifier<MagnifierInfo> magnifierInfo)

用于构建带有 MagnifierController 的 Widget 的函数签名。

每个放大镜只会调用一次此构建器。

如果构建器将 controller 参数的 MagnifierController.animationController 字段设为 AnimationController，MagnifierController 就会在放大镜进入和退出时驱动该动画。

在构建的放大镜生命周期内，magnifierInfo 参数会通过新的 MagnifierInfo 实例持续更新；例如，用户在文本框上移动手指时就会更新。

实现

    Widget? Function(

    );
