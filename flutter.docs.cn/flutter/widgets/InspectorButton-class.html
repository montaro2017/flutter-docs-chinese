InspectorButton
description

InspectorButton 类 抽象

用于创建 Material 或 Cupertino 风格检查器按钮的抽象基类。

子类负责在 build 方法中实现对应设计的渲染逻辑，并通过 foregroundColor 和 backgroundColor 提供相应设计的颜色。
