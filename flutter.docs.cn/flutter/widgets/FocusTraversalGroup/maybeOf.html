FocusTraversalPolicy? maybeOf(
  1. BuildContext context
)

给定 BuildContext 时，返回适用于最近祖先 Focus widget 的 FocusNode 的 FocusTraversalPolicy；如果没有适用策略，则返回 null。

如果找不到 Focus 或 FocusScope 祖先，或找不到适用于该节点的 FocusTraversalPolicy，则返回 null。

此函数会查找最近的祖先 Focus（或 FocusScope）widget，并使用其 FocusNode（或 FocusScopeNode）沿焦点树向上查找适用于该节点的 FocusTraversalPolicy。

调用此函数不会建立重新构建依赖，因为改变遍历顺序不会改变 widget 树，因此无需因此重建任何内容。

在 widget 树中引入 FocusTraversalGroup 即可设置 FocusTraversalPolicy；它会将该策略关联到最近祖先 Focus widget 下方的焦点树。

另请参阅：

  • maybeOfNode for a similar function that will look for a policy using a given FocusNode.
  • of for a similar function that will throw if no FocusTraversalPolicy applies.

实现

static FocusTraversalPolicy? maybeOf(BuildContext context) {
  final FocusNode? node = Focus.maybeOf(context, scopeOk: true, createDependency: false);
  if (node == null) {
    return null;
  }
  return FocusTraversalGroup.maybeOfNode(node);
}
