重写

收到弹出此路由的请求。如果路由可以在内部处理（例如它有自己的内部状态栈），则返回 false；否则返回 true（即返回调用 super.didPop 的结果）。返回 false 会阻止 NavigatorState.pop 的默认行为。

此方法返回 true 时，Navigator 会将此路由从历史记录中移除，但不会立即调用 dispose。此时由路由负责调用 NavigatorState.finalizeRoute，该方法随后会对路由调用 dispose。这种顺序允许路由在弹出后、释放前播放退出动画或执行其他视觉效果。

此方法应调用 didComplete 来完成 popped Future（默认实现也只做这件事）；路由不应等退出动画结束后才完成该 Future。

result 参数的说明见 popped、didComplete 和 currentResult。

实现

@override
bool didPop(T? result) {
  assert(
    _controller != null,
    '$runtimeType.didPop called before calling install() or after calling dispose().',
  );
  assert(!_transitionCompleter.isCompleted, 'Cannot reuse a $runtimeType after disposing it.');
  _result = result;
  _simulation = _createSimulationAndVerify(forward: false);
  if (_simulation == null) {
    _controller!.reverse();
  } else {
    _controller!.animateBackWith(_simulation!);
  }
  return super.didPop(result);
}
