CustomPaint 类

一个提供画布、可在绘制阶段进行绘图的 widget。

收到绘制请求时，CustomPaint 会先让其 painter 在当前画布上绘制，然后绘制其子项，最后再让 foregroundPainter 进行绘制。画布的坐标系与 CustomPaint 对象的坐标系一致。绘制器应在从原点开始、覆盖给定尺寸区域的矩形内绘制。（如果绘制器超出这些边界，分配给栅格化绘制命令的内存可能不足，最终行为将无法确定。）若要强制限制在这些边界内绘制，可以用 ClipRect widget 包裹此 CustomPaint。

绘制器通过继承 CustomPainter 来实现。

由于 custom paint 会在绘制过程中调用绘制器，因此不能在回调期间调用 setState 或 markNeedsLayout（此帧的布局已经完成）。

自定义绘制器通常根据其 child 确定自身尺寸。如果没有子项，则会尝试采用指定的 size，其默认值为 Size.zero。父级可能会对该尺寸施加约束。

isComplex 和 willChange 属性是提供给合成器栅格缓存的提示。

此示例展示如何在 CustomPaint widget 中使用 CustomPainter 页面中的自定义绘制器示例，为文本绘制背景。
link 
CustomPaint(
  painter: Sky(),
  child: const Center(
    child: Text(
      'Once upon a time...',
      style: TextStyle(
        fontSize: 40.0,
        fontWeight: FontWeight.w900,
        color: Color(0xFFFFFFFF),
      ),
    ),
  ),
)

另请参阅：

  • CustomPainter, the class to extend when creating custom painters.
  • Canvas, the class that a custom painter uses to paint.
