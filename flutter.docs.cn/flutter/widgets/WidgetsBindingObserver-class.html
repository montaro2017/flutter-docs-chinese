WidgetsBindingObserver
description

WidgetsBindingObserver 类 抽象 mixin

向 widgets 层 binding 注册的类所实现的接口。

任何类都可以使用此接口，不限于 widget。WidgetsBinding.addObserver 和 WidgetsBinding.removeObserver 会通过此接口通知对象环境变化，例如设备度量值或无障碍设置变化。MediaQuery 等功能便使用了此接口。

可以直接扩展此类或将其混入，以获得所有处理器的默认行为。也可以使用 implements 关键字；这种情况下必须实现所有处理器（分析器会列出遗漏的处理器）。

若要开始接收通知，请将实现 WidgetsBindingObserver 接口的对象传给 WidgetsBinding.instance.addObserver。为避免内存泄漏，对象生命周期结束时，请调用 WidgetsBinding.instance.removeObserver 注销它。

此示例展示了如何实现 State 和 WidgetsBindingObserver 协议的部分内容，以响应应用生命周期消息。请参见 didChangeAppLifecycleState。

若要响应其他通知，请将此示例中的 didChangeAppLifecycleState 方法替换为此类中的其他方法。
