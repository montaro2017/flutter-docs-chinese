RichText 类

富文本段落。

RichText 组件用于显示包含多种样式的文本。要显示的内容由一组 TextSpan 对象构成的树来描述；每个对象都有一个对应样式，该样式用于其子树。文本可能会根据布局约束换成多行，也可能始终显示在同一行。

RichText 组件显示的文本必须显式设置样式。选择样式时，可以使用当前 DefaultTextStyle.of 和 BuildContext 提供默认样式。还可以使用 MediaQuery.maybeBoldTextOf、MediaQuery.maybeLineHeightScaleFactorOverrideOf、MediaQuery.maybeLetterSpacingOverrideOf、MediaQuery.maybeWordSpacingOverrideOf 和 MediaQuery.maybeParagraphSpacingOverrideOf，确保文本样式具有良好的可访问性。有关如何为 RichText 设置样式的详情，请参见 TextStyle 文档。

若要自动集成 DefaultTextStyle，可以考虑使用 Text 组件。当所有文本使用同一种样式时，Text 的默认构造函数更简洁。Text.rich 构造函数允许多个文本片段使用默认文本样式，同时也可以为各个片段指定样式。

此示例展示如何使用 RichText 组件组合不同样式的文本。显示的内容为“Hello bold world,”，其中“bold”一词使用粗体字重突出显示。
link 
RichText(
  text: TextSpan(
    text: 'Hello ',
    style: DefaultTextStyle.of(context).style,
    children: const <TextSpan>[
      TextSpan(text: 'bold', style: TextStyle(fontWeight: FontWeight.bold)),
      TextSpan(text: ' world!'),
    ],
  ),
)

文本选择

若要使此 RichText 支持选择，此 RichText 需要放在 SelectionArea 或 SelectableRegion 的子树中，并为它的 RichText.selectionRegistrar 指定一个 SelectionRegistrar。可以使用 SelectionContainer.maybeOf，从位于组件树中 SelectionArea 或 SelectableRegion 下方的 context 获取 SelectionRegistrar。这样，用户便可以通过鼠标或触摸事件选择 RichText 中的文本。

如果同一个 build 方法同时创建 SelectionArea 和 RichText，请使用 Builder，确保调用 SelectionContainer.maybeOf 时传入的 BuildContext 位于组件树中 SelectionArea 的下方。

启用文本选择以绘制选择高亮时，还需要设置 selectionColor。

此示例展示如何为 SelectionArea 子树中的 RichText 指定 SelectionRegistrar。
link 
SelectionArea(
  child: Builder(
    builder: (BuildContext context) {
      return RichText(
        text: const TextSpan(text: 'Hello'),
        selectionRegistrar: SelectionContainer.maybeOf(context),
        selectionColor: const Color(0xAF6694e8),
      );
    },
  ),
)

另请参阅：

  • TextStyle用于说明如何设置文本样式。
  • TextSpan用于描述段落中的文本。
  • Text会自动将DefaultTextStyle描述的环境样式应用于单个字符串。
  • Text.rich是一个 const 文本 widget，提供与RichText类似的功能。Text.rich会从TextStyle继承DefaultTextStyle。
  • SelectableRegion提供了选择系统的概述。
