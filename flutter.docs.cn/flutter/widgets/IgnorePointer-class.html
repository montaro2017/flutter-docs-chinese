IgnorePointer 类

在命中测试期间不可见的组件。

当 ignoring 为 true 时，此组件及其子树在命中测试中不可见。它仍会在布局期间占据空间，并照常绘制子组件。由于它的 RenderBox.hitTest 返回 false，因此它不能成为定位事件的目标。

The following sample has an IgnorePointer widget wrapping the Column which contains a button. When ignoring is set to true anything inside the Column can not be tapped. When ignoring is set to false anything inside the Column can be tapped.

语义

使用此类也可能影响其下方语义子树的收集方式。

如果 ignoring 为 true，语义子树中的指针相关 SemanticsAction 会被移除；否则子树保持不变。

ignoringSemantics 已弃用，不建议使用。此属性最初用于绕过 v3.8.0-12.0.pre 之前 IgnorePointer 及相关组件的语义行为。

在该版本之前，当 ignoring 为 true 时，整个语义子树都会被丢弃。开发者只能使用 ignoringSemantics 保留语义子树。

从该版本开始，当 ignoring 为 true 时，只会阻止语义子树中的用户操作，其他 SemanticsProperties 仍会保留。因此，不再需要 ignoringSemantics。

如果 ignoringSemantics 为 true，语义子树会被丢弃，因此辅助技术无法感知该子树。

如果 ignoringSemantics 为 false，语义子树会照常收集。

另请参阅：

  • AbsorbPointer, which also prevents its children from receiving pointer events but is itself visible to hit testing.
  • SliverIgnorePointer, the sliver version of this widget.
