ReadingOrderTraversalPolicy 类

按“阅读顺序”遍历焦点。

默认情况下，阅读顺序遍历会先沿阅读方向移动，再向下移动，具体算法如下：

  1. 找到屏幕上位置最高（最靠上）的节点矩形，即其 top 边缘位置最高的矩形。
  2. 找到与由该矩形上边缘和下边缘定义的无限水平带相交的其他节点。
  3. 从上面找到的节点中，选择在阅读顺序中最靠前的节点。

此策略会使用包围 FocusTraversalGroup 的 context 中的环境 Directionality，以确定哪个方向属于“阅读顺序”。

另请参阅：

  • FocusNode，用于了解焦点系统。
  • FocusTraversalGroup, 一种将其分组，并为其应用遍历策略的组件：Focus 节点（位于该组件下方的 widget 树中）。
  • WidgetOrderTraversalPolicy，一种依据 widget 创建顺序确定遍历顺序的策略。
  • DirectionalFocusTraversalPolicyMixin，一种实现定向焦点遍历的 mixin。
  • OrderedTraversalPolicy，一种通过 FocusTraversalOrder widget 显式指定遍历顺序的策略。
