AnimatedWidget 类 抽象

当给定的 Listenable 值变化时会重新构建的 widget。

AnimatedWidget 最常与 Animation 对象配合使用，因为它们属于 Listenable；但它也可用于任何 Listenable，包括 ChangeNotifier 和 ValueNotifier。

AnimatedWidget 最适合原本无状态的 widget。要使用 AnimatedWidget，请继承该类并实现 build 函数。

对于涉及额外状态的复杂情况，可以考虑使用 AnimatedBuilder 或 ListenableBuilder。

与 ImplicitlyAnimatedWidget 的关系

AnimatedWidget 及其子类接收显式传入的 Listenable 参数，通常是由 AnimationController 派生的 Animation。在大多数情况下，开发者必须手动管理该 AnimationController 的生命周期。相比之下，ImplicitlyAnimatedWidget 及其子类会自动管理内部的 AnimationController，因此不必提供外部 Animation，更易于使用。如果只需设置动画目标值并配置时长或曲线，可以考虑使用 ImplicitlyAnimatedWidget（或其子类），而不是此类（或其子类）。

常见动画 widget

框架提供了许多动画 widget，通常命名为 FooTransition，其中 Foo 是对应非动画 widget 的名称。不要将此类的子类与 ImplicitlyAnimatedWidget 的子类混淆（见上文）；后者通常命名为 AnimatedFoo。常用动画 widget 包括：

  • ListenableBuilder, which uses a builder pattern that is useful for complex Listenable use cases.
  • AnimatedBuilder, which uses a builder pattern that is useful for complex Animation use cases.
  • AlignTransition，是 Align 的动画版本。
  • DecoratedBoxTransition，是 DecoratedBox 的动画版本。
  • DefaultTextStyleTransition，是 DefaultTextStyle 的动画版本。
  • PositionedTransition，是 Positioned 的动画版本。
  • RelativePositionedTransition，是 Positioned 的动画版本。
  • RotationTransition, which animates the rotation of a widget.
  • ScaleTransition, which animates the scale of a widget.
  • SizeTransition, which animates its own size.
  • SlideTransition, which animates the position of a widget relative to its normal position.
  • FadeTransition，是 Opacity 的动画版本。
  • AnimatedModalBarrier，是 ModalBarrier 的动画版本。
