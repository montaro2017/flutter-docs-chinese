RenderNestedScrollViewViewport
description

RenderNestedScrollViewViewport 类

供 NestedScrollView 使用的 RenderViewport 变体。

此视口接收一个 SliverOverlapAbsorberHandle，并在视口需要重新计算布局时（例如发生滚动时）通知它。

构造函数

RenderNestedScrollViewViewport({AxisDirection axisDirection = AxisDirection.down, required AxisDirection crossAxisDirection, required ViewportOffset offset, double anchor = 0.0, List<RenderSliver>? children, RenderSliver? center, required SliverOverlapAbsorberHandle handle, Clip clipBehavior = Clip.hardEdge})
Create a variant of RenderViewport that has a SliverOverlapAbsorberHandle.
