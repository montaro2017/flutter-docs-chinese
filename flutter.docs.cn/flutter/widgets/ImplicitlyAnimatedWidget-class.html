ImplicitlyAnimatedWidget
description

ImplicitlyAnimatedWidget 类 抽象

用于构建可为属性变化添加动画效果的组件的抽象类。

此类型的组件首次加入组件树时不会播放动画。之后，如果组件以不同的值重新构建，它会在指定的时长内对这些变化进行动画处理。

由子类决定要为哪些属性添加动画。子类的 State 必须继承 ImplicitlyAnimatedWidgetState，并提供遍历相关字段以执行动画的方式。

与AnimatedWidget的关系

ImplicitlyAnimatedWidget及其子类会在属性变化时自动为变化添加动画。为此，它们会创建并管理自己的内部 AnimationController 来驱动动画。这些组件使用简单，无需手动管理 AnimationController 的生命周期，但功能也有一定限制：除动画属性的目标值外，开发者只能选择动画的时长和曲线。如果需要更精细地控制动画（例如在动画中途停止），可以使用 AnimatedWidget 或其子类。这些组件通过传入 Animation 来驱动动画，让开发者能够完全控制动画，但需要手动管理底层 AnimationController。

常用的隐式动画组件

框架提供了许多隐式动画组件。它们通常命名为 AnimatedFoo，其中 Foo 是对应非动画组件的名称。常用的隐式动画组件包括：

  • TweenAnimationBuilder, which animates any property expressed by a Tween to a specified target value.
  • AnimatedAlign，是 Align 的隐式动画版本。
  • AnimatedContainer，是 Container 的隐式动画版本。
  • AnimatedDefaultTextStyle，是 DefaultTextStyle 的隐式动画版本。
  • AnimatedScale，是 Transform.scale 的隐式动画版本。
  • AnimatedRotation，是 Transform.rotate 的隐式动画版本。
  • AnimatedSlide, which implicitly animates the position of a widget relative to its normal position.
  • AnimatedOpacity，是 Opacity 的隐式动画版本。
  • AnimatedPadding，是 Padding 的隐式动画版本。
  • AnimatedPhysicalModel，是 PhysicalModel 的隐式动画版本。
  • AnimatedPositioned，是 Positioned 的隐式动画版本。
  • AnimatedPositionedDirectional，是 PositionedDirectional 的隐式动画版本。
  • AnimatedTheme，是 Theme 的隐式动画版本。
  • AnimatedCrossFade, which cross-fades between two given children and animates itself between their sizes.
  • AnimatedSize, which automatically transitions its size over a given duration.
  • AnimatedSwitcher, which fades from one widget to another.
