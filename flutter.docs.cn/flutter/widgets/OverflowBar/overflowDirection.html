overflowDirection 属性

VerticalDirection overflowDirection
final

定义水平布局发生溢出时 children 的排列顺序。

This parameter is only used if the horizontal layout overflows, i.e. if there isn't enough horizontal room for the children 和 spacing.

如果子项无法放入单行，就会改为纵向排列。此属性为 VerticalDirection.down 时，第一个子项位于列顶部，因为排列从顶部“开始”、到底部“结束”。反之，此属性为 VerticalDirection.up 时，第一个子项位于列底部，因为排列从底部“开始”、到顶部“结束”。

默认值为 VerticalDirection.down。

另请参阅：

  • overflowAlignment，它定义了纵向“溢出”布局中子项的水平对齐方式。
