SliverChildListDelegate 类

使用显式列表为 sliver 提供子项的委托对象。

许多 sliver 会延迟构建盒子子项，避免创建超出 Viewport 可视范围的子项。此委托对象使用显式列表提供子项，虽然方便，但会降低延迟构建子项带来的收益。

通常，预先构建所有 widget 效率不高。更好的做法是创建一个按需构建子项的委托对象，例如使用 SliverChildBuilderDelegate，或直接继承 SliverChildDelegate。

当子项列表可以提前确定（例如，理想情况下子项本身是编译时常量），因此不会在每次创建委托对象时重新构建；或者列表很小、很可能始终可见（按需构建并无收益）时，可以使用此类。例如，对话框的主体可能同时符合这两个条件。

如果 addAutomaticKeepAlives 为 true（默认值），给定 children 列表中的 widget 会自动包装在 AutomaticKeepAlive widget 中；如果 addRepaintBoundaries 为 true（默认值），则会自动包装在 RepaintBoundary widget 中。

辅助功能

CustomScrollView 要求使用 IndexedSemantics 为语义子项添加标注。默认情况下，委托对象会在 addSemanticIndexes 参数设为 true 时完成此操作。

如果在单个滚动视图中使用多个委托对象，默认情况下索引会不正确。可以使用 semanticIndexOffset 偏移每个委托对象的语义索引，使索引单调递增。例如，若滚动视图包含两个委托对象，且第一个委托对象有 10 个贡献语义信息的子项，则第二个委托对象应将其子项的偏移量设为 10。

在某些情况下，只应为部分子 widget 添加语义索引。例如，在 ListView.separated() 中，分隔项没有对应的索引。可以提供 semanticIndexCallback：对于分隔项索引返回 null，并将非分隔项的索引向下取整后除以二。

See SliverChildBuilderDelegate for sample code using semanticIndexOffset 和 semanticIndexCallback.
