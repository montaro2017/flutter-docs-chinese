按焦点顺序对给定的 descendants 排序。

子类应重写此方法，为 next 和 previous 实现不同的排序方式。如果返回的可迭代对象遗漏了给定范围的某个后代节点，用户将无法通过 next/previous 键盘遍历到该节点。

用于启动遍历的节点（传给 next 或 previous 的节点）会作为 currentNode 传入。

列表中包含当前节点后，算法才能确定哪些节点与当前节点相邻。如果从列表中移除 currentNode，调用 next 或 previous 时焦点不会改变，并且方法会返回 false。

此方法不用于方向焦点遍历（inDirection），只用于确定 next 和 previous 的焦点顺序。

重写此函数时，对项目排序请使用 mergeSort，不要使用 Dart 默认的列表排序算法。默认算法不稳定（被视为相等的项目可能以任意顺序出现，并在不同排序间改变位置），而 mergeSort 是稳定排序。
