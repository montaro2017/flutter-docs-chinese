SliverChildBuilderDelegate 类

使用构建器回调为 sliver 提供子项的委托对象。

许多 sliver 会延迟构建盒子子项，避免创建超出 Viewport 可视范围的子项。此委托对象通过 NullableIndexedWidgetBuilder 回调提供子项，因此只有在子项显示时才会构建它们。

如果 addAutomaticKeepAlives 为 true（默认值），构建器回调返回的 widget 会自动包装在 AutomaticKeepAlive widget 中；如果 addRepaintBoundaries 为 true（默认值），则会自动包装在 RepaintBoundary widget 中。

辅助功能

CustomScrollView 要求使用 IndexedSemantics 为语义子项添加标注。默认情况下，委托对象会在 addSemanticIndexes 参数设为 true 时完成此操作。

如果在单个滚动视图中使用多个委托对象，默认情况下索引会不正确。可以使用 semanticIndexOffset 偏移每个委托对象的语义索引，使索引单调递增。例如，若滚动视图包含两个委托对象，且第一个委托对象有 10 个贡献语义信息的子项，则第二个委托对象应将其子项的偏移量设为 10。

此示例代码展示如何使用 semanticIndexOffset，在单个滚动视图中处理多个委托对象。
link 
CustomScrollView(
  semanticChildCount: 4,
  slivers: <Widget>[
    SliverGrid(
      gridDelegate: _gridDelegate,
      delegate: SliverChildBuilderDelegate(
        (BuildContext context, int index) {
           return const Text('...');
         },
         childCount: 2,
       ),
     ),
    SliverGrid(
      gridDelegate: _gridDelegate,
      delegate: SliverChildBuilderDelegate(
        (BuildContext context, int index) {
           return const Text('...');
         },
         childCount: 2,
         semanticIndexOffset: 2,
       ),
     ),
  ],
)

在某些情况下，只应为部分子 widget 添加语义索引。例如，在 ListView.separated() 中，分隔项没有对应的索引。可以提供 semanticIndexCallback：对于分隔项索引返回 null，并将非分隔项的索引向下取整后除以二。

此示例展示如何使用 semanticIndexCallback 为部分子节点标注语义索引。奇数索引处的 Spacer widget 不应分配语义索引。
link 
CustomScrollView(
  semanticChildCount: 5,
  slivers: <Widget>[
    SliverGrid(
      gridDelegate: _gridDelegate,
      delegate: SliverChildBuilderDelegate(
        (BuildContext context, int index) {
           if (index.isEven) {
             return const Text('...');
           }
           return const Spacer();
         },
         semanticIndexCallback: (Widget widget, int localIndex) {
           if (localIndex.isEven) {
             return localIndex ~/ 2;
           }
           return null;
         },
         childCount: 10,
       ),
     ),
  ],
)
