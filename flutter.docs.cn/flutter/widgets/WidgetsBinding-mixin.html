WidgetsBinding mixin

连接 Flutter Widgets 层与引擎的纽带。

WidgetsBinding 管理一棵以 rootElement 为根的 Element 树。调用 runApp（它会间接调用 attachRootWidget）即可启动这棵 Element 树。

与渲染树的关系

一棵 Element 树可以关联多棵渲染树，这些渲染树由底层的 RendererBinding 管理。

Element 树分为两类区域：渲染区域和非渲染区域。

渲染区域是 Element 树中由渲染树支撑的一部分，用于描述屏幕上绘制的像素。此区域中的 Element.renderObject 永远不会返回 null，因为其中的元素都关联着 RenderObject。几乎所有 Widget 都可以放入渲染区域；值得注意的例外包括 View、ViewCollection 和 RootWidget。

非渲染区域是 Element 树中没有渲染树支撑的一部分。此区域中的 Element.renderObject 会返回 null，因为其中的元素没有关联任何 RenderObject。此区域只能使用不会生成 RenderObject 的 Widget，因为没有渲染树可供挂接。也就是说，不能在此区域使用 RenderObjectWidget。此区域通常包含 InheritedWidget、View 和 ViewCollection，用于跨渲染区域向树中注入数据，并将各渲染区域（以及相应的渲染树）组织成统一的 Element 树。

从 rootElement 开始的 Element 树根节点位于非渲染区域。在非渲染区域中，使用 View Widget 启动渲染树，从而开始一个渲染区域。在渲染区域中，则可以使用 ViewAnchor 开始新的非渲染区域。

要判断一个元素是否位于渲染区域，可以沿树向上遍历，并在其祖先上调用 Element.debugExpectsRenderObjectForSlot。如果遇到返回 false 的元素，它就位于非渲染区域；如果遇到 RenderObjectElement 祖先，它就位于渲染区域。
