移除先前注册的回调。

如果给定回调尚未注册，则忽略此次调用。

实现

@override
void removeCallback(ValueGetter<Future<bool>> callback) {
  super.removeCallback(callback);
  if (!hasCallbacks) {
    WidgetsBinding.instance.removeObserver(this);
  }
}
