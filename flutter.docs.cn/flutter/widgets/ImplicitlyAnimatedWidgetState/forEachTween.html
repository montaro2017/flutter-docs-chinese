使用指定的 visitor 函数遍历此状态控制的每个 tween。

子类职责

要添加动画的属性在状态中以 Tween 成员变量表示。对于每个 tween，forEachTween 实现都应使用适当的参数调用 visitor，并将返回结果存回成员变量。传给 visitor 的参数如下：

tween 参数应包含当前 tween 值。状态首次初始化时，此值为 null。

targetValue 参数应包含状态正在趋近的值。例如，如果状态正在为组件的透明度添加动画，此参数应包含组件当前的透明度值。

constructor 参数应包含一个函数，该函数接收一个值（正在添加动画的组件属性值），并返回一个从该值开始的 tween。

此方法的调用时机

forEachTween 最初会在 initState 期间调用。此时 visitor 的 tween 参数应为 null，因此 visitor 会调用其 constructor 参数来首次构建 tween。生成的 tween 会将 begin 设为目标值，并将 end 设为 null；此时不会启动动画。

当此状态的 widget 更新（从而触发 didUpdateWidget 方法）时，会再次调用 forEachTween，检查目标值是否变化。如果目标值已变化，表示应启动动画，此时 visitor 会相应更新 tween 的 start 和 end 值，然后启动动画。

其他成员变量

包含基于 forEachTween 创建的 tween 的属性的子类，应重写 didUpdateTweens 来更新这些属性。不要在 forEachTween 中更新依赖属性。

此示例实现了一个隐式动画组件的 State。每当 widget.targetColor 变化时，该组件都会在不同颜色之间播放动画。
link 
class MyWidgetState extends AnimatedWidgetBaseState<MyWidget> {
  ColorTween? _colorTween;

  @override
  Widget build(BuildContext context) {
    return Text(
      'Hello World',
      // Computes the value of the text color at any given time.
      style: TextStyle(color: _colorTween?.evaluate(animation)),
    );
  }

  @override
  void forEachTween(TweenVisitor<dynamic> visitor) {
    // Update the tween using the provided visitor function.
    _colorTween = visitor(
      // The latest tween value. Can be `null`.
      _colorTween,
      // The color value toward which we are animating.
      widget.targetColor,
      // A function that takes a color value and returns a tween
      // beginning at that value.
      (dynamic value) => ColorTween(begin: value as Color?),
    ) as ColorTween?;

    // We could have more tweens than one by using the visitor
    // multiple times.
  }
}
