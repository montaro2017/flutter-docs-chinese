TraversalEdgeBehavior
description

TraversalEdgeBehavior enum

控制焦点到达 FocusScopeNode 边缘时如何转移。对于按顺序（上一个或下一个）移动，边缘指第一个或最后一个项目；对于方向性移动，边缘指 FocusScopeNode 最外侧的项目。例如，向下移动时，边缘节点是底部坐标最大的节点；向左移动时，边缘节点是 x 坐标最小的节点。

This enumeration only controls the traversal behavior performed by FocusTraversalPolicy. Other methods of focus transfer, such as direct calls to FocusNode.requestFocus 和 FocusNode.unfocus, are not affected by this enumeration.

另请参阅：

  • FocusTraversalPolicy, which implements the logic behind this enum.
  • FocusScopeNode, which is configured by this enum.

Values

closedLoop → const TraversalEdgeBehavior

Keeps the focus among the items of the focus scope.

当边缘节点继续移动时，将焦点转移到 FocusScopeNode 的相反方向一侧的边缘节点，从而形成一个可聚焦项目的闭环。

对于移动转移，在最后一个可聚焦项目之后请求下一个焦点会将焦点转移到第一个项目；在第一个项目之前请求焦点则会将焦点转移到最后一个项目。

对于方向转移，在最右侧节点持续请求向右焦点会将焦点转移到最左侧节点；在最左侧节点持续请求向左焦点会将焦点转移到最右侧节点。

leaveFlutterView → const TraversalEdgeBehavior

Allows the focus to leave the FlutterView.

在最后一个可聚焦项目之后请求下一个焦点，或在第一个项目之前请求上一个焦点，会取消所有已聚焦节点的焦点。如果焦点遍历操作由嵌入方（例如 Flutter Engine）发起，嵌入方会收到结果，表示焦点已离开当前 FlutterView。例如，通过键盘（通常是 TAB 键）调用的 NextFocusAction 会收到 KeyEventResult.skipRemainingHandlers，从而允许嵌入方处理该快捷键。在 Web 上，控制权通常会交给浏览器，使用户能够访问地址栏、退出 iframe，或聚焦 Flutter 管理范围之外的 HTML 元素。

parentScope → const TraversalEdgeBehavior

Allows focus to traverse up to parent scope.

到达当前作用域边缘时请求下一个焦点，会向上查找当前作用域的父作用域，并将焦点移至当前作用域旁边的焦点节点。

If there is no parent scope above the current scope, fallback to closedLoop behavior.

stop → const TraversalEdgeBehavior

Stops the focus traversal at the edge of the focus scope.

焦点到达焦点作用域边缘时，仍保持在当前位置。
