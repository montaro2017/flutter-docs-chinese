FixedExtentMetrics 类

用于固定项目尺寸滚动视图的 ScrollPosition 度量信息。

这些度量信息可从 ScrollNotification 中获取，例如由 ListWheelScrollView（使用 FixedExtentScrollController）生成的通知；它们还提供当前 itemIndex 和滚动视图的范围信息。

FixedExtent 指可滚动项目的尺寸相同。这与父类名称 FixedScrollMetrics 中的 Fixed 含义不同，后者指其不可变性。
