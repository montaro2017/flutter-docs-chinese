DraggableScrollableNotification 类

与 DraggableScrollableSheet 的 extent（即尺寸）以及子列表的滚动偏移量（即位置）相关的 Notification。

DraggableScrollableSheet 的尺寸发生变化时，会向其祖先发送通知。通过拖动改变面板 extent 时，此通知会沿 widget 树向上冒泡，因此某个 NotificationListener 会收到其所有后代 DraggableScrollableSheet 发出的通知。若只关注最近的后代 DraggableScrollableSheet 发出的通知，请检查通知的 depth 属性是否为零。

NotificationListener 收到 extent 通知时，监听器所在 widget 已完成 build 和 layout，因此此时再调用 State.setState 已经太迟。尝试根据 extent 通知调整构建或布局，会导致布局落后于实际状态一帧，用户体验较差。extent 通知主要用于驱动动画。Scaffold widget 会监听 extent 通知，并在底部面板向上滚动时驱动 FloatingActionButton 的动画。
