Wrap 类

将子项分成多行或多列显示的 widget。

Wrap 会先布局每个子项，并尝试沿由 direction 指定的主轴将其紧邻前一个子项放置，子项之间留出 spacing 的间隔。如果空间不足以容纳某个子项，Wrap 会沿交叉轴在现有子项旁创建新的一行（run）。

所有子项分配到各行后，会根据主轴上的 alignment 和交叉轴上的 crossAxisAlignment 确定各行内子项的位置。

随后，根据 runSpacing 和 runAlignment 确定各行在交叉轴上的位置。

此示例在 Wrap 中显示代表四位联系人的 Chip，并根据需要让它们自动换行。
link 
Wrap(
  spacing: 8.0, // gap between adjacent chips
  runSpacing: 4.0, // gap between lines
  children: <Widget>[
    Chip(
      avatar: CircleAvatar(backgroundColor: Colors.blue.shade900, child: const Text('AH')),
      label: const Text('Hamilton'),
    ),
    Chip(
      avatar: CircleAvatar(backgroundColor: Colors.blue.shade900, child: const Text('ML')),
      label: const Text('Lafayette'),
    ),
    Chip(
      avatar: CircleAvatar(backgroundColor: Colors.blue.shade900, child: const Text('HM')),
      label: const Text('Mulligan'),
    ),
    Chip(
      avatar: CircleAvatar(backgroundColor: Colors.blue.shade900, child: const Text('JL')),
      label: const Text('Laurens'),
    ),
  ],
)
