BoxScrollView
description

BoxScrollView 类 抽象

采用单子项布局模型的 ScrollView。

ScrollView 通常会装饰滚动条 Scrollbar 和过度滚动指示器，这些由继承得到的 ScrollBehavior 管理。在 ScrollView 上方放置 ScrollConfiguration 可以修改该 ScrollView 的这些行为；也可以为 MaterialApp.scrollBehavior 或 CupertinoApp.scrollBehavior 提供 ScrollBehavior，以统一管理整个应用的行为。

另请参阅：

  • ListView, which is a BoxScrollView that uses a linear layout model.
  • GridView, which is a BoxScrollView that uses a 2D layout model.
  • CustomScrollView, which can combine multiple child layout models into a single scroll view.
