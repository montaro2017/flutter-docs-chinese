didPushNext 方法

void didPushNext()

新的 route 推入到此 route 上方并暂时遮挡它时调用。

此方法会在推入操作期间同步调用，早于转场动画完成。当前 route 在动画退出时仍可能部分可见。若要在 route 完全被遮挡后执行操作，可以监听 ModalRoute.secondaryAnimation 的动画完成状态，例如：

link 
ModalRoute.of(context)?.secondaryAnimation?.addStatusListener((AnimationStatus status) {
  if (status == AnimationStatus.completed) {
    // This route is now fully obscured by the new route.
  }
});
