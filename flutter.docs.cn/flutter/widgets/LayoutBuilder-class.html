LayoutBuilder 类

构建一个可根据父组件尺寸变化的组件树。

它类似于 Builder，但框架会在布局时调用 builder 函数，并提供父组件的约束。当父组件限制子组件尺寸，且不依赖子组件的固有尺寸时，这很有用。LayoutBuilder 的最终尺寸会与其子组件相同。

在以下情况下会调用 builder 函数：

  • The first time the widget is laid out.
  • When the parent widget passes different layout constraints.
  • When the parent widget updates this widget and updateShouldRebuild returns true.
  • When the dependencies that the builder function subscribes to change.

如果父组件反复传入相同的约束，布局期间将不会调用 builder 函数。

如果某个祖先跳过此子树的布局，导致约束过期，builder 会使用上一次已知的约束重新构建。

如果子组件应小于父组件，可将其包在 Align 中。如果子组件可能需要更大的空间，可将其包在 SingleChildScrollView 或 OverflowBox 中。
