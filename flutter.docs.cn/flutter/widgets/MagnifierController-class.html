MagnifierController 类

放大镜控制器。

与直接持有 OverlayEntry 相比，MagnifierController 的主要优势在于，MagnifierController 会处理等待放大镜进入或退出动画完成的逻辑。

如果放大镜需要进入或退出动画，应将动画控制器提供给 MagnifierController.animationController。随后 MagnifierController 会驱动 AnimationController，并等待动画完成后再将放大镜从 Overlay 中移除。

若要检查放大镜状态，请参阅 MagnifierController.shown。

构造函数

MagnifierController({AnimationController? animationController})
If there is no in / out animation for the magnifier, animationController should be left null.
