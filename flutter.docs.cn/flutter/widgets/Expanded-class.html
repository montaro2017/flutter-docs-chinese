Expanded 类

用于扩展 Row、Column 或 Flex 子项，使该子项填满可用空间的 widget。

使用 Expanded widget 可以让 Row、Column 或 Flex 的子项沿主轴扩展并填满可用空间（例如，Row 沿水平方向，Column 沿垂直方向）。如果有多个子项需要扩展，可用空间会根据 flex 因子分配。

Expanded widget 必须是 Row、Column 或 Flex 的后代，并且从 Expanded widget 到其外层 Row、Column 或 Flex 的路径上只能包含 StatelessWidget 或 StatefulWidget（不能包含 RenderObjectWidget 等其他类型的 widget）。

此示例展示如何在 Column 中使用 Expanded widget，使中间的子项（此处为 Container）扩展并填满空间。

flutter create --sample=widgets.Expanded.1 mysample
