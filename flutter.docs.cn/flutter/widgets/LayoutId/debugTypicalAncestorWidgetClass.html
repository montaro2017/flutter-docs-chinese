描述通常用于设置 RenderObjectWidget 的 ParentData；applyParentData 会将数据写入该对象。

此值仅用于错误消息，通过 debugTypicalAncestorWidgetDescription 告知用户通常会用哪个组件包裹此 ParentDataWidget。

实现

返回的 Type 应描述 RenderObjectWidget 的子类。如果支持多个 Type，请使用 debugTypicalAncestorWidgetDescription；它通常会插入此值，但也可重写以描述多个 Type。

  @override
  Type get debugTypicalAncestorWidgetClass => FrogJar;

如果“典型”父组件是泛型（Foo<T>），可考虑指定一个典型类型参数（例如通常会特化为 int 时使用 Foo<int>），或指定上界（例如 Foo<Object?>）。
