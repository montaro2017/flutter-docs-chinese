StretchingOverscrollIndicator 类

当滚动视图发生过度滚动时显示的 Material Design 视觉提示。

StretchingOverscrollIndicator 会监听 ScrollNotification，以拉伸 Scrollable 的内容。这些通知通常由 ScrollView（例如 ListView 或 GridView）生成。

触发时，StretchingOverscrollIndicator 会在显示过度滚动提示之前生成 OverscrollIndicatorNotification。若要阻止显示该提示，请对通知调用 OverscrollIndicatorNotification.disallowIndicator。

当 ThemeData.useMaterial3 为 true 时，MaterialScrollBehavior.buildOverscrollIndicator 会在通常使用此类过度滚动提示的平台（例如 Android）上创建此 widget。否则，当 ThemeData.useMaterial3 为 false 时，会改用 GlowingOverscrollIndicator。

另请参阅：

  • OverscrollIndicatorNotification, which can be used to prevent the stretch effect from being applied at all.
  • NotificationListener, to listen for the OverscrollIndicatorNotification.
  • GlowingOverscrollIndicator, the default overscroll indicator for TargetPlatform.android 和 TargetPlatform.fuchsia.
