Shortcuts 类

为后代创建按键绑定，使其按键组合能够触发特定操作的 widget。

此 widget 会建立一个供后代使用的 ShortcutManager。当键盘组合映射到某个 Intent 时，后代可通过该管理器调用 Action。

此 widget 与 CallbackShortcuts 类似，但功能更强。与 CallbackShortcuts 不同，此 widget 将按键绑定与其实现分开。这样的分离让 Shortcuts 能根据当前焦点上下文调整按键绑定。例如，删除 intent 对应的操作可能是在文本输入中删除字符，也可能是在文件菜单中删除文件。

详细说明请参阅文章 使用 Actions 和 Shortcuts。

Here, we will use the Shortcuts 和 Actions widgets to add and subtract from a counter. When the child widget has keyboard focus, and a user presses the keys that have been defined in Shortcuts, the action that is bound to the appropriate Intent for the key is invoked.

It also shows the use of a CallbackAction to avoid creating a new Action subclass.

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.Shortcuts.1 mysample

这个稍复杂但更灵活的示例会创建自定义 Action 子类，用于在获得键盘焦点的 widget（此处为 Column）中递增和递减。用户按下向上或向下方向键时，自定义操作会递增或递减数据模型。

此示例还展示了如何向 Intent 传递参数，并将其传给 Action。操作可以从自身构造时获取数据（例如此示例中的 model），也可以从调用时传入的 intent 获取数据（例如递增操作的 amount）。
