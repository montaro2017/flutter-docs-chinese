ListWheelChildBuilderDelegate 类

通过 builder 回调为 ListWheelScrollView 提供子项的 delegate。

ListWheelScrollView 会按需构建子项，避免创建 Viewport 中不可见的子项。此 delegate 通过 IndexedWidgetBuilder 回调提供子项，因此子项无需在显示之前构建。
