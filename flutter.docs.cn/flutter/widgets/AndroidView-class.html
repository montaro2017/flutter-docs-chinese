AndroidView 类

在 Widget 层级中嵌入 Android 视图。

要求 Android API 级别为 23 或更高。

嵌入 Android 视图的开销较大；如果可以使用 Flutter 中的等效实现，应避免嵌入 Android 视图。

嵌入的 Android 视图会像其他 Flutter widget 一样绘制，变换效果也同样适用于它。

此 widget 会填满所有可用空间，因此其父级必须提供有界的布局约束。

此 widget 会参与 Flutter 手势竞技场，并且仅当它获胜时才会将触摸事件分发给平台视图。可以通过构造函数参数 gestureRecognizers 指定应分发给平台视图的手势。如果手势识别器集合为空，则仅当没有其他手势识别器认领该事件时，才会将手势分发给平台视图。

Android 视图对象通过 PlatformViewFactory 创建。插件可以使用 PlatformViewRegistry#registerViewFactory 注册平台视图工厂。

通常在插件的 registerWith 方法中完成注册，例如：

  public static void registerWith(Registrar registrar) {
    registrar.platformViewRegistry().registerViewFactory("webview", WebViewFactory(registrar.messenger()));
  }

平台视图的生命周期与此 widget 的 State 对象相同。State 被释放时，平台视图及辅助资源会延迟释放（部分资源立即释放，其他资源由平台垃圾回收器释放）。当有状态 widget 从树中移除或在树中移动时，其状态会被释放。如果有状态 widget 带有 key，且只是在同级元素之间移动，或者带有 GlobalKey 并在树中移动，则不会释放状态。
