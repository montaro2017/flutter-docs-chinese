SlottedContainerRenderObjectMixin<SlotType, ChildType extends RenderObject> mixin

供由 SlottedMultiChildRenderObjectWidget 配置的 RenderObject 使用的 mixin。

调用 childForSlot，可以获取当前占据指定 slot 的 RenderObject 子项。

实现者可以考虑重写 children，以一致顺序（例如命中测试顺序）返回此渲染对象的子项。

类型参数 SlotType 是此 RenderObject 及其配置来源 SlottedMultiChildRenderObjectWidget 所用 slot 的类型。通常，SlotType 是 Enum 类型。

类型参数 ChildType 是子项所用 RenderObject 的类型（例如 RenderBox 或 RenderSliver）。通常，ChildType 为 RenderBox。此 mixin 不支持不同 slot 使用不同类型的子项。

请参阅 SlottedMultiChildRenderObjectWidget，其中包含此 mixin 与 SlottedMultiChildRenderObjectWidget 配合使用的示例代码。

另请参阅：

  • ContainerRenderObjectMixin, which organizes its children in a single list.
Superclass constraints
  • RenderObject
