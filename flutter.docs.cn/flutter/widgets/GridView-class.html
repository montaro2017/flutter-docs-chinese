GridView 类

可滚动的二维组件数组。

网格的主轴方向，也就是其滚动方向（scrollDirection）。

最常用的网格布局是 GridView.count（在交叉轴上创建固定数量的网格项）和 GridView.extent（创建交叉轴范围不超过最大值的网格项）。自定义 SliverGridDelegate 可生成任意二维子组件布局，包括未对齐或相互重叠的布局。

若要创建包含大量（甚至无限多个）子组件的网格，请使用 GridView.builder 构造函数，并将 SliverGridDelegateWithFixedCrossAxisCount 或 SliverGridDelegateWithMaxCrossAxisExtent 设为 gridDelegate。

若要使用自定义的 SliverChildDelegate，请使用 GridView.custom。

若要创建线性排列的子组件，请使用 ListView。

若要控制滚动视图的初始滚动偏移，请提供一个已设置 controller 属性的 ScrollController.initialScrollOffset。

迁移到 CustomScrollView

GridView 本质上是一个 CustomScrollView，其 SliverGrid 属性中只有一个 CustomScrollView.slivers。

如果 GridView 不再满足需求（例如滚动视图需要同时包含网格和列表，或网格需要与 SliverAppBar 等组件组合），可以直接将代码从使用 GridView 迁移到 CustomScrollView；迁移过程很简单。

key、scrollDirection、reverse、controller、primary、physics 和 shrinkWrap 在 GridView 上的属性，分别对应 CustomScrollView 上同名的属性。

CustomScrollView.slivers 属性应为一个仅包含 SliverGrid 的列表。

GridView 的 childrenDelegate 属性对应于 GridView 的 GridView 上的 SliverGrid.delegate 属性；gridDelegate 属性对应于 GridView 的 SliverGrid.gridDelegate 属性。

The GridView, GridView.count, and GridView.extent constructors' children arguments correspond to the childrenDelegate being a SliverChildListDelegate with that same argument. The GridView.builder constructor's itemBuilder 和 childCount arguments correspond to the childrenDelegate being a SliverChildBuilderDelegate with the matching arguments.

The GridView.count 和 GridView.extent constructors create custom grid delegates, and have equivalently named constructors on SliverGrid to ease the transition: SliverGrid.count 和 SliverGrid.extent respectively.

GridView 的 padding 属性相当于在 SliverPadding 中（而不是直接在网格上）加入到 CustomScrollView.slivers 属性，并将 SliverGrid 设为 SliverPadding 的子组件。

将代码迁移为使用 CustomScrollView 后，可以在 SliverList 列表中加入其他 sliver，例如 SliverAppBar 或 CustomScrollView.slivers。

在会话期间保留滚动位置

滚动视图会尝试使用 PageStorage 持久化滚动位置。要禁用此行为，可将 ScrollController.keepScrollOffset 上的 controller 设为 false。若启用此功能，建议将 PageStorageKey 用作此组件的 key，以便区分不同的滚动视图。

问题排查

内边距

默认情况下，GridView 会自动为网格可滚动区域的边缘添加内边距，以避开 MediaQuery 的 padding 所指示的局部遮挡。若要避免此行为，请将 padding 覆盖为零内边距。

The following example demonstrates how to override the default top padding using MediaQuery.removePadding.
link 
Widget myWidget(BuildContext context) {
  return MediaQuery.removePadding(
    context: context,
    removeTop: true,
    child: GridView.builder(
      gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
        crossAxisCount: 3,
      ),
      itemCount: 300,
      itemBuilder: (BuildContext context, int index) {
        return Card(
          color: Colors.amber,
          child: Center(child: Text('$index')),
        );
      }
    ),
  );
}

另请参阅：

  • SingleChildScrollView，一种只有一个子组件的可滚动组件。
  • ListView，用于线性排列可滚动组件的列表。
  • PageView，由可滚动子组件组成的列表，每个子组件大小均与视口相同。
  • CustomScrollView，使用 sliver 创建自定义滚动效果的可滚动组件。
  • SliverGridDelegateWithFixedCrossAxisCount，创建交叉轴上网格项数量固定的布局。
  • SliverGridDelegateWithMaxCrossAxisExtent，创建交叉轴范围不超过最大值的网格项布局。
  • ScrollNotification 和 NotificationListener，可用于监听滚动位置，而无需使用 ScrollController。
  • 布局组件目录。
