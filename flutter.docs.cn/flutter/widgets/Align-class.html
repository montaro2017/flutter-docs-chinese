Align 类

一个用于在自身内部对齐子级，并可选择根据子级尺寸调整自身大小的 widget。

例如，若要将一个方框对齐到右下角，可以为它设置一个紧约束，使其尺寸大于子级的自然尺寸，并将对齐方式设为 Alignment.bottomRight。

如果此 widget 的尺寸受到约束，且 widthFactor 和 heightFactor 均为 null，它会尽可能扩展到最大尺寸。如果某个方向不受约束，且对应的尺寸因子为 null，则 widget 在该方向上会与子级尺寸一致。如果尺寸因子不为 null，则此 widget 在对应方向上的尺寸为子级尺寸乘以该因子。例如，widthFactor 为 2.0 时，此 widget 的宽度始终是子级宽度的两倍。

The Align widget in this example uses one of the defined constants from Alignment, Alignment.topRight. This places the FlutterLogo in the top right corner of the parent blue Container.

link 
Center(
  child: Container(
    height: 120.0,
    width: 120.0,
    color: Colors.blue[50],
    child: const Align(
      alignment: Alignment.topRight,
      child: FlutterLogo(
        size: 60,
      ),
    ),
  ),
)

工作原理

alignment 属性描述子级坐标系中的一个点，以及此 widget 坐标系中的另一个点。Align widget 会放置 child，使 child这两个点彼此重合。

下面示例中使用的 Alignment 定义了两个点：

  • (0.2 * width of FlutterLogo/2 + width of FlutterLogo/2, 0.6 * height of FlutterLogo/2 + height of FlutterLogo/2) = (36.0, 48.0) in the coordinate system of the FlutterLogo.
  • (0.2 * width of Align/2 + width of Align/2, 0.6 * height of Align/2 + height of Align/2) = (72.0, 96.0) in the coordinate system of the Align widget (blue area).

Align widget 会放置 FlutterLogo，使这两个点彼此重合。在此示例中，FlutterLogo 的左上角相对于 Align widget 的左上角位于 (72.0, 96.0) - (36.0, 48.0) = (36.0, 48.0) 处。

link 
Center(
  child: Container(
    height: 120.0,
    width: 120.0,
    color: Colors.blue[50],
    child: const Align(
      alignment: Alignment(0.2, 0.6),
      child: FlutterLogo(
        size: 60,
      ),
    ),
  ),
)

下面示例中使用的 FractionalOffset 定义了两个点：

  • (0.2 * width of FlutterLogo, 0.6 * height of FlutterLogo) = (12.0, 36.0) in the coordinate system of the FlutterLogo.
  • (0.2 * width of Align, 0.6 * height of Align) = (24.0, 72.0) in the coordinate system of the Align widget (blue area).

Align widget 会放置 FlutterLogo，使这两个点彼此重合。在此示例中，FlutterLogo 的左上角相对于 Align widget 的左上角位于 (24.0, 72.0) - (12.0, 36.0) = (12.0, 36.0) 处。

FractionalOffset 类使用以 Container 左上角为原点的坐标系；这与上文使用 Alignment 时以中心为原点的坐标系不同。

link 
Center(
  child: Container(
    height: 120.0,
    width: 120.0,
    color: Colors.blue[50],
    child: const Align(
      alignment: FractionalOffset(0.2, 0.6),
      child: FlutterLogo(
        size: 60,
      ),
    ),
  ),
)
