PopupRoute
description

PopupRoute<T> 类 抽象

在当前路由上方覆盖显示组件的模态路由。

用户是否可以通过点击模态屏障关闭此路由。

模态屏障是在每个路由后方绘制的遮罩，通常会阻止用户与当前路由下方的路由交互，并对这些路由进行部分遮挡。

例如，显示对话框时，通常会在其下方的页面上覆盖一层较暗的模态屏障。

如果 barrierDismissible 为 true，点击此屏障、按键盘上的 Escape 键，或调用 Navigator.pop 等路由弹出函数，都会使当前路由弹出，且结果值为 null。

如果 barrierDismissible 为 false，点击屏障不会产生效果。

如果此 getter 可能返回不同的值，则应调用 changedInternalState 或 changedExternalState，使更改生效。

此处可以安全地使用 navigator.context 查找继承组件，因为 Navigator 会在依赖项发生变化时调用 changedExternalState，而 changedExternalState 会使模态屏障重建。

另请参阅：

  • Navigator.pop，用于关闭当前路由。
  • barrierColor，控制此路由遮罩层的颜色。
  • ModalBarrier，实现此功能的 widget。
