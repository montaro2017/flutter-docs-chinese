DefaultAssetBundle 类

用于确定其后代默认 asset bundle 的 widget。

例如，当未显式指定 bundle 时，Image 会用它来确定应为 AssetImage 使用哪个 bundle。

在测试中，可以用它覆盖当前 asset bundle，从而向被测 widget 注入特定资源。

例如，测试可以按如下方式创建一个测试 asset bundle：

link 
class TestAssetBundle extends CachingAssetBundle {
  @override
  Future<ByteData> load(String key) async {
    if (key == 'resources/test') {
      return ByteData.sublistView(utf8.encode('Hello World!'));
    }
    return ByteData(0);
  }
}

……然后使用此 bundle 实现，通过 DefaultAssetBundle 包裹被测 widget：
link 
// continuing from previous example...
await tester.pumpWidget(
  MaterialApp(
    home: DefaultAssetBundle(
      bundle: TestAssetBundle(),
      child: const TestWidget(),
    ),
  ),
);

假设 TestWidget 使用 DefaultAssetBundle.of 获取其 AssetBundle，那么请求 “resources/test” 资源时，它现在会获得 TestAssetBundle 中的 “Hello World!” 数据。

另请参阅：

  • AssetBundle, the interface for asset bundles.
  • rootBundle, the default asset bundle.
