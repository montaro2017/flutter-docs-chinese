BackdropFilter 类

一种先对现有已绘制内容应用滤镜，再绘制 child 的 widget。

滤镜会应用于其父级或祖先 widget 裁剪范围内的整个区域。如果没有裁剪，则会应用于全屏。

滤镜结果会使用 blendMode 参数混合回背景。所有平台都支持的 blendMode 值只有 BlendMode.srcOver，适用于大多数场景。但当 BackdropFilter 的父级使用临时缓冲区或保存图层（例如 Opacity widget）时，该值可能产生意外结果。在这种情况下，使用 BlendMode.src 可能会得到更理想的效果。

如果多个背景滤镜 widget 共享同一个 BackdropKey，Flutter 引擎可以将它们合并为一次渲染操作。背景键唯一标识背景滤镜的输入；共享该键表示滤镜可以只执行一次，从而显著降低场景中使用多个背景滤镜的开销。可以通过 backdropKey 构造参数手动提供该键，也可以通过 .grouped 构造函数从继承的 BackdropGroup widget 中查找。

彼此重叠的背景滤镜不应使用同一个背景键，否则重叠区域中的结果可能看起来像只应用了一个滤镜。

以下代码片段演示如何使用背景键，让列表中的每个项目都能高效地应用模糊效果。引擎只执行一次背景模糊，但视觉结果与分别模糊多次相同。

 Widget build(BuildContext context) {
   return BackdropGroup(
     child: ListView.builder(
       itemCount: 60,
       itemBuilder: (BuildContext context, int index) {
         return ClipRect(
           child: BackdropFilter.grouped(
             filter: ui.ImageFilter.blur(
               sigmaX: 40,
               sigmaY: 40,
             ),
             child: Container(
               color: Colors.black.withValues(alpha: 0.2),
               height: 200,
               child: const Text('Blur item'),
             ),
           ),
         );
      }
    ),
  );
}

If the BackdropFilter needs to be applied to an area that exactly matches its child, wraps the BackdropFilter with a clip widget that clips exactly to that child.
link 
Stack(
  fit: StackFit.expand,
  children: <Widget>[
    Text('0' * 10000),
    Center(
      child: ClipRect(  // <-- clips to the 200x200 [Container] below
        child: BackdropFilter(
          filter: ui.ImageFilter.blur(
            sigmaX: 5.0,
            sigmaY: 5.0,
          ),
          child: Container(
            alignment: Alignment.center,
            width: 200.0,
            height: 200.0,
            child: const Text('Hello World'),
          ),
        ),
      ),
    ),
  ],
)

此效果的开销相对较高，尤其是应用模糊等非局部滤镜时。

如果只想对单个 widget 应用 ImageFilter（而不是对某个 widget 下方的所有内容应用滤镜），请改用 ImageFiltered。在这种情况下，ImageFiltered 更易使用，开销也低于 BackdropFilter。

This example shows how the common case of applying a BackdropFilter blur to a single sibling can be replaced with an ImageFiltered widget. This code is generally simpler and the performance will be improved dramatically for complex filters like blurs.

下面的实现开销过高。

link 
 Widget buildBackdrop() {
   return Stack(
     children: <Widget>[
       Positioned.fill(child: Image.asset('image.png')),
       Positioned.fill(
         child: BackdropFilter(
           filter: ui.ImageFilter.blur(sigmaX: 6, sigmaY: 6),
         ),
       ),
     ],
   );
 }

可以改用以下方式，直接对该子 widget 应用模糊效果。
link 
 Widget buildFilter() {
   return ImageFiltered(
     imageFilter: ui.ImageFilter.blur(sigmaX: 6, sigmaY: 6),
     child: Image.asset('image.png'),
   );
 }

另请参阅：

  • ImageFiltered, which applies an ImageFilter to its child.
  • DecoratedBox, which draws a background under (or over) a widget.
  • Opacity, which changes the opacity of the widget itself.
  • https://flutter.dev/go/ios-platformview-backdrop-filter-blur for details and restrictions when an iOS PlatformView needs to be blurred.
