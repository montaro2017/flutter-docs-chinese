ContextMenuController 类

在指定位置构建并管理上下文菜单。

整个应用在任意时刻只能显示一个上下文菜单。在此类的某个实例上调用 show，会隐藏其他已显示的实例。

此示例展示如何使用 GestureDetector，在 widget 子树中任意接收到鼠标右键单击或长按的位置显示上下文菜单。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.ContextMenuController.1 mysample

另请参阅：

  • BrowserContextMenu，用于在 Web 上禁用浏览器的上下文菜单，并显示由 Flutter 绘制的上下文菜单。
