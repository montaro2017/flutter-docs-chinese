LocalHistoryRoute
description

LocalHistoryRoute<T> mixin

供路由使用的混入，可通过弹出列表在内部处理返回导航。

Navigator 收到弹出指令时，当前路由有机会在内部处理该操作。如果 LocalHistoryRoute 的本地历史条目列表不为空，它便会在内部处理弹出操作。此时不会移除当前路由，而是从列表中移除最近添加的 LocalHistoryEntry，并调用其 LocalHistoryEntry.onRemove。

  • Route，用于说明泛型类型参数 T 的含义。
