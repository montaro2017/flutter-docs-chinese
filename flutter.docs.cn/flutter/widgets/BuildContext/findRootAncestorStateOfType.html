findRootAncestorStateOfType<T extends State<StatefulWidget>> abstract 方法

T? findRootAncestorStateOfType<T extends State<StatefulWidget>>()

返回最远的祖先 StatefulWidget 所对应的 State 对象，且该 Widget 是给定类型 T 的实例。

其行为与 findAncestorStateOfType 相同，但会继续检查后续祖先，直到不存在类型为 T 的实例，然后返回最后找到的对象。

此操作的时间复杂度同样为 O(N)，但这里的 N 表示整个 Widget 树，而非子树。
