AnimatedPositioned 类

Positioned 的动画版本。每当给定位置发生变化时，它会在指定时长内自动为子级位置添加过渡动画。

仅当其父级为 Stack 时才有效。

如果此动画会导致子级的尺寸发生变化，适合使用此 widget。如果子级尺寸应保持不变，只有位置随时间变化，则可以改用 SlideTransition。SlideTransition 在动画每一帧只会触发重绘，而 AnimatedPositioned 还会触发布局。

下图展示了此 widget 的效果，使用的 curve 为 Curves.fastOutSlowIn。

可以为动画选择 curve 和 duration，此 widget 会自动过渡到新的目标位置。如果需要更精细地控制动画（例如在动画进行到一半时停止），可以改用 PositionedTransition，并向其传入 Animation。这样虽然可以精细调整动画，但需要手动管理底层 AnimationController 的生命周期，开发工作也更多。
