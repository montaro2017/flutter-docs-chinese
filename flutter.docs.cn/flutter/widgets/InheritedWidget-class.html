description

InheritedWidget 类 抽象

用于在组件树中高效向下传递信息的组件基类。

要从构建上下文获取最近的特定类型继承组件，请使用 BuildContext.dependOnInheritedWidgetOfExactType。

以这种方式引用继承组件后，当继承组件自身状态发生变化时，使用它的组件会重新构建。

下面是一个名为 FrogColor 的继承型 widget 基本框架：
link 
class FrogColor extends InheritedWidget {
  const FrogColor({
    super.key,
    required this.color,
    required super.child,
  });

  final Color color;

  static FrogColor? maybeOf(BuildContext context) {
    return context.dependOnInheritedWidgetOfExactType<FrogColor>();
  }

  static FrogColor of(BuildContext context) {
    final FrogColor? result = maybeOf(context);
    assert(result != null, 'No FrogColor found in context');
    return result!;
  }

  @override
  bool updateShouldNotify(FrogColor oldWidget) => color != oldWidget.color;
}

of 和 maybeOf 方法的实现

按照惯例，会在 of 和 maybeOf 两个静态方法中使用 InheritedWidget，并调用 BuildContext.dependOnInheritedWidgetOfExactType。这样，该类就能定义自己的回退逻辑，以应对作用域内不存在该 widget 的情况。

of 方法通常返回非空实例；如果找不到 InheritedWidget，则会触发断言。maybeOf 方法返回可空实例；如果找不到 InheritedWidget，则返回 null。of 方法通常在内部调用 maybeOf。

有时，of 和 maybeOf 方法返回的是数据，而不是继承型 widget 本身；例如这里可以返回 Color，而不是 FrogColor widget。

有时，继承型 widget 是另一个类的实现细节，因此会设为私有。在这种情况下，通常会在公共类上实现 of 和 maybeOf 方法。例如，Theme 实现为一个 StatelessWidget，它会构建一个私有继承型 widget；Theme.of 使用 BuildContext.dependOnInheritedWidgetOfExactType 查找该私有继承型 widget，然后返回其中的 ThemeData。

调用 of 或 maybeOf 方法

使用 of 或 maybeOf 方法时，context 必须是 InheritedWidget 的后代，也就是说它必须位于组件树中该 InheritedWidget 的“下方”。

此示例中使用的 context 来自 Builder；它是 FrogColor widget 的子级，因此这种用法有效。
link 
// continuing from previous example...
class MyPage extends StatelessWidget {
  const MyPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: FrogColor(
        color: Colors.green,
        child: Builder(
          builder: (BuildContext innerContext) {
            return Text(
              'Hello Frog',
              style: TextStyle(color: FrogColor.of(innerContext).color),
            );
          },
        ),
      ),
    );
  }
}

此示例中使用的 context 来自 MyOtherPage widget；它是 FrogColor widget 的父级，因此这种用法无效，并且调用 FrogColor.of 时会触发断言。
link 
// continuing from previous example...

class MyOtherPage extends StatelessWidget {
  const MyOtherPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: FrogColor(
        color: Colors.green,
        child: Text(
          'Hello Frog',
          style: TextStyle(color: FrogColor.of(context).color),
        ),
      ),
    );
  }
}
