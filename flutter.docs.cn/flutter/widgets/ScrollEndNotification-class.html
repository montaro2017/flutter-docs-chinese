ScrollEndNotification 类

表示 Scrollable 组件已停止滚动的通知。

此示例展示如何通过 NotificationListener 监听此通知，触发自动滚动，使最后一个部分可见的定高列表项对齐。也可以监听 ScrollController 的 ScrollPosition.isScrollingNotifier 实现类似效果；此外还提供了一个基于 ScrollPosition.isScrollingNotifier 的示例。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.ScrollEndNotification.1 mysample

此示例会在一个特殊的“对齐项”sliver 部分可见（与视口顶部或底部重叠）时，自动将其滚动到视口顶部或底部。与上一个示例不同，此示例通过 GlobalKey 从 RenderSliver 获取单个 sliver 的布局信息，因此不要求所有列表项具有相同尺寸。
