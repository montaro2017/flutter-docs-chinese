MediaQuery.removeViewInsets 构造函数

MediaQuery.removeViewInsets({
  1. Key? key,
  2. required BuildContext context,
  3. bool removeLeft = false,
  4. bool removeTop = false,
  5. bool removeRight = false,
  6. bool removeBottom = false,
  7. required Widget child,
})

创建一个新的 MediaQuery，从给定 context 环境中的 MediaQuery 继承数据，但移除指定的view insets。

当组件以某种方式使用了 MediaQuery 的view insets，导致其后代或兄弟组件不再能获取这些view insets时，应将此组件插入组件树。

context 参数的作用域内必须存在 MediaQuery。

如果 removeLeft、removeTop、removeRight 和 removeBottom 四个参数均为 false（默认值），则返回的 MediaQuery 会原样复用环境中的 MediaQueryData，这通常没有实际用处。

另请参阅：

  • MediaQueryData.viewInsets, the affected property of the MediaQueryData.
  • MediaQuery.removePadding, the same thing but for MediaQueryData.padding.
  • MediaQuery.removeViewPadding, the same thing but for MediaQueryData.viewPadding.

实现

MediaQuery.removeViewInsets({
  super.key,
  required BuildContext context,
  bool removeLeft = false,
  bool removeTop = false,
  bool removeRight = false,
  bool removeBottom = false,
  required super.child,
}) : data = MediaQuery.of(context).removeViewInsets(
       removeLeft: removeLeft,
       removeTop: removeTop,
       removeRight: removeRight,
       removeBottom: removeBottom,
     );
