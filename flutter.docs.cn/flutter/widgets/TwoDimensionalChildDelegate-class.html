TwoDimensionalChildDelegate
description

TwoDimensionalChildDelegate 类 抽象

一个为二维滚动提供子项的 delegate。

TwoDimensionalScrollView 会按需构建盒子子项，避免创建超出 TwoDimensionalViewport 可见范围的子项。它不会接收显式的 List，而是通过 TwoDimensionalChildDelegate 获取子项。

作为 ChangeNotifier，此 delegate 允许子类通知其监听器（通常是 RenderTwoDimensionalViewport 的子类），以便在 delegate 的相关属性变化时触发重建。此 delegate 的 getter 或 builder 返回值发生变化时，应调用 notifyListeners。这会通知 RenderTwoDimensionalViewport 重新查询 getter 和 builder，从而更新视口中子项的布局。

另请参阅：

  • TwoDimensionalChildBuilderDelegate, an concrete subclass of this that lazily builds children on demand.
  • TwoDimensionalChildListDelegate, an concrete subclass of this that uses a two dimensional array to layout children.
