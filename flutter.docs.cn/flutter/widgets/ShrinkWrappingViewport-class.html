description

ShrinkWrappingViewport 类

一种内部尺寸较大、并会沿主轴收缩包裹其子项的 widget。

ShrinkWrappingViewport 根据自身尺寸和给定的 offset 显示部分子项。offset 变化时，视口中可见的子项也会随之变化。

ShrinkWrappingViewport 与 Viewport 的区别在于：Viewport 会扩展以填满主轴，而 ShrinkWrappingViewport 会沿主轴调整自身尺寸以适应子项。收缩包裹的开销较大，因为 offset 变化时（例如标题栏折叠时），子项乃至视口本身都可能改变尺寸。

ShrinkWrappingViewport 不能直接包含盒子子项。例如，可以改用 SliverList、SliverFixedExtentList、SliverGrid 或 SliverToBoxAdapter。

另请参阅：

  • ListView, PageView, GridView, and CustomScrollView, which combine Scrollable 和 ShrinkWrappingViewport into widgets that are easier to use.
  • SliverToBoxAdapter, which allows a box widget to be placed inside a sliver context (the opposite of this widget).
  • Viewport, a viewport that does not shrink-wrap its contents.
