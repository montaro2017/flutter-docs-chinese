reverse 属性

bool reverse
final

列表主体是否沿阅读方向排列子组件。

例如，如果阅读方向为从左到右，且 mainAxis 为 Axis.horizontal，那么当 reverse 为 false 时，列表主体从左向右排列子组件；当 reverse 为 true 时，则从右向左排列。

同样，如果 mainAxis 为 Axis.vertical，那么当 reverse 为 false 时，列表主体从上向下排列；当 reverse 为 true 时，则从下向上排列。

默认为 false。

实现

final bool reverse;
