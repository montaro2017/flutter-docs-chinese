size 属性

Size size
final

媒体的逻辑像素尺寸（例如屏幕尺寸）。

不同设备上的逻辑像素视觉尺寸大致相同。物理像素是设备硬件像素的实际尺寸。每个逻辑像素对应的物理像素数由 devicePixelRatio 描述。

获取尺寸时，优先使用 MediaQuery.sizeOf，而不是 MediaQuery.of.size：前者只会在 size 变化时通知，后者则会在所有 MediaQueryData 发生变化时通知。

对于绘制在 Overlay 中的 widget，不要假定 Overlay 的尺寸与 MediaQuery 的尺寸相同。嵌套的 overlay 可能具有不同尺寸。

问题排查

缓存 MediaQuery.sizeOf(context) 返回的尺寸并在之后使用，被认为是不良实践。这会使应用无法响应布局变化，并可能导致意外行为。

例如，在启动期间，尤其是在 release 模式下，首次返回的尺寸可能是 Size.zero。当原生平台报告实际分辨率后，尺寸才会更新。使用 MediaQuery.sizeOf 可确保尺寸变化时，依赖该尺寸的 widget 会自动重建。

有关简介，请参阅文章 创建自适应与响应式应用。

另请参阅：

  • FlutterView.physicalSize, which returns the size of the view in physical pixels.
  • FlutterView.display, which returns reports display information like size, and refresh rate.
  • MediaQuery.sizeOf, a method to find and depend on the size defined for a BuildContext.
