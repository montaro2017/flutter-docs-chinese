viewInsets 属性

EdgeInsets viewInsets
final

被系统界面完全遮挡的显示区域，通常是设备键盘遮挡的部分。

移动设备键盘显示时，viewInsets.bottom 对应键盘顶部的位置。

This value is independent of the padding 和 viewPadding. viewPadding is measured from the edges of the MediaQuery widget's bounds. Padding is calculated based on the viewPadding and viewInsets. The bounds of the top level MediaQuery created by WidgetsApp are the same as the window (often the mobile device screen) that contains the app.

另请参阅：

  • FlutterView, which provides some additional detail about this property and how it relates to padding 和 viewPadding.
