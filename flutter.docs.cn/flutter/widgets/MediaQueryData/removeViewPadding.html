removeViewPadding 方法

MediaQueryData removeViewPadding({
  1. bool removeLeft = false,
  2. bool removeTop = false,
  3. bool removeRight = false,
  4. bool removeBottom = false,
})

创建此媒体查询数据的副本，并将指定的 viewPadding 替换为零。

如果 removeLeft、removeTop、removeRight 和 removeBottom 四个参数均为 false（默认值），则原样返回此 MediaQueryData。

另请参阅：

  • MediaQuery.removeViewPadding 使用此方法从当前环境中移除 viewPadding（其所属的 MediaQuery）。
  • removePadding，功能相同，但作用于 padding。
  • removeViewInsets，功能相同，但作用于 viewInsets。

实现

MediaQueryData removeViewPadding({
  bool removeLeft = false,
  bool removeTop = false,
  bool removeRight = false,
  bool removeBottom = false,
}) {
  if (!(removeLeft || removeTop || removeRight || removeBottom)) {
    return this;
  }
  return copyWith(
    padding: padding.copyWith(
      left: removeLeft ? 0.0 : null,
      top: removeTop ? 0.0 : null,
      right: removeRight ? 0.0 : null,
      bottom: removeBottom ? 0.0 : null,
    ),
    viewPadding: viewPadding.copyWith(
      left: removeLeft ? 0.0 : null,
      top: removeTop ? 0.0 : null,
      right: removeRight ? 0.0 : null,
      bottom: removeBottom ? 0.0 : null,
    ),
  );
}
