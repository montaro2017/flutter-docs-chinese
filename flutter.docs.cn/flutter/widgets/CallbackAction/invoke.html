重写

执行此 Action 时调用。

通过 Actions.invoke 调用 Action，或直接调用 ActionDispatcher.invokeAction 时，ActionDispatcher 会调用此方法。

此方法仅供 ActionDispatcher 或其子类调用，并且只有在 isEnabled 为 true 时才能调用。

重写此方法时，返回值可以是任意 Object；但如果将重写方法的返回类型改为与实际返回值相符，可以获得更好的类型安全性。

例如，如果重写后的 invoke 返回 int，可以按如下方式定义：

class IncrementIntent extends Intent {
  const IncrementIntent({required this.index});

  final int index;
}

class MyIncrementAction extends Action<IncrementIntent> {
  @override
  int invoke(IncrementIntent intent) {
    return intent.index + 1;
  }
}

若要接收调用 Action 的结果，必须通过 Actions.invoke 或 ActionDispatcher 调用它。通过 Shortcuts Widget 调用的 Action 会忽略其返回值。

如果 Action 的行为取决于 BuildContext，请改为继承 ContextAction，而不是 Action。

实现

@override
Object? invoke(T intent) => onInvoke(intent);
