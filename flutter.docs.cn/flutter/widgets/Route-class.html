Route<T> 类 抽象

由 Navigator 管理的条目的抽象。

此类定义了 navigator 与被推入或弹出 navigator 的“route”之间的抽象接口。大多数 route 都有视觉表现形式，会使用一个或多个 OverlayEntry 对象将内容放入 navigator 的 Overlay 中。

有关如何在导航中使用 Route 的更多说明（含代码示例），请参阅 Navigator。

如需让 route 通过平台自适应的转场替换整个屏幕，请参阅 MaterialPageRoute。

如果 settings 是 Page 的子类，则 route 可以归属于某个 page。基于 page 的 route 不同于无 page 的 route：前者会在 Navigator.pages 更新期间通过 Page.createRoute 创建。与此 route 关联的 page 在 route 的生命周期内可能发生变化。如果 Navigator 更新了此 route 的 page，就会调用 changedInternalState，通知 route 其 page 已更新。

类型参数 T 是 route 的返回类型，用于 currentResult、popped 和 didPop。如果 route 不返回值，可以使用 void 类型。
