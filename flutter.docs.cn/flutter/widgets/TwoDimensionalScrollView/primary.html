primary 属性

bool? primary
final

此滚动视图是否为与父级 PrimaryScrollController 关联的主滚动视图。

为 true 时，即使内容不足以实际滚动，此滚动视图仍可滚动。否则，默认情况下只有内容足够时用户才能滚动此视图。请参阅 physics。

为 true 时，此滚动视图也会用于默认的 ScrollAction。如果应用中其他获得焦点的部分未处理某个 ScrollAction，就会通过此滚动视图执行该操作。例如，执行 Page Up 和 Page Down 等 Shortcuts 键盘事件时便会如此。

在 iOS 上，点按状态栏时也会滚动此视图回到顶部。

如果已向 controller 提供 ScrollController，此值不能为 true，因为一个 ScrollView 只能关联一个 ScrollController。

设为 false 会明确禁止继承任何 PrimaryScrollController。

默认为 null。如果为 null 且未提供 controller，则使用 PrimaryScrollController.shouldInherit 决定是否自动继承。

默认情况下，每个 ModalRoute 注入的 PrimaryScrollController 都配置为：在 TargetPlatformVariant.mobile 平台上，为滚动方向为 Axis.vertical 的 ScrollView 自动继承。若在应用中再添加一个 PrimaryScrollController，它会覆盖上层的 PrimaryScrollController。
