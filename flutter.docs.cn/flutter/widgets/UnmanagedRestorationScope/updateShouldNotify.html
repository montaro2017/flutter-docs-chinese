框架是否应通知继承此组件的组件。

此组件重新构建时，有时需要重新构建继承它的组件，有时则不需要。例如，如果此组件持有的数据与 oldWidget 持有的数据相同，就无需重新构建继承 oldWidget 数据的组件。

框架通过调用此函数来区分这些情况，并将此前占据组件树中此位置的组件作为参数传入。传入组件的 runtimeType 保证与此对象相同。

实现

@override
bool updateShouldNotify(UnmanagedRestorationScope oldWidget) {
  return oldWidget.bucket != bucket;
}
