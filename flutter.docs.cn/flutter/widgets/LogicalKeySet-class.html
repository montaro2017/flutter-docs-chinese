LogicalKeySet 类

由一组 LogicalKeyboardKey 组成，可用作映射中的键。

LogicalKeySet 可用作 ShortcutActivator。对于 Delete 或 Ctrl+C 等常见快捷键，不建议使用 LogicalKeySet；条件允许时优先使用 SingleActivator，其行为更接近常见平台的习惯。

用作 ShortcutActivator 时，只有按下所有 keys 且未按下其他按键，LogicalKeySet 才会激活 intent；但修饰键不区分左右侧（例如左 Ctrl 和右 Ctrl 视为相同）。

在下面的示例中，按下以下按键组合时计数器会增加：

  • Control left, then C.
  • Control right, then C.
  • C, then Control left.

但按下以下组合时不会增加：

  • Control left, then A, then C.

要使用此代码示例创建本地项目，请运行：
flutter create --sample=widgets.LogicalKeySet.1 mysample

这也是 Set 的轻量包装，但它会将相等性比较从对象标识改为内容比较，因此包含相同按键的不同集合也会被视为相等。
