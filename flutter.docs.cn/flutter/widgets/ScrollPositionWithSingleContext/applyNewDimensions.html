applyNewDimensions 方法

  1. @重写
void applyNewDimensions()
重写

通知滚动活动，底层视口或内容的尺寸已发生变化。

在 applyViewportDimension 或 applyContentDimensions 更改 minScrollExtent、maxScrollExtent 或 viewportDimension 后调用此方法。调用此方法时，必须先使用 correctPixels 对 pixels 进行所有修正，再调用此方法。

默认实现会调用 activity 的 ScrollActivity.applyNewDimensions 方法，将新尺寸通知给该活动。

另请参阅：

  • applyViewportDimension, which is called when new viewport dimensions are established.
  • applyContentDimensions, which is called after new viewport dimensions are established, and also if new content dimensions are established, and which calls ScrollPosition.applyNewDimensions.

实现

@override
void applyNewDimensions() {
  super.applyNewDimensions();
  context.setCanDrag(physics.shouldAcceptUserOffset(this));
}
