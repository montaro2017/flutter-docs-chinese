CompositedTransformFollower
description

CompositedTransformFollower 类

一种跟随 CompositedTransformTarget 定位的组件。

此组件会在合成阶段（绘制阶段之后，详见 WidgetsBinding.drawFrame）参与合成，并应用变换，使关联目标的 targetAnchor 与此组件的 followerAnchor 重合。除非 offset 不等于 Offset.zero，否则这两个锚点的全局坐标相同；若 offset 不为零，followerAnchor 会在关联 CompositedTransformTarget 的坐标空间中按 offset 偏移，该目标组件即关联的 CompositedTransformTarget。

作为 link 使用的 LayerLink 对象，必须与对应 CompositedTransformTarget 使用的对象相同。

在绘制顺序中，CompositedTransformTarget 必须位于此 CompositedTransformFollower 之前。

只有当目标位置位于此组件父级认为可命中的区域内时，才能对其后代进行命中测试。如果父级覆盖整个屏幕，这一点自然成立。因此，此组件通常用作应用级 Overlay 中 OverlayEntry 的根组件（例如由 MaterialApp 组件的 Navigator 创建的 Overlay）。

CompositedTransformFollower 和 CompositedTransformTarget 与 OverlayPortal.overlayChildLayoutBuilder 不兼容，因此不能同时使用。可以改用 OverlayPortal.overlayChildLayoutBuilder。

另请参阅：

  • CompositedTransformTarget, the widget that this widget can target.
  • FollowerLayer, the layer that implements this widget's logic.
  • Transform, which applies an arbitrary transform to a child.
  • OverlayPortal.overlayChildLayoutBuilder, which achieves a similar target-following effect, but also allows the follower to be sized and positioned dynamically based on the target's size and position.
