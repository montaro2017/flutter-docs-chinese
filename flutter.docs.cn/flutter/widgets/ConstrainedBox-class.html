ConstrainedBox 类

为其子项施加额外约束的组件。

例如，如果希望 child 的最小高度为 50.0 逻辑像素，可以将 const BoxConstraints(minHeight: 50.0) 用作 constraints。

此代码片段通过应用 BoxConstraints.expand 约束，使子 widget（带有一些 Text 的 Card）填满父项：
link 
ConstrainedBox(
  constraints: const BoxConstraints.expand(),
  child: const Card(child: Text('Hello World!')),
)

使用 SizedBox.expand 组件也能实现相同效果。

另请参阅：

  • BoxConstraints, the class that describes constraints.
  • UnconstrainedBox，一种会尝试让子组件不受约束地绘制的容器。
  • SizedBox, which lets you specify tight constraints by explicitly specifying the height or width.
  • FractionallySizedBox 根据自身尺寸的一定比例调整子项大小，并依据 Alignment 值对子项进行定位。
  • AspectRatio 会尝试在父项约束范围内调整自身尺寸，同时使子项符合指定的宽高比。
  • The 布局组件目录.
