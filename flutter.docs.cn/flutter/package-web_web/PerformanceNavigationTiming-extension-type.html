PerformanceNavigationTiming

PerformanceNavigationTiming extension type

PerformanceNavigationTiming 接口提供用于存储和获取浏览器文档导航事件指标的方法和属性。例如，可用此接口确定加载或卸载文档所需的时间。

性能时间线只包含当前文档，因此其中只有一个 PerformanceNavigationTiming 对象。该对象继承了 PerformanceResourceTiming 和 PerformanceEntry 的所有属性和方法。

下图展示了 PerformanceNavigationTiming 中定义的所有时间戳属性。

API 文档内容来自 MDN Web 文档。
