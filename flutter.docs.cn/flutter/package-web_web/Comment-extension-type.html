Comment

Comment extension type

Comment 接口表示标记语言中的文本注释；这类注释通常不会直接显示在页面上，但可以在源代码视图中读取。

在 HTML 和 XML 中，注释内容位于“<!--”和“-->”之间。在 XML（例如 SVG 或 MathML 标记）中，注释内不能使用“--”字符序列。

API 文档来源：MDN Web Docs。
