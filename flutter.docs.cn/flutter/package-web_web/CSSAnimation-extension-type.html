CSSAnimation

CSSAnimation extension type

CSSAnimation 接口属于 Web Animations API，表示一个 Animation 对象。

API 文档来源：MDN Web Docs。

on
  • JSObject
实现的类型
  • Animation
  • JSObject
可用扩展
  • JSAnyOperatorExtension
  • JSAnyUtilityExtension
  • JSObjectUnsafeUtilExtension
  • NullableUndefineableJSAnyExtension

属性

animationName → String
animationName 是 CSSAnimation 接口的属性，返回描述应用于元素的动画的一个或多个关键帧 at-rule 的名称。
无设置器
currentTime ↔ CSSNumberish?
属性 Animation.currentTime 是 Web Animations API 返回并设置动画的当前时间值（毫秒），无论动画正在运行还是处于暂停状态。
读写访问器对继承
effect ↔ AnimationEffect?
属性 Animation.effect 是 Web Animations API 获取并设置动画的目标效果。目标效果可以是基于 AnimationEffect，例如 KeyframeEffect，也可以是 null。
读写访问器对继承

pending → bool
只读属性 Animation.pending 是 Web Animations API 指示动画当前是否正在等待异步操作，例如开始播放或暂停正在运行的动画。
无设置器继承
playbackRate ↔ double
属性 Animation.playbackRate 是 Web Animations API 返回或设置动画的播放速率。
读写访问器对继承
playState → AnimationPlayState
只读属性 Animation.playState 是 Web Animations API 返回一个枚举值，用于描述动画的播放状态。
无设置器继承
ready → JSPromise<Animation>
只读属性 Animation.ready 是 Web Animations API 返回一个 Promise，动画准备就绪后该 Promise 会完成。每当动画进入 "pending" 播放状态 或被取消时，都会创建一个新的 Promise；这两种情况下，动画都已准备好重新启动。
无设置器继承
replaceState → AnimationReplaceState
只读属性 Animation.replaceState 是 Web Animations API 指示动画被另一个动画替代后，是否已被浏览器自动移除。
无设置器继承
runtimeType → Type
此对象运行时类型的表示。
无设置器继承
startTime ↔ CSSNumberish?
属性 Animation.startTime 是 Animation 接口的一个属性，其值是一个双精度浮点值，表示计划开始播放动画的时间。
读写访问器对继承
timeline ↔ AnimationTimeline?
属性 Animation.timeline 是 Animation 接口返回或设置与此动画关联的 AnimationTimeline。时间线为同步提供时间值来源，并且是基于 AnimationTimeline 的对象。默认情况下，动画的时间线与 Document 的时间线相同。
读写访问器对继承
