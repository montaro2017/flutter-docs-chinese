priority 属性

int get priority

可以创建在文档中彼此重叠的 Range 对象。

当多个不同的 Highlight 对象使用彼此重叠的范围，并通过伪元素设置高亮样式时，可能会发生样式冲突。

如果两个文本范围彼此重叠，且都通过 css_custom_highlight_api 高亮，并且都使用 CSS color 属性设置样式，浏览器就需要决定重叠部分应使用哪种颜色。

默认情况下，所有高亮的优先级相同，浏览器会使用最近注册的高亮为重叠部分设置样式。

Highlight 接口的 priority 属性是一个 Number，用于更改此默认行为，并决定在重叠部分发生样式冲突时采用哪个高亮的样式。

请注意，高亮的所有样式都会应用；只有多个重叠高亮使用相同 CSS 属性时，浏览器才需要解决冲突。高亮样式冲突的解决方式也不取决于伪元素规则在源代码中的顺序，也不取决于 CSS 属性是否标记为 !important。

实现

external int get priority;
set priority (int value)
