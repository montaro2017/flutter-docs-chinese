Cache

Cache extension type

Cache 接口为缓存于长期内存中的 Request / Response 对象对提供持久化存储机制。Cache 对象的生命周期取决于浏览器，但同一来源下的脚本通常可以依赖已填充的 Cache 对象继续存在。Cache 接口既可在窗口作用域中使用，也可在 worker 中使用。虽然它定义在 Service Worker 规范中，但并非必须与 service worker 配合使用。

一个来源可以拥有多个具名 Cache 对象。你需要自行实现脚本（例如 ServiceWorker 中的脚本）如何处理 Cache 更新。除非明确请求更新，否则 Cache 中的条目不会更新；除非删除，否则不会过期。使用 CacheStorage.open 打开指定名称的 Cache 对象，然后调用任意 Cache 方法来维护该 Cache。

你还需要定期清理缓存条目。每个浏览器都会对单个来源可使用的缓存存储量设定硬性上限。可以通过 StorageManager.estimate 方法获取 Cache 配额使用量估算。浏览器会尽力管理磁盘空间，但也可能删除某个来源的 Cache 存储。通常，浏览器会删除某个来源的全部数据，或完全不删。请按名称对缓存进行版本管理，并仅在对应版本的脚本能够安全操作时使用这些缓存。更多信息请参阅删除旧缓存。

注意：键匹配算法取决于值中的 VARY 标头。因此，要匹配新键，需要同时检查 Cache 对象条目的键和值。

注意：缓存 API 不遵循 HTTP 缓存标头。

API 文档内容来源于 MDN Web 文档。
