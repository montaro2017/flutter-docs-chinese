Canvas 2D API 的 CanvasRenderingContext2D.rect() 方法会向当前路径添加一个矩形。

与其他会修改当前路径的方法一样，此方法不会直接绘制任何内容。若要将矩形绘制到画布上，可以使用 CanvasRenderingContext2D.fill 或 CanvasRenderingContext2D.stroke 方法。

注意：若要一步完成矩形的创建和绘制，请使用 CanvasRenderingContext2D.fillRect 或 CanvasRenderingContext2D.strokeRect 方法。
