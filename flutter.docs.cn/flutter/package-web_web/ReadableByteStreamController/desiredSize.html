desiredSize 属性

double? get desiredSize

ReadableByteStreamController 接口的只读 desiredSize 属性会返回将流的内部队列填充到其“期望大小”所需的字节数。

流使用该值向底层源表示首选的数据流速率。支持限速或暂停数据流入的源（并非所有源都支持！）应控制数据流入，使流缓冲区的 desiredSize 保持为正数并尽可能接近零。

流使用 desiredSize 向下游使用者施加背压。
