Window

Window extension type

Window 接口表示一个包含文档的窗口；其 document 属性指向该窗口中加载的 DOM 文档。

可以使用 document.defaultView 属性获取指定文档对应的窗口。

JavaScript 代码可以访问一个名为 window 的全局变量，它表示脚本当前运行所在的窗口。

Window 接口包含各种函数、命名空间、对象和构造函数，它们不一定都与用户界面窗口的概念直接相关。不过，需要全局可用的这些项目适合放在 Window 接口中。其中许多内容记录在 JavaScript 参考和 DOM 参考中。

在使用标签页的浏览器中，每个标签页都由各自的 Window 对象表示；在某个标签页中运行的 JavaScript 代码所看到的全局 window 始终代表该代码所在的标签页。不过，即使在标签页浏览器中，某些属性和方法仍作用于包含这些标签页的整个窗口，例如 Window.resizeTo 和 Window.innerHeight。通常，无法合理归属于某个标签页的内容都归属于窗口本身。
