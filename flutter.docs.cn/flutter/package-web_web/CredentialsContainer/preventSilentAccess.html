preventSilentAccess 方法

JSPromise<JSAny?> preventSilentAccess()

CredentialsContainer 接口的 preventSilentAccess() 方法会设置一个标志，用于指定在今后访问当前来源时是否允许自动登录，随后返回一个兑现为 undefined 的 Promise。例如，用户退出网站后可以调用此方法，确保其下次访问时不会自动登录。按来源进行的中介控制是浏览器存储凭据时增加的检查点，用于告知用户账号的登录状态。此方法通常在用户退出网站后调用，以确保下次访问时不会自动传递该用户的登录信息。

此方法在早期规范版本中称为 requireUserMediation()。支持情况详见浏览器兼容性部分。
