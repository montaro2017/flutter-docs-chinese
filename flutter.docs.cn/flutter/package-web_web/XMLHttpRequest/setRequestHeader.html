XMLHttpRequest 的 setRequestHeader() 方法用于设置 HTTP 请求标头的值。使用 setRequestHeader() 时，必须在调用 XMLHttpRequest.open 之后、调用 XMLHttpRequest.send 之前调用此方法。如果多次调用此方法并设置同一个标头，多个值会合并到同一个请求标头中。

首次调用 setRequestHeader() 后，每次再次调用时，指定文本都会追加到现有标头内容的末尾。

如果未通过此方法设置 Accept 标头，则调用 XMLHttpRequest.send 发送请求时，会附带值为 "*/*" 的 Accept 标头。

出于安全原因，有些请求标头的值由用户代理控制。前端 JavaScript 代码尝试设置这些标头时会被忽略，且不会收到警告或错误。

此外，请求中可以添加 Authorization HTTP 标头，但如果请求被重定向到其他源，该标头会被移除。

注意：发送跨域请求时，自定义标头可能会触发“预检响应中的 Access-Control-Allow-Headers 不允许此标头”异常。在这种情况下，需要在服务器端的响应标头中配置允许的请求标头。
