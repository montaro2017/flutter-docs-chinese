readyState

readyState 属性

int get readyState

@AvailableInWorkers("window_and_worker_except_service")

XMLHttpRequest.readyState 属性会返回 XMLHttpRequest 客户端当前所处的状态。XHR 客户端可能处于以下状态：

数值 状态 说明
0 UNSENT 客户端已创建，尚未调用 open()。
1 OPENED 已调用 open()。
2 HEADERS_RECEIVED 已调用 send()，响应标头和状态码现已可用。
3 LOADING 正在下载；responseText 包含部分数据。
4 DONE 操作已完成。
  • UNSENT
    • ：XMLHttpRequest 客户端已创建，但尚未调用 open() 方法。
  • OPENED
    • ：已调用 open() 方法。在此状态下，可以使用 setRequestHeader() 方法设置请求标头，也可以调用 send() 方法以开始获取资源。
  • HEADERS_RECEIVED
    • ：已调用 send()；所有重定向（如果有）均已完成，并且已收到响应标头。
  • LOADING
    • ：正在接收响应正文。如果 responseType 为 "text" 或空字符串，responseText 会随着加载过程包含部分文本响应。
  • DONE
    • ：资源获取操作已完成。这表示数据传输可能已成功完成，也可能已失败。

实现

external int get readyState;
