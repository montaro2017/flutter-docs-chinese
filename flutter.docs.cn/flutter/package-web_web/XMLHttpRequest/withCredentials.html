withCredentials

withCredentials 属性

bool get withCredentials

@AvailableInWorkers("window_and_worker_except_service")

XMLHttpRequest.withCredentials 属性是一个布尔值，用于指示跨站 Access-Control 请求是否应携带 Cookie、身份验证标头或 TLS 客户端证书等凭据。对同源请求设置 withCredentials 不会产生影响。

此外，此标志也用于指示是否忽略响应中的 Cookie。默认值为 false。如果要让来自其他域的 XMLHttpRequest 响应为其自身域设置 Cookie，必须在发送请求前将 withCredentials 设为 true。通过将 withCredentials 设为 true 获取的第三方 Cookie 仍受同源策略约束，因此请求脚本无法通过 document.cookie 或响应标头访问这些 Cookie。

注意：此设置不会影响同源请求。

注意：无论 Access-Control- 标头的值如何，来自其他域的 XMLHttpRequest 响应都不能为其自身域设置 Cookie，除非在发送请求前将 withCredentials 设为 true。
