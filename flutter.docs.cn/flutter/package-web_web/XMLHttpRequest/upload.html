upload 属性

XMLHttpRequestUpload get upload

@AvailableInWorkers("window_and_worker_except_service")

XMLHttpRequest 的 upload 属性会返回一个 XMLHttpRequestUpload 对象，可通过观察该对象来监控上传进度。

这是一个不透明对象，但它同时也是 XMLHttpRequestEventTarget，因此可以为其添加事件监听器以跟踪上传过程。

注意：为此对象添加事件监听器会使请求不再属于“简单请求”；如果是跨域请求，则会触发预检请求，详见 CORS。因此，必须在调用 XMLHttpRequest.send 之前注册事件监听器，否则不会分发上传事件。

注意：规范似乎还要求在调用 XMLHttpRequest.open 之后添加事件监听器。不过，浏览器在这方面存在缺陷，通常需要在调用 XMLHttpRequest.open之前注册监听器才能正常工作。

上传对象上可能触发以下事件，可用于监控上传过程：

事件 说明
[XMLHttpRequestUpload.loadstart_event] 上传已开始。
[XMLHttpRequestUpload.progress_event] 定期触发，用于报告当前已完成的上传进度。
[XMLHttpRequestUpload.abort_event] 上传操作已中止。
[XMLHttpRequestUpload.error_event] 上传失败，发生了错误。
[XMLHttpRequestUpload.load_event] 上传已成功完成。
[XMLHttpRequestUpload.timeout_event] 由于未能在 [XMLHttpRequest.timeout] 指定的时间间隔内收到响应，上传已超时。
[XMLHttpRequestUpload.loadend_event] 上传已结束。此事件不区分成功或失败，并且无论结果如何，都会在上传结束时发送。在此事件之前，已经会触发 load、error、abort 或 timeout 事件之一，以说明上传结束的原因。
