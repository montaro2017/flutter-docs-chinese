WaveShaperNode

WaveShaperNode extension type

WaveShaperNode 接口表示一种非线性失真器。

它是一个 AudioNode，通过使用曲线对信号施加波形整形失真。除了明显的失真效果外，它还常用于为信号增添温暖感。

WaveShaperNode 始终恰好有一个输入和一个输出。

Number of inputs 1
Number of outputs 1
Channel count mode "max"
Channel count 2 (not used in the default count mode)
Channel interpretation "speakers"

API 文档来源于 MDN Web 文档。
