CrossOriginWindow

CrossOriginWindow 类

跨源窗口的安全包装器。

由于浏览器限制了跨源访问，Dart 运行时无法为跨源窗口提供类型，也无法对其执行非空断言。若要安全地与跨源窗口交互，请改用此包装器。

对应的 dart:html 类型是 _DOMWindowCrossFrame。

此类型仅包含以下 WHATWG HTML 规范所允许的 API：https://html.spec.whatwg.org/multipage/nav-history-apis.html#crossoriginproperties-(-o-)。某些浏览器可能允许更多访问。
