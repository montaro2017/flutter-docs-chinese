HTMLTableRowElement 接口的 insertCell() 方法会在表格行（tr）中插入一个新单元格（td），并返回该单元格的引用。

注意：insertCell() 会直接将单元格插入该行。无需像使用 Document.createElement 创建新的 <td> 元素时那样，再通过 Node.appendChild 单独追加该单元格。

不过，不能使用 insertCell() 创建新的 <th> 元素。
