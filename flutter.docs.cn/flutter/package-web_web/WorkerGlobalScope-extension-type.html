WorkerGlobalScope

WorkerGlobalScope extension type

WorkerGlobalScope 接口属于 Web Workers API，表示任意工作线程的作用域。工作线程没有浏览上下文；该作用域包含通常由 Window 对象提供的信息，例如事件处理程序、控制台或关联的 WorkerNavigator 对象。每个 WorkerGlobalScope 都有自己的事件循环。

此接口通常会由不同类型的工作线程专门化：专用工作线程使用 DedicatedWorkerGlobalScope，共享工作线程使用 SharedWorkerGlobalScope，而 ServiceWorker 使用 ServiceWorkerGlobalScope。self 属性会返回各上下文专用的作用域。

API 文档来源：MDN Web 文档。
