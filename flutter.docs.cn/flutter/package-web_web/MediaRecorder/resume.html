void resume()

MediaRecorder 接口的 resume() 方法用于恢复此前已暂停的媒体录制。

如果 MediaRecorder.state 已经是 “recording”，调用 resume() 不会产生任何效果。

调用 resume() 方法时，浏览器会将一个任务加入队列，并按以下步骤执行：

  1. 如果 MediaRecorder.state 为 "inactive"，则抛出 DOM InvalidStateError 异常并终止这些步骤。如果 MediaRecorder.state 不为 "inactive"，则继续下一步。
  2. 将 MediaRecorder.state 设为 "recording"。
  3. 继续将数据收集到当前的 Blob 中。
  4. 触发 resume 事件。
