void showPicker()

HTMLInputElement.showPicker() 方法会显示浏览器为 input 元素提供的选择器。

这与通常选中该元素时显示的选择器相同，但也可以通过按下按钮或其他用户交互来触发。

浏览器通常会为以下类型的输入框实现此功能："date"、"month"、"week"、"time"、"datetime-local"、"color" 或 "file"。也可以使用 datalist 元素或 autocomplete 属性为选择器预先填充项目。

更一般地说，如果平台上的任意输入元素具有选择器，此方法理想情况下都应能显示该选择器。
