HTMLInputElement.setSelectionRange() 方法用于设置 input 或 textarea 元素当前文本选区的起始和结束位置。

元素必须处于焦点状态，此调用才会生效。

还可以选择指定选区的方向。例如，可以指明选区是由用户从所选文本末尾向开头单击并拖动而设置的。

此方法可在一次调用中更新 HTMLInputElement.selectionStart、HTMLInputElement.selectionEnd 和 HTMLInputElement.selectionDirection 属性。

元素的输入类型必须是以下之一：password、search、tel、text 或 url。否则，浏览器会抛出 InvalidStateError 异常。

如果要选中输入元素中的所有文本，可以改用 HTMLInputElement.select() 方法。
