stepDown 方法

void stepDown([
  1. int n
])

HTMLInputElement.stepDown([n]) 方法会将数值类型 input 元素的值减小一个 step 属性值；如果传入数字参数，则最多减小 step 属性值的 n 倍。

调用此方法时，会将 value 减去（step * n）。如果未指定 n，则默认为 1；如果未指定 step，则使用 step 的默认值。

所有支持 step 属性的数值、日期和时间类型输入框均可使用此方法，包括 date、month、week、time、datetime-local、number 和 range。

给定 <input id="myTime" type="time" max="17:00" step="900" value="17:00">，调用 myTime.stepDown(3) 会将值改为 16:15，即时间减少 3 * 900 秒，也就是 45 分钟。如果不带参数调用 myTime.stepDown()，由于 n 默认为 1，结果将是 16:45。

<!-- decrements by intervals of 900 seconds (15 minute) -->
<input type="time" max="17:00" step="900" />

<!-- decrements by intervals of 7 days (one week) -->
<input type="date" max="2019-12-25" step="7" />

<!-- decrements by intervals of 12 months (one year) -->
<input type="month" max="2019-12" step="12" />

不过，在 <input type="time" max="17:00" step="900"> 上调用 stepDown，不会像预期那样将值设为 17:00；这与当输入框为 <input type="time" min="17:00" step="900"> 时调用 stepUp 的行为不同。第一次调用 stepDown 会将初始值设为 23:45，即使已设置 max 属性。第二次调用会将值设为 17:00，第三次调用则会将值设为 16:45。

let input1 = document.createElement("input");
input1.setAttribute("type", "time");
input1.setAttribute("min", "17:00");
input1.setAttribute("step", 900);
console.log(input1.value); // ""
input1.stepUp();
console.log(input1.value); // "17:00"
// However
let input2 = document.createElement("input");
input2.setAttribute("type", "time");
input2.setAttribute("max", "17:00");
input2.setAttribute("step", 900);
console.log(input2.value); // ""
input2.stepDown();
console.log(input2.value); // "23:45"
input2.stepDown();
console.log(input2.value); // "17:00"
input2.stepDown();
console.log(input2.value); // "16:45"

调用此方法时，会在表单控件的约束范围内，按 step 属性值乘以参数所得的数值更改控件的值。如果未传入参数，则默认值为 1。此方法不会使值低于设置的 min 值，也不会违反 step 属性的约束。若 n 为负数，则值会增加，但不会超过 max 值。

如果调用 stepDown() 方法前的值无效（例如不符合 step 属性设置的约束），调用 stepDown() 后会返回一个符合表单控件约束的值。

如果表单控件不是时间、日期或数值类型，因而不支持 step 属性（参见上方支持的输入类型列表），或者 step 值设为 any，则会抛出 InvalidStateError 异常。

  • HTMLInputElement.stepDown

    • ：将 value 减去（step * n），其中 n 默认为 1。以下情况会抛出 InvalidStateError 异常：

      • if the method is not applicable to for the current type value,
      • if the element has no step value,
      • if the value cannot be converted to a number,
      • if the resulting value is above the max or below the min.
