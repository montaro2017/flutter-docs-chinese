OscillatorNode

OscillatorNode extension type

OscillatorNode 接口表示周期性波形，例如正弦波。它是一个 AudioScheduledSourceNode 音频处理模块，会产生指定频率的波形，实际效果就是持续的音调。

Number of inputs 0
Number of outputs 1
Channel count mode max
Channel count 2 (not used in the default count mode)
Channel interpretation speakers

API 文档来源：MDN Web Docs。
