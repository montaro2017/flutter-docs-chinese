注意：建议使用以下方式替代此已弃用的方法：直接设置 orientationX、orientationY 和 orientationZ 属性。

PannerNode 接口的 setOrientation() 方法用于定义音频源的播放方向。

如果声音的方向性很强，此设置会产生显著影响；方向性由三个锥形相关属性控制：PannerNode.coneInnerAngle、PannerNode.coneOuterAngle 和 PannerNode.coneOuterGain。在这种情况下，背向听者的声音可能会很轻，甚至完全听不见。

参数 x、y 和 z 没有单位，使用右手笛卡尔坐标系描述三维空间中的方向向量。该方向向量的默认值为 (1, 0, 0)。
