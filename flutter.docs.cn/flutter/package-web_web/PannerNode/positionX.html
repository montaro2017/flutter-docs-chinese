positionX

positionX 属性

AudioParam get positionX

positionX 属性用于指定 PannerNode 接口中音频源在三维笛卡尔坐标系里的 X 坐标，对应水平轴（左—右）。

完整的向量由音频源的位置和朝向（即其面向的方向）共同定义。位置表示为（PannerNode.positionX、PannerNode.positionY、PannerNode.positionZ），朝向表示为（PannerNode.orientationX、PannerNode.orientationY、PannerNode.orientationZ）。

声音的方向性由 PannerNode.coneInnerAngle、PannerNode.coneOuterAngle 和 PannerNode.coneOuterGain 等属性指定，它会影响播放时听到的音量。如果声音朝向听者，听起来会比背向听者时更响。

此属性包含的 AudioParam 为只读；不过，仍可通过为其 AudioParam.value 属性赋新值来更改参数值。
