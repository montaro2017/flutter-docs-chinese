@AvailableInWorkers("service")

ExtendableEvent.waitUntil() 方法会告知事件分发器当前仍有工作正在进行。它也可用于检测工作是否成功。在 Service Worker 中，waitUntil() 会告知浏览器，直到 Promise 完结之前工作仍在进行；如果希望工作完成，浏览器就不应终止 Service Worker。

Service Worker 中的 ServiceWorkerGlobalScope.install_event 事件会使用 Service Worker 的 waitUntil()，使 Service Worker 保持在 ServiceWorkerRegistration.installing 阶段，直到任务完成。如果传给 waitUntil() 的 Promise 被拒绝，则安装视为失败，正在安装的 Service Worker 会被丢弃。这样做主要是为了确保 Service Worker 依赖的所有核心缓存都成功填充后，才将其视为已安装。

Service Worker 中的 ServiceWorkerGlobalScope.activate_event 事件会使用 Service Worker 的 waitUntil()，在传给 waitUntil() 的 Promise 完结之前暂缓分发 fetch 和 push 等功能事件。这样 Service Worker 就有时间更新数据库架构并删除过期的 Cache，使其他事件可以依赖已完整升级的状态。

必须先在事件回调中调用 waitUntil()，之后则可以多次调用，直到传入的所有 Promise 都已完结。
