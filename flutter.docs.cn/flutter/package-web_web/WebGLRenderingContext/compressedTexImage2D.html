WebGLRenderingContext.compressedTexImage2D() 和 WebGL2RenderingContext.compressedTexImage3D() 方法属于 WebGL API，用于指定压缩格式的二维或三维纹理图像。

使用这些方法前，必须先通过 WebGL 扩展启用压缩图像格式。
