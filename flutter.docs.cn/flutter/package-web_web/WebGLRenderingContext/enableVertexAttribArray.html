WebGLRenderingContext 的 enableVertexAttribArray() 方法属于 WebGL API，用于开启属性数组列表中指定索引处的通用顶点属性数组。

注意：调用 WebGLRenderingContext.disableVertexAttribArray 可以禁用该属性数组。

在 WebGL 中，适用于特定顶点的值存储在 属性 中。这些值仅供 JavaScript 代码和顶点着色器使用。属性通过索引号引用，该索引对应 GPU 维护的属性列表。根据平台和/或 GPU 的不同，某些顶点属性索引可能有预定义用途；其他索引则由 WebGL 层在创建属性时分配。

无论哪种情况，属性只有启用后才能使用，而且默认处于禁用状态，因此需要调用 enableVertexAttribArray() 启用各个属性。完成后，可以使用其他方法访问属性，包括 WebGLRenderingContext.vertexAttribPointer、WebGLRenderingContext.vertexAttrib 和 WebGLRenderingContext.getVertexAttrib。
