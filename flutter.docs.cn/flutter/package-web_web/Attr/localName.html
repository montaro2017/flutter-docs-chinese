localName 属性

String get localName

Attr 接口的 localName 只读属性会返回属性限定名称的本地部分，也就是去掉前置命名空间后缀的属性名称。例如，限定名称为 xml:lang 时，如果元素支持该命名空间，返回的本地名称就是 lang。

无论创建属性时使用了何种大小写，本地名称始终为小写。

注意：HTML 仅在 SVG 和 MathML 元素上支持固定的一组命名空间：xml（用于 xml:lang 属性）、xlink（用于 xlink:href、xlink:show、xlink:target 和 xlink:title 属性），以及 xpath。

因此，HTML 元素属性的本地名称始终与其限定名称相同：冒号会被视为普通字符。在 SVG 或 MathML 等 XML 中，冒号表示前缀的结束位置，前面的部分是命名空间；此时本地名称可能与限定名称不同。
