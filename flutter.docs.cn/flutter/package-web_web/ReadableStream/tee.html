tee 方法

JSArray<ReadableStream> tee()

ReadableStream 接口的 tee() 方法会分流当前可读流，并返回一个包含两个新 ReadableStream 实例的双元素数组，分别代表生成的两个分支。

这样可以让两个读取器按顺序或同时读取一个流，也可以让它们以不同速度读取。例如，在 ServiceWorker 中，你可能希望从服务器获取响应并将其流式传输到浏览器，同时也传输到 ServiceWorker 缓存。由于响应正文只能消费一次，因此需要创建两个副本。

分流后的流会按照两个 ReadableStream 分支中较快的使用者速率部分施加背压；未读取的数据则会无限制地排入消费较慢的 ReadableStream 队列中，且没有背压。也就是说，当两个分支的内部队列中都存在未读元素时，原始 ReadableStream 控制器的内部队列才会开始填充；当其 ReadableStreamDefaultController.desiredSize ≤ 0，或字节流控制器的 ReadableByteStreamController.desiredSize ≤ 0 时，控制器就会停止对传入 ReadableStream.ReadableStream 的底层源调用 pull(controller)。如果只消费一个分支，整个正文都会被排入内存。因此，不要使用内置 tee() 以不同速度并行读取非常大的流。应改为寻找能够完全按照消费较慢分支的速度施加背压的实现。

要取消流，需要分别取消生成的两个分支。分流通常会在整个过程中锁定原始流，阻止其他读取器锁定它。
