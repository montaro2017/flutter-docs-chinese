FontFace

FontFace extension type

CSS 字体加载 API 的 FontFace 接口表示一个可用的字体面。

此接口定义字体面的来源（外部资源的 URL 或缓冲区），以及 style、weight 等字体属性。对于 URL 字体源，它允许开发者控制远程字体的获取和加载时机，并跟踪加载状态。

API 文档来源：MDN Web Docs。
