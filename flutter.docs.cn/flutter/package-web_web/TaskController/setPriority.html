setPriority 方法

void setPriority(

可以调用 TaskController 接口的 setPriority() 方法，为此控制器的 signal 设置新的优先级。如果某个优先级任务配置为使用此信号，任务优先级也会随之更改。

优先级更改后，系统会分发 prioritychange 事件以通知观察者。只有优先级确实发生变化时，此方法才会发出通知（如果调用不会改变优先级，就不会触发该事件）。

请注意，只有优先级可变的任务才能更改优先级。如果任务的优先级不可变，则会忽略此函数调用。
