href 属性

String get href

Location 接口的 href 属性可返回包含完整 URL 的字符串，也允许更新该 URL。

设置 href 的值会导航到指定 URL。若要执行重定向，请使用 Location.replace。与设置 href 属性值的区别在于，使用 location.replace() 导航到指定 URL 后，当前页面不会保存到会话历史记录中，因此用户无法通过后退按钮返回该页面。
