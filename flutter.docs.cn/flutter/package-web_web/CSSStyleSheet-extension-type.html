CSSStyleSheet

CSSStyleSheet extension type

CSSStyleSheet 接口表示一个 CSS 样式表，可用于检查和修改其中包含的规则列表。它继承父接口 StyleSheet 的属性和方法。

样式表由一组 CSSRule 对象组成，每个对象代表样式表中的一条规则。这些规则保存在 CSSRuleList 中，可通过样式表的 CSSStyleSheet.cssRules 属性获取。

例如，一条规则可能是 CSSStyleRule 对象，其中包含如下样式：

h1,
h2 {
  font-size: 16pt;
}

另一条规则可能是 at 规则，等等。

有关获取 CSSStyleSheet 对象的各种方式，请参阅获取 StyleSheet 一节。也可以直接构造 CSSStyleSheet 对象。构造函数以及 CSSStyleSheet.replace 和 CSSStyleSheet.replaceSync 方法是规范中的较新补充，用于支持可构造样式表。

API 文档内容来源于 MDN Web 文档。
