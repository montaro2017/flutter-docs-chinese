@AvailableInWorkers("dedicated")

DedicatedWorkerGlobalScope 接口的 postMessage() 方法会向创建该 Worker 的主线程发送消息。

此方法接收一个数据参数，其中包含要从 Worker 复制到主线程的数据。该数据可以是结构化克隆算法支持的任意值或 JavaScript 对象，包括循环引用。

此方法还可以接收一个可选数组，其中包含要转移到主线程的可转移对象。与数据参数不同，转移后的对象将无法再由 Worker 线程使用。（在可行时，对象会通过高性能的零拷贝操作进行转移。）

创建该 Worker 的主作用域可以使用 Worker.postMessage 方法向创建它的线程发送信息。
