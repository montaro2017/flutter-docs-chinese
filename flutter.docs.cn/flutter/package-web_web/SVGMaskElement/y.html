SVGAnimatedLength get y

SVGMaskElement 接口的只读 y 属性会返回一个 SVGAnimatedLength 对象，其中包含 mask 元素 y 属性的值。该值表示遮罩区域左上角的 y 轴坐标。

注意：尽管此属性是只读的，但它只是一个容器，其中的两个值可以修改：SVGAnimatedLength.baseVal 和 SVGAnimatedLength.animVal。
