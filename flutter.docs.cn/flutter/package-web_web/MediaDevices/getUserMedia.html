getUserMedia 方法

JSPromise<MediaStream> getUserMedia([
  1. MediaStreamConstraints constraints
])

MediaDevices 接口的 getUserMedia() 方法会请求用户授权使用媒体输入设备，并生成包含所请求媒体类型轨道的 MediaStream。

例如，此媒体流可以包含视频轨道（由摄像头、录像设备、屏幕共享服务等物理或虚拟视频源生成）、音频轨道（由麦克风、模数转换器等物理或虚拟音频源生成），也可能包含其他类型的轨道。

此方法会返回一个 Promise，并在成功时兑现为 MediaStream 对象。如果用户拒绝授权，或没有可用的匹配媒体，则 Promise 会分别因 NotAllowedError 或 NotFoundError DOMException 而拒绝。

注意：返回的 Promise 可能既不兑现也不拒绝，因为用户不必作出选择，也可能忽略此请求。
