typeMismatch

typeMismatch 属性

bool get typeMismatch

typeMismatch 是 ValidityState 对象的只读属性，指示用户编辑 input 的值后，该值是否不符合元素 type 属性设定的约束。

如果 type 属性要求特定格式的字符串（例如 email 和 url 类型），而值不符合该类型设定的约束，则 typeMismatch 属性为 true。

email 输入类型要求提供一个或多个有效电子邮件地址，具体取决于是否存在 multiple 属性。有效电子邮件地址包含用户名部分和域名，可带或不带顶级域名。如果 email 输入值既不是空字符串，也不是单个有效电子邮件地址；或者在存在 multiple 属性时，不是一个或多个以逗号分隔的电子邮件地址，则会出现 typeMismatch。

url 输入类型要求提供一个或多个有效 URL，具体取决于是否存在 multiple 属性。有效 URL 包含协议，可选地包含 IP 地址，或包含可选的子域名、域名和顶级域名组合。如果 URL 输入值既不是空字符串，也不是单个有效 URL；或者在存在 multiple 属性时，不是一个或多个以逗号分隔的 URL，则会出现 typeMismatch。

Input type Value Expected value
email x@y or x@y.z email address, with or without TLD
url x: or x://y.z protocol or full URL with protocol
