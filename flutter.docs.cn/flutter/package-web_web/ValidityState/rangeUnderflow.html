rangeUnderflow 属性

bool get rangeUnderflow

ValidityState 对象的只读属性 rangeUnderflow 指示用户编辑 input 的值后，该值是否不符合元素 min 属性设定的约束。

如果字段为数值类型（包括 date、month、week、time、number 和 range），并且设置了 min 值，那么当该值不符合 min 值设定的约束时，rangeUnderflow 属性为 true。

如下所示：

<input type="number" min="20" max="40" step="2" />

如果 value < 20，rangeUnderflow 将为 true。为 true 时，该元素匹配 :out-of-range 和 :invalid CSS 伪类。
