$Console

$Console extension type

console 对象提供访问调试控制台的能力（例如 Firefox 中的 Web console）。

不同运行时中的 console API 实现可能有所不同。尤其是某些在线编辑器和 IDE 中，部分 console 方法的行为可能不同，或完全不可用。若要查看本文档描述的行为，可以在浏览器开发者工具中尝试这些方法；不过即使在不同浏览器之间，也可能存在差异。

可以从任意全局对象访问 console 对象。在浏览上下文中，它是 Window 的属性；在 worker 中，则是 WorkerGlobalScope 的特定变体。它公开为 Window.console，也可以直接通过 console 引用。例如：

console.log("Failed to open the specified link");

本页介绍 console 对象提供的方法，并给出一些用法示例。

API 文档来源：MDN Web Docs。
