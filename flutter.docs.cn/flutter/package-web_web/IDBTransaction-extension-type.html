IDBTransaction

IDBTransaction extension type

IDBTransaction 接口属于 IndexedDB API，通过事件处理程序属性提供对数据库的静态异步事务。所有数据读写都在事务中进行。使用 IDBDatabase 启动事务，使用 IDBTransaction 设置事务模式（例如 readonly 或 readwrite），然后访问 IDBObjectStore 发出请求。也可以使用 IDBTransaction 对象中止事务。

创建事务时事务就已启动，而不是等到发出第一个请求时才启动。请看下面的示例：

const trans1 = db.transaction("foo", "readwrite");
const trans2 = db.transaction("foo", "readwrite");
const objectStore2 = trans2.objectStore("foo");
const objectStore1 = trans1.objectStore("foo");
objectStore2.put("2", "key");
objectStore1.put("1", "key");

代码执行后，对象存储中应包含值 "2"，因为 trans2 应在 trans1 之后运行。

在事件循环任务之间，事务会在活动和非活动状态之间切换。在创建事务的任务中，以及各个请求的 success 或 error 事件处理程序所在的任务中，事务处于活动状态。在其他所有任务中，事务均处于非活动状态，此时发出请求会失败。如果事务处于活动状态时没有发出新请求，并且也没有其他尚未完成的请求，事务就会自动提交。

API 文档来源：MDN Web Docs。
