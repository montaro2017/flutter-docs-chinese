CustomEvent.initCustomEvent() 方法用于初始化一个 CustomEvent 对象。如果事件已经派发，此方法不会执行任何操作。

以这种方式初始化的事件必须通过 Document.createEvent 方法创建。派发事件前，必须调用此方法设置事件，然后使用 EventTarget.dispatchEvent 派发。事件派发后，再调用此方法将不会产生任何效果。

注意：此方法已弃用，请勿再使用。

请改用特定事件的构造函数，例如 CustomEvent.CustomEvent。有关用法的更多信息，请参阅创建和触发事件。
