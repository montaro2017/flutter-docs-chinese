Navigator

Navigator extension type

Navigator 接口表示用户代理的状态和身份。脚本可以通过它查询用户代理信息，并注册自身以执行某些活动。

可以通过只读属性 window.navigator 获取 Navigator 对象。

API 文档来源：MDN Web Docs。
