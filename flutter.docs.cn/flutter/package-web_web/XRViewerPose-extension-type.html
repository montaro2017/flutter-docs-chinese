XRViewerPose

XRViewerPose extension type

WebXR Device API 的 XRViewerPose 接口表示观察者在场景中的视点姿势（位置和方向）。每个 XRViewerPose 可以包含多个视图，例如分别表示左右眼之间的轻微位置差异。

此视图可以表示多种视点，例如用户 XR 头显中的视角、玩家通过鼠标和键盘控制化身移动后显示在屏幕上的视角，或用于让旁观者观看场景的虚拟摄像机视角。

API 文档内容来源于 MDN Web Docs。
