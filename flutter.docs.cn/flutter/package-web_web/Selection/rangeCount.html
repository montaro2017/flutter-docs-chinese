rangeCount 属性

int get rangeCount

Selection.rangeCount 只读属性会返回选择中的范围数。

新加载的页面在用户尚未单击之前，rangeCount 为 0。用户单击页面后，rangeCount 为 1，即使页面上没有可见的选择也是如此。

通常用户一次只能选择一个范围，因此 rangeCount 通常为 1。也可以通过脚本让选择包含多个范围。

Gecko 浏览器允许跨表格单元格进行多重选择。在 Firefox 中，可以使用 Ctrl+单击在文档中选择多个范围（除非单击发生在设置了 display: table-cell CSS 属性的元素内）。
