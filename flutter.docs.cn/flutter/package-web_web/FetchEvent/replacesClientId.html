replacesClientId 属性

String get replacesClientId

@AvailableInWorkers("service")

FetchEvent 接口的只读 replacesClientId 属性是页面导航期间将被替换的 Client 的 Client.id。

例如，从页面 A 导航到页面 B 时，replacesClientId 是与页面 A 关联的 Client 的 ID。从 about:blank 导航到其他页面时，此值可能是空字符串，因为 about:blank 的 Client 会被重复使用，而不会被替换。

此外，如果此次 fetch 不是导航请求，replacesClientId 将为空字符串。此属性可用于在导航即将发生之前访问或联系即将被替换的 Client。

实现

external String get replacesClientId;
