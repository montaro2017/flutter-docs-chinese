getOffsetReferenceSpace 方法

XRReferenceSpace getOffsetReferenceSpace(
  1. XRRigidTransform originOffset
)

XRReferenceSpace 接口的 getOffsetReferenceSpace() 方法会返回一个新的参考空间对象，用于描述调用该方法的对象与三维空间中给定点之间的位置差异。返回的 getOffsetReferenceSpace() 对象如果是在 XRReferenceSpace 上调用该方法，则是 XRReferenceSpace；如果是在 XRBoundedReferenceSpace 对象上调用，则是有边界的参考空间对象。

换句话说，如果你有一个三维空间中的对象，并且需要将另一个对象相对于它定位，可以调用 getOffsetReferenceSpace()，传入第二个对象相对于调用该方法的对象所需的位置和方向，即相对于调用 getOffsetReferenceSpace() 的对象的位置和方向。

之后绘制场景时，可以使用偏移参考空间来相对定位对象，并根据观察者的位置应用所需变换，从而正确渲染对象。示例 根据非 XR 输入实现旋转 展示了如何使用此方法，让用户通过鼠标调整视角的俯仰和偏航。
