getSize 方法

int getSize()

@AvailableInWorkers("dedicated")

FileSystemSyncAccessHandle 接口的 getSize() 方法返回句柄关联文件的大小，单位为字节。

注意：在较早版本的规范中，FileSystemSyncAccessHandle.close、FileSystemSyncAccessHandle.flush、getSize() 和 FileSystemSyncAccessHandle.truncate 被错误地规定为异步方法，一些浏览器的旧版本也按此方式实现。不过，目前所有支持这些方法的浏览器都将它们实现为同步方法。
