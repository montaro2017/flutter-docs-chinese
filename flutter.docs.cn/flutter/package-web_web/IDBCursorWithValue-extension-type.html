IDBCursorWithValue

IDBCursorWithValue extension type

IndexedDB API 的 IDBCursorWithValue 接口表示一个游标，用于遍历数据库中的多条记录。它与 IDBCursor 相同，但额外包含 value 属性。

游标具有一个数据源，用于指示它正在遍历哪个索引或对象存储。它在范围内有一个位置，并按照记录键的升序或降序方向移动。应用可以使用游标异步处理其范围内的所有记录。

可以同时拥有任意数量的游标。对于给定的游标，始终会获得表示它的同一个 IDBCursorWithValue 对象。操作实际作用于底层索引或对象存储。

API 文档来源：MDN Web Docs。
