location

location 属性

int get location

只读的 KeyboardEvent.location 属性会返回一个 unsigned long，表示按键在键盘或其他输入设备上的位置。

可能的值包括：

常量 值 说明
DOM_KEY_LOCATION_STANDARD 0 该按键只有一种版本，或者无法区分该按键的左侧和右侧版本；并且它不是在数字键盘上按下的，也不是被视为数字键盘组成部分的按键。
DOM_KEY_LOCATION_LEFT 1 按下的是该按键的左侧版本。例如，在标准的 101 键美式键盘上按下了左侧 Control 键。此值仅用于在键盘上有多个可能位置的按键。
DOM_KEY_LOCATION_RIGHT 2 按下的是该按键的右侧版本。例如，在标准的 101 键美式键盘上按下了右侧 Control 键。此值仅用于在键盘上有多个可能位置的按键。
DOM_KEY_LOCATION_NUMPAD 3

该按键位于数字键盘上，或者其虚拟键码对应数字键盘。

注意：当 NumLock 处于锁定状态时，Firefox 对数字键盘上的按键始终返回 DOM_KEY_LOCATION_NUMPAD。当 NumLock 未锁定且键盘确实带有数字键盘时，Firefox 也始终返回 DOM_KEY_LOCATION_NUMPAD。另一方面，如果键盘没有数字键盘（例如笔记本电脑键盘），某些按键只有在 NumLock 锁定时才会作为数字键盘按键。此类按键触发键盘事件时，location 属性的值取决于具体按键，也就是说，该值不能是 DOM_KEY_LOCATION_NUMPAD。

注意：在 Firefox 和 Internet Explorer 中，NumLock 键的键盘事件都会将位置标记为 DOM_KEY_LOCATION_STANDARD。
DOM_KEY_LOCATION_MOBILE 4

该按键位于移动设备上，可能是物理键盘，也可能是虚拟键盘。
DOM_KEY_LOCATION_JOYSTICK 5

该按键是游戏控制器上的按钮，或移动设备上的操纵杆。
