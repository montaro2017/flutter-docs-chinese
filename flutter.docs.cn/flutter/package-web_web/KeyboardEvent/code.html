code 属性

String get code

KeyboardEvent.code 属性表示键盘上的物理按键（与按下按键后生成的字符不同）。换言之，该属性返回的值不会因键盘布局或修饰键状态而改变。

如果输入设备不是物理键盘，而是虚拟键盘或辅助功能设备，浏览器会尽可能返回与物理键盘相符的值，以最大限度地兼容物理和虚拟输入设备。

如果要根据输入设备上的物理位置而不是按键对应的字符来处理按键，此属性会很有用；例如，编写用键盘按键模拟游戏手柄操作的游戏代码时就常常如此。不过请注意，不能通过 KeyboardEvent.code 的值确定按键生成的字符，因为按键代码的名称可能与键帽上印出的字符，或计算机实际生成的字符不一致。

例如，在 QWERTY 布局键盘上，Q 键返回的 code 是 "KeyQ"；但在 Dvorak 键盘上，同一个 code 值表示 ' 键，在 AZERTY 键盘上则表示 A 键。因此，如果用户使用的键盘布局不是预期布局，就无法用 code 的值判断用户所看到的按键名称。

若要确定按键事件对应的字符，请改用 KeyboardEvent.key 属性。
