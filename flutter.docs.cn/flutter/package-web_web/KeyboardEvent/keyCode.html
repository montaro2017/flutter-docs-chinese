keyCode 属性

int get keyCode

已弃用的只读 KeyboardEvent.keyCode 属性表示一个依赖于系统和具体实现的数值代码，用于标识按键未修饰时对应的值。

此值通常是与该按键对应的十进制 ASCII（20）或 Windows 1252 代码。如果无法识别该按键，则值为 0。

应尽可能避免使用此属性；它已弃用一段时间。请改用 KeyboardEvent.code（表示按下的物理按键）或 KeyboardEvent.key（表示按键映射的字符）。如果需要支持非常旧的浏览器，请检查这两个属性的兼容性。

注意：处理 keydown 和 keyup 事件时，Web 开发者不应使用 keyCode 属性判断可打印字符。如上所述，keyCode 属性无法有效表示可打印字符，尤其是按下 Shift 或 Alt 键后输入的字符。
