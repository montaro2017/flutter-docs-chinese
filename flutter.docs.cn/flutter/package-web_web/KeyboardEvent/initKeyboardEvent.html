KeyboardEvent.initKeyboardEvent() 方法用于初始化键盘事件对象的属性。此方法曾在 DOM Level 3 Events 草案中引入，但在后续草案中已弃用。由于以实验性方式实现此方法会破坏现有 Web 应用，Gecko 不会支持此功能（参见 Firefox 错误 999645）。如果可用，Web 应用应使用构造函数代替此方法。
