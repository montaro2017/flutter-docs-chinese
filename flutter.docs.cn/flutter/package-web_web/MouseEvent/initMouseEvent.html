MouseEvent.initMouseEvent() 方法用于初始化已创建的鼠标事件的值（通常使用 Document.createEvent 方法创建）。

警告：此方法已弃用，请勿再使用。

请改用特定事件的构造函数，例如 MouseEvent.MouseEvent。创建并触发事件页面介绍了这些构造函数的用法。

以这种方式初始化的事件必须通过 Document.createEvent 方法创建。必须先调用此方法设置事件，然后才能使用 EventTarget.dispatchEvent 分发事件。
