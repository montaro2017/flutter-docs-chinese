action 属性

String get action

@AvailableInWorkers("service")

action 是 NotificationEvent 接口的只读属性，返回用户所单击通知按钮的字符串 ID。如果用户单击的是通知中非操作按钮的区域，或者通知没有按钮，则返回空字符串。通知 ID 在创建通知时通过 actions 数组属性设置；除非替换该通知，否则无法修改。

实现

external String get action;
