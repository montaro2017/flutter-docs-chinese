Touch

Touch extension type

Touch 接口表示触摸敏感设备上的单个接触点。接触点通常是手指或触控笔，设备可以是触摸屏或触控板。

Touch.radiusX、Touch.radiusY 和 Touch.rotationAngle 描述用户与屏幕之间的接触区域，即触摸区域。处理手指这类指向不精确的设备时，这些信息很有帮助。这些值用于描述一个尽可能贴合整个接触区域（例如用户指尖）的椭圆。

注意：许多属性值取决于硬件。例如，如果设备无法检测施加在表面上的压力，force 值将始终为 0。radiusX 和 radiusY 也可能如此；如果硬件只报告单个点，这些值将为 1。

API 文档来源于 MDN Web 文档。

radiusY → double

rotationAngle → double
只读属性 rotationAngle 属于 Touch 接口，返回接触区域椭圆的旋转角度（单位为度），该椭圆由 Touch.radiusX 和 Touch.radiusY 定义。该值介于 0 到 90 之间。这三个值共同描述一个椭圆，用于近似表示用户与屏幕的接触区域大小和形状。例如，它可以是表示指尖与屏幕接触的大椭圆，也可以是表示触控笔笔尖的小椭圆。

target → EventTarget
target 是 Touch 接口的只读属性，返回触摸最初落在表面时开始接触的（EventTarget）。即使触点之后移出该元素的交互区域，或该元素已从文档中移除，此属性仍指向该目标。请注意，如果目标元素从文档中移除，事件仍会以其为目标，因此不一定会继续冒泡到 window 或 document。如果触摸过程中元素有可能被移除，最佳做法是将触摸监听器直接附加到目标上。
