crossOriginIsolated 属性

bool get crossOriginIsolated

WorkerGlobalScope 接口的只读属性 crossOriginIsolated 会返回一个布尔值，用于指示网站是否处于跨源隔离状态。该状态可降低旁路攻击的风险，并开放一些功能：

  • 可以创建 SharedArrayBuffer，并通过 DedicatedWorkerGlobalScope.postMessage 或 MessagePort.postMessage 调用发送。
  • Performance.now 提供更高的精度。
  • Performance.measureUserAgentSpecificMemory 可以访问。

当响应中的跨源开启者策略标头值为 same-origin，且跨源嵌入器策略标头值为 require-corp 或 credentialless 时，网站处于跨源隔离状态。
