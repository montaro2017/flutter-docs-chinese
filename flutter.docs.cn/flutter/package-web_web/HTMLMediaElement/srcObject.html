srcObject 属性

MediaProvider? get srcObject

HTMLMediaElement 接口的 srcObject 属性用于设置或返回为该 HTMLMediaElement 提供媒体来源的对象。

该对象可以是 MediaStream、MediaSource、Blob 或 File（继承自 Blob）。

注意：截至 2020 年 3 月，只有 Safari 完全支持 srcObject，即支持将 MediaSource、MediaStream、Blob 和 File 对象用作其值。其他浏览器支持 MediaStream 对象；在这些浏览器完善支持之前，可以改为使用 URL.createObjectURL_static 创建 URL，并将其赋给 HTMLMediaElement.src（示例见下文）。此外，从 Chromium 108 开始，也支持将专用 worker 中的 MediaSource 对象附加到此属性：将从 worker 转移过来的该对象的 MediaSourceHandle 实例赋给 srcObject 即可。
