playbackRate 属性

double get playbackRate

HTMLMediaElement.playbackRate 属性设置媒体的播放速率，可用于实现快进、慢放等用户控件。正常播放速率会乘以此值以得到当前速率，因此值为 1.0 表示正常速度。

playbackRate 为负数表示媒体应倒放，但目前尚未得到广泛支持。1

当快进或慢放的速率超出实用范围时，音频会静音（例如，Gecko 会在 0.25 到 4.0 范围之外静音）。

默认情况下会校正音频的音高。可以使用 HTMLMediaElement.preservesPitch 属性禁用音高校正。
