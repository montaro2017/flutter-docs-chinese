inlineSize 属性

double get inlineSize

ResizeObserverSize 接口的只读 inlineSize 属性会返回被观察元素边框盒在行内方向上的长度。对于水平书写模式的盒子，这是水平方向，即宽度；如果书写模式为垂直方向，则是垂直方向，即高度。

有关书写模式、块方向和行内方向的更多说明，请阅读处理不同的文本方向。
