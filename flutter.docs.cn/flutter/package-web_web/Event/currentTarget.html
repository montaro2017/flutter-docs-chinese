currentTarget 属性

EventTarget? get currentTarget

Event 接口的 currentTarget 只读属性用于标识附加了事件处理器的元素。

该元素不一定与事件触发所在的元素相同，因为事件可能在处理器所在元素的某个后代上触发，然后向上冒泡到处理器所在元素。事件实际触发所在的元素由 Event.target 给出。

请注意，只有在处理事件的处理器内部才能获取 currentTarget 的值。在事件处理器外部，该值为 null。例如，如果在事件处理器中获取了对 Event 对象的引用，然后在处理器外部访问其 currentTarget 属性，该属性值将为 null。
