cancelable 属性

bool get cancelable

Event 接口的 cancelable 只读属性表示该事件是否可以取消，从而阻止它发生，就像该事件从未发生过一样。

如果事件不可取消，其 cancelable 属性值将为 false，事件监听器也无法阻止该事件发生。

浏览器原生事件中，可取消的事件大多由用户与页面交互触发。取消 Element.click_event、Element.wheel_event 或 Window.beforeunload_event 事件，分别会阻止用户点击内容、使用鼠标滚轮滚动页面或离开当前页面。

由其他 JavaScript 代码创建的合成事件，会在创建时指定是否可以取消。

若要取消事件，请在该事件上调用 event.preventDefault 方法。这会阻止实现执行与该事件关联的默认操作。

处理多种事件的事件监听器，在调用 event.preventDefault 方法前，可能需要先检查 cancelable 属性。
