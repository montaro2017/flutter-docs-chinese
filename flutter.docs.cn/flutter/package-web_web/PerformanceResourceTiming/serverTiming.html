serverTiming 属性

JSArray<PerformanceServerTiming> get serverTiming

只读的 serverTiming 属性会返回一个数组，其中包含服务器计时指标对应的 PerformanceServerTiming 条目。

服务器计时指标要求服务器发送 Server-Timing 响应标头。例如：

Server-Timing: cache;desc="Cache Read";dur=23.2

serverTiming 条目可以出现在 navigation 和 resource 条目中。

实现

external JSArray<PerformanceServerTiming> get serverTiming;
