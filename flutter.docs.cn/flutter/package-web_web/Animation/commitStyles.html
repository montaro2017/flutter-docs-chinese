commitStyles 方法

void commitStyles()

Web Animations API 的 Animation 接口中的 commitStyles() 方法会将动画当前样式的计算值写入目标元素的 style 属性。即使动画已自动移除，commitStyles() 仍然可以使用。

commitStyles() 可以与 fill 配合使用，使动画结束后仍保留其最终状态。单独使用 fill 也能达到相同效果，但不建议使用无限期填充的动画。动画优先级高于所有静态样式，因此无限期填充的动画可能会阻止目标元素按常规方式设置样式。

使用 commitStyles() 会将样式状态写入元素的 style 属性，之后可以像往常一样修改或替换这些样式。
