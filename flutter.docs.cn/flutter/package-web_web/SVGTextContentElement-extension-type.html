SVGTextContentElement

SVGTextContentElement extension type

SVGTextContentElement 接口由支持渲染子文本内容的元素实现。多个文本相关接口会继承此接口，例如 SVGTextElement、SVGTSpanElement、SVGTRefElement 和 SVGTextPathElement。

API 文档来源：MDN Web 文档。
