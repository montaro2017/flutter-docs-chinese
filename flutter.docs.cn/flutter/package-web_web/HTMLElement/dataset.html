dataset

dataset 属性

DOMStringMap get dataset

HTMLElement 接口的只读 dataset 属性提供对元素自定义数据属性（data-*）的读写访问。它会公开一个字符串映射（DOMStringMap），其中每个 data-* 属性对应一个条目。

注意：dataset 属性本身可以读取，但不能直接写入。所有写操作都必须针对 dataset 中的各个属性进行，而这些属性分别对应数据属性。

HTML data-* 属性及其对应的 DOM dataset.property 会根据读取或写入时所在的位置，转换其名称：

  • HTML 中
    • ：属性名以 data- 开头，只能包含字母、数字、连字符（-）、句点（.）、冒号（:）和下划线（_）。所有大写字母（A 到 Z）都会转换为小写。
  • JavaScript 中
    • ：自定义数据属性的属性名与 HTML 属性名相同，但不含 data- 前缀；名称中的单个连字符（-）会被移除，以便将其后的字母大写。

除了以下说明外，你还可以阅读文章使用数据属性，了解如何使用 HTML 数据属性。

名称转换

  • 从 dash-style 转换为 camelCase

    • ：自定义数据属性名称会按以下规则转换为 DOMStringMap 条目的键：
  1. 将所有 ASCII 大写字母（A 到 Z）转换为小写；
  2. 移除前缀 data-（包括连字符）；
  3. 如果连字符（U+002D）后跟 ASCII 小写字母 a 到 z，则移除该连字符并将字母转换为大写；
  4. 其他字符（包括其他连字符）保持不变。

  • 从 camelCase 转换为 dash-style

    • ：反向转换会将键映射为属性名，规则如下：
  1. 限制：转换前，连字符不能紧接 ASCII 小写字母 a 到 z；
  2. 添加 data- 前缀；
  3. 在每个 ASCII 大写字母 A 到 Z 前添加连字符，再将该字母转换为小写；
  4. 其他字符保持不变。

例如，data-abc-def 属性对应 dataset.abcDef。

访问值

  • 可以使用 camelCase 名称/键作为 dataset 的对象属性来设置和读取数据属性：element.dataset.keyname。
  • 也可以使用方括号语法设置和读取数据属性：element.dataset['keyname']。
  • 可以使用 in 运算符检查指定属性是否存在：'keyname' in element.dataset。请注意，这会遍历 dataset 的原型链；如果外部代码可能污染原型链，这样做可能不安全。还有其他替代方式，例如 'keyname')"，或直接检查 element.dataset.keyname !== undefined。

设置值

  • 设置属性时，其值始终会转换为字符串。例如：element.dataset.example = null 会转换为 data-example="null"。

  • 若要移除属性，可以使用 delete 运算符：delete element.dataset.keyname。
