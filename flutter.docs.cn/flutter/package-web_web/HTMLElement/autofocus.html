autofocus

autofocus 属性

bool get autofocus

HTMLElement 接口的 autofocus 属性是一个布尔值，反映 autofocus HTML 全局属性。该属性表示页面加载时是否应聚焦此控件；如果此属性设置在 dialog 元素内部，或设置在具有 popover 属性的元素上，则在对话框或弹出层显示时也会聚焦。

一个文档中只能有一个表单关联元素、一个 dialog 元素或一个带有 popover 属性的元素指定此属性。如果指定了多个，则最先插入且设置了此属性的元素（通常是页面上的第一个此类元素）会获得初始焦点。

注意：设置此属性不会立即将焦点移至关联元素；它只是告知浏览器在元素插入文档时将焦点移到该元素。如果在插入之后设置，也就是大多数情况下在文档加载之后设置，则不会产生可见效果。
