style 属性

CSSStyleDeclaration get style

HTMLElement 的只读 style 属性以实时 CSSStyleDeclaration 对象的形式返回元素的内联样式。该对象包含元素所有样式属性的列表，但只有元素内联 style 属性中定义的属性才有对应的值。

简写属性会展开。例如，设置 style="border-top: 1px solid black" 后，会改为设置相应的长属性（、和）。

此属性是只读的，不能将 CSSStyleDeclaration 对象赋给它。不过，可以直接将字符串赋给 style 属性来设置内联样式。在这种情况下，该字符串会传递给 CSSStyleDeclaration.cssText。以这种方式使用 style 会完全覆盖元素的所有内联样式。

因此，若要为元素添加特定样式而不更改其他样式值，通常最好在 CSSStyleDeclaration 对象上单独设置各项属性。例如，可以写成 element.style.backgroundColor = "red"。

将样式声明设为 null 或空字符串即可重置该声明，例如 elt.style.color = null。

注意：CSS 属性名称会按照以下规则转换为 JavaScript 标识符：

  • 如果属性名由一个单词组成，则保持原样：height 会保留为小写。由于 float 曾是 JavaScript 保留关键字，该属性名历史上会转换为 cssFloat。现在所有现代浏览器都支持在 JavaScript 中直接使用 float 访问 CSS 的 float 属性；cssFloat 仍受旧版浏览器支持，在现代浏览器中也作为别名保留。
  • If the property is made of several words, separated by dashes, the dashes are removed and it is converted to : background-attachment becomes backgroundAttachment.

style 属性在 CSS 层叠中的优先级与通过 style 属性设置的内联样式声明相同。
