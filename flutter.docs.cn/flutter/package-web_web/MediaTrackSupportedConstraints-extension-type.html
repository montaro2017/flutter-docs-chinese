MediaTrackSupportedConstraints

MediaTrackSupportedConstraints extension type

MediaTrackSupportedConstraints 字典用于列出 或浏览器在实现 MediaStreamTrack 对象时所识别的可约束属性。MediaDevices.getSupportedConstraints 会返回一个符合 MediaTrackSupportedConstraints 结构的对象。

由于 WebIDL 接口定义的工作方式，如果请求了不受支持的约束，不会发生错误。相反，指定的约束仍会应用，但请求中无法识别的约束会被剔除。这可能导致令人困惑且难以调试的错误；如果你需要区分约束被静默忽略和约束被接受的情况，请务必在尝试设定约束前使用 getSupportedConstraints() 获取支持信息。

实际的约束集使用基于 MediaTrackConstraints 字典的对象来描述。

有关约束工作方式的更多信息，请参阅功能、约束和设置。

API 文档来源：MDN Web Docs。
