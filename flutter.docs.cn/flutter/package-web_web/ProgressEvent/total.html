total 属性

int get total

ProgressEvent.total 只读属性是一个 64 位无符号整数，表示正在传输或处理的数据总大小（字节）。

通过 HTTP 下载资源时，此值取自 Content-Length 响应标头。它仅统计 HTTP 消息正文，不包括标头和其他开销。

如果事件的 ProgressEvent.lengthComputable 属性为 false，此值没有意义，应忽略。

实现

external int get total;
