EventTarget 接口的 addEventListener() 方法会设置一个函数，使其在指定事件传递到目标时被调用。

常见的事件目标包括 Element 及其子元素、Document 和 Window，但任何支持事件的对象都可以作为目标（例如 IDBRequest）。

注意：addEventListener() 是推荐的事件监听器注册方式，优点如下：

  • 它允许为同一事件添加多个处理程序。这对于需要与其他库或扩展协同工作的库、JavaScript 模块及其他代码尤其有用。
  • In contrast to using an onXYZ property, it gives you finer-grained control of the phase when the listener is activated (capturing vs. bubbling).
  • It works on any event target, not just HTML or SVG elements.

addEventListener() 方法会将一个函数，或一个实现了 handleEvent() 函数的对象，添加到此方法所调用的 EventTarget 上针对指定事件类型的监听器列表中。如果该函数或对象已经在此目标的监听器列表中，就不会重复添加。

注意：如果某个匿名函数已注册为特定目标的事件监听器，之后代码中又在 addEventListener 调用中提供了一个内容相同的匿名函数，那么第二个函数也会添加到该目标的事件监听器列表中。

实际上，即使反复使用完全相同且不变的源代码来定义匿名函数，它们也并不相同，即使是在循环中定义的也一样。

在这种情况下反复定义相同的匿名函数可能会带来问题。（详见下文的内存问题。）

如果在一个监听器内部（也就是说，在事件处理过程中）向 EventTarget 添加另一个事件监听器，该事件不会触发新添加的监听器。不过，在事件流的后续阶段（例如冒泡阶段），新监听器可能会被触发。
