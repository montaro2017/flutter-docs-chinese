mode 属性

TextTrackMode get mode

TextTrack 接口的 mode 属性是一个字符串，用于指定和控制文本轨道的模式：disabled、hidden 或 showing。你可以读取此值以确定当前模式，也可以更改此值来切换模式。

Safari 还要求：使用自定义视频播放器控件时，必须将布尔属性 default 设为 true，字幕提示才会显示。

值

表示轨道当前模式的字符串。取值之一：

  • disabled
    • ：字幕轨道当前已禁用。虽然它仍会在 DOM 中公开，但用户代理会忽略它。没有活动提示，也不会触发事件；用户代理也不会尝试获取该轨道的提示。这是默认值；如果指定了 default 布尔属性，则默认值为 showing。
  • hidden
    • ：字幕轨道当前处于活动状态，但不显示提示。如果用户代理尚未尝试获取该轨道的提示，很快就会尝试获取（并填充 TextTrack.cues 属性）。用户代理会维护活动提示列表（位于轨道的 TextTrack.activeCues 属性中），并在相应时间触发事件，即使文本没有显示也如此。
  • showing
    • ：字幕轨道当前已启用并可见。如果尚未获取提示列表，很快就会获取。TextTrack.activeCues 列表会持续维护，并在适当时间触发事件；轨道文本也会根据样式和 TextTrack.kind 正确绘制。如果指定了轨道的 default 布尔属性，此项就是默认值。
