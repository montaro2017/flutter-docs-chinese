inBandMetadataTrackDispatchType 属性

String get inBandMetadataTrackDispatchType

inBandMetadataTrackDispatchType 是 TextTrack 接口的只读属性，返回由 TextTrack 对象表示的文本轨道的带内元数据分发类型。

带内元数据分发类型是从媒体资源中提取的字符串，专用于带内元数据轨道。可能包含此类轨道的媒体资源示例，是在网络上流式传输电视广播的电台。文本轨道可用于包含广告定向元数据，也可用于在烹饪节目中提供食谱数据等附加信息，或在游戏节目中提供问答游戏数据。

加载这些轨道时，可以使用此属性的值将它们关联到专用脚本模块。
