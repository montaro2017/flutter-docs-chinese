devicePixelRatio 属性

double get devicePixelRatio

Window 接口的 devicePixelRatio 属性返回当前显示设备的物理像素分辨率与 CSS 像素分辨率之比。

该值也可以理解为像素尺寸之比：一个 CSS 像素的尺寸与一个物理像素的尺寸之比。简单来说，它告诉浏览器绘制一个 CSS 像素时应使用屏幕上的多少个实际像素。

当标准显示器与 HiDPI 或 Retina 显示器之间存在差异时，此属性很有用。后两者会用更多屏幕像素绘制相同对象，因此图像更清晰。

可以使用 Window.matchMedia 检查 devicePixelRatio 的值是否发生变化（例如，用户将窗口拖到像素密度不同的显示器上时就可能发生变化）。请参阅下方示例。
