sessionStorage

sessionStorage 属性

Storage get sessionStorage

只读属性 sessionStorage 可访问当前源对应的会话 Storage 对象。sessionStorage 与 Window.localStorage 类似；区别在于 localStorage 数据不会过期，而 sessionStorage 数据会在页面会话结束时清除。

  • 每当浏览器在某个标签页中加载文档时，都会创建一个唯一的页面会话并分配给该标签页。该页面会话只能在该标签页中访问。
  • 页面会话会持续到标签页或浏览器关闭为止，并且在页面重新加载和恢复后仍会保留。
  • 在新标签页或窗口中打开页面会创建一个新会话，其值来自顶层浏览上下文；这与会话 Cookie 的工作方式不同。
  • 使用相同 URL 打开多个标签页/窗口时，每个标签页/窗口都会创建自己的 sessionStorage。
  • 复制标签页时，该标签页的 sessionStorage 会复制到新标签页。
  • 关闭标签页/窗口会结束会话，并清除 sessionStorage 中的对象。

sessionStorage 中存储的数据与页面使用的协议有关。具体来说，通过 HTTP 访问网站时（例如 http://example.com），脚本存储的数据会放在一个 sessionStorage 对象中；通过 HTTPS 访问同一网站时（例如 example.com），数据则存放在另一个对象中。

键和值始终采用 UTF-16 字符串格式，每个字符占用两个字节。与对象类似，整数键会自动转换为字符串。

实现

external Storage get sessionStorage;
