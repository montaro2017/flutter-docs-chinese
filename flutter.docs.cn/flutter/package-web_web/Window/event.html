event 属性

Event? get event

Window 的只读属性 event 会返回网站代码当前正在处理的 Event。如果当前不在事件处理程序中，该值始终为 undefined。

编写新代码时应避免使用此属性，而应使用传递给事件处理函数的 Event。此属性并非所有环境都支持；即使支持，也可能使代码变得脆弱。

注意：此属性可能不可靠，在某些情况下返回的 Event 可能不是预期的值。此外，对于在影子树中派发的事件，Window.event 返回的值并不准确。
