window.requestIdleCallback() 方法会将函数加入队列，使其在浏览器空闲期间调用。开发者可以借此在主事件循环中执行后台和低优先级工作，而不影响动画、输入响应等对延迟敏感的事件。通常按先进先出的顺序调用这些函数；不过，如果某个回调指定了 timeout，必要时可能会调整调用顺序，以便在超时前执行它。

可以在空闲回调函数中调用 requestIdleCallback()，安排另一个回调，但它最早也会在事件循环的下一轮执行。

注意：对于必须执行的工作，强烈建议设置 timeout 选项；否则回调可能要等待数秒才会执行。
