window 属性

Window get window

Window 对象的 window 属性指向窗口对象自身。

因此，以下表达式都会返回同一个窗口对象：

window.window;
window.window.window;
window.window.window.window;
// …

在网页中，window 对象也是一个全局对象。这意味着：

  1. 脚本中的全局变量实际上都是 window 的属性：
var global = { data: 0 };
alert(global === window.global); // displays "true"
  1. 可以直接访问 window 对象的内置属性，无需在属性名前添加 window.：
setTimeout("alert('Hi!')", 50); // equivalent to using
window.setTimeout().
alert(window === window.window); // displays "true"

window 属性指向对象自身，可能是为了便于引用全局对象。否则，就必须在脚本顶部手动执行 let window = this; 赋值。

设置此属性的另一个原因是，如果没有它，就无法写出例如 window.open('https://google.com/') 这样的调用；只能使用 open('https://google.com/')。

使用此属性的另一个原因是，一些库希望同时提供面向对象版本和非面向对象版本（尤其是 JavaScript 模块）。例如，如果使用“this.window.location.href”，JavaScript 模块可以在其定义的类中创建名为“window”的属性（因为模块默认没有全局“window”变量），并在构造该模块类时传入一个窗口对象。这样，该类函数中的“this.window”就会指向该窗口对象。在非命名空间版本中，“this.window”会指回“window”，从而也能方便地获取文档位置。另一个优点是，此类对象（即使类定义在模块之外）可以随时更改其窗口引用；如果将“window”引用写死，就无法做到这一点。类中的默认值仍可设为当前窗口对象。
