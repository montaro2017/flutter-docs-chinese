size 属性

String get size

已弃用的 HTMLFontElement.size 属性是一个字符串，反映 size HTML 属性。它可以是 1 到 7 之间的字号，也可以是相对于默认值 3 的数值，例如 -2 或 +1。

该字符串必须符合以下 HTML 微语法之一：

微语法 说明 示例
有效的字号数字字符串 1 到 7 范围内的整数 6
相对字号字符串 +x 或 -x，其中 x 表示相对于 3 的数值（结果应在 1 到 7 范围内） +2
-1

external String get size;
