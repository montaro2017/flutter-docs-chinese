Path2D

Path2D extension type

Canvas 2D API 的 Path2D 接口用于声明路径，之后可在 CanvasRenderingContext2D 对象上使用。CanvasRenderingContext2D 接口的路径方法也存在于此接口中，因此可以方便地保留路径，并在需要时重新绘制。

API 文档内容来自 MDN Web 文档。
