Event

Event extension type

Event 接口表示在 EventTarget 上发生的事件。

事件可以由用户操作触发，例如单击鼠标按钮或敲击键盘，也可以由 API 生成，用来表示异步任务的进度。还可以通过编程方式触发事件，例如调用元素的 HTMLElement.click() 方法，或定义事件后使用 EventTarget.dispatchEvent() 将其发送到指定目标。

事件有许多类型，其中一些使用基于 Event 主接口的其他接口。Event 本身包含所有事件共有的属性和方法。

许多 DOM 元素都可以设置为接收（或“监听”）这些事件，并执行代码来响应（或“处理”）事件。事件处理器通常通过 HTML 元素（例如 <button>、<div>、<span> 等）的 EventTarget.addEventListener() 连接（或“附加”）到元素上；这通常取代了旧式 HTML 事件处理器属性。此外，正确添加这些处理器后，也可以在需要时使用 removeEventListener() 将其移除。

注意：一个元素可以有多个此类处理器，甚至可以有多个处理同一种事件的处理器，尤其是在不同的独立代码模块分别为各自目的添加处理器时。（例如，网页中的广告模块和统计模块都在监测视频观看情况。）

当许多元素彼此嵌套且各自都有处理器时，事件处理可能会变得非常复杂。尤其是当父元素与其子元素在空间上重叠时，同一个事件可能同时发生在它们身上，导致父元素也收到子元素收到的事件；此时事件的处理顺序取决于各个已触发处理器的事件冒泡和捕获设置。
