display 属性

String get display

FontFace 接口的 display 属性根据字体是否已下载以及何时可用，决定字体面的显示方式。此属性等同于 CSS font-display 描述符。

使用此属性时，字体加载过程分为三个阶段。前两个阶段的时长取决于属性值和用户代理（见下文）。

  • block period
    • : The browser invisibly prepares a fallback font. If the font face loads during this time, it's used to display the text and display is complete.
  • 字体交换阶段
    • ：如果字体仍未加载，则显示后备字体。字体加载后，后备字体会替换为下载的字体。
  • 失败阶段
    • ：如果字体仍未加载，则显示后备字体，之后不会再进行字体替换。
