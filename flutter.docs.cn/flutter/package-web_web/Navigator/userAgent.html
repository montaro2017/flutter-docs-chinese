userAgent 属性

String get userAgent

Navigator.userAgent 是一个只读属性，返回当前浏览器的用户代理字符串。

注意：规范要求浏览器通过此字段提供尽可能少的信息。不要假设同一浏览器的未来版本会继续返回相同值。尽量不要使用此属性；如果必须使用，只用于识别浏览器当前及过去的版本。新浏览器可能会采用与旧浏览器相同或部分相同的 UA，因此无法保证用户代理确实是此属性所宣称的浏览器。

还要注意，浏览器用户可以按需更改此字段的值（UA 欺骗）。

根据用户代理字符串识别浏览器并不可靠，也不建议这样做，因为用户代理字符串可由用户自行配置。例如：

  • 在 Firefox 中，可修改偏好设置 general.useragent.override（位于 about:config）。一些 Firefox 扩展会这样做；不过，这只会更改发送的 HTTP 标头以及 navigator.userAgent 返回的值。其他方法可能会使用 JavaScript 代码识别浏览器。
  • Opera 6+ 允许用户通过菜单设置浏览器标识字符串。
