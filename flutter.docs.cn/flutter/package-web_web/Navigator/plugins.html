plugins 属性

PluginArray get plugins

返回一个 PluginArray 对象，其中列出了描述应用程序中已安装插件的 Plugin 对象。返回对象的命名属性不可枚举（非常旧的浏览器版本除外）。

近期版本的规范将返回列表的内容固定下来。如果支持内嵌查看 PDF 文件，该属性会列出五个标准插件；如果不支持内嵌查看 PDF 文件，则会返回空列表。

注意：请使用 Navigator.pdfViewerEnabled 来确定是否支持内嵌查看 PDF 文件。不要根据此属性推断。

“五个标准插件”是开发者最常用于检测是否支持内嵌查看 PDF 文件的插件。返回这些插件可使旧代码更可靠地判断是否支持内嵌查看。不过不建议新代码采用此方法，因为此属性最终可能会被移除。

旧版浏览器还会列出 Adobe Flash 插件和 PDF 查看器扩展。
