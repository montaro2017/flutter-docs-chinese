deviceMemory 属性

double get deviceMemory

deviceMemory 是 Navigator 接口的只读属性，返回设备内存容量的近似值，单位为 GB。

为减少 ，报告的值并不精确。系统会将内存容量向下取整到最接近的 2 的幂，再除以 1024，得到近似值。之后还会将数值限制在上下界内，以保护内存容量特别低或特别高的设备所有者的隐私。

实现

external double get deviceMemory;
