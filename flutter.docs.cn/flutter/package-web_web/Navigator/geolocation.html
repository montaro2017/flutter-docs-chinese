geolocation 属性

Geolocation get geolocation

Navigator.geolocation 是一个只读属性，返回 Geolocation 对象，使 Web 内容能够访问设备的位置。网站或应用可以据此根据用户位置提供个性化结果。

注意：出于安全原因，网页尝试访问位置信息时，会通知用户并请求授权。请注意，各浏览器请求此权限的策略和方式可能不同。

实现

external Geolocation get geolocation;
