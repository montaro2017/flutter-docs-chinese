webdriver 属性

bool get webdriver

webdriver 是 navigator 接口的只读属性，用于指示用户代理是否受自动化控制。

此属性为协作的用户代理定义了一种标准方式，供其向文档表明自己受 WebDriver 控制，例如以便在自动化期间触发备用代码路径。

在以下情况下，navigator.webdriver 属性的值为 true：

  • Chrome
    • ：使用了 --enable-automation 或 --headless 标志，或使用了 --remote-debugging-port。
  • Firefox
    • ：传入了 marionette.enabled 首选项或 --marionette 标志。
