XMLHttpRequest

XMLHttpRequest extension type

@AvailableInWorkers("window_and_worker_except_service")

XMLHttpRequest（XHR）对象用于与服务器交互。你可以从 URL 获取数据，而无需完整刷新页面，因此网页可以只更新其中一部分内容，而不会打断用户当前的操作。

尽管名称中带有 XML，XMLHttpRequest 也可以用于获取任何类型的数据，并不局限于 XML。

如果通信需要接收服务器发送的事件或消息数据，可以考虑通过 EventSource 接口使用服务器发送事件。如果需要全双工通信，WebSockets 可能更合适。

API 文档内容来源于 MDN Web Docs。
