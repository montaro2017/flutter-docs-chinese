RTCPeerConnection 接口的 addIceCandidate() 方法会向连接的远端描述中添加新的远端候选项。远端描述用于说明连接远端的状态。

使用 RTCPeerConnection 的网站或应用通过信令通道从远端对等端收到新的 ICE 候选项后，会调用 RTCPeerConnection.addIceCandidate()，将新收到的候选项交给浏览器的 ICE 代理。此操作会将新的远端候选项添加到 RTCPeerConnection 的远端描述中，该描述用于说明连接远端的状态。

调用 addIceCandidate() 时，如果缺少 candidate 参数或其值为 null，则添加的 ICE 候选项表示“候选项结束”。如果指定对象的 RTCIceCandidate.candidate 缺失或为空字符串（""），含义也相同，表示所有远端候选项均已传送完毕。

候选项结束通知会通过一个 a 行值为 end-of-candidates 的候选项传递给远端对等端。

协商期间，应用通常会收到许多候选项，并以这种方式将它们交给 ICE 代理，以便其逐步建立潜在连接方式的列表。相关内容另见WebRTC 连通性和信令与视频通话。
