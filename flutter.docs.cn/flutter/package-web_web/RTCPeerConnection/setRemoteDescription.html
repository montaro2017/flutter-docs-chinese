RTCPeerConnection 接口的 setRemoteDescription() 方法会将指定的会话描述设为远端对等端当前的提议或应答。此描述指定连接远端的属性，包括媒体格式。该方法接收一个参数（会话描述），并返回一个 Promise；描述异步更改完成后，此 Promise 会兑现。

通常在通过信令服务器收到另一对等端发送的提议或应答后调用此方法。请注意，如果连接已建立时调用 setRemoteDescription()，表示正在重新协商（可能是为了适应网络状况变化）。

由于双方需要交换描述，直到就配置达成一致，因此调用 setRemoteDescription() 提交的描述不会立即生效。协商完成前，连接会继续使用当前配置；协商完成后，双方同意的配置才会生效。
