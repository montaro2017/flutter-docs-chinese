bufferedAmount

bufferedAmount 属性

int get bufferedAmount

RTCDataChannel 的只读属性 bufferedAmount 会返回当前排队等待通过数据通道发送的数据字节数。调用 RTCDataChannel.send 方法可能会使队列累积数据。此值只统计用户代理自身缓冲的数据，不包括帧封装开销，也不包括操作系统或网络硬件缓冲的数据。

用户代理可以自行决定实际发送数据的方式，例如在事件循环期间定期发送，或完全异步地发送。消息实际发出后，此值会相应减少。

注意：关闭数据通道不会重置此计数，即使用户代理会清除队列中的消息也是如此。不过，通道关闭后继续尝试发送消息，仍会增加 bufferedAmount 的值，尽管这些消息既不会发送，也不会被缓冲。

此值降至 RTCDataChannel.bufferedAmountLowThreshold 属性指定的值或更低时，用户代理会触发 RTCDataChannel.bufferedamountlow_event 事件。例如，可用此事件实现在缓冲区有空间时继续排队发送更多消息。
