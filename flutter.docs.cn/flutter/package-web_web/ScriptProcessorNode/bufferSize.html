bufferSize 属性

int get bufferSize

ScriptProcessorNode 接口的 bufferSize 属性会返回一个整数，表示输入和输出缓冲区的大小，单位为采样帧。其值可以是范围 256 – 16384 内的 2 的幂。

注意：此功能已由 AudioWorklets 和 AudioWorkletNode 接口取代。
