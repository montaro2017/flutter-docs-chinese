RTCIceCandidate

RTCIceCandidate extension type

RTCIceCandidate 接口属于 WebRTC API，表示一种候选交互式连接建立（ICE）配置，可用于建立 RTCPeerConnection。

ICE 候选项描述 WebRTC 与远端设备通信所需的协议和路由。启动 WebRTC 对等连接时，连接双方通常会分别提出多个候选项，直到双方协商选出最合适的连接配置。随后，WebRTC 会使用该候选项的详细信息发起连接。

有关 ICE 流程的详细信息，请参阅 WebRTC 会话的生命周期。WebRTC 连通性一文还提供了其他有用信息。

API 文档内容来自 MDN Web 文档。

address → String?
RTCIceCandidate 接口的只读 address 属性是一个字符串，提供候选项来源设备的 IP 地址。该address 的默认值是 null（除非另有指定）。
无 setter
candidate → String
只读属性 candidate 属于 RTCIceCandidate 接口会返回一个详细描述候选项的字符串。 大多数其他属性实际上都是从 RTCIceCandidate 中提取的。
无 setter
component → RTCIceComponent?
只读 component 属性属于 RTCIceCandidate 接口上的属性是一个字符串，用于指明该候选项是 RTP 还是 RTCP 候选项。
无 setter
foundation → String?

RTCIceCandidate 接口的只读 priority 属性指定远端对等端所认为的候选项优先级；值越高，远端对等端认为该候选项越合适。

sdpMid → String?
只读属性 sdpMid 属于 RTCIceCandidate 接口会返回一个字符串，指定与候选项关联的媒体组件的媒体流标识标签。此 ID 会唯一标识与该组件关联的给定媒体流。
无 setter
sdpMLineIndex → int?
只读 sdpMLineIndex 属性属于 RTCIceCandidate 接口上的属性是一个从 0 开始的索引，用于描述与候选项关联的媒体 m 行。
无 setter
tcpType → RTCIceTcpCandidateType?
RTCIceCandidate 接口的只读 tcpType 属性包含在 TCP 候选项中，用于提供有关候选项类型的更多细节。
无 setter
type → RTCIceCandidateType?
RTCIceCandidate 接口的只读 type 属性指定此对象所表示的候选项类型。
无 setter
usernameFragment → String?
只读 usernameFragment 属性属于 RTCIceCandidate 接口上的属性是一个字符串，指示唯一标识单个 ICE 交互会话的用户名片段（“ufrag”）。
无 setter
