BaseAudioContext

BaseAudioContext extension type

Web Audio API 的 BaseAudioContext 接口为在线和离线音频处理图提供基础定义，分别由 AudioContext 和 OfflineAudioContext 表示。通常不会直接使用 BaseAudioContext，而是通过这两个继承接口之一使用它提供的功能。

BaseAudioContext 可以作为事件的目标，因此它实现了 EventTarget 接口。

API 文档来源：MDN Web Docs。

createAnalyser() → AnalyserNode
createAnalyser() 是 BaseAudioContext 接口的方法，用于创建 AnalyserNode，可从中获取音频的时间和频率数据，并据此生成数据可视化。
createBiquadFilter() → BiquadFilterNode
createBiquadFilter() 是 BaseAudioContext 接口的方法，用于创建 BiquadFilterNode，它表示一种二阶滤波器，可配置为多种常见滤波器类型。
createBuffer(int numberOfChannels, int length, num sampleRate) → AudioBuffer
createBuffer() 是 BaseAudioContext 接口的方法，用于创建新的空 AudioBuffer 对象。随后可向其中填入数据，并通过 AudioBufferSourceNode 播放。
createBufferSource() → AudioBufferSourceNode
createBufferSource() 是 BaseAudioContext 接口的方法，用于创建新的 AudioBufferSourceNode 节点，以播放 AudioBuffer 对象中的音频数据。音频缓冲区（AudioBuffer）可通过 BaseAudioContext.createBuffer 创建，也可以由 BaseAudioContext.decodeAudioData 成功解码后返回。
createChannelMerger([int numberOfInputs]) → ChannelMergerNode
createChannelMerger() 是 BaseAudioContext 接口的方法，用于创建 ChannelMergerNode，将多个音频流中的通道合并为一个音频流。
createChannelSplitter([int numberOfOutputs]) → ChannelSplitterNode
createChannelSplitter() 是 BaseAudioContext 接口的方法，用于创建 ChannelSplitterNode，以便访问音频流中的各个通道并分别处理。
createConstantSource() → ConstantSourceNode
createConstantSource() 是 BaseAudioContext 接口的方法，用于创建 ConstantSourceNode。该音频源会持续输出单声道（单通道）信号，其样本值均为同一个常数。
createConvolver() → ConvolverNode
createConvolver() 是 BaseAudioContext 接口的方法，用于创建 ConvolverNode，常用于为音频添加混响效果。更多信息请参阅 spec definition of Convolution 规范定义。
createDelay([num maxDelayTime]) → DelayNode
createDelay() 是 BaseAudioContext 接口的方法，用于创建 DelayNode，以将输入音频信号延迟指定时长。
createDynamicsCompressor() → DynamicsCompressorNode
createDynamicsCompressor() 是 BaseAudioContext 接口的方法，用于创建 DynamicsCompressorNode，可对音频信号应用动态压缩。
createGain() → GainNode
createGain() 是 BaseAudioContext 接口的方法，用于创建 GainNode，以控制音频图的整体增益（或音量）。
createIIRFilter(JSArray<JSNumber> feedforward, JSArray<JSNumber> feedback) → IIRFilterNode
createIIRFilter() 是 BaseAudioContext 接口的方法，用于创建 IIRFilterNode，它表示通用的 infinite impulse response（IIR）滤波器，可配置为多种滤波器类型。
createOscillator() → OscillatorNode
createOscillator() 是 BaseAudioContext 接口的方法，用于创建 OscillatorNode，即表示周期波形的信号源；它会持续生成固定音调。
createPanner() → PannerNode
createPanner() 是 BaseAudioContext 接口的方法，用于创建 PannerNode，以便在 3D 空间中对输入音频流进行空间化处理。
createPeriodicWave(JSArray<JSNumber> real, JSArray<JSNumber> imag, [PeriodicWaveConstraints constraints]) → PeriodicWave
createPeriodicWave() 是 BaseAudioContext 接口的方法，用于创建 PeriodicWave，以定义周期波形，并可用于塑造 OscillatorNode 的输出。
createScriptProcessor([int bufferSize, int numberOfInputChannels, int numberOfOutputChannels]) → ScriptProcessorNode
createScriptProcessor() 是 BaseAudioContext 接口的方法，用于创建 ScriptProcessorNode，以便直接处理音频。
createStereoPanner() → StereoPannerNode
createStereoPanner() 是 BaseAudioContext 接口的方法，用于创建 StereoPannerNode，以便对音源应用立体声平移。该节点使用 low-cost panning algorithm 将输入音频流定位在立体声声像中。
createWaveShaper() → WaveShaperNode
createWaveShaper() 是 BaseAudioContext 接口的方法，用于创建 WaveShaperNode，它表示非线性失真，可用于为音频应用失真效果。

decodeAudioData(JSArrayBuffer audioData, [DecodeSuccessCallback? successCallback, DecodeErrorCallback? errorCallback]) → JSPromise<AudioBuffer>
decodeAudioData() 是 BaseAudioContext 接口的方法，用于异步解码从 ArrayBuffer 加载的音频文件数据。数据可通过 fetch、XMLHttpRequest 或 FileReader 加载。解码后的 AudioBuffer 会重采样至 AudioContext 的采样率，然后传递给回调函数或 Promise。
