targetRaySpace 属性

XRSpace get targetRaySpace

XRInputSource 的只读属性 targetRaySpace 会返回一个 XRSpace（通常是 XRReferenceSpace），表示虚拟空间中目标射线的位置和方向。其原生原点会跟踪目标射线起点的位置，方向则表示控制器设备本身的朝向。结合输入源的 XRInputSource.targetRayMode 解读这些值，可以完整确定该设备作为输入源的含义。

若要获取表示输入控制器在虚拟空间中位置和方向的 XRSpace，请使用 XRInputSource.gripSpace 属性。

实现

external XRSpace get targetRaySpace;
