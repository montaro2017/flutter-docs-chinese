cmp 方法

int cmp(
  1. JSAny? first,
  2. JSAny? second
)

IDBFactory 接口的 cmp() 方法会将两个值作为键进行比较，以确定它们在 IndexedDB 操作（例如存储和迭代）中的相等关系与顺序。

注意：不要使用此方法比较任意 JavaScript 值，因为许多 JavaScript 值不是有效的 IndexedDB 键（例如布尔值和对象），或者会被视为等价的 IndexedDB 键（例如，IndexedDB 会忽略数组中的非数字属性并将其视为空数组，因此所有包含非数字属性的数组都被视为等价）。如果任一值不是有效的键，此方法会抛出异常。

实现

external int cmp(
  JSAny? first,
  JSAny? second,
);
