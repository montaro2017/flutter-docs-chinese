Selection

Selection extension type

Selection 对象表示用户选中的文本范围或当前插入符位置。若要获取 Selection 对象以供检查或操作，请调用 window.getSelection。

用户可以从左向右（按文档顺序）或从右向左（与文档顺序相反）进行选择。锚点是用户开始选择的位置，焦点是用户结束选择的位置。使用桌面鼠标进行选择时，锚点位于按下鼠标按钮的位置，焦点位于释放鼠标按钮的位置。

注意：锚点和焦点不要与选择范围的起始和结束位置混淆。根据选择方向，锚点可能位于焦点之前，也可能位于焦点之后。

API 文档来源：MDN Web 文档。
