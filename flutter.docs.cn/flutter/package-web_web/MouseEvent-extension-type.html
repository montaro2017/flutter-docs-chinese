MouseEvent

MouseEvent extension type

MouseEvent 接口表示用户与指点设备（例如鼠标）交互时发生的事件。常见的此类事件包括 Element.click_event、Element.dblclick_event、Element.mouseup_event 和 Element.mousedown_event。

MouseEvent 继承自 UIEvent，后者又继承自 Event。虽然保留 MouseEvent.initMouseEvent 方法是为了向后兼容，但创建 MouseEvent 对象时应使用 MouseEvent.MouseEvent 构造函数。

还有一些更具体的事件基于 MouseEvent，包括 WheelEvent、DragEvent 和 PointerEvent。

API 文档来源：MDN Web Docs。
