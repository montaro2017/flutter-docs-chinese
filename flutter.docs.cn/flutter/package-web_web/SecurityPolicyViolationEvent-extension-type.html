SecurityPolicyViolationEvent

SecurityPolicyViolationEvent extension type

SecurityPolicyViolationEvent 接口继承自 Event，表示当文档或 worker 的内容安全策略遭到违反时所发送事件的事件对象。

API 文档来源：MDN Web 文档。
