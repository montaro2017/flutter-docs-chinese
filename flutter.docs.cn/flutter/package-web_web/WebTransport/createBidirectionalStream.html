WebTransport 接口的 createBidirectionalStream() 方法会异步打开并返回一个双向流。

该方法返回一个 Promise，完成后会得到一个 WebTransportBidirectionalStream 对象。该对象具有 readable 和 writable 属性，可用于可靠地从服务器读取数据并向服务器写入数据。“可靠”表示数据传输及其顺序都得到保证。与 WebTransport.datagrams 相比，这种方式传输较慢（但比 WebSockets 快）；当可靠性和顺序很重要时，例如聊天应用，就需要使用这种方式。

可以通过 sendOrder 选项指定创建的流中排队字节的发送顺序。设置后，发送顺序较高的流中的排队字节保证先于发送顺序较低的流发送。如果未设置顺序编号，字节的发送顺序由具体实现决定。不过，即使较高发送顺序的流先发送，其字节也不一定先到达。
