SubtleCrypto 接口的 deriveBits() 方法可用于从基础密钥派生一组比特。

该方法接收基础密钥、要使用的派生算法以及要派生的比特长度作为参数。它会返回一个 Promise，兑现值为包含派生比特的 ArrayBuffer。

此方法与 SubtleCrypto.deriveKey() 非常相似，但 deriveKey() 返回的是 CryptoKey 对象，而不是 ArrayBuffer。从本质上说，deriveKey() 由 deriveBits() 和随后调用的 importKey() 组成。

此函数支持与 deriveKey() 相同的密钥派生算法：ECDH、HKDF 和 PBKDF2。有关这些算法的更多信息，请参阅支持的算法。
