SubtleCrypto 接口的 wrapKey() 方法用于“封装”密钥。也就是说，它先以外部可移植格式导出密钥，再对导出的密钥进行加密。封装密钥有助于在不可信环境中保护密钥，例如存储在未受保护的数据存储中，或通过未受保护的网络传输时。

与 SubtleCrypto.exportKey 一样，你需要为密钥指定导出格式。要导出密钥，必须将 CryptoKey.extractable 设置为 true。

不过，由于 wrapKey() 还会加密要导出的密钥，因此还需要传入用于加密它的密钥。该密钥有时称为“封装密钥”。

wrapKey() 的逆操作是 SubtleCrypto.unwrapKey：wrapKey 由“导出 + 加密”组成，而 unwrapKey 由“导入 + 解密”组成。
