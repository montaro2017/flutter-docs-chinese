languages 属性

JSArray<JSString> get languages

WorkerNavigator.languages 是只读属性，返回一个字符串数组，表示用户的首选语言。语言使用符合 5646, "Tags for Identifying Languages (also known as BCP 47)" 的语言标签描述。返回的数组按偏好排序，最偏好的语言排在首位。

WorkerNavigator.language 的值是返回数组中的第一个元素。

当用户更改首选语言导致该值变化时，会在 WorkerGlobalScope 对象上触发 Window.languagechange_event 事件。

用户浏览器发出的每个 HTTP 请求中的 Accept-Language HTTP 标头，与 navigator.languages 属性使用相同的值，但会额外包含 qvalues（质量值）字段，例如 en-US;q=0.8。

实现

external JSArray<JSString> get languages;
