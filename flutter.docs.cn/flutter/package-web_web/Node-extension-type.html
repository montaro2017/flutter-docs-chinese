Node

Node extension type

Node 接口是一个抽象基类，许多其他 DOM API 对象都以它为基础，因此这些对象类型可以采用相似甚至可互换的方式使用。由于它是抽象类，因此不存在普通的 Node 对象。所有实现 Node 功能的对象都基于它的某个子类。最常见的子类包括 Document、Element 和 DocumentFragment。

此外，每种 DOM 节点都由基于 Node 的接口表示，包括 Attr、CharacterData（Text、Comment、CDATASection 和 ProcessingInstruction 都基于它）以及 DocumentType。

在某些情况下，Node 基础接口的某项特性可能不适用于其某个子接口；此时，继承该接口的节点可能会根据具体情况返回 null 或抛出异常。例如，尝试向无法包含子节点的节点类型添加子节点时会抛出异常。

API 文档来源：MDN Web Docs。
