Element 接口的 requestPointerLock() 方法允许异步请求锁定指向给定元素的指针。

若要跟踪请求成功还是失败，必须在 Document 层级监听 Document.pointerlockchange_event 和 Document.pointerlockerror_event 事件。

注意：在当前规范中，requestPointerLock() 只会通过触发 Document.pointerlockchange_event 或 Document.pointerlockerror_event 事件来报告请求成功或失败。一项针对规范的拟议更新会让 requestPointerLock() 返回一个用于报告成功或失败的 Promise。本页面介绍的是返回 Promise 的版本。不过请注意，该版本尚未成为标准，也未被所有浏览器实现。更多信息请参阅浏览器兼容性。
