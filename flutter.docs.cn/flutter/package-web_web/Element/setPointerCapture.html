Element 接口的 setPointerCapture() 方法用于将特定元素指定为后续指针事件的捕获目标。在释放捕获之前（通过调用 Element.releasePointerCapture，或触发 Element.pointerup_event 事件），该指针的后续事件都会以此捕获元素为目标。

注意：指针捕获会使目标捕获所有后续指针事件，就像这些事件发生在捕获目标上那样。因此，只要保持捕获，pointerover、pointerenter、pointerleave 和 pointerout 就不会触发。对于支持直接操作的触屏浏览器，触发 pointerdown 事件时会在该元素上调用隐式指针捕获。可以在目标元素上调用 element.releasePointerCapture 手动释放捕获；如果未手动释放，则会在 pointerup 或 pointercancel 事件后隐式释放。

注意：如果需要在 DOM 中移动元素，请务必在移动 DOM 之后调用 setPointerCapture()，以免 setPointerCapture() 无法继续跟踪该元素。例如，如果要使用 Element.append() 将元素移动到其他位置，请在移动后对该元素调用 setPointerCapture()，也就是在调用 Element.append() 之后再调用它。

指针捕获概述

指针捕获允许将特定指针事件（PointerEvent）重新定向到指定元素，而不是指针所在位置的常规目标（或命中测试目标）。这样，即使指针设备的接触点移出元素（例如由于滚动或平移），也能确保该元素继续接收指针事件。
