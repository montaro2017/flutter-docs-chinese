innerHTML 属性

JSAny get innerHTML

Element 的 innerHTML 属性用于获取或设置元素内部包含的 HTML 或 XML 标记。

更准确地说，读取 innerHTML 会获得元素内部嵌套子 DOM 元素的序列化结果；设置它则会解析给定的 HTML 或 XML，并替换元素内部的 DOM 树。

如果要将 HTML 插入文档而不是替换元素内容，请使用 Element.insertAdjacentHTML 方法。

从该属性读取的 DOM 树序列化结果不包含影子根。如果需要获取包含影子根的 HTML 字符串，应改用 Element.getHTML 或 ShadowRoot.getHTML 方法。同样，使用 innerHTML 设置元素内容时，HTML 字符串会被解析为不包含影子根的 DOM 元素。

例如，无论是否指定 shadowrootmode 属性，<template> 都会被解析为 HTMLTemplateElement。若要使用包含声明式影子根的 HTML 字符串设置元素内容，必须使用 Element.setHTMLUnsafe 或 ShadowRoot.setHTMLUnsafe。
