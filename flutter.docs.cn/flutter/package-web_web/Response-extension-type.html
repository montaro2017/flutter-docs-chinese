Response

Response extension type

Fetch API 的 Response 接口表示对请求的响应。

可以使用 Response.Response 构造函数创建新的 Response 对象，但更常见的情况是，其他 API 操作会返回 Response 对象，例如 service worker 的 FetchEvent.respondWith，或普通的 fetch 调用。

API 文档来源：MDN Web Docs。
