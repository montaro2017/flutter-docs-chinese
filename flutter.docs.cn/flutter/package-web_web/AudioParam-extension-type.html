AudioParam

AudioParam extension type

Web Audio API 的 AudioParam 接口表示与音频相关的参数，通常是某个 AudioNode 的参数（例如 GainNode.gain）。

可以为 AudioParam 设置特定值或值变化，并安排这些变化在特定时间按指定模式发生。

每个 AudioParam 都有一个最初为空的事件列表，用于定义值何时以及如何变化。列表不为空时，通过 AudioParam.value 属性进行的更改会被忽略。此事件列表支持使用任意基于时间轴的自动化曲线，在非常精确的时刻安排变化。所用时间由 BaseAudioContext.currentTime 定义。

API 文档来源：MDN Web Docs。
