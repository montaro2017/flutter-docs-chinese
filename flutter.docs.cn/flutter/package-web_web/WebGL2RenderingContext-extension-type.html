WebGL2RenderingContext

WebGL2RenderingContext extension type

WebGL2RenderingContext 接口为 HTML canvas 元素的绘图表面提供 OpenGL ES 3.0 渲染上下文。

若要获取此接口的对象，请对 <canvas> 元素调用 HTMLCanvasElement.getContext，并传入 "webgl2" 作为参数：

const canvas = document.getElementById("myCanvas");
const gl = canvas.getContext("webgl2");

注意：WebGL 2 是 WebGL 1 的扩展。WebGL2RenderingContext 接口实现了 WebGLRenderingContext 接口的所有成员。在 WebGL 2 上下文中使用时，某些 WebGL 1 上下文的方法可以接受额外的值。相关信息会在 WebGL 1 参考页面中注明。

WebGL 教程提供了更多入门信息、示例和资源。

API 文档来源于 MDN Web 文档。
