ElementInternals

ElementInternals extension type

文档对象模型中的 ElementInternals 接口为 Web 开发者提供了一种方式，使自定义元素能够完整参与 HTML 表单。它提供了相关工具，让你可以像操作标准 HTML 表单元素一样操作这些元素，同时还会向该元素公开 无障碍对象模型。

API 文档内容来源于 MDN Web Docs。
