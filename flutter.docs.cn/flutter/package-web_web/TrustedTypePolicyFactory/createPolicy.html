createPolicy() 方法属于 TrustedTypePolicyFactory 接口，它会创建一个 TrustedTypePolicy 对象，该对象实现通过 policyOptions 传入的规则。

默认策略

在 Chrome 中，名称为 "default" 的策略会创建一种特殊策略：当字符串（而非 Trusted Type 对象）被传入注入接收点时，会使用此策略。在从向注入接收点插入字符串的应用逐步迁移期间，可以使用此策略。

注意：上述行为在规范中尚未最终确定，未来可能会发生变化。

警告：宽松的默认策略可能会破坏使用 Trusted Types 的初衷，因此应通过严格规则定义该策略，确保它无法用于运行危险代码。
