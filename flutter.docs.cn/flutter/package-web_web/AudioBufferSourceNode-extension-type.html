AudioBufferSourceNode

AudioBufferSourceNode extension type

AudioBufferSourceNode 接口是一种 AudioScheduledSourceNode，表示以内存中的音频数据（存储在 AudioBuffer 中）作为来源的音频源。

此接口特别适合播放对时间精度要求很高的音频，例如必须与特定节奏匹配、可以保存在内存中而无需从磁盘或网络播放的声音。对于同样要求精准定时、但必须从网络流式传输或从磁盘播放的声音，可以使用 AudioWorkletNode 实现播放。

AudioBufferSourceNode 没有输入端，且恰好有一个输出端；输出声道数与其 AudioBufferSourceNode.buffer 属性指定的 AudioBuffer 相同。如果未设置缓冲区（即 buffer 为 null），输出将是单声道静音（每个采样值均为 0）。

AudioBufferSourceNode 只能播放一次；每次调用 AudioBufferSourceNode.start 后，如果要再次播放相同声音，就必须创建新的节点。幸运的是，创建此类节点的开销很低，而实际的 AudioBuffer 可以重复用于多次播放。事实上，可以采用“触发后不再管理”的方式使用这些节点：创建节点，调用 start() 开始播放，然后无需保留对它的引用。它会在适当的时候自动进行垃圾回收，但要等声音播放结束之后才会回收。

允许多次调用 AudioScheduledSourceNode.stop。如果 AudioBufferSourceNode 尚未播放到缓冲区末尾，最近一次调用会替换之前的调用。
