HTMLObjectElement

HTMLObjectElement extension type

HTMLObjectElement 接口提供了用于操作表示外部资源的 object 元素布局和呈现的特殊属性与方法（除通过继承从 HTMLElement 接口获得的属性和方法外）。

API 文档来源：MDN Web Docs。

on
  • JSObject
实现的类型
  • HTMLElement
  • JSObject
Available extensions
  • ElementCustomEvents
  • ElementEventGetters
  • JSAnyOperatorExtension
  • JSAnyUtilityExtension
  • JSObjectUnsafeUtilExtension
  • NodeGlue
  • NullableUndefineableJSAnyExtension
