警告：强烈不建议使用 document.write() 方法。

正如HTML 规范本身所警告的：

此方法的行为十分特殊。在某些情况下，它可能会影响以下内容的状态：

当 HTML 解析器正在运行时，此方法可能影响 HTML 解析器，从而生成与文档源代码不对应的 DOM（例如，写入的字符串是 "<plaintext>" 或 "<!--"）。在其他情况下，此调用会先清除当前页面，效果如同调用了 document.open()。还有一些情况下，该方法会被忽略或抛出异常。用户代理明确可以不执行通过此方法插入的 script 元素。更糟的是，在某些情况下，此方法的确切行为还可能取决于网络延迟，导致非常难以调试的故障。基于以上所有原因，强烈不建议使用此方法。

因此，请避免使用 document.write()；如果可能，也请更新仍在使用它的现有代码。

document.write() 方法会将文本字符串写入由 document.open 打开的文档流。

注意：由于 document.write() 会写入文档流，因此在已关闭（已加载）的文档上调用 document.write() 会自动调用 document.open()，并清空文档。
