timeline 属性

DocumentTimeline get timeline

Document 接口的只读 timeline 属性表示当前文档的默认时间轴。该时间轴是 DocumentTimeline 的一个特殊实例。

每个 document 都有唯一的时间轴，该时间轴在 document 的整个生命周期内持续存在，包括调用 Document.open 时。

此时间轴表示从 Performance.timeOrigin 起经过的毫秒数。在时间起点之前，时间轴处于非活动状态，其 AnimationTimeline.currentTime 为 null。

注意：与非活动文档关联的文档时间轴也视为非活动状态。非活动文档是指未关联 Window、iframe 或 frame 的 Document。
