requestStorageAccess 方法

JSPromise<JSAny?> requestStorageAccess()

Document 接口的 requestStorageAccess() 方法允许在第三方上下文中加载的内容（即嵌入 iframe 中的内容）请求访问第三方 Cookie和未分区状态。对于默认阻止第三方未分区 Cookie访问以改善隐私（例如防止跟踪）的用户代理，此方法尤为重要；它属于 Storage Access API。

若要检查是否已获准访问第三方 Cookie，可以调用 Permissions.query，并将功能名称指定为 "storage-access"。

注意：服务器设置的 Permissions Policy 可能会阻止使用此功能。此外，文档还必须通过特定于浏览器的其他检查，例如允许列表、阻止列表、设备端分类、用户设置、反点击劫持启发式检查，或请求用户明确授权。
