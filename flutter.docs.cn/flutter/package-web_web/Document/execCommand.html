execCommand 方法实现了多种不同的命令。其中一些命令可以访问剪贴板，另一些则用于编辑表单输入控件、contenteditable 元素，或整个文档（在启用设计模式时）。

访问剪贴板时，建议使用较新的 Clipboard API，而不是 execCommand()。不过，编辑命令目前没有替代方案：与直接操作 DOM 不同，execCommand() 执行的修改会保留撤销缓冲区（编辑历史）。

大多数命令都会影响文档中的选区。例如，某些命令（加粗、斜体等）会设置当前选中文本的格式；另一些命令会删除选区、插入新元素（替换选区），或影响整行内容（例如缩进）。只有当前处于活动状态的可编辑元素可以被修改，但某些命令（例如 copy）无需可编辑元素也能执行。

注意：根据浏览器和配置，execCommand() 执行的修改可能会触发，也可能不会触发 Element.beforeinput_event 和 Element.input_event 事件。如果触发了这些事件，其处理程序会在 execCommand() 返回前运行。开发者需要注意此类递归调用，尤其是在响应这些事件时调用 execCommand()。从 Firefox 82 开始，嵌套的 execCommand() 调用始终会失败，详见 bug 1634262。
