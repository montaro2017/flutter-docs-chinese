Document 对象的静态 parseHTMLUnsafe() 方法用于解析 HTML 字符串（其中可能包含声明式 Shadow DOM），并据此创建新的 Document 实例。

方法名称中的 “Unsafe”（不安全）表示：解析时虽然不会执行 <script> 元素，但此方法不会清理其他可能导致 XSS 的不安全输入。

生成的 Document 的内容类型为 "text/html"，字符集为 UTF-8，URL 为 "about:blank"。

实现
