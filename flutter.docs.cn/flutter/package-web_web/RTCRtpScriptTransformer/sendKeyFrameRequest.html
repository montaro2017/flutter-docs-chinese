sendKeyFrameRequest 方法

JSPromise<JSAny?> sendKeyFrameRequest()

处理入站编码视频帧的 WebRTC 编码转换可以调用 RTCRtpScriptTransformer 接口的 sendKeyFrameRequest() 方法，请求发送器发送关键帧。

此方法仅在接收视频帧（而非音频帧），且接收方因某种原因无法在没有新关键帧的情况下解码视频时才能调用。请注意，用户代理可以判断无需请求关键帧；此时即使请求实际并未发送，返回的 Promise 仍会兑现。

注意：例如，有新用户加入 WebRTC 会议时可以调用此方法，以缩短其收到关键帧并开始显示视频之前的等待时间。更多信息请参阅《使用 WebRTC 编码转换》中的触发关键帧。
