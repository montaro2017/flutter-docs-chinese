IDBObjectStore

IDBObjectStore extension type

IDBObjectStore 接口属于 IndexedDB API，表示数据库中的一个对象存储。对象存储中的记录会按键排序，因此可以快速插入、查找并按顺序检索。

API 文档来源：MDN Web 文档。

clear() → IDBRequest
clear() 方法属于 IDBObjectStore 接口。它会创建并立即返回一个 IDBRequest 对象，并在单独的线程中清空此对象存储。此方法用于删除对象存储中的所有现有数据。
count([JSAny? query]) → IDBRequest
count() 方法属于 IDBObjectStore 接口。它会返回一个 IDBRequest 对象，并在单独的线程中返回与给定键或 IDBKeyRange 匹配的记录总数。如果未提供参数，则返回存储中的记录总数。
createIndex(String name, JSAny keyPath, [IDBIndexParameters options]) → IDBIndex
createIndex() 方法属于 IDBObjectStore 接口，可在已连接的数据库中创建并返回一个新的 IDBIndex 对象。它会创建一个新字段或列，为每条数据库记录定义一个要存储的数据点。

get() 方法属于 IDBObjectStore 接口。它会返回一个 IDBRequest 对象，并在单独的线程中返回指定键所选中的对象。此方法用于从对象存储中检索特定记录。
getAll([JSAny? query, int count]) → IDBRequest
getAll() 方法属于 IDBObjectStore 接口，返回一个 IDBRequest 对象，其中包含对象存储中与指定参数匹配的所有对象；若未提供参数，则包含存储中的所有对象。
