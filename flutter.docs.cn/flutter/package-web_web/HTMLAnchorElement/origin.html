origin 属性

String get origin

HTMLAnchorElement.origin 只读属性是一个字符串，包含所表示 URL 的源的 Unicode 序列化形式。

也就是说：

  • 对于使用 http 或 https 方案的 URL，其源由方案、'://'、域名、':' 和端口依次组成（如果显式指定，默认端口分别为 80 和 443）；
  • 对于使用 file: 方案的 URL，该值取决于浏览器；
  • 对于使用 blob: 方案的 URL，其源与 URL 后面的源相同。例如，blob: 后接 "blob:https://mozilla.org" 时，源为 "https://mozilla.org"。
