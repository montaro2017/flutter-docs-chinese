isPrimary

isPrimary 属性

bool get isPrimary

PointerEvent 接口的只读 isPrimary 属性用于指示生成事件的指针设备是否为主指针。如果触发事件的指针是主指针，则返回 true；否则返回 false。

在多指针场景中（例如支持多个触点的触摸屏），此属性用于在每种指针类型的活动指针集合中标识一个主指针。只有主指针会产生兼容性鼠标事件。如果开发者只希望支持单指针交互，可以忽略非主指针。

鼠标设备对应的指针始终视为主指针。如果没有其他活动的笔输入指针，分发其 Element.pointerdown_event 事件的笔指针就视为主笔指针。如果没有其他活动的触摸输入指针，分发其 Element.pointerdown_event 事件的触摸指针就视为主触摸指针。

同时使用两种或更多指针设备类型时，每种 PointerEvent.pointerType 都可以有一个主指针。例如，同时移动触摸点和鼠标光标时，两个指针对应的指针都视为主指针。如果存在多个主指针，它们都会产生兼容性鼠标事件（有关指针、鼠标和触摸交互的更多信息，请参阅 Pointer_events）。
