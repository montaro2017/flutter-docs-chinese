Range

Range extension type

Range 接口表示文档中的一个片段，其中可以包含节点以及文本节点的一部分。

可以使用 Document.createRange 方法创建 range。也可以通过 Selection 对象的 Selection.getRangeAt 方法，或 Document 对象的 Document.caretRangeFromPoint 方法获取 Range 对象。

此外，也可以使用 Range.Range 构造函数。

API 文档来源：MDN Web Docs。
