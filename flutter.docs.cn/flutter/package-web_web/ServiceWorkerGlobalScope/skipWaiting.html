skipWaiting 方法

JSPromise<JSAny?> skipWaiting()

@AvailableInWorkers("service")

ServiceWorkerGlobalScope 接口的 skipWaiting() 方法会强制等待中的 service worker 成为活动的 service worker。

将此方法与 Clients.claim 配合使用，可确保底层 service worker 的更新立即对当前客户端和所有其他活动客户端生效。
