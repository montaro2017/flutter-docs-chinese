HttpRequest

HttpRequest 类

警告

此类已弃用，并将在未来版本中移除 package:web。

请改用跨平台的 package:http，以及基于 XMLHttpRequest 的 BrowserClient 适配器。

此辅助工具用于简化对 XMLHttpRequest 的操作。

此处的逻辑从 dart:html 复制而来，用于弥补 package:web 中缺失的功能。

HttpRequest 可用于从 HTTP 和 FTP 协议获取数据，也适用于 AJAX 风格的页面更新。

获取文本文件（例如 JSON 格式文件）内容最简单的方法是使用 getString。例如，下面的代码会获取 JSON 文件内容并打印其长度：

var path = 'myData.json';
HttpRequest.getString(path).then((String fileContents) {
  print(fileContents.length);
}).catchError((error) {
  print(error.toString());
});

从其他服务器获取数据

出于安全原因，浏览器会限制嵌入式应用发出的请求。此类的默认行为要求发起请求的代码与所请求的资源来自同一来源（域名、端口和应用层协议）。在上面的示例中，myData.json 文件必须与使用它的应用位于同一位置。
