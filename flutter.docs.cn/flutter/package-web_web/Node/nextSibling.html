nextSibling 属性

Node? get nextSibling

nextSibling 是 Node 接口的只读属性，返回指定节点在其父节点 Node.childNodes 中紧随其后的节点；如果指定节点是父元素中的最后一个子节点，则返回 null。

注意：浏览器会在文档中插入 Text 节点，以表示源标记中的空白。因此，例如通过 Node.firstChild 或 Node.previousSibling 获取的节点，可能是空白文本节点，而不是作者预期获取的实际元素。

DOM 中的空白一文介绍了有关此行为的更多信息。

可以使用 Element.nextElementSibling 来获取下一个元素，并跳过空白节点、元素间的其他文本或注释。

若要沿相反方向遍历子节点列表，请使用 Node.previousSibling。

实现
