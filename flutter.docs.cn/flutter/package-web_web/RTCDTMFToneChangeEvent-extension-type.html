RTCDTMFToneChangeEvent

RTCDTMFToneChangeEvent extension type

RTCDTMFToneChangeEvent 接口表示用于指示 DTMF 音开始或结束播放的事件。此接口由 tonechange 事件使用。

API 文档内容来自 MDN Web 文档。
