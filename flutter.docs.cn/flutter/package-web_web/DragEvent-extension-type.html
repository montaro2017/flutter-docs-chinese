DragEvent

DragEvent extension type

DragEvent 接口是一种表示拖放交互的 Event。用户将指针设备（例如鼠标）放在触摸表面上，然后将指针拖动到新位置（例如另一个 DOM 元素），即可开始拖动。应用可以根据自身需求解释拖放交互。

此接口继承自 MouseEvent 和 Event。

API 文档来源：MDN Web Docs。
