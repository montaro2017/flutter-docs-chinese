claim

claim 方法

JSPromise<JSAny?> claim()

@AvailableInWorkers("service")

Clients 接口的 claim() 方法允许活动的 Service Worker 将自己设为其 ServiceWorkerRegistration.scope 作用范围内所有客户端的 ServiceWorkerContainer.controller。对于因此受此 Service Worker 控制的客户端，会在其 ServiceWorkerContainer 上触发 "controllerchange" 事件。

Service Worker 初次注册时，页面要等到下次加载才会使用它。调用 claim() 方法会使这些页面立即受到控制。请注意，这会导致你的 Service Worker 控制通过常规网络加载，或可能由其他 Service Worker 加载的页面。

实现
