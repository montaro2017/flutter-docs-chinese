commonAncestorContainer 属性

Node get commonAncestorContainer

Range.commonAncestorContainer 只读属性会返回文档树中最深层、同时包含Node 的两个边界点以及 Range 的节点。因此，如果 Range.startContainer 和 Range.endContainer 都指向同一个节点，该节点就是共同祖先容器。

由于 Range 不一定连续，也可能只选中节点的一部分，因此该属性可方便地用于查找包围整个 Range 的 Node。

此属性为只读。若要更改 Node 的祖先容器，可以使用设置 Range 起止位置的各种方法，例如 Range.setStart 和 Range.setEnd。

实现

external Node get commonAncestorContainer;
