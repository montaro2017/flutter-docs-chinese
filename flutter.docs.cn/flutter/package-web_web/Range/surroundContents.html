Range.surroundContents() 方法会将 Range 的内容移入新节点，并将该节点放置在指定 range 的起点。

此方法几乎等同于 newNode.appendChild(range.extractContents()); range.insertNode(newNode)。包裹完成后，range 的边界点会包含 newNode。

但是，如果 Range 只通过一个边界点拆分了非 Text 节点，则会抛出异常。也就是说，与上述替代做法不同，如果存在部分选中的节点，这些节点不会被克隆，操作会直接失败。
