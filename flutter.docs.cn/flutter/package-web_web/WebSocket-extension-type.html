WebSocket

WebSocket extension type

WebSocket 对象提供了用于创建和管理与服务器之间 WebSocket 连接的 API，也提供了通过该连接发送和接收数据的功能。

要创建 WebSocket，请使用 WebSocket() 构造函数。

API 文档来源：MDN Web 文档。

bufferedAmount → int
WebSocket.bufferedAmount 只读属性会返回通过调用 send() 排队、但尚未发送到网络的数据字节数。队列中的数据全部发送后，此值会重置为零。连接关闭时，该值不会重置；如果继续调用 send()，此值会持续增长。

send(JSAny data) → void
WebSocket.send() 方法会将指定数据加入发送队列，通过 WebSocket 连接传输到服务器；bufferedAmount 的值会增加容纳这些数据所需的字节数。如果数据无法发送（例如需要缓冲但缓冲区已满），套接字会自动关闭。如果连接处于 CONNECTING 状态时调用 send()，浏览器会抛出异常。如果连接处于 CLOSING 或 CLOSED 状态时调用 send()，浏览器会静默丢弃数据。
