echoCancellation 属性

bool get echoCancellation

MediaTrackSettings 字典的 echoCancellation 属性是一个布尔值，用于指示音频轨道是否启用了回声消除。通过它可以确定为符合指定约束而选取的值；这些约束由调用 MediaDevices.getUserMedia 或 MediaStreamTrack.applyConstraints 时提供的 MediaTrackConstraints.echoCancellation 属性描述。

回声消除功能会尝试减少或消除用户输出设备与输入设备之间的串音，以避免双向音频连接产生回声。例如，它可能会应用滤波器，防止扬声器发出的声音被麦克风采集并包含在输入轨道中。

如有需要，可以检查调用 MediaDevices.getSupportedConstraints 返回的 MediaTrackSupportedConstraints.echoCancellation 值，以确定是否支持此约束。不过通常无需这样做，因为浏览器会忽略自己不认识的约束。

由于 不包含此信息，与 WebRTC RTCPeerConnection 关联的轨道永远不会包含此属性。
