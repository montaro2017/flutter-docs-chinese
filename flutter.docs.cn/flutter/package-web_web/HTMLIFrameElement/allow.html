allow 属性

String get allow

HTMLIFrameElement 接口的 allow 属性表示为此 <iframe> 元素指定的权限策略。该策略根据请求的来源，定义 <iframe> 元素可以使用哪些功能（例如访问 microphone、camera、battery、web-share 等）。

allow 属性指定的权限策略会在 Permissions-Policy 响应头指定的策略基础上进一步收紧限制，而不会取代该策略。

更多详情请参阅 <iframe> 的权限策略语法。

该属性反映 iframe 元素的 allow 属性值。

实现

external String get allow;
set allow (String value)

实现

external set allow(String value);
