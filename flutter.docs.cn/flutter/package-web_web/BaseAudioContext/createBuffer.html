BaseAudioContext 接口的 createBuffer() 方法用于创建新的空 AudioBuffer 对象，之后可以向其中填充数据，并通过 AudioBufferSourceNode 播放。

有关音频缓冲区的更多详情，请参阅 AudioBuffer 参考页面。

注意：过去 createBuffer() 可以接收压缩数据并返回解码后的采样值，但规范已移除此功能，因为解码在主线程上执行，会导致 createBuffer() 阻塞其他代码。异步方法 decodeAudioData() 也能完成相同任务：接收 MP3 等压缩音频，并直接返回可通过 AudioBufferSourceNode 播放的 AudioBuffer。对于播放 MP3 等简单场景，应使用 decodeAudioData()。
