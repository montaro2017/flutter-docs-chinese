EventSource

EventSource extension type

EventSource 接口是 Web 内容使用服务器发送事件的接口。

EventSource 实例会与 HTTP 服务器建立持久连接，服务器以 text/event-stream 格式发送事件。连接会一直保持打开状态，直到调用 EventSource.close 将其关闭。

连接建立后，服务器发来的消息会以事件的形式传递给你的代码。如果收到的消息中包含 event 字段，触发的事件类型就与该字段的值相同。如果没有 event 字段，则会触发通用的 EventSource.message_event 事件。

与 WebSocket 不同，服务器发送事件是单向的；也就是说，数据消息只会从服务器传送到客户端（例如用户的 Web 浏览器）。当无需以消息形式从客户端向服务器发送数据时，服务器发送事件是很好的选择。例如，EventSource 适合处理社交媒体状态更新、新闻源，或将数据传入客户端存储机制，例如 IndexedDB 或 Web Storage。

警告：在未使用 HTTP/2 时，SSE 可同时打开的连接数存在上限；如果打开多个标签页，这个限制尤其明显，因为上限按每个浏览器计算，而且数值很低（6 个）。Chrome 和 Firefox 均已将此问题标记为“不会修复”。该限制按浏览器和域名分别计算，因此你可以在所有标签页中连接到 www.example1.com 的 SSE 连接最多为 6 个，同时连接到 www.example2.com 的 SSE 连接也最多为 6 个。（来源：Stack Overflow。）使用 HTTP/2 时，客户端与服务器会协商可同时使用的 HTTP 流最大数量（默认值为 100）。
