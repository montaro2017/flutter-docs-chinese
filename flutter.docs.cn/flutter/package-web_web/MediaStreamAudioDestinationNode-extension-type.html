MediaStreamAudioDestinationNode

MediaStreamAudioDestinationNode extension type

MediaStreamAudioDestinationNode 接口表示一个音频目标，它由包含单个 AudioMediaStreamTrack 的 WebRTC MediaStream 组成，其用法类似于通过 MediaDevices.getUserMedia 获取的 MediaStream。

它是一个充当音频目标的 AudioNode，通过 AudioContext.createMediaStreamDestination 方法创建。

Number of inputs 1
Number of outputs 0
Channel count 2
Channel count mode "explicit"
Channel count interpretation "speakers"

API 文档来源：MDN Web Docs。
