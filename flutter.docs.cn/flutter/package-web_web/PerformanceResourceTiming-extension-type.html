PerformanceResourceTiming

PerformanceResourceTiming extension type

PerformanceResourceTiming 接口支持获取和分析应用资源加载的详细网络计时数据。应用可以利用这些计时指标确定获取特定资源（例如 XMLHttpRequest、图像或脚本）所需的时间。

API 文档内容来自 MDN Web 文档。

connectEnd → double
connectEnd 只读属性返回 DOMHighResTimeStamp 时间戳，表示浏览器完成与服务器建立资源连接的时刻。该时间戳包括建立传输连接所用时间，以及 TLS 握手、SOCKS 身份验证等其他时间间隔。
无设置器
connectStart → double
connectStart 只读属性返回 DOMHighResTimeStamp 时间戳，表示用户代理开始与服务器建立资源连接之前的时刻。
无设置器
decodedBodySize → int
decodedBodySize 只读属性返回通过 fetch（HTTP 或缓存）获取的消息正文大小（以八位字节计），并已移除应用的内容编码（如 gzip 或 Brotli）。如果资源来自应用缓存或本地资源，则返回移除内容编码后的负载大小。
无设置器
domainLookupEnd → double
domainLookupEnd 只读属性返回 DOMHighResTimeStamp 时间戳，表示浏览器完成该资源的域名查找之后的时刻。
无设置器

无设置器

encodedBodySize 只读属性表示通过 fetch（HTTP 或缓存）获取的负载正文大小（以八位字节计），尚未移除任何内容编码（如 gzip 或 Brotli）。如果资源来自应用缓存或本地资源，则返回移除内容编码前的负载正文大小。
无设置器

secureConnectionStart 只读属性返回一个 DOMHighResTimeStamp 时间戳，记录浏览器开始为当前连接建立安全连接握手之前的时刻。如果不使用安全连接，该属性返回 0。
无设置器
serverTiming → JSArray<PerformanceServerTiming>
serverTiming 只读属性返回一个数组，其中包含 PerformanceServerTiming 条目，即服务器计时指标。
无设置器
startTime → double
只读属性 startTime 返回该条目首次记录的时间。其含义取决于该条目的 PerformanceEntry.entryType 值。
无设置器继承
transferSize → int
transferSize 只读属性表示获取资源的大小（以八位字节计），包括响应头字段和响应负载正文（定义见 RFC7230）。
无设置器
workerStart → double
workerStart 是 PerformanceResourceTiming 接口的只读属性，返回一个 DOMHighResTimeStamp 时间戳：如果 Service Worker 线程已在运行，则记录分发 FetchEvent 之前的时刻；否则记录启动 Service Worker 线程之前的时刻。如果 Service Worker 未拦截该资源，则该属性始终返回 0。
无设置器
