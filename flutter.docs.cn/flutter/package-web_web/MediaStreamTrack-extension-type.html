MediaStreamTrack

MediaStreamTrack extension type

MediaStreamTrack 接口属于 Media Capture and Streams API，表示流中的一条媒体轨道；通常是音频或视频轨道，也可能存在其他类型的轨道。

某些用户代理会继承此接口，以提供更精确的信息或功能，例如 CanvasCaptureMediaStreamTrack。

API 文档来源：MDN Web Docs。
