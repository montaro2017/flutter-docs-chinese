naturalWidth 属性

int get naturalWidth

HTMLImageElement 接口的只读 naturalWidth 属性返回图像经过密度校正后的固有（自然）宽度，单位为 CSS 像素。

这是图像在宽度不受任何限制时的宽度。如果既未指定图像宽度，也未将图像放入会限制或明确指定其宽度的容器中，该值就是图像的 CSS 像素宽度。

对应的 HTMLImageElement.naturalHeight 属性会返回图像的自然高度。

注意：大多数情况下，自然宽度就是服务器发送的图像实际宽度。不过，浏览器可能会在将图像交给渲染器之前对其进行修改。例如，Chrome 会降低低端设备上图像的分辨率。在这种情况下，naturalWidth 会将浏览器干预后修改图像的宽度视为自然宽度，并返回该值。
