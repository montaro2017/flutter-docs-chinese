Document

Document extension type

Document 接口表示浏览器中加载的任意网页，并作为访问网页内容（即 DOM 树）的入口。

DOM 树包含 body、table 等元素，以及许多其他元素。它还提供文档级功能，例如获取网页 URL 和在文档中创建新元素。

Document 接口描述了各类文档共有的属性和方法。根据文档类型（例如 HTML、XML、SVG 等），还可以使用更丰富的 API：以 "text/html" 内容类型提供的 HTML 文档也实现了 HTMLDocument 接口，而 XML 和 SVG 文档则实现 XMLDocument 接口。

API 文档来源：MDN Web Docs。

write(JSAny text) → void

警告：强烈不建议使用 document.write() 方法。

正如 HTML 规范本身所警告的那样：

此方法的行为非常特殊。在某些情况下，此方法可能会影响

HTML 解析器运行时的状态，从而导致 DOM 与文档源内容不对应（例如，写入的字符串为“<plaintext>”或“<!--”）。在其他情况下，调用会先清空当前页面，就像调用了document.open()一样。还有一些情况下，此方法会被忽略或抛出异常。用户代理被明确允许不执行通过此方法插入的 script 元素。更糟的是，此方法的确切行为有时取决于网络延迟，可能导致很难调试的故障。基于以上原因，强烈不建议使用此方法。

因此，应避免使用 document.write()；如果可能，也应更新仍在使用它的现有代码。
