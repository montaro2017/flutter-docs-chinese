XMLDocument

XMLDocument extension type

XMLDocument 接口表示 XML 文档。它继承通用的 Document，且未添加任何专属方法或属性；不过，若干算法对这两种文档类型的处理方式有所不同。

API 文档内容来源于 MDN Web Docs。

on
  • JSObject
实现的类型
  • Document
  • JSObject
Available extensions
  • DocumentCustomEvents
  • JSAnyOperatorExtension
  • JSAnyUtilityExtension
  • JSObjectUnsafeUtilExtension
  • NodeGlue
  • NullableUndefineableJSAnyExtension

警告：强烈不建议使用 document.write() 方法。

正如 HTML 规范本身所警告的那样：

此方法的行为非常特殊。在某些情况下，此方法可能会影响

HTML 解析器运行时的状态，从而导致 DOM 与文档源内容不对应（例如，写入的字符串为“<plaintext>”或“<!--”）。在其他情况下，调用会先清空当前页面，就像调用了document.open()一样。还有一些情况下，此方法会被忽略或抛出异常。用户代理被明确允许不执行通过此方法插入的 script 元素。更糟的是，此方法的确切行为有时取决于网络延迟，可能导致很难调试的故障。基于以上原因，强烈不建议使用此方法。

因此，应避免使用 document.write()；如果可能，也应更新仍在使用它的现有代码。
