OfflineAudioContext

OfflineAudioContext extension type

OfflineAudioContext 接口属于 AudioContext 接口，表示由多个互相连接的 AudioNode 构成的音频处理图。与标准 AudioContext 不同，OfflineAudioContext 不会将音频渲染到设备硬件，而是尽可能快速地生成音频，并将结果输出到 AudioBuffer。

API 文档来源：MDN Web Docs。
