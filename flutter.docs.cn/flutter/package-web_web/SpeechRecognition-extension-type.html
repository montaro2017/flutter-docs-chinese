SpeechRecognition

SpeechRecognition extension type

Web Speech API 中的 SpeechRecognition 接口是识别服务的控制接口；它还负责处理识别服务发送的 SpeechRecognitionEvent。

注意：在 Chrome 等某些浏览器中，网页上的语音识别会使用基于服务器的识别引擎。音频会发送到 Web 服务进行识别处理，因此离线时无法使用。

API 文档来源：MDN Web 文档。
