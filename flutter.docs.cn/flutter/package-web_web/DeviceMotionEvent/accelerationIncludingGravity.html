accelerationIncludingGravity 属性

DeviceMotionEventAcceleration? get accelerationIncludingGravity

DeviceMotionEvent 接口的只读 accelerationIncludingGravity 属性会返回设备记录的加速度，单位为米每二次方秒（m/s²）。与会补偿重力影响的 DeviceMotionEvent.acceleration 不同，该值是用户引起的设备加速度与大小相等、方向相反的重力加速度之和。换句话说，它测量的是 比力。实际上，该值表示加速度计测得的原始数据。

此值通常不如 DeviceMotionEvent.acceleration 有用，但对于无法从加速度数据中去除重力的设备（例如没有陀螺仪的设备），它可能是唯一可用的值。

注意：accelerationIncludingGravity 这个名称可能会造成误解。该属性表示包含重力影响的加速度。例如，设备平放在水平表面且屏幕朝上时，Z 轴上的重力为 -9.8，acceleration.z 为 0，而 accelerationIncludingGravity.z 为 9.8。类似地，设备自由下落且屏幕水平朝上时，Z 轴上的重力为 -9.8，acceleration.z 为 -9.8，而 accelerationIncludingGravity.z 为 0。
