AudioTimestamp getOutputTimestamp()

AudioContext 接口的 getOutputTimestamp() 方法会返回一个新的 AudioTimestamp 对象，其中包含两个与当前音频上下文相关的音频时间戳值。

这两个值如下：

  • AudioTimestamp.contextTime：音频输出设备当前正在渲染的采样帧时间（即输出音频流的位置），其单位和起点与上下文的 BaseAudioContext.currentTime 相同。简单来说，它表示自音频上下文创建以来经过的时间。
  • AudioTimestamp.performanceTime：估算存储的 contextTime 所对应的采样帧由音频输出设备渲染的时刻。该时间使用与 performance.now 相同的单位和起点，表示自包含此音频上下文的文档首次渲染以来经过的时间。
