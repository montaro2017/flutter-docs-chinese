createMediaStreamDestination 方法

MediaStreamAudioDestinationNode createMediaStreamDestination()

AudioContext 接口的 createMediaStreamDestination() 方法会创建新的 MediaStreamAudioDestinationNode 对象，并将其关联到表示音频流的 MediaStream。该流属于 WebRTC，可以存储在本地文件中，也可以发送到另一台计算机。

创建节点时会同时创建 MediaStream，可通过 MediaStreamAudioDestinationNode 的 stream 属性访问。此流的用法类似于通过 navigator.getUserMedia 获取的 MediaStream，例如可以使用 RTCPeerConnection 的 addStream() 方法将其发送给远端对等端。

有关媒体流目标节点的更多详情，请参阅 MediaStreamAudioDestinationNode 参考页面。
