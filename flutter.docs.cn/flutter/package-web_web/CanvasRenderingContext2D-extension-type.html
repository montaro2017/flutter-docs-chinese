CanvasRenderingContext2D

CanvasRenderingContext2D extension type

CanvasRenderingContext2D 接口属于 Canvas API，为 canvas 元素的绘图表面提供 2D 渲染上下文。它用于绘制形状、文本、图像及其他对象。

此页面的参考部分介绍了该接口的属性和方法。Canvas 教程还提供了更多说明、示例和资源。

对于 OffscreenCanvas，也有一个提供渲染上下文的对应接口。离屏渲染上下文继承了 CanvasRenderingContext2D 的大多数属性和方法，详情请参阅 OffscreenCanvasRenderingContext2D 参考页面。

API 文档内容来源于 MDN Web 文档。
