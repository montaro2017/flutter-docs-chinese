reset 方法

void reset()

HTMLFormElement.reset() 方法会将表单元素恢复为默认值。此方法的效果与点击表单的 <input type="reset"> 控件相同。

如果表单控件（例如重置按钮）的名称或 id 为 reset，它会遮蔽表单的 reset 方法。该方法不会重置输入控件的其他属性，例如 disabled。

请注意，如果调用 Element.setAttribute 设置某个属性的值，之后调用 reset() 不会将该属性恢复为默认值，而会保留 Element.setAttribute 设置的值。
