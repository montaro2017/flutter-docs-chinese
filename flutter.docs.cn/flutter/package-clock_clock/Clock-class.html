Clock

Clock 类

“当前时间”及相对于当前时间的时间点提供器。

此类在设计时考虑了可测试性。当前时间点（即 now()）由一个返回 DateTime 的函数定义。提供自定义时间函数或使用 Clock.fixed，即可控制 Clock 返回的确切时间，并据此设置测试预期。

大多数用户应使用顶层 clock 字段来访问默认的 Clock 实现；该实现可通过 withClock 覆盖。
