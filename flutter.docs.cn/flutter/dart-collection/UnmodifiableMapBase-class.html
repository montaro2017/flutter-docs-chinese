UnmodifiableMapBase

UnmodifiableMapBase<K, V> 类 抽象

不可修改 Map 的基本实现。

此类为不可修改 Map 的所有成员提供基本实现，但有两个成员除外。只需扩展此类并实现 keys 和 operator[]，即可实现一个简单的不可修改 Map 类。

调用修改操作时会抛出异常。其余非修改操作都基于 keys 和 operator[] 实现。

keys 可迭代对象应提供高效的 Iterable.length 和 Iterable.contains 操作，并且在迭代时应能检测键集合是否被并发修改。

通常也可以通过重写其他部分成员来实现更高效的版本。
