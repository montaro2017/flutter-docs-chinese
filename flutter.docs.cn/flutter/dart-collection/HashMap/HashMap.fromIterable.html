创建一个 HashMap，其键和值由 iterable 计算得出。

此构造函数会对 iterable 中的每个元素分别应用 key 和 value，以计算出键值对。

键值对中的键不必唯一。同一个键最后一次出现时，会覆盖之前的值。

如果未指定 key 和 value，则默认使用恒等函数。示例：

final numbers = [11, 12, 13, 14];
final mapFromIterable = HashMap<int, int>.fromIterable(numbers,
    key: (i) => i, value: (i) => i * i);
print(mapFromIterable); // {11: 121, 12: 144, 13: 169, 14: 196}

实现

factory HashMap.fromIterable(
  Iterable iterable, {
  K Function(dynamic element)? key,
  V Function(dynamic element)? value,
}) {
  HashMap<K, V> map = HashMap<K, V>();
  MapBase._fillMapWithMappedIterable(map, iterable, key, value);
  return map;
}
