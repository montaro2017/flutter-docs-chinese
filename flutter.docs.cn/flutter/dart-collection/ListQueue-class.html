ListQueue

ListQueue<E> 类 final

基于列表实现的 Queue。

此队列使用循环缓冲区保存元素，并会在缓冲区填满时扩展为更大的缓冲区。因此，查看队首元素和移除元素可保证为常数时间，添加操作的摊销时间为常数。

无论用作队列还是栈，此结构都很高效。

示例：

final queue = ListQueue<int>();

要向队列添加对象，请使用 add、addAll、addFirst 或 addLast。

queue.add(5);
queue.addFirst(0);
queue.addLast(10);
queue.addAll([1, 2, 3]);
print(queue); // {0, 5, 10, 1, 2, 3}

要检查队列是否为空，请使用 isEmpty 或 isNotEmpty。要获取队列条目数，请使用 length。

final isEmpty = queue.isEmpty; // false
final queueSize = queue.length; // 6

要获取队列的首项或末项，请使用 first 或 last。

final first = queue.first; // 0
final last = queue.last; // 3

要按索引获取条目值，请使用 elementAt。

final itemAt = queue.elementAt(2); // 10

要将队列转换为列表，请调用 toList。

final numbers = queue.toList();
print(numbers); // [0, 5, 10, 1, 2, 3]

要从队列中移除条目，请调用 remove、removeFirst 或 removeLast。

queue.remove(10);
queue.removeFirst();
queue.removeLast();
print(queue); // {5, 1, 2}

要一次移除多个元素，请使用 removeWhere。

queue.removeWhere((element) => element == 1);
print(queue); // {5, 2}

要移除队列中所有不符合条件的元素，请使用 retainWhere。

queue.retainWhere((element) => element < 4);
print(queue); // {2}

要移除所有条目并清空队列，请使用 clear。

queue.clear();
print(queue.isEmpty); // true
print(queue); // {}
