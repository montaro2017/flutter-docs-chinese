HashMap

HashMap<K, V> 类 抽象 final

基于哈希表实现的 Map。

HashMap 无序（不保证迭代顺序）。

HashMap 的键必须具有一致的 Object.== 和 Object.hashCode 实现。这意味着 == 运算符必须在键上定义稳定的等价关系（自反、对称、传递且随时间保持一致），并且 hashCode 在被 == 判定为相等的对象之间必须相同。

通过 forEach 遍历映射的键、值或条目时，顺序可能任意。只有在映射被修改时，迭代顺序才会改变。值的迭代顺序与对应键相同，因此并行迭代 keys 和 values 会得到匹配的键值对。

注意：在对映射执行操作期间（例如在 forEach 或 putIfAbsent 调用期间执行的函数中），或迭代映射的 keys、values 或 entries 时，不要修改映射（添加或移除键）。更改现有键的值（例如使用 operator[]= 或 update）不会改变映射结构，也不会中断迭代。

键位于映射中时，不要以会改变其相等性（从而改变哈希码）的方式修改它们。如果某个映射键的 Object.hashCode 发生变化，之后查找该键可能会失败。

示例：

final Map<int, String> planets = HashMap(); // Is a HashMap

要向映射添加数据，请使用 operator[]=、addAll 或 addEntries。

planets[3] = 'Earth';
planets.addAll({4: 'Mars'});
final gasGiants = {6: 'Jupiter', 5: 'Saturn'};
planets.addEntries(gasGiants.entries);
print(planets); // fx {5: Saturn, 6: Jupiter, 3: Earth, 4: Mars}

要检查映射是否为空，请使用 isEmpty 或 isNotEmpty。要查找映射条目数，请使用 length。

final isEmpty = planets.isEmpty; // false
final length = planets.length; // 4

forEach 会遍历映射中的所有条目。

planets.forEach((key, value) {
  print('$key \t $value');
  // 5        Saturn
  // 4        Mars
  // 3        Earth
  // 6        Jupiter
});

要检查映射是否包含特定键的条目，请使用 containsKey。

final keyOneExists = planets.containsKey(4); // true
final keyFiveExists = planets.containsKey(1); // false

要检查映射是否包含特定值的条目，请使用 containsValue。

final marsExists = planets.containsValue('Mars'); // true
final venusExists = planets.containsValue('Venus'); // false

要移除具有特定键的条目，请使用 remove。

final removeValue = planets.remove(6);
print(removeValue); // Jupiter
print(planets); // fx {4: Mars, 3: Earth, 5: Saturn}

要根据键和值同时移除多个条目，请使用 removeWhere。

planets.removeWhere((key, value) => key == 5);
print(planets); // fx {3: Earth, 4: Mars}

要根据特定键是否已有条目，有条件地添加或修改其值，请使用 putIfAbsent 或 update。

planets.update(4, (v) => 'Saturn');
planets.update(8, (v) => '', ifAbsent: () => 'Neptune');
planets.putIfAbsent(4, () => 'Another Saturn');
print(planets); // fx {4: Saturn, 8: Neptune, 3: Earth}

要根据现有键和值更新所有键对应的值，请使用 updateAll。

planets.updateAll((key, value) => 'X');
print(planets); // fx {8: X, 3: X, 4: X}

要移除所有条目并清空映射，请使用 clear。

planets.clear();
print(planets); // {}
print(planets.isEmpty); // true
