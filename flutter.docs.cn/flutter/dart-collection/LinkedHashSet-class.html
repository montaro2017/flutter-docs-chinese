LinkedHashSet

LinkedHashSet<E> 类 抽象 final

LinkedHashSet 是一种基于哈希表实现的 Set。

Set 的默认实现是 LinkedHashSet。

LinkedHashSet 还会记录元素的插入顺序，迭代时按从最早插入到最新插入的顺序进行。

LinkedHashSet 中的元素必须具有一致的 Object.== 和 Object.hashCode 实现。这意味着 == 运算符必须在元素上定义稳定的等价关系（自反、对称、传递且随时间保持一致），并且 hashCode 对由 == 判定为相等的对象必须相同。

元素按插入顺序迭代。后添加的元素会在迭代中靠后出现。再次添加集合中已有的元素不会改变它在迭代顺序中的位置；但移除某个元素后再重新添加，它会成为迭代中的最后一个元素。

只要对象的哈希码分布良好，HashSet 上的大多数简单操作都可在（可能摊销的）常数时间内完成：add、contains、remove 和 length。

注意：对集合执行操作期间不要修改集合（添加或移除元素）。例如，在 forEach 或 containsAll 调用期间执行的函数中，或迭代集合时，都不要修改集合。

当元素位于集合中时，不要以会改变其相等性（从而改变其哈希码）的方式修改元素。某些专用集合可能允许更宽松的相等性规则；此时应在文档中说明其不同的行为和限制。

示例：

final planets = <String>{}; // LinkedHashSet

要向集合添加数据，请使用 add 或 addAll。

final uranusAdded = planets.add('Uranus'); // true
planets.addAll({'Venus', 'Mars', 'Earth', 'Jupiter'});
print(planets); // {Uranus, Venus, Mars, Earth, Jupiter}

要检查集合是否为空，请使用 isEmpty 或 isNotEmpty。要获取集合中元素的数量，请使用 length。

print(planets.isEmpty); // false
print(planets.length); // 5

要检查集合是否包含某个特定值，请使用 contains。

final marsExists = planets.contains('Mars'); // true

forEach 方法会对集合中的每个元素调用一个函数。

planets.forEach(print);
// Uranus
// Venus
// Mars
// Earth
// Jupiter

要复制集合，请使用 toSet。

final copySet = planets.toSet();
print(copySet); // {Uranus, Venus, Mars, Earth, Jupiter}

要移除一个元素，请使用 remove。

final removedValue = planets.remove('Mars'); // Mars
print(planets); // {Uranus, Venus, Earth, Jupiter}

要一次移除多个元素，请使用 removeWhere 或 removeAll。

planets.removeWhere((element) => element.startsWith('E'));
print(planets); // {Uranus, Venus, Jupiter}

要移除集合中所有不符合条件的元素，请使用 retainWhere。

planets.retainWhere((element) => element.contains('Jupiter'));
print(planets); // {Jupiter}
```dart continued
