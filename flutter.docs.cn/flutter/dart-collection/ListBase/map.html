重写

此可迭代对象的当前元素经过 toElement 转换后的结果。

返回一个新的惰性 Iterable，其中的元素由按迭代顺序对该 Iterable 中的每个元素调用 toElement 创建。

返回的可迭代对象采用惰性求值，因此在实际迭代它之前，不会遍历此可迭代对象；开始迭代后，它会逐个调用 toElement 来创建元素。转换后的元素不会被缓存。多次迭代返回的 Iterable 时，每次迭代都会对每个元素调用一次提供的 toElement 函数。

返回的可迭代对象上的方法可以省略对某些元素调用 toElement，前提是无需这些元素的结果。例如，elementAt 可能只调用一次 toElement。

等价于：

Iterable<T> map<T>(T toElement(E e)) sync* {
  for (var value in this) {
    yield toElement(value);
  }
}

示例：

var products = jsonDecode('''
[
  {"name": "Screwdriver", "price": 42.00},
  {"name": "Wingnut", "price": 0.50}
]
''');
var values = products.map((product) => product['price'] as double);
var totalPrice = values.fold(0.0, (a, b) => a + b); // 42.5.

实现

Iterable<T> map<T>(T f(E element)) => MappedListIterable<E, T>(this, f);
