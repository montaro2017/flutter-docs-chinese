使用给定的 equals 和 hashCode 创建一个按插入顺序排列的哈希集合。

提供的 equals 必须定义稳定的等价关系，且 hashCode 必须与 equals 保持一致。

如果提供了 equals 和 hashCode 中的一个，通常也应提供另一个。

某些 equals 或 hashCode 函数可能不适用于所有对象。如果提供了 isValidKey，它会检查候选元素是否有效；该元素不一定是 E 的实例，例如 contains 的参数，其类型为 Object?。如果对某个对象调用 isValidKey 返回 false，就不会调用 equals 和 hashCode 函数，也不会假定集合中存在与该对象相等的键。默认的 isValidKey 仅检查对象是否为 E 的实例，这意味着：

LinkedHashSet<int>(equals: (int e1, int e2) => (e1 - e2) % 5 == 0,
                   hashCode: (int e) => e % 5);

无需传入 isValidKey 参数，因为默认实现只接受 int 值，而这些值可同时用于 equals 和 hashCode。

如果未提供 equals、hashCode 或 isValidKey，则默认的 isValidKey 会接受所有值。默认的相等性和哈希码操作被认为适用于所有对象。

同样，如果 equals 为 identical、hashCode 为 identityHashCode，并且省略了 isValidKey，则生成的集合将基于对象标识；此时 isValidKey 默认接受所有键。也可以直接使用 LinkedHashSet.identity 创建此类集合。
