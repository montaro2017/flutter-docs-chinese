ListBase

ListBase<E> 类 抽象 mixin

列表的抽象实现。

ListBase 可用作实现 List 接口的基类。

此类仅通过 length 和 operator[] 成员实现所有读取操作。它通过这些成员以及 add、length= 和 operator[]= 实现写入操作。使用此基类的类应实现这五项操作。

注意：出于向后兼容的原因，add 有一个默认实现，但它只适用于元素类型可为空的列表。对于元素类型不可为空的列表，必须实现 add 方法。

注意：如果只将四项 length 和 [] 读写操作转发给普通的可增长 List（例如由 [] 字面量创建的列表），那么 add 和 addAll 操作在 ListBase 中的性能会很差。这些操作每次执行 add 都会将列表长度增加一；反复增加可增长列表的长度效率不高。为避免此问题，请重写 add 和 addAll，使其也直接转发给可增长列表；或者在可行时，使用 package:collection/collection.dart 中的 DelegatingList，而不是 ListMixin。
