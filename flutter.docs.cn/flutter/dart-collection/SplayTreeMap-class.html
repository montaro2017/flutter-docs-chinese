SplayTreeMap

SplayTreeMap<K, V> 类 final

一种由可相互比较排序的对象组成的 Map。

此映射基于自平衡二叉树。大多数单条目操作的摊销时间复杂度为对数级。

映射的键在排序和判等时都使用构造函数传入的 compare 函数进行比较。如果映射中只有键 a，那么当且仅当 compare(a, b) == 0 时，map.containsKey(b) 才会返回 true，并且不会检查 a == b。如果省略 compare 函数，则假定对象实现了 Comparable，并使用其 Comparable.compareTo 方法进行比较。在这种情况下，不可比较的对象（包括 null）不能用作键。

若要允许使用不受 compare 函数支持的对象调用 operator []、remove 或 containsKey，可以额外提供一个 isValidKey 谓词函数。对于可能不是 K 类型的参数值，会先调用此函数进行检查，再使用 compare 函数。如果省略 isValidKey 函数，则默认通过检查该值是否为 K 类型来判定。

注意：当映射正在执行某项操作时（例如在 forEach 或 putIfAbsent 调用期间执行的函数中），或正在遍历映射（keys、values 或 entries）时，不要修改映射（添加或移除键）。

示例：

final planetsByMass = SplayTreeMap<double, String>((a, b) => a.compareTo(b));

向映射添加数据时，请使用 operator[]=、addAll 或 addEntries。

planetsByMass[0.06] = 'Mercury';
planetsByMass
    .addAll({0.81: 'Venus', 1.0: 'Earth', 0.11: 'Mars', 317.83: 'Jupiter'});

若要检查映射是否为空，请使用 isEmpty 或 isNotEmpty。若要查找映射条目的数量，请使用 length。

print(planetsByMass.isEmpty); // false
print(planetsByMass.length); // 5

forEach 方法会对映射中的每个键值条目调用一个函数。

planetsByMass.forEach((key, value) {
  print('$key \t $value');
  // 0.06    Mercury
  // 0.11    Mars
  // 0.81    Venus
  // 1.0     Earth
  // 317.83  Jupiter
});

若要检查映射是否包含特定键对应的条目，请使用 containsKey。

final keyOneExists = planetsByMass.containsKey(1.0); // true
final keyFiveExists = planetsByMass.containsKey(5); // false

若要检查映射是否包含特定值对应的条目，请使用 containsValue。

final earthExists = planetsByMass.containsValue('Earth'); // true
final plutoExists = planetsByMass.containsValue('Pluto'); // false

若要移除特定键对应的条目，请使用 remove。

final removedValue = planetsByMass.remove(1.0);
print(removedValue); // Earth

若要根据键和值同时移除多个条目，请使用 removeWhere。

planetsByMass.removeWhere((key, value) => key <= 1);
print(planetsByMass); // {317.83: Jupiter}

若要根据特定键是否已有条目，有条件地添加或修改其值，请使用 putIfAbsent 或 update。

planetsByMass.update(1, (v) => '', ifAbsent: () => 'Earth');
planetsByMass.putIfAbsent(317.83, () => 'Another Jupiter');
print(planetsByMass); // {1.0: Earth, 317.83: Jupiter}

若要根据现有键和值更新所有键对应的值，请使用 updateAll。

planetsByMass.updateAll((key, value) => 'X');
print(planetsByMass); // {1.0: X, 317.83: X}

若要移除所有条目并清空映射，请使用 clear。

planetsByMass.clear();
print(planetsByMass.isEmpty); // false
print(planetsByMass); // {}
