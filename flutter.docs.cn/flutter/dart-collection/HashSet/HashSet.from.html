HashSet<E>.from 构造函数

HashSet<E>.from(
  1. Iterable elements
)

创建一个包含所有 elements 的哈希集合。

此构造函数会像 HashSet<E>() 一样创建哈希集合，并将给定的所有 elements 按顺序添加到集合中。如果 elements 中有两个相等但不完全相同的条目，则结果集合会保留第一个。

所有 elements 都应是 E 的实例。elements 这个 iterable 本身可以具有任意元素类型，因此此构造函数可用于向下转型 Set，例如：

Set<SuperType> superSet = ...;
Set<SubType> subSet =
    HashSet<SubType>.from(superSet.whereType<SubType>());

示例：

final numbers = <num>[10, 20, 30];
final hashSetFrom = HashSet<int>.from(numbers);
print(hashSetFrom); // fx {20, 10, 30}

实现

factory HashSet.from(Iterable<dynamic> elements) {
  HashSet<E> result = HashSet<E>();
  for (final e in elements) {
    result.add(e as E);
  }
  return result;
}
