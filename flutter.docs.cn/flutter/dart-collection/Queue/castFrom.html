Queue<T> castFrom<S, T>(
  1. Queue<S> source
)
重写

将 source 适配为 Queue<T>。

每当队列要生成非 T 类型的元素时，访问该元素就会抛出异常。

向适配后的队列存入 T 类型的值时，如果该值不是 S 的实例，则操作会抛出异常。

如果从 source 访问的所有元素实际上都是 T 的实例，并且存入返回队列的所有元素实际上都是 S 的实例，那么返回的队列就可以作为 Queue<T> 使用。

接受 Object? 作为参数的方法，例如 contains 和 remove，会将参数直接传递给此队列的方法，不做任何检查。

实现

static Queue<T> castFrom<S, T>(Queue<S> source) => CastQueue<S, T>(source);
