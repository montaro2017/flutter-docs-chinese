cast<R> 方法

List<R> cast<R>()
重写

返回此列表的一个视图，将其视为包含 R 类型实例的列表。

如果此列表只包含 R 的实例，则所有读取操作都能正常工作。如果某项操作尝试读取非 R 实例的元素，则会抛出异常。

添加到列表中的元素（例如通过 add 或 addAll 添加）必须是 R 的实例，才能作为添加函数的有效参数；它们也必须是 E 的实例，才能被此列表接受。

接受 Object? 作为参数的方法，例如 contains 和 remove，会将参数直接传递给此列表的方法，不做任何检查。因此，即使看起来不会产生效果，也可以成功执行 listOfStrings.cast<int>().remove("a")。

通常实现为 List.castFrom<E, R>(this)。

实现

List<R> cast<R>() => UnmodifiableListView(_source.cast<R>());
