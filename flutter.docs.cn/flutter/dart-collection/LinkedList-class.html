LinkedList

LinkedList<E extends LinkedListEntry<E>> 类 base

一种专用的双向链表，其中元素扩展自 LinkedListEntry。

这不是通用数据结构，只接受扩展自 LinkedListEntry 的元素。对于允许在两端以常数时间添加和移除元素的泛型集合，请参阅 Queue 的实现。

这不是 List 的实现。尽管名称中有 List，此类并未实现 List 接口，也不支持按索引进行常数时间查找。

由于元素本身包含此链表的链接，每个元素同一时间只能属于一个链表。要将元素添加到另一个链表，必须先将它从当前链表（如果有）移除。出于同样的原因，remove 和 contains 方法基于对象标识进行判断，即使 LinkedListEntry 选择重写了 Object.== 也一样。

作为交换，每个元素都知道自己在链表中的位置以及所属链表。因此，只要持有该元素，就能以常数时间执行 LinkedListEntry.insertAfter、LinkedListEntry.insertBefore 和 LinkedListEntry.unlink 操作。

LinkedList 还支持在任一端以常数时间添加和移除元素，并提供常数时间的 length getter。

示例：

final class EntryItem extends LinkedListEntry<EntryItem> {
  final int id;
  final String text;
  EntryItem(this.id, this.text);

  @override
  String toString() {
    return '$id : $text';
  }
}

void main() {
  final linkedList = LinkedList<EntryItem>();
  linkedList
      .addAll([EntryItem(1, 'A'), EntryItem(2, 'B'), EntryItem(3, 'C')]);
  print(linkedList.first); // 1 : A
  print(linkedList.last); // 3 : C

  // Add new item after first item.
  linkedList.first.insertAfter(EntryItem(15, 'E'));
  // Add new item before last item.
  linkedList.last.insertBefore(EntryItem(10, 'D'));
  // Iterate items.
  for (var entry in linkedList) {
    print(entry);
    // 1 : A
    // 15 : E
    // 2 : B
    // 10 : D
    // 3 : C
  }

  // Remove item using index from list.
  linkedList.elementAt(2).unlink();
  print(linkedList); // (1 : A, 15 : E, 10 : D, 3 : C)
  // Remove first item.
  linkedList.first.unlink();
  print(linkedList); // (15 : E, 10 : D, 3 : C)
  // Remove last item from list.
  linkedList.remove(linkedList.last);
  print(linkedList); // (15 : E, 10 : D)
  // Remove all items.
  linkedList.clear();
  print(linkedList.length); // 0
  print(linkedList.isEmpty); // true
}
