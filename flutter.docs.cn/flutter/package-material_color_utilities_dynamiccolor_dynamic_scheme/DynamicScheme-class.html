DynamicScheme

DynamicScheme 类

由一组表示当前界面状态的值构造（例如是否使用深色主题、主题样式等），并提供一组 TonalPalette，用于生成符合主题样式的颜色。DynamicColor 使用它来解析出具体颜色。
