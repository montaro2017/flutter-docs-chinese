构造函数

Vector4List(int length, [int offset = 0, int stride = 0])
创建一个包含 length 个元素的新向量列表。还可以指定偏移量 offset（位于 buffer 中），以及向量之间的 stride。
Vector4List.fromList(List<Vector4> list, [int offset = 0, int stride = 0])
根据向量列表创建新的向量列表。还可以指定偏移量 offset（位于 buffer 中），以及向量之间的 stride。
Vector4List.view(Float32List buffer, [int offset = 0, int stride = 0])
创建一个新的向量列表，将其作为 buffer 的视图。还可以指定偏移量 offset（位于 buffer 中），以及向量之间的 stride。
