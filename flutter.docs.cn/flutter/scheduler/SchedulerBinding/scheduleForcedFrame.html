scheduleForcedFrame 方法

void scheduleForcedFrame()

通过调用 dart:ui.PlatformDispatcher.scheduleFrame 安排新帧。

调用后，即使通常情况下 scheduleFrame 不会安排帧（例如设备屏幕已关闭），引擎仍会调用 handleBeginFrame。

框架使用此方法，在手机旋转时强制渲染一帧，以便屏幕重新亮起时已有尺寸正确的渲染结果。

若要在此函数每次安排帧时都将堆栈跟踪打印到控制台，请将 debugPrintScheduleFrameStacks 设为 true。

除非必须立即安排帧，否则优先使用 scheduleFrame；设备本应空闲时调用 scheduleForcedFrame 会显著增加电池消耗。

如果目的是尽快更新渲染（例如应用启动时），可以考虑改用 scheduleWarmUpFrame。

实现

void scheduleForcedFrame() {
  if (_hasScheduledFrame) {
    return;
  }
  assert(() {
    if (debugPrintScheduleFrameStacks) {
      debugPrintStack(label: 'scheduleForcedFrame() called. Current phase is $schedulerPhase.');
    }
    return true;
  }());
  ensureFrameCallbacksRegistered();
  platformDispatcher.scheduleFrame();
  _hasScheduledFrame = true;
}
