Ticker 类

启用时，每个动画帧都会调用一次其回调。

若要获取 Ticker，可考虑使用 TickerProvider。

Ticker 创建时默认处于禁用状态。调用 start 可启用它。

将 muted 设为 true 可以静默 Ticker。静默期间，时间仍会流逝，也仍可调用 start 和 stop，但不会调用任何回调。

按照惯例，Ticker 的使用者（例如 AnimationController）会调用 start 和 stop 方法；创建该 Ticker 的 TickerProvider 则控制 muted 属性。例如，使用 TickerProviderStateMixin 的 State 会在其子树根据 TickerMode 被禁用时静默 Ticker。

另请参阅：

  • TickerProvider 用于获取 ticker。
  • SchedulerBinding.scheduleFrameCallback 用于驱动 ticker。
