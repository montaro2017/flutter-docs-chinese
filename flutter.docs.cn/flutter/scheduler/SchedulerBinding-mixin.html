SchedulerBinding
description

SchedulerBinding mixin

用于运行以下回调和任务的调度器：

  • 临时回调由系统的 dart:ui.PlatformDispatcher.onBeginFrame 回调触发，用于使应用行为与系统显示同步。例如，Ticker 和 AnimationController 都由此触发。

  • 持久回调由系统的 dart:ui.PlatformDispatcher.onDrawFrame 回调触发，在临时回调执行后更新系统显示。例如，渲染层使用它来驱动渲染流水线。

  • 帧后回调在持久回调运行后、即将从 dart:ui.PlatformDispatcher.onDrawFrame 回调返回前运行。

  • 非渲染任务在帧与帧之间运行。这些任务具有优先级，并按照 schedulingStrategy 的规则按优先级顺序执行。
