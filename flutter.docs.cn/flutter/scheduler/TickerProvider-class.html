TickerProvider 类 抽象

由能够提供 Ticker 对象的类实现的接口。

若要获取 TickerProvider，可考虑在 State 子类中混入 TickerProviderStateMixin（始终适用）或 SingleTickerProviderStateMixin（适用时效率更高），使其实现 TickerProvider。随后可将该 State 传递给较底层的组件或其他相关对象。这样可以确保生成的 Ticker 只会在该 State 的子树启用时滴答，启用状态由 TickerMode 定义。

在组件测试中，WidgetTester 对象也实现了 TickerProvider。

任何希望在每次触发帧时收到通知的对象都可以使用 Ticker；不过，最常见的方式是通过 AnimationController 间接使用。AnimationController 需要借助 TickerProvider 获取 Ticker。
