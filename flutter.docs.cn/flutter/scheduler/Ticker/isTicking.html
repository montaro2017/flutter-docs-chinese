isTicking 属性

bool get isTicking

此 Ticker 是否已安排在下一帧调用其回调。

已 muted 的 Ticker 仍可处于活动状态（参见 isActive），但不会滴答。在这种情况下，Ticker 不会调用回调，isTicking 会返回 false，但时间仍会流逝。

如果 SchedulerBinding.lifecycleState 表示应用当前不可见（例如设备屏幕已关闭），此方法会返回 false。

实现

bool get isTicking {
  if (_future == null) {
    return false;
  }
  if (muted) {
    return false;
  }
  if (SchedulerBinding.instance.framesEnabled) {
    return true;
  }
  if (SchedulerBinding.instance.schedulerPhase != SchedulerPhase.idle) {
    return true;
  } // for example, we might be in a warm-up frame or forced frame
  return false;
}
