FileSpan

FileSpan 类 抽象

SourceSpan，位于某个 SourceFile 中。

与基础类 SourceSpan 不同，FileSpan 会根据偏移量和 file 的内容延迟计算行号和列号。SourceSpan.message 还能够提供比 SourceSpan.message 更多的上下文；如果可能，SourceSpan.union 会返回 FileSpan。

可以通过 SourceFile.span 创建 FileSpan。
