SourceFile

SourceFile 类

表示源文件的类。

它不一定对应磁盘上的文件，也可以是一段通常关联有 URL 的文本。

此构造函数已弃用。
SourceFile.decoded(Iterable<int> decodedChars, {Object? url})
根据解码后的代码单元列表创建新的源文件。
SourceFile.fromString(String text, {Object? url})
根据 text 创建新的源文件。
