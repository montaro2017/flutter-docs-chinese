SourceSpanWithContext 构造函数

SourceSpanWithContext(
  1. SourceLocation start,
  2. SourceLocation end,
  3. String text,
  4. String _context,
)

在给定的 context 中创建一个新的 span，范围从 start 到 end（不包含 end），并包含 text。

start 和 end 必须具有相同的源 URL，且 start 必须位于 end 之前。text 的字符数必须等于 start 与 end 之间的距离。context 必须包含 text，且 text 应从 context 中某一行的开头起，在 start.column 处开始。

实现

SourceSpanWithContext(
    SourceLocation start, SourceLocation end, String text, this._context)
    : super(start, end, text) {
  if (!context.contains(text)) {
    throw ArgumentError('The context line "$context" must contain "$text".');
  }

  if (findLineStart(context, text, start.column) == null) {
    throw ArgumentError('The span text "$text" must start at '
        'column ${start.column + 1} in a line within "$context".');
  }
}
