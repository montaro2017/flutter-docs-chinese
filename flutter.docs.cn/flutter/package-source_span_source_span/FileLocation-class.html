FileLocation

FileLocation 类

SourceLocation，位于某个 SourceFile 中。

与基础类 SourceLocation 不同，FileLocation 会根据偏移量和 file 的内容，延迟计算行号和列号。

可以通过 SourceFile.location 创建 FileLocation。
