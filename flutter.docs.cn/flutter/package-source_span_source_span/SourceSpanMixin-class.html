SourceSpanMixin

SourceSpanMixin 类 抽象

用于轻松实现 SourceSpan 的 mixin。

此 mixin 根据 start、end 和 text 实现 SourceSpan 的方法。它假定 start 和 end 具有相同的源 URL，start 位于 end 之前，并且 text 的字符数等于 start 与 end 之间的距离。
