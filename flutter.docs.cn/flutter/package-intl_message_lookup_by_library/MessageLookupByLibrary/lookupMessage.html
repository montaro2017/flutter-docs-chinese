返回消息的本地化版本。传入的是消息的原始版本，其中包含待翻译的 messageText，并且可以根据一个或多个变量进行插值。

例如，若 message="Hello, $name"，则 examples = {'name': 'Sparky'}。如果不使用用户的默认区域设置，或无法轻易检测区域设置，请显式传入 locale。

最终，外围函数及其参数的信息将由系统自动提取；目前必须通过 name 和 args 参数显式传入。

实现

String? lookupMessage(
  String? messageText,
  String? locale,
  String? name,
  List<Object>? args,
  String? meaning, {
  MessageIfAbsent? ifAbsent,
}) {
  var actualName = computeMessageName(name, messageText, meaning);
  Object? translation;
  if (actualName != null) {
    translation = this[actualName];
  }
  if (translation == null) {
    return ifAbsent == null ? messageText : ifAbsent(messageText, args);
  } else {
    args = args ?? const [];
    return evaluateMessage(translation, args);
  }
}
