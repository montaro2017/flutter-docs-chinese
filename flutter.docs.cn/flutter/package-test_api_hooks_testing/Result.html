Values

success → const Result

测试目前尚未以任何方式失败。

请注意，这并不意味着测试之后不会失败。

skipped → const Result

测试或其某个部分已被跳过。

这表示测试尚未失败。不过，这并不意味着测试之后不会失败。

failure → const Result

测试已失败。

只有抛出 TestFailure 才会导致失败；其他异常都会导致错误。

error → const Result

测试已崩溃。

除 TestFailure 之外的任何异常都视为错误。
