Locale

Locale 类 抽象

Unicode 区域标识符的表示形式。

创建 Locale 实例时，可以考虑使用以下方式：

  • fromSubtags：用于指定语言、文字和地区子标签。
  • parse：用于解析 Unicode 区域标识符字符串（失败时会抛出异常）。
  • tryParse：用于解析 Unicode 区域标识符字符串（失败时返回 null）。
