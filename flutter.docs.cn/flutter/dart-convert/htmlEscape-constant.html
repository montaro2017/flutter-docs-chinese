htmlEscape top-level constant

HtmlEscape const htmlEscape

一种将字符转换为 HTML 实体的 String 转换器。

此转换器用于在将文本插入 HTML 文档前对其进行清理。HTML 中有特殊含义的字符会转换为 HTML 实体（例如，将 & 转换为 &amp;）。

通用转换器会转义在 HTML 属性或普通元素内容中具有特殊含义的所有字符。对于 CSS 或 JavaScript 等特殊内容类型的元素，可能需要了解该内容类型的专用转义方式。

如果更清楚地知道文本将插入的上下文，就可以省略对某些字符的转义（例如，不在属性值中时可以不转义引号）。

转义后的文本只能用于带引号的 HTML 属性值内部，或普通元素的文本内容中。即使文本已转义，将它放在标签中但不位于带引号的属性值内，仍然有危险。

实现

const HtmlEscape htmlEscape = HtmlEscape();
