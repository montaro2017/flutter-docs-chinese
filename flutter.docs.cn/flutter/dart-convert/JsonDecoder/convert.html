重写

将给定的 JSON 字符串 input 转换为对应对象。

解析后的 JSON 值类型包括 num、String、bool、Null，由已解析 JSON 值组成的 List，以及从 String 映射到已解析 JSON 值的 Map。

如果初始化 this 时提供了 reviver，解析过程会对每个已解析的对象属性或列表元素调用该 reviver。参数包括属性名（String）或列表索引（int），以及已解析的值。reviver 的返回值会用作该属性的值，取代原先解析出的值。

如果输入不是有效的 JSON 文本，则抛出 FormatException。

实现

dynamic convert(String input) => _parseJson(input, _reviver);
