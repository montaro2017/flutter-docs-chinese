MemoryFileSystem

MemoryFileSystem 类 抽象

一种 FileSystem 实现，完全驻留在内存中，其内部表示大致基于文件系统层次结构标准。

MemoryFileSystem 适用于模拟和测试，也可用于在向实际系统读写之前缓存或暂存数据。

此 FileSystem 接口实现不会直接使用任何 dart:io API；它仅使用该库的枚举值和接口。因此，它也适用于浏览器。
