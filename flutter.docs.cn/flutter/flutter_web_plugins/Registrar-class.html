Registrar 类

用于以 Dart 实现的 Flutter 插件的注册器。

Web 平台插件以 Dart 实现，并在编译应用时由 flutter 工具生成的代码通过此类注册。

此类实现 BinaryMessenger，用于将框架发出的消息路由到已注册的插件。

创建平台通道时请使用此 BinaryMessenger，这样通道才能接收来自平台端的消息。例如：

class MyPlugin {
  static void registerWith(Registrar registrar) {
    final MethodChannel channel = MethodChannel(
      'com.my_plugin/my_plugin',
      const StandardMethodCodec(),
      registrar, // the registrar is used as the BinaryMessenger
    );
    final MyPlugin instance = MyPlugin();
    channel.setMethodCallHandler(instance.handleMethodCall);
  }

  Future<dynamic> handleMethodCall(MethodCall call) async {
    // ...
  }

  // ...
}
