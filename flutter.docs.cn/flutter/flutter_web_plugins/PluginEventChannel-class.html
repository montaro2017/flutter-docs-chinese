PluginEventChannel<T> 类

一个具名通道，通过流向框架端发送事件。

这是平台端的 EventChannel 对应实现。EventChannel 从平台插件接收事件流，而此通道则向框架端的监听处理程序发送事件流。

如果未提供 codec，则使用 StandardMethodCodec。如果未提供 binaryMessenger，则使用向框架端发送消息的 pluginBinaryMessenger。

使用此类创建的通道提供两种订阅事件流的方法。这些方法使用指定 codec 的编码方式。

第一种方法是 listen。调用后，当事件添加到 controller 时，通道便会开始向框架端转发消息。这会触发 controller 的 StreamController.onListen 回调。

另一种方法是 cancel。调用后，通道会停止向框架转发事件。这会触发 controller 的 StreamController.onCancel 回调。

框架未订阅时，添加到 controller 的事件会被静默丢弃。
