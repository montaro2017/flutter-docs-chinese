onViewFocusChange 属性

  1. @重写
ViewFocusChangeCallback? get onViewFocusChange
重写

焦点在不同 FlutterView 之间切换后立即调用的回调。

当平台将焦点从一个 FlutterView 移至另一个时，会调用此回调，指出新获得焦点的视图以及焦点到达的方向。例如，若焦点沿正向移动到 ID 为 2 的 FlutterView（可能是按下 Tab 的结果），回调会收到一个 ViewFocusEvent，其中状态为 ViewFocusState.focused，方向为 ViewFocusDirection.forward。

通常，事件接收方会将焦点移至 ID 为 2 的 FlutterView 中第一个可聚焦的组件。如果视图沿反方向获得焦点（例如按下 Shift + Tab），通常会聚焦该视图中的最后一个可聚焦组件。

平台可能会从某个 FlutterView 移除焦点。例如，在 Web 上，浏览器可能将焦点移至其他元素或浏览器内置界面；在桌面设备上，操作系统可能切换到另一个窗口（例如在 Windows 上按 Alt + Tab）。在这些情况下，onViewFocusChange 会以 ViewFocusState.unfocused 状态和 ViewFocusDirection.undefined 方向调用。

事件接收方通常会响应此事件，移除应用中的所有焦点指示。

应用也可以通过调用 requestViewFocusChange，以编程方式请求将焦点移至所需的 FlutterView。

此回调会在设置它时所在的同一 zone 中调用。

另请参阅：

  • requestViewFocusChange，用于以编程方式指示平台将焦点移至另一个 FlutterView。
  • ViewFocusState，用于查看允许的焦点转换列表。
  • ViewFocusDirection，用于查看允许的焦点方向列表。
  • ViewFocusEvent，即提供给回调的事件对象。

@override
ViewFocusChangeCallback? get onViewFocusChange => _platformDispatcher.onViewFocusChange;
