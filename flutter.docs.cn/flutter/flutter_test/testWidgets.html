在 Flutter 测试环境中运行 callback。

使用此函数测试自定义 StatelessWidget 和 StatefulWidget。

回调可以是异步的（使用 async/await 或显式使用 Future）。

timeout 参数指定由 test 包实现的兜底超时时间。若设置该参数，应使用较长时间（数分钟）。通过 flutter test 运行的测试默认超时时间为 10 分钟；通过 flutter run 运行的测试则没有限制。具体默认值为 TestWidgetsFlutterBinding.defaultTestTimeout。

如果 semanticsEnabled 参数设为 true，则在将 tester 传递给 callback 之前，已调用 WidgetTester.ensureSemantics；回调完成后会自动释放该句柄。此参数默认为 true。

此函数会使用 test 包的 test 函数，将给定回调注册为测试。回调运行时会获得一个新的 WidgetTester 实例。find 对象提供便捷的组件 Finder，供 WidgetTester 使用。

如果设置了 variant 参数，testWidgets 会针对 TestVariant.values 中的每个值各运行一次测试。如果未设置 variant，则会在基础测试环境中运行一次。

如果传入 tags，这些用户自定义标签会由 test 包实现。

experimentalLeakTesting 参数仍处于实验阶段，不建议在 Flutter 框架之外使用。将 experimentalLeakTesting 设为 true 后，它会在测试执行期间跟踪创建的对象是否发生泄漏；否则会使用 LeakTesting.settings。若要为整个包或文件夹调整设置，请在 flutter_test_config.dart 中修改 LeakTesting.settings（参阅 https://flutter.dev/to/flutter-test-docs）；也可在测试文件的 main 函数中调整（不要使用 setUp 或 setUpAll）。若要仅对某个测试关闭泄漏跟踪，请将 experimentalLeakTesting 设为 LeakTrackingForTests.ignore()。

示例代码

testWidgets('MyWidget', (WidgetTester tester) async {
  await tester.pumpWidget(const MyWidget());
  await tester.tap(find.text('Save'));
  expect(find.text('Success'), findsOneWidget);
});

@isTest
void testWidgets(
  String description,
  WidgetTesterCallback callback, {
  bool? skip,
  test_package.Timeout? timeout,
  bool semanticsEnabled = true,
  TestVariant<Object?> variant = const DefaultTestVariant(),
  dynamic tags,
  int? retry,
  LeakTesting? experimentalLeakTesting,
}) {
  assert(
    variant.values.isNotEmpty,
    'There must be at least one value to test in the testing variant.',
  );
  final TestWidgetsFlutterBinding binding = TestWidgetsFlutterBinding.ensureInitialized();
  final tester = WidgetTester._(binding);
  for (final Object? value in variant.values) {
    final String variationDescription = variant.describeValue(value);
    // IDEs may make assumptions about the format of this suffix in order to
    // support running tests directly from the editor (where they may have
    // access to only the test name, provided by the analysis server).
    // See https://github.com/flutter/flutter/issues/86659.
    final combinedDescription = variationDescription.isNotEmpty
        ? '$description (variant: $variationDescription)'
        : description;
    test(
      combinedDescription,
      () {
        tester._testDescription = combinedDescription;
        SemanticsHandle? semanticsHandle;
        tester._recordNumberOfSemanticsHandles();
        if (semanticsEnabled) {
          semanticsHandle = tester.ensureSemantics();
        }
        test_package.addTearDown(binding.postTest);
        return binding.runTest(
          () async {
            debugResetSemanticsIdCounter();
            Object? memento;
            try {
              memento = await variant.setUp(value);
              binding.reset(); // TODO(ianh): the binding should just do this itself in _runTest
              maybeSetupLeakTrackingForTest(experimentalLeakTesting, combinedDescription);
              await callback(tester);
            } finally {
              await variant.tearDown(value, memento);
              maybeTearDownLeakTrackingForTest();
            }
            semanticsHandle?.dispose();
          },
          tester._endOfTestVerifications,
          description: combinedDescription,
        );
      },
      skip: skip,
      timeout: timeout ?? binding.defaultTestTimeout,
      tags: tags,
      retry: retry,
    );
  }
}
