重写

将给定图像中由 src 参数指定的子区域，绘制到由 dst 参数指定的轴对齐矩形中。

应用滤镜时，采样范围可能会超出 src 矩形，最多超出半个滤镜宽度。

对同一图像使用不同参数多次调用此方法，可以合并为一次 drawAtlas 调用，以提高性能。

实现

  invocations.add(

      _MethodCall(#drawImageRect, <dynamic>[image, src, dst, Paint.from(paint)]),
      stack: StackTrace.current,
    ),
  );
}
