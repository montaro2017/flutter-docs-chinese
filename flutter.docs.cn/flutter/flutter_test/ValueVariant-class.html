ValueVariant<T> 类

一种 TestVariant，会针对给定的每个值分别运行测试。

要使用此变体，请在测试前定义它，然后在测试中访问 currentValue。

这些值通常是枚举，但不一定必须是枚举。系统会使用给定值的 toString 来描述该变体，并从其 toString 输出中移除类型名称，因此枚举值只会显示具体值，不会显示类型。

以下示例展示了如何设置测试以访问 currentValue。本例会运行两项测试，分别使用 value1，以及 value2。使用 value2 会失败。两项测试的名称如下：

  • Test handling of TestScenario (value1)
  • Test handling of TestScenario (value2)
link 
enum TestScenario {
  value1,
  value2,
  value3,
}

final ValueVariant<TestScenario> variants = ValueVariant<TestScenario>(
  <TestScenario>{TestScenario.value1, TestScenario.value2},
);
void main() {
  testWidgets('Test handling of TestScenario', (WidgetTester tester) async {
    expect(variants.currentValue, equals(TestScenario.value1));
  }, variant: variants);
}
