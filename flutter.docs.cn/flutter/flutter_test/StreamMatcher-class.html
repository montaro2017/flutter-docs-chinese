StreamMatcher

StreamMatcher 类 抽象

用于匹配 Stream 或 StreamQueue 事件的匹配器。

Stream 匹配器旨在让人们轻松为流创建复杂的预期，并将这些预期与测试的其他部分交错执行。它们可用于匹配 Stream 发出的所有事件：

expect(stream, emitsInOrder([
  // Values match individual events.
  "Ready.",

  // Matchers also run against individual events.
  startsWith("Loading took"),

  // Stream matchers can be nested. This asserts that one of two events are
  // emitted after the "Loading took" line.
  emitsAnyOf(["Succeeded!", "Failed!"]),

  // By default, more events are allowed after the matcher finishes
  // matching. This asserts instead that the stream emits a done event and
  // nothing else.
  emitsDone
]));

它也可以匹配 StreamQueue，此时会消费匹配到的事件。调用 expect 会返回一个 Future，在匹配器完成匹配时结束。你可以对其使用 await，以便在不同时间消费不同事件：

var stdout = StreamQueue(stdoutLineStream);

// Ignore lines from the process until it's about to emit the URL.
await expectLater(stdout, emitsThrough('WebSocket URL:'));

// Parse the next line as a URL.
var url = Uri.parse(await stdout.next);
expect(url.host, equals('localhost'));

// You can match against the same StreamQueue multiple times.
await expectLater(stdout, emits('Waiting for connection...'));

用户可以调用 StreamMatcher 创建自定义匹配器。
