重写

使用新提供的 Scene 更新视图在 GPU 上的渲染内容。

必须在调用 PlatformDispatcher.onBeginFrame 或 PlatformDispatcher.onDrawFrame 回调期间调用此函数。

如果在一次 PlatformDispatcher.onBeginFrame/PlatformDispatcher.onDrawFrame 回调序列中第二次调用此函数，或在这些回调之外调用，则该调用会被忽略。

要记录图形操作，先创建 PictureRecorder，再构造 Canvas，并将该 PictureRecorder 传给其构造函数。完成所有图形操作后，调用 PictureRecorder 的 PictureRecorder.endRecording 函数，以获得表示这些图形操作的最终 Picture。

接下来，创建 SceneBuilder，并使用 SceneBuilder.addPicture 将 Picture 添加其中。然后调用 SceneBuilder.build 方法获取 Scene 对象，再通过此 render 函数将其显示给用户。

如果视图配置了宽松的 physicalConstraints（即 ViewConstraints.isTight 返回 false），则必须提供满足这些约束的 size。此方法不会检查所提供的 size 是否确实符合约束（应由更高层完成检查），但不合法的 size 可能导致渲染行为未定义。如果未提供 size，则改用 physicalSize。

另请参阅：

  • SchedulerBinding, the Flutter framework class which manages the scheduling of frames.
  • RendererBinding, the Flutter framework class which manages layout and painting.
