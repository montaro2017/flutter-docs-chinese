通过系统通道模拟发送硬件按键 down 事件。

此方法用于编写测试。

此方法只模拟来自物理键盘而非软键盘的按键，并且只能模拟键映射表中列出的按键，例如 kAndroidToLogicalKey、kMacOsToPhysicalKey 等。

将 platform 指定为 Platform.operatingSystem 允许的平台之一，即可使事件看起来像是来自该平台。Web 上默认为“web”；其他环境中则默认为 defaultTargetPlatform 所对应的操作系统名称。

测试完成后，会清除所有仍处于按下状态的按键。

如果框架处理了此按键事件，则返回 true。

另请参阅：

  • simulateKeyUpEvent 和 simulateKeyRepeatEvent to simulate the corresponding key up and repeat event.

实现

Future<bool> simulateKeyDownEvent(
  LogicalKeyboardKey key, {
  String? platform,
  PhysicalKeyboardKey? physicalKey,
  String? character,
}) async {
  final bool handled = await KeyEventSimulator.simulateKeyDownEvent(
    key,
    platform: platform,
    physicalKey: physicalKey,
    character: character,
  );
  final ServicesBinding binding = ServicesBinding.instance;
  if (!handled && binding is TestWidgetsFlutterBinding) {
    await binding.testTextInput.handleKeyDownEvent(key);
  }
  return handled;
}
