emitsInAnyOrder function

StreamMatcher emitsInAnyOrder(
  1. Iterable matchers
)

返回一个 StreamMatcher；当 matchers 中的每个匹配器都能以任意顺序匹配时，它就会匹配该流。

如果任意匹配器未能匹配，此匹配器就会失败且不消耗任何事件。如果匹配器存在多种可能的匹配顺序，则选择消耗事件数量最多的顺序。

只要任意一组匹配器序列匹配该流，其他序列抛出的错误都会被忽略。如果没有序列匹配且多个序列抛出了错误，则重新抛出第一个错误。

请注意，检查 matchers 的所有排列在最坏情况下的复杂度为 O(n!)，因此仅应在 matchers 数量很少时调用。

实现

StreamMatcher emitsInAnyOrder(Iterable matchers) {
  var streamMatchers = matchers.map(emits).toSet();
  if (streamMatchers.length == 1) return streamMatchers.first;
  var description =
      'do the following in any order:\n'
      '${bullet(streamMatchers.map((matcher) => matcher.description))}';

  return StreamMatcher(
    (queue) async => await _tryInAnyOrder(queue, streamMatchers) ? null : '',
    description,
  );
}
