TestDefaultBinaryMessenger 类

用于测试环境的默认二进制消息传递器，是 BinaryMessenger 的子类。

它会跟踪跨越 Flutter 平台边界发送的数据状态，便于测试框架监控平台消息并与之同步。

从框架发送到平台的消息

框架通过 send 方法向平台发送消息。

若要拦截从框架发送到平台的消息，可使用 setMockMessageHandler、setMockDecodedMessageHandler 和 setMockMethodCallHandler（另请参阅 checkMockMessageHandler）。

若要等待所有待处理的框架到平台消息完成，可使用 platformMessagesFinished getter，它会提供适当的 Future。pendingMessageCount getter 则返回当前未完成消息的数量。

从平台发送到框架的消息

平台通过 ChannelBuffers API 发送消息。可以使用 handlePlatformMessage 向框架发送模拟消息。

这些消息的监听器通过 setMessageHandler 配置。
