FinderBase<CandidateType> 类 抽象

封装在候选项列表中搜索并筛选候选项的逻辑，只保留符合查找器定义要求的候选项。

实现类需要实现 allCandidates 来定义完整的搜索空间，并实现 findInCandidates 来定义查找器的要求。

此库包含 Finder 和 SemanticsFinder，分别用于搜索 Flutter 的元素树和语义树。

如果搜索可以表示为谓词，请考虑将 MatchFinderMixin 与 Finder 或 SemanticsFinder 基类一起使用。

如果搜索还需要筛选另一个查找器的结果，请考虑将 ChainedFinderMixin 与 Finder 或 SemanticsFinder 基类一起使用。
