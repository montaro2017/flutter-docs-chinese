description

TestFlutterView 类

一种包装另一个 FlutterView 的 FlutterView，可在测试中伪造部分属性。

不要手动实例化此类，因为它需要一个由 PlatformDispatcher 提供的底层 FlutterView。

另请参阅：

  • WidgetTester.view 可用于访问 TestFlutterView， 适用于单视图应用或 widget 测试。
  • WidgetTester.viewOf 可用于访问多视图应用在特定情况下对应的 TestFlutterView。
  • TestPlatformDispatcher, 可用于伪造特定平台的 功能。
实现的类型
  • FlutterView

构造函数

TestFlutterView({required FlutterView view, required TestPlatformDispatcher platformDispatcher, required TestDisplay display})
构造一个 TestFlutterView，其所有行为默认委托给指定的 FlutterView，除非在测试中显式重写。
