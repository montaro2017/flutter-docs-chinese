reassembleApplication 方法

Future<void> reassembleApplication()
继承

触发整个应用重新绘制，例如热重载之后。

当应用代码发生变化时，开发工具会调用此方法，使应用加载变更后的代码。也可以通过发送 ext.flutter.reassemble 服务扩展信号手动触发。

此方法的计算开销很大，不应在生产代码中调用。在生产环境中，没有合理理由需要触发整个应用重新绘制。Flutter 框架的各个部分都知道何时需要重绘。只有在开发过程中代码确实发生动态变化（例如热重载），或切换调试标志时，才需要调用此方法。

运行此方法期间，事件会被锁定（例如，指针事件不会派发）。

子类（Binding 类）应重写 performReassemble，以响应对此方法的调用。不要重写此方法本身。

实现

Future<void> reassembleApplication() {
  return lockEvents(performReassemble);
}
