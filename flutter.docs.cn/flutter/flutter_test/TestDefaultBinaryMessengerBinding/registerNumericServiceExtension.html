使用给定名称（完整名称为 "ext.flutter.name"）注册服务扩展方法。该方法接受一个与方法同名的参数；如果提供该参数，其值必须能被 double.parse 解析。省略参数时则读取当前值。（其他参数会被忽略。）

调用服务扩展方法时，会调用 getter 回调获取当前值。

服务扩展方法收到新值时，会将该值传给 setter 回调。

只有在构建中包含 vm-service 时，才能启用已注册的服务扩展；而 vm-service 只会在 debug 和 profile 模式下包含。虽然 release 模式无法使用服务扩展，但如果没有用可供 tree shaker 移除相关代码的条件保护，它的代码仍可能进入 Dart 快照，导致二进制体积增大（参见下方示例）。

以下代码注册的服务扩展仅包含在 debug 构建中。
link 
void myRegistrationFunction() {
  assert(() {
    // Register your service extension here.
    return true;
  }());
}

使用以下代码片段注册的服务扩展可在 debug 和 profile 模式下使用。
link 
void myOtherRegistrationFunction() {
  // kReleaseMode is defined in the 'flutter/foundation.dart' package.
  if (!kReleaseMode) {
    // Register your service extension here.
  }
}

这两种条件保护都能确保 Dart 的 tree shaker 在 release 构建中移除服务扩展代码。

实现

@protected
void registerNumericServiceExtension({
  required String name,
  required AsyncValueGetter<double> getter,
  required AsyncValueSetter<double> setter,
}) {
  registerServiceExtension(
    name: name,
    callback: (Map<String, String> parameters) async {
      if (parameters.containsKey(name)) {
        await setter(double.parse(parameters[name]!));
        _postExtensionStateChangedEvent(name, (await getter()).toString());
      }
      return <String, dynamic>{name: (await getter()).toString()};
    },
  );
}
