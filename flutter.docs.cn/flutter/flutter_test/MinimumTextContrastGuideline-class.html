MinimumTextContrastGuideline 类

一项准则，用于验证所有通过文本提供语义的节点是否达到最低对比度。

此准则由《Web 内容无障碍指南》规定，详见 http://www.w3.org/TR/UNDERSTANDING-WCAG20/visual-audio-contrast-contrast.html。

另请参阅：

  • AccessibilityGuideline，概述无障碍指南及其使用方式。
  • MinimumTextContrastGuidelineAAA, which follows the WCAG AAA level.
