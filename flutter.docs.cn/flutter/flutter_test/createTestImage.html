创建任意尺寸的测试图像。

如果 cache 参数设为 true，图像会缓存在当前测试套件的剩余执行期间。通常建议这样做：如果测试套件中的大多数测试使用尺寸相同的图像，就能节省整个套件运行期间的内存和 CPU 时间。但如果图像只在套件中使用一次，尤其是图像尺寸较大时，应避免缓存，因为它会在套件运行期间一直占用内存。

此方法需要执行真正的异步操作，在 FakeAsync 区域中无法正常工作；这些区域由 testWidgets 建立。通常应在运行 testWidgets 前将其作为设置步骤调用，例如在 setUp 或 setUpAll 中调用。如有需要，也可通过 WidgetTester.runAsync 调用。

实现

Future<ui.Image> createTestImage({int width = 1, int height = 1, bool cache = true}) =>
    TestAsyncUtils.guard(() async {
      assert(width > 0);
      assert(height > 0);

      final int cacheKey = Object.hash(width, height);
      if (cache && _cache.containsKey(cacheKey)) {
        return _cache[cacheKey]!.clone();
      }

      final ui.Image image = await _createImage(width, height);
      if (cache) {
        _cache[cacheKey] = image.clone();
      }
      return image;
    });
