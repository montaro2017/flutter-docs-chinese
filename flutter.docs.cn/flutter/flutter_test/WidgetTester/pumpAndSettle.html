重写

反复使用给定的 duration 调用 pump，直到不再安排新帧。此方法至少会调用一次 pump，即使调用时没有安排任何帧也是如此，以便清空可能会自行安排新帧的待处理微任务。

此方法本质上会等待所有动画完成。

如果在给定的 timeout 时间内无法稳定下来，测试就会失败（此方法会抛出异常）。尤其是存在无限动画时（例如不确定进度指示器持续旋转），此方法会抛出异常。

默认超时时间为十分钟，长于大多数合理的有限动画时长。

如果函数成功返回，则会返回执行 pump 的次数。

通常更好的做法是确切找出每一帧的必要原因，然后只调用所需次数的 pump。这样有助于发现回归问题，例如动画比预期晚一帧才开始。

也可以检查此函数的返回值是否符合预期的 pump 次数。

实现

@override
Future<int> pumpAndSettle([
  Duration duration = const Duration(milliseconds: 100),
  EnginePhase phase = EnginePhase.sendSemanticsUpdate,
  Duration timeout = const Duration(minutes: 10),
]) {
  assert(duration > Duration.zero);
  assert(timeout > Duration.zero);
  assert(() {
    final WidgetsBinding binding = this.binding;
    if (binding is LiveTestWidgetsFlutterBinding &&
        binding.framePolicy == LiveTestWidgetsFlutterBindingFramePolicy.benchmark) {
      matcher_expect.fail(
        'When using LiveTestWidgetsFlutterBindingFramePolicy.benchmark, '
        'hasScheduledFrame is never set to true. This means that pumpAndSettle() '
        'cannot be used, because it has no way to know if the application has '
        'stopped registering new frames.',
      );
    }
    return true;
  }());
  return TestAsyncUtils.guard<int>(() async {
    final DateTime endTime = binding.clock.fromNowBy(timeout);
    var count = 0;
    do {
      if (binding.clock.now().isAfter(endTime)) {
        throw FlutterError('pumpAndSettle timed out');
      }
      await binding.pump(duration, phase);
      count += 1;
    } while (binding.hasScheduledFrame);
    return count;
  });
}
