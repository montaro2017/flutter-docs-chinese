enterText 方法

Future<void> enterText(
  1. FinderBase<Element> finder,
  2. String text
)

使 finder 指定的文本输入组件获得焦点，并将其内容替换为 text，效果如同由屏幕键盘输入。

finder 指定的组件必须是 EditableText，或包含 EditableText 后代。例如：find.byType(TextField)、find.byType(TextFormField) 或 find.byType(EditableText)。

返回的 Future 完成时，文本输入组件的内容将与 text 完全相同，插入光标位于 text 末尾。

如果只想让 finder 获得焦点而不输入文本，请参阅 showKeyboard。

若要向其他组件输入文本（例如像 EditableText 一样维护 TextInputConnection 的自定义组件），请先确保该组件已建立连接（例如使用 tap 使其获得焦点），然后直接调用 testTextInput.enterText（参阅 TestTextInput.enterText）。

实现

Future<void> enterText(FinderBase<Element> finder, String text) async {
  return TestAsyncUtils.guard<void>(() async {
    await showKeyboard(finder);
    testTextInput.enterText(text);
    await idle();
  });
}
