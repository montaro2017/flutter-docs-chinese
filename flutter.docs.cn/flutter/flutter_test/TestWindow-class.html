TestWindow
description

TestWindow 类

已弃用。将在 Flutter 的未来版本中移除。

弃用此类是为 Flutter 即将推出的多视图和多窗口支持做准备。

此 SingletonFlutterWindow 会包装另一个 SingletonFlutterWindow，并允许在测试中模拟部分属性。

某些组件（例如 MaterialApp）的测试可能需要模拟 SingletonFlutterWindow 的某些属性。TestWindow 通过覆盖真实 SingletonFlutterWindow 的属性并提供所需的模拟值来实现这一点。测试使用的绑定 TestWidgetsFlutterBinding 中包含一个供所有测试使用的 TestWindow。

示例代码

测试可以按以下方式使用 TestWindow：

testWidgets('your test name here', (WidgetTester tester) async {
  // Retrieve the TestWidgetsFlutterBinding.
  final TestWidgetsFlutterBinding testBinding = tester.binding;

  // Fake the desired properties of the TestWindow. All code running
  // within this test will perceive the following fake text scale
  // factor as the real text scale factor of the window.
  testBinding.platformDispatcher.textScaleFactorTestValue = 2.5;

  // Test code that depends on text scale factor here.
});

每项测试都会重新创建 TestWidgetsFlutterBinding，因此某项测试中定义的任何模拟值都不会保留到下一项测试。

如果测试需要覆盖真实 SingletonFlutterWindow 的属性，并在之后恢复使用真实 SingletonFlutterWindow 的属性，TestWindow 提供了清除各项测试值的方法，例如 clearDevicePixelRatioTestValue。

要清除 TestWindow 中的所有模拟测试值，可以使用 clearAllTestValues。

另请参阅：

  • TestPlatformDispatcher, which wraps a PlatformDispatcher for testing purposes and is used by the platformDispatcher property of this class.
