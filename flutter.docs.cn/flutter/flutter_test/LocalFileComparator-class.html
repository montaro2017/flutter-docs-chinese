LocalFileComparator 类

flutter test 使用的默认 GoldenFileComparator 实现。

“黄金文件”是指主图像，它被视为你选择捕获的某个组件、状态、应用或其他视觉表示的真实渲染结果。此比较器会从本地文件系统加载黄金文件，并将黄金键视为相对于测试文件所在目录的路径。

此比较器会逐像素比较解码后的 PNG，只有完全匹配时才返回 true。如果捕获的测试图像与黄金文件不匹配，此比较器会提供输出以展示差异，详情如下。

使用 flutter test --update-goldens 时，LocalFileComparator 会更新磁盘上的黄金文件，使其与渲染结果一致。

黄金文件测试的本地输出

黄金文件测试失败时，LocalFileComparator 会输出测试反馈。反馈以差异图像的形式保存在黄金键指定位置下新建的 failures 目录中。差异图像包括参与比较的主图像和测试图像、仅显示检测到像素差异的图像，以及将这些像素差异叠加在主图像上的遮罩图像。

包含字体

自定义字体在不同平台或不同 Flutter 版本中的渲染效果可能不同。例如，在 Windows 上使用字体生成的黄金图像很可能与其他操作系统生成的图像不同。即使在同一平台上，如果使用不同版本的 Flutter 测试生成的黄金图像，测试也可能失败并需要更新图像。

默认情况下，Flutter 框架使用名为 'Ahem' 的字体，以方块代替字符；不过，也可以使用自定义字体渲染图像。例如，以下代码展示了如何为黄金测试加载 'Roboto' 字体：

如何为黄金图像加载自定义字体。
link 
testWidgets('Creating a golden image with a custom font', (WidgetTester tester) async {
  // Assuming the 'Roboto.ttf' file is declared in the pubspec.yaml file
  final Future<ByteData> font = rootBundle.load('path/to/font-file/Roboto.ttf');

  final FontLoader fontLoader = FontLoader('Roboto')..addFont(font);
  await fontLoader.load();

  await tester.pumpWidget(const MyWidget());

  await expectLater(
    find.byType(MyWidget),
    matchesGoldenFile('myWidget.png'),
  );
});

上面的示例只为该特定测试加载所需字体。若要为所有黄金文件测试加载字体，可以将 FontLoader.load() 调用移到 flutter_test_config.dart 中。这样，每次测试前都会加载字体：

从 flutter_test_config.dart 文件加载自定义字体。
link 
Future<void> testExecutable(FutureOr<void> Function() testMain) async {
  setUpAll(() async {
    final FontLoader fontLoader = FontLoader('SomeFont')..addFont(someFont);
    await fontLoader.load();
  });

  await testMain();
}
