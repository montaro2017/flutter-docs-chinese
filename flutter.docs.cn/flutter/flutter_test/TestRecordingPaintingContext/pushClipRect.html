重写

使用矩形进一步裁剪后续绘制内容。

needsCompositing 参数指定子对象是否需要合成。通常，此值与调用方的 RenderObject.needsCompositing 相同。如果为 false，此方法会返回 null，表示不再需要图层。如果调用此方法的渲染对象将 oldLayer 存储在其 RenderObject.layer 字段中，则应将该字段设为 null。

当 needsCompositing 为 false 时，此方法会使用比实际创建图层更高效的方式应用图层效果。

offset 参数表示从画布坐标系原点到调用方坐标系原点的偏移量。

clipRect 参数指定用于裁剪 painter 绘制内容的矩形（以调用方的坐标系表示）。其中不应包含 offset。

应用 clipRect 时会调用 painter 回调。该回调会在调用 pushClipRect 期间同步执行。

clipBehavior 参数控制矩形的裁剪方式。

oldLayer 参数应指定上一帧创建的图层。这会为引擎提供更多信息以进行性能优化。通常，这是渲染对象创建一次并在后续帧中重复使用的 RenderObject.layer 值，直到不再需要图层（例如渲染对象不再需要合成），或渲染对象更改图层类型（例如从不透明度图层改为矩形裁剪图层）。

实现

@override
ClipRectLayer? pushClipRect(
  bool needsCompositing,
  Offset offset,
  Rect clipRect,
  PaintingContextCallback painter, {
  Clip clipBehavior = Clip.hardEdge,
  ClipRectLayer? oldLayer,
}) {
  clipRectAndPaint(
    clipRect.shift(offset),
    clipBehavior,
    clipRect.shift(offset),
    () => painter(this, offset),
  );
  return null;
}
