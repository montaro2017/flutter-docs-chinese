drawFrame 方法

  1. @重写
void drawFrame()
重写

驱动渲染流水线以生成一帧。

此方法由 handleDrawFrame 调用；当引擎需要布局和绘制一帧时，会自动调用后者。

每一帧包含以下阶段：

  1. 动画阶段：通过 PlatformDispatcher.onBeginFrame 注册的 handleBeginFrame 方法会按注册顺序调用通过 scheduleFrameCallback 注册的所有临时帧回调。其中包括驱动 AnimationController 对象的所有 Ticker 实例，因此所有活动的 Animation 对象都会在此阶段更新。

  2. 微任务阶段：handleBeginFrame 返回后，临时帧回调安排的微任务会运行。这通常包括本帧完成的 Ticker 和 AnimationController 对象所对应的 Future 回调。

handleBeginFrame 之后，会调用通过 dart:ui.PlatformDispatcher.onDrawFrame 注册的 handleDrawFrame，后者会调用所有持久帧回调。其中最重要的是本方法 drawFrame，其执行过程如下：

  1. 布局阶段：系统中所有标记为脏的 RenderObject 都会进行布局（参见 RenderObject.performLayout）。有关如何将对象标记为需要布局的脏状态，请参阅 RenderObject.markNeedsLayout。

  2. 合成位阶段：更新所有标记为脏的 RenderObject 对象的合成位。参见 RenderObject.markNeedsCompositingBitsUpdate。

  3. 绘制阶段：重新绘制系统中所有标记为脏的 RenderObject（参见 RenderObject.paint），并生成 Layer 树。有关如何将对象标记为需要绘制的脏状态，请参阅 RenderObject.markNeedsPaint。

  4. 合成阶段：将图层树转换为 Scene 并发送到 GPU。

  5. 语义阶段：更新系统中所有标记为脏的 RenderObject 的语义信息，并生成 SemanticsNode 树。有关如何将对象标记为需要更新语义的脏状态，请参阅 RenderObject.markNeedsSemanticsUpdate。

关于第 3 至第 7 步的更多信息，请参阅 PipelineOwner。

  1. The finalization phase: After drawFrame returns, handleDrawFrame then invokes post-frame callbacks (registered with addPostFrameCallback).

某些绑定（例如 WidgetsBinding）会在此列表中增加额外步骤（例如参见 WidgetsBinding.drawFrame）。

实现

@override
void drawFrame() {
  assert(inTest);
  try {
    debugBuildingDirtyElements = true;
    buildOwner!.buildScope(rootElement!);
    if (_phase != EnginePhase.build) {
      rootPipelineOwner.flushLayout();
      if (_phase != EnginePhase.layout) {
        rootPipelineOwner.flushCompositingBits();
        if (_phase != EnginePhase.compositingBits) {
          rootPipelineOwner.flushPaint();
          if (_phase != EnginePhase.paint && sendFramesToEngine) {
            _firstFrameSent = true;
            for (final RenderView renderView in renderViews) {
              renderView.compositeFrame(); // this sends the bits to the GPU
            }
            if (_phase != EnginePhase.composite) {
              rootPipelineOwner.flushSemantics(); // this sends the semantics to the OS.
              assert(
                _phase == EnginePhase.flushSemantics || _phase == EnginePhase.sendSemanticsUpdate,
              );
            }
          }
        }
      }
    }
    buildOwner!.finalizeTree();
  } finally {
    debugBuildingDirtyElements = false;
  }
}
