deferFirstFrame 方法

  1. @重写
void deferFirstFrame()
重写

告知框架暂不向引擎发送首帧，直到调用对应的 allowFirstFrame。

可在首帧渲染前执行异步初始化工作（首帧渲染会关闭启动画面）。框架仍会完成生成帧所需的全部工作，但这些帧不会发送到引擎，也不会显示在屏幕上。

首帧发送到引擎后再调用此方法不会产生任何效果。

实现

@override
void deferFirstFrame() {
  assert(_firstFrameDeferredCount >= 0);
  _firstFrameDeferredCount += 1;
}
