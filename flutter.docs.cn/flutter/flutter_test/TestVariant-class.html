TestVariant<T> 类 抽象

用于描述测试环境变体的抽象基类。

这些变体作为 testWidgets 的 variants 参数元素。

添加更多测试变体时请谨慎：每增加一种变体，测试运行次数就会相应增加，可能大幅延长运行全部测试所需的时间。
