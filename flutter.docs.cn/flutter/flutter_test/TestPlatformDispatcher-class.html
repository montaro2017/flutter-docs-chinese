TestPlatformDispatcher
description

TestPlatformDispatcher 类

此 PlatformDispatcher 会包装另一个 PlatformDispatcher，并允许在测试中伪造部分属性。

另请参阅：

  • TestFlutterView 会包装一个 FlutterView，用于测试和模拟。
实现的类型
  • PlatformDispatcher

构造函数

TestPlatformDispatcher({required PlatformDispatcher platformDispatcher})
构造一个 TestPlatformDispatcher，除非为测试显式重写，否则会将所有行为委托给给定的 PlatformDispatcher。
