尝试从给定组件的中心开始执行快速甩动手势，移动给定距离并达到指定速度。

若 warnIfMissed 参数为 true（默认值），当指定的 Finder 找到的组件及位置无法实际接收到指针事件时，会在控制台显示警告。例如，组件被遮挡、位置在屏幕外，或组件对指针事件透明时，就会发生这种情况。

如果你有意不实际命中指定元素，可将此参数设为 false 以关闭警告。

offset 表示指针在屏幕全局坐标系中移动的距离。

Offset.dy 为正值表示指针向下移动，Offset.dy 为负值表示指针向上移动。同理，Offset.dx 为正值表示指针向右移动，Offset.dx 为负值表示向左移动。

此操作可能会泵入帧。

恰好会合成 50 个指针事件。

speed 表示沿 offset 指定方向的每秒像素数。

offset 和 speed 决定各指针事件之间的间隔。例如，若 offset 为向下 200 像素，speed 为每秒 800 像素，则每移动 4 像素（200/50）发送一次指针事件，持续 250 毫秒（200/800），也就是每隔 1.25 毫秒（250/200）发送一次事件。

为使测试更贴近真实情况，此期间可能会泵入帧（通过调用 pump）。如果总时长超过 frameInterval，则在发送事件期间，每经过该时长或每合成一个事件时会泵入一帧，取两者中较少发生的频率。

如果在实时环境中使用此方法且需要精确控制时间，请参阅 LiveTestWidgetsFlutterBindingFramePolicy.benchmarkLive。

如果 initialOffset 不为零，指针会先移动该偏移量，然后泵入一段 initialOffsetDelay 延迟。此功能可模拟先拖动再快速甩动的操作，包括先向与甩动方向相反的方向拖动（例如先向右拖动 200 像素，再向左甩动 200 像素，最终回到拖动起点）。

快速甩动本质上是以特定速度结束的拖动。如果只想拖动并结束，而不执行快速甩动，请使用 drag。

实现

Future<void> fling(
  finders.FinderBase<Element> finder,
  Offset offset,
  double speed, {
  int? pointer,
  int buttons = kPrimaryButton,
  Duration frameInterval = const Duration(milliseconds: 16),
  Offset initialOffset = Offset.zero,
  Duration initialOffsetDelay = const Duration(seconds: 1),
  bool warnIfMissed = true,
  PointerDeviceKind deviceKind = PointerDeviceKind.touch,
}) {
  final FlutterView? view = _maybeViewOf(finder);
  return flingFrom(
    getCenter(finder, warnIfMissed: warnIfMissed, callee: 'fling'),
    offset,
    speed,
    pointer: pointer,
    buttons: buttons,
    frameInterval: frameInterval,
    initialOffset: initialOffset,
    initialOffsetDelay: initialOffsetDelay,
    deviceKind: deviceKind,
    view: view,
  );
}
