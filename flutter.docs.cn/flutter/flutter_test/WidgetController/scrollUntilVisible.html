沿 Scrollable.axisDirection 方向，反复将 Scrollable 滚动 delta 的距离，直到与 finder 匹配的组件可见。

每次滚动之间，时钟会前进 duration 指定的时间。

滚动会持续到 finder 指定内容的起始位置可见。这是由 Scrollable.ensureVisible 方法的默认参数值决定的。

如果 scrollable 为 null，则会改用用于查找 Scrollable 的 Finder。

如果 continuous 为 true，则会重复使用同一手势来模拟实际手指滚动的效果。这在配合 GestureDetector.onTap 等监听器时很有用。默认值为 false。

如果滚动 maxScrolls 次后仍未找到 finder，则抛出 StateError。

This is different from ensureVisible in that this allows looking for finder that is not yet built. The caller must specify the scrollable that will build child specified by finder when there are multiple Scrollable。

另请参阅：

  • dragUntilVisible, which implements the body of this method.

实现

Future<void> scrollUntilVisible(
  finders.FinderBase<Element> finder,
  double delta, {
  finders.FinderBase<Element>? scrollable,
  int maxScrolls = 50,
  Duration duration = const Duration(milliseconds: 50),
  bool continuous = false,
}) {
  assert(maxScrolls > 0);
  scrollable ??= finders.find.byType(Scrollable);
  return TestAsyncUtils.guard<void>(() async {
    Offset moveStep;
    switch (widget<Scrollable>(scrollable!).axisDirection) {
      case AxisDirection.up:
        moveStep = Offset(0, delta);
      case AxisDirection.down:
        moveStep = Offset(0, -delta);
      case AxisDirection.left:
        moveStep = Offset(delta, 0);
      case AxisDirection.right:
        moveStep = Offset(-delta, 0);
    }
    await dragUntilVisible(
      finder,
      scrollable,
      moveStep,
      maxIteration: maxScrolls,
      duration: duration,
      continuous: continuous,
    );
  });
}
