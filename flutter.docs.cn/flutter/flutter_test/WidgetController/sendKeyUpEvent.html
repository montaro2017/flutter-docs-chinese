通过系统通道模拟发送物理按键抬起事件。

此方法只模拟来自物理键盘的按键抬起事件，不模拟软键盘事件。

将 platform 指定为 Platform.operatingSystem 允许的平台之一，即可使事件看起来像是来自该类系统。如果未指定，Web 平台默认为“web”，其他平台则根据 defaultTargetPlatform 使用操作系统名称。

指定事件的 physicalKey 可覆盖模拟事件中的对应值。如果未指定，则会根据相应的逻辑 key，使用美国键盘布局中的默认值。

如果框架处理了该按键事件，则返回 true。

另请参阅：

  • sendKeyDownEvent 和 sendKeyRepeatEvent to simulate the corresponding key down and repeat event.
  • sendKeyEvent to simulate both the key up and key down in the same call.

实现

Future<bool> sendKeyUpEvent(
  LogicalKeyboardKey key, {
  String? platform,
  PhysicalKeyboardKey? physicalKey,
}) async {
  // Internally wrapped in async guard.
  return simulateKeyUpEvent(key, platform: platform, physicalKey: physicalKey);
}
