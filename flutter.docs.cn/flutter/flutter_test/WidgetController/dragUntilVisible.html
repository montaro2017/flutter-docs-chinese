反复将 view 拖动 moveStep 的距离，直到 finder 指向的内容可见。

moveStep 是虚拟手指在每次拖动之间于虚拟屏幕上移动的偏移量。按照标准触摸输入习惯，Offset.dy 为负值表示向上滑动（显示下方项目），Offset.dy 为正值表示向下滑动（显示上方项目）；Offset.dx 为正值表示向右滑动（显示左侧项目），Offset.dx 为负值表示向左滑动（显示右侧项目）。

每次拖动之间，时钟会前进 duration 指定的时间。

如果经过 maxIteration 次拖动后仍未找到 finder，则会抛出 StateError。

另请参阅：

  • scrollUntilVisible 会对该方法进行封装，处理 Scrollable 时更加方便。

实现

Future<void> dragUntilVisible(
  finders.FinderBase<Element> finder,
  finders.FinderBase<Element> view,
  Offset moveStep, {
  int maxIteration = 50,
  Duration duration = const Duration(milliseconds: 50),
  bool continuous = false,
}) {
  return TestAsyncUtils.guard<void>(() async {
    TestGesture? gesture;
    while (maxIteration > 0 && finder.evaluate().isEmpty) {
      if (continuous) {
        gesture ??= await startGesture(getCenter(view, warnIfMissed: true));
        await gesture.moveBy(moveStep);
      } else {
        await drag(view, moveStep);
      }
      await pump(duration);
      maxIteration -= 1;
    }
    await gesture?.up();
    await Scrollable.ensureVisible(element(finder));
  });
}
