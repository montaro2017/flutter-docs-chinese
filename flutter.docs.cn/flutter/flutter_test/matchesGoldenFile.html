matchesGoldenFile function

AsyncMatcher matchesGoldenFile(
  1. Object key, {
  2. int? version,
})

断言 Finder、Future<ui.Image> 或 ui.Image 与由 key 标识的黄金图像文件匹配；还可选择指定 version 版本号。

如果参数是 Finder，则该 Finder 必须恰好匹配一个组件；该组件的图像取自其第一个 RepaintBoundary 祖先渲染出的内容。因此，你可以将测试组件包装在 RepaintBoundary 中，以指定测试关注的区域。

key 可以是 Uri 或 String 格式的网址。

version 是用于区分历史黄金文件的数字。此参数为可选项。

这是一个异步匹配器，因此调用方使用时应调用 expectLater，并等待 expectLater 返回的 Future。

黄金文件测试

“黄金文件”指作为真实结果的主图像，它代表你选择捕获的某个组件、状态、应用或其他视觉内容的渲染效果。

可以对测试运行 flutter test --update-goldens，以创建或更新用于比较的主黄金图像文件。

匹配 matchesGoldenFile 的示例调用。
link 
await expectLater(
  find.text('Save'),
  matchesGoldenFile('save.png'),
);

await expectLater(
  image,
  matchesGoldenFile('save.png'),
);

await expectLater(
  imageFuture,
  matchesGoldenFile(
    'save.png',
    version: 2,
  ),
);

await expectLater(
  find.byType(MyWidget),
  matchesGoldenFile('goldens/myWidget.png'),
);

包含字体

自定义字体在不同平台或不同 Flutter 版本上的渲染效果可能不同。例如，在 Windows 上生成的含字体黄金文件，可能与其他操作系统生成的文件不同。即使在同一平台上，如果使用不同 Flutter 版本运行黄金文件测试，测试也可能失败，需要更新图像。

Flutter 框架默认使用名为“Ahem”的字体，以方块代替字符；不过，也可以使用自定义字体渲染图像。例如，下面展示了如何在黄金文件测试中加载“Roboto”字体：

如何为黄金图像加载自定义字体。
link 
testWidgets('Creating a golden image with a custom font', (WidgetTester tester) async {
  // Assuming the 'Roboto.ttf' file is declared in the pubspec.yaml file
  final Future<ByteData> font = rootBundle.load('path/to/font-file/Roboto.ttf');

  final FontLoader fontLoader = FontLoader('Roboto')..addFont(font);
  await fontLoader.load();

  await tester.pumpWidget(const MyWidget());

  await expectLater(
    find.byType(MyWidget),
    matchesGoldenFile('myWidget.png'),
  );
});

上例只会为该特定测试加载所需字体。若要为所有黄金文件测试加载字体，可以将 FontLoader.load() 调用移到 flutter_test_config.dart 中。这样，每个测试运行前都会加载该字体：

如何从 flutter_test_config.dart 文件加载自定义字体。
link 
Future<void> testExecutable(FutureOr<void> Function() testMain) async {
  setUpAll(() async {
    final FontLoader fontLoader = FontLoader('SomeFont')..addFont(someFont);
    await fontLoader.load();
  });

  await testMain();
}

另请参阅：

  • goldenFileComparator，它是此匹配器的后端。
  • LocalFileComparator 是 flutter test 的默认 GoldenFileComparator 实现。
  • matchesReferenceImage；如果要验证两个不同代码路径是否会生成相同图像，应改用此匹配器。
  • flutter_test 文档讨论了测试配置，调用方可据此为此匹配器替换后端。

实现

AsyncMatcher matchesGoldenFile(Object key, {int? version}) {
  return switch (key) {
    Uri() => MatchesGoldenFile(key, version),
    String() => MatchesGoldenFile.forStringPath(key, version),
    _ => throw ArgumentError('Unexpected type for golden file: ${key.runtimeType}'),
  };
}
