matchAsync 方法

  1. @重写
dynamic matchAsync(
  1. Object? item

如果与 item 匹配，则返回 null；如果不匹配，则返回说明失败原因的 String。

此方法可以返回 Future，也可以同步返回值。如果返回 Future，则在该 Future 完成前，expect 和测试都不会完成。

如果此方法同步返回 String，expect 会同步抛出 TestFailure，而 matches 会同步返回 false。

实现

@override
dynamic /*FutureOr<String>*/ matchAsync(Object? item) {
  if (item is! Function && item is! Future) {
    return 'was not a Function or Future';
  }

  if (item is Future) {
    return _matchFuture(item, 'emitted ');
  }

  try {
    var value = (item as Function)();
    if (value is Future) {
      return _matchFuture(value, 'returned a Future that emitted ');
    }

    return indent(prettyPrint(value), first: 'returned ');
  } catch (error, trace) {
    return _check(error, trace);
  }
}
