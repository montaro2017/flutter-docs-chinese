description

PaintPattern 类 抽象

用于匹配显示列表（Canvas 调用）的图案构建器接口。

paints 匹配器会返回 PaintPattern，以便你在 expect 调用中构建图案。

图案采用子集匹配，也就是说，图案未描述的调用会被忽略。例如，可以跳过变换调用。
