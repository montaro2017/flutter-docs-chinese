ensureInitialized static 方法

TestWidgetsFlutterBinding ensureInitialized([
  1. @visibleForTesting Map<String, String>? environment
])

创建并初始化绑定。此函数具有幂等性；再次调用时会直接返回先前创建的实例。

如果测试通过 flutter test 运行，此函数会使用 AutomatedTestWidgetsFlutterBinding；否则（例如通过 flutter run 运行），则使用 LiveTestWidgetsFlutterBinding。函数通过检查环境变量中是否存在名为 FLUTTER_TEST 的变量来判断。

如果 FLUTTER_TEST 的值为 true，则表示此测试由 flutter test 调用。如果未设置 FLUTTER_TEST，或其值为 false，则表示此测试由 flutter run 调用。

浏览器环境目前不支持 LiveTestWidgetsFlutterBinding，因此在浏览器中运行时，此函数始终会设置 AutomatedTestWidgetsFlutterBinding。

environment 参数用于测试测试框架本身，即检查框架如何响应不同的环境变量值；除该用途外不应使用此参数。

如果在调用 ensureInitialized 之前已显式初始化 TestWidgetsFlutterBinding 的子类，则无论上述逻辑如何，都会返回该绑定。这使测试能够强制使用特定的测试绑定。

testWidgets 会自动调用此函数。

实现

static TestWidgetsFlutterBinding ensureInitialized([
  @visibleForTesting Map<String, String>? environment,
]) {
  return _instance ?? binding.ensureInitialized(environment);
}
