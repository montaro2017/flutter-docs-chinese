TestGesture 构造函数

TestGesture({
  1. required EventDispatcher dispatcher,
  2. int pointer = 1,

创建一个 TestGesture，但不派发任何事件。随后可以操作此 TestGesture 来执行后续操作。

默认使用的指针标识符为 1。可以通过提供 pointer 参数来指定其他值。

必须通过 hitTester 参数提供一个用于命中测试的函数，并通过 dispatcher 参数提供一个用于派发事件的函数。

设备 kind 默认为 PointerDeviceKind.touch，但指针在 PointerDeviceKind.touch 的 "up" 状态时，移动事件必须使用其他类型，例如 PointerDeviceKind.mouse，因为触摸设备在指针 "up" 时无法产生移动事件。

所有参数都不能为 null。dispatcher 和 hitTester 参数为必填项。

实现

TestGesture({
  required EventDispatcher dispatcher,
  int pointer = 1,
  PointerDeviceKind kind = PointerDeviceKind.touch,
  int? device,
  int buttons = kPrimaryButton,
}) : _dispatcher = dispatcher,
     _pointer = TestPointer(pointer, kind, device, buttons);
