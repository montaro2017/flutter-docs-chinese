每次测试某个值前调用的函数，并接收即将测试的值。

此函数应保留恢复测试环境至初始状态所需的状态。调用 tearDown 时，会通过返回的 Object 恢复环境。测试完成后，此对象会作为 memento 传递给 tearDown。

实现

@override
Future<T> setUp(T value) async => _currentValue = value;
