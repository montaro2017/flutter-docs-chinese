WidgetTester 类

以编程方式与组件及测试环境交互的类。

通常，测试会使用 pumpWidget 加载组件树（方式与 Flutter 应用中的 runApp 非常相似）。之后可使用 tap、drag、enterText、fling、longPress 等方法与应用交互。应用运行在 FakeAsync zone 中，因此可以有意地逐步推进时间；这通过 pump 方法完成。

随后可使用 expect 检查应用状态，通常借助 find 命名空间中的 Finder，以及 findsOneWidget 等 Matcher。

testWidgets('MyWidget', (WidgetTester tester) async {
  await tester.pumpWidget(const MyWidget());
  await tester.tap(find.text('Save'));
  await tester.pump(); // allow the application to handle
  await tester.pump(const Duration(seconds: 1)); // skip past the animation
  expect(find.text('Success'), findsOneWidget);
});

为方便起见，此类的实例（例如 testWidgets 提供的实例）可用作 AnimationController 对象的 vsync。

当绑定为 LiveTestWidgetsFlutterBinding 时，来自 LiveTestWidgetsFlutterBinding.deviceEventDispatcher 的事件会由 dispatchEvent 处理。因此，使用 flutter run 运行测试时，可以点按屏幕生成与测试相关的 Finder。
