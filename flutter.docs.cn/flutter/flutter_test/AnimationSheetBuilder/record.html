返回一个 widget，用固定大小的框渲染可供录制的 widget。

返回的 widget 会将 child 包装在固定大小的框中，尺寸由 frameSize 指定；同时也会将 key 应用于返回的 widget。

仅当 recording 参数为 true，或当前处于由 recording 包装的流程中时，才会录制帧。两种情况下，每帧绘制结果都会被保存，之后可供 collate 使用。如果均不满足，则不会录制帧，这适用于测试准备阶段。

另请参阅：

  • WidgetTester.pumpFrames, which renders a widget in a series of frames with a fixed time interval.

实现

Widget record(Widget child, {Key? key, bool recording = true}) {
  return _AnimationSheetRecorder(
    key: key,
    size: frameSize,
    allLayers: allLayers,
    handleRecorded: !recording
        ? null
        : (Future<ui.Image> futureImage) {
            _recordedFrames.add(
              _AsyncImage(() async {
                final ui.Image image = await futureImage;
                assert(
                  image.width == frameSize.width && image.height == frameSize.height,
                  'Unexpected size mismatch: frame has (${image.width}, ${image.height}) '
                  'while `frameSize` is $frameSize.',
                );
                return image;
              }()),
            );
          },
    child: child,
  );
}
