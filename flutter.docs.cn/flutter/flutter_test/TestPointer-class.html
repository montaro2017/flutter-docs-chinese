TestPointer 类

用于生成连贯模拟指针事件的类。

可以用它手动模拟单个事件，但生成连贯手势最简单的方法是使用 TestGesture。

构造函数

TestPointer([int pointer = 1, PointerDeviceKind kind = PointerDeviceKind.touch, int? device, int buttons = kPrimaryButton])
创建一个 TestPointer. 默认指针标识符为 1，也可通过构造函数参数覆盖。
