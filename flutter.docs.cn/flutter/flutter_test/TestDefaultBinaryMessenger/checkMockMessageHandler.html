如果 handler 参数与先前传递给 setMockMessageHandler、setMockDecodedMessageHandler 或 setMockMethodCallHandler 的 handler 相同，则返回 true。

具体而言，它会将传入的参数与传给 setMockMessageHandler 的 identity 参数进行比较；如果 identity 为 null，则默认使用传给该方法的 handler 参数。

此方法适用于测试或测试框架，可用来断言指定通道的模拟处理器未被先前的测试更改。

如果 handler 为 null，且 channel 未设置处理器，则返回 true。

每次测试结束后都会清除已注册的回调。

实现

bool checkMockMessageHandler(String channel, Object? handler) =>
    _outboundHandlerIdentities[channel] == handler;
