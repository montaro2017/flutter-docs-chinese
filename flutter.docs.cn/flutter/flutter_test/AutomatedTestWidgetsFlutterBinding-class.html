AutomatedTestWidgetsFlutterBinding 类

这是 TestWidgetsFlutterBinding 的一个变体，通常用于在 flutter test 环境中执行测试，集成测试除外。

执行集成测试时，会改用 LiveTestWidgetsFlutterBinding。

此绑定控制时间，使测试能够验证较长的动画序列，而无需按真实时间运行。

此类假设始终在调试模式下运行（因为测试总是在调试模式下运行）。

测试运行时，绑定必须提供哪些 mixin，请参阅 TestWidgetsFlutterBinding。
