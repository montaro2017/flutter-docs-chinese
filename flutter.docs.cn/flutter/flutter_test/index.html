flutter_test 库

Flutter 的测试库，基于 package:test 构建。

测试配置

此测试库提供了一些结构，供项目配置测试。

按测试或文件配置

由于此测试库以 package:test 为基础，因此可以使用 package:test 现有的结构来初始化测试，包括 setUp 和 setUpAll 方法。

按目录层级配置

除了 package:test 提供的结构外，此库还支持按目录配置测试。

执行测试文件前，Flutter 测试框架会从测试文件所在目录开始沿目录层级向上查找名为 flutter_test_config.dart 的文件。如果找到该配置文件，框架会假定文件包含一个具有以下签名的 main 方法：

Future<void> testExecutable(FutureOr<void> Function() testMain) async { }

测试框架会执行该方法，并将测试的 main() 方法传入。配置文件中的 main() 方法负责调用测试自己的 main() 方法。

找到配置文件后，测试框架会停止向上扫描目录层级。也就是说，距离测试文件最近的配置文件会被选中，其他配置文件都会忽略。如果遇到 pubspec.yaml，框架也会停止扫描，因为该文件表示项目根目录。

如果没有找到配置文件，测试就会照常执行。

另请参阅：

  • WidgetController.hitTestWarningShouldBeFatal, which can be set in a flutter_test_config.dart file to turn warnings printed by WidgetTester.tap and similar APIs into fatal errors.
  • debugCheckIntrinsicSizes, which can be set in a flutter_test_config.dart file to enable deeper RenderBox tests of the intrinsic APIs automatically while laying out widgets.
