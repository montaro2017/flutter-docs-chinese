WidgetController
description

WidgetController 类 抽象

以编程方式与组件交互的类。

专为单元测试设计的此类变体，请参阅 WidgetTester。适用于设备实时测试的变体，请参阅 LiveWidgetController。

具体子类必须实现 pump 方法。

实现类
  • LiveWidgetController
  • WidgetTester

构造函数

WidgetController(WidgetsBinding binding)
创建一个使用给定绑定的 WidgetController。
