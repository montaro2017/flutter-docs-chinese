Finder backButton()

查找标准的“返回”按钮。

许多用户界面中都有“返回”按钮，用于让用户返回上一页、上一个屏幕或上一个状态。

测试中经常需要查找此类按钮，以便点击它们或验证它们是否存在。但不同平台和语言区域使用的图标、标签和工具提示各不相同，因此不适合依据这些属性查找。

此查找器使用 StandardComponentType 枚举查找带有 StandardComponentType.backButton 对应键的按钮。如果其他 widget 被赋予该键，它也会被视为 widget 树中的“官方”返回按钮，因此即使使用不同的图标或工具提示，此匹配器仍能找到它。

示例代码

expect(find.backButton(), findsOneWidget);

另请参阅：

  • StandardComponentType：用于枚举用户界面中常见组件的枚举类型。这些组件在不同平台、地区设置和设备上的呈现方式可能略有不同。
  • BackButton, the Flutter Material widget that represents the back button.

实现

Finder backButton() {
  return byKey(StandardComponentType.backButton.key);
}
