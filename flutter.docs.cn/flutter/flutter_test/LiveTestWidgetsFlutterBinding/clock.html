当前时间。

在自动化测试环境（flutter test）中，这是一个虚拟时钟：测试开始时从 2015 年 1 月开始计时，每次以非零时长调用 pump 时都会推进。

在实时测试环境（flutter run）中，此对象显示实际的墙上时钟时间。

实现

@override
Clock get clock => const Clock();
