由引擎调用，使框架准备生成新帧。

此函数会调用通过 scheduleFrameCallback 注册的所有临时帧回调。随后函数返回，运行所有已调度的微任务（例如临时帧回调所解析的 Future 的处理器），然后调用 handleDrawFrame 继续处理此帧。

如果给定的时间戳为 null，则会沿用上一帧的时间戳。

若要在调试模式下于每帧开始时显示横幅，请将 debugPrintBeginFrameBanner 设为 true。横幅会通过 debugPrint 输出到控制台，并包含帧编号（每帧递增 1）和帧时间戳。如果给定的时间戳为 null，则会显示“预热帧”而非时间戳。这样可以区分框架主动推进的帧与引擎响应操作系统“Vsync”信号而请求的帧。

也可以将 debugPrintEndFrameBanner 设为 true，在每帧结束时显示横幅。这样可以区分帧内打印的日志语句与帧间打印的日志语句（例如响应事件或计时器时）。

@override
void handleBeginFrame(Duration? rawTimeStamp) {
  if (_drawFrame != _HandleDrawFrame.reset) {
    throw StateError('handleBeginFrame() called before previous handleDrawFrame()');
  }
  if (_expectingFrame ||
      _expectingFrameToReassemble ||
      (framePolicy == LiveTestWidgetsFlutterBindingFramePolicy.fullyLive) ||
      (framePolicy == LiveTestWidgetsFlutterBindingFramePolicy.benchmarkLive) ||
      (framePolicy == LiveTestWidgetsFlutterBindingFramePolicy.benchmark) ||
      (framePolicy == LiveTestWidgetsFlutterBindingFramePolicy.fadePointers && _viewNeedsPaint)) {
    _drawFrame = _HandleDrawFrame.drawFrame;
    super.handleBeginFrame(rawTimeStamp);
  } else {
    _drawFrame = _HandleDrawFrame.skipFrame;
  }
}
