scheduleForcedFrame 方法

  1. @重写
void scheduleForcedFrame()
重写

通过调用 dart:ui.PlatformDispatcher.scheduleFrame 强制安排新帧。

调用后，即使 scheduleFrame 通常不会安排帧（例如设备屏幕已关闭），引擎仍会调用 handleBeginFrame。

手机旋转时，框架会使用此方法强制以正确尺寸渲染一帧，这样屏幕重新亮起时就能显示尺寸正确的画面。

若要在此函数每次安排帧时都向控制台打印堆栈跟踪，请将 debugPrintScheduleFrameStacks 设为 true。

除非必须立即安排帧，否则优先使用 scheduleFrame；当设备本应处于空闲状态时，使用 scheduleForcedFrame 会显著增加电池消耗。

如果目的是尽快更新渲染（例如应用启动时），请考虑改用 scheduleWarmUpFrame。

实现

@override
void scheduleForcedFrame() {
  if (framePolicy == LiveTestWidgetsFlutterBindingFramePolicy.benchmark) {
    // In benchmark mode, don't actually schedule any engine frames.
    return;
  }
  super.scheduleForcedFrame();
}
