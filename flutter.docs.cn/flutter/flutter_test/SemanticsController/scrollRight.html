scrollRight 方法

void scrollRight({
  1. FinderBase<SemanticsNode>? scrollable,
})

对由 scrollable 找到的 SemanticsNode 执行 SemanticsAction.scrollRight 操作；如果未提供 scrollable，则对默认语义树中的第一个可滚动节点执行该操作。

在以下情况下抛出 StateError：

  • 给定的 scrollable 返回的结果数量不为 1。
  • 通过 scrollable 找到的 SemanticsNode 不支持 SemanticsAction.scrollRight。

实现

void scrollRight({finders.FinderBase<SemanticsNode>? scrollable}) {
  performAction(scrollable ?? finders.find.semantics.scrollable(), SemanticsAction.scrollRight);
}
