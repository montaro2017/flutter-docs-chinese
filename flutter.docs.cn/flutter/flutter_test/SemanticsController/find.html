SemanticsNode find(
  1. FinderBase<Element> finder
)

尝试查找 finder 第一个结果对应的 SemanticsNode。

如果查找器标识的对象没有自己的语义节点，则返回第一个具有语义的祖先节点的语义数据。该祖先的语义数据会包含此子节点以及其他已合并节点的信息。

如果查找器标识对象的 SemanticsNode 被强制合并到某个祖先节点（例如通过 MergeSemantics 组件），则返回合并后的节点。该节点将包含所有被合并节点的语义信息。

如果查找器返回多个元素，或者找不到语义信息或语义未启用，则抛出 StateError。

实现

SemanticsNode find(finders.FinderBase<Element> finder) {
  TestAsyncUtils.guardSync();
  final Iterable<Element> candidates = finder.evaluate();
  if (candidates.isEmpty) {
    throw StateError('Finder returned no matching elements.');
  }
  if (candidates.length > 1) {
    throw StateError('Finder returned more than one element.');
  }
  final Element element = candidates.single;
  RenderObject? renderObject = element.findRenderObject();
  SemanticsNode? result = renderObject?.debugSemantics;
  while (renderObject != null && (result == null || result.isMergedIntoParent)) {
    renderObject = renderObject.parent;
    result = renderObject?.debugSemantics;
  }
  if (result == null) {
    throw StateError('No Semantics data found.');
  }
  return result;
}
