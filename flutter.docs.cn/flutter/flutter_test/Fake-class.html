Fake

Fake 类 抽象 mixin

用作其他对象的替身；除非某些方法已被明确重写，否则不能使用该对象。

对于每个字段和方法，fake 的默认行为都是抛出 UnimplementedError。测试代码会用到的字段和方法，应在实现类中手动重写。

fake 不支持从测试中验证调用或定义行为，因此不能用作 mock。

大多数情况下，共享且完整、没有 noSuchMethod 的 fake 实现比 extends Fake 更合适；不过，与混合手动 @override 实现的 extends Mock 相比，extends Fake 更合适。

使用示例：

// Real class.
class Cat {
  String meow(String suffix) => 'Meow$suffix';
  String hiss(String suffix) => 'Hiss$suffix';
}

// Fake class.
class FakeCat extends Fake implements Cat {
  @override
  String meow(String suffix) => 'FakeMeow$suffix';
}

void main() {
  // Create a new fake Cat at runtime.
  var cat = new FakeCat();

  // Try making a Cat sound...
  print(cat.meow('foo')); // Prints 'FakeMeowfoo'
  print(cat.hiss('foo')); // Throws
}

警告：Fake 使用 noSuchMethod，这属于一种运行时反射，会导致生成的代码质量较低。因此，Fake 严禁用于生产代码，尤其是在 Dart Web（dart2js、DDC）和 Dart Mobile（Flutter）环境中。
