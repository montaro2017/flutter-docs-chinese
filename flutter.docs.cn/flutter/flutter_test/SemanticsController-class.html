SemanticsController 类

以编程方式与 Semantics 树交互的类。

用于测试 Semantics 树。辅助技术、搜索引擎和其他分析软件会利用该树确定应用的含义。

应通过 WidgetController.semantics 访问。如果没有提供自定义实现，则会创建默认的 SemanticsController。
