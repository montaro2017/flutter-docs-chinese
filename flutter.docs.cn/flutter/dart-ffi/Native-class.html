Native

Native<T> 类 final

用于将外部声明绑定到其本机实现的注解。

只能用于静态函数、顶层函数和变量的 external 声明。

带有 Native 注解的 external 函数由本机代码实现。实现位于 assetId 指定的本机库中。类似地，带有 Native 注解的 external 变量通过读取或写入本机内存来实现。

编译器和/或运行时会建立从 assetId 到本机库的绑定关系，具体取决于目标平台。随后，编译器/运行时可以在本机库中解析或查找符号（标识符），以找到本机函数或本机全局变量，并将 external Dart 函数或变量声明绑定到对应的本机声明。默认情况下，运行时会查找与 Dart 中注解函数或变量同名的本机符号。可以通过注解的 symbol 参数覆盖此名称。

用于函数时，T 必须是表示本机函数参数和返回类型的函数类型。参数和返回类型必须是 NativeType 的子类型。

用于变量时，T 必须是兼容的本机类型。例如，可以使用 Int32 注解 int 字段。

如果省略 @Native 注解中的类型参数 T，系统会根据声明的静态类型推断该参数；该类型必须满足以下约束：

对于函数或方法声明：

  • 返回类型必须是以下之一：
    • Pointer
    • void
    • 复合类型的子类型，例如 Struct 或 Union
  • 参数类型必须是复合类型或 Pointer 的子类型
  • The parameter types must be subtypes of compound types or Pointer

    • 对于变量声明，类型可以是以下任意一种：

    • Pointer
    • 复合类型的子类型，例如 Struct 或 Union

    对于不可重新赋值的本机全局变量，可以在 Dart 中使用 final 变量或 getter，以防止修改本机字段。

    示例：

    @Native<Int64 Function(Int64, Int64)>()
external int sum(int a, int b);

@Native()
external void free(Pointer p);

@Native<Int64>()
external int aGlobalInt;

@Native()
external final Pointer<Char> aGlobalString;

    调用 @Native 函数，以及读取或写入 @Native 变量时，会按以下顺序尝试解析 symbol：

    1. 提供的或默认的 assetId；
    2. 在 dart_api.h 中使用 Dart_SetFfiNativeResolver 设置的本机解析器；以及
    3. 当前进程。

    这三种方式中必须至少有一种能为该符号提供绑定，否则方法调用或变量访问会失败。

    注意：这是一项实验性功能，未来可能会发生变化。
