UnsignedInt

UnsignedInt 类 final

C 语言的 unsigned int 类型。

通常是无符号 32 位整数。 如需保证为 32 位整数，请使用 C uint32_t 类型对应的 Uint32。 对于有符号 int，请使用 Int。

UnsignedInt 是一种原生类型，不应在 Dart 代码中构造。 它只出现在原生类型签名中，以及作为 Struct 和 Union 字段的注解。
