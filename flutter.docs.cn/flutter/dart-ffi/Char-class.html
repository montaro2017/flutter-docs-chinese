Char

Char 类 final

C 语言的 char 类型。

通常是有符号或无符号的 8 位整数。若要保证使用 8 位整数，请将 Int8 与 C 的 int8_t 类型配合使用，或将 Uint8 与 C 的 uint8_t 类型配合使用。若要明确指定 signed 或 unsigned char，请使用 SignedChar 或 UnsignedChar。

Char 是本机类型，不应在 Dart 代码中构造。它只会出现在本机类型签名中，以及作为 Struct 和 Union 字段的注解。
