assetId

assetId 属性

String? assetId
final

如果不使用默认值，此处指定解析 symbol 时使用的资源 ID。

如果未指定资源名称，则默认使用当前库的 library 声明上 DefaultAsset 注解指定的资源 ID；如果当前库没有 DefaultAsset 注解，则改用该库的 URI 字符串。

示例（文件 package:a/a.dart）：

@Native<Int64 Function(Int64, Int64)>()
external int sum(int a, int b);

示例 2（文件 package:a/a.dart）：

@DefaultAsset('package:a/a.dart')
library a;

import 'dart:ffi';

@Native<Int64 Function(Int64, Int64)>()
external int sum(int a, int b);

示例 3（文件 package:a/a.dart）：

@Native<Int64 Function(Int64, Int64)>(assetId: 'package:a/a.dart')
external int sum(int a, int b);

以上三个示例等效。

如果可能，优先使用库 URI 作为资源名称，而不是显式指定资源名称。与在 Native 注解中指定资源名称相比，优先在 library 声明上使用 DefaultAsset。
