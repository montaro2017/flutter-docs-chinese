Abi

Abi 类

应用程序二进制接口（ABI）。

ABI 定义数据的内存布局以及本机代码的函数调用协议。通常由操作系统针对其运行的每种体系结构分别定义。

Dart VM 可以运行在多种操作系统和体系结构上。支持的 ABI 由 Abi 对象表示。所有受支持的 ABI 请参阅 values。
