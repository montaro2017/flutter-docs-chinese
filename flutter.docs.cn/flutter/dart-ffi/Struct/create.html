从 typedData 中的字节创建一个结构体视图。

创建的结构体子类实例将由位于 TypedData.offsetInBytes 加上 offset 乘以 TypedData.elementSizeInBytes 处的字节提供后备存储。也就是说，该子类声明的外部实例变量的 getter 和 setter 会从 typedData 的 TypedData.buffer 中读取或写入值，起始位置为 TypedData.offsetInBytes 加上 offset 乘以 TypedData.elementSizeInBytes。typedData 的 TypedData.lengthInBytes 必须足以容纳该结构体子类的 sizeOf。无论 typedData 是 Uint8List、Float64List 还是其他 TypedData，都没有区别；它只会通过其 TypedData.buffer、TypedData.offsetInBytes 和 TypedData.lengthInBytes 被视为 ByteBuffer 的视图。

如果省略 typedData，则会在 Dart 堆上分配一个全新的 ByteBuffer，其大小恰好足以容纳所创建结构体的 sizeOf，并将其用作存储结构体字段的内存。

如果提供了 offset，则访问 typedData 时会偏移 offset 乘以 TypedData.elementSizeInBytes。

示例：

final class Point extends Struct {
  @Double()
  external double x;

  @Double()
  external double y;

  /// Creates Dart managed memory to hold a `Point` and returns the
  /// `Point` view on it.
  factory Point(double x, double y) {
    return Struct.create()
      ..x = x
      ..y = y;
  }

  /// Creates a [Point] view on [typedData].
  factory Point.fromTypedData(TypedData typedData) {
    return Struct.create(typedData);
  }
}

要从 Pointer 创建结构体对象，请使用 StructPointer.ref。
