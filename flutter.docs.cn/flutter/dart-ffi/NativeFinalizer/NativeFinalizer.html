NativeFinalizer(
  1. Pointer<NativeFinalizerFunction> callback

使用给定的终结回调创建终结器。

callback 必须是可以在 Dart isolate 之外执行的本机函数。因此，不支持传入 FFI 跳板（通过 Pointer.fromFunction 获得的函数指针）。

回调不得通过 Dart C API 重新进入 Dart VM，但有两个例外：允许调用 Dart_DeletePersistentHandle 和 Dart_DeleteWeakPersistentHandle。调用其他任何 Dart C API 函数都会导致未定义行为，可能引发崩溃、死锁或无提示的内存损坏等问题。

callback 可能会在任意线程上调用。该线程会有当前 isolate 组，但没有当前 isolate。
