address 属性

Pointer<Uint8> get address

底层数据的内存地址。

表示此 address 的 expression.address 形式的表达式，只能作为调用叶子 Native 外部函数时的完整参数表达式出现。

示例：

@Native<Void Function(Pointer<Uint8>)>(isLeaf: true)
external void myFunction(Pointer<Uint8> pointer);

void main() {
  final list = Uint8List(10);
  myFunction(list.address);
}

.address 之前的表达式会像赋值语句左侧一样求值，得到可访问该表达式背后存储空间的对象，可用于读取和写入。随后，.address 会提供指向该存储空间的本机指针。

调用叶子 Native 外部函数时，会在即将进入本机代码前求值 .address。这样可以确保 Dart 垃圾回收器不会移动该地址所指向的对象。
