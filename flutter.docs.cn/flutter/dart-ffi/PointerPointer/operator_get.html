Pointer<T> operator [](
  1. int index
)

从此位置偏移 index 处加载 Dart 值。

存储时会先将 Pointer 解箱（相当于使用 .address）；加载时会将指针装箱（相当于使用 Pointer.fromAddress）。

在 32 位平台上，address 必须按 4 字节对齐；在 64 位平台上，address 必须按 8 字节对齐。
