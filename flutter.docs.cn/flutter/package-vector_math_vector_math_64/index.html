vector_math_64

vector_math_64 库

此库包含多种向量运算，可用于游戏、模拟或渲染。

该库包含向量类（Vector2、Vector3 和 Vector4）、矩阵类（Matrix2、Matrix3 和 Matrix4），以及与碰撞检测相关的类（Aabb2、Aabb3、Frustum、Obb3、Plane、Quad、Ray、Sphere 和 Triangle）。

此外还提供了一些实用功能，例如颜色运算（参见 Colors 类）和常见的 OpenGL 运算（例如 makeViewMatrix、makePerspectiveMatrix 或 pickRay）。
