Cookie

Cookie 类 抽象 interface

Cookie 的表示形式。对于服务器通过 Cookie 标头值接收的 Cookie，只会设置 name 和 value 属性。在服务器端构造用于 “set-cookie” 标头的 Cookie，以及客户端通过 “set-cookie” 标头接收 Cookie 时，可以使用所有字段。
