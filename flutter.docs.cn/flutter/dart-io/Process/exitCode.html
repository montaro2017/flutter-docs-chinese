exitCode 属性

Future<int> get exitCode

一个 Future，进程结束时会以该进程的退出代码完成。

以 ProcessStartMode.detached 或 ProcessStartMode.detachedWithStdio 模式运行的进程没有可用的退出代码；使用此 getter 会抛出 StateError。

退出代码的处理方式因平台而异。

在 Linux 和 OS X 上，正常退出代码是 [0..255] 范围内的正值。如果进程因信号而终止，退出代码是 [-255..-1] 范围内的负值，其绝对值就是信号编号。例如，进程因段错误崩溃时，退出代码为 -11，因为 SIGSEGV 信号编号为 11。

在 Windows 上，进程可以将任意 32 位值作为退出代码。返回时，此代码会转换为有符号值。某些特殊值用于报告系统事件导致的终止。例如，进程因访问冲突崩溃时，32 位退出代码为 0xc0000005，返回值则为负数 -1073741819。若要获取原始 32 位值，请使用 (0x100000000 + exitCode) & 0xffffffff。

无法保证返回的 future 完成时，stdout 和 stderr 已报告完进程的缓冲输出。若要确保捕获全部输出，请等待这些流发出 done 事件。
