启动进程并以非交互方式运行至结束。运行的进程以 executable 为可执行文件，并接收指定的 arguments。

建议为 executable 使用绝对路径，因为可执行文件路径的解析方式因平台而异。在 Windows 上，解析 executable 路径时，会忽略 PATH（在 environment 映射参数中设置）以及 workingDirectory 参数中设置的路径，并忽略其中的 executable 路径。

使用 workingDirectory 设置进程的工作目录。请注意，在某些平台上，会先切换目录再执行进程；使用相对路径指定可执行文件和参数时，这可能会产生影响。

使用 environment 设置进程的环境变量。如果未设置，则继承父进程的环境。目前仅支持 US-ASCII 环境变量；如果传入包含 US-ASCII 范围之外码点的环境变量，可能会发生错误。

如果 includeParentEnvironment 为 true，进程的环境将包含父进程的环境，且 environment 中的设置优先。默认值为 true。

如果 runInShell 为 true，进程将通过系统 shell 启动。在 Linux 和 OS X 上使用 /bin/sh；在 Windows 上使用 %WINDIR%\system32\cmd.exe。

注意：在 Windows 上，如果 executable 是批处理文件（.bat 或 .cmd），无论 runInShell 的值如何，操作系统都可能通过系统 shell 启动它。因此，参数可能会按照 shell 规则解析。例如：

void main() async {
  // Will launch notepad.
  await Process.run('test.bat', ['test&notepad.exe']);
}

将 stdout 和 stderr 解码为文本时所用的编码由 stdoutEncoding 和 stderrEncoding 控制。默认编码为 systemEncoding。如果使用 null，则不会进行解码，ProcessResult 将保存二进制数据。

返回一个 Future<ProcessResult>，进程运行结束后会以运行结果完成，即退出代码、标准输出和标准错误。

以下代码在 Linux 上使用 Process.run 在 test.dart 文件中搜索 main。

var result = await Process.run('grep', ['-i', 'main', 'test.dart']);
stdout.write(result.stdout);
stderr.write(result.stderr);
