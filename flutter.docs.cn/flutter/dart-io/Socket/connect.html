与指定主机和端口建立新的套接字连接，并返回一个 Future：连接成功后以 Socket 完成；如果主机查找或连接失败，则以错误完成。

host 可以是 String 或 InternetAddress。如果 host 是 String，connect 会执行 InternetAddress.lookup，并依次尝试连接其返回的所有 InternetAddress。如果未能建立连接，则返回第一个失败连接产生的错误。

可以使用 sourceAddress 参数指定建立连接时要绑定的本地地址。sourceAddress 可以是 String 或 InternetAddress。如果传入 String，其内容必须是数字形式的 IP 地址。

sourcePort 参数指定要绑定的本地端口。如果未指定 sourcePort 或指定为零，则会自动选择一个端口。

timeout 参数用于指定等待连接建立的最长时间。如果 timeout 长于系统级超时时长，实际超时可能早于 timeout 指定的时间。超时时会抛出 SocketException，并取消所有正在进行的 host 连接尝试。

实现

static Future<Socket> connect(
  host,
  int port, {
  sourceAddress,
  int sourcePort = 0,
  Duration? timeout,
}) {
  final IOOverrides? overrides = IOOverrides.current;
  if (overrides == null) {
    return Socket._connect(
      host,
      port,
      sourceAddress: sourceAddress,
      sourcePort: sourcePort,
      timeout: timeout,
    );
  }
  return overrides.socketConnect(
    host,
    port,
    sourceAddress: sourceAddress,
    sourcePort: sourcePort,
    timeout: timeout,
  );
}
