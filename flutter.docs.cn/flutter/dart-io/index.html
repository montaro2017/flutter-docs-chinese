dart:io

dart:io 库

为非 Web 应用提供文件、套接字、HTTP 及其他输入输出支持。

重要：基于浏览器的应用无法使用此库。只有以下环境可以导入并使用 dart:io 库：

  • 服务器
  • 命令行脚本
  • Flutter 移动应用
  • Flutter 桌面应用

此库允许你操作文件、目录、套接字、进程、HTTP 服务器和客户端等。许多与输入输出相关的操作都是异步的，并通过 Future 或 Stream 处理；这两个类型都定义在 dart:async 库中。

在代码中使用 dart:io 库：

import 'dart:io';

有关 Dart 输入输出的介绍，请参阅 dart:io 库概览。

File、Directory 和 Link

File、Directory 或 Link 实例分别表示本机文件系统中的文件、目录或链接。

可以通过这些类型的对象操作文件系统。例如，可以重命名文件或目录：

File myFile = File('myFile.txt');
myFile.rename('yourFile.txt').then((_) => print('file renamed'));

File、Directory 和 Link 类提供的许多方法会异步运行并返回 Future。

FileSystemEntity

File、Directory 和 Link 都继承自 FileSystemEntity。除了作为这些类的父类之外，FileSystemEntity 还提供多个用于处理路径的静态方法。

要获取路径信息，可以使用 FileSystemEntity 的静态方法，例如 FileSystemEntity.isDirectory、FileSystemEntity.isFile 和 FileSystemEntity.exists。由于文件系统访问涉及输入输出，这些方法是异步的，并返回 Future。

FileSystemEntity.isDirectory(myPath).then((isDir) {
  if (isDir) {
    print('$myPath is a directory');
  } else {
    print('$myPath is not a directory');
  }
});

HttpServer 和 HttpClient

HttpClient 和 HttpServer 类提供底层 HTTP 功能。

与直接使用这些类相比，可以考虑使用软件包中更便于开发者使用且更易组合的 API。

对于 HTTP 客户端，请参阅 package:http。

对于 HTTP 服务器，请参阅 “编写 HTTP 服务器”（位于 dart.dev）。

进程

Process 类提供了在本机运行进程的方法。例如，下面的代码会启动一个进程，递归列出 web 目录下 web 中的文件。

Process.start('ls', ['-R', 'web']).then((process) {
  stdout.addStream(process.stdout);
  stderr.addStream(process.stderr);
  process.exitCode.then(print);
});

使用 Process.start 会返回一个 Future；进程启动后，该 Future 会以 Process 对象完成。此 Process 对象允许你在进程运行期间与其交互。使用 Process.run 也会返回一个 Future；启动的进程终止后，该 Future 会以 ProcessResult 对象完成。此 ProcessResult 对象会收集进程的输出和退出代码。

使用 Process.start 时，必须读取 Process.stdout 和 Process.stderr 流中的所有数据，否则系统资源将无法释放。

WebSocket

WebSocket 类支持 WebSocket 协议，可实现客户端与服务器应用之间的全双工通信。

WebSocket 服务器使用普通 HTTP 服务器接收 WebSocket 连接。初始握手是一个 HTTP 请求，随后会将其升级为 WebSocket 连接。服务器使用 WebSocketTransformer 升级请求，并监听返回的 WebSocket 上的数据。例如，下面是一个监听 WebSocket 上“ws”数据的简易服务器：

runZoned(() async {
  var server = await HttpServer.bind('127.0.0.1', 4040);
  server.listen((HttpRequest req) async {
    if (req.uri.path == '/ws') {
      var socket = await WebSocketTransformer.upgrade(req);
      socket.listen(handleMsg);
    }
  });
}, onError: (e) => print("An error occurred."));

客户端使用 WebSocket.connect 方法和 WebSocket 协议 URI 连接到 WebSocket。客户端可以通过 WebSocket.add 方法向 WebSocket 写入数据。例如：

var socket = await WebSocket.connect('ws://127.0.0.1:4040/ws');
socket.add('Hello, World!');

可以查看 websocket_sample 应用；它使用 WebSocket 与服务器通信。

Socket 和 ServerSocket

客户端和服务器使用 Socket 通过 TCP 协议通信。在服务器端使用 ServerSocket，在客户端使用 Socket。服务器通过 bind() 方法创建监听套接字，然后在该套接字上监听传入连接。例如：

ServerSocket.bind('127.0.0.1', 4041)
  .then((serverSocket) {
    serverSocket.listen((socket) {
      socket.transform(utf8.decoder).listen(print);
    });
  });

客户端使用 connect() 方法连接 Socket，该方法会返回一个 Future。使用 write()、writeln() 或 writeAll() 是通过套接字发送数据最简单的方式。例如：

Socket.connect('127.0.0.1', 4041).then((socket) {
  socket.write('Hello, World!');
});

除了 Socket 和 ServerSocket，还提供 RawSocket 和 RawServerSocket 类，用于以更底层的方式访问异步套接字输入输出。

标准输出、错误和输入流

此库提供标准输出、错误和输入流，分别命名为 stdout、stderr 和 stdin。

stdout 和 stderr 都是 IOSink，并拥有相同的一组方法和属性。

向 stdout 写入字符串：

stdout.writeln('Hello, World!');

向 stderr 写入对象列表：

stderr.writeAll([ 'That ', 'is ', 'an ', 'error.', '\n']);

标准输入流是真正的 Stream，因此继承了 Stream 类的属性和方法。

从命令行同步读取文本（程序会阻塞，等待用户输入信息）：

String? inputText = stdin.readLineSync();
