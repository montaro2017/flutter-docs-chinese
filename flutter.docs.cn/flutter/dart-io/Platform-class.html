Platform

Platform 类 抽象 final

有关当前程序运行环境的信息。

Platform 提供操作系统、计算机主机名、环境变量值、正在运行的程序路径以及该程序的其他全局属性等信息。

获取当前 Dart 脚本的 URI

使用 script getter 获取当前正在运行的 Dart 脚本 URI。

import 'dart:io' show Platform;

void main() {
  // Get the URI of the script being run.
  var uri = Platform.script;
  // Convert the URI to a path.
  var path = uri.toFilePath();
}

获取环境变量的值

environment getter 会在 Map 中返回环境变量的名称和值，其中键和值都是字符串。此 Map 不可修改。以下示例展示如何获取 PATH 环境变量的值。

import 'dart:io' show Platform;

void main() {
  Map<String, String> envVars = Platform.environment;
  print(envVars['PATH']);
}

确定操作系统

可以使用 operatingSystem getter 获取表示操作系统名称的字符串。也可以使用静态布尔 getter，例如 isMacOS、isLinux、isWindows 等。

import 'dart:io' show Platform;

void main() {
  // Get the operating system as a string.
  String os = Platform.operatingSystem;
  // Or, use a predicate getter.
  if (Platform.isMacOS) {
    print('is a Mac');
  } else {
    print('is not a Mac');
  }
}
