ZLibCodec

ZLibCodec 类 final

ZLibCodec 会将原始字节编码为 ZLib 压缩字节，也会将 ZLib 压缩字节解码为原始字节。

level → int
压缩级别level 可设置的范围为-1..9，其中6 是默认压缩级别。高于6 会提高压缩率，但会增加 CPU 和内存占用。低于 6 会减少 CPU 和内存占用，但压缩率也会降低。
final
memLevel → int
指定内部压缩状态应分配的内存量。1 使用最少内存，但速度较慢且压缩率较低； 9 使用最多内存以获得最佳速度。默认值为8.
final
raw → bool
为 true 时，deflate 会生成不带 zlib 头部或尾部的原始数据，并且不会计算 adler32 校验值。

strategy → int
调整压缩算法。普通数据使用 strategyDefault；由过滤器（或预测器）生成的数据使用 strategyFiltered；仅使用 Huffman 编码（不进行字符串匹配）时使用 strategyHuffmanOnly；匹配距离限制为 1（游程编码）时使用 strategyRle。
final
windowBits → int
窗口大小（历史缓冲区大小）的以 2 为底的对数。取值范围为 8..15。数值越大，压缩率越高，但内存占用也越大。默认值为 15
