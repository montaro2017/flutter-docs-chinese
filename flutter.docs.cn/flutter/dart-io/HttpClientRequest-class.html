HttpClientRequest

HttpClientRequest 类 抽象 interface

用于客户端连接的 HTTP 请求。

要构造请求，请使用此类提供的 headers 属性设置标头，并将数据写入请求正文。HttpClientRequest 是一个 IOSink。可以使用 IOSink 的方法（例如 writeCharCode()）写入 HTTP 请求正文。首次调用任一 IOSink 方法时，请求标头会被发送。标头发送后再调用任何会更改标头的方法，都会抛出异常。

通过 IOSink 写入字符串数据时，所用编码由“Content-Type”标头的“charset”参数决定。

var client = HttpClient();
HttpClientRequest request = await client.get('localhost', 80, '/file.txt');
request.headers.contentType =
    ContentType('application', 'json', charset: 'utf-8');
request.write('text content👍🎯'); // Strings written will be UTF-8 encoded.

如果未提供 charset，则默认使用 ISO-8859-1（Latin 1）。

var client = HttpClient();
HttpClientRequest request = await client.get('localhost', 80, '/file.txt');
request.headers.add(HttpHeaders.contentTypeHeader, "text/plain");
request.write('blåbærgrød'); // Strings written will be ISO-8859-1 encoded

如果使用不受支持的编码，并且所调用的 write() 方法接受字符串参数，则会抛出异常。
