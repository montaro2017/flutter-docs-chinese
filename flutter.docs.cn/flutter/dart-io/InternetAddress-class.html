InternetAddress

InternetAddress 类 抽象 interface

互联网地址或 Unix 域地址。

此对象保存一个互联网地址。如果该地址来自 DNS 查找，对象还会保存用于查找的主机名。互联网地址与端口号组合后表示一个端点，套接字可以连接到该端点，监听套接字也可以绑定到该端点。
