HttpClient

HttpClient 类 抽象 interface

用于与 HTTP 服务器通信的 HTTP 客户端。

注意：应避免直接使用 HttpClient 发送 HTTP 请求。你可以通过 HttpClient，借助 IOClient 适配器，间接使用 package:http。

使用更高层次的库（例如 package:http）可以让你以最少的代码改动切换实现。例如，package:http 的 Client 提供了适用于浏览器的实现，以及在 Android 和 iOS 上使用平台原生 HTTP 客户端的实现。与 HttpClient 不同，这些原生实现可以使用代理、VPN 等系统功能。

向 HTTP 服务器发送请求并接收响应。在向同一服务器发送多个请求时，会维护会话 Cookie 及其他 Cookie 等状态。

HttpClient 提供多种方法，用于向 HTTP 服务器发送 HttpClientRequest 并接收 HttpClientResponse。例如，GET 和 POST 请求分别可以使用 get、getUrl、post 和 postUrl 方法。

简单 GET 请求示例

getUrl 请求分为两个步骤，由两个 Future 触发。第一个 Future 完成并返回 HttpClientRequest 时，底层网络连接已建立，但尚未发送任何数据。你可以在第一个 Future 的回调函数中设置请求的 HTTP 标头和正文。首次向请求对象写入数据或调用 close 时，请求会发送到服务器。

从服务器收到 HTTP 响应后，由 close 返回的第二个 Future 会以 HttpClientResponse 对象完成。此对象可用于访问响应的标头和正文。正文以 HttpClientResponse 实现的流形式提供。如果响应包含正文，就必须读取它，否则会导致资源泄漏。如果不需要正文，可以考虑使用 HttpClientResponse.drain。

var client = HttpClient();
try {
  HttpClientRequest request = await client.get('localhost', 80, '/file.txt');
  // Optionally set up headers...
  // Optionally write to the request object...
  HttpClientResponse response = await request.close();
  // Process the response
  final stringData = await response.transform(utf8.decoder).join();
  print(stringData);
} finally {
  client.close();
}

用于 HttpClientRequest 的 Future 由 getUrl 和 open 等方法创建。

HTTPS 连接

HttpClient 可以通过 TLS（SSL）安全网络协议连接服务器并发送 HTTPS 请求。如果服务器证书由 Mozilla 编译的默认可信 CA（证书颁发机构）列表中的根 CA 签名，则使用 https: scheme 调用 getUrl 即可自动建立连接。

若要添加自定义可信证书颁发机构，或向要求客户端证书的服务器发送客户端证书，请将 SecurityContext 对象作为可选的 context 参数传递给 HttpClient 构造函数。所需的安全选项可以在 SecurityContext 对象上设置。

标头

所有 HttpClient 请求默认都会设置以下标头：

Accept-Encoding: gzip

这样一来，如果可能，HTTP 服务器就可以对正文使用 gzip 压缩。如果不需要此行为，请将 Accept-Encoding 标头设为其他值。若要关闭响应的 gzip 压缩，请清除此标头：

 request.headers.removeAll(HttpHeaders.acceptEncodingHeader)

关闭 HttpClient

HttpClient 支持持久连接，并会缓存网络连接，以便在可能时将其用于多个请求。因此，请求完成后，网络连接仍可能保持打开一段时间。使用 HttpClient.close 可以关闭 HttpClient 对象并断开空闲网络连接。

启用和禁用代理

默认情况下，HttpClient 使用环境中提供的代理配置，详见 findProxyFromEnvironment。若要禁用代理，请将 findProxy 属性设为 null。

HttpClient client = HttpClient();
client.findProxy = null;
