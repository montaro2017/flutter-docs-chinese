ContentType

ContentType 类 抽象 interface

用作 HttpHeaders.contentTypeHeader 标头值的 MIME/IANA 媒体类型。

ContentType 是不可变对象。

实现的类型
  • HeaderValue

构造函数

ContentType(String primaryType, String subType, {String? charset, Map<String, String?> parameters = const {}})
创建新的内容类型对象，并设置主类型和子类型。也可通过 charset 和 parameters 设置字符集及其他参数。如果传入 charset，且 parameters 也包含 charset，则传入的 charset 会覆盖 parameters 中的值。parameters 中传入的键会转换为小写。charset 条目无论是以 charset 还是在 parameters 中传入，其值都会转换为小写。
