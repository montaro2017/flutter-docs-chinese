将套接字绑定到指定的 host 和 port。

套接字绑定并开始监听 port 后，返回的 future 会以已绑定套接字的 RawDatagramSocket 完成。

host 可以是 String 或 InternetAddress。如果 host 是 String，bind 会执行 InternetAddress.lookup，并使用列表中的第一个值。若只允许本地主机发起的传入连接，请使用 InternetAddress.loopbackIPv4 或 InternetAddress.loopbackIPv6，以便在环回接口上监听。若要允许来自任意网络的传入连接，可使用 InternetAddress.anyIPv4 或 InternetAddress.anyIPv6 绑定到所有接口，也可以使用特定接口的 IP 地址。

绑定到同一地址的所有监听器都应设置 reuseAddress，否则会抛出 SocketException。

reusePort 指定是否可以重复使用该端口。

ttl 设置通过此套接字发送的数据报的生存时间（time to live）。
