Stdout

Stdout 类

连接到进程标准输出或标准错误的 IOSink。

提供一个阻塞式 IOSink，因此使用它写入时会一直阻塞，直到输出完成。

在某些情况下，这种阻塞行为并不理想，因为它不具备 dart:io 通常提供的非阻塞行为。使用属性 nonBlocking 可获取具有非阻塞行为的 IOSink。

此类还可用于检查 stdout 或 stderr 是否连接到终端，并查询一些终端属性。

addError API 继承自 StreamSink。调用它会导致未处理的异步错误，除非为 done 设置了错误处理程序。

lineTerminator 字段供 write、writeln、writeAll 和 writeCharCode 方法使用，用于转换 "\n"。默认情况下，"\n" 会按字面值输出。
