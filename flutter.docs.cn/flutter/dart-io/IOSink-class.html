IOSink

IOSink 类 抽象 interface

组合字节和文本的输出接收器。 IOSink 将字节 StreamSink 与文本 StringSink 组合起来，便于同时输出字节和文本。 IOSink 用于写入字节。通过 write 或 writeCharCode 写入的字符串会使用 encoding 转换为字节。通过 add 或 addStream 添加的整数数据会被视为字节数据，并会像使用 int.toUnsigned 一样截断为无符号 8 位值。无法保证转换何时发生，因为这取决于 sink 的具体实现。 文本（write）和字节（add）可以自由交错写入。 通过 addStream 添加流期间，在 addStream 完成之前，任何进一步向 IOSink 添加或写入内容的操作都会失败。 sink 关闭后，向 IOSink 添加数据会导致错误。
