FileSystemEntity

FileSystemEntity 类 抽象

File、Directory 和 Link 的公共超类。

目录列表操作会返回 FileSystemEntity 对象。要判断某个 FileSystemEntity 是 File、Directory 还是 Link，请执行类型检查：

if (entity is File) (entity as File).readAsStringSync();

你也可以使用 type 或 typeSync 方法来确定文件系统对象的类型。

此类中的大多数方法都同时提供同步和异步版本，例如 exists 和 existsSync。除非有特定理由需要使用同步版本，否则建议优先使用异步版本，以免阻塞程序。

以下示例展示了 exists 方法的用法：

var isThere = await entity.exists();
print(isThere ? 'exists' : 'nonexistent');
