HttpServer

HttpServer 类 抽象

使用 HTTP 协议提供网页等内容的服务器。

注意：HttpServer 提供底层 HTTP 功能。建议用户评估 编写 HTTP 服务器教程中介绍的高级 API，详见 dart.dev。

HttpServer 是一种 Stream，提供 HttpRequest 对象。每个 HttpRequest 都有关联的 HttpResponse 对象。服务器通过向该 HttpResponse 对象写入内容来响应请求。以下示例展示了如何将 HttpServer 绑定到端口 80 上的 IPv6 InternetAddress（HTTP 服务器的标准端口），并监听请求。端口 80 是默认 HTTP 端口。不过，大多数系统需要超级用户权限才能访问该端口。本地测试时，可以使用非保留端口（1024 及以上）。

import 'dart:io';

void main() async {
  var server = await HttpServer.bind(InternetAddress.anyIPv6, 80);
  await server.forEach((HttpRequest request) {
    request.response.write('Hello, world!');
    request.response.close();
  });
}

对于不完整的请求（缺少全部或部分标头），服务器会忽略它们，不会为其生成异常或 HttpRequest 对象。同样，向 HttpResponse 写入时发生的任何 Socket 异常都会被忽略，后续写入也会被忽略。

HttpRequest 会公开请求标头，并在请求正文存在时将其作为数据流提供。如果正文尚未读取，服务器在向 HttpResponse 写入内容或关闭 HttpResponse 时会将其排空。

绑定安全 HTTPS 连接

使用 bindSecure 创建 HTTPS 服务器。

服务器会向客户端提供证书。证书链和私钥在 SecurityContext 对象中设置，并将该对象传递给 bindSecure。

import 'dart:io';

void main() async {
  var chain =
      Platform.script.resolve('certificates/server_chain.pem').toFilePath();
  var key = Platform.script.resolve('certificates/server_key.pem').toFilePath();
  var context = SecurityContext()
    ..useCertificateChain(chain)
    ..usePrivateKey(key, password: 'dartdart');
  var server =
      await HttpServer.bindSecure(InternetAddress.anyIPv6, 443, context);
  await server.forEach((HttpRequest request) {
    request.response.write('Hello, world!');
    request.response.close();
  });
}

证书和密钥均为 PEM 文件，可以使用 OpenSSL 工具创建和管理。
