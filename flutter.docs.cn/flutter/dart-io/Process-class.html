Process

Process 类 抽象 interface

用于执行程序的工具。

使用静态 start 和 run 方法启动新进程。run 方法会以非交互方式运行进程直至结束。相比之下，start 方法允许代码与正在运行的进程交互。

使用 run 方法启动进程

下面的代码示例使用 run 方法创建一个进程，用于运行 UNIX 命令 ls，该命令会列出目录内容。进程终止时，run 方法会以 ProcessResult 对象完成。该对象可用于访问进程的输出和退出代码。run 方法不会返回 Process 对象，因此代码无法与正在运行的进程交互。

import 'dart:io';

main() async {
  // List all files in the current directory in UNIX-like systems.
  var result = await Process.run('ls', ['-l']);
  print(result.stdout);
}

使用 start 方法启动进程

下面的示例使用 start 创建进程。start 方法会返回一个包含 Process 对象的 Future。Future 完成时，进程已经启动，代码便可与其交互，例如向 stdin 写入数据、监听 stdout 等。

下面的示例启动 UNIX cat 工具；如果不提供命令行参数，它会回显输入内容。程序向进程的标准输入流写入数据，并打印其标准输出流中的数据。

import 'dart:io';
import 'dart:convert';

main() async {
  var process = await Process.start('cat', []);
  process.stdout
      .transform(utf8.decoder)
      .forEach(print);
  process.stdin.writeln('Hello, world!');
  process.stdin.writeln('Hello, galaxy!');
  process.stdin.writeln('Hello, universe!');
}

标准输入输出流

如前一个代码示例所示，可以通过 getter stdout 与 Process 的标准输出流交互，也可以通过 getter stdin 与 Process 的标准输入流交互。此外，Process 还提供 getter stderr，用于访问 Process 的标准错误流。

Process 的流与当前程序的顶层流彼此独立。

注意：stdin、stdout 和 stderr 通过父进程与启动的子进程之间的管道实现。这些管道的容量有限。如果子进程写入 stderr 或 stdout 的数据超过容量，而输出又没有被读取，子进程就会阻塞，等待管道缓冲区腾出空间。例如：

import 'dart:io';

main() async {
  var process = await Process.start('cat', ['largefile.txt']);
  // The following await statement will never complete because the
  // subprocess never exits since it is blocked waiting for its
  // stdout to be read.
  await process.stderr.forEach(print);
}

退出代码

调用 exitCode 方法可获取进程的退出代码。退出代码表示程序是成功终止（通常以 0 表示），还是发生了错误。

如果使用 start 方法，可通过 Process 对象上的 Future 获取 exitCode（如下方示例所示）。如果使用 run 方法，则可通过 ProcessResult 实例上的 getter 获取 exitCode。

import 'dart:io';

main() async {
  var process = await Process.start('ls', ['-l']);
  var exitCode = await process.exitCode;
  print('exit code: $exitCode');
}
