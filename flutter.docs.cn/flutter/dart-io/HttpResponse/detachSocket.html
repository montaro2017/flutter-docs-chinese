将底层套接字从 HTTP 服务器分离。套接字分离后，HTTP 服务器将不再对其执行任何操作。

通常在收到 HTTP 升级请求、并且需要使用其他协议继续通信时调用此方法。

如果 writeHeaders 为 true，状态行和 headers 会在套接字分离前写入套接字。如果为 false，则会立即分离套接字，不向其写入任何数据。默认值为 true。
