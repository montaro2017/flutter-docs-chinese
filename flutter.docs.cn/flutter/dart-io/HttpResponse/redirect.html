redirect abstract 方法

Future redirect(
  1. Uri location, {
  2. int status = HttpStatus.movedTemporarily,
})
将响应设为重定向到 location。

location 中的 URI 应为绝对 URI，但不会对此进行强制检查。

默认情况下，重定向使用 HTTP 状态码 HttpStatus.movedTemporarily（302）；也可以通过 status 参数指定其他状态码。

此方法还会调用 close，并返回由 close 返回的 future。
