HttpHeaders

HttpHeaders 类 抽象 interface

HTTP 请求和响应的标头。

在某些情况下，标头不可变：

  • HttpRequest 和 HttpClientResponse 的标头始终不可变。

  • HttpResponse 和 HttpClientRequest 的标头从开始写入正文时起不可变。

在这些情况下，修改标头的方法会抛出异常。

对 HTTP 标头执行的所有操作都不区分标头名称的大小写。

要设置标头值，请使用 set() 方法：

request.headers.set(HttpHeaders.cacheControlHeader,
                    'max-age=3600, must-revalidate');

要获取标头值，请使用 value() 方法：

print(request.headers.value(HttpHeaders.userAgentHeader));

HttpHeaders 对象会按照标准规范，为每个名称保存一个值列表。大多数情况下，一个名称只有一个值。最常见的操作方式是使用 set() 设置值，并使用 value() 获取值。
