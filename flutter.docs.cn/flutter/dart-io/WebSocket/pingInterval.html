pingInterval

pingInterval 属性

Duration? pingInterval
getter/setter 对

Ping 信号之间的间隔。

每隔一个 pingInterval 会发送一条 ping 消息；开始计时的时点是设置新值后或收到 pong 消息后的第一个 pingInterval。如果对端未以 pong 消息回应 ping，系统会认为 WebSocket 已断开，并使用 WebSocketStatus.goingAway 关闭码关闭连接。发送 ping 信号后，必须在一个 pingInterval 内收到 pong 消息。

任何时候都不会同时存在两个尚未回应的 ping；收到 pong 后才会启动下一次 ping 计时器。

将 pingInterval 设为 null 可禁用 ping 消息发送。

默认值为 null。
