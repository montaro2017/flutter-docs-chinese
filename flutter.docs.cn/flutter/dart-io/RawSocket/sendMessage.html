int sendMessage(

  3. int offset = 0,

向套接字写入套接字控制消息和数据字节。

从 offset 开始，将 controlMessages 和最多 count 个 data 字节写入套接字。如果未提供 count，则会尽可能多地写入字节。如果不需要发送控制消息，请改用 write。

收到已发送的控制消息后，这些消息会一直保留，直到下一次调用 readMessage；届时，所有当前可用的控制消息都会包含在返回的 SocketMessage 中。调用 read 只会读取数据字节，不会影响控制消息。

count 必须为正数（大于零）。

返回写入的字节数，该值不会大于 count，也不会大于 data.length - offset。返回值为零表示控制消息未发送。

此函数不会阻塞，只有套接字中有可用缓冲区空间时才会写入数据。

如果无法发送消息，则抛出 OSError。

RawSecureSocket 不支持此功能。

Android、Fuchsia 和 Windows 不支持此功能。
