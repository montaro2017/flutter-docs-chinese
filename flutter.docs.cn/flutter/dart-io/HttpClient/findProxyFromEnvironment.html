findProxyFromEnvironment static 方法

  1. Uri url, {
  2. Map<String, String>? environment,

根据环境变量中指定的代理配置，解析 HTTP 连接所用代理服务器的函数。

此函数会读取以下环境变量：

http_proxy
https_proxy
no_proxy
HTTP_PROXY
HTTPS_PROXY
NO_PROXY

http_proxy 和 HTTP_PROXY 指定 http:// URL 使用的代理服务器，格式为 hostname:port。如果未指定端口，则默认使用 1080。如果两者都已设置，则优先使用小写变量。

https_proxy 和 HTTPS_PROXY 指定 https:// URL 使用的代理服务器，格式为 hostname:port。如果未指定端口，则默认使用 1080。如果两者都已设置，则优先使用小写变量。

no_proxy 和 NO_PROXY 指定一个以逗号分隔的主机名后缀列表，这些主机名不使用代理。例如，值“localhost,127.0.0.1”会使发往“localhost”和“127.0.0.1”的请求都不使用代理服务器。如果两者都已设置，则优先使用小写变量。

若要启用此代理解析方式，请将此函数赋给 HttpClient 的 findProxy 属性。

HttpClient client = HttpClient();
client.findProxy = HttpClient.findProxyFromEnvironment;

如果不想使用系统环境变量，可以通过包装此函数来传入另一组环境变量。

HttpClient client = HttpClient();
client.findProxy = (url) {
  return HttpClient.findProxyFromEnvironment(
      url, environment: {"http_proxy": ..., "no_proxy": ...});
}

如果代理需要身份验证，也可以配置用户名和密码。请使用 username:password@hostname:port 格式来包含用户名和密码。或者，对于需要身份验证的代理，也可以使用 addProxyCredentials API 设置凭据。

实现

static String findProxyFromEnvironment(
  Uri url, {
  Map<String, String>? environment,
}) {
  HttpOverrides? overrides = HttpOverrides.current;
  if (overrides == null) {
    return _HttpClient._findProxyFromEnvironment(url, environment);
  }
  return overrides.findProxyFromEnvironment(url, environment);
}
