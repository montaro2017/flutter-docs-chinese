autoUncompress

autoUncompress 属性

bool autoUncompress
getter/setter 对

获取或设置是否自动解压响应正文。

HTTP 响应正文可能经过压缩。在大多数情况下，直接提供解压后的正文最方便，因此默认会自动解压。但在某些情况下（例如实现透明代理时），则需要保留未解压的流。

注意：响应标头不会被修改。这意味着启用自动解压后，Content-Length 标头仍反映原始压缩正文的长度。同样，Content-Encoding 标头也会保留指示压缩状态的原始值。

注意：只有当 Content-Encoding 标头值为 gzip 时才会自动解压。

更改此值后，它会影响此客户端生成的所有后续响应。

设为 false 可禁用自动解压。

默认值为 true。

实现

bool autoUncompress = true;
