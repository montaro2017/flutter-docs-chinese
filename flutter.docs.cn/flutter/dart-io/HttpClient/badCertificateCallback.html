badCertificateCallback 属性

set badCertificateCallback (bool callback(X509Certificate cert, String host, int port)?)
设置一个回调，用于决定是否接受与服务器建立安全连接，前提是服务器证书无法通过任何受信任的根证书验证。 使用此 HttpClient 发送安全 HTTP 请求时，如果服务器返回的证书无法通过验证，系统会异步调用此回调，并传入 X509Certificate 对象以及服务器的主机名和端口。如果 badCertificateCallback 的值为 null，则会拒绝该无效证书，效果等同于回调返回 false。 如果回调返回 true，则接受安全连接，并且发起请求的方法所返回的 Future<HttpClientRequest> 会以有效的 HttpRequest 对象完成。如果回调返回 false，该 Future<HttpClientRequest> 会以异常完成。 如果尝试连接时收到无效证书，库会调用发起请求时 badCertificateCallback 所对应的函数，即使此后 badCertificateCallback 的值已经更改。

实现

void set badCertificateCallback(
  bool Function(X509Certificate cert, String host, int port)? callback,
);
