connectionFactory

connectionFactory 属性

set connectionFactory (Future<ConnectionTask<Socket>> f(Uri url, String? proxyHost, int? proxyPort)?)

设置用于创建套接字连接的函数。

请求的 URL（例如通过 getUrl 指定）和代理配置（f.proxyHost 与 f.proxyPort）会作为参数传递。如果连接未经过代理，则 f.proxyHost 和 f.proxyPort 为 null。

由于连接可能会根据主机和端口进行复用，只要 f.proxyHost 和 f.proxyPort 不为 null，此函数就不能忽略它们。如果返回的 Socket 不支持代理，可以将 findProxy 设为直接连接。

例如：

import "dart:io";

void main() async {
  HttpClient client = HttpClient()
    ..connectionFactory = (Uri uri, String? proxyHost, int? proxyPort) {
        assert(proxyHost == null);
        assert(proxyPort == null);
        var address = InternetAddress("/var/run/docker.sock",
            type: InternetAddressType.unix);
        return Socket.startConnect(address, 0);
    }
    ..findProxy = (Uri uri) => 'DIRECT';

  final request = await client.getUrl(Uri.parse("http://ignored/v1.41/info"));
  final response = await request.close();
  print(response.statusCode);
  await response.drain();
  client.close();
}
