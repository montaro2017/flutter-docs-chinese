requestedUri 属性

Uri get requestedUri

请求所请求的 URI。

如果请求 URI 是绝对 URI（例如 “https://www.example.com/foo”），则按原样返回。否则，会根据请求 URI 路径（例如 “/foo”）和 HTTP 标头字段重建并返回 URI。

重建 scheme 时会使用 “X-Forwarded-Proto” 标头。如果该标头不存在，则根据连接的套接字类型确定：如果连接通过 SecureSocket 建立，则 scheme 为 “https”；否则为 “http”。

重建主机时会使用 “X-Forwarded-Host” 标头。如果该标头不存在，则使用 “Host” 标头。如果两者都不存在，则使用服务器的主机名。
