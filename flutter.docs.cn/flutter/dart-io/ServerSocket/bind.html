在指定地址和端口上监听。

返回的 future 完成时，服务器套接字已绑定到指定的 address 和 port，并开始在该地址和端口上监听。

address 可以是 String 或 InternetAddress。如果 address 是 String，bind 会执行 InternetAddress.lookup，并使用列表中的第一个值。若只允许本地主机发起的传入连接，请使用 InternetAddress.loopbackIPv4 或 InternetAddress.loopbackIPv6，以便在环回适配器上监听。若要允许来自网络的传入连接，可使用 InternetAddress.anyIPv4 或 InternetAddress.anyIPv6 绑定到所有接口，也可以绑定到特定接口的 IP 地址。

如果使用 IPv6 地址，则会同时接受 IPv6 和 IPv4 连接。若只接受 IPv6 连接，请将 v6Only 设为 true。

如果 port 为 0，系统会选择一个临时端口。可以通过 port getter 获取实际使用的端口。

可选参数 backlog 用于指定底层操作系统配置监听时使用的等待队列长度。如果 backlog 为 0（默认值），系统会选择一个合适的值。

可选参数 shared 指定是否允许其他 ServerSocket 对象绑定到相同的 address、port 和 v6Only 组合。如果 shared 为 true，且此隔离区或其他隔离区中还有更多服务器套接字绑定到该端口，则传入连接会分配给所有已绑定的服务器套接字。这样可以将连接分配到多个隔离区。

实现

static Future<ServerSocket> bind(
  address,
  int port, {
  int backlog = 0,
  bool v6Only = false,
  bool shared = false,
}) {
  final IOOverrides? overrides = IOOverrides.current;
  if (overrides == null) {
    return ServerSocket._bind(
      address,
      port,
      backlog: backlog,
      v6Only: v6Only,
      shared: shared,
    );
  }
  return overrides.serverSocketBind(
    address,
    port,
    backlog: backlog,
    v6Only: v6Only,
    shared: shared,
  );
}
