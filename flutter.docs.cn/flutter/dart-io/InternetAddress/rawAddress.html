rawAddress 属性

Uint8List get rawAddress

此 InternetAddress 的原始地址。

对于 IP 地址，结果是长度为 4 或 16 的字节列表。对于 Unix 域地址，则返回表示 address 的 UTF-8 编码字节序列。

返回的列表是一个新副本，因此可以修改该列表，而不会改变 InternetAddress。
