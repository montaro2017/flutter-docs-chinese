File

File 类 抽象 interface

文件系统中文件的引用。 File 表示文件系统中的一个 路径，可对该路径执行各种操作。你可以通过从 FileSystemEntity 继承的 parent 属性获取文件所在的父目录。 创建 File 对象时，需提供路径名，以便程序访问文件系统中的指定文件。 
var myFile = File('file.txt');
File 类提供了用于操作文件及其内容的方法。你可以使用这些方法打开和关闭文件、读取和写入内容、创建和删除文件，以及检查文件是否存在。 读取或写入文件时，可以使用流（通过 openRead）、随机访问操作（通过 open），也可以使用 readAsString 等便捷方法。 此类中的大多数方法都有同步和异步两种形式，例如 readAsString 和 readAsStringSync。除非有特定理由需要使用同步版本，否则建议优先使用异步版本，以免阻塞程序。

如果路径是链接

如果 path 是符号链接而不是文件，File 的方法会作用于链接最终指向的目标；但 delete 和 deleteSync 除外，它们作用于链接本身。

从文件读取

以下代码示例使用异步 readAsString 方法，以字符串形式读取文件的全部内容： 
import 'dart:async';
import 'dart:io';

void main() {
  File('file.txt').readAsString().then((String contents) {
    print(contents);
  });
}
使用 Stream 读取文件更加灵活实用。通过 openRead 打开文件会返回一个流，该流以字节块的形式提供文件数据。读取该流，即可在数据可用时处理文件内容。你可以依次使用多个转换器来处理文件内容，使其符合所需格式，或为输出做好准备。 如果要读取大型文件、使用转换器处理数据，或需要与 WebSocket 等其他 API 兼容，可以考虑使用流。 
import 'dart:io';
import 'dart:convert';
import 'dart:async';

void main() async {
  final file = File('file.txt');
  Stream<String> lines = file.openRead()
    .transform(utf8.decoder)       // Decode bytes to UTF-8.
    .transform(LineSplitter());    // Convert stream to individual lines.
  try {
    await for (var line in lines) {
      print('$line: ${line.length} characters');
    }
    print('File is now closed.');
  } catch (e) {
    print('Error: $e');
  }
}

写入文件

要向文件写入字符串，请使用 writeAsString 方法： 
import 'dart:io';

void main() async {
  final filename = 'file.txt';
  var file = await File(filename).writeAsString('some content');
  // Do something with the file.
}
你也可以使用 Stream 向文件写入内容。使用 openWrite 打开文件会返回一个 IOSink，可向其中写入数据。记得使用 IOSink.close 方法关闭该 sink。 
import 'dart:io';

void main() async {
  var file = File('file.txt');
  var sink = file.openWrite();
  sink.write('FILE ACCESSED ${DateTime.now()}\n');
  await sink.flush();

  // Close the IOSink to free system resources.
  await sink.close();
}

使用异步方法

为避免程序意外阻塞，此类提供了多个异步方法，它们会返回 Future。例如，用于获取文件长度的 length 方法会返回一个 Future。等待该 Future 完成，即可在结果就绪后获取结果。 
import 'dart:io';

void main() async {
  final file = File('file.txt');

  var length = await file.length();
  print(length);
}
除了 length，exists、lastModified、stat 等方法也都是异步方法。

特殊的“nul”文件

在 Linux 和 Mac 上，“/dev/null”；在 Windows 上，“\?\NUL”指向一个特殊文件：写入其中的所有内容都会被丢弃，读取时则始终返回空内容。请注意，在 Windows 上，不带“\?”前缀的“nul”指向当前目录中一个名为“nul”的普通文件。
