  1. String file, {
  2. String? password,

将证书添加到受信任 X509 证书集合中，供 SecureSocket 客户端连接使用。

file 是包含 X509 证书的 PEM 或 PKCS12 文件路径，通常包含证书颁发机构的根证书。对于 PKCS12 文件，password 是文件密码；对于 PEM 文件，password 会被忽略。假设 file 格式正确，其中的其他内容都会被忽略。

注意：此函数会调用 File.readAsBytesSync，因此会阻塞等待文件 I/O。建议改用 setTrustedCertificatesBytes。

iOS 注意事项：在 iOS 上，此调用只接受单个 DER 编码 X509 证书的字节。可以多次调用，以便向上下文添加多个受信任证书。可以使用 openssl 工具从 PEM 编码证书获取 DER 编码证书：

$ openssl x509 -outform der -in cert.pem -out cert.der
