RawSocket

RawSocket 类 抽象 interface

TCP 连接。

套接字连接将本地套接字连接到远端套接字。数据以 Uint8List 形式由本地套接字接收，并可通过 read 方法读取；也可以通过 write 方法发送到远端套接字。

此类的 Stream 接口会在发生特定变化时发出事件通知，例如数据变为可用时（RawSocketEvent.read），或远端停止监听时（RawSocketEvent.closed）。
