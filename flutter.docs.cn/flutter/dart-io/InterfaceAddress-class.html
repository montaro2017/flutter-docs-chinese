InterfaceAddress

InterfaceAddress 类 抽象 interface

绑定到 NetworkInterface 的 InternetAddress，并附带网络配置详情。

除了地址本身，还提供前缀长度（也称子网掩码长度）；对于 IPv4 地址，还提供网络的广播地址。
