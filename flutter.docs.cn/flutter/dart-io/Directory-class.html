Directory

Directory 类 抽象 interface

文件系统中目录（或文件夹）的引用。

Directory 是一个包含 path 的对象，可以对该路径执行操作。目录路径可以是 绝对路径，也可以是相对路径。它可以访问其 父目录，因为它是 FileSystemEntity。

Directory 还提供对系统临时文件目录 systemTemp 的静态访问，以及访问和更改 当前目录 的功能。

创建新的 Directory，以访问指定路径对应的目录：

var myDir = Directory('myDir');

Directory 的大多数实例方法都提供同步和异步版本，例如 create 和 createSync。除非有特殊原因必须使用同步版本，否则建议优先使用异步版本，以避免阻塞程序。

创建目录

以下代码示例使用 create 方法创建目录。将 recursive 参数设为 true，可以创建指定目录及其所有必需的父目录（如果这些目录尚不存在）。

import 'dart:io';

void main() async {
  // Creates dir/ and dir/subdir/.
  var directory = await Directory('dir/subdir').create(recursive: true);
  print(directory.path);
}

列出目录条目

使用 list 或 listSync 方法获取目录中包含的文件和目录。将 recursive 设为 true 可递归列出所有子目录；将 followLinks 设为 true 可跟随符号链接。list 方法会返回一个 Stream，其中包含 FileSystemEntity 对象。可以监听该流，在每个对象被找到时访问它：

import 'dart:io';

void main() async {
  // Get the system temp directory.
  var systemTempDir = Directory.systemTemp;

  // List directory contents, recursing into sub-directories,
  // but not following symbolic links.
  await for (var entity in
      systemTempDir.list(recursive: true, followLinks: false)) {
    print(entity.path);
  }
}

使用异步方法

I/O 操作在等待完成时可能会暂时阻塞程序。为避免阻塞，所有涉及 I/O 的方法都提供异步版本，并返回一个 Future。Future 会在 I/O 操作完成时完成。在此期间，Dart 程序不会被阻塞，可以执行其他操作。

例如，exists 方法用于确定目录是否存在，它通过 Future 异步返回布尔值。

import 'dart:io';

void main() async {
  final myDir = Directory('dir');
  var isThere = await myDir.exists();
  print(isThere ? 'exists' : 'nonexistent');
}

除了 exists，stat、rename 等方法也都是异步方法。
