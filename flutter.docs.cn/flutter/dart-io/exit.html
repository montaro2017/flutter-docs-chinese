exit function

Never exit(
  1. int code
)

使用给定的退出代码立即退出 Dart VM 进程。

此操作不会等待任何异步操作结束，也不会执行 finally 代码块。因此，使用 exit 很可能导致数据丢失。

不会显式终止子进程（但子进程检测到其父进程已退出后，可能会自行终止）。

调试时，如果调用了 exit，VM 将不会遵循 --pause-isolates-on-exit 标志，因为调用此方法会使 Dart VM 进程立即关闭。若要在退出时正确中断，可考虑在调用 exit 前，通过 dart:developer 中的 debugger，或通过 dart:isolate 中的 Isolate.pause 暂停 Isolate.current。

退出代码的处理方式因平台而异。

在 Linux 和 OS X 上，正常终止时的退出代码始终在 [0..255] 范围内。如果设置了此范围之外的退出代码，实际退出代码将取其低 8 位并作为无符号值处理。例如，使用 -1 作为退出代码时，报告的实际退出代码为 255。

在 Windows 上，退出代码可以设置为任意 32 位值。不过，其中一些值保留用于报告崩溃等系统错误。

此外，Dart 可执行文件本身使用退出代码 254 报告编译时错误，并使用退出代码 255 报告运行时错误（未处理的异常）。

基于以上原因，建议仅使用 [0..127] 范围内的退出代码，向外围环境传达 Dart 程序的运行结果，以避免跨平台问题。

实现

Never exit(int code) {
  IOOverrides? overrides = IOOverrides.current;
  if (overrides == null) {
    if (!_EmbedderConfig._mayExit) {
      throw new UnsupportedError(
        "This embedder disallows calling dart:io's exit()",
      );
    }
    _ProcessUtils._exit(code);
  }
  overrides.exit(code);
}
