同步将字符串写入文件。

打开文件，使用给定编码写入字符串，然后关闭文件。

默认情况下，writeAsStringSync 会创建文件以供写入；如果文件已存在，则会截断该文件。若要将字节追加到现有文件，请将可选的 mode 参数设为 FileMode.append。

如果参数 flush 设为 true，则在返回前会将写入的数据刷新到文件系统。

此方法不会将换行字符（"\n"）转换为平台惯用的行结束符（例如 Windows 上的 "\r\n"）。如果需要使用平台惯用的行结束符分隔各行，请在 contents 中使用 Platform.lineTerminator。

如果操作失败，则抛出 FileSystemException。
