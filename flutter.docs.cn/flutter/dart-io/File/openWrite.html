openWrite

openWrite abstract 方法

IOSink openWrite({
  1. FileMode mode = FileMode.write,
  2. Encoding encoding = utf8,
})

为此文件创建新的独立 IOSink。

不再使用 IOSink 时必须将其关闭，以释放系统资源。

文件的 IOSink 可以通过两种模式打开：
  • FileMode.write: truncates the file to length zero.
  • FileMode.append: sets the initial write position to the end of the file.

通过返回的 IOSink 写入字符串时，会使用 encoding 指定的编码。返回的 IOSink 具有 encoding 属性，创建 IOSink 后也可以更改该属性。

返回的 IOSink 不会将换行字符（"\n"）转换为平台惯用的行结束符（例如 Windows 上的 "\r\n"）。如果需要平台特定的行结束符，请写入 Platform.lineTerminator。

打开或写入文件时如果发生错误，IOSink.done、IOSink.flush 和 IOSink.close futures 都会以 FileSystemException 完成。必须处理 IOSink.done future 的错误，否则该错误会变成未捕获错误。

例如，可以使用 FutureExtensions.ignore 忽略 IOSink.done 的错误，并记得在 try/catch 中 await IOSink.flush 和 IOSink.close 调用：

final sink = File('/tmp').openWrite(); // Can't write to /tmp
sink.done.ignore();
sink.write("This is a test");
try {
  // If one of these isn't awaited, then errors will pass silently!
  await sink.flush();
  await sink.close();
} on FileSystemException catch (e) {
  print('Error writing file: $e');
}

如果要在 IOSink.flush 和 IOSink.close 调用所在上下文之外异步处理错误，可以对 IOSink.done 使用 Future.catchError。

final sink = File('/tmp').openWrite(); // Can't write to /tmp
sink.done.catchError((e) {
 // Handle the error.
});
