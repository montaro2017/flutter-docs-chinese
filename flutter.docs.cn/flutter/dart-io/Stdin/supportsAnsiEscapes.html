supportsAnsiEscapes 属性

bool get supportsAnsiEscapes

是否连接到支持 ANSI 转义序列的终端。

并非所有终端都能被识别，而且并非所有已识别终端都能报告是否支持 ANSI 转义序列，因此此值只是尽力检测支持情况的结果。

不同终端实际支持的转义序列可能不同：有些终端支持更多序列，而且即使是同一种转义序列，不同终端的行为也可能不一致。

通常支持 ANSI 颜色选择。

目前，如果 TERM 环境变量包含字符串 xterm、screen、rxvt 或 tmux，就会将其视为支持 ANSI 转义序列的依据。在 Windows 上，只有 Windows 10 v.1511（“TH2”，OS build 10586）之后的版本会被检测为支持输出 ANSI 转义序列；只有 v.1607（“Anniversary Update”，OS build 14393）之后的版本会被检测为支持输入 ANSI 转义序列。
