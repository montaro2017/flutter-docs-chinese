ProcessSignal

ProcessSignal 类 interface

在 Posix 系统上，ProcessSignal 用于向子进程发送特定信号，参见 Process.kill。

某些 ProcessSignal 也可以被监听，以拦截默认信号处理程序并实现其他处理方式。详情请参见 ProcessSignal.watch。
