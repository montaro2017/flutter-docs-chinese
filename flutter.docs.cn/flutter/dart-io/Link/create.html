在文件系统中创建符号链接。

创建的链接会指向 target 指定的路径，无论该路径是否存在。

返回一个 Future<Link>，链接创建完成后，该 Future 会以此链接完成。如果链接路径已存在，则 Future 会以错误完成。

如果 recursive 为 false（默认值），则仅当链接路径中的所有目录都存在时才创建链接。如果 recursive 为 true，则会先创建所有不存在的父路径。除非 target 路径中的目录也位于 path 中，否则不会影响这些目录。

在 Windows 平台上，此调用会创建真正的符号链接，而不是目录联接。Windows 将文件链接和目录链接视为不同且不可互换的链接类型。每个链接要么是文件链接，要么是目录链接，其类型在创建时确定；在大多数用途下，该链接随后也会被视为文件或目录。操作这两种链接时使用不同的 Win32 API。例如，删除文件链接要使用 DeleteFile 函数，而删除目录链接必须使用 RemoveDirectory。

如果 target 存在，Windows 上创建的符号链接类型会与 target 的类型一致；否则会创建文件链接。即使之后将 target 替换为其他类型的对象，链接的类型也不会改变，此时 resolveSymbolicLinks 将无法解析该链接。

要在 Windows 上创建符号链接，Dart 必须以管理员身份运行，或者系统必须启用开发者模式；否则调用时会抛出 FileSystemException，其 errno 为 ERROR_PRIVILEGE_NOT_HELD。

在其他平台上，会使用 POSIX symlink() 调用创建包含 target 字符串的符号链接。如果 target 是相对路径，则相对于链接所在目录解释。
