collectedLeaksReporter 属性

LeaksCallback collectedLeaksReporter
getter/setter 对

处理测试中发现的内存泄漏。

设置此处理程序可通过编程方式分析泄漏。它会在测试运行结束时调用。默认报告器在发现泄漏时会使测试失败。

用于测试泄漏跟踪功能。

实现

static LeaksCallback collectedLeaksReporter =
    (Leaks leaks) => expect(leaks, isLeakFree);
