LeakTesting

LeakTesting 类

用于测试的 leak_tracker 设置。

设置 LeakTesting.settings 可更改测试的默认泄漏跟踪设置。可在 flutter_test_config.dart 中为包或文件夹设置，也可在测试文件的 setUpAll 中设置。

如果要为一组测试更新设置，请记得将原值保存到局部变量，并在该组的 tearDownAll 中恢复。

要自定义单个测试的默认设置，请使用返回调整后 LeakTesting.settings 的方法：

testWidgets(
    'initialTimerDuration falls within limit',
    leakTracking: LeakTesting.settings.withIgnoredAll(),
    (WidgetTester tester) async {
      ...

如果在测试运行期间更新了 LeakTesting.settings，新值将在下一个测试中生效。
