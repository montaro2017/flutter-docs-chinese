absolute 属性

  1. @重写
T get absolute
重写

一个 FileSystemEntity，其路径为 path 的绝对路径。

返回实例的类型与此实体的类型相同。

如果文件系统实体的路径已经是绝对路径（由 isAbsolute 报告），则直接返回该实体。对于非绝对路径，如果可能，则返回路径为绝对路径的实体（isAbsolute），但仍指向同一个文件系统对象。

实现

@override
T get absolute => wrap(delegate.absolute as D);
