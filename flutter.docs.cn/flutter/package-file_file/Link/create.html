在文件系统中创建符号链接。

创建的链接将指向 target 指定的路径，无论该路径是否存在。

返回一个 Future<Link>，该对象会在链接创建后以该链接完成。如果链接路径已存在，Future 将以错误完成。

如果 recursive 为 false（默认值），则只有当链接路径中的所有目录都已存在时才会创建链接。如果 recursive 为 true，则会先创建所有不存在的父目录。除非这些目录也位于 path 中，否则不会影响 target 路径中的目录。

在 Windows 平台上，此调用会创建真正的符号链接，而不是联接点。Windows 将指向文件和指向目录的链接视为不同且不可互换的类型。每个链接要么是文件链接，要么是目录链接；创建时会确定类型。此后，在大多数情况下，该链接会被视为文件或目录。操作这两类链接时会使用不同的 Win32 API。例如，删除文件链接要使用 DeleteFile 函数，而删除目录链接必须使用 RemoveDirectory。

如果 target 存在，则创建的 Windows 符号链接类型会与 target 相同；否则会创建文件链接。之后即使将 target 替换为不同类型的对象，已创建链接的类型也不会改变，此时 resolveSymbolicLinks 将无法解析该链接。

在 Windows 上创建符号链接时，Dart 必须以管理员模式运行，或者系统必须启用开发人员模式；否则调用时会抛出 FileSystemException，其 errno 会设为 ERROR_PRIVILEGE_NOT_HELD。

在其他平台上，会使用 POSIX symlink() 调用创建一个包含字符串 target 的符号链接。如果 target 是相对路径，则会相对于包含该链接的目录进行解析。
