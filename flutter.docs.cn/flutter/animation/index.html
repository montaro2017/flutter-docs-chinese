animation 库

Flutter 动画系统。

使用时，请导入 package:flutter/animation.dart。

本库提供在 Flutter 中实现动画的基础构件。框架的其他层使用这些构件，为应用提供更高级的动画支持。例如，widget 库包含 ImplicitlyAnimatedWidget 和 AnimatedWidget，方便对 Widget 的某些属性添加动画。如果这些动画 widget 无法满足特定使用场景，可以使用本库提供的基础构件实现自定义动画效果。

本库仅依赖 Dart 核心库和 physics.dart 库。

基础：Animation 类

Flutter 将动画表示为一个在指定时间内变化的值，这个值可以是任意类型。例如，它可以是一个 double，表示 Widget 淡出时的当前不透明度；也可以是 widget 从一种颜色平滑过渡到另一种颜色时的当前背景 Color。动画的当前值由 Animation 对象表示，它是动画库的核心类。除了当前动画值，Animation 对象还保存当前的 AnimationStatus。该状态表示动画在概念上是从起点向终点运行，还是反向运行，也可以表示动画目前停在起点或终点。

其他对象可以向 Animation 注册监听器，以便在动画值或动画状态变化时收到通知。Widget 可以通过 Animation.addListener 注册这样的值监听器，在值变化时使用当前动画值重新构建自身。例如，widget 可以监听动画，在每次值变化时将自身的不透明度更新为动画值。同样，通过 Animation.addStatusListener 注册状态监听器，可以在当前动画结束时触发其他操作。

下面的视频以 widget 的不透明度动画为例，展示当前动画状态和动画值如何随时间变化。这个 Animation 由 AnimationController 驱动（见下一节）。动画触发前，状态为 dismissed，值为 0.0。当值从 0.0 变化到 1.0，使 widget 淡入时，状态变为 forward。当动画值达到 1.0、widget 完全淡入时，状态为 completed。再次触发动画使 widget 淡出时，状态变为 reverse，动画值回到 0.0。此时 widget 完全淡出，动画状态恢复为 dismissed，直到再次触发动画。

虽然不能直接实例化 Animation（它是抽象类），但可以使用 AnimationController 创建一个。

驱动动画：AnimationController

AnimationController 是一种特殊的 Animation。每当运行应用的设备准备好显示新的一帧时，它就推进动画值（通常每秒更新约 60 次）。凡是需要 Animation 的地方，都可以使用 AnimationController。顾名思义，AnimationController 还可以控制它的 Animation：它提供随时停止动画，以及正向或反向运行动画的方法。

默认情况下，AnimationController 正向运行时，会在指定时长内将动画值从 0.0 线性增加到 1.0。许多场景需要使用其他类型的值、改变动画值的范围，或者改变值之间的过渡方式。这些都可以通过包装动画实现：使用 Animatable（见下文）包装动画，可以将动画值转换到其他范围或类型，例如对 Color 或 Rect 添加动画。此外，使用 CurvedAnimation 包装动画，可以为它应用 Curve。曲线动画按照指定曲线改变数值，而不是线性增加。框架内置了许多曲线（见 Curves）。例如，Curves.easeOutCubic 会在动画开始时快速增加动画值，随后逐渐减速，直到达到目标值：

为不同类型添加动画：Animatable

Animatable<T> 接收 Animation<double> 作为输入，并生成 T 类型的值。这类对象可以将 AnimationController（或任何其他 double 类型的 Animation）的动画值范围映射到其他范围；新范围甚至可以不再使用 double 类型。借助 Tween 或 TweenSequence（见下文）这样的 Animatable，AnimationController 可以在指定时长内，让 Color、Rect、Size 等多种类型从一个值平滑过渡到另一个值。

数值插值：Tween

将 Tween 应用于 double 类型的 Animation，可以改变动画值的范围和类型。例如，要让 Widget 的背景在两种 Color 之间平滑过渡，可以使用 ColorTween。每个 Tween 都指定一个起始值和结束值。当驱动 Tween 的 Animation 值从 0.0 推进到 1.0 时，它会生成起始值与结束值之间的插值。随着驱动它的 Animation 值接近 1.0，Tween 生成的值通常会越来越接近结束值。

一个 Animation 或 AnimationController 可以驱动多个 Tween。例如，要同时为 widget 的尺寸和颜色添加动画，可以创建一个 AnimationController，同时驱动 SizeTween 和 ColorTween。

框架提供许多 Tween 子类（如 IntTween、SizeTween、RectTween 等），用于为常见属性添加动画。

分阶段动画：TweenSequence

TweenSequence 可以让指定属性分阶段平滑变化。序列中的每个 Tween 负责一个不同阶段，并具有相应的权重。动画运行时，各阶段依次执行。例如，要将 widget 的背景从黄色变为绿色，短暂停留后再变为红色，可以在一个补间序列中指定三个补间：一个 ColorTween 从黄色变为绿色，一个 ConstantTween 保持绿色，再用一个 ColorTween 从绿色变为红色。每个补间都需要指定权重，表示它所占的时间相对于其他补间的比例。如果两个 ColorTween 的权重均为 2，ConstantTween 的权重为 1，那么每个 ColorTween 的过渡时间都是 ConstantTween 的两倍。与普通 Tween 一样，TweenSequence 由 Animation 驱动：当驱动它的 Animation 从 0.0 运行到 1.0 时，TweenSequence 就会遍历所有阶段。
