TweenSequence<T> 类

用于创建值由一系列 Tween 定义的 Animation。

每个 TweenSequenceItem 都有一个权重，用于确定它占动画总时长的比例。每个补间定义由其权重确定的时间区间内的动画值。

此示例定义一个动画：在前 40% 的播放区间内，使用缓动曲线将值从 5.0 插值到 10.0；接下来的 20% 保持为 10.0；最后 40% 再返回 5.0。
link 
final Animation<double> animation = TweenSequence<double>(
  <TweenSequenceItem<double>>[
    TweenSequenceItem<double>(
      tween: Tween<double>(begin: 5.0, end: 10.0)
        .chain(CurveTween(curve: Curves.ease)),
      weight: 40.0,
    ),
    TweenSequenceItem<double>(
      tween: ConstantTween<double>(10.0),
      weight: 20.0,
    ),
    TweenSequenceItem<double>(
      tween: Tween<double>(begin: 10.0, end: 5.0)
        .chain(CurveTween(curve: Curves.ease)),
      weight: 40.0,
    ),
  ],
).animate(myAnimationController);
