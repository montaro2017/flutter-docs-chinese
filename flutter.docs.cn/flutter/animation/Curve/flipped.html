flipped 属性

Curve get flipped

返回对当前曲线进行反向反转得到的新曲线。

这通常适合与 CurvedAnimation.reverseCurve 一同使用。

另请参阅：

  • FlippedCurve，用于实现此 getter 的类。
  • ReverseAnimation，用于反转 Animation ，其作用对象并非 Curve.
  • CurvedAnimation，能够分别指定正向曲线和反向曲线。

实现

Curve get flipped => FlippedCurve(this);
