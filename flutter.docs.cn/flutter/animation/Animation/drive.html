drive<U> 方法

  1. @optionalTypeArgs
Animation<U> drive<U>(
  1. Animatable<U> child
)

将一个 Tween（或 CurveTween）链接到此 Animation 上。

此方法仅对 Animation<double> 实例有效（即 T 为 double 的情况）。这意味着，例如它可以作用于 AnimationController 对象，以及 CurvedAnimation、ProxyAnimation、ReverseAnimation、TrainHoppingAnimation 等。

它返回一个 Animation，其类型为 U，与方法参数 child 的类型一致；其值由将给定的 Tween 应用于此 Animation 的值而得出。

给定一个 AnimationController _controller，以下代码会创建一个 Animation<Alignment>：当控制器的值从 0.0 变为 1.0 时，动画会从左上方摆动到右上方：
link 
Animation<Alignment> alignment1 = _controller.drive(
  AlignmentTween(
    begin: Alignment.topLeft,
    end: Alignment.topRight,
  ),
);

该 alignment1.value 可用于 widget 的 build 方法，例如通过 Align 放置子项，使子项位置随时间从左上方移到右上方。

通常会为这类曲线添加缓动效果，例如让过渡在开始时较慢、结束时较快。以下代码展示如何将上例中的对齐补间与缓动曲线（此处为 Curves.easeIn）串联起来。由于补间的参数不会变化，此例会在其他位置创建可重复使用的补间变量。

link 
final Animatable<Alignment> tween = AlignmentTween(begin: Alignment.topLeft, end: Alignment.topRight)
  .chain(CurveTween(curve: Curves.easeIn));
// ...
final Animation<Alignment> alignment2 = _controller.drive(tween);

以下代码与前例完全等效。当补间值依赖其他变量时，通常将补间直接内联创建会更清晰：
link 
Animation<Alignment> alignment3 = _controller
  .drive(CurveTween(curve: Curves.easeIn))
  .drive(AlignmentTween(
    begin: Alignment.topLeft,
    end: Alignment.topRight,
  ));

此方法可与 Animatable 配合使用，该对象由 Animatable.fromCallback 创建，可通过回调函数转换动画。这适用于起点或终点不明确的动画。例如，以下代码会将当前位置转换为循环变化的红色色值。
link 
Animation<Color> color = Animation<double>.fromValueListenable(_scrollPosition)
  .drive(Animatable<Color>.fromCallback((double value) {
    return Color.fromRGBO(value.round() % 255, 0, 0, 1);
  }));

另请参阅：

  • Animatable.animate，执行相同的操作。
  • AnimationController，通常用于驱动动画。
  • CurvedAnimation 是应用缓动曲线的另一种方式，可替代 CurveTween，并支持为正向和反向分别指定不同的曲线。
  • Animatable.fromCallback 可根据任意变换创建 Animatable。

实现

@optionalTypeArgs
Animation<U> drive<U>(Animatable<U> child) {
  assert(this is Animation<double>);
  return child.animate(this as Animation<double>);
}
