从 ValueListenable 创建新动画。

返回的动画状态始终为 AnimationStatus.forward。可以选择使用 transformer 函数转换所提供 listenable 的值。

使用此构造函数，可以将 ValueListenableBuilder 控件替换为对应的动画控件，例如 FadeTransition。

  return ValueListenableBuilder<double>(
    valueListenable: _scrollPosition,

      return Opacity(opacity: opacity, child: child);

      color: Colors.red,
