Animation<T> 类 抽象

一个可能随时间变化、正向或反向推进的值。

动画具有 value（类型为 T）和 status。在概念上，值位于某条路径上，状态则表示该值当前如何沿路径移动：正向、反向，或停在终点或起点。路径可能折返，例如动画使用弹跳曲线时。因此，即使动画在概念上正向运行，其值也未必单调变化。

使用动画的对象可以通过 addListener 和 addStatusListener 监听值或状态的变化。监听器回调在流水线的动画阶段调用，紧接着才会重新构建 widget。

动画可以随时间自行正向或反向运行，例如用户触摸按钮后，按钮的不透明度在固定时长内逐渐变化；也可以由用户驱动，例如用户来回拖动滑块时的位置变化；还可以同时采用两种方式，例如松开后自动吸附到位的开关，或响应拖动和甩动手势的 Dismissible。这些行为通常通过调用底层 AnimationController 的方法来控制。动画正在运行时，通常由 Ticker 驱动，在每一帧更新。

使用动画

对于简单的动画效果，可以考虑使用 ImplicitlyAnimatedWidget 的子类，例如 AnimatedScale、AnimatedOpacity 等。如果 ImplicitlyAnimatedWidget 已能满足需求，就无需直接使用 Animation 或本节讨论的其他类。

否则，动画通常源自一个 AnimationController（它本身也是 Animation<double>），由实现了 TickerProvider 的 State 创建。可以使用 Tween 或 CurvedAnimation 等，从这个动画派生出更多动画。这些动画可以用于配置 AnimatedWidget，使用其众多子类之一，例如 FadeTransition；也可以直接使用动画值。

例如，AnimationController 可以表示从 0.0 到 1.0 的抽象动画进度；随后由 CurvedAnimation 应用缓动曲线，再分别应用 SizeTween 和 ColorTween，生成 Animation<Size> 和 Animation<Color>，控制 widget 随着动画推进而缩小并改变颜色。

性能注意事项

由于动画运行过程中 Animation 对象的身份保持不变，负责协调复杂动画的 StatefulWidget 可以方便地通过它向各个子 widget 传递动画进度。可以让树中较高层的 widget 向较低层的 widget 传递 Animation 本身，而不是它的值，从而避免动画运行时每帧都重新构建较高层的 widget。如果叶子 widget 也不直接使用 value，而是像 FadeTransition 那样，将整个 Animation 对象传给渲染对象，那么它们也可能避免重新构建，甚至避免重新布局，使动画每帧只需重新绘制。

另请参阅：

  • ImplicitlyAnimatedWidget and its subclasses, which provide animation effects without the need to manually work with Animation, AnimationController, or even State.
  • AnimationController, an animation you can run forward and backward, stop, or set to a specific value.
  • Tween, which can be used to convert Animation<double>s into other kinds of Animation。
  • AnimatedWidget and its subclasses, which provide animation effects that can be controlled by an Animation.
