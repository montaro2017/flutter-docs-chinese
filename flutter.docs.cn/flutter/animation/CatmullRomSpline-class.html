CatmullRomSpline 类

一条使用向心 Catmull-Rom 样条平滑穿过给定控制点的二维样条曲线。

使用 transform 对曲线求值时，输出值会从一个控制点平滑地移动到下一个控制点，并经过这些控制点。

与大多数三次样条不同，Catmull-Rom 样条的优势在于其曲线会经过传给它们的控制点。它们是三次多项式表示，事实上 Catmull-Rom 样条可以在数学上转换为三次样条。本类实现的是一种“向心”Catmull-Rom 样条。向心一词意味着它在单个段内不会形成环路或自交。

另请参阅：

  • Centripetal Catmull–Rom splines on Wikipedia.
  • Parameterization and Applications of Catmull-Rom Curves, a paper on using Catmull-Rom splines.
  • CatmullRomCurve, an animation curve that uses a CatmullRomSpline as its internal representation.
