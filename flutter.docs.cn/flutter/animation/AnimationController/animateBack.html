以“反向”方式驱动动画，从当前值运行到给定目标值。

返回一个 TickerFuture，它将在动画完成时完成。

最近返回的 TickerFuture（如果存在）会被标记为已取消，这意味着该 future 永远不会完成，而其派生的 TickerFuture.orCancel future 将以 TickerCanceled 错误完成。

动画运行期间，无论 target < value 是否成立，status 都为 AnimationStatus.reverse。动画结束、到达 target 时，status 为 AnimationStatus.dismissed。

如果 target 参数与动画当前的 value 相同，则不会运行动画，返回的 TickerFuture 已处于完成状态。
