使用弹簧和初始速度驱动动画，范围限制在 lowerBound 与 upperBound 之间。

如果速度为正，动画将运行到完成状态；否则运行到 dismissed 状态。速度以每秒单位数表示。如果设置了 SemanticsBinding.disableAnimations 标志，速度会乘以一个较为任意的系数 200。

springDescription 参数可用于指定驱动动画的自定义 SpringType.criticallyDamped 或 SpringType.overDamped 弹簧。默认使用 SpringType.criticallyDamped 弹簧。有关如何创建合适的 SpringDescription，请参阅 SpringDescription.withDampingRatio。

生成的弹簧模拟不能是 SpringType.underDamped 类型，因为这种弹簧会振荡，而不是执行 fling。

返回一个 TickerFuture，它将在动画完成时完成。

最近返回的 TickerFuture（如果存在）会被标记为已取消，这意味着该 future 永远不会完成，而其派生的 TickerFuture.orCancel future 将以 TickerCanceled 错误完成。

实现

@awaitNotRequired
TickerFuture fling({
  double velocity = 1.0,
  SpringDescription? springDescription,
  AnimationBehavior? animationBehavior,
}) {
  springDescription ??= _kFlingSpringDescription;
  _direction = velocity < 0.0 ? _AnimationDirection.reverse : _AnimationDirection.forward;
  final double target = velocity < 0.0
      ? lowerBound - _kFlingTolerance.distance
      : upperBound + _kFlingTolerance.distance;
  final AnimationBehavior behavior = animationBehavior ?? this.animationBehavior;
  // The "200.0" value is arbitrary (it was chosen because it worked for the drawer widget).
  final scale = behavior._enableAnimations ? 1.0 : 200.0;
  final simulation = SpringSimulation(springDescription, value, target, velocity * scale)
    ..tolerance = _kFlingTolerance;
  assert(
    simulation.type != SpringType.underDamped,
    'The specified spring simulation is of type SpringType.underDamped.\n'
    'An underdamped spring results in oscillation rather than a fling. '
    'Consider specifying a different springDescription, or use animateWith() '
    'with an explicit SpringSimulation if an underdamped spring is intentional.',
  );
  stop();
  return _startSimulation(simulation);
}
