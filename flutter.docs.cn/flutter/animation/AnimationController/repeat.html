开始正向运行此动画，并在完成后重新开始。

如果未显式设置 min 和 max，默认在 AnimationController 的 lowerBound 与 upperBound 之间重复运行。

将 reverse 设为 true 后，每次重复的起始值会在 min 和 max 之间交替，而不是始终从 min 重新开始。动画从 max 运行到 min 时，status 为 AnimationStatus.reverse。

动画每次运行的时长为 period。如果未提供 period，则使用 duration。必须在调用 repeat 之前设置该时长，可以在构造函数中设置，也可以稍后通过 duration setter 设置。

如果为 count 传入值，动画将在运行指定次数后停止。否则，动画会无限重复。

返回一个永远不会完成的 TickerFuture，除非指定了 count。动画停止时（例如调用 stop），TickerFuture.orCancel future 会以错误完成。

最近返回的 TickerFuture（如果存在）会被标记为已取消，这意味着该 future 永远不会完成，而其派生的 TickerFuture.orCancel future 将以 TickerCanceled 错误完成。

实现

@awaitNotRequired
TickerFuture repeat({
  double? min,
  double? max,
  bool reverse = false,
  Duration? period,
  int? count,
}) {
  min ??= lowerBound;
  max ??= upperBound;
  period ??= duration;
  assert(() {
    if (period == null) {
      throw FlutterError(
        'AnimationController.repeat() called without an explicit period and with no default Duration.\n'
        'Either the "period" argument to the repeat() method should be provided, or the '
        '"duration" property should be set, either in the constructor or later, before '
        'calling the repeat() function.',
      );
    }
    return true;
  }());
  assert(max >= min);
  assert(max <= upperBound && min >= lowerBound);
  assert(count == null || count > 0, 'Count shall be greater than zero if not null');
  stop();
  return _startSimulation(
    _RepeatingSimulation(_value, min, max, reverse, period!, _directionSetter, count),
  );
}
