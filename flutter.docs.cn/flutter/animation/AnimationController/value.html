value 属性

  1. @重写
double get value
重写

动画的当前值。

设置此值会通知所有监听器，告知值已发生变化。

如果控制器当前正在运行，设置此值还会停止控制器；发生这种情况时，也会通知所有状态监听器。

实现

@override
double get value => _value;
set value (double newValue)

停止动画控制器，并将动画设为当前值。

新值会限制在 lowerBound 和 upperBound 设定的范围内。

即使值没有变化，也会通知值监听器。如果动画此前正在播放，则会通知状态监听器。

如果最近返回过 TickerFuture，该 future 会被标记为已取消：它不会完成，而其派生的 TickerFuture.orCancel future 会以 TickerCanceled 错误完成。

另请参阅：

  • reset 等同于将 value 设为 lowerBound。
  • stop 会中止动画，但不改变其值或状态；除完成或取消 TickerFuture 外，不会分发任何通知。
  • forward、reverse、animateTo、animateWith、animateBackWith、fling 和 repeat 都会启动动画控制器。

实现

set value(double newValue) {
  stop();
  _internalSetValue(newValue);
  notifyListeners();
  _checkStatusChanged();
}
