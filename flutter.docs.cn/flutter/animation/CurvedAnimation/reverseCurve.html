reverseCurve 属性

Curve? reverseCurve
getter/setter 对

反向运行时使用的曲线。

如果父动画尚未达到 AnimationStatus.completed 或 AnimationStatus.dismissed 状态就改变方向，CurvedAnimation 会继续使用同一条曲线（但沿相反方向运行），以避免视觉上的不连续。

由于 CurvedAnimation 可能向父动画添加监听器，必须只创建一次（例如在 State.initState 中），并在 State.dispose 中释放。不要在每次 build 时重新创建，否则每次重建都会泄漏已添加的监听器。如果不需要 reverseCurve，优先使用 parent.drive(CurveTween(curve: curve))，它不需要单独释放。

如果此字段为 null，则两个方向都使用 curve。
