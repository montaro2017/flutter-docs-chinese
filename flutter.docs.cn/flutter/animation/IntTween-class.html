IntTween 类

两个整数之间的插值，结果四舍五入。

本类专门处理 Tween<int> 的插值，使其适用于整数：先在给定的起始值和结束值之间插值，再将结果舍入到最近的整数。

这是使用整数时最接近线性补间的近似。可与 StepTween 和 Tween<double> 比较。

调用 lerp 或 transform 之前，必须将 begin 和 end 设置为非 null 值。

有关插值对象的使用方法，请参阅 Tween。
