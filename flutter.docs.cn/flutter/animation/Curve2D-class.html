Curve2D 类 抽象

定义二维参数曲线求值 API 的抽象类。

Curve2D 与 Curve 的区别在于，插值结果是 Offset 值而非 double 值，名称中的“2D”由此而来。两者都将一个范围为 0.0 到 1.0（包含端点）的 double 参数 t 作为 transform 函数的输入。与 Curve 不同，Curve2D 不要求将 t=0.0 和 t=1.0 映射为特定的输出值。

传给 transform 的插值参数 t 表示沿曲线的进度，但不一定以恒定速度推进。因此，将 t 增加例如 0.1，可能在曲线的某一段移动很长距离，在另一段却几乎没有移动，具体取决于曲线的定义。

此示例展示如何使用 Curve2D 修改控件的位置，使其沿任意路径移动。
