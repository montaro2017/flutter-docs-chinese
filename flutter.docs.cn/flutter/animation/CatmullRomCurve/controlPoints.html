controlPoints 属性

List<Offset> controlPoints
final

用于创建此曲线的控制点。

controlPoints 中每个 Offset 的 dx 值，表示曲线应当经过该控制点 dy 值时所对应的动画值。

controlPoints 列表必须满足以下条件：

  • 列表中至少要包含两个点。
  • 每个点的 X 值必须大于 0.0 且小于 1.0。
  • 每个点的 X 值必须大于前一个点的 X 值（即严格递增）；Y 值不受限制。
  • 生成的样条在 X 方向上必须是单值的，也就是说，每个 X 值必须恰好对应一个 Y 值。因此，控制点不能生成自我回环或重叠的样条。

静态函数 validateControlPoints 可用于检查这些条件是否得到满足，若满足则返回 true。在调试模式下，它还可以选择性地以文本形式返回一组原因。在调试模式下，构造函数会断言这些条件成立，并在断言失败时打印相应的原因。

使用 transform 对该曲线求值时，数值会从一个控制点平滑插值到下一个控制点，依次经过 (0.0, 0.0)、给定的各个控制点以及 (1.0, 1.0)。
