AnimationController 类

动画的控制器。

此类让你能够执行如下任务：

  • Play an animation forward or in reverse, or stop an animation.
  • Set the animation to a specific value.
  • Define the upperBound 和 lowerBound values of an animation.
  • Create a fling animation effect using a physics simulation.

默认情况下，AnimationController 会在给定时长内线性地产出从 0.0 到 1.0 的值。

当动画处于活动状态时，动画控制器会在运行应用的设备准备好显示新一帧时（通常约为每秒 60–120 个值）生成一个新值。如果动画控制器通过 TickerProvider 与某个 State 关联，那么当该 State 的子树按 TickerMode 的定义被禁用时，它的更新将被静默；时间仍会流逝，forward 和 stop 等方法仍可调用并会改变值，但控制器本身不会生成新值。

Ticker 提供器

AnimationController 需要一个 TickerProvider，它通过构造函数的 vsync 参数进行配置。构造函数使用该 TickerProvider 创建一个 Ticker，AnimationController 用它来逐步推进所控制的动画。

有关获取 ticker 提供器的建议，请参阅 TickerProvider。通常由相关的 State 充当 ticker 提供器，做法是应用合适的 mixin（例如 SingleTickerProviderStateMixin），使 State 子类实现 TickerProvider。

生命周期

AnimationController 不再需要时应予以 dispose，以降低泄漏的可能性。与 StatefulWidget 搭配使用时，通常在 State.initState 方法中创建 AnimationController，并在 State.dispose 方法中将其释放。

在 AnimationController 中使用 Future

启动动画的方法会返回一个 TickerFuture 对象，该对象在动画成功完成时完成，且永远不会抛出错误；如果动画被取消，则该 future 永远不会完成。此对象还有一个 TickerFuture.orCancel 属性，返回一个在动画成功完成时完成、在动画中止时以错误完成的 future。

可以使用它来编写类似下面 fadeOutAndUpdateState 方法的代码。

以下是一个有状态的 Foo 控件。它的 State 使用 SingleTickerProviderStateMixin 实现所需的 TickerProvider，在 State.initState 中创建控制器，并在 State.dispose 中释放控制器。控制器的时长由 Foo 控件的属性配置；该属性变化时，通过 State.didUpdateWidget 更新控制器。
link 
class Foo extends StatefulWidget {
  const Foo({ super.key, required this.duration });

  final Duration duration;

  @override
  State<Foo> createState() => _FooState();
}

class _FooState extends State<Foo> with SingleTickerProviderStateMixin {
  late AnimationController _controller;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this, // the SingleTickerProviderStateMixin
      duration: widget.duration,
    );
  }

  @override
  void didUpdateWidget(Foo oldWidget) {
    super.didUpdateWidget(oldWidget);
    _controller.duration = widget.duration;
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Container(); // ...
  }
}

以下方法（属于 State 子类）使用 Dart 的异步语法等待 Future 对象，从而驱动两个动画控制器：
link 
Future<void> fadeOutAndUpdateState() async {
  try {
    await fadeAnimationController.forward().orCancel;
    await sizeAnimationController.forward().orCancel;
    setState(() {
      dismissed = true;
    });
  } on TickerCanceled {
    // the animation got canceled, probably because we were disposed
  }
}

上述代码假设动画控制器是在 State 子类对 State.dispose 方法的重写中被释放的。由于释放控制器会取消动画（抛出 TickerCanceled 异常），此处的代码可以跳过在每一步验证 State.mounted 是否仍为 true。（同样，这里假设控制器是在 State.initState 中创建、在 State.dispose 中释放的，如上一节所述。）

此示例展示如何使用 AnimationController 和 SlideTransition 创建动画数字，效果类似老式弹珠台或汽车里程表。新数字从下方滑入，旧数字则向上滑出视野。若控制器正在播放动画时发生点击，会缩短 AnimationController.duration，避免动画效果落后。
