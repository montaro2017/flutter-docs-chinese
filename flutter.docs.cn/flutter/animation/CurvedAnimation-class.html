CurvedAnimation 类

对另一个动画应用曲线的动画。

当需要对动画对象应用非线性的 Curve 时，CurvedAnimation 很有用，尤其是在希望动画正向和反向运行时使用不同曲线的情况下。

根据给定曲线，CurvedAnimation 的输出范围可能比输入范围更宽。例如，Curves.elasticIn 等弹性曲线会明显超过或低于默认的 0.0 到 1.0 范围。

如果要对 Tween 应用 Curve，可考虑使用 CurveTween。

不再需要 CurvedAnimation 时应释放它，以清理可能添加的监听器。释放父动画（通常是 AnimationController）也会清理此对象。不要在 build 方法内创建 CurvedAnimation，否则每次重建都会泄漏已添加的监听器。如果不需要 reverseCurve，优先使用 parent.drive(CurveTween(curve: curve))，它不需要单独释放。

以下代码展示如何将曲线应用到由 AnimationController controller 生成的线性动画。
link 
final Animation<double> animation = CurvedAnimation(
  parent: controller,
  curve: Curves.ease,
);

以下第二段代码展示如何在正向和反向播放时分别应用不同的曲线。CurveTween 无法实现这一点，因为应用 Tween 时并不知道动画的播放方向。
link 
final Animation<double> animation = CurvedAnimation(
  parent: controller,
  curve: Curves.easeIn,
  reverseCurve: Curves.easeOut,
);

默认情况下，reverseCurve 与正向的 curve 相同。

另请参阅：

  • CurveTween，提供另一种表达上方第一个示例的方式。
  • AnimationController，提供创建和释放以下对象的示例： AnimationController.
  • Curve.flipped 和 FlippedCurve，用于获得以下曲线的反转形式： Curve.
