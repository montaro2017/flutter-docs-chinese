Tween<T extends Object?> 类

起始值与结束值之间的线性插值。

如果需要在某个范围内进行插值，Tween 会很有用。

要在动画中使用 Tween 对象，请调用该 Tween 对象的 animate 方法，并把想要修改的 Animation 对象传给它。

可以使用 chain 方法把多个 Tween 对象串联起来，从而得到它们的 transform 方法的函数复合结果。对得到的 Tween 调用 animate 来配置单个 Animation 对象，与依次对每个 Tween 分别调用 animate 方法的效果相同，但效率更高，因为它避免了为中间结果创建 Animation 对象。

假设 _controller 是一个 AnimationController，我们想创建一个由该控制器驱动并保存到 _animation 中的 Animation<Offset>。以下是两种可行写法：
link 
_animation = _controller.drive(
  Tween<Offset>(
    begin: const Offset(100.0, 50.0),
    end: const Offset(200.0, 300.0),
  ),
);

link 
_animation = Tween<Offset>(
  begin: const Offset(100.0, 50.0),
  end: const Offset(200.0, 300.0),
).animate(_controller);

在这两种情况下，_animation 变量持有的对象都会在 _controller 动画的整个生命周期内返回一个值（_animation.value），该值表示上面两个偏移量之间连线上的一个点。如果在上面的代码中改用 MaterialPointArcTween 而不是 Tween<Offset>，这些点将沿着一条优美的曲线而不是直线移动，无需做任何其他改动。

性能优化

补间是可变的；具体来说，它们的 begin 和 end 值可以在运行时更改。通过 Animation.drive 使用 Tween 创建的对象会立即响应底层 Tween 的更改（不过只有在 Animation 正在主动播放动画时才会触发监听器）。这可以用来动态地更改动画，而不必从 AnimationController 到最终的 Tween 重新创建链上的所有对象。

不过，如果某个 Tween 的值从不改变，还可以再做一层优化：可以把该对象存放在 static final 变量中，使每次需要该 Tween 时使用的都是同一个实例。例如，这比每次调用 State.build 方法时都重新创建一个完全相同的 Tween 更可取。

需要特殊考虑的类型

带有 lerp 静态方法的类，通常都有相应的专用 Tween 子类来调用该方法。例如，ColorTween 使用 Color.lerp 来实现 ColorTween.lerp 方法。

定义了 + 和 - 运算符用于组合值（T + T → T 和 T - T → T），以及 * 运算符用于乘以 double 进行缩放（T * double → T）的类型，可以直接与 Tween<T> 一起使用。

这并不适用于任何具有 +、- 和 * 运算符的类型。特别是，int 并不满足这一严格的约定（int * double 实际返回的是 num，而不是 int）。因此有两个专门的类可用于对整数进行插值：

  • IntTween 使用 double.round 近似实现线性插值。
  • StepTween 使用 double.floor，确保结果不会大于使用 Tween<double> 时的结果。

Size 上的相关运算符同样不满足这一约定，因此 SizeTween 使用 Size.lerp。

此外，一些确实具有合适的 +、- 和 * 运算符的类型，也仍然拥有以更专门的方式执行插值的 Tween 子类。其中一个例子是上面提到的 MaterialPointArcTween。AlignmentTween、AlignmentGeometryTween 和 FractionalOffsetTween 则是另一组使用专用 lerp 方法、而不是仅仅依赖运算符的 Tween（尤其是，这使它们能够以更有用的方式处理 null 值）。

可空性

begin 和 end 字段是可空的；Tween 在创建时不必指定非空值。

如果 T 是可空的，那么 lerp 和 transform 可能返回 null。这通常出现在 begin 为 null 且 t 为 0.0，或 end 为 null 且 t 为 1.0，或两者都为 null（无论 t 取何值）的情况下。

如果 T 是非空的，那么在使用 lerp 或 transform 之前，begin 和 end 都必须设置为非空值，否则它们会抛出异常。

实现 Tween

要针对新类型特化本类，子类应当实现 lerp 方法（以及一个构造函数）。本类的其他方法全都是基于 lerp 定义的。
