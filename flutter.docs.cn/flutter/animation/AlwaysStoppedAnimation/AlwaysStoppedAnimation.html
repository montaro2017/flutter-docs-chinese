使用给定值创建 AlwaysStoppedAnimation。

由于 AlwaysStoppedAnimation 的 value 和 status 永远不会改变，监听器也永远不会被调用。因此，可以安全地在多个位置复用同一个 AlwaysStoppedAnimation 实例。如果要使用的 value 在编译时已知，应以 const 构造函数的方式调用此构造函数。
