Animatable<T> 类 抽象

以 Animation<double> 为输入，生成 T 类型值的对象。

输入动画的值通常在名义上处于 0.0 到 1.0 范围内，但原则上可以提供任意值。

Animatable 的主要子类是 Tween。

实现类
  • CurveTween
  • Tween
  • TweenSequence
