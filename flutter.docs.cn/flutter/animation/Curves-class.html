easeInExpo → const Cubic

一条起始迅速、结束缓慢的三次动画曲线。
easeOutBack → const Cubic
一条起始迅速、结束缓慢的三次动画曲线。该曲线与 Curves.elasticOut 类似，都会在到达终点前越过其边界。不过，该曲线在上升之后不会反复摆动，而只越过边界一次。

easeOutQuart → const Cubic
一条起始迅速、结束缓慢的三次动画曲线。该曲线是 Curves.easeInQuart 的翻转版本。
easeOutQuint → const Cubic
一条起始迅速、结束缓慢的三次动画曲线。该曲线是 Curves.easeInQuint 的翻转版本。
easeOutSine → const Cubic
一条起始迅速、结束缓慢的三次动画曲线。它与 Curves.easeOut 类似，但采用正弦缓动，使开始和结束处略为平缓。尽管如此，结果依然相当平缓，乍看之下很难与 Curves.linear 区分开来。
