Simulation 类 抽象

所有模拟的基类。

模拟描述一个在一维空间中受到特定力作用的对象，并提供以下功能：

  • The object's position, x
  • The object's velocity, dx
  • Whether the simulation is "done", isDone

通常，当对象在给定的 tolerance 范围内完全静止时，模拟就算“完成”。

x、dx 和 isDone 函数都接收一个时间参数，用于指定计算所针对的时刻。理论上，模拟可以是无状态的，因此可查询任意时刻。但实际上，有些模拟并非如此；调用这些函数中的任意一个，都会将模拟推进到指定时刻。

因此，一般而言，对模拟的查询所使用的时间应大于或等于此前查询过的所有时间。

模拟不规定距离、速度和时间的单位。调用方应建立一套约定，并在所有相关对象中始终遵循该约定。
