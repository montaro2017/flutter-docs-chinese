kTertiaryButton top-level constant

int const kTertiaryButton

PointerEvent.buttons 中对应跨设备“第三操作”行为的位。

它等同于：

  • kMiddleMouseButton：鼠标第三按钮。
  • kSecondaryStylusButton：触控笔上的次要按键。由于触控笔接触本身已对应“次要操作”（接触是触控笔的主要操作），因此此按键被视为第三按键。

另请参阅：

  • kPrimaryButton，用于描述跨设备的“主要操作”行为。
  • kSecondaryButton，用于描述跨设备的“次要操作”行为。

实现

const int kTertiaryButton = 0x04;
