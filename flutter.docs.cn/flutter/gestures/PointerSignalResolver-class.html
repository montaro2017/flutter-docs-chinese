PointerSignalResolver 类

当多个监听器都希望处理指针信号事件时，此类用于协调由哪个监听器处理。

指针信号（例如 PointerScrollEvent）会立即发生，因此与参与手势竞技场的事件不同，指针信号总是在事件分发结束时得到处理。但如果对这些信号感兴趣的对象直接处理它们，可能会导致问题，例如控件树中的多个 Scrollable 控件响应同一个鼠标滚轮事件。使用此类后，事件只会分发给第一个注册的处理器，而它对应于控件树中层级最深的控件。

使用此类时，对象应按如下方式注册事件处理器：

void handleSignalEvent(PointerSignalEvent event) {
  GestureBinding.instance.pointerSignalResolver.register(event, (PointerSignalEvent event) {
    // handle the event...
  });
}

此示例设置为不使用解析器时，在外层方框上滚动鼠标滚轮只会改变外层方框的颜色；在内层方框上滚动时，内外两个方框都会改变颜色（因为它们都收到了该事件）。
