PositionedGestureDetails 类 抽象 interface

表示包含位置信息的手势详细信息的抽象接口。

此类为涉及位置数据的手势详细信息提供通用接口，例如拖动和点击。它通过支持在多种手势类型之间共享逻辑，简化了手势处理；用户可以创建一个方法，统一处理包含此位置信息的各类手势详情。例如：

void handlePositionedGestures(PositionedGestureDetails details) {
  // Handle the positional information of the gesture details.
}
