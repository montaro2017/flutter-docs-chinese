PointerHoverEvent 类

指针未与设备接触期间，相对于设备发生了移动。

另请参阅：

  • PointerEnterEvent，报告指针进入对象时的情况。
  • PointerExitEvent，报告指针离开对象时的情况。
  • PointerMoveEvent，报告指针与设备接触时的移动。
  • Listener.onPointerHover，允许调用方在 widget 树中收到这些事件的通知。
