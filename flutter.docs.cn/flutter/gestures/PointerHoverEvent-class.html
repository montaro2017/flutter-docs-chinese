PointerHoverEvent 类

指针未与设备接触期间，相对于设备发生了移动。

另请参阅：

  • PointerEnterEvent, which reports when the pointer has entered an object.
  • PointerExitEvent, which reports when the pointer has left an object.
  • PointerMoveEvent, which reports movement while the pointer is in contact with the device.
  • Listener.onPointerHover，允许调用方在 widget 树中收到这些事件的通知。
