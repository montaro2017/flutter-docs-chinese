MacOSScrollViewFlingVelocityTracker 类

一种 VelocityTracker 子类，可近似实现 macOS 滚动视图的速度估算策略。

当触发快速滑动的触摸抬起时，此类报告的估算速度接近 macOS 滚动视图在收到相同 PointerMoveEvent 时报告的速度。

与 VelocityTracker 不同，此类使用被跟踪指针最近几个速度样本的加权平均值来估算速度，而不是对较多数据点进行线性回归。添加数据点和估算速度的开销都很低。

要获取速度，请调用 getVelocity 或 getVelocityEstimate。手势拖动结束时，估算速度通常用作 Scrollable 的初始快速滑动速度。
