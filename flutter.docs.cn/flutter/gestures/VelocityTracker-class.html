VelocityTracker 类

根据 PointerMoveEvent 数据计算指针速度。

通过调用 addPosition 提供输入数据。添加数据的开销很低。

要获取速度，请调用 getVelocity 或 getVelocityEstimate。这会根据目前已添加的数据计算速度。仅在需要使用速度时才调用这些方法，因为它们的开销相对较高。

接收到的数据点越多，速度估算的质量通常越高。
