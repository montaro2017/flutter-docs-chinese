PointerEvent 类 抽象

触摸、触控笔或鼠标事件的基类。

指针事件使用屏幕坐标空间，并按比例转换为逻辑像素。逻辑像素近似构成每厘米约 38 像素或每英寸 96 像素的网格。

这样，无论设备的具体硬件特性如何，都可以识别手势。尤其是触摸容差（参见 kTouchSlop）等特性可以按大致的物理长度定义，使用户在高密度屏幕和低分辨率设备上都能移动相同的距离。

出于类似原因，指针事件不受渲染层中任何变换的影响。因此，在将位移量用于渲染中的移动之前，可能需要先进行缩放。例如，如果滚动列表以 2 倍比例显示，则必须按相反比例缩放指针位移量，列表滚动起来才会像跟随用户手指一样。

另请参阅：

  • dart:ui.FlutterView.devicePixelRatio, which defines the device's current resolution.
  • Listener, a widget that calls callbacks in response to common pointer events.
