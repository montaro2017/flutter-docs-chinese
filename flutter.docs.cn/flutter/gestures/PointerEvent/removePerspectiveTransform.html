移除 transform 中的“透视”分量。

将结果变换矩阵应用于 z 坐标为零的点（通常所有由 Offset 表示的点都符合这一假设）时，其他坐标仍按原方式变换，但新的 z 坐标会再次变为零。这通过将矩阵的第三列和第三行设为“0, 0, 1, 0”来实现。

实现

static Matrix4 removePerspectiveTransform(Matrix4 transform) {
  final vector = Vector4(0, 0, 1, 0);
  return transform.clone()
    ..setColumn(2, vector)
    ..setRow(2, vector);
}
