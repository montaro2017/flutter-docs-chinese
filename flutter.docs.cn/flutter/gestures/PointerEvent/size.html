size 属性

double size
final

屏幕上受到按压的区域。

此值按比例缩放到 0 到 1 的范围，可用于判断是否为大面积触摸事件。该值仅在 Android 上设置，是设备特定的近似值，范围取决于设备可检测的数值。例如，0.1 可能表示指尖触摸，0.2 表示整个手指触摸，0.3 表示整个手掌触摸。

由于此值使用设备特定且未经校准的范围，因此用途有限，主要是为了能够为 AndroidView 还原原始指针事件。
