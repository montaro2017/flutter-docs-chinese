BaseTapAndDragGestureRecognizer
description

BaseTapAndDragGestureRecognizer 类 sealed

用于识别点击和移动手势的识别器基类。

在一个 GestureRecognizer 中承担 TapGestureRecognizer 和 DragGestureRecognizer 的职责。

手势竞技场行为

BaseTapAndDragGestureRecognizer 仅会在 kPrimaryButton 的指针事件中参与竞争，前提是至少设置了一个非 null 的 onTap* 或 onDrag* 回调。

如果它判断当前手势既不是点击（例如指针接触屏幕时被拖动得太远），也不是拖动（例如指针移动距离不足以构成拖动），就会认输。

此识别器不会对识别出的每次点击立即宣布获胜，但会对每次拖动宣布获胜。

在竞技场中的所有其他识别器都失败后，如果追踪的连续点击次数大于 1 且 kPressTimeout 计时结束，或者指针已从起点移动足够远的全局距离而构成拖动时，此识别器会宣布获胜。

如果此识别器在指针仍接触屏幕时输掉竞技场（无论是自行认输，还是其他识别器获胜），它会触发 onCancel，而不是 onTapUp 或 onDragEnd。

与 TapGestureRecognizer 和 DragGestureRecognizer 竞争时

与 TapGestureRecognizer 和 DragGestureRecognizer 类似，BaseTapAndDragGestureRecognizer 检测到点击时不会急于宣布获胜，因此与这些识别器及其他识别器竞争时可能会落败。同样，当 eagerVictoryOnDrag 设为 false 时，此识别器检测到拖动也不会急于宣布获胜。默认情况下，eagerVictoryOnDrag 为 true，所以检测到拖动时会立即争取获胜。

与 TapGestureRecognizer 竞争时，如果指针移动未超过点击容差，先进入竞技场的识别器获胜，此时识别到的是点击。如果指针移动超过点击容差，此识别器默认获胜，此时识别到的是拖动。

与 DragGestureRecognizer 竞争时，如果指针移动的全局距离不足以构成拖动，两个识别器会在竞技场中平局。如果指针移动距离足够，先进入竞技场的识别器获胜，此时识别到的是拖动。

flutter create --sample=gestures.BaseTapAndDragGestureRecognizer.1 mysample

此示例展示如何将 TapAndPanGestureRecognizer 连接到嵌套的 RawGestureDetector。假设代码位于一个 State 对象中，其中的 _last 字段会显示为手势检测器的子组件。

在此示例中，如果指针移动超过拖动阈值，最先收到 PointerEvent 的第一个 TapAndPanGestureRecognizer 实例会赢得竞技场，因为识别器会立即宣布获胜。

示例中哪个识别器先收到事件，取决于指针首先落在两个容器的哪个位置。如果指针从两个容器重叠的区域开始，最内层的组件会先收到事件。如果指针从黄色容器内开始，该容器中的识别器会先收到事件。

如果指针移动未超过拖动阈值，则最先进入竞技场的识别器获胜（也就是说，两者平局，手势竞技场会调用 GestureArenaManager.sweep，让最先加入竞技场的成员获胜）。

RawGestureDetector(
  gestures: <Type, GestureRecognizerFactory>{
    TapAndPanGestureRecognizer: GestureRecognizerFactoryWithHandlers<TapAndPanGestureRecognizer>(
      () => TapAndPanGestureRecognizer(),
      (TapAndPanGestureRecognizer instance) {
        instance
          ..onTapDown = (TapDragDownDetails details) { setState(() { _last = 'down_a'; }); }
          ..onDragStart = (TapDragStartDetails details) { setState(() { _last = 'drag_start_a'; }); }
          ..onDragUpdate = (TapDragUpdateDetails details) { setState(() { _last = 'drag_update_a'; }); }
          ..onDragEnd = (TapDragEndDetails details) { setState(() { _last = 'drag_end_a'; }); }
          ..onTapUp = (TapDragUpDetails details) { setState(() { _last = 'up_a'; }); }
          ..onCancel = () { setState(() { _last = 'cancel_a'; }); };
      },
    ),
  },
  child: Container(
    width: 300.0,
    height: 300.0,
    color: Colors.yellow,
    alignment: Alignment.center,
    child: RawGestureDetector(
      gestures: <Type, GestureRecognizerFactory>{
        TapAndPanGestureRecognizer: GestureRecognizerFactoryWithHandlers<TapAndPanGestureRecognizer>(
          () => TapAndPanGestureRecognizer(),
          (TapAndPanGestureRecognizer instance) {
            instance
              ..onTapDown = (TapDragDownDetails details) { setState(() { _last = 'down_b'; }); }
              ..onDragStart = (TapDragStartDetails details) { setState(() { _last = 'drag_start_b'; }); }
              ..onDragUpdate = (TapDragUpdateDetails details) { setState(() { _last = 'drag_update_b'; }); }
              ..onDragEnd = (TapDragEndDetails details) { setState(() { _last = 'drag_end_b'; }); }
              ..onTapUp = (TapDragUpDetails details) { setState(() { _last = 'up_b'; }); }
              ..onCancel = () { setState(() { _last = 'cancel_b'; }); };
          },
        ),
      },
      child: Container(
        width: 150.0,
        height: 150.0,
        color: Colors.blue,
        child: Text(_last),
      ),
    ),
  ),
)
