nthMouseButton function

int nthMouseButton(
  1. int number
)

PointerEvent.buttons 中对应第 n 个鼠标按钮的位。

在 Flutter 移动端和桌面端，number 参数最大为 62；在 Flutter Web 上最大为 32。

部分鼠标按钮的语义名称参见 kPrimaryMouseButton、kSecondaryMouseButton、kMiddleMouseButton、kBackMouseButton 和 kForwardMouseButton。

实现

int nthMouseButton(int number) => (kPrimaryMouseButton << (number - 1)) & kMaxUnsignedSMI;
