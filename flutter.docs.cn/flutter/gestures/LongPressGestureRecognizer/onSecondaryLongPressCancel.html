onSecondaryLongPressCancel 属性

GestureLongPressCancelCallback? onSecondaryLongPressCancel
getter/setter 对

当此前触发过 onSecondaryLongPressDown 的指针最终不会触成长按时调用。

如果此前触发过 onSecondaryLongPressDown，则在该手势输掉竞技场时触发此回调。

如果此识别器赢得竞技场，则会改为调用 onSecondaryLongPressStart 和 onSecondaryLongPress。

如果因超过 postAcceptSlopTolerance 而停用手势，则不会调用此回调，因为此时手势已经赢得竞技场。

另请参阅：

  • kSecondaryButton, the button this callback responds to.
