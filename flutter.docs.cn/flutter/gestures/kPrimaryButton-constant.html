kPrimaryButton top-level constant

int const kPrimaryButton

PointerEvent.buttons 中对应跨设备“主要操作”行为的位。

具体来说，它包括：

  • kTouchContact：指针接触触摸屏。
  • kStylusContact：触控笔接触屏幕。
  • kPrimaryMouseButton：鼠标主按钮。

另请参阅：

  • kSecondaryButton，用于描述跨设备的“次要操作”行为。
  • kTertiaryButton，用于描述跨设备的“第三操作”行为。

实现

const int kPrimaryButton = 0x01;
