AboutListTile 类

用于显示关于信息对话框的 ListTile。

此 widget 通常放在应用的 Drawer 中。点击后会通过 showAboutDialog 显示关于信息对话框。

关于信息对话框会包含一个按钮，用于查看应用所用软件的许可证。显示的许可证由 LicenseRegistry API 提供；你可以使用该 API 将更多许可证添加到列表中。

如果应用没有 Drawer，应提供一种方式来调用 showAboutDialog，或至少调用 showLicensePage。

此示例展示打开 AboutDialog 的两种方式：第一种使用 AboutListTile，第二种使用 showAboutDialog 函数。
