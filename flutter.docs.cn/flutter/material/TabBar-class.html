TabBar 类

Material Design 主标签栏。

主标签位于内容窗格顶部的应用栏下方，用于显示主要内容目的地。

通常将其创建为 AppBar 的 AppBar.bottom 部分，并与 TabBarView 配合使用。

如果未提供 TabController，则必须提供 DefaultTabController 祖先。标签控制器的 TabController.length 必须等于 tabs 列表和 TabBarView.children 列表的长度。

其祖先组件中必须有一个 Material 组件。

如果当前上下文中设置了 TabBarThemeData，则使用其中的值。

此示例展示如何使用 DefaultTabController 实现 TabBar 和 TabBarView。每个 Tab 都按编写顺序对应 TabBarView 的一个子项。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.TabBar.1 mysample

也可以使用 TabController 实现 TabBar，以获得更多控制 TabBar 和 TabBarView 行为的选项。如下所示，这可以替代 DefaultTabController。

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.TabBar.2 mysample

此示例展示 Material 3 中嵌套的 TabBar。它由一个主 TabBar 和一个嵌套的次级 TabBar 组成。主 TabBar 使用 DefaultTabController，次级 TabBar 使用 TabController。

要使用此代码示例创建本地项目，请运行：

此示例展示如何根据 TabBar 的滚动情况应用自定义行为。它在 NotificationListener 回调中使用滚动通知（ScrollMetricsNotification 和 ScrollNotification）监视滚动偏移量，并据此自定义界面。

  • TabBar.secondary, for a secondary tab bar.
  • TabBarView, which displays page views that correspond to each tab.
  • TabController, which coordinates tab selection between a TabBar and a TabBarView.
  • https://m3.material.io/components/tabs/overview, the Material 3 tab bar specification.
