重写

描述此 widget 所表示的用户界面部分。

框架会在多种情况下调用此方法。例如：

  • After calling initState.
  • After calling didUpdateWidget.
  • After receiving a call to setState.
  • After a dependency of this State object changes (e.g., an InheritedWidget referenced by the previous build changes).
  • After calling deactivate and then reinserting the State object into the tree at another location.

此方法可能会在每一帧中调用，因此除了构建 Widget 外，不应产生任何副作用。

框架会将此 widget 下方的子树替换为此方法返回的 widget。根据返回的 widget 是否能够更新现有子树的根节点（由调用 Widget.canUpdate 判定），框架会更新现有子树，或移除它并重新创建子树。

通常，实现会返回一组新创建的 Widget，并根据此 Widget 的构造函数信息、给定的 BuildContext 以及此 State 对象的内部状态进行配置。

给定的 BuildContext 包含此 Widget 在树中构建位置的信息。例如，该 context 提供树中此位置的继承 Widget 集合。BuildContext 参数始终与此 State 对象的 context 属性相同，并且在此对象的整个生命周期内保持不变。此处冗余地提供 BuildContext 参数，是为了使此方法与 WidgetBuilder 的签名一致。

设计讨论

为什么 build 方法定义在 State 上，而不是 StatefulWidget 上？

将 Widget build(BuildContext context) 方法定义在 State 上，而不是将 Widget build(BuildContext context, State state) 方法定义在 StatefulWidget 上，可以让开发者在继承 StatefulWidget 时拥有更大的灵活性。

例如，AnimatedWidget 是 StatefulWidget 的子类，它为子类引入了一个抽象的 Widget build(BuildContext context) 方法供其实现。如果 StatefulWidget 本身已有一个 build 方法，该方法接收 State 参数，那么 AnimatedWidget 就不得不把自己的 State 对象提供给子类，即使其 State 对象只是 AnimatedWidget 的内部实现细节。

从概念上说，也可以用类似方式将 StatelessWidget 实现为 StatefulWidget 的子类。如果 build 方法定义在 StatefulWidget 而不是 State 上，这种实现方式就不再可行。

将 build 函数放在 State 而不是 StatefulWidget 上，也有助于避免一类与闭包隐式捕获 this 有关的错误。如果在 StatefulWidget 的 build 函数中定义闭包，该闭包会隐式捕获 this，也就是当前 Widget 实例，因此该实例不可变的字段会处于作用域内：

// (this is not valid Flutter code)
class MyButton extends StatefulWidgetX {
  MyButton({super.key, required this.color});

  final Color color;

  @override
  Widget build(BuildContext context, State state) {
    return SpecialWidget(
      handler: () { print('color: $color'); },
    );
  }
}

例如，假设父组件构建 MyButton 时将 color 设为蓝色，那么打印函数中的 $color 会如预期一样指向蓝色。现在假设父组件重建 MyButton 并将其颜色设为绿色。第一次构建创建的闭包仍隐式引用原来的 Widget，因此即使 Widget 已更新为绿色，$color 打印的仍是蓝色；如果该闭包的生命周期超过了 Widget，它就会打印过时的信息。

相反，如果将 build 函数放在 State 对象上，build 期间创建的闭包会隐式捕获 State 实例，而不是 Widget 实例：

class MyButton extends StatefulWidget {
  const MyButton({super.key, this.color = Colors.teal});

  final Color color;
  // ...
}

class MyButtonState extends State<MyButton> {
  // ...
  @override
  Widget build(BuildContext context) {
    return SpecialWidget(
      handler: () { print('color: ${widget.color}'); },
    );
  }
}

现在父组件将 MyButton 重建为绿色时，第一次构建创建的闭包仍引用同一个 State 对象。该对象会在重建期间保留，但框架已更新其 State 对象的 widget 属性，使其指向新的 MyButton 实例，因此 ${widget.color} 会如预期一样打印绿色。

@protected
@override
Widget build(BuildContext context) {
  assert(debugCheckHasMaterialLocalizations(context));
  final Widget child = NotificationListener<ScrollNotification>(
    onNotification: _handleScrollNotification,
    child: NotificationListener<OverscrollIndicatorNotification>(
      onNotification: _handleIndicatorNotification,
      child: widget.child,
    ),
  );
  assert(() {
    if (_status == null) {
      assert(_dragOffset == null);
      assert(_isIndicatorAtTop == null);
    } else {
      assert(_dragOffset != null);
      assert(_isIndicatorAtTop != null);
    }
    return true;
  }());

  final bool showIndeterminateIndicator =
      _status == RefreshIndicatorStatus.refresh || _status == RefreshIndicatorStatus.done;

  return Stack(
    children: <Widget>[
      child,
      if (_status != null)
        Positioned(
          top: _isIndicatorAtTop! ? widget.edgeOffset : null,
          bottom: !_isIndicatorAtTop! ? widget.edgeOffset : null,
          left: 0.0,
          right: 0.0,
          child: SizeTransition(
            alignment: AlignmentDirectional(-1.0, _isIndicatorAtTop! ? 1.0 : -1.0),
            sizeFactor: _positionFactor, // This is what brings it down.
            child: Padding(
              padding: _isIndicatorAtTop!
                  ? EdgeInsets.only(top: widget.displacement)
                  : EdgeInsets.only(bottom: widget.displacement),
              child: Align(
                alignment: _isIndicatorAtTop! ? Alignment.topCenter : Alignment.bottomCenter,
                child: ScaleTransition(
                  scale: _scaleFactor,
                  child: AnimatedBuilder(
                    animation: _positionController,
                    builder: (BuildContext context, Widget? child) {
                      final Widget materialIndicator = RefreshProgressIndicator(
                        semanticsLabel:
                            widget.semanticsLabel ??
                            MaterialLocalizations.of(context).refreshIndicatorSemanticLabel,
                        semanticsValue: widget.semanticsValue,
                        value: showIndeterminateIndicator ? null : _value.value,
                        valueColor: _valueColor,
                        backgroundColor: widget.backgroundColor,
                        strokeWidth: widget.strokeWidth,
                        elevation: widget.elevation,
                      );

                      final Widget cupertinoIndicator = CupertinoActivityIndicator(
                        color: widget.color,
                      );

                      switch (widget._indicatorType) {
                        case _IndicatorType.material:
                          return materialIndicator;

                        case _IndicatorType.adaptive:
                          final ThemeData theme = Theme.of(context);
                          switch (theme.platform) {
                            case TargetPlatform.android:
                            case TargetPlatform.fuchsia:
                            case TargetPlatform.linux:
                            case TargetPlatform.windows:
                              return materialIndicator;
                            case TargetPlatform.iOS:
                            case TargetPlatform.macOS:
                              return cupertinoIndicator;
                          }

                        case _IndicatorType.noSpinner:
                          return Container();
                      }
                    },
                  ),
                ),
              ),
            ),
          ),
        ),
    ],
  );
}
