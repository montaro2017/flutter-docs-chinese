InputDecoration 类

用于装饰 Material Design 文本输入框的边框、标签、图标和样式。

TextField 和 InputDecorator 使用 InputDecoration 对象描述装饰。实际上，此类只是 InputDecorator 的配置；具体的绘制工作由 InputDecorator 完成。

此示例展示如何使用 InputDecorator 设置 TextField 的样式。输入区域左侧显示“发送消息”图标，四周带有边框。输入区域内显示 hintText，帮助用户了解需要输入的内容；区域下方则显示 helperText 和 counterText。

link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.InputDecoration.1 mysample

此示例展示如何使用 InputDecorator 设置“折叠”TextField 的样式。折叠的 TextField 会为提示文本和输入区域添加边框，但不会在它们周围增加内边距。
