showDialog<T> function

Future<T?> showDialog<T>({
  1. required BuildContext context,
  2. required WidgetBuilder builder,
  3. bool barrierDismissible = true,
  4. Color? barrierColor,
  5. String? barrierLabel,
  6. bool useSafeArea = true,
  7. bool useRootNavigator = true,
  8. RouteSettings? routeSettings,
  9. Offset? anchorPoint,
  10. TraversalEdgeBehavior? traversalEdgeBehavior,
  11. bool fullscreenDialog = false,
  12. bool? requestFocus,
  13. AnimationStyle? animationStyle,
})

在当前应用内容上方显示 Material 对话框，并提供 Material 的进入和退出动画、模态遮罩颜色以及遮罩行为（点击遮罩可关闭对话框）。

如果通过 flutter config --enable-windowing 启用了窗口模式，对话框会由窗口系统显示在独立窗口中，而不是作为当前窗口内的模态覆盖层。此功能仅适用于支持对话框窗口类型的平台。真正的对话框窗口没有遮罩。

此函数接收一个 builder，通常用于构建 Dialog 控件。对话框下方的内容会被 ModalBarrier 遮暗。builder 返回的控件与最初调用 showDialog 的位置不共享上下文。如果对话框需要动态更新，请使用 StatefulBuilder 或自定义的 StatefulWidget。

context 参数用于查找对话框所用的 Navigator 和 Theme。它只在调用此方法时使用。对话框关闭前，可以安全地将对应控件从树中移除。

barrierDismissible 参数用于指定点击遮罩是否会关闭对话框。默认值为 true，且不能为 null。如果通过 flutter config --enable-windowing 启用了窗口模式，则会忽略此参数，因为对话框显示在没有模态遮罩的独立窗口中。

barrierColor 参数用于指定模态遮罩的颜色，遮罩会使对话框下方的所有内容变暗。如果为 null，则使用 DialogThemeData 的 barrierColor 字段；若该字段也为 null，则使用默认颜色 Colors.black54。如果通过 flutter config --enable-windowing 启用了窗口模式，则会忽略此参数，因为对话框显示在没有模态遮罩的独立窗口中。

useSafeArea 参数用于指定对话框是否只能显示在屏幕上未被操作系统占用的“安全”区域内（详情请参阅 SafeArea）。默认值为 true，表示对话框不会与操作系统区域重叠。设为 false 时，对话框仅受屏幕尺寸限制。此参数不能为 null。

useRootNavigator 参数用于确定将对话框推送到距离给定 context 最远还是最近的 Navigator。useRootNavigator 的默认值为 true，此方法创建的对话框路由会推送到根导航器。此参数不能为 null。

routeSettings 参数会传给 showGeneralDialog。详情请参阅 RouteSettings。

如果不为 null，traversalEdgeBehavior 参数会指定焦点移出对话框路由中第一个或最后一个项目时的处理方式。默认使用 TraversalEdgeBehavior.closedLoop，因为对话框通常允许用户在其中循环切换焦点，而不离开对话框。如果通过 flutter config --enable-windowing 启用了窗口模式，则会忽略此参数，因为独立对话框窗口会自行管理焦点遍历。

requestFocus 参数用于指定显示对话框时是否请求焦点。如果未提供 requestFocus，则使用 Navigator.requestFocus 的值。如果通过 flutter config --enable-windowing 启用了窗口模式，则会忽略此参数，因为独立对话框窗口的焦点由窗口系统管理。

DisplayFeature 可以将屏幕划分为多个子屏幕。系统会选择距离 anchorPoint 最近的子屏幕来渲染内容。

如果未提供 anchorPoint，则会使用 Directionality：

  • for TextDirection.ltr, anchorPoint is Offset.zero, which will cause the content to appear in the top-left sub-screen.
  • for TextDirection.rtl, anchorPoint is Offset(double.maxFinite, 0), which will cause the content to appear in the top-right sub-screen.

如果未提供 anchorPoint，且树中没有 Directionality 祖先控件，则在调试模式下构建此控件时会触发断言。

如果应用包含多个 Navigator 对象，可能需要调用 Navigator.of(context, rootNavigator: true).pop(result) 来关闭对话框，而不是只调用 Navigator.pop(context, result)。

返回一个 Future，在对话框关闭时以传给 Navigator.pop 的值（如果有）完成。

对话框中的状态恢复

使用此方法不会为对话框启用状态恢复。若要启用状态恢复，请结合 DialogRoute，使用 Navigator.restorablePush 或 Navigator.restorablePushNamed。

有关状态恢复的更多信息，请参阅 RestorationManager。

此示例演示如何创建可恢复状态的 Material 对话框。具体做法是：设置 MaterialApp.restorationScopeId 启用状态恢复，并在点击按钮时使用 Navigator.restorablePush 推送 DialogRoute。

在 Android 上测试状态恢复：

  1. Turn on "Don't keep activities", which destroys the Android activity as soon as the user leaves it. This option should become available when Developer Options are turned on for the device.
  2. Run the code sample on an Android device.
  3. Create some in-memory state in the app on the phone, e.g. by navigating to a different screen.
  4. Background the Flutter app, then return to it. It will restart and restore its state.

在 iOS 上测试状态恢复：

  1. Open ios/Runner.xcworkspace/ in Xcode.
  2. (iOS 14+ only): Switch to build in profile or release mode, as launching an app from the home screen is not supported in debug mode.
  3. Press the Play button in Xcode to build and run the app.
  4. Create some in-memory state in the app on the phone, e.g. by navigating to a different screen.
  5. Background the app on the phone, e.g. by going back to the home screen.
  6. Press the Stop button in Xcode to terminate the app while running in the background.
  7. Open the app again on the phone (not via Xcode). It will restart and restore its state.

实现

Future<T?> showDialog<T>({
  required BuildContext context,
  required WidgetBuilder builder,
  bool barrierDismissible = true,
  Color? barrierColor,
  String? barrierLabel,
  bool useSafeArea = true,
  bool useRootNavigator = true,
  RouteSettings? routeSettings,
  Offset? anchorPoint,
  TraversalEdgeBehavior? traversalEdgeBehavior,
  bool fullscreenDialog = false,
  bool? requestFocus,
  AnimationStyle? animationStyle,
}) {
  assert(_debugIsActive(context));
  assert(debugCheckHasMaterialLocalizations(context));

  final CapturedThemes themes = InheritedTheme.capture(
    from: context,
    to: Navigator.of(context, rootNavigator: useRootNavigator).context,
  );
  final NavigatorState navigator = Navigator.of(context, rootNavigator: useRootNavigator);

  return showRawDialog(
    context: context,
    useRootNavigator: useRootNavigator,
    routeSettings: routeSettings,
    fullscreenDialog: fullscreenDialog,
    routeBuilder: (BuildContext routeContext, WidgetBuilder _) {
      return DialogRoute<T>(
        context: routeContext,
        builder: builder,
        barrierColor:
            barrierColor ??
            DialogTheme.of(context).barrierColor ??
            Theme.of(context).dialogTheme.barrierColor ??
            Colors.black54,
        barrierDismissible: barrierDismissible,
        barrierLabel: barrierLabel,
        useSafeArea: useSafeArea,
        settings: routeSettings,
        themes: themes,
        anchorPoint: anchorPoint,
        traversalEdgeBehavior: traversalEdgeBehavior ?? TraversalEdgeBehavior.closedLoop,
        requestFocus: requestFocus,
        animationStyle: animationStyle,
        fullscreenDialog: fullscreenDialog,
      );
    },
    builder: (BuildContext routeContext) {
      // Wrap the build dialog with the theme, text direction, and media
      // query data from the caller's context (not the navigator's context,
      // which would resolve to the root app theme and override captured themes).
      final TextDirection textDirection = Directionality.of(context);
      final ThemeData themeData = Theme.of(context);
      final MediaQueryData mediaQuery = MediaQuery.of(context);
      final Widget dialogContent = _DialogPopScope(
        onPop: Navigator.of(navigator.context).pop,
        child: Builder(
          builder: (BuildContext innerContext) {
            return _FullWindowDialogWrapper(child: builder(innerContext));
          },
        ),
      );

      return Directionality(
        textDirection: textDirection,
        child: Theme(
          data: themeData,
          child: MediaQuery(data: mediaQuery, child: dialogContent),
        ),
      );
    },
  );
}
