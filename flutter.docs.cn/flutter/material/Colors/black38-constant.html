black38 constant

Color const black38

不透明度为 38% 的黑色。

在浅色主题中（即 Theme 的 ThemeData.brightness 为 Brightness.light 时），此颜色用于禁用图标以及 DataTable 中的占位文字。

另请参阅：

  • black, black87, black54, black45, black26, black12，它们是此颜色不同不透明度的变体。

实现

static const Color black38 = Color(0x61000000);
