Typography 类

Material 应用中用于 TextTheme 的颜色和字形布局。

整体 Theme 提供的文本主题（ThemeData.textTheme）基于当前区域设置的 MaterialLocalizations.scriptCategory。它由颜色文本主题与字形布局文本主题合并而成：black 浅色主题使用 Brightness.light，white 深色主题使用 Brightness.dark；字形布局则根据区域设置使用 englishLike、dense 或 tall。

如需获取本地化文本主题，请使用 Theme.of(context).textTheme。

颜色文本主题包括 blackMountainView、whiteMountainView、blackCupertino 和 whiteCupertino。Mountain View 主题的 TextStyle 基于 Android 使用的 Roboto 字体。Cupertino 主题则采用 Apple 在 iOS 上使用的 San Francisco font 字体。

这里提供两组字形布局主题：2014 版和 2018 版。2014 版对应最初的 Material Design 规范，并且是默认设置。2018 版对应规范的第二次迭代，在字号、字重和字间距方面有所不同。

默认情况下，ThemeData.typography 为 Typography.material2014(platform: platform)，使用 englishLike2014、dense2014 和 tall2014。若要使用 2018 版文本主题的字形布局，请通过 Typography.material2018 构造函数指定相应值：

typography: Typography.material2018(platform: platform)

另请参阅：

  • material.io/design/typography/
  • m3.material.io/styles/typography
