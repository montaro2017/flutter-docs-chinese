RadioMenuButton<T> 类

将 Radio widget 与 MenuItemButton 组合在一起的菜单项。

若要单独设置单选按钮的样式，可添加一个 RadioTheme 祖先。

此示例展示了一个包含三个带快捷键单选按钮的菜单；选中按钮时会更改页面主体的背景颜色。
link

flutter create --sample=material.RadioMenuButton.1 mysample
