Slider 类

Material Design 滑块。

用于从一段数值范围中进行选择。

此示例展示离散和连续的 Slider。将 Slider.year2023 标志设为 false 时，Slider 会呈现更新后的 Material 3 设计外观。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.Slider.1 mysample

此示例展示如何使用 Slider 的 Slider.secondaryTrackValue 在滑块上显示次级轨道。

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.Slider.2 mysample

滑块可用于从连续或离散的数值集合中选择。默认情况下，范围从 min 到 max，使用连续值。若要使用离散值，请为 divisions 指定非 null 值，以设置离散区间数。例如，若 min 为 0.0、max 为 50.0 且 divisions 为 5，则可选离散值为 0.0、10.0、20.0、30.0、40.0 和 50.0。

滑块各部分的名称如下：

  • The "thumb", which is a shape that slides horizontally when the user drags it.
  • The "track", which is the line that the slider thumb slides along.
  • The "value indicator", which is a shape that pops up when the user is dragging the thumb to indicate the value being selected.
  • The "active" side of the slider is the side between the thumb and the minimum value.
  • The "inactive" side of the slider is the side between the thumb and the maximum value.

如果 onChanged 为 null，或 min..max 范围为空（即 min 与 max 相等），滑块就会被禁用。

滑块 widget 本身不维护状态。滑块状态改变时，widget 会调用 onChanged 回调。大多数使用滑块的 widget 都会监听 onChanged 回调，并使用新的 value 重新构建滑块，以更新其外观。若要获知数值何时开始或结束变化，可设置可选回调 onChangeStart 和/或 onChangeEnd。

默认情况下，滑块会尽可能宽，并在垂直方向居中。如果约束没有上限，它会尝试将轨道设为 144 像素宽（两侧留有边距），并在垂直方向紧贴内容。

其祖先组件中必须有一个 Material 组件。

其祖先中必须有一个 MediaQuery widget。通常，应用 widget 树顶部的 MaterialApp 或 WidgetsApp 会引入该 widget。

滑块使用其上方 widget 树中某个 SliderTheme widget 提供的 SliderThemeData，或使用其上方 Theme widget 的 ThemeData.sliderTheme，来确定显示方式（例如颜色、滑块拇指形状等）。也可以用 activeColor 和 inactiveColor 覆盖部分颜色；若要更精细地控制外观，请使用 SliderThemeData。

另请参阅：

  • SliderTheme 和 SliderThemeData for information about controlling the visual appearance of the slider.
  • Radio, for selecting among a set of explicit values.
  • Checkbox 和 Switch, for toggling a particular value on or off.
  • material.io/design/components/sliders.html
  • MediaQuery, from which the text scale factor is obtained.
