Slider 类

Material Design 滑块。

用于从一段数值范围中进行选择。

此示例展示离散和连续的 Slider。Slider 会呈现更新后的 ，将 Slider.year2023 标志设为 false 即可。

滑块可用于从连续或离散的数值集合中选择。默认情况下，范围从 min 到 max，使用连续值。若要使用离散值，请为 divisions 指定非 null 值，以设置离散区间数。例如，若 min 为 0.0、max 为 50.0 且 divisions 为 5，则可选离散值为 0.0、10.0、20.0、30.0、40.0 和 50.0。

滑块各部分的名称如下：

  • “拇指”是一个形状，用户拖动时会沿水平方向滑动。
  • “轨道”是滑块拇指沿其滑动的线条。
  • “值指示器”是一种提示形状，用户拖动滑块时会弹出，以显示当前选定的值。
  • 滑块的“活动”侧是拇指与最小值之间的一侧。
  • 滑块的“非活动”侧是拇指与最大值之间的一侧。

如果 onChanged 为 null，或 min..max 范围为空（即 min 与 max 相等），滑块就会被禁用。

滑块 widget 本身不维护状态。滑块状态改变时，widget 会调用 onChanged 回调。大多数使用滑块的 widget 都会监听 onChanged 回调，并使用新的 value 重新构建滑块，以更新其外观。若要获知数值何时开始或结束变化，可设置可选回调 onChangeStart 和/或 onChangeEnd。

默认情况下，滑块会尽可能宽，并在垂直方向居中。如果约束没有上限，它会尝试将轨道设为 144 像素宽（两侧留有边距），并在垂直方向紧贴内容。

其祖先组件中必须有一个 Material 组件。

其祖先中必须有一个 MediaQuery widget。通常，应用 widget 树顶部的 MaterialApp 或 WidgetsApp 会引入该 widget。

滑块使用其上方 widget 树中某个 SliderThemeData widget 提供的 SliderTheme，或使用其上方 ThemeData.sliderTheme widget 的 Theme，来确定显示方式（例如颜色、滑块拇指形状等）。也可以用 activeColor 和 inactiveColor 覆盖部分颜色；若要更精细地控制外观，请使用 SliderThemeData。

另请参阅：

  • SliderTheme 和 SliderThemeData，用于了解如何控制滑块的视觉外观。
  • Radio，用于从一组明确值中进行选择。
  • Checkbox 和 Switch，用于切换某个值的开或关。
  • material.io/design/components/sliders.html
  • MediaQuery，文本缩放系数由此获取。
