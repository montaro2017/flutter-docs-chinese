FloatingActionButtonLocation const miniStartDocked

起始端对齐的 FloatingActionButton 悬浮在 Scaffold.bottomNavigationBar 上方，使浮动操作按钮的中心与底部导航栏的顶部对齐，并针对小型浮动操作按钮进行了优化。

如果 Scaffold.bottomNavigationBar 的值是 BottomAppBar，底部应用栏的形状可以包含一个“凹口”，以容纳与其重叠的浮动操作按钮。

此位置适用于将 FloatingActionButton.mini 设为 true 的情况，使浮动操作按钮在视觉上与 Scaffold.body 中的 ListView 内某个 ListTile 的 ListTile.leading 槽位中的 CircleAvatar 对齐。

对于没有底部导航栏的应用，这个位置通常没有实际用处。

实现

static const FloatingActionButtonLocation miniStartDocked = _MiniStartDockedFabLocation();
