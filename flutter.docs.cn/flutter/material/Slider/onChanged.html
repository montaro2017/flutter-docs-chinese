onChanged 属性

ValueChanged<double>? onChanged
final

用户拖动滑块选择新值时持续调用。

滑块会将新值传给回调，但只有父组件使用新值重建滑块后，状态才会改变。

如果为 null，滑块会显示为禁用状态。

提供给 onChanged 的回调应使用 StatefulWidget 更新父级 State.setState 的状态，以便重建父组件。

link 
Slider(
  value: _duelCommandment.toDouble(),
  min: 1.0,
  max: 10.0,
  divisions: 10,
  label: '$_duelCommandment',
  onChanged: (double newValue) {
    setState(() {
      _duelCommandment = newValue.round();
    });
  },
)

另请参阅：

  • onChangeStart 是在用户开始更改值时调用的回调。
  • onChangeEnd 是在用户停止更改值时调用的回调。
