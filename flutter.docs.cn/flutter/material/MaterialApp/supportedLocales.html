supportedLocales 属性

Iterable<Locale> supportedLocales
final

此应用已提供本地化支持的区域设置列表。

默认仅支持美式英语。应用应配置此列表，使其与实际支持的区域设置一致。

此列表不能为 null。默认值仅为 [const Locale('en', 'US')]。

列表顺序很重要。默认的区域设置解析算法 basicLocaleListResolution 按以下优先级尝试匹配：

  1. 匹配 Locale.languageCode、Locale.scriptCode 和 Locale.countryCode。
  2. 仅匹配 Locale.languageCode 和 Locale.scriptCode。
  3. 仅匹配 Locale.languageCode 和 Locale.countryCode。
  4. 仅匹配 Locale.languageCode。
  5. 当所有首选区域设置均无法匹配时，仅匹配 Locale.countryCode。
  6. 返回 supportedLocales 的第一个元素作为回退值。

如果多个受支持的区域设置符合其中某项条件，仅返回第一个匹配项。

可通过提供 localeListResolutionCallback 覆盖默认区域设置解析算法。提供的 basicLocaleListResolution 针对速度进行了优化，没有实现考虑语言间距离的完整算法（例如 Unicode TR35 定义的算法）。

支持具有多种文字系统的语言时，建议显式指定 Locale.scriptCode。也可定义不含 Locale.countryCode 的区域设置，为特定文字系统提供通用回退值。

要完整支持具有多种文字系统的语言，应定义仅包含语言的通用区域设置（例如 zh）、仅包含语言与文字系统的区域设置（例如 zh_Hans 和 zh_Hant），以及所需的语言、文字系统和国家组合（例如 zh_Hans_CN）。并非严格要求支持所有这些区域设置，但完整定义它们可在更多情况下正确解析。可使用 Locale.fromSubtags 构造函数指定这些区域设置：

// Full Chinese support for CN, TW, and HK
supportedLocales: <Locale>[
  const Locale.fromSubtags(languageCode: 'zh'), // generic Chinese 'zh'
  const Locale.fromSubtags(languageCode: 'zh', scriptCode: 'Hans'), // generic simplified Chinese 'zh_Hans'
  const Locale.fromSubtags(languageCode: 'zh', scriptCode: 'Hant'), // generic traditional Chinese 'zh_Hant'
  const Locale.fromSubtags(languageCode: 'zh', scriptCode: 'Hans', countryCode: 'CN'), // 'zh_Hans_CN'
  const Locale.fromSubtags(languageCode: 'zh', scriptCode: 'Hant', countryCode: 'TW'), // 'zh_Hant_TW'
  const Locale.fromSubtags(languageCode: 'zh', scriptCode: 'Hant', countryCode: 'HK'), // 'zh_Hant_HK'
],

省略部分回退值可能使边界情况解析错误。例如，如果省略 zh_Hans 和 zh_Hans_CN，台湾的简体中文用户（zh_Hans_TW）可能被解析为繁体中文。

此值原样传递给此组件构建的 WidgetsApp。

另请参阅：

  • localizationsDelegates，本地化应用必须指定此项。
  • GlobalMaterialLocalizations，一个 localizationsDelegates 值，为多种语言提供 Material 本地化资源。
  • Flutter 国际化教程， flutter.dev/to/internationalization/。
