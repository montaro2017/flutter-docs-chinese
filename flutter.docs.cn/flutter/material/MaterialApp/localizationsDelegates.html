localizationsDelegates 属性

Iterable<LocalizationsDelegate>? localizationsDelegates
final

此应用的 Localizations 组件使用的委托。

这些委托共同定义此应用的 Localizations 组件所需的全部本地化资源。

如果国际化应用需要 GlobalMaterialLocalizations 中列出的某个区域设置的翻译，应指定此参数，并列出应用能处理的 supportedLocales。

// The GlobalMaterialLocalizations and GlobalWidgetsLocalizations
// classes require the following import:
// import 'package:flutter_localizations/flutter_localizations.dart';

const MaterialApp(
  localizationsDelegates: <LocalizationsDelegate<Object>>[
    // ... app-specific localization delegate(s) here
    GlobalMaterialLocalizations.delegate,
    GlobalWidgetsLocalizations.delegate,
  ],
  supportedLocales: <Locale>[
    Locale('en', 'US'), // English
    Locale('he', 'IL'), // Hebrew
    // ... other locales the app supports
  ],
  // ...
)

为新的区域设置添加本地化

以下信息适用于较少见的情况：应用为 GlobalMaterialLocalizations 尚未支持的语言添加翻译。

生成 WidgetsLocalizations 和 MaterialLocalizations 的委托会自动加入。应用可实现 LocalizationsDelegate<WidgetsLocalizations> 或 LocalizationsDelegate<MaterialLocalizations>，让 load 方法返回自定义的 WidgetsLocalizations 或 MaterialLocalizations，从而提供自己的本地化版本。

例如，要为 MaterialLocalizations 添加尚未支持的区域设置（如 const Locale('foo', 'BR')），首先创建提供翻译的 MaterialLocalizations 子类：

class FooLocalizations extends MaterialLocalizations {
  FooLocalizations();
  @override
  String get okButtonLabel => 'foo';
  // ...
  // lots of other getters and methods to override!
}

然后必须创建 LocalizationsDelegate 子类，以提供 MaterialLocalizations 子类的实例。此例中，它基本上只是构造 FooLocalizations 对象的方法。这里使用 SynchronousFuture，因为“加载”本地化对象时没有异步工作。

// continuing from previous example...
class FooLocalizationsDelegate extends LocalizationsDelegate<MaterialLocalizations> {
  const FooLocalizationsDelegate();
  @override
  bool isSupported(Locale locale) {
    return locale == const Locale('foo', 'BR');
  }
  @override
  Future<FooLocalizations> load(Locale locale) {
    assert(locale == const Locale('foo', 'BR'));
    return SynchronousFuture<FooLocalizations>(FooLocalizations());
  }
  @override
  bool shouldReload(FooLocalizationsDelegate old) => false;
}

构建 MaterialApp 时提供 FooLocalizationsDelegate，会覆盖自动加入的 MaterialLocalizations 委托，因为每种 LocalizationsDelegate.type 仅使用第一个委托，而自动加入的委托位于应用的 localizationsDelegates 列表末尾。

// continuing from previous example...
const MaterialApp(
  localizationsDelegates: <LocalizationsDelegate<Object>>[
    FooLocalizationsDelegate(),
  ],
  // ...
)

另请参阅：

  • supportedLocales，必须与 localizationsDelegates 一同指定。
  • GlobalMaterialLocalizations，为多种语言提供 Material 本地化的 localizationsDelegates 值。
  • Flutter 国际化教程：flutter.dev/to/internationalization/。
