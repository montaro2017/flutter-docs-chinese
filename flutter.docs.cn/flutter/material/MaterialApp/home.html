home 属性

Widget? home
final

应用默认路由的组件（Navigator.defaultRouteName，即 /）。

应用正常启动时首先显示此路由，除非指定了 initialRoute。如果 initialRoute 无法显示，也会显示此路由。

要在设置构造函数 home 参数的代码中直接调用 Theme.of、MediaQuery.of 等方法，可使用 Builder 组件获取 BuildContext。

如果指定了 home，则 routes 不能包含 / 条目，因为 home 已替代该条目。

仅在提供了路由时才构建 Navigator（通过 home、routes、onGenerateRoute 或 onUnknownRoute 提供）；否则 builder 不能为 null。

使用 home 与使用 builder 的区别在于，home 子树插入在应用的 Navigator 下方（因此也位于 Overlay 下方，后者由 Navigator 使用）。因此，使用 home 时，对话框会自动正常工作，应用会使用 routes 表，Navigator.push 和 Navigator.pop 等 API 也会按预期工作。而 builder 返回的组件插入在应用的 Navigator（如果存在）上方。
