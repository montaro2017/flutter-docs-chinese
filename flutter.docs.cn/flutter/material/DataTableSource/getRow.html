getRow abstract 方法

DataRow? getRow(
  1. int index
)

调用此方法以获取特定行的数据。

行应设置稳定的键，以便数据源排序时仍能保留状态（例如响应 DataColumn.onSort 时）。无论排序顺序如何，同一个 DataRow 都应使用一致的键（即键表示数据的身份，而不是行的位置）。

DataRow.byIndex 构造函数可方便地创建此方法所需的 DataRow 对象，无需为每一行单独设置键。传给该构造函数的索引是底层数据的索引，与 getRow 的 index 参数不同；后者表示排序后的位置。

如果给定索引没有对应的行，或者该行的数据尚不可用，则返回 null。此时该行会留空，并在表格上显示加载指示器。数据可用后，或者确认该行索引已超出表格范围后，调用 notifyListeners。（参见 rowCount。）

底层数据发生变化时，调用 notifyListeners。
