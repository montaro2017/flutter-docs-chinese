重写

根据传入的状态绘制值指示器形状。

context 参数表示 RangeSlider 的渲染框。

center 参数指定绘制此形状中心的位置。此偏移量相对于 context 画布的原点。

activationAnimation 参数表示用户开始与 RangeSlider 交互时触发的动画；用户停止与滑块交互时，动画会反向播放。

enableAnimation 参数表示 RangeSlider 启用时触发的动画；滑块禁用时，动画会反向播放。当 RangeSlider.onChanged 不为 null 时，RangeSlider 处于启用状态。滑块启用状态变化时，可使用此参数绘制此形状的中间帧。

当 RangeSlider.divisions 非 null 时，isDiscrete 参数为 true。为 true 时，滑块会在轨道上方绘制刻度标记。

isOnTop 参数表示两个值指示器中位于最上层的一个；它始终是最近选中拇指对应的指示器。默认情况下，此参数用于给上层指示器绘制描边，使两个指示器更容易区分。

textScaleFactor 参数可用于确定组件应放大还是缩小绘制：当 textScaleFactor 大于 1 时放大，在 0 到 1 之间时缩小。通常根据 MediaQueryData.textScaler 计算此值。

sizeWithOverflow 参数可用于确定常规滑块范围以外组件绘制区域的边界。它表示一个框的尺寸；该框的中心与滑块边界对齐，值指示器必须绘制在框内。此框通常比滑块更大。

parentBox 参数是 RangeSlider 的 RenderBox。其尺寸等属性可用于辅助绘制此形状。

sliderTheme 参数是分配给此形状所属 RangeSlider 的主题。

textDirection 参数可用于确定如何定位额外文本或图形（即 labelPainter 所绘制文本之外的内容）。labelPainter 参数已设置好 textDirection。

value 参数是滑块当前的参数化值，范围为 0.0 到 1.0。

thumb 参数指定此方法应绘制两个拇指中的哪一个（起始端或末尾端）。

实现

@override
void paint(
  PaintingContext context,
  Offset center, {
  required Animation<double> activationAnimation,
  required Animation<double> enableAnimation,
  bool? isDiscrete,
  bool isOnTop = false,
  required TextPainter labelPainter,
  required RenderBox parentBox,
  required SliderThemeData sliderTheme,
  TextDirection? textDirection,
  Thumb? thumb,
  double? value,
  double? textScaleFactor,
  Size? sizeWithOverflow,
}) {
  assert(!sizeWithOverflow!.isEmpty);
  final enableColor = ColorTween(
    begin: sliderTheme.disabledThumbColor,
    end: sliderTheme.valueIndicatorColor,
  );
  // Add a stroke of 1dp around the top paddle.
  _pathPainter.paint(
    context.canvas,
    center,
    Paint()..color = enableColor.evaluate(enableAnimation)!,
    activationAnimation.value,
    labelPainter,
    textScaleFactor!,
    sizeWithOverflow!,
    isOnTop ? sliderTheme.overlappingShapeStrokeColor : sliderTheme.valueIndicatorStrokeColor,
  );
}
