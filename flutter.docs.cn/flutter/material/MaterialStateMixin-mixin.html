MaterialStateMixin<T extends StatefulWidget> mixin

供需要了解子 Widget 的 WidgetState 值变化的 State 类使用的 mixin。

仅将此 mixin 应用于 State 类不会产生任何作用；但在编写包含子 InkWell、GestureDetector、MouseRegion 或 Focus Widget 的 build 方法时，它会很有帮助。这类 State 类无需为每种用户交互手动创建处理器，而是可以提供一个 ValueChanged<bool> 函数，由 MaterialStateMixin 管理活动的 WidgetState 集合，并在需要时调用 setState。

此示例展示如何编写一个使用 StatefulWidget 的组件，其中通过 MaterialStateMixin mixin 监听 WidgetState 的值。
link 
class MyWidget extends StatefulWidget {
  const MyWidget({super.key, required this.color, required this.child});

  final WidgetStateColor color;
  final Widget child;

  @override
  State<MyWidget> createState() => MyWidgetState();
}

class MyWidgetState extends State<MyWidget> with MaterialStateMixin<MyWidget> {
  @override
  Widget build(BuildContext context) {
    return InkWell(
      onFocusChange: updateMaterialState(WidgetState.focused),
      child: ColoredBox(
        color: widget.color.resolve(materialStates),
        child: widget.child,
      ),
    );
  }
}
