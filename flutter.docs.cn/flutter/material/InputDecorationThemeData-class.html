InputDecorationThemeData 类

定义 InputDecorator 的默认外观。

后代组件通过 InputDecorationThemeData 获取当前主题的 InputDecorationTheme.of。当组件使用 InputDecorationTheme.of 时，如果主题之后发生变化，组件会自动重建。

InputDecoration.applyDefaults 方法用于将输入装饰主题与 InputDecoration 对象合并。

另请参阅：

  • ThemeData.inputDecorationTheme, which specifies an input decoration theme as part of the overall Material theme.
