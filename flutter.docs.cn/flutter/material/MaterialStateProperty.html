MaterialStateProperty<T> typedef

  1. @Deprecated('Use WidgetStateProperty instead. ' 'Moved to the Widgets layer to make code available outside of Material. ' 'This feature was deprecated after v3.19.0-0.3.pre.')
MaterialStateProperty<T> = WidgetStateProperty<T>

用于将值解析为 T 类型的接口。它通过 resolve 方法，根据 Widget 的交互“状态”确定解析结果；该状态由一组 MaterialState 表示。

Material 状态属性表示依赖 Widget Material“状态”的值。状态以一组 MaterialState 值编码，例如 WidgetState.focused、WidgetState.hovered 和 WidgetState.pressed。例如，InkWell.overlayColor 定义墨水区域在按下（即“水波纹颜色”）、获得焦点或悬停时的填充颜色。InkWell 使用该叠加颜色的 resolve 方法，根据墨水区域当前状态计算颜色。

ButtonStyle 用于配置 TextButton、ElevatedButton 和 OutlinedButton 等按钮的外观，其中包含许多 Material 状态属性。按钮 Widget 会跟踪当前 Material 状态，并在需要属性值时使用 resolve 方法解析按钮样式中的状态属性。

此示例展示如何使用 MaterialStateProperty 覆盖 TextButton 的默认文本和图标颜色（即“前景色”）。按钮在按下、悬停或获得焦点时，文本颜色为 Colors.blue；否则为 Colors.red。
