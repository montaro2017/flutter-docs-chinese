MaterialStateOutlineInputBorder
description

MaterialStateOutlineInputBorder 类 抽象

定义一种同时也是 OutlineInputBorder 和 MaterialStateProperty 的边框。

此类使具有 OutlineInputBorder 类型属性的组件也能接受 MaterialStateProperty<OutlineInputBorder> 值。状态输入边框属性表示依赖组件“交互状态”的输入边框。该状态由 Set 中的 MaterialState 表示，例如 MaterialState.pressed、MaterialState.focused 和 MaterialState.hovered。

MaterialStateOutlineInputBorder 只能用于文档明确说明支持它的组件，例如 InputDecoration.border。

使用 MaterialStateOutlineInputBorder 有以下方式：

  1. 创建 MaterialStateOutlineInputBorder 的子类，并实现抽象的 resolve 方法。
  2. 使用 MaterialStateOutlineInputBorder.resolveWith，并传入一个回调函数，用于解析给定状态下的颜色。

如果在不支持解析 MaterialStateProperty<OutlineInputBorder> 的属性或参数中使用 MaterialStateOutlineInputBorder，则所有状态都会使用其默认颜色值。

若要定义 const MaterialStateOutlineInputBorder，需要继承 MaterialStateOutlineInputBorder 并重写其 resolve 方法。还需要向父类构造函数提供 defaultValue，以便在编译时确定其默认颜色。
