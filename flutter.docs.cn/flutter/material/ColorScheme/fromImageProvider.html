根据给定的 imageProvider 派生并生成 ColorScheme。

Material Color Utilities 会从所提供的 ImageProvider 中提取主导颜色，再以此生成一组协调且满足无障碍对比度要求的 ColorScheme。

如果任何可选颜色参数为非 null，该颜色便会替代生成方案中对应字段的颜色。这样应用可以按需覆盖特定 ColorScheme 颜色。

由于算法的特性，imageProvider 中最主导的颜色最终不一定会成为 ColorScheme 中的颜色。

提取颜色时，提供的图像会缩小到最大 112×112 像素。

此示例展示如何使用 ColorScheme.fromImageProvider 创建基于内容生成的动态配色方案。

  • pub.dev/packages/material_color_utilities, the package used to algorithmically determine the dominant color and to generate the ColorScheme.

  // Extract dominant colors from image.
  final QuantizerResult quantizerResult = await _extractColorsFromImageProvider(provider);
  final Map<int, int> colorToCount = quantizerResult.colorToCount.map(

  );

  // Score colors for color scheme suitability.
  final List<int> scoredResults = Score.score(colorToCount, desired: 1);

    brightness,
    baseColor,
    dynamicSchemeVariant,
    contrastLevel,
  );
