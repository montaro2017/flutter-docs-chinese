RefreshIndicator 类

支持 Material“下拉刷新”交互模式的 widget。

当子项中的 Scrollable 后代发生过度滚动时，会淡入显示一个圆形进度指示器。滚动结束后，如果指示器被拖动到完全不透明的程度，就会调用 onRefresh 回调。此回调应更新可滚动内容，然后完成其返回的 Future。回调的 Future 完成后，刷新指示器会消失。

通过 RefreshIndicator.triggerMode 配置触发模式。

问题排查

刷新指示器没有显示

如果 RefreshIndicator 的可滚动后代可以过度滚动（也就是可滚动内容大于视口），刷新指示器就会显示。若要确保即使可滚动内容没有超出视口，RefreshIndicator 仍始终显示，请将可滚动组件的 Scrollable.physics 属性设为 AlwaysScrollableScrollPhysics：

ListView(
  physics: const AlwaysScrollableScrollPhysics(),
  // ...
)

RefreshIndicator 只能与垂直滚动视图搭配使用。

另请参阅：

  • material.io/design/platform-guidance/android-swipe-to-refresh.html
  • RefreshIndicatorState, can be used to programmatically show the refresh indicator.
  • RefreshProgressIndicator, widget used by RefreshIndicator to show the inner circular progress spinner during refreshes.
  • CupertinoSliverRefreshControl, an iOS equivalent of the pull-to-refresh pattern. Must be used as a sliver inside a CustomScrollView instead of wrapping around a ScrollView because it's a part of the scrollable instead of being overlaid on top of it.
