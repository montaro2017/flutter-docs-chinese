TextField 类

Material Design 文本输入框。

文本输入框允许用户通过实体键盘或屏幕键盘输入文字。

用户每次更改输入框中的文字时，都会调用 onChanged 回调。用户表示已完成输入时（例如按下屏幕键盘上的按钮），会调用 onSubmitted 回调。

使用 controller 控制输入框中显示的文字。例如，若要设置初始值，可使用已包含文字的 controller。controller 还可控制选区和组合区域，并监听文字、选区及组合区域的变化。

默认情况下，文本输入框带有 decoration，会在输入框下方绘制分隔线。可使用 decoration 属性控制装饰，例如添加标签或图标。将 decoration 设为 null 会完全移除装饰，包括为标签预留空间而额外添加的内边距。

如果 decoration 不为 null（默认情况），文本输入框的祖先组件中必须有一个 Material 组件。

若要将 TextField 与其他 FormField 组件一起放入 Form，可考虑使用 TextFormField。

组件获得焦点时，会通过底层 EditableText 的 AutomaticKeepAliveClientMixin.wantKeepAlive 暂缓销毁，以避免丢失选区。移除焦点后即可销毁。

不再需要 TextEditingController 时，请调用 TextEditingController.dispose，以释放该对象使用的资源。

如果此输入框位于会延迟创建子项的滚动容器中，例如 ListView 或 CustomScrollView，则应指定 controller。其生命周期应由滚动容器的有状态祖先组件管理。

生命周期

用户完成编辑（例如按下键盘上的“完成”按钮）时，会依次执行两个操作：

第一步：结束编辑。此步骤的默认行为会调用 onChanged，但可以覆盖。详情请参阅 onEditingComplete。

第二步：将用户输入的值传给 onSubmitted 并调用它。

用户完成当前输入组件的编辑后，可通过 onSubmitted 手动将焦点移到另一个输入组件。

组件获得焦点时，会通过 AutomaticKeepAliveClientMixin.wantKeepAlive 暂缓销毁，以避免丢失选区。移除焦点后即可销毁。

大多数应用使用 onSubmitted 回调即可响应用户输入。

用户完成编辑时也会运行 onEditingComplete 回调。它与 onSubmitted 不同：前者有默认行为，会更新文本控制器并释放键盘焦点。需要其他行为的应用可以覆盖默认的 onEditingComplete 回调。

也可以随时通过 TextEditingController 的 TextEditingController.text 读取输入框当前的字符串。

处理表情符号和其他复杂字符

处理可能包含复杂字符的用户输入时，务必使用 characters。这样可以确保扩展字素簇和代理项对按用户所见被视为单个字符。

例如，获取用户输入长度时，请使用 string.characters.length。不要使用 string.length，也不要使用 string.runes.length。复杂字符“👨‍👩‍👦”在用户看来是一个字符，因此 string.characters.length 会直观地返回 1；而 string.length 会返回 8，string.runes.length 会返回 5！

可在上方的 DartPad 示例中输入表情符号 👨‍👩‍👦 并提交。示例代码使用 value.characters.length 计算长度，因此会正确地将该表情符号计为一个字符。

聚焦时保持插入光标可见

获得焦点时，此小组件会尝试在以下情况下保持文本区域及其插入光标可见（即使 showCursor 为 false）：

  • When the user focuses this text field and it is not readOnly.
  • When the user changes the selection of the text field, or changes the text when the text field is not readOnly.
  • When the virtual keyboard pops up.

排查常见无障碍问题

自定义用户输入的无障碍播报

若要自定义文字变化触发的用户输入无障碍播报，请使用 SemanticsService.sendAnnouncement 发出所需的播报。

在 iOS 上，当 TextInputFormatter 为货币输入框插入千位分隔符时，屏幕键盘可能会错误播报最近输入的内容。以下示例通过始终将输入框内容播报为美元金额，来抑制默认无障碍播报（\$ 会插入美元符号，$newText 会插入 newText 变量的值）：

onChanged: (String newText) {
  if (newText.isNotEmpty) {
    SemanticsService.sendAnnouncement(
      View.of(context),
      '\$$newText',
       Directionality.of(context),
    );
  }
}
