ElevatedButtonThemeData 类

一种 ButtonStyle，用于通过 ElevatedButton 或整体 ElevatedButtonTheme 的 Theme 覆盖 ThemeData.elevatedButtonTheme 的默认外观。

style 的属性会覆盖 ElevatedButton 的默认样式，即 ButtonStyle 返回的 ElevatedButton.defaultStyleOf。只有样式中非 null 的属性值或解析后非 null 的 WidgetStateProperty 值会生效。

另请参阅：

  • ElevatedButtonTheme, the theme which is configured with this class.
  • ElevatedButton.defaultStyleOf, which returns the default ButtonStyle for text buttons.
  • ElevatedButton.styleFrom，将简单值转换为与 ElevatedButton 默认样式一致的 ButtonStyle。
  • WidgetStateProperty.resolve, "resolve" a material state property to a simple value based on a set of WidgetState。
  • ThemeData.elevatedButtonTheme，可用于为整体 Theme 之下的 ElevatedButton 覆盖默认的 ButtonStyle。
