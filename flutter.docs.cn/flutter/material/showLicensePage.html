显示 LicensePage，用于列出应用所用软件的许可证。

应用参数与 LicensePage 的属性相对应。

context 参数用于查找此页面对应的 Navigator。

useRootNavigator 参数用于确定将页面推送到距离给定 context 最远还是最近的 Navigator。默认值为 false。

如果应用有 Drawer，可以考虑改用 AboutListTile，而不是直接调用此函数。

由 showAboutDialog 显示的 AboutDialog 包含一个按钮，点击后会调用 showLicensePage。

LicensePage 中显示的许可证由 LicenseRegistry API 提供；你可以使用该 API 将更多许可证添加到列表中。

实现

void showLicensePage({
  required BuildContext context,
  String? applicationName,
  String? applicationVersion,
  Widget? applicationIcon,
  String? applicationLegalese,
  bool useRootNavigator = false,
}) {
  final CapturedThemes themes = InheritedTheme.capture(
    from: context,
    to: Navigator.of(context, rootNavigator: useRootNavigator).context,
  );
  Navigator.of(context, rootNavigator: useRootNavigator).push(
    MaterialPageRoute<void>(
      builder: (BuildContext context) => themes.wrap(
        LicensePage(
          applicationName: applicationName,
          applicationVersion: applicationVersion,
          applicationIcon: applicationIcon,
          applicationLegalese: applicationLegalese,
        ),
      ),
    ),
  );
}
