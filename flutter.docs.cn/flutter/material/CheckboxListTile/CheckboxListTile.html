创建一个由列表项和复选框组合而成的组件。

复选框列表项本身不维护状态。复选框状态变化时，widget 会调用 onChanged 回调。大多数使用复选框的 widget 都会监听 onChanged 回调，并使用新的 value 重建复选框列表项，以更新复选框的视觉外观。

以下参数为必填项：

  • value，用于确定复选框是否选中。只有当 tristate 为 true 时，value 才可以为 null。
  • onChanged，会在复选框的值需要更改时调用。将其设为 null 可禁用复选框。
