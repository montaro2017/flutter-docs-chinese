TextButton 类

Material Design“文本按钮”。

文本按钮适用于工具栏、对话框或与其他内容内联的场景；应通过内边距与周围内容拉开距离，使按钮清晰可辨。文本按钮没有可见边框，因此必须依靠相对于其他内容的位置来明确其上下文。在对话框和卡片中，应将它们成组放置在底部的某个角落。避免在文本按钮容易与其他内容融为一体的位置使用，例如列表中间。

文本按钮是在（零高程）Material 小组件上显示标签 child 的按钮。标签的 Text 和 Icon 小组件使用 style 中的 ButtonStyle.foregroundColor 显示。触摸按钮时，会填充 style 中的 ButtonStyle.backgroundColor。

文本按钮的默认样式由 defaultStyleOf 定义。可通过此按钮的 style 参数覆盖其样式；可通过 TextButtonTheme 覆盖子树中所有文本按钮的样式；还可通过应用 Theme 的 ThemeData.textButtonTheme 属性覆盖应用中的所有文本按钮样式。

静态方法 styleFrom 可根据简单值便捷地创建文本按钮的 ButtonStyle。

如果 onPressed 和 onLongPress 回调均为 null，则此按钮会被禁用，不会响应触摸。

  • ElevatedButton，按下时 Material 表面会上移的填充式按钮。
  • FilledButton，是一种按下时不会升起的填充按钮。
  • FilledButton.tonal，是使用次要填充色的填充按钮变体。
  • OutlinedButton，是一种带描边且没有填充色的按钮。
