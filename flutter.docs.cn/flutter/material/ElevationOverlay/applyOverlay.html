在深色主题中，将叠加颜色应用到表面颜色上，以表示其高度等级。

使用 Material Design 3 时，不再使用这种颜色叠加，而改用“表面色调”叠加。详情请参阅 applySurfaceTint 和 ThemeData.useMaterial3。

在深色主题中，Material 投影可能不易看清，因此除了阴影之外，还应使用“叠加层”来表示表面的高度。组件高度越高，叠加层的不透明度也越高。此函数会按需计算并将叠加层应用到指定颜色。

如果当前主题为深色（ThemeData.brightness 为 Brightness.dark），且 ThemeData.applyElevationOverlayColor 为 true，同时给定的 color 是 ColorScheme.surface，则此函数会返回叠加了半透明 ColorScheme.onSurface 的 color。叠加层的不透明度根据 elevation 计算。

否则，直接返回未经修改的 color。

另请参阅：

  • ThemeData.applyElevationOverlayColor，用于控制是否应用叠加色来表示高度。
  • overlayColor which computes the needed overlay color.
  • Material which uses this to apply an elevation overlay to its surface.
  • material.io/design/color/dark-theme.html, which specifies how the overlay should be applied.

实现

static Color applyOverlay(BuildContext context, Color color, double elevation) {
  final ThemeData theme = Theme.of(context);
  if (elevation > 0.0 &&
      theme.applyElevationOverlayColor &&
      theme.brightness == Brightness.dark &&
      color.withOpacity(1.0) == theme.colorScheme.surface.withOpacity(1.0)) {
    return colorWithOverlay(color, theme.colorScheme.onSurface, elevation);
  }
  return color;
}
