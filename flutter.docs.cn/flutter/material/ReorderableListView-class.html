ReorderableListView 类

一个列表，用户可以通过拖动来交互式地重新排列其中的条目。

此示例展示了如何通过拖动重新排列列表项。当子组件被拖到新位置时，会调用 onReorderItem 参数指定的回调。

link

若要在本地项目中使用此代码示例，请运行：
flutter create --sample=material.ReorderableListView.1 mysample

默认情况下，在 TargetPlatformVariant.desktop 平台上，每个条目顶部都会添加拖动手柄，供用户抓住并移动条目。在 TargetPlatformVariant.mobile 平台上不会添加拖动手柄，但用户长按条目任意位置即可开始移动。可以通过 ReorderableListView.buildDefaultDragHandles 控制是否显示拖动手柄。

所有列表项都必须具有 key。

此示例展示了如何使用 ReorderableListView.proxyDecorator 回调，自定义列表项被拖动时的外观。

拖动过程中，ReorderableListView.proxyDecorator 回调返回的组件会作为列表项的“代理”（替代项）。代理组件以原列表项为子组件。此示例中的 ReorderableListView.proxyDecorator 回调与默认实现类似，但会更改代理项的背景颜色。
link

若要在本地项目中使用此代码示例，请运行：
flutter create --sample=material.ReorderableListView.2 mysample

此示例展示了如何使用 ReorderableListView.proxyDecorator 回调，自定义 Card 被拖动时的外观。

默认的 proxyDecorator 会将被拖动项包装在 Material 组件中，并为其高度添加动画。此示例展示如何使用 ReorderableListView.proxyDecorator 回调更新被拖动卡片的高度，而不插入新的 Material 组件。
