CloseButtonIcon 类

适用于当前 TargetPlatform 的“关闭”图标。

当前平台通过查询环境中的 Theme 确定。

另请参阅：

  • CloseButton, an IconButton with a CloseButtonIcon that calls Navigator.maybePop to return to the previous route.
  • IconButton，是用于创建图标按钮的通用组件。
  • Icon，Material Design 图标。
  • ThemeData.platform，指定当前平台。
