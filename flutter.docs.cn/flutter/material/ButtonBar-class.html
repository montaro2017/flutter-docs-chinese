ButtonBar 类

一行末端对齐的按钮；水平空间不足时会改为纵向排列。

更新为 OverflowBar

ButtonBar 已被效率更高的 widget OverflowBar 取代。

// Before
// ignore: deprecated_member_use
ButtonBar(
  alignment: MainAxisAlignment.spaceEvenly,
  children: <Widget>[
    TextButton( child: const Text('Button 1'), onPressed: () {}),
    TextButton( child: const Text('Button 2'), onPressed: () {}),
    TextButton( child: const Text('Button 3'), onPressed: () {}),
  ],
);

// After
OverflowBar(
  alignment: MainAxisAlignment.spaceEvenly,
  children: <Widget>[
    TextButton( child: const Text('Button 1'), onPressed: () {}),
    TextButton( child: const Text('Button 2'), onPressed: () {}),
    TextButton( child: const Text('Button 3'), onPressed: () {}),
  ],
);

详情请参阅 OverflowBar 文档。

使用 ButtonBar

按钮会根据 buttonPadding 水平排列。子项放在一个 Row 中，并使用 MainAxisAlignment.end。当 Directionality 为 TextDirection.ltr 时，按钮栏子项靠右对齐，最后一个子项位于最右侧。当 Directionality 为 TextDirection.rtl 时，子项靠左对齐，最后一个子项位于最左侧。

如果按钮栏的宽度超过 widget 的最大宽度约束，按钮就会改为纵向排列。此时 MainAxisAlignment 会被视为交叉轴（水平）对齐方式。例如，按钮溢出且将 ButtonBar.alignment 设为 MainAxisAlignment.start 时，按钮会与按钮栏的水平起始边对齐。

ButtonBar 可通过 ButtonBarTheme 配置。ButtonBar 的属性为 null 时，会使用外围 ButtonBarTheme 的对应属性；如果该属性也为 null，则使用下方字段文档中说明的默认值。

children 会被包裹在一个 ButtonTheme 中。该主题复制外围的 ButtonTheme，并按上文所述用 ButtonBar 的属性覆盖按钮相关属性，包括 buttonTextTheme、buttonMinWidth、buttonHeight、buttonPadding 和 buttonAlignedDropdown。

Dialog 使用此 widget 在对话框底部排列操作按钮。

另请参阅：

  • TextButton, a simple flat button without a shadow.
  • ElevatedButton，按下时 Material 表面会上移的填充式按钮。
  • OutlinedButton, a TextButton with a border outline.
  • Card, at the bottom of which it is common to place a ButtonBar.
  • Dialog, which uses a ButtonBar for its actions.
  • ButtonBarTheme, which configures the ButtonBar.
