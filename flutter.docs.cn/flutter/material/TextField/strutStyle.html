strutStyle 属性

StrutStyle? strutStyle
final

用于垂直布局的支撑线样式。

StrutStyle 用于建立可预测的垂直布局。由于字体可能因用户输入而异，也可能受到字体回退影响，默认启用 StrutStyle.forceStrutHeight，以将所有行锁定为由 style 提供的基础 TextStyle 高度，确保输入文本适合分配的空间。

如果为 null，支撑线会继承 style 中的值，并将 StrutStyle.forceStrutHeight 设为 true。如果未传入 style，则使用主题的 TextStyle 生成 strutStyle。

若要禁用基于支撑线的垂直对齐，并允许根据输入字形动态调整垂直布局，请使用 StrutStyle.disabled。

Flutter 的支撑线基于排版中的支撑线和 CSS 的 line-height。
