maxLines 属性

int? maxLines
final

同时显示的最大行数，必要时会换行。

此值会影响输入框自身的高度，但不会限制用户可输入的总行数。

如果设为 1（默认值），文字不会换行，而是水平滚动。

如果为 null，则不限制行数。文字容器会预留一行的垂直空间，并随着输入内容增加而自动增高，直到达到其约束的高度。

如果此值不为 null，则必须大于 0。输入框会固定显示指定行数，并占用足够的水平空间。结合设置 minLines 后，输入框可在指定范围内增高或缩小。

结合 minLines 和 maxLines 可实现以下所有行为。这些示例同样适用于 TextField、TextFormField、CupertinoTextField 和 EditableText。

输入框始终占用一行，必要时可水平滚动。

const TextField()

输入框高度从一行开始，随着输入文字增加而增高。如果父组件限制了高度，达到限制后就会改为垂直滚动。

const TextField(maxLines: null)

输入框高度足以显示指定行数。输入更多行时，内容会垂直滚动。

const TextField(maxLines: 2)

输入框高度随内容增长，但会限制在最小值和最大值之间。最大值可设为 maxLines: null，表示不限制。

const TextField(minLines: 2, maxLines: 4)

另请参阅：

  • minLines, which sets the minimum number of lines visible.
  • expands, which determines whether the field should fill the height of its parent.
