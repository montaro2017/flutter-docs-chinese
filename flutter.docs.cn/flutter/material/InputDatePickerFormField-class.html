InputDatePickerFormField 类

一种配置为接受并验证用户输入日期的 TextFormField。

字段保存或提交时，文本会根据当前区域设置的紧凑日期格式解析为 DateTime。如果输入文本无法解析为日期，则会在字段下方显示 errorFormatText 消息。

firstDate、lastDate 和 selectableDayPredicate 用于限制有效日期。如果输入日期不在日期范围内，或未通过给定的谓词，则会在字段下方显示 errorInvalidText 消息。

另请参阅：

  • showDatePicker, which shows a dialog that contains a Material Design date picker which includes support for text entry of dates.
  • MaterialLocalizations.parseCompactDate, which is used to parse the text input into a DateTime.
