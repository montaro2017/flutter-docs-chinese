Drawer 类

一种 Material Design 面板，会从 Scaffold 边缘横向滑入，用于显示应用中的导航链接。

此组件的 Material 3 版本是 NavigationDrawer。对于配置为使用 Material 3 的应用，建议优先使用它（参阅 ThemeData.useMaterial3）。

抽屉通常通过 Scaffold.drawer 属性使用。抽屉的子组件通常是一个 ListView，其第一个子项为 DrawerHeader，用于显示当前用户的状态信息。其余子项通常由 ListTile 构成，末尾常放置 AboutListTile。

当 Scaffold 中存在 Drawer 时，AppBar 会自动显示合适的 IconButton 以打开 Drawer。Scaffold 也会自动处理从屏幕边缘滑动以显示抽屉的手势。

迁移到 NavigationDrawer

此组件的 Material 3 版本是 NavigationDrawer，对于配置为使用 Material 3 的应用，建议优先使用（参阅 ThemeData.useMaterial3）。NavigationDrawer 的外观略有不同，详情请参阅 Material 3 规范：m3.material.io/components/navigation-drawer/overview。Drawer 只能包含一个子组件，而 NavigationDrawer 可以包含一组组件，通常包括 NavigationDrawerDestination，也可以包含标题和分隔线等自定义组件。

此示例展示如何创建一个 Scaffold，其中包含一个 AppBar 和一个 Drawer。用户点击“菜单”图标所在的 AppBar，以打开 Drawer。该Drawer 显示四项内容：一个页眉和三个菜单项。 该Drawer 使用 ListView 显示这四项内容；必要时，用户可以滚动浏览。

flutter create --sample=material.Drawer.2 mysample

打开的抽屉可以通过滑动关闭手势、按 Escape 键、轻触遮罩层或调用 Navigator.pop 等路由弹出方法来关闭。例如，轻触抽屉项目时可以关闭抽屉：

ListTile(
  leading: const Icon(Icons.change_history),
  title: const Text('Change history'),
  onTap: () {
    // change app state...
    Navigator.pop(context); // close the drawer
  },
);

另请参阅：

  • Scaffold.drawer, where one specifies a Drawer so that it can be shown.
  • Scaffold.of, to obtain the current ScaffoldState, which manages the display and animation of the drawer.
  • ScaffoldState.openDrawer, which displays its Drawer, if any.
  • material.io/design/components/navigation-drawer.html
