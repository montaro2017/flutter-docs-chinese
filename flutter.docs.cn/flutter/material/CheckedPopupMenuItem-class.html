CheckedPopupMenuItem<T> 类

Material Design 弹出菜单中带勾选标记的菜单项。

若要显示弹出菜单，请使用 showMenu 函数。若要创建用于显示弹出菜单的按钮，可以考虑使用 PopupMenuButton。

CheckedPopupMenuItem 的高度为 kMinInteractiveDimension 像素，与 PopupMenuItem 默认的最小高度相同。其水平布局使用 ListTile；勾选标记是 Icons.done 图标，显示在 ListTile.leading 位置。

假设某个弹出菜单有一个 Commands 枚举，用于列出可能的命令，其中包括 Commands.heroAndScholar 和 Commands.hurricaneCame；并且还有一个布尔成员字段 _heroAndScholar。下面的示例展示一个菜单：其中一个菜单项带有勾选标记，可切换该布尔值；另一个菜单项不带勾选标记，用于选择第二个选项。（示例还在两个菜单项之间放置了分隔线。）
link 
PopupMenuButton<Commands>(
  onSelected: (Commands result) {
    switch (result) {
      case Commands.heroAndScholar:
        setState(() { _heroAndScholar = !_heroAndScholar; });
      case Commands.hurricaneCame:
        // ...handle hurricane option
        break;
      // ...other items handled here
    }
  },
  itemBuilder: (BuildContext context) => <PopupMenuEntry<Commands>>[
    CheckedPopupMenuItem<Commands>(
      checked: _heroAndScholar,
      value: Commands.heroAndScholar,
      child: const Text('Hero and scholar'),
    ),
    const PopupMenuDivider(),
    const PopupMenuItem<Commands>(
      value: Commands.hurricaneCame,
      child: ListTile(leading: Icon(null), title: Text('Bring hurricane')),
    ),
    // ...other items listed here
  ],
)

请特别注意，第二个菜单项在 ListTile.leading 位置使用了一个空白 Icon 的 ListTile，从而与带勾选标记的菜单项保持相同的对齐方式。

另请参阅：

  • PopupMenuItem, a popup menu entry for picking a command (as opposed to toggling a value).
  • PopupMenuDivider, a popup menu entry that is just a horizontal line.
  • showMenu，可在指定位置动态显示弹出菜单。
  • PopupMenuButton, an IconButton that automatically shows a menu when it is tapped.
