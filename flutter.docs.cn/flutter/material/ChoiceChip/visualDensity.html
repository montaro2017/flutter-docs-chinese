visualDensity 属性

  1. @重写
VisualDensity? visualDensity
final

定义芯片布局的紧凑程度。

水平密度变化不会影响芯片。

在界面中，密度指元素在垂直和水平方向上的紧凑程度。它没有单位，因为不同界面元素对密度的含义各不相同。对于按钮，密度会影响按钮居中标签周围的间距；对于列表，密度会影响各条目基线之间的距离。

密度值通常为整数，但也可以使用范围内的任意值。范围从 VisualDensity.minimumDensity（-4）到 VisualDensity.maximumDensity（4），含两端。负值表示界面更紧凑，正值表示界面更疏朗。如果组件不支持给定值，会将其限制为最近的受支持值。

默认情况下，垂直和水平方向的视觉密度都为 0，这与 Material Design 规范中组件的默认视觉密度一致。

经验上，密度每增加或减少 1，对应约 4 个逻辑像素。但这并非严格换算关系，因为组件会根据自身需要解释密度值。

较大的值会增加间距（密度更低），较小的值会减小间距（密度更高）。

在 Material Design 3 中，对于以下组件，visualDensity 不会覆盖默认视觉密度；所有平台上这些组件的默认值均为 VisualDensity.standard：

  • IconButton - To override the default value of IconButton.visualDensity, use ThemeData.iconButtonTheme instead.
  • Checkbox - To override the default value of Checkbox.visualDensity, use ThemeData.checkboxTheme instead.

另请参阅：

  • ThemeData.visualDensity, which specifies the visualDensity for all widgets within a Theme.
