SearchAnchor 类

管理一个“搜索视图”路由，让用户可以从搜索查询的建议补全项中进行选择。

可以创建 SearchController 并调用 SearchController.openView，也可以点按搜索锚点来显示搜索视图路由。点按锚点或调用 SearchController.openView 后，搜索视图会扩展到指定大小，或扩展至整个屏幕。默认情况下，它只会在移动平台上全屏显示。可通过 SearchAnchor.isFullScreen 覆盖此默认设置。

通常通过 SearchBar、IconButton 或 Icon 打开搜索视图。如果 builder 返回 Icon 或其他不可点按的 widget，则无需显式调用 SearchController.openView。

如果搜索视图路由未处于全屏模式，窗口尺寸改变时该路由会弹出并关闭。不过，若搜索视图处于全屏模式，改变窗口尺寸（例如将移动设备从纵向旋转为横向）不会关闭搜索视图。

此示例展示如何在 SearchAnchor 中使用 IconButton 打开搜索视图，并演示如何使用 SearchController 打开或关闭搜索视图路由。
