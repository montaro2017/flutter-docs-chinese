MaterialPointArcTween 类

一种 Tween，可沿圆弧对 Offset 进行插值。

此类专门实现了 Tween<Offset> 的插值，使中间点不沿直线移动，而是遵循圆弧轨迹，并符合 Material Design 原则。

圆弧半径与包含 begin 和 end 点的边界框有关。如果边界框的高度大于宽度，圆心会与终点水平对齐；否则，圆心会与起点对齐。圆弧的扫掠角始终不超过 90 度。

另请参阅：

  • Tween, for a discussion on how to use interpolation objects.
  • MaterialRectArcTween, which extends this concept to interpolating Rect。
