trackColor 属性

WidgetStateProperty<Color?>? trackColor
final

此 Switch 轨道的颜色。

会根据以下状态进行解析：

  • WidgetState.selected.
  • WidgetState.hovered.
  • WidgetState.focused.
  • WidgetState.disabled.

此示例根据 Switch 当前的 WidgetState 解析 trackColor，并在处于 WidgetState.disabled 状态时提供不同的 Color。
link 
Switch(
  value: true,
  onChanged: (bool value) { },
  thumbColor: WidgetStateProperty.resolveWith<Color>((Set<WidgetState> states) {
    if (states.contains(WidgetState.disabled)) {
      return Colors.orange.withValues(alpha: .48);
    }
    return Colors.orange;
  }),
)

如果为 null，则选中状态使用 activeTrackColor，默认状态使用 inactiveTrackColor。若这些值均为 null，则使用 SwitchThemeData.trackColor；如果该值也为 null，则使用以下颜色：

State Light theme Dark theme
Default Color(0x52000000) Colors.white30
Selected activeThumbColor with alpha 0x80 activeThumbColor with alpha 0x80
Disabled Colors.black12 Colors.white10
