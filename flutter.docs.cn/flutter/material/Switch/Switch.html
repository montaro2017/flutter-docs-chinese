创建 Material Design 开关。

开关本身不维护任何状态。开关状态改变时，widget 会调用 onChanged 回调。大多数使用开关的 widget 会监听 onChanged 回调，并使用新的 value 重新构建开关，以更新其视觉外观。

以下参数为必填项：

  • value determines whether this switch is on or off.
  • onChanged is called when the user toggles the switch on or off.
