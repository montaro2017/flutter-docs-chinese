DialogThemeData 类

为后代 Dialog 小组件定义默认属性值。

后代小组件通过 DialogTheme.of 获取当前的 DialogThemeData 对象。可以使用 DialogThemeData.copyWith 自定义 DialogThemeData 实例。

通常会将 DialogThemeData 作为整体 Theme 的一部分，通过 ThemeData.dialogTheme 指定。

默认情况下，所有 DialogThemeData 属性均为 null。如果属性为 null，Dialog 会使用 ThemeData 中的值（如果存在）；否则 Dialog 会采用自身的默认值。详情请参阅各个 Dialog 属性的说明。

另请参阅：

  • Dialog, a dialog that can be customized using this DialogTheme.
  • AlertDialog, a dialog that can be customized using this DialogTheme.
  • SimpleDialog, a dialog that can be customized using this DialogTheme.
  • ThemeData，用于描述应用的整体主题信息。
