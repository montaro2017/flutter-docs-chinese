SimpleDialog 类

Material Design 简单对话框。

简单对话框用于让用户从多个选项中进行选择。它可以包含一个可选标题，显示在选项上方。

选项通常由 SimpleDialogOption 组件表示。如果使用其他组件，请参阅 contentPadding，了解如何遵循 Material Design 的间距规范。

如果对话框用于告知用户某种情况，可考虑使用 AlertDialog。

通常将其作为子组件传给 showDialog，由该方法显示对话框。

在此示例中，用户需要从两个选项中进行选择，这些选项由枚举表示。此处的 showDialog 方法会返回一个 Future，并以该枚举中的某个值完成。如果用户取消对话框（例如在 Android 上按返回键，或点击对话框后方的遮罩），future 将以 null 值完成。

此示例将返回值用作 switch 语句的索引。使用枚举作为返回值并据此执行 switch 语句的一个优点是：如果 switch 语句没有涵盖枚举中的每个值，分析器会发出提示。

link 
Future<void> _askedToLead() async {
  switch (await showDialog<Department>(
    context: context,
    builder: (BuildContext context) {
      return SimpleDialog(
        title: const Text('Select assignment'),
        children: <Widget>[
          SimpleDialogOption(
            onPressed: () { Navigator.pop(context, Department.treasury); },
            child: const Text('Treasury department'),
          ),
          SimpleDialogOption(
            onPressed: () { Navigator.pop(context, Department.state); },
            child: const Text('State department'),
          ),
        ],
      );
    }
  )) {
    case Department.treasury:
      // Let's go.
      // ...
    break;
    case Department.state:
      // ...
    break;
    case null:
      // dialog dismissed
    break;
  }
}
