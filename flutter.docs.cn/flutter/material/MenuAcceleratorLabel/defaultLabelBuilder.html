作为 builder 的默认值。当 index 为非负数时，会将标签绘制为带有适当 TextSpan 的 RichText，并在选中的快捷键字符下方显示下划线；当 index 为负数时，则使用 Text 组件。

此函数的参数如下：

  • The context supplies the BuildContext to use.
  • The label is the MenuAcceleratorLabel.label attribute for the relevant MenuAcceleratorLabel with the accelerator markers stripped out of it.
  • index 表示适用于此快捷键的字符在 label.characters 中的位置。如果它为 -1，则不应突出显示快捷键。否则，应以某种方式在渲染后的标签中突出显示该字符（通常使用下划线）。需要注意的是，index 不是 String label 中的索引，而是 Characters 可迭代对象中由 label.characters 返回的位置，因此它按用户可见字符（即字素簇）计数，而不是按 Unicode 码点计数。

实现

static Widget defaultLabelBuilder(BuildContext context, String label, int index) {
  if (index < 0) {
    return Text(label);
  }
  final TextStyle defaultStyle = DefaultTextStyle.of(context).style;
  final Characters characters = label.characters;
  return RichText(
    text: TextSpan(
      children: <TextSpan>[
        if (index > 0)
          TextSpan(text: characters.getRange(0, index).toString(), style: defaultStyle),
        TextSpan(
          text: characters.getRange(index, index + 1).toString(),
          style: defaultStyle.copyWith(decoration: TextDecoration.underline),
        ),
        if (index < characters.length - 1)
          TextSpan(text: characters.getRange(index + 1).toString(), style: defaultStyle),
      ],
    ),
  );
}
