ExpansionTileController typedef

  1. @Deprecated('Use ExpansibleController instead. ' 'This feature was deprecated after v3.31.0-0.1.pre.')
ExpansionTileController = ExpansibleController

允许控制单个 ExpansionTile 的展开/折叠状态。

有时需要以编程方式展开或折叠 ExpansionTile，例如根据系统事件重新配置已有条目。为此，可创建一个带有 ExpansionTileController 的 ExpansionTile，并由有状态组件持有控制器；也可以通过 ExpansibleController.of 查找该条目自动创建的 ExpansionTileController。

调用 ExpansibleController.of 的典型用法，是在 ExpansionTile 的某个后代组件的 build 方法中调用它。

如果 ExpansionTile 与引用控制器的回调在同一个 build 函数中创建，那么该函数的 context 参数（即 build 函数的上下文）不能用于查找 ExpansionTileController，因为它位于返回组件树中该组件的“上方”。这种情况下，可以添加 Builder，它会提供一个新的作用域，其中的 BuildContext 位于 ExpansionTile 的“下方”：

link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.ExpansionTileController.1 mysample

更高效的做法是将 build 函数拆分为多个组件。这样会引入一个新的上下文，可用于获取 ExpansionTileController。外层组件创建一个 ExpansionTile，并填入新的内部组件实例；随后在这些内部组件中使用 ExpansionTileController.of。

ExpansibleController.expand 和 ExpansibleController.collapse 方法会导致 ExpansionTile 重建，因此不能从 build 方法中调用。

不再需要 ExpansionTileController 时，记得将其释放，以确保清理该对象使用的资源。
