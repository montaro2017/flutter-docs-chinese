DatePickerDialog 类

Material 风格的日期选择对话框。

此组件由 showDatePicker 在内部使用，也可以直接压入 Navigator 导航栈以启用状态恢复。有关状态恢复应用示例，请参阅 showDatePicker。

另请参阅：

  • showDatePicker, which is a way to display the date picker.
