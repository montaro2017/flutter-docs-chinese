ToggleButtonsThemeData 类

为后代 ToggleButtons 小组件定义默认属性值。

后代小组件通过 ToggleButtonsTheme.of 获取当前的 ToggleButtonsThemeData 对象。可使用 ToggleButtonsThemeData.copyWith 自定义 ToggleButtonsThemeData 实例。

通常会通过 ThemeData.toggleButtonsTheme，将 ToggleButtonsThemeData 指定为整体 Theme 的一部分。

另请参阅：

  • ToggleButtonsTheme, which describes the actual configuration of a toggle buttons theme.
