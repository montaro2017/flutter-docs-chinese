CarouselScrollPhysics 类

CarouselView 使用的滚动物理效果。

这些物理效果会使轮播条目吸附到条目边界。

另请参阅：

  • ScrollPhysics，定义滚动物理效果 API 的基类。
  • PageScrollPhysics，用于 PageView 的滚动物理效果。
