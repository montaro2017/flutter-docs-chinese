根据传入的状态绘制数值指示器形状。

context 参数表示 RangeSlider 的渲染框。

center 参数是此形状中心的绘制偏移量。该偏移量相对于 context 画布的原点。

用户开始与 RangeSlider 交互时会触发 activationAnimation 动画；用户停止与滑块交互时，动画会反向播放。

启用 RangeSlider 时会触发 enableAnimation 动画，禁用滑块时则反向播放。RangeSlider 在 RangeSlider.onChanged 非 null 时处于启用状态。滑块启用状态发生变化时，可使用此动画绘制该形状的中间帧。

当 RangeSlider.divisions 非 null 时，isDiscrete 参数为 true。此时，滑块会在轨道上绘制刻度标记。

isOnTop 参数表示两个数值指示器中位于最上层的那个，它始终对应最近选中的滑块。在默认情况下，此参数用于为最上层指示器绘制描边，以便更清楚地区分两个指示器。

textScaleFactor 参数可用于确定组件应放大还是缩小绘制：textScaleFactor 大于 1 时放大，介于 0 和 1 之间时缩小。该值通常根据 MediaQueryData.textScaler 计算。

sizeWithOverflow 参数可用于确定常规滑块边界之外组件绘制区域的边界。它表示一个框的尺寸，该框中心与滑块边界对齐；数值指示器必须绘制在此框内。此尺寸通常大于滑块本身。

parentBox 参数是 RangeSlider 的 RenderBox。其大小等属性可用于辅助绘制此形状。

sliderTheme 参数是分配给此形状所属 RangeSlider 的主题。

textDirection 参数可用于确定如何放置 labelPainter 绘制的文本以外的额外文本或图形。labelPainter 参数已经设置了 textDirection。

value 参数是滑块当前的参数化数值（范围为 0.0 到 1.0）。

thumb 参数用于指定此方法要绘制两个滑块中的哪一个（起始或结束滑块）。
