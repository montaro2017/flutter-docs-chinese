MaterialBanner 类

Material Design 横幅。

横幅用于显示重要而简洁的信息，并提供供用户处理或关闭横幅的操作。用户必须执行某项操作才能将其关闭。

横幅应显示在屏幕顶部应用栏的下方。横幅会持续显示且不阻断界面，用户可随时忽略它或与之交互。

直接放入 widget 树中的横幅是静态的。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.MaterialBanner.1 mysample

MaterialBanner 也可以通过 ScaffoldMessenger 展示。 以下示例使用 ScaffoldMessengerState.showMaterialBanner() 方法显示 MaterialBanner。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.MaterialBanner.2 mysample

如果只有一个 actions，它会与 content 并排显示。否则，actions 会显示在 content 下方。使用 forceActionsBelow 可覆盖此行为。

如果 actions 显示在 content 下方，它们会按行排列。如果空间不足以显示所有内容，则会改为按列排列。

必须提供 actions 和 content。也可以提供可选的前置组件（通常是 Image）。还可通过 contentTextStyle 和 backgroundColor 自定义横幅。

此组件与 widgets 库中的 Banner 组件无关。
