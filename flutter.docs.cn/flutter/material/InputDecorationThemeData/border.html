border 属性

InputBorder? border
final

绘制在装饰容器周围的边框形状。

如果 border 是 WidgetStateInputBorder，则最终边框可能根据 WidgetState.focused 状态变化，也就是根据 TextField 是否获得焦点变化。

装饰容器是指 filled 为 true 时填充、并按照 border 绘制边框的区域。它紧邻 InputDecoration.icon，位于包含 InputDecoration.helperText、InputDecoration.errorText 和 InputDecoration.counterText 的组件上方。

边框的边界（即 border.getOuterPath() 的值）定义了要填充的区域。

仅当未指定相应的 errorBorder、focusedBorder、focusedErrorBorder、disabledBorder 或 enabledBorder 时，才会使用此属性。InputDecorator 会根据 InputBorder.borderSide、InputDecoration.errorText、InputDecoration.enabled 和当前 InputDecorator.isFocused 的值配置此边框的 Theme 属性。

通常使用 UnderlineInputBorder 或 OutlineInputBorder。如果为 null，InputDecorator 默认使用 const UnderlineInputBorder()。

另请参阅：

  • InputBorder.none，不绘制边框。
  • UnderlineInputBorder, which draws a horizontal line at the bottom of the input decorator's container.
  • OutlineInputBorder，InputDecorator 边框会在输入装饰器容器周围绘制圆角矩形。
