enabledBorder 属性

InputBorder? enabledBorder
final

InputDecorator 已启用且未显示错误时显示的边框。

另请参阅：

  • InputDecoration.enabled，当 InputDecorator 被禁用时，该值为 false。
  • InputDecoration.errorText，若非 null，则为 InputDecorator 显示的错误文本。
  • border，了解 InputDecorator 边框的显示位置。
  • UnderlineInputBorder，InputDecorator 边框会沿输入装饰器容器底部绘制水平线。
  • OutlineInputBorder，InputDecorator 边框会在输入装饰器容器周围绘制圆角矩形。
  • InputBorder.none，不绘制边框。
  • errorBorder，当 InputDecorator.isFocused 为 false 且 InputDecoration.errorText 为 non-null 时显示。
  • focusedBorder，当 InputDecorator.isFocused 为 true 且 InputDecoration.errorText 为 null 时显示。
  • focusedErrorBorder，当 InputDecorator.isFocused 为 true 且 InputDecoration.errorText 为 non-null 时显示。
  • disabledBorder，当 InputDecoration.enabled 为 false 且 InputDecoration.errorText 为 null 时显示。
