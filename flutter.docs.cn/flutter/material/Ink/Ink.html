Ink 构造函数

Ink({
  1. Key? key,
  2. EdgeInsetsGeometry? padding,
  3. Color? color,
  4. Decoration? decoration,
  5. double? width,
  6. double? height,
  7. Widget? child,
})

在 Material 上绘制装饰（可以是纯色）。

height 和 width 的值包含 padding。

color 参数是 decoration: BoxDecoration(color: color) 的简写，因此不能同时传入 color 和 decoration 参数。若要同时指定 color 和 decoration，可以将颜色作为 color 参数传给 BoxDecoration 的构造函数。

如果不打算在此装饰上绘制任何内容，可以考虑改用 Container，并为其设置 BoxDecoration。

实现

Ink({
  super.key,
  this.padding,
  Color? color,
  Decoration? decoration,
  this.width,
  this.height,
  this.child,
}) : assert(padding == null || padding.isNonNegative),
     assert(decoration == null || decoration.debugAssertIsValid()),
     assert(
       color == null || decoration == null,
       'Cannot provide both a color and a decoration\n'
       'The color argument is just a shorthand for "decoration: BoxDecoration(color: color)".',
     ),
     decoration = decoration ?? (color != null ? BoxDecoration(color: color) : null);
