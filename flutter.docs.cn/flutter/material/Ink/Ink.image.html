创建一个从 ImageProvider 获取图像并显示在 Material 上的组件。

此参数是简写形式：为 BoxDecoration 仅设置 BoxDecoration.image 属性，再将其传给 Ink 构造函数。该 DecorationImage 的属性会根据此方法的参数设置；它属于此 BoxDecoration。

如果不打算在此图像上绘制其他内容，可以考虑使用 Container，并为其设置 BoxDecoration.image。也可以提供 onImageError 参数，以监听解析图像时发生的错误。

alignment、repeat 和 matchTextDirection 参数也不能为 null，但它们都有默认值。

这些参数的含义请参阅 paintImage。

实现

Ink.image({
  super.key,
  this.padding,
  required ImageProvider image,
  ImageErrorListener? onImageError,
  ColorFilter? colorFilter,
  BoxFit? fit,
  AlignmentGeometry alignment = Alignment.center,
  Rect? centerSlice,
  ImageRepeat repeat = ImageRepeat.noRepeat,
  bool matchTextDirection = false,
  this.width,
  this.height,
  this.child,
}) : assert(padding == null || padding.isNonNegative),
     decoration = BoxDecoration(
       image: DecorationImage(
         image: image,
         onError: onImageError,
         colorFilter: colorFilter,
         fit: fit,
         alignment: alignment,
         centerSlice: centerSlice,
         repeat: repeat,
         matchTextDirection: matchTextDirection,
       ),
     );
