ExpansionTileThemeData 类

与 ExpansionTileTheme 搭配使用，为后代 ExpansionTile 组件定义默认属性值。

后代组件通过 ExpansionTileTheme.of 获取当前的 ExpansionTileThemeData 对象。可以使用 ExpansionTileThemeData 自定义 ExpansionTileThemeData.copyWith 实例。

ExpansionTileThemeData 通常作为整体 Theme 的一部分，通过 ThemeData.expansionTileTheme 指定。

所有 ExpansionTileThemeData 属性的默认值均为 null。主题属性为 null 时，ExpansionTile 会根据整体 Theme 的 textTheme 和 colorScheme 提供自己的默认值。详情请参阅各个 ExpansionTile 属性。

另请参阅：

  • ThemeData，用于描述应用的整体主题信息。
  • ExpansionTileTheme which overrides the default ExpansionTileTheme of its ExpansionTile descendants.
  • ThemeData.textTheme, text with a color that contrasts with the card and canvas colors.
  • ThemeData.colorScheme, the thirteen colors that most Material widget default colors are based on.
