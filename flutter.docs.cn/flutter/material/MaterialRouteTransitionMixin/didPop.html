didPop 方法

  1. @重写

  1. T? result
)
重写

收到弹出此路由的请求。如果路由可以在内部处理（例如它有自己的内部状态栈），则返回 false；否则返回 true（即返回调用 super.didPop 的结果）。返回 false 会阻止 NavigatorState.pop 的默认行为。

此方法返回 true 时，导航器会从历史记录中移除此路由，但不会立即调用 dispose。路由需要自行调用 NavigatorState.finalizeRoute，后者会进一步调用该路由的 dispose。这样路由便能在弹出后、释放前播放退出动画或其他视觉效果。

此方法应调用 didComplete 来完成 popped Future（默认实现只会执行此操作）；路由不应等退出动画结束后才调用。

关于 result 参数，请参阅 popped、didComplete 和 currentResult。

实现

@override
bool didPop(T? result) {
  controller?.reverseDuration = reverseTransitionDuration;
  return super.didPop(result);
}
