barrierCurve 属性

Curve get barrierCurve
继承

用于显示和隐藏模态屏障的动画曲线。

模态屏障是在每条路由后方绘制的遮罩，通常用于阻止用户与当前路由下方的路由交互，并使这些路由部分变暗。

例如，显示对话框时，对话框下方的页面通常会被模态屏障调暗。

路由正在进入位置时，颜色会从透明渐变为指定的 barrierColor。

如果此 getter 返回的曲线发生变化，应调用 changedInternalState 或 changedExternalState，使更改生效。

此处可以安全地使用 navigator.context 查找继承组件，因为 Navigator 会在依赖项变化时调用 changedExternalState，而该方法会使模态屏障重建。changedExternalState

默认值为 Curves.ease。

另请参阅：

  • barrierColor，用于确定模态转场最终显示的颜色。
  • Curves，其中列出了一组常用曲线。
  • AnimatedModalBarrier，实现此功能的 widget。

实现

Curve get barrierCurve => Curves.ease;
