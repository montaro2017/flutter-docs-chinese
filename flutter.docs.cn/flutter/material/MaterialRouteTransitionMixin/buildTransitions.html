重写

重写此方法，用一个或多个过渡组件包装 child，以定义路由进入和离开屏幕的方式。

默认情况下，子组件（包含 buildPage 返回的组件）不会被任何过渡组件包装。

与 Route 不同，只要 buildPage 可见且状态发生变化，就会调用 buildTransitions（例如活动路由的 canPop 值发生变化时）。

buildTransitions 通常用于定义新顶层路由进入和离开时的动画。Navigator 将路由推入栈顶时，新路由的主 animation 会从 0.0 播放到 1.0。Navigator 弹出顶层路由时（例如用户按下返回按钮），主动画会从 1.0 播放到 0.0。

以下示例使用主动画驱动 SlideTransition，使新路由被推入 Navigator 的栈中时，从屏幕底部垂直滑入。路由弹出时，SlideTransition 则使路由从屏幕顶部滑回底部。

这里使用 PageRouteBuilder 演示 buildTransitions 方法。重写 buildTransitions 时，也可以用相同方式定义方法主体。

link 
PageRouteBuilder<void>(
  pageBuilder: (BuildContext context,
      Animation<double> animation,
      Animation<double> secondaryAnimation,
  ) {
    return Scaffold(
      appBar: AppBar(title: const Text('Hello')),
      body: const Center(
        child: Text('Hello World'),
      ),
    );
  },
  transitionsBuilder: (
      BuildContext context,
      Animation<double> animation,
      Animation<double> secondaryAnimation,
      Widget child,
   ) {
    return SlideTransition(
      position: Tween<Offset>(
        begin: const Offset(0.0, 1.0),
        end: Offset.zero,
      ).animate(animation),
      child: child, // child is the value returned by pageBuilder
    );
  },
)

Navigator 将路由推入栈顶时，可以使用 secondaryAnimation 定义原栈顶路由如何离开屏幕。类似地，弹出顶层路由时，可以使用次级动画定义其下方路由如何重新显示。推入新路由时，原栈顶路由的次级动画从 0.0 播放到 1.0；弹出顶层路由时，其下方路由的次级动画从 1.0 播放到 0.0。

下面的示例添加了一个由 secondaryAnimation 驱动的过渡。当新路由被推入其上方、使此路由离开屏幕时，此路由会沿新路由的反方向移动。当顶层路由弹出、此路由重新显示时，也会采用相应的过渡。
link 
PageRouteBuilder<void>(
  pageBuilder: (BuildContext context,
      Animation<double> animation,
      Animation<double> secondaryAnimation,
  ) {
    return Scaffold(
      appBar: AppBar(title: const Text('Hello')),
      body: const Center(
        child: Text('Hello World'),
      ),
    );
  },
  transitionsBuilder: (
      BuildContext context,
      Animation<double> animation,
      Animation<double> secondaryAnimation,
      Widget child,
  ) {
    return SlideTransition(
      position: Tween<Offset>(
        begin: const Offset(0.0, 1.0),
        end: Offset.zero,
      ).animate(animation),
      child: SlideTransition(
        position: Tween<Offset>(
          begin: Offset.zero,
          end: const Offset(0.0, 1.0),
        ).animate(secondaryAnimation),
        child: child,
      ),
     );
  },
)

实际使用中，secondaryAnimation 很少用到。

此方法的参数如下：

  • context: The context in which the route is being built.
  • animation: When the Navigator pushes a route on the top of its stack, the new route's primary animation runs from 0.0 to 1.0. When the Navigator pops the topmost route this animation runs from 1.0 to 0.0.
  • secondaryAnimation: When the Navigator pushes a new route on the top of its stack, the old topmost route's secondaryAnimation runs from 0.0 to 1.0. When the Navigator pops the topmost route, the secondaryAnimation for the route below it runs from 1.0 to 0.0.
  • child, the page contents, as returned by buildPage.

另请参阅：

  • buildPage, which is used to describe the actual contents of the page, and whose result is passed to the child argument of this method.

实现

@override
Widget buildTransitions(
  BuildContext context,
  Animation<double> animation,
  Animation<double> secondaryAnimation,
  Widget child,
) {
  final PageTransitionsTheme theme = Theme.of(context).pageTransitionsTheme;
  return theme.buildTransitions<T>(this, context, animation, secondaryAnimation, child);
}
