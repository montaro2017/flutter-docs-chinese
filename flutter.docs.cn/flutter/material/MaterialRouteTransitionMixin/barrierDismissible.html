barrierDismissible 属性

  1. @重写
bool get barrierDismissible
继承

是否可以通过点击模态屏障关闭此路由。

模态屏障是在每条路由后方绘制的遮罩，通常用于阻止用户与当前路由下方的路由交互，并使这些路由部分变暗。

例如，显示对话框时，对话框下方的页面通常会被模态屏障调暗。

如果 barrierDismissible 为 true，点击屏障、按键盘上的 Esc，或调用 Navigator.pop 等弹出路由的方法，都会关闭当前路由，并将结果设为 null。

如果 barrierDismissible 为 false，点击屏障不会产生效果。

如果此 getter 返回的值发生变化，应调用 changedInternalState 或 changedExternalState，使更改生效。

此处可以安全地使用 navigator.context 查找继承组件，因为 Navigator 会在依赖项变化时调用 changedExternalState，而该方法会使模态屏障重建。changedExternalState

另请参阅：

  • Navigator.pop, which is used to dismiss the route.
  • barrierColor, which controls the color of the scrim for this route.
  • ModalBarrier, the widget that implements this feature.

实现

@override
bool get barrierDismissible => _barrierDismissible;
