创建日历日期选择器。

它会显示 initialDate 所在月份的日期网格；如果该值为 null，则显示 currentDate 所在月份。initialDate 不为 null 时，会选中其指示的日期。

可以使用可选的 onDisplayedMonthChanged 回调跟踪当前显示的月份。

用户界面提供了更改当前显示月份年份的方式。默认显示日期网格；若将 initialCalendarMode 设为 DatePickerMode.year，则可以从年份选择界面开始。

lastDate 必须晚于或等于 firstDate。

如果提供了 initialDate，它必须位于 firstDate 与 lastDate 之间，或与其中一个日期相等。

currentDate 表示当前日期（即今天），该日期会在日期网格中高亮显示。如果为 null，则使用 DateTime.now() 的日期。

如果 selectableDayPredicate 和 initialDate 均不为 null，则 selectableDayPredicate 必须对 initialDate 返回 true。

calendarDelegate 控制选择器中的日期解释、格式化和导航。提供自定义实现即可支持尼泊尔历、回历、佛历等其他历法。默认值为 GregorianCalendarDelegate。

实现

CalendarDatePicker({
  super.key,
  required DateTime? initialDate,
  required DateTime firstDate,
  required DateTime lastDate,
  DateTime? currentDate,
  required this.onDateChanged,
  this.onDisplayedMonthChanged,
  this.initialCalendarMode = DatePickerMode.day,
  this.selectableDayPredicate,
  this.calendarDelegate = const GregorianCalendarDelegate(),
}) : initialDate = initialDate == null ? null : calendarDelegate.dateOnly(initialDate),
     firstDate = calendarDelegate.dateOnly(firstDate),
     lastDate = calendarDelegate.dateOnly(lastDate),
     currentDate = calendarDelegate.dateOnly(currentDate ?? calendarDelegate.now()) {
  assert(
    !this.lastDate.isBefore(this.firstDate),
    'lastDate ${this.lastDate} must be on or after firstDate ${this.firstDate}.',
  );
  assert(
    this.initialDate == null || !this.initialDate!.isBefore(this.firstDate),
    'initialDate ${this.initialDate} must be on or after firstDate ${this.firstDate}.',
  );
  assert(
    this.initialDate == null || !this.initialDate!.isAfter(this.lastDate),
    'initialDate ${this.initialDate} must be on or before lastDate ${this.lastDate}.',
  );
  assert(
    selectableDayPredicate == null ||
        this.initialDate == null ||
        selectableDayPredicate!(this.initialDate!),
    'Provided initialDate ${this.initialDate} must satisfy provided selectableDayPredicate.',
  );
}
