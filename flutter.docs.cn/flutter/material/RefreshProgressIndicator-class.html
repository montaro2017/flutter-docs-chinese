RefreshProgressIndicator
description

RefreshProgressIndicator 类

用于指示 Widget 内容正在刷新的进度指示器。

通常用于下拉刷新交互。有关通过 Scrollable Widget 实现完整下拉刷新的示例，请参见 RefreshIndicator。

指示器弧线使用动画值 valueColor 显示。若要指定固定颜色，请使用：AlwaysStoppedAnimation<Color>(color)。

另请参阅：

  • RefreshIndicator, which automatically displays a CircularProgressIndicator when the underlying vertical scrollable is overscrolled.
