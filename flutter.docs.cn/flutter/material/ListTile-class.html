ListTile 类

一种固定高度的单行组件，通常包含文字以及前置或尾随图标。

列表项包含一至三行文字，两侧可选配图标或复选框等其他组件。列表项的图标（或其他组件）由 leading 和 trailing 参数指定。第一行文字不可省略，通过 title 指定。可选的 subtitle 会占用额外一行文字的空间；如果 isThreeLine 为 true，则占用两行。若 dense 为 true，列表项整体高度以及包裹 title 和 subtitle 的 DefaultTextStyle 字号都会缩小。

调用方需要确保 title 不换行；并确保 subtitle 不换行（当 isThreeLine 为 false 时），或最多换为两行（为 true 时）。

leading 和 trailing 组件的高度会根据 Material spec 进行限制。为满足无障碍需求，单行列表项有例外。请参阅下方示例，了解如何同时满足 Material 规范和无障碍要求。

leading 和 trailing 组件的横向尺寸可以任意扩展，因此请确保对它们进行适当约束。

列表项通常用于 ListView，也可以排列在 Drawer 或 Card 中的 Column 里。

此组件需要在组件树中有一个 Material 祖先，才能绘制自身；通常由应用的 Scaffold 提供。tileColor、selectedTileColor、focusColor 和 hoverColor 不是由 ListTile 自身绘制，而是由 Material 祖先绘制。可将 Material 包在 ListTile 外部，例如：

link 
const ColoredBox(
  color: Colors.green,
  child: Material(
    child: ListTile(
      title: Text('ListTile with red background'),
      tileColor: Colors.red,
    ),
  ),
)

使用 Material 包裹 ListTile 时的性能注意事项

逐个使用 Material 包裹大量 ListTile 会产生较高开销。建议只包裹确有需要的 ListTile，或尽可能为它们共用一个 Material 祖先。

要为 tileColor、selectedTileColor、focusColor 和 hoverColor 设置动画，必须使用 Material 包裹 ListTile。这些颜色由 Material 祖先绘制，而不是由列表项自身绘制。

若要在 Row 中使用 ListTile，需要将其包裹在 Expanded Widget 中。ListTile 需要固定的宽度约束，而 Row 不会约束其子项。
link 
const Row(
  children: <Widget>[
    Expanded(
      child: ListTile(
        leading: FlutterLogo(),
        title: Text('These ListTiles are expanded '),
      ),
    ),
    Expanded(
      child: ListTile(
        trailing: FlutterLogo(),
        title: Text('to fill the available space.'),
      ),
    ),
  ],
)

Tile 也可以有更复杂的布局。下面的 tile 可以点按，但当 _act 变量不等于 2 时会被禁用。点按 tile 后，整行会显示墨迹飞溅效果（参见 InkWell）。
link 
ListTile(
  leading: const Icon(Icons.flight_land),
  title: const Text("Trix's airplane"),
  subtitle: _act != 2 ? const Text('The airplane is only in Act II.') : null,
  enabled: _act == 2,
  onTap: () { /* react to the tile being tapped */ }
)

为满足无障碍要求，可轻触的 leading 和 trailing 组件尺寸至少应为 48x48。不过，为遵循 Material 规范，单行列表项中的 trailing 和 leading 组件视觉高度最多应为 32（dense: true）或 40（dense: false），这可能与无障碍尺寸要求冲突。

因此，单行列表项允许根据自身高度限制 leading 和 trailing 组件的高度。这可以创建尺寸足够大的可轻触组件，但开发者仍需确保这些 leading 和 trailing 组件符合 Material 规范。

下面是一个单行、非 dense ListTile 示例，其可点按的 leading Widget 符合无障碍要求和 Material 规范。若要将其调整为单行 dense ListTile，请将垂直内边距设为 8.0。
link 
ListTile(
  leading: GestureDetector(
    behavior: HitTestBehavior.translucent,
    onTap: () {},
    child: Container(
      width: 48,
      height: 48,
      padding: const EdgeInsets.symmetric(vertical: 4.0),
      alignment: Alignment.center,
      child: const CircleAvatar(),
    ),
  ),
  title: const Text('title'),
  dense: false,
)
