Chip 类

Material Design Chip。

Chip 是紧凑型元素，用于表示属性、文本、实体或操作。

提供非 null 的 onDeleted 回调后，Chip 会包含一个用于删除自身的按钮。

其祖先必须包含 Material、MediaQuery、Directionality 和 MaterialLocalizations。通常，MaterialApp 和 Scaffold 会提供这些 Widget。label 和 clipBehavior 参数不得为 null。

link 
Chip(
  avatar: CircleAvatar(
    backgroundColor: Colors.grey.shade800,
    child: const Text('AB'),
  ),
  label: const Text('Aaron Burr'),
)

另请参阅：

  • InputChip，以紧凑形式呈现复杂信息的芯片，例如人物、地点或事物等实体，或对话文本。
  • ChoiceChip，允许从一组选项中单选。ChoiceChip 包含相关的描述性文本或类别。
  • FilterChip，使用标签或描述性词语筛选内容。
  • ActionChip，表示与主要内容相关的操作。
  • CircleAvatar, which shows images or initials of entities.
  • Wrap，可将子项排列为多行或多列。
  • material.io/design/components/chips.html
