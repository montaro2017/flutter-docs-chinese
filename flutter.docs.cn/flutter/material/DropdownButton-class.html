DropdownButton<T> 类

Material Design 按钮，用于从项目列表中进行选择。

下拉按钮允许用户从多个项目中选择。按钮会显示当前选中的项目，以及一个用于打开菜单并选择其他项目的箭头。

Updating to DropdownMenu

Material 3 提供了此组件的对应版本 DropdownMenu。对于启用了 Material 3（参见 ThemeData.useMaterial3）的应用，推荐使用该组件。DropdownMenu 的视觉样式略有不同，详情请参阅 Material 3 规范：m3.material.io/components/menus/guidelines。

DropdownMenu 的 API 也略有不同。若要从 DropdownButton 迁移到 DropdownMenu，需要进行以下更改：

  1. 不要使用 DropdownButton.items（它接收 DropdownMenuItem 列表），而应使用 DropdownMenu.dropdownMenuEntries（它接收 DropdownMenuEntry 列表）。

  2. 不要使用 DropdownButton.onChanged，而应使用 DropdownMenu.onSelected；后者同样是一个在用户选择条目时调用的回调。

  3. 在 DropdownMenu 中，应用无需跟踪当前选中项。因此，不必在 DropdownButton.value 属性中跟踪当前选择，而可以将 DropdownMenu.initialSelection 属性设为尚无用户操作前应选中的项目。

  4. 你可能还需要调整 DropdownMenu 的样式；详情请参阅 DropdownMenu 构造函数中的属性。

请参阅下方示例，了解如何从 DropdownButton 迁移到 DropdownMenu。

Using DropdownButton

某个祖先组件必须是 Material，通常由应用的 Scaffold 提供。

类型 T 是每个下拉项目所代表的 value 值的类型。给定菜单中的所有条目必须使用一致的值类型，通常使用枚举。items 中的每个 DropdownMenuItem 都必须使用相同的类型参数进行实例化。

onChanged 回调应更新定义下拉按钮当前值的状态变量，并调用 State.setState，以便使用新值重建下拉按钮。
