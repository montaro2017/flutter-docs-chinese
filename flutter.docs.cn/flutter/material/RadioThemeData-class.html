RadioThemeData 类

为后代 Radio widget 定义属性默认值。

后代 widget 可通过 RadioTheme.of 获取当前的 RadioThemeData 对象。可使用 RadioThemeData.copyWith 自定义 RadioThemeData 实例。

通常，RadioThemeData 会通过 ThemeData.radioTheme 配置为整体 Theme 的一部分。

所有 RadioThemeData 属性的默认值都是 null。如果属性为 null，Radio 会在 ThemeData 中存在相应值时使用该值，否则会根据整体 Theme 的 colorScheme 提供自身默认值。详情请参阅各个 Radio 属性。

另请参阅：

  • ThemeData，用于描述应用的整体主题信息。
  • RadioTheme, which is used by descendants to obtain the RadioThemeData.
