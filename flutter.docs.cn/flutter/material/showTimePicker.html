显示一个包含 Material Design 时间选择器的对话框。

返回的 Future 会在用户关闭对话框时，以用户选择的时间完成。如果用户取消对话框，则返回 null。

显示一个对话框，并将 initialTime 设为当前时间。
link 
Future<TimeOfDay?> selectedTime = showTimePicker(
  initialTime: TimeOfDay.now(),
  context: context,
);

context、barrierDismissible、barrierColor、barrierLabel、useRootNavigator 和 routeSettings 参数会传给 showDialog，其文档介绍了这些参数的用途。

builder 参数可用于包装对话框控件，以添加 Localizations.override、Directionality 或 MediaQuery 等继承控件。

initialEntryMode 参数用于设置时间选择器初始采用的输入方式（钟面拨盘或文本输入）。

可提供 helpText、cancelText、errorInvalidText、hourLabelText、minuteLabelText 和 confirmText 等可选字符串，以覆盖默认值。

可选的 orientation 参数用于设置显示对话框时采用的 Orientation。默认根据环境中 MediaQueryData.size 和 MediaQuery 推导方向：较宽的尺寸使用横向，较高的尺寸使用纵向。可以使用此参数覆盖默认值，强制对话框以纵向或横向显示。

可选的 switchToInputEntryModeIcon 参数用于自定义输入图标；当 TimePickerEntryMode 为 TimePickerEntryMode.dial 时会显示该图标。

默认使用 Icon 控件，图标为 Icons.keyboard_outlined。

可选的 switchToTimerEntryModeIcon 参数用于自定义输入图标；当 TimePickerEntryMode 为 TimePickerEntryMode.input 时会显示该图标。

默认使用 Icon 控件，图标为 Icons.access_time。

DisplayFeature 可以将屏幕划分为多个子屏幕。系统会选择距离 anchorPoint 最近的子屏幕来渲染内容。

如果未提供 anchorPoint，则会使用 Directionality：

  • for TextDirection.ltr, anchorPoint is Offset.zero, which will cause the content to appear in the top-left sub-screen.
  • for TextDirection.rtl, anchorPoint is Offset(double.maxFinite, 0), which will cause the content to appear in the top-right sub-screen.

如果未提供 anchorPoint，且树中没有 Directionality 祖先控件，则在调试模式下构建此控件时会触发断言。

默认情况下，时间选择器会从整体主题的 ColorScheme 获取颜色。也可以将 TimePickerThemeData 提供给整体主题，进一步自定义时间选择器。

显示一个对话框，并将文本方向覆盖为 TextDirection.rtl。
link 
Future<TimeOfDay?> selectedTimeRTL = showTimePicker(
  context: context,
  initialTime: TimeOfDay.now(),
  builder: (BuildContext context, Widget? child) {
    return Directionality(
      textDirection: TextDirection.rtl,
      child: child!,
    );
  },
);

显示一个对话框，时间始终采用 24 小时制显示。
link 
Future<TimeOfDay?> selectedTime24Hour = showTimePicker(
  context: context,
  initialTime: const TimeOfDay(hour: 10, minute: 47),
  builder: (BuildContext context, Widget? child) {
    return MediaQuery(
      data: MediaQuery.of(context).copyWith(alwaysUse24HourFormat: true),
      child: child!,
    );
  },
);

实现

Future<TimeOfDay?> showTimePicker({
  required BuildContext context,
  required TimeOfDay initialTime,
  TransitionBuilder? builder,
  bool barrierDismissible = true,
  Color? barrierColor,
  String? barrierLabel,
  bool useRootNavigator = true,
  TimePickerEntryMode initialEntryMode = TimePickerEntryMode.dial,
  String? cancelText,
  String? confirmText,
  String? helpText,
  String? errorInvalidText,
  String? hourLabelText,
  String? minuteLabelText,
  RouteSettings? routeSettings,
  EntryModeChangeCallback? onEntryModeChanged,
  Offset? anchorPoint,
  Orientation? orientation,
  Icon? switchToInputEntryModeIcon,
  Icon? switchToTimerEntryModeIcon,
  bool emptyInitialInput = false,
}) async {
  assert(debugCheckHasMaterialLocalizations(context));

  final Widget dialog = TimePickerDialog(
    initialTime: initialTime,
    initialEntryMode: initialEntryMode,
    cancelText: cancelText,
    confirmText: confirmText,
    helpText: helpText,
    errorInvalidText: errorInvalidText,
    hourLabelText: hourLabelText,
    minuteLabelText: minuteLabelText,
    orientation: orientation,
    onEntryModeChanged: onEntryModeChanged,
    switchToInputEntryModeIcon: switchToInputEntryModeIcon,
    switchToTimerEntryModeIcon: switchToTimerEntryModeIcon,
    emptyInitialInput: emptyInitialInput,
  );
  return showDialog<TimeOfDay>(
    context: context,
    barrierDismissible: barrierDismissible,
    barrierColor: barrierColor,
    barrierLabel: barrierLabel,
    useRootNavigator: useRootNavigator,
    builder: (BuildContext context) {
      return builder == null ? dialog : builder(context, dialog);
    },
    routeSettings: routeSettings,
    anchorPoint: anchorPoint,
  );
}
