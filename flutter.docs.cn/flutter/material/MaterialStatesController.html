MaterialStatesController typedef

  1. @Deprecated('Use WidgetStatesController instead. ' 'Moved to the Widgets layer to make code available outside of Material. ' 'This feature was deprecated after v3.19.0-0.3.pre.')
MaterialStatesController = WidgetStatesController

管理一组 MaterialState，并在状态变化时通知监听器。

供需要公开内部状态的组件使用，以便扩展为其添加对其他状态的支持。示例请参阅 TextButton。

控制器的 value 是当前状态集合。每当 value 发生变化时，都会通知监听器。只能通过 update 更改 value，不应直接修改。

控制器的 value 表示组件视觉属性（通常是 MaterialStateProperty 值）用于解析的状态集合。它并非组件的内在状态。组件负责确保控制器的 value 跟踪其内在状态。例如，不能通过向控制器添加 WidgetState.focused 来请求组件获得键盘焦点。组件获得或失去焦点时，会 update 控制器的 value 并通知监听器。

在 MaterialStatesController 监听器中调用 setState 时，应使用 SchedulerBinding.addPostFrameCallback，将 setState 延迟到当前帧渲染完成后执行。通常都应使用 SchedulerBinding.addPostFrameCallback，因为依赖 MaterialStatesController 的某些组件可能会在 build 方法中调用 update。这种情况下，如果监听器在构建阶段调用 setState，就会导致错误。

另请参阅：

  • WidgetStatesController，非 Material 版本，可与 MaterialStatesController 互换使用。
