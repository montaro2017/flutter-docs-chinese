DialogTheme 类

为 Dialog 小组件定义主题。

后代小组件通过 DialogTheme.of 获取当前的 DialogThemeData 对象。DialogThemeData 实例可通过 DialogThemeData.copyWith 自定义。

titleTextStyle 和 contentTextStyle 用于 AlertDialog 与 SimpleDialog。

另请参阅：

  • Dialog，可通过此 DialogTheme 自定义。
  • AlertDialog，可通过此 DialogTheme 自定义。
  • SimpleDialog，可通过此 DialogTheme 自定义。
  • ThemeData，用于描述应用的整体主题信息。
