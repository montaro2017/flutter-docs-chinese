ScrollbarThemeData 类

定义后代 Scrollbar widget 的默认属性值。

后代 widget 通过 ScrollbarTheme.of(context) 获取当前的 ScrollbarThemeData 对象。可以使用 ScrollbarThemeData.copyWith 自定义 ScrollbarThemeData 实例。

通常会通过 ThemeData.scrollbarTheme，将 ScrollbarThemeData 指定为整体 Theme 中 ScrollbarTheme 的一部分。

默认情况下，ScrollbarThemeData 的所有属性均为 null。属性为 null 时，Scrollbar 会自行计算默认值，通常会参考整体主题的 ThemeData.colorScheme。

另请参阅：

  • ThemeData，用于描述应用的整体主题信息。
