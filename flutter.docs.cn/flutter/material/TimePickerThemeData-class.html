TimePickerThemeData 类

定义通过 showTimePicker 显示的控件的视觉属性。

后代控件使用 TimePickerThemeData 对象，并通过 TimePickerTheme.of 获取当前主题。可使用 TimePickerThemeData 的 TimePickerThemeData.copyWith 方法自定义实例。

通常会在整体 Theme 中通过 ThemeData.timePickerTheme 指定 TimePickerThemeData。

默认情况下，TimePickerThemeData 的所有属性均为 null。为 null 时，showTimePicker 会提供自己的默认值。

另请参阅：

  • ThemeData，用于描述应用的整体主题信息。
  • TimePickerTheme, which describes the actual configuration of a time picker theme.
