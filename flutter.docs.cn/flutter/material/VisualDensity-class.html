VisualDensity 类

定义用户界面组件的视觉密度。

在 UI 中，密度指组件在垂直和水平方向上的“紧凑”程度。密度没有单位，因为它对不同 UI 组件的含义各不相同。

视觉密度的默认值在垂直和水平方向上均为零，这对应 Material Design 规范中的组件默认视觉密度。它不会影响文本大小、图标大小或内边距。

默认视觉密度因平台而异：移动平台（Android、iOS、Fuchsia）使用 VisualDensity.standard，桌面平台（macOS、Windows、Linux）使用 VisualDensity.compact。详情请参阅 defaultDensityForPlatform。

例如，对于按钮，它会影响按钮子项周围的间距；对于列表，它会影响列表条目基线之间的距离；对于芯片，它只影响垂直尺寸，不影响水平尺寸。

以下是一些会响应密度变化的小组件：

  • Checkbox
  • Chip
  • ElevatedButton
  • FilledButton
  • IconButton
  • InputDecorator（为 TextField 等组件提供密度支持）
  • ListTile
  • MaterialButton
  • OutlinedButton
  • Radio
  • RawMaterialButton
  • TextButton

另请参阅：

  • ThemeData.visualDensity，此属性用于指定 Material 组件的基础水平密度。
  • Material Design 密度指南。
