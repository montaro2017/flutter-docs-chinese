在最近的 Scaffold 祖先中显示 Material Design 底部表单。若要显示持久底部表单，请使用 Scaffold.bottomSheet。

返回一个控制器，可用于关闭底部表单或对其进行其他操作。

可传入可选的 backgroundColor、elevation、shape、clipBehavior、constraints 和 transitionAnimationController 参数，以自定义持久底部表单的外观和行为。详情请参阅 BottomSheet 文档。

enableDrag 参数用于指定是否可以上下拖动底部表单，以及是否可以向下滑动将其关闭。

sheetAnimationStyle 参数用于覆盖底部表单的动画时长和反向动画时长。

如果提供了 AnimationStyle.duration，则会在底层的 BottomSheet.createAnimationController 中用于覆盖底部表单的动画时长。

如果提供了 AnimationStyle.reverseDuration，则会在底层的 BottomSheet.createAnimationController 中用于覆盖底部表单的反向动画时长。

若要禁用底部表单动画，请使用 AnimationStyle.noAnimation。

要使用此代码示例创建本地项目，请运行：

若要重建底部表单（例如，它是有状态的），请调用此方法返回的控制器上的 PersistentBottomSheetController.setState。

新的底部表单会成为所属 ModalRoute 的 LocalHistoryEntry，并在 Scaffold 的应用栏中添加一个返回按钮，用于关闭底部表单。

若要创建不作为 LocalHistoryEntry、且不会在所属 Scaffold 应用栏中添加返回按钮的持久底部表单，请使用 Scaffold.bottomSheet 构造参数。

相关组件是模态底部表单，它可替代菜单或对话框，并会阻止用户与应用的其余部分交互。可使用 showModalBottomSheet 函数创建并显示模态底部表单。

context 参数用于查找底部表单所属的 Scaffold。它只会在调用此方法时使用，因此在关闭底部表单之前，可以安全地将对应组件从树中移除。

另请参阅：

  • BottomSheet，会成为 builder 返回的 widget 的父级。
  • showModalBottomSheet，可用于显示模态底部面板。
  • Scaffold.of，有关如何获取 BuildContext 的信息。
  • Material 2 规范。
  • Material 3 规范。
  • AnimationStyle，用于覆盖底部面板的动画时长和反向动画时长。

实现

PersistentBottomSheetController showBottomSheet({
  required BuildContext context,
  required WidgetBuilder builder,
  Color? backgroundColor,
  double? elevation,
  ShapeBorder? shape,
  Clip? clipBehavior,
  BoxConstraints? constraints,
  bool? enableDrag,
  bool? showDragHandle,
  AnimationController? transitionAnimationController,
  AnimationStyle? sheetAnimationStyle,
}) {
  assert(debugCheckHasScaffold(context));

  return Scaffold.of(context).showBottomSheet(
    builder,
    backgroundColor: backgroundColor,
    elevation: elevation,
    shape: shape,
    clipBehavior: clipBehavior,
    constraints: constraints,
    enableDrag: enableDrag,
    showDragHandle: showDragHandle,
    transitionAnimationController: transitionAnimationController,
    sheetAnimationStyle: sheetAnimationStyle,
  );
}
