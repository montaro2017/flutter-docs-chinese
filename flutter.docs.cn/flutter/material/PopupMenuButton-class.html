description

PopupMenuButton<T> 类

按下按钮时显示菜单；当用户选择菜单项并因此关闭菜单时，会调用 onSelected。传递给 onSelected 的值就是所选菜单项的值。

可以提供 child 或 icon 之一，但不能同时提供两者。如果提供了 icon，PopupMenuButton 的行为就类似 IconButton。

如果两者都为 null，则会根据平台创建标准的溢出图标。

迁移到 MenuAnchor

Material 3 提供了一个组件 MenuAnchor，对于配置为使用 Material 3 的应用，建议优先使用它（参见 ThemeData.useMaterial3）。MenuAnchor 组件的视觉效果略有不同，详情请参阅 Material 3 规范：m3.material.io/components/menus/guidelines。

MenuAnchor 组件的 API 也略有不同。MenuAnchor 是为创建从锚点展开的菜单而设计的较底层接口。

从 PopupMenuButton 迁移到 MenuAnchor 时，可以按以下步骤操作：

  1. 不再使用 PopupMenuButton.itemBuilder 构建 PopupMenuEntry 列表，而是使用接收 Widget 列表的 MenuAnchor.menuChildren。通常可以像下面的示例一样使用 MenuItemButton 列表。

  2. 不再使用 PopupMenuButton.onSelected 回调，而是通过 MenuItemButton.onPressed 属性，为每个 MenuItemButton 单独设置回调。

  3. 若要将 MenuAnchor 锚定到某个组件，可以使用 MenuAnchor.builder 返回所需组件，通常是 TextButton 或 IconButton。

  4. 你可能还需要设置 MenuItemButton 的样式，详情请参阅 MenuItemButton 文档。
