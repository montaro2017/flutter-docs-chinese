显示包含 Material Design 日期范围选择器的全屏模态对话框。

用户保存所选范围后，返回的 Future 会解析为用户选择的 DateTimeRange。用户取消对话框时则返回 null。

如果 initialDateRange 不为 null，则将其作为初始选中的日期范围。若提供此值，initialDateRange.start 必须早于或等于 initialDateRange.end。

firstDate 是允许选择的最早日期，lastDate 是允许选择的最晚日期。

如果提供了初始日期范围，initialDateRange.start 和 initialDateRange.end 都必须在 firstDate 与 lastDate 之间或等于其中之一。对于这些 DateTime 值，只比较日期部分，忽略时间字段。

currentDate 表示当前日期（即今天），会在日期网格中高亮显示。为 null 时使用 DateTime.now()。

可选参数 initialEntryMode 用于设置日期选择器的初始模式：DatePickerEntryMode.calendar（可滚动的日历月份网格）或 DatePickerEntryMode.input（两个文本输入框）。默认值为 DatePickerEntryMode.calendar。

可选参数 switchToInputEntryModeIcon 用于自定义对话框角落的图标；当 DatePickerEntryMode 为 DatePickerEntryMode.calendar 时会显示该图标。点击后会将 DatePickerEntryMode 切换为 DatePickerEntryMode.input。为 null 时使用 Icon(useMaterial3 ? Icons.edit_outlined : Icons.edit)。

可选参数 switchToCalendarEntryModeIcon 用于自定义对话框角落的图标；当 DatePickerEntryMode 为 DatePickerEntryMode.input 时会显示该图标。点击后会将 DatePickerEntryMode 切换为 DatePickerEntryMode.calendar。为 null 时使用 Icon(Icons.calendar_today)。

calendarDelegate 控制日期选择器中的日期解释、格式化和导航。提供自定义实现即可支持尼泊尔历、伊斯兰历、佛历等其他历法。默认使用 GregorianCalendarDelegate。

以下可选字符串参数可用于覆盖对话框不同部分的默认文本：

  • helpText，对话框顶部显示的标签。
  • cancelText，文本输入模式下取消按钮上的文本。
  • confirmText，文本输入模式下确定按钮上的文本。
  • saveText，全屏日历模式下保存按钮上的文本。
  • errorFormatText，输入文本不是有效日期格式时显示的提示。
  • errorInvalidText，输入文本不是可选日期时显示的提示。
  • errorInvalidRangeText，日期范围无效时显示的提示（例如开始日期晚于结束日期）。
  • fieldStartHintText，开始日期输入框为空时用于提示用户的文本。
  • fieldEndHintText，结束日期输入框为空时用于提示用户的文本。
  • fieldStartLabelText，开始日期输入框的标签。
  • fieldEndLabelText，结束日期输入框的标签。

可选参数 locale 用于设置日期选择器的区域设置。默认使用环境中由 Localizations 提供的区域设置。

可选参数 textDirection 用于设置日期选择器的文字方向（TextDirection.ltr 或 TextDirection.rtl）。默认使用环境中由 Directionality 提供的文字方向。如果 locale 和 textDirection 均不为 null，则 textDirection 会覆盖根据 locale 选定的方向。

context、barrierDismissible、barrierColor、barrierLabel、useRootNavigator 和 routeSettings 参数会传递给 showDialog；其文档说明了这些参数的用法。

可以使用 builder 参数包装对话框控件，以添加 Theme 等继承式控件。

DisplayFeature 可能会将屏幕分割为多个子屏幕。内容会显示在距离 anchorPoint 最近的子屏幕中。

如果未提供 anchorPoint，则会使用 Directionality：

  • 对于 TextDirection.ltr，anchorPoint 为 Offset.zero，内容会显示在左上方的子屏幕。
  • 对于 TextDirection.rtl，anchorPoint 为 Offset(double.maxFinite, 0)，内容会显示在右上方的子屏幕。

如果未提供 anchorPoint，且控件树中不存在 Directionality 祖先控件，则在调试模式下构建此控件时会触发断言。

状态恢复

使用此方法不会为日期范围选择器启用状态恢复。要启用状态恢复，请通过 Navigator.restorablePush 或 Navigator.restorablePushNamed 将 DateRangePickerDialog 推入导航栈。

有关状态恢复的更多信息，请参阅 RestorationManager。

在 Android 上测试状态恢复：

  1. 启用“Don't keep activities”（不保留活动）。启用后，用户离开 Android 活动时系统会立即销毁该活动。设备开启开发者选项后即可找到此设置。
  2. 在 Android 设备上运行代码示例。
  3. 在手机上的应用中创建一些内存状态，例如导航到其他屏幕。
  4. 将 Flutter 应用切换到后台，再返回应用。应用会重新启动并恢复状态。

在 iOS 上测试状态恢复：

  1. 在 Xcode 中打开 ios/Runner.xcworkspace/。
  2. （仅限 iOS 14 及更高版本）：切换到 profile 或 release 构建模式，因为不支持在 debug 模式下从主屏幕启动应用。
  3. 在 Xcode 中点击播放按钮以构建并运行应用。
  4. 在手机上的应用中创建一些内存状态，例如导航到其他屏幕。
  5. 将应用切换到后台，例如返回手机主屏幕。
  6. 在应用仍处于后台时，点击 Xcode 中的停止按钮终止应用。
  7. 在手机上重新打开应用（不要通过 Xcode 打开）。应用会重新启动并恢复状态。

此示例演示如何创建可恢复状态的 Material 日期范围选择器。通过指定 MaterialApp.restorationScopeId 启用状态恢复，并在点击按钮时使用 Navigator.restorablePush 推入 DateRangePickerDialog。

Future<DateTimeRange?> showDateRangePicker({
  required BuildContext context,
  DateTimeRange? initialDateRange,
  required DateTime firstDate,
  required DateTime lastDate,
  DateTime? currentDate,
  DatePickerEntryMode initialEntryMode = DatePickerEntryMode.calendar,
  String? helpText,
  String? cancelText,
  String? confirmText,
  String? saveText,
  String? errorFormatText,
  String? errorInvalidText,
  String? errorInvalidRangeText,
  String? fieldStartHintText,
  String? fieldEndHintText,
  String? fieldStartLabelText,
  String? fieldEndLabelText,
  Locale? locale,
  bool barrierDismissible = true,
  Color? barrierColor,
  String? barrierLabel,
  bool useRootNavigator = true,
  RouteSettings? routeSettings,
  TextDirection? textDirection,
  TransitionBuilder? builder,
  Offset? anchorPoint,
  TextInputType keyboardType = TextInputType.datetime,
  Icon? switchToInputEntryModeIcon,
  Icon? switchToCalendarEntryModeIcon,
  SelectableDayForRangePredicate? selectableDayPredicate,
  CalendarDelegate<DateTime> calendarDelegate = const GregorianCalendarDelegate(),
}) async {
  initialDateRange = initialDateRange == null ? null : calendarDelegate.datesOnly(initialDateRange);
  firstDate = calendarDelegate.dateOnly(firstDate);
  lastDate = calendarDelegate.dateOnly(lastDate);
  assert(
    !lastDate.isBefore(firstDate),
    'lastDate $lastDate must be on or after firstDate $firstDate.',
  );
  assert(
    initialDateRange == null || !initialDateRange.start.isBefore(firstDate),
    "initialDateRange's start date must be on or after firstDate $firstDate.",
  );
  assert(
    initialDateRange == null || !initialDateRange.end.isBefore(firstDate),
    "initialDateRange's end date must be on or after firstDate $firstDate.",
  );
  assert(
    initialDateRange == null || !initialDateRange.start.isAfter(lastDate),
    "initialDateRange's start date must be on or before lastDate $lastDate.",
  );
  assert(
    initialDateRange == null || !initialDateRange.end.isAfter(lastDate),
    "initialDateRange's end date must be on or before lastDate $lastDate.",
  );
  assert(
    initialDateRange == null ||
        selectableDayPredicate == null ||
        selectableDayPredicate(
          initialDateRange.start,
          initialDateRange.start,
          initialDateRange.end,
        ),
    "initialDateRange's start date must be selectable.",
  );
  assert(
    initialDateRange == null ||
        selectableDayPredicate == null ||
        selectableDayPredicate(initialDateRange.end, initialDateRange.start, initialDateRange.end),
    "initialDateRange's end date must be selectable.",
  );
  currentDate = calendarDelegate.dateOnly(currentDate ?? calendarDelegate.now());
  assert(debugCheckHasMaterialLocalizations(context));

  Widget dialog = DateRangePickerDialog(
    initialDateRange: initialDateRange,
    firstDate: firstDate,
    lastDate: lastDate,
    currentDate: currentDate,
    selectableDayPredicate: selectableDayPredicate,
    initialEntryMode: initialEntryMode,
    helpText: helpText,
    cancelText: cancelText,
    confirmText: confirmText,
    saveText: saveText,
    errorFormatText: errorFormatText,
    errorInvalidText: errorInvalidText,
    errorInvalidRangeText: errorInvalidRangeText,
    fieldStartHintText: fieldStartHintText,
    fieldEndHintText: fieldEndHintText,
    fieldStartLabelText: fieldStartLabelText,
    fieldEndLabelText: fieldEndLabelText,
    keyboardType: keyboardType,
    switchToInputEntryModeIcon: switchToInputEntryModeIcon,
    switchToCalendarEntryModeIcon: switchToCalendarEntryModeIcon,
    calendarDelegate: calendarDelegate,
  );

  if (textDirection != null) {
    dialog = Directionality(textDirection: textDirection, child: dialog);
  }

  if (locale != null) {
    dialog = Localizations.override(context: context, locale: locale, child: dialog);
  }

  return showDialog<DateTimeRange>(
    context: context,
    barrierDismissible: barrierDismissible,
    barrierColor: barrierColor,
    barrierLabel: barrierLabel,
    useRootNavigator: useRootNavigator,
    routeSettings: routeSettings,
    useSafeArea: false,
    builder: (BuildContext context) {
      return builder == null ? dialog : builder(context, dialog);
    },
    anchorPoint: anchorPoint,
  );
}
