创建一个 const SegmentedButton。

segments 至少必须包含一个分段，但建议包含 2 到 5 个。如果只需要一个分段，可考虑改用 Checkbox 或 Radio widget。如果需要超过五个选项，可考虑使用 FilterChip 或 ChoiceChip widget。

如果 onSelectionChanged 为 null，整个分段按钮会被禁用。

默认情况下，selected 只能包含一项。但如果 multiSelectionEnabled 为 true，则 selected 可以包含多项。如果 emptySelectionAllowed 为 true，则 selected 可以为空。

const SegmentedButton({

  required this.selected,
  this.onSelectionChanged,

  this.showSelectedIcon = true,
  this.selectedIcon,
  this.direction = Axis.horizontal,
}) : assert(segments.length > 0),
     assert(selected.length > 0 || emptySelectionAllowed),
     assert(selected.length < 2 || multiSelectionEnabled);
