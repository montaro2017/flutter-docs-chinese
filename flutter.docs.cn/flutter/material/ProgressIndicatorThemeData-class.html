ProgressIndicatorThemeData 类

覆盖后代 ProgressIndicator widget 的视觉属性默认值。

后代 widget 可通过 ProgressIndicatorTheme.of 获取当前的 ProgressIndicatorThemeData 对象。可使用 ProgressIndicatorThemeData.copyWith 自定义 ProgressIndicatorThemeData 实例。

通常，ProgressIndicatorThemeData 会通过 ThemeData.progressIndicatorTheme 配置为整体 Theme 的一部分。

另请参阅：

  • ProgressIndicatorTheme, an InheritedWidget that propagates the theme down its subtree.
  • ThemeData.progressIndicatorTheme, which describes the defaults for any progress indicators as part of the application's ThemeData.
