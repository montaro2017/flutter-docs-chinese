PopupMenuThemeData 类

定义用于显示弹出菜单的路由，以及 PopupMenuItem 和 PopupMenuDivider widget 的视觉属性。

后代 widget 可通过 PopupMenuTheme.of 获取当前的 PopupMenuThemeData 对象。可使用 PopupMenuThemeData.copyWith 自定义 PopupMenuThemeData 实例。

通常，PopupMenuThemeData 会通过 ThemeData.popupMenuTheme 配置为整体 Theme 的一部分。也可以使用 PopupMenuTheme 为其 widget 子树单独配置主题。

所有 PopupMenuThemeData 属性的默认值都是 null。如果其中任何属性为 null，弹出菜单就会使用自身的默认值。

另请参阅：

  • ThemeData，用于描述应用的整体主题信息。
