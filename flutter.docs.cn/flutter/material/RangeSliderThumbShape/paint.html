根据传入的状态绘制滑块形状。

context 参数表示 RangeSlider 的渲染框。

center 参数是此形状中心的绘制偏移量。该偏移量相对于 context 画布的原点。

用户开始与 RangeSlider 交互时会触发 activationAnimation 动画；用户停止与滑块交互时，动画会反向播放。

启用 RangeSlider 时会触发 enableAnimation 动画，禁用滑块时则反向播放。RangeSlider 在 RangeSlider.onChanged 非 null 时处于启用状态。滑块启用状态发生变化时，可使用此动画绘制该形状的中间帧。

当 RangeSlider.divisions 非 null 时，isDiscrete 参数为 true。此时，滑块会在轨道上绘制刻度标记。

当 RangeSlider.onChanged 为 null 时，isEnabled 参数为 false，否则为 true。为 true 时，滑块会响应输入。

如果 isOnTop 参数为 true，则会将此滑块绘制在另一个滑块之上，因为它是最近被选中的滑块。

sliderTheme 参数是分配给此形状所属 RangeSlider 的主题。

textDirection 参数可用于确定如何调整任一滑块的方向，例如为左侧和右侧滑块绘制不同的形状。

thumb 参数用于指定此方法要绘制两个滑块中的哪一个（起始或结束滑块）。

isPressed 参数可用于为选中的滑块提供额外的选中或按下状态视觉反馈，例如绘制更大的阴影。
