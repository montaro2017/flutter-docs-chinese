返回一个主要基于 Theme 的 ThemeData.textTheme 和 ThemeData.colorScheme 的 ButtonStyle，并填充了大多数非 null 值。

返回的样式可以由 style 参数覆盖，也可以由 themeStyleOf 返回的样式覆盖；某些按钮专属主题（如 TextButtonTheme 或 ElevatedButtonTheme）会提供该样式。例如，可以通过 TextButton.style 构造函数参数或 TextButtonTheme 覆盖 TextButton 子类的默认样式。

具体的按钮子类应返回一个 ButtonStyle，尽可能多地设置非 null 属性，并确保所有非 null 的 WidgetStateProperty 属性都能解析为非 null 值。

可以为 null 的属性

一些属性（例如 ButtonStyle.fixedSize）设置后会覆盖同一 ButtonStyle 中的其他值，因此允许为 null。以下汇总了此函数返回的 ButtonStyle 中允许为 null 的属性及其原因：

  • ButtonStyle.fixedSize because it would override other values in the same ButtonStyle, like ButtonStyle.maximumSize.
  • ButtonStyle.side because null is a valid value for a button that has no side. OutlinedButton returns a non-null default for this, however.
  • ButtonStyle.backgroundBuilder 和 ButtonStyle.foregroundBuilder because they would override the ButtonStyle.foregroundColor 和 ButtonStyle.backgroundColor of the same ButtonStyle.

另请参阅：

  • themeStyleOf, returns the ButtonStyle of this button's component theme.
