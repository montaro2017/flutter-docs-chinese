scaledPadding static 方法

EdgeInsetsGeometry scaledPadding(
  1. EdgeInsetsGeometry geometry1x,
  2. EdgeInsetsGeometry geometry2x,
  3. EdgeInsetsGeometry geometry3x,
  4. double fontSizeMultiplier,
)

框架供子类使用的便捷方法，根据 fontSizeMultiplier 参数返回插值后的值：

  • 0 - 1 geometry1x
  • 1 - 2 lerp(geometry1x, geometry2x, fontSizeMultiplier - 1)
  • 2 - 3 lerp(geometry2x, geometry3x, fontSizeMultiplier - 2)
  • otherwise geometry3x

当系统文字缩放设置变化时，框架会用此方法估算带文本标签按钮的默认内边距。通常会传入针对不同系统文字缩放值调整过的 geometry1x、geometry2x、geometry3x 数据，以及 TextTheme.labelLarge。geometry1xgeometry2xgeometry3x

由于历史原因，fontSizeMultiplier 参数表示 ButtonStyle 中指定的默认字号，乘以当前环境的字体缩放比例后，再除以 14.0（按钮使用的默认字号）。ButtonStyle

实现

static EdgeInsetsGeometry scaledPadding(
  EdgeInsetsGeometry geometry1x,
  EdgeInsetsGeometry geometry2x,
  EdgeInsetsGeometry geometry3x,
  double fontSizeMultiplier,
) {
  return switch (fontSizeMultiplier) {
    <= 1 => geometry1x,
    < 2 => EdgeInsetsGeometry.lerp(geometry1x, geometry2x, fontSizeMultiplier - 1)!,
    < 3 => EdgeInsetsGeometry.lerp(geometry2x, geometry3x, fontSizeMultiplier - 2)!,
    _ => geometry3x,
  };
}
