onSelected 属性

  1. @重写
ValueChanged<bool>? onSelected
final

当芯片需要在选中和未选中状态之间切换时调用。

点击芯片时，如果设置了 onSelected 回调，则会将其应用于 !selected（参见 selected）。

芯片会将新值传递给回调，但不会立即更改状态；只有父 Widget 使用新值重新构建芯片后，状态才会更新。

传递给 onSelected 的回调应调用父级 StatefulWidget 的 State.setState 方法更新状态，以便重新构建父级 Widget。

onSelected 与 TappableChipAttributes.onPressed 回调不能同时指定。

一个StatefulWidget 示例展示了如何在 InputChip 中使用 onSelected。
link 
class Wood extends StatefulWidget {
  const Wood({super.key});

  @override
  State<StatefulWidget> createState() => WoodState();
}

class WoodState extends State<Wood> {
  bool _useChisel = false;

  @override
  Widget build(BuildContext context) {
    return InputChip(
      label: const Text('Use Chisel'),
      selected: _useChisel,
      onSelected: (bool newValue) {
        setState(() {
          _useChisel = newValue;
        });
      },
    );
  }
}
