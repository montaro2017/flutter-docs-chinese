GregorianCalendarDelegate 类

CalendarDelegate 的公历实现。

公历是全球使用最广泛的民用历法。此代理根据公历系统提供标准的日期解析、格式化和导航功能。

此代理是CalendarDatePicker的默认日历系统。

另请参阅：

  • CalendarDelegate, the base class for defining custom calendars.
  • CalendarDatePicker, which uses this delegate for date selection.
