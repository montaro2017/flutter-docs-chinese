AlertDialog 类

Material Design 警告对话框。

警告对话框（也称为基本对话框）用于告知用户需要确认的情况。警告对话框可以包含可选标题和可选操作列表：标题显示在内容上方，操作显示在内容下方。

如果需要让用户从多个选项中进行选择，可考虑使用 SimpleDialog。

通常将其作为子组件传给 showDialog，由该方法显示对话框。

此代码片段展示 State 中的一个方法：调用后会显示对话框，并返回一个在对话框关闭时完成的 Future。
link 
Future<void> _showMyDialog() async {
  return showDialog<void>(
    context: context,
    barrierDismissible: false, // user must tap button!
    builder: (BuildContext context) {
      return AlertDialog(
        title: const Text('AlertDialog Title'),
        content: const SingleChildScrollView(
          child: ListBody(
            children: <Widget>[
              Text('This is a demo alert dialog.'),
              Text('Would you like to approve of this message?'),
            ],
          ),
        ),
        actions: <Widget>[
          TextButton(
            child: const Text('Approve'),
            onPressed: () {
              Navigator.of(context).pop();
            },
          ),
        ],
      );
    },
  );
}

此示例展示一个 TextButton：点击后会调用 showDialog。该方法会在应用当前内容上方显示 Material 对话框，并返回一个在对话框关闭时完成的 Future。

警告对话框与滚动

默认情况下，警告对话框会调整自身尺寸以容纳子组件。

如果内容过多，无法在屏幕垂直方向内完整显示，对话框仍会显示标题和操作，并让content溢出。这通常不是期望的效果。可考虑在 content 中使用 SingleChildScrollView 等可滚动组件，避免内容溢出。

由于对话框会根据内容调整自身尺寸，content 必须支持报告自身的固有尺寸。因此，ListView、GridView 和 CustomScrollView 等延迟渲染组件不能直接用于 AlertDialog；除非将它们包在能够强制指定尺寸的组件中，例如 SizedBox。

若要更精细地控制对话框尺寸，可直接使用 Dialog。

另请参阅：

  • SimpleDialog 负责滚动内容，但不包含 actions 操作项。
  • Dialog 是 AlertDialog 和 SimpleDialog 的基础。
  • CupertinoAlertDialog 是 iOS 风格的警告对话框。
  • showDialog 会实际显示对话框并返回其结果。
