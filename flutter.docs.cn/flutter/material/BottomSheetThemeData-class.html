BottomSheetThemeData 类

为 BottomSheet 的 Material 定义默认属性值。

后代 widget 使用 Theme.of(context).bottomSheetTheme 获取当前 BottomSheetThemeData 对象。BottomSheetThemeData 实例可以通过 BottomSheetThemeData.copyWith 自定义其实例。

通常会通过 ThemeData.bottomSheetTheme，将 BottomSheetThemeData 指定为整体 Theme 的一部分。

BottomSheetThemeData 的所有属性默认均为 null。为 null 时，BottomSheet 会使用自身的默认值。

另请参阅：

  • ThemeData, which describes the overall theme information for the application.
