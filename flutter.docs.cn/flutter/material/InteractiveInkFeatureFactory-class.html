InteractiveInkFeatureFactory 类 抽象

对 InteractiveInkFeature 构造函数的封装，供 InkWell、InkResponse 和 ThemeData 使用。

InteractiveInkFeature 实现应提供一个静态 const splashFactory 值，其类型为此类的实例。可使用 splashFactory 配置 InkWell、InkResponse 或 ThemeData。
