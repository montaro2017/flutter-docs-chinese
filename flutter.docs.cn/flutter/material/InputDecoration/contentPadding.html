contentPadding 属性

EdgeInsetsGeometry? contentPadding
final

输入装饰容器的内边距。

当 filled 为 true 时，装饰容器是填充颜色的区域；边框由 border 绘制。该区域紧邻 icon，并位于包含 helperText、errorText 和 counterText 的组件上方。

默认情况下，contentPadding 会根据 isDense 和 border 类型确定。

如果 isCollapsed 为 true，则 contentPadding 为 EdgeInsets.zero。

Material 3 默认内容内边距

当 border 的 isOutline 为 false 且 filled 为 true 时，isDense 为 true 的 contentPadding 是 EdgeInsets.fromLTRB(12, 4, 12, 4)；为 false 时是 EdgeInsets.fromLTRB(12, 8, 12, 8)。（另一种密度状态对应的间距由 isDense 决定。）

当 border 的 isOutline 为 false 且 filled 为 false 时，isDense 为 true 的 contentPadding 是 EdgeInsets.fromLTRB(0, 4, 0, 4)；为 false 时是 EdgeInsets.fromLTRB(0, 8, 0, 8)。（另一种密度状态对应的间距由 isDense 决定。）

当 border 的 isOutline 为 true 时，isDense 为 true 的 contentPadding 是 EdgeInsets.fromLTRB(12, 16, 12, 8)；为 false 时是 EdgeInsets.fromLTRB(12, 20, 12, 12)。（另一种密度状态对应的间距由 isDense 决定。）

Material 2 默认内容内边距

当 border 的 isOutline 为 false 且 filled 为 true 时，isDense 为 true 的 contentPadding 是 EdgeInsets.fromLTRB(12, 8, 12, 8)；为 false 时是 EdgeInsets.fromLTRB(12, 12, 12, 12)。（另一种密度状态对应的间距由 isDense 决定。）

当 border 的 isOutline 为 false 且 filled 为 false 时，isDense 为 true 的 contentPadding 是 EdgeInsets.fromLTRB(0, 8, 0, 8)；为 false 时是 EdgeInsets.fromLTRB(0, 12, 0, 12)。（另一种密度状态对应的间距由 isDense 决定。）

当 border 的 isOutline 为 true 时，isDense 为 true 的 contentPadding 是 EdgeInsets.fromLTRB(12, 20, 12, 12)；为 false 时是 EdgeInsets.fromLTRB(12, 24, 12, 16)。（另一种密度状态对应的间距由 isDense 决定。）
