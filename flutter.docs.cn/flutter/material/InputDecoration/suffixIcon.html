suffixIcon 属性

Widget? suffixIcon
final

显示在文本输入框可编辑区域及 suffix 或 suffixText 后方、装饰容器内部的图标。

后缀图标的尺寸和颜色会通过 IconTheme 自动配置，因此无需在图标组件中显式指定。

后缀图标的最小尺寸限制为 48px × 48px，但可以更大。尺寸超过 24px 时需要增加额外内边距，以符合 Material Design 规范：输入框右边缘与后缀图标尾缘之间应有 12px 间距。以下示例展示了如何设置后缀图标尾缘的内边距：

suffixIcon: Padding(
  padding: const EdgeInsetsDirectional.only(end: 12.0),
  child: _myIcon, // myIcon is a 48px-wide widget.
)

当 filled 为 true 时，装饰容器是填充颜色的区域；边框由 border 绘制。该区域紧邻 icon，并位于包含 helperText、errorText 和 counterText 的组件上方。

可使用具有固定 widthFactor 和 heightFactor 的 Align 更改后缀图标的对齐方式。

此示例展示如何使用具有固定 widthFactor 和 heightFactor 的 Align，调整后缀图标的对齐方式。

  • Icon 和 ImageIcon, which are typically used to show icons.
  • suffix 和 suffixText, which are other ways to show content after the text field (but before the icon).
  • prefixIcon, which is the same but on the leading edge.
  • Align A widget that aligns its child within itself and optionally sizes itself based on the child's size.
