LinearProgressIndicator 类

Material Design 线性进度指示器，也称为进度条。

沿直线显示进度的组件。线性进度指示器分为两种：

  • 确定进度。确定型进度指示器在每个时刻都有特定值，该值应从 0.0 单调递增到 1.0；达到 1.0 时，指示器即完成。若要创建确定型进度指示器，请将 value 设为 0.0 到 1.0 之间的非 null 值。
  • 不确定进度。不确定型进度指示器在每个时刻都没有特定值，而是表示进度正在进行，但不显示剩余进度。若要创建不确定型进度指示器，请将 value 设为 null。

指示线使用动画值 valueColor 显示。若要指定固定颜色值，请使用：AlwaysStoppedAnimation<Color>(color)。

可使用 minHeight 指定指示器的最小高度。也可用 SizedBox 包裹组件以增加其高度。

此示例展示了确定和不确定的 LinearProgressIndicator。当将 LinearProgressIndicator 的 LinearProgressIndicator.year2023 标志设为 false 时，指示器会采用 所示的外观。

动画同步

多个 CircularProgressIndicator 或 LinearProgressIndicator 同时在屏幕上播放动画时（例如加载项目列表），彼此不同步的动画可能显得杂乱。为解决此问题，可以使用自定义 AnimationController 驱动指示器动画。

这样可以让多个指示器同步到同一个动画源。为一组指示器实现此功能的最便捷方式，是通过 ProgressIndicatorTheme 提供控制器（参见 ProgressIndicatorThemeData.controller）。该主题子树中的所有 CircularProgressIndicator 或 LinearProgressIndicator 都会共享同一动画，从而使效果更协调、自然。

也可以直接将特定的 AnimationController 传给单个指示器的 controller 属性。

有关示例，请参阅 CircularProgressIndicator 文档。

  • RefreshIndicator, which automatically displays a CircularProgressIndicator 当底层的垂直可滚动区域滚动过界时自动显示 CircularProgressIndicator。
