DataTableSource 类 抽象

用于为 PaginatedDataTable 对象提供行数据的数据源。

数据表数据源主要提供以下两项信息：

  • 数据表中的行数（rowCount）。
  • 每一行的数据（索引范围为 0 到 rowCount - 1）。

它还提供监听器 API（addListener/removeListener），以便数据使用方在数据变化时收到通知。数据发生变化时，调用 notifyListeners 发送通知。

DataTableSource 对象应长期存在，不要在每次构建时重新创建。

如果 DataTableSource 与支持可排序列的 PaginatedDataTable 一起使用（参见 DataColumn.onSort 和 PaginatedDataTable.sortColumnIndex），数据源返回的行必须按排序后的顺序排列。
