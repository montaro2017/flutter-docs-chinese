在 position 处显示一个包含 items 的弹出菜单。

items 参数不能为空。

position 和 positionBuilder 只能提供其中一个。两者都提供会触发断言错误。菜单显示时会调用 positionBuilder 计算位置，并在每次布局更新时再次调用；当需要根据当前布局在运行时确定位置时，这很有用。

如果指定了 initialValue，则第一个值匹配的菜单项会高亮显示；position 的矩形区域垂直中心会尽可能与该高亮项的垂直中心对齐。

如果未指定 initialValue，菜单顶部会与 position 矩形区域的顶部对齐。

在这两种情况下，如有必要，都会调整菜单位置以确保其显示在屏幕内。

在水平方向上，菜单会朝空间较大的一侧展开。例如，如果 position 表示屏幕左边缘处的矩形，菜单左边缘就会与该 position 矩形的左边缘对齐，并向右展开。如果 position 矩形区域的两侧到屏幕相对边缘的距离相等，则使用当前的 Directionality 作为平局判定依据，优先朝阅读方向展开。

通过遍历 items，找到第一个满足 PopupMenuEntry.represents 方法对 initialValue 的判断的菜单项，从而确定 initialValue 在 position 处的位置；随后将列表中该项之前所有组件的 PopupMenuEntry.height 值相加。

elevation 参数指定菜单所在的 z 坐标。默认值为 8，这是弹出菜单的合适高度。

context 参数用于查找菜单对应的 Navigator 和 Theme。它只会在调用此方法时使用，因此在关闭弹出菜单之前，可以安全地将对应组件从树中移除。

useRootNavigator 参数用于确定将菜单推送到距离给定 context 最远还是最近的 Navigator。默认值为 false。

semanticLabel 参数供无障碍框架在菜单打开和关闭时播报屏幕转场。如果未提供此标签，则默认使用 MaterialLocalizations.popupMenuLabel。

clipBehavior 参数用于裁剪菜单形状。默认值为 Clip.none。

requestFocus 参数用于指定菜单显示时是否应请求焦点。如果该值为 null，则改用 Navigator.requestFocus。

另请参阅：

  • PopupMenuItem, a popup menu entry for a single value.
  • PopupMenuDivider, a popup menu entry that is just a horizontal line.
  • CheckedPopupMenuItem, a popup menu item with a checkmark.
  • PopupMenuButton, which provides an IconButton that shows a menu by calling this method automatically.
  • SemanticsConfiguration.namesRoute, for a description of edge triggered semantics.

实现

Future<T?> showMenu<T>({
  required BuildContext context,
  RelativeRect? position,
  PopupMenuPositionBuilder? positionBuilder,
  required List<PopupMenuEntry<T>> items,
  T? initialValue,
  double? elevation,
  Color? shadowColor,
  Color? surfaceTintColor,
  String? semanticLabel,
  ShapeBorder? shape,
  EdgeInsetsGeometry? menuPadding,
  Color? color,
  bool useRootNavigator = false,
  BoxConstraints? constraints,
  Clip clipBehavior = Clip.none,
  RouteSettings? routeSettings,
  AnimationStyle? popUpAnimationStyle,
  bool? requestFocus,
}) {
  assert(items.isNotEmpty);
  assert(debugCheckHasMaterialLocalizations(context));
  assert(
    (position != null) != (positionBuilder != null),
    'Either position or positionBuilder must be provided.',
  );

  switch (defaultTargetPlatform) {
    case TargetPlatform.iOS:
    case TargetPlatform.macOS:
      break;
    case TargetPlatform.android:
    case TargetPlatform.fuchsia:
    case TargetPlatform.linux:
    case TargetPlatform.windows:
      semanticLabel ??= MaterialLocalizations.of(context).popupMenuLabel;
  }

  final menuItemKeys = List<GlobalKey>.generate(items.length, (int index) => GlobalKey());
  final NavigatorState navigator = Navigator.of(context, rootNavigator: useRootNavigator);
  return navigator.push(
    _PopupMenuRoute<T>(
      position: position,
      positionBuilder: positionBuilder,
      items: items,
      itemKeys: menuItemKeys,
      initialValue: initialValue,
      elevation: elevation,
      shadowColor: shadowColor,
      surfaceTintColor: surfaceTintColor,
      semanticLabel: semanticLabel,
      barrierLabel: MaterialLocalizations.of(context).menuDismissLabel,
      shape: shape,
      menuPadding: menuPadding,
      color: color,
      capturedThemes: InheritedTheme.capture(from: context, to: navigator.context),
      constraints: constraints,
      clipBehavior: clipBehavior,
      settings: routeSettings,
      popUpAnimationStyle: popUpAnimationStyle,
      requestFocus: requestFocus,
    ),
  );
}
