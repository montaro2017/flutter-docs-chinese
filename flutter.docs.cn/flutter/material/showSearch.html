showSearch<T> function

Future<T?> showSearch<T>({
  1. required BuildContext context,
  2. required SearchDelegate<T> delegate,
  3. String? query = '',
  4. bool useRootNavigator = false,
  5. bool maintainState = false,
})

显示全屏搜索页面，并在页面关闭时返回用户选择的搜索结果。

搜索页面包含一个带搜索框的应用栏，以及一个可显示搜索建议或搜索结果的主体区域。

搜索页面的外观由提供的 delegate 决定。初始查询字符串由 query 提供，默认值为空字符串。如果 query 为 null，则使用 delegate.query 作为初始查询。

此方法返回选中的搜索结果，该结果可通过调用 SearchDelegate.close 设置。如果使用系统返回按钮关闭搜索页面，则返回 null。

一个 SearchDelegate 同一时间只能关联一个处于活动状态的 showSearch 调用。再次使用同一个 delegate 实例调用 showSearch 之前，请先调用 SearchDelegate.close。

useRootNavigator 参数用于确定将搜索页面推送到距离给定 context 最远还是最近的 Navigator。默认情况下，useRootNavigator 为 false，此方法会将搜索页面路由推送到距离给定 context 最近的 Navigator。该参数不能为 null。

maintainState 参数用于确定路由在非活动状态时是否应保留在内存中（详情请参阅 ModalRoute.maintainState）。默认情况下，maintainState 为 false。

此方法触发的搜索页面转场效果，在触发转场的屏幕顶部包含 AppBar，且从属于 AppBar.actions 的 IconButton 调用时效果最佳。可以使用 SearchDelegate.transitionAnimation 提供的动画，在搜索页面淡入或淡出时触发底层页面上的其他动画。常见做法是在 AppBar.leading 位置为 AnimatedIcon 添加动画，例如从汉堡菜单图标切换为退出搜索页面所用的返回箭头。

处理表情符号和其他复杂字符

处理可能包含复杂字符的用户输入时，务必使用 characters。这样可以确保扩展字素簇和代理项对按用户所见被视为单个字符。

例如，获取用户输入长度时，请使用 string.characters.length。不要使用 string.length，也不要使用 string.runes.length。复杂字符“👨‍👩‍👦”在用户看来是一个字符，因此 string.characters.length 会直观地返回 1；而 string.length 会返回 8，string.runes.length 会返回 5！

另请参阅：

  • SearchDelegate to define the content of the search page.

实现

Future<T?> showSearch<T>({
  required BuildContext context,
  required SearchDelegate<T> delegate,
  String? query = '',
  bool useRootNavigator = false,
  bool maintainState = false,
}) {
  delegate.query = query ?? delegate.query;
  delegate._currentBody = _SearchBody.suggestions;
  return Navigator.of(
    context,
    rootNavigator: useRootNavigator,
  ).push(_SearchPageRoute<T>(delegate: delegate, maintainState: maintainState));
}
