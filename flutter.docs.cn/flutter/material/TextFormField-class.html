TextFormField 类

一个包含 TextField 的 FormField。

这是一个便捷组件，会将 TextField 包装在 FormField 中。

不要求存在 Form 祖先组件。Form 可用于一次性保存、重置或验证多个字段。若不使用 Form，可将 GlobalKey<FormFieldState>（参阅 GlobalKey）传给构造函数，再通过 GlobalKey.currentState 保存或重置表单字段。

指定 controller 后，其 TextEditingController.text 会作为 initialValue。如果此 FormField 位于会延迟创建子项的滚动容器中（例如 ListView 或 CustomScrollView），则应指定 controller。其生命周期应由滚动容器的有状态祖先组件管理。

如果未指定 controller，可使用 initialValue 为自动创建的控制器设置初始值。

组件获得焦点时，会通过底层 EditableText 的 AutomaticKeepAliveClientMixin.wantKeepAlive 暂缓销毁，以避免丢失选区。移除焦点后即可销毁。

不再需要 TextEditingController 时，请调用 TextEditingController.dispose，以释放该对象使用的资源。

默认情况下，decoration 会将当前环境中的 InputDecorationThemeData 应用于 InputDecoration。详情请参阅 InputDecoration.applyDefaults。

各种参数的说明请参阅 TextField 文档。

创建带有 InputDecoration 和验证器函数的 TextFormField。

link 
TextFormField(
  decoration: const InputDecoration(
    icon: Icon(Icons.person),
    hintText: 'What do people call you?',
    labelText: 'Name *',
  ),
  onSaved: (String? value) {
    // This optional block of code can be used to run
    // code when the user saves the form.
  },
  validator: (String? value) {
    return (value != null && value.contains('@')) ? 'Do not use the @ char.' : null;
  },
)
