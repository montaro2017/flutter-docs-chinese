MaterialApp 类

使用 Material Design 的应用。

一个便捷组件，封装 Material Design 应用通常需要的多个组件。它基于 WidgetsApp，添加 Material Design 特有的功能，例如 AnimatedTheme 和 GridPaper。

MaterialApp 将 WidgetsApp.textStyle 配置为醒目的红黄文字样式，用于警告开发者应用尚未定义默认文字样式。通常，应用的 Scaffold 会构建 Material 组件，其默认 Material.textStyle 定义整个 Scaffold 的文字样式。

MaterialApp 配置顶层 Navigator，按以下顺序查找路由：

  1. 对于 / 路由，如果 home 属性非 null，则使用它。

  2. 否则，如果 routes 表包含该路由的条目，则使用该条目。

  3. 否则，如果提供了 onGenerateRoute，则调用它。对于未由 home 和 routes 处理的任何有效路由，它应返回非 null 值。

  4. 最后，如果其他方式均失败，则调用 onUnknownRoute。

如果创建了 Navigator，上述选项中至少一个必须能处理 / 路由，因为启动时指定无效 initialRoute 时会使用它（例如，在 Android 上另一个应用通过 intent 启动此应用；参见 dart:ui.PlatformDispatcher.defaultRouteName）。

此组件还会配置顶层 Navigator（如果存在）的观察器，以执行 Hero 动画。

MaterialApp 自动创建 DefaultSelectionStyle。如果 ThemeData.textSelectionTheme 中的颜色非 null，则使用这些颜色；否则，MaterialApp 将 DefaultSelectionStyle.selectionColor 设为不透明度为 0.4 的 ColorScheme.primary，并将 DefaultSelectionStyle.cursorColor 设为 ColorScheme.primary。

如果 home、routes、onGenerateRoute 和 onUnknownRoute 均为 null，而 builder 非 null，则不创建 Navigator。

此示例展示如何创建一个 MaterialApp ，并禁用“debug”横幅，然后设置 home 路由，该路由会在应用启动时显示。

link 
MaterialApp(
  home: Scaffold(
    appBar: AppBar(
      title: const Text('Home'),
    ),
  ),
  debugShowCheckedModeBanner: false,
)

此示例展示如何创建一个 MaterialApp ，使用 routes Map 来定义“home”路由和“about”路由。
link 
MaterialApp(
  routes: <String, WidgetBuilder>{
    '/': (BuildContext context) {
      return Scaffold(
        appBar: AppBar(
          title: const Text('Home Route'),
        ),
      );
    },
    '/about': (BuildContext context) {
      return Scaffold(
        appBar: AppBar(
          title: const Text('About Route'),
        ),
      );
     }
   },
)

此示例展示如何创建一个 MaterialApp ，并定义一个 theme ，供应用中的 Material widget 使用。

link 
MaterialApp(
  theme: ThemeData(
    brightness: Brightness.dark,
    primaryColor: Colors.blueGrey
  ),
  home: Scaffold(
    appBar: AppBar(
      title: const Text('MaterialApp Theme'),
    ),
  ),
)

问题排查

为什么应用文字是红色并带有黄色下划线？

缺少 Material 祖先组件的 Text 组件会以醒目的红黄文字样式渲染。

通常的解决方式是为组件提供 Scaffold 祖先组件。Scaffold 会创建定义默认文字样式的 Material 组件。

const MaterialApp(
  title: 'Material App',
  home: Scaffold(
    body: Center(
      child: Text('Hello World'),
    ),
  ),
)

另请参阅：

  • Scaffold，提供标准应用元素，例如 AppBar 和 Drawer。
  • Navigator，用于管理应用的页面栈。
  • MaterialPageRoute，定义以 Material 特有方式过渡的应用页面。
  • WidgetsApp，定义基本应用元素，不依赖 Material 库。
  • Flutter 国际化教程：flutter.dev/to/internationalization/。
