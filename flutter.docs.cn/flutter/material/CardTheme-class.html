CardTheme 类

为后代 Card widget 定义默认属性值。

后代 widget 使用 CardTheme.of 获取当前的 CardThemeData 对象。可以通过 CardThemeData.copyWith 自定义 CardThemeData 实例。

通常会通过整体 Theme 的 ThemeData.cardTheme 指定 CardThemeData。

默认情况下，所有 CardThemeData 属性均为 null。值为 null 时，Card 会在 ThemeData 有对应值时使用该值，否则使用自身的默认值。

另请参阅：

  • ThemeData, which describes the overall theme information for the application.
