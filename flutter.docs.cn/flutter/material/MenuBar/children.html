children 属性

List<Widget> children
final

作为 MenuBar 顶层子项的菜单项列表。

Flutter 中的 Widget 不可变，因此直接通过 List 等 API 修改 children（例如 someMenuBarWidget.menus.add(...)）会导致行为异常。每次修改菜单列表时，都必须提供一个新列表对象。

使用 MenuItemButton 的菜单可以为其 MenuItemButton.shortcut 指定 SingleActivator 或 CharacterActivator，以显示相应的快捷键提示。快捷键标签虽然显示在菜单中，但快捷键不会自动处理。必须在适用的上下文中启用快捷键，并通过其他机制处理。

如果要全局启用快捷键，但不方便在菜单栏外围的上下文中定义，可以考虑通过 ShortcutRegistry 注册（WidgetsApp 已包含一个，因此 MaterialApp 和 CupertinoApp 也包含），如下面示例所示。为确保选择菜单项和触发快捷键执行相同操作，建议两者调用同一个回调。

此示例展示了一个 MenuBar ，其中包含一个顶层菜单和三个菜单项：“About”、用于显示消息的复选框菜单项以及“Quit”。这些菜单项由枚举值标识，快捷键则通过 ShortcutRegistry.
