BottomNavigationBar 类

显示在应用底部的 Material widget，用于在少量视图之间进行选择，通常为三个至五个。

此组件已有更新版本 NavigationBar；新应用以及配置为使用 Material 3 的应用优先使用该版本（参见 ThemeData.useMaterial3）。

底部导航栏由多个条目组成，每个条目包含文字标签、图标或两者，并排列在 Material 表面上。它可以在应用的顶层视图之间提供快速导航。对于更大的屏幕，侧边导航可能更合适。

底部导航栏通常与 Scaffold 搭配使用，并通过 Scaffold.bottomNavigationBar 参数传入。

底部导航栏的 type 会改变 items 的显示方式。如果未指定条目类型，则条目少于四个时自动设为 BottomNavigationBarType.fixed，否则设为 BottomNavigationBarType.shifting。

items 至少必须包含两个条目，并且每个条目的图标和标签都不能为空。

  • BottomNavigationBarType.fixed：items 少于四个时的默认类型。如果 selectedItemColor 不为 null，则使用该颜色渲染选中项目，否则在 Brightness.light 主题中使用主题的 ColorScheme.primary 颜色，在 Brightness.dark 主题中使用 ColorScheme.secondary。如果 backgroundColor 为 null，导航栏的背景颜色默认为 Material 的背景颜色 ThemeData.canvasColor（基本上是不透明白色）。
  • BottomNavigationBarType.shifting：items 为四个或更多时的默认类型。如果 selectedItemColor 为 null，所有项目均以白色渲染。导航栏的背景颜色与所选项目的 BottomNavigationBarItem.backgroundColor 相同。此时假定每个项目都具有不同的背景颜色，且该颜色与白色之间具有良好的对比度。

迁移到 NavigationBar

NavigationBar 组件的视觉效果略有不同，更多详情请参阅 Material 3 规范：m3.material.io/components/navigation-bar/overview。

NavigationBar 组件的 API 也略有不同。要从 BottomNavigationBar 迁移到 NavigationBar，需要进行以下更改。

  1. 将接收 BottomNavigationBarItem 列表的 BottomNavigationBar.items 替换为接收组件列表的 NavigationBar.destinations。通常使用 NavigationDestination 组件列表。与 BottomNavigationBarItem 一样，NavigationDestination 也具有标签和图标字段。

  2. 将 BottomNavigationBar.onTap 替换为 NavigationBar.onDestinationSelected，它同样是在用户轻触导航栏项目时调用的回调。

  3. 将 BottomNavigationBar.currentIndex 替换为 NavigationBar.selectedIndex，它同样是一个整数，表示所选目标的索引。

  4. 你可能还需要调整 NavigationBar 的样式，更多详情请参阅 NavigationBar 构造函数中的属性。
