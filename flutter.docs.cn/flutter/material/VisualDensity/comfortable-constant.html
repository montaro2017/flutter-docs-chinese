VisualDensity const comfortable

对 VisualDensity 作“舒适”解释时使用的配置。

各个组件会独立解释密度值，并根据 Material Design 规范中针对各自用例的“舒适”设置，以不同程度呈现比 standard 更紧凑、比 compact 更宽松的视觉效果。

它在两个轴上的密度值均为 -1。

实现

static const VisualDensity comfortable = VisualDensity(horizontal: -1.0, vertical: -1.0);
