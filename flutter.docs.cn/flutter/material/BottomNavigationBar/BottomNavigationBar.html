创建底部导航栏，通常作为 Scaffold 的 Scaffold.bottomNavigationBar 参数。

items 至少必须包含两个条目，并且每个条目的图标和标签都不能为空。

如果 type 为 null，则有两个或三个 items 时使用 BottomNavigationBarType.fixed，否则使用 BottomNavigationBarType.shifting。

iconSize、selectedFontSize、unselectedFontSize 和 elevation 参数必须为非负数。

如果 selectedLabelStyle.color 和 unselectedLabelStyle.color 均不为 null，则它们会代替 selectedItemColor 和 unselectedItemColor 使用。

如果使用自定义 IconThemeData，必须同时提供 selectedIconTheme 和 unselectedIconTheme，并且必须设置 IconThemeData.color 和 IconThemeData.size。

如果将 useLegacyColorScheme 设为 false，选中图标会使用 selectedIconTheme 的值，而不是 iconSize 和 selectedItemColor；未选中图标会使用 unselectedIconTheme 的值，而不是 iconSize 和 unselectedItemColor。

如果同时设置了 selectedLabelStyle.fontSize 和 selectedFontSize，则使用 selectedLabelStyle.fontSize。

selectedItemColor 和 fixedColor 只能指定其中一个。建议使用前者，fixedColor 仅为向后兼容而保留。

如果 showSelectedLabels 为 null，则使用 BottomNavigationBarThemeData.showSelectedLabels。如果 BottomNavigationBarThemeData.showSelectedLabels 为 null，则 showSelectedLabels 默认为 true。

如果 showUnselectedLabels 为 null，则使用 BottomNavigationBarThemeData.showUnselectedLabels。如果 BottomNavigationBarThemeData.showSelectedLabels 为 null，则当 type 为 BottomNavigationBarType.fixed 时，showUnselectedLabels 默认为 true；当 type 为 BottomNavigationBarType.shifting 时，默认为 false。

BottomNavigationBar({
  super.key,
  required this.items,
  this.onTap,
  this.currentIndex = 0,
  this.elevation,
  this.type,
  Color? fixedColor,
  this.backgroundColor,
  this.iconSize = 24.0,
  Color? selectedItemColor,
  this.unselectedItemColor,
  this.selectedIconTheme,
  this.unselectedIconTheme,
  this.selectedFontSize = 14.0,
  this.unselectedFontSize = 12.0,
  this.selectedLabelStyle,
  this.unselectedLabelStyle,
  this.showSelectedLabels,
  this.showUnselectedLabels,
  this.mouseCursor,
  this.enableFeedback,
  this.landscapeLayout,
  this.useLegacyColorScheme = true,
}) : assert(items.length >= 2),
     assert(
       items.every((BottomNavigationBarItem item) => item.label != null),
       'Every item must have a non-null label',
     ),
     assert(0 <= currentIndex && currentIndex < items.length),
     assert(elevation == null || elevation >= 0.0),
     assert(iconSize >= 0.0),
     assert(
       selectedItemColor == null || fixedColor == null,
       'Either selectedItemColor or fixedColor can be specified, but not both',
     ),
     assert(selectedFontSize >= 0.0),
     assert(unselectedFontSize >= 0.0),
     selectedItemColor = selectedItemColor ?? fixedColor;
