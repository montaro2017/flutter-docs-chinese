NavigationRail 类

一种 Material Design 组件，通常显示在应用左侧或右侧，用于在少量视图（通常为三到五个）之间导航。

导航轨道适用于宽视口布局，例如桌面网页或平板横屏布局。对于较小的布局（例如手机竖屏），应改用 BottomNavigationBar。

导航轨道通常作为定义应用 Scaffold 主体的 Row 的第一个或最后一个元素。

应用中所有 NavigationRail 的外观可通过 NavigationRailTheme 指定。主题属性为 null 时，其默认值基于 Theme 的 ThemeData.textTheme、ThemeData.iconTheme 和 ThemeData.colorScheme。

自适应布局可以构建不同的 Scaffold 实例，以便在较宽的布局中使用导航轨道，在较窄的布局中使用底部导航栏。示例请参阅 the adaptive_scaffold.dart sample。

此示例展示如何在 Scaffold 中创建 NavigationRail，其中包含三个 NavigationRailDestination，如 https://m3.material.io/components/navigation-rail/overview 所述。

  • NavigationRailDestination, which is used as a model to create tappable destinations in the navigation rail.
  • BottomNavigationBar, which is a similar navigation widget that's laid out horizontally.
