AppBarThemeData 类

为后代 AppBar widget 定义默认属性值。

后代控件通过 AppBarThemeData 的 AppBarTheme.of 获取当前主题配置。可以使用 AppBarThemeData 对象的 AppBarThemeData.copyWith 方法自定义该对象。

通常会通过 ThemeData.appBarTheme，将 AppBarThemeData 指定为整体 Theme 的一部分。

AppBarThemeData 的所有属性默认均为 null。属性为 null 时，AppBar 会优先采用 ThemeData 中提供的值；如果没有，则使用自身默认值。详情请参阅各个 AppBar 属性。

另请参阅：

  • AppBar, which is the widget that this theme configures.
  • ThemeData，用于描述应用的整体主题信息。
