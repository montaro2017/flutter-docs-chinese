GappedSliderTrackShape 类

Slider 的带间隙轨道形状。

GappedSliderTrackShape由激活轨道和非激活轨道组成。激活轨道使用SliderThemeData.activeTrackColor，非激活轨道使用SliderThemeData.inactiveTrackColor。

轨道形状的外侧拐角采用圆弧半径，内侧拐角的半径为 2 像素。

激活轨道与非激活轨道之间的间隙大小由SliderThemeData.trackGap决定。 如果SliderThemeData.thumbShape 为 HandleThumbShape，并且拇指处于按压状态，则拇指宽度会缩小，因此GappedSliderTrackShape的轨道间隙也会缩小。

如果SliderThemeData.trackGap 为 null，则轨道间隙的默认大小为 6 像素。

这是Slider的默认轨道形状。如果ThemeData.useMaterial3 为 false， 则默认轨道形状为RoundedRectSliderTrackShape。

另请参阅：

  • Slider, which includes an overlay defined by this shape.
  • SliderTheme, which can be used to configure the overlay shape of all sliders in a widget subtree.
