automaticallyImplyActions 属性

bool automaticallyImplyActions
final

控制当 actions widget 为 null 时，是否尝试自动推断该 widget。

如果 AppBar.actions 为 null 或为空，且此值为 true，则尝试自动推断应使用的 actions widget。如果此值为 false，则当 AppBar.actions 为 null 或为空时，actions widget 列表保持为空。如果 AppBar.actions 不为 null，此参数不起作用。
