SearchViewThemeData 类

定义由 SearchAnchor 控件创建的搜索视图配置。

后代控件通过 SearchViewTheme.of 获取当前的 SearchViewThemeData 对象。

通常会通过 ThemeData.searchViewTheme，将 SearchViewThemeData 指定为整体 Theme 的一部分。也可以使用 SearchViewTheme 配置其自身的控件子树。

默认情况下，SearchViewThemeData 的所有属性均为 null。如果其中任何属性为 null，搜索视图会使用自身的默认值。

另请参阅：

  • ThemeData, which describes the overall theme for the application.
  • SearchBarThemeData, which describes the theme for the search bar itself in a SearchBar widget.
  • SearchAnchor, which is used to open a search view route.
