description

TableRowInkWell 类

Material 中可响应触摸的矩形区域，但会将墨水飞溅效果裁剪到最近表格中的当前行。

必须位于 Material 小组件后代中才能产生墨水反馈，并且必须位于 Table 小组件后代中才能确定表格行。

TableRowInkWell 必须与 Table 位于相同的坐标空间中（允许平移）。如果它发生旋转、缩放或其他变换，就无法在自身坐标系中用 Rect 描述行矩形，因此不会显示飞溅效果。（通常很容易做到这一点：只需将 TableRowInkWell 直接放在 Table 中，并将单元格的其他内容放入其中。）

另请参阅：

  • DataTable, which makes use of TableRowInkWell when DataRow.onSelectChanged is defined and DataCell.onTap is not.
