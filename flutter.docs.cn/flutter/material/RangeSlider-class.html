RangeSlider 类

Material Design 范围滑块。

用于从一系列数值中选择一个范围。

由于范围滑块有 5 个刻度、范围为 0 到 100，因此数值间隔为 20，也就是分为 0、20、40、60、80 和 100。本示例将范围值初始化为 40 和 80。

link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.RangeSlider.1 mysample

范围滑块可用于从连续或离散的数值集合中进行选择。默认使用从 min 到 max 的连续数值范围。若要使用离散值，请为 divisions 指定非 null 值，以表示离散区间的数量。例如，若 min 为 0.0、max 为 50.0 且 divisions 为 5，则滑块可取 0.0、10.0、20.0、30.0、40.0 和 50.0 这些离散值。

滑块各部分的名称如下：

  • The "thumbs", which are the shapes that slide horizontally when the user drags them to change the selected range.
  • The "track", which is the horizontal line that the thumbs can be dragged along.
  • The "tick marks", which mark the discrete values of a discrete slider.
  • The "overlay", which is a highlight that's drawn over a thumb in response to a user tap-down gesture.
  • “值指示器”是用户拖动滑块时弹出的形状，用于显示当前选定的值。
  • The "active" segment of the slider is the segment between the two thumbs.
  • The "inactive" slider segments are the two track intervals outside of the slider's thumbs.

如果 onChanged 为 null，或 min..max 表示的范围为空（即 min 等于 max），范围滑块就会被禁用。

范围滑块 widget 本身不维护状态。滑块状态改变时，widget 会调用 onChanged 回调。大多数使用范围滑块的 widget 都会监听 onChanged 回调，并用新的 values 重新构建滑块，以更新其外观。若要获知数值何时开始变化或何时变化结束，请设置可选回调 onChangeStart 和/或 onChangeEnd。

默认情况下，滑块会尽可能宽，并在垂直方向居中。约束无界时，它会尝试将轨道宽度设为 144 像素（包括两侧边距），并在垂直方向紧贴内容。

其某个祖先必须是 Material widget。通常由 Scaffold widget 提供。

其某个祖先必须是 MediaQuery widget。通常由应用 widget 树顶部的 MediaQuery widget（例如 MaterialApp） 或 WidgetsApp widget 引入。

滑块会使用 widget 树中其上方的 SliderTheme widget 或 Theme widget 内 ThemeData.sliderTheme 提供的 SliderThemeData，以确定显示方式（例如颜色、滑块形状等）。也可以通过 activeColor 和 inactiveColor 属性覆盖部分颜色；若要更精细地控制颜色及其他视觉属性，请使用 SliderThemeData。

另请参阅：

  • SliderTheme 和 SliderThemeData for information about controlling the visual appearance of the slider.
  • Slider, for a single-valued slider.
  • Radio, for selecting among a set of explicit values.
  • Checkbox 和 Switch, for toggling a particular value on or off.
  • material.io/design/components/sliders.html
  • MediaQuery, from which the text scale factor is obtained.
