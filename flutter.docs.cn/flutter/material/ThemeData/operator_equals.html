重写

相等运算符。

所有 Object 的默认行为都是：仅当此对象与 other 是同一个对象时才返回 true。

重写此方法可以为类指定不同的相等关系，但该关系仍必须满足等价关系，也就是说必须满足以下条件：

  • 完备性：对所有参数都必须返回布尔值，且不应抛出异常。

  • 自反性：对所有对象 o，o == o 都必须为 true。

  • 对称性：对所有对象 o1 和 o2，o1 == o2 与 o2 == o1 必须同时为 true 或同时为 false。

  • 传递性：对所有对象 o1、o2 和 o3，若 o1 == o2 且 o2 == o3 为 true，则 o1 == o3 也必须为 true。

此方法还应随时间保持一致：只有至少一个对象发生更改时，两个对象是否相等才应改变。

如果子类重写了相等运算符，也应重写 hashCode 方法，以保持一致性。
