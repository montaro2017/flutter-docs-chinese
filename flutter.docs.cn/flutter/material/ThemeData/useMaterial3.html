useMaterial3 属性

bool useMaterial3
final

用于选择退出 Material 3 特性的临时标志。

此标志默认为 true。若为 false，组件会继续使用 Material 2 的颜色、排版和其他特性。

长远来看，此标志将被弃用，最终只支持 Material 3。我们建议应用在条件允许时尽快迁移到 Material 3。迁移完成前，可以将此标志设为 false。

默认值

如果构造 ThemeData 时将 useMaterial3 设为 true，部分属性会采用更新后的默认值。不过，在 ThemeData.copyWith 中将 useMaterial3 设为 true，不会改变生成的 ThemeData 中这些属性的值。

Property Material 3 default Material 2 default
colorScheme M3 baseline light color scheme M2 baseline light color scheme
typography Typography.material2021 Typography.material2014
splashFactory InkSparkle* or InkRipple InkSplash

* 如果目标平台为 Android 且应用未运行在 Web 上；否则会回退为 InkRipple。

如果 brightness 为 Brightness.dark，默认配色方案将根据 useMaterial3，采用 M3 或 M2 基线深色配色方案。

受影响的组件

此标志会影响样式和组件。

样式

  • 颜色：ColorScheme, Material (see table above)
  • 形状：（参见下方组件）
  • 排版：Typography (see table above)

组件

  • 徽标：Badge
  • 底部应用栏：BottomAppBar
  • 底部工作表：BottomSheet
  • 按钮
    • 常用按钮：ElevatedButton, FilledButton, FilledButton.tonal, OutlinedButton, TextButton
    • 浮动操作按钮：FloatingActionButton, FloatingActionButton.extended
    • 图标按钮：IconButton, IconButton.filled (新增), IconButton.filledTonal, IconButton.outlined
    • 分段按钮：SegmentedButton (replacing ToggleButtons)
  • 卡片：Card
  • 复选框：Checkbox, CheckboxListTile
  • 芯片：
    • ActionChip（用于辅助和建议芯片），
    • FilterChip, ChoiceChip（用于单选筛选芯片），
    • InputChip
  • 日期选择器：showDatePicker, showDateRangePicker, DatePickerDialog, DateRangePickerDialog, InputDatePickerFormField
  • 对话框：AlertDialog, Dialog.fullscreen
  • 分隔线：Divider, VerticalDivider
  • 列表：ListTile
  • 菜单：MenuAnchor, DropdownMenu, MenuBar
  • 导航栏：NavigationBar (replacing BottomNavigationBar)
  • 导航抽屉：NavigationDrawer (replacing Drawer)
  • 导航栏轨道：NavigationRail
  • 进度指示器：CircularProgressIndicator, LinearProgressIndicator
  • 单选按钮：Radio, RadioListTile
  • 搜索：SearchBar, SearchAnchor,
  • 提示条：SnackBar
  • 滑块：Slider, RangeSlider
  • 开关：Switch, SwitchListTile
  • 标签页：TabBar, TabBar.secondary
  • 文本字段：TextField以及其 InputDecoration
  • 时间选择器：showTimePicker, TimePickerDialog
  • 顶部应用栏：AppBar, SliverAppBar, SliverAppBar.medium, SliverAppBar.large

此外，此标志还会启用 Android 12 引入的功能。

  • 拉伸式过度滚动：MaterialScrollBehavior
  • 波纹：splashFactory (see table above)

另请参阅：

  • Material 3 specification.
