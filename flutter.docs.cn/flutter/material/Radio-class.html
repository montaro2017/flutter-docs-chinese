Radio<T> 类

Material Design 单选按钮。

此 widget 会构建一个带有 Material 样式界面的 RawRadio。

用于从多个互斥值中进行选择。选中某个分组中的单选按钮后，该组内其他按钮将取消选中。值的类型为 T，即 Radio 类的类型参数。通常会使用枚举表示这些值。

此 widget 通常有一个 RadioGroup 祖先，该祖先接收 RadioGroup.groupValue；其下与之匹配的 value 对应的 Radio 会被选中。

下面示例展示了用 ListTile 包装 Radio widget 的用法，效果类似于使用 RadioListTile widget。

当前选中的字符会传入 RadioGroup.groupValue，其值由示例的 State 维护。在此例中，第一个 Radio 初始时会被选中，因为 _character 初始化为 SingingCharacter.lafayette。

按下第二个单选按钮后，示例会通过 setState 更新状态，将 _character 更新为 SingingCharacter.jefferson。这会使按钮使用更新后的 RadioGroup.groupValue 重新构建，因此第二个按钮会被选中。

它的某个祖先必须是 Material widget。
