IconButton 类

Material Design 图标按钮。

图标按钮是在Material Widget 上显示的一张图片；用户触摸时，它会以颜色（墨水效果）填充响应。

图标按钮常用于AppBar.actions 字段，也可以用于许多其他位置。

如果onPressed 回调为 null，则按钮会被禁用且不会响应触摸。

其某个祖先节点必须是Material Widget。在 Material Design 3 中，此要求已不再适用，因为此 Widget 会构建以下类的子类： ButtonStyleButton。

图标按钮的触摸区域在条件允许时至少为 kMinInteractiveDimension 像素，不受实际iconSize 的影响，以满足touch target size（触摸目标尺寸） Material Design 规范中的要求。alignment（对齐方式）控制图标在触摸区域内的位置。

此示例展示了一个使用 Material 图标“volume_up”来调高音量的 IconButton。

图标尺寸

创建图标按钮时，如果使用Icon，请勿通过Icon.size参数覆盖图标尺寸，而应使用图标按钮的iconSize参数。如下例所示：

IconButton(
  iconSize: 72,
  icon: const Icon(Icons.favorite),
  onPressed: () {
    // ...
  },
),

避免这样做：

IconButton(
  icon: const Icon(Icons.favorite, size: 72),
  onPressed: () {
    // ...
  },
),

否则，按钮尺寸将基于默认图标尺寸，而不是 72；这可能导致布局异常或内容裁切。

添加填充背景

图标按钮不支持指定背景颜色或其他背景装饰，因为图标通常直接显示在父 Widget 的背景上。位于AppBar.actions 中的图标按钮就是一例。

使用Ink Widget 很容易创建带填充背景的图标按钮。Ink Widget 会在底层Material上绘制装饰，并呈现水波纹和高亮效果；这些效果由后代 Widget 提供的InkResponse提供。

此示例中，图标按钮的背景颜色由Ink Widget 定义，其 child 是一个IconButton。图标按钮的填充背景为浅蓝色圆形，大小与按钮相同。

Material Design 3 为 IconButton 引入了新类型（standard 和 contained）。默认的IconButton 属于 standard 类型。要创建填充图标按钮，请使用IconButton.filled；要创建填充色调图标按钮，请使用IconButton.filledTonal；要创建描边图标按钮，请使用IconButton.outlined。

Material Design 3 还将IconButton 视为切换按钮。为兼容现有应用，可通过isSelected 属性选择性地控制切换功能。

当isSelected 为 null 时，按钮表现为普通按钮。如果isSelected 不为 null，按钮则表现为切换按钮。如果isSelected 为 true，则显示selectedIcon；如果为 false，则显示普通icon。

在 Material Design 3 中，IconTheme 和IconButtonTheme 用于覆盖IconButton 的默认样式。如果两个主题都存在，则IconButtonTheme 会覆盖IconTheme，无论哪个主题离IconButton 更近。每个IconButton 的属性按以下优先顺序解析：Widget 属性、IconButtonTheme 属性、IconTheme 属性以及内部默认属性值。

在 Material Design 3 中，IconButton.visualDensity 默认值为VisualDensity.standard （适用于所有平台）；否则，如果IconButton.visualDensity 设为VisualDensity.compact，按钮将呈圆角矩形。用户可通过IconButtonTheme、IconButton.style或IconButton.visualDensity进行自定义。
