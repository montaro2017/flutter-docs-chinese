CheckboxListTile 类

一个带 ListTile 的 Checkbox。换句话说，就是带标签的复选框。

整个列表项都可交互：点按任意位置都会切换复选框。

此组件的 value、onChanged、activeColor 和 checkColor 属性与 Checkbox widget 中同名属性相同。

title、subtitle、isThreeLine、dense 和 contentPadding 属性与 ListTile 中的同名属性类似。

此组件的 selected 属性类似于 ListTile.selected 属性。列表项选中时，其 activeColor 会用作文本颜色；若 activeColor 为 null，则使用主题中的 CheckboxThemeData.overlayColor。

此组件不会协调 selected 状态与 value 状态；若要在复选框选中时让列表项也显示为选中状态，请为两者传入相同的值。

在从左到右的语言环境中，复选框默认显示在右侧（即尾随端）。可以通过 controlAffinity 更改位置。secondary 组件会放在另一侧。这对应于 ListTile.leading 和 ListTile.trailing 这两个 ListTile 属性。

此组件需要树中有一个 Material 祖先组件作为绘制表面，通常由应用的 Scaffold 提供。tileColor 和 selectedTileColor 并非由 CheckboxListTile 本身绘制，而是由其 Material 祖先组件绘制。因此，可以在 CheckboxListTile 外包一层 Material，例如：

link 
ColoredBox(
  color: Colors.green,
  child: Material(
    child: CheckboxListTile(
      tileColor: Colors.red,
      title: const Text('CheckboxListTile with red background'),
      value: true,
      onChanged:(bool? value) { },
    ),
  ),
)

为 CheckboxListTile 添加 Material 包装层时的性能注意事项

分别为大量 CheckboxListTile 包裹 Material 会带来较高开销。请只包裹确实需要的 CheckboxListTile，或尽可能使用共同的 Material 祖先组件。

要将 CheckboxListTile 显示为禁用状态，请将 onChanged 回调设为 null。

此 widget 展示一个复选框；选中后会减慢所有动画（包括复选框自身的选中动画）。

CheckboxListTile 中的语义信息

由于整个 CheckboxListTile 都可交互，因此它应将自身表示为一个统一的交互实体。

为此，CheckboxListTile 会用 MergeSemantics 组件包裹其子组件。MergeSemantics 会尝试将后代的 Semantics 节点合并为语义树中的一个节点。因此，如果任何子组件需要自己的 Semantics 节点，CheckboxListTile 就会抛出错误。

例如，不能将 RichText 组件嵌套为 CheckboxListTile 的后代。RichText 内含手势识别器，需要自己的 Semantics 节点，这与 CheckboxListTile 希望将所有后代语义节点合并为一个节点直接冲突。因此，类似场景可能需要创建自定义单选列表项组件。
