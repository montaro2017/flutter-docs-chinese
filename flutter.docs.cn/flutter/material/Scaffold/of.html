ScaffoldState of(
  1. BuildContext context
)

从最近一个包围给定 context 的此类实例中查找 ScaffoldState。

如果没有此类实例包围给定 context，调试模式下会触发断言，发布模式下会抛出异常。

此方法开销较大，因为它会遍历元素树。

典型用法是在 Scaffold 子级的 build 方法中调用 Scaffold.of 函数。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.Scaffold.of.1 mysample

当 Scaffold 实际上是在同一个 build 函数中创建时，不能使用 build 函数的 context 参数查找该 Scaffold（因为它位于返回 widget 树中当前 widget 的“上方”）。此时可以使用下面这种基于 Builder 的方式，创建新的作用域并提供位于 Scaffold“下方”的 BuildContext：
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.Scaffold.of.2 mysample

更高效的做法是将 build 函数拆分为多个 widget。这样会引入一个新的 context，可从中获取 Scaffold。具体而言，外层 widget 创建 Scaffold，并在其中放置新的内层 widget 实例；随后在这些内层 widget 中使用 Scaffold.of。

另一种不够优雅但更快捷的做法是为 Scaffold 指定一个 GlobalKey，再通过 key.currentState 属性获取 ScaffoldState，而不是调用 Scaffold.of。

如果当前作用域中没有 Scaffold，此方法会抛出异常。若没有 Scaffold 时要返回 null，请改用 maybeOf。

实现

static ScaffoldState of(BuildContext context) {
  final ScaffoldState? result = context.findAncestorStateOfType<ScaffoldState>();
  if (result != null) {
    return result;
  }
  throw FlutterError.fromParts(<DiagnosticsNode>[
    ErrorSummary('Scaffold.of() called with a context that does not contain a Scaffold.'),
    ErrorDescription(
      'No Scaffold ancestor could be found starting from the context that was passed to Scaffold.of(). '
      'This usually happens when the context provided is from the same StatefulWidget as that '
      'whose build function actually creates the Scaffold widget being sought.',
    ),
    ErrorHint(
      'There are several ways to avoid this problem. The simplest is to use a Builder to get a '
      'context that is "under" the Scaffold. For an example of this, please see the '
      'documentation for Scaffold.of():\n'
      '  https://api.flutter.dev/flutter/material/Scaffold/of.html',
    ),
    ErrorHint(
      'A more efficient solution is to split your build function into several widgets. This '
      'introduces a new context from which you can obtain the Scaffold. In this solution, '
      'you would have an outer widget that creates the Scaffold populated by instances of '
      'your new inner widgets, and then in these inner widgets you would use Scaffold.of().\n'
      'A less elegant but more expedient solution is assign a GlobalKey to the Scaffold, '
      'then use the key.currentState property to obtain the ScaffoldState rather than '
      'using the Scaffold.of() function.',
    ),
    context.describeElement('The context used was'),
  ]);
}
