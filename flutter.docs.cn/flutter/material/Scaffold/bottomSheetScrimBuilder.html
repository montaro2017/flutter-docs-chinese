bottomSheetScrimBuilder 属性

Widget? Function(BuildContext, Animation<double>) bottomSheetScrimBuilder
final

底部工作表打开时，用于构建遮挡主要内容的控件的 builder。

builder 会接收当前的 BuildContext 和一个 Animation 作为参数。动画 Animation 的值范围为 0.0 到 1.0，取决于底部工作表遮挡屏幕的程度。0.0 表示遮挡屏幕 70%，1.0 表示完全遮挡屏幕。

如果此值为 null，则使用颜色为 Colors.black 的不可关闭 ModalBarrier。底部工作表打开或关闭时，屏障会淡入淡出。

如果 builder 返回 null，则不显示遮罩。
