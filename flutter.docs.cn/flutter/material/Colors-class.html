Colors 类 抽象 final

代表 Material Design 颜色调色板的 Color 和 ColorSwatch 常量。

与其直接使用这些调色板中的固定颜色，不如使用 Theme.of 获取当前主题的 ThemeData.colorScheme。Material 组件通常默认使用其中定义的颜色。

大多数色板包含 50 以及从 100 到 900、每 100 递增的颜色。数值越小，颜色越浅；数值越大，颜色越深。强调色色板（例如 redAccent）只包含 100、200、400 和 700 这些值。

此外还提供一系列具有常见不透明度的黑色和白色。例如，black54 是不透明度为 54% 的纯黑色。

若要从某个色板中选择特定颜色，请使用所需颜色对应的整数索引访问色板，如下所示：
link 
Color selection = Colors.green[400]!; // Selects a mid-range green.

每个 ColorSwatch 常量本身就是一种颜色，可以直接使用。例如：
link 
Container(
  color: Colors.blue, // same as Colors.blue[500] or Colors.blue.shade500
)

颜色调色板

黑色与白色

这些颜色按透明度区分。低透明度颜色（例如 Colors.white12 和 Colors.white10）很难看清，通常应避免使用；它们适用于非常轻微的视觉效果。

此处未展示 Colors.transparent，因为它完全不可见！
