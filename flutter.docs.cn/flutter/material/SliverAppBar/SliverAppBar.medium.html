创建可放置在 CustomScrollView 中的 Material Design 中型顶部应用栏。

返回一个 SliverAppBar，并为 Material 3 定义的中型顶部应用栏配置适当的默认值。它初始时完全展开，标题位于主图标行下方的区域中。滚动 CustomScrollView 时，标题会滚动到主图标行下方。完全折叠后，主图标行中会淡入显示较小版本的标题。再次展开时则会反向变化。

此示例展示如何在 SliverAppBar.medium 中使用 CustomScrollView。

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.SliverAppBar.SliverAppBar.medium.1 mysample

  • AppBar，用于构建较小或标题居中的顶部应用栏。
  • SliverAppBar.large，用于构建大型顶部应用栏。
  • https://m3.material.io/components/top-app-bar/overview，Material 3 顶部应用栏规范。

const SliverAppBar.medium({
  super.key,
  this.leading,
  this.automaticallyImplyLeading = true,
  this.title,
  this.actions,
  this.automaticallyImplyActions = true,
  this.flexibleSpace,
  this.bottom,
  this.elevation,
  this.scrolledUnderElevation,
  this.shadowColor,
  this.surfaceTintColor,
  this.forceElevated = false,
  this.backgroundColor,
  this.foregroundColor,
  this.iconTheme,
  this.actionsIconTheme,
  this.primary = true,
  this.centerTitle,
  this.excludeHeaderSemantics = false,
  this.titleSpacing,
  this.collapsedHeight,
  this.expandedHeight,
  this.floating = false,
  this.pinned = true,
  this.snap = false,
  this.stretch = false,
  this.stretchTriggerOffset = 100.0,
  this.onStretchTrigger,
  this.shape,
  this.toolbarHeight = _MediumScrollUnderFlexibleConfig.collapsedHeight,
  this.leadingWidth,
  this.toolbarTextStyle,
  this.titleTextStyle,
  this.systemOverlayStyle,
  this.forceMaterialTransparency = false,
  this.useDefaultSemanticsOrder = true,
  this.clipBehavior,
  this.actionsPadding,
}) : assert(floating || !snap, 'The "snap" argument only makes sense for floating app bars.'),
     assert(stretchTriggerOffset > 0.0),
     assert(
       collapsedHeight == null || collapsedHeight >= toolbarHeight,
       'The "collapsedHeight" argument has to be larger than or equal to [toolbarHeight].',
     ),
     _variant = _SliverAppVariant.medium;
