Switch 类

Material Design 开关。

用于切换单个设置的开启或关闭状态。

开关本身不维护任何状态。开关状态改变时，widget 会调用 onChanged 回调。大多数使用开关的 widget 会监听 onChanged 回调，并使用新的 value 重新构建开关，以更新其视觉外观。

如果 onChanged 回调为 null，开关会被禁用（不会响应输入）。默认情况下，禁用开关的滑块和轨道会以灰色系渲染。可以通过 inactiveThumbColor 和 inactiveTrackColor 自定义禁用开关的默认外观。

其祖先组件中必须有一个 Material 组件。

Material Design 3 支持在 Switch 滑块上添加图标。将 ThemeData.useMaterial3 设为 true 后，可以使用 Switch.thumbIcon，根据 Switch 的不同 WidgetState 添加可选图标。
