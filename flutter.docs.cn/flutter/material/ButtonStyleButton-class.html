ButtonStyleButton
description

ButtonStyleButton 类 抽象

按钮基类 StatefulWidget，其样式由 ButtonStyle 对象定义。

具体子类必须重写 defaultStyleOf 和 themeStyleOf。

另请参阅：

  • ElevatedButton，按下时 Material 表面会上移的填充式按钮。
  • FilledButton，是一种按下时不会升起的填充按钮。
  • FilledButton.tonal，是使用次要填充色的填充按钮变体。
  • OutlinedButton，是一种带描边且没有填充色的按钮。
  • TextButton，是一种没有描边或填充色的按钮。
  • m3.material.io/components/buttons/overview, an overview of each of the Material Design button types and how they should be used in designs.
