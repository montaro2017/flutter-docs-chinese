根据传入的状态绘制轨道形状。

context 参数与包含 Slider 渲染盒的上下文相同。

offset 参数表示 parentBox 原点相对于其 context 画布原点的偏移。此形状必须根据该偏移进行绘制。请参阅 PaintingContextCallback。

parentBox 参数是 Slider 的 RenderBox。可以使用其尺寸等属性辅助绘制此形状。

sliderTheme 参数是分配给此形状所属 Slider 的主题。

enableAnimation 参数表示一个动画：启用 Slider 时触发，禁用时反向播放。当 Slider.onChanged 不为 null 时，Slider 处于启用状态。滑块启用状态变化时，可使用此动画为该形状绘制中间帧。

thumbCenter 参数是圆钮中心相对于 PaintingContext.canvas 原点的偏移。它可作为将轨道划分为两个区段的分界点。

secondaryOffset 参数是次要值相对于 PaintingContext.canvas 原点的偏移。

如果此值不为 null，轨道会被划分为三个区段。

当 Slider.onChanged 为 null 时，isEnabled 参数为 false；否则为 true。值为 true 时，滑块会响应输入。

如果 Slider.divisions 不为 null，isDiscrete 参数为 true。此时滑块会在轨道上绘制刻度标记。

textDirection 参数可用于确定如何绘制轨道区段，具体取决于区段是否处于活动状态。

滑块起点与圆钮之间的轨道段为活动轨道段；圆钮与滑块终点之间的轨道段为非活动轨道段。在 TextDirection.ltr 中，滑块起点位于左侧；在 TextDirection.rtl 中，起点位于右侧。
