MenuBarThemeData 类

供 MenuBarTheme 用于定义 MenuBar widget 视觉属性的数据类。

此类定义 MenuBar widget 自身的视觉属性，不包括子菜单。子菜单属性由 MenuThemeData 或 MenuButtonThemeData 定义。

后代 widget 使用 MenuBarTheme.of 获取当前的 MenuBarThemeData 对象。

通常会将 MenuBarThemeData 作为整体 Theme 的一部分，通过 ThemeData.menuBarTheme 指定。也可以使用 MenuTheme 配置其自身的 widget 子树。

默认情况下，MenuBarThemeData 的所有属性均为 null。如果其中任一属性为 null，菜单栏就会使用自身的默认值。

另请参阅：

  • MenuThemeData, which describes the theme for the submenus of a MenuBar.
  • MenuButtonThemeData, which describes the theme for the MenuItemButtons in a menu.
  • ThemeData, which describes the overall theme for the application.
