Dialog 类

Material Design 对话框。

此对话框组件不限定对话框的具体内容。通常建议使用 AlertDialog 或 SimpleDialog，它们分别实现了特定类型的 Material Design 对话框。

此示例展示如何创建 Dialog 和 Dialog.fullscreen 组件。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.Dialog.1 mysample

尺寸约束

Material 3 规范建议对话框最大宽度为 560dp。由于历史原因，Flutter 的 Dialog 组件默认没有此约束。面向桌面或 Web 等大屏幕的应用，建议设置 constraints 属性。

此示例展示一个 Dialog，使用 BoxConstraints，其约束由 Material 3 规范定义。
link 
const Dialog(constraints: BoxConstraints(maxWidth: 560, minHeight: 280));

另请参阅：

  • AlertDialog, for dialogs that have a message and some buttons.
  • SimpleDialog, for dialogs that offer a variety of options.
  • showDialog, which actually displays the dialog and returns its result.
  • material.io/design/components/dialogs.html
