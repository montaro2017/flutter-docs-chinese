根据简单值构造 MenuItemButton 的 ButtonStyle 的静态便捷方法。

foregroundColor 用于创建 ButtonStyle.foregroundColor 的 WidgetStateProperty 值。指定 foregroundColor 可设置按钮图标的颜色；使用 backgroundColor 设置按钮的背景填充色；使用 disabledForegroundColor 和 disabledBackgroundColor 设置按钮禁用时的图标颜色和填充色。

同样，enabledMouseCursor 和 disabledMouseCursor 参数用于构建 ButtonStyle.mouseCursor。

iconColor 和 disabledIconColor 用于构建 ButtonStyle.iconColor；iconSize 用于构建 ButtonStyle.iconSize。

其他所有参数要么直接使用，要么用于创建一个在所有状态下都取单一值的 WidgetStateProperty。

所有参数默认均为 null，因此此方法返回的 ButtonStyle 不会覆盖任何属性。

例如，如需覆盖 MenuItemButton 的默认前景色和叠加色，并保留按下、获得焦点和悬停状态下所有标准的不透明度调整，可以这样编写：

MenuItemButton(
  leadingIcon: const Icon(Icons.pets),
  style: MenuItemButton.styleFrom(foregroundColor: Colors.green),
  onPressed: () {
    // ...
  },
  child: const Text('Button Label'),
),
