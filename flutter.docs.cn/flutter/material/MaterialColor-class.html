MaterialColor 类

定义一种颜色，并提供该颜色的十个色阶。

颜色的色阶通过索引引用。索引越大，颜色越深。有效索引共有 10 个：50、100、200、……、900。此颜色的值应与索引 500 的颜色以及 shade500 相同。

迁移到 ColorScheme

对于配置为使用 Material 3 的应用，建议使用 ColorScheme 表示颜色（参见 ThemeData.useMaterial3）。有关 Material 3 颜色的更多信息，请参阅规范：m3.material.io/styles/color/the-color-system。

在 Material 3 中，颜色通过颜色角色及其对应的令牌表示。ColorScheme 类中的每个属性都表示上述规范定义的一个颜色角色。

Flutter 中的 Material 3 颜色

可以使用组件属性在组件级别为 Flutter 的 Material 组件指定颜色，也可以使用主题类在应用级别指定颜色。

例如，可以将 AppBar.backgroundColor 设为特定的 Color 值，从而设置 AppBar 的背景色。

若要为整个应用统一设置 AppBar 背景色，可以通过 ThemeData 类为 MaterialApp 设置 ThemeData.appBarTheme 属性。也可以在组件子树的根部放置 AppBarTheme，以覆盖该子树中所有 AppBar 的默认外观。

另一种方法是将 ThemeData.colorScheme 属性设为自定义的 ColorScheme，从而在整个应用中使用统一的 ColorScheme 配色方案。默认情况下，AppBar.backgroundColor 使用 ColorScheme.surface。

从 MaterialColor 迁移到 ColorScheme

在大多数情况下，Flutter 组件都提供了新的属性，支持接收 ColorScheme，而不再使用 MaterialColor。

例如，以前你可能会使用 primarySwatch 构造 ThemeData：

ThemeData(
  primarySwatch: Colors.amber,
)

在 Material 3 中，可以使用 ColorScheme 类，通过 ColorScheme.fromSeed 构造函数创建具有相同配色的 ThemeData：

ThemeData(
 colorScheme: ColorScheme.fromSeed(seedColor: Colors.amber),
)

ColorScheme.fromSeed 构造函数会生成一组色调色板，并用它们创建配色方案。

也可以使用 ColorScheme.fromSwatch 构造函数：

ThemeData(
 colorScheme: ColorScheme.fromSwatch(primarySwatch: Colors.amber),
)

ColorScheme.fromSwatch 构造函数会直接根据 MaterialColor 中使用的具体颜色值创建配色方案。

另请参阅：

  • Colors, which defines all of the standard material colors.
