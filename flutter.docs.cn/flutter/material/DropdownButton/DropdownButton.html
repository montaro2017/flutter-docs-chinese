创建一个下拉按钮。

各个 items 的值必须互不相同。value 不为 null 时，必须与某个 DropdownMenuItem 的值相等。如果 items 或 onChanged 为 null，按钮将被禁用，下拉箭头会显示为灰色。

如果 value 为 null 且按钮已启用，则显示非 null 的 hint。

如果 value 为 null 且按钮已禁用，则显示非 null 的 disabledHint。如果 disabledHint 为 null，则显示非 null 的 hint。

dropdownColor 参数指定下拉菜单展开时的背景颜色。如果为 null，则使用当前主题的 ThemeData.canvasColor。
