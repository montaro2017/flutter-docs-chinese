selectedItemBuilder 属性

DropdownButtonBuilder? selectedItemBuilder
final

用于自定义与 DropdownMenuItem 对应的下拉按钮显示内容的构建器，这些菜单项位于 items 中。

选中某个 DropdownMenuItem 后，按钮显示列表中与该菜单项在 DropdownMenuItem 同一索引处的组件，对应索引位于 items 中。

此示例展示一个 DropdownButton：按钮上显示的 Text 与 DropdownMenuItem 对应，但内容不同。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.DropdownButton.selectedItemBuilder.1 mysample

如果此回调为 null，则显示 DropdownMenuItem 列表中与 items 中的 value 相匹配的菜单项。

此构建器返回的组件列表长度必须与 items 列表完全相同。
