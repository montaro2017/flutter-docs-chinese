FilledButton.icon({
  1. Key? key,
  2. required VoidCallback? onPressed,
  3. VoidCallback? onLongPress,
  4. ValueChanged<bool>? onHover,
  5. ValueChanged<bool>? onFocusChange,
  6. ButtonStyle? style,
  7. FocusNode? focusNode,
  8. bool autofocus = false,
  9. Clip? clipBehavior = Clip.none,
  10. MaterialStatesController? statesController,
  11. Widget? icon,
  12. required Widget label,
  13. IconAlignment? iconAlignment,
})

使用 icon 和 label 创建填充按钮。

图标和标签按行排列，两端带有内边距，彼此之间留有间隔。

如果 icon 为 null，此构造函数会创建一个不显示图标的 FilledButton。

决定以下组件中图标的对齐方式：

  • ElevatedButton.icon,
  • FilledButton.icon,
  • FilledButton.tonalIcon.
  • OutlinedButton.icon,
  • TextButton.icon,

iconAlignment 的效果取决于 TextDirection。如果 textDirection 为 TextDirection.ltr，则 IconAlignment.start 和 IconAlignment.end 分别将图标对齐到左侧和右侧。如果 textDirection 为 TextDirection.rtl，则对齐方向相反。

默认为 IconAlignment.start。

实现

FilledButton.icon({
  super.key,
  required super.onPressed,
  super.onLongPress,
  super.onHover,
  super.onFocusChange,
  super.style,
  super.focusNode,
  super.autofocus = false,
  super.clipBehavior = Clip.none,
  super.statesController,
  Widget? icon,
  required Widget label,
  IconAlignment? iconAlignment,
}) : _variant = _FilledButtonVariant.filled,
     _addPadding = icon != null,
     super(
       child: icon != null
           ? _FilledButtonWithIconChild(
               label: label,
               icon: icon,
               buttonStyle: style,
               iconAlignment: iconAlignment,
             )
           : label,
     );
