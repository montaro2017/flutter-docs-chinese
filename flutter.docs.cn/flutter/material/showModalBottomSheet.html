显示一个 Material Design 模态底部面板。

模态底部面板可替代菜单或对话框，并会阻止用户与应用的其余部分交互。

与之密切相关的是持久底部面板，它会显示补充应用主要内容的信息，同时允许用户继续与应用交互。可以通过 showBottomSheet 函数或 ScaffoldState.showBottomSheet 方法创建并显示持久底部面板。

isScrollControlled 参数用于指定该路由是否对应一个会使用 DraggableScrollableSheet 的底部面板。如果底部面板包含可滚动子项（例如 ListView 或 GridView），并且需要支持拖动，请考虑将此参数设为 true。

isDismissible 参数用于指定用户点击遮罩时是否关闭底部面板。

enableDrag 参数用于指定是否可以上下拖动底部面板，以及是否可以向下滑动将其关闭。

useSafeArea 参数用于指定面板是否避开顶部、左侧和右侧的系统遮挡区域。为 false 时，不会添加 SafeArea，并会在顶部应用 MediaQuery.removePadding，因此底部面板内部的 SafeArea 也不会避开顶部的系统遮挡区域。默认值为 false。

可以传入可选的 backgroundColor、elevation、shape、clipBehavior、constraints 和 transitionAnimationController 参数，自定义模态底部面板的外观和行为。详情请参阅 BottomSheet 的相关文档。

transitionAnimationController 用于控制底部面板的进入和退出动画。不再需要此控制器时，其所有者应调用 AnimationController.dispose。

可选的 settings 参数用于设置模态底部面板的 RouteSettings。当用户希望通过 NavigatorObserver 观察 PopupRoute 时，这尤其有用。

DisplayFeature 可以将屏幕划分为多个子屏幕。系统会选择距离 anchorPoint 最近的子屏幕来渲染内容。

如果未提供 anchorPoint，则会使用 Directionality：

  • 当方向为 TextDirection.ltr 时，anchorPoint 设为 Offset.zero，内容会显示在左上方子屏幕。
  • 当方向为 TextDirection.rtl 时，anchorPoint 设为 Offset(double.maxFinite, 0)，内容会显示在右上方子屏幕。

如果未提供 anchorPoint，且树中没有 Directionality 祖先控件，则在调试模式下构建此控件时会触发断言。

context 参数用于查找底部面板所用的 Navigator 和 Theme。它只在调用此方法时使用。底部面板关闭前，可以安全地将对应控件从树中移除。

useRootNavigator 参数为 true 时，确保使用根导航器显示 BottomSheet。如果调用方位于另一个 Navigator 内，但模态 BottomSheet 需要显示在所有其他内容之上，这会很有用。

返回一个 Future，在模态底部面板关闭时以传给 Navigator.pop 的值（如果有）完成。

barrierLabel 参数可用于设置自定义遮罩标签。如果未设置，则默认为当前上下文中的 MaterialLocalizations.modalBarrierDismissLabel。

sheetAnimationStyle 参数用于覆盖模态底部面板的动画时长和反向动画时长。

requestFocus 参数用于指定显示底部面板时是否请求焦点。如果未提供 requestFocus，则使用 Navigator.requestFocus 的值。

如果提供了 AnimationStyle.duration，则会用它覆盖底层 BottomSheet.createAnimationController 中的模态底部面板动画时长。

如果提供了 AnimationStyle.reverseDuration，则会用它覆盖底层 BottomSheet.createAnimationController 中的模态底部面板反向动画时长。

要禁用底部面板动画，请使用 AnimationStyle.noAnimation。

实现

Future<T?> showModalBottomSheet<T>({
  required BuildContext context,
  required WidgetBuilder builder,
  Color? backgroundColor,
  String? barrierLabel,
  double? elevation,
  ShapeBorder? shape,
  Clip? clipBehavior,
  BoxConstraints? constraints,
  Color? barrierColor,
  bool isScrollControlled = false,
  double scrollControlDisabledMaxHeightRatio = _kDefaultScrollControlDisabledMaxHeightRatio,
  bool useRootNavigator = false,
  bool isDismissible = true,
  bool enableDrag = true,
  bool? showDragHandle,
  bool useSafeArea = false,
  RouteSettings? routeSettings,
  AnimationController? transitionAnimationController,
  Offset? anchorPoint,
  AnimationStyle? sheetAnimationStyle,
  bool? requestFocus,
}) {
  assert(debugCheckHasMediaQuery(context));
  assert(debugCheckHasMaterialLocalizations(context));

  final NavigatorState navigator = Navigator.of(context, rootNavigator: useRootNavigator);
  final MaterialLocalizations localizations = MaterialLocalizations.of(context);
  return navigator.push(
    ModalBottomSheetRoute<T>(
      builder: builder,
      capturedThemes: InheritedTheme.capture(from: context, to: navigator.context),
      isScrollControlled: isScrollControlled,
      scrollControlDisabledMaxHeightRatio: scrollControlDisabledMaxHeightRatio,
      barrierLabel: barrierLabel ?? localizations.scrimLabel,
      barrierOnTapHint: localizations.scrimOnTapHint(localizations.bottomSheetLabel),
      backgroundColor: backgroundColor,
      elevation: elevation,
      shape: shape,
      clipBehavior: clipBehavior,
      constraints: constraints,
      isDismissible: isDismissible,
      modalBarrierColor: barrierColor ?? Theme.of(context).bottomSheetTheme.modalBarrierColor,
      enableDrag: enableDrag,
      showDragHandle: showDragHandle,
      settings: routeSettings,
      transitionAnimationController: transitionAnimationController,
      anchorPoint: anchorPoint,
      useSafeArea: useSafeArea,
      sheetAnimationStyle: sheetAnimationStyle,
      requestFocus: requestFocus,
    ),
  );
}
