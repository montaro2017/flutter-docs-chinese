SliderThemeData 类

为后代 Slider 控件提供默认视觉属性。

后代控件可通过 SliderTheme.of 获取当前 SliderThemeData，并使用 SliderThemeData.copyWith 进行自定义。 SliderThemeData SliderThemeData

通常会将其作为 ThemeData.sliderTheme 的一部分使用。 SliderThemeData Theme

这些属性同时适用于 Slider 和 RangeSlider：tickMarkShape、thumbShape、trackShape、valueIndicatorShape 仅用于 Slider；rangeTickMarkShape、rangeThumbShape、rangeTrackShape、rangeValueIndicatorShape、overlappingShapeStrokeColor、minThumbSeparation 和 thumbSelector 仅用于 RangeSlider。其余属性两者通用。 Slider Slider RangeSlider RangeSlider

滑块由以下部分组成：

  • The "thumb", which is a shape that slides horizontally when the user drags it.
  • The "track", which is the line that the slider thumb slides along.
  • The "tick marks", which are regularly spaced marks that are drawn when using discrete divisions.
  • The "value indicator", which appears when the user is dragging the thumb to indicate the value being selected.
  • The "overlay", which appears around the thumb, and is shown when the thumb is pressed, focused, or hovered. It is painted underneath the thumb, so it must extend beyond the bounds of the thumb itself to actually be visible.
  • The "active" side of the slider is the side between the thumb and the minimum value.
  • The "inactive" side of the slider is the side between the thumb and the maximum value.
  • The Slider is disabled when it is not accepting user input. See Slider for details on when this happens.

可通过 SliderTrackShape、SliderComponentShape 和 SliderTickMarkShape 的子类自定义各部分的形状。例如：RoundSliderThumbShape、RectangularSliderTrackShape、RoundSliderTickMarkShape、RectangularSliderValueIndicatorShape 和 RoundSliderOverlayShape。

将 trackHeight 设为 0 可隐藏轨道；将 SliderComponentShape.noThumb 赋给 thumbShape 可隐藏滑块；将 noOverlay 赋给 overlayShape 可隐藏叠加层；将 noTickMark 赋给 tickMarkShape 可隐藏刻度标记；将 ShowValueIndicator 赋给 showValueIndicator 可隐藏值指示器。

另请参阅：

  • SliderTheme widget, which can override the slider theme of its children.
  • Theme widget, which performs a similar function to SliderTheme, but for overall themes.
  • ThemeData, which has a default SliderThemeData.
  • SliderComponentShape，可用于为 Slider 的滑块、悬浮层和值指示器以及 RangeSlider 的悬浮层创建自定义形状。
  • SliderTrackShape，可用于为 Slider 的轨道创建自定义形状。
  • SliderTickMarkShape，可用于为 Slider 的刻度标记创建自定义形状。
  • RangeSliderThumbShape，可用于为 RangeSlider 的滑块创建自定义形状。
  • RangeSliderValueIndicatorShape，可用于为 RangeSlider 的数值指示器创建自定义形状。
  • RangeSliderTrackShape，可用于为 RangeSlider 的轨道创建自定义形状。
  • RangeSliderTickMarkShape，可用于为 RangeSlider 的刻度标记创建自定义形状。
