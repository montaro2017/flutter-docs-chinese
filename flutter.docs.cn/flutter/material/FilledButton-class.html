FilledButton 类

Material Design 的填充按钮。

填充按钮的视觉效果仅次于 FloatingActionButton，适合用于流程中的重要最终操作，例如保存、立即加入或确认。

填充按钮是在 Material 组件上显示的标签 child。标签中的 Text 和 Icon 按照 style 的 ButtonStyle.foregroundColor 显示；按钮的填充背景则采用 ButtonStyle.backgroundColor。

填充按钮的默认样式由 defaultStyleOf 定义。可以通过其 style 参数覆盖单个按钮的样式，通过 FilledButtonTheme 覆盖子树中所有填充按钮的样式，或通过应用的 Theme 的 ThemeData.filledButtonTheme 属性覆盖整个应用中填充按钮的样式。

静态方法 styleFrom 可以根据简单的取值便捷地创建填充按钮的 ButtonStyle。

如果 onPressed 和 onLongPress 回调均为 null，按钮将处于禁用状态。

如需创建“填充色调”按钮，请使用 FilledButton.tonal。

视觉密度效果

按钮的外观受外围 Theme 或其 style 中的 VisualDensity 影响。视觉密度会调整 ButtonStyle.padding 和 ButtonStyle.minimumSize，以适应不同平台的界面密度。关于它对组件布局及各平台默认值的影响，详见 VisualDensity。
