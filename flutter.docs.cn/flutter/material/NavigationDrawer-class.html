NavigationDrawer 类

Material Design 导航抽屉组件。

除了 Drawer 的功能外，导航抽屉还为在应用的主要目标页面之间切换提供了持久、便捷的方式。

图标和文字的样式不受父级 DefaultTextStyle 或 IconTheme 影响，而由参数或 NavigationDrawerThemeData 控制。

children 是要显示在抽屉中的组件列表，可以包含任意组件；但 NavigationDrawerDestination 会被特殊处理，它们会作为一组目标项。当用户选中其中一项时，会调用 onDestinationSelected，并传入该目标项在组内的索引。

此示例展示了如何在 Scaffold 小部件中使用 NavigationDrawer。该 NavigationDrawer 包含标题小部件、分隔线小部件和三个 NavigationDrawerDestination 小部件。初始 selectedIndex 为 0。onDestinationSelected 回调会更改所选目标项的索引，并在 Scaffold 的主体中显示对应的小部件。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.NavigationDrawer.1 mysample

另请参阅：

  • Scaffold.drawer, where one specifies a Drawer so that it can be shown.
  • Scaffold.of, to obtain the current ScaffoldState, which manages the display and animation of the drawer.
  • ScaffoldState.openDrawer, which displays its Drawer, if any.
