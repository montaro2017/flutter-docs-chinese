AboutDialog 类

关于信息对话框。它会显示应用图标、名称、版本号和版权信息，并提供按钮以查看应用所用软件的许可证。

若要显示 AboutDialog，请使用 showAboutDialog。

如果应用包含 Drawer，可以使用 AboutListTile widget 简化显示关于信息对话框的流程。

由 showAboutDialog 显示的 AboutDialog 包含一个按钮，点击后会调用 showLicensePage。

LicensePage 中显示的许可证由 LicenseRegistry API 提供；你可以使用该 API 将更多许可证添加到列表中。
