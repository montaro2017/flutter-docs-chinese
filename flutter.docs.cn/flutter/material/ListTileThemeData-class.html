ListTileThemeData 类

与 ListTileTheme 配合使用，为后代 ListTile 组件以及构建 ListTile 的组件（如 CheckboxListTile、RadioListTile 和 SwitchListTile）定义默认属性值。

后代组件通过 ListTileTheme.of 获取当前的 ListTileThemeData 对象。可使用 ListTileThemeData.copyWith 自定义 ListTileThemeData 实例。

通常会通过 ThemeData.listTileTheme 将 ListTileThemeData 指定为整体 Theme 的一部分。

默认情况下，ListTileThemeData 的所有属性均为 null。主题属性为 null 时，ListTile 会根据整体 Theme 的 textTheme 和 colorScheme 提供自己的默认值。详情请参阅各个 ListTile 属性。

Drawer 组件会为其子组件指定列表项主题，并将 style 设为 ListTileStyle.drawer。

另请参阅：

  • ThemeData，用于描述应用的整体主题信息。
