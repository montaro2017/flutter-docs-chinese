在最近的 Scaffold 中显示 Material Design 底部表单。若要显示持久底部表单，请使用 Scaffold.bottomSheet。

返回一个可用于关闭或以其他方式操作底部表单的控制器。

若要重新构建底部表单（例如，它具有状态），请对本方法返回的控制器调用 PersistentBottomSheetController.setState。

新的底部表单会成为外层 ModalRoute 的 LocalHistoryEntry，并在所属 Scaffold 的应用栏中添加一个返回按钮，用于关闭底部表单。

transitionAnimationController 控制底部表单的进入和退出动画。该控制器的所有者负责在不再需要时调用 AnimationController.dispose。

若要创建不会成为 LocalHistoryEntry 且不会在外层 Scaffold 应用栏中添加返回按钮的持久底部表单，请使用 Scaffold.bottomSheet 构造参数。

持久底部工作表用于补充应用主要内容，即使用户与应用其他部分交互，它也会保持可见。

与之相关的组件是模态底部工作表，它可替代菜单或对话框，并会阻止用户与应用其他部分交互。可通过 showModalBottomSheet 创建并显示模态底部工作表。

此示例演示如何使用 showBottomSheet 在用户点击按钮时显示底部面板，并演示如何使用 Navigator 关闭底部面板。

sheetAnimationStyle 参数用于覆盖底部表单的动画时长和反向动画时长。

如果提供了 AnimationStyle.duration，则会用它覆盖底层 BottomSheet.createAnimationController 中底部表单的动画时长。

如果提供了 AnimationStyle.reverseDuration，则会用它覆盖底层 BottomSheet.createAnimationController 中底部表单的反向动画时长。

若要禁用底部表单动画，请使用 AnimationStyle.noAnimation。

PersistentBottomSheetController showBottomSheet(
  WidgetBuilder builder, {
  Color? backgroundColor,
  double? elevation,
  ShapeBorder? shape,
  Clip? clipBehavior,
  BoxConstraints? constraints,
  bool? enableDrag,
  bool? showDragHandle,
  AnimationController? transitionAnimationController,
  AnimationStyle? sheetAnimationStyle,
}) {
  assert(() {
    if (widget.bottomSheet != null) {
      throw FlutterError(
        'Scaffold.bottomSheet cannot be specified while a bottom sheet '
        'displayed with showBottomSheet() is still visible.\n'
        'Rebuild the Scaffold with a null bottomSheet before calling showBottomSheet().',
      );
    }
    return true;
  }());
  assert(debugCheckHasMediaQuery(context));

  _closeCurrentBottomSheet();
  final AnimationController controller =
      (transitionAnimationController ??
            BottomSheet.createAnimationController(this, sheetAnimationStyle: sheetAnimationStyle))
        ..forward();
  setState(() {
    _currentBottomSheet = _buildBottomSheet(
      builder,
      isPersistent: false,
      animationController: controller,
      backgroundColor: backgroundColor,
      elevation: elevation,
      shape: shape,
      clipBehavior: clipBehavior,
      constraints: constraints,
      enableDrag: enableDrag,
      showDragHandle: showDragHandle,
      shouldDisposeAnimationController: transitionAnimationController == null,
    );
  });
  return _currentBottomSheet!;
}
