初始化或恢复此 State 对象使用的 RestorableProperty 时调用。

此方法会在 State.initState 后立即至少调用一次，以便将 RestorableProperty 注册到 mixin；即使状态恢复已关闭，或此 State 对象没有可用的恢复数据，也会调用。

通常会在此方法中调用 registerForRestoration，将此 State 对象使用的所有 RestorableProperty 注册到 mixin。如果有可用恢复数据，注册操作会将属性值恢复为数据中记录的值；否则会将其初始化为该属性专用的默认值。

每当有新的恢复数据（以新的 bucket 形式）提供给 mixin 时，都会再次调用此方法。此时，State 对象必须重新注册所有先前注册的属性，使其值恢复为新恢复数据中记录的值。

提供新的状态恢复数据时，此方法可能会改变已注册属性的值。因此，所有依赖特定 RestorableProperty 值的初始化逻辑都应放在此方法中。这样，当 RestorableProperty 属性从新提供的恢复数据中恢复后，这些逻辑会重新执行。

首次调用此方法时，传入的 oldBucket 参数始终为 null。之后因新的恢复数据（以新 bucket 形式）触发调用时，该参数为 bucket 先前的值。

实现

@protected
@override
void restoreState(RestorationBucket? oldBucket, bool initialRestore) {
  registerForRestoration(_drawerOpened, 'drawer_open');
  registerForRestoration(_endDrawerOpened, 'end_drawer_open');
}
