使用一个或多个转场 widget 包装子项，以定义 route 如何进入和离开屏幕。

子类会重写此方法来创建转场动画。

MaterialPageRoute.buildTransitions 方法就是使用此方法构建转场的一个示例。它会通过 Theme.of(context).pageTransitionsTheme 查找当前的 PageTransitionsTheme，然后根据主题的 ThemeData.platform 选择一个 PageTransitionsBuilder，并将其委托给此方法。

实现

@override
Widget buildTransitions<T>(
  PageRoute<T> route,
  BuildContext context,
  Animation<double> animation,
  Animation<double> secondaryAnimation,
  Widget child,
) {
  return _PredictiveBackGestureDetector(
    route: route,
    builder:
        (
          BuildContext context,
          _PredictiveBackPhase phase,
          PredictiveBackEvent? startBackEvent,
          PredictiveBackEvent? currentBackEvent,
        ) {
          // Only do a predictive back transition when the user is performing a
          // pop gesture. Otherwise, for things like button presses or other
          // programmatic navigation, fall back to ZoomPageTransitionsBuilder.
          if (route.popGestureInProgress) {
            return _PredictiveBackFullscreenPageTransition(
              animation: animation,
              secondaryAnimation: secondaryAnimation,
              getIsCurrent: () => route.isCurrent,
              phase: phase,
              child: child,
            );
          }

          return ZoomPageTransitionsBuilder(
            backgroundColor: fallbackColor,
          ).buildTransitions(route, context, animation, secondaryAnimation, child);
        },
  );
}
