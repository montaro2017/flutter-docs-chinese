ShapedInputBorder 类

在 InputDecorator 的容器周围绘制自定义形状。

此边框允许将任意 ShapeBorder 用作输入装饰器边框，从而在保留浮动标签间隙功能的同时，为自定义边框形状提供最大的灵活性。

当输入装饰器的标签浮起时（例如其输入子项获得焦点时），标签会显示在边框轮廓的间隙中。

输入装饰器的“容器”是其 helper、error 和 counter 上方可选填充的区域。

若要在本地项目中使用此代码示例，请运行：
flutter create --sample=material.ShapedInputBorder.1 mysample

另请参阅：

  • OutlineInputBorder，传统的圆角矩形边框。
  • UnderlineInputBorder，是默认的 InputDecorator 边框，会沿输入装饰器容器底部绘制水平线。
  • RoundedSuperellipseBorder，可与此边框搭配使用，以创建 iOS 风格的形状。
  • InputDecoration，用于配置 InputDecorator。
