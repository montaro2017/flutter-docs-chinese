WidgetStateInputBorder 类 抽象 interface

定义一种同时也是 InputBorder 和 WidgetStateProperty 的输入边框。

此类使具有 InputBorder 类型属性的组件也能接受 WidgetStateProperty 对象。

WidgetStateInputBorder 只能用于文档明确说明支持它的组件，例如 InputDecoration.border。

创建 WidgetStateInputBorder 的方式：

  1. 创建一个继承 OutlineInputBorder 或 UnderlineInputBorder 并实现 WidgetStateInputBorder 的类。该类还需要重写 resolve 方法。
  2. 使用 WidgetStateInputBorder.resolveWith，并传入一个用于解析给定状态下输入边框的回调函数。
  3. 使用 WidgetStateInputBorder.fromMap，通过 WidgetStateMap 指定边框。
