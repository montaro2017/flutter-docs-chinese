PaginatedDataTable 类

一种遵循 Material 2 设计规范、通过多页展示数据的表格。

分页数据表每页显示 rowsPerPage 行数据，并提供切换页面的控件。

数据从 DataTableSource 延迟读取。此控件以 Card 形式呈现。

如果 key 是 PageStorageKey，则 initialFirstRowIndex 会保存到 PageStorage 中。

此示例展示如何显示一个包含三列（姓名、年龄和角色）的 DataTable。这些列由三个 DataColumn 对象定义。表格包含三位示例用户的三行数据，数据分别由三个 DataRow 对象定义。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.PaginatedDataTable.1 mysample

此示例展示如何在分页数据表中支持排序数据。
