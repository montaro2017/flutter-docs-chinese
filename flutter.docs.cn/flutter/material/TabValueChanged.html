TabValueChanged<T> typedef

TabValueChanged<T> = void Function(T value, int index)

用于 TabBar 回调的签名，用于报告指定 index 处的 Tab 底层值已发生变化。

供 TabBar.onHover 和 TabBar.onFocusChange 回调使用。提供的 value 为 true 表示已获得焦点或指针已悬停在标签上；为 false 则表示焦点已丢失或指针已离开标签。

实现
