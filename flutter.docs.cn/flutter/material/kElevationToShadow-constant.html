kElevationToShadow top-level constant

Map<int, List<BoxShadow>> const kElevationToShadow

Material Design 用于 BoxShadow 定义的阴影偏移映射表。

以下高度值定义了阴影：1、2、3、4、6、8、9、12、16、24。

每个条目包含三个阴影，必须将它们组合起来，才能获得该高度对应的预定义效果。

当使用 BoxDecoration 或其他采用 BoxShadow 对象列表的类来模拟阴影时，此映射很有用。

kElevationToShadow 定义的阴影使用 BlurStyle.normal。若要将 kElevationToShadow 中的阴影转换为使用其他 BlurStyle（例如用于 MagnifierDecoration），可以考虑采用如下表达式：

kElevationToShadow[12]!.map((BoxShadow shadow) => shadow.copyWith(blurStyle: BlurStyle.outer)).toList(),

另请参阅：

  • Material 可以接受任意 double 值作为其高度，并动态生成阴影。
  • material.io/design/environment/elevation.html

实现

const Map<int, List<BoxShadow>> kElevationToShadow =
    _elevationToShadow;
