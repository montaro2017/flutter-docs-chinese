RadioTheme 类

为后代 Radio 组件应用单选按钮主题。

后代组件通过 RadioTheme.of 获取当前主题的 RadioTheme 对象。使用 RadioTheme.of 的组件会在主题之后发生变化时自动重建。

可以通过 ThemeData.radioTheme 将单选按钮主题指定为整体 Material 主题的一部分。

另请参阅：

  • RadioThemeData, which describes the actual configuration of a radio theme.
