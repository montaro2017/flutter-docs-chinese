PageTransitionsTheme 类

为不同的 TargetPlatform 定义 MaterialPageRoute 使用的页面过渡动画。

MaterialPageRoute.buildTransitions 方法会通过 Theme.of(context).pageTransitionsTheme 查找当前的 PageTransitionsTheme，并委托给 buildTransitions。

如果未找到与平台匹配的构建器，则会使用 ZoomPageTransitionsBuilder。

此示例展示了一个定义自定义 PageTransitionsTheme 的 MaterialApp。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.PageTransitionsTheme.1 mysample

另请参阅：

  • ThemeData.pageTransitionsTheme, which defines the default page transitions for the overall theme.
  • FadeUpwardsPageTransitionsBuilder，定义了与 Android O 所提供转场相似的页面转场。
  • OpenUpwardsPageTransitionsBuilder，定义了与 Android P 所提供转场相似的页面转场。
  • ZoomPageTransitionsBuilder，定义了与 Android Q 提供的页面转场相似的转场。
  • FadeForwardsPageTransitionsBuilder，定义了与 Android U 提供的页面转场相似的转场。
  • CupertinoPageTransitionsBuilder，定义与原生 iOS 页面转场相匹配的水平页面转场。
