继承

此对象通过 deactivate 从树中移除后重新插入时调用。

大多数情况下，State 对象停用后不会重新插入树中，框架会调用其 dispose 方法，以表示该对象即将被垃圾回收。

不过，有时 State 对象停用后，框架会将其重新插入树中的其他位置（例如，包含该 State 对象的子树因使用 GlobalKey 而从树中一个位置移动到另一个位置）。发生这种情况时，框架会调用 activate，让 State 对象重新获取其在 deactivate 中释放的资源。随后还会调用 build，让对象适应树中的新位置。如果框架重新插入此子树，会在将其从树中移除的动画帧结束前完成。因此，State 对象可以将大多数资源的释放延迟到框架调用其 dispose 方法时。

框架首次将 State 对象插入树中时不会调用此方法，而会在这种情况下调用 initState。

此方法的实现应先调用继承的方法，例如 super.activate()。

  • Element.activate, the corresponding method when an element transitions from the "inactive" to the "active" lifecycle state.
