TabBarTheme 类

为后代 TabBar 小组件定义默认属性值。

后代小组件通过 TabBarTheme.of 获取当前的 TabBarThemeData 对象。可使用 TabBarThemeData.copyWith 自定义 TabBarThemeData 实例。

通常会通过 ThemeData.tabBarTheme，将 TabBarThemeData 指定为整体 Theme 的一部分。

另请参阅：

  • TabBarThemeData, which describes the actual configuration of a tab bar theme.
