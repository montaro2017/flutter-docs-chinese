ExpansionTile 类

一种单行 ListTile，带有展开箭头图标；点按后可展开或折叠条目，以显示或隐藏 children。

此组件通常与 ListView 搭配，用于创建可展开/折叠的列表项。与 ListView 等滚动组件配合使用时，必须为 key 指定唯一的 PageStorageKey，以便 ExpansionTile 在滚出或滚入视野时保存和恢复展开状态。

此类会覆盖其 ListTile 的 ListTileThemeData.iconColor 和 ListTileThemeData.textColor 主题属性。条目展开和折叠时，这些颜色会在 iconColor 与 collapsedIconColor 之间，以及 textColor 与 collapsedTextColor 之间分别进行动画过渡。

在从左向右书写的语言中，展开箭头默认显示在右侧（即尾随边）。可以使用 controlAffinity 更改位置；该属性映射到 ExpansionTile 的 leading 和 trailing 属性。

无障碍访问

ExpansionTile 的无障碍行为会根据设备实际平台进行适配，而非主题中设置的平台。这可确保 iOS 和 macOS 上的 VoiceOver 等辅助技术获得正确的平台专属语义提示，即使应用主题配置为模拟其他平台的外观也不例外。
