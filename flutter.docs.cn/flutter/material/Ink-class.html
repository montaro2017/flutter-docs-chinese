Ink 类

一个便捷组件，可在 Material 组件上绘制图像及其他装饰，使 InkWell 和 InkResponse 的水波纹效果绘制在这些装饰上方。

由 InkWell 和 InkResponse 绘制的水波纹和高亮效果，会直接绘制在底层的 Material 上，并位于该材质上其他组件（例如 Text 和 Icon）之下。如果在 Material 上方绘制不透明图像（例如使用 Container 或 DecoratedBox），这些墨水效果会被其完全遮挡，因此不可见；这些图形覆盖在 Material 上方。

此组件会将给定的 Decoration 直接绘制到 Material 上，方式与 InkWell 和 InkResponse 相同。这样水波纹就能绘制在原本不透明的图形上方。

另一种解决方案是在不透明图形上方放置 MaterialType.transparency 材质。这样，InkWell 和 InkResponse 产生的墨水效果就会绘制在不透明图形上方的透明材质上，而不是绘制在底层 Material 上、被不透明图形遮住。

限制

此组件与其他墨水效果有相同的限制，详见 Material 文档。尤其要注意：Ink 组件在 Material 对象的生命周期内不得改变位置，除非每次位置变化时都派发 LayoutChangedNotification。ListView 等滚动组件会自动派发此通知，但 SlideTransition 等动画过渡不会。

此外，如果多个 Ink 组件在同一位置绘制到同一个 Material 上，它们的相对顺序没有保证。装饰会按照添加到材质上的顺序绘制；通常这与它们在组件树中的顺序一致，但在动态场景中，顺序看起来可能有些随机。

此示例展示如何使用 Material 组件和 Ink 在其上绘制黄色矩形，同时让墨水效果仍显示在矩形上方：
link 
Material(
  color: Colors.teal[900],
  child: Center(
    child: Ink(
      color: Colors.yellow,
      width: 200.0,
      height: 100.0,
      child: InkWell(
        onTap: () { /* ... */ },
        child: const Center(
          child: Text('YELLOW'),
        )
      ),
    ),
  ),
)

下面的示例展示如何在 Material 组件上绘制图像，并在图像上方放置 InkWell：
link 
Material(
  color: Colors.grey[800],
  child: Center(
    child: Ink.image(
      image: const AssetImage('cat.jpeg'),
      fit: BoxFit.cover,
      width: 300.0,
      height: 200.0,
      child: InkWell(
        onTap: () { /* ... */ },
        child: const Align(
          alignment: Alignment.topLeft,
          child: Padding(
            padding: EdgeInsets.all(10.0),
            child: Text(
              'KITTEN',
              style: TextStyle(
                fontWeight: FontWeight.w900,
                color: Colors.white,
              ),
            ),
          ),
        )
      ),
    ),
  ),
)

如果要裁剪此 Ink.image，该怎么做？

直接用裁剪组件包裹 Ink 不会生效，因为负责裁剪的是其绘制目标 Material。

在此示例中，图像没有按预期被裁剪，因为它绘制在 Scaffold 正文所用的 Material 上，而该 Material 并未被 ClipRRect 包裹。

link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.Ink.3 mysample

一种解决方案是有意将 Ink.image 包裹在 Material 中。 这样，绘制图像的 Material 也会负责裁剪该内容。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.Ink.4 mysample

另请参阅：

  • Container，此组件的一种更通用形式，它会自行绘制，而不是委托最近的 Material widget 绘制。
  • InkDecoration，即此组件使用的 InkFeature 子类，该子类用于在 Material widget 上绘制。
  • InkWell 和 InkResponse，它们也会在 Material widget 上绘制内容。
