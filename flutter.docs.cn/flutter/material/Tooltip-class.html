Tooltip 类

Material Design 工具提示框。

工具提示框会显示文本标签，帮助说明按钮或其他用户界面操作的功能。将按钮包装在 Tooltip 小组件中，并提供一条消息；长按该小组件时会显示此消息。

许多小组件（例如 IconButton、FloatingActionButton 和 PopupMenuButton）都带有 tooltip 属性；该属性不为 null 时，小组件会在构建时包含一个 Tooltip。

工具提示框通过提供小组件的文本说明来提升其无障碍性，例如屏幕阅读器可以朗读这些说明。

此示例展示一个基础的 Tooltip，其子级为 Text。message 包含要显示的提示文本。网页和桌面端会在鼠标悬停于 Tooltip 包裹的子项上时显示提示；移动设备上则会在长按组件时显示。

此工具提示默认显示在 Text 上方，而不是下方，因为其当前的 TooltipThemeData.preferBelow 为 false。（参见 MaterialApp.theme。）建议设置该主题数据，以免手指或光标遮住工具提示。其他设置方式请参见：

  • Theme.data, ThemeData.tooltipTheme
  • TooltipTheme.data

也可以通过 Tooltip.preferBelow，直接在每个工具提示框上设置。

link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.Tooltip.1 mysample

此示例涵盖 Tooltip 的大多数属性。使用 decoration 为 Tooltip 添加渐变和 borderRadius；使用 constraints 设置最小宽度。preferBelow 为 true，因此工具提示框优先显示在 Tooltip 子项下方；但下方空间不足时，也可能显示在上方。使用 textStyle 设置“message”的字体大小。showDuration 接受一个 Duration，用于在长按结束或鼠标指针离开子项后继续显示消息。waitDuration 接受一个 Duration，表示鼠标指针必须悬停在子项上多久才会显示工具提示框。

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.Tooltip.2 mysample

此示例展示了一个富文本 Tooltip：指定 richMessage 参数，而不是 message 参数（两者只能有一个不为 null）。richMessage 属性可以指定任意 InlineSpan，包括 WidgetSpan。
