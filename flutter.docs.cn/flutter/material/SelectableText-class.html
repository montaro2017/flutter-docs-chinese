SelectableText 类

显示单一文本样式且可供选择的一段文字。

也可以考虑改用 SelectionArea 或 SelectableRegion，它们可以在 widget 子树范围内启用文本选择，其中包括但不限于 Text widget。

SelectableText widget 会以单一样式显示一段文本。根据布局约束，这段文字可能换成多行，也可能全部显示在同一行。

style 参数是可选的。省略时，文本会使用最近祖先 DefaultTextStyle 的样式。如果给定样式的 TextStyle.inherit 属性为 true（默认值），给定样式会与最近祖先 DefaultTextStyle 合并。例如，可以在保留默认字体系列和字号的同时，将文本加粗。

组件获得焦点时，会通过底层 EditableText 的 AutomaticKeepAliveClientMixin.wantKeepAlive 暂缓销毁，以避免丢失选区。移除焦点后即可销毁。

link 
const SelectableText(
  'Hello! How are you?',
  textAlign: TextAlign.center,
  style: TextStyle(fontWeight: FontWeight.bold),
)

使用 SelectableText.rich 构造函数时，SelectableText widget 可以显示由不同样式 TextSpan 组成的段落。下面的示例会为每个单词应用不同样式，显示“Hello beautiful world”。

link 
const SelectableText.rich(
  TextSpan(
    text: 'Hello', // default text style
    children: <TextSpan>[
      TextSpan(text: ' beautiful ', style: TextStyle(fontStyle: FontStyle.italic)),
      TextSpan(text: 'world', style: TextStyle(fontWeight: FontWeight.bold)),
    ],
  ),
)

交互性

若要让 SelectableText 响应触摸事件，可以使用 onTap 回调实现所需行为。

滚动注意事项

如果此 SelectableText 不在 Scaffold 后代中，并且位于 Scrollable 或嵌套的 Scrollable 中，可以考虑在包含此 SelectableText 的根 Scrollable 上方放置 ScrollNotificationObserver，以确保 SelectableText 及其组件（例如 TextSelectionOverlay）正确协调滚动。

另请参阅：

  • Text, which is the non selectable version of this widget.
  • TextField, which is the editable version of this widget.
  • SelectionArea, which enables the selection of multiple Text widgets and of other widgets.
