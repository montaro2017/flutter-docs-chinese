DataTable 类

遵循 Material 2 设计规范的数据表格。

性能注意事项

列宽会根据表格内容自动确定。使用此组件显示大量数据的开销较高，因为需要测量两次：一次用于协调各列尺寸，另一次用于实际布局表格。

SingleChildScrollView 即使只有部分内容可见，也会装载并绘制整个子组件。若要高效处理大量数据的表格，可以考虑以下其他方案：

  • TableView, a widget from the two_dimensional_scrollables package.
  • PaginatedDataTable, which automatically splits the data into multiple pages.
  • CustomScrollView, for greater control over scrolling effects.

此示例展示如何显示一个 DataTable，包含三列：姓名、年龄和角色。这些列由三个 DataColumn 对象。表格包含三位示例用户的三行数据，其数据由三个 DataRow 对象定义。

DataTable 可以根据 columns 中的任意列进行升序或降序排序。如果 sortColumnIndex 非 null，则表格会按指定列中的值排序。布尔标志 sortAscending 用于控制排序顺序。

另请参阅：

  • DataColumn, which describes a column in the data table.
  • DataRow, which contains the data for a row in the data table.
  • DataCell, which contains the data for a single cell in the data table.
  • PaginatedDataTable, which shows part of the data in a data table and provides controls for paging through the remainder of the data.
  • TableView from the two_dimensional_scrollables package, for displaying large amounts of data without pagination.
