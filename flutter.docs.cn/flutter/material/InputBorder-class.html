InputBorder 类 抽象

定义 InputDecorator 边框的外观。

输入装饰器的边框由 InputDecoration.border 指定。

边框相对于输入装饰器的“容器”绘制；该容器是装饰器上方可选的填充区域，位于辅助文本、错误文本和计数器之上。

输入边框会绘制一条线，其粗细和颜色由 borderSide 定义。输入装饰器的渲染器会在获得或失去焦点等状态变化时，通过 copyWith 创建新的输入边框副本，从而为边框外观添加动画效果。

另请参阅：

  • UnderlineInputBorder，是默认的 InputDecorator 边框，会沿输入装饰器容器底部绘制水平线。
  • OutlineInputBorder，InputDecorator 边框会在输入装饰器容器周围绘制圆角矩形。
  • InputDecoration, which is used to configure an InputDecorator.
