创建 Material Design 次级标签栏。

次级标签用于内容区域内，进一步区分相关内容并建立层级结构。

此示例展示 Material 3 中嵌套的 TabBar。它由一个主 TabBar 和一个嵌套的次级 TabBar 组成。主 TabBar 使用 DefaultTabController，次级 TabBar 使用 TabController。
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.TabBar.TabBar.secondary.1 mysample

另请参阅：

  • TabBar, for a primary tab bar.
  • TabBarView, which displays page views that correspond to each tab.
  • TabController, which coordinates tab selection between a TabBar and a TabBarView.
  • https://m3.material.io/components/tabs/overview, the Material 3 tab bar specification.
