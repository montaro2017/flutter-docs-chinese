Material 类

一块 Material 表面。

Material 组件负责以下事项：

  1. 裁剪：如果 clipBehavior 不为 Clip.none，Material 会按 shape、type 和 borderRadius 指定的形状裁剪组件子树。出于性能考虑，clipBehavior 默认是 Clip.none。有关这对 Ink 组件裁剪效果的示例，请参阅 Ink。
  2. 高度：Material 会沿 Z 轴将组件子树抬高 elevation 像素，并绘制相应的阴影。
  3. 墨水效果：Material 会在子组件下方显示由 InkFeature 实现的墨水效果，例如 InkSplash 和 InkHighlight。

Material 隐喻

Material 是 Material Design 的核心隐喻。每块 Material 都有一定的高度，这会影响它与其他表面之间的视觉关系以及投射阴影的方式。

大多数用户界面元素在概念上要么绘制在 Material 表面上，要么本身由 Material 构成。Material 会通过 InkSplash 和 InkHighlight 效果响应用户输入。若要触发表面反馈，请使用通过 Material.of 获取的 MaterialInkController。

通常，Material 的特征不应随时间变化（例如，Material 不应改变其 color、shadowColor 或 type）。elevation、shadowColor 和 surfaceTintColor 的变化会在 animationDuration 内执行动画。若 type 不是 MaterialType.transparency，且前一个 shape 与后一个 shape 的值之间支持 ShapeBorder.lerp，则形状变化也会在 animationDuration 内执行动画。

形状

Material 的形状由 shape、type 和 borderRadius 决定。

  • If shape is non null, it determines the shape.
  • If shape is null and borderRadius is non null, the shape is a rounded rectangle, with corners specified by borderRadius.
  • If shape 和 borderRadius are null, type determines the shape as follows:
    • MaterialType.canvas: the default material shape is a rectangle.
    • MaterialType.card: the default material shape is a rectangle with rounded edges. The edge radii is specified by kMaterialEdges.
    • MaterialType.circle: the default material shape is a circle.
    • MaterialType.button: the default material shape is a rectangle with rounded edges. The edge radii is specified by kMaterialEdges.
    • MaterialType.transparency: the default material shape is a rectangle.

边框

如果 shape 不为 null（且包含边框），也会绘制其边框。

布局变化通知

布局发生变化时（例如 Material 上的列表滚动后），必须在相关子树中派发 LayoutChangedNotification。具体来说，不应将 SlideTransition 等过渡组件放在 Material 内部，用来移动包含 InkResponse、InkWell、Ink 或其他使用 InkFeature 机制的组件子树。否则，进行中的墨水效果（例如涟漪和高亮）不会随新布局移动。

在 Material 表面上绘制

Material 组件通常会在最近的 Material 祖先上触发反馈。例如，指针悬停在列表项上时，ListTile.hoverColor 会在该列表项的 Material 表面上触发反馈。如果中间的组件以遮挡表面的方式绘制（例如在 DecoratedBox 上设置 BoxDecoration.color），这些反馈就会被遮住。为避免这种情况，可使用 InkDecoration 直接装饰 Material 表面。
