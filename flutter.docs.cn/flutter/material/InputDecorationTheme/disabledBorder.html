disabledBorder 属性

InputBorder? get disabledBorder

覆盖 InputDecoration.disabledBorder 的默认值。

此属性已弃用，并将在未来版本中废弃。请改用 InputDecorationThemeData.disabledBorder（位于 data 中）。

实现

InputBorder? get disabledBorder => _data != null ? _data.disabledBorder : _disabledBorder;
