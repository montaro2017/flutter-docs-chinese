OutlineInputBorder 构造函数

const OutlineInputBorder({
  1. BorderSide borderSide = const BorderSide(),
  2. BorderRadius borderRadius = const BorderRadius.all(Radius.circular(4.0)),
  3. double gapPadding = 4.0,
})

为 InputDecorator 创建圆角矩形轮廓边框。

如果 borderSide 参数为 BorderSide.none，则不会绘制边框。不过，它仍会定义形状（当 InputDecoration.filled 为 true 时可以看到该形状）。

如果应用没有将 borderSide 参数指定为 BorderSide.none，输入装饰器会根据当前主题和 InputDecorator.isFocused，使用 copyWith 替换为自身的边框边侧设置。

borderRadius 参数默认为四个角半径均为 4.0 的圆形半径。角半径必须是圆形，即 Radius.x 和 Radius.y 的值必须相同。

另请参阅：

  • InputDecoration.floatingLabelBehavior, which should be set to FloatingLabelBehavior.never when the borderSide is BorderSide.none. If left as FloatingLabelBehavior.auto, the label will extend beyond the container as if the border were still being drawn.

实现

const OutlineInputBorder({
  super.borderSide = const BorderSide(),
  this.borderRadius = const BorderRadius.all(Radius.circular(4.0)),
  this.gapPadding = 4.0,
}) : assert(gapPadding >= 0.0);
