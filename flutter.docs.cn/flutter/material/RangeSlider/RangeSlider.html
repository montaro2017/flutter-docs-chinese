创建一个 Material Design 范围滑块。

范围滑块 widget 本身不维护状态。滑块状态改变时，widget 会调用 onChanged 回调。大多数使用范围滑块的 widget 都会监听 onChanged 回调，并用新的 values 重新构建滑块，以更新其外观。若要获知数值何时开始变化或何时变化结束，请设置可选回调 onChangeStart 和/或 onChangeEnd。

  • values, which determines currently selected values for this range slider.
  • onChanged, which is called while the user is selecting a new value for the range slider.
  • onChangeStart, which is called when the user starts to select a new value for the range slider.
  • onChangeEnd, which is called when the user is done selecting a new value for the range slider.

可以使用 activeColor 和 inactiveColor 属性覆盖部分颜色；若要更精细地控制外观，请使用 SliderThemeData。

min 必须小于或等于 max。

values 参数的 RangeValues.start 属性必须小于或等于其 RangeValues.end 属性。values 参数的 RangeValues.start 和 RangeValues.end 属性必须大于或等于 min 参数，且小于或等于 max 参数。

divisions 参数必须为 null 或大于零。

     assert(values.start <= values.end),
