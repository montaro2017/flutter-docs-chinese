重写

结合传入的状态绘制此形状。

context 参数与包含Slider 的渲染盒的 context 相同。

center 参数表示此形状中心的绘制偏移量。该偏移量相对于 context 画布原点。

activationAnimation 参数表示用户开始与滑块交互时触发的动画；用户停止交互时，动画会反向播放。

enableAnimation 参数表示在Slider 启用时触发的动画；滑块禁用时，该动画会反向播放。Slider 在Slider.onChanged不为 null 时处于启用状态。滑块启用状态变化时，可用此动画绘制此形状的中间帧。

如果Slider.divisions 不为 null，则 isDiscrete 参数为 true。此时，滑块会在轨道上绘制刻度标记。

如果 labelPainter 参数不为 null，则应调用TextPainter.paint，在 labelPainter 的指定位置绘制标签。如果 labelPainter 参数为 null，则说明没有向Slider提供标签。

parentBox 参数表示RenderBox，即Slider 的 RenderBox。其 size 等属性可用于辅助绘制此形状。

sliderTheme 参数是分配给Slider的主题，此形状属于该滑块。

textDirection 参数用于确定如何摆放额外的文字或图形（即 labelPainter 绘制的文字之外的内容）。labelPainter 已设置好 textDirection。

value 参数表示滑块当前的参数值，范围为 0.0 到 1.0。

textScaleFactor 参数用于确定组件应绘制得更大还是更小，具体取决于textScaleFactor 大于 1 时放大，介于 0 和 1 时缩小。通常根据MediaQueryData.textScaler计算得出。

sizeWithOverflow 参数可用于确定常规滑块边界以外组件的绘制范围。它表示一个矩形框的尺寸，该框的中心与滑块边界对齐，数值指示器必须绘制在框内。通常此尺寸大于滑块本身。

@override
void paint(
  PaintingContext context,
  Offset center, {
  required Animation<double> activationAnimation,
  required Animation<double> enableAnimation,
  required bool isDiscrete,
  required TextPainter labelPainter,
  required RenderBox parentBox,
  required SliderThemeData sliderTheme,
  required TextDirection textDirection,
  required double value,
  required double textScaleFactor,
  required Size sizeWithOverflow,
}) {
  assert(sliderTheme.disabledThumbColor != null);
  assert(sliderTheme.thumbColor != null);
  assert(sliderTheme.thumbSize != null);

  final colorTween = ColorTween(
    begin: sliderTheme.disabledThumbColor,
    end: sliderTheme.thumbColor,
  );
  final Color color = colorTween.evaluate(enableAnimation)!;

  final Canvas canvas = context.canvas;
  final Size thumbSize = sliderTheme.thumbSize!.resolve(
    <WidgetState>{},
  )!; // This is resolved in the paint method.
  final rrect = RRect.fromRectAndRadius(
    Rect.fromCenter(center: center, width: thumbSize.width, height: thumbSize.height),
    Radius.circular(thumbSize.shortestSide / 2),
  );
  canvas.drawRRect(rrect, Paint()..color = color);
}
