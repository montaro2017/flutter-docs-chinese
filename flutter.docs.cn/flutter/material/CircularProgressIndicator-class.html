CircularProgressIndicator 类

Material Design 圆形进度指示器，通过旋转表示应用当前正忙。

沿圆形路径显示进度的组件。圆形进度指示器分为两种：

  • 确定进度。确定型进度指示器在每个时刻都有特定值，该值应从 0.0 单调递增到 1.0；达到 1.0 时，指示器即完成。若要创建确定型进度指示器，请将 value 设为 0.0 到 1.0 之间的非 null 值。
  • 不确定进度。不确定型进度指示器在每个时刻都没有特定值，而是表示进度正在进行，但不显示剩余进度。若要创建不确定型进度指示器，请将 value 设为 null。

指示弧线使用动画值 valueColor 显示。若要指定固定颜色，请使用：AlwaysStoppedAnimation<Color>(color)。

此示例展示了确定进度和不确定进度两种 CircularProgressIndicator。 该CircularProgressIndicator 将采用 ；将 CircularProgressIndicator.year2023 标志设为 false 时即如此。

动画同步

当屏幕上同时有多个 CircularProgressIndicator 或 LinearProgressIndicator 正在播放动画（例如列表中有多个加载项）时，各自独立的动画可能显得杂乱。为解决此问题，可以使用自定义的 AnimationController 驱动指示器动画。

这样便可让多个指示器同步到同一个动画源。为一组指示器实现这一点，最方便的方法是通过 ProgressIndicatorTheme 提供控制器（参见 ProgressIndicatorThemeData.controller）。该主题子树中的所有 CircularProgressIndicator 或 LinearProgressIndicator 都会共享同一动画，使整体效果更加协调悦目。

也可以将特定的 AnimationController 直接传给单个指示器的 controller 属性。

此示例演示如何同步多个 CircularProgressIndicator 的不确定进度动画，并使用 Theme.

点击按钮可添加或移除指示器。默认情况下，它们都会共享 ProgressIndicatorThemeData.controller，从而保持动画同步。

点击“切换”按钮会将主题控制器设为 null。这会使每个指示器创建自己的内部控制器，导致动画不再同步。
