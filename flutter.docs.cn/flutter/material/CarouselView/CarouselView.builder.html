创建一个可滚动轮播视图，其中的固定尺寸条目按需创建。

此构造函数支持延迟加载轮播条目。只会构建当前可见或即将可见的条目，因此在处理大量条目时能提升性能。

仅当索引大于或等于零且小于 itemCount 时，才会调用 itemBuilder 回调。

此示例展示如何通过延迟加载创建包含 1000 个条目的轮播视图：
link

要使用此代码示例创建本地项目，请运行：
flutter create --sample=material.CarouselView.CarouselView.builder.1 mysample

另请参阅：

  • CarouselView.new 用显式子项创建轮播视图。
  • CarouselView.weighted 创建带权重项目的轮播视图。
  • CarouselView.weightedBuilder 通过延迟加载创建带权重项目的轮播视图。
