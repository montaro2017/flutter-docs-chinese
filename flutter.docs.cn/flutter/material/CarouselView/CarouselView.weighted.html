创建一个可滚动列表，其中每个子 widget 的尺寸由提供的 flexWeights 动态决定。

必须提供 flexWeights 参数，用于定义各个子 widget 的相对尺寸比例。

滚动过程中，每个可见条目沿主轴的范围（尺寸）会根据滚动进度动态变化。交叉轴范围由父级约束决定。当第一个可见条目完全滚出屏幕后，下一个条目会成为第一个可见条目，并获得原先首个条目的尺寸。其余可见条目则保持彼此之间的相对布局。

例如，布局权重为 [1, 6, 1] 时，flexWeights 的长度表示同时显示三个条目。它们的布局如下：

  • First item: Extent is (1 / (1 + 6 + 1)) * viewport extent.
  • Second item: Extent is (6 / (1 + 6 + 1)) * viewport extent.
  • Third item: Extent is (1 / (1 + 6 + 1)) * viewport extent.

假设主轴视口范围为 800，首个条目是条目 0，则三个可见条目的范围分别为 100、600 和 100。条目 0 滚出屏幕时，条目 1 的范围会从 600 平滑缩小到 100。例如，条目 0 有 30% 滚出屏幕时，条目 1 的尺寸应缩小 600 与 100 之差的 30%，即 600 - 0.3 * (600 - 100)。类似地，条目 2 的范围会从 100 增加到 600，即 100 + 0.3 * (600 - 100)。

最初可见的条目在滚动中改变尺寸时，条目 3 会进入视野并填补剩余空间。它的范围从 shrinkExtent 的最小值开始（未提供 shrinkExtent 时为 0），然后逐渐增大到与最后一个可见条目的范围相同（本例中为 100）。

将 consumeMaxWeight 设为 true 后，每个子项在滚动时都可以扩展到最大权重。例如，flexWeights 为 [1, 7, 1] 时，第一项的初始权重为 1。启用 consumeMaxWeight 并向前滚动后，第一项可以扩展到权重 7，并在其前方留下权重为 1 的空白。此功能特别适用于 Material Design 3 中所示的 Hero 和 Center-aligned hero 布局。
