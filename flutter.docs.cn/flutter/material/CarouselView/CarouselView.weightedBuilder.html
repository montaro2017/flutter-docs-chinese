创建一个可滚动轮播视图，其中的加权条目按需创建。

此构造函数结合了 CarouselView.weighted 与延迟加载的优点。它会按需构建条目，同时保持加权布局系统。

flexWeights 参数决定布局，itemBuilder 则会在条目即将可见时创建条目。

此示例展示如何创建带有延迟加载的加权轮播视图：
link 
CarouselView.weightedBuilder(
  flexWeights: const <int>[1, 7, 1],
  itemCount: 100,
  itemBuilder: (BuildContext context, int index) {
    return ColoredBox(
      color: Colors.primaries[index % Colors.primaries.length],
      child: Center(
        child: Text('Item $index'),
      ),
    );
  },
)
