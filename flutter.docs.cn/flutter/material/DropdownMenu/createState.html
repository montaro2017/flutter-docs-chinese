createState 方法

  1. @重写
State<DropdownMenu<T>> createState()
重写

为组件在树中的给定位置创建可变状态。

子类应重写此方法，返回新创建的关联 State 子类实例：

@override
State<SomeWidget> createState() => _SomeWidgetState();

在 StatefulWidget 的生命周期中，框架可能多次调用此方法。例如，如果组件被插入树中的多个位置，框架会为每个位置分别创建一个 State 对象。同样，如果组件从树中移除后又重新插入，框架会再次调用 createState 来创建新的 State 对象，从而简化 State 对象的生命周期。

实现

@override
State<DropdownMenu<T>> createState() => _DropdownMenuState<T>();
