SliverAppBar 类

一种可与 CustomScrollView 集成的 Material Design 应用栏。

应用栏由工具栏组成，也可能包含其他组件，例如 TabBar 和 FlexibleSpaceBar。应用栏通常通过 IconButton 提供一个或多个常用操作，也可在末尾放置 PopupMenuButton 来提供较少使用的操作。

Sliver 应用栏通常作为 CustomScrollView 的第一个子项，这样它可以与滚动视图集成，根据滚动偏移改变高度，或浮在其他内容上方。若需要固定高度并显示在屏幕顶部的应用栏，请使用 AppBar，并将其放在 Scaffold.appBar 插槽中。

leading、title 和 actions 等工具栏组件显示在 bottom（如果有）上方。如果指定了 flexibleSpace，它会叠放在工具栏和底部组件后方。

以下示例可放入 CustomScrollView 的 CustomScrollView.slivers 列表中：
link 
SliverAppBar(
  expandedHeight: 150.0,
  flexibleSpace: const FlexibleSpaceBar(
    title: Text('Available seats'),
  ),
  actions: <Widget>[
    IconButton(
      icon: const Icon(Icons.add_circle),
      tooltip: 'Add new entry',
      onPressed: () { /* ... */ },
    ),
  ]
)

另请参阅：

  • CustomScrollView，它会将 SliverAppBar 集成到滚动内容中。
  • AppBar，固定高度的应用栏，可放在 Scaffold.appBar 中。
  • TabBar，屏幕中有多个标签页时，通常放在 bottom 插槽中，该插槽属于 AppBar。
  • IconButton 与 actions 配合，用于在应用栏中显示按钮。
  • PopupMenuButton 可通过 actions 在应用栏中显示弹出菜单。
  • FlexibleSpaceBar 与 flexibleSpace 配合，在应用栏可展开和折叠时使用。
