MenuStyle 类

菜单共有的视觉属性。

由 MenuBar 和 MenuAnchor 创建的菜单及其主题具有 MenuStyle 属性，用于指定要覆盖默认值的视觉属性。默认值由各个菜单 widget 定义，通常基于整体主题的 ThemeData.colorScheme 和 ThemeData.textTheme。

默认情况下，MenuStyle 的所有属性均为 null。

MenuStyle 的许多属性都是 WidgetStateProperty 对象，会根据菜单状态解析为不同值。例如，Color 属性由 WidgetStateProperty<Color> 定义，菜单按下、悬停、获得焦点、禁用等状态下可解析为不同颜色。

这些属性可以只覆盖某个状态或所有状态的默认值。例如，要创建一个 SubmenuButton，使其菜单按下时背景色为半透明度 50% 的颜色方案主色，可以这样编写：

SubmenuButton(
  menuStyle: MenuStyle(
    backgroundColor: WidgetStateProperty.resolveWith<Color?>(
      (Set<WidgetState> states) {
        if (states.contains(WidgetState.focused)) {
          return Theme.of(context).colorScheme.primary.withValues(alpha: 0.5);
        }
        return null; // Use the component's default.
      },
    ),
  ),
  menuChildren: const <Widget>[ /* ... */ ],
  child: const Text('Fly me to the moon'),
),

在此例中，其他菜单状态下的背景色会回退到 SubmenuButton 的默认值。若要无条件设置菜单在所有状态下的 backgroundColor，可以这样编写：

const SubmenuButton(
  menuStyle: MenuStyle(
    backgroundColor: WidgetStatePropertyAll<Color>(Colors.green),
  ),
  menuChildren: <Widget>[ /* ... */ ],
  child: Text('Let me play among the stars'),
),

若要以相同方式配置应用中的所有菜单，请在整体主题中指定 menuTheme：

MaterialApp(
  theme: ThemeData(
    menuTheme: const MenuThemeData(
      style: MenuStyle(backgroundColor: WidgetStatePropertyAll<Color>(Colors.red)),
    ),
  ),
  home: const MyAppHome(),
),

另请参阅：

  • MenuAnchor, a widget which hosts cascading menus.
  • MenuBar, a widget which defines a menu bar of buttons hosting cascading menus.
  • MenuButtonTheme, the theme for SubmenuButtons and MenuItemButton。
  • ButtonStyle, a similar configuration object for button styles.
