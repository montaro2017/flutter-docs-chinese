CarouselView 类

一种 Material Design 轮播组件。

CarouselView 会呈现可滚动的条目列表，每个条目的尺寸都可以根据所选布局动态变化。

当 infinite 为 true 时，轮播视图会创建无限循环的条目，允许向两个方向连续滚动。

Material Design 3 引入了 4 种轮播布局：

  • Multi-browse: This layout shows at least one large, medium, and small carousel item at a time. This layout is supported by CarouselView.weighted.
  • Uncontained (default): This layout show items that scroll to the edge of the container. This layout is supported by CarouselView.
  • Hero: This layout shows at least one large and one small item at a time. This layout is supported by CarouselView.weighted.
  • Full-screen: This layout shows one edge-to-edge large item at a time and scrolls vertically. The full-screen layout can be supported by both constructors.

默认构造函数实现非容纳式布局模型，条目会滚动到容器边缘，行为类似于所有子项尺寸一致的 ListView。CarouselView.weighted 支持动态调整条目尺寸：每个条目会分配一个权重，以决定其占据的视口比例。此构造函数可用于创建多内容浏览、Hero 等布局。若要使用 CarouselView 实现全屏布局，请将 itemExtent 设为屏幕尺寸；若使用 CarouselView.weighted，则将 flexWeights 设为只包含一个整数的数组。

Scaffold(
  body: CarouselView(
    scrollDirection: Axis.vertical,
    itemExtent: double.infinity,
    children: List<Widget>.generate(10, (int index) {
      return Center(child: Text('Item $index'));
    }),
  ),
),

// ...

Scaffold(
  body: CarouselView.weighted(
    scrollDirection: Axis.vertical,
    flexWeights: const <int>[1], // Or any positive integers as long as the length of the array is 1.
    children: List<Widget>.generate(10, (int index) {
      return Center(child: Text('Item $index'));
    }),
  ),
),

在 CarouselView.weighted 中，权重表示相对比例。例如，布局权重为 [3, 2, 1] 时，第一个可见条目占据视口的 3/6，第二个占据 2/6，最后一个占据 1/6。轮播视图滚动时，后一个条目的尺寸会逐渐变为前一个条目的尺寸。因此，当第一个可见条目完全滚出屏幕后，其余条目会延续之前的布局。使用 CarouselView.weighted 可以构建多内容浏览、Hero、居中 Hero 和全屏布局，如 Carousel specs所示。

CarouselController 用于控制 CarouselController.initialItem，后者决定初次显示 CarouselView 或 CarouselView.weighted 时第一个完全展开的条目。对于 CarouselView，每个条目尺寸固定，因此很容易确定。对于 CarouselView.weighted，例如权重为 [1, 2, 3, 2, 1] 且初始条目为 4（第四项）时，视图会显示条目 2、3、4、5 和 6，其权重分别为 1、2、3、2 和 1。

CarouselView.itemExtent 属性必须为非 null，并定义条目的基础尺寸。条目通常保持此尺寸，但滚动期间第一个和最后一个可见条目可能会略微压缩。shrinkExtent 属性用于控制这些压缩条目允许达到的最小尺寸。

在桌面平台上运行的桌面端和 Web 环境中，默认禁用使用鼠标拖动滚动，以符合自然的交互习惯。

为了进一步符合此类预期行为，可以在滚动鼠标滚轮时按住 Shift 键，以水平滚动。

此键盘驱动的行为由 ScrollBehavior.pointerAxisModifiers 决定，而 ScrollBehavior.dragDevices 用于管理哪些设备可以拖动可滚动组件。
