TooltipThemeData 类

为后代 Tooltip widget 定义默认属性值。

后代 widget 使用 TooltipTheme.of 获取当前的 TooltipThemeData 对象。TooltipThemeData 实例可以通过 TooltipThemeData.copyWith 自定义其实例。

通常会通过 ThemeData.tooltipTheme，将 TooltipThemeData 指定为整体 Theme 的一部分。

另请参阅：

  • TooltipTheme, a widget which overrides the tooltip theme for a subtree.
  • ThemeData.tooltipTheme, which specifies a tooltip theme as part of an overall theme.
  • MaterialApp.theme, which specifies a theme for the whole application.
