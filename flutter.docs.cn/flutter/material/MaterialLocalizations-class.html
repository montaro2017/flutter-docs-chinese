MaterialLocalizations
description

MaterialLocalizations 类 abstract

定义 Material 组件使用的本地化资源值。

另请参阅：

  • DefaultMaterialLocalizations 是此接口的默认实现，仅支持英语 。
  • GlobalMaterialLocalizations 为多种语言提供 Material 本地化支持 。
实现类
  • DefaultMaterialLocalizations
  • GlobalMaterialLocalizations
