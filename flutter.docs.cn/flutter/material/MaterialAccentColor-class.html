MaterialAccentColor 类

定义一种强调色，并提供该强调色的四种色阶。

颜色的色阶通过索引引用：索引越小，颜色越浅；索引越大，颜色越深。有效索引为 100、200、400 和 700。此颜色的值应与索引 200 的颜色以及 shade200 相同。

另请参阅：

  • Colors, which defines all of the standard material colors.
  • material.io/go/design-theming#color-color-schemes
