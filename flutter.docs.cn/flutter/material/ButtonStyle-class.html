ButtonStyle 类

按钮共有的视觉属性。

按钮及其主题都具有 ButtonStyle 属性，用于指定要覆盖默认值的视觉属性。默认值由各个按钮 widget 定义，通常基于整体主题的 ThemeData.colorScheme 和 ThemeData.textTheme。

默认情况下，所有 ButtonStyle 属性均为 null。

许多 ButtonStyle 属性都是 WidgetStateProperty 对象，会根据按钮状态解析为不同的值。例如，Color 属性由 WidgetStateProperty<Color> 定义，可根据按钮是否被按下、悬停、聚焦或禁用等状态解析为不同颜色。

这些属性可以只覆盖某个状态或覆盖所有状态的默认值。例如，若要创建一个 ElevatedButton，使其仅在按下时将背景设为主题配色方案中的主色并使用 50% 不透明度，可以这样编写：

ElevatedButton(
  style: ButtonStyle(
    backgroundColor: WidgetStateProperty.resolveWith<Color?>(
      (Set<WidgetState> states) {
        if (states.contains(WidgetState.pressed)) {
          return Theme.of(context).colorScheme.primary.withValues(alpha: 0.5);
        }
        return null; // Use the component's default.
      },
    ),
  ),
  child: const Text('Fly me to the moon'),
  onPressed: () {
    // ...
  },
),

在此示例中，其他按钮状态的背景色会回退到 ElevatedButton 的默认值。若要无条件地为所有状态设置按钮的 backgroundColor，可以这样编写：

ElevatedButton(
  style: const ButtonStyle(
    backgroundColor: WidgetStatePropertyAll<Color>(Colors.green),
  ),
  child: const Text('Let me play among the stars'),
  onPressed: () {
    // ...
  },
),

直接配置 ButtonStyle，可以非常精确地控制按钮在所有状态下的视觉属性。需要自定义品牌外观时，通常需要这种控制粒度。不过，很多时候只需根据少数几个简单参数，大范围调整按钮样式。按钮的 styleFrom() 方法可以实现这种调整，例如：ElevatedButton.styleFrom、FilledButton.styleFrom、OutlinedButton.styleFrom 和 TextButton.styleFrom。

例如，若要覆盖 TextButton 的默认文本颜色、图标颜色和叠加层颜色，同时保留按下、聚焦和悬停状态下标准的不透明度调整，可以这样编写：

TextButton(
  style: TextButton.styleFrom(foregroundColor: Colors.green),
  child: const Text('Let me see what spring is like'),
  onPressed: () {
    // ...
  },
),

若要以相同方式配置应用中的所有文本按钮，请指定整体主题的 textButtonTheme：

MaterialApp(
  theme: ThemeData(
    textButtonTheme: TextButtonThemeData(
      style: TextButton.styleFrom(foregroundColor: Colors.green),
    ),
  ),
  home: const MyAppHome(),
),

Material 3 按钮类型

Material Design 3 定义了五种常见按钮类型。Flutter 通过以下按钮类提供支持：

Type Flutter implementation
Elevated ElevatedButton
Filled FilledButton
Filled Tonal FilledButton.tonal
Outlined OutlinedButton
Text TextButton
