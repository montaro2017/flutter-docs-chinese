根据按需创建的 Widget 项构建可重新排序的列表。

当列表视图包含大量子项时，适合使用此构造函数，因为 builder 只会为当前可见的子项调用。

itemBuilder 回调只会收到大于或等于零且小于 itemCount 的索引。

itemBuilder 必须始终返回非 null 的 Widget，并在调用时实际创建该 Widget 实例。避免使用返回预先构造 Widget 的 builder。如果列表视图的子项已提前创建，或在创建 ReorderableListView 本身时一次性全部创建，使用 ReorderableListView 构造函数会更高效。不过，最高效的方式是使用此构造函数的 itemBuilder 回调按需创建实例。

此示例使用 ReorderableListView.builder 构造函数创建列表。借助 IndexedWidgetBuilder，列表项会在需要时延迟构建。

const ReorderableListView.builder({
  super.key,
  required this.itemBuilder,
  required this.itemCount,
  @Deprecated(
    'Use the onReorderItem callback instead. '
    'The onReorderItem callback adjusts the newIndex parameter for a removed item at the oldIndex. '
    'This feature was deprecated after v3.41.0-0.0.pre.',
  )
  this.onReorder,
  this.onReorderItem,
