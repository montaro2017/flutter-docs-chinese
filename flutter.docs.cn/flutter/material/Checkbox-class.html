Checkbox 类

一种 Material Design 复选框。

复选框本身不维护状态。状态变化时，widget 会调用 onChanged 回调。大多数使用复选框的 widget 都会监听 onChanged 回调，并使用新的 value 重建复选框，以更新其视觉外观。

如果 tristate 为 true，复选框可以显示 true、false 和 null 三种值。value 为 null 时会显示短横线。默认情况下，tristate 为 false，此时复选框的 value 必须为 true 或 false。

其祖先组件中必须有一个 Material 组件。

此示例展示如何借助 WidgetStateProperty 覆盖 Checkbox 的默认主题。当 Checkbox 被按下、悬停或聚焦时，其颜色为 Colors.blue；否则为 Colors.red。
