DataTableThemeData 类

为后代 DataTable 组件定义默认属性值。

后代组件会通过 DataTableTheme.of 获取当前的 DataTableThemeData 对象。DataTableThemeData 实例可使用 DataTableThemeData.copyWith 进行自定义。

通常会将 DataTableThemeData 作为整体 Theme 的一部分，通过 ThemeData.dataTableTheme 指定。

DataTableThemeData 的所有属性默认均为 null。当属性为 null 时，DataTable 会使用 ThemeData 中定义的值（如果存在）；否则会根据整体 Theme 的 textTheme 和 colorScheme 提供默认值。详情请参阅各个 DataTable 属性。

  • ThemeData，用于描述应用的整体主题信息。
