重写

根据传入的状态绘制值指示器形状。

context 参数表示 RangeSlider 的渲染盒。

center 参数是绘制此形状中心位置的偏移量。此偏移量相对于 context 画布的原点。

activationAnimation 参数表示用户开始与 RangeSlider 交互时触发的动画；用户停止与滑块交互时，动画会反向播放。

enableAnimation 参数表示启用 RangeSlider 时触发的动画；滑块禁用时动画会反向播放。若 RangeSlider 的 RangeSlider.onChanged 不为 null，则滑块处于启用状态。滑块启用状态变化时，可用此参数绘制该形状的过渡帧。

当 isDiscrete 为 true（即 RangeSlider.divisions 非 null）时，滑块会在轨道上绘制刻度线。

isOnTop 表示两个值指示器中位于最上层的那个，也就是最近选中的滑块拇指对应的指示器。默认情况下，系统会为最上层指示器绘制描边，以便区分两个指示器。

textScaleFactor 可用于确定组件应放大还是缩小绘制：当 textScaleFactor 大于 1 时放大，介于 0 和 1 之间时缩小。此值通常根据 MediaQueryData.textScaler 计算。

sizeWithOverflow 参数用于确定常规滑块边界之外组件的绘制范围。它是一个盒子的尺寸，该盒子的中心与滑块边界对齐，值指示器必须绘制在其中。通常此尺寸大于滑块本身。

parentBox 参数是 RenderBox（即 RangeSlider）的 RenderBox。其 size 等属性可用于辅助绘制此形状。

sliderTheme 参数是应用于此形状所属 RangeSlider 的主题。

textDirection 参数可用于确定除 labelPainter 所绘制文本之外的额外文本或图形的定位方式。labelPainter 已设置好 textDirection。

value 参数是滑块当前的参数化值，范围为 0.0 到 1.0。

thumb 参数用于指定此方法应绘制两个拇指中的哪一个（起点或终点）。

@override
void paint(
  PaintingContext context,
  Offset center, {
  required Animation<double> activationAnimation,
  required Animation<double> enableAnimation,
  bool? isDiscrete,
  bool? isOnTop,
  required TextPainter labelPainter,
  double? textScaleFactor,
  Size? sizeWithOverflow,
  required RenderBox parentBox,
  required SliderThemeData sliderTheme,
  TextDirection? textDirection,
  double? value,
  Thumb? thumb,
}) {
  final Canvas canvas = context.canvas;
  final double scale = activationAnimation.value;
  _pathPainter.paint(
    parentBox: parentBox,
    canvas: canvas,
    center: center,
    scale: scale,
    labelPainter: labelPainter,
    textScaleFactor: textScaleFactor!,
    sizeWithOverflow: sizeWithOverflow!,
    backgroundPaintColor: sliderTheme.valueIndicatorColor!,
    strokePaintColor: isOnTop!
        ? sliderTheme.overlappingShapeStrokeColor
        : sliderTheme.valueIndicatorStrokeColor,
  );
}
