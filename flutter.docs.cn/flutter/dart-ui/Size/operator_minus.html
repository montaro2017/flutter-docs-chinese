Size 的二元减法运算符。

从一个 Size 中减去另一个 Size，会返回一个 Offset，用于表示左侧操作数比右侧操作数大多少。将所得 Offset 加到作为右侧操作数的 Size 上，会返回一个与左侧操作数相等的 Size，即与左侧操作数的 Size 相同。也就是说，如果 sizeA - sizeB -> offsetA，则 offsetA + sizeB -> sizeA。

将 Offset 从 Size 中减去，会返回一个小于 Size 操作数的 Size，缩小量由 Offset 操作数给出。换言之，返回的 Size 的 width 等于左侧操作数的 width 减去右侧操作数的 Offset.dx；其 height 等于左侧操作数的 height 减去右侧操作数的 Offset.dy。

实现

OffsetBase operator -(OffsetBase other) {
  if (other is Size) {
    return Offset(width - other.width, height - other.height);
  }
  if (other is Offset) {
    return Size(width - other.dx, height - other.dy);
  }
  throw ArgumentError(other);
}
