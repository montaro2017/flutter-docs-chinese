LineMetrics

LineMetrics 类

LineMetrics 用于保存段落中单行的度量数据和统计信息。

这里的度量针对整行，表示该行的最大范围，而不是单个文本运行或字形的度量。若需更详细的度量信息，请参阅 TextBox 和 Paragraph.getBoxesForRange。

应直接通过 Paragraph.computeLineMetrics 方法获取 LineMetrics。
