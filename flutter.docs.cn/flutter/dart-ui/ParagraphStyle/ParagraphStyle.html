创建一个新的 ParagraphStyle 对象。

  • textAlign：段落各行中的文本对齐方式。如果最后一行被省略（见下文的 ellipsis），则会在该行截断后、添加省略号之前应用对齐方式。参见：https://github.com/flutter/flutter/issues/9819

  • textDirection：文本方向，即从左向右（例如挪威语）或从右向左（例如希伯来语）。它决定段落的整体方向，以及 textAlign 字段中 TextAlign.start 和 TextAlign.end 的含义。

  • maxLines：绘制的最大行数。超出此数量的行会被静默丢弃。例如，如果 maxLines 为 1，则只渲染一行。如果 maxLines 为 null，但 ellipsis 不为 null，则超出宽度约束的第一行之后的行都会被丢弃。宽度约束由传递给 Paragraph.layout 方法的 ParagraphConstraints 对象设置。

  • fontFamily：绘制文本时使用的字体系列名称；当文本范围未附加 textStyle 时使用。

  • fontSize：绘制文本时使用的字形回退尺寸（逻辑像素）。没有 TextStyle 时会使用此值。

  • height：文本范围的回退高度，以字体大小的倍数表示。若未通过 TextStyle.height 指定高度，则使用此回退值。在此处以及 TextStyle 中省略 height（或将其设为 kTextHeightNone），可让行高采用字体定义的高度；该高度可能与 fontSize 不完全相同。

  • textHeightBehavior：指定如何将 height 倍数应用于首行的上升部和末行的下降部。

  • leadingDistribution：指定由 height 倍数增加的额外垂直空间如何分配到文本上方和下方。默认值为 TextLeadingDistribution.proportional。

  • fontWeight：绘制文本时使用的字重（例如粗体）。

  • fontStyle：绘制字母时使用的字体样式变体（例如斜体）。

  • strutStyle：支柱样式的属性。支柱定义一组最小行高相关度量，可用于实现更高级的行间距行为。

  • ellipsis：用于省略溢出文本的字符串。如果 maxLines 不为 null，则在最后一个渲染行超出宽度约束时（如有设置）应用 ellipsis。如果 maxLines 为 null，则对第一个超出宽度约束的行应用 ellipsis，并丢弃后续行。宽度约束由传递给 Paragraph.layout 方法的 ParagraphConstraints 对象设置。空字符串和 null 等效，都会关闭此行为。

  • locale：用于选择特定地区字形的区域设置。
