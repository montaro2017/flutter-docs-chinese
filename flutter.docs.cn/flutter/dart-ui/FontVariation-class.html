FontVariation

FontVariation 类

可用于自定义可变字体的轴标签和值。

某些字体是可变字体，通过调整字体设计轴的值，可以生成一系列不同的字形样式。

例如：

const TextStyle(fontVariations: <ui.FontVariation>[ui.FontVariation('slnt', -5.0)])

字体变体与 FontFeature 类提供的字体特性不同。字体特性可以离散地启用或禁用，而字体变体提供的是连续可调的控制轴。

另请参阅：

  • learn.microsoft.com/en-us/typography/opentype/spec/dvaraxisreg#registered-axis-tags 列出了已注册的轴标签。

  • docs.microsoft.com/en-us/typography/opentype/spec/otvaroverview 概述了字体变体技术。
