Paragraph

Paragraph 类 抽象

一段文本。

段落会保留文本中每个字形的大小和位置，并且可以高效地调整大小和绘制。

要创建 Paragraph 对象，请使用 ParagraphBuilder。

可以使用 Canvas.drawParagraph 方法，在 Canvas 上显示段落。
