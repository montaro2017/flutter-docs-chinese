Paragraph

Paragraph 类 抽象

一段文本。

段落会保留文本中每个字形的大小和位置，并且可以高效地调整大小和绘制。

要创建 Paragraph 对象，请使用 ParagraphBuilder。

可以使用 Canvas.drawParagraph 方法，在 Canvas 上显示段落。

方法

computeLineMetrics() → List<LineMetrics>
返回完整的 LineMetrics 列表，详细描述布局后每一行的各项 度量信息。
dispose() → void
释放此对象使用的资源。调用此方法后，该对象将无法继续使用。
getBoxesForPlaceholders() → List<TextBox>
返回包含段落中所有占位符的文本框列表。
getBoxesForRange(int start, int end, {BoxHeightStyle boxHeightStyle = BoxHeightStyle.tight, BoxWidthStyle boxWidthStyle = BoxWidthStyle.tight}) → List<TextBox>
返回包含给定文本范围的文本框列表。
getClosestGlyphInfoForOffset(Offset offset) → GlyphInfo?
返回 GlyphInfo，表示段落坐标系中距离给定 offset 最近的字形；如果文本为空，或已被完全裁剪或省略，则返回 null。
getGlyphInfoAt(int codeUnitOffset) → GlyphInfo?
返回 GlyphInfo，其位于段落中给定 UTF-16 codeUnitOffset 处；如果给定的 codeUnitOffset 超出可见 行范围或该位置已被省略，则返回 null。
getLineBoundary(TextPosition position) → TextRange
返回 TextRange，即给定 TextPosition 所在行的范围。
getLineMetricsAt(int lineNumber) → LineMetrics?
返回 lineNumber 所在行的 LineMetrics；如果给定的 lineNumber 大于或等于 numberOfLines，则返回 null。
getLineNumberAt(int codeUnitOffset) → int?
返回 codeUnitOffset 指向的代码单元所在行的行号。
getPositionForOffset(Offset offset) → TextPosition
返回距离给定偏移量最近的文本位置。
getWordBoundary(TextPosition position) → TextRange
返回 TextRange，即给定 TextPosition 所在单词的范围。
layout(ParagraphConstraints constraints) → void
计算段落中每个字形的大小和位置。
