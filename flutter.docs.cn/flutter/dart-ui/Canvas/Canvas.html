创建一个画布，用于将图形操作记录到给定的图片记录器中。

实现可能会丢弃完全位于给定 cullRect 之外、且会影响像素的图形操作。不过，例如某条命令部分绘制在 cullRect 内外时，实现仍可能在这些边界之外绘制。若要确保丢弃指定区域之外的像素，可考虑使用 clipRect。cullRect 是可选参数；默认情况下会保留所有操作。

若要结束记录，请对给定记录器调用 PictureRecorder.endRecording。
