将一组 Vertices 作为一个或多个三角形绘制到画布上。

Paint.color 属性指定三角形使用的默认颜色。

如果设置了 Paint.shader 属性，它会完全覆盖颜色，改用指定的 ImageShader、Gradient 或其他着色器提供的颜色。

blendMode 参数用于控制如何将 vertices 中的颜色与 paint 中的颜色组合。如果 vertices 未指定颜色，blendMode 不起作用。如果 vertices 指定了颜色，则会使用 blendMode 参数，将 paint 中 Paint.shader 或 Paint.color 提供的颜色与 vertices 中指定的颜色混合。在此混合过程中，paint 参数中的颜色视为源，vertices 中的颜色视为目标。BlendMode.dst 会忽略 paint，只使用 vertices 的颜色；BlendMode.src 会忽略 vertices 的颜色，只使用 paint 中的颜色。

所有参数都不得为 null。

另请参阅：

  • Vertices.new, which creates a set of vertices to draw on the canvas.
  • Vertices.raw, which creates the vertices using typed data lists rather than unencoded lists.
  • paint, Image shaders can be used to draw images on a triangular mesh.
