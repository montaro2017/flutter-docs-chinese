saveLayer abstract 方法

void saveLayer(

将当前变换和裁剪状态的副本保存到保存栈中，然后创建一个新组，后续调用都会绘制到该组中。之后弹出保存栈时，该组会展平到一个图层中，并应用给定 paint 的 Paint.colorFilter 和 Paint.blendMode。

这样可以创建合成效果，例如让一组绘图命令呈现半透明效果。如果不使用 saveLayer，组内各部分会分别绘制，因此重叠区域会比非重叠区域更暗。使用 saveLayer 将它们编为一组后，可以先以不透明颜色绘制整个组，再通过 saveLayer 的画笔使整个组透明。

调用 restore 可弹出保存栈，并将画笔应用到该组。

将 saveLayer 与裁剪配合使用

当矩形裁剪操作（通过 clipRect 执行）与光栅缓冲区的坐标轴不对齐，或裁剪操作不是直线边界（例如由 clipRRect 创建的圆角矩形裁剪，或由 clipPath 创建的任意复杂路径裁剪）时，裁剪边缘需要进行抗锯齿处理。

如果两个绘制调用在此类裁剪区域的边缘重叠，且没有使用 saveLayer，第一次绘制会先与背景进行抗锯齿混合；随后第二次绘制会与第一次绘制和背景混合后的结果进行抗锯齿混合。相反，如果在建立裁剪后立即使用 saveLayer，第二次绘制会在图层中覆盖第一次绘制。因此图层被裁剪并合成时（调用 restore 时），只有第二次绘制会与背景进行抗锯齿混合。

例如，下面这个 CustomPainter.paint 方法会绘制一个边缘干净的白色圆角矩形：

void paint(Canvas canvas, Size size) {
  Rect rect = Offset.zero & size;
  canvas.save();
  canvas.clipRRect(RRect.fromRectXY(rect, 100.0, 100.0));
  canvas.saveLayer(rect, Paint());
  canvas.drawPaint(Paint()..color = Colors.red);
  canvas.drawPaint(Paint()..color = Colors.white);
  canvas.restore();
  canvas.restore();
}

而下面这个方法会绘制红色轮廓：红色画笔先在裁剪边缘与背景进行抗锯齿混合，随后白色画笔也与背景（其中包括已裁剪的红色绘制结果）进行类似的抗锯齿混合：

void paint(Canvas canvas, Size size) {
  // (this example renders poorly, prefer the example above)
  Rect rect = Offset.zero & size;
  canvas.save();
  canvas.clipRRect(RRect.fromRectXY(rect, 100.0, 100.0));
  canvas.drawPaint(Paint()..color = Colors.red);
  canvas.drawPaint(Paint()..color = Colors.white);
  canvas.restore();
}

如果裁剪只影响一次绘制操作，则无需考虑这个问题。例如，下面的绘制方法会画出两个边缘干净的白色圆角矩形，即使裁剪没有放在单独的图层中执行：

void paint(Canvas canvas, Size size) {
  canvas.save();
  canvas.clipRRect(RRect.fromRectXY(Offset.zero & (size / 2.0), 50.0, 50.0));
  canvas.drawPaint(Paint()..color = Colors.white);
  canvas.restore();
  canvas.save();
  canvas.clipRRect(RRect.fromRectXY(size.center(Offset.zero) & (size / 2.0), 50.0, 50.0));
  canvas.drawPaint(Paint()..color = Colors.white);
  canvas.restore();
}

顺便一提，像这样绘制圆角矩形时，不必使用 clipRRect 和 drawPaint，优先使用 drawRRect 方法。这些示例使用 drawPaint 代指“会被裁剪的复杂绘制操作”，以说明上述问题。

性能注意事项

一般来说，saveLayer 的开销相对较大。

GPU（图形处理器，即负责处理图形的硬件）有多种硬件架构，但大多数都会批量处理命令并重新排序以提升性能。使用图层时，渲染管线必须切换渲染目标（从一个图层切换到另一个图层）。切换渲染目标可能会刷新 GPU 命令缓冲区，这通常会使大批量处理带来的优化失效。切换渲染目标还会产生大量内存开销：GPU 需要将当前帧缓冲区内容从针对写入优化的内存区域复制出来，并在恢复先前的渲染目标（图层）时再复制回去。
