将图像的多个部分（即 atlas）绘制到画布上。

当需要将图像的多个部分绘制到画布上时（例如使用精灵图或进行缩放），此方法可优化绘制过程。它比多次调用 drawImageRect 更高效，还提供更多功能：可以分别旋转或缩放各图像部分，并使用纯色与这些部分混合或调制。

此方法接收一个 Rect 对象列表，每个对象分别定义 atlas 图像中要独立绘制的一部分。每个 Rect 都与 transforms 列表中的一个 RSTransform 条目对应，该条目定义图像部分的绘制位置、旋转角度和统一缩放比例。每个 Rect 还可以关联一个可选的 Color；绘制到画布前，会先使用 blendMode 将该颜色与对应的图像部分合成。整个操作可分解为以下步骤：

  • 使用 blendMode 参数，将 rects 参数中每个条目指定的图像矩形部分与 colors 列表中对应的颜色混合（如果指定了颜色）。在此操作阶段，图像部分视为源，关联的颜色视为目标。
  • 使用 transforms 列表中对应条目所表示的平移、旋转和缩放属性，并结合 Paint 对象的属性，将第一步的结果混合到画布上。

如果需要执行第一阶段（将图像的各部分分别与颜色混合），则 colors 和 blendMode 参数都不得为 null，并且 colors 列表中必须为每个图像部分提供一个条目。如果不需要此阶段，colors 参数可以为 null 或空列表，blendMode 参数也可以为 null。

可选的 cullRect 参数可以提供图集所有部分绘制后坐标边界的估算值。系统会将其与裁剪区域比较；如果两者没有交集，就可以快速跳过此次操作。

以下示例展示了如何从单个精灵图集中绘制多个不旋转、不缩放的精灵：

class Sprite {
  Sprite(this.index, this.center);
  int index;
  Offset center;
}

class MyPainter extends CustomPainter {
  MyPainter(this.spriteAtlas, this.allSprites);

  // assume spriteAtlas contains N 10x10 sprites side by side in a (N*10)x10 image
  ui.Image spriteAtlas;
  List<Sprite> allSprites;

  @override
  void paint(Canvas canvas, Size size) {
    Paint paint = Paint();
    canvas.drawAtlas(spriteAtlas, <RSTransform>[
      for (final Sprite sprite in allSprites)
        RSTransform.fromComponents(
          rotation: 0.0,
          scale: 1.0,
          // Center of the sprite relative to its rect
          anchorX: 5.0,
          anchorY: 5.0,
          // Location at which to draw the center of the sprite
          translateX: sprite.center.dx,
          translateY: sprite.center.dy,
        ),
    ], <Rect>[
      for (final Sprite sprite in allSprites)
        Rect.fromLTWH(sprite.index * 10.0, 0.0, 10.0, 10.0),
    ], null, null, null, paint);
  }

  // ...
}

另一个示例展示了如何绘制可选带透明度和旋转效果的精灵：

class Sprite {
  Sprite(this.index, this.center, this.alpha, this.rotation);
  int index;
  Offset center;
  int alpha;
  double rotation;
}

class MyPainter extends CustomPainter {
  MyPainter(this.spriteAtlas, this.allSprites);

  // assume spriteAtlas contains N 10x10 sprites side by side in a (N*10)x10 image
  ui.Image spriteAtlas;
  List<Sprite> allSprites;

  @override
  void paint(Canvas canvas, Size size) {
    Paint paint = Paint();
    canvas.drawAtlas(spriteAtlas, <RSTransform>[
      for (final Sprite sprite in allSprites)
        RSTransform.fromComponents(
          rotation: sprite.rotation,
          scale: 1.0,
          // Center of the sprite relative to its rect
          anchorX: 5.0,
          anchorY: 5.0,
          // Location at which to draw the center of the sprite
          translateX: sprite.center.dx,
          translateY: sprite.center.dy,
        ),
    ], <Rect>[
      for (final Sprite sprite in allSprites)
        Rect.fromLTWH(sprite.index * 10.0, 0.0, 10.0, 10.0),
    ], <Color>[
      for (final Sprite sprite in allSprites)
        Colors.white.withAlpha(sprite.alpha),
    ], BlendMode.srcIn, null, paint);
  }

  // ...
}

transforms 和 rects 列表的长度必须相等。如果 colors 参数不为 null，则该列表必须为空，或与另外两个列表长度相同。
