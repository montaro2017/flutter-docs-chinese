PathMetric

PathMetric 类

用于测量 Path 并提取子路径的工具。

迭代 Path.computeMetrics 返回的对象，以获取 PathMetric 对象。如果需要随机访问元素或多次迭代，应使用 path.computeMetrics().toList()，因为 PathMetrics 不会缓存结果。

创建后，这些度量值仅对调用 Path.computeMetrics 时指定的路径有效。如果添加了其他轮廓或更新了现有轮廓，就必须重新计算度量值。先前创建的度量值仍引用计算时的路径快照，而不会反映之后对路径所做的修改。
