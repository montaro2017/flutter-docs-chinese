touch → const PointerDeviceKind

基于触控的指针设备。

最常见的是触摸屏。

用户在 iOS 上使用触控板时，如果 UIApplicationSupportsIndirectInputEvents 未出现在 Info.plist 中或其值为 NO，点击也会分发 kind 为 touch 的事件。

另请参阅：

  • UIApplicationSupportsIndirectInputEvents.
mouse → const PointerDeviceKind

基于鼠标的指针设备。

最常见的是桌面设备或 Web 上的鼠标。

用户在 iOS 上使用触控板时，如果 UIApplicationSupportsIndirectInputEvents 未出现在 Info.plist 中或其值为 NO，移动指针光标也会分发 kind 为 mouse 的事件，点击则会分发 kind 为 mouse 的事件。

另请参阅：

  • UIApplicationSupportsIndirectInputEvents.
stylus → const PointerDeviceKind

带有触控笔的指针设备。

invertedStylus → const PointerDeviceKind

触控笔已翻转的指针设备。

trackpad → const PointerDeviceKind

来自触控板的手势。

这里的触控板指一种带有间接表面的触控指针设备（用户通过触摸非屏幕表面来操作屏幕）。

用户使用实体触控板执行缩放、平移、滚动或旋转手势时，受支持的平台会分发 kind 为 trackpad 的事件。

kind 为 trackpad 的事件，其 PointerChange 只能是 add、remove 或与平移/缩放相关的值。

有些平台不支持或未完全支持触控板手势，可能会将其转换为模拟拖动的虚假指针事件。这些事件的 kind 通常是 touch 或 mouse，而不是 trackpad。这包括但不限于 Web，以及 UIApplicationSupportsIndirectInputEvents 未出现在 Info.plist 中或其值为 NO 时的 iOS。

使用触控板移动指针光标或点击，通常会触发 touch 或 mouse 事件，但不会触发 trackpad 事件。

另请参阅：

  • UIApplicationSupportsIndirectInputEvents.
