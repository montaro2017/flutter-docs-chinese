FilterQuality

FilterQuality enum

为会采样图像的 ImageFilter 和 Shader 对象，以及会渲染图像的 Canvas 操作指定图像采样质量。

放大图像时，质量通常从低到高依次为 none、low、medium；对于非常大的缩放比例（超过 10 倍），high 质量最高。

缩小图像时，medium 的质量最好，尤其适用于将图像缩小到原尺寸的一半以下，或在此类缩放比例之间进行动画。若缩小幅度在 50% 到 100% 之间，low 和 high 的效果相近；低于原尺寸 50% 时，图像可能会丢失细节并出现缺失。

如果需要在放大和缩小图像时都获得较高质量，或缩放比例未知，通常可以选择 medium，以取得较好的平衡。

Values

none → const FilterQuality

速度最快，但质量也最低的过滤方法。

此值使用“最近邻”算法，图像放大或缩小时会直接重复或移除像素。

low → const FilterQuality

质量优于 none，速度快于 medium。

此值使用“双线性”算法，在图像像素之间平滑插值。

medium → const FilterQuality

综合效果最佳的过滤方法；只有在缩放比例非常大时，效果才不如 high。

此值在 low 指定的“双线性”算法基础上使用 Mipmap：预先计算图像的高质量低分辨率版本，尺寸依次减半、减至四分之一、八分之一等，再在这些版本间混合，从而避免小尺寸下的细节损失。

另请参阅：

  • FilterQuality class-level documentation that goes into detail about relative qualities of the constant values.
high → const FilterQuality

放大图像时质量最佳，适用于缩放比例大于 5 到 10 倍的情况。

缩小图像时，如果缩放比例低于 0.5 倍或正在对缩放比例进行动画处理，效果可能不如 medium。

此选项的速度也最慢。

此值使用标准“双三次”算法，通过三次方程平滑像素间的突变，同时保留一定的边缘感并避免结果出现尖峰。
