创建一个新的 TextStyle 对象。

  • color：绘制文本时使用的颜色。若指定此项，则 foreground 必须为 null。
  • decoration：绘制在文本附近的装饰效果（例如下划线）。
  • decorationColor：文本装饰所使用的颜色。
  • decorationStyle：文本装饰的样式（例如虚线）。
  • decorationThickness：装饰线的粗细，相对于字体指定的粗细进行缩放。
  • fontWeight：绘制文本时使用的字重（例如粗体）。
  • fontStyle：绘制字母时使用的字体样式变体（例如斜体）。
  • fontFamily：绘制文本时使用的字体名称（例如 Roboto）。如果提供了 fontFamilyFallback 且未指定 fontFamily，则 fontFamilyFallback 中的第一个字体会作为首选字体。当找不到优先级较高的字体或该字体缺少所需字形时，将使用优先级较低的字体。
  • fontFamilyFallback：当高优先级字体中找不到某个字形时，按回退顺序使用的字体名称列表。当 fontFamily 为 null 时，此列表中的第一个字体会作为首选字体。内部会将 'fontFamilyis concatenated to the front of this list. When no font family is provided through 'fontFamilyFallback' (null or empty) orfontFamily` 未提供时，使用平台默认字体。
  • fontSize：绘制文本时使用的字形大小，单位为逻辑像素。
  • letterSpacing：每个字母之间增加的间距，单位为逻辑像素。
  • wordSpacing：每段空白字符（即单词之间）增加的间距，单位为逻辑像素。
  • textBaseline：此文本跨度与其父文本跨度之间应对齐的公共基线；对于根文本跨度，则与行框对齐。
  • height：此文本跨度的高度，是字体大小的倍数。将 height 设为 kTextHeightNone 后，行高会采用字体定义的高度，该值可能与 fontSize 的高度不同。
  • leadingDistribution：当 height 设置为非 null 且不等于 kTextHeightNone 时，额外的垂直空间在文本上方和下方的分配方式。若未指定，则默认为段落的 TextHeightBehavior。
  • locale：用于选择区域特定字形的区域设置。
  • background：绘制在文本背景上的画笔。
  • foreground：用于绘制文本的画笔。若指定此项，则 color 必须为 null。
  • fontFeatures：要应用于文本的字体特性。
  • fontVariations：要应用于文本的字体变体。
