Path

Path 类 抽象

平面上复杂的一维子集。

路径由若干子路径和一个当前点组成。

子路径由不同类型的线段组成，例如直线、弧线或贝塞尔曲线。 子路径可以开放或闭合，也可以自相交。

闭合子路径会根据当前 fillType 围出平面上的一个区域（该区域也可能由不相连的部分组成）。

当前点最初位于原点。 每次执行向子路径添加线段的操作后，当前点都会更新为该线段的终点。

可以使用 Canvas.drawPath 在画布上绘制路径，也可以使用 Canvas.clipPath 创建裁剪区域。

方法

addArc(Rect oval, double startAngle, double sweepAngle) → void
添加一条新的子路径，其中包含一个圆弧线段。圆弧沿给定矩形所界定椭圆的边缘延伸，从椭圆周围的 startAngle 弧度处开始，扫过 sweepAngle 弧度。0 弧度对应椭圆最右侧与穿过矩形中心的水平线相交的点；正角度沿椭圆顺时针增加。
addOval(Rect oval) → void
添加一条新的子路径，其中包含一条构成椭圆的曲线，该椭圆填满给定矩形。
addPath(Path path, Offset offset, {Float64List? matrix4}) → void
将 path 的子路径按 offset 偏移后添加到此路径中。
addPolygon(List<Offset> points, bool close) → void
添加一条由一系列线段组成的新子路径，这些线段依次连接给定的各点。
addRect(Rect rect) → void
添加一条由四条线段组成的新子路径，用于描出给定矩形的轮廓。
addRRect(RRect rrect) → void
添加一条由直线和曲线组成的新子路径， 用于构成参数所描述的圆角矩形。
addRSuperellipse(RSuperellipse rsuperellipse) → void
添加一条由曲线组成的新子路径， 用于构成参数所描述的圆角超椭圆。
arcTo(Rect rect, double startAngle, double sweepAngle, bool forceMoveTo) → void
如果 forceMoveTo 参数为 false， 则添加一条直线段和一条弧线段。
arcToPoint(Offset arcEnd, {Radius radius = Radius.zero, double rotation = 0.0, bool largeArc = false, bool clockwise = true}) → void
追加最多四条圆锥曲线， 以构成半径为 radius、旋转角度为 rotation 的椭圆（角度以度为单位， 方向为顺时针）。
close() → void
闭合最后一条子路径， 效果等同于从当前点向该子路径的起点绘制一条直线。
computeMetrics({bool forceClosed = false}) → PathMetrics
为此路径创建一个 PathMetrics 对象， 用于描述路径轮廓的各种属性。
conicTo(double x1, double y1, double x2, double y2, double w) → void
添加一段从当前点延伸到目标点 (x2,y2) 的贝塞尔曲线，控制点为 (x1,y1)，权重为 w。权重大于 1 时曲线为双曲线，等于 1 时为抛物线，小于 1 时为椭圆。
contains(Offset point) → bool
测试给定的点是否位于此路径内部。（也就是说，如果将此路径用于 Canvas.clipPath，该点是否会处于路径的可见部分。）
cubicTo(double x1, double y1, double x2, double y2, double x3, double y3) → void
添加一段三次贝塞尔曲线，从当前点延伸至给定的点 (x3,y3)，并使用控制点 (x1,y1) 和 (x2,y2)。
extendWithPath(Path path, Offset offset, {Float64List? matrix4}) → void
将 path 的子路径按 offset 偏移后添加到此路径。 当前子路径会延伸到 path 的第一条子路径； 必要时会用 lineTo 将它们连接起来。

moveTo(double x, double y) → void
在给定坐标处开始一条新的子路径。
