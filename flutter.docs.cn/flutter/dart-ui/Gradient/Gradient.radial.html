创建以 center 为中心、延伸至距中心 radius 处的径向渐变。

如果提供了 colorStops，则 colorStops[i] 是一个介于 0.0 到 1.0 之间的数值，用于指定渐变中 color[i] 的起始位置。如果未提供 colorStops，则默认只有位于 0.0 和 1.0 的两个色标（因此 color 必须恰好包含两个条目）。小于 0.0 的色标值会向上调整为 0.0，大于 1.0 的值会向下调整为 1.0。每个色标值必须大于或等于前一个值；不满足此条件的值会向上调整到前一个色标值。

半径之前和之后的行为由 tileMode 参数决定。详情请参阅 TileMode 枚举。

如果 center、radius、colors 或 tileMode 为 null，或者 colors 或 colorStops 中包含 null 值，此构造函数会抛出 NoSuchMethodError。

如果提供了 matrix4，渐变填充会相对于局部坐标系应用指定的 4×4 矩阵变换。matrix4 必须是按列优先顺序排列、包含 16 个值的列表。

如果提供了 focal，且它不等于 center，同时提供了不等于 0.0 的 focalRadius，生成的 shader 将是双点圆锥径向渐变，其中 focal 是焦点圆的中心，focalRadius 是该圆的半径。如果提供的 focal 不等于 center，则这两个偏移量中至少有一个必须不等于 Offset.zero。

实现

Gradient.radial(
  Offset center,
  double radius,
  List<Color> colors, [
  List<double>? colorStops,
  TileMode tileMode = TileMode.clamp,
  Float64List? matrix4,
  Offset? focal,
  double focalRadius = 0.0,
]) : assert(_offsetIsValid(center)),
     assert(matrix4 == null || _matrix4IsValid(matrix4)),
     super._() {
  _validateColorStops(colors, colorStops);
  final Float32List? colorStopsBuffer = colorStops == null
      ? null
      : Float32List.fromList(colorStops);
  final Float32List colorsBuffer = _encodeWideColorList(colors);

  // If focal is null or focal radius is null, this should be treated as a regular radial gradient
  // If focal == center and the focal radius is 0.0, it's still a regular radial gradient
  if (focal == null || (focal == center && focalRadius == 0.0)) {
    _constructor();
    _initRadial(
      center.dx,
      center.dy,
      radius,
      colorsBuffer,
      colorStopsBuffer,
      tileMode.index,
      matrix4,
    );
  } else {
    assert(
      center != Offset.zero || focal != Offset.zero,
    ); // will result in exception(s) in Skia side
    _constructor();
    _initConical(
      focal.dx,
      focal.dy,
      focalRadius,
      center.dx,
      center.dy,
      radius,
      colorsBuffer,
      colorStopsBuffer,
      tileMode.index,
      matrix4,
    );
  }
}
