TileMode

TileMode enum

定义如何处理渐变或图像滤镜定义范围之外的区域。

渐变

渐变具有特定边界，形成内部区域和外部区域。TileMode 控制如何确定这些边界之外区域的颜色：

  • 线性渐变：内部区域是两点之间的区域（渐变 API 中通常称为 start 和 end），更准确地说，是垂直于两点连线的两条平行线之间的区域。该区域之外的颜色由 TileMode 决定。

  • 径向渐变：内部区域是由圆心和半径确定的圆盘。圆盘之外的颜色由 TileMode 决定。

  • 扫描渐变：内部区域是 startAngle 与 endAngle 之间的角扇区。扇区之外的颜色由 TileMode 决定。

图像滤镜

应用滤镜（例如模糊）时，可能需要从图像边界之外采样颜色；TileMode 定义如何确定这些越界采样值：

  • It controls what color values are used when the filter needs to sample from areas outside the original image.
  • This is particularly important for effects like blurring near image edges.

另请参阅：

  • painting.Gradient, the superclass for LinearGradient 和 RadialGradient, as used by BoxDecoration et al, which works in relative coordinates and can create a Shader representing the gradient for a particular Rect on demand.
  • dart:ui.Gradient, the low-level class used when dealing with the Paint.shader property directly, with its Gradient.linear 和 Gradient.radial constructors.
  • dart:ui.ImageFilter.blur, an ImageFilter that may sometimes need to read samples from outside an image to combine with the pixels near the edge of the image.

Values

clamp → const TileMode
超出边缘的采样会钳制为定义的内部区域中最近的颜色。

对于渐变，这表示内部区域之外的部分会使用最靠近该区域的色标颜色绘制。

对于扫描渐变，startAngle 与 endAngle 所定义角扇区之外的整个区域，都会使用最靠近该区域的色标颜色绘制。

对于图像滤镜，源图像之外的采样会使用最近边缘像素替代。

repeated → const TileMode
超出边缘的采样会从定义区域的另一端重复取样。

对于渐变，这相当于将 0.0 到 1.0 的色标区间重复延伸到 1.0 到 2.0、2.0 到 3.0，依此类推；线性渐变还会沿负方向延伸到 -1.0 到 0.0、-2.0 到 -1.0 等区间。

对于扫描渐变，超过 endAngle 或小于 startAngle 的角度会沿同一方向（顺时针）重复渐变图案。

对于图像滤镜，源图像会像平铺在扩展后的采样空间中一样处理，每个图块方向都与原图一致。

mirror → const TileMode
超出边缘的采样会在定义区域内来回镜像。

对于渐变，这相当于先将 0.0 到 1.0 的色标区间反向重复到 2.0 到 1.0，再正向重复到 2.0 到 3.0，然后再次反向重复到 4.0 到 3.0，依此类推；线性渐变也会沿负方向以相同方式处理。

对于扫描渐变，角度超过 endAngle 或小于 startAngle 时，渐变图案会来回镜像。

对于图像滤镜，源图像会在采样空间中交替正反或上下平铺。

decal → const TileMode
超出边缘的采样会视为透明黑色。

渐变会在径向渐变的圆盘之外、定义线性渐变内部区域的平行线之外，或扫描渐变的角扇区之外绘制为透明。

对于扫描渐变，只绘制 startAngle 与 endAngle 之间的扇区；其他区域均为透明。

对于图像滤镜，源图像之外的采样会以透明黑色替代。
