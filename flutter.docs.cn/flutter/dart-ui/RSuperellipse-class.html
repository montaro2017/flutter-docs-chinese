RSuperellipse

RSuperellipse 类

一种不可变的圆角超椭圆。

圆角超椭圆（不要与标准超椭圆混淆）是通过用圆弧替换超椭圆的四个曲线角形成的形状。标准超椭圆遵循公式 x^n + y^n = a^n；当 n > 2 时会形成圆角，但这些角往往过于尖锐和突出。用圆弧替换后，形状会显得更柔和、更自然。

从视觉上看，圆角超椭圆类似常见的圆角矩形（RRect），但直边与角之间的过渡更平滑。它与 SwiftUI 中采用 .continuous 圆角样式的 RoundedRectangle 形状非常接近。
