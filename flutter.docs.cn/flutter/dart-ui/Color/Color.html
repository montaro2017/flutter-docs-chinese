Color 构造函数

const Color(
  1. int value
)

根据一个 int 的低 32 位构造 ColorSpace.sRGB 颜色。

各位的解释如下：

  • 第 24 至 31 位表示 alpha 值。
  • 第 16 至 23 位表示红色值。
  • 第 8 至 15 位表示绿色值。
  • 第 0 至 7 位表示蓝色值。

换言之，如果 AA、RR、GG 和 BB 分别表示十六进制的 alpha、红、绿、蓝值，则颜色可以写作 Color(0xAARRGGBB)。

例如，要得到完全不透明的橙色，可以使用 const Color(0xFFFF9000)（FF 表示 alpha，FF 表示红，90 表示绿，00 表示蓝）。

说明

每种颜色都以浮点颜色分量存储；每个分量的最终值通过存储 c / 255 近似表示，其中 c 是四个分量之一（alpha、红、绿、蓝）。

实现

const Color(int value)
  : this._fromARGBC(value >> 24, value >> 16, value >> 8, value, ColorSpace.sRGB);
