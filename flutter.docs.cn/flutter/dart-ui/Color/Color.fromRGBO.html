Color.fromRGBO 构造函数

const Color.fromRGBO(
  1. int r,
  2. int g,
  3. int b,
  4. double opacity,
)

根据红、绿、蓝和不透明度构造 sRGB 颜色，类似 CSS 中的 rgba()。

  • r is red, from 0 to 255.
  • g is green, from 0 to 255.
  • b is blue, from 0 to 255.
  • opacity is alpha channel of this color as a double, with 0.0 being transparent and 1.0 being fully opaque.

超出范围的值会通过对 255 取模调整到范围内。

另请参见 fromARGB，它将不透明度作为整数接收。

说明

每种颜色都以浮点颜色分量存储；每个分量的最终值通过存储 c / 255 近似表示，其中 c 是四个分量之一（alpha、红、绿、蓝）。

实现

const Color.fromRGBO(int r, int g, int b, double opacity)
  : this._fromRGBOC(r, g, b, opacity, ColorSpace.sRGB);
