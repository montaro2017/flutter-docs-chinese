在两种颜色之间进行线性插值。

此方法旨在提升速度，因此结果可能不够美观。可以考虑使用 HSVColor，或编写自定义的颜色插值逻辑。

如果任一颜色为 null，此函数会从另一颜色的透明实例进行线性插值。通常这比从 material.Colors.transparent（const Color(0x00000000)）插值更合适，因为后者特指透明黑色。

t 参数表示时间线上的位置：0.0 表示插值尚未开始，返回 a（或与 a 等效的值）；1.0 表示插值已完成，返回 b（或与 b 等效的值）；介于两者之间的值表示时间线从 a 到 b 的相应位置。插值也可以外推到 0.0 和 1.0 之外，因此负值和大于 1.0 的值均有效（例如 Curves.elasticInOut 等曲线很容易产生这类值）。每个通道都会限制在 0 到 255 的范围内。

t 的值通常取自 Animation<double>，例如 AnimationController。

如果两种颜色属于不同的色彩空间，插值前会将它们都转换到色域更广的色彩空间。结果也会使用色域更广的色彩空间。例如，在 sRGB 颜色和 Display P3 颜色之间插值会得到 Display P3 结果。

实现

static Color? lerp(Color? x, Color? y, double t) {
  assert(x?.colorSpace != ColorSpace.extendedSRGB);
  assert(y?.colorSpace != ColorSpace.extendedSRGB);
  if (y == null) {
    if (x == null) {
      return null;
    } else {
      return _scaleAlpha(x, 1.0 - t);
    }
  } else {
    if (x == null) {
      return _scaleAlpha(y, t);
    } else {
      final Color a;
      final Color b;
      final ColorSpace resultColorSpace;
      if (x.colorSpace == y.colorSpace) {
        a = x;
        b = y;
        resultColorSpace = x.colorSpace;
      } else {
        resultColorSpace = _widerColorSpace(x.colorSpace, y.colorSpace);
        a = x.withValues(colorSpace: resultColorSpace);
        b = y.withValues(colorSpace: resultColorSpace);
      }
      return Color.from(
        alpha: clampDouble(_lerpDouble(a.a, b.a, t), 0, 1),
        red: clampDouble(_lerpDouble(a.r, b.r, t), 0, 1),
        green: clampDouble(_lerpDouble(a.g, b.g, t), 0, 1),
        blue: clampDouble(_lerpDouble(a.b, b.b, t), 0, 1),
        colorSpace: resultColorSpace,
      );
    }
  }
}
