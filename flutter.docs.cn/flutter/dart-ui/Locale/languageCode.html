languageCode

languageCode 属性

String get languageCode

此 Locale 的主要语言子标签。

此值不能为 null，也可以是表示“未定义”的“und”。

该值应为在 IANA 语言子标签注册表中登记为“language”类型的字符串，且大小写必须与注册表中的写法一致。

如果注册表中某个已弃用的语言子标签有首选代码，则会将其替换为首选代码。例如，const Locale('he') 和 const Locale('iw') 相等，且二者的 languageCode 都是 he，因为已弃用的语言子标签 iw 已被 he 取代。

此值必须是 Unicode CLDR 补充数据中列出的有效 Unicode 语言子标签。

另请参阅：

  • Locale.fromSubtags, which describes the conventions for creating Locale objects.

实现

String get languageCode => _deprecatedLanguageSubtagMap[_languageCode] ?? _languageCode;
