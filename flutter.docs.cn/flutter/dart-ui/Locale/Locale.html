Locale 构造函数

const Locale(
  1. String _languageCode, [
  2. String? _countryCode
])

创建新的 Locale 对象。第一个参数是主要语言子标签，第二个参数是区域子标签（也称为“国家/地区”子标签）。

例如：

const Locale swissFrench = Locale('fr', 'CH');
const Locale canadianFrench = Locale('fr', 'CA');

主要语言子标签不能为 null。区域子标签为可选项。没有区域/国家子标签时，应省略该参数或传入 null，不能传入空字符串。

子标签值区分大小写，且必须是 CLDR 补充数据中的有效子标签：language、region。主要语言子标签必须为 2 到 8 个小写字母，但不能是 4 个字母。区域子标签必须为 2 个大写字母或 3 位数字。详情请参阅 Unicode 语言标识符规范。

默认情况下不会检查有效性，但某些方法可能会丢弃无效数据。

另请参阅：

  • Locale.fromSubtags, which also allows a scriptCode to be specified.

实现

const Locale(this._languageCode, [this._countryCode])
  : assert(_languageCode != ''),
    scriptCode = null;
