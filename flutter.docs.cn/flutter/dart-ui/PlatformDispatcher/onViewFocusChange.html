onViewFocusChange 属性

ViewFocusChangeCallback? get onViewFocusChange

焦点在不同 FlutterView 之间切换后立即调用的回调。

当平台将焦点从一个 FlutterView 移至另一个时，会调用此回调，告知新获得焦点的视图以及焦点接收方向。例如，如果焦点沿正向移动到 ID 为 2 的 FlutterView（可能是按下 Tab 键所致），回调会收到一个 ViewFocusEvent，其状态为 ViewFocusState.focused，方向为 ViewFocusDirection.forward。

通常，事件接收方会将焦点移至 ID 为 2 的 FlutterView 内第一个可聚焦的组件。如果视图沿反向获得焦点（可能是按下 Shift + Tab 所致），通常会聚焦该视图内最后一个可聚焦的组件。

平台可能会从某个 FlutterView 移除焦点。例如，在 Web 上，浏览器可能会将焦点移至另一个元素或浏览器内置界面；在桌面平台上，操作系统可能会切换到另一个窗口（例如在 Windows 上按 Alt + Tab）。在这些情况下，onViewFocusChange 会收到状态 ViewFocusState.unfocused 和方向 ViewFocusDirection.undefined。

事件接收方通常会移除应用中所有焦点指示。

应用也可以调用 requestViewFocusChange，以编程方式请求将焦点移至指定的 FlutterView。

框架会在设置此回调时所在的同一个 zone 中调用它。

另请参阅：

  • requestViewFocusChange to programmatically instruct the platform to move focus to a different FlutterView.
  • ViewFocusState for a list of allowed focus transitions.
  • ViewFocusDirection for a list of allowed focus directions.
  • ViewFocusEvent, which is the event object provided to the callback.

实现

ViewFocusChangeCallback? get onViewFocusChange => _onViewFocusChange;
set onViewFocusChange (ViewFocusChangeCallback? callback)

实现

set onViewFocusChange(ViewFocusChangeCallback? callback) {
  _onViewFocusChange = callback;
  _onViewFocusChangeZone = Zone.current;
}
