更改此平台分发器保留的语义数据。

如果 semanticsEnabled 为 true，表示用户请求在此平台分发器的语义内容发生变化时调用此函数。

无论哪种情况，此函数都会释放给定的更新对象，这意味着该语义更新之后不能再使用。

实现
