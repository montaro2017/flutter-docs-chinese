ImageByteFormat

ImageByteFormat enum

使用 Image.toByteData 时应返回的图像字节格式。

继承关系

Values

rawRgba → const ImageByteFormat

原始 RGBA 格式。

未编码的字节数据，按行优先排列，采用预乘 alpha 的 RGBA 格式，每个通道 8 位。

rawStraightRgba → const ImageByteFormat

原始直通 RGBA 格式。

未编码的字节数据，按行优先排列，采用直通 alpha 的 RGBA 格式，每个通道 8 位。

rawUnmodified → const ImageByteFormat

原始未修改格式。

未编码的字节数据，采用图像现有格式。例如，灰度图像可能为每个像素使用一个 8 位通道。

rawExtendedRgba128 → const ImageByteFormat

原始扩展范围 RGBA 格式。

未编码的字节数据，按行优先排列，采用直通 alpha 的 RGBA 格式，每个通道为 32 位浮点数（IEEE 754 binary32）。

Example usage:

import 'dart:ui' as ui;
import 'dart:typed_data';

Future<Map<String, double>> getFirstPixel(ui.Image image) async {
  final ByteData data =
      (await image.toByteData(format: ui.ImageByteFormat.rawExtendedRgba128))!;
  final Float32List floats = Float32List.view(data.buffer);
  return <String, double>{
    'r': floats[0],
    'g': floats[1],
    'b': floats[2],
    'a': floats[3],
  };
}
png → const ImageByteFormat

PNG format.

用于图像的无损压缩格式。此格式非常适合边缘清晰的图像（例如屏幕截图或精灵图）以及包含文本的图像，并支持透明度。PNG 格式支持任一维度最多 2,147,483,647 像素的图像，但实际可用内存通常会更早限制图像大小。

PNG 图像通常使用 .png 文件扩展名和 image/png MIME 类型。

另请参阅：

  • en.wikipedia.org/wiki/Portable_Network_Graphics, the Wikipedia page on PNG.
  • tools.ietf.org/rfc/rfc2083.txt, the PNG standard.
