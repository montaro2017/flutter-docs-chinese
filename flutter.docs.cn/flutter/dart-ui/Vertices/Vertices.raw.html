使用 Flutter 引擎所需的编码格式，创建供 Canvas.drawVertices 使用的一组顶点数据。

mode 参数描述如何解释这些点：作为独立三角形（VertexMode.triangles）、滑动点窗口所形成的一组三角形链（相邻三角形共享一条边，VertexMode.triangleStrip），或共享一个中心点的扇形三角形（VertexMode.triangleFan）。

positions 参数提供画布空间中的点，用于绘制三角形。每个点在列表中由两个数字表示，第一个是 x 坐标，第二个是 y 坐标。（因此，列表中的条目数必须为偶数。）

如果指定 colors 参数，它会为 positions 中的每个点提供颜色。每种颜色以 8 位颜色通道的 ARGB 格式表示（类似 Color.value 的内部表示），因此如果指定此列表，其长度必须是 positions 的一半。每个三角形会绘制为在其三个顶点颜色之间混合的渐变。（随后，这些颜色会与调用 Canvas.drawVertices 时指定的 Paint 混合。）

如果指定 textureCoordinates 参数，它会提供 Paint 图像中的采样点，并将这些点与 positions 中对应的点关联。每个点在列表中由两个数字表示，第一个是 x 坐标，第二个是 y 坐标。如果指定此列表，其长度必须与 positions 相同。

indices 参数指定绘制各点的顺序。如果省略该参数（或虽已提供但为空），则按 positions 中的顺序处理各点，相当于 indices 是从 0 到 n-2 的列表，其中 n 是 positions 中点对的数量（即 positions 长度的一半）。如果指定的 indices 非空，则至少包含三个条目，但长度可以更多。索引可以多次引用 positions 数组中的同一偏移量，也可以跳过某些位置。

如果指定了 indices 参数，列表中的所有值都必须是 positions 中点对的有效索引。例如，若 positions 有 12 个数字（表示 6 个坐标点），则 indicies 中的数字必须在 0 到 5（含）之间。

mode 和 positions 参数都不能为 null。

实现

Vertices.raw(
  VertexMode mode,
  Float32List positions, {
  Int32List? colors,
  Float32List? textureCoordinates,
  Uint16List? indices,
}) {
  if (positions.length % 2 != 0) {
    throw ArgumentError(
      '"positions" must have an even number of entries (each coordinate is an x,y pair).',
    );
  }
  if (colors != null && colors.length * 2 != positions.length) {
    throw ArgumentError('"positions" and "colors" lengths must match.');
  }
  if (textureCoordinates != null && textureCoordinates.length != positions.length) {
    throw ArgumentError('"positions" and "textureCoordinates" lengths must match.');
  }
  assert(() {
    if (indices != null) {
      for (var index = 0; index < indices.length; index += 1) {
        if (indices[index] * 2 >= positions.length) {
          throw ArgumentError(
            '"indices" values must be valid indices in the positions list '
            '(i.e. numbers in the range 0..${positions.length ~/ 2 - 1}), '
            'but indices[$index] is ${indices[index]}, which is too big.',
          );
        }
      }
    }
    return true;
  }());
  if (!_init(this, mode.index, positions, textureCoordinates, colors, indices)) {
    throw ArgumentError('Invalid configuration for vertices.');
  }
}
