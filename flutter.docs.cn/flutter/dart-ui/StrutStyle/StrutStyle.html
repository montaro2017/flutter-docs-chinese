创建一个新的 StrutStyle 对象。

  • fontFamily：绘制文本时使用的字体名称（例如 Roboto）。

  • fontFamilyFallback：一个有序的字体系列名称列表；当找不到 fontFamily 指定的字体时，会按顺序查找这些字体。

  • fontSize：绘制文本时使用的字形尺寸（逻辑像素）。

  • height：行框的最小高度，以字体大小的倍数表示。当 fontSize 不为 null 时，段落各行的高度至少为 (height + leading) * fontSize。省略 height（或将其设为 kTextHeightNone）可让最小行高采用字体定义的高度，该高度可能与 fontSize 不完全相同。当 fontSize 为 null 时，不设最小行高。基线对齐导致的高字形或较大的 TextStyle.fontSize 可能使布局后的实际行高超过此处指定的值。此属性只有在提供 fontSize 时才生效。

  • leading：行间最小额外间距，以字体大小的倍数表示。此属性只有在提供 fontSize 时才生效。此属性增加的间距始终均匀分布在文本上方和下方，与 leadingDistribution 无关。

  • leadingDistribution：指定由 height 倍数增加的额外垂直空间如何分配到文本上方和下方；这与 leading 无关（后者始终均匀分布在文本上方和下方）。默认采用段落 TextHeightBehavior 的 leading 分布方式。

  • fontWeight：绘制文本时使用的字重（例如粗体）。

  • fontStyle：绘制字母时使用的字体样式变体（例如斜体）。

  • forceStrutHeight：为 true 时，段落会强制所有行的基线间距恰好为 (height + leading) * fontSize。此时 TextStyle 不再能影响行高，较高的字形可能与上方的行重叠。如果指定了 fontFamily，首行的总上升高度将取该 fontFamily 的 Ascent + half-leading 与 (height + leading) * fontSize 中的较小值。否则，由首段文本的 Ascent + half-leading 决定。
