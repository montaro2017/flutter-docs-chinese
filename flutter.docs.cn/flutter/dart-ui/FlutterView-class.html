FlutterView

FlutterView 类

用于绘制 Flutter Scene 的视图。

每个 FlutterView 都有自己的图层树；每当使用 Scene 调用其 render 方法时，都会渲染该图层树。

通过 PlatformDispatcher 获取对 FlutterView 对象的引用。

内边距与填充

在此示意图中，黑色区域表示应用无法绘制其上的系统界面。红色区域表示视图填充，视图可能无法在其中检测手势，也可能不应在其中绘制。灰色区域表示系统键盘；键盘显示时可能会覆盖底部视图填充。

viewInsets 是操作系统为系统界面预留的物理像素区域，例如键盘区域；绘制在该区域中的任何内容都会被完全遮挡。

viewPadding 表示显示屏各边可能被系统界面或显示屏上的物理结构部分遮挡的物理像素区域，例如电视的过扫描区域或手机上的“刘海”。与内边距不同，这些区域可能有部分仍能显示视图绘制的像素而未被遮挡，例如手机顶部的刘海只覆盖该区域的一部分。内边距则会部分或完全遮挡窗口，例如不透明键盘或半透明状态栏会遮挡一片连续区域。

padding 属性根据 viewInsets 和 viewPadding 共同计算得出。适当情况下，视图内边距会占用视图填充，例如手机键盘覆盖底部视图填充时，就会“吸收”这部分填充。

如果客户端希望无论视图内边距如何变化，都根据视图填充定位元素，应使用 viewPadding 属性。例如，无论键盘是否显示，都希望相对于 iPhone“安全区域”将组件绘制在屏幕中央。

padding 适用于只想知道需要考虑多少填充、而不关心当前内边距状态的客户端，例如判断某个手势是否应参与滚动计算。此值会随内边距的当前状态而变化。例如，键盘显示时，底部视图填充区域中的所有手势都会被键盘拦截，因此无需在 viewPadding 中考虑这部分区域；使用 padding 进行此类计算始终是安全的。
