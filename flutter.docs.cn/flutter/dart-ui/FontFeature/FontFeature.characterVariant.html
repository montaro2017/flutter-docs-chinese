选择一个字符变体。（cv01 至 cv99）

字体最多可包含 99 个字符变体，编号为 1 至 99；每个变体都可以单独启用或禁用。

相关字符变体通常会归入风格集，并通过 FontFeature.stylisticSet 特性（ssXX）控制。

Source Code Pro 字体支持多种字符的 cvXX 特性。下例选择了变体 1（cv01）、2（cv02）和 4（cv04）。变体 1 会改变字符“a”的呈现方式，变体 2 会改变小写“g”，变体 4 会改变小写“i”和“l”。此外还有此处未展示的变体，可控制 beta 和 theta 等希腊字符的呈现方式。

值得注意的是，这与风格集不同：影响字符“a”的风格集也会影响 beta；影响字符“g”的风格集也会影响 theta 和 delta。

class ExampleWidget extends StatelessWidget {
  const ExampleWidget({super.key});

  @override
  Widget build(BuildContext context) {
    // The Source Code Pro font can be downloaded from Google Fonts
    // (https://www.google.com/fonts).
    return Text(
      'aáâ β gǵĝ θб Iiíî Ll',
      style: TextStyle(
        fontFamily: 'Source Code Pro',
        fontFeatures: <FontFeature>[

          FontFeature.characterVariant(2),
          FontFeature.characterVariant(4),
        ],
      ),
    );
  }

实现

factory FontFeature.characterVariant(int value) {
  assert(value >= 1);
  assert(value <= 99);
  return FontFeature('cv${value.toString().padLeft(2, "0")}');
}
