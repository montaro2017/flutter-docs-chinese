使用特定于区域设置的字形。（locl）

某些字符的呈现形式会随当前区域设置而变化，尤以 Unicode 中日韩统一表意文字区块的字符为甚。例如，“草”（U+8349，草）这个汉字在繁体中文中顶部有断笔，在简体中文、日语、韩语和越南语中则是完整的一横。其他字母体系也存在这种差异，例如保加利亚语和塞尔维亚语字母表中的西里尔字符与俄语中的形式不同。

某种字体可能默认使用其设计所针对的区域设置对应的字形，但仍支持其他区域设置的替代形式。启用此特性后，如果存在特定于区域设置的替代字形，系统就会使用区域设置（例如通过 painting.TextStyle.locale 指定）来决定采用哪些字形。禁用此特性后，字体渲染会忽略区域设置信息，只使用默认字形。

此特性默认启用。使用 FontFeature.localeAware(enable: false) 可以关闭区域设置适配。（当然，完全不指定区域设置也会达到同样效果。）

Noto Sans CJK 字体支持中日韩字符的 locl 特性。由于 localeAware 特性默认启用，此示例没有显式使用它，而是展示如何设置区域设置，以说明 Noto Sans 如何根据区域设置调整字形。

flutter create --sample=dart.dart_ui.FontFeature.FontFeature.localeAware.1 mysample 

import 'package:flutter/widgets.dart';

/// Flutter code sample for [FontFeature.localeAware].

void main() => runApp(const ExampleApp());

class ExampleApp extends StatelessWidget {
  const ExampleApp({super.key});

  @override
  Widget build(BuildContext context) {
    return WidgetsApp(
      builder: (BuildContext context, Widget? navigator) =>
          const ExampleWidget(),
      color: const Color(0xffffffff),
    );
  }
}

class ExampleWidget extends StatelessWidget {
  const ExampleWidget({super.key});

  @override
  Widget build(BuildContext context) {
    // The Noto family of fonts can be downloaded from Google Fonts
    // (https://www.google.com/fonts).
    return const Text(
      '次 化 刃 直 入 令',
      locale: Locale(
        'zh',
        'CN',
      ), // or Locale('ja'), Locale('ko'), Locale('zh', 'TW'), etc
      style: TextStyle(fontFamily: 'Noto Sans'),
    );
  }
}
