启用花饰字形。（swsh）

某些字体会在部分字符上设计精美的装饰，例如夸张的衬线、长尾、长起笔，或其他延伸基础字形的装饰笔画。

此特性会启用这些花饰的呈现。某些字体为每个字符提供多种花饰；如果指定参数，就会选择相应的花饰（设为 0 则全部禁用）。

某些字体包含数量惊人的替代花饰。例如，Adobe Poetica 就以此特性提供了 63 种不同的“与”符号字形！

BioRhyme Expanded 字体支持 swsh 特性，专门用于大写字母“Q”“R”和与符号字形。

import 'package:flutter/widgets.dart';

/// Flutter code sample for [FontFeature.swash].

void main() => runApp(const ExampleApp());

class ExampleApp extends StatelessWidget {
  const ExampleApp({super.key});

  @override
  Widget build(BuildContext context) {
    return WidgetsApp(
      builder: (BuildContext context, Widget? navigator) =>
          const ExampleWidget(),
      color: const Color(0xffffffff),
    );
  }
}

class ExampleWidget extends StatelessWidget {
  const ExampleWidget({super.key});

  @override
  Widget build(BuildContext context) {
    // The BioRhyme Expanded font can be downloaded from Google Fonts
    // (https://www.google.com/fonts).
    return const Text(
      'Queer & Romantic',
      style: TextStyle(
        fontFamily: 'BioRhyme Expanded',
        fontFeatures: <FontFeature>[FontFeature.swash()],
      ),
    );
  }
}
