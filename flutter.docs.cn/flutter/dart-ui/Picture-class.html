Picture

Picture 类 抽象

表示一系列已录制图形操作的对象。

若要创建 Picture，请使用 PictureRecorder。

可以通过 SceneBuilder.addPicture 方法，使用 SceneBuilder 将 Picture 放入 Scene。也可以通过 Canvas.drawPicture 方法，将 Picture 绘制到 Canvas 上。
