ImageFilter.blur 构造函数

ImageFilter.blur({
  1. double sigmaX = 0.0,
  2. double sigmaY = 0.0,
  3. TileMode? tileMode,
  4. Rect? bounds,
})

创建应用高斯模糊的图像滤镜。

sigma_x 和 sigma_y 分别是高斯核在 X 方向和 Y 方向上的标准差。

tile_mode 定义执行标准无限范围模糊时，如何对边缘处的像素进行采样。

bounds 参数为可选参数，可启用“有界模糊”模式。当 bounds 不为 null 时，图像滤镜会将其从定义的边界矩形之外读取的任何采样值替换为透明黑色。随后，最终加权总和会除以非透明采样值的总权重（有效 alpha），从而得到不透明输出。

有界模式可防止边界附近内容的颜色渗入模糊区域；当模糊必须严格限制在裁剪区域内时，通常会使用此模式，例如 iOS 风格的磨砂玻璃效果。

bounds 矩形以画布当前坐标空间指定，并会受到当前变换影响；因此，它在最终画布坐标中可能并非轴对齐。

实现

factory ImageFilter.blur({
  double sigmaX = 0.0,
  double sigmaY = 0.0,
  TileMode? tileMode,
  Rect? bounds,
}) {
  return _GaussianBlurImageFilter(
    sigmaX: sigmaX,
    sigmaY: sigmaY,
    tileMode: tileMode,
    bounds: bounds,
  );
}
