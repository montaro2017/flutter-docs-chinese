hasImplicitScrolling 属性

bool hasImplicitScrolling
final

当用户尝试将焦点移至屏幕外的子节点时，平台是否可以滚动此语义节点。

例如，ListView widget 支持隐式滚动，因此用户可以轻松地将无障碍焦点移至下一组子节点。PageView widget 不支持隐式滚动，因此用户到达当前页面末尾时不会自动导航到下一页。
