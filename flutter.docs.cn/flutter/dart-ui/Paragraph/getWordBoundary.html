TextRange getWordBoundary(
  1. TextPosition position

返回给定 TextPosition 所在单词的 TextRange。

空格、符号和标点等非单词字符的两侧都视为单词边界。在这种情况下，此方法会返回 (offset, offset+1)。Unicode 标准附件 #29 对单词边界有更精确的定义：http://www.unicode.org/reports/tr29/#Word_Boundaries。

TextPosition 会被视为插入光标位置，并根据其 TextPosition.affinity 确定该位置指向哪个字符。例如，在 string = 'Hello word' 中，对 TextPosition(offset: 5, affinity: TextPosition.upstream) 求单词边界会返回范围 (0, 5)，因为该位置指向字符“o”，而不是空格。
