TextPosition getPositionForOffset(
  1. Offset offset
)

返回距离给定偏移量最近的文本位置。

无论给定的 offset 是否靠近文本（即使 offset 并不靠近任何文本，或段落为空），此方法都会返回一个 TextPosition。拖动文本选择手柄时，可用此方法确定要选择的文本。

另请参阅：

  • getClosestGlyphInfoForOffset，它会返回与给定 Offset 最接近字符的更多信息。
