Rect

Rect 类

不可变的二维轴对齐浮点矩形，其坐标相对于给定原点。

可以通过其构造函数创建 Rect，也可以使用 Offset 和 Size，借助 & 运算符创建：

Rect myRect = const Offset(1.0, 2.0) & const Size(3.0, 4.0);

构造函数

Rect.fromCenter({required Offset center, required double width, required double height})
根据中心点、宽度和高度构造矩形。
Rect.fromCircle({required Offset center, required double radius})
构造一个包围给定圆形的矩形。
Rect.fromLTRB(double left, double top, double right, double bottom)
根据左、上、右、下边缘构造矩形。
const
Rect.fromLTWH(double left, double top, double width, double height)
根据左边缘、上边缘、宽度和高度构造矩形。
const
Rect.fromPoints(Offset a, Offset b)
构造能包围给定所有偏移量的最小矩形，并将这些偏移量视为相对于原点的向量。

方法

contains(Offset offset) → bool
判断给定偏移量指定的点是否位于此矩形的左、右、上、下边缘之间。该偏移量假定相对于原点。
deflate(double delta) → Rect
返回一个新矩形，其边缘按给定的 delta 向内移动。
expandToInclude(Rect other) → Rect
返回一个新矩形，它是能够包围此矩形和给定矩形的边界框。
inflate(double delta) → Rect
返回一个新矩形，其边缘按给定的 delta 向外移动。
intersect(Rect other) → Rect
返回给定矩形与此矩形的交集所形成的新矩形。要使该结果有意义，两个矩形必须重叠。如果两者不重叠，生成的 Rect 将具有负宽度或负高度。
noSuchMethod(Invocation invocation) → dynamic
访问不存在的方法或属性时调用。
继承
overlaps(Rect other) → bool
other 与此矩形是否存在非零面积的重叠。
shift(Offset offset) → Rect
返回一个按给定偏移量平移的新矩形。

translate(double translateX, double translateY) → Rect
返回一个新矩形：将 translateX 加到 x 分量上，并将 translateY 加到 y 分量上。
