向场景中添加一个显示性能统计信息的对象。

开发期间可用它评估应用性能。enabledOptions 控制显示哪些统计信息，bounds 控制统计信息的显示位置。

enabledOptions 是一个位字段，定义了以下位：

  • 0x01: displayRasterizerStatistics - 显示光栅线程帧耗时
  • 0x02: visualizeRasterizerStatistics - 绘制光栅线程帧耗时图表
  • 0x04: displayEngineStatistics - 显示 UI 线程帧耗时
  • 0x08: visualizeEngineStatistics - 绘制 UI 线程帧耗时图表 将 enabledOptions 设为 0x0F 以启用当前定义的所有功能。

“UI 线程”是执行主 Dart isolate（可调用 FlutterView.render 的 isolate）中所有代码的线程。UI 线程帧耗时是执行 PlatformDispatcher.onBeginFrame 回调所花费的总时间。“光栅线程”是随后在 CPU 上运行的线程，它会处理 Dart 代码提供的 Scene，将其转换为 GPU 命令并发送给 GPU。

更多详情请参阅 rendering 库中的 PerformanceOverlayOption 枚举。
