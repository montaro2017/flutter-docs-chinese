将矩形裁剪操作压入操作栈。

矩形以外的光栅化内容会被丢弃。

如果 oldLayer 不为 null，引擎会在渲染新图层时尝试重用旧图层分配的资源。这纯粹是一项优化，不会影响渲染正确性。

将图层传递给 addRetained，或作为 push 方法的 oldLayer 参数，都算作对该图层的使用。一个图层在同一场景中最多只能使用一次。例如，不能同时将它传递给两个 push 方法，也不能同时传递给 push 方法和 addRetained。

将图层传递给 addRetained 时，其所有后代图层也会被视为已在此场景中使用。后代图层同样受单次使用限制。

将图层作为 push 方法的 oldLayer 参数传入后，后续帧中便不能再使用它。如果要继续重用该图层关联的资源，请保存 push 方法返回的图层对象，并在下一帧使用该对象，而不是原始对象。

另请参阅 pop，了解操作栈详情；并参阅 Clip 了解不同的裁剪模式。默认情况下，裁剪会进行抗锯齿处理（clip = Clip.antiAlias）。
