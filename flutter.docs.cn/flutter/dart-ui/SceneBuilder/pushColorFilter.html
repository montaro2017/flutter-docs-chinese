将颜色滤镜操作压入操作栈。

给定颜色会使用指定的混合模式应用于对象的光栅化结果。

如果 oldLayer 不为 null，引擎会尝试在渲染新图层时重用旧图层分配的资源。这纯粹是优化，不会影响渲染正确性。

将图层传给 addRetained，或作为 push 方法的 oldLayer 参数，均视为该图层已被使用。同一个图层在一个场景中最多只能使用一次。例如，不能同时将它传给两个 push 方法，也不能同时传给 push 方法和 addRetained。

将图层传给 addRetained 时，其所有后代图层也会被视为已在此场景中使用。后代图层同样只能使用一次。

将图层作为 push 方法的 oldLayer 参数传入后，后续帧中便不能再使用该图层。如果要继续重用与图层关联的资源，请保存 push 方法返回的图层对象，并在下一帧中使用该对象，而不是原始对象。

有关操作栈的详情，请参见 pop。
