Values

none → const Clip

不进行裁剪。

这是大多数 widget 的默认选项：如果内容没有超出 widget 边界，就不会产生裁剪性能开销。

如果内容确实溢出，可以考虑以下 Clip 选项：

  • hardEdge, 这是速度最快但精度较低的裁剪方式。
  • antiAlias, 其速度略慢于 hardEdge，但边缘经过平滑处理。
  • antiAliasWithSaveLayer, 其速度比 antiAlias 慢得多，因此应 尽量少用。
hardEdge → const Clip

执行裁剪，但不应用抗锯齿。

此模式会启用裁剪，但曲线和非轴对齐直线会出现锯齿，因为不会尝试进行抗锯齿处理。

速度比其他裁剪模式快，但比 none 慢。

需要裁剪时，这是一个合理的选择，前提是容器为轴对齐矩形，或圆角半径很小的轴对齐圆角矩形。

另请参阅：

  • antiAlias，当需要裁剪且形状不是轴对齐矩形时，建议使用。
antiAlias → const Clip

使用抗锯齿进行裁剪。

此模式会对裁剪边缘进行抗锯齿处理；当裁剪形状的边缘为斜线、曲线或其他非轴对齐形状时，可以减少锯齿。

此模式比 antiAliasWithSaveLayer 快得多，但比 hardEdge 慢。

与 hardEdge 和 antiAliasWithSaveLayer 不同，这种裁剪可能出现边缘渗色伪影 (Skia Fiddle example).

另请参阅：

  • hardEdge, 速度更快，但精度较低。
  • antiAliasWithSaveLayer，速度慢得多，但可避免边缘渗色伪影。
  • Paint.isAntiAlias，它是通用绘制操作的抗锯齿开关。
antiAliasWithSaveLayer → const Clip

裁剪时应用抗锯齿，并紧接着创建 saveLayer。

此模式不仅会进行抗锯齿裁剪，还会分配一个屏幕外缓冲区。之后所有绘制都会在该缓冲区中完成，最后再进行裁剪并合成回去。

此模式速度很慢。与 antiAlias 不同，它不会产生边缘渗色伪影，但会因引入屏幕外缓冲区而改变语义。例如，请参阅这个不使用 saveLayer 的 Skia Fiddle，以及这个使用 saveLayer 的 Skia Fiddle。

仅在必要时使用此模式。例如，图像叠加在颜色差异很大的背景上时。遇到这种情况，可以考虑避免在同一位置叠加多种颜色（例如，只在图像缺失处显示背景色）。如果可行，优先使用 antiAlias，因为它快得多。

另请参阅：

  • antiAlias, 速度快得多，且裁剪效果相近。
  • Canvas.saveLayer.
