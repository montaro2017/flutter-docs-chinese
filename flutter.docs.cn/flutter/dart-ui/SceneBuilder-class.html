SceneBuilder

SceneBuilder 类 抽象

构建一个包含给定视觉内容的 Scene。

随后可使用 FlutterView.render 渲染此 Scene。

若要向 Scene 绘制图形操作，请先使用 PictureRecorder 和 Canvas 创建 Picture，然后通过 addPicture 将其添加到场景中。

与 Flutter 框架配合使用

Flutter 框架的 RendererBinding 提供了创建 SceneBuilder 对象的钩子（RendererBinding.createSceneBuilder），供测试接入场景创建逻辑。在 Flutter 框架上下文中创建 SceneBuilder 时，可考虑调用 RendererBinding.createSceneBuilder，而不是直接调用 SceneBuilder.new 构造函数。

如果直接使用 dart:ui API，而未使用 Flutter 框架绑定、flutter_test 框架等，则不适用上述建议。
