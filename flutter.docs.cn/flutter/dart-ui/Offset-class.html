Offset

Offset 类

不可变的二维浮点偏移量。

通常，Offset 有两种解释方式：

  1. 表示笛卡尔坐标空间中一个相对于单独维护的原点、具有指定距离的点。 例如，在 RenderBox 协议中，子项的左上角位置通常表示为相对于父级盒子左上角的 Offset。

  2. 表示可应用于坐标的向量。 例如，绘制 RenderObject 时，父级会收到一个相对于屏幕原点的 Offset，并可将它与子项的偏移量相加，得出屏幕原点到每个子项的 Offset。

由于同一个 Offset 在某个时刻可以按一种含义解释，之后又按另一种含义解释，因此这两种含义共用同一个类。

另请参阅：

  • Size, 表示描述矩形大小的向量。
