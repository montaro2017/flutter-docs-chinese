DisplayFeature

DisplayFeature 类

可能被硬件特征遮挡的显示区域。

目前仅 Android 会填充此值。

bounds 以逻辑像素为单位。在具有两个屏幕的设备上，坐标系的原点 (0,0) 位于左侧或上方屏幕的左上角，并延伸覆盖两个屏幕及其间的可视区域。

type 描述此 DisplayFeature 的行为以及它是否会遮挡显示区域。例如，DisplayFeatureType.hinge 和 DisplayFeatureType.cutout 都会遮挡显示区域，而 DisplayFeatureType.fold 不会。

state 包含可折叠显示特征（DisplayFeatureType.hinge 和 DisplayFeatureType.fold）的姿态信息。姿态表示显示屏的形状，例如 DisplayFeatureState.postureFlat 或 DisplayFeatureState.postureHalfOpened。对于 DisplayFeatureType.cutout，不使用 state，其值为 DisplayFeatureState.unknown。
