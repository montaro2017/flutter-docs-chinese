FragmentShader

FragmentShader 类 base

由 FragmentProgram 生成的 Shader。

可通过 FragmentProgram.fragmentShader 方法获取此类实例。float uniform 列表会初始化为着色器所需的大小，并填充为零。之后可调用 setFloat 设置 float 类型的 uniform，调用 setImageSampler 设置 sampler uniform。

FragmentShader 可以重复使用，这样能高效避免重新分配和初始化 uniform 缓冲区及 sampler。不过，如果需要同时存在两个 float uniform 或 sampler 不同的 FragmentShader 对象，就必须分别调用两次 FragmentProgram.fragmentShader 来获取它们。
