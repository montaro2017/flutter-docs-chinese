SemanticsHitTestBehavior

SemanticsHitTestBehavior enum

描述语义节点在命中测试期间应如何响应。

此枚举允许框架向平台的无障碍层传达指针事件处理行为。不同平台可能会根据各自的无障碍基础设施采用不同的实现方式。

另请参阅：

  • SemanticsUpdateBuilder.updateNode, which accepts this enum.

Values

defer → const SemanticsHitTestBehavior

采用平台推断的默认命中测试行为。

设为 defer 时，平台会根据语义节点的属性（例如交互行为、路由范围等）推断合适的行为。

在 Web 上，对于非交互式语义节点，默认推断行为是 transparent，允许指针事件穿透。

这是默认值，可保持向后兼容。

opaque → const SemanticsHitTestBehavior

该语义元素对命中测试是不透明的：它会接收其边界内的所有指针事件，并阻止这些事件传递到 Z 顺序中位于其后的元素（同级元素和祖先元素）。

此节点的子节点仍可正常接收指针事件。只有在视觉上位于此节点后方（堆叠顺序较低）的元素会被阻止接收事件。

这通常用于对话框、底部面板和抽屉等模态表面：它们应阻止用户与后方内容交互，同时允许用户与自身内容交互。

平台实现：

  • 在 Web 上，这会对应 CSS 属性 pointer-events: all。
transparent → const SemanticsHitTestBehavior

该语义元素对命中测试是透明的。

透明节点不会接收命中测试事件，并允许事件穿透到后方元素。

注意：这与框架的 HitTestBehavior.translucent 不同；后者会接收事件，同时允许事件穿透。Web 的二值 pointer-events 属性（all 或 none）无法支持真正的半透明行为。

平台实现：

  • 在 Web 上，这会对应 CSS 属性 pointer-events: none。
