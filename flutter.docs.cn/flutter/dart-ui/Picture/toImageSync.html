同步创建并返回此 picture 的图像句柄。

返回的图像宽为 width 像素、高为 height 像素。picture 会在从 (0, 0) 到 (width, height) 的边界内栅格化；超出边界的内容会被裁剪。

图像对象会同步创建并返回，但栅格化是异步进行的。如果栅格化失败，在将图像绘制到 Canvas 时会抛出异常。

如果有可用的 GPU 上下文，图像会驻留在 GPU 上，不会复制回主机内存，因此绘制效率更高。

如果没有可用的 GPU 上下文，则会由 CPU 执行栅格化。

targetFormat 参数指定返回的 Image 的像素格式。如果指定 TargetPixelFormat.dontCare，系统会根据 GPU 能力自动选择像素格式。
