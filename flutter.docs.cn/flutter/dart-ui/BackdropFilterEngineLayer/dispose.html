dispose 方法

void dispose()
继承

释放此对象使用的资源。调用此方法后，对象将无法再使用。

EngineLayer 会间接持有特定平台的图形资源。其中某些资源（例如图像）可能占用大量内存。对于不再使用的 EngineLayer 对象，应尽快调用 dispose，以免这些资源一直保留到下一次垃圾回收。

此 EngineLayer 释放后，便不能再用作保留层，也不得将其作为 oldLayer 传给接受该参数的任何 SceneBuilder 方法。

此调用不能是叶调用，因为原生函数会调用 Dart API（Dart_SetNativeInstanceField）。

实现

@override
void dispose() {
  assert(_nativeLayer != null, 'Object disposed');
  _nativeLayer!.dispose();
  assert(() {
    _nativeLayer = null;
    return true;
  }());
}
