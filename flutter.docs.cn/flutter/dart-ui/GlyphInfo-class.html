GlyphInfo

GlyphInfo 类 final

段落中某个字符（或一串视觉上相连字符）的度量信息。

另请参阅：

  • Paragraph.getGlyphInfoAt，用于查找文本中与某个代码单元关联的 GlyphInfo。
  • Paragraph.getClosestGlyphInfoForOffset，用于查找屏幕上距离给定 Offset 最近的字形对应的 GlyphInfo。
