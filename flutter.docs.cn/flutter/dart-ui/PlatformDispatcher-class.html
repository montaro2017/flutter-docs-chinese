PlatformDispatcher

PlatformDispatcher 类

平台事件分发器单例。

与宿主操作系统接口交互的最基础接口。

这是平台消息和配置事件进入框架的中央入口。

它提供核心调度器 API、输入事件回调、图形绘制 API 以及其他核心服务。

它管理应用的 views 列表，以及各种平台属性的 configuration。

建议避免通过 PlatformDispatcher.instance 静态引用此单例，而优先使用绑定来解析依赖，例如 WidgetsBinding.instance.platformDispatcher。关于推荐这种做法的原因，请参阅 PlatformDispatcher.instance。
