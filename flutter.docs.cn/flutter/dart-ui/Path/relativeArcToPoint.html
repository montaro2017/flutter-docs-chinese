追加最多四条加权圆锥曲线，以描绘一个半径为 radius、按 rotation 旋转的椭圆弧（旋转角以度为单位，方向为顺时针）。

路径中的最后一个点记为 (px, py)。

第一条曲线从路径中的最后一个点开始，最后一条曲线终止于 arcEndDelta.dx + px 和 arcEndDelta.dy + py。曲线方向由 clockwise 和 largeArc 决定，且扫过角始终小于 360 度。

如果任一半径为零，或 arcEndDelta.dx 与 arcEndDelta.dy 均为零，则追加一条简单直线。如果两个半径都大于零但过小，无法描述弧线，则会缩放半径以适配路径中的最后一个点。
