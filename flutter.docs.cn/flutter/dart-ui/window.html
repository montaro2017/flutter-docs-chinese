已弃用，未来版本的 Flutter 将移除此属性。

此全局属性已弃用，以便为 Flutter 即将推出的多视图和多窗口支持做准备。

对于只有一个视图的应用（例如面向单屏移动设备的应用），它表示主视图。如果嵌入器支持多个视图，它会指向最先创建且被视为主视图的那个视图。如果尚未创建任何视图，或最先创建的视图已被移除，则会抛出异常。

可以通过以下方式迁移依赖此弃用属性的代码：

如果可以取得 BuildContext，可以通过 View.of 查找与该上下文关联的 FlutterView。它提供与此弃用属性相同的功能。不过，平台特定功能已移至 PlatformDispatcher，可通过 View.of 返回的视图访问 FlutterView.platformDispatcher。使用带有 BuildContext 的 View.of，是迁移并弃用此 window 属性的首选方式。

如果没有上下文可用于查找 FlutterView，可以直接使用 PlatformDispatcher 访问平台特定功能。它还通过 PlatformDispatcher.views 维护所有可用 FlutterView 的列表，因此无需上下文也能访问视图特定功能。如果可行，请通过 binding（例如 WidgetsBinding.instance.platformDispatcher）访问 PlatformDispatcher，而不是使用静态单例 PlatformDispatcher.instance。关于推荐此做法的原因，请参阅 PlatformDispatcher.instance。

另请参阅：

  • FlutterView, which gives an application access to view-specific functionality.
  • PlatformDispatcher, which gives an application access to platform-specific functionality.
  • PlatformDispatcher.views, for a list of all available views.
