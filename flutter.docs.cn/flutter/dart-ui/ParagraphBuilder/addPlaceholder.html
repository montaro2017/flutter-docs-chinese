在段落中添加内联占位空间。

段落中会包含指定尺寸的矩形空间，其中不包含文本。

width 和 height 参数指定占位矩形的尺寸。

alignment 参数指定占位矩形相对于周围文本的垂直对齐方式。使用 PlaceholderAlignment.baseline、PlaceholderAlignment.aboveBaseline 或 PlaceholderAlignment.belowBaseline 对齐模式时，必须通过 baseline 设置基线。使用 PlaceholderAlignment.baseline 时，baselineOffset 表示基线距矩形顶部的距离。baselineOffset 默认为 height。

示例：

  • For a 30x50 placeholder with the bottom edge aligned with the bottom of the text, use: addPlaceholder(30, 50, PlaceholderAlignment.bottom);
  • For a 30x50 placeholder that is vertically centered around the text, use: addPlaceholder(30, 50, PlaceholderAlignment.middle);.
  • For a 30x50 placeholder that sits completely on top of the alphabetic baseline, use: addPlaceholder(30, 50, PlaceholderAlignment.aboveBaseline, baseline: TextBaseline.alphabetic).
  • For a 30x50 placeholder with 40 pixels above and 10 pixels below the alphabetic baseline, use: addPlaceholder(30, 50, PlaceholderAlignment.baseline, baseline: TextBaseline.alphabetic, baselineOffset: 40).

每个占位符周围都允许换行。

装饰线根据最近一次压入的 TextStyle 中定义的字体绘制。绘制时会将占位空间视作存在 Unicode 文本；无论占位符的高度和对齐方式如何，装饰效果都相同。若要隐藏装饰线或手动调整其位置以适应布局，应在添加占位符前压入具有所需装饰行为的文本样式。

穿过占位符绘制的装饰线与文本位于同一画布/图层上。因此，绘制在占位空间之上的内容会覆盖装饰线，可能使其部分不可见。

占位符在文本缓冲区中以 Unicode U+FFFC“对象替换字符”表示。每个占位符都会向文本缓冲区添加一个对象替换字符。

scale 参数会按指定比例缩放 width 和 height，并记录该比例。可通过 placeholderScales 获取已添加占位符的缩放比例。此参数主要用于辅助功能缩放。
