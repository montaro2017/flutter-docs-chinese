TextHeightBehavior 构造函数

const TextHeightBehavior({
  1. bool applyHeightToFirstAscent = true,
  2. bool applyHeightToLastDescent = true,
  3. TextLeadingDistribution leadingDistribution = TextLeadingDistribution.proportional,
})

创建一个新的 TextHeightBehavior 对象。

  • applyHeightToFirstAscent：为 true 时，TextStyle.height 修饰值会作用于第一行的 ascent；为 false 时，将使用字体默认的 ascent。
  • applyHeightToLastDescent：为 true 时，TextStyle.height 修饰值会作用于最后一行的 descent；为 false 时，将使用字体默认的 descent。
  • leadingDistribution：行距在文本上方和下方 的分布方式。

所有属性默认都为 true（按常规方式应用高度调整）。

实现

const TextHeightBehavior({
  this.applyHeightToFirstAscent = true,
  this.applyHeightToLastDescent = true,
  this.leadingDistribution = TextLeadingDistribution.proportional,
});
