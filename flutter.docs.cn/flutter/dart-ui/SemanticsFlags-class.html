SemanticsFlags

SemanticsFlags 类

表示一组布尔标记，用于传达 widget 的无障碍状态和属性等语义信息。

例如，这些标记可以指示某个元素是否可勾选、当前是否已选中、是否可选择，或是否具有按钮功能。

创建一组用于描述 widget 各种状态的语义标志。 除非另有指定，否则所有标志默认均为 false。
