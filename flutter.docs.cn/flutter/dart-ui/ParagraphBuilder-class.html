ParagraphBuilder

ParagraphBuilder 类 抽象

构建一个 Paragraph，其中包含具有指定样式信息的文本。

若要设置段落的对齐方式、截断和省略行为，请将配置合适的 ParagraphStyle 对象传递给 ParagraphBuilder.new 构造函数。

然后，组合调用 pushStyle、addText 和 pop，向对象添加带样式的文本。

最后，调用 build 获取构造完成的 Paragraph 对象。此后，构建器将不能再使用。

构造出 Paragraph 后，先对其调用 Paragraph.layout，再使用 Canvas.drawParagraph 绘制。
