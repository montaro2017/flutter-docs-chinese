ImageShader(

  5. FilterQuality? filterQuality,

创建一个图像平铺着色器。

第一个参数指定要渲染的图像。可以使用 decodeImageFromList 函数，将字节数据中的图像解码为此处所需的格式。（在生产代码中，最好从 instantiateImageCodec 开始处理。）

第二和第三个参数分别指定 x 方向和 y 方向的 TileMode。可以使用 TileMode.repeated 平铺图像。

第四个参数提供应用于此效果的矩阵。表达式 Matrix4.identity().storage 会创建一个预先填入单位矩阵的 Float64List。

除 filterQuality 外，所有参数都是必需的且不得为 null。如果构造时未指定 filterQuality，系统会根据其使用环境推导该值，例如从 Paint.filterQuality 获取。

实现

@pragma('vm:entry-point')
ImageShader(
  Image image,
  TileMode tmx,
  TileMode tmy,
  Float64List matrix4, {
  FilterQuality? filterQuality,
}) : assert(!image.debugDisposed),
     super._() {
  if (matrix4.length != 16) {
    throw ArgumentError('"matrix4" must have 16 entries.');
  }
  _constructor();
  final String? error = _initWithImage(
    image._image,
    tmx.index,
    tmy.index,
    filterQuality?.index ?? -1,
    matrix4,
  );
  if (error != null) {
    throw Exception(error);
  }
}
