DisplayCornerRadii

DisplayCornerRadii 类

显示器四个角的圆角半径集合。

此类表示显示器角部的弧度，半径值以物理像素为单位。

如果某个角是直角（没有圆角），其半径为 0.0。

目前仅 Android API 31 及更高版本会填充此值。
