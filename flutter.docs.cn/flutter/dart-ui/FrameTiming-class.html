FrameTiming

FrameTiming 类

帧的时间相关性能指标。

如果使用完整的 Flutter 框架，请通过 SchedulerBinding.addTimingsCallback 获取这些指标。相比直接使用 PlatformDispatcher.onReportTimings，更推荐前者，因为 SchedulerBinding.addTimingsCallback 支持多个回调。如果无法使用 SchedulerBinding，请参阅 PlatformDispatcher.onReportTimings 了解如何获取这些指标。

调试模式（不带任何标志运行 flutter run）下的指标可能因调试开销而与 profile 和 release 模式下的指标差异很大。因此，建议只在 profile 和 release 模式下监控和分析性能指标。
