Canvas

Canvas 类 abstract

用于记录图形操作的接口。

Canvas 对象用于创建 Picture 对象；后者可与 SceneBuilder 配合构建 Scene。不过，在常规用法中，这些工作都由框架处理。

画布具有一个当前变换矩阵，该矩阵会应用于所有操作。初始时，变换矩阵为恒等变换。可以通过 translate、scale、rotate、skew 和 transform 方法修改它。

画布还具有一个当前裁剪区域，该区域会应用于所有操作。初始时，裁剪区域为无限范围。可以通过 clipRect、clipRRect 和 clipPath 方法修改它。

可以使用由 save、saveLayer 和 restore 方法管理的栈来保存和恢复当前变换与裁剪状态。

与 Flutter 框架配合使用

Flutter 框架的 RendererBinding 提供了创建 Canvas 对象的钩子（RendererBinding.createCanvas），允许测试接入场景创建逻辑。在 Flutter 框架上下文中创建要与 Canvas 中的 PictureLayer 配合使用的 Scene 时，可考虑调用 RendererBinding.createCanvas，而不是直接调用 Canvas.new 构造函数。

如果使用画布生成其他用途的位图，则不适用上述建议，例如使用 Picture.toImage 生成 PNG 图像。

getDestinationClipBounds() → Rect
返回当前保存栈中所有裁剪操作合并后的保守边界。这些裁剪操作均在此 Canvas 对象上执行。边界以目标坐标空间测量，也就是 Picture 将被渲染到的坐标空间。
getLocalClipBounds() → Rect
返回当前保存栈中所有裁剪操作合并后的保守边界。这些裁剪操作均在此 Canvas 对象上执行。边界以当前执行渲染操作所使用的本地坐标空间测量。
getSaveCount() → int
返回保存栈中的条目数，包括初始状态。干净的画布返回 1；每次调用 save 或 saveLayer 都会使计数增加，每次对应的 restore 调用则会使计数减少。
getTransform() → Float64List
返回当前变换，其中包含自创建此 Canvas 对象以来执行的所有变换方法的组合结果，并遵循 save/restore 历史记录。
noSuchMethod(Invocation invocation) → dynamic
访问不存在的方法或属性时调用。
继承
restore() → void
如果保存栈中有内容，则弹出当前栈项；否则不执行任何操作。
restoreToCount(int count) → void
将保存栈恢复到先前的层级，该层级可通过 getSaveCount 获得。如果 count 小于 1，则将栈恢复到初始状态。如果 count 大于当前的 getSaveCount，则不执行任何操作。
rotate(double radians) → void
向当前变换添加旋转。参数以弧度为单位，方向为顺时针。
save() → void
将当前变换和裁剪状态的副本保存到保存栈中。
saveLayer(Rect? bounds, Paint paint) → void
将当前变换和裁剪状态的副本保存到保存栈中，然后创建一个新分组，后续调用都会成为该分组的一部分。之后弹出保存栈时，该分组会展平为一个图层，并应用给定 paint 的 Paint.colorFilter 和 Paint.blendMode。
scale(double sx, [double? sy]) → void
向当前变换添加轴对齐的缩放：第一个参数指定水平方向的缩放比例，第二个参数指定垂直方向的缩放比例。
skew(double sx, double sy) → void
向当前变换添加轴对齐的倾斜。第一个参数是水平倾斜量，以顺时针绕原点方向的升程与运行距离之比为单位；第二个参数是垂直倾斜量，单位相同。

translate(double dx, double dy) → void
向当前变换添加平移：第一个参数指定坐标空间的水平偏移量，第二个参数指定垂直偏移量。
