shader 属性

Shader? get shader

描边或填充形状时使用的着色器。

此值为 null 时，将改用 color。

另请参阅：

  • Gradient，一种用于绘制颜色渐变的 shader。
  • ImageShader，一种以平铺方式绘制 Image 的 shader。
  • colorFilter 会覆盖 shader。
  • color，当 shader 和 colorFilter 均为 null 时使用。

实现

Shader? get shader {
  return _objects?[_kShaderIndex] as Shader?;
}
set shader (Shader? value)

实现

set shader(Shader? value) {
  assert(() {
    assert(value == null || !value.debugDisposed, 'Attempted to set a disposed shader to $this');
    return true;
  }());
  assert(() {
    if (value is FragmentShader) {
      if (!value._validateSamplers()) {
        throw Exception('Invalid FragmentShader ${value._debugName ?? ''}: missing sampler');
      }
    }
    return true;
  }());
  _ensureObjectsInitialized()[_kShaderIndex] = value;
}
