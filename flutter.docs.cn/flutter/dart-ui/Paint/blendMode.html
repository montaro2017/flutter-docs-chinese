blendMode 属性

BlendMode get blendMode

绘制形状或合成图层时应用的混合模式。

源颜色来自正在绘制的形状（例如 Canvas.drawPath），或正在合成的图层（即在调用 Canvas.saveLayer 与 Canvas.restore 之间绘制的图形）；如有设置，则先应用 colorFilter。

目标颜色来自形状或图层将要合成到的背景。

默认值为 BlendMode.srcOver。

另请参阅：

  • Canvas.saveLayer 会使用其 Paint 的 blendMode，并在调用 Canvas.restore 时合成图层。
  • BlendMode 说明了 Canvas.saveLayer 与 blendMode 配合使用的方式。

实现

BlendMode get blendMode {
  final int encoded = _data.getInt32(_kBlendModeOffset, _kFakeHostEndian);
  return BlendMode.values[encoded ^ _kBlendModeDefault];
}
set blendMode (BlendMode value)

实现

set blendMode(BlendMode value) {
  final int encoded = value.index ^ _kBlendModeDefault;
  _data.setInt32(_kBlendModeOffset, encoded, _kFakeHostEndian);
}
