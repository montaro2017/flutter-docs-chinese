Vertices

Vertices 类 base

供 Canvas.drawVertices 使用的一组顶点数据。

顶点数据由画布坐标空间中的一系列点组成。根据 VertexMode，这些点会被解释为独立三角形（VertexMode.triangles）、滑动点窗口所形成的一组三角形链（相邻三角形共享一条边，VertexMode.triangleStrip），或共享一个中心点的扇形三角形（VertexMode.triangleFan）。

每个点都可以关联一种颜色。每个三角形会绘制为在其三个顶点颜色之间混合的渐变。如果未指定颜色，则所有点都默认为透明黑色。

随后，这些颜色会与调用 Canvas.drawVertices 时指定的 Paint 混合。该 Paint 可以是纯色（Paint.color），也可以是通过 shader 指定的位图（Paint.shader），通常是渐变（Gradient）或图像（ImageFilter）。位图使用与画布相同的坐标空间（若使用 ImageFilter，这与源图像的坐标空间明显不同：源图像会按照滤镜配置平铺，绘制三角形时采样的是完成所有重复后的无限图像）。

Vertices 中的每个点都关联到该图像中的一个特定点。绘制每个三角形时，会在图像中对应于三角形三个顶点的点之间插值并采样。

Vertices.new 构造函数通过 Offset 和 Color 对象列表配置上述数据。Vertices.raw 构造函数则使用 Float32List、Int32List 和 Uint16List 对象；这些类型更接近内部使用的数据格式，因此可以减少部分转换开销。如果数据来自其他来源（例如文件），并且能直接解析为底层表示形式，raw 构造函数会很有用。
