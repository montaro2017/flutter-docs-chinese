将像素值数组转换为 Image 对象。

pixels 参数是像素数据。数据先按 format 指定的顺序打包为字节，再按行分组，顺序为从左到右、从上到下。

rowBytes 参数是数据缓冲区中每行像素占用的字节数。如果未指定，默认值为 width 乘以所提供 format 中每个像素的字节数。

targetWidth 和 targetHeight 参数指定输出图像的尺寸，单位为图像像素。如果它们与图像的固有尺寸不同，图像将在解码后缩放。如果 allowUpscaling 未设为 true，则即使只有一个维度超出图像固有尺寸，两个维度都会被限制在各自的固有尺寸以内。如果只指定其中一个参数，图像将保持原宽高比，并调整另一维以匹配指定尺寸。如果两者都未指定，则保留图像的固有尺寸。

通常应避免将图像放大到超过其固有尺寸，因为这会导致图像占用不必要的更多内存。建议改为缩放 Canvas 变换。如果必须放大图像，则必须将 allowUpscaling 参数设为 true。

实现

void decodeImageFromPixels(
  Uint8List pixels,
  int width,
  int height,
  PixelFormat format,
  ImageDecoderCallback callback, {
  int? rowBytes,
  int? targetWidth,
  int? targetHeight,
  bool allowUpscaling = true,
  TargetPixelFormat targetFormat = TargetPixelFormat.dontCare,
}) {
  if (targetWidth != null) {
    assert(allowUpscaling || targetWidth <= width);
  }
  if (targetHeight != null) {
    assert(allowUpscaling || targetHeight <= height);
  }

  ImmutableBuffer.fromUint8List(pixels).then((ImmutableBuffer buffer) {
    final descriptor = ImageDescriptor.raw(
      buffer,
      width: width,
      height: height,
      rowBytes: rowBytes,
      pixelFormat: format,
    );

    if (!allowUpscaling) {
      if (targetWidth != null && targetWidth! > descriptor.width) {
        targetWidth = descriptor.width;
      }
      if (targetHeight != null && targetHeight! > descriptor.height) {
        targetHeight = descriptor.height;
      }
    }

    descriptor
        .instantiateCodec(
          targetWidth: targetWidth,
          targetHeight: targetHeight,
          targetFormat: targetFormat,
        )
        .then((Codec codec) {
          final Future<FrameInfo> frameInfo = codec.getNextFrame();
          codec.dispose();
          return frameInfo;
        })
        .then((FrameInfo frameInfo) {
          buffer.dispose();
          descriptor.dispose();

          return callback(frameInfo.image);
        });
  });
}
