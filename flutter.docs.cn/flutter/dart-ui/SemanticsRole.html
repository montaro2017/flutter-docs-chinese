SemanticsRole

SemanticsRole enum

用于描述语义节点角色的枚举。

在各个平台上，这些角色会转换为对应的原生无障碍角色。

继承关系
  • Object
  • Enum
  • SemanticsRole
Available extensions
  • EnumName

Values

none → const SemanticsRole

不代表任何角色。

tab → const SemanticsRole

选项卡按钮。

另请参阅：

  • tabBar, which is the role for containers of tab buttons.
tabBar → const SemanticsRole

包含选项卡按钮。

另请参阅：

  • tab, which is the role for tab buttons.
tabPanel → const SemanticsRole

选项卡的主显示区域。

dialog → const SemanticsRole

弹出对话框。

alertDialog → const SemanticsRole

警告对话框。

table → const SemanticsRole

表格结构，其中的数据按行和列排列。

另请参阅：

  • cell, row, columnHeader for table related roles.
cell → const SemanticsRole

表格 table 中不包含列标题或行标题信息的单元格。

另请参阅：

  • table,row, columnHeader for table related roles.
row → const SemanticsRole

表格中的一行，包含 cell 或 columnHeader，位于 table 中。

另请参阅：

  • table ,cell,columnHeader for table related roles.
columnHeader → const SemanticsRole

表格 table 中包含列标题信息的单元格。

另请参阅：

  • table ,cell, row for table related roles.
dragHandle → const SemanticsRole

用于拖动内容的控件。

例如，ReorderableList 的拖动手柄。

spinButton → const SemanticsRole

点击时可循环切换内容的控件。

例如，CalendarDatePicker 中用于切换上个月和下个月的按钮。

comboBox → const SemanticsRole

附带下拉列表框的输入字段。

例如，DropdownMenu

menuBar → const SemanticsRole

通常持续显示且以水平方向呈现的 menu。

例如，MenuBar。

menu → const SemanticsRole

始终可见的控件列表，或可打开和关闭的 widget。

例如，MenuAnchor 或 DropdownButton。

menuItem → const SemanticsRole

下拉菜单中由 menu 或 menuBar 创建的项目。

另请参阅：

  • menuItemCheckbox, a menu item with a checkbox. The menuItemCheckbox can also be used within menu 和 menuBar.
  • menuItemRadio, a menu item with a radio button. This role is used by menu or menuBar as well.
menuItemCheckbox → const SemanticsRole

下拉菜单中带复选框的项目，由 menu 或 menuBar 创建。

另请参阅：

  • menuItem 和 menuItemRadio for menu related roles.
menuItemRadio → const SemanticsRole

下拉菜单中带单选按钮的项目，由 menu 或 menuBar 创建。

另请参阅：

  • menuItem 和 menuItemCheckbox for menu related roles.
list → const SemanticsRole

用于以纵向或横向布局显示多个 listItem 的容器。

例如，LisView 或 Column。

listItem → const SemanticsRole

列表中的一个 list 项目。

form → const SemanticsRole

表示表单的区域。

tooltip → const SemanticsRole

将鼠标悬停在组件上时显示的提示，用于提供上下文说明。

loadingSpinner → const SemanticsRole

通过旋转表示应用正忙的图形对象。

例如，CircularProgressIndicator。

progressBar → const SemanticsRole

以数值显示进度的图形对象。

例如，LinearProgressIndicator。

hotKey → const SemanticsRole

键盘快捷键输入字段，允许用户输入按键组合或按键序列。

例如，Shortcuts。

radioGroup → const SemanticsRole

一组单选按钮。

status → const SemanticsRole

提供建议性信息的组件，这些信息的重要程度不足以使用 alert。

例如，网页的加载提示。

alert → const SemanticsRole

提供重要且通常具有时效性信息的组件。

alert 角色只应当用于需要用户立即关注的信息，例如：

  • An invalid value was entered into a form field.
  • The user's login session is about to expire.
  • The connection to the server was lost so local changes will not be saved.
complementary → const SemanticsRole

与主要内容相关的辅助区段。

complementary 角色属于地标角色，可用于描述侧边栏或提示框。

更多信息请参阅：https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/complementary_role

contentInfo → const SemanticsRole

页脚区段，包含版权信息、导航链接和隐私声明等标识信息。

contentInfo 角色属于地标角色。更多信息请参阅：https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/contentinfo_role

main → const SemanticsRole

文档的主要内容。

该区段包含与文档中心主题或应用主要功能直接相关或对其进行扩展的内容。

此角色属于地标角色。更多信息请参阅：https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/main_role

navigation → const SemanticsRole

包含导航链接的网页区域。

此角色属于地标角色。更多信息请参阅：https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/navigation_role

region → const SemanticsRole

重要程度足够高、但无法归入 main、contentInfo、complementary 或 navigation 等其他地标角色的内容区段。

更多信息请参阅：https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/region_role
