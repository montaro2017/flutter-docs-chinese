physicalSize

physicalSize 属性

Size get physicalSize

平台最近一次报告的矩形当前尺寸；渲染到此视图的场景会绘制在该矩形内。

如果视图使用宽松的 physicalConstraints，此值可能会过时几帧，因为只有当平台处理了某一帧所选的尺寸（由 render 方法提供）后，此值才会更新。因此，UI 框架布局算法的根输入应使用 physicalConstraints，而不是此值。

此值变化时会调用 PlatformDispatcher.onMetricsChanged。使用 Flutter 框架时，建议通过 MediaQuery.of 获取尺寸（通过 MediaQueryData.size），而不是直接从 FlutterView 获取 physicalSize。这样，尺寸变化时，依赖它的 widget 会自动重建，无需监听 PlatformDispatcher.onMetricsChanged。

应用启动时，在 Dart 代码运行前可能还无法确定视图尺寸。如果在应用生命周期早期读取此值，可能会返回 Size.zero。

此值不考虑屏幕键盘或其他系统 UI。padding 和 viewInsets 属性会说明视图各侧有多少区域可能被系统 UI 遮挡。

另请参阅：

  • WidgetsBindingObserver, for a mechanism at the widgets layer to observe when this value changes.

实现

Size get physicalSize => _viewConfiguration.size;
