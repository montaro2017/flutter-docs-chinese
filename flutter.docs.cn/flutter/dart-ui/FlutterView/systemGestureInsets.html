systemGestureInsets 属性

ViewPadding get systemGestureInsets

显示矩形每一侧的物理像素数；视图可以在该矩形内渲染，但操作系统会占用这些边缘区域来识别系统导航手势。

例如，操作系统可能会使用屏幕的垂直边缘区域。用户从边缘向内滑动时，系统会带用户返回之前访问过的屏幕。

此属性变化时会调用 PlatformDispatcher.onMetricsChanged。

另请参阅：

  • WidgetsBindingObserver, for a mechanism at the widgets layer to observe when this value changes.
  • MediaQuery.of, a simpler mechanism for the same.

实现

ViewPadding get systemGestureInsets => _viewConfiguration.systemGestureInsets;
