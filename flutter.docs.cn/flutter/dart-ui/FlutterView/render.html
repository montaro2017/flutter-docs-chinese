使用新提供的 Scene 更新视图在 GPU 上的渲染内容。

必须在调用 PlatformDispatcher.onBeginFrame 或 PlatformDispatcher.onDrawFrame 回调期间调用此函数。

如果在一次 PlatformDispatcher.onBeginFrame/PlatformDispatcher.onDrawFrame 回调序列中第二次调用此函数，或在这些回调之外调用，则该次调用会被忽略。

要记录图形操作，先创建 PictureRecorder，再构造 Canvas 并将该 PictureRecorder 传给其构造函数。完成所有图形操作后，在 PictureRecorder 上调用 PictureRecorder.endRecording，即可获得表示这些图形操作的最终 Picture。

接下来创建 SceneBuilder，并使用 SceneBuilder.addPicture 将 Picture 添加到其中。然后调用 SceneBuilder.build 获取 Scene 对象，并通过此 render 函数将其显示给用户。

如果视图配置了宽松的 physicalConstraints（即 ViewConstraints.isTight 返回 false），则必须提供满足这些约束的 size。此方法不会检查所提供的 size 是否确实满足约束（应由更高层完成检查），但不合法的 size 可能导致未定义的渲染行为。如果未提供 size，则使用 physicalSize。

另请参阅：

  • SchedulerBinding，Flutter 框架中负责帧调度的类。
  • RendererBinding，Flutter 框架中负责布局和绘制的类。

实现

void render(Scene scene, {Size? size}) {
  _render(
    viewId,
    scene as _NativeScene,
    size?.width ?? physicalSize.width,
    size?.height ?? physicalSize.height,
  );
}
