SingletonFlutterWindow

SingletonFlutterWindow 类

已弃用。将在 Flutter 的未来版本中移除。

弃用此类是为了配合 Flutter 即将推出的多视图支持，并最终支持多个窗口。

此类已拆分为 FlutterView 和 PlatformDispatcher。FlutterView 为应用提供特定于视图的功能，而 PlatformDispatcher 包含适用于所有视图的平台特定功能。

此类是全局 window 单例的底层实现；该单例也已弃用。迁移选项请参阅 window 文档。

另请参阅：

  • FlutterView, which gives an application access to view-specific functionality.
  • PlatformDispatcher, which gives an application access to platform-specific functionality.
