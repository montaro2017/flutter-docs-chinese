defaultRouteName

defaultRouteName 属性

String get defaultRouteName

应用启动时嵌入器请求的路由或路径。

读取此值会返回 PlatformDispatcher 单例中的值。因此，建议改为从 WidgetsBinding.instance.platformDispatcher 获取此值；如果无法使用 WidgetsBinding，则可从 PlatformDispatcher.instance 获取。此值转发到 PlatformDispatcher，是为了方便只使用单个主窗口的应用。

如果未请求特定路由，此值为字符串“/”。

Android

在 Android 上，可以通过 initialRoute 方法设置初始路由，该方法属于 FlutterActivity 的 Intent 构建器。

对于独立引擎，请参阅 https://docs.flutter.dev/development/add-to-app/android/add-flutter-screen#initial-route-with-a-cached-engine。

iOS

在 iOS 上，可以通过 FlutterViewController.setInitialRoute 初始化方法设置初始路由。

对于独立引擎，请参阅 https://docs.flutter.dev/development/add-to-app/ios/add-flutter-screen#route。

另请参阅：

  • Navigator, a widget that handles routing.
  • SystemChannels.navigation, which handles subsequent navigation requests from the embedder.

实现

String get defaultRouteName => platformDispatcher.defaultRouteName;
