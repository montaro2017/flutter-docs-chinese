更新与给定 id 关联的节点信息。

语义节点构成一棵树，树根的 ID 始终为零。childrenInTraversalOrder 和 childrenInHitTestOrder 分别列出此节点的直接子节点 ID：前者按遍历顺序排列，后者按命中测试顺序排列。两个列表长度必须相同，且包含相同的 ID；它们只能在 ID 的排列顺序上不同。有关不同子节点顺序的更多信息，请参阅 DebugSemanticsDumpOrder。

系统会保留当前从根节点可达的节点。某次更新无需包含未发生变化的节点信息。更新后，如果某个节点从根节点不可达，该节点就会从树中移除。

flags 是一个位字段，包含适用于此节点的 SemanticsFlag。

actions 是一个位字段，包含此节点可以执行的 SemanticsAction。如果用户希望对该节点执行其中某项操作，系统会调用 PlatformDispatcher.onSemanticsActionEvent，并传入指定待执行操作的 SemanticsActionEvent。由于语义树是异步维护的，调用 PlatformDispatcher.onSemanticsActionEvent 回调时，相关操作可能已不再可用。

identifier 是一个描述节点的字符串，供通过查询无障碍层级工作的 UI 自动化工具使用，例如 Android UI Automator、iOS XCUITest 或 Appium。此字符串不会展示给用户。

label 是描述此节点的字符串。value 属性以字符串形式描述节点当前的值。执行 SemanticsAction.increase 操作后，increasedValue 字符串将成为 value 字符串；执行 SemanticsAction.decrease 操作后，decreasedValue 字符串将成为 value 字符串。hint 字符串描述对此节点执行操作后会产生什么结果。所有这些字符串的阅读方向由 textDirection 指定。

labelAttributes、valueAttributes、hintAttributes、increasedValueAttributes 和 decreasedValueAttributes 分别是 label、value、hint、increasedValue 和 decreasedValue 所携带的 StringAttribute 列表。在语义更新过程中不得更改这些列表的内容。

tooltip 是一个字符串，用于描述用户悬停在此语义节点对应的 widget 上或长按时显示的补充信息。

textSelectionBase 和 textSelectionExtent 字段描述 value 中当前选中的文本。值为 -1 表示当前没有选区起点或终点。

maxValueLength 字段用于指示可编辑文本字段是否限制输入字符数。值为 -1 表示不限制输入字符数。currentValueLength 字段表示已使用的字符数。当 maxValueLength 大于或等于 0 时，currentValueLength 也必须为

0；否则应将其设为 -1。

platformViewId 字段引用一个平台视图，该视图的语义节点将作为此节点的子节点添加。如果指定了平台视图，childrenInHitTestOrder 和 childrenInTraversalOrder 必须为空。值为 -1 表示此节点未关联平台视图。

对于可滚动节点，scrollPosition 描述当前滚动位置（逻辑像素）。scrollExtentMax 和 scrollExtentMin 描述 scrollPosition 的有效最大值和最小值。任一值或两者均可为无穷大，表示滚动范围不受限制。例如，在过度滚动期间，scrollPosition 的值可能暂时超出此范围。scrollChildren 是参与语义信息的子节点总数；scrollIndex 是第一个参与语义信息的可见子节点的索引。

traversalParent 指定一个语义节点的 ID，该节点在无障碍遍历中充当此节点的逻辑父节点。此参数仅供 Web 引擎使用，用于在绘制顺序中没有直接连接关系的节点之间建立父子关系。为确保无障碍遍历正确，traversalParent 应设为逻辑遍历父节点的 ID。此参数仅适用于 Web，因为其他平台可以在按遍历顺序生成语义树时完成节点嫁接。嫁接后，遍历顺序和命中测试顺序会有所不同；其他平台可以接受这种情况。但 Web 引擎假定这两种顺序完全相同，因此无法提前执行嫁接。Web 引擎会通过此参数设置 aria-owns 属性来更新遍历顺序。值为 -1 表示没有特殊的遍历父节点。此参数对其他平台无效。

rect 是此节点在自身坐标系中占据的区域。

transform 是一个矩阵，用于将此节点的坐标系映射到其父节点的坐标系。

headingLevel 描述此节点是否为标题，以及它所代表的标题层级。值为 0 表示此节点不是标题；值为 1 或更大时，表示此节点是相应层级的标题。有效值范围为 1 至 6（含边界）。此属性仅供 Web 平台使用，对其他平台无效。

linkUrl 描述此节点所链接到的 URI。如果此节点不是链接，应将其设为空字符串。

role 描述此节点的角色。如果未设置，则默认为 SemanticsRole.none。

locale 描述此节点内容（即 label、value 和 hint）的语言。

如果 validationResult 不为 null，则表示表单字段的验证结果；如果为 null，则表示未验证此节点或验证结果未知。验证用户输入但未使用此参数的表单字段，应通过其他方式向用户传达验证错误，例如将错误文本包含在 label 中。

hitTestBehavior 描述此节点在命中测试期间应如何响应。设为 SemanticsHitTestBehavior.defer（默认值）时，平台会根据节点自身的其他语义属性（不包括从父节点继承的属性）推断适当的行为。不同平台的实现可能不同。

例如，对话框等模态表面可以将此值设为 SemanticsHitTestBehavior.opaque，阻止指针事件传递到其后方的内容；非交互式装饰元素则可以将其设为 SemanticsHitTestBehavior.transparent，允许指针事件穿透。

另请参阅：

  • https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Roles/heading_role
  • https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-level
  • SemanticsValidationResult, that describes possible values for the validationResult argument.
  • SemanticsHitTestBehavior, which describes how hit testing behaves.
