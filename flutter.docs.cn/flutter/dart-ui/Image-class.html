Image

Image 类

指向已解码原始图像数据（像素）的不透明句柄。

若要获取 Image 对象，请使用 ImageDescriptor API。

若要绘制 Image，请使用 Canvas 类的方法，例如 Canvas.drawImage。

接收图像对象的类或方法，在不再需要该句柄时必须调用 dispose。若要创建可共享底层图像的引用，请调用 clone。接收新实例的方法或对象随后负责释放它；只有在所有未释放的句柄都释放后，底层图像才会被释放。

如果 dart:ui 传递了 Image 对象，而接收方希望与其他调用方共享该句柄，则必须在调用 dispose 之前调用 clone。已释放的句柄无法再创建新句柄。

另请参阅：

  • Image, the class in the widgets library.
  • ImageDescriptor, which allows reading information about the image and creating a codec to decode it.
  • instantiateImageCodec, a utility method that wraps ImageDescriptor.
