Document

Document 类

所有文档的基类。

浏览器加载的每个网页都有自己的 Document 对象，通常是 HtmlDocument。

如果你不熟悉 DOM 概念，请参阅 Dart 教程 目标 2：连接 Dart 与 HTML。
