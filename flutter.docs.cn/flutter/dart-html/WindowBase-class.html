WindowBase

WindowBase 类 抽象

浏览器标签页或窗口的顶层容器。

在 Web 浏览器中，WindowBase 对象表示任意浏览器窗口。此对象包含窗口的状态及其与其他窗口的关系，例如哪个窗口打开了当前窗口。

注意：此类可表示任意窗口；Window 用于访问当前窗口或标签页的属性和内容。
