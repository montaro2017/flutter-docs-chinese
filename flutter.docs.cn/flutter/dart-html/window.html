window

window top-level property

Window get window

网页的顶层容器，通常是浏览器标签页或窗口。

浏览器中加载的每个网页都有自己的 Window，它是该网页的容器。

如果网页包含 <iframe> 元素，则每个 <iframe> 都有自己的 Window 对象，且只能由对应的 <iframe> 访问。

  • Window （MDN）
