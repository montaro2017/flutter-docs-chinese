dart:html

dart:html 库

为需要与浏览器及 DOM（文档对象模型）交互的网页应用提供 HTML 元素和其他资源。

注意

此核心库已弃用，计划于 2025 年底移除。它已由 package:web 取代。详情请参阅迁移指南。

此库包含 DOM 元素类型、CSS 样式、本地存储、媒体、语音、事件等内容。 若要开始使用，请查看 Element 类，它是许多 HTML DOM 类型的基类。

有关使用 Dart 编写 Web 应用的信息，请参阅 https://dart.dev/web。
