CssRect

CssRect 类 抽象

用于表示 CSS 尺寸的类。

与用途更广泛的 Rectangle 类不同，此类的值可变，因此可以通过编程方式更改元素的高度。

重要提示：使用这些方法会执行 CSS 计算，可能触发浏览器回流。因此不建议在动画帧期间使用这些属性。另请参阅：浏览器回流
