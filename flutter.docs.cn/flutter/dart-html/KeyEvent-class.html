KeyEvent

KeyEvent 类

一种自定义 KeyboardEvent，旨在消除跨浏览器差异，并为所有键盘事件提供 keyCode 和 charCode 信息（如果能够确定这些信息）。

KeyEvent 尝试在“原始”KeyboardEvent 的基础上，提供更高级、更完善的键盘事件信息。

KeyEvent 的使用方式与底层 KeyboardEvent 略有不同。使用 KeyEvent 时，需要先创建一个流，再将 KeyEvent 添加到该流，而不是使用 EventTarget.dispatchEvent。下面是一个用法示例：

// Initialize a stream for the KeyEvents:
var stream = KeyEvent.keyPressEvent.forTarget(document.body);
// Start listening to the stream of KeyEvents.
stream.listen((keyEvent) =>
    window.console.log('KeyPress event detected ${keyEvent.charCode}'));
...
// Add a new KeyEvent of someone pressing the 'A' key to the stream so
// listeners can know a KeyEvent happened.
stream.add(new KeyEvent('keypress', keyCode: 65, charCode: 97));

此类仍在积极开发中。我们希望了解如何让它尽可能支持各种国际键盘。欢迎报告问题！
