HttpRequest

HttpRequest 类

用于从 URL 获取数据的客户端 XHR 请求，正式名称为 XMLHttpRequest。

注意：应避免直接使用 HttpRequest 发送 HTTP 请求。可以通过 BrowserClient 适配器间接使用 HttpRequest；该适配器属于 package:http。

使用 package:http 等更高层级的库，可以用最少的代码更改切换实现方式。例如，package:http 的 Client 在浏览器中有相应实现，也提供在 Android 和 iOS 上使用平台原生 HTTP 客户端的实现。

HttpRequest 可用于通过 HTTP 和 FTP 协议获取数据，也适用于 AJAX 风格的页面更新。

获取文本文件（例如 JSON 格式文件）内容的最简单方法是使用 getString。例如，以下代码获取 JSON 文件内容并打印其长度：

var path = 'myData.json';
HttpRequest.getString(path).then((String fileContents) {
  print(fileContents.length);
}).catchError((error) {
  print(error.toString());
});

从其他服务器获取数据

出于安全原因，浏览器会限制嵌入式应用发出的请求。使用此类的默认行为时，发出请求的代码必须与请求的资源来自同一源（域名、端口和应用层协议）。在上面的示例中，myData.json 文件必须与使用它的应用位于同一位置。
