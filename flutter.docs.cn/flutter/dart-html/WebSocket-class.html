WebSocket

WebSocket 类

使用 WebSocket 接口连接到 WebSocket，并通过该连接发送和接收数据。

要在 Web 应用中使用 WebSocket，首先创建一个 WebSocket 对象，并将 WebSocket URL 作为构造函数参数传入。

var webSocket = new WebSocket('ws://127.0.0.1:1337/ws');

要通过 WebSocket 发送数据，请使用 send 方法。

if (webSocket != null && webSocket.readyState == WebSocket.OPEN) {
  webSocket.send(data);
} else {
  print('WebSocket not connected, message $data not sent');
}

要通过 WebSocket 接收数据，请为 message 事件注册监听器。

webSocket.onMessage.listen((MessageEvent e) {
  receivedData(e.data);
});

message 事件处理程序会接收一个 MessageEvent 对象作为唯一参数。也可以按 Event 的说明定义 open、close 和 error 处理程序。

更多信息请参阅 library tour 中的 WebSockets 章节，以及 HTML5Rocks.com 教程 Introducing WebSockets。
