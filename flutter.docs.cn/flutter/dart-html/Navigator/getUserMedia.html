getUserMedia

getUserMedia 方法

Future<MediaStream> getUserMedia({
  1. dynamic audio = false,
  2. dynamic video = false,
})

从本地计算机获取媒体流（视频和/或音频）。

使用 MediaStream.supported 检查当前平台是否支持此功能。参数 audio 和 video 默认为 false（分别表示媒体流不使用音频或视频）。

简单用法示例：

window.navigator.getUserMedia(audio: true, video: true).then((stream) {
  var video = new VideoElement()
    ..autoplay = true
    ..src = Url.createObjectUrlFromStream(stream);
  document.body.append(video);
});

用户也可以为 audio 或 video 参数传入 Map，以指定媒体流的必需和可选约束。如果不传入映射而传入 true，则会获得具有音频或视频能力、但不附加其他约束的 MediaStream。音频和视频的具体约束名称仍在调整中；以下是添加更多约束的示例。

window.navigator.getUserMedia(
    audio: true,
    video: {'mandatory':
               { 'minAspectRatio': 1.333, 'maxAspectRatio': 1.334 },
            'optional':
               [{ 'minFrameRate': 60 },
                { 'maxWidth': 640 }]
});

实现

@SupportedBrowser(SupportedBrowser.CHROME)
Future<MediaStream> getUserMedia({audio = false, video = false}) {
  var completer = new Completer<MediaStream>();
  var options = {'audio': audio, 'video': video};
  _ensureGetUserMedia();
  this._getUserMedia(
    convertDartToNative_SerializedScriptValue(options),
    (stream) {
      completer.complete(stream);
    },
    (error) {
      completer.completeError(error);
    },
  );
  return completer.future;
}
