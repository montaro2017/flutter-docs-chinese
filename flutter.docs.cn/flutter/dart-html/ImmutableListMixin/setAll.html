重写

使用 iterable 中的对象覆盖列表元素。

从 index 位置开始，将 iterable 中的元素写入此列表。此操作不会增加列表长度。

index 必须非负，且不得大于 length。

iterable 中的元素数量不得超过从 index 到 length 的可用位置数。

如果 iterable 基于此列表，其值可能会在 setAll 操作期间发生变化。

final list = <String>['a', 'b', 'c', 'd'];
list.setAll(1, ['bee', 'sea']);
print(list); // [a, bee, sea, d]
