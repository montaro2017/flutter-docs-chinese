重写

将 other 中的所有键值对添加到此映射中。

如果 other 中的键已存在于此映射中，则其对应的值会被覆盖。

此操作等同于对每个键及其对应值执行 this[key] = value。该操作会遍历 other，因此遍历期间 other 不得发生变化。

final planets = <int, String>{1: 'Mercury', 2: 'Earth'};
planets.addAll({5: 'Jupiter', 6: 'Saturn'});
print(planets); // {1: Mercury, 2: Earth, 5: Jupiter, 6: Saturn}

实现

void addAll(Map<String, String> other) {
  other.forEach((k, v) {
    this[k] = v;
  });
}
