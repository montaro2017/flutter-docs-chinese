KeyCode

KeyCode 类 抽象

定义 KeyboardEvent.keyCode 返回的按键代码值。

重要提示：不同浏览器在不同地区设置和键盘布局下处理按键代码及其变体的方式差异很大。提供这些常量是为了让处理按键的代码更易读。
