NodeValidatorBuilder

NodeValidatorBuilder 类

帮助构建标准节点验证策略的类。

默认情况下，此类不会接受任何内容，但可以使用“allow*”函数扩展允许的元素或属性类型。

所有 allow 函数都采用叠加规则：只要某条规则接受元素，该元素就会被接受。

请注意，清理不仅用于防止跨站脚本攻击，也用于防止信息以意料之外的方式显示。例如，只用于显示基本格式文本的内容可能不希望出现 <video> 标签。在这种情况下，使用仅配置了 allowTextElements 的空 NodeValidatorBuilder 可能更合适。
