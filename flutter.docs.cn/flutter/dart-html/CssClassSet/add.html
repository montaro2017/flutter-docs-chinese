将类 value 添加到元素。

add 和 addAll 相当于 Dart 中的 jQuery addClass。

如果此 CssClassSet 对应一个元素，则当 value 已添加到集合时返回 true，否则返回 false。

如果此 CssClassSet 对应多个元素，则始终返回 false。

value 必须是表示单个类的有效“令牌”，即非空且不包含空白字符的字符串。若要添加多个类，请使用 addAll。
