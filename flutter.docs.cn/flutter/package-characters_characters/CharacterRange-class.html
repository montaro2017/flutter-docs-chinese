CharacterRange

CharacterRange 类 抽象

Characters 中的一段字符范围。

source 中一段连续字符，对应源序列中的起始和结束位置。范围可以为空；即便如此，它仍对应一个位置，此时起始和结束位置相同。

源序列可分为范围之前的字符、范围本身，以及范围之后的字符。

有些操作会检查或处理当前范围中的字符，另一些操作则通过移动起点和/或终点来修改范围。

一般而言，以 move 开头的操作会同时移动起点和终点，选取一个与当前范围不重叠的新范围。以 collapse 开头的操作会将当前范围缩小为其子范围。以 expand 开头的操作会通过将终点向后移动或起点向前移动来扩大当前范围；以 drop 开头的操作则会通过将起点向后移动或终点向前移动来缩小当前范围，从一端或两端移除字符。

此字符范围实现了 Iterator。不带参数调用 moveNext 操作时，会逐个迭代 source 序列中的下一个字符。
