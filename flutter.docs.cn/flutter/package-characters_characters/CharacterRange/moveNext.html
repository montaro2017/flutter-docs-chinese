重写

将范围移动到当前范围之后的下一个 count 个字符。

新范围从当前范围的末尾开始，并包含后续 count 个字符；如果后续字符不足 count 个，则尽可能包含现有字符。

count 不能为负数。如果为零，调用效果与 collapseToEnd 相同。

如果当前范围后有 count 个字符，返回 true；否则返回 false。
