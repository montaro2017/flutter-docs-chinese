FakeTimer

FakeTimer 类

由 FakeAsync 控制的 Timer 实现。

周期性计时器会尽量保持等时触发。自启动以来，每经过 duration 的整数倍，就会尽可能立即触发，而不受之前回调实际运行时间的影响。此行为与 VM 计时器一致。

Web 上的重复计时器则会在上一次回调结束后再等待一个 duration 才重新安排，因此回调延迟或运行时间较长都会使触发时间后移。这样可以保证两次回调之间至少间隔一个 duration。
