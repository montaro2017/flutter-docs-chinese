ViewingConditions

ViewingConditions 类

在传统色彩空间中，只需根据观察者对颜色的测量结果即可识别颜色。CAM16 等色彩外观模型还会使用颜色被观察时的环境信息，这些信息称为观察条件。

例如，在传统假设中，正午太阳光的白点被视为白色；而 CAM16 会将其准确测量为略带色度的蓝色。（大致为色相 203、彩度 3、明度 100）

此类会缓存 CAM16 转换过程中仅取决于观察条件的中间值，从而提升计算速度。
