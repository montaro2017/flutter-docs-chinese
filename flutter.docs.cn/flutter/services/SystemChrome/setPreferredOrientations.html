setPreferredOrientations static 方法

Future<void> setPreferredOrientations(
  1. List<DeviceOrientation> orientations
)

指定应用界面可以显示的设备方向集合。

orientation 参数是 DeviceOrientation 枚举值列表。空列表表示由操作系统采用默认设置。

限制

Android

如果 Flutter 应用面向 Android 16（API 36）或更高版本，且设备显示宽度 >= 600 dp，则无法通过 SystemChrome.setPreferredOrientations 设置设备方向。详情请参阅 Android 16 文档此处。

Android 仅允许以下方向组合：

  • None (empty) - Corresponds to unspecified
  • portraitUp - Corresponds to portrait
  • landscapeLeft - Corresponds to landscape
  • portraitDown - Corresponds to reversePortrait
  • portraitUp, portraitDown - Corresponds to userPortrait
  • landscapeRight - Corresponds to reverseLandscape
  • landscapeLeft, landscapeRight - Corresponds to userLandscape
  • portraitUp, landscapeLeft, landscapeRight - Corresponds to user
  • portraitUp, portraitDown, landscapeLeft, landscapeRight - Corresponds to fullUser

Android 屏幕可能会对锁定方向的应用采用信箱模式，尤其是在较大屏幕上。Android 启用信箱模式时，MediaQueryData.size 报告的是信箱区域的尺寸，而不是全屏尺寸。应用若根据屏幕尺寸决定是否锁定方向，必须使用当前 FlutterView 的 display 属性。

// A widget that locks the screen to portrait if it is less than 600
// logical pixels wide.
class MyApp extends StatefulWidget {
  const MyApp({ super.key });

  @override
  State<MyApp> createState() => _MyAppState();
}

class _MyAppState extends State<MyApp> with WidgetsBindingObserver {
  ui.FlutterView? _view;
  static const double kOrientationLockBreakpoint = 600;

  @override
  void initState() {
    super.initState();
    WidgetsBinding.instance.addObserver(this);
  }

  @override
  void didChangeDependencies() {
    super.didChangeDependencies();
    _view = View.maybeOf(context);
  }

  @override
  void dispose() {
    WidgetsBinding.instance.removeObserver(this);
    _view = null;
    super.dispose();
  }

  @override
  void didChangeMetrics() {
    final ui.Display? display = _view?.display;
    if (display == null) {
      return;
    }
    if (display.size.width / display.devicePixelRatio < kOrientationLockBreakpoint) {
      SystemChrome.setPreferredOrientations(<DeviceOrientation>[
        DeviceOrientation.portraitUp,
      ]);
    } else {
      SystemChrome.setPreferredOrientations(<DeviceOrientation>[]);
    }
  }

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      home: Placeholder(),
    );
  }
}

iOS

只有在 iPad 上停用多任务处理时，系统才会遵循此设置。

你可以选择在 iPad 上停用多任务处理。这样 setPreferredOrientations 就会生效，但应用将不再支持 Slide Over 和 Split View 多任务功能。

如果决定停用多任务处理，可以在 Xcode 的 Deployment Info 中将“Requires full screen”设为 true。

实现

static Future<void> setPreferredOrientations(List<DeviceOrientation> orientations) async {
  await SystemChannels.platform.invokeMethod<void>(
    'SystemChrome.setPreferredOrientations',
    _stringify(orientations),
  );
}
