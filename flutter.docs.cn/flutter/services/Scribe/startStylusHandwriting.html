startStylusHandwriting static 方法

Future<void> startStylusHandwriting()

通知 Android 开始接收手写笔手写输入。

通常，在活动文本字段中检测到来自 PointerDeviceKind.stylus 的 PointerDownEvent 后调用此方法，表示手写笔开始书写。如果当前没有活动的 TextInputConnection，则会忽略此调用。

每次调用此方法之前都应调用 isFeatureAvailable，以确认设备支持且当前可用手写笔手写输入。

支持 Android API 33 及更高版本。

另请参阅：

  • developer.android.com/reference/android/view/inputmethod/InputMethodManager#startStylusHandwriting(android.view.View), which is the corresponding API on Android that this method attempts to mirror.
  • EditableText.stylusHandwritingEnabled, which controls whether Flutter's built-in text fields support handwriting input.

实现

static Future<void> startStylusHandwriting() {
  return _channel.invokeMethod<void>('Scribe.startStylusHandwriting');
}
