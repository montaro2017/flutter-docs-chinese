使用给定名称注册服务扩展方法（完整名称为“ext.flutter.name”）。该方法可选地接受一个名为“value”的参数。省略参数时读取当前值；提供参数时则设置当前值。此方法会返回当前值。

响应服务扩展方法调用时，会调用 getter 回调获取当前值。

服务扩展方法以新值调用时，会将该值传给 setter 回调。

只有构建中包含 vm-service 时，注册的服务扩展才能启用；只有调试模式和性能分析模式的构建会包含 vm-service。服务扩展虽然不能在发布模式下使用，但其代码仍可能被包含在 Dart 快照中，增大二进制文件体积。因此，应使用可让 tree shaker 移除该代码的保护条件包裹它（参见下面的示例代码）。

以下代码注册的服务扩展只会包含在调试构建中。
link 
void myRegistrationFunction() {
  assert(() {
    // Register your service extension here.
    return true;
  }());
}

使用以下代码片段注册的服务扩展可在调试模式和性能分析模式下使用。
link 
void myOtherRegistrationFunction() {
  // kReleaseMode is defined in the 'flutter/foundation.dart' package.
  if (!kReleaseMode) {
    // Register your service extension here.
  }
}

这两种保护条件都能确保 Dart 的 tree shaker 在发布构建中移除服务扩展代码。

实现

@protected
void registerStringServiceExtension({
  required String name,
  required AsyncValueGetter<String> getter,
  required AsyncValueSetter<String> setter,
}) {
  registerServiceExtension(
    name: name,
    callback: (Map<String, String> parameters) async {
      if (parameters.containsKey('value')) {
        await setter(parameters['value']!);
        _postExtensionStateChangedEvent(name, await getter());
      }
      return <String, dynamic>{'value': await getter()};
    },
  );
}
