KeyDataTransitMode enum

按键消息信息的传递模式。

此枚举已弃用，并将被移除。由于移除 RawKeyEvent 及相关 API 后将不再需要此枚举，因此目前没有计划提供直接替代项。

不同平台使用不同的方法、类和模型向框架报告原生按键事件，这种方式称为“传递模式”。

框架必须确定当前平台实现的传递模式，并据此采取相应行为（例如在必要时转换和合成事件）。与键盘相关的单元测试也可能需要模拟每种传递模式的平台。

应用启动时，KeyEventManager 会推断当前平台的传递模式。

另请参阅：

  • KeyEventManager, which infers the transit mode of the current platform and guides how key messages are dispatched.
  • debugKeyEventSimulatorTransitModeOverride, overrides the transit mode used to simulate key events.
  • KeySimulatorTransitModeVariant, an easier way to set debugKeyEventSimulatorTransitModeOverride in widget tests.

Values

rawKeyData → const KeyDataTransitMode

键盘事件信息以原始按键数据的形式传递。

原始按键数据是平台的原生键盘事件信息，通过 method channel 以 JSON 形式发送，随后会被解释为平台对应的 RawKeyEventData 子类。

If the current transit mode is rawKeyData, the raw key data is converted to both KeyMessage.events 和 KeyMessage.rawEvent.

keyDataThenRawKeyData → const KeyDataTransitMode

键盘事件信息先以转换后的按键数据传递，再传递原始按键数据。

按键数据（ui.KeyData）是由平台原生键盘事件信息转换而来的标准化事件流，并通过 embedder API 发送。其事件模型参见 HardwareKeyboard。

原始按键数据是平台的原生键盘事件信息，通过 method channel 以 JSON 形式发送，并由 RawKeyEventData 的子类解释。

如果当前传递模式为 keyDataThenRawKeyData，则 KeyEventManager 会将 ui.KeyData 用作 KeyMessage.events，并将原始数据用作 KeyMessage.rawEvent。
