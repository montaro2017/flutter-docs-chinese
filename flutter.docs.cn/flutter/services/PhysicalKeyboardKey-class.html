description

PhysicalKeyboardKey 类

包含静态值的类，用于描述 RawKeyEvent.physicalKey 返回的按键。

这些是物理按键，即代表 QWERTY 键盘上特定按键位置的按键。它不受当前生效的修饰键、输入模式或键盘布局影响。这与 LogicalKeyboardKey 不同；后者表示结合修饰键、输入模式和/或键盘布局进行解释的逻辑按键。

例如，假设你要制作一款游戏，希望按下 CAPS LOCK 旁边的键（QWERTY 键盘上的 “A” 键）时让玩家向左移动。此时应检查物理按键，以确保无论该键实际输入什么字符，识别到的都是键盘上那个固定位置的按键。

相反，如果要实现按 “Q” 键退出某项功能的应用，应检查逻辑按键，以便匹配键帽上标有 “Q” 的按键，而不是始终查找 “TAB 键旁边的按键”；例如在法语键盘上，TAB 旁边的键标有 “A”。

此示例演示如何检测用户是否按下 CAPS LOCK 右侧的物理按键。

若要使用此代码示例创建本地项目，请运行：
flutter create --sample=services.PhysicalKeyboardKey.1 mysample

另请参阅：

  • RawKeyEvent，监听键盘事件的 widget 接收的键盘事件对象。
  • Focus.onKey，widget 上用于处理按键事件的处理器。
  • RawKeyboardListener，用于监听（但不处理）键盘事件的 widget。
