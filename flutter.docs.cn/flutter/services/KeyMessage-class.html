KeyMessage 类

由原生按键消息转换并汇总而成的信息。

此类已弃用并将被移除。由于移除 RawKeyEvent 及相关 API 后不再需要此类，因此没有计划提供直接替代方案。

通过实际按下或释放键盘按键产生的原生按键消息，在 Flutter 中会转换为两种不同的事件流：

  • The KeyEvent stream, represented by KeyMessage.events (recommended).
  • The RawKeyEvent stream, represented by KeyMessage.rawEvent (legacy, to be deprecated).

单独使用 KeyEvent 流或 RawKeyEvent 流，都能完整描述键盘消息，但两者采用不同的事件模型。Flutter 仍在从旧模型迁移到新模型，因此迁移完成前会同时分发这两种事件流。KeyMessage 会将同一条原生按键消息在两种模型中转换出的事件片段组合起来，方便统一传递。

通常，应用只处理 KeyMessage.events 或 KeyMessage.rawEvent 之一，而不会同时处理两者。例如，处理一个 KeyMessage 就意味着处理其 KeyMessage.events 中的每个事件。

在高级场景中，组件可能需要同时处理两种事件流。例如，FocusNode 有一个用于分发 RawKeyEvent 的 onKey，以及一个用于分发 KeyEvent 的 onKeyEvent。处理 KeyMessage 时，会先对 events 中的每个 KeyEvent 调用 onKeyEvent，然后对 rawEvent 调用 onKey。无论 KeyEventResult 的值如何，所有回调都会执行；它们的结果会通过 combineKeyEventResults 合并为该节点的结果。

// ignore: deprecated_member_use
void handleMessage(FocusNode node, KeyMessage message) {
  final List<KeyEventResult> results = <KeyEventResult>[];
  if (node.onKeyEvent != null) {
    for (final KeyEvent event in message.events) {
      results.add(node.onKeyEvent!(node, event));
    }
  }
  // ignore: deprecated_member_use
  if (node.onKey != null && message.rawEvent != null) {
    // ignore: deprecated_member_use
    results.add(node.onKey!(node, message.rawEvent!));
  }
  final KeyEventResult result = combineKeyEventResults(results);
  // Progress based on `result`...
}
