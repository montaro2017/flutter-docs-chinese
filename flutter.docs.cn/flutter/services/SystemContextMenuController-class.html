SystemContextMenuController 类

用于访问系统上下文菜单。

上下文菜单例如会在选择文本时显示。Flutter 通常自行绘制此菜单；此类处理的是由平台绘制的上下文菜单。

同一时间只能显示一个实例。如果系统上下文菜单已显示时调用 show，会先隐藏当前菜单，再在新的 Rect 位置显示。实例被隐藏时，会通过 onSystemHide 收到通知。

目前，此系统上下文菜单与文本输入绑定。显示的按钮及其操作取决于当前活动的 TextInputConnection。没有活动的 TextInputConnection 时调用此类不会产生任何效果。

不再需要时，请调用 dispose。

另请参阅：

  • ContextMenuController, which controls Flutter-drawn context menus.
  • SystemContextMenu, which wraps this functionality in a widget.
  • MediaQuery.maybeSupportsShowingSystemContextMenu, which indicates whether the system context menu is supported.
