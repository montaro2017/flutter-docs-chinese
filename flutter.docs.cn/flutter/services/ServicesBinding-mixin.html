ServicesBinding
description

ServicesBinding mixin

监听平台消息，并将其分发给 defaultBinaryMessenger。

ServicesBinding 还会注册一个 LicenseEntryCollector，用于公开资源包根目录中 NOTICES 文件（或其压缩版本 NOTICES.Z）所列的许可证；此外还会实现 ext.flutter.evict 服务扩展（参见 evict）。
