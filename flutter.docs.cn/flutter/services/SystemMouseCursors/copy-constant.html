copy constant

SystemMouseCursor const copy

指示当前操作会复制项目的光标。

通常呈箭头形状，角落带有方框加号。

对应于：

  • Android: TYPE_COPY
  • Web: copy
  • Linux: copy
  • macOS: dragCopyCursor

实现

static const SystemMouseCursor copy = SystemMouseCursor._(kind: 'copy');
