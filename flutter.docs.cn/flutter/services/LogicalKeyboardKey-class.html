LogicalKeyboardKey
description

LogicalKeyboardKey 类

包含一组静态值，用于描述 RawKeyEvent.logicalKey 返回的按键。

这些值表示逻辑按键，即根据当前生效的修饰键、输入模式或键盘布局来解释的按键。

这与 PhysicalKeyboardKey 不同；后者表示键盘特定位置上的物理按键，不考虑修饰键状态、输入模式或键盘布局。

例如，如果你要实现一个按下“Q”键就退出的应用，应检查逻辑键，因为你希望匹配标有“Q”的按键，而不是始终查找“TAB 键旁边的按键”：在法语键盘上，TAB 旁边的按键标有“A”。

反过来，如果你要制作一个游戏，并希望按下 CAPS LOCK 旁边的按键（QWERTY 键盘上的“A”键）让角色向左移动，则应检查物理键。这样无论该按键产生什么字符，检测到的都是键盘上那个位置的按键。

此示例演示如何检测用户是否选择了逻辑“Q”键，并在选中时处理该按键。
