system constant

BasicMessageChannel<Object?> const system

用于系统事件的 JSON BasicMessageChannel。

事件以键为字符串的 Map 形式公开。type 键指定事件类型；当前支持的系统事件类型列于下方。可以通过 BasicMessageChannel.setMessageHandler 注册处理程序。

  • memoryPressure：表示操作系统希望应用释放缓存以回收更多内存。请参阅 WidgetsBindingObserver.didHaveMemoryPressure；每当此通道收到消息时都会触发该回调。

实现

static const BasicMessageChannel<Object?> system = BasicMessageChannel<Object?>(
  'flutter/system',
  JSONMessageCodec(),
);
