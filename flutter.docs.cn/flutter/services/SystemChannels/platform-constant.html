platform constant

MethodChannel const platform

用于调用各类平台方法的 JSON MethodChannel。

此通道定义了以下出站方法（通过 OptionalMethodChannel.invokeMethod 调用）：

  • Clipboard.setData：将参数 Map 中 text 条目的内容放入系统剪贴板。参见 Clipboard.setData。

  • Clipboard.getData：从系统剪贴板返回指定格式的数据。参数为 String。目前只支持 text/plain（Clipboard.kTextPlain）。结果是仅含一个 text 键的 Map。参见 Clipboard.getData。

  • HapticFeedback.vibrate：触发系统默认的触觉反馈。参见 HapticFeedback.vibrate。

  • SystemSound.play：触发系统音效。参数必须是描述所需音效的 String；目前只支持 click。参见 SystemSound.play。

  • SystemChrome.setPreferredOrientations：向操作系统声明所需的显示方向。参数是 List，其中的值是 DeviceOrientation 枚举值的字符串表示。参见 SystemChrome.setPreferredOrientations。

  • SystemChrome.setApplicationSwitcherDescription：向操作系统提供在系统级应用列表（例如应用切换器）中描述应用时要使用的标签和颜色。参数是包含两个键的 Map：label 是应用说明 String，primaryColor 是 32 位整数（低 8 位为蓝色通道，接下来的 8 位为绿色通道，再接下来的 8 位为红色通道，高 8 位全部置位；不透明颜色的值与 Color.value 相同）。primaryColor 也可以为零，表示使用系统默认颜色。参见 SystemChrome.setApplicationSwitcherDescription。

  • SystemChrome.setEnabledSystemUIOverlays：指定应用运行时要显示哪些系统界面覆盖层。参数是 List，其中的值是 SystemUiOverlay 枚举值的字符串表示。参见 SystemChrome.setEnabledSystemUIMode。只有在使用 SystemUiMode.manual 时，才能单独配置各个 SystemUiOverlay。

  • SystemChrome.setEnabledSystemUIMode：指定应用的 SystemUiMode。使用 SystemUiMode.manual 时，可选参数 overlays 是一个 List，其中的值为 SystemUiOverlay 枚举值的字符串表示。参见 SystemChrome.setEnabledSystemUIMode。

  • SystemChrome.setSystemUIOverlayStyle：指定系统界面覆盖层（例如 Android 或 iOS 上的状态栏）应使用 light 还是 dark。参数只能是这两个字符串之一。参见 SystemChrome.setSystemUIOverlayStyle。

  • SystemNavigator.pop：通知操作系统关闭应用，或执行最接近的等效操作。参见 SystemNavigator.pop。

  • System.exitApplication：要求引擎向应用发送退出请求（使用下文的 System.requestAppExit）；如果请求未被取消，则通过平台 UI 工具包的终止 API 结束应用。

此通道定义了以下入站方法（通过 MethodChannel.setMethodCallHandler 注册）：

  • SystemChrome.systemUIChange：用户更改了系统界面覆盖层的可见性。使用 SystemChrome.setEnabledSystemUIMode 配置 SystemUiMode 时，此事件尤其相关。若要响应应用状态的此项变化，请参见 SystemChrome.setSystemUIChangeCallback。

  • System.requestAppExit：应用请求终止。参见 ServicesBinding.exitApplication。

  • System.initializationComplete：通知引擎绑定已完成初始化。初始化任务可能包括注册应用退出请求处理程序。

shell 端未实现的方法调用会被忽略（因此，即使相关插件可能缺失，调用这些方法也是安全的）。

实现

static const MethodChannel platform = OptionalMethodChannel(
  'flutter/platform',
  JSONMethodCodec(),
);
