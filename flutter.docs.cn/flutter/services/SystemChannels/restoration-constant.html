MethodChannel const restoration

用于与引擎同步状态恢复数据的 MethodChannel。

此通道定义了以下出站方法（通过 OptionalMethodChannel.invokeMethod 调用）：

  • get：从引擎获取当前的状态恢复信息（例如操作系统提供的信息）。方法返回一个映射，其中的 enabled 布尔值表示 embedder 是否支持收集状态恢复数据。如果 enabled 为 true，映射中还可能包含存放在 data 键下的恢复数据，框架可据此还原状态。恢复数据编码为 Uint8List。
  • put: Sends the current restoration data to the engine. Takes the restoration data encoded as Uint8List as argument.

此通道定义了以下入站方法（通过 MethodChannel.setMethodCallHandler 注册）。

  • push: Called by the engine to send newly provided restoration information to the framework. The argument given to this method has the same format as the object that the get method returns.

另请参阅：

  • RestorationManager, which uses this channel and also describes how restoration data is used in Flutter.

实现

static const MethodChannel restoration = OptionalMethodChannel('flutter/restoration');
