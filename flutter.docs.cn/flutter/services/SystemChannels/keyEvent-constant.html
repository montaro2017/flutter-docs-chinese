keyEvent constant

BasicMessageChannel<Object?> const keyEvent

用于键盘事件的 JSON BasicMessageChannel。

此通道收到的每条入站消息（通过 BasicMessageChannel.setMessageHandler 注册）都由一个 Map 组成，其中包含平台特定的数据，以及一个 type 字段；该字段的值为 keydown 或 keyup。

在 Android 上，可用字段由 RawKeyEventDataAndroid 的属性定义。

在 Fuchsia 上，可用字段由 RawKeyEventDataFuchsia 的属性定义。

目前不会在其他平台上发送消息。

另请参阅：

  • RawKeyboard 使用此 channel 暴露按键数据。
  • RawKeyEvent.fromMessage 可将此数据解码为上文提到的 RawKeyEvent 子类。

实现

static const BasicMessageChannel<Object?> keyEvent = BasicMessageChannel<Object?>(
  'flutter/keyevent',
  JSONMessageCodec(),
);
