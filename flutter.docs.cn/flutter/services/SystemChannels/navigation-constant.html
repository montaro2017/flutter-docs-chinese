navigation constant

MethodChannel const navigation

用于导航的 JSON MethodChannel。

此通道定义了以下入站方法（通过 MethodChannel.setMethodCallHandler 注册）：

  • 系统希望移除当前路由时调用 popRoute（例如用户按下系统级返回按钮时）。

  • 操作系统指示应用打开特定页面时，会调用 pushRoute，并传入一个字符串参数。

  • pushRouteInformation, which is called with a map, which contains a location string and a state object, when the operating system instructs the application to open a particular page. These parameters are stored under the key location 和 state in the map.

以下方法用于相反方向的数据流：框架向引擎通知路由变化。

  • selectSingleEntryHistory 用于启用单条目历史记录模式。

  • selectMultiEntryHistory 用于启用多条目历史记录模式。

  • 应用导航到新位置时会调用 routeInformationUpdated，并传入两个参数：location（URL）和 state（对象）。

  • routeUpdated 是已弃用的 API，可在与 routeInformationUpdated 相同的情况下调用。它的参数为 routeName（URL）和 previousRouteName（该参数会被忽略）。

这些 API 由 SystemNavigator 类公开。

另请参阅：

  • WidgetsBindingObserver.didPopRoute 和 WidgetsBindingObserver.didPushRoute, which expose this channel's methods.
  • Navigator which manages transitions from one page to another. Navigator.push, Navigator.pushReplacement, Navigator.pop 和 Navigator.replace, utilize this channel's methods to send route change information from framework to engine.

实现

static const MethodChannel navigation = OptionalMethodChannel(
  'flutter/navigation',
  JSONMethodCodec(),
);
