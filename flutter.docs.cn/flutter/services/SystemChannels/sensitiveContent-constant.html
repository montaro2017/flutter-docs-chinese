sensitiveContent constant

MethodChannel const sensitiveContent

用于设置和获取 Flutter Android View 内容敏感级别的 MethodChannel。

此通道定义了以下出站方法（通过 OptionalMethodChannel.invokeMethod 调用）：

  • setContentSensitivity：将包含 widget 树的 Flutter Android View 的内容敏感级别设为某个 ContentSensitivity 级别。第二个参数是此通道应为相关 Flutter 视图设置的 ContentSensitivity 级别索引。

  • getContentSensitivity：获取包含 widget 树的 Flutter Android View 的内容敏感级别；返回值是某个 ContentSensitivity 级别的索引。

  • isSupported：返回此设备是否支持设置内容敏感级别。

实现

static const MethodChannel sensitiveContent = OptionalMethodChannel('flutter/sensitivecontent');
