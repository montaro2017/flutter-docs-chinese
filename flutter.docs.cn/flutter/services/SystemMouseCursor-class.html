SystemMouseCursor 类

在应用运行的平台上受原生支持的鼠标光标。

系统光标无需外部资源即可使用，其外观也符合原生应用的使用体验。系统光标的示例包括指向箭头、指针手形、用于调整大小的双向箭头和文本输入 I 形光标等。

一个 SystemMouseCursor 实例对应各个平台上表达同一概念的一个光标，例如文本、可点击或禁止操作。由于各个平台支持的系统光标集合不同，多个实例可能对应同一个系统光标。

下文列出了各光标在不同平台上对应的原生光标：

  • Android：Java API 名称
  • Web：CSS 光标
  • Windows：Win32 API 名称
  • Windows UWP：WinRT API，winrt::Windows::UI::Core::CoreCursorType
  • Linux：GDK，gdk_cursor_new_from_name
  • macOS：Objective-C API 名称

如果未列出应用当前运行的平台，使用该光标时会回退到 SystemMouseCursors.basic。

SystemMouseCursors 列出了 Flutter 支持的所有系统光标。这些光标在引擎中硬编码，因此不支持手动实例化此类。
