MethodChannel 类

用于通过异步方法调用与平台插件通信的命名通道。

发送方法调用前会先将其编码为二进制数据，收到的二进制结果则会解码为 Dart 值。所用的 MethodCodec 必须与平台插件使用的编解码器兼容；可在平台侧为此通道创建对应的方法通道。参数和结果的 Dart 类型为 dynamic，但只能使用指定 MethodCodec 支持的值。使用不受支持的值属于编程错误，会导致抛出异常。所有编解码器都支持 null 值。

通道的逻辑身份由其名称决定。名称相同的通道会相互干扰通信。

Flutter 框架提供的所有 MethodChannel 都保证先进先出（FIFO）顺序。应用可以假定，通过内置 MethodChannel 发送的方法调用会按发送顺序到达平台插件。

另请参阅：flutter.dev/to/platform-channels/
