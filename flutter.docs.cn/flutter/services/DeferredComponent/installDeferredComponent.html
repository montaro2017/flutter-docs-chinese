installDeferredComponent static 方法

Future<void> installDeferredComponent({
  1. required String componentName,
})

请求下载并安装由 componentName 标识的纯资源延迟组件。

此方法返回一个 Future<void>，当功能安装完成且资源可供使用时，该 future 会完成。发生错误时，future 会以错误完成。

此方法适用于仅包含资源的延迟组件，或仅加载同时包含 Dart 代码和资源的组件中的资源。包含 Dart 代码的延迟组件应调用延迟导入库前缀上的 loadLibrary()，以确保 Dart 代码正确加载，因为 loadLibrary() 会提供 Dart 库加载过程所需的加载单元 ID。例如：

import 'split_component.dart' deferred as split_component;
// ...
void _showSplit() {
  // ...
  split_component.loadLibrary();
  // ...
}

此方法不会加载组件中关联的 Dart 库，但会下载所需文件，因此之后调用 loadLibrary() 加载时会更快完成。

此方法安装的资源可以像其他本地资源一样，通过提供字符串路径来访问。

另请参阅：

  • uninstallDeferredComponent，用于请求卸载组件的方法。
  • loadLibrary，用于触发安装包含相应 Dart 库的延迟组件。

实现

static Future<void> installDeferredComponent({required String componentName}) async {
  await SystemChannels.deferredComponent.invokeMethod<void>(
    'installDeferredComponent',
    <String, dynamic>{'loadingUnitId': -1, 'componentName': componentName},
  );
}
