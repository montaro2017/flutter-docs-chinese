BasicMessageChannel<T> 类

一个具名通道，使用异步消息传递与平台插件通信。

消息在发送前会编码为二进制，收到的二进制消息会解码为 Dart 值。所使用的 MessageCodec 必须与平台插件使用的编解码器兼容。为此，可在平台端创建与此通道对应的基本消息通道。发送和接收消息的 Dart 类型为 T，但只能使用指定 MessageCodec 支持的值。使用不受支持的值属于编程错误，并会导致抛出异常。所有编解码器都支持 null 消息。

通道的逻辑身份由其名称确定。名称相同的通道会相互干扰通信。

Flutter 框架提供的所有 BasicMessageChannel 都保证先进先出（FIFO）顺序。应用可以认为，通过内置 BasicMessageChannel 发送的消息会按发送顺序传递。

参见：flutter.dev/to/platform-channels/
