physicalKey 属性

  1. @重写
PhysicalKeyboardKey get physicalKey
重写

返回一个对象，表示此按键在 QWERTY 键盘上的物理位置。

PhysicalKeyboardKey 不考虑按键映射、修饰键（例如 SHIFT）以及按键上的标签。无论当前使用何种键盘映射，它都将按 QWERTY 键盘描述按键位置。

PhysicalKeyboardKey 用于描述和检测特定位置上的按键。

例如，如果你想制作一款游戏，让 CAPS LOCK 右侧的按键控制玩家向左移动，就可以将此 physicalKey 的结果与 PhysicalKeyboardKey.keyA 比较，因为在 QWERTY 键盘上它是 CAPS LOCK 旁边的按键。即使在法语键盘上，CAPS LOCK 旁的按键按下后会产生“Q”，比较结果也相同。

如果希望应用无论按键位置如何，都能响应具有特定字符的按键，请改用 RawKeyEvent.logicalKey。

另请参阅：

  • logicalKey for the non-location-specific key generated by this event.
  • RawKeyEvent.physicalKey, where this value is available on the event.

实现

@override
PhysicalKeyboardKey get physicalKey {
  return kWebToPhysicalKey[code] ??
      PhysicalKeyboardKey(LogicalKeyboardKey.webPlane + code.hashCode);
}
