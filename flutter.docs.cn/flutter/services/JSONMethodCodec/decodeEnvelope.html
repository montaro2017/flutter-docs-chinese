从二进制数据解码指定的结果 envelope。

如果 envelope 表示错误，则抛出 PlatformException；否则返回信封中封装的结果。

decodeEnvelope 返回的类型是 dynamic（而不是 Object?），这意味着不会对其返回值执行类型检查。强烈建议立即将返回值转换为已知类型，以避免因拼写错误引发运行时错误；这类错误原本可以由类型检查器捕获。

实现

@override
dynamic decodeEnvelope(ByteData envelope) {
  final Object? decoded = const JSONMessageCodec().decodeMessage(envelope);
  if (decoded is! List) {
    throw FormatException('Expected envelope List, got $decoded');
  }
  if (decoded.length == 1) {
    return decoded[0];
  }
  if (decoded.length == 3 &&
      decoded[0] is String &&
      (decoded[1] == null || decoded[1] is String)) {
    throw PlatformException(
      code: decoded[0] as String,
      message: decoded[1] as String?,
      details: decoded[2],
    );
  }
  if (decoded.length == 4 &&
      decoded[0] is String &&
      (decoded[1] == null || decoded[1] is String) &&
      (decoded[3] == null || decoded[3] is String)) {
    throw PlatformException(
      code: decoded[0] as String,
      message: decoded[1] as String?,
      details: decoded[2],
      stacktrace: decoded[3] as String?,
    );
  }
  throw FormatException('Invalid envelope: $decoded');
}
