RawKeyEventDataWindows 类

Windows 平台特定的按键事件数据。

此类已弃用，并将被移除。将不再提供平台特定的按键事件数据。请参阅 KeyEvent 了解可用信息。

此对象包含从 Windows 的 Win32 API 获取的按键事件信息。

另请参阅：

  • RawKeyboard，使用此接口公开按键数据。
