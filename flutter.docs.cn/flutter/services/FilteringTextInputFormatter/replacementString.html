replacementString 属性

String replacementString
final

用于替换禁止模式的字符串。

对于拒绝列表（allow 为 false），filterPattern 的每个匹配项都会被此字符串替换。如果 filterPattern 一次可匹配多个字符，那么多个字符可能会被此 replacementString 的一个实例替换。

对于允许列表（allow 为 true），filterPattern 各匹配项之间的字符序列会整体替换，无论其中包含多少字符。

例如，假设 filterPattern 仅由字母“o”组成，将其应用于初始值为“Into The Woods”的文本字段，并将 replacementString 设为 *。

如果 allow 为 true，结果将是“ooo*”。每段不匹配模式的字符序列都会被单独替换为一个替换字符串，无论该序列包含多少字符。

如果 allow 为 false，结果将是“Int* the W**ds”。每段匹配序列都会被替换，并且每个“o”都会单独匹配该模式。

如果模式为 RegExp o+，当 allow 为 true 时结果相同；当 allow 为 false 时，结果则为“Int* the W*ds”（两个“o”被同一个替换字符串替换），因为模式会同时匹配两个“o”。

文本替换后，过滤器可能会调整文本的选区和 composing 区域，使它们仍覆盖相同文本。例如，若模式为 o+，且最后一个字符“s”被选中：“Into The Wood|s|”，结果将是“Into The W*d|s|”；即使“s”现在是第 12 个字符，选区仍会选中它。

如果选区（或 composing 区域）的一个端点严格位于禁止模式内部（例如“Into The |Wo|ods”），该端点将移动到替换字符串末尾。如果模式为 o+，原文本和选区为“Into The |Wo|ods”，结果将变为“Into The |W*|ds”。
