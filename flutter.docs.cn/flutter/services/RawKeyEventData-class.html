RawKeyEventData
description

RawKeyEventData 类 抽象

平台特定键盘事件数据的基类。

此类已弃用，之后将被移除。届时将不再提供平台特定的键盘事件数据。有关可用功能，请参阅 KeyEvent。

此基类为各目标平台的键盘事件数据结构提供共同类型。

另请参阅：

  • RawKeyEventDataAndroid, a specialization for Android.
  • RawKeyEventDataFuchsia, a specialization for Fuchsia.
  • RawKeyDownEvent 和 RawKeyUpEvent, the classes that hold the reference to RawKeyEventData 的子类配合使用。
  • RawKeyboard, which uses these interfaces to expose key data.
