TextInputType const webSearch

针对网页搜索进行优化。

请求使用包含便于网页搜索和输入 URL 的按键的键盘。

在 iOS 上，请求使用便于输入 “.” 的默认键盘。与 url 不同，此键盘提供空格键。

在 Android 上，此类型会映射为 url 键盘类型，因为该键盘始终显示空格键。

实现

static const TextInputType webSearch = TextInputType._(11);
