void flushData()

手动将恢复数据刷新到引擎。

恢复数据发生变化时通常也会安排一帧（因为数据通常在 State.setState 调用中修改，并且通常会影响界面）。恢复数据会在每帧结束时自动刷新到引擎，因此通常无需直接调用此方法。不过，如果修改恢复数据时没有触发新帧，就必须调用此方法，以确保及时将更新后的数据发送到引擎。例如，Scrollable 的滚动活动结束时，最终滚动偏移量会在两帧之间确定，且不会安排新帧。

如果已经安排了一帧，调用此方法不会产生任何操作；恢复数据会在该帧结束时刷新到引擎。如果调用此方法时没有安排帧，则会直接将当前恢复数据发送到引擎。

实现

void flushData() {
  assert(!_debugDoingUpdate);
  if (SchedulerBinding.instance.hasScheduledFrame) {
    return;
  }
  _doSerialization();
  assert(!_serializationScheduled);
}
