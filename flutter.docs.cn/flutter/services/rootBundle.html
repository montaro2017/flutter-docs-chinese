rootBundle
description

rootBundle top-level property

AssetBundle rootBundle
final

加载此应用时使用的 AssetBundle。

rootBundle 包含应用构建时打包的资源。若要将资源添加到应用的 rootBundle，请将它们加入应用 pubspec.yaml 清单中 flutter 部分下的 assets 子项。

例如：

name: my_awesome_application
flutter:
  assets:
   - images/hamilton.jpeg
   - images/lafayette.jpeg

建议不要直接使用 rootBundle，而是使用 DefaultAssetBundle.of，通过当前 BuildContext 获取 AssetBundle。这一间接层允许祖先 widget 在运行时替换不同的 AssetBundle（例如用于测试或本地化），而不是直接依赖构建时创建的 rootBundle。为方便使用，widget 层级顶部的 WidgetsApp 或 MaterialApp 会将 DefaultAssetBundle 配置为 rootBundle。

另请参阅：

  • DefaultAssetBundle
  • NetworkAssetBundle

实现

final AssetBundle rootBundle = _initRootBundle();
