AutofillHints
description

AutofillHints 类 抽象 final

不同平台上常用的自动填充提示字符串集合。

每种提示都至少在一个受支持的平台上预定义。请查阅相关文档，了解各平台对这些提示的支持情况，以及每种提示对应的平台取值。
