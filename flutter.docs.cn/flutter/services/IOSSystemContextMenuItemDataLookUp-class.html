IOSSystemContextMenuItemDataLookUp
description

IOSSystemContextMenuItemDataLookUp 类 final

用于系统内置“查询”按钮的 IOSSystemContextMenuItemData。

必须指定 title，通常使用 WidgetsLocalizations.lookUpButtonLabel。

操作由平台处理。

另请参阅：

  • SystemContextMenuController，用于显示系统上下文菜单。
  • IOSSystemContextMenuItemLookUp, which performs a similar role but at the widget level, where the title can be replaced with a default localized value.
