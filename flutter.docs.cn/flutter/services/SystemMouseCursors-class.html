SystemMouseCursors
description

SystemMouseCursors 类 抽象 final

一组系统 MouseCursor。

系统光标是当前平台提供的标准鼠标光标，无需外部资源。

SystemMouseCursors 是 Flutter 所支持各个平台系统光标集合的超集，因此其中某些对象可能映射到相同的结果，或回退到 basic 箭头。映射关系由 Flutter 引擎定义。

光标名称应根据其用途命名，而非外观，因为不同平台可能会（虽然并不常见）为同一种用途使用不同形状的光标。
