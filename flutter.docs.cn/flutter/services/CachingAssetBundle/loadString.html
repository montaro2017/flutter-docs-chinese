重写

从资源包中获取字符串。

如果未找到资源，则抛出异常。

如果 cache 参数设为 false，则数据不会被缓存，读取时也可能绕过缓存。如果调用方计划自行缓存数据，这会很有用。（即使设为 true，根据资源包实现方式，数据也可能不会被缓存。）

存储的字符串必须采用 UTF-8 编码，因为解码时会使用 Utf8Codec。如果字符串超过 50 KB，解码过程会交由隔离区执行，以避免主线程卡顿。

实现

@override
Future<String> loadString(String key, {bool cache = true}) {
  if (cache) {
    return _stringCache.putIfAbsent(key, () => super.loadString(key));
  }
  return super.loadString(key);
}
