HardwareKeyboard 类

管理来自硬件键盘的按键事件。

HardwareKeyboard 管理 Flutter 应用中来自硬件键盘（而非屏幕键盘）的所有按键事件。它从原生平台接收按键数据，将按键事件分发给已注册的处理器，并记录键盘状态。

若要在按键按下、保持或释放时收到通知，请使用 addHandler 添加处理器。若只需在应用的特定区域获得焦点时收到通知，可使用 Focus 组件的 onFocusChanged 属性，而不是 addHandler。不再需要通知或处理器即将释放时，应使用 removeHandler 移除处理器。

若要查询某个按键是否处于按住状态，或某种锁定模式是否启用，请使用 physicalKeysPressed、logicalKeysPressed 或 lockModesEnabled。在按键事件处理器中使用这些状态时，它们已根据当前事件更新。

单例 HardwareKeyboard 实例由 ServicesBinding 持有，作为 ServicesBinding.keyboard 提供，也可以通过静态访问器 HardwareKeyboard.instance 方便地访问。

事件模型

无论原生平台为何，Flutter 都使用统一的事件模型（KeyEvent）和按键选项（LogicalKeyboardKey 与 PhysicalKeyboardKey），同时尽可能保留平台特有功能。

HardwareKeyboard 保证按键模型经过“规范化”：按键事件流由一系列“按键点击序列”组成。每个序列依次包含一个 KeyDownEvent、零个或多个 KeyRepeatEvent，以及一个 KeyUpEvent，且它们具有相同的物理键和逻辑键。

示例：

  • Tap and hold key A, US layout:
    • KeyDownEvent(physicalKey: keyA, logicalKey: keyA, character: "a")
    • KeyRepeatEvent(physicalKey: keyA, logicalKey: keyA, character: "a")
    • KeyUpEvent(physicalKey: keyA, logicalKey: keyA)
  • Press ShiftLeft, tap key A, then release ShiftLeft, US layout:
    • KeyDownEvent(physicalKey: shiftLeft, logicalKey: shiftLeft)
    • KeyDownEvent(physicalKey: keyA, logicalKey: keyA, character: "A")
    • KeyRepeatEvent(physicalKey: keyA, logicalKey: keyA, character: "A")
    • KeyUpEvent(physicalKey: keyA, logicalKey: keyA)
    • KeyUpEvent(physicalKey: shiftLeft, logicalKey: shiftLeft)
  • Tap key Q, French layout:
    • KeyDownEvent(physicalKey: keyA, logicalKey: keyQ, character: "q")
    • KeyUpEvent(physicalKey: keyA, logicalKey: keyQ)
  • Tap CapsLock:
    • KeyDownEvent(physicalKey: capsLock, logicalKey: capsLock)
    • KeyUpEvent(physicalKey: capsLock, logicalKey: capsLock)

Flutter 应用启动时，所有按键均处于释放状态，所有锁定模式均已停用。收到按键事件时，HardwareKeyboard 会先更新状态，再分发回调：KeyDownEvent 和 KeyUpEvent 会设置或重置按下状态，而 KeyDownEvent 还会切换锁定模式。

Flutter 会在平台允许的情况下，通过合成事件（KeyEvent.synthesized）尝试与键盘的实际状态同步。初始状态非空，或焦点窗口/应用发生变化，都可能造成不同步。例如，应用启动时若 CapsLock 已启用，则在第一个按键事件到达前，会合成并分发 CapsLock 的 KeyDownEvent 和 KeyUpEvent。

最终生成的事件流与原生按键事件流并非一一对应。有些原生事件可能被跳过，有些事件则可能是合成的，并不对应任何原生事件。合成事件会通过 KeyEvent.synthesized 标记。

示例：

  • Flutter starts with CapsLock on, the first press of keyA:
    • KeyDownEvent(physicalKey: capsLock, logicalKey: capsLock, synthesized: true)
    • KeyUpEvent(physicalKey: capsLock, logicalKey: capsLock, synthesized: true)
    • KeyDownEvent(physicalKey: keyA, logicalKey: keyA, character: "a")
  • While holding ShiftLeft, lose window focus, release shiftLeft, then focus back and press keyA:
    • KeyUpEvent(physicalKey: shiftLeft, logicalKey: shiftLeft, synthesized: true)
    • KeyDownEvent(physicalKey: keyA, logicalKey: keyA, character: "a")

Flutter 不区分多个键盘。它会将所有事件都视为来自同一个键盘，尝试解决冲突并生成规范化的按键事件流，因此该事件流可能与实际键盘状态不完全一致。

另请参阅：

  • KeyDownEvent, KeyRepeatEvent, and KeyUpEvent, the classes used to describe specific key events.
  • instance, the singleton instance of this class.
