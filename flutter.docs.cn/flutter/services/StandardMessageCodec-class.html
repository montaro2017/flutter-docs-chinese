StandardMessageCodec 类

使用 Flutter 标准二进制编码的 MessageCodec。

支持的消息必须是以下形式的无环值：

  • null
  • bool 值
  • num 值
  • String
  • Uint8List、Int32List、Int64List、Float64List
  • 由受支持的值组成的 List
  • 从受支持的值映射到受支持值的 Map

无论内容是什么，解码后的值都会使用 List<Object?> 和 Map<Object?, Object?>。

decodeMessage 返回的类型是 dynamic（而不是 Object?），这意味着不会对其返回值执行类型检查。强烈建议立即将返回值转换为已知类型，以避免拼写错误导致的运行时错误；这类错误原本可以由类型检查器捕获。

子类可以重写 writeValue 和 readValueOfType，以扩展此编解码器。

Android 特定说明

在 Android 上，消息按以下方式表示：

  • null：null
  • bool：java.lang.Boolean
  • int：对于可用 32 位二进制补码表示的值，使用 java.lang.Integer；否则使用 java.lang.Long
  • double：java.lang.Double
  • String：java.lang.String
  • Uint8List：byte[]
  • Int32List：int[]
  • Int64List：long[]
  • Float64List：double[]
  • List：java.util.ArrayList
  • Map：java.util.HashMap

从 Java 发送 java.math.BigInteger 时，会将其转换为表示该整数十六进制形式的 String。（该值会标记为大整数；可以通过此类的子类原生支持它，参见 writeValue 中的讨论。）此编解码器不支持从 Dart 发送大整数。

iOS 特定说明

在 iOS 上，消息按以下方式表示：

  • null：nil
  • bool：NSNumber numberWithBool:
  • int：对于可用 32 位二进制补码表示的值，使用 NSNumber numberWithInt:；否则使用 NSNumber numberWithLong:
  • double：NSNumber numberWithDouble:
  • String：NSString
  • Uint8List、Int32List、Int64List、Float64List：FlutterStandardTypedData
  • List：NSArray
  • Map：NSDictionary
