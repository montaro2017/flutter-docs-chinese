selectMultiEntryHistory static 方法

Future<void> selectMultiEntryHistory()

选择多条目历史记录模式。

在 Web 上，此操作会将浏览器历史记录模式切换为跟踪 routeInformationUpdated 所有更新并将其组成历史记录栈的模式。这是默认模式。

目前在其他平台上会忽略此操作。

另请参阅：

  • selectSingleEntryHistory 会强制历史记录中仅保留一个条目。

实现

static Future<void> selectMultiEntryHistory() {
  return SystemChannels.navigation.invokeMethod<void>('selectMultiEntryHistory');
}
