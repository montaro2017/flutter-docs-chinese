AndroidMotionEvent 类

Android MotionEvent 的 Dart 版本。

当 Flutter 收到一个事件，并判定该事件应由平台视图而非其他 Flutter 组件处理时，AndroidViewController 会使用此类描述转发给该平台视图的指针事件。

另请参阅：

  • AndroidViewController.sendMotionEvent, which can be used to send an AndroidMotionEvent explicitly.
