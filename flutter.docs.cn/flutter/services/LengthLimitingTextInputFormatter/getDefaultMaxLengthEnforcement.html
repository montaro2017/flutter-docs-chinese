返回遵循指定 platform 惯例的 MaxLengthEnforcement。

特定平台的行为

不同平台默认遵循各自的原生行为。

  • Android、Windows：使用 MaxLengthEnforcement.enforced，遵循这些平台的原生行为。输入中日韩字符时，组合输入内容由 IME 处理。
  • iOS：MaxLengthEnforcement.truncateAfterCompositionEnds。iOS 没有默认行为，需要用户自行实现。为避免影响中日韩文字输入，应允许组合输入内容暂时超出限制。
  • Web、macOS、Linux、Fuchsia：MaxLengthEnforcement.truncateAfterCompositionEnds。这些平台默认允许组合输入内容超出限制。

实现

static MaxLengthEnforcement getDefaultMaxLengthEnforcement([TargetPlatform? platform]) {
  if (kIsWeb) {
    return MaxLengthEnforcement.truncateAfterCompositionEnds;
  } else {
    switch (platform ?? defaultTargetPlatform) {
      case TargetPlatform.android:
      case TargetPlatform.windows:
        return MaxLengthEnforcement.enforced;
      case TargetPlatform.iOS:
      case TargetPlatform.macOS:
      case TargetPlatform.linux:
      case TargetPlatform.fuchsia:
        return MaxLengthEnforcement.truncateAfterCompositionEnds;
    }
  }
}
