physicalKey 属性

PhysicalKeyboardKey physicalKey
final

返回表示此按键物理位置的对象。

PhysicalKeyboardKey 表示键盘发送的 USB HID 代码，不考虑键盘映射、修饰键（例如 SHIFT）和按键上的标签。

PhysicalKeyboardKey 用于描述和检测特定位置上的按键。它可能有名称，但名称只是便于记忆的助记符（例如 keyA 比 0x70004 更容易记住），名称来源于该键在 QWERTY 键盘上的效果，并不代表按键的实际字符（例如 AZERTY 键盘上的物理 keyA 可能对应 Q 键）。

例如，如果你想制作一款游戏，让 CAPS LOCK 键右侧的按键控制玩家向左移动，就应将物理键与 PhysicalKeyboardKey.keyA 比较，因为它在 QWERTY 键盘上位于 CAPS LOCK 右侧。即使使用 AZERTY 键盘，CAPS LOCK 右侧按下时会产生“Q”，比较结果也相同。

如果希望应用根据按键上的特定字符作出响应，而不受按键位置影响，请改用 KeyEvent.logicalKey。

另外，尽管物理键使用 USB HID 代码定义，其值也不一定与硬件生成并传递给驱动程序的 HID 代码相同。在大多数平台上，Flutter 必须将平台表示形式映射回 HID 代码，因为平台不会提供原始 HID 代码。选择 USB HID 是因为它是定义完善的标准，可用于标识 Flutter 应用可能遇到的按键。

另请参阅：

  • logicalKey for the non-location specific key generated by this event.
  • character for the character generated by this keypress (if any).
