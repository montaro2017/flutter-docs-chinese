uncontrolled constant

MouseCursor const uncontrolled

一种特殊值，本身不会更改光标，但会阻止其后方的其他区域更改光标。

当指针进入光标为 uncontrolled 的区域时，会保留先前的光标，直到指针移出该区域。具体而言，该区域会吸收鼠标光标命中测试，但不会更改指针光标。

当区域显示平台视图，并希望由操作系统处理指针事件并相应更改光标时，这一设置很有用。为此，该区域的光标不能是任何 Flutter 光标，否则指针进入区域时可能覆盖系统的请求；光标也不能为 null，否则区域后方的组件仍可更改光标。

实现

static const MouseCursor uncontrolled = _NoopMouseCursor._();
