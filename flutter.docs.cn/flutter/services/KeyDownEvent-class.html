KeyDownEvent 类

表示用户在键盘上按下按键的事件。

另请参阅：

  • KeyRepeatEvent, a key event representing the user holding a key, causing repeated events.
  • KeyUpEvent, a key event representing the user releasing a key.
  • HardwareKeyboard, which produces this event.
