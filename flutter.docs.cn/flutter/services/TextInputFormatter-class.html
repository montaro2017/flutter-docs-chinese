TextInputFormatter 类 抽象

可以选择将 TextInputFormatter 注入 EditableText，以便在编辑文本时实时验证和格式化内容。

只有在输入法编辑器 (IME) 提交文本时才应应用文本修改，不应修改仍处于组合状态的文本（即仅在 TextEditingValue.composing 折叠时修改）。

另请参阅 FilteringTextInputFormatter。它是一个子类，可按给定模式移除用户输入的匹配或不匹配字符。

要创建自定义格式化器，请扩展 TextInputFormatter 类并实现 formatEditUpdate 方法。

处理表情符号和其他复杂字符

处理可能包含复杂字符的用户输入时，务必使用 characters。这样可以确保扩展字素簇和代理对按用户所见作为单个字符处理。

例如，计算用户输入长度时应使用 string.characters.length。不要使用 string.length，也不要使用 string.runes.length。复杂字符 “👨‍👩‍👦” 对用户来说是一个字符，string.characters.length 会直观地返回 1；而 string.length 返回 8，string.runes.length 返回 5！

另请参阅：

  • EditableText on which the formatting apply.
  • FilteringTextInputFormatter, a provided formatter for filtering characters.
