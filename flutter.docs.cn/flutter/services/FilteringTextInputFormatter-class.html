FilteringTextInputFormatter 类

一种 TextInputFormatter，会将匹配（或不匹配）特定模式的字符替换为给定的 replacementString，从而阻止这些字符被插入。

在新的 TextEditingValue 中找到的过滤字符会被替换为 replacementString（默认为空字符串）；当前的 TextEditingValue.selection 和 TextEditingValue.composing 区域也会相应调整。

此格式化器通常用于匹配新 TextEditingValue 中可能重复出现的 Pattern。它不会完全拒绝新的 TextEditingValue；如果给定的 filterPattern 未匹配，则回退到当前的 TextEditingValue。以下情况可考虑使用其他 TextInputFormatter：

// _pattern is a RegExp or other Pattern object
TextInputFormatter.withFunction(
  (TextEditingValue oldValue, TextEditingValue newValue) {
    return _pattern.hasMatch(newValue.text) ? newValue : oldValue;
  },
),

如果要根据整个字符串是否满足某个条件来接受或拒绝新输入，请使用其他格式化器。例如，FilteringTextInputFormatter 通常不应与包含位置匹配符（^ 或 $）的 RegExp 搭配使用，因为这类模式通常用于匹配整个字符串。

iOS 上的引号字符

过滤单引号（'）或双引号（"）时，请注意，iOS 默认键盘实际插入的是方向性特殊字符（单引号为 ‘ 和 ’，双引号为 “ 和 ”）。为了兼容 iOS，建议在正则表达式中包含这三种变体。
