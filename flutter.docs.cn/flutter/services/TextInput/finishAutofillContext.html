结束当前自动填充上下文；如果 shouldSave 为 true，还可能保存用户输入供以后使用。

通常应在用户完成输入时调用此方法。例如，在 Form 中，通常会在提交表单内容前或后立即调用。

最外层的 AutofillGroup 在释放时也会自动调用 finishAutofillContext。可以通过 AutofillGroup.onDisposeAction 覆盖默认行为。

自动填充上下文是平台文本输入插件中的一组输入字段。调用 TextInput.finishAutofillContext 且将 shouldSave 设为 true 时，建议平台在上下文销毁前保存当前上下文中存储的用户输入。

目前，同一时间最多只能有一个自动填充上下文。当 AutofillGroup 中的任一输入字段请求自动填充时（可自动填充的 EditableText 获得焦点时会自动请求），当前自动填充上下文会合并该 AutofillGroup 的内容。如果当前没有自动填充上下文，则会创建一个上下文来保存该组中新加入的输入字段。

输入字段加入自动填充上下文后，会一直留在其中，直到该上下文被销毁。为防止资源泄漏，请调用 TextInput.finishAutofillContext，通知文本输入插件用户已完成当前上下文中的输入。平台文本输入插件会根据 shouldSave 参数，允许或阻止平台保存用户输入。平台通常会显示“保存以供自动填充？”提示，请用户确认。

在许多平台上，调用 finishAutofillContext 会显示保存用户输入的对话框并打断用户操作流程。理想情况下，每个屏幕最多只显示一次此对话框。可以移除过早调用的 finishAutofillContext，避免保存输入界面出现得过于频繁。不过，如果当前不存在自动填充上下文，调用 finishAutofillContext 通常不会显示保存用户输入的界面。

另请参阅：

  • EditableText.autofillHints for autofill save troubleshooting tips.
  • AutofillGroup.onDisposeAction, a configurable action that runs when a topmost AutofillGroup is getting disposed.

实现

static void finishAutofillContext({bool shouldSave = true}) {
  for (final TextInputControl control in TextInput._instance._inputControls) {
    control.finishAutofillContext(shouldSave: shouldSave);
  }
}
