TextInputControl mixin

用于实现文本输入控件的接口。此类控件会接收文本编辑状态变更和可视输入控件请求。

当已连接文本输入客户端的编辑状态发生变化，或客户端请求显示、隐藏输入控件等操作时，框架会发送编辑状态变更和输入控件请求。

可以使用 TextInput.setInputControl 安装输入控件，也可以使用 TextInput.restorePlatformInputControl 恢复默认的平台文本输入控件。

必须扩展 TextInputControl 类。TextInputControl 的实现应调用 TextInput.updateEditingValue，将用户输入发送给已连接的输入客户端。

此示例展示了 TextInputControl 的基本实现。

要使用此代码示例创建本地项目，请运行：
flutter create --sample=services.TextInputControl.1 mysample

另请参阅：

  • TextInput.setInputControl, a method to install a custom text input control.
  • TextInput.restorePlatformInputControl, a method to restore the default platform text input control.
  • TextInput.updateEditingValue, a method to send user input to the framework.
