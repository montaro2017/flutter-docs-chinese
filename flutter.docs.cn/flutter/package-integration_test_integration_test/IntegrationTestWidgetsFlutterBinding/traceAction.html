traceAction 方法

Future<void> traceAction(
  1. Future action(), {
  2. List<String> streams = const <String>['all'],
  3. bool retainPriorEvents = false,
  4. String reportKey = 'timeline',
})

这是一个便捷方法：它会调用 traceTimeline，并将结果返回主机，供 flutter_driver 风格的测试使用。

此方法会记录 action 期间的时间线，并以 reportKey 为键将结果添加到 reportData。reportData 包含测试成功或失败之外的其他信息，会传回主机并由 ResponseDataCallback 处理，该回调在 integrationDriver 中定义。默认情况下，数据会写入 build/integration_response_data.json，键名为 timeline。

如果在一个测试中多次调用此方法，reportKey 必须唯一，否则后续结果会覆盖先前结果。多次调用此方法的测试还必须提供自定义 ResponseDataCallback，以决定时间线输出的写入位置和方式。例如：

import 'package:integration_test/integration_test_driver.dart';

Future<void> main() {
  return integrationDriver(
    responseDataCallback: (Map<String, dynamic>? data) async {
      if (data != null) {
        for (final MapEntry<String, dynamic> entry in data.entries) {
          print('Writing ${entry.key} to the disk.');
          await writeResponseData(
            entry.value as Map<String, dynamic>,
            testOutputFilename: entry.key,
          );
        }
      }
    },
  );
}

streams 和 retainPriorEvents 参数会原样传递给 traceTimeline。

实现

Future<void> traceAction(
  Future<dynamic> Function() action, {
  List<String> streams = const <String>['all'],
  bool retainPriorEvents = false,
  String reportKey = 'timeline',
}) async {
  final vm.Timeline timeline = await traceTimeline(
    action,
    streams: streams,
    retainPriorEvents: retainPriorEvents,
  );
  reportData ??= <String, dynamic>{};
  reportData![reportKey] = timeline.toJson();
}
