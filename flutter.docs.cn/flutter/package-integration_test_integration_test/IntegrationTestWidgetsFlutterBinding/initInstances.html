void initInstances()
重写

初始化方法。

子类重写此方法以接入平台并配置其服务。子类必须调用 super.initInstances()。

运行此方法时，binding 尚未完全初始化（例如，其他 binding mixin 可能尚未运行其 initInstances 方法）。因此，此方法中的代码应避免调用回调，或同步触发通常假定 binding 已就绪的代码。

按惯例，如果要将此服务作为单例提供，应公开为 MixinClassName.instance，即一个静态 getter；它返回不可为空的值 MixinClassName._instance，该静态字段由 initInstances() 设置。为改善开发者体验，实际返回值应为 BindingBase.checkInstance(_instance)（参见 checkInstance），如以下示例所示。
link 
mixin BazBinding on BindingBase {
  @override
  void initInstances() {
    super.initInstances();
    _instance = this;
    // ...binding initialization...
  }

  static BazBinding get instance => BindingBase.checkInstance(_instance);
  static BazBinding? _instance;

  // ...binding features...
}
