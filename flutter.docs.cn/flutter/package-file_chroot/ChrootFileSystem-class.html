ChrootFileSystem

ChrootFileSystem 类

通过路径提供对另一个 FileSystem 的访问视图的文件系统。

这与 Linux 操作系统中的 chroot 操作概念相似。经过这种修改的文件系统无法命名或访问指定目录树之外的文件。

Example use:

// Create a "file system" where the root directory is /tmp/some-dir.
var fs = ChrootFileSystem(existingFileSystem, '/tmp/some-dir');

使用注意事项：

  • 此文件系统维护自己的 currentDirectory，与底层文件系统的当前目录相互独立。新实例会自动从根目录（即 /）开始。

  • 此文件系统不会调用底层操作系统的系统调用（例如 chroot），因此开发者不应假设它提供了超出实际能力的安全环境。例如，可以通过 delegate 访问底层文件系统。这说明该文件系统只是为了方便使用而提供的抽象，并非安全措施。

  • 由于符号链接需要手动解析（而不是委托处理），此文件系统必然会产生一定的性能开销。
