Function

Function 类 抽象 final

一个函数值。

Function 类是所有函数类型的超类型，本身不包含任何值。所有实现 Function 的对象，其运行时类型都是函数类型。

Function 类型不包含函数的参数签名或返回类型信息。若要表达更精确的函数类型，请使用函数类型语法：关键字 Function 后接参数列表，或类型参数列表和参数列表，并且还可以指定可选的返回类型。

函数类型语法与函数定义类似，只是将函数名称替换为“Function”。

示例：

String numberToString(int n) => "$n";
String Function(int n) fun = numberToString; // Type annotation
assert(fun is String Function(int)); // Type check.
List<String Function(int)> functions = [fun]; // Type argument.

String Function(int) 是一种函数类型，表示该函数接受一个位置参数 int 并返回 String。

泛型函数类型示例：

T id<T>(T value) => value;
X Function<X>(X) anotherId = id; // Parameter name may be omitted.
int Function(int) intId = id<int>;

凡是允许使用类型的地方都可以使用函数类型；它也常用作接受其他函数（即“回调”）作为参数的函数的参数类型。

void doSomething(String Function(int) callback) {
  print(callback(1));
}

函数类型具有 Object 声明的所有成员，因为函数类型是 Object 的子类型。

函数类型还有一个 call 方法，其签名与函数类型本身相同。调用 call 方法的行为与直接调用函数相同。它主要用于有条件地调用可空函数值。

String Function(int) fun = (n) => "$n";
String Function(int) fun2 = fun.call; // Valid.
print(fun2.call(1)); // Prints "1".

String Function(int)? maybeFun = Random().nextBool() ? fun : null;
print(maybeFun?.call(1)); // Prints "1" or "null".

Function 类型有若干在此 class 声明中不可见的特殊特性。

Function 类型是所有函数类型的超类型，因此允许将任意函数赋给它，但它不会说明如何调用该函数。

不过，静态类型为 Function 的值仍然可以像函数一样调用。

Function f = (int x) => "$x";
print(f(1)); // Prints "1".

f("not", "one", "int"); // Throws! No static warning.

此类调用属于动态调用，效果与函数值的静态类型为 dynamic 时完全相同，也同样不安全。运行时会检查参数列表是否与函数参数匹配；如果不匹配，调用将以 Error 失败。此类调用不进行静态类型检查，任何参数列表都会被接受并在运行时检查。

每种函数类型都有一个类型为自身函数类型的 call 方法；Function 类型也有一个特殊的 call 成员，其行为如同一个函数类型为 Function 的方法（这种方法签名无法用普通 Dart 代码表达）。

Function fun = (int x) => "$x";

var fun2 = fun.call; // Inferred type of `fun2` is `Function`.

print(fun2.call(1)); // Prints "1";

Function? maybeFun = Random().nextBool() ? fun : null;
print(maybeFun?.call(1)); // Prints "1" or "null".
