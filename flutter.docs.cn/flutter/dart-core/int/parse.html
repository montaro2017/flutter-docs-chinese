重写
将 source 解析为可能带符号的整数字面量，并返回其值。

source 必须是非空的 radix 进制数字序列，可选地以负号或正号（“-”或“+”）开头。

radix 必须在 2..36 范围内。使用的数字先是十进制数字 0..9，再是字母“a”..“z”，分别表示 10 到 35。也接受对应的小写字母的大写形式。

如果未指定 radix，则默认为 10。此时，source 中的数字也可以以 0x 开头，这时会将其解释为十六进制整数字面量。当 int 由 64 位有符号整数实现时，十六进制整数字面量可以表示大于 263 的值；此时会将其视为无符号数来解析，所得值为对应的有符号整数值。

对于任意整数 n 和有效基数 r，都保证 n == int.parse(n.toRadixString(r), radix: r)。

如果 source 字符串不是有效的整数字面量（可选地带有正负号前缀），则会抛出 FormatException。

若要避免抛出后立即捕获 FormatException，可以改用 tryParse 处理潜在的解析错误。

示例：

var value = int.tryParse(text);
if (value == null) {
  // handle the problem
  // ...
}
