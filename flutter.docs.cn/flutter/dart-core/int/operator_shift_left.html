int operator <<(
  1. int shiftAmount
)

将此整数的位向左移动 shiftAmount 位。

左移会增大数值，效果相当于将该数乘以 pow(2, shiftAmount)。

结果大小没有限制。必要时，可以使用适当的掩码与运算来限制中间值。

如果 shiftAmount 为负数，则会报错。

示例：

print((3 << 1).toRadixString(2)); // 0011 -> 0110
print((9 << 2).toRadixString(2)); // 1001 -> 100100
print((10 << 3).toRadixString(2)); // 1010 -> 1010000
