测试另一个对象是否与此函数相等。

函数对象只与其他函数对象相等（即满足 object is Function 的对象），永远不会与非函数对象相等。

某些函数对象因被识别为表示“同一个函数”，所以会通过 == 判断为相等：

  • 它们是同一个对象。静态函数和顶层函数作为值使用时是编译时常量，因此多次引用同一函数始终会得到同一个对象；在声明局部函数的同一作用域内多次引用该函数声明，也会得到同一个对象。

    void main() {
  assert(identical(print, print));
  int add(int x, int y) => x + y;
  assert(identical(add, add));
}

  • 这些函数是从同一个对象提取出的同一个成员方法。多次从同一对象提取（“tear off”）其实例方法并将其转换为函数值，会得到相等但不一定标识相同的函数值。

    var o = Object();
assert(o.toString == o.toString);

  • 相同泛型函数使用相同类型实例化后，会得到相等的结果。

    T id<T>(T value) => value;
assert(id<int> == id<int>);

    （如果该函数是常量且类型参数在编译时已知，结果也可能具有相同标识。）

不同次求值产生的函数字面量，不保证也不要求得到标识相同或相等的函数对象。例如：

var functions = <Function>[];
for (var i = 0; i < 2; i++) {
  functions.add((x) => x);
}
print(identical(functions[0], functions[1])); // 'true' or 'false'
print(functions[0] == functions[1]); // 'true' or 'false'

如果这些不同的值具有相同标识，它们始终相等。

如果函数值相等，则保证它们对所有参数的行为都无法区分。

如果两个函数的行为不同，它们就永远不会相等或具有相同标识。

不要求函数表达式的值具有特定的相等性或对象标识，是为了允许编译器进行优化。如果函数表达式不依赖周围变量，实现可以安全地在多次求值之间共享。例如：

List<int> ints = [6, 2, 5, 1, 4, 3];
ints.sort((x, y) => x - y);
print(ints);

编译器可以将闭包 (x, y) => x - y 转换为顶层函数。
