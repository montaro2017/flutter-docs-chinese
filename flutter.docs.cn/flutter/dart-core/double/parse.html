double parse(
  1. String source
)
重写
将 source 解析为 double 字面量并返回其值。

可选的正负号（+ 或 -）后面可以是字符串 "Infinity"、字符串 "NaN" 或浮点数表示形式。浮点数由尾数和可选的指数部分组成。尾数可以是小数点 . 后跟一串（十进制）数字，也可以是一串数字，可选地后接小数点和更多数字。指数部分（可选）由字符 "e" 或 "E"、可选的正负号以及一位或多位数字组成。source 不能为 null。

会忽略开头和末尾的空白字符。

如果 source 字符串不是有效的 double 字面量，则抛出 FormatException。

若要避免抛出后立即捕获 FormatException，可以改用 tryParse 处理潜在的解析错误。

以下是可接受字符串的示例：

"3.14"
"  3.14 \xA0"
"0."
".0"
"-1.e3"
"1234E+7"
"+.12e-9"
"-NaN"

实现
