dart:core

dart:core 库

Dart 程序通用的内置类型、集合及其他核心功能。

此库会自动导入。

此库中的一些类（如 String 和 num）支持 Dart 的内置数据类型。其他类（如 List 和 Map）提供用于管理对象集合的数据结构。还有一些类表示常用数据类型，例如 URI、日期和时间以及错误。

数字和布尔值

int 和 double 分别支持 Dart 的内置数值类型：整数和双精度浮点数。bool 类型的对象只有 true 或 false 两种值。这些类型的变量可以通过字面量创建：

int meaningOfLife = 42;
double valueOfPi  = 3.141592;
bool visible      = true;

字符串和正则表达式

String 是不可变的，表示一系列字符。

String shakespeareQuote = "All the world's a stage, ...";

StringBuffer 提供了一种高效构建字符串的方式。

var moreShakespeare = StringBuffer();
moreShakespeare.write('And all the men and women ');
moreShakespeare.write('merely players; ...');

String 和 StringBuffer 类支持字符串拆分、拼接及其他字符串处理功能。

bool isPalindrome(String text) => text == text.split('').reversed.join();

RegExp 实现了 Dart 正则表达式，用于定义在文本中匹配模式的语法。例如，下面的正则表达式可以匹配包含一个或多个数字的子字符串：

var numbers = RegExp(r'\d+');

Dart 正则表达式与 JavaScript 正则表达式具有相同的语法和语义。JavaScript 正则表达式规范见 ecma-international.org/ecma-262/5.1/#sec-15.10。

集合

dart:core 库提供了基本集合，例如 List、Map 和 Set。

List 是具有长度的有序对象集合，有时也称为数组。如果需要通过索引访问对象，请使用 List。

var superheroes = ['Batman', 'Superman', 'Harry Potter'];

Set 是无序的唯一对象集合。无法通过索引（位置）高效获取其中的元素。向集合中添加已有元素不会产生任何效果。

var villains = {'Joker'};
print(villains.length); // 1
villains.addAll(['Joker', 'Lex Luthor', 'Voldemort']);
print(villains.length); // 3

Map 是无序的键值对集合，每个键只能出现一次。Map 有时也称为关联数组，因为它将键关联到某个值，以便轻松检索。如果需要通过唯一标识符访问对象，请使用 Map。

var sidekicks = {'Batman': 'Robin',
                 'Superman': 'Lois Lane',
                 'Harry Potter': 'Ron and Hermione'};

除了这些类，dart:core 还包含 Iterable 接口，它定义了对象集合共有的功能，例如对集合中的每个元素运行函数、逐个测试元素、检索对象以及确定元素数量。

Iterable 由 List 和 Set 实现，Map 则使用它来表示键和值。

关于其他类型的集合，请参阅 dart:collection 库。

日期和时间

使用 DateTime 表示一个时间点，使用 Duration 表示一段时间。

可以通过构造函数或解析格式正确的字符串来创建 DateTime 对象。

var now = DateTime.now();
var berlinWallFell = DateTime(1989, 11, 9);
var moonLanding = DateTime.parse("1969-07-20");

通过指定各个时间单位来创建 Duration 对象。

var timeRemaining = const Duration(hours: 56, minutes: 14);

除了 DateTime 和 Duration，dart:core 还包含用于测量经过时间的 Stopwatch 类。

Uri

Uri 对象表示统一资源标识符，用于标识某项资源，例如 Web 上的资源。

var dartlang = Uri.parse('http://dartlang.org/');

错误

Error 类表示程序运行期间发生的错误。此类的子类表示特定类型的错误。

其他文档

有关如何使用内置类型的更多信息，请参阅 内置类型。

此外，还可以查看 dart:core 简介，了解此库中更多类型的信息。
