Object const 重写

用于覆盖接口成员的实例成员上的注解。

注解不会影响 Dart 程序的含义。Dart 分析器会识别此注解，并据此针对有效程序中可能存在的问题提供提示或警告。因此，此注解的含义由 Dart 分析器定义。

@override 注解表达了某个声明应该覆盖接口方法的意图，而单看该声明无法得知这一点。此信息使分析器能够在该意图未实现时发出警告，例如成员意图覆盖超类成员或实现接口成员，却未能做到。这可能是因为成员名称拼写错误，或超类重命名了该成员。

@override 注解适用于实例方法、实例 getter、实例 setter 和实例变量（字段）。应用于实例变量时，表示该变量的隐式 getter 和 setter（如果有）被标记为覆盖；它不会影响变量本身。

还可以使用更多 lint 规则，基于 @override 注解启用更多警告。
