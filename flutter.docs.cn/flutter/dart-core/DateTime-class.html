DateTime

DateTime 类

时间线上的一个时刻，例如 GMT 时间 1969 年 7 月 20 日晚上 8:18。

DateTime 可表示与纪元（UTC 时间 1970-01-01）相距最多 100,000,000 天的时间值，范围为 -271821-04-20 至 275760-09-13。

可以使用构造函数创建 DateTime 对象，也可以解析符合 ISO 8601 子集规范的格式正确的字符串。注意：小时采用 24 小时制，范围为 0 到 23。

例如：

final now = DateTime.now();
final berlinWallFell = DateTime.utc(1989, 11, 9);
final moonLanding = DateTime.parse('1969-07-20 20:18:04Z'); // 8:18pm

创建 DateTime 对象时，它会固定在 UTC 时区或当前计算机的本地时区。

创建后，DateTime 对象的值和时区都不能更改。

可以使用属性获取 DateTime 对象的各个时间单位。

print(berlinWallFell.year); // 1989
print(berlinWallFell.month); // 11
print(berlinWallFell.day); // 9
print(moonLanding.hour); // 20
print(moonLanding.minute); // 18

为方便使用并提高可读性，DateTime 类为每个 day 和 month 名称都提供了常量，例如 august 和 friday。使用这些常量可以让代码更易读：

final berlinWallFell = DateTime.utc(1989, DateTime.november, 9);
print(DateTime.november); // 11
assert(berlinWallFell.month == DateTime.november);
assert(berlinWallFell.weekday == DateTime.thursday);

Day 和 month 的值从 1 开始，一周从 Monday 开始。因此，january 和 monday 常量的值都是 1。

使用 UTC 和本地时间

除非明确使用 UTC 时区创建，否则 DateTime 对象使用本地时区。使用 isUtc 判断 DateTime 对象是否基于 UTC。

final dDay = DateTime.utc(1944, 6, 6);
print(dDay.isUtc); // true

final dDayLocal = DateTime(1944, 6, 6);
print(dDayLocal.isUtc); // false

使用 toLocal 和 toUtc 方法，可以获取转换到另一个时区后的等效日期和时间。

final localDay = dDay.toLocal(); // e.g. 1944-06-06 02:00:00.000
print(localDay.isUtc); // false

final utcFromLocal = localDay.toUtc(); // 1944-06-06 00:00:00.000Z
print(utcFromLocal.isUtc); // true

使用 timeZoneName 获取该 DateTime 对象所在时区的缩写名称。

print(dDay.timeZoneName); // UTC
print(localDay.timeZoneName); // e.g. EET

调用 timeZoneOffset，可以获取 UTC 与 DateTime 对象所在时区之间的时差。

print(dDay.timeZoneOffset); // 0:00:00.000000
print(localDay.timeZoneOffset); // e.g. 2:00:00.000000

比较 DateTime 对象

DateTime 类提供了按时间先后顺序比较 DateTime 对象的方法，例如 isAfter、isBefore 和 isAtSameMomentAs。

print(berlinWallFell.isAfter(moonLanding)); // true
print(berlinWallFell.isBefore(moonLanding)); // false
print(dDay.isAtSameMomentAs(localDay)); // true

将 DateTime 与 Duration 配合使用

可以将 add 和 subtract 方法与 Duration 对象配合使用，以另一个 DateTime 为基础创建新对象。例如，要查找从现在起 36 小时后的时刻，可以这样写：

final now = DateTime.now();
final later = now.add(const Duration(hours: 36));

要查明两个 DateTime 对象之间相隔多久，请使用 difference，它会返回一个 Duration 对象：

final difference = berlinWallFell.difference(moonLanding);
print(difference.inDays); // 7416

不同时区中的两个日期之间的差值只是两个时间点之间的纳秒数，不会考虑日历日数。这意味着，如果期间发生夏令时调整，本地时间的两个午夜之间的时长可能小于相隔天数乘以 24 小时。如果上面的差值使用澳大利亚本地时间计算，则为 7415 天零 23 小时，inDays 因而只会报告 7415 个完整天数。
