String toStringAsFixed(
  1. int fractionDigits
)
此数的定点字符串表示形式。

先将此数转换为 double，再计算字符串表示形式，与 toDouble 的行为相同。

如果 this 的绝对值大于或等于 10^21，此方法会返回由 this.toStringAsExponential() 生成的指数形式。否则返回最接近的字符串表示，并在小数点后保留恰好 fractionDigits 位。如果 fractionDigits 为 0，则省略小数点。

参数 fractionDigits 必须是满足 0 <= fractionDigits <= 20 的整数。

示例：

1.toStringAsFixed(3);  // 1.000
(4321.12345678).toStringAsFixed(3);  // 4321.123
(4321.12345678).toStringAsFixed(5);  // 4321.12346
123456789012345.toStringAsFixed(3);  // 123456789012345.000
10000000000000000.toStringAsFixed(4); // 10000000000000000.0000
5.25.toStringAsFixed(0); // 5
