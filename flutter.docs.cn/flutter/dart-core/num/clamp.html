num clamp(
  1. num lowerLimit,
  2. num upperLimit
)

将此 num 限制在 lowerLimit-upperLimit 范围内。

比较使用 compareTo，因此会考虑 -0.0。这也意味着 double.nan 会被视为最大的 double 值。

参数 lowerLimit 和 upperLimit 必须构成有效范围，即 lowerLimit.compareTo(upperLimit) <= 0。

示例：

var result = 10.5.clamp(5, 10.0); // 10.0
result = 0.75.clamp(5, 10.0); // 5
result = (-10).clamp(-5, 5.0); // -5
result = (-0.0).clamp(-5, 5.0); // -0.0
