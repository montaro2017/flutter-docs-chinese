Comparator<T> typedef

Comparator<T> = int Function(T a, T b)

通用比较函数的签名。

比较函数用于表示一组对象类型上的排序。类型上的全序意味着，对于任意两个值，它们要么相等，要么其中一个大于另一个（此时后者必须小于前者）。

Comparator 函数通过返回以下值来表示这种全序：

  • 如果 a 小于 b，则返回负整数；
  • 如果 a 等于 b，则返回零；
  • 如果 a 大于 b，则返回正整数。

实现

typedef Comparator<T> = int Function(T a, T b);
