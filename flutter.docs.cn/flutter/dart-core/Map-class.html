Map

Map<K, V> 类 抽象 interface

键值对集合，可通过每个键检索与之关联的值。

映射中的键数量有限，且每个键恰好关联一个值。

映射及其键和值都可以迭代。迭代顺序由映射的具体类型决定。例如：

  • The plain HashMap is unordered (no order is guaranteed),
  • the LinkedHashMap iterates in key insertion order,
  • and a sorted map like SplayTreeMap iterates the keys in sorted order.

通常不允许在映射操作执行期间修改映射（添加或移除键），例如在 forEach 调用期间执行的函数中修改。迭代键或值时修改映射也可能破坏迭代。

当键位于映射中时，通常不允许更改键的相等性（因此也不允许更改其哈希码）。某些专用子类型可能允许这样做，此时应记录相关行为。

键相等性必须是一种等价关系。如果存储在映射中的键与用于查找的键对二者是否相等的判断不一致，也就是相等性不具备对称性，则查找行为未定义。
