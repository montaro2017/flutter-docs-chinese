Stopwatch

Stopwatch 类

用于测量运行期间所经过时间的秒表。

秒表处于运行或停止状态。它测量秒表运行期间经过的时间。

秒表刚创建时处于停止状态，已测量的经过时间为零。

可以通过 elapsed、elapsedMilliseconds、elapsedMicroseconds 或 elapsedTicks 以不同格式获取经过的时间。

调用 start 可启动秒表。

示例：

final stopwatch = Stopwatch();
print(stopwatch.elapsedMilliseconds); // 0
print(stopwatch.isRunning); // false
stopwatch.start();
print(stopwatch.isRunning); // true

要停止或暂停秒表，请使用 stop。如果只是暂时暂停，请使用 start 继续计时。

stopwatch.stop();
print(stopwatch.isRunning); // false
Duration elapsed = stopwatch.elapsed;
await Future.delayed(const Duration(seconds: 1));
assert(stopwatch.elapsed == elapsed); // No measured time elapsed.
stopwatch.start(); // Continue measuring.

reset 方法会将经过时间重置为零。秒表运行或停止时都可以调用此方法，且不会改变秒表当前是否正在运行。

// Do some work.
stopwatch.stop();
print(stopwatch.elapsedMilliseconds); // Likely > 0.
stopwatch.reset();
print(stopwatch.elapsedMilliseconds); // 0
