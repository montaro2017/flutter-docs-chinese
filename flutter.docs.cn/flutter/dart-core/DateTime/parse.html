DateTime parse(
  1. String formattedString
)

根据 formattedString 构造一个新的 DateTime 实例。

如果无法解析输入字符串，则抛出 FormatException。

此函数解析 ISO 8601 的一个子集，其中包含 RFC 3339 接受的格式。

目前接受的输入格式如下：

  • 日期：带符号的四至六位年份、两位月份和两位日期，可选择用 - 分隔。示例："19700101"、"-0004-12-24"、"81030-04-01"。
  • 可选的时间部分，用 T 或空格与日期分隔。时间部分先是两位数的小时，然后可以依次包含两位数的分钟、两位数的秒，以及以“.”或“,”开头且至少包含一位数字的秒的小数部分。分钟和秒可以用“:”与前面的部分分隔。示例："12"、"12:30:24.124"、"12:30:24,124"、"123010.50"。
  • 可选的时区偏移部分，可以用空格与前一部分分隔。时区可以写作“z”或“Z”，也可以写成带符号的两位数小时，并可选地附加两位数分钟。符号必须是“+”或“-”，不能省略。小时和分钟之间可以用“:”分隔。示例：“Z”、“-10”、“+01:30”、“+1130”。

其中包括 toString 和 toIso8601String 的输出；解析后会得到一个时间与原值相同的 DateTime 对象。

结果始终使用本地时间或 UTC。如果指定了 UTC 以外的时区偏移量，则会将时间转换为对应的 UTC 时间。

可接受的字符串示例：

  • "2012-02-27"
  • "2012-02-27 13:27:00"
  • "2012-02-27 13:27:00.123456789z"
  • "2012-02-27 13:27:00,123456789z"
  • "20120227 13:27:00"
  • "20120227T132700"
  • "20120227"
  • "+20120227"
  • "2012-02-27T14Z"
  • "2012-02-27T14+00:00"
  • "-123450101 00:00:00 Z"：表示 -12345 年。
  • "2002-02-27T14:00:00-0500"：等同于 "2002-02-27T19:00:00Z"。

此方法接受超出范围的组成部分值，并将其解释为向更大时间单位进位。例如，“2020-01-42”会被解析为 2020-02-11，因为该月最后一个有效日期是 2020-01-31，因此第 42 天会解释为该月的 31 天加上次月的 11 天。

若要检测并拒绝无效的组成部分值，请使用 DateFormat.parseStrict，该方法来自 intl 软件包。

实现

static DateTime parse(String formattedString) {
  var re = _parseFormat;
  Match? match = re.firstMatch(formattedString);
  if (match != null) {
    int parseIntOrZero(String? matched) {
      if (matched == null) return 0;
      return int.parse(matched);
    }

    // Parses fractional second digits of '.(\d+)' into the combined
    // microseconds. We only use the first 6 digits because of DateTime
    // precision of 999 milliseconds and 999 microseconds.
    int parseMilliAndMicroseconds(String? matched) {
      if (matched == null) return 0;
      int length = matched.length;
      assert(length >= 1);
      int result = 0;
      for (int i = 0; i < 6; i++) {
        result *= 10;
        if (i < matched.length) {
          result += matched.codeUnitAt(i) ^ 0x30;
        }
      }
      return result;
    }

    int years = int.parse(match[1]!);
    int month = int.parse(match[2]!);
    int day = int.parse(match[3]!);
    int hour = parseIntOrZero(match[4]);
    int minute = parseIntOrZero(match[5]);
    int second = parseIntOrZero(match[6]);
    int milliAndMicroseconds = parseMilliAndMicroseconds(match[7]);
    int millisecond =
        milliAndMicroseconds ~/ Duration.microsecondsPerMillisecond;
    int microsecond = milliAndMicroseconds.remainder(
      Duration.microsecondsPerMillisecond,
    ) as int;
    bool isUtc = false;
    if (match[8] != null) {
      // timezone part
      isUtc = true;
      String? tzSign = match[9];
      if (tzSign != null) {
        // timezone other than 'Z' and 'z'.
        int sign = (tzSign == '-') ? -1 : 1;
        int hourDifference = int.parse(match[10]!);
        int minuteDifference = parseIntOrZero(match[11]);
        minuteDifference += 60 * hourDifference;
        minute -= sign * minuteDifference;
      }
    }
    DateTime? result = _finishParse(
      years,
      month,
      day,
      hour,
      minute,
      second,
      millisecond,
      microsecond,
      isUtc,
    );
    if (result == null) {
      throw FormatException("Time out of range", formattedString);
    }
    return result;
  } else {
    throw FormatException("Invalid date format", formattedString);
  }
}
