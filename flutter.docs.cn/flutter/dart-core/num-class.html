num

num 类 sealed

整数或浮点数。

任何非 int 或 double 类型都不能扩展或实现 num；否则会产生编译时错误。

另请参阅：

  • int：整数。
  • double：双精度浮点数。
  • 内置数字类型
  • 数字表示
