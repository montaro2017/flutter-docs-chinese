创建一个表示所提供名称的新 Symbol。

由相等的 name 字符串创建的 Symbol 彼此相等。如果使用 const 创建，则具有相同 name 字符串的 Symbol 会被规范化，因此彼此相同。

某些 name 字符串会创建也可以通过符号字面量创建的 Symbol，或者在运行 Dart 程序时隐式创建的 Symbol，例如通过 Object.noSuchMethod 创建。

如果 name 是一个不以下划线开头的 Dart 标识符，或者是由多个以 . 分隔的标识符组成的限定标识符，或者是除 unary- 以外的用户可定义运算符名称（包括“+”、“-”、“*”、“/”、“%”、“~/”、“&”、“|”、“^”、“~”、“<<”、“>>”、“>>>”、“<”、“<=”、“>”、“>=”、“==”、“[]”或“[]=”），则 Symbol(name) 的结果等于在 name 内容前加上 # 所创建的符号字面量，并且 const Symbol(name) 与该符号字面量相同。也就是说，#foo == Symbol("foo")，且 identical(#foo, const Symbol("foo"))。

如果 name 是一个不以下划线开头的单个标识符，后接 =，则该符号是 setter 名称，并且可以等于 Object.noSuchMethod 调用中的 Invocation.memberName。

无法通过符号构造函数创建私有符号字面量，例如 #_foo。像 const Symbol("_foo") 这样的符号不等于任何符号字面量，也不等于由 noSuchMethod 引入的任何源名称符号。

assert(Symbol("foo") == Symbol("foo"));
assert(Symbol("foo") == #foo);
assert(identical(const Symbol("foo"), const Symbol("foo")));
assert(identical(const Symbol("foo"), #foo));
assert(Symbol("[]=") == #[]=);
assert(identical(const Symbol("[]="), #[]=));
assert(Symbol("foo.bar") == #foo.bar);
assert(identical(const Symbol("foo.bar"), #foo.bar));

创建的实例会重写 Object.==。
