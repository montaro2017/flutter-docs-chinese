创建一个用于弃用实现某个类或 mixin 的注解。

此注解可用于当前允许被实现的 class 或 mixin 声明（即未标记为 final、sealed 或 base），但该声明将在后续版本中不再允许被实现。

任何现有的、通过 implements 实现该接口的类、mixin 或枚举声明都会触发警告，提示这种用法已弃用。此注解不影响扩展或混入该类或 mixin 的类（参见 Deprecated.extend、Deprecated.mixin 和 Deprecated.subclass）。

此注解不会由子类继承。如果公开子类也将变为不可实现（被注解的声明变为 final 或 base 时会如此，但变为 sealed 时不会），则该子类也应弃用实现能力。

如果提供了 message，它会作为警告的一部分显示。消息应面向编写实现类的程序员，建议替代方案（如果有），并说明预计何时移除此功能（如果早于或晚于下一个主版本）。

实现
