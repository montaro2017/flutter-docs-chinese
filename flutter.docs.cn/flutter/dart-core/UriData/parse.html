将字符串解析为 data URI。

字符串必须符合以下格式：

'data:' (type '/' subtype)? (';' attribute '=' value)* (';base64')? ',' data

其中 type、subtype、attribute 和 value 按 RFC 2045 定义，data 是由 URI 字符（RFC 2396 中的 uric）组成的序列。

这意味着所有字符都必须是 ASCII 字符；但 URI 可以包含表示非 ASCII 字节值的百分号转义，以便将其解释并转换为相应字符串。

解析过程会检查 Base64 编码的数据是否有效，并将其规范化为默认 Base64 字母表及带填充的形式。非 Base64 数据会在必要时使用百分号转义，以确保其有效；已有转义也会规范化大小写。

如果之后发现各个部分包含无法成功解码为字符串的内容，访问这些部分时仍可能失败。例如，已有百分号转义可能表示无法使用所选 Encoding 解码的字节（参见 contentAsString）。

如果 uri 不是有效的 data URI，则抛出 FormatException。

实现

static UriData parse(String uri) {
  if (uri.length >= 5) {
    int dataDelta = _startsWithData(uri, 0);
    if (dataDelta == 0) {
      // Exact match on "data:".
      return _parse(uri, 5, null);
    }
    if (dataDelta == 0x20) {
      // Starts with a non-normalized "data" scheme containing upper-case
      // letters. Parse anyway, but throw away the scheme.
      return _parse(uri.substring(5), 0, null);
    }
  }
  throw FormatException("Does not start with 'data:'", uri, 0);
}
