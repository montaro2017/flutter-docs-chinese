Deprecated

Deprecated 类

@Deprecated('migration') 注解用于标记已弃用的功能。

deprecated 注解是简写形式，表示弃用将在未指定的“下一个版本”生效，且不提供迁移说明。

功能可以是 API 的任何组成部分，从整个库到单个参数都可以。

@Deprecated 注解旨在告知目前正在使用该功能的开发者，他们很快就需要停止在代码中使用它，即使该功能目前仍能正常工作。

弃用是一种提前警告，表示该功能计划在之后的某个时间移除；具体时间可能会在 message 中说明。已弃用的功能不应继续使用，依赖它的代码未来某个时候将会失效。如果现有代码使用了该功能，就应重写代码以停止使用它。

弃用功能应在 message 中说明如何实现相同效果，以便程序员了解如何重写代码。

@Deprecated 注解可用于库、顶层声明（变量、getter、setter、函数、类、mixin、扩展和 typedef）、类级声明（变量、getter、setter、方法、运算符或构造函数，无论是否为静态成员）、命名可选参数和末尾的可选位置参数。

弃用状态会传递到已弃用功能所包含的部分：

  • If a library is deprecated, so is every member of it.
  • If a class is deprecated, so is every member of it.
  • If a variable is deprecated, so are its implicit getter and setter.

如果某个功能在父类中被弃用，子类不会自动随之弃用。父类中的成员可以被移除而子类仍保留该成员，因此必须允许只在父类中弃用该成员。

处理 Dart 源代码的工具可以在以下情况下报告弃用使用：

  • the code imports a deprecated library.
  • the code exports a deprecated library, or any deprecated member of a non-deprecated library.
  • the code refers statically to a deprecated declaration.
  • 代码使用了一个静态类型已知对象的成员，而该成员在此静态类型的接口上已被弃用。
  • the code calls a method with an argument where the corresponding optional parameter is deprecated on the object's static type.

如果弃用用法位于本身已弃用的库、类或方法中，工具不应因此打扰用户。已弃用功能可以预期会使用其他已弃用功能。
