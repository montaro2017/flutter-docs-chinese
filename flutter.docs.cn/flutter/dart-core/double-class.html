double

double 类 抽象 final

双精度浮点数。

num 中 double 类型特有的常量和操作，以及继承操作的专门实现。Dart 的 double 是符合 IEEE 754 标准的 64 位浮点数。

double 类型具有传染性。对 double 执行的操作会返回 double 结果。

任何类尝试扩展或实现 double 都会导致编译时错误。
