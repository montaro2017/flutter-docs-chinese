使用 fillValue 覆盖一个范围内的元素。

将索引大于或等于 start 且小于 end 的位置设为 fillValue。

调用时，指定的范围 start 和 end 必须有效。从 start 到 end 的范围有效条件是：0 ≤ start ≤ end ≤ length。空范围（即 end == start）也是有效的。

如果元素类型不可为空，则必须提供 fillValue，且其值不能为 null。

示例：

final words = List.filled(5, 'old');
print(words); // [old, old, old, old, old]
words.fillRange(1, 3, 'new');
print(words); // [old, new, new, old, old]
