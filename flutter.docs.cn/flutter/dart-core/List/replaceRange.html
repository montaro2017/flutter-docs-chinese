使用 replacements 中的元素替换一个范围内的元素。

先移除从 start 到 end 的对象，再从 start 位置插入 replacements 中的元素。

final numbers = <int>[1, 2, 3, 4, 5];
final replacements = [6, 7];
numbers.replaceRange(1, 4, replacements);
print(numbers); // [1, 6, 7, 5]

调用时，指定的范围 start 和 end 必须有效。从 start 到 end 的范围有效条件是：0 ≤ start ≤ end ≤ length。空范围（即 end == start）也是有效的。

操作 list.replaceRange(start, end, replacements) 大致等同于：

final numbers = <int>[1, 2, 3, 4, 5];
numbers.removeRange(1, 4);
final replacements = [6, 7];
numbers.insertAll(1, replacements);
print(numbers); // [1, 6, 7, 5]

但此方法可能更高效。

列表必须可增长。即使 replacements 的元素数量与被替换范围相同，此方法也不能用于长度固定的列表。在这种情况下，请改用 setRange。
