Runes

Runes 类 final

String 中的 rune（整数形式的 Unicode 码点）。

字符串中的字符使用 UTF-16 编码。解码 UTF-16 时会合并代理项对，从而得到 Unicode 码点。沿用 Go 的类似术语，Dart 使用 rune 一词表示代表 Unicode 码点的整数。使用字符串的 runes 属性获取字符串中的 rune。

示例：

const string = 'Dart';
final runes = string.runes.toList();
print(runes); // [68, 97, 114, 116]

对于由代理项对组成的基本多文种平面（平面 0）之外的字符，runes 会合并这对代理项并返回一个整数。

例如，Unicode 字符“男人”表情（👨，U+1F468）由代理项 U+d83d 和 U+dc68 合并而成。

示例：

const emojiMan = '👨';
print(emojiMan.runes); // (128104)

// Surrogate pairs:
for (final item in emojiMan.codeUnits) {
  print(item.toRadixString(16));
  // d83d
  // dc68
}
