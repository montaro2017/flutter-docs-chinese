Object

Object 类

除 null 以外所有 Dart 对象的基类。

由于 Object 是 Dart 非空类型类层次结构的根类，因此除 Null 以外的所有 Dart 类都是 Object 的子类。

定义类时，应考虑重写 toString，使其返回描述该类实例的字符串。你可能还需要定义 hashCode 和 operator ==，具体说明请参阅 实现映射键部分，以及 dart:core 简介。
