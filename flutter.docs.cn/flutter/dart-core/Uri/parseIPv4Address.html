将 host 解析为 IP 版本 4（IPv4）地址，并按网络字节顺序（大端序）以 4 个字节组成的列表返回。

如果提供了 start 和 end，则只解析 host 中由它们指定的有效范围。默认解析整个 host。

如果 host（或指定范围）不是有效的 IPv4 地址表示形式，则抛出 FormatException。有效形式为 <octet>.<octet>.<octet>.<octet>，每个八位组都是 0..255 范围内且不带前导零的十进制数字。

实现

static List<int> parseIPv4Address(
  String host, [
  @Since('3.10') int start = 0,
  @Since('3.10') int? end,
]) {
  end = RangeError.checkValidRange(start, end, host.length);
  var list = Uint8List(4);
  _parseIPv4Address(host, start, end, list, 0);
  return list;
}
