根据各个组件创建新的 URI。

通过命名参数设置各组件。可以提供任意数量的组件。path 和 query 组件可以分别通过两种不同的命名参数设置。

通过 scheme 设置方案组件。方案会规范化为全小写字母。如果省略方案或将其设为空字符串，URI 就不包含方案部分。

通过 userInfo 设置 authority 组件中的用户信息部分。默认值为空字符串，因此不会出现在 URI 的字符串表示形式中。

通过 host 设置 authority 组件中的主机部分。主机可以是主机名、IPv4 地址或置于 '[' 和 ']' 中的 IPv6 地址。如果主机包含冒号字符，且尚未提供 '[' 和 ']'，则会自动添加。主机名会规范化为全小写字母。

通过 port 设置 authority 组件中的端口部分。如果省略 port 或将其设为 null，则使用 URI 方案的默认端口，这与显式传入该端口等价。已识别的方案及其默认端口为“http”（80）和“https”（443）。其他所有方案的默认端口均视为零。

如果提供了 userInfo、host 或 port 中的任意一项，则根据 hasAuthority，URI 会包含 authority。

通过 path 或 pathSegments 设置路径组件。使用 path 时，它应是有效的 URI 路径，但除通用分隔符“:/@[]?#”以外的无效字符会在必要时转义。反斜杠 \ 会转换为斜杠 /。使用 pathSegments 时，提供的每个路径段会先进行百分号编码，然后使用正斜杠连接。

路径段的百分号编码会编码除非保留字符以及以下字符之外的所有字符：!$&'()*+,;=:@。如果其他组件要求使用绝对路径，且路径尚未以斜杠 / 开头，则会在前面添加一个斜杠。

通过 query 或 queryParameters 设置查询组件。使用 query 时，提供的字符串应是有效的 URI 查询；除通用分隔符以外的无效字符会在必要时转义。使用 queryParameters 时，会根据提供的映射构建查询。映射中的每个键和值都会进行百分号编码，并使用等号和与号连接。映射中的值必须是 null、字符串或由字符串构成的 Iterable。一个可迭代对象对应同一键的多个值；空可迭代对象或 null 表示该键没有值。

键和值的百分号编码会编码除非保留字符以外的所有字符，并将空格替换为 +。如果 query 是空字符串，则等同于省略它。要创建实际存在但为空的查询部分，请对 queryParameters 使用空映射。

如果 query 和 queryParameters 均被省略或设为 null，URI 就不包含查询部分。

通过 fragment 设置片段组件。它应是有效的 URI 片段；除通用分隔符以外的无效字符会在必要时转义。如果省略 fragment 或将其设为 null，URI 就不包含片段部分。

示例：

final httpsUri = Uri(
    scheme: 'https',
    host: 'dart.dev',
    path: 'language/built-in-types',
    fragment: 'numbers');
print(httpsUri); // https://dart.dev/language/built-in-types#numbers

final mailtoUri = Uri(
    scheme: 'mailto',
    path: 'John.Doe@example.com',
    queryParameters: {'subject': 'Example'});
print(mailtoUri); // mailto:John.Doe@example.com?subject=Example
