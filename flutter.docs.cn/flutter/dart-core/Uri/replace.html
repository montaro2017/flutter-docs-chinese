基于此 URI 创建一个新 Uri，并替换其中的某些部分。

此方法接受与 Uri 构造函数相同的参数，且参数含义也相同。

path 和 pathSegments 最多只能提供一个。同样，query 和 queryParameters 也最多只能提供一个。

未提供的每个部分都会默认使用此 Uri 中对应的值。

此方法不同于 Uri.resolve：后者以层次方式覆盖组件，而此方法可以单独替换 Uri 的各个部分。

示例：

final uri1 = Uri.parse(
    'https://dart.dev/libraries/dart-core#utility-classes');

final uri2 = uri1.replace(
    scheme: 'https',
    path: 'libraries/dart-core',
    fragment: 'uris');
print(uri2); // https://dart.dev/libraries/dart-core#uris

此方法的行为类似于使用此 Uri 中的部分参数调用 Uri 构造函数。例如：

final Uri uri3 = Uri(
    scheme: 'https',
    userInfo: uri1.userInfo,
    host: uri1.host,
    port: uri2.port,
    path: 'language/built-in-types',
    query: uri1.query,
    fragment: null);
print(uri3); // https://dart.dev/language/built-in-types

此方法可视为上述 Uri 构造函数调用的简写；由于无需再次检查从此 Uri 获取的部分是否有效，执行速度也可能稍快。
