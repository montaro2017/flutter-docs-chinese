String encodeComponent(
  1. String component
)

对字符串 component 进行百分号编码，使其可安全地作为 URI 组件的字面值使用。

除大小写英文字母、数字以及字符 -_.!~*'() 外，所有字符都会进行百分号编码。这组字符由 RFC 2396 指定，也与 ECMA-262 5.1 版中 encodeUriComponent 的规定一致。

手动编码路径段或查询组件时，请记得在构建路径或查询字符串之前分别编码每个部分。

编码查询部分时，请考虑使用 encodeQueryComponent。

要避免显式编码，在构造 Uri 时使用可选命名参数 pathSegments 和 queryParameters。

示例：

const request = 'http://example.com/search=Dart';
final encoded = Uri.encodeComponent(request);
print(encoded); // http%3A%2F%2Fexample.com%2Fsearch%3DDart

实现

static String encodeComponent(String component) {
  return _Uri._uriEncode(_unreserved2396Mask, component, utf8, false);
}
