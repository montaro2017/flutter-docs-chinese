Uri.dataFromString 构造函数

Uri.dataFromString(
  1. String content, {
  2. String? mimeType,
  3. Encoding? encoding,
  4. Map<String, String>? parameters,
  5. bool base64 = false,
})

创建一个 data: URI，其中包含 content 字符串。

使用 encoding 或 parameters 中指定的字符集将内容转换为字节（未指定或无法识别时默认为 US-ASCII），然后将字节编码到生成的 data URI 中。

默认使用百分号编码（任何非 ASCII 或 URI 无效字节都会替换为百分号编码）。如果 base64 为 true，则改用 base64 对字节进行编码。

如果未提供 encoding，且 parameters 中包含 charset 条目，则会使用 Encoding.getByName 查询该名称；如果查询返回一种编码，就会用它将 content 转换为字节。如果同时提供 encoding 和 parameters 中的字符集，两者应保持一致，否则解码时将无法通过字符集参数确定编码。

如果提供了 mimeType 和/或 parameters，它们会添加到所创建的 URI 中。如果其中包含 data URI 不允许的字符，该字符会进行百分号转义。如果字符为非 ASCII 字符，则会先进行 UTF-8 编码，再对字节进行百分号编码。在 data URI 中省略 mimeType 表示 text/plain，正如省略 charset 参数表示 US-ASCII 一样。

要读取内容，请使用 UriData.contentAsString。

示例：

final uri = Uri.dataFromString(
  'example content',
  mimeType: 'text/plain',
  parameters: <String, String>{'search': 'file', 'max': '10'},
);
print(uri); // data:;search=name;max=10,example%20content

实现

factory Uri.dataFromString(
  String content, {
  String? mimeType,
  Encoding? encoding,
  Map<String, String>? parameters,
  bool base64 = false,
}) {
  UriData data = UriData.fromString(
    content,
    mimeType: mimeType,
    encoding: encoding,
    parameters: parameters,
    base64: base64,
  );
  return data.uri;
}
