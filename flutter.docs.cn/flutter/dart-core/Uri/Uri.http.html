Uri.http

Uri.http 构造函数

Uri.http(
  1. String authority, [
  2. String unencodedPath,
  3. Map<String, dynamic>? queryParameters
])

根据 authority、路径和查询创建新的 http URI。

示例：

var uri = Uri.http('example.org', '/path', { 'q' : 'dart' });
print(uri); // http://example.org/path?q=dart

uri = Uri.http('user:password@localhost:8080', '');
print(uri); // http://user:password@localhost:8080

uri = Uri.http('example.org', 'a b');
print(uri); // http://example.org/a%20b

uri = Uri.http('example.org', '/a%2F');
print(uri); // http://example.org/a%252F

scheme 始终设置为 http。

userInfo、host 和 port 组件取自 authority 参数。如果 authority 为 null 或空字符串，创建的 Uri 就没有 authority，不能直接用作 HTTP URL，因为 HTTP URL 必须具有非空主机名。

path 组件取自 unencodedPath 参数。传入的路径不得预先编码，因为此构造函数会对其编码。只有 / 会被识别为路径分隔符。如果省略，路径默认为空。

query 组件取自可选的 queryParameters 参数。
