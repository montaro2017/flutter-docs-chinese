检查范围是否表示可索引对象的一个切片。

如果该范围不适用于长度为给定 length 的可索引对象，则抛出异常。对于长度为给定 length 的可索引对象，有效范围需满足：

0 <= [start] <= [end] <= [length]。end 为 null 时视为等同于 length。

startName 和 endName 的默认值分别为 "start" 和 "end"。

返回实际的 end 值：如果 end 为 null，则返回 length；否则返回 end。

实现

static int checkValidRange(
  int start,
  int? end,
  int length, [
  String? startName,
  String? endName,
  String? message,
]) {
  // Comparing with `0` as receiver produces better dart2js type inference.
  // Ditto `start > end` below.
  if (0 > start || start > length) {
    startName ??= "start";
    throw RangeError.range(start, 0, length, startName, message);
  }
  if (end != null) {
    if (start > end || end > length) {
      endName ??= "end";
      throw RangeError.range(end, start, length, endName, message);
    }
    return end;
  }
  return length;
}
