Comparable

Comparable<T> 类 抽象 interface

供具有内在顺序的类型使用的接口。

compareTo 操作用于定义对象的全序，可用于对象排序。

Comparable 接口适用于定义类型的自然顺序。如果一种类型有多种排序方式，且没有哪一种明显属于自然顺序，那么最好不要使用 Comparable 接口，而是分别提供多个 Comparator。

建议 Comparable 的排序结果与其 operator == 相等性一致（当且仅当 a.compareTo(b) == 0 时，a == b），但这并非强制要求。例如，double 和 DateTime 的 compareTo 方法与 operator == 并不一致。对于 double，compareTo 方法比相等性判断更精确；对于 DateTime，则不如相等性判断精确。

示例：

(0.0).compareTo(-0.0);   // => 1
0.0 == -0.0;             // => true
var now = DateTime.now();
var utcNow = now.toUtc();
now == utcNow;           // => false
now.compareTo(utcNow);   // => 0

Comparable 接口并不意味着必须提供比较运算符 <、<=、> 和 >=。只有当排序属于“小于/大于”排序，也就是自然地会用“小于”来描述两个元素的顺序时，才应定义这些运算符。

如果相等运算符与 compareTo 的结果不一致，比较运算符应遵循相等运算符，因此很可能也会与 compareTo 不一致。否则，比较运算符应与 compareTo 方法一致，即 a < b 当且仅当 a.compareTo(b) < 0。

double 类定义了与相等性兼容的比较运算符。这些运算符在 -0.0 和 NaN 上与 double.compareTo 的结果不同。

DateTime 类没有比较运算符，而是提供了名称更明确的 DateTime.isBefore 和 DateTime.isAfter，两者的结果都与 DateTime.compareTo 一致。
