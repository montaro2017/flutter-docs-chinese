RegExp 构造函数

RegExp(
  1. String source, {
  2. bool multiLine = false,
  3. bool caseSensitive = true,
  4. bool unicode = false,
  5. bool dotAll = false,
})

构造一个正则表达式。

如果 source 不符合有效的正则表达式语法，则抛出 FormatException。

如果代码启用了 multiLine，那么 ^ 和 $ 除了分别匹配输入的开头和结尾外，也会匹配每一行的开头和结尾。

如果代码禁用了 caseSensitive，Dart 匹配时会忽略字母大小写。例如，禁用 caseSensitive 时，正则表达式模式 a 同时匹配 a 和 A。

如果代码启用了 unicode，Dart 会按照 ECMAScript 标准将该模式视为 Unicode 模式。

如果代码启用了 dotAll，则 . 模式会匹配所有字符，包括行终止符。

示例：

final wordPattern = RegExp(r'(\w+)');
final digitPattern = RegExp(r'(\d+)');

这些示例将原始字符串作为参数。建议将原始字符串用作 RegExp 构造函数的参数，因为这样可以方便地将 \ 和 $ 字符用作正则表达式保留字符。

使用非原始字符串编写的相同示例如下：

final wordPattern = RegExp('(\\w+)'); // Should be raw string.
final digitPattern = RegExp('(\\d+)'); // Should be raw string.

只有在需要使用字符串插值时才使用非原始字符串。例如：

Pattern keyValuePattern(String keyIdentifier) =>
    RegExp('$keyIdentifier=(\\w+)');

像这样将字符串原样包含在正则表达式模式中时，请确保字符串不包含正则表达式保留字符。如果无法确保这一点，请使用 escape 函数将这些字符转换为安全形式，从而只匹配字符串本身：

Pattern keyValuePattern(String anyStringKey) =>
    RegExp('${RegExp.escape(anyStringKey)}=(\\w+)');
