int

int 类 抽象 final

整数。

int 的默认实现采用 64 位二进制补码整数，溢出时运算结果会回绕到该范围内。

注意：编译为 JavaScript 时，整数仅限于可由双精度浮点数精确表示的值。可用整数包括 -2^53 到 2^53 之间的所有整数，以及部分绝对值更大的整数，其中也包括一些大于 2^63 的整数。因此，int 类中的运算符和方法在 Dart VM 与编译为 JavaScript 的 Dart 代码之间有时会有不同表现。例如，编译为 JavaScript 时，位运算符会将操作数截断为 32 位整数。

类不能扩展、实现 int，也不能将其混入。
