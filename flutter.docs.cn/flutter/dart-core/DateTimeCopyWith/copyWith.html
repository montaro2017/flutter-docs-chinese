通过更新各个属性，从此对象创建一个新的 DateTime。

copyWith 方法会创建一个新的 DateTime 对象。其 DateTime.year、DateTime.hour 等属性的值由同名参数提供；如果未提供参数或参数为 null，则沿用该属性的现有值。

示例：

final now = DateTime.now();
final sameTimeOnMoonLandingDay =
    now.copyWith(year: 1969, month: 07, day: 20);

与 DateTime 和 DateTime.utc 构造函数（此操作会使用它们创建新值）一样，属性值可以超出其允许范围，例如 month 不在 1 到 12 之间。这可能会影响更高位的属性（例如，月份为 13 时会变为下一年的 1 月）。

还请注意，如果结果是本地时间的 DateTime，季节性时区调整（夏令时）可能导致某些日期、小时和分钟的组合不存在，或出现多次。前一种情况下，会改用相邻两个时区之一中的对应时间；后一种情况下，则会选择其中一个时间。

实现

DateTime copyWith({
  int? year,
  int? month,
  int? day,
  int? hour,
  int? minute,
  int? second,
  int? millisecond,
  int? microsecond,
  bool? isUtc,
}) {
  return ((isUtc ?? this.isUtc) ? DateTime.utc : DateTime.new)(
    year ?? this.year,
    month ?? this.month,
    day ?? this.day,
    hour ?? this.hour,
    minute ?? this.minute,
    second ?? this.second,
    millisecond ?? this.millisecond,
    microsecond ?? this.microsecond,
  );
}
