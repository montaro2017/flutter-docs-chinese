为多个对象创建组合哈希码。

即使参数为 null，也会为所有实际提供的参数计算哈希码，并通过数值运算组合每个参数的 Object.hashCode。

示例：

class SomeObject {
  final Object a, b, c;
  SomeObject(this.a, this.b, this.c);
  bool operator ==(Object other) =>
      other is SomeObject && a == other.a && b == other.b && c == other.c;
  int get hashCode => Object.hash(a, b, c);
}

示例：

在单次程序执行期间，使用相同参数多次调用此函数，计算结果保持一致。

hashAll 函数在接收一个按相同顺序包含此函数实际参数的集合时，会返回与此函数相同的结果。
