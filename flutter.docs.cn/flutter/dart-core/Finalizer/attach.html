attach

attach abstract 方法

void attach(
  1. Object value,
  2. T finalizationToken, {
  3. Object? detach,
})

将此终结器附加到 value。

当 value 不再能被程序访问，且仍与此终结器关联时，此终结器的回调可能会以 finalizationToken 为参数被调用。每个处于活动状态的关联最多触发一次回调；通过调用 Finalizer.detach 分离的关联除外。

detach 值仅供终结器识别当前关联。如果提供了非 null 的 detach 值，就可以将同一个（标识相同的）值传给 Finalizer.detach 以移除关联。如果未提供非 null 值，则之后无法移除该关联。

value 和 detach 参数不会使对应对象被程序视为可访问。两者都必须是可用作 Expando 键的对象，也可以是同一个对象。

示例：

class Database {
  // Keeps the finalizer itself reachable, otherwise it might be disposed
  // before the finalizer callback gets a chance to run.
  static final Finalizer<DBConnection> _finalizer =
      Finalizer((connection) => connection.close());

  factory Database.connect() {
    // Wraps the connection in a nice user API,
    // *and* closes connection if the user forgets to.
    final connection = DBConnection.connect();
    final wrapper = Database._fromConnection();
    // Calls finalizer callback when `wrapper` is no longer reachable.
    _finalizer.attach(wrapper, connection, detach: wrapper);
    return wrapper;
  }

  Database._fromConnection();

  // Some useful methods.
}

可以使用同一个终结令牌关联多个对象，也可以将同一个对象多次附加到终结器，并为各次关联使用相同或不同的终结令牌。
