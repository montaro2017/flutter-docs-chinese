Expando

Expando<T extends Object> 类 final

Expando 允许为对象添加新属性。

它不能用于数字、字符串、布尔值、记录、null、dart:ffi 指针、dart:ffi 结构体或 dart:ffi 联合体。

对象变得不可访问后，Expando 不会继续持有添加的属性值。

由于总能创建一个与现有数字相同的新数字，因此数字上的 expando 属性永远无法释放。为避免这种情况，不能为数字添加 expando 属性。字符串、布尔值和 null 也适用同样的理由：它们都有字面量，多次出现时会计算为相同的值。此外，记录没有明确且持久的对象标识，因此也不能添加 expando 属性。

其他类没有此限制，即使是编译时常量对象也可以添加。为编译时常量添加 expando 属性时请谨慎，因为这些对象会一直存活。
