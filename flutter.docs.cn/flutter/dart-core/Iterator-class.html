Iterator

Iterator<E> 类 抽象 interface

用于从对象中逐个获取元素的接口。

for-in 结构会透明地使用 Iterator 来判断迭代是否结束并获取每一项（即元素）。

如果在迭代期间修改了被迭代的对象，则行为未指定。

Iterator 初始位置在第一个元素之前。因此，访问首个元素前必须使用 moveNext 前移迭代器。如果没有剩余元素，moveNext 会返回 false，此后所有 moveNext 调用也都会返回 false。

在调用 current 之前，或在 moveNext 已返回 false 之后，不得访问 moveNext 值。

典型的 Iterator 用法如下：

var it = obj.iterator;
while (it.moveNext()) {
  use(it.current);
}
