UriData

UriData 类 final

用于访问 data: URI 结构的方式。

Data URI 是可以包含任意二进制数据的非层次 URI，由 RFC 2397 定义。

此类支持解析 URI 文本、提取 URI 的各个部分，以及根据结构化部分构建 URI 文本。
