split

split abstract 方法

List<String> split(
  1. Pattern pattern
)

在与 pattern 匹配的位置拆分字符串，并返回子字符串列表。

使用 Pattern.allMatches 查找此字符串中与 pattern 匹配的所有位置，并返回匹配项之间、首个匹配项之前以及最后一个匹配项之后的子字符串列表。

const string = 'Hello world!';
final splitted = string.split(' ');
print(splitted); // [Hello, world!];

如果模式与此字符串完全不匹配，结果始终是只包含原字符串的列表。

如果 pattern 是 String，则以下情况始终成立：

string.split(pattern).join(pattern) == string

如果首个匹配项是在字符串开头的空匹配，则结果中不包含它之前的空子字符串。如果最后一个匹配项是在字符串末尾的空匹配，则结果中不包含它之后的空子字符串。如果某个空匹配紧接在前一个匹配项之后（即其起始位置等于前一个匹配项的结束位置），则结果中不包含两个匹配项之间的空子字符串。

const string = 'abba';
final re = RegExp(r'b*');
// re.allMatches(string) will find four matches:
// * empty match before first "a".
// * match of "bb"
// * empty match after "bb", before second "a"
// * empty match after second "a".
print(string.split(re)); // [a, a]

字符串开头或结尾处的非空匹配项，以及紧跟在另一匹配项之后的非空匹配项，不会进行特殊处理，并会在结果中产生空子字符串：

const string = 'abbaa';
final splitted = string.split('a'); // ['', 'bb', '', '']

如果此字符串为空字符串，且 pattern 匹配空字符串，则结果为空列表，因为首尾空匹配之前和之后的空字符串都不会包含在结果中。（如果模式不匹配，结果仍是只包含原空字符串 [""] 的列表。）

const string = '';
print(string.split('')); // []
print(string.split('a')); // []

使用空模式拆分时，字符串会被拆分为单个代码单元组成的字符串。

const string = 'Pub';
print(string.split('')); // [P, u, b]

// Same as:
var codeUnitStrings = [
  for (final unit in string.codeUnits) String.fromCharCode(unit)
];
print(codeUnitStrings); // [P, u, b]

拆分位置依据 UTF-16 代码单元边界，而不是 rune（Unicode 码点）边界：

// String made up of two code units, but one rune.
const string = '\u{1D11E}';
final splitted = string.split('');
print(splitted); // ['\ud834', '\udd1e'] - 2 unpaired surrogate values

要获取由字符串各个 rune 组成的字符串列表，不应使用 split。可以按如下方式为每个 rune 获取一个字符串：

const string = '\u{1F642}';
for (final rune in string.runes) {
  print(String.fromCharCode(rune));
}
