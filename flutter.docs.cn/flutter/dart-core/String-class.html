String

String 类 抽象 final

由 UTF-16 代码单元组成的序列。

字符串主要用于表示文本。一个字符可能由多个码点表示，每个码点由一个或两个代码单元组成。例如，巴布亚新几内亚国旗字符需要四个代码单元表示两个码点，但应将其视为单个字符：“🇵🇬”。不支持该旗帜字符的平台可能会显示字母“PG”。如果交换两个码点，就会变成瓜德罗普岛旗帜“🇬🇵”（“GP”）。

字符串可以是单行或多行。单行字符串使用匹配的单引号或双引号书写，多行字符串使用三引号书写。以下都是有效的 Dart 字符串：

'Single quotes';
"Double quotes";
'Double quotes in "single" quotes';
"Single quotes in 'double' quotes";

'''A
multiline
string''';

"""
Another
multiline
string""";

字符串是不可变的。虽然不能更改字符串，但可以对字符串执行操作并创建一个新字符串：

const string = 'Dart is fun';
print(string.substring(0, 4)); // 'Dart'

可以使用加号（+）运算符连接字符串：

const string = 'Dart ' + 'is ' + 'fun!';
print(string); // 'Dart is fun!'

相邻的字符串字面量会自动连接：

const string = 'Dart ' 'is ' 'fun!';
print(string); // 'Dart is fun!'

可以使用 ${} 在字符串中插入 Dart 表达式的值。求值标识符时可以省略花括号：

const string = 'dartlang';
print('$string has ${string.length} letters'); // dartlang has 8 letters

字符串由一系列 Unicode UTF-16 代码单元表示，可以通过 codeUnitAt 或 codeUnits 成员访问：

const string = 'Dart';
final firstCodeUnit = string.codeUnitAt(0);
print(firstCodeUnit); // 68, aka U+0044, the code point for 'D'.
final allCodeUnits = string.codeUnits;
print(allCodeUnits); // [68, 97, 114, 116]

也可以通过索引运算符获取由各代码单元组成的字符串表示：

const string = 'Dart';
final charAtIndex = string[0];
print(charAtIndex); // 'D'

字符串中的字符以 UTF-16 编码。解码 UTF-16 时会合并代理项对，从而得到 Unicode 码点。与 Go 的术语类似，Dart 使用 rune 一词表示代表 Unicode 码点的整数。使用字符串的 runes 属性获取其中的 rune：

const string = 'Dart';
final runes = string.runes.toList();
print(runes); // [68, 97, 114, 116]

对于由代理项对组成的基本多文种平面（平面 0）之外的字符，runes 会合并代理项并返回一个整数。例如，Unicode 音乐符号高音谱号（“𝄞”，rune 值为 0x1D11E）由 UTF-16 代理项对 0xD834 和 0xDD1E 组成。使用 codeUnits 会返回代理项对，而使用 runes 会返回其合并后的值：

const clef = '\u{1D11E}';
for (final item in clef.codeUnits) {
  print(item.toRadixString(16));
  // d834
  // dd1e
}
for (final item in clef.runes) {
  print(item.toRadixString(16)); // 1d11e
}

String 类不能被扩展或实现。尝试这样做会导致编译时错误。
