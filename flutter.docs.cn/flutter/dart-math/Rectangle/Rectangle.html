Rectangle<T extends num> 构造函数

const Rectangle<T extends num>(
  1. T left,
  2. T top,
  3. T width,
  4. T height,
)

创建一个由 (left, top) 和 (left+width, top+height) 确定范围的矩形。

该矩形包含 x 坐标位于 left 与 left + width 之间、y 坐标位于 top 与 top + height 之间的点，边界均包含在内。

width 和 height 应为非负数。如果 width 或 height 为负数，则会被限制为零。

如果 width 和 height 都为零，则此“矩形”仅包含点 (left, top)。

示例：

var rectangle = const Rectangle(20, 50, 300, 600);
print(rectangle.left); // 20
print(rectangle.top); // 50
print(rectangle.right); // 320
print(rectangle.bottom); // 650

旧版 API：不建议在新代码中使用 Rectangle。详情请参阅 Rectangle 类 API 文档。

实现

const Rectangle(this.left, this.top, T width, T height)
  : width = (width < 0)
        ? (width == double.negativeInfinity ? 0.0 : (-width * 0)) as dynamic
        : (width + 0 as dynamic), // Inline _clampToZero<num>.
    height = (height < 0)
        ? (height == double.negativeInfinity ? 0.0 : (-height * 0)) as dynamic
        : (height + 0 as dynamic);
