pow function

num pow(
  1. num x,
  2. num exponent
)

返回 x 的 exponent 次幂。

如果 x 是 int，且 exponent 是非负的 int，则结果为 int；否则会先将两个参数都转换为 double，结果为 double。

对于整数，次幂始终等于 x 的 exponent 次幂的数学结果，唯一限制是可用内存。

对于 double，pow(x, y) 按以下方式处理边界情况：

  • 如果 y 为零（0.0 或 -0.0），结果始终为 1.0。
  • 如果 x 为 1.0，结果始终为 1.0。
  • 否则，如果 x 或 y 是 NaN，结果就是 NaN。
  • 如果 x 为负数（但不是 -0.0），且 y 是有限的非整数，结果为 NaN。
  • 如果 x 为 Infinity 且 y 为负数，结果为 0.0。
  • 如果 x 为 Infinity 且 y 为正数，结果为 Infinity。
  • 如果 x 为 0.0 且 y 为负数，结果为 Infinity。
  • 如果 x 为 0.0 且 y 为正数，结果为 0.0。
  • 如果 x 为 -Infinity 或 -0.0，且 y 是奇整数，则结果为 -pow(-x ,y)。
  • 如果 x 为 -Infinity 或 -0.0，且 y 不是奇整数，则结果与 pow(-x , y)。
  • 如果 y 为 Infinity 且 x 的绝对值小于 1，结果为 0.0。
  • 如果 y 为 Infinity 且 x 为 -1，结果为 1.0。
  • 如果 y 为 Infinity 且 x 的绝对值大于 1，结果为 Infinity。
  • 如果 y 为 -Infinity，结果为 1/pow(x, Infinity)。

这与 IEEE 标准 754-2008 中定义的 pow 函数相对应。

请注意，结果可能溢出。如果整数以 64 位数表示，整数结果可能被截断，而 double 结果可能溢出为正或负的 double.infinity。

实现

external num pow(num x, num exponent);
