Rectangle

Rectangle<T extends num> 类

用于表示二维矩形的类，其属性不可变。

旧版 API：不建议在新代码中使用 Rectangle。

  • 如果在 Rectangle 类中使用 dart:html，建议迁移到 package:web。有关迁移原因和方法，请参阅 迁移指南。
  • 如果需要在某个坐标系中保存矩形边界，可以考虑使用 record。根据用途，可以写成 var boundaries = (mixX: x1, maxX: x2, minY: y1, maxY: y2)。
  • 如果需要进行相交计算或包含性检查， 可以考虑使用专门的库，例如 package:vector_math。
  • 如果你正在开发 Flutter 应用或软件包，可以考虑使用 Rect 类型（位于 dart:ui 中）。
