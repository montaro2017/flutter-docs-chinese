Point

Point<T extends num> 类

用于表示二维位置的实用类。

示例：

var leftTop = const Point(0, 0);
var rightBottom = const Point(200, 400);

旧版 API：不建议在新代码中使用 Point。

  • 如果在 Point 类中使用 dart:html，建议迁移到 package:web。有关迁移原因和方法，请参阅 迁移指南。
  • If you want to combine an x 和 y coordinate, consider using a record. Depending on how you will use it, this could look like var point = (x, y) or var point = (x: x, y: y).
  • 如果需要执行向量加法或标量乘法等向量运算，可以考虑使用专门的向量数学库，例如 package:vector_math。
  • If you are developing a Flutter application or package, consider using the Offset type from dart:ui.
