atan2 function

double atan2(
  1. num a,
  2. num b
)

atan 的变体。

将两个参数都转换为 double。

返回正 x 轴与向量（b, a）之间的弧度角。结果范围为 -PI..PI。

如果 b 为正数，则结果与 atan(a/b) 相同。

当 a 为负数时（包括 a 是 double 类型的 -0.0 时），结果为负数。

如果 a 等于零，则认为向量（b, a）与 x 轴平行，即使 b 也等于零。b 的符号决定向量沿 x 轴的方向。

如果任一参数为 NaN，则返回 NaN。

实现

external double atan2(num a, num b);
