使用给定描述（转换为字符串后）和主体创建一个新的测试用例。

此描述会添加到所有外层 group 的描述中。如果传入 testOn，系统会将其解析为平台选择器；测试只会在匹配的平台上运行。

如果传入 timeout，它会修改或替换默认的 30 秒超时时间。超时修改按套件、组、测试的顺序优先应用，因此 timeout 也会修改组或套件上设置的超时。

如果 skip 是字符串或 true，则跳过此测试。如果是字符串，应说明跳过测试的原因；运行测试时会打印此原因。

如果传入 tags，则会声明应用于测试的用户自定义标签。这些标签可用于在命令行选择或跳过测试，也可用于批量配置测试。所有标签都应在包配置文件中声明。此参数可以是包含标签名称的 Iterable，也可以是表示单个标签的 String。

如果传入 retry，则在测试被标记为失败之前，会按指定次数重试。

onPlatform 可按平台配置测试。它是一个映射：键为可解析为 PlatformSelector 的字符串，值为注解类：Timeout、Skip 或这些注解组成的列表。这些注解仅适用于指定平台。例如：

test('potentially slow test', () {
  // ...
}, onPlatform: {
  // This test is especially slow on Windows.
  'windows': Timeout.factor(2),
  'browser': [
    Skip('TODO: add browser support'),
    // This will be slow on browsers once it works on them.
    Timeout.factor(2)
  ]
});

如果匹配多个平台，注解会按顺序应用，效果如同它们位于嵌套组中。

如果 solo 标志为 true，则只运行标记为“solo”的测试和组。此限制仅适用于当前测试套件内的测试；其他套件中的测试照常运行。我们建议尽可能避免使用此标志，改用测试运行器的 -n 标志按名称筛选测试。

实现

@isTest
void test(
  Object? description,
  FutureOr<dynamic> Function() body, {
  String? testOn,
  Timeout? timeout,
  Object? skip,
  Object? tags,
  Map<String, dynamic>? onPlatform,
  int? retry,
  TestLocation? location,
  @doNotSubmit bool solo = false,
}) {
  _declarer.test(
    description.toString(),
    body,
    testOn: testOn,
    timeout: timeout,
    skip: skip,
    onPlatform: onPlatform,
    tags: tags,
    retry: retry,
    location: location,
    solo: solo,
  );

  // Force dart2js not to inline this function. We need it to be separate from
  // `main()` in JS stack traces in order to properly determine the line and
  // column where the test was defined. See sdk#26705.
  return;
  return; // ignore: dead_code
}
