GpuSurfaceFrame

GpuSurfaceFrame 类 sealed

从 GpuSurface 获取的可写帧。

帧是 colorTexture 的临时写入租约。请将最终颜色写入该纹理，然后调用 present。如果不呈现此帧，请调用 discard，以便表面复用其后备纹理。

每个已获取帧必须且只能调用一次 present 或 discard。在调用 present 后调用 discard 不会产生任何效果；在调用 discard 后调用 present 则会抛出异常。
