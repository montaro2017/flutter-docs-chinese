void bindVertexBuffer(

  2. int slot = 0,
})

将 bufferView 作为顶点缓冲区绑定到指定的 slot。

slot 用于选择数据所在的顶点缓冲区绑定槽位，该槽位与当前管线的 VertexLayout 中声明的相应 VertexBuffer 槽位匹配。默认值 0 与着色器包声明的默认布局一致，适用于所有单缓冲区调用点。若要绑定多个结构数组顶点缓冲区，请为每个槽位分别调用此方法。

要绘制的顶点数量需单独传给 draw。

不支持稀疏绑定。调用 draw 或 drawIndexed 前，必须绑定 [0, highestBound] 范围内的每个槽位，否则会抛出指出未绑定槽位的 StateError。槽位可以按任意顺序绑定。

slot 必须在 [0, 16) 范围内（这是当前 Flutter GPU 对顶点缓冲区绑定数量的限制）。某些设备还可能限制单条管线使用的顶点属性总数。

实现

void bindVertexBuffer(BufferView bufferView, {int slot = 0}) {
  if (slot < 0 || slot >= _kMaxVertexBufferSlots) {
    throw RangeError.range(
      slot,
      0,
      _kMaxVertexBufferSlots - 1,
      'slot',
      'bindVertexBuffer slot must be in [0, $_kMaxVertexBufferSlots)',
    );
  }
  _boundVertexSlotsMask |= 1 << slot;
  if (slot > _maxBoundVertexSlot) {
    _maxBoundVertexSlot = slot;
  }
  bufferView.buffer._bindAsVertexBuffer(
    this,
    bufferView.offsetInBytes,
    bufferView.lengthInBytes,
    slot,
  );
}
