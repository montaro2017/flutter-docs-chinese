PixelFormat

PixelFormat enum

Texture 中纹素的内存布局。

每个名称都按顺序列出纹理的组成分量、每个分量的位宽，以及这些位的解释方式。例如，r8g8b8a8UNormInt 是一种每像素 32 位的格式，包含红、绿、蓝、透明度四个 8 位分量，每个分量都存储为无符号归一化整数。

分量标识：

  • r、g、b：红、绿、蓝颜色分量。
  • a：透明度分量。
  • d：深度分量。
  • s：模板分量。
  • UNorm：无符号整数；读取时会将其从 [0, 2^bits - 1] 范围映射到浮点数范围 [0.0, 1.0]。
  • UInt：读取时不进行归一化处理的无符号整数。
  • Float：IEEE 754 浮点数。
  • SRGB：颜色分量以 sRGB 色彩空间存储，读写时会在 sRGB 与线性空间之间转换。

块压缩格式根据其压缩方案（BC、ETC2 或 ASTC）和块尺寸命名。块几何信息请参阅 PixelFormatProperties；硬件支持的分组方式请参阅 TextureCompressionFamily。

r8g8b8a8UNormInt → const PixelFormat

Four 8 bit components (red, green, blue, alpha), stored as unsigned normalized integers.

This is the most common 32 bit per pixel color format and the default for GpuContext.createTexture.
