重写

将此帧发布为表面的当前图像。

commandBuffer 必须是包含对 colorTexture 最终写入操作的命令缓冲区。记录这些写入操作后、提交 commandBuffer 前，请调用此方法。

调用此方法不会提交 commandBuffer。它会将此帧关联到 commandBuffer，以便表面可以根据命令缓冲区的完成状态判断何时可以考虑复用该纹理。

必须提交 commandBuffer，才能渲染已呈现的帧。在提交之前，GpuImageSurface.currentImage 不会包含此帧的内容，并且该后备纹理仍无法用于后续帧。如果呈现了帧却从未提交其命令缓冲区，那么下一次调用 GpuImageSurface.acquireNextFrame 会抛出 StateError。

已发布的图像可通过 GpuImageSurface.currentImage 获取。

实现

@override
GpuPresentStatus present(CommandBuffer commandBuffer) {
  if (!_isActive) {
    throw StateError(
      'GpuSurfaceFrame has already been presented or discarded.',
    );
  }
  _surface._presentFrame(this, commandBuffer);
  _isActive = false;
  colorTexture._valid = false;
  return GpuPresentStatus.success;
}
