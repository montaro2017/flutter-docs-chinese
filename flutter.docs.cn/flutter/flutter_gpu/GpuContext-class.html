GpuContext

GpuContext 类 base

图形上下文的句柄，用于创建和管理 GPU 资源。

若要获取默认图形上下文，请使用 getContext。

属性

defaultColorFormat → PixelFormat
可用于存储四通道颜色（红/绿/蓝/Alpha）的受支持纹理格式：PixelFormat。
无 setter
defaultDepthStencilFormat → PixelFormat
可用于同时存储模板和深度分量的受支持纹理格式：PixelFormat。此方法不会返回仅含深度或仅含模板分量的纹理。
无 setter
defaultStencilFormat → PixelFormat
可用于存储模板信息的受支持纹理格式：PixelFormat。如果没有仅含模板分量的格式，也可能包含深度通道。
无 setter
doesSupportFramebufferRenderMipmap → bool
后端是否可以将纹理的非零 mip 层级附加为渲染目标（参见 ColorAttachment.mipLevel）。始终支持渲染到立方体贴图的面或数组层；此限制仅针对非零 mip 层级。Metal 和 Vulkan 支持此功能；GLES 后端目前不支持，尚未实现对非零 mip 层级的渲染。
无 setter
doesSupportManuallyMippedTextures → bool
手动使用 Texture.overwrite 上传 mip 层级（而非使用 CommandBuffer.generateMipmap 生成）的纹理，是否能按正确的层级进行采样。Metal 和 Vulkan 支持此功能；对于没有 GL_APPLE_texture_max_level 扩展的 OpenGL ES 2.0 设备，此能力为 false，采样此类纹理会得到黑色。依赖手动构建的 mip 链（例如预过滤环境贴图）前，请先检查此项。
无 setter
doesSupportOffscreenMSAA → bool
后端是否支持对离屏颜色和模板附件进行多重采样抗锯齿。部分仅支持 OpenGLES 的设备不支持此功能。
无 setter

maxSamplerAnisotropy → int
设备采样器支持的最大各向异性限制值（参见 SamplerOptions.maxAnisotropy）。
无 setter
minimumUniformByteAlignment → int
