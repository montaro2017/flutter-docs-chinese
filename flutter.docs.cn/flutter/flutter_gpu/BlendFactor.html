BlendFactor

BlendFactor enum

用于缩放混合方程中一个输入值的系数。

为颜色附件启用混合后，片元着色器生成的新颜色（源颜色）会与附件中已有的颜色（目标颜色）合并。两侧的颜色会先分别乘以一个 BlendFactor，再通过 BlendOperation 合并：

result.rgb = (sourceColorFactor * source.rgb) <op> (destinationColorFactor * destination.rgb);
result.a   = (sourceAlphaFactor * source.a)   <op> (destinationAlphaFactor * destination.a);

某些因子引用的“混合颜色”是单独提供给混合方程的常量颜色，与源颜色和目标颜色不同。
