VertexAttribute

VertexAttribute 类 final

描述单个顶点属性：它按名称对应哪个着色器输入、在所属顶点缓冲区元素中的字节偏移量，以及它的格式。

name 必须与所绑定顶点着色器中的 in（或等效阶段输入）声明完全一致。按名称查找属性（而不是使用原始位置索引），可使 Dart 侧布局不易受着色器源码编辑影响；这与通过 Shader.getUniformSlot 按名称解析 uniform 绑定的方式相同。

同一个 VertexBuffer 中的两个属性不能占用重叠的字节范围（也就是说，缓冲区各属性的 [offsetInBytes, offsetInBytes + format.bytesPerElement) 范围必须互不相交）。

构造函数

VertexAttribute({required String name, required VertexFormat format, int offsetInBytes = 0})
