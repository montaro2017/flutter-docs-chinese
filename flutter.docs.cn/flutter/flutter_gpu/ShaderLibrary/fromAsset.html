Future<ShaderLibrary?> fromAsset(
  1. String assetName

加载 assetName 对应的着色器资源包并返回其 ShaderLibrary；如果无法解析资源包，则返回 null。

此方法是异步的，因此适用于所有平台。一些平台只能异步读取资源；为了保持 API 一致，所有平台上的加载操作都采用异步方式。在支持同步读取的平台上，返回的 Future 仍会在当前执行轮次内完成。加载失败会通过 Future 报告，而不会同步抛出。

库会按 assetName 缓存，因此重复加载同一资源会返回相同实例。缓存还用于支持热重载（参见 reinitialize），热重载会按资源路径查找库。

实现

static Future<ShaderLibrary?> fromAsset(String assetName) async {
  final cached = _registry[assetName];
  if (cached != null) {
    return cached;
  }
  final lib = ShaderLibrary._();
  final error = lib._initializeWithAsset(assetName);
  if (error != null) {
    throw Exception("Failed to initialize ShaderLibrary: ${error}");
  }
  _registry[assetName] = lib;
  assert(() {
    _ensureHooksRegistered();
    return true;
  }());
  return lib;
}
