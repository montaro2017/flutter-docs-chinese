通过资源管理器重新获取 assetKey 对应的资源，并将其重新解析到该键的缓存 ShaderLibrary 中，同时将每个着色器标记为脏状态，以便下次构建管线时将其移除并重新注册。主要调用方是驱动热重载的 flutter_tools 服务扩展 ext.ui.gpu.reinitializeShaderLibrary；测试也可直接调用此方法。如果尚未加载 assetKey 对应的库，则不执行任何操作。

assetKey 必须是资源在资源包中的路径，即传给 fromAsset 并列于资源清单中的同一字符串。该路径既是此处的注册表键，也是 flutter_tools 分发的值，两者必须匹配，才能成功重新加载。

实现

static void reinitialize(String assetKey) {
  final ShaderLibrary? lib = _registry[assetKey];
  if (lib == null) {
    // No library for this asset is loaded yet; the next `fromAsset` call
    // will pick up the fresh bytes on its own.
    return;
  }
  final String? error = lib._reinitializeWithAsset(assetKey);
  if (error != null) {
    throw Exception("Failed to reinitialize ShaderLibrary: ${error}");
  }
}
