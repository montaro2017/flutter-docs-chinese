GpuImageSurfaceFrame acquireNextFrame()
重写

获取可用作最终渲染目标的颜色纹理。

返回的 GpuImageSurfaceFrame 持有其 GpuSurfaceFrame.colorTexture 的写入租约。渲染器应将最终颜色结果写入此纹理，然后调用 GpuSurfaceFrame.present。

表面不会返回仍是当前图像、正在等待生产者 GPU 工作完成，或仍被 Flutter 引用的后备纹理。如果没有可保留并复用的后备纹理，表面会再分配一个。

实现

@override
GpuImageSurfaceFrame acquireNextFrame() {
  _checkPreviousPresentSubmitted();
  final Texture texture = Texture._surface(
    _gpuContext,
    _format,
    _width,
    _height,
  );
  final int textureIndex = _acquireNextFrame(texture);
  if (textureIndex < 0) {
    throw Exception('Failed to acquire a Flutter GPU surface frame.');
  }
  texture._valid = true;
  return GpuImageSurfaceFrame._(this, textureIndex, texture);
}
