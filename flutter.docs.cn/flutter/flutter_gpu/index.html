flutter_gpu

gpu 库

Flutter GPU 是一个低级 API，可用于从头构建渲染软件包。

若要使用，请先在 pubspec.yaml 文件中添加 SDK 依赖：

dependencies:
  flutter_gpu:
    sdk: flutter

然后在 Dart 文件中添加导入语句：

import `package:flutter_gpu/gpu.dart`;

另请参阅：

  • Flutter GPU documentation.
