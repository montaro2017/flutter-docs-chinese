Preview 类 base

用于标记返回 widget 预览的函数的注解。

注意：此接口尚不稳定，之后会发生变化。

带有 @Preview() 注解的函数必须公开，并返回 Widget 或 WidgetBuilder。此注解只能用于顶层函数、类中定义的静态方法，以及没有必需参数的公共 Widget 构造函数和工厂构造函数。
link 
@Preview(name: 'Top-level preview')
Widget preview() => const Text('Foo');

@Preview(name: 'Builder preview')
WidgetBuilder builderPreview() {
  return (BuildContext context) {
    return const Text('Builder');
  };
}

class MyWidget extends StatelessWidget {
  @Preview(name: 'Constructor preview')
  const MyWidget.preview({super.key});

  @Preview(name: 'Factory constructor preview')
  factory MyWidget.factoryPreview() => const MyWidget.preview();

  @Preview(name: 'Static preview')
  static Widget previewStatic() => const Text('Static');

  @override
  Widget build(BuildContext context) {
    return const Text('MyWidget');
  }
}

重要说明：提供给 @Preview() 注解的所有值都必须是常量，回调参数也必须是静态且非私有的。在运行时创建 Preview 实例时（包括在 Preview.transform() 中），不受这些限制。

另请参阅：

  • MultiPreview, a base class which allows for creating multiple Previews with a single annotation.
  • flutter.dev/to/widget-previews for details on getting started with widget previews.
