protected top-level constant

Object const protected

用于标注仅应由子类使用的实例成员的注解。

用于标注类或 mixin 中的实例成员；此成员仅应对声明它的库、该类或 mixin 的其他实例成员及其子类型可见。

如果此注解用于字段，也会应用于该字段所隐式生成的 getter，以及适用时生成的 setter。

表示类或 mixin C 中被标注的实例成员（方法、getter、setter、运算符或字段）m 只能在特定位置引用。在声明 C 的库中引用是有效的。此外，在 C 的实例成员中，或在扩展、实现或混入 C 的类（直接或间接）中，或在以 C 为超类约束的 mixin 中引用也有效。在适用于 C 的 extension 的实例成员中引用同样有效。

此外，引用 m 的 C 实例也有限制：对 m 的引用必须位于声明 C 的同一库中，或必须引用 this.m（显式或隐式），而不能引用 C 的其他实例上的 m。

analyzer 等工具可在以下情况下提供反馈：

  • the annotation is associated with anything other than an instance member,
  • a reference to a member m which has this annotation, declared in a class or mixin C, is found outside of the declaring library and outside of an instance member in any class that extends, implements, or mixes in C or any mixin that uses C as a superclass constraint, or
  • a reference to a member m which has this annotation, declared in a class or mixin C, is found outside of the declaring library and the receiver is something other than this.
