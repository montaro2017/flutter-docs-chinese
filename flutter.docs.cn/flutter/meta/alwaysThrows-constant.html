Object const alwaysThrows

用于标记始终会抛出异常的函数的注解。

用于标注函数，表示该函数始终会抛出异常。重写了此类已标注函数的任何实例成员，也应遵守这一约定。

在 Dart 2.0 之前的代码中，analyzer 等工具可借此判断代码块是否会“退出”。例如：

@alwaysThrows toss() { throw 'Thrown'; }

int fn(bool b) {
  if (b) {
    return 0;
  } else {
    toss();
    print("Hello.");
  }
}

如果没有在 toss 上添加此注解，看起来 fn 似乎并非始终返回值。此注解表明 fn 确实总会退出。此外，注解还表明调用 toss 后的任何语句（例如 print 调用）都是死代码。

工具也可以要求遵守此约定；也就是说，如果带有此注解的函数并非始终抛出异常，工具可以发出警告。

已弃用：此注解已弃用，并计划在未来版本的 package:meta 中移除。在 Dart 2.9 及更高版本中，可以改用 Never 返回类型来表示函数永不返回。
