experimental

experimental top-level constant

Object const experimental

用于标记声明具有实验性且可能发生变化的注解。

用于标注库，或库公开接口中的声明（例如顶层成员、类成员和函数参数），表示此 API 处于实验阶段，可能随时被移除或修改；即使这通常会构成破坏性变更，也无需更新所属 package 的版本。

如果将此注解应用于库，其效果等同于将注解应用于该库的所有顶层成员。将注解应用于类时，子类不会自动继承此注解，但该类的成员会应用此注解。

analyzer 等工具可在以下情况下提供反馈：

  • 此注解关联的声明不属于库的公共接口（例如局部变量或私有声明），或者它关联的是库中第一条指令以外的其他指令；或者
  • 该声明被某个包引用，而该包尚未明确表示有意使用实验性 API（详情待定）。

实现

const Object experimental = _Experimental();
