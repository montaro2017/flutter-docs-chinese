visibleForOverriding top-level constant

Object const visibleForOverriding

用于标注不应在所属 package 之外使用的声明的注解。

用于标注被设为公开以便重写、但不应在定义它的库之外引用的实例成员。

analyzer 等工具可在以下情况下提供反馈：

  • 该注解关联的声明不是类或 mixin 中的公开实例成员，或
  • 该成员在其定义所在的库之外被引用。
