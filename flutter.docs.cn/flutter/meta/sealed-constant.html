sealed top-level constant

Object const sealed

用于标注不得在所属 package 之外创建子类的类的注解。

与被标注类位于同一 package 的类仍可照常扩展、实现或混入该类。

analyzer 等工具可在以下情况下提供反馈：

  • 注解关联的对象不是类，
  • 注解关联了类 C，且存在类或 mixin D，它会扩展、实现、混入或约束为 C；同时 C 和 D 声明在不同的包中。

注意：在 Dart 3 及更高版本中，可以使用内置类修饰符控制当前库之外允许进行哪些形式的子类型化。有关如何使用类修饰符的详细信息，请参阅 Class modifiers 文档。
