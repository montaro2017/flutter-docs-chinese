创建一个 Int32List 视图，用于查看 data 中一段元素范围。

创建 data.buffer 中与 data 从 start 到 end 的元素相对应范围的视图。如果 data 是 Uint16List 这类类型化数据列表，则视图包含索引从 start 到 end 的元素所占用的字节。如果 data 是 ByteData，则将其视为字节列表。

如果提供了 start 和 end，它们必须满足：

0 ≤ start ≤ end ≤ elementCount

其中 elementCount 是 data 中的元素数量；对于类型化数据列表，它等于 List.length。

如果省略，start 默认为零，end 默认为 elementCount。

所查看字节范围的起始和结束索引必须是 4 的倍数。

实现

factory Int32List.sublistView(TypedData data, [int start = 0, int? end]) {
  int elementSize = data.elementSizeInBytes;
  end = RangeError.checkValidRange(
    start,
    end,
    data.lengthInBytes ~/ elementSize,
  );
  int byteLength = (end - start) * elementSize;
  if (byteLength % bytesPerElement != 0) {
    throw ArgumentError(
      "The number of bytes to view must be a multiple of " +
          "$bytesPerElement",
    );
  }
  return data.buffer.asInt32List(
    data.offsetInBytes + start * elementSize,
    byteLength ~/ bytesPerElement,
  );
}
