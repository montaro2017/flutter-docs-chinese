Int32x4

Int32x4 类 抽象 final

Int32x4 类型及其运算。

Int32x4 使用“通道”存储 4 个 32 位位掩码，通道依次称为“x”、“y”、“z”和“w”。

select(Float32x4 trueValue, Float32x4 falseValue) → Float32x4
合并 trueValue 与 falseValue，以此 Int32x4 作为位掩码：选择 trueValue 的对应位（该 Int32x4 中的位为 1 时）；选择 falseValue 的对应位（该 Int32x4 中的位为 0 时）。
shuffle(int mask) → Int32x4
打乱各通道的值。mask 必须是 256 个 shuffle 常量之一。
shuffleMix(Int32x4 other, int mask) → Int32x4
打乱此 Int32x4 和 other 的 lane 值。返回的 Int32x4 会以此 Int32x4 作为 XY 通道，并以 other 作为 ZW 通道。使用 mask，其规则与 shuffle 相同。
