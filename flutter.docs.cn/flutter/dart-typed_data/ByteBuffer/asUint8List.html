Uint8List asUint8List([
  1. int offsetInBytes = 0,
  2. int? length
])

创建此字节缓冲区某一区域的 Uint8List视图。

此视图由该字节缓冲区中的字节提供后备存储。对 Uint8List 所做的任何更改也会反映到缓冲区中，反之亦然。

视图区域从 offsetInBytes 开始，包含 length 个字节。如果省略 length，则范围延伸至缓冲区末尾。

起始索引和长度必须指定缓冲区中的有效范围：

  • offsetInBytes 不得为负数，
  • length 不得为负数，且
  • offsetInBytes + length 不得大于 lengthInBytes。
