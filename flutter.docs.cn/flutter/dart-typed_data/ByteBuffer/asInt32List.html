Int32List asInt32List([
  1. int offsetInBytes = 0,
  2. int? length
])

创建此字节缓冲区某一区域的 Int32List视图。

此视图由该字节缓冲区中的字节提供后备存储。对 Int32List 所做的任何更改也会反映到缓冲区中，反之亦然。

视图区域从 offsetInBytes 开始，该偏移必须按 32 位对齐；区域包含 length 个 32 位整数，其字节序与主机相同（Endian.host）。如果省略 length，范围会尽可能延伸至缓冲区末尾；如果 lengthInBytes 不能被 四 整除，末尾字节将无法包含在视图中。

起始索引和长度必须指定缓冲区中有效的 32 位对齐范围：

  • offsetInBytes must not be negative,
  • offsetInBytes must be divisible by four,
  • length must not be negative, and
  • offsetInBytes + length * 4 must not be greater than lengthInBytes.

实现
