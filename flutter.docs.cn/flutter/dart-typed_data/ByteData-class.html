ByteData

ByteData 类 抽象 final

固定长度、可随机访问的字节序列，也可随机且不对齐地访问这些字节所表示的定宽整数和浮点数。

ByteData 可用于打包和解包外部来源的数据（例如网络或文件系统），并且比普通 List 实现更高效地处理大量数值数据。它既可通过省去对象头节省空间，也可通过 ByteData 避免复制数据来节省时间。

如果数据以字节形式传入，可以通过共享同一个缓冲区将其转换为 ByteData。

Uint8List bytes = ...;
var blob = ByteData.sublistView(bytes);
if (blob.getUint32(0, Endian.little) == 0x04034b50) { // Zip file marker
  ...
}

此外，ByteData 还可用于有意将表示一种算术类型的字节重新解释为另一种类型。例如，以下代码片段会确定一个 32 位浮点数（以大端序存储）所对应的 32 位有符号整数：

var bdata = ByteData(8);
bdata.setFloat32(0, 3.04);
int huh = bdata.getInt32(0); // 0x40428f5c

类尝试继承或实现 ByteData 会导致编译时错误。
