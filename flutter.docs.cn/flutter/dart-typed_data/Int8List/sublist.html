sublist abstract 方法

Int8List sublist(
  1. int start, [
  2. int? end
])
重写

创建一个新列表，包含 start 与 end 之间的元素。

新列表是一个 Int8List，包含此列表中位置大于或等于 start 且小于 end 的元素，并保持原有顺序。

var numbers = Int8List.fromList([0, 1, 2, 3, 4]);
print(numbers.sublist(1, 3)); // [1, 2]
print(numbers.sublist(1, 3).runtimeType); // Int8List

如果省略 end，则默认为此列表的 length。

print(numbers.sublist(1)); // [1, 2, 3, 4]

start 和 end 位置必须满足以下关系：0 ≤ start ≤ end ≤ this.length。如果 end 等于 start，则返回空列表。
