Float32x4

Float32x4 类 抽象 final

四个 32 位浮点数。

Float32x4 使用“通道”存储四个 32 位浮点数，通道依次命名为 x、y、z 和 w。

可以对一个或多个 Float32x4 中的多个值执行单次运算。该运算会分别作用于操作数的每个通道，并生成一个新的 Float32x4（或类似的多值）结果，其中包含各通道的运算结果。

Float32x4 类不可被继承或实现。
