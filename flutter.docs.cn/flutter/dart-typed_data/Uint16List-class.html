Uint16List

Uint16List 类 抽象 final

可视为 TypedData 的 16 位无符号整数定长列表。

对于较长的列表，此实现相比默认的 List 实现，在空间和时间效率上都可能高出许多。

存储到列表中的整数会截断为低 16 位，并按无符号 16 位整数解释，取值范围为 0 到 65535。

类若尝试扩展或实现 Uint16List，会产生编译时错误。

实现的类型
  • TypedDataList<int>
Available extensions

  • Uint16ListAddress
  • Uint16ListToJSUint16Array
