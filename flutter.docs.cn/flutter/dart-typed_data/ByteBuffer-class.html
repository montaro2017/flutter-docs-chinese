ByteBuffer

ByteBuffer 类 抽象 final

构成类型化数据对象底层存储的一段字节序列。

可通过类型化视图更高效地处理大量二进制或数值数据。

类尝试继承或实现 ByteBuffer 会导致编译时错误。

Available extensions
  • ByteBufferToJSArrayBuffer
