Static Methods

alphaBlend(Vector4 foreground, Vector4 background, Vector4 result) → void
将前景色 foreground 混合到背景色 background 上，并将结果存入 result。
fromHexString(String value, Vector4 result) → void
将格式为“#FF0F00”、“#FFFF0F00”、“#FF0”或“#FFF0”的颜色字符串（可带或不带前导“#”，且不区分大小写）转换为对应的颜色值，并存入 result。如果传入的 value 包含四组字符，则第一组会作为 alpha 通道处理。
fromRgba(int r, int g, int b, int a, Vector4 result) → void
将分量 r、g、b 和 a 介于 0 到 255 之间的颜色转换为分量值介于 0.0 到 1.0 之间的颜色，并存入 result。
gammaToLinear(Vector4 gammaColor, Vector4 linearColor, [double gamma = 2.2]) → void
将 gammaColor 从伽马空间转换到线性颜色空间，并将结果存入 linearColor。也可以指定可选参数 gamma，默认值为 2.2。
hslToRgb(Vector4 hslColor, Vector4 rgbColor) → void
将 hslColor 从色相、饱和度和亮度（HSL）颜色模型转换为 RGB 颜色模型，并存入 rgbColor。
hsvToRgb(Vector4 hsvColor, Vector4 rgbColor) → void
将 hsvColor 从色相、饱和度和值（HSV）颜色模型转换为 RGB 颜色模型，并存入 rgbColor。
linearToGamma(Vector4 linearColor, Vector4 gammaColor, [double gamma = 2.2]) → void
将 linearColor 从线性空间转换到伽马颜色空间，并将结果存入 gammaColor。也可以指定可选参数 gamma，默认值为 2.2。
rgbToHsl(Vector4 rgbColor, Vector4 hslColor) → void
将 rgbColor 从 RGB 颜色模型转换为色相、饱和度和亮度（HSL）颜色模型，并存入 hslColor。
rgbToHsv(Vector4 rgbColor, Vector4 hsvColor) → void
将 rgbColor 从 RGB 颜色模型转换为色相、饱和度和值（HSV）颜色模型，并存入 hsvColor。
toGrayscale(Vector4 input, Vector4 result) → void
将颜色 input 转换为灰度颜色，并将其存入 result。
toHexString(Vector4 input, {bool alpha = false, bool short = false}) → String
将颜色 input 转换为不带前导“#”的十六进制字符串。若要包含 alpha 通道，请将 alpha 设为 true；默认值为 false。如果 short 为 true，生成的十六进制字符串也可能采用简写形式，例如 #ff0（默认值为 false）。
