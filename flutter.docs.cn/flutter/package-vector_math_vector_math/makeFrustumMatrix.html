构造新的 OpenGL 透视投影矩阵。

left 和 right 指定左右垂直裁剪面的坐标。bottom 和 top 指定上下水平裁剪面的坐标。near 和 far 指定近、远深度裁剪面的坐标。

实现

Matrix4 makeFrustumMatrix(
  double left,
  double right,
  double bottom,
  double top,
  double near,
  double far,
) {
  final view = Matrix4.zero();
  setFrustumMatrix(view, left, right, bottom, top, near, far);
  return view;
}
