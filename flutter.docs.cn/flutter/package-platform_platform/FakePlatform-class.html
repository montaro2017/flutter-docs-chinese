FakePlatform

FakePlatform 类 final

已弃用的 Platform 接口的可变实现。

警告

测试非弃用 API 时，请使用 package:platform/testing.dart，并使用 TestNativePlatform 为原生平台属性提供自定义值。

实现的类型

Available extensions
  • PlatformIsOS
注解
