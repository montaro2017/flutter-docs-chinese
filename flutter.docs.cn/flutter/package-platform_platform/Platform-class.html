Platform

Platform 类 抽象 final

Dart 运行时的平台信息。

提供有关当前运行时环境的信息。

如果以原生代码运行，nativePlatform 对象将非 null，并提供该平台的信息，包括 NativePlatform.operatingSystem 名称。

如果在浏览器中运行，browserPlatform 对象将非 null，并提供浏览器信息。
