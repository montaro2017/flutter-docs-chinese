TestNativePlatform

TestNativePlatform 类 final

用于测试的自定义 NativePlatform。

构造函数可以不设置个别属性。读取未设置的属性会抛出异常；但如果测试不使用这些属性，就不必为它们提供值。

此类不应在生产环境中使用，因为它会降低编译器对 NativePlatform.operatingSystem 值或 NativePlatform.isLinux 等检查结果的预测能力，从而可能生成更大的程序。
