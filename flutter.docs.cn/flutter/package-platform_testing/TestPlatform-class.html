TestPlatform

TestPlatform 类 final

用于测试的自定义 Dart runtime 平台信息。

此类实现了 Platform，但允许使用 TestBrowserPlatform 或 TestNativePlatform 作为非 null 的平台对象。

实现的类型
  • Platform
Available extensions
  • PlatformIsOS
注解
  • @visibleForTesting
