使用 SyncHttpRequestClient 创建新的同步 WebDriver。

此操作会引入对 dart:io 的依赖。
注意：WebDriver 端点将通过对 uri 调用 resolve 来构造。因此，如果 uri 不以斜杠结尾，最后一个路径部分将被移除。

实现

core.WebDriver createDriver(
        {Uri? uri,
        Map<String, dynamic>? desired,
        core.WebDriverSpec spec = core.WebDriverSpec.Auto,
        Map<String, String> webDriverHeaders = const {}}) =>
    core.createDriver(
        (prefix) => SyncHttpRequestClient(prefix, headers: webDriverHeaders),
        uri: uri,
        desired: desired,
        spec: spec);
