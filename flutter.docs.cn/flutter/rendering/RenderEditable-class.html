RenderEditable
description

RenderEditable 类

在可滚动容器中显示文本，并可显示闪烁光标和手势识别器。

这是可编辑文本字段的渲染器。它本身不直接提供文本编辑操作，但会处理文本选区和光标操作。

文本 text 会按照给定的 offset 滚动，并根据 textAlign 对齐。maxLines 属性控制文本显示为一行还是多行。如果 selection 未折叠，则会使用 selectionColor 绘制选区；如果选区已折叠，则表示光标位置。当 showCursor 为 true 时显示光标，并使用 cursorColor 绘制光标。

键盘处理、输入法处理、滚动、切换 showCursor 值以实际实现光标闪烁，以及上文未提及的其他功能，均由更高层负责，不由此对象处理。
