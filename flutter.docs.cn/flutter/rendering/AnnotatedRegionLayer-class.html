AnnotatedRegionLayer
description

AnnotatedRegionLayer<T extends Object> 类

一种合成图层，会为其子级附加一个值。将此图层推入图层树是添加注解的常见方式。

注解是可选的任意类型对象。将其附加到图层后，可以使用位置通过 Layer.find 或 Layer.findAllAnnotations 检索。搜索会递归进行，并受注解类型的透明性概念控制；相关说明请参阅 Layer.findAnnotations 文档。

收到注解搜索请求时，此图层会根据各子级的透明性，将相同的搜索委托给每个子级。之后，只有满足以下所有条件时，才会添加此图层自己的注解：

  • 目标类型必须与注解类型 T 完全相同。
  • 如果提供了 size，目标位置必须位于由 size 和 offset 形成的矩形内。

如果任一子级对某种注解类型不透明，或者 opaque 为 true 且已添加此图层的注解，则此图层对该注解类型不透明。
