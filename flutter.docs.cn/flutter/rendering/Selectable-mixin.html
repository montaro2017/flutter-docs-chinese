Selectable mixin

位于 SelectionArea widget 下时，可供用户选择的 mixin。

此对象接收选择事件，其 value 必须反映此 Selectable 当前的选区。value 发生变化时，此对象还必须通知监听器。

此对象负责绘制选区高亮。

若要接收选择事件，此 mixin 必须向 SelectionRegistrar 注册自身。使用 SelectionContainer.maybeOf 获取选择注册器，并混入 SelectionRegistrant，即可自动订阅 SelectionRegistrar。

此 mixin 通常会混入 RenderObject。RenderObject.paint 方法负责推送传递给 pushHandleLayers 的 LayerLink。

此类将 SelectionGeometry 作为其 value 返回；接收到选择事件并导致选区几何信息发生变化时，还负责通知监听器。

另请参阅：

  • SelectableRegion, which provides an overview of selection system.
