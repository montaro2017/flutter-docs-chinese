ImageFilterConfig.blur 构造函数

const ImageFilterConfig.blur({
  1. double sigmaX,
  2. double sigmaY,
  3. TileMode tileMode,

})

创建一个高斯模糊配置。

sigmaX 和 sigmaY 参数分别表示高斯核在 x 和 y 方向上的标准差。

tileMode 参数决定模糊效果如何处理边缘。

bounded 参数（默认值为 false）用于控制采样策略：

  • If false, the filter is applied to the entire canvas using standard sampling.
  • If true, the filter performs a "bounded blur", typically used to replicate the high-fidelity frosted-glass effect seen on iOS.

在“有界模糊”模式下，高斯核只会从对象的边界矩形内部采样。边界以外的像素会被视为透明，并对结果进行归一化，以确保边缘保持完全不透明。此模式可防止相邻内容的颜色渗入。

与底层 API ui.ImageFilter.blur 不同，此构造函数不需要显式提供 Rect。由于 ImageFilterConfig 在绘制阶段解析，它会自动使用 ImageFilterContext 提供的 Rect 边界。这样无需手动管理坐标，效果就能与布局保持同步。

此模式只限制模糊的采样来源，不会裁剪输出。通常应将它与裁剪组件（例如 ClipRect）配合使用，以免在对象边界之外看到模糊伪影。
