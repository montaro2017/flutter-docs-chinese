void pushLayer(
  1. ContainerLayer childLayer,
  2. PaintingContextCallback painter,
  3. Offset offset, {
  4. Rect? childPaintBounds,
})

将给定图层追加到录制内容中，并使用该图层调用 painter 回调，同时将 childPaintBounds 作为子项的估算绘制边界提供给回调。childPaintBounds 可用于调试，但不会影响绘制。

给定图层必须是尚未附加的孤立图层。（提供新创建的对象而不是复用现有图层，即可满足此要求。）

offset 是传递给 painter 的偏移量，特别要注意，它并非应用于图层本身的偏移量。概念上，图层默认没有位置或尺寸，但可以变换其内容。例如，OffsetLayer 会对其子项应用偏移。

如果未指定 childPaintBounds，则会使用当前图层的绘制边界。当子图层不会对其内容应用任何变换或裁剪时，这样做是合适的。如果指定了 childPaintBounds，它必须采用新图层的坐标系（即该图层对内容应用变换后，其子项所看到的坐标系），并且不应超出当前图层的绘制边界。

另请参阅：

  • addLayer, 用于推入图层，但不在其中继续绘制内容。

实现

void pushLayer(
  ContainerLayer childLayer,
  PaintingContextCallback painter,
  Offset offset, {
  Rect? childPaintBounds,
}) {
  // If a layer is being reused, it may already contain children. We remove
  // them so that `painter` can add children that are relevant for this frame.
  if (childLayer.hasChildren) {
    childLayer.removeAllChildren();
  }
  stopRecordingIfNeeded();
  appendLayer(childLayer);
  final PaintingContext childContext = createChildContext(
    childLayer,
    childPaintBounds ?? estimatedBounds,
  );

  painter(childContext, offset);
  childContext.stopRecordingIfNeeded();
}
