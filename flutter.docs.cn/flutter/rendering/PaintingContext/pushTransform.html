使用矩阵变换继续绘制内容。

needsCompositing 参数表示子项是否需要合成。通常，该值与调用方的 RenderObject.needsCompositing 相同。如果为 false，此方法会返回 null，表示不再需要图层。若调用此方法的渲染对象将 oldLayer 存储在其 RenderObject.layer 字段中，则应将该字段设为 null。

当 needsCompositing 为 false 时，此方法会使用比实际创建图层更高效的方式应用图层效果。

offset 参数是传递给 painter 的偏移量，也是 transform 所用原点的偏移量。

transform 参数是调用 painter 时用于变换坐标系的 Matrix4。其中不应包含 offset。该变换实际上会在应用 offset 后应用。

调用 pushTransform 期间会同步调用 painter 回调，并在回调执行期间应用 transform。

oldLayer 参数应指定上一帧创建的图层，以便向引擎提供更多信息进行性能优化。通常，该值是渲染对象创建一次后在后续帧中持续复用的 RenderObject.layer，直到不再需要图层（例如渲染对象不再需要合成），或渲染对象更改图层类型（例如从透明度图层改为矩形裁剪图层）。

实现

TransformLayer? pushTransform(
  bool needsCompositing,
  Offset offset,
  Matrix4 transform,
  PaintingContextCallback painter, {
  TransformLayer? oldLayer,
}) {
  final effectiveTransform = Matrix4.translationValues(offset.dx, offset.dy, 0.0)
    ..multiply(transform)
    ..translateByDouble(-offset.dx, -offset.dy, 0, 1);
  if (needsCompositing) {
    final TransformLayer layer = oldLayer ?? TransformLayer();
    layer.transform = effectiveTransform;
    pushLayer(
      layer,
      painter,
      offset,
      childPaintBounds: MatrixUtils.inverseTransformRect(effectiveTransform, estimatedBounds),
    );
    return layer;
  } else {
    canvas
      ..save()
      ..transform(effectiveTransform.storage);
    painter(this, offset);
    canvas.restore();
    return null;
  }
}
