继续绘制内容，并将其与颜色滤镜混合。

offset 是传递给 painter 的偏移量，特别要注意，它并非应用于图层本身的偏移量。概念上，图层默认没有位置或尺寸，但可以变换其内容。例如，OffsetLayer 会对其子项应用偏移。

colorFilter 参数是混合 painter 绘制内容时使用的 ColorFilter 值。

调用 pushColorFilter 期间会同步调用 painter 回调，并在回调执行期间应用 colorFilter。

oldLayer 参数应指定上一帧创建的图层，以便向引擎提供更多信息进行性能优化。通常，该值是渲染对象创建一次后在后续帧中持续复用的 RenderObject.layer，直到不再需要图层（例如渲染对象不再需要合成），或渲染对象更改图层类型（例如从透明度图层改为矩形裁剪图层）。

调用此函数的 RenderObject 很可能需要让其 RenderObject.alwaysNeedsCompositing 属性返回 true。这样会告知祖先渲染对象此渲染对象将包含一个合成图层，例如促使祖先使用合成裁剪。

实现

ColorFilterLayer pushColorFilter(
  Offset offset,
  ColorFilter colorFilter,
  PaintingContextCallback painter, {
  ColorFilterLayer? oldLayer,
}) {
  final ColorFilterLayer layer = oldLayer ?? ColorFilterLayer();
  layer.colorFilter = colorFilter;
  pushLayer(layer, painter, offset);
  return layer;
}
