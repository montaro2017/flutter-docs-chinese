dispose 方法

  1. @重写
void dispose()
重写

清除此图层持有的所有保留资源。

此方法必须释放 ui.EngineLayer 和 ui.Picture 等资源。调用后图层仍可使用，但它持有的所有图形相关资源都需要重新创建。

此方法只释放此图层自身的资源。例如，如果它是 ContainerLayer，则不会释放任何子级的资源。不过，调用此方法时，ContainerLayer 会移除其所有子级；如果此图层是某个已移除子级句柄的最后持有者，该子级可能会递归清理自身资源。

所有尚未释放的 LayerHandle 都释放后，会自动调用此方法。LayerHandle 对象通常由此图层的 parent 图层，以及参与创建此图层的 RenderObject 持有。

调用此方法后，此对象将无法再使用。

实现

@override
void dispose() {
  removeAllChildren();
  _callbacks.clear();
  super.dispose();
}
