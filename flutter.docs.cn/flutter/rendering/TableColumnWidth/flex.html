flex 方法

double? flex(
  1. Iterable<RenderBox> cells
)

布局表格时若有剩余空间，则应用于单元格的 flex 因子。剩余空间会按各列的 flex 值比例分配给具有 flex 值的列（值越大，分配的空间越多）。

cells 参数是一个可迭代对象，提供此列中的所有单元格。遍历单元格按定义属于 O(N) 操作，因此执行此类操作的算法应视为开销较大。
