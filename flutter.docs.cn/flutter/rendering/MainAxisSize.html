MainAxisSize enum

主轴上应占用多少空间。

弹性布局期间，可用的主轴空间会分配给子项。分配后可能仍有剩余空间。此值用于控制在传入布局约束允许的范围内，是尽量增大还是减小剩余空闲空间。

另请参阅：

  • Column, Row, and Flex, 弹性布局 widget。
  • Expanded 和 Flexible, the widgets that controls a flex widgets' children's flex.
  • RenderFlex, 弹性布局 render object。
  • MainAxisAlignment, 用于控制如何分配剩余空间。

Values

min → const MainAxisSize

在满足传入布局约束的前提下，尽量减少主轴方向的空闲空间。

如果传入的布局约束具有足够大的 BoxConstraints.minWidth 或 BoxConstraints.minHeight，仍可能存在非零空闲空间。

如果传入的布局约束没有上限，且任一子级具有非零的 FlexParentData.flex 和 FlexFit.tight 适配方式（由 Expanded 应用），RenderFlex 会触发断言，因为剩余空闲空间将是无限的，而盒子不能具有无限尺寸。

max → const MainAxisSize

在满足传入布局约束的前提下，尽量增大主轴方向的空闲空间。

如果传入的布局约束具有足够小的 BoxConstraints.maxWidth 或 BoxConstraints.maxHeight，可能仍没有空闲空间。

如果传入的布局约束没有上限，RenderFlex 会触发断言，因为剩余空闲空间将是无限的，而盒子不能具有无限尺寸。
