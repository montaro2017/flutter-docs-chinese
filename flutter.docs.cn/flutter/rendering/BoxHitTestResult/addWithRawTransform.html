addWithRawTransform 方法

bool addWithRawTransform({
  1. required Matrix4? transform,
  2. required Offset position,
  3. required BoxHitTest hitTest,
})

将 position 转换到子对象的局部坐标系，以便对该子对象执行命中测试。

必须在提供的 hitTest 回调中实现对子对象的实际命中测试；调用回调时，会将变换后的 position 作为参数传入。

与 addWithPaintTransform 不同，此处提供的 transform 矩阵会直接用于变换 position，不会经过任何预处理。

如果 transform 为 null，则按恒等变换处理，并将 position 原样传给 hitTest 回调。

此函数返回 hitTest 回调的返回值。

另请参阅：

  • addWithPaintTransform, 作用相同，但接收绘制变换矩阵。

实现

bool addWithRawTransform({
  required Matrix4? transform,
  required Offset position,
  required BoxHitTest hitTest,
}) {
  final Offset transformedPosition = transform == null
      ? position
      : MatrixUtils.transformPoint(transform, position);
  if (transform != null) {
    pushTransform(transform);
  }
  final bool isHit = hitTest(this, transformedPosition);
  if (transform != null) {
    popTransform();
  }
  return isHit;
}
