endOffset 属性

int endOffset
final

相对于内容起点的选区终点。

例如，Text widget 的内容采用 TextSpan 树的形式。

以下是一个 Text widget 及其 TextSpan 树：

link 
const Text.rich(
  TextSpan(
    text: 'Hello world, ',
    children: <InlineSpan>[
      WidgetSpan(
        child: Text('how are you today? '),
      ),
      TextSpan(
        text: 'Good, thanks for asking.',
      ),
    ],
  ),
)

如果选区从“world”开头延伸到 TextSpan 树末尾的句点“.”，则 SelectionHandler.getSelection 返回的 SelectedContentRange 相对于 TextSpan 树的文本，且 WidgetSpan 的内容会被展平。startOffset 为 6，endOffset 为 56。这会计入 WidgetSpan 中长度为 19 的内容，因此整体内容长度为 56。
