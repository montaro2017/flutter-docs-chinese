IntrinsicColumnWidth 类

根据该列所有单元格的固有尺寸确定列宽。

这是一种开销非常大的列宽计算方式。

可以提供一个弹性值。如果指定了该值且不为 null，那么所有非弹性列确定尺寸后，此列会参与剩余空间的分配。

flex(Iterable<RenderBox> cells) → double?
布局表格时，如果还有剩余空间，则应用于单元格的 flex 系数。剩余空间会按 flex 值的比例分配给设置了 flex 的列（flex 值越大，分配的空间越多）。
重写
maxIntrinsicWidth(Iterable<RenderBox> cells, double containerWidth) → double
该列应具有的理想宽度。此值必须大于或等于 minIntrinsicWidth。列宽可能超过此值，例如列具有弹性，或表格宽度被强制设为大于所有 maxIntrinsicWidth 值之和。
