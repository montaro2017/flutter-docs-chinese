CustomPainterSemantics 类

包含相关属性，用于描述 CustomPaint 使用的 Canvas 上某个矩形内绘制的信息。

例如，辅助技术会使用这些信息来提升应用的无障碍体验。

应实现 CustomPainter.semanticsBuilder，为 CustomPaint 绘制的整幅图像构建语义描述，而不是只描述其中某个矩形。

另请参阅：

  • SemanticsNode, which is created using the properties of this class.
  • CustomPainter, which creates instances of this class.
