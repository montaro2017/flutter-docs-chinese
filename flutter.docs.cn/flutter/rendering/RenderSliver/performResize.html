重写

仅使用约束更新渲染对象的尺寸。

不要直接调用此函数，应改为调用 layout。只有在布局期间此渲染对象确实需要执行工作时，layout 才会调用此函数。父对象提供的布局约束可通过 constraints getter 获取。

仅当 sizedByParent 为 true 时才会调用此函数。

将 sizedByParent 设为 true 的子类应重写此方法以计算自身尺寸。RenderBox 的子类可考虑改为重写 RenderBox.computeDryLayout。

  assert(false);
