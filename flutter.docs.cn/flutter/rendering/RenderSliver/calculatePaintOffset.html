calculatePaintOffset 方法

double calculatePaintOffset(
  1. SliverConstraints constraints, {
  2. required double from,
  3. required double to,
})

计算从 from 到 to 的区域中可见的部分。此计算假设可见区域仅从 SliverConstraints.scrollOffset 起，延伸至 SliverConstraints.remainingPaintExtent 所表示的长度，并且滚动偏移量与绘制偏移量呈线性关系。

例如，如果约束的滚动偏移量为 100、剩余绘制范围为 100，而此方法的参数描述区域 50..150，那么返回值将为 50（即从滚动偏移量 100 到 150 的部分）。

如果已消耗的滚动偏移量与已消耗的绘制范围之间并非一一对应，此方法就没有用处。例如，如果 sliver 始终绘制相同的范围，但其消耗的滚动偏移范围与 SliverConstraints.scrollOffset 成正比，那么此函数的结果将不一致。

实现

// This could be a static method but isn't, because it would be less convenient
// to call it from subclasses if it was.
double calculatePaintOffset(
  SliverConstraints constraints, {
  required double from,
  required double to,
}) {
  assert(from <= to);
  final double a = constraints.scrollOffset;
  final double b = constraints.scrollOffset + constraints.remainingPaintExtent;
  // the clamp on the next line is to avoid floating point rounding errors
  return clampDouble(
    clampDouble(to, a, b) - clampDouble(from, a, b),
    0.0,
    constraints.remainingPaintExtent,
  );
}
