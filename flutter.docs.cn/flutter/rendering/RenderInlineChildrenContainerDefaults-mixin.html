RenderInlineChildrenContainerDefaults mixin

A mixin that provides useful default behaviors for text RenderBoxes (RenderParagraph 和 RenderEditable for example) with inline content children managed by the ContainerRenderObjectMixin mixin.

此 mixin 假定由 ContainerRenderObjectMixin mixin 管理的每个子项都对应一个 PlaceholderSpan，并按照文本的逻辑顺序排列（即用户阅读文本时遇到各 PlaceholderSpan 的顺序）。

若要在 RenderBox 类中使用此 mixin：

  • Call layoutInlineChildren in the performLayout 和 computeDryLayout implementation, and during intrinsic size calculations, to get the size information of the inline widgets as a List of PlaceholderDimensions. Determine the positioning of the inline widgets (which is usually done by a TextPainter using its line break algorithm).

  • 使用内联 widget 的定位信息调用 positionInlineChildren。

  • 实现 RenderBox.applyPaintTransform，也可以使用 defaultApplyPaintTransform。

  • 在 RenderBox.paint 中调用 paintInlineChildren，以绘制内联 widget。

  • 在 RenderBox.hitTestChildren 中调用 hitTestInlineChildren，以对内联 widget 执行命中测试。

另请参阅：

  • WidgetSpan.extractFromInlineSpan, a helper function for extracting WidgetSpans from an InlineSpan tree.
Superclass constraints
  • RenderBox
  • ContainerRenderObjectMixin<RenderBox, TextParentData>
Mixin applications
  • RenderEditable
  • RenderParagraph
