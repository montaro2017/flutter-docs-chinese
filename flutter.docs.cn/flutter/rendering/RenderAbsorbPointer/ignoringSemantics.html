ignoringSemantics 属性

  1. @Deprecated('Use ExcludeSemantics or create a custom absorb pointer widget instead. ' 'This feature was deprecated after v3.8.0-12.0.pre.')
bool? get ignoringSemantics

构建语义树时，是否忽略此渲染对象的语义信息。

不建议使用 ignoringSemantics，该用法已弃用。此属性是在 v3.8.0-12.0.pre 之前引入的，用于绕过 IgnorePointer 及相关组件的语义行为。

在该版本之前，如果 absorbing 为 true，整个语义子树都会被丢弃。开发者只能使用 ignoringSemantics 来保留语义子树。

在该版本之后，即使将 absorbing 设为 true，也只会阻止语义子树中的用户操作，其他 SemanticsProperties 仍会保留。因此不再需要 ignoringSemantics。

如果 ignoringSemantics 为 true，语义子树就会被丢弃，因此辅助技术将无法访问该子树。

如果 ignoringSemantics 为 false，则照常收集语义子树。

有关语义树的更多信息，请参阅 SemanticsNode。

实现

set ignoringSemantics(bool? value) {
  if (value == _ignoringSemantics) {
    return;
  }
  _ignoringSemantics = value;
  markNeedsSemanticsUpdate();
}
