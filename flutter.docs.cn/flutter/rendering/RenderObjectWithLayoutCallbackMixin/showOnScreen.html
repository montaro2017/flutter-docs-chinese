尝试让此 RenderObject 或其后代的一部分或全部显示在屏幕上。

如果提供了 descendant，则会让该 RenderObject 显示出来。如果省略 descendant，则会让此 RenderObject 显示出来。

可选参数 rect 用于描述应在屏幕上显示该 RenderObject 的哪个区域。如果 rect 为 null，则会显示整个 RenderObject（由其 paintBounds 定义）。如果提供了 descendant 参数，rect 会相对于该后代的坐标系解释；否则相对于此 RenderObject 解释。

可将 duration 参数设为非零值，通过 curve 定义的动画将目标对象移入屏幕。

另请参阅：

  • RenderViewportBase.showInViewport, which RenderViewportBase 和 SingleChildScrollView 会将此方法委托给。

实现

void showOnScreen({
  RenderObject? descendant,
  Rect? rect,
  Duration duration = Duration.zero,
  Curve curve = Curves.ease,
}) {
  parent?.showOnScreen(
    descendant: descendant ?? this,
    rect: rect,
    duration: duration,
    curve: curve,
  );
}
