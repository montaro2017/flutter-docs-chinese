FractionalOffsetTween 类

在两个分数偏移量之间进行插值。

此类针对分数偏移量，对 Tween<FractionalOffset> 的插值功能进行了专门处理。

有关如何使用插值对象的讨论，请参阅 Tween。

另请参阅：

  • AlignmentTween, 用于在两个 Alignment 对象之间进行插值。
