GrowthDirection enum

相对于滚动偏移轴，sliver 内容的排列方向。

例如，一个沿 AxisDirection.down 方向排列、按字母顺序显示的垂直列表，如果其 GrowthDirection.forward，则 A 位于顶部、Z 位于底部，A 靠近起点；将这样的列表改为 AxisDirection.up 且使用 GrowthDirection.reverse，结果也相同。另一方面，若垂直字母列表沿 AxisDirection.down 排列且使用 GrowthDirection.reverse，则 Z 位于顶部（滚动偏移为零处），A 位于其下方。

大多数滚动视图默认按 GrowthDirection.forward 排列。更改 ScrollView.anchor、ScrollView.center 的默认值，或同时更改二者，可以将滚动视图配置为使用 GrowthDirection.reverse。

此示例展示了一个 CustomScrollView，其中包含 Radio 按钮位于 AppBar.bottom that change the AxisDirection，以展示不同配置。 CustomScrollView.anchor 和 CustomScrollView.center 属性也经过设置，使滚动偏移量为 0 的位置处于视口中央；并在两侧分别展示 GrowthDirection.forward 和 GrowthDirection.reverse 。共享 CustomScrollView.center 键的 sliver 会定位在 CustomScrollView.anchor。

Values

forward → const GrowthDirection

This sliver's contents are ordered in the same direction as the AxisDirection. For example, a vertical alphabetical list that is going AxisDirection.down with a GrowthDirection.forward would have the A at the top and the Z at the bottom, with the A adjacent to the origin.

另请参阅：

  • applyGrowthDirectionToAxisDirection, which returns the direction in which the scroll offset increases.
reverse → const GrowthDirection

This sliver's contents are ordered in the opposite direction of the AxisDirection.

另请参阅：

  • applyGrowthDirectionToAxisDirection, which returns the direction in which the scroll offset increases.
