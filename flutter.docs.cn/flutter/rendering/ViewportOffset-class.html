ViewportOffset 类 抽象

视口中应显示内容的哪一部分。

pixels 值决定视口使用哪个滚动偏移量来选择要显示的内容。用户滚动视口时，此值会改变，显示的内容也随之改变。

此对象是一个 Listenable；当 pixels 改变时，它会通知监听器。

另请参阅：

  • ScrollPosition，是一种常用的具体子类。
  • RenderViewportBase，是一种使用视口偏移量的渲染对象。
