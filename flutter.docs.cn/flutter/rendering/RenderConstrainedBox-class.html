RenderConstrainedBox 类

为子对象施加额外约束。

渲染约束盒会将渲染盒协议中的大多数函数代理给子对象，但在对子对象布局时，还会通过应用 additionalConstraints 来收紧父对象提供的约束。

例如，如果要让 child 的最小高度为 50.0 个逻辑像素，可以将 const BoxConstraints(minHeight: 50.0) 作为 additionalConstraints。
