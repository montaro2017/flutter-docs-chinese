explicitChildNodes 属性

bool get explicitChildNodes

此 RenderObject 的后代是否可以向此 widget 注释的 SemanticsNode 添加语义信息。

设为 false 时，后代可以使用希望贡献给语义树的语义信息来注释父级的 SemanticsNode。设为 true 时，后代只有向树中引入新的显式 SemanticsNode 才能贡献语义信息。

此设置通常与 SemanticsConfiguration.isSemanticBoundary 配合使用，为子项创建可写或不可写的语义边界。

实现

bool get explicitChildNodes => _explicitChildNodes;
set explicitChildNodes (bool value)

实现

set explicitChildNodes(bool value) {
  if (_explicitChildNodes == value) {
    return;
  }
  _explicitChildNodes = value;
  markNeedsSemanticsUpdate();
}
