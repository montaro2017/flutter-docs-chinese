继承

允许修改此对象的子项列表（以及所有后代），也允许修改同一渲染树中由此对象所属的 PipelineOwner 管理的其他脏节点。callback 参数会同步调用，且仅在回调执行期间允许进行这些修改。

此方法用于在布局期间按需构建子项列表（例如根据对象尺寸构建），并允许在此过程中移动树中的节点（例如处理 GlobalKey 重新挂载），同时确保每个节点在每帧中最多布局一次。

调用此函数会禁用若干用于捕获潜在错误的断言。因此通常不建议使用此函数。

只能在布局期间调用此函数。

实现

@protected
void invokeLayoutCallback<T extends Constraints>(LayoutCallback<T> callback) {
  assert(_debugMutationsLocked);
  assert(_debugDoingThisLayout);
  assert(!_doingThisLayoutWithCallback);
  _doingThisLayoutWithCallback = true;
  try {
    owner!._enableMutationsToDirtySubtrees(() {
      callback(constraints as T);
    });
  } finally {
    _doingThisLayoutWithCallback = false;
  }
}
