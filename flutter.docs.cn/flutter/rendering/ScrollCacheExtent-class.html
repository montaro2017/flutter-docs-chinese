ScrollCacheExtent
description

ScrollCacheExtent 类 sealed

在视口周围额外显示并布局的内容量。

缓存区域用于在 sliver 显示于屏幕之前先对其进行布局。落入该区域的项目即使尚不可见也会先行布局，从而使视口能够提前渲染它们，让项目滚动进入视野时更加顺畅。

此类封装了缓存范围的数值及其样式。缓存范围既可以通过 ScrollCacheExtent.pixels 定义为固定的逻辑像素数，也可以通过 ScrollCacheExtent.viewport 定义为视口主轴范围的倍数。

另请参阅：

  • Viewport.scrollCacheExtent，该属性使用此类来定义缓存区域。
