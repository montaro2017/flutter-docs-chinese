判断给定的 Selectable 是否由此 RenderParagraph 创建。

RenderParagraph 会将文本拆分为多个 Selectable，并以 PlaceholderSpan 或 WidgetSpan 作为分隔。

实现

bool selectableBelongsToParagraph(Selectable selectable) {
  if (_lastSelectableFragments == null) {
    return false;
  }
  return _lastSelectableFragments!.contains(selectable);
}
