RenderSliverPinnedPersistentHeader
description

RenderSliverPinnedPersistentHeader 类 抽象

一种包含 RenderBox 子节点的 sliver：沿正向滚动时，子节点不会滚出视口；首次滚入视口时保持完整尺寸，随后随着视口继续滚动而逐渐缩小。

在可能的情况下，此 sliver 会避免与前面已布局的其他 sliver 重叠。
