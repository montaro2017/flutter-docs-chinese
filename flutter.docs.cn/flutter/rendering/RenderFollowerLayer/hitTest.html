重写

确定给定位置上有哪些渲染对象。

如果此渲染对象或其某个后代吸收了命中（阻止其下方的对象被命中），则返回 true，并将所有包含该点的渲染对象添加到给定命中测试结果中。如果命中可以继续传递给下方的其他对象，则返回 false。

调用方负责将 position 从全局坐标变换为相对于此 RenderBox 原点的位置。此 RenderBox 负责检查给定位置是否在自身边界内。

如果需要变换，调用方必须调用 BoxHitTestResult.addWithPaintTransform、BoxHitTestResult.addWithPaintOffset 或 BoxHitTestResult.addWithRawTransform，以便在 HitTestResult 中记录所需的变换操作。这些方法也会帮助将变换应用到 position。

命中测试要求布局为最新状态，但不要求绘制为最新状态。这意味着渲染对象可以依赖在命中测试期间已调用 performLayout 和 hitTest，但不能依赖此前已调用 paint。例如，某个渲染对象可能是 RenderOpacity 的子节点；即使透明度为零且不会对子节点调用 paint，但仍可能调用 hitTest。

实现

@override
bool hitTest(BoxHitTestResult result, {required Offset position}) {
  // Disables the hit testing if this render object is hidden.
  if (link.leader == null && !showWhenUnlinked) {
    return false;
  }
  // RenderFollowerLayer objects don't check if they are
  // themselves hit, because it's confusing to think about
  // how the untransformed size and the child's transformed
  // position interact.
  return hitTestChildren(result, position: position);
}
