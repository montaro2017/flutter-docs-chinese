supportsRasterization 方法

  1. @重写
bool supportsRasterization()
重写

此图层或其任一子图层是否可以通过 ui.Scene.toImage 或 ui.Scene.toImageSync 栅格化。

如果为 false，调用上述方法可能会得到不完整的图像。

此值可能会在对象的生命周期内变化，因为子图层本身可能会被添加或移除。

实现

@override
bool supportsRasterization() {
  return false;
}
