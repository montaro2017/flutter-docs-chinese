scrollCacheExtent 属性

ScrollCacheExtent get scrollCacheExtent

视口会在可见区域的前后各保留一段缓存范围，以缓存用户滚动后即将显示的子项。

位于此缓存范围内的子项即使尚未显示在屏幕上，也会参与布局。scrollCacheExtent 描述缓存范围在视口前缘之前和后缘之后延伸的距离。

视口尝试用子项覆盖的总范围为：前缘之前的 scrollCacheExtent + 主轴范围 + 后缘之后的 scrollCacheExtent。

缓存范围也用于实现 iOS 上隐式的无障碍滚动：当无障碍焦点从视口内可见的子项移动到缓存范围内不可见的子项时，框架会通过一次（隐式）滚动操作将该子项滚动到视野中。

getter 永远不会返回 null，但字段可以为空，因为 setter 可以设为 null，以将值重置为 RenderAbstractViewport.defaultCacheExtent 像素（此时 ScrollCacheExtent.style 必须为 CacheExtentStyle.pixel）。

另请参阅：

  • ScrollCacheExtent.style，用于控制 scrollCacheExtent 的单位。

实现

ScrollCacheExtent get scrollCacheExtent => _scrollCacheExtent;
set scrollCacheExtent (ScrollCacheExtent? value)

实现

set scrollCacheExtent(ScrollCacheExtent? value) {
  final ScrollCacheExtent effectiveValue =
      value ?? const ScrollCacheExtent.pixels(RenderAbstractViewport.defaultCacheExtent);
  if (effectiveValue == _scrollCacheExtent) {
    return;
  }
  _scrollCacheExtent = effectiveValue;
  markNeedsLayout();
}
