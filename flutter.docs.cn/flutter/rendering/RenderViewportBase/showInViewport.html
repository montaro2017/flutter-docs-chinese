通过调整提供的 ViewportOffset offset，使给定 descendant 在给定 viewport 中完全可见；也就是将其显示在此 viewport 内。

可选的 rect 参数用于描述应在视口中显示 descendant 的哪个区域。如果 rect 为 null，则会显示整个 descendant。rect 会相对于 descendant 的坐标系解释。

返回的 Rect 描述显示后 descendant 或 rect 在视口中的新位置。有关此 Rect 的完整定义，请参阅 RevealedOffset.rect。

如果 descendant 为 null，则此方法不执行任何操作，并返回 rect。

If both descendant 和 rect are null, null is returned because there is nothing to be shown in the viewport.

可以将 duration 参数设为非零值，以通过由 curve 定义的动画将目标对象滚动到视口中。

另请参阅：

  • RenderObject.showOnScreen, overridden by RenderViewportBase and the renderer for SingleChildScrollView to delegate to this method.

实现

static Rect? showInViewport({
  RenderObject? descendant,
  Rect? rect,
  required RenderAbstractViewport viewport,
  required ViewportOffset offset,
  Duration duration = Duration.zero,
  Curve curve = Curves.ease,
}) {
  if (descendant == null) {
    return rect;
  }
  final RevealedOffset leadingEdgeOffset = viewport.getOffsetToReveal(
    descendant,
    0.0,
    rect: rect,
  );
  final RevealedOffset trailingEdgeOffset = viewport.getOffsetToReveal(
    descendant,
    1.0,
    rect: rect,
  );
  final double currentOffset = offset.pixels;
  final RevealedOffset? targetOffset = RevealedOffset.clampOffset(
    leadingEdgeOffset: leadingEdgeOffset,
    trailingEdgeOffset: trailingEdgeOffset,
    currentOffset: currentOffset,
  );
  if (targetOffset == null) {
    // `descendant` is between leading and trailing edge and hence already
    //  fully shown on screen. No action necessary.
    assert(viewport.parent != null);
    final Matrix4 transform = descendant.getTransformTo(viewport.parent);
    return MatrixUtils.transformRect(transform, rect ?? descendant.paintBounds);
  }

  offset.moveTo(targetOffset.offset, duration: duration, curve: curve);
  return targetOffset.rect;
}
