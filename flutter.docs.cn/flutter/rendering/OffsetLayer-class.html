OffsetLayer 类

相对于父图层存在偏移量的图层。

偏移图层是高效重绘的关键，因为它们由 RenderObject 树中的重绘边界创建（参见 RenderObject.isRepaintBoundary）。当要求一个重绘边界渲染对象在 PaintingContext 中的指定偏移处绘制时，它会先检查自己是否需要重绘。如果不需要，就通过修改其 offset 属性复用现有的 OffsetLayer（及其整个子树），从而跳过后续的绘制遍历。
