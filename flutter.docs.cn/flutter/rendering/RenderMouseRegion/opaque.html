opaque 属性

bool get opaque

此对象是否应阻止其视觉上位于后方的 RenderMouseRegion 检测指针，并据此影响它们的 onHover、onEnter 和 onExit 行为。

opaque 为 true 时，此对象会吸收鼠标指针，阻止其兄弟对象（以及所有既非其祖先也非其后代的对象）检测鼠标指针，即使指针位于这些对象的区域内也一样。

opaque 为 false 时，此对象不会影响其后方 RenderMouseRegion 的行为；只要指针位于它们各自的区域内，这些对象仍会检测到指针。

默认为 true。

实现

bool get opaque => _opaque;
set opaque (bool value)

实现

set opaque(bool value) {
  if (_opaque != value) {
    _opaque = value;
    // Trigger [MouseTracker]'s device update to recalculate mouse states.
    markNeedsPaint();
  }
}
