在子树中的 localPosition 位置搜索类型为 S 的注解，并在适用时添加注解 value。

此方法始终会搜索其子级；如果任何子级返回 true，则跳过其余子级。无论子级返回什么，只要满足以下所有条件，此方法就会添加此图层自己的注解：

  • 目标类型必须与注解类型 T 完全相同。
  • 如果提供了 size，目标位置必须位于由 size 和 offset 形成的矩形内。

此搜索过程遵循 onlyFirst：当 onlyFirst 为 true 时，搜索会在子级中找到第一个注解后停止；只有子级未提供注解时，才会检查图层自身的注解。

如果任一子级返回 true，或者 opaque 为 true 且已添加此图层的注解，则返回值为 true。

有关图层注解、参数和返回值的说明，请参阅 Layer.findAnnotations。

实现

@override
bool findAnnotations<S extends Object>(
  AnnotationResult<S> result,
  Offset localPosition, {
  required bool onlyFirst,
}) {
  bool isAbsorbed = super.findAnnotations(result, localPosition, onlyFirst: onlyFirst);
  if (result.entries.isNotEmpty && onlyFirst) {
    return isAbsorbed;
  }
  if (size != null && !(offset & size!).contains(localPosition)) {
    return isAbsorbed;
  }
  if (T == S) {
    isAbsorbed = isAbsorbed || opaque;
    final Object untypedValue = value;
    final typedValue = untypedValue as S;
    result.add(AnnotationEntry<S>(annotation: typedValue, localPosition: localPosition - offset));
  }
  return isAbsorbed;
}
