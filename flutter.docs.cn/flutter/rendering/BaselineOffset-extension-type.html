BaselineOffset extension type

一个包装类型，用于表示 RenderBox 的基线位置。

on
  • double?

构造函数

BaselineOffset(double? offset)
const

属性

offset → double?
final

方法

minOf(BaselineOffset other) → BaselineOffset
比较此 BaselineOffset 与 other，并返回更接近原点的那个。

运算符

operator +(double offset) → BaselineOffset
返回一个新的基线位置，按 offset 像素偏移，使 this 进一步远离原点；若 this 为 noBaseline，则保持不变。

常量

noBaseline → const BaselineOffset
一个表示关联的 RenderBox 没有任何基线的值。
