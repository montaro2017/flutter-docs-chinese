MouseTracker 类

跟踪鼠标设备与注释之间的关系，并据此触发鼠标事件和光标变化。

MouseTracker 会跟踪鼠标设备与 MouseTrackerAnnotation 之间的关系；该关系由 updateWithEvent 和 updateAllDevices 通知。每次更新时，MouseTracker 会在适用的情况下触发以下变化：

  • 分发鼠标相关的指针事件（指针进入、悬停和退出）。
  • 更改鼠标光标。
  • 在 mouseIsConnected 发生变化时发出通知。

此类是一个 ChangeNotifier；当 mouseIsConnected 的值发生变化时，它会通知监听器。

全局单例 RendererBinding 持有一个 MouseTracker 实例。
