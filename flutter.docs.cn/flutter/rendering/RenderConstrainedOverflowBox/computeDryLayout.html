重写

计算 getDryLayout 返回的值。不要直接调用此函数，应改为调用 getDryLayout。

在实现 performLayout 或 performResize 的子类中重写此方法；如果将 sizedByParent 设为 true 而未重写 performResize，也应重写此方法。给定 BoxConstraints 后，此方法应返回该 RenderBox 希望获得的 Size。

此方法返回的 size 必须与 RenderBox 在 performLayout（或在 performResize 中，如果 sizedByParent 为 true）为自身计算出的 size 一致。

如果此算法依赖子对象的大小，应使用该子对象的 getDryLayout 方法获取大小。

这种布局称为“干运行”布局，以区别于由 performLayout 执行的常规“湿运行”布局；它会在不改变任何内部状态的情况下，计算给定约束下所需的尺寸。

无法确定大小时

有些渲染对象无法高效地计算自身大小。例如，大小可能由某个回调计算，而渲染对象无法推断该回调的行为。

在这种情况下，可能无法（或至少不切实际地）返回有效结果。此时，函数应在 assert 中调用 debugCannotComputeDryLayout，并返回一个虚设值 const Size(0, 0)。

实现

@override
@protected
Size computeDryLayout(covariant BoxConstraints constraints) {
  return switch (fit) {
    OverflowBoxFit.max => constraints.biggest,
    OverflowBoxFit.deferToChild => child?.getDryLayout(constraints) ?? constraints.smallest,
  };
}
