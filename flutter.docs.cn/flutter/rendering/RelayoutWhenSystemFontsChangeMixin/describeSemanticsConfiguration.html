继承

报告此节点的语义信息，例如供无障碍功能使用。

具有有意义语义信息的子类应重写此方法。

给定的 SemanticsConfiguration 对象可变，应根据当前状态为其添加标注。不要保留对此对象的引用；在 describeSemanticsConfiguration 调用上下文之外修改它（例如异步计算完成后）通常不会产生任何效果，最坏情况下还会因数据状态不一致而导致崩溃。

abstract class SemanticButtonRenderObject extends RenderObject {
  @override
  void describeSemanticsConfiguration(SemanticsConfiguration config) {
    super.describeSemanticsConfiguration(config);
    config
      ..onTap = _handleTap
      ..label = 'I am a button'
      ..isButton = true;
  }

  void _handleTap() {
    // Do something.
  }
}
