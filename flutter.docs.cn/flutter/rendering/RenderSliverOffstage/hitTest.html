确定给定位置上的渲染对象集合。

如果给定点位于此渲染对象或其某个后代中，则返回 true。并将包含该点的渲染对象添加到给定的命中测试结果中。

调用方负责提供被调用对象局部坐标系中的位置。被调用对象负责检查给定位置是否在其边界内。

命中测试要求布局信息是最新的，但不要求绘制信息是最新的。这意味着渲染对象可以依赖 performLayout 已在 hitTest 前调用，但不能依赖 paint 已调用。例如，渲染对象可能是 RenderOpacity 的子节点；即使不绘制子节点，不透明度为零时，RenderOpacity 仍会对其子节点调用 hitTest，即使它不绘制子节点（paint）。

RenderSliver 对象的坐标

mainAxisPosition 是沿 AxisDirection（应用 GrowthDirection 后）从 sliver 已绘制区域边缘量起的距离。方向可能不太直观，例如当方向为 AxisDirection.up 时，距离是从 sliver 已绘制区域的底部量起。

crossAxisPosition 是沿另一条轴的距离。如果交叉轴为水平轴（即 SliverConstraints.axisDirection 为 AxisDirection.down 或 AxisDirection.up），则 crossAxisPosition 是从 sliver 左边缘量起的距离。如果交叉轴为垂直轴（即 SliverConstraints.axisDirection 为 AxisDirection.right 或 AxisDirection.left），则 crossAxisPosition 是从 sliver 顶部边缘量起的距离。

为 sliver 实现命中测试

为新的 sliver 渲染对象实现命中测试时，最直接的方法是重写其 hitTestSelf 和 hitTestChildren 方法。

实现

@override
bool hitTest(
  SliverHitTestResult result, {
  required double mainAxisPosition,
  required double crossAxisPosition,
}) {
  return !offstage &&
      super.hitTest(
        result,
        mainAxisPosition: mainAxisPosition,
        crossAxisPosition: crossAxisPosition,
      );
}
