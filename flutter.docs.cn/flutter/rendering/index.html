rendering 库

Flutter 渲染树。

使用时，请导入 package:flutter/rendering.dart。

Flutter Widgets 库使用 RenderObject 层级来实现布局和绘制后端。通常，你可以在应用中使用自定义 RenderBox 类实现特定效果，但大多数情况下，你只会在调试布局问题时接触 RenderObject 层级。

如果你直接基于 rendering 库开发自己的库或应用，就需要一个 binding（参见 BindingBase）。你可以使用 RenderingFlutterBinding，也可以创建自己的 binding。若自行创建，至少需要导入 ServicesBinding、GestureBinding、SchedulerBinding、PaintingBinding 和 RendererBinding。rendering 库不会自动创建 binding，而是依赖已初始化且具备这些功能的 binding。
