toImageSync 方法

Image toImageSync(
  1. Rect bounds, {
  2. double pixelRatio = 1.0,
})

捕获此图层及其子项的当前状态并生成图像。

返回的 ui.Image 包含未压缩的原始 RGBA 字节，其偏移量为 bounds 的左上角，尺寸则等于 bounds 的大小乘以 pixelRatio。

pixelRatio 表示逻辑像素与输出图像尺寸之间的缩放比例。它独立于设备的 dart:ui.FlutterView.devicePixelRatio；因此，指定 1.0（默认值）会使图像中的输出像素与逻辑像素一一对应。

此 API 的功能与 toImage 类似，但它会立即在栅格线程启动栅格化，并在栅格化完成之前返回图像。

另请参阅：

  • RenderRepaintBoundary.toImage 用于了解 render object 层级的类似 API。
  • dart:ui.Scene.toImage 了解有关返回图像的更多信息。

实现

ui.Image toImageSync(Rect bounds, {double pixelRatio = 1.0}) {
  final ui.Scene scene = _createSceneForImage(bounds, pixelRatio: pixelRatio);

  try {
    // Size is rounded up to the next pixel to make sure we don't clip off
    // anything.
    return scene.toImageSync(
      (pixelRatio * bounds.width).ceil(),
      (pixelRatio * bounds.height).ceil(),
    );
  } finally {
    scene.dispose();
  }
}
