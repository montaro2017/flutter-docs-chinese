PaintingContext 类

绘制内容的上下文。

RenderObject 不会直接持有画布，而是通过绘制上下文进行绘制。绘制上下文包含一个用于接收各项绘制操作的 Canvas，也提供绘制子渲染对象的函数。

绘制子渲染对象时，绘制上下文持有的画布可能发生变化，因为子项绘制前后的操作可能分别记录在不同的合成图层中。因此，不要在可能绘制子渲染对象的操作前后持有画布引用。

使用 PaintingContext.repaintCompositedChild 和 pushLayer 时，会自动创建新的 PaintingContext 对象。
