markParentNeedsLayout 方法

  1. @protected
void markParentNeedsLayout()
继承

将此渲染对象的布局信息标记为变脏，然后交由父对象处理。

只有当子类重写 markNeedsLayout 或 markNeedsLayoutForSizedByParentChange，并引入了更多需要将脏布局处理延后交给父对象的原因时，才应调用此函数。详情请参阅 markNeedsLayout。

仅当 parent 不为 null 时调用。

实现

@protected
void markParentNeedsLayout() {
  assert(_debugCanPerformMutations);
  _needsLayout = true;
  assert(this.parent != null);
  final RenderObject parent = this.parent!;
  if (!_doingThisLayoutWithCallback) {
    parent.markNeedsLayout();
  } else {
    assert(parent._debugDoingThisLayout);
  }
  assert(parent == this.parent);
}
