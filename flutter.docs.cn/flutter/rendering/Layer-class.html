Layer 类 抽象

合成图层。

绘制期间，渲染树会生成一棵合成图层树，并将其上传到引擎，由合成器显示。此类是所有合成图层的基类。

大多数图层的属性都可以修改，图层也可以移动到其他父级下。完成此类更改后，必须显式地重新合成场景；图层树不会自行维护脏状态。

要合成图层树，请使用 RendererBinding.createSceneBuilder 创建 ui.SceneBuilder 对象，将其传递给根 Layer 对象的 addToScene 方法，然后调用 ui.SceneBuilder.build 获取 ui.Scene。之后可以使用 ui.FlutterView.render 绘制此 ui.Scene。

内存

图层会在帧与帧之间保留资源，以加快渲染速度。图层会一直保留这些资源，直到所有引用该图层的 LayerHandle 都将其引用置为 null。

释放图层后不得再使用。如果 RenderObject 需要保留图层以供后续使用，就必须为该图层创建句柄。RenderObject.layer 属性会自动处理这一点，但其他图层必须使用各自的 LayerHandle。

此 RenderObject 是一个重绘边界，并会推入额外的 ClipRectLayer。
link 
class ClippingRenderObject extends RenderBox {
  final LayerHandle<ClipRectLayer> _clipRectLayer = LayerHandle<ClipRectLayer>();

  @override
  bool get isRepaintBoundary => true; // The [layer] property will be used.

  @override
  void paint(PaintingContext context, Offset offset) {
    _clipRectLayer.layer = context.pushClipRect(
      needsCompositing,
      offset,
      Offset.zero & size,
      super.paint,
      oldLayer: _clipRectLayer.layer,
    );
  }

  @override
  void dispose() {
    _clipRectLayer.layer = null;
    super.dispose();
  }
}
