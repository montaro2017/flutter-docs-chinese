spacing 属性

double get spacing

主轴上子节点之间的间距。

间距只会应用于主轴方向上的子节点之间。

如果 spacing 为 10.0 且 mainAxisAlignment 为 MainAxisAlignment.start，第一个子节点会放在主轴起始处，第二个子节点会放在第一个之后 10.0 像素处，依此类推。第一个子节点之前和最后一个子节点之后都不会应用 spacing。

如果 spacing 为 10.0 且 mainAxisAlignment 为 MainAxisAlignment.end，最后一个子节点会放在主轴末端，倒数第二个子节点会放在它之前 10.0 像素处，依此类推。第一个子节点之前和最后一个子节点之后都不会应用 spacing。

如果 spacing 为 10.0 且 mainAxisAlignment 为 MainAxisAlignment.center，子节点会在主轴居中排列，彼此间隔 10.0 像素。第一个子节点之前和最后一个子节点之后都不会应用 spacing。

如果 spacing 为 10.0 且 mainAxisAlignment 为 MainAxisAlignment.spaceBetween，主轴上每个子节点之间至少会有 10.0 像素的间距。如果两个子节点之间有 100.0 像素的空闲空间，那么它们之间至少会间隔 10.0 像素，剩余的 90.0 像素则作为子节点之间的空闲空间。第一个子节点之前和最后一个子节点之后都不会应用 spacing。

如果 spacing 为 10.0 且 mainAxisAlignment 为 MainAxisAlignment.spaceAround，主轴上每个子节点之间至少会有 10.0 像素的间距，剩余空闲空间则会分配到子节点之间，以及第一个子节点之前和最后一个子节点之后。第一个子节点之前和最后一个子节点之后都不会应用 spacing。

如果 spacing 为 10.0 且 mainAxisAlignment 为 MainAxisAlignment.spaceEvenly，主轴上每个子节点之间至少会有 10.0 像素的间距，剩余空闲空间则会平均分配到子节点之间，以及第一个子节点之前和最后一个子节点之后。第一个子节点之前和最后一个子节点之后都不会应用 spacing。

spacing 不为零时，布局尺寸在主轴方向上会大于所有子节点布局尺寸之和。

如果所有子节点的布局尺寸与它们之间的总间距超过主轴上的最大约束，子节点就会溢出。例如，有两个子节点，最大约束为 100.0 像素，每个子节点的布局尺寸为 50.0 像素，间距为 10.0 像素时，子节点总共会溢出 10.0 像素。

默认为 0.0。

实现

double get spacing => _spacing;
set spacing (double value)

实现

set spacing(double value) {
  if (_spacing == value) {
    return;
  }
  _spacing = value;
  markNeedsLayout();
}
