performLayout 方法

  1. @重写
void performLayout()
重写

执行此渲染对象的布局计算工作。

不要直接调用此函数，应改为调用 layout。当此渲染对象在布局期间确实需要执行工作时，layout 会调用此函数。可通过 constraints getter 获取父对象提供的布局约束。

如果 sizedByParent 为 true，此函数不应实际更改此渲染对象的尺寸；应由 performResize 完成这项工作。如果 sizedByParent 为 false，此函数则应更改此渲染对象的尺寸，并指示其子对象执行布局。

实现此函数时，必须对每个子项调用 layout。如果此对象的布局信息依赖子项的布局信息，应将 parentUsesSize 设为 true。设为 true 可确保子项执行布局时，此渲染对象也会重新布局。否则，子项可以更改其布局信息而不通知此渲染对象。

某些特殊的 RenderObject 子类（例如 OverlayPortal.overlayChildLayoutBuilder 使用的对象）会在其 performLayout 实现中调用 applyPaintTransform。为确保这类 RenderObject 获得最新的绘制变换，RenderObject 子类通常应在此方法中更新绘制变换（由 applyPaintTransform 报告），而不是在 paint 中更新。

实现

@override
void performLayout() {
  size = _sizeForConstraints(constraints);
}
