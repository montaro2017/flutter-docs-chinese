TextureLayer 类

将后端纹理映射到矩形上的合成图层。

后端纹理是可以应用（映射）到 Flutter 视图某个区域的图像。它们通过特定平台的纹理注册器创建、管理和更新。通常由插件完成这项工作，例如集成宿主平台的视频播放器、摄像头或 OpenGL API 的插件，也可以集成其他类似的图像来源。

纹理图层使用整数 ID 引用其后端纹理。纹理 ID 从纹理注册器获取，并且作用域限定在对应的 Flutter 视图内。注销后，注册器可以自行决定是否重用纹理 ID。使用注册器当前未知的纹理 ID 时，不会报错，只会显示空白矩形。

插入图层树后，纹理图层会按照后端的指示自动重绘（例如收到视频帧时）。此类重绘通常不需要执行 Dart 代码。

纹理图层始终是图层树中的叶节点。

另请参阅：

  • TextureRegistry for how to create and manage backend textures on Android.
  • TextureRegistry Protocol for how to create and manage backend textures on iOS.

构造函数

TextureLayer({required Rect rect, required int textureId, bool freeze = false, FilterQuality filterQuality = ui.FilterQuality.low})
创建一个纹理层，其边界由 rect 指定，后端纹理由 textureId 标识。若 freeze 为 true，纹理将不会接收新的帧；使用 filterQuality 设置该层的 FilterQuality。
