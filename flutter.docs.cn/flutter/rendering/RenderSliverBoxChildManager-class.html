RenderSliverBoxChildManager 类 抽象

RenderSliverMultiBoxAdaptor 用于管理子对象的代理。

RenderSliverMultiBoxAdaptor 对象会延迟实例化子对象，以免为 viewport 中不可见的子对象消耗资源。此代理允许这些对象创建和移除子对象，并估算整个子对象列表占据的总滚动范围。
