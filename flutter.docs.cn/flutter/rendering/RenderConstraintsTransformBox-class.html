description

RenderConstraintsTransformBox 类

一种 RenderBox，可对自身约束应用任意变换，再使用变换后的 BoxConstraints 布局子节点；还可选择裁剪溢出内容，或将溢出视为错误。

此 RenderBox 使用将 constraintsTransform 应用于此 RenderBox 自身 constraints 后生成的 BoxConstraints 来布局子节点。随后，该盒子会尝试在自身约束允许的范围内采用与子节点相同的尺寸。如果最终尺寸不同，则会根据 alignment 对齐子节点。如果盒子无法扩展到足以容纳整个子节点，且 clipBehavior 不是 Clip.none，则会裁剪子节点。

在调试模式下，如果 clipBehavior 为 Clip.none 且子节点溢出容器，控制台会打印警告，并在发生溢出的位置显示黑黄相间的条纹区域。

当 child 为 null 时，此 RenderBox 会采用尽可能小的尺寸，且不会发生溢出。

此 RenderBox 可用于确保遵循 child 的部分自然尺寸，并在开发期间提前发出警告。例如，如果 child 需要最小高度才能完整显示内容，可以将 constraintsTransform 设为一个会移除传入 BoxConstraints 中 maxHeight 约束的函数。这样，即使父级 RenderObject 未能提供足够的垂直空间，调试模式仍会显示警告，同时允许 child 继续沿垂直方向增长。

另请参阅：

  • ConstraintsTransformBox 小部件使用此 RenderObject，并公开相同的功能。
  • RenderConstrainedBox 会渲染一个对其子项施加约束的盒子。
  • RenderConstrainedOverflowBox：此渲染对象施加给子项的约束与从父对象收到的约束不同，因此子项可能会溢出父对象。
  • RenderConstraintsTransformBox：先对约束应用任意变换，再使用新约束确定子项尺寸；发生溢出时将其视为错误。
