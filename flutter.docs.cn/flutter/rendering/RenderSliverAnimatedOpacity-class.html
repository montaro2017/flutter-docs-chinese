RenderSliverAnimatedOpacity
description

RenderSliverAnimatedOpacity 类

根据 Animation 驱动，使其 sliver 子对象呈现部分透明效果。

这是 RenderSliverOpacity 的一种变体，使用 Animation<double> 而不是 double 来控制不透明度。
