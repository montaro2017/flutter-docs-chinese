RenderAndroidView 类

用于 Android 视图的渲染对象。

需要 Android API 级别 23 或更高版本。

RenderAndroidView 负责为 Android View 设置尺寸、显示该视图并向其传递触摸事件。

此渲染对象的布局行为是填满所有可用空间，因此其父对象必须提供有界的布局约束。

此渲染对象会参与 Flutter 手势竞技场，并且仅当它赢得竞技场时才会向平台视图分发触摸事件。可以通过构造函数参数 gestureRecognizers 中的工厂指定应分发给平台视图的具体手势，也可以调用 updateGestureRecognizers。如果手势识别器集合为空，则仅当没有其他手势识别器认领该手势时，才会将其分发给平台视图。

另请参阅：

  • AndroidView which is a widget that is used to show an Android view.
  • PlatformViewsService which is a service for controlling platform views.
