RenderSliverScrollingPersistentHeader
description

RenderSliverScrollingPersistentHeader 类 抽象

一种包含 RenderBox 子节点的 sliver：子节点通常随滚动移动；到达视口前缘（通常是顶部）时，会缩小到最小尺寸，然后继续滚动。

此 sliver 不会尝试避免与其他内容重叠。

构造函数

RenderSliverScrollingPersistentHeader({RenderBox? 子项, OverScrollHeaderStretchConfiguration? stretchConfiguration})
创建一个 sliver：当它到达视口起始处时收缩，随后滚出视野。
