安排指定的瞬时帧回调。

将给定回调添加到帧回调列表中；如果 scheduleNewFrame 参数为 true，还会确保安排一个新帧。

scheduleNewFrame 参数决定是否应调用 scheduleFrame 来确保生成新帧。默认为 true。

如果在帧的动画阶段调用此方法（此时仍在执行瞬时帧回调），callback 会在下一帧调用，而不是当前帧。

如果这是一次性注册，请忽略 rescheduling 参数。

如果此回调每次触发后都会重新注册，那么重新注册时应将 rescheduling 参数设为 true。此设置在发布构建中不起作用；但在调试构建中，它会确保为此回调保存的堆栈跟踪是该回调首次注册时的原始堆栈跟踪，而不是重新注册时的堆栈跟踪。这样更容易追查调用该回调的最初原因。如果 rescheduling 为 true，则调用必须位于帧回调的上下文中。

使用此方法注册的回调可以通过 cancelFrameCallbackWithId 取消。

另请参阅：

  • WidgetsBinding.drawFrame，说明使用 Flutter widget 的应用中每帧的各个阶段，以及瞬时帧回调在这些阶段中的位置。

实现

int scheduleFrameCallback(
  FrameCallback callback, {
  bool rescheduling = false,
  bool scheduleNewFrame = true,
}) {
  if (scheduleNewFrame) {
    scheduleFrame();
  }
  _nextFrameCallbackId += 1;
  _transientCallbacks[_nextFrameCallbackId] = _FrameCallbackEntry(
    callback,
    rescheduling: rescheduling,
  );
  return _nextFrameCallbackId;
}
