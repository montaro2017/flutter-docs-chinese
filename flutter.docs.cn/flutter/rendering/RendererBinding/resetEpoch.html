resetEpoch 方法

void resetEpoch()
继承

当时间戳计算方式发生非单调变化时，准备调度器以应对此变化。

调度器收到的回调假定时间戳会单调递增。传递给 handleBeginFrame 的原始时间戳是单调的，但调度器可能会为了应用 timeDilation 而调整时间戳。如果不谨慎处理，这些调整可能导致时间看起来倒退。

resetEpoch 函数会重置后续时间戳调整所使用的基准值，确保时间戳保持单调递增。例如，如果 timeDilation 减小，resetEpoch 不会缩放从时间起点开始累计的 Duration，而只会缩放自调用 resetEpoch 以来累计的时长。

设置 timeDilation 时会自动调用 resetEpoch，因此你无需自行调用 resetEpoch。

实现

void resetEpoch() {
  _epochStart = _adjustForEpoch(_lastRawTimeStamp);
  _firstRawTimeStampInEpoch = null;
}
