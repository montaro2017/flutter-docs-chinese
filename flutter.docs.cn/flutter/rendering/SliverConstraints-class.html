SliverConstraints 类

用于 RenderSliver 布局的不可变布局约束。

SliverConstraints 从接收约束的 sliver 的角度描述视口当前的滚动状态。例如，scrollOffset 为零表示 sliver 的前缘在视口中可见，而不是表示视口本身的滚动偏移量为零。
