SliverGridRegularTileLayout 类

使用尺寸和间距均相同网格单元的 SliverGridLayout。

网格不会直接接收 SliverGridLayout，而是接收 SliverGridDelegate；后者可根据当前 SliverConstraints 计算 SliverGridLayout。

此布局由 SliverGridDelegateWithFixedCrossAxisCount 和 SliverGridDelegateWithMaxCrossAxisExtent 使用。

另请参阅：

  • SliverGridDelegateWithFixedCrossAxisCount 使用此布局。
  • SliverGridDelegateWithMaxCrossAxisExtent 使用此布局。
  • SliverGridLayout 表示任意网格单元布局。
  • SliverGridGeometry 表示网格中单个网格单元的大小和位置。
  • SliverGridDelegate.getLayout 返回此对象，用于描述委托对象的布局。
  • RenderSliverGrid 在其 RenderSliverGrid.performLayout 方法中使用此类。
