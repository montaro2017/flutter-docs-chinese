重写

将合成给定子级时会应用的变换应用到给定矩阵。

具体来说，此方法应应用于子级原点的变换。若对一系列图层调用 applyTransform，除非最深层图层在 addToScene 中将 layerOffset 归零（即向其子级传递 Offset.zero），并将传入的 layerOffset（例如作为变换）合并到 ui.SceneBuilder 中，否则结果将不可靠；该变换也会包含在 applyTransform 应用的变换中。

例如，如果 addToScene 应用 layerOffset 后向子级传递 Offset.zero，那么该偏移应包含在此处应用的变换中；如果 addToScene 只是将 layerOffset 传递给子级，则不应将其包含在此处应用的变换中。

此方法仅在调用 addToScene 后立即有效，且必须在任何属性发生更改之前调用。

默认实现不执行任何操作，因为 ContainerLayer 默认会在其自身（ContainerLayer）的原点处合成子级。

通常 child 参数不应为 null，因为理论上图层可以分别变换每个子级。不过，某些图层可能明确允许该值为 null，例如它们确定会对所有子级应用相同的变换。

FollowerLayer 使用此方法将其子级变换到 LeaderLayer 的位置。

实现

@override
void applyTransform(Layer? child, Matrix4 transform) {
  assert(child != null);
  assert(_lastEffectiveTransform != null || this.transform != null);
  if (_lastEffectiveTransform == null) {
    transform.multiply(this.transform!);
  } else {
    transform.multiply(_lastEffectiveTransform!);
  }
}
