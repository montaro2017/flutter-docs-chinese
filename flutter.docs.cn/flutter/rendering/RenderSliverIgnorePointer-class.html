RenderSliverIgnorePointer
description

RenderSliverIgnorePointer 类

一种在命中测试期间不可见的渲染对象。

当 ignoring 为 true 时，此渲染对象及其子树不会参与命中测试。它在布局期间仍会占用空间，也会照常绘制其 sliver 子项。由于该渲染对象的 hitTest 返回 false，因此它不会成为定位事件的目标。

语义

使用此类也可能影响其下方语义子树的收集方式。

如果 ignoring 为 true，会从语义子树中移除与指针相关的 SemanticsAction；否则，子树保持不变。

不建议使用 ignoringSemantics，该属性现已弃用。它最初用于解决 Flutter v3.8.0-12.0.pre 之前 IgnorePointer 及相关组件的语义行为问题。

在该版本之前，如果 ignoring 为 true，整个语义子树都会被移除。开发者只能使用 ignoringSemantics 来保留语义子树。

在该版本之后，当 ignoring 设为 true 时，它只会阻止语义子树中的用户操作，同时保留其他 SemanticsProperties。因此，不再需要 ignoringSemantics。

如果 ignoringSemantics 为 true，语义子树会被移除，因此辅助技术无法访问该子树。

如果 ignoringSemantics 为 false，则照常收集语义子树。
