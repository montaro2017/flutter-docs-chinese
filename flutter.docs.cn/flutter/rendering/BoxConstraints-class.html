BoxConstraints 类

RenderBox 布局所使用的不可变布局约束。

当且仅当以下关系全部成立时，Size 才符合 BoxConstraints：

  • minWidth <= Size.width <= maxWidth
  • minHeight <= Size.height <= maxHeight

约束本身必须满足以下关系：

  • 0.0 <= minWidth <= maxWidth <= double.infinity
  • 0.0 <= minHeight <= maxHeight <= double.infinity

double.infinity 是每项约束都允许使用的合法值。

盒子布局模型

Flutter 框架中的渲染对象采用单遍布局模型：先沿渲染树向下传递约束，再沿渲染树向上返回具体几何信息。

对于盒子，约束由 BoxConstraints 表示，如上所述，它由四个数值组成：最小宽度 minWidth、最大宽度 maxWidth、最小高度 minHeight 和最大高度 maxHeight。

盒子的几何信息由 Size 表示，并且必须满足上述约束。

每个 RenderBox（为盒子类 widget 提供布局模型的对象）都会从父级接收 BoxConstraints，随后布局自己的每个子级，最后选取一个符合 BoxConstraints 的 Size。

渲染对象会独立于布局过程来定位子级。父级通常会根据子级大小决定其位置。子级并不知道自己的位置，因此位置变化时不一定会重新布局或重新绘制。

术语

如果某个轴上的最小约束和最大约束相同，则该轴受到紧约束。另请参阅：BoxConstraints.tightFor、BoxConstraints.tightForFinite、tighten、hasTightWidth、hasTightHeight、isTight。

某个轴的最小约束为 0.0 时，该轴是宽松的（无论最大约束是多少；如果最大约束也为 0.0，则该轴会同时受到紧约束和宽松约束！）。另请参阅：BoxConstraints.loose、loosen。

最大约束不是无穷大的轴称为有界。另请参阅：hasBoundedWidth、hasBoundedHeight。

最大约束为无穷大的轴称为无界。如果某个轴受到无穷大的紧约束（其最小和最大约束均为无穷大），则该轴是扩展的。另请参阅：BoxConstraints.expand。

最小约束为无穷大的轴称为无限（根据定义，此时最大约束也必定为无穷大）。另请参阅：hasInfiniteWidth、hasInfiniteHeight。

当一个尺寸满足 BoxConstraints 描述时，该尺寸即为受约束。另请参阅：constrain、constrainWidth、constrainHeight、constrainDimensions、constrainSizeAndAttemptToPreserveAspectRatio、isSatisfiedBy。
