description

RenderWrap 类

将子项排列成多个水平或垂直行的渲染对象。

RenderWrap 会对每个子项进行布局，并尝试沿主轴将它放在前一个子项旁边。主轴由 direction 指定，子项之间留出 spacing 间距。如果空间不足以容纳子项，RenderWrap 会在交叉轴上、已有子项旁创建新的一行。

将所有子项分配到各行后，会根据主轴上的 alignment 和交叉轴上的 crossAxisAlignment 来定位每行中的子项。

随后会根据 runSpacing 和 runAlignment 在交叉轴上定位各行。
