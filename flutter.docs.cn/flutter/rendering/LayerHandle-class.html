LayerHandle<T extends Layer> 类

用于防止 Layer 的平台图形资源被释放的句柄。

Layer 对象会保留 ui.EngineLayer 和 ui.Picture 等原生资源。这些对象本身可能直接或间接保留大量纹理内存。

只要还有对象能够将图层添加到场景中，就必须保留该图层的原生资源。通常，这类对象是其 Layer.parent，或尚未释放、会将该图层添加到 ContainerLayer 的 RenderObject。图层会自动持有其子项的句柄；RenderObject 会自动持有其 RenderObject.layer 的句柄，以及通过 PaintingContext.canvas 绘制到其中的任何 PictureLayer 的句柄。在至少获取过一个句柄且所有句柄都已释放后，图层会自动释放其资源。创建其他图层对象的 RenderObject 必须手动管理这些图层的句柄，方式与 RenderObject.layer 的实现类似。

RenderObject.layer 会自动管理句柄。

如果 RenderObject 除了 RenderObject.layer 之外还创建了其他图层，并且打算将这些图层与 RenderObject.layer 分开复用，就必须为这些图层创建句柄，并在不再需要时将其释放。例如，如果它在 RenderObject.paint 中重新创建现有图层或将其置为 null，就应释放旧图层的句柄。它还应释放在 RenderObject.dispose 中持有的所有图层句柄。

要释放图层句柄，请将其 layer 属性设为 null。
