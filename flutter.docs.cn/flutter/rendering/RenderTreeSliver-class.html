RenderTreeSliver
description

RenderTreeSliver 类

一种沿主轴线性排列多个 TreeSliverNode 的 sliver，同时会错开正在进入或离开视口的节点。

每个子节点的范围由 itemExtentBuilder 决定。

另请参阅：

  • TreeSliver，该 widget 用于创建和管理此渲染对象。
