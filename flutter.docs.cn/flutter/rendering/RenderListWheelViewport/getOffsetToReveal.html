返回用于显示目标 target RenderObject 所需的偏移量。

RenderViewportBase.showInViewport 会使用此方法；而 RenderObject.showOnScreen 会对 RenderViewportBase 使用前者，语义系统则会通过该功能为无障碍工具实现滚动。

可选的 rect 参数用于描述 viewport 中应显示 target 对象的哪个区域。如果 rect 为 null，则显示整个 target RenderObject（由其 RenderObject.paintBounds 定义）。如果提供了 rect，它必须使用 target 对象的坐标系。

alignment 参数描述应用返回的偏移量后目标应位于何处。如果 alignment 为 0.0，子对象应尽可能靠近 viewport 的前缘；如果 alignment 为 1.0，子对象应尽可能靠近后缘；如果 alignment 为 0.5，子对象应尽可能靠近 viewport 的中心。

target 不一定是此 viewport 的直接子对象，但必须是其后代。位于此 viewport 与 target 之间的其他 viewport 不会被调整。

此方法假设 viewport 的内容呈线性移动；也就是说，viewport 的偏移量变化 x 时，target 在 viewport 中也会移动 x。

The optional Axis is used by RenderTwoDimensionalViewport.getOffsetToReveal to determine which of the two axes to compute an offset for. One dimensional subclasses like RenderViewportBase 和 RenderListWheelViewport will ignore the axis value if provided, since there is only one Axis.

在 RenderTwoDimensionalViewport 上调用此方法时，如果省略 axis，则会使用 RenderTwoDimensionalViewport.mainAxis。要在两个坐标轴上正确显示对象，应针对每个 Axis 调用此方法，因为返回的 RevealedOffset.offset 仅表示两个 ScrollPosition 之一的偏移量。

另请参阅：

  • RevealedOffset, which describes the return value of this method.

实现

@override
RevealedOffset getOffsetToReveal(
  RenderObject target,
  double alignment, {
  Rect? rect,
  Axis? axis, // Unused, only Axis.vertical supported by this viewport.
}) {
  // `target` is only fully revealed when in the selected/center position. Therefore,
  // this method always returns the offset that shows `target` in the center position,
  // which is the same offset for all `alignment` values.
  rect ??= target.paintBounds;

  // `child` will be the last RenderObject before the viewport when walking up from `target`.
  var child = target;
  while (child.parent != this) {
    child = child.parent!;
  }

  final parentData = child.parentData! as ListWheelParentData;
  final double targetOffset = parentData.offset.dy; // the so-called "centerPosition"

  final Matrix4 transform = target.getTransformTo(child);
  final Rect bounds = MatrixUtils.transformRect(transform, rect);
  final Rect targetRect = bounds.translate(0.0, (size.height - itemExtent) / 2);

  return RevealedOffset(offset: targetOffset, rect: targetRect);
}
