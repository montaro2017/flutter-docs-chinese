debugNeedsPaint 属性

bool get debugNeedsPaint

此渲染对象的绘制信息是否已变脏。

此属性仅在 debug 模式下设置。通常，渲染对象不应根据自身是否变脏来决定运行时行为，因为它们只应在布局和绘制之前立即被标记为变脏。在非 debug 构建中始终返回 false。

此属性供测试和断言使用。

可能出现 debugNeedsPaint 为 false 而 debugNeedsLayout 为 true 的情况，而且这种情况很常见。此时，该渲染对象仍会在下一帧重绘，因为框架会在渲染对象完成布局后、进入绘制阶段前，隐式调用 markNeedsPaint 方法。

实现

bool get debugNeedsPaint {
  if (!kDebugMode) {
    return false;
  }
  return _needsPaint;
}
