重写

如果调用 paint，给定的子项是否会被绘制。

某些 RenderObject 在配置为不产生任何可见效果时，会跳过绘制其子项。例如，offstage 属性为 true 的 RenderOffstage，或不透明度值为零的 RenderOpacity。

在这些情况下，父对象仍可通过 applyPaintTransform 提供非零矩阵，告知调用方如果绘制该子项，其绘制位置会在哪里。或者，如果父对象无法确定子项的有效矩阵，因而无法有意义地确定其绘制位置，则可以提供全零矩阵。

实现

@override
bool paintsChild(RenderBox child) {
  assert(child.parent == this);
  return !size.isEmpty && !child.size.isEmpty;
}
