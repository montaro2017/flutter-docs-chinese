RenderSliverFixedExtentList
description

RenderSliverFixedExtentList 类

一种沿线性序列排列多个盒子子节点、且这些子节点在主轴上的范围相同的 sliver。

RenderSliverFixedExtentList 会从偏移量零开始，沿主轴以线性序列排列子节点，彼此之间没有间隙。每个子节点在主轴上的尺寸都固定为 itemExtent，在交叉轴上的尺寸则固定为 SliverConstraints.crossAxisExtent。

RenderSliverFixedExtentList 比 RenderSliverList 更高效，因为 RenderSliverFixedExtentList 无需对子节点执行布局即可获得子节点在主轴上的范围。

另请参阅：

  • RenderSliverList, which does not require its children to have the same extent in the main axis.
  • RenderSliverFillViewport, which determines the itemExtent based on SliverConstraints.viewportMainAxisExtent.
  • RenderSliverFillRemaining, which determines the itemExtent based on SliverConstraints.remainingPaintExtent.
