description

RenderShrinkWrappingViewport 类

一种内部尺寸大于外部尺寸，并沿主轴按子项收缩的渲染对象。

RenderShrinkWrappingViewport 会根据自身尺寸和给定的 offset 显示部分子项。随着偏移量变化，视口中可见的子项也会随之改变。

RenderShrinkWrappingViewport 与 RenderViewport 不同：RenderViewport 会扩展以填满主轴，而 RenderShrinkWrappingViewport 会沿主轴调整自身尺寸以贴合其子项。这种按子项收缩的行为开销较大，因为子项以及视口本身可能会在 offset 变化时改变尺寸（例如折叠式标题栏发生变化时）。

RenderShrinkWrappingViewport 不能直接包含 RenderBox 子项。例如，可以改用 RenderSliverList、RenderSliverFixedExtentList、RenderSliverGrid 或 RenderSliverToBoxAdapter。

另请参阅：

  • RenderViewport，其内容不会按子项收缩。
  • RenderSliver，该页面还介绍了 Sliver 协议。
  • RenderBox，该页面还介绍了 Box 协议。
  • RenderSliverToBoxAdapter，它允许将 RenderBox 对象放入 RenderSliver 中（与此类的作用相反）。
