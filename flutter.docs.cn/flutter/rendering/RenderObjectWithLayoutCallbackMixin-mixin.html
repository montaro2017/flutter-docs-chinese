description

RenderObjectWithLayoutCallbackMixin mixin

用于管理带有 layoutCallback 的 RenderObject 的 mixin。如果通过 scheduleLayoutCallback 安排了回调，它会在此 RenderObject 的布局过程中执行。

布局回调通常会在 RenderObject 的布局过程中修改该 RenderObject 的渲染子树。当祖先 RenderObject 在其 performLayout 实现中选择跳过此 RenderObject 的布局时（例如出于性能考虑，Overlay 可能会跳过树中处于屏幕外的 OverlayEntry 的布局），通常不会调用 layoutCallback，因为不会调用 layout 方法。如果 layoutCallback 涉及重建已标记为脏的 Widget（尤其是 LayoutBuilder Widget），这可能会带来问题。与渲染子树不同，Widget 树中所有已标记为脏的 Widget（包括屏幕外的 Widget）通常都必须重建。此 mixin 可确保：一旦安排了 layoutCallback，即使祖先 RenderObject 跳过了它，也仍会调用该回调；但如果此 RenderObject 从未完成过布局，则不会调用。

子类不得直接调用布局回调。应在 performLayout 实现中调用 runLayoutCallback。

另请参阅：

  • LayoutBuilder 和 SliverLayoutBuilder, which use the mixin.
Superclass constraints
  • RenderObject
Mixin applications
  • RenderAbstractLayoutBuilderMixin
