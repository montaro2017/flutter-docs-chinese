  1. @重写

  1. covariant RenderBox child

重写

返回从 sliver 前缘可见部分到子节点靠近该边缘一侧的距离，方向沿滚动轴。

例如，如果 constraints 表示此 sliver 的轴方向为 AxisDirection.down，则此值是从 sliver 可见部分顶部到子节点顶部的距离。如果子节点有一部分滚出了视口顶部，此值将为负数。相反，如果 constraints 表示轴方向为 AxisDirection.up，则此值是从 sliver 可见部分底部到子节点底部的距离。两种情况下，测量方向都与 SliverConstraints.scrollOffset 的递增方向一致。

子节点不可见时调用此方法无效。

参数必须是 child 属性的值。

必须由 RenderSliverPersistentHeader 的子类实现。

如果没有子节点，则应返回 0.0。

实现

@override
double childMainAxisPosition(RenderBox child) {
  assert(child == this.child);
  assert(_childPosition != null);
  return _childPosition!;
}
