debugAssertIsValid 方法

bool debugAssertIsValid({
  1. bool isAppliedConstraint = false,
  2. InformationCollector? informationCollector,
})

断言约束有效。

此检查可能比 isNormalized 更详细。

例如，BoxConstraints 子类会验证约束中不包含 double.nan。

如果 isAppliedConstraint 参数为 true，则会强制执行更严格的规则。布局期间检查即将应用于 RenderObject 的约束时，此参数会设为 true；检查可能还会受其他约束影响的约束时，则不会设为 true。例如，验证 RenderConstrainedBox.additionalConstraints 有效性的断言不会设置此参数，而验证传递给 RenderObject.layout 方法的参数时会设置。

informationCollector 参数接受一个可选回调；即将抛出异常时会调用此回调。收集到的信息会附加在错误行之后，包含在错误消息中。

禁用断言时，返回值与 isNormalized 相同。

实现

bool debugAssertIsValid({
  bool isAppliedConstraint = false,
  InformationCollector? informationCollector,
}) {
  assert(isNormalized);
  return isNormalized;
}
