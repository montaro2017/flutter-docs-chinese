isValid 属性

bool get isValid

此 VerticalCaretMovementRun 是否仍可继续。

底层文本布局未发生变化时，VerticalCaretMovementRun 才有效。

当 isValid 为 false 时，不得访问 current 值以及 movePrevious、moveNext 和 moveByOffset 方法。

实现

bool get isValid {
  if (!_isValid) {
    return false;
  }
  final List<ui.LineMetrics> newLineMetrics = _editable._textPainter.computeLineMetrics();
  // Use the implementation detail of the computeLineMetrics method to figure
  // out if the current text layout has been invalidated.
  if (!identical(newLineMetrics, _lineMetrics)) {
    _isValid = false;
  }
  return _isValid;
}
