向 RenderEditable 提供新的 RenderEditablePainter 时，确定是否需要重新绘制。

如果新实例表示的信息与旧实例不同，此方法应返回 true；否则应返回 false。oldDelegate 为 null 时，除非新的绘制器起初不绘制任何内容，否则此方法应始终返回 true。

如果此方法返回 false，则可能会省略 paint 调用。不过，只要它所附着的 RenderEditable 需要重新绘制，就仍会调用 paint，即使 shouldRepaint 返回 false 也是如此。
