返回从 sliver 前缘可见部分到给定子节点靠近该边缘一侧的距离。

例如，如果 constraints 表示此 sliver 的轴方向为 AxisDirection.down，则此值是从 sliver 可见部分顶部到子节点顶部的距离。相反，如果 constraints 表示轴方向为 AxisDirection.up，则此值是从 sliver 可见部分底部到子节点底部的距离。两种情况下，测量方向都与 SliverConstraints.scrollOffset 和 SliverLogicalParentData.layoutOffset 的递增方向一致。

对于作为 RenderSliver 的子节点，其子节点前缘指子节点可见部分的前缘，而不是该子节点局部滚动偏移量为 0.0 的位置。对于非 RenderSliver 子节点（例如 RenderBox 子节点），返回的是到盒子边缘的实际距离，因为这些盒子无法处理滚动。

此方法与 childScrollOffset 不同：childMainAxisPosition 返回距离 sliver 前缘可见部分的距离，而 childScrollOffset 返回距离 sliver 零滚动偏移量的距离。

对不可见的子节点调用此方法无效。

实现

@override
double childMainAxisPosition(RenderSliver child) {
  final childParentData = child.parentData! as SliverPhysicalParentData;
  return switch (applyGrowthDirectionToAxisDirection(
    child.constraints.axisDirection,
    child.constraints.growthDirection,
  )) {
    AxisDirection.down => childParentData.paintOffset.dy,
    AxisDirection.right => childParentData.paintOffset.dx,
    AxisDirection.up =>
      geometry!.paintExtent - child.geometry!.paintExtent - childParentData.paintOffset.dy,
    AxisDirection.left =>
      geometry!.paintExtent - child.geometry!.paintExtent - childParentData.paintOffset.dx,
  };
}
