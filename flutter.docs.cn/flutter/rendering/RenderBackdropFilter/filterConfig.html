filterConfig 属性

ImageFilterConfig get filterConfig

应用于现有绘制内容的图像滤镜配置。

例如，可以使用 ImageFilterConfig.blur 创建背景模糊效果。

filterConfig 属性等同于 filter（通过 ImageFilterConfig.new 构造函数实现），但 ImageFilterConfig 独有的功能除外（例如 ImageFilterConfig.blur 中的 bounds 参数）。

赋予新的 filterConfig 会覆盖通过 filter setter 赋值的任何现有滤镜。

实现

ImageFilterConfig get filterConfig => _filterConfig;
set filterConfig (ImageFilterConfig value)

实现

set filterConfig(ImageFilterConfig value) {
  if (_filterConfig == value) {
    return;
  }
  _filterConfig = value;
  markNeedsPaint();
}
