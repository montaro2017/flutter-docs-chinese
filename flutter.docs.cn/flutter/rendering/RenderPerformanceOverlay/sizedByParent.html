sizedByParent 属性

  1. @重写
bool get sizedByParent
重写

尺寸计算算法的输入是否只有约束（尤其是不受子节点影响）。

返回 false 始终是正确的；但如果返回 true，计算此渲染对象的尺寸可能更高效，因为约束未发生变化时无需重新计算尺寸。

子类通常始终返回相同的值。如果此值可能变化，则每当它发生变化时，子类都应确保调用 markNeedsLayoutForSizedByParentChange。

返回 true 的子类不得在 performLayout 中更改此渲染对象的尺寸。此工作应由 performResize 执行；对于 RenderBox 子类，也可以在 RenderBox.computeDryLayout 中执行。

实现

@override
bool get sizedByParent => true;
