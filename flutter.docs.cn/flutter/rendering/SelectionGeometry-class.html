SelectionGeometry 类

当前选区的几何信息。

其中包括选区起点和终点的位置、行高、包围选区的矩形等详情。移动平台使用这些信息绘制选区控件。

几何信息中的位置使用 SelectionHandler 或 Selectable 的局部坐标。
