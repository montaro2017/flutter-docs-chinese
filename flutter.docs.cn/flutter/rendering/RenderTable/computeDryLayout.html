重写

计算 getDryLayout 的返回值。请勿直接调用此函数，而应调用 getDryLayout。

如果子类实现了 performLayout 或 performResize，或者将 sizedByParent 设为 true 但没有重写 performResize，则应重写此方法。此方法应返回在给定 BoxConstraints 下此 RenderBox 希望获得的 Size。

此方法返回的尺寸必须与 RenderBox 在 performLayout（如果 sizedByParent 为 true，则在 performResize）中为自身计算出的 size 相匹配。

如果此算法依赖子项的尺寸，应通过该子项的 getDryLayout 方法获取尺寸。

之所以称为“干”布局，以区别于 performLayout 执行的常规“湿”布局，是因为它会在不更改任何内部状态的情况下，根据给定约束计算期望尺寸。

无法确定尺寸时

有些情况下，渲染对象没有高效的方法来计算自身尺寸。例如，尺寸可能由某个回调计算得出，而渲染对象无法据此推导尺寸。

在这种情况下，可能无法（或至少不切实际地）返回有效结果。此时，函数应在 assert 中调用 debugCannotComputeDryLayout，并返回一个占位值 const Size(0, 0)。

实现

@override
@protected
Size computeDryLayout(covariant BoxConstraints constraints) {
  if (rows * columns == 0) {
    return constraints.constrain(Size.zero);
  }
  final List<double> widths = _computeColumnWidths(constraints);
  final double tableWidth = widths.fold(0.0, (double a, double b) => a + b);
  var rowTop = 0.0;
  for (var y = 0; y < rows; y += 1) {
    var rowHeight = 0.0;
    for (var x = 0; x < columns; x += 1) {
      final int xy = x + y * columns;
      final RenderBox? child = _children[xy];
      if (child != null) {
        final childParentData = child.parentData! as TableCellParentData;
        switch (childParentData.verticalAlignment ?? defaultVerticalAlignment) {
          case TableCellVerticalAlignment.baseline:
            assert(
              debugCannotComputeDryLayout(
                reason:
                    'TableCellVerticalAlignment.baseline requires a full layout for baseline metrics to be available.',
              ),
            );
            return Size.zero;
          case TableCellVerticalAlignment.top:
          case TableCellVerticalAlignment.middle:
          case TableCellVerticalAlignment.bottom:
          case TableCellVerticalAlignment.intrinsicHeight:
            final Size childSize = child.getDryLayout(BoxConstraints.tightFor(width: widths[x]));
            rowHeight = math.max(rowHeight, childSize.height);
          case TableCellVerticalAlignment.fill:
            break;
        }
      }
    }
    rowTop += rowHeight;
  }
  return constraints.constrain(Size(tableWidth, rowTop));
}
