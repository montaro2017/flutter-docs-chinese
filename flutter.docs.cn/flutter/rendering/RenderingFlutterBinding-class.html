RenderingFlutterBinding
description

RenderingFlutterBinding 类

供直接使用渲染框架的应用使用的具体绑定实现。这是将框架与 Flutter 引擎连接起来的桥梁。

直接使用渲染框架时，必须使用此绑定，或使用实现相同接口的绑定。以下混入用于实现此绑定：

  • GestureBinding，实现命中测试的基本功能。
  • SchedulerBinding，引入帧的概念。
  • ServicesBinding，提供对插件子系统的访问。
  • SemanticsBinding，支持无障碍功能。
  • PaintingBinding，支持解码图像。
  • RendererBinding，负责处理渲染树。

只有直接编写渲染层代码时才需要使用此绑定。若编写更高层的库，例如 Flutter Widgets 库，则应使用该层的绑定（参见 WidgetsFlutterBinding）。

RenderingFlutterBinding 可以管理多个渲染树。每棵渲染树都以一个 RenderView 为根；必须通过 addRenderView 将其添加到 binding，才能在生成帧、命中测试等过程中纳入考虑。此外，渲染树必须由一个 PipelineOwner 管理，并且该 PipelineOwner 必须属于以 rootPipelineOwner 为根的 PipelineOwner 树。

按照上述方式将 PipelineOwner 和 RenderView 添加到此 binding，是更高层抽象的职责。此 binding 本身不直接拥有任何 RenderView。
