performLayout 方法

  1. @重写
void performLayout()
重写

执行此渲染对象的布局计算。

不要直接调用此函数，应改为调用 layout。只有在布局期间此渲染对象确实需要执行工作时，layout 才会调用此函数。父对象提供的布局约束可通过 constraints getter 获取。

如果 sizedByParent 为 true，此函数不应更改此渲染对象的尺寸；应由 performResize 完成该工作。如果 sizedByParent 为 false，此函数则应同时更改此渲染对象的尺寸，并指示其子对象执行布局。

实现此函数时，必须对每个子对象调用 layout。如果布局信息依赖子对象的布局信息，则将 parentUsesSize 设为 true。这样可确保子对象重新布局时，此渲染对象也会重新布局；否则，子对象可以在不通知此渲染对象的情况下更改其布局信息。

某些特殊的 RenderObject 子类（例如 OverlayPortal.overlayChildLayoutBuilder 使用的子类）会在其 performLayout 实现中调用 applyPaintTransform。为了确保此类 RenderObject 获得最新的绘制变换，RenderObject 子类通常应在此方法中更新绘制变换（即 applyPaintTransform 所报告的变换），而不是在 paint 中更新。

实现

@override
void performLayout() {
  final BoxConstraints constraints = this.constraints;
  if (child != null) {
    child!.layout(_additionalConstraints.enforce(constraints), parentUsesSize: true);
    size = child!.size;
  } else {
    size = _additionalConstraints.enforce(constraints).constrain(Size.zero);
  }
}
