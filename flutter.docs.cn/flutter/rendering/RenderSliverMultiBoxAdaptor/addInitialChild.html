布局期间调用，以创建并添加具有给定索引和滚动偏移量的子节点。

必要时会调用 RenderSliverBoxChildManager.createChild 来实际创建并添加子节点。也可能从缓存中获取该子节点；请参阅 SliverMultiBoxAdaptorParentData.keepAlive。

如果没有缓存的子节点，且 createChild 未添加任何子节点，则返回 false；否则返回 true。

此方法不会对新子节点执行布局。

调用此方法时没有可见的子节点，因此调用 createChild 期间不能移除任何子节点。该调用也不应添加其他子节点，只有由 createChild 创建并返回的子节点例外。

实现

@protected
bool addInitialChild({int index = 0, double layoutOffset = 0.0}) {
  assert(_debugAssertChildListLocked());
  assert(firstChild == null);
  _createOrObtainChild(index, after: null);
  if (firstChild != null) {
    assert(firstChild == lastChild);
    assert(indexOf(firstChild!) == index);
    final firstChildParentData = firstChild!.parentData! as SliverMultiBoxAdaptorParentData;
    firstChildParentData.layoutOffset = layoutOffset;
    return true;
  }
  childManager.setDidUnderflow(true);
  return false;
}
