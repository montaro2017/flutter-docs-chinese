automaticSystemUiAdjustment 属性

bool automaticSystemUiAdjustment
getter/setter 对

是否由 Flutter 自动计算所需的系统界面样式。

启用此设置后，Flutter 会在每一帧中对屏幕顶部和底部的图层树执行命中测试，查找带有 AnnotatedRegionLayer 且包含 SystemUiOverlayStyle 实例的图层。屏幕顶部的命中测试结果用于确定状态栏设置，底部的结果用于确定系统导航栏设置。

如果底部没有 AnnotatedRegionLayer，则使用屏幕顶部的命中测试结果确定系统导航栏设置。如果顶部没有 AnnotatedRegionLayer，则使用底部的命中测试结果确定系统状态栏设置。

将此项设为 false 不会重置先前的自动调整；将其设为 true 也不会立即使应用更新。

如果要以命令方式设置系统界面样式，建议将 automaticSystemUiAdjustment 设为 false。

另请参阅：

  • AnnotatedRegion, for placing SystemUiOverlayStyle in the layer tree.
  • SystemChrome.setSystemUIOverlayStyle, for imperatively setting the system ui style.

实现

bool automaticSystemUiAdjustment = true;
