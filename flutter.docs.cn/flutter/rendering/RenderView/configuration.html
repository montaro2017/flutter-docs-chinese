configuration 属性

ViewConfiguration get configuration

根布局使用的约束。

通常由 RendererBinding 在 RenderView 注册到它时设置此配置；必要时它也会更新配置。因此，如果与 RendererBinding 配合使用，就不得手动设置此属性，因为 RendererBinding 会覆盖该值。

如果测试需要更改视图尺寸，应在相应的 TestFlutterView（通常为 WidgetTester.view）上设置 TestFlutterView.physicalSize，而不是直接在 RenderView 上设置配置。

调用 prepareInitialFrame 之前，必须直接设置 configuration，或在构造函数中传入配置。

set configuration(ViewConfiguration value) {
  if (_configuration == value) {
    return;
  }
  final ViewConfiguration? oldConfiguration = _configuration;
  _configuration = value;
  if (_rootTransform == null) {
    // [prepareInitialFrame] has not been called yet, nothing more to do for now.
    return;
  }
  if (oldConfiguration == null || configuration.shouldUpdateMatrix(oldConfiguration)) {
    replaceRootLayer(_updateMatricesAndCreateNewRootLayer());
  }
  assert(_rootTransform != null);
  markNeedsLayout();
}
