hitTest 方法

bool hitTest(
  1. HitTestResult result, {

确定给定位置上有哪些渲染对象。

如果给定点位于此渲染对象或其某个后代中，则返回 true。并将包含该点的渲染对象添加到给定的命中测试结果中。

position 参数使用渲染视图的坐标系，也就是逻辑像素坐标。这不一定与根 Layer 使用的坐标系相同，后者通常使用物理像素（设备像素）。

实现

bool hitTest(HitTestResult result, {required Offset position}) {
  child?.hitTest(BoxHitTestResult.wrap(result), position: position);
  result.add(HitTestEntry(this));
  return true;
}
