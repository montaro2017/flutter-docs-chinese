连接到 Flutter 应用。

如果应用当前已暂停（例如停在断点处），则恢复应用运行。

dartVmServiceUrl 参数是 Dart VM service 的 URL。如果未指定，则使用 VM_SERVICE_URL 环境变量指定的 URL。两者必须指定其一。

printCommunication 参数决定是否将测试与应用之间的命令通信打印到标准输出。

logCommunicationToFile 参数决定是否将测试与应用之间的命令通信记录到 flutter_driver_commands.log。

isolateNumber 参数指定要连接的 isolate。如果设为 null，则连接到 dartVmServiceUrl 上找到的第一个正在运行的 isolate。

fuchsiaModuleTarget 参数指定用于确定要控制哪个模块的模式。在 Fuchsia 设备上运行时，必须设置此参数或 FUCHSIA_MODULE_TARGET 环境变量（环境变量会按子字符串模式处理）。如果已设置 isolateNumber，则会忽略此字段，因为该信息已足以连接到 isolate。在非 Fuchsia 设备上会忽略此参数。

headers 参数可选，用于指定要包含在 WebSocket 连接中的 HTTP 标头。此参数仅用于 VMServiceFlutterDriver 连接。

返回值是一个 future。此方法不会超时，但可能失败并以错误完成。如有需要，调用方可以使用 Future.timeout 设置超时时间。

实现

static Future<FlutterDriver> connect({
  String? dartVmServiceUrl,
  bool printCommunication = false,
  bool logCommunicationToFile = true,
  int? isolateNumber,
  Pattern? fuchsiaModuleTarget,
  Duration? timeout,
  Map<String, dynamic>? headers,
}) async {
  if (Platform.environment['FLUTTER_WEB_TEST'] != null) {
    return WebFlutterDriver.connectWeb(
      hostUrl: dartVmServiceUrl,
      timeout: timeout,
      printCommunication: printCommunication,
      logCommunicationToFile: logCommunicationToFile,
    );
  }
  return VMServiceFlutterDriver.connect(
    dartVmServiceUrl: dartVmServiceUrl,
    printCommunication: printCommunication,
    logCommunicationToFile: logCommunicationToFile,
    isolateNumber: isolateNumber,
    fuchsiaModuleTarget: fuchsiaModuleTarget,
    headers: headers,
  );
}
