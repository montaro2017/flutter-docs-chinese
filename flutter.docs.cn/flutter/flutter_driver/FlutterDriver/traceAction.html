Future<Timeline> traceAction(
  1. Future action(), {
  2. List<TimelineStream> streams = const <TimelineStream>[TimelineStream.all],
  3. bool retainPriorEvents = false,
})

运行 action 并输出其性能跟踪信息。

等待 action 返回的 Future 完成后，再停止跟踪。

此方法只是对 startTracing 和 stopTracingAndDownloadTimeline 的便捷封装。

streams 将记录的时间线事件流限制为所列出的流。默认情况下会记录所有流。

如果 retainPriorEvents 为 true，则保留调用 action 之前记录的事件；否则，在调用 action 前清除先前事件。默认情况下会清除先前事件。

如果在 debug 模式下运行此方法，会打印警告，建议改为在 profile 模式下运行基准测试。

对于 WebFlutterDriver，此功能仅支持 Chrome。
