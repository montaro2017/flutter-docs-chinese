重复通过 scroll 按 dxScroll 和 dyScroll 滚动由 scrollable 定位的 widget，直到 item 可见；随后调用 scrollIntoView，确保该项最终位置符合 alignment。

scrollable 必须定位到包含 item 的可滚动 widget。通常使用 find.byType('ListView') 或 find.byType('CustomScrollView')。

dxScroll 和 dyScroll 至少有一个必须非零。

如果 item 位于当前可见项下方，应为 dyScroll 指定一个足够小的负值，以便显示 item，同时避免将其向上滚动并完全移出视野。如果 item 位于上方，则为 dyScroll 指定正值。

如果 item 位于当前可见项右侧，应为 dxScroll 指定一个足够小的负值，以便显示 item，同时避免将其滚动并完全移出视野。如果 item 位于左侧，则为 dyScroll 指定正值。

timeout 的值应足够长，以容纳将某项滚动到可见位置所需的所有滚动操作。默认情况下不设置超时时间。

实现

Future<void> scrollUntilVisible(
  SerializableFinder scrollable,
  SerializableFinder item, {
  double alignment = 0.0,
  double dxScroll = 0.0,
  double dyScroll = 0.0,
  Duration? timeout,
}) async {
  assert(dxScroll != 0.0 || dyScroll != 0.0);

  // Kick off an (unawaited) waitFor that will complete when the item we're
  // looking for finally scrolls onscreen. We add an initial pause to give it
  // the chance to complete if the item is already onscreen; if not, scroll
  // repeatedly until we either find the item or time out.
  var isVisible = false;
  Object? waitForError;
  StackTrace? waitForStack;
  // ignore: unawaited_futures
  waitFor(item, timeout: timeout).then<void>(
    (_) {
      isVisible = true;
    },
    onError: (Object error, StackTrace stack) {
      waitForError = error;
      waitForStack = stack;
    },
  );

  await Future<void>.delayed(const Duration(milliseconds: 500));
  while (!isVisible && waitForError == null) {
    await scroll(scrollable, dxScroll, dyScroll, const Duration(milliseconds: 100));
    await Future<void>.delayed(const Duration(milliseconds: 500));
  }
  if (waitForError != null) {
    Error.throwWithStackTrace(waitForError!, waitForStack!);
  }

  return scrollIntoView(item, alignment: alignment);
}
