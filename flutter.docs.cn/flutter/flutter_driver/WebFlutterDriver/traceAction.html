重写

运行 action，并为其输出性能跟踪。

在停止跟踪之前，等待 action 返回的 Future 完成。

这只是对 startTracing 和 stopTracingAndDownloadTimeline 的便捷封装。

streams 将记录的时间线事件流限制为所列出的流。默认情况下会记录所有流。

如果 retainPriorEvents 为 true，则保留调用 action 之前记录的事件；否则会在调用 action 前清除之前的事件。默认情况下会清除之前的事件。

如果在调试模式下运行，将打印警告，建议改用 profile 模式运行基准测试。

对于 WebFlutterDriver，此功能仅支持 Chrome。

实现

@override
Future<Timeline> traceAction(
  Future<dynamic> Function() action, {
  List<TimelineStream> streams = const <TimelineStream>[TimelineStream.all],
  bool retainPriorEvents = false,
}) async {
  _checkBrowserSupportsTimeline();
  if (!retainPriorEvents) {
    await clearTimeline();
  }
  await startTracing(streams: streams);
  await action();

  return stopTracingAndDownloadTimeline();
}
