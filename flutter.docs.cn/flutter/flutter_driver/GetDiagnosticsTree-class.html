GetDiagnosticsTree 类

Flutter Driver 命令，用于获取 finder 指定对象的 JSON 序列化 DiagnosticsNode 树。

返回的 DiagnosticsNode 树的 DiagnosticsType 由 diagnosticsType 指定。
