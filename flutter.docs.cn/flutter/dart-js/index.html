dart:js 库

提供与 JavaScript 互操作的底层支持。

注意

通常应使用 dart:js_interop，而不是此库。更多信息请参阅 JS 互操作文档。

此库允许 Dart 访问 JavaScript 对象，以便获取和设置属性、调用 JavaScript 对象的方法以及调用 JavaScript 函数。在可行时，此库会在 Dart 与 JavaScript 对象之间进行转换；无法转换时则提供代理。

此库不会让 Dart 对象可供 JavaScript 使用，其方法和属性无法从 JavaScript 访问。不过，Dart 函数仍可传递给 JavaScript 并由其调用。

JsObject 是核心类型，表示 JavaScript 对象的代理。JsObject 可访问底层 JavaScript 对象的属性和方法。可以通过调用 JavaScript 获取 JsObject，也可以从 JavaScript 构造函数的代理创建它。

顶层 getter context 提供一个表示 JavaScript 全局对象（通常为 window）的 JsObject。

以下示例通过调用 JavaScript 全局函数 alert() 显示警告对话框：

import 'dart:js';

main() => context.callMethod('alert', ['Hello from Dart!']);

此示例展示如何从 JavaScript 构造函数创建 JsObject 并访问其属性：

import 'dart:js';

main() {
  var object = JsObject(context['Object']);
  object['greeting'] = 'Hello';
  object['greet'] = (name) => "${object['greeting']} $name";
  var message = object.callMethod('greet', ['JavaScript']);
  context['console'].callMethod('log', [message]);
}

代理与自动转换

在 JsObject 上设置属性或向 JavaScript 方法、函数传递参数时，Dart 对象会自动转换为 JavaScript 对象或由代理表示。访问 JavaScript 属性时，或者 JavaScript 调用 Dart 闭包时，JavaScript 对象也会转换为 Dart 对象。

函数和闭包会通过可调用的代理进行处理。赋给 JavaScript 属性的 Dart 闭包会被代理为 JavaScript 函数。从 Dart 访问的 JavaScript 函数会被代理为 JsFunction，可通过其 JsFunction.apply 方法调用。

以下类型会直接传输，不会创建代理：

  • 基本类型：null, bool, num, String, DateTime
  • TypedData，包括其子类（如 Int32List, but not ByteBuffer
  • 编译为 Web 时还包括：Blob, Event, ImageData, KeyRange, Node, and Window.

使用 JsObject.jsify() 转换集合

若要从 Dart 集合创建 JavaScript 集合，请使用 JsObject.jsify 构造函数。它会将 Dart Map 和 Iterable 转换为 JavaScript 对象和数组。

以下表达式会创建一个包含属性 a 和 b 的新 JavaScript 对象：

var jsMap = JsObject.jsify({'a': 1, 'b': 2});

以下表达式会创建一个 JavaScript 数组：

var jsArray = JsObject.jsify([1, 2, 3]);
