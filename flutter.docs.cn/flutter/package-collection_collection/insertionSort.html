使用插入排序对列表中从 start（包含）到 end（不包含）的部分进行排序。

如果省略 compare，则默认对对象调用 Comparable.compareTo。此时，对象必须实现 Comparable。

插入排序是一种简单的排序算法。对于 n 个元素，它需要约 n * log(n) 次比较，但移动次数最多可达 n 的平方。排序会原地执行，不使用额外内存。

对于较短的列表，与简单算法相比，大量移动的影响较小，因此插入排序通常是短列表的首选算法。

此插入排序是稳定的：相等元素排序后的顺序与原始顺序相同。

实现

void insertionSort<E>(List<E> elements,
    {int Function(E, E)? compare, int start = 0, int? end}) {
  // If the same method could have both positional and named optional
  // parameters, this should be (list, [start, end], {compare}).
  compare ??= defaultCompare;
  end ??= elements.length;

  for (var pos = start + 1; pos < end; pos++) {
    var min = start;
    var max = pos;
    var element = elements[pos];
    while (min < max) {
      var mid = min + ((max - min) >> 1);
      var comparison = compare(element, elements[mid]);
      if (comparison < 0) {
        max = mid;
      } else {
        min = mid + 1;
      }
    }
    elements.setRange(min + 1, pos + 1, elements, min);
    elements[min] = element;
  }
}
