MapEquality

MapEquality<K, V> 类

映射的相等性比较。

两个映射只有在条目数量相同，且两个映射中成对对应条目的键和值都相等时才相等。

equals 和 hash 方法接受 null 值，即使 isValidKey 对 null 返回 false 也是如此。null 的 hash 值为 null.hashCode。
