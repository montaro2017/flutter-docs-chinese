PriorityQueue

PriorityQueue<E> 类 抽象

优先队列是一种根据优先级排列元素的工作列表。

此队列允许添加元素，并按优先级顺序移除元素。同一个对象可以多次加入队列。对于优先级相同的对象（即 comparison 函数返回零），其顺序未作规定。

涉及对象相等性的操作 contains 和 remove 使用 Object.== 判断相等。在大多数情况下，这与对象标识（identical）相同；但对于 String 等类型，用户通常会合理地认为不同对象可以表示相同的值。如果元素重写了 Object.==，那么 comparison 函数必须始终为相等对象提供相同优先级，否则 contains 或 remove 可能无法正常工作。
