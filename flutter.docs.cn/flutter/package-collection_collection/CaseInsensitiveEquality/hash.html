为多个对象创建组合哈希码。

即使参数为 null，也会计算所有实际传入参数的哈希码，并通过数值组合每个参数的 Object.hashCode 得出结果。

示例：

class SomeObject {
  final Object a, b, c;
  SomeObject(this.a, this.b, this.c);
  bool operator ==(Object other) =>
      other is SomeObject && a == other.a && b == other.b && c == other.c;
  int get hashCode => Object.hash(a, b, c);
}

在同一程序执行期间，如果多次使用相同参数调用此函数，计算结果将保持一致。

此函数生成的哈希值不保证在同一程序的不同运行之间保持稳定，也不保证在同一程序不同 isolate 中运行时保持稳定。具体算法可能因平台或平台库版本而异，也可能取决于每次程序执行时都会变化的值。

如果向 hashAll 函数传入一个按相同顺序包含此函数实际参数的集合，其结果与此函数相同。

实现

@override
int hash(String string) => hashIgnoreAsciiCase(string);
