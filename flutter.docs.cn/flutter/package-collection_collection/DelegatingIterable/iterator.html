iterator

iterator 属性

  1. @重写
Iterator<E> get iterator
继承

一个新的 Iterator，用于遍历此 Iterable 的元素。

可迭代类可以规定元素的迭代顺序，例如 List 始终按索引顺序迭代；也可以不规定顺序，例如基于哈希的 Set 可以按任意顺序迭代。

每次读取 iterator 都会返回一个新迭代器，可用于重新遍历所有元素。同一个可迭代对象的迭代器可以独立推进；只要底层集合没有改变，它们就应按相同顺序返回相同元素。

修改集合可能使新迭代器返回不同的元素，也可能改变现有元素的顺序。List 精确定义了迭代顺序，因此修改列表会以可预测的方式改变该顺序。向基于哈希的 Set 添加新元素时，其迭代顺序可能完全改变。

创建新迭代器后修改底层集合，可能使下一次对该迭代器调用 Iterator.moveNext 时发生错误。任何可修改的可迭代类都应说明哪些操作会破坏迭代。

实现

@override
Iterator<E> get iterator => _base.iterator;
