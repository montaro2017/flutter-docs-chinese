MapKeySet

MapKeySet<E> 类

一种不可修改的 Set 视图，用来查看 Map 的键。

此集合会将所有操作委托给底层映射。

每个 Map 中的键都不重复，因此可以将这些键无损地视为一个 Set，即使 Map.keys getter 只显示键的 Iterable 视图也一样。

请注意，此集合不支持 lookup。
