IterableZip

IterableZip<T> 类

一种可迭代对象，会迭代来自其他可迭代对象的值列表。

读取 iterator 时，会为传递给构造函数的 Iterable 中的每个 Iterable 创建一个 Iterator。

只要所有这些迭代器都有下一个值，就会将这些值组合成一个列表，作为此 Iterable 的 Iterator 的下一个值。一旦任何迭代器没有更多值，组合后的迭代器也会停止。
