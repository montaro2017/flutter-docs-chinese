DelegatingIterable

DelegatingIterable<E> 类

一种 Iterable，会将所有操作委托给基础可迭代对象。

此类可用于隐藏可迭代对象的非 Iterable 方法，也可以通过继承此类，在现有可迭代对象的基础上添加额外功能。
