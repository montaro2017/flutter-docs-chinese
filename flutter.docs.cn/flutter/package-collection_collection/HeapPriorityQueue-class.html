HeapPriorityQueue

HeapPriorityQueue<E> 类

基于堆实现的优先级队列。

元素以堆结构存储，优先级最高的元素可以立即访问；平均而言，修改单个元素所需时间与元素数量的对数成正比。

  • The add 和 removeFirst operations take amortized logarithmic time, O(log(n)), but may occasionally take linear time when growing the capacity of the heap.
  • The addAll operation works as doing repeated add operations.
  • The first getter takes constant time, O(1).
  • The clear 和 removeAll methods also take constant time, O(1).
  • The contains 和 remove operations may need to search the entire queue for the elements, taking O(n) time.
  • The toList operation effectively sorts the elements, taking O(n*log(n)) time.
  • The toUnorderedList operation copies, but does not sort, the elements, and is linear, O(n).
  • The toSet operation effectively adds each element to the new set, taking an expected O(n*log(n)) time.
