HeapPriorityQueue

HeapPriorityQueue<E> 类

基于堆实现的优先级队列。

元素以堆结构存储，优先级最高的元素可以立即访问；平均而言，修改单个元素所需时间与元素数量的对数成正比。

  • add 和 removeFirst 操作的摊还时间复杂度为对数级 O(log(n))，但扩展堆容量时偶尔可能需要线性时间。
  • addAll 操作的实现方式是重复执行 add 操作。
  • first getter 的时间复杂度为常数级 O(1)。
  • clear 和 removeAll 方法的时间复杂度也为常数级 O(1)。
  • contains 和 remove 操作可能需要搜索整个队列来查找元素，时间复杂度为 O(n)。
  • toList 操作实际上会对元素排序，时间复杂度为 O(n*log(n))。
  • toUnorderedList 操作会复制元素但不排序，时间复杂度为线性级 O(n)。
  • toSet 操作实际上会将每个元素添加到新集合中，预期时间复杂度为 O(n*log(n))。
