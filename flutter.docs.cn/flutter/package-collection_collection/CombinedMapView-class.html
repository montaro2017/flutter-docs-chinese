CombinedMapView

CombinedMapView<K, V> 类

返回一个新映射，将多个映射展平并合并为一个映射。

所有方法和访问器都会将新映射视为一个拼接后的映射，但其底层实现会按需访问各个映射实例。如果某个键出现在多个映射中，则返回第一个映射中的值。

生成的映射提供索引运算符（[]），其复杂度为 O(maps)，而不是 O(1)；该映射不可修改，但底层映射的更改仍会反映在生成的映射中。

length getter 的复杂度为 O(M)，其中 M 是所有映射中的条目总数，因为计算长度时需要移除重复条目。
