返回 element 在此已排序列表中应处的索引。

使用二分查找定位 element 应处的位置，比较次数与 log(n) 成正比。列表必须按照元素的 keyOf 自然顺序排序，否则结果未定义。

如果列表中包含 element，则返回其索引；否则返回插入 element 后仍能保持列表有序的第一个位置。如果列表中的所有元素与 element 相比都更小，该位置可能是列表的 length。

如果提供了 start 和 end，则只搜索该范围，而且只需保证该范围已排序。

实现

int lowerBoundBy<K extends Comparable<K>>(E element, K Function(E) keyOf,

    algorithms.lowerBoundBy<E, K>(
        this, keyOf, compareComparable, element, start, end);
