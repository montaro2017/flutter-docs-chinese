posix → Style
POSIX 风格的路径使用 "/"（正斜杠）作为分隔符。绝对路径以 "/" 开头。UNIX、Linux、Mac OS X 等系统使用此风格。
final
url → Style
URL 并非文件系统路径，但此风格也支持 URL，以便在浏览器中更轻松地处理 URL 路径。
final
windows → Style
Windows 路径使用 \（反斜杠）作为分隔符。绝对路径以驱动器号和冒号（例如 C:）开头，或以两个反斜杠（\\）开头，表示 UNC 路径。
