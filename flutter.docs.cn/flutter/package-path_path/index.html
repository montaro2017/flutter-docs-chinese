path

path 库

功能全面、支持跨平台的路径操作库。

此路径库的设计初衷是使用前缀导入，但如果不需要，也可以不加前缀：

import 'package:path/path.dart' as p;

最常见的用法是调用顶层函数。这些函数会根据当前工作目录和宿主平台的路径风格（POSIX、Windows 或 URL）操作路径字符串。例如：

p.join('directory', 'file.txt');

此代码调用顶层 join 函数，使用当前平台的目录分隔符拼接“directory”和“file.txt”。

如果希望无论程序运行在哪个平台，都按指定平台处理路径，可以创建 Context 并为其指定 Style：

var context = p.Context(style: Style.windows);
context.join('directory', 'file.txt');

即使程序运行在 POSIX 机器上，此代码也会使用 Windows 路径分隔符拼接“directory”和“file.txt”。
