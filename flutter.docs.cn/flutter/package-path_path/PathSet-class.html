PathSet

PathSet 类

包含路径的集合，使用 p.equals 和 p.hash 比较元素。

构造函数

PathSet({Context? context})
创建一个空的 PathSet，其内容使用 context.equals 和 context.hash 进行比较。
PathSet.of(Iterable<String> other, {Context? context})
创建一个 PathSet，其内容与 other 相同，且元素使用 context.equals 和 context.hash 进行比较。
