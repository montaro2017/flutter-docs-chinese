# 脚本清理建议（待确认，未删除）

检查范围为 2026-10-20 工作区的 237 个 Python 脚本。通过源码静态检查了同目录导入、子进程脚本名及现有 Markdown/Python 引用；没有执行任何翻译补丁或删除文件。静态检查不能识别仓库外的手动调用、计划任务或字符串动态拼接调用，因此以下是清理候选，不是“已证明永远不会再用”。

## 优先候选：两个历史排查脚本

| 文件 | 当前用途 | 可以考虑删除的理由 | 删除后失去什么 |
| --- | --- | --- | --- |
| [check_archive_case.py](check_archive_case.py) | 只打印 Threshold 构造页与属性页在 ZIP 中的路径、标题。 | 用途非常具体；`verify_case_pages.py` 已包含这两页必须分离、标题类型正确的正式断言。未发现其他脚本调用它。 | 失去这个定点打印入口；正式大小写校验、修复和翻译不依赖它。 |
| [inspect_homepage.py](inspect_homepage.py) | 打印指定页面的纯英文文本片段。 | 属于人工排查辅助工具，不被翻译流程调用；默认读取根目录 `index.html`，当前该文件不存在。新的文本提取及英文残留报告可承担主要排查工作。 | 失去逐个原始文本节点打印的简易方式；新统计的“残留句子候选”与它不完全等价。也可以保留并修正默认路径。 |

## 批量候选：217 个历史译文补丁

| 匹配范围 | 数量 | 功能与建议 |
| --- | ---: | --- |
| `add_*.py` | 214 | 按 API、类或方法补充预先写好的译文。属于历史录入工具，可统一考虑归档或删除。 |
| `complete_curved_labels.py`、`complete_train_batch.py` | 2 | 补齐曲线动画/跳跃切换动画的共享标签与固定正文。和其他历史补丁同类。 |
| `_batch_raw_ios.py` | 1 | 复用 Android 等已有说明，并补齐旧 iOS 原始按键事件译文。历史批次，无自动调用方。 |

217 个文件合计 **389,763 字节，约 381 KiB**。清理主要能减少文件数量和误运行机会，节省磁盘空间很有限。逐个文件及用途见[脚本说明中的历史补丁清单](脚本说明.md)。

判断依据：没有发现这些脚本被其他现存 Python 工具导入或以脚本文件名调用；日常生成与校验直接读取主映射 JSON，并不重新执行补丁。只移除补丁脚本，不会自动删掉映射或已经生成的中文页面。

需要保留的区别：历史补丁仍记录早期译文的录入逻辑，少数脚本包含从原文提取、复用既有译文、替换成员标签等过程；删除后这些录入步骤不能再直接运行。因此在正式删除前，应确认有用译文已保存在现行映射中，并可从 Git 历史找回脚本。这里没有运行旧补丁来验证“能否重新合并”，因为运行它们本身会改写现行译文。

已有过时实例：静态读取 `add_bitfield.py` 的固定译文并与当前 `translations.json` 对照，其涉及的 6 个页面中有 5 页至少一个块已与旧脚本不同。这证明旧补丁不能直接当作当前译文的重建清单；差异本身不表示当前译文有问题。

## 建议保留

| 范围 | 理由 |
| --- | --- |
| `translate_docs.py`、`homepage_translation.py`、`sync_progress_module.py` | 生成中文页面、处理首页及维护进度的直接工具。 |
| `case_paths.py`、`shared_translation.py` | 多个正式工具实际导入的公共模块。 |

| `text_language_stats.py`、`translation_coverage.py`、两个 `test_*.py` | 本次新增的文本统计、树形报告与相关测试；虽不直接翻译，却是已明确需要的功能。 |
| `pending/build_anim_todo.py`、`pending/split_batches.py`、`pending/validate_batch.py`、`pending/merge_batches.py` | 当前本地批次准备、分配、校验和合并工具。目录被忽略不等于脚本已无用；应在确认对应批次不再需要后另行整理。 |

**建议先考虑删除两个定点排查工具，再决定是否统一归档或删除 217 个历史补丁。当前没有删除、移动或重跑任何候选脚本，也没有改动翻译映射与站点页面。**
