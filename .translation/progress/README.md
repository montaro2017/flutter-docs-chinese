# 翻译任务续接入口

## 读取顺序

每次续接只沿下面路径打开文件；不需要把所有进度清单都读一遍：

1. **先读本文件**，按任务范围决定下一步。
2. **只读一个目标索引**：Material 任务读 `material/README.md`；其他 API 库任务读 `libraries/README.md`。
3. **再读一个未完成模块清单**：从目标索引挑选仍有待办的模块；若索引有分组，先打开对应分组文件，再选模块。
4. **只处理清单中列出的未完成页面和段落**。页面完成后同步进度，之后不再读取该页清单；模块完成后索引会移除它。

只查看整体完成度时，读完第 1 步后直接读取 [总体进度](../翻译进度.md)，无需进入模块索引。

## 读取规则

- 只看完成度：读取 [总体进度](../翻译进度.md)。
- 继续 Material：先读 [Material 索引](./material/README.md)，再选一个模块并只读对应的模块清单。
- 继续其他 API 库：先读 [其他库索引](./libraries/README.md)，再读目标库的索引，最后只读选定未完成模块的清单。
- 处理指定页面：直接在对应库的模块清单中查该页面，只查看该页所列待译段落。
- 已完成模块或库：索引和清单会自动移除，无需查阅。

模块清单按页面列出尚未翻译的正文段落编号（从 0 开始）。完成翻译后，保留链接、代码和锚点，运行校验，再同步对应模块：

```powershell
python -X utf8 .translation\sync_progress_module.py material/ActionChip.md
```

同步后模块索引只保留仍未完成的项目；具体页与段落只保存在未完成模块清单中。
