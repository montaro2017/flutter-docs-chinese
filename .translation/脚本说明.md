# 翻译脚本说明

本清单记录 2026-10-20 工作区中的 237 个 Python 脚本：20 个工具和测试、217 个历史翻译补丁。范围包括被 Git 忽略的 `pending/` 中现存脚本；文档站自带的 JavaScript 静态资源不属于本清单。

以下路径均相对于 `.translation/`。命令在仓库根目录执行，使用 `python -X utf8 .translation/脚本名.py`；公共模块由其他程序导入，无需单独执行。运行翻译、复制或校验前，先按 [progress/README.md](progress/README.md) 的指引读取任务范围。
