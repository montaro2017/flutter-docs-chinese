# Flutter API 中文文档

本仓库是 Flutter API 文档的中文翻译版本。中文翻译由 OpenAI Codex 协助完成，使用模型 **GPT-6.1-sol**（GPT-6 系列）；当前仍在持续翻译和校对中。实际进度见 [翻译进度](.translation/翻译进度.md)。

## 浏览文档

打开 [`flutter.docs.cn/index.html`](flutter.docs.cn/index.html) 即可浏览离线文档。

## 目录说明

- `flutter.docs.cn/`：中文文档站点。
- `flutter.docs/`：原始英文文档来源，不纳入 Git。
- `.translation/`：翻译映射、工具和续接进度。
